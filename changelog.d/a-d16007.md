## Type system (Track A)

- **D16007 closed: a negated `is` guard over an un-annotated parameter runs.** `if !(p is A) { p.y } else { p.x }` registers `A` as the alternative its `else` arm takes, as the positive guard does for its `then` arm, so `A | B` meets the demand member by member; and a pin that makes the negated test always false skips its `then` arm.
