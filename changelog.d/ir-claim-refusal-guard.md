## Infrastructure (Track F)

- **An IR claim no longer turns a loud refusal into invalid wasm:** a claimed unit skips legacy's lowering, and with it any refusal legacy raises there, so the claim could write a module that fails validation (D17095, D17096). The native host now rebuilds such a unit with claims off. Legacy's refusal is the answer (rc 1, with a note naming the claim). Where legacy builds the program, a normal build ships legacy's bytes with one stderr line, and under `$VL_IR_STRICT=1`, which the gate, CI, `ir-identity.sh` and `ir-parity.vl` set, it fails with rc 70. The gate row `ir claim refusals` (`ir-parity.vl --pop refusals`) holds every program legacy refuses at emit to the same refusal with claims on. `$VL_FAULT_INJECT_CLAIMED` corrupts the claimed module only, as the fallback's control.
