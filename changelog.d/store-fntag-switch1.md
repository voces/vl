## Type system (Track A)

- **One storage decider, first class switched:** the check's tag decision (`fnTagDecide`) now also tries the function sets its own set-binding rows find a call through (`setBindTrySets`). It leaves to the decision after the elaboration a set an instance may bind otherwise: one with a generic member, one reaching a stored parameter, one handed to or by a set's members, and a partial one. Over 6,513 `@run` programs, programs whose decision the late pass still changes fall from 415 to 353, no late pass drops a new check tag, and no program's wasm or output moves.
