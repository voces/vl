## Codegen, memory & runtime (Track B)

- **A list of a never-filled `let x = null` is the `[null]` list:** un-annotated, `[x]`, `[x = null]` and `[x, x]` are refused at check time as `[null]` is ("annotate the list or the binding"), instead of an invalid module or, after a closure wrote `x`, a list printing `2` for `null`; under a `null[]` destination (a typed binding, a `null[]` parameter, an index store) they run (D17304).
