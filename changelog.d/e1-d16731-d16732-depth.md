## Type system (Track A)

- **D16731, D16732 closed:** records holding un-annotated functions of different results run nested to any depth: a list literal, a value `if`, a rewritten `let`, a push and a returned list. The walks deciding the set's rep take no depth budget; a type walk stops at a type it has met, a literal walk follows the literal. The returned spelling built invalid wasm at five and six levels.
- **D16740, D16741 closed (clause 1):** a deep literal's leaf is built at its destination's rep at any depth: a `null` beside a value seven records down, and an `i64` literal five records down in a list, no longer build invalid wasm.
- A field read through records whose type names a type variable no longer costs time exponential in the depth (sixteen levels: 13.6 s to 0.04 s).
