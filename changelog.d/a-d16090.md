## Type system (Track A)

- **D16090 closed:** a re-pointed `let` of un-annotated lambdas whose results differ dispatches at a call through it, as declared functions already did: `let f = (a) => a + 1; if c { f = (_a) => "s" }; print(f(3))` prints `s`, and the result is the members' join (`i32 | string`). Still refused: a call through the binding before the lambda's write, the binding returned or handed on (D16096), and a capturing member (D16095).
