## Codegen, memory & runtime (Track B)

- **D16013 closed:** a list literal's closure, nested-list or nullable element row is keyed by its element type normalized as the element's name would be (`storageNormTy`), not by re-parsing the rendered name. The normalizer is one type-to-type function: literal leaves widen to base (string literals inside a union and litunion aliases outside a parameter stay), a one-member union is its member, and a function or list is rebuilt fresh. Identity on the corpus.
