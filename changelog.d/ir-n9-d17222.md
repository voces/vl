## Codegen, memory & runtime (Track B)

- **A captured never-filled `let x = null` takes writes of `null`:** a closure's read of the binding after a statement `x = null` in its frame now builds, instead of an invalid module (D17222), and a write used as a value (`print(x = null)`, `() => x = null`) yields `null` instead of the "assignment used as a value" refusal (D17221).
