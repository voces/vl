## Infrastructure (Track F)

- **`$VL_OPAQUE_SNAMES=1` labels every interned shape row `#rowN`, a measuring instrument for the D6 interner re-key (step 7).** A pass that decides on a row's label rather than its type moves the program. Unset, every program builds the same bytes. Armed, 410 programs move. 178 of them name one reader: a nested-struct field's element type is recorded from its row's name.
