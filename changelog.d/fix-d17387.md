## Codegen, memory & runtime (Track B)

- **A generic join of two list literals is right in an instance binding two number types** (D17387, clause 1, silently wrong). `if k { [a] } else { [b] }` in `w<A, B>`, called as `w(1.5, 2, false)`, printed `.length` 0 and trapped on `[0]`, and its annotated or returned spelling was invalid wasm at `(i32, f64)`. The instance's re-check now keeps the two lists apart as the instance's type of the `if` does, and a literal's union arm reads the instance's type, so each arm is built and tagged at its own list. The IR claims these functions too (two `array element coercion` rows cleared).
