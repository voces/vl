## Codegen, memory & runtime (Track B)

- **A list literal's rendered record element is keyed by its row type:** `arrLitElemKeyTy`'s nominal rung answered `cUserTypes[name]`, which is -1 for the render of an anonymous record (`{r:i32}`), so the intern re-parsed the name. It now passes the row type the name was rendered from (`arrLitNominalRowTy`, through `rlKeyTyOf`). Identity on the corpus.
