## Type system (Track A)

- **D16991 closed:** an empty `Map()` or `Set()` handed to a generic passes the first `is K` arm that tests it, as an empty list does, and is built as a `K`; it answered by the hole default's type (`{[string]: i32}`), so `is {[i32]: f64}` was false. Arms that only test never clash, and an arm that writes decides over them.
