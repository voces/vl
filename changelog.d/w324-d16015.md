## Codegen, memory & runtime (Track B)

- **D16015 closed:** an element or field write used as a value now runs in every position — an operand, a call argument, a module-level initializer — by yielding the cell its store parks, with siblings evaluated in source order. The refusal left names its case: a value typed apart from its target (D16016), a map entry (D16017), a byte-list element (D16018).
