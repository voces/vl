## Codegen, memory & runtime (Track B)

- **D16015 closed:** an element or field write used as a value now runs in every position — an operand, a call argument, a module-level initializer — by yielding the cell its store parks, with siblings evaluated in source order. The refusal left names its case: a value typed apart from its target (D16016), a map entry (D16017).
- **D16018 closed:** a byte-list element write used as a value yields its right-hand side, as DECISIONS rules, not the stored low byte: `print(b[1] = x)` with `x` 300 printed `44`, a wrong value, and now prints `300`.
