## Type system (Track A)

- **D15805, the record-in-record spelling:** a record nested in records, whose function field holds un-annotated functions returning different types, runs a call through the field whichever arm or return built it: two and three levels, the inner record bound out, returned, a nested field written, and beside other fields (the record matrix's `nested`, `nested_deep`, `nested_returned`). The judge lifts any path of fields as it lifts one. A record nested in a list's element stays refused: lifted, it builds an invalid module (D15805's witness).
