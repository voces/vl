## Testing

- **A test whose child died by a signal is a harness error, not a pass, and an OOM kill fails the gate.** Every `deno test` the gate, CI and `deno task test` run preloads `tests/support/signal_guard.ts`: a `Deno.Command` child killed by a signal, or exiting 128 or more, throws `harness error: … killed by SIGKILL`, so an expect-failure case can no longer read the OOM killer as the failure it wanted. `scripts/gate.sh` reads the kernel's OOM-kill count (`/proc/vmstat`, the cgroup's `memory.events`) at the start and end of a run and fails the run on a rise, whatever the rows read; a row that died by signal says so. `tests/ci_signal_guard_test.ts` runs a SIGKILLed expect-failure fixture with and without the guard, checks every `deno test` carries it, and pins the counter.
