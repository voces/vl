## Codegen, memory & runtime (Track B)

- **IR coverage: a null test of a `null`-typed field on a callback parameter or a closure's `let`, byte-identical to legacy.** A read whose variable is held at a record row its type does not record (a rowless record, or a record stored at another row) reads that row's field, so `(y) => y.f == null` over a list stored at a wider record is built. The read-and-drop is now a value (`RDeadNullTest`) that stands in the test's place, as legacy's `emitDeadNullTest` writes it, so a test after a constant field (`{ n: 2, s: [y.f == null] }`) keeps legacy's order. `null test nullty operand` falls to 1 tests/cases function (behind a capture binding).
