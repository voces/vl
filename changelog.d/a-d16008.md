## Type system (Track A)

- **D16008 closed:** the `else` arm of a record `is` test over an un-annotated parameter reads the pin minus the record, so `function F(h) { if h is A { print(h.v) } else { print(h) } }` with `h: A | i32` prints `5`; a field read in the arm still demands its field of the argument.
