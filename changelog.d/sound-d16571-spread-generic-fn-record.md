## Codegen, memory & runtime (Track B)

- **D16571 closed:** a list literal holding a record of a generic function name, spread into a push in a generic body (`rs.push(...[{ f: id }])` onto `{f: (x: T) => T}[]`), passed the check and built an invalid module at its second instance; it now runs at each instance. The literal every instance shares is typed only by the body's own check, and its elements are delivered at the list's element per instance. A body that also pushed directly, or called the field, trapped; both run. **D16572 closed** by the same delivery: a bare `...[id]`, an un-annotated list, and a spread initialiser (`= [...[id]]`) run. Filed D16695 (the spread binding `const src = [id]` still traps), D16696 (`rs.push({ n: 1 }, ...[{ n: 2 }])` is refused at emit), D16697 (a closed function element refuses the spread at the second call).
