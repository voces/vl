## Type system (Track A)

- **D16688 closed:** a refused map key type reports once. An index of the refused map no longer adds `array index must be i32, got {…}`; a parameter or return annotation over such a key names the key, as a binding does, where it said `unknown type '{[boolean]:i32}'`; and the sentence reads `An f64-keyed Map` where it said `A f64-keyed`.
