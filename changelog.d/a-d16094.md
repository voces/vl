## Type system (Track A)

- **D16094 narrowed:** a choice of un-annotated functions whose results differ, handed to an open parameter, dispatches in the callee's instance, as a re-pointed `let` handed on does (D16009). This covers an `if`, a function returning either, two `return`s, and a binding of one. `print(ap(if c { str } else { inc }, 3))` prints `s`, and D13740's witness prints `3`. A choice whose set the decision leaves untagged, because a closed function type also reads it, is refused by the second check with today's message. A `let` returned and then handed on is still refused (D16094).
