## Testing

- **`tests/ir_lists_layout_test.ts` keeps the IR kind lists one member per line.** It names any packed line: an or-pattern arm of four or more IR kinds in `ir.vl`, `ir_verify.vl` or `ir_lower.vl`, a packed continuation line of the `Rhs`/`IrNode` unions, or a packed `compiler/lint.vl` closed set mirrored from `ir.vl`. `vl fmt` keeps the one-per-line layout but cannot restore it, so a branch that merged master while keeping its own packed line reintroduced the conflict #9380 removed. A control case pins the detector; on a pre-fix branch commit it names 23 lines. `format-notes.md` now says to refresh the seed before `vl fmt -w` after merging master: a seed from before #9380 rejoins the lists.
