## Type system (Track A)

- **D16997 closed:** a list narrowed by `is K[]` is no longer handed on as `K[]` through an alias (`const r = q`), an `if`/`match` arm, an inferred return or an un-annotated record or list literal, where a later write through the original could put a non-`K` in a `K[]`. An alias or inferred return reads it at its declared type; an arm or literal member is refused with the copy. Per the owner ruling of 2026-11-19.
