## Codegen, memory & runtime (Track B)

- **Step 7 L2, mono: whether an annotation can pin an instance is answered by its type.** `monoAnnPinName(name, ty)` was a ladder over the pin's spelling (`isSName`, `arrElemNameRaw`, `variantIndexOf`, the span tests, a scalar-name list, `isUName*AB` by name). It is now `monoAnnPinOkTy(ty)`, an exhaustive match over the type: a keyed union or a list of one, a record with a struct, variant or inline row, a list of records, scalars or composites, a bare map, a scalar with a value rep, or a nullable of any of these. The name is only echoed. The four callers that passed no type now pass one: the narrowed nominal record, the `for` walk record and the variant rows (`uVarTyIx`). `monoStructAnnName`, `monoScalarAnnName`, `monoCompositeListAnnName` and `monoNulAnnName` are deleted; `emit_mono.vl`'s spelling reads 42 → 15.
