## Type system (Track A)

- **D15926:** a module `const` or `let` copy of a member of a function set, called, runs beside a returned list of records whose function field holds functions of different results: the copy is a direct call, so the set is tagged, and the copy holds the member's id. It was refused by D15926's floor, and before that built an invalid module. A called bound list of a member stays refused (D15928).
