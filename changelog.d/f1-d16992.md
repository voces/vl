## Codegen, memory & runtime (Track B)

- **D16992 closed:** compile cost no longer grows super-linearly in the number of generics instanced once each. Four per-instance passes walked the whole program: `instAllocsOf`'s frame scan, the generic-alias annotation lookups, `monoDeclIsAssigned`'s assignment scan, and `fnStmtsIndexOf`'s index, which every slot write dropped. Each now does only its own work. 1600 such generics build at 1.14G guest fuel (was 4.54G), and a compile of 800 takes 32% less CPU; the `generic first instances` scaling axis reads 1.82 (was 2.53), and its bar is back to 2.5.
