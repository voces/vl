## Type system (Track A)

- **Fixed D17445** (clause 1): a generic call that left a type parameter unbound (only `null` reaching `T | null`, or a union's concrete member taking the argument) typed its result with the raw parameter, while its instance bound it to `never`; `wrap(null, false).x ?? -1` built invalid wasm, and `??`, `.length`, `is` and arm reads over such results were emit refusals. The result now reads the parameter as `never` and drops the members that empties (`T | null` is `null`, `T | i32` is `i32`). A write into a `never` slot of the result is a check refusal. Filed D17446 (a generic's record field or list element join drops a concrete arm) and D17447 (a list of a `null` unit builds invalid wasm).
