## Codegen, memory & runtime (Track B)

- **IR coverage: a closure read across closure openness.** A hole lambda's cell read where one closure type leaves a parameter or result open and the other closes it missed at `narrowed read`, `global read coercion`, `capture binding` or an if arm. An example is `const c = (y) => y + "C"; const fs = [c]`. Every closure lowers to the one closure struct, so the read is now the cell retagged, by `cloHoleRetag`. tests/cases `narrowed read` went from 68 functions to 37, `global read coercion` from 65 to 48 and `capture binding` from 74 to 56, and a new tests/cases program calls through each retagged form.
