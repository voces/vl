## Type system (Track A)

- **D16099 closed:** a call's result holding an un-annotated function, handed straight to a generic `(x: T) => R` parameter, runs. `app(pick1(true), 3)` prints `4`, where `pick1` returns `inc`. The same holds for a returned choice of functions that agree. Before, it was refused at emit, and the call's result was left open, so `const q: boolean = app(pick1(true), 3)` passed check. It is now `i32` and refused there. On master a closed-parameter spelling (`apr<R>(g: (x: i32) => R)`) passed check that way and printed `true` for the `i32` `4`: clause 1, filed and closed as D16142. A call-result function whose `T` only the call fixes is still refused at emit (D16143).
