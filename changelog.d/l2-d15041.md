## Type system (Track A)

- **D15041 closed: a type parameter bound by the encloser's own type parameter and by an `f64` argument
  joins at `f64`** (`refactor-notes/2026-11-17-l2-d15041.md`). `mix(u, v)` in `w2<U>(u: U, v: f64)` runs

  refused at the call.
