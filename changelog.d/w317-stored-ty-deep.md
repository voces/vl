## Codegen, memory & runtime (Track B)

- **Step 7 L2, mono: tagged records and literal pins read their rows by type.** A record literal holding a tagged set is built at the row of its stored type. An `#anonN` parameter pin finds its literal's row by the literal's type instead of its label. A ref-list element of a generic instance's function-holding record finds its row by type, up to function-value sets, instead of by name. Closes D16020 (its witness now runs armed) and D16040. The label is still read for a pin forwarded from another instance (D16021, 1 program). No unarmed behaviour change: 257 of 257 programs that reach a changed rung are byte-identical.
