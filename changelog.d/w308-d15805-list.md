## Type system (Track A)

- **D15805, the bound-list spelling:** a bound list whose elements hold records nested in them, whose function field holds un-annotated functions returning different types, runs a call through the field: indexed at run time, three levels deep, walked, an element or the inner record bound out, pushed, and beside other fields. The tag decision builds the records nested in the elements at the list's rep (`fnTagHeldRecLit`) and finds a split set in a nested field; the judge lifts that path for a bound list. A returned list stays refused (D15805's witness).
