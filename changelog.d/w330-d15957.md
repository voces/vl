## Type system (Track A)

- **A read of a re-pointed generic `let` takes its most recent write (D15956, D15957).**
  `let k = plus; k(1); k = inner; k(true)` runs. So does delivering `[k]` at
  `((b: boolean) => void)[]` after `k = inner`. A write of a declared generic installs a narrowing
  row, and a read the row reaches is that function's name.
  - Writes in a branch or a loop keep the binding's whole set, as do captures and a value that
    names no one function.
  - The narrowing applies only on the driver's retry of a program the whole-set typing refused,
    so every program that typing accepts checks as before.
  - The hole-lambda spelling is D16110.
