## Type system (Track A)

- **D16009 closed:** a re-pointed `let` of un-annotated functions whose results differ, handed to an open parameter (`ap(f, 3)` with `function ap(g, x) { return g(x) }`), dispatches in the callee on the function it holds and gives the caller the members' join: `let f = inc; if c { f = str }; print(ap(f, 3))` prints `s`. Returned first and then handed on, or a choice handed on, is still refused (D16094).
