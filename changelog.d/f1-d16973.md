## Codegen, memory & runtime (Track B)

- **D16973's trap closed:** a `.map` whose un-annotated callback returns a record or `null` (a lambda, a named `const` lambda or a named function) builds a list whose elements may be null. A `== null` test or a `?.` on a null element now reads it, where it trapped on a null reference. A field read of a list of a union arm or `null` stays a loud emit reject, open as D16973.
