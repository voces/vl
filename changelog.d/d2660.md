## Type system (Track A)

- **D2660 contained (clause 1 → clause 2):** a read of an un-annotated `let x = null` delivered before a later write fills it (a generic call, an annotated binding, an argument, a `.push`, in a loop or not) is judged at the type the write fills it with, as the annotated twin is, and refused when the destination cannot take it, where it checked clean and built invalid wasm. Running it is the flow-sensitive-read backlog item.
