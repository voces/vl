## Type system (Track A)

- **#8833 regression fixed; D16892's list spellings run:** a container read in place settles at its read only when no binding holds it: a `Map()`/`Set()` call, a call whose callee hands back only parameters given such containers (`take(Map())`, `two(true, Map(), Map())`), or an element of a list literal of them (`[Map()][0].get("a") ?? 7`, `take([Map()])[0].get("a") ?? 7`). A read through a binding (`take(m).has("a")`, `[m][0]`, `fld({m: m})`, a callee returning a global) no longer pins it before its later writes, which `vl check` had refused (`set: expected i32, got string`).
