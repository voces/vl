## Type system (Track A)

- **D16892 closed:** an empty `Map()` read in place, directly or as an element of a list literal (`Map().get("a") ?? 7`, `[Map()][0].get("a") ?? 7`, `take([Map()])[0].get("a") ?? 7`), runs. `two(true, Map(), Map()).has("q")` keeps running: a call handed fresh containers and scalars counts as fresh. A read through a call or list handed a binding (`take(m).has("a")`, `[m][0].has("a")`) no longer settles that binding before its later writes, which #8833 had made `vl check` refuse (`set: expected i32, got string`).
