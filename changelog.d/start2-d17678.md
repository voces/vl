## Type system (Track A)

- **D17678 closed:** a typed lambda inside a function with an un-annotated parameter reads the function's names: where a typed destination inside the lambda (a result annotation, a binding's function type, an annotated local) pinned the parameter, the lambda's per-instance re-check took no snapshot of the enclosing names and refused `undeclared identifier`. An encloser with an un-annotated parameter now has its names snapshotted, marked so the snapshot opens no per-instance build of its own (`closures/typed-lambda-reads-hole-encloser-names.vl`).
