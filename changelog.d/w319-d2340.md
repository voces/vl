## Codegen, memory & runtime (Track B)

- **A `let` with no initializer can be shared with a closure whatever its type (D2340, D3371).**
  A closure that captures such a binding and sees it assigned afterwards used to be refused when
  the type had no zero value: a record, a union, a function, a list or a map. The binding now lives
  in a `T | null` cell. A read made before the first write traps and names the binding
  (`` `p` read before it is assigned ``), as a module global read before its initializer does; a
  type that admits `null` traps the same way, so its unassigned state is never read as `null`.
- **`??` over a nullable function value lowers (D4341, D3170, D3245).** Calling the result inline,
  binding it first, a named-function default, a record field written back, and a captured list's
  element read inside a closure all run.
