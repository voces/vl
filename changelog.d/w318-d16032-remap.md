## Codegen, memory & runtime (Track B)

- **Step 7, D16032: the arm-row and closure-arm readers read rows.** `unionArmRowsOfTy` stops
  looking up a union's arms by its name. A hole's scalar `T | null` box, the one case where
  that name lookup found a row the type did not, now reads the box's own row.
  `unionClosureArmTyOfTy` reads the row its type keys, else the type's members, and takes no
  name. `unionArmTysOfTy`, `unionArmTys` and `unionTyArms` are deleted. Every program that
  reaches these sites builds byte-identical.
