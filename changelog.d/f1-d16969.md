## Codegen, memory & runtime (Track B)

- **D16969 closed:** a union of nested lists that all spell one list, such as `i32[][] | K[][]` over `K = 1 | 2`, is now stored as that list in a binding, parameter, return, capture, nullable, map value or list element. It was refused at emit with `only i32[] arrays and struct/union element arrays are supported`. As a record field (D16980), or written with the literal-set member first (D16981), it is still refused.
