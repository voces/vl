## Type system (Track A)

- **D16562 closed:** a generic function handed to a generic's function-typed parameter that nothing else binds takes the unbound default at the call, in the checker: the call's row records that instance and the elaboration no longer picks its own. Every `i32` use keeps running, `apply(sel(gid), 1.5)` (was invalid wasm) and `d()(4)` now run, and a use at another type is refused at check with a note naming the remedy (`sel<f64>(…)`) instead of trapping. The run face is filed as D16630.
