## Type system (Track A)

- **D16759 closed:** an un-annotated `const e = []` handed to a generic `V[]` parameter and then written at another element than the unbound default (`e.push(2.5)` after `probe(e)`) now runs: the call's instance is built at the element the list settles at, not at the default when the call is checked. The interim refusal is gone; a call that binds `V` from another argument at a different type than a later write gives the list is refused at the call as a type mismatch. A `V[]` result of such a call is still refused at emit (D16782).
