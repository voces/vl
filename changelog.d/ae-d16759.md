## Type system (Track A)

- **D16759 closed:** an un-annotated `const e = []` handed to a generic `V[]` parameter and then written at another element than the unbound default (`e.push(2.5)` after `probe(e)`) now runs: the call's instance is built at the element the list settles at, not at the default when the call is checked. The interim refusal is gone. A call that binds `V` from another argument fixes the list at that binding, so a later `push(4)` after `first(e, 1.5)` widens into the `f64[]` as it does for an annotated list. A `V[]` result of such a call is still refused at emit (D16782).
