## Codegen, memory & runtime (Track B)

- **D16102 closed (soundness):** a field write whose right-hand side calls something that rebinds the receiver (`h.p = sw()` where `sw` reassigns `h`, through a closure, a parameter, a nested field or an element) no longer narrows the field afterwards, so `h.p?.x ?? 0` reads the new object's `null` instead of trapping.
