## Codegen, memory & runtime (Track B)

- **D16872 closed (clause 1):** a call through a list of un-annotated functions of two result types handed through a generic (`const xs = id([inc0, half])`), bound in a block or a function (`const v = xs[0](3)`), no longer builds an invalid module: the value-flow rewrite's direct call returns the member's `i32`, and a `let` whose slot is laid out `f64` or `i64` now takes its init widened to that slot.
