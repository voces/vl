## Soundness (Track A)

- **D16758 closed (clause 1):** an un-annotated `const e = []` handed to a generic `V[]` parameter no longer builds invalid wasm. The call held the binding's open element at the callee's own unbound `V`, a type no caller can build. It now leaves the element open and binds `V` at the element the row settles at, in a function body as well as at top level, and through `V[] | null` and record-field parameters. A later write that fixes the element at a type other than the unbound default is refused at the call (D16759, was a loud emit reject). A `V[][]` parameter is still refused at emit (D16760, unchanged).
