## Type system (Track A)

- **D17001 closed:** inside `is K[]` over a list arm stored apart from `K[]` (`u8[]`, `i64[]`, `f64[]`), with `K` a numeric literal set, an element reads as a `K`, converted from the arm's own rep; it was refused (`cannot assign i32 to 'k' of type K`). Writes and loops (D17002), string sets (D17003) and record arms (D17004) are filed open.
