## Codegen, memory & runtime (Track B)

- **A shared scalar `let` read before its first write traps instead of reading `0` (D16023).**
  A closure that read a captured `let x: i32` (or `string`, `boolean`, …) with no initializer
  before anything assigned it got the type's zero. Such a binding now takes the same cell as
  every other type (D2340), so the read traps and names the binding. A `let` with an
  initializer is unchanged.
