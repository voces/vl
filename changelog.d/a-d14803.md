## Type system (Track A)

- **D14803 closed (owner ruling):** an argument only a union of type parameters admits binds every candidate parameter to its type, so `F(5)` against `F<A, B>(v: A | B): boolean { v }` reads as `F<i32, i32>(5)` and is refused at the return instead of printing `true`; `G<A, B>(v: A | B): A | B { v }` called as `G(5)` runs.
