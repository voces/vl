## Codegen, memory & runtime (Track B)

- **IR claims: the builder asks a string append site's arm without minting its global pair, and a claim whose build mints a synthetic global falls back.** `strSiteArmsAt` minted the site's buffer and frontier globals (`synthSitePairIdx`) when asked. The IR builder asks it at claim time, before legacy's writing mints the map backings, so a claimed body could reorder the module's synthetic globals. The builder now asks `strInPlaceModeAsked` and `strSiteOfRhsAsked`, which mint nothing (`synthSitePairAvailable`), and legacy still mints the pair where it writes the site. `irClaimFn` and `irClaimStart` count the synthetic globals around the build, and a build that minted one falls back as `claim fell back: build minted a synthetic global`, which `ir-shadow.vl --claims` reds on.
