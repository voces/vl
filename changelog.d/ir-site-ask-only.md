## Codegen, memory & runtime (Track B)

- **IR claims: the builder asks a string append site's arm without minting its global pair, and the lowering mints it where legacy does.** `strSiteArmsAt` minted a global site's buffer and frontier globals (`synthSitePairIdx`) when asked, and the IR builder asked it at claim time. A claimed body could then reorder the module's synthetic globals relative to legacy's writing. The builder now asks `strInPlaceModeAsked` and `strSiteOfRhsAsked`, which pass `ask` to `strSiteArmsAt` and mint nothing (`synthSitePairAvailable`). The lowering asks legacy's arm at the first node of each assignment whose right side is a `+` chain (`strSiteArmMint`), where `emitAssignUnder` asks it. `irClaimFn` and `irClaimStart` count the synthetic globals around the build, and a build that minted one falls back as `claim fell back: build minted a synthetic global`, which `ir-shadow.vl --claims` reds on. No shipped byte moves.
