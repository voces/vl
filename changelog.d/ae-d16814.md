## Type system (Track A)

- **D16814 closed:** a higher-order function handed an un-annotated function at one call and a lambda literal or a declared function at another (`app(hinc, 2)`, `app((s: string) => s, "e")`) no longer fails `vl check` with `hinc`'s body checked at the lambda's type: each instance calls only the functions its own calls hand it.
