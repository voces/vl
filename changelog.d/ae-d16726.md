## Type system (Track A)

- **D16726, D16886 closed:** an empty `Map()` or `Set()`, or a generic's call handing one back (`take(Set())`), read in place by a key read (`Set().has(1)`, `Map().has("a")`, `Map()[1] ?? 0`, `Map().keys().length`, `take(Map())[1] ?? 0`) runs instead of being refused at emit: it settles as a bound container only read does, its key fixed by the read. The receiver is still evaluated where it sits.
