## Type system (Track A)

- **D16098 closed:** a re-pointed `let` of un-annotated or generic functions whose results differ, handed to a generic `(x: T) => R` parameter whose result is their join, dispatches on the function it holds: `let f = inc; if c { f = str }; print(app(f, 3))` prints `s`. D12214's witness now prints `1`. Where one member's result does not fit the destination's (`same<T>(g: (x: T) => T, …)`, or D9003's closed `(a: i32) => i32`), it is still refused at the write.
