## Type system (Track A)

- **D17099 closed:** an un-annotated function, or a choice of them, handed through a generic that hands its argument back (`id(inc)`, `fst(inc, 1)`, `id(id(g))`) to a closed function type whose result is wider (`i32 | string`, `i32 | null`, `f64`) now runs at an argument, a return, a binding and a record field. The check decides it there and builds the adapter a `let` gets. Before, the call trapped with an indirect call type mismatch.
