### D16884 — `is K[][]` of a nested `i32` list arm of a box union, `K` a set of `i32` literals, is silently false

**closed 2026-11-16 · runs, prints `1` `0` `1` · was check-clean silently wrong, `vl check` rc 0, printed `0` for every list · clause 1 · fixed in wasmEmit.vl with [D4778](D4778.md): `emitListIsAcrossReps` tests an `i32` list arm as deep as a list of `i32` literals by its leaves (`LIST_ARM_NUMS`, `listArmNumsDepth`), where the other-tag rule skipped it · pin: `tests/cases/unions/is-literal-list-against-int-list-arm.vl` · found closing D4778 · filed 2026-11-16 against master `2a0b71c1a`**

Repro:

    type K = 0 | 1
    function f(x: i32[][] | string) {
      if x is K[][] { print(1) } else { print(0) }
    }
    f([[1]])
    f([[3]])
    f([])

Want:

    1
    0
    1

#### Mechanism

`K[][]` keeps a tag of its own (no arm holds it), so the `i32[][]` arm's tag differs, and the D16047
rule that an arm with another tag never fits skipped the arm: the box test answered false for every
value. A list of `i32` literals is the case that rule misses: an `i32` list arm as deep fits it
when every leaf is a member.
