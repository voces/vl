#### Mechanism

A map value of type `(() => L) | null`, where `L` is a literal union, has no value rep. A map
the program builds itself is refused loudly at emit ("unsupported map value type"). A map that
arrives only through a narrowed union parameter is never built, so nothing refuses it, and the
read builds an invalid module. The same nullable function type runs as a local, a list element
and a record field, and a map of it runs when the result is `boolean`, `i32 | string` or `L[]`,
or when the value is not nullable.
