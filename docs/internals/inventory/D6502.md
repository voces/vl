#### Mechanism

From the ablation only. [D6482](D6482.md)'s close records the pair an instance re-asks when
both sides are type parameters or parameter holes; at a `T[]` parameter the second argument
meets `T` bound to the first argument's element, a derived hole, so no pair is recorded.
Admitting an element-of hole over a parameter hole in `tyParamsApart` alone does not move
the witness.
