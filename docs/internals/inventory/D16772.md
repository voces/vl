**open · loud check reject · clause 2 · narrowed 2026-11-16 by lane AE: a bare un-annotated parameter is instanced at the build (`recAnnArgRepBy`), so the `argument` cell of `same-elems-result-of-built-list` and `map-callback-over-built-list` runs · CAPABILITY: the annotated parameter and the annotated return run · `this container's {f: null} elements are stored at J, the row its stores build; handing it on as {f: null}[] is type-valid but not supported yet` · the `argument` and `return_inferred` cells (un-annotated face) of `same-elems-result-of-built-list`, `map-callback-over-built-list` and `same-elems-result-in-literal`, and their `map_value`/`map_set` cells · residue of D16767 · found by lane WIDTH · filed 2026-11-16 against master `0ab7c1bf7`**

#### Mechanism

`dA`'s delivery keeps `mk2` building at `J`, so `src` stores its elements at `J`
(`recBuiltElemOf`). An un-annotated result is typed at `src`'s own `{ f: null }[]`, which
`recBuiltRetListsRefuse` refuses because the build is not its own row; a map value and a record
literal's field are typed the same way. A bare un-annotated parameter no longer is: its instance is
keyed by the build (`recAnnArgRepBy`), as an annotated one's is. The result would have to be
inferred at the build, or the call counted as a delivery that lands `mk2`'s call off `J`.

#### Grading list

and the un-annotated `argument` cell of `same-elems-result-in-literal`; `identity_returned` and
`filter_in_record_argument` (both faces), which hand the list to the same positions.
