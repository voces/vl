### D16772 — a generic's `V[]` result over an open `[]` binding is refused at emit

**loud emit reject · clause 2 · `emitProgram: '.length' on a receiver the emitter cannot classify as a list, string, map or set` · found grading D16759's neighbours; the same on master · filed 2026-11-16 against master `6fb5ac348`**

Repro:

    function g<V>(v: V[]): V[] { return v }
    const e = []
    const h = g(e)
    print(h.length)
    // vl check: rc 0.  vl run: emit error at `h.length`

Want:

    0

#### Mechanism

The call leaves `V` unbound, since its only argument is an open list, so its result type is
`V[]` with the callee's own `V`, and `h` is typed with it. `settleHeldPins` binds `V` on the
call's bind row once the row settles, but the result type the binding took at the call is not
revisited.

#### Ablation

| spelling | outcome | needed? |
| --- | --- | --- |
| `print(g(e).length)` | the same emit refusal | no |
| `const e: i32[] = []` | runs, `0` | **yes** (the open list) |
| `function g<V>(v: V[]) { return v.length }` | runs, `0` (D16758) | **yes** (the `V[]` result) |
