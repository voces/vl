Repro:

    // file: c.vl

    // file: d.vl

    // file: entry.vl

    // now runs: the Want block below (closed 2026-11-15)

Want:

    5
    6

#### Mechanism

Localised at the close. A lambda or named function nested in a generic body is cloned per
instance with its body shared (`monoCloneLambdaSubst`), and the rewrite lowered the member call
in that shared body once, so every clone called one instance's `grow`; the refusal stood in for
that, since letting it through emitted a wasm that failed to validate. Each clone's copy step
(`monoCloneGenericCallArm`) now lowers the call to its own instance's direct call.
