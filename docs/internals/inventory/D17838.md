#### Mechanism

`tyPinElem`, `tyPinKey` and `tyPinVal` (`check_types.vl`) solve a hole child through `holeSolve`;
a child below zero that is no hole code (a sentinel minted as such) is written into the row's field.
The close mints every open child as a hole, so a pin never writes a row.

#### Grading list

`tests/cases/lists/` and `tests/cases/maps/` cases that pin an empty literal by its first store.
