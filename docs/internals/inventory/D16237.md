### D16237 — a hole function written into a field through a narrowed read of an un-annotated map is not pinned by a walk's call

**loud emit reject · `cannot take the generic function dbl as a value — … No call site pins dbl` · clause 2 · open · `vl check` rc 0 · the sentence is false: the walk calls the field it was written to · 18 un-annotated cells of `ffc-map-of-hole-fn-records-field-written.matrix.vl` · filed 2026-11-15 against master `55151b054`**

    function inc(n) { return n + 1 }

#### Mechanism

The write `r.f = dbl` lands in the map's value record through a narrowed binding of a map read.
The walk's loop variable reads the same record, but the write leaf is not reached from the map's
place path, so the walk's call does not pin `dbl`. A key read of the map (`m[k]`) does pin it.
The held-map arm of `fnTagWriteLeavesOf` covers a map written at its own path, not a field below
a map read; that is the suspected gap.
