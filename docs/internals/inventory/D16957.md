### D16957 — an optional-chain read of a field of a record a map stores builds no shape when that field is a `??` over a read of a container adopted at a wider record

**loud emit reject · clause 2 (a program `vl check` accepts does not build) · open · found driving `recCoalesceDefaultDeliver` with fn-coverage (the coalesce-default cluster no corpus program runs) · filed 2026-11-18 against master `896cac16` by lane F2**

Repro:

    type J = { f: i32 | null }
    const m = Map()
    m.set("a", { f: 4 })
    const wm: {[string]: J} = m
    const d = { f: 1 }
    const w3 = Map()
    w3.set("b", { x: m.get("a") ?? d })
    print(w3.get("b")?.x.f ?? 0)
    // vl run: emit error at 8:17, "emitProgram: ref valtype with no interned shape"

Want:

    4

#### Mechanism

`m` is adopted at `J` by `wm`, so `m.get("a")` is a read of a container built at a wider record,
and the `??` default `d` is delivered at that record (`recCoalesceDefaultDeliver`). The stored
record `{ x: … }` then holds a field built at `J`; the optional-chain read of that field through
`w3.get("b")?.x` asks for a ref value type the emitter never interned. A plain read of the same
stored record, or the same chain over a record whose field is not a coalesce over a built read,
builds.
