#### Mechanism

`monoIfChainRebuildPinned` refuses a tail join of type parameters that carries a `null` and pins
at two number types (`monoNulJoinMixesNumbers`, D3363): the caller reads the call without the
join's box, so the box the instance would build has nothing to land in. The refusal names a
mechanism, not a design rule; the program is type-valid.

The caller's side is [D3611](D3611.md)'s: `paramNullJoin` is never kept apart, so the call reads
`f64 | null`. Lane HL measured both halves together on its 2,718-cell grid: marking that join apart
and dropping this refusal turned 499 refused cells right, but 69 refused cells wrong, 40 invalid
and 48 trapping, and lost 15 that ran (a generic `==` and list literal over the three-member union
trap, D3535; a `??` in a hole body builds invalid wasm). Those readers are the work this row needs.
