### D13782 — a choice of un-annotated functions whose results differ, called at a caller's un-annotated parameter, traps on the indirect call

**trap after load · `wasm trap: indirect call type mismatch` in `bad` · `vl check` rc 0 · clause 1 · open · the same choice called at a concrete type is refused ([D13740](D13740.md)), and so is the re-pointed `let` ([D9003](D9003.md)); at an open parameter both are left to the pin, which judges neither · found closing [D13740](D13740.md) · present on master `46e8112f6` · filed 2026-10-25 against master `46e8112f6`**

Repro:

    function twice(s) { return s + s }
    function lenOf(s) { return s.length }
    const k = [1].length > 1
    function bad(z) {
      const f = if k { twice } else { lenOf }
      print(f(z))
    }
    bad("ab")
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch

#### Mechanism

Not ablated to a line. The call `f(z)` passes `z`'s open hole, and the arm-against-arm judge
(`holeLetWritesDisagreeAt`, check_relate_core.vl) defers only the list-element and field reads
at an open type. Nothing judges the arms again at `bad`'s pin, `string`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the open parameter (`bad(z: string)`) | check reject | **yes** |
| the choice (`let f = twice` then `f = lenOf`) | trap after load | no |

#### Grading list

- The re-pointed `let` spelling in the ablation, which is D9003's shape at an open parameter.
- The choice handed to a callee beside the open parameter,
  `function bad(z) { print(only(z, if k { twice } else { lenOf })) }` with
  `function only(n, f) { return f(n) }`, which is a loud emit reject
  (`unsupported argument type for `f` in a call to `only``) and should be the same refusal.
