### D7121 — a module-scope block's binding typed by a union that reaches a nullable literal union through an alias widens with no scratch frame

**closed 2026-10-19 by lane L6 · runs, prints `false` · was check-clean invalid wasm · clause 1 · the `let` scan that reserves the string-op scratch frame asks the binding's declared TYPE whether a literal member widens to a string (`tyTakesAtomAsStr`), not its spelling · pins: `tests/cases/unions/litunion-atom-module-block-binding-alias-union.vl` (read in place and from a closure) · found closing [D7043](D7043.md) by the `nullable-litunion-through-alias-arm` matrix's `block_*_capture` cells · present on master `e55677bd8` · filed and closed 2026-10-19 against master `e55677bd8`**

Repro:

    type A = ("a" | "b") | null
    type U = A | i32
    const ga: ("a" | "b") | null = "a"
    if true {
      const c: U = ga
      print(c == null)
    }
    // vl check: rc 0.  vl run: invalid module, top-level: unknown local

Want:

    false

#### Mechanism

A binding in a module-scope block is a local of the start function, so its widening is reserved
by `letWidensAtomToStr`. That scan asked `unionTakesAtomAsStr` of the binding's spelling, and the
spelling `U` names an alias, so no frame was reserved. This is [D7043](D7043.md)'s mechanism at
the `let` scan.
