#### Mechanism

D3261's fix is inlining: the escape step inlines a record producer into its callers so
`--heap2local` can see the allocation die. It declines a producer over
`ESCAPE_INLINE_MAX_BYTES` (320 body bytes), and a producer over `RUN_ONCE_INLINE_LEAF_BYTES`
(160, loop-free, no calls) that run-once code calls, since inlining a large body at every
call site costs code size and L8's baseline-tier penalty. The ruling (B) promises no
`struct.new` for any small non-escaping record result, which past these bounds needs what it
names: a multi-value-returning variant of the producer, used at call sites that only read the
fields. Recommendation: build that ABI (non-exported, not a function value, at most 8 scalar
fields) when a consumer's profile shows a large producer on a hot path; plumb's does not today.
