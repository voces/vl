### D15143 — a closure's hand of a bundle parameter into a callee instance shared with a direct caller gets no record without the split plan

**closed 2026-11-03 — the repro runs without the split plan too. Was: runs today and must keep running, leaning on the split plan · filed 2026-11-03 against master `8af9776f`**

Repro:

    function keep(g) { print(g(7)) }
    function lap(f) {
      print(f(2.5))
      const h = () => keep(f)
      h()
    }
    function go(k: i32) {
      lap((a) => a + k)
      keep((x) => x - k)
    }
    go(2)

Want:

    4.5
    9
    5

#### Mechanism

`keep`'s instance at `(i32) => i32` serves both the closure's hand and `go`'s direct call, so the
closure's hand joins it to `lap`'s record and `go`'s lambda is wanted at `lap`'s other signature,
`(f64) => f64`. The join runs once the elaboration's instances are built, so it cannot mint that
instance itself. It now notes each instance a chain is missing (`elabJoinDemandNote`), the
preparation takes one more bounded round, and that round enqueues the notes on time
(`elabJoinDemandsEnqueue`), so the next join finds them built.

#### Ablation

| ingredient removed (plan off) | outcome | needed? |
| --- | --- | --- |
| `go`'s direct `keep(...)` call | runs | **yes** |
| the closure (`lap` hands `keep(f)` from its own body) | runs | **yes** |
| a `const` copy in place of the closure (`const kk = keep; kk(f)`) | still refuses | no |

#### Grading list

The `const`-copy spelling above, and two `lap` instances beside the direct call
(`lap((a) => a + k); lap((a) => a * k); keep((x) => x - k)`).
