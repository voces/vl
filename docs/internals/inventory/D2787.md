### D2787 — a join of two type-parameter values read inside the generic body is built at one pin's scalar

**closed 2026-09-27 · the filed repro RUNS and prints `b` then `1` · was check-clean invalid wasm on master `829bd497c` · filed 2026-09-27 from the #3209 review · fixture `tests/cases/generics/value-join-at-the-pin.vl`**

Repro:

    function f<A, B>(a: A, b: B, k: boolean) {
      const r = if k { a } else { b }
      print(r)
    }
    f(1, "b", false)
    f(1, "b", true)
    // vl check: rc 0.  vl run: invalid module inside `f`, expected i32, found (ref $type)

Want:

    b
    1

#### Mechanism

Not localised. The generic body joins two bare type parameters by collapsing to one side, so
the instance lowers the value `if` at the scalar blocktype of `A`'s pin and stores the string
into it. No spelling of this shape ran on either earlier master: the returned-binding spelling
(`const r = …; r`, printed by the caller) was invalid wasm on both. A numeric pair runs.

Closed by D2893's re-typing: the join is printed from its binding, a sink, so the instance
types it `i32 | string`. The grading list's `is` read, annotated return and returned-binding
spellings are other delivery positions and stay open as D2906.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the read in the body (`r` returned from its binding, printed by the caller) | invalid wasm on master | no |
| the binding (`if k { a } else { b }` as the tail, printed by the caller) | runs | **yes** |
| the non-numeric pair (`f(1, 2.5, …)`) | runs | **yes** |
| the second type parameter (`f<T>(a: T, b: T, …)`) | runs | **yes** |

#### Grading list

The same body with `if r is string` in place of `print(r)`, and the annotated return
`function f<A, B>(a: A, b: B, k: boolean): A | B { const r = if k { a } else { b }; r }`,
which is still invalid wasm.

Same bind-position family, identical on master, from the #3209 round-3 grids (`rv3209r3-b1`):
a type parameter joined with a concrete non-numeric value, `f<A>(a: A, k: boolean) { const r
= if k { a } else { true }; return r }` with `f(1, false)`, prints `1` where `true` is right;
the bind position over an `i32`/`f32`, `string` or `i64` pair beside a non-numeric one is
invalid wasm; three type parameters, `gen3_bool_i32_f64_nest` prints a wrong value and
`gen3_*_bind2` is invalid; and `gen_f32_f64_retstmt` is invalid.
