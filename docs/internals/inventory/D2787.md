### D2787 — a join of two type-parameter values read inside the generic body is built at one pin's scalar

**check-clean invalid wasm · identical on master `781f68091` · filed 2026-09-27 from the #3209 review**

Repro:

    function f<A, B>(a: A, b: B, k: boolean) {
      const r = if k { a } else { b }
      print(r)
    }
    f(1, "b", false)
    f(1, "b", true)
    // vl check: rc 0.  vl run: invalid module inside `f`, expected i32, found (ref $type)

#### Mechanism

Not localised. Since D2760 the join types `A | B`, which the pin substitutes to `i32 | string`,
a value box. The instance still lowers the `if` at the scalar blocktype of one arm and stores
the string into it. Returning `r` and printing it at the call site ran on master `f6db92e0d`, is
invalid wasm on `781f68091`, and refuses loudly with D2760 (`narrowed union atom has no value
box`), so the family is the value `if` over two type parameters at a scalar pin.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the read in the body (`r` returned, printed by the caller) | invalid wasm on master, a loud emit reject with D2760 | no |
| the second type parameter (`f<T>(a: T, b: T, …)`) | runs | **yes** |

#### Grading list

The same body with `if r is string` in place of `print(r)`.
