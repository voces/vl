Repro:

    type S = { iocp: i64, skip: boolean }
    let portQueues: {[i32]: i64[]} = Map()
    function complete(s: S, ov: i64, atOnce: boolean) {
      __store_i64__(64, ov)
      if s.iocp != 0 && !(atOnce && s.skip) {
        const q = portQueues[s.iocp as% i32] ?? []
        q.push(ov)
        portQueues[s.iocp as% i32] = q
      }
    }
    export function main() {
      complete({ iocp: 5, skip: false }, 1, false)
      print("taken ok")
      complete({ iocp: 0, skip: false }, 1, false)
      print("not taken ok")
    }
    main()

#### Mechanism

An assignment yields its right side, so the checker infers `complete`'s return as
`i64[] | null` (the else-less tail `if` falls through to `null`), and `synthNulListRetAnns` pins
that return, making the function non-void after `computeVoidFns` had voided it. At the body's
end the emitter asks `fnRetNullBearing` whether the fall-through can be `null`; it knew only the
i32-backed nullable list (`retNulListFlag`), not a distinct-backing scalar list (`i64[]`,
`f64[]`, `string[]`) or a ref-array (`S[]`, `i32[][]`), so it padded with `unreachable` — which
runs on both paths, because the arm's write was also not the function's value ([D2496](D2496.md)).
`emitNullForRet` already had the ref-array `ref.null`; the scalar-list one was added, and
`fnRetNullBearing` now answers for both. The same gap trapped the plainest spellings, an arm
ending in a value (`if k != 0 { [1 as i64] }`) and an annotated `: i64[] | null` whose
`if k != 0 { return [...] }` falls through.

#### Ablation

| ingredient changed (on `0a0d24ac9`) | outcome | needed? |
| --- | --- | --- |
| the module map made a local | still traps | no |
| the `&&` condition made `k != 0` | still traps | no |
| the map write made a global, field or local-name write of the list | still traps | no |
| the write made a bare value `[1 as i64]` | still traps | no |
| `i64[]` values made `i32`, `string` or `i32[]` | runs | **yes**: the list rep |
| an `else` arm added | runs as a statement | **yes**: the fall-through |
| `: void` on the function | runs | **yes**: the inferred return |
| the write made `portQueues.set(...)` | runs | **yes**: a void tail |
| a `return` after the `if` | runs | **yes** (plumb's workaround) |
