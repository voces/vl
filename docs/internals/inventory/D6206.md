#### Mechanism

From the ablation only. The split plan gives `q` a slot per type from its reads' argument
types (D6020), but the one read here is at `T`, which the plan cannot key, and the call's
recorded type stays open.

Lane L1, 2026-10-17, measured by hand split. Copying `g` per instance with `q` shared still
refuses, with the same message. Copying `g` and also giving each copy its own `q`
(`const q1 = fw(id)`, read only by `g1`) runs, printing `s 2`. So a close copies `g` per
instance and renames the read of `q` inside each copy to a slot of its own. A copy is
minted at apply from a fresh parse, so that rename has to be matched by node position inside
a copy the plan never saw.
