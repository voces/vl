#### Mechanism

`ihAmbientMeetsIn` (iface_hash.vl) declines a root when a module outside its closure declares a
record field set that the closure spells in field position: after `.` or `?.`, inside `{` before
`:` or `?`, or alone between `{` or `,` and `}`, `,` or `=`. The rule is sound, because record
adoption and literal typing can reach such a set across modules. But it keys on the field names
alone, so a one-letter field such as `rng.vl`'s `s` meets every closure that reads any `.s`.

On a copy of diderven at two workers, `vl check src` declines 78 roots on `ambient`. By culprit:
`rng.vl` 9, `tools/pieces.vl` 8 (`px,x0,x1,y0,y1`), `std:buffer` 7 (a wild row),
`items/uniquedef.vl` 7 (`stat,share`), `items/consumables.vl` 7 (`mat,life,mana`), and
`state.vl` 6 (the type name `Input`). The rest are 5 or fewer each.

#### Ablation

Each culprit was taken to the key that met, and each key to the fact it stands for.

- **Record field sets: the arena half.** `rng.vl`, `pieces.vl`, `uniquedef.vl` and
  `consumables.vl` all met through the arena half, which read every `TyObj` in the MERGED
  arena. That arena always holds the outside module's own declaration, so the test reduced to
  "G spells the field names". The fact it guards is that G's own check holds a record of that
  set. The index now records, per field set, the modules that hold it: every record level they
  spell, and every record their checked nodes' types reach (`ihIxReach`). A set meets only when
  a module of G holds it and G spells it (`ihIxHolds`). The skip path's `ihAmbientFvArena`
  already reads G's own arena in the same way.
- **Type names.** `state.vl`'s `Input` met as a NAME key. Type names are module-scoped, which
  was probed in both directions. An unimported name refuses in both checks, and two modules'
  same-named private types coexist and run. So a name can differ only where a report row
  renders it. A NAME key now meets only when the root has rows.
- **Operators.** `std:buffer` was wild because every operator made its statement wild. On a
  structural type that is right. An outside `"[]"` on `{ base: i32, length: i32 }` indexes G's
  own twin record in the merged check, while G alone reports `cannot index non-array W` (a
  hidden error, pinned). On a `new` type, a value enters G only where G names the type, so the
  operator is keyed by that name (`IH_AK_OPER`). The parameter's spelling carries the merge
  suffix (`F32View$m…`), so it is read through `ihDeclBase`. This removed all 11 of
  `std:buffer`'s declines.
