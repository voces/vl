### D8162 — a record literal holding a hole call's result, returned and bound un-annotated, has no interned shape

**closed · filed 2026-10-20 against master `da93ef793` · clause 2 · closed with D2850, by minting the instance's record row at its pin · fixture `objects/record-holding-hole-call-result.vl`**

Repro:

    function inc(a) { return a + 1 }
    function boxed(h) { return { v: h(5) } }
    const b = boxed(inc)
    print(b.v)
    // vl check: rc 0.  vl run: emitProgram: ref valtype with no interned shape

Want:

    6

#### Mechanism

An instance of D2850. A record literal in an un-annotated function's body is a constructor
whose shape holds a type variable, so it gets no row of its own. The hole call is scenery:
`function mk(a) { return { v: a } }` with `print(mk(3).v)` refuses the same way, and so does
`{ v: a / 2.0 }` over `mk(3)`, while `{ v: a + 1 }` and `[h(5)]` run. `instRetKeepsRecordsIn`
(`emit_collect.vl`) declines a record result over a type variable, so `mintPinnedObjLitRows`
mints no row for the instance, and an un-annotated destination has no declared row for the
record to be built at. Annotating `h` or the destination gives it one, and both run. The close
is D2850's (a row per pin, with a converting copy at every destination), in `emit_collect.vl`
and the emitters, outside lane L1b's file boundary.

#### Ablation

#### Grading list

The `f64` spelling `function half(a) { return a / 2.0 }` with `boxed(half)`, wanting `2.5`.

#### Close

Closed with D2850, because `boxed` is a constructor in that row's sense: its result record
holds a type the instance pins. Its row is now minted at each instance's pin. The repro prints
`6`, and the `half` spelling prints `2.5`. Fixture `objects/record-holding-hole-call-result.vl`.
