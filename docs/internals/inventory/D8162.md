### D8162 — a record literal holding a hole call's result, returned and bound un-annotated, has no interned shape

**loud emit reject · filed 2026-10-20 against master `da93ef793` · clause 2, present on master**

Repro:

    function inc(a) { return a + 1 }
    function boxed(h) { return { v: h(5) } }
    const b = boxed(inc)
    print(b.v)
    // vl check: rc 0.  vl run: emitProgram: ref valtype with no interned shape

Want:

    6

#### Mechanism

Not traced. The record literal's field type is a hole call's result, so `boxed`'s inferred
result is a record over an open type. Annotating `h` or the destination closes it before
emit, and both of those spellings run. This is independent of D8100: it refuses the same way
with an `i32`-preserving `inc` and with an annotated `inc(a: i32): i32`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `h: (i32) => i32` on `boxed` | runs, `6` | **yes** |
| `: { v: i32 }` on `b` | runs, `6` | **yes** |
| `inc(a: i32): i32` annotated | still refuses | no |
| the binding for `print(boxed(inc).v)` | still refuses | no |
| `inc` for `half` (`a / 2.0`) | still refuses | no |

#### Grading list

The `f64` spelling `function half(a) { return a / 2.0 }` with `boxed(half)`, wanting `2.5`.
