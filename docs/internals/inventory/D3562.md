### D3562 — a field read through a union of record types lowered only for scalar and string fields, so every other field rep was a check-clean emit refusal

**closed 2026-10-03, with [D1962](D1962.md) · was loud emit reject, clause 2 · `emitProgram: field access receiver is not a struct` (and `field-assignment receiver is not a struct` for a write) · sunpa SP-019 · filed 2026-10-03 against master `315552b88`**

Repro:

    type A = { kind: string, n: i32[] }
    type B = { kind: string, n: i32[], extra: f64 }
    function first(p: A | B) { p.n[0] }
    const a: A = { kind: "a", n: [1] }
    print(first(a))

Want:

    1

#### Mechanism

The checker types a field every member carries as the join of the members' field types
(`sharedUnionFieldTy`), and the emitter lowers it by dispatching on the box tag to each
member's own field index (`emitMem`, `sharedUnionFieldPlan`). The dispatch is an `if (result
<rep>)` chain, and its blocktype came from a table of five codes (`i32`, `f64`, `i64`, `f32`,
`string`); any other field fell to the plain-struct rung and refused. The fix spells the
blocktype from `pushFieldStorage` when every member stores the field at one storage type, lowers
a write the same way into a stashed value, resolves a nested read's row
(`sharedFieldTgtStructIdx`), and, when members store different scalar atoms, boxes each arm
under its atom's tag. The checker now joins such numbers apart (`i32 | f64`), as an `if` over
the members' reads does under the numeric-join ruling. `A.v: boolean` beside `B.v: i32` shares
code 0 and used to read as an i32 (`is boolean` false for the boolean arm); it boxes now.
A write through the union must fit every member's field (the meet, not the read's join):
`p.kind = "b"` over literal discriminants, or an `i32` into a member's `1 | 2`, is a check
error (`sharedFieldWriteRefused`), and the emitter stores only when every member declares the
field at one type. A read whose join would widen a list (`i32[]` beside `(1 | 2)[]`, or
`f64[]`) is refused as an `if` over the members' reads is (`sharedFieldJoinWidens`).
