#### Mechanism

`emitOptChainIsNull` emits the receiver for the `ref.is_null` test, and its `else` arm asks
`emitOptChainValue`, which emits the receiver AGAIN to read the field off it. For a scalar
leaf the else arm is the constant `0`, so the second emission never happens and the defect is
invisible; a code-15 leaf (the field is itself a nullable struct) and a code-16 one (a value
union, whose box tag is read off the field) are the arms that read the receiver a second
time. Neither function staged the receiver, and neither asked whether re-emitting it was
safe — `optRecvReReadable` guarded only `emitOptMemberValue` (D1670).

The chain's base is now evaluated once into a frame-reserved `(ref null struct)` stash
(`optRecvSlot`) and every later read is a `ref.cast` off it. The stash is teed in on the
first read rather than written up front, so the fused map and `.get` arms — which never
re-read the receiver — emit exactly the bytes they always did.

#### Ablation

Receiver shape x annotation face, each cell calling `mk` once in the source and printing the
call counter:

| leaf field | direct call | value call, inferred | value call, annotated | pre-bound name |
| --- | --- | --- | --- | --- |
| nullable struct | 2 → **1** | 2 → **1** | 2 → **1** | 1 (control) |
| value union `i32 \| string` | 2 → **1** | 2 → **1** | 2 → **1** | 1 (control) |
| nullable union | 2 → **1** | 2 → **1** | 2 → **1** | 1 (control) |
| i32 (control) | 1 | 1 | 1 | 1 |

`string`, `string | null`, `i32[] | null` and `f64` leaves each printed `1` before and after:
their `else` arm is a constant, so they never reached the second emission. A `boolean` leaf
refused loudly (`needs a re-readable receiver`, through `exprNulBool`) and now runs.

The receiver's own shape is not an ingredient — a direct call, a call through an inferred
function value, a call through an annotated one and a field read off a call all doubled, and
a two-link chain (`mkD()?.inner?.y`) tripled, one evaluation per link.
