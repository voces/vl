### D17006 — a function returning a call's list of tagged-id records directly, un-bound, is refused at its return

**loud emit reject · `a returned container of functions is built at another storage than this function's result` · clause 2 · open · `vl check` rc 0 · found grading [D15923](D15923.md)'s close · filed 2026-11-19 against master `47c76f402`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function mk() { return { a: [{ f: inc0 }, { f: half }] } }
    function via() { return mk().a }
    const xs = via()
    print(xs[0].f(3))
    // vl check: rc 0.  vl run: emitProgram: a returned container of functions is built at another storage than this function's result

Want:

    4

#### Mechanism

Not traced. The list's storage is the tagged ids row of `mk`'s literals; `via`'s result is
typed at the open record element, and its return names no storage for the member read.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the member read bound first, `const r = mk().a; return r` | runs, `4` | **yes** |
| the record around the list, `mk()` returns the list, `via` returns `mk()` | runs, `4` | **yes** |
| differing results, `half(a) { return a * 2 }` | runs, `4` | **yes** |
