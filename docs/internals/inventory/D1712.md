### D1712 — a `??` join is keyed by the OPERAND's member order, so the same union declared the other way round is a different registry key and the name does not resolve

**check-clean invalid wasm · filed 2026-09-06 against master `1f7406139` · one source token
apart from a cell that runs — `type M = i32 | A` versus `type M = A | i32` · 0 corpus cells**

Repro:

    type A = { r: i32 }
    type M = A | i32
    function mkN(): i32 | null { return null }
    function st(): A { return { r: 8 } }
    const w: M = mkN() ?? st()
    if w is A { print(w.r) } else { print(0) }
    // vl check: rc 0.  vl run: exit 70,
    // the emitted module failed to validate: type mismatch: expected i32, found (ref $type)

#### Mechanism

The `??` result type is built from the operand first, so `i32 | null` with an `A` default joins
to `i32 | A`. `nodeRegisteredUnionName` resolves that arena type through the canon-keyed reverse
index, and the row the program registered is `A | i32` — a different member SEQUENCE, which the
union member-set ABI treats as a different key. The name comes back "" and the arm falls to the
scalar tail with the operand's `i32` block type.

The two orders are the same REP: a struct arm's tag is its variant index and a scalar atom's is
`scalarTagOfKind` (`uVariants.length + k`), both program-global, so neither depends on where the
member sits in the declaration. Whether the lookup may therefore be order-insensitive is a
ruling this row wants and does not make: the standing ABI note says a member set is never
deduped and never reordered, and it says so about box tags, which this measurement does not
contradict but does not settle either.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the member order (`type M = i32 \| A`) | runs, prints `8` | **yes** — the only difference |
| the struct arm (`type M = string \| i32` with a string default) | runs | **yes** — a value join resolves without the registry |
| the null value (`return 4`, so the default is dead) | refuses identically | no |
| the call operand (`const v = mkN()` first) | refuses identically | no |

#### Grading list

The four ablation rows, both orders side by side as the pair that must agree, and
`tests/cases/unions/coalesce-result-rep.vl`'s declared mixed-union lines. A close that makes
the lookup order-insensitive must re-run the union member-set ABI's own fixtures — the box-tag
