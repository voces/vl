### D4870 — `.map` whose callback returns a list has no result list of lists

**loud emit reject · clause 2 · found closing D4861, whose refusal points at a copy that is this `.map` one level down · filed 2026-10-15 against master `0a7e96cce`**

Repro:

    const c = [1].map((n) => [n])
    print(c[0][0])
    // vl check: rc 0.  vl run: emitProgram: ref valtype with no interned shape

Want:

    1

#### Mechanism

Not yet ablated past the table. `mfResultKindOf` names a result list for struct, variant,
union, string and scalar callback returns; a callback returning a list has no arm, and the
nested spelling `a.map((r) => r.map((x) => x as f64))` over `a: i32[][]` refuses instead with
`unsupported .map/.filter element type`. The same `i32[][]` built with `push` runs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the list return (`(n) => n`) | runs | **yes** |
| the inner `.map` (`a.map((r) => r.length)` over `i32[][]`) | runs | **yes** |
