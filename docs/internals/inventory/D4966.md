### D4966 — a declared record whose field spells `{ x: i32 }[] | i32[]` makes `is P[]` over that union refuse

**closed · was a loud emit reject (`emitProgram: `is` names a declared union member with no interned arm representation`), the same on PR #3869's head `8dad45216` · fixture `tests/cases/unions/shape-list-union-return-into-field.vl` · filed 2026-10-15**

Repro:

    type P = { x: i32 }
    type W = { f: { x: i32 }[] | i32[] }
    const g: { x: i32 }[] | i32[] = [{ x: 4 }]
    if g is P[] { print(g[0].x) } else { print("N") }
    // vl check: rc 0.  vl run: emitProgram: `is` names a declared union member with no interned arm representation (deferred value-union composition)

Want:

    4

#### Mechanism

Declaring `W` interned the field union's record arm under its shape spelling `{x:i32}`, and `P`,
the same type, got no ref-list slot of its own, so `is P[]` found no arm representation. Closed
by D4932's mint in `rlInternNameTy`: a shape-spelled record interns as its declared twin.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the declaration of `W` | runs, prints `4` | **yes** |
| the shape spelling in `W`'s field (`f: P[] \| i32[]`) | `array value does not match any array member of the union` | no |
| the shape spelling of `g` (`g: P[] \| i32[]`) | `array value does not match any array member of the union` | no |

Both spellings of the record arm, one by shape and one by name, are what the program needs;
which side carries which only changes the message.
