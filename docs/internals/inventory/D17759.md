### D17759 — a popped element of a list of lambdas whose set is tagged, narrowed and called, has no tag dispatch callee

**loud emit reject, `cannot yet lower this statement (tag dispatch callee rep)` · filed 2026-11-27 against master `1faa021d1` by COV-UNION**

Repro:

    const f = (a) => a + 1
    const d = (a) => a * 2
    const two = [f, d]
    const s = two.pop()
    if s != null { print(s(3)) }
    const m = [f]
    print(m[0](3))
    // vl check: rc 0.  vl run: emit error (tag dispatch callee rep) at 5:26

#### Mechanism

`f` sits in two lists, which makes its set a tagged one; a read of `two.pop()` is then a
nullable box of a member id, and the narrowed read handed to the tag dispatch has no callee
rep it accepts.
