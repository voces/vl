### D17759 — a popped element of a list of lambdas whose set is tagged, narrowed and called, has no tag dispatch callee

**closed 2026-11-28 by COV-UNION · runs, its witness prints its expected value · was a loud emit reject, `cannot yet lower this statement (tag dispatch callee rep)` · a tag dispatch's callee stored as a nullable id (the `i32 | null` box) is read non-null (`readNonNull`), as the checker narrowed it, in both the valued and the statement dispatch (`tagDispatchAt`, ir_build.vl) · pinned by `tests/cases/closures/tagged-set-popped-element-called.vl`**

Repro:

    const f = (a) => a + 1
    const d = (a) => a * 2
    const two = [f, d]
    const s = two.pop()
    if s != null { print(s(3)) }
    const m = [f]
    print(m[0](3))
    // vl check: rc 0.  vl run: emit error (tag dispatch callee rep) at 5:26

Want:

    6
    4

#### Mechanism

`f` sits in two lists, which tags its set; `two.pop()` is then a nullable member id, stored as
the `i32 | null` box, and the narrowed read of the module binding `s` handed to the dispatch
(`tagCallee`) is read at that stored rep. The dispatch took only a plain `i32` id. The same
lambdas declared in a function body are D17785.
