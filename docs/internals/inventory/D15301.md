### D15301 — a value `if` of record literals holding different un-annotated functions, delivered onward, is refused at emit

**open · loud emit reject · `emitProgram: cannot take the generic function id1 as a value — a function value carries ONE signature` · clause 2 · bound to a `const` it runs since D15300 · found grading D15300 · filed 2026-11-04 against master `bd1aa74b7`**

Repro:

    function id1(a) { return a }
    function id2(a) { return a }
    const c = 1 > 0
    function mk() { return if c { { f: id1 } } else { { f: id2 } } }
    print(mk().f(2))

Want:

    2

#### Mechanism

The choice is the holder of its arms' records (D15300), and a holder's own position is judged
as any holder's: `ftHoldCtxOk` accepts a delivery only where the destination's type is the
holder's own. A returned, listed, pushed, assigned or argument choice is delivered to a
destination typed by something other than the choice.

#### Ablation

| position | outcome |
| --- | --- |
| `const r = <choice>` | runs (D15300) |
| a record field `{ r: <choice> }` | runs |
| returned, `mk().f(2)` | loud emit reject |
| a list element `[<choice>]` | loud emit reject, `a ref list's element row does not resolve` |
| pushed onto a list of one record | loud emit reject |
| assigned to a `let` of one record | loud emit reject |
| an argument to an un-annotated parameter | loud emit reject |
