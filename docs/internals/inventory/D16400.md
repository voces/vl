### D16400 — a lambda's declared record parameter takes no wider row: the width rewrite respells named declarations only

**loud check reject · clause 2 · `an object value of shape … flowing into P drops the field …` · the `lambda_param` cell (annotated face) of `record-param-width-before`/`-between` · found by lane I in L3 PR A · filed 2026-11-15 against master `3d526470a`**

#### Mechanism

The record-width rewrite (D3992, `check_width.vl`) notes a candidate by the callee's declaration and respells that declaration's parameter as a row slot. A call through a `const` bound to a lambda reaches no named declaration (`wsCalleeDecl` answers an `Ident` callee's top-level function only), so the parameter is never noted and the refusal stands. A2 work: note the lambda the binding holds.
