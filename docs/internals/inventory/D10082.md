#### Mechanism

`slice` hands the list to a built-in whose result shares the source's element, and the emitter's
per-call-type plan for `xs` declined on that read, so `id`'s element instance was never chosen.
The spread copy took the same plan since [D9595](D9595.md). The plan now accepts `xs.slice(...)`
as a read, records `xs` as sliced, and keeps it reachable through its element slot. Its literal
then takes one instance from the copy's calls. The `xs[0]` calls take their own instances. With
`ys.push(inc)` and `ys[1](2)` it runs. The copy called at two types is [D10190](D10190.md), and
an index write through the copy is [D10191](D10191.md).
