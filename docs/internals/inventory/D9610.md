### D9610 — an inline list of un-annotated functions handed to an un-annotated parameter that the body binds to an annotated local

**loud emit reject · `vl check` rc 0 · `emitProgram: cannot take the generic function `inc0` as a value` · clause 2 · found closing [D9360](D9360.md) · present on master `88e064e88` · filed 2026-10-22 against master `88e064e88`**

Repro:

    function inc0(a) { return a + 1 }
    function early(a) {
      const k: ((x: i32) => i32)[] = a
      return k[0](4)
    }
    print(early([inc0]))
    // vl check rc 0.  vl run: emit error: emitProgram: cannot take the generic function `inc0`
    //   as a value ... No call site pins `inc0`

Want:

    5

#### Mechanism

Not traced. The literal's element is instanced from the pins of the parameter's element slot
(`monoOpenFnListPin`, emit_mono.vl), which take only a call's pin, and here the slot is reached
by an annotation alone. Admitting an annotation's pin there did not move the witness, so the
annotation's pin does not reach the parameter's slot either.

#### Ablation

| variant | outcome |
| --- | --- |
| `const g = [inc0]`, `early(g)` | runs, `5` |
| `return a[0](4) + k.length` in place of `return k[0](4)` | the same emit reject |
| `early(a: ((x: i32) => i32)[])` | runs, `5` |
