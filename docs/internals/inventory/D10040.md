#### Mechanism

The literal `x` is adopted node-side into the declared row `Node` (`anonValueFitsField`), but
the list literal's element row is asked of the arena type `{v: i32, next: null}` through
`shapeNominalOfTy`, whose field-set scan (`structRowOfObjFieldSetK`) compares field codes
only: a `null` field's code is not `Node | null`'s nested-struct code, so no row matched and the
element fell to the `i32`-list floor in `emitArrI32`. Once the list was held at `Node`, an
anonymous record's list field holding it (`{ items: xs }`) still keyed its element by the
literal's own spelling, a second list type the stored `Node[]` did not validate against, and
a field read through it refused with `field access receiver is not a struct`.
