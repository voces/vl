### D10040 — an inferred list of a record literal bound to a `const`, beside a declared record whose nullable field nests a record, is refused at emit

**loud emit reject · clause 2 · present on master `210107bfe` · found closing [D9963](D9963.md), as the list sibling of its map value · filed 2026-10-22 against master `210107bfe`**

Repro:

    type Node = { v: i32, next: Node | null }
    const x = { v: 1, next: null }
    const xs = [x]
    print(xs[0].v)
    // vl check: rc 0.  vl run: emitProgram: struct array elements are not supported

Want:

    1

#### Mechanism

Not traced. The literal is adopted into the declared row, as in [D9963](D9963.md), but the
list literal's element emit (`emitProgram`'s struct-element arm, wasmEmit.vl) does not reach
the row through `mvValRowOfShape`, which only the map value layer reads, so D9963's close does
not move it.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| no declaration of `Node` | prints `1` | **yes** |
| the literal inline, `[{ v: 1, next: null }]` | prints `1` | **yes**, the binding |
| `const xs: Node[] = [x]` | prints `1` | **yes** |
| `const x: Node = …` | prints `1` | **yes** |
| `next: Q \| null` over a non-recursive `Q` | refuses identically | no |
| `w: string \| null` in place of the nested record | prints `1` | **yes**, a nested-record field |

#### Grading list

The spellings above, and the list read through an un-annotated parameter
(`function f(v) { const xs = [v] … }` with a record argument), which refuses with the same
message without the declaration.
