### D15574 — a list of one hole parameter, slot-written with a second, bound at one call to one generic and at another to two, is refused

**loud emit reject · clause 2 · `vl check` rc 0, then `emitProgram: a generic function taken as a value reaches no call that fixes its type` · refused before and after [D15572](D15572.md)'s close · found closing D15572 · filed 2026-11-08 against master `0cfd71c8`**

Repro:

    function id<T>(x: T): T { x }
    function id2<U>(x: U): U { x }
    function use(ys) { print(ys.length) }

    // vl check: rc 0.  vl run: emitProgram: a generic function taken as a value reaches no call that fixes its type

#### Mechanism

Each call alone runs: `take(id, id)` is [D15568](D15568.md) and `take(id, id2)` is D15572. Together,
the first call refuses its argument. The second call joins `{id}` into `{id, id2}`, so `{id}` is decided
with the joined set, while the first instance binds both parameters to `{id}` itself. The two instances
hold `{id}` at two reps, and the decision takes neither.

| --- | --- | --- |
| `take(id, id)` | runs, `1` then `5` | **yes** |
| `take(id, id2)` | runs, `1` then `5` | **yes** |
| `take(id2, id)` in place of `take(id, id)` | runs | **yes** |
