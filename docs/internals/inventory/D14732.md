### D14732 — a call through a tagged set returning a list of ref elements took its result slot from the list type

**closed · refused at emit (`emitProgram: ref valtype with no interned shape`) until a call through a tagged set whose result is a list of ref elements took its result slot from that list's element (`emitFnTagDispatch`), as every other ref-list slot read does · a string result ran already · filed and closed 2026-10-31 against master `ef36ed6c`**

Repro:

    function wrap(a) { return [a] }
    function wrap2(a) { return [a, a, a] }
    const c = true
    const s = if c { wrap } else { wrap2 }
    function one(g, x) { return g(x) }
    print(one(s, [1]).length)
    print(s(1).length)

Want:

    1
    1

#### Mechanism

`fnTagDecide` tags `s`'s set, and the call inside `one` dispatches on its id. `wrap` at `i32[]`
returns `i32[][]`, a list of ref elements, and the dispatch's `if` took its result's table slot
from `rlSlotOfTy` of the list type rather than of its element, found none, and refused. The
call's arms and its mint fact were already right: retyping the arms changed nothing.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the direct call `s(1)` | runs | **yes** |
| `one(s, [1])` at `i32[]` (call it at `1`) | runs | **yes** |
| the choice (`const s = wrap`) | runs | **yes** |

#### Grading list

- `one(s, [1])` and `s(1)` in either order, through a binding, and indexed (`s(1)[0]`).
- `one(s, "ab")`, whose result holds no ref element, ran before the fix too.
