### D3076 — a literal-union value narrowed out of a `K | i32` box and handed to a lambda is passed as the box

**check-clean invalid wasm · clause 1 · 4 cells of the lane-LP lambda grid (every narrowed literal cell that fails; the generic un-annotated face refuses at emit instead) · the same on master `67ca68cf3` · filed 2026-09-28 against master `67ca68cf3`**

Repro:

    type K = "a" | "b"
    const zz: (K | i32)[] = ["a", "b", 3]
    const f = (w) => w == "a"
    for e in zz { if !(e is i32) { print(f(e)) } }
    // vl check: rc 0.  vl run: invalid module in the top-level code: type mismatch: expected
    // i32, found (ref $type)

Want:

    true
    false

#### Mechanism

Not investigated past the ablation. `e` narrows from the `K | i32` box to `K`, whose rep is an
interned `i32` atom, and the lambda instance takes that atom. The call hands it the box, so the
narrowed read that would unbox the atom does not run at a lambda's argument. The generic twin,
`app<T>(x: T, p: (T) => boolean)` given a narrowed `q: K | i32`, keys the instance at the
wide `K | i32` (a loud `no interned signature (K|i32)=>boolean`) when the lambda is
un-annotated, and fails validation inside `app` when it is annotated `(w: K)`.

| the generic `app<T>(x: T): T` with no callback | runs | **yes**, at the generic |
