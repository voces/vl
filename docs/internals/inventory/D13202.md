    function add(a, b) { return a + b }
    function apply2(g, s) {
      print(g(s, s))

#### Mechanism

Measured. The keys are `c:_,f64,` and `c:_,_,`, each naming the element's `s`. The `g` slots
of list siblings are unified in fn-flow, so `monoElemPinTysUnder` read `apply2`'s pin
`(?s, ?s)` while computing `apply3`'s parameter types, and the instance stayed open.
