### D13202 — a named generic handed to list elements whose keys all name an element's value parameter is refused

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: neighbouring spellings build, see the ablation ([D10700](D10700.md), [D12701](D12701.md)) · found closing [D12701](D12701.md) · present before lane L1's D12701 PR (seed at `e07ab908c`) and after it · filed 2026-10-25 against master `db5624b1c`**

Repro:

    function add(a, b) { return a + b }
    function apply2(g, s) {
      print(g(s, s))
    }
    function apply3(g, s) {
      print(g(s, 0.25))
    }
    for f in [apply3, apply2] { f(add, 0.5) }
    // vl check: rc 0.  vl run: emitProgram: a generic function is passed to a function value whose parameter type names a type parameter this closure does not bind

    0.75
    1

#### Mechanism

Not measured. The keys are `c:_,f64,` and `c:_,_,`, each naming the element's `s`. With `add`
named at the call, no hole of an enclosing function carries the slot, so the instance must
come from the element's own value binding.
