### D13964 — a returned re-pointed `let` of two hole functions, handed to a callee, is never judged, so the callee's call traps

**loads then traps · `vl check` rc 0, `wasm trap: indirect call type mismatch` · clause 1 · open · the direct call `sel(true)(3)` is refused at the write (`cannot write 'str' to 'f'`) · found beside [D13963](D13963.md) · filed 2026-10-26 against master `8a0465bd3`**

Repro:

    function inc(a) { return a + 1 }
    function str(a) { return "s" }
    function sel(c: boolean) {
      let f = inc
      if c { f = str }
      return f
    }
    function ap(f, x) { return f(x) }
    print(ap(sel(true), 3))
    // vl check: rc 0.  vl run: wasm trap, indirect call type mismatch

#### Mechanism

The hole-argument judge in `check_calls.vl` runs for an argument that is an `Ident` with two or
more written functions, or one `holeFnReadsSlot` accepts. A call argument is neither:
`holeFnReadsSlot` walks the call's returns to the `let` read, and accepts only slot and choice
reads, not a re-pointed `let`. So `holeLetJudge` never sees the binding. The direct call takes
the call-result path, which judges every read, and refuses.
