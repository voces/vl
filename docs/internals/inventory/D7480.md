### D7480 — a nested function that captures, read twice in one frame, compares unequal to itself

**check-clean silently wrong · wrong value · `vl check` rc 0 · clause 1 · under the [D7180](D7180.md) ruling a function value's identity is its declaration and captures, and both reads capture the same frame's `n`, so `a == b` is `true` · the same nested function capturing nothing prints `true`, and so does a capturing lambda copied into a second binding · found closing [D7382](D7382.md) · present on master `1c86d0f42` · filed 2026-10-19 against master `1c86d0f42`**

Repro:

    function outer(n: i32) {
      function inner(x: i32): i32 { return x + n }
      const a = inner
      const b = inner
      print(a == b)
    }
    outer(3)
    // PRINTS false

Want:

    true

#### Mechanism

Not located. Each read of a capturing nested function builds a fresh closure with a fresh
environment, and a closure comparison compares the environment by reference, so two reads of
one declaration in one frame differ.
