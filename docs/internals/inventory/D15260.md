#### Mechanism

A call whose callee is a join or a list element of a tagged set is dispatched per member by mono.
The root row pass's per-arm loop (`fnTagCallArms`) mints each member's instance at the call's
arguments, with `elabSetArgBind`'s set binding, but notes a key only against a member's own direct
call, never against the arm of the dispatched call. `elabCallInstFrom` therefore answers -1 for the
arm, and `monoPinHoleParam` reads the argument instead of a binding. With the split plan on, the
plan covers the arm; with it off, deleting the argument read refuses `add` as a generic value.
