### D6750 — the check skip serves an edit that adds a plain-name value use of a fresh builder in a module that does not import it

**now a loud check reject under the skip too, closed by lane S5 banking each fresh value's occurrence digest in every module · loud check reject on the whole check · on master the skip served the edit with no diagnostic · clause 1 (skip soundness) · found by lane S5 while enumerating the fresh-literal adoption's inputs · filed 2026-10-18 against master `89cdf67b1`, and present before #4131 too**

Repro:

    // file: lib.vl
    export function area(n: i32): i32 { return n * 2 }
    function zz(mk: i32): void { print(mk) }
    // file: lib2.vl
    export function mk() { { f: 4 } }
    // file: main.vl
    import { area } from "./lib"
    import { mk } from "./lib2"
    let v = { f: 1.5 }
    v = mk()
    print(v.f)
    print(area(2))
    // vl check: rc 1, main 4:4 `{f: i32} is not {f: f64}`.  An armed check banked without
    // `zz` in lib.vl, then given this lib.vl as the edit, served it with no diagnostic.

#### Mechanism

`main`'s `v = mk()` adopts `mk`'s literal at `{f: f64}` only while `mk` has a single call site
(`recFnBuiltAtDst`, check_fit_rules.vl). `rcwCallSites` counts the occurrences of the PLAIN name
`mk` in every module, and any one that is not a callee is a value use that makes the count
unknown. So `zz`'s parameter read in lib, a module that does not import `mk`, withdraws the
adoption and `main` refuses. The skip re-checked only lib: lib's interface did not change, and
`skFreshBanked` declines only for a pair whose ORIGIN is in S, here (main, lib2), with lib2 not
in S. Nothing compared lib's occurrences of the name.

#### Ablation

| ingredient changed | outcome under the skip | needed? |
| --- | --- | --- |
| `zz` calls a parameter `mk` (`mk()`) | declines `ambient` | **yes**, a value read |
| a local lambda named `mk` in lib | serves, and the whole check agrees | **yes**, a use the frame does not resolve elsewhere |
| `v = mk()` removed from main | serves, and the whole check agrees | **yes**, an adopted delivery |
