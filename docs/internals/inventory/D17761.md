### D17761 — a fresh binding adopted at a record of `f64 | string` would read its `i32 | string` field as the `f64`

**runs today and must keep running · a refutation pin: F2's adoption at a widening union leaf printed `lost i32` here · filed 2026-11-27 against master `1faa021d1` by lane CENSUS**

Repro:

    type D = { v: f64 | string }
    const xn: i32 | string = 3
    const on = { v: xn }
    const dn: D = on
    print(dn.v)
    const tn = on.v
    if tn is i32 { print(tn / 2) } else { print("lost i32") }

Want:

    3
    1

#### Mechanism

As D17760, without the `null`: the read `on.v` would take `D`'s field type, which keeps the
numbers of the union apart only at the delivery (D3011), not in the binding. `destAdopts`
refuses the non-literal union leaf.
