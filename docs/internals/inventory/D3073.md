### D3073 — a function value returning `Circle[]` delivered as `() => readonly Shape[]` keeps its own signature, and the call through the wider type traps

**closed · a function value delivered at a function type of another rep is rewritten into an adapter at that type · fixture `tests/cases/closures/fn-value-adapter-at-wider-type.vl` · was trap after load · found grading [D3058](D3058.md) · filed 2026-09-28 against master `67ca68cf3`, closed 2026-09-30 against master `3291e99e1`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    function mkf(x: Circle[]): () => readonly Shape[] {
      const g = () => x
      return g
    }
    const f = mkf([{ r: 1 }])
    print(f().length)
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch

Want:

    1

#### Mechanism

The checker accepted the covariant result, but no function value was converted on the way: `g`
kept its own `() => Circle[]` signature, and the call through `() => readonly Shape[]` was a
`call_indirect` at the other one. `assignableExpr` now hands every delivery of a function value
whose type may differ in rep from the destination's to `fvaAdapt` (typecheck.vl), which rewrites
the value in place into `(p…): R => f(p…)` at the destination type and checks it as written
code, so each argument and the result convert through the ordinary delivery. A function
declaration or a `const` is called directly; any other value is read once, as the argument of a
lambda called in place. A list or object literal adapts each element; a function already inside
a container or behind `| null` is refused at check, since nothing converts it there. The result
here is the [D3041](D3041.md) view, which needed [D3380](D3380.md)'s row for a call result.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `return () => x` directly | runs, prints `1` | **yes** (a value with its own signature) |
| `g` returned as `() => readonly Circle[]` | runs, prints `1` | **yes** (the widening) |
| a named `function h(): Circle[]` passed as a `() => readonly Shape[]` argument | the same trap | no |
| `h` bound to a `const f: () => readonly Shape[]` | loud emit reject (`closure ref-list result element twin`) | no (another face) |
| a scalar `() => i32` returned as `() => i64` | loud check reject | no (the checker refuses it) |
