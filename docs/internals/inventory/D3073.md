### D3073 — a function value returning `Circle[]` delivered as `() => readonly Shape[]` keeps its own signature, and the call through the wider type traps

**trap after load · clause 1 · found grading [D3058](D3058.md) · the same on master `67ca68cf3` · filed 2026-09-28 against master `67ca68cf3`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    function mkf(x: Circle[]): () => readonly Shape[] {
      const g = () => x
      return g
    }
    const f = mkf([{ r: 1 }])
    print(f().length)
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch

Want:

    1

#### Mechanism

Not investigated past the ablation. The checker accepts a function type whose result is a record
list where the result is a `readonly` list of a union holding it (a covariant return), but no
function value is converted on the way: `g` is built with its own `() => Circle[]` signature,
and the call through `() => readonly Shape[]` is a `call_indirect` at the other signature. A
lambda written directly in the return position takes the destination's signature and runs
([D3058](D3058.md)); a value that already has a signature needs an adapter, or the checker has
to refuse the delivery. Deciding between those two is a question about function-type variance.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `return () => x` directly | runs, prints `1` | **yes** (a value with its own signature) |
| `g` returned as `() => readonly Circle[]` | runs, prints `1` | **yes** (the widening) |
| a named `function h(): Circle[]` passed as a `() => readonly Shape[]` argument | the same trap | no |
| `h` bound to a `const f: () => readonly Shape[]` | loud emit reject (`closure ref-list result element twin`) | no (another face) |
| a scalar `() => i32` returned as `() => i64` | loud check reject | no (the checker refuses it) |

#### Grading list

The argument, binding, return and record-field positions for a named function and a bound
lambda, and the nullable and scalar-pair results.
