### D15161 — a map written two functions of different result types, handed to an un-annotated parameter that reads it by get, is refused at check

**loud check reject · `cannot write 'half' to an element of 'm'` · clause 2 · open, target `1.5` · found closing [D15137](D15137.md): the read in the binding's own scope runs · filed 2026-11-03 against master `b813a46b`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function run(m) {
      const g = m.get("b")
      if g != null { print(g(3)) }
    }
    const m = Map()
    m.set("a", inc0)
    m.set("b", half)
    run(m)
    // Want: 1.5

#### Mechanism

`holeSlotJudge` (check_relate_core.vl) judges a read through a parameter one call argument at a time (`holeSlotArgJudge`), and that path does not take the lift D15137 gives a binding whose slot writes `elabSlotJoinTy` joined.
