### D15161 — a map written two functions of different result types, handed to an un-annotated parameter that reads it by get, is refused at check

**loud check reject · `argument 1: parameter is used as a map but nothing in the body pins its key or value — add a type annotation` · clause 2 · open, target `1.5` · found closing [D15137](D15137.md): the read in the binding's own scope runs · filed 2026-11-03 against master `b813a46b` · refused since #6138 by the un-annotated map parameter floor (`tests/cases/maps/error-infer-param-map-not-pinned.vl`; lifting it is bidirectional inference, ROADMAP E5), and the function-value half is [D15174](D15174.md); filed with `cannot write 'half' to an element of 'm'`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function run(m) {
      const g = m.get("b")
      if g != null { print(g(3)) }

#### Mechanism

`holeSlotJudge` (check_relate_core.vl) judges a read through a parameter one call argument at a time (`holeSlotArgJudge`), and that path does not take the lift D15137 gives a binding whose slot writes `elabSlotJoinTy` joined.

Two further gaps stand behind this one, and D15167's close leaves both. A hole parameter that only
reads its map refuses every map argument when it is declared before the call, the deliberate floor
in `tests/cases/maps/error-infer-param-map-not-pinned.vl` (ROADMAP E5). Declared after the call,
the witness passed check and refused at emit, which was [D15174](D15174.md), now closed: that
spelling prints `1.5`, and the E5 floor is the one blocker left.
