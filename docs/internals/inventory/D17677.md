#### Mechanism

`mk` returns its `let` at its declared result row, while `xs`'s ref-list slot lays elements out at
another row on another struct heap. Each call result therefore reaches the list literal at a record
rep that no retag joins to the element's. D17671's close builds a returned literal at the result's
row; a returned place is not a literal, so the value itself has to be held at the row the list
stores. This is the records part of the "place reads at storage" series.
