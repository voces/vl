#### Mechanism

Not traced. With one member (`[inc, null]`, D17865) the set is tagged and the list is the nullable
id's list. With two members the same list's `null` meets a closure element rep, so the two-member
set is not held as ids here. Other spellings refuse at other sites: the element read past a null
test, `const f = xs[0]` (`global initializer coercion`); a join `[if c { inc } else { null }, dbl]`
walked by a `for` (`narrowed read`).
