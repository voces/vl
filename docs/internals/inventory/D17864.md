### D17864 — a set delivered to a written union of function types is refused, though each member fits some arm

**loud check reject · clause 2, M1-adjacent, queued after M3 (coordinator) · `cannot assign (_) => string | boolean to 'k' of type F` · emit reject on master, check reject since M1 · filed 2026-11-28 against master `15901f4e3` by lane CENSUS**

Repro:

    function str(_a) { return "s" }
    function bo(_a) { return true }
    type F = ((a: i32) => string) | ((a: i32) => boolean)
    function run(c: boolean) {
      const g = if c { str } else { bo }
      const k: F = g
      print(1)
    }

#### Mechanism

The choice's type is one function type at the join of its members' results (M1). Assignability
compares that one type with each arm of `F`, and neither arm takes a `string | boolean` result.
A set-aware assignability admits a set when each member fits some arm. On master the same program
was an emit reject (`cannot take the generic function \`str\` as a value`).
