### D16746 — a `for i in a until b` loop indexing an un-annotated list parameter is refused at emit with an internal message

**loud emit reject · clause 1 (check accepts what emit refuses) and clause 2 · found closing [D16744](D16744.md) · filed 2026-11-16 against master `7de99c68a`**

Repro:

    function run(xs) { for i in 0 until 2 { print(xs[i] + 1) } }
    run([1, 2])
    // vl check: rc 0.  vl run: emit error, "emitProgram: identifier is not a parameter, local, or global"

Want:

    2
    3

#### Mechanism

Not yet located. The loop's index read of the parameter is the ingredient. Without it, and with
the parameter annotated or the loop a `while`, it runs.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| parameter annotated `xs: i32[]` | runs | **yes** |
| the element read dropped (`print(i)`) | runs | **yes** |
| the bound `xs.length` or a `const n` instead of `2` | still refused | no |
| elements functions instead of numbers | still refused | no |

#### Grading list

- `for i in 0 until xs.length { print(xs[i](3)) }` over a list of functions.
