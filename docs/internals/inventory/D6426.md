### D6426 — a generic called with values of two distinct type parameters at one of its own is check-clean invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · DESIGN: the checker owes the refusal it gives the direct spellings · found grading [D6372](D6372.md) · filed 2026-10-18 against master `066d19373`**

Repro:

    function g<T>(x: T, y: T): T { return y }
    function f<T, U>(a: T, b: U): T { return g(a, b) }
    print(f(1, "s"))
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `f`: type mismatch: expected i32, found (ref $2); $2 is `string`

#### Mechanism

From the ablation only. The checker accepts `g(a, b)` with `a: T` and `b: U` as a call of
`g` at one type, so `f`'s result, typed `T`, holds the `U` value. Read directly, the same
mismatch is refused at check.

#### Ablation

| spelling | outcome | needed? |
| --- | --- | --- |
| the witness | check-clean invalid wasm | — |
| `return b` for `return g(a, b)` | loud check reject, `return type mismatch: expected i32, got string` | **yes** |
| `const c: T = b` then `return c` | loud check reject, `cannot assign string to 'c' of type i32` | **yes** |
| `print(f(1, 2))` | runs, `2` | **yes** |
