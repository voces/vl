#### Mechanism

A depth-16 `--names` profile puts the cost under `collectA` → `mvShapeOfMapNodeTy` →
`mvShapeOfValNameTys`, in `structIndexOfTypeName` and `mvValKindOfNameTy` over the value
record's render, `7·2^depth` characters, and under `sigKeyOfTy` → `annParamKindTy` for the
parameter. The parameter is not needed: the map binding alone still doubles, so the walk that
spells the value is the map's shape collection, not the signature.

#### Grading list

**Left open by the lane that closed D9512-D9515, 2026-10-22.** The cost is not a signature
token a rung can answer from the type. `collectA` → `mvShapeOfMapNodeTy` renders the map value
with `nodeTyMapValName` and hands the spelling to `mvShapeOfValNameTys`, `mvValKindOfNameTy`
and `structIndexOfTypeName`, and `sigKeyOfTy`'s map arm reaches the same spelling through
`mvSlotOfMapNameTys`: the map-value tables are keyed on the value's render, so a close needs
those tables keyed on the arena type rather than a rung in front of them. The fuel is
unchanged by that lane (64.9M, 189.4M and 2.45e9 at depths 8, 12 and 16). With D9512 closed,
`tests/vl_compile_gc_test.ts` takes this row's witness at depth 23, which traps under the
null collector in `mvShapeOfMapNodeTy` → `tyToEmitNameAt` in a fraction of a second; when
this row closes, the test needs a witness that still traps.

**After a deep declared record's map finds its slot from the arena type, 2026-10-22.**
`mvShapeOfMapNodeTy` asks `mvDeclRecSlotOfTy` before rendering the value: a value that is a
declared record owning its struct row, not a variant and nested past depth 8 (the threshold
`tyEmitNameKey` uses) takes the slot `mvSlotOfTyKArm` interns from the type. The row must
have no layout twin, neither another struct row the scan may match (`sigRowHasNoTwin`) nor a
variant arm with the same field names (`sigRowHasNoArmTwin`): the render path keys a twin's
map on the same spelling, so `{[string]: Dot}` beside an arm `Circle = {r: i32}` takes
Circle's slot there (`tests/cases/maps/arm-valued-map-beside-layout-twin.vl`). `sigParamTokOfTy`
asks `sigDeclRecMapTokOfTy` for a string- or i32-keyed map parameter of such a record, keyed by
the same slot. The depth bound is load-bearing: master interns the annotation's map under a
nominal key and the node's map again under its render, and an unbounded rung that reuses the
first slot changes module bytes at every depth while the disassembly stays identical. Below
the bound every program takes master's path. Before landing, a validating seed with the bound
removed computed both answers wherever the rung fired and trapped when the slots' value kind,
struct row, key kind, variant, arm signature or ref-list slot differed, or when the signature
token differed; a control seed trapped whenever the rung fired. Over the 16,265 files of
`tests/cases` and the distilled corpus the validating seed trapped in none, and the control
seed trapped in 93. With the bound, the module of every one of 16,274 files and the
