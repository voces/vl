#### Mechanism

`mvShapeOfValNameTys`, in `structIndexOfTypeName` and `mvValKindOfNameTy` over the value
record's render, `7·2^depth` characters, and under `sigKeyOfTy` → `annParamKindTy` for the
parameter. The parameter is not needed: the map binding alone still doubles, so the walk that
spells the value is the map's shape collection, not the signature.
