#### Mechanism

The outer list literal joins its record elements. The field's literal in one sibling is
all-`null` (`[null]`), so it names no element type, and in another it holds a list (`[[1]]`). The
two siblings are built at different reps for the same field `(i64[] | null)[]`, and the list
literal stores both, so the module fails to validate. Either sibling alone runs, as do the same
two records built as separate `const`s, a map of them, and the field's two literals in one list
(`[null, [1]]`). The element must be a list: a nullable record, string or scalar element runs.
