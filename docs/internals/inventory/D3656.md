### D3656 — an `if` nested in an arm of an ANNOTATED return's join boxes its widened runtime tail at the tail's own type

**check-clean silently wrong · clause 1 · D3571's mechanism at the return position · found by the #3379 review (`rv79`) · the same on master `32b753681` and with #3379 · filed 2026-10-05**

Repro:

    function mk(q: i32 | null, r: i32 | null): i32 | f64 {
      if q != null { q } else { if r != null { r } else { 2.5 } }
    }
    const x = mk(null, -3)
    print(x is f64)
    print(x / 2)
    // master printed false, -1

Want:

    true
    -1.5

#### Mechanism

A prediction until a close confirms it. The inner `if` alone types `f64`, as in
[D3571](D3571.md), but the tail of a function body delivered to an annotated union return is
lowered by the return path's own union chain, which #3379's `ifJoinAdaptsScalar` does not reach:
`r` is boxed at its own `i32` member of `i32 | f64`.
