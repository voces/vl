### D2676 — a type parameter bound only by an explicit type argument leaves a body union with a map member answering `is` false for the map it holds

**check-clean silently wrong · clause 1 · found grading D2493's close · identical on master · filed 2026-09-26 against master `525837973`**

Repro:

    function g<V>(n: {[i32]: i32}) {
      const u: V | {[i32]: i32} = n
      u is {[i32]: i32}
    }
    const mi: {[i32]: i32} = Map()
    print(g<string>(mi))
    // PRINTS false

#### Mechanism

`V` appears in no parameter, so only the explicit type argument binds it. The same body with
`V` also bound by a parameter (`g<V>(m: V, n: {[i32]: i32})`, called `g("s", mi)`) prints
`true` since D2657's close (`false` on master too): that instance registers the union the pin
mints and boxes `n` under its member's tag. Here the body's `V | {[i32]: i32}` is not lowered as that registered union, and the
test reads the map member's tag off something that does not carry it. Not yet measured further
than the ablation below.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `V` bound by a parameter too (`g<V>(m: V, n)`, `g("s", mi)`) | prints `true` | **yes** |
| the map member (`const u: V \| R = n` over `type R = { a: i32 }`) | `emitProgram: ref valtype with no interned shape` | **yes** — a record member is loud |
| the same-rep pair (`V := {[i32]: string}`, or `V := {[i32]: boolean}`) | the same `false` | no |

#### Grading list

The three spellings in the ablation, each printing `true` once closed.
