#### Mechanism

**The ingredient is the two holes agreeing, not disagreeing** — which is the opposite of what
the axis was built to look for. The sampler's second-hole table draws seven differing reps and
one `same` control; over 519 `generic2` pairs the differing reps produced **0** disagreements
between them and `same` produced **18**, five of them SILENT.

Both holes must be a MAP. A list, a struct and a scalar at both holes all run, so it is not
"one instance, two holes at one rep" in general; and the map's VALUE type is not the ingredient
either — `{[string]: i32}` at both holes is invalid wasm too.

#### Closed

The ablation above held the second argument fixed at a map, and that hid the ingredient. The
second argument was always an empty `Map()`, and an empty `Map()` handed to any type parameter
was invalid wasm on its own: `function p1<B>(b: B): i32 { return 1 }` with `p1(Map())`, and
`p1(Set())` too. The first argument being a map was never needed. The elaboration left the call's
row at `{[_]: _}`, so mono pinned `B` at the unbound default `i32` while the caller built a map.

`elabEmptyElemsAtI32` now closes an empty map's or set's open key at `string` and open value at
`i32`, which is the mono map `emitMapNew` builds for an unpinned `Map()`. Mono's
`monoOpenArgDefaultPin` reads that closed parameter type when the argument's own type still
reaches an inference hole (`tyReachesHole`; `{[_]: _}` has no `TyVar`, so `tyHasTyVar` missed it).

back through an identity into `{[string]: i32}` and into `{[i32]: string}`, and a nested generic.

`p1(if true { Map() } else { null })` (D14889). Fixture:
