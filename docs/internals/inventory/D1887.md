#### Mechanism

The ingredient is an empty `Map()` or `Set()` handed to a type parameter, whatever the other
arguments are. `function p1<B>(b: B): i32 { return 1 }` with `p1(Map())` is invalid wasm on
its own, and so is `p1(Set())`. The first argument being a map is not needed. The sampler's
`same` control happened to pair two maps, and the second one was always an empty `Map()`.

The empty map's type is `{[_]: _}`. Its key and value are inference holes, not type variables.
The elaboration closed an empty `[]` at `i32[]` (`elabEmptyElemsAtI32`), but it had no arm for
a map, so the call's row stayed open. Mono's `monoOpenArgDefaultPin` asked `tyHasTyVar` whether
the argument was open. That is false for `{[_]: _}`, so mono kept the unbound default `i32` for
the parameter. The caller then built the map struct and handed it to an `i32` parameter.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `p1<B>(b: B)` with `p1(Map())`, no other argument | still invalid wasm | no (a second parameter) |
| a first argument that is not a map (`pass2(1, Map())`, `pass2([1], Map())`) | still invalid wasm | no (a map at the first hole) |
| `{[string]: i32}` or `{[string]: string}` as the first argument | still invalid wasm | no (the value type) |
| `Set()` for `Map()` | still invalid wasm | no (map rather than set) |
| an annotated empty map, `const e: {[string]: i32} = Map()`, as the argument | prints `1` | **yes** (the inference holes) |
| `[]` for `Map()` | prints `1` | **yes** (the map; `[]` is already closed at `i32[]`) |
| a concrete parameter type | prints `1` | **yes** (the type parameter) |

#### Closed

`elabEmptyElemsAtI32` now closes an empty map's or set's open key at `string` and open value at
`i32`, which is the mono map `emitMapNew` builds for an unpinned `Map()`. Mono's
`monoOpenArgDefaultPin` reads that closed parameter type when the argument's own type still
reaches an inference hole (`tyReachesHole`; `{[_]: _}` has no `TyVar`, so `tyHasTyVar` missed it).

Now runs: the witness, `p1(Map())`, `p1(Set())`, a second parameter at `Map()`, `Map()` handed
back through an identity into `{[string]: i32}` and into `{[i32]: string}`, and a nested generic.

`p1(if true { Map() } else { null })` (D14889). Fixture:
