#### Mechanism

`cwIxBuild` runs once per arena length, and twice in a `vl check` (D7580). Each build called
`nodeSpineChildren` for every node in both the frame walk and the parent pass, allocating a fresh
list each time; resolved an identifier's frame through `cwFrameOfUse`, which interned the name,
and then interned it again for the occurrence row; kept the frame parent table in an `i32` map; and
grew seven per-node columns and the root-dedup set one push or one map probe at a time. Both node
walks also tested kinds in an order unrelated to how often they occur, and a `match` tests its arms
in order. The index answers the same questions in the same order; only the cost of building it fell.
