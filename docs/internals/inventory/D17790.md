### D17790 — a list-of-records element's function field, copied into a record annotated at another signature, keeps the closure of the instance an other call pinned

**closed 2026-11-28 by lane START-2 — the witness prints `2`, `2.5` · a literal a function called at two or more sites returns is the join of its calls, so its record field holds the set's ids (`recRetSharedLeaf`), and each delivery site converts the id with a value arm keyed by (site, set, signature) · fixtures `tests/cases/functions/set-value-converted-at-each-delivery-site.vl`, `tests/cases/functions/set-value-converted-in-annotated-lambda-result.vl` · both sites in one program stay open as [D17802](D17802.md) · was: loads then traps · clause 1 · filed 2026-11-28 against master `2693ffdcf`**

Repro:

    function id(a) { return a }
    function deliver() { return [{ f: id }] }
    const u = deliver()
    print(u[0].f(2))
    for r in deliver() {
      const h: { f: (a: f64) => f64 } = { f: r.f }
      print(h.f(2.5))
    }
    // vl check: rc 0.  vl run: 2, then wasm trap: indirect call type mismatch

Want:

    2
    2.5

#### Mechanism

The set `{id}` is not tagged for a list of record literals (`ftCallFreshLits` takes a record
literal only), so the list's elements hold the closure of the instance `u[0].f(2)` pins, at
`(i32) => i32`. `{ f: r.f }` copies that closure into the `(f64) => f64` field with no
conversion, and the call through it traps. The family of [D17775](D17775.md): the same
delivery as a `.map` lambda's annotated result is refused at check instead.

#### Ablation

| spelling | outcome |
| --- | --- |
| this repro | trap |
| a lambda called directly, `const k = (r): { f: (a: f64) => f64 } => ({ f: r.f })` at `deliver()[0]` | trap |
| an index read bound first, `const w = deliver()[0]` then `{ f: w.f }` | runs |
| no `u[0].f(2)` | runs |
