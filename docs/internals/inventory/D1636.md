### D1636 — `structIndexOfExpr` had no MODULE-frame `let` rung, so a block binding's field read resolved to no struct

**closed · filed 2026-09-05 against master `abecf8da` · closed against `d040e263`**

`structIndexOfExpr`'s Ident arm gained the module-frame `let` rung, ANNOTATED only. The
annotated rebind runs, and the un-annotated face and the literal-fed control are unchanged.

Repro:

    type W = { f: { name: string, n: i32 } }
    const m: { [string]: { name: string, n: i32 } } = Map()
    m["k"] = { name: "ada", n: 3 }
    const mv = m["k"]
    if mv != null {
      const w: W = { f: mv }
      w.f = mv
      const v: { name: string, n: i32 } = w.f
      const g = () => v
      print(g().n)
    }
    // vl check: rc 0.  vl run: the emitted module failed to validate inside the module's
    // top-level code: type mismatch: expected (ref $type), found (ref null $type)

#### Mechanism

Not the annotation, and not the `??` family: the probe reads `memCode=-1 recvStructIx=-1
recvModLet=27 recvLetStructIx=1`, so the receiver's row IS resolvable from the arena — it is
`structIndexOfExpr` that never asks. `w` is bound inside a module-scope BLOCK, which is no
frame's `fnBody` and not a global, so the Ident arm's four rungs (params, the emit-time
declared-locals table, the globals registry, the capture set) are all silent and D1633's
`frameLetOf` returns -1 at `fnIx < 0`. The table that would answer speaks only while the
start function's body is emitted, and the env struct is typed in the type section.

With the receiver unresolved, `w.f` classified as no field, the annotated rebind kept the
bare-struct kind, and the env field was declared non-null over a `(ref null $S)` local — the
field's storage, which the map-read source is what interned that way.

**The rung is ANNOTATED-only, and that is the whole safety argument.** An initializer
resolves against the frame it is written in, so reading one from outside can name a
different row than the local was declared at: the unrestricted rung answered row 0 for an
un-annotated `const g1 = m[k] ?? {r: null}` and cost 18 corpus classes (66 cells)
`runs -> check-clean invalid wasm`. An annotation reads the same from anywhere.
