    function inc(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function deliver(n) {
      const w = [inc, dbl]
      return [w]
    }

Want:

#### Mechanism

The returned literal's element is the local `w`, and `deliver`'s one instance walked the
template's own body, which `monoRecordInstOpen` leaves open. So neither `w`'s binding nor the
returned literal was recorded. The instance now takes its own copy of each:

* the `const` of a list of function names left open at a function (`monoLetOwnCopy`, with
  `monoInstLetCopy` mapping a shared read to it);
* the returned literal (`monoRetBoundLitCopy`).

`monoRetLitElemTy` types the returned literal from the bound element's pinned type, which is
[D9661](D9661.md)'s change (`monoBoundFnListElemsTy`, emit_mono.vl).
