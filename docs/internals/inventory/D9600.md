### D9600 — a returned nested list of un-annotated functions whose inner list is bound to a local first has no interned shape

**loud emit reject · `vl check` rc 0 · `ref valtype with no interned shape`, no position · clause 2 · found closing [D9551](D9551.md) · present on master `8789642ad` · filed 2026-10-22 against master `8789642ad`**

Repro:

    function inc(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function deliver(n) {
      const w = [inc, dbl]
      return [w]
    }
    const v = deliver(1)
    print(v[0][1](3))
    // vl check rc 0.  vl run: emit error: emitProgram: ref valtype with no interned shape

Want:

    6

#### Mechanism

Partly traced. [D9551](D9551.md)'s fix records the inner literal's type where the returned
literal holds it inline (`monoRetLitElemTy`, emit_mono.vl). Here the returned literal's element
is the local `w`, and a probe on the read of `w`'s slot counted zero pins in each of `deliver`'s
walk contexts, so the caller's pin on `e.e` does not reach the literal `w` is bound to. Why it
stops at the local is not traced.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the local (`return [[inc, dbl]]`) | runs, `6` | **yes** |
| the parameter (`deliver()`) | same refusal | no |
