### D17797 — a maker called at two types beside another maker of the same un-annotated function is refused at emit

**loud emit reject · `a generic function taken as a value reaches no call that fixes its type` · clause 1 · `vl check` rc 0 · filed 2026-11-28 against master `77e1160e` by COV-CLOS-3 (found writing D17129's witness)**

Repro:

    function inc0(a) { return a + 1 }
    function mk(f) { return { f: f } }
    print(mk(inc0).f(3))
    function mk2(f) { return { g: f } }
    print(mk2(inc0).g(3))
    print(mk2(inc0).g(4.5))
    // vl check: rc 0.  vl run: emit error at 5:11, "reaches no call that fixes its type"

Want:

    4
    4
    5.5

#### Mechanism

Not traced. `mk2`'s two calls pin `inc0` at `i32` and at `f64`; alone they run, as does `mk`
alone. Together, the first `mk2` call's argument finds no pin.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `mk` maker and its call | runs | **yes** |
| `mk2`'s `f64` call | runs | **yes** |
| `mk` replaced by a direct `print(inc0(3))` | runs | **yes** |
| `mk` called twice at `i32` | still refuses | no |
