### D5171 — a copy of a written `let` of a generic called both at `string` and at a string literal union is refused

**loud emit reject · `vl check` rc 0 · clause 2 · OPEN · found while re-grading D4244 · filed 2026-10-17 against master `8eed466cb`**

Repro:

    function gA<U>(u: U) { print("A"); print(u) }
    function gB<V>(v: V) { print("B"); print(v) }
    type S = "p" | "q"
    const a: S = "q"
    let x = gA
    x = gB
    let y = x
    y("r")
    y(a)
    // vl check: rc 0.  vl run: the function binding `y`, a copy of a reassigned binding, is called at more than one argument type

Want:

    B
    r
    B
    q

#### Mechanism

D4244 runs when the `string` call goes through `x` and the union call through the copy `y`,
and `x("r")` with `x(a)` runs with no copy. Here the COPY takes both calls, and the split
refuses a copy called at two argument types. An unmerged candidate that annotates each member
of the copy set at its call's signature in the instance record ran this witness and the variant
below (branch `l1-bank-at-call-signature-reference`); it was not landed, because #3941 closed
D4892 and D4893 by another mechanism first.
