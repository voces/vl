#### Mechanism

The same collection gap as D3115, at a leaf D3115's close does not mint. At an `i32 | null` or
`i32 | string` pin the inner `[x]` is a list of union boxes, so the outer element is a ref list
of a ref list, a row `arrLitFrameLeafRow` does not name: it answers only the three scalar-leaf
rows. The outer literal keeps the template's `i32[]` row, and the inner box list is stored into
an `i32`-list backing.
