### D3461 — a nested record literal whose outer field is named like a field of a record arm in a scope-level union refuses at emit

**loud emit reject · clause 2 · open · pre-existing, the same on master `c17016a1e` · filed 2026-10-02 against master `c17016a1e`**

Repro:

    const v: i32 | { a: i32 } = 5
    const n = { a: { b: 7 } }
    print(n.a.b)
    // vl check: rc 0.  vl run: emitProgram: field access receiver is not a struct

Want:

    7

#### Mechanism

Not localised past the ablation. The union's arm `{ a: i32 }` is a record with a field named `a`,
and `n`'s outer field is also `a`; reading through `n.a` then meets the arm's `i32` field where the
inner record should be, so the receiver of `.b` is not a struct. The two records have nothing else
in common and `v` is never read. The sibling that reads the inner field as a list is not a
refusal but invalid wasm (last ablation row), so the family reaches clause 1 as well.
