### D2219 — a closure capturing a literal-union atom narrowed to a set that another declaration names returns a string into an i32 result

**check-clean invalid wasm · `type mismatch: expected i32, found (ref $type)` inside the closure · found reviewing D2205's close · filed 2026-09-23 against master `0d5421468`**

Repro:

    type M = "x" | "y" | "z"
    function takeYZ(k: "y" | "z") { print(k) }
    function f(m: M) {
      if m is "x" {
        print("x")
      } else {
        takeYZ(m)
        const g = () => m
        print(g())
      }
    }
    f("y")

#### Mechanism

The narrowed type (`"y" | "z"`, minted by the else-branch subtraction) is a fresh union whose
member set equals one another declaration registered (`takeYZ`'s parameter, or a `type YZ`).
The closure's inferred result is classified by that set: `litUnionAliasNameOfTy` finds the
registered set, so the result valtype is the i32 atom. The closure's return widens the captured
atom to a string anyway, so its body pushes a string ref where its signature declares an i32.
With no declaration naming the set the same closure runs, typed and widened as a string.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the declaration naming `"y" \| "z"` (`takeYZ`, or `type YZ = "y" \| "z"`) | runs | **yes** |
| the narrowing (capture `m` at its declared type) | runs | **yes** |
| the closure (`print(m)`) | runs | **yes** |
| the `takeYZ(m)` call (keep the declaration) | invalid wasm | no |
| a D2205 overlap test `m is "y" \| "z" \| "q"` instead of the else-branch | invalid wasm | no |
