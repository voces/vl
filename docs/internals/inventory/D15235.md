### D15235 — a record literal pushed into a list whose elements are built at a wider record is check-clean invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · open, target `8` then `4` · found grading [D15189](D15189.md) · filed 2026-11-04 against master `b30abf13`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const xs = [mk()]
    xs.push({ f: 8 })
    print(xs[1].f)
    print(wideJ.f ?? 0)

Want:

    8
    4

#### Mechanism

Not ablated past the table. `xs`'s elements are built at `J` (the `wideJ` delivery widens `mk`'s
result), and the pushed literal is built at its own `{f: i32}`, so the push hands the list a struct
of the wrong row.

| this repro | invalid wasm |
