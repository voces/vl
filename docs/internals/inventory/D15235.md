### D15235 — a record literal pushed into a list whose elements are built at a wider record is check-clean invalid wasm

**closed 2026-11-04 · runs, prints `8` then `4` · was check-clean invalid wasm, `vl check` rc 0 · clause 1 · found grading [D15189](D15189.md) · filed 2026-11-04 against master `b30abf13` · closed by the pass-end literal stamp (`recLitPlaceBuiltTy`, formerly `recAsgBuiltRep`) answering a record literal pushed or index-stored into a list, or a list literal spread into a push, at the list's recorded element build, read through one alias step (`recHeldElemBuilt`, shared with D15189) · fixture `tests/cases/soundness/record-literal-pushed-into-built-list-runs.vl` · a fresh record binding pushed is [D15237](D15237.md)**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const xs = [mk()]
    xs.push({ f: 8 })
    print(xs[1].f)
    print(wideJ.f ?? 0)

Want:

    8
    4

#### Mechanism

`xs`'s elements are built at `J` (the `wideJ` delivery widens `mk`'s result), and the pushed literal
was built at its own `{f: i32}`, so the push handed the list a struct of the wrong row. The checker
had recorded `xs`'s element build (`recBuiltElemOf`); the pass-end stamp never asked it for a push.
