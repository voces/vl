### D6473 — a maker's generic result in a module record field, called at two types, is refused when the field is also read through a function's result or a list element

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same record returned or listed with only its other field read runs ([D6424](D6424.md)) · found closing [D6424](D6424.md) · filed 2026-10-18 against master `b21da3d5d`**

Repro:

    function k<T>(x: T): T { return x }
    function mk() { return k }
    const r = { f: mk(), g: 7 }
    function get() { return r }
    print(r.f(1))
    print(r.f("z"))
    print(get().f(5))
    // vl check: rc 0.  vl run: emitProgram: a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type

Want:

    1
    z
    5

#### Mechanism

From the ablation only. The field-slot plan follows a returned or listed record to its reads
and declines when one of them reads the asked field, since that read is a third call of the
field it does not split ([D6424](D6424.md)).
