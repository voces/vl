### D2729 — an un-annotated list of an anonymous record and `null` has no element rep

**loud emit reject · open · clause 2 · the literal alone, returned, joined in an `if`, and from a lambda (`a nullable-{v:i32} list element has no rep`) · identical on master · filed 2026-09-26 against master `90b63b840`**

Repro:

    const x = [{ v: 1 }, null]
    print(x.length)

#### Mechanism

The checker types the literal `({v: i32} | null)[]`; the emitter has no ref-list row for a
nullable ANONYMOUS record, so the bare `null` element reaches `emitNullLitNode` with no struct
seed and refuses with `bare null needs a struct-typed context` (the lambda return spelling
refuses as `a nullable-{v:i32} list element has no rep`). A declared record (`type V = {v: i32}`
and `[a, null]` with `a: V`) runs, and runs from a two-return join since D2716, and so does the
annotated `({ v: i32 } | null)[]`.

| the anonymous record (a declared `V`) | runs | **yes** |
| the annotation `({ v: i32 } \| null)[]` | the annotated spelling runs | **yes** |
