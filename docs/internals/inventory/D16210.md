#### Mechanism

`elabListElemBuild` (`emit_elab.vl`) answers a receiver's element build for a binding, a list
built at a wider record (`recArgBuiltTyIn`) and a stamped `filter` or `slice` call. A field read
`r.ys` is none of those, so the callback keeps its template parameter `{f: null}`, which no
value is stored at. The check's floor does not see it either: it walks reads of list bindings.
