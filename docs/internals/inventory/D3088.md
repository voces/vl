### D3088 — a lambda returning a captured `(Circle | null)[]` as `readonly (Shape | null)[]` is refused because a handle reaches a function literal

**loud check reject · clause 2 · 36 cells of the lane-LP view grid (every nullable lambda-return cell) · the same on master `505bb44e0` · filed 2026-09-28 against master `505bb44e0`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    function mkf(l: (Circle | null)[]): () => readonly (Shape | null)[] { return (): readonly (Shape | null)[] => l }
    print(mkf([null])().length)
    // vl check: type error, `a handle to it reaches a function literal on line 4, which this
    // check cannot follow`

Want:

    1

#### Mechanism

Not investigated past the ablation. The refusal is `rcwErr`, the record covariant-write rule
([D2060](D2060.md)), whose walk ends at the lambda that captures the parameter. The non-null
pair takes the [D3041](D3041.md) view in the same position, and a nullable record row shares its
twin's view, so the destination being `readonly` is what the rule does not use here.
