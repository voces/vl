#### Close

Traced 2026-11-14. The elaboration's slot fact for `m4` was `{[string]: (f64) => f64}`, closed by
`elabHeldFnTy` from `half`'s only enumerated instance, the one through `ws`. Mono pinned `m4` at
`(i32) => f64` from the push. No instance of `half` existed at the push's signature, because
nothing demanded one. `elabMapCellDeliveries`, beside `elabCellDeliveries` in `elabCellPeers` and
in the same phase before `elabSettle`, enqueues each un-annotated function a map binding stores at
the parameters of the closed function type of the holder it is pushed onto or set into
(`elabEnqueueAtParams`). With two instances, `elabHeldFnTy` declines, so mono pins from the
delivery. Late demands stay at 8.
