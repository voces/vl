#### Mechanism

At `V = null` the list is `null[]`, whose rep is the i32 backing with `null` as the sentinel `2`.
A null-typed element takes its null from the destination it is delivered at (`nullOwnAt`). The
annotated `const ys: V[] = [v]` has that destination, so it stores `2`. The un-annotated literal
records none, so the element pushed the bottom null ref into the i32 array. `emitArrI32` now
stores the sentinel for every `null`-typed element of a `null[]` list
(`arrElemIsNullUnitAt`), and evaluates a non-literal element first for its effects.
