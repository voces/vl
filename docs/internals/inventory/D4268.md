### D4268 — a field read over record arms that both store a nullable integer field emits invalid wasm

**check-clean invalid wasm · clause 1 · the same on master `641b6f84d` when the arms carry a literal discriminant; D4056 makes the union legal without one, so more programs reach it · found by the D4056 review-round-2 grid (`d4056_then_read_positions.py`, pair `{ v: i32 | null } | { v: 1 | null }`, 8 cells) · filed 2026-10-12 against master `641b6f84d`**

Repro:

    type A = { v: i32 | null }
    type B = { v: 1 | null }
    function f(u: A | B) {
      const y: i32 | null = u.v
      if y == null { print("null") } else { print(y) }
    }
    const x1: B = { v: 1 }
    f(x1)
    const x3: A = { v: 4 }
    f(x3)
    // vl check: rc 0.  vl run: invalid module, "type mismatch: expected i32, found (ref $1); $1 is `union box`"

Want:

    1
    4

#### Mechanism

Both arms store `v` as a value-union box. The shared-field plan sees the same field code in
every arm, so `armFieldUnionName` names no box for the read, and the delivery treats the read
as an `i32` atom and boxes it a second time.
