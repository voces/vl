### D14750 — a call built at a wider record, handed to a parameter annotated at its own record that only reads a field, refuses

**open · loud check reject · clause 2 · filed 2026-11-01 against master `dac9daa5`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const d: J = mk()
    function u(a: { f: i32 }) { a.f }
    print(u(mk()))
    print(d.f ?? 0)
    // vl check: {f: i32} is not J: they store field `f` differently, at `const d: J = mk()`

#### Mechanism

`const d: J = mk()` builds `mk`'s record at `J`, and the second call `u(mk())` delivers that
build to `a: { f: i32 }`. `u` only reads `a.f`, so an instance of `u` at `J` would run, which is
how D14532 instances an annotated callee by the rep of a container read handed to it
(`recAnnArgTakesRep`). A call result is not routed there: `recSitesLandAt` finds the site landing
at `{ f: i32 }`, which stores `f` apart from `J`, and refuses the build.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `u`'s annotation (`function u(a)`) | runs (D14741's hole) | **yes** |
| `const d: J = mk()` | runs | **yes** |
| the call relayed as `r()`, `r` returning `const k = id(mk())` | still refuses (the PR fixing D14741 pins it) | no |
