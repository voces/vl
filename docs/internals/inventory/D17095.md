#### Mechanism

A fresh `Map()` is typed at the bundle record its values hold only when the elaboration notes the
map as holding the record whole (`elabSlotRecordNote`). Its walk accepts only slot reads (index,
`get`, `set`, `has`), so a `keys()` iteration declines the note. The map is then declared at the single closure while `lap(...)` returns the bundle record. Legacy alone
refuses at the store ("a function returning a parameter called at two signatures is called where
its result is not used at one of them"); the invalid module is the claimed start, which skips that
refusal (IR-P1's, as in [D17094](D17094.md)). It holds at module scope and
inside a function alike, so it is not D17094's cross-frame decline.
