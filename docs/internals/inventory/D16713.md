### D16713 — an `is i32[]` test on an un-annotated parameter bound at `string[] | null`, whose arm reads the list, builds invalid wasm

**closed 2026-11-16 · runs, prints `9` · was check-clean invalid wasm, clause 1 · fixed by lane AE4: the null-niche test now answers false for a list the `is` relation says the niche's list never is (as D16370 does for records), and a `&&`/`||` operand an instance-decided `is` leaves dead lowers as a dead arm · the template's `argument`, `early_return_guard` and `array_element_place` un-annotated cells now run, 0 runs → not-runs, 0 silent · fixture `tests/cases/unions/hole-is-list-niche-never.vl` · the `argument` and `early_return_guard` un-annotated cells of `inferred-generic-list-union-complement.matrix.vl` ([D5111](D5111.md)'s template) · filed 2026-11-16 against master `c040079c`**

Repro:

    function take(a) {
      if a is i32[] { print(a.length) } else { print(9) }
    }
    const x: string[] | null = null
    take(x)

Want:

    9

#### Mechanism

Two lowerings, one per spelling. In the hole instance the receiver is a `string[] | null` null
niche, and `nulNicheIsTestImpossible` (wasmEmit.vl) knew only records and maps. So `a is i32[]`
lowered as the niche's non-null test, and the arm read the `string list` as an `i32` list. The
list arm added there asks `isTestAnswer` of the niche's list. `string[]` against `i32[]` answers
never, empty included: the D16047 refinement says an annotated empty list is tested by its arm.
The test then folds to `0`, and `staticIsGuard` drops the arm. A `&&` or `||` right operand
was not covered by that drop. It was lowered at the narrowed type under the constant guard, so
`emitBinExprNode` now lowers it with `emitDeadValueArm` when `staticIsGuard` decides it dead.

The template reaches it through a generic `wrap` whose tail `[1, 2, 3]` follows a `return`, so it
is not the result. `wrap` infers `string[] | null`, so the template's `@@WANT@@` is `9`. A template
that returns the tail gets `3` instead.
