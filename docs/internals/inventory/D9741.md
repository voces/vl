#### Mechanism

The lambda's result was inferred from its body alone, a map whose key and value are holes.
The contextual rungs in `finishInferredReturn` adopted the expected result for niche, boxed and
list results only, so the hole map stayed the lambda's type and the emitter built `Map()` with
no return seed, where the value slot comes from (`expCtxTakeMapSlot`). The annotated spelling
supplies that seed through its declared `fnRet`. The close adds one rung, last, that takes the
expected result whenever the inferred one holds a hole (`unresolvedHole`) or is refused by
`fnSlotAssignable`, and every returned value is delivered to it (`retValsDeliver`); the
lambda is recorded (`noteCtxRetLambda`, check_side_rows.vl) and `synthRetAnnots` pins its
`fnRet` to that type, so it lowers as the annotated lambda does. The map-value tables were not
touched.
