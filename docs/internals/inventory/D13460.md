### D13460 — a shared field read typed `i32 | string | null` names its box after the first member's `i32 | null` box, and prints a string as `null`

**closed 2026-10-25 · runs, prints `3`, `null` and `z` · fixed: a read whose join holds `null` names its box as a union row does (`armFieldUnionName`, emit_classify.vl, via `valueUnionNameOfTy`) · pins: `tests/cases/unions/shared-mixed-nullable-field-read.vl` · was check-clean silently wrong, clause 1, printing `null` for `"z"` · pre-existing on master `ad209bcf6` · found closing [D13361](D13361.md) · filed 2026-10-25 against master `ad209bcf6`**

Repro:

    type A = { k: i32 | null, x: i32 }
    type B = { k: string, y: string }
    function F(u: A | B) {
      print(u.k)
    }
    F({ k: 3, x: 1 })
    F({ k: null, x: 1 })
    F({ k: "z", y: "s" })

Want:

    3
    null
    z

#### Mechanism

The read's type is `i32 | string | null`, a `TyNullable` over a union, so `nodeTyIsUnionRow`
was false at it and `armFieldUnionName` fell back to `sharedPlanBoxName`, the first member's
`i32 | null` box. The string member's box was then read through that box's tags, where the
string tag names no member, and printed as `null`. An `is string` test over the same read was
false for the same reason.
