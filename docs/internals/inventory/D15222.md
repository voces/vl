### D15222 — an inferred record result's row is derived by walking the function's return statements, where a list result's is a recorded per-function fact

**runs today and must keep running · a pin on [D14900](D14900.md)'s witness while `criRowByStamp` (emit_collect.vl) still walks `collectRetValues` and reads each value's stamp · open · the list twin records one row per function since [D15203](D15203.md); this row asks the record result to read the same kind of fact · filed 2026-11-04 against master `214d93f9`**

Repro:

    type J = { r: i32 | null }
    function idn<T>(v: T): T { v }
    const u: J | string = idn({ r: 4 })
    const k = { r: 5 }
    print(k.r)
    if u is J { print(u.r ?? 0) }

Want:

    5
    4

#### Mechanism

A record result's row follows the rep stamp of every value the function returns, found by an emit-side walk of its returns (D14900). The list result's row is recorded once, against the function, where the returned values' rows are joined; moving the record result onto the same fact removes the walk.
