#### Mechanism

A receiver whose type each instance supplies picks its candidate per instance
(`ovHoleCallTy` in the checker, `monoPinBinOps` in the emitter). The emitter re-dispatches a
member call per instance only when its receiver is one of the generic's own parameters
(`ufcsSitePinnable`, `drwRecvIsTyParam`, D2520), so the checker refuses every other hole
receiver rather than let one instance's choice serve all. The same call on `a` itself runs.
The ingredient, a local alias of a hole parameter that only a parameter receiver's per-instance
re-read covers, is shared with [D16807](D16807.md), where the alias reaches the emitter at the
template's open type.


#### Close (2026-11-16, L2 alias receiver)

Per-instance dispatch was keyed on the generic's own parameter name: `ufcsSitePinnable` in the
checker, `drwRecvIsTyParam` in the rewrite, `monoPinnedOperandTy` in mono. `aliasRootParam` and
`aliasedParamName` (`check_call_resolve.vl`) now follow a `const`, an unwritten `let` or a chain of
them to the parameter it holds, and all three take such a local as that parameter. A `let` written
anywhere, in a closure or a loop included, is not followed
(`error-member-call-through-reassigned-alias.vl`).
