#### Mechanism

The element is an optional call (or read) through a record field whose type is a hole
(un-annotated) function. Where that `?.` expression is an un-annotated list literal's element, the
checker types the element `null` alone and refuses the list as one of only `null`; the same
expression bound to a `const` first, or in an annotated list, checks and runs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the list's annotation added (`(f64 \| null)[]`) | checks, runs | **yes** |
| the field typed (`type R = { f: (a: i32) => f64 }`, annotated map) | checks, runs | **yes** |
| the `?.` expression bound to a `const` first, then listed | checks, runs | **yes** |
| `?.` for a plain `.f(4)` after a null check | checks, runs | **yes** |
| the call (`[m["b"]?.f]`, a bare optional read) | still refused | no |
| the plainest siblings the sentence forbids: `[g()]` with `g(): f64 \| null`, `[x?.y]` over a typed `R \| null` | check, run | — (out of scope) |
