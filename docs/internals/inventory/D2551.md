### D2551 — a lambda inside a generic body was cloned per instance only in a binding, a field, a `return` argument or a block's tail; every other position shared one lifted slot

**closed 2026-09-25 — the filed repro RUNS and prints `5` then `q` · was check-clean invalid wasm · clause 1 · the sibling positions #3168 left shared (its review's `rv3168r3-p/arg2.vl`, `arr2.vl`) · filed 2026-09-25 against master `a09d1f6bc` · fixture `tests/cases/generics/lambda-any-position-per-instance.vl`**

Repro:

    function app<U>(f: () => U): U {
      return f()
    }
    function gen<T>(r: T): T {
      return app(() => r)
    }
    print(gen(5))
    print(gen("q"))

#### Mechanism

`monoPinBodyLambdas` walked a whitelist of positions: a binding's initialiser, an object
field, a `return` argument, a block's tail. A lambda written anywhere else (a call argument,
a list element, a map value, an `if` arm, a condition, a parenthesised immediately called
value, a `match` arm, a lambda inside a lambda) was lifted once and every instance called it,
so the second instance read the first's rep. The walk now descends every operand of every
expression through `monoExprKids`/`monoExprRebuild` and clones each lambda literal it meets.
Three facts the rebuilt nodes need came with it: a rebuilt node records the checked type of
the node it replaces at the instance's binding (an array literal's emission reads it), a
field call on an object literal reads that literal's own closure rather than the first literal
of its shape (`fieldClosureFeOfRecv`), and a clone is typed at the pin as a value. Two
positions also needed the sibling rows: D2552 (a value call's callee) and D2553 (a generic
call inside the clone). An un-annotated lambda parameter the checker inferred at `T` is now a
fifth reason to clone, annotated at the pin, which also closed D2433.

Graded over 25 positions × 8 instance types (i32, string, f64, boolean, i64, a record, a
function type, a list), each program calling the generic at the cell's type, at `i32` and at
`string`: master ran 8 of 200 (116 invalid wasm), this change runs 188 (1 invalid wasm). Of the
12 that do not, 5 are refusals the non-generic twin makes too (a record through
`{ f: () => r }.f()`, a `.map` returning a function or a list), 1 is a D2553 residue
(`app(() => app(() => r))` at a function type, loud), and 6 are D2554 (a list literal of `T`
as an inline `.map`/`.filter` receiver: 5 loud, the function-type `.filter` invalid wasm, as
on master). Program-per-type grading at one instance: master 116 of 200, this change 188.
