#### Mechanism

`c` copied the narrowed read of `e`, whose value is still the `{tag, payload}` box, and was
declared at the box, so a plain `c` delivered the box to the `(ref null $Circle)` parameter.
`letInitTyIsNarrowedNulArm` (`emit_classify.vl`) is the nullable twin of
`letInitTyIsNarrowedArm`: an un-annotated binding whose initializer the checker typed
`X | null`, `X` a union arm, while the initializer is still the box. It gives the binding the
`nulvariant` cell in `letInitCellKind`, `collectLocals` and `captureValStructIdx`, and
`emitLetDeclStmt` owes the arm unbox, cast with `ref.cast null` (`emitArmUnboxCast`) so the
null arm's null payload survives.
