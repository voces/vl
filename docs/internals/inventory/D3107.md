### D3107 — an un-annotated binding of a value narrowed to `Circle | null` is passed to a nullable-record parameter as the box

**check-clean invalid wasm · clause 1 · 30 cells of the #3273 review's grids · the same on master `d408f2da4` · filed 2026-09-28 against master `d408f2da4`**

Repro:

    type Circle = { r: i32 }
    function g(w: Circle | null) { return w == null }
    const zz: (Circle | null | string)[] = [{ r: 4 }, null]
    for e in zz {
      if !(e is string) {
        const c = e
        print(g(c))
      }
    }
    // vl check: rc 0.  vl run: invalid module in the top-level code: type mismatch: expected
    // (ref null $type)

Want:

    false
    true

#### Mechanism

Not fixed here. `c` copies the narrowed read of `e`, whose value is still the `{tag, payload}`
box ([D3097](D3097.md) unboxes the read at a delivery, not at a binding), and `c` is declared at the
box. At the call, `c` is a plain identifier with no narrowing of its own, so no unbox fires and
the box reaches the `(ref null $Circle)` parameter.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `g(e)` directly, no binding | runs ([D3097](D3097.md)) | **yes** (the binding) |
| `const c: Circle \| null = e` | runs, prints `false`, `true` | **yes** (the un-annotated binding) |

#### Grading list

Both faces of the binding; the binding delivered to a lambda, a value call and a return.
