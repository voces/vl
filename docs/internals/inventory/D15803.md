### D15803 — a `?.` call whose receiver is a call, written inside an assignment's operand, is refused at emit, where the same expression bound or printed runs

**closed 2026-11-12 · runs, `1.5` · was loud emit reject, `emitProgram: an optional call needs a receiver the guard can read twice — bind it to a name first`, clause 2 · found grading D15801's `?.` matrix (`opt-call-record-fn-field-two-results.matrix.vl`) · filed 2026-11-12 · fixed by binding a `?.` callee's computed receiver around its call where it stands (`hmsBindOptCallInPlace`, check_match_hoist.vl): `(if true { const $om = <receiver>; $om?.f(args) } else { null })`, the receiver evaluated once and before the arguments, a null one skipping them**

Repro:

    function half(a: i32): f64 { return a / 2.0 }
    const rs = [{ f: half }]
    let acc = 0.0
    acc = acc + (rs.get(0)?.f(3) ?? 0.0)
    print(acc)

Want:

    1.5

#### Mechanism

The `?.` call's guard reads its receiver twice, once to test it and once to call through it, so a
computed receiver must first be bound to a name (D5300). `hoistMatchScrutinees` binds it ahead of
the statement only where nothing before it in the statement can be rebound. In `acc = acc + (…)`
the left operand reads `acc`, a written `let`, so the hoist declines, rightly. The in-place binder
(`hmsBindOptInPlace`, D5331) then declined too, because the `?.` read is a call's callee and wrapping
the read alone changes the call. It now binds the receiver around the call instead.

#### Ablation

| spelling | outcome |
| --- | --- |
| the witness | runs, `1.5` (was loud emit reject) |
| a receiver with an effect, `acc = acc + (get()?.f(arg()) ?? 0.0)` | runs: the receiver once, before the argument |
| a null receiver, `acc = acc + (none()?.f(arg()) ?? 10.0)` | runs, the argument not evaluated |
| printed, `print(rs.get(0)?.f(3) ?? 0.0)` | runs, `1.5` |
| in an expression, `print(1.0 + (rs.get(0)?.f(3) ?? 0.0))` | runs, `2.5` |
| bound first, `const x = rs.get(0)?.f(3) ?? 0.0; acc = acc + x` | runs |
| a field read, not a call, `acc = acc + (rs.get(0)?.n ?? 0.0)` | runs |
