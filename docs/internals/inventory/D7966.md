### D7966 — a `??` of a nullable `i32` and a literal-union atom default delivers the atom's id into the box

**closed 2026-10-20 by lane L6b · runs, prints `b` · was check-clean invalid wasm · clause 1 · the result is the `i32 | AB | null` box, whose `AB` arm is stored as its member string, and the default's atom id was delivered into it unconverted; the default now decodes into the member-string arm · pin: `tests/cases/literal-unions/coalesce-map-read-joins-atom.vl` · filed 2026-10-20 against master `aec7a5332`**

Repro:

    type AB = "a" | "b"
    const n: i32 | null = null
    const xn: AB | null = "b"
    const r = n ?? xn
    print(r)

Want:

    b

#### Mechanism

`n ?? xn` is the `i32 | AB | null` box. The default is an atom niche, an `i32` at the
wasm level, and the lowering delivered it without widening it to its member string. With
a nullable default the module failed to validate; with a non-null one it ran and printed
the atom's id.

#### Ablation

| ingredient changed (on master `aec7a5332`) | outcome | needed? |
| --- | --- | --- |
| `const xn: AB = "a"`, then `if r is i32 { print(1) } else { print(r) }` | prints `0` | no, a non-null atom too |
| `const xn: string \| null = "b"` | runs, prints `b` | **yes**, the atom |
| `else if r != null { print(r) }` after `if r is i32` | check-clean invalid wasm | no |

#### Grading list

The non-null default (`rAtom` in the pin), the narrowed print after `is i32` (which still
meets [D7965](D7965.md) when the else arm keeps the null), and the hole face
(`nicheOrNumU`).
