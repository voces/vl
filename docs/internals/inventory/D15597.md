### D15597 — a `const` lambda capturing in a generic encloser, handed to a parameter that calls it at two types, refuses as a "copy of a reassigned binding"

**loud emit reject · clause 2, `vl check` rc 0, then `emitProgram: the function binding `same`, a copy of a reassigned binding, is called at more than one argument type` · D15596's neighbour · filed 2026-11-09 against master `82d99608`**

Repro:

    function mid<F>(a: F) {
      print(a("x"))
      print(a(2))
    }
    function outer<U>(u: U) {
      const same = (k) => {
        print(u)
        k
      }
      mid(same)
    }
    outer(7)
    outer(true)

Want:

    7
    x
    7
    2
    true
    x
    true
    2

#### Mechanism

The nested-function spelling (`function same(k)`) is bundled per encloser instance since D15596.
Bound with `const`, the lambda takes another path that refuses, and the refusal is wrong twice:
nothing reassigns `same`, and one value called at two signatures is a bundle, not a refusal.
Not yet traced past the message.
