### D15185 — a fresh literal handed to a generic that delivers its parameter wider and hands it back is refused

**closed 2026-11-03 · runs, prints `9` · was loud check reject, `{y: i32, x: i32} is not V: they store field `x` differently` · clause 2 · CAPABILITY: the fresh-binding twin runs · split from [D15184](D15184.md) · filed 2026-11-03 against master `f265220a` · closed by keying the hand-back instance at the pin's record ([D14532](D14532.md)'s argument rep): the parameter is rep-transparent past a record-annotated parameter only read for scalar fields, the pin builds the literal there, and the call's result is judged as a built read where it is handed on · fixtures `tests/cases/soundness/fresh-literal-handed-back-by-generic-delivering-it-wider-runs.vl`, `fresh-literal-handed-back-wider-then-on-at-own-type-runs.vl` (a must-error pin until [D15373](D15373.md))**

Repro:

    type V = { y: i32, x: i32 | string }
    function k(v: V): i32 { 1 }
    function back<T>(v: T): T { k(v); v }
    print(back({ y: 2, x: 9 }).x)
    // vl check: rc 1, "{y: i32, x: i32} is not V: they store field `x` differently"

Want:

    9

#### Mechanism

The pin `T := {y: i32, x: i32}` delivers `v` to `k`'s `V`, which stores `x` as a union box.
[D14760](D14760.md)'s close builds the caller's fresh literal at `V` where the parameter is only
delivered (`paramOnlyDelivered`, check_demands.vl), and its precondition is that no use lets the
value leave the call. Here `back` hands `v` back, so the caller reads the literal at its own type
while it is built at `V`. The fresh-binding twin, `const v = { y: 2, x: 9 }; k(v); print(v.x)`,
runs: the binding is built at `V` and its reads are served by that rep.

#### Close

`pinArgOfParamRead` admits the literal when the parameter is `cbaParamRepTransparent`, and that
predicate, which also keys the instance at the rep row, now counts an argument handed to a
record-annotated parameter of a non-generic function read only for fields holding no record,
list, map or function. The literal is built at `V`, the instance of `back` at `V`'s rep, and
the caller's field reads are served there. A whole hand-on at the caller's own type (an
own-typed parameter) is the built-read refusal, as for a container read; it could run through
a copy, which depends on [D15093](D15093.md). A record literal assigned into a binding holding
such a result is built at its record. A callee that writes or stores the record stays refused
([D2060](D2060.md)).

#### Plan

Not D14760's recorder. Apply [D14532](D14532.md)'s argument-rep mechanism (`recArgRepNote`, the
`callBindRep` rows) to a generic whose parameter is delivered wider and handed back. The
argument is built at `V`, the instance of `back` is built at `V`'s rep, and the caller's read of
the result is served at that rep, as the binding twin's reads are.

#### Ablation
