#### Mechanism

Not yet ablated past its ingredients. The binding's record joins its field over both maps, so
`u.m` holds `{inc0, dbl}`, while each literal `{ m: hm }` and `{ m: hm2 }` carries its own map's
one-member set; the written literal resolves no struct row of the joined record. D15392 is the
same shape over a list field.

`closures/hole-fn-map-record-let-rewritten.vl` holds this program and runs only because an
unrelated block in it, a `let fm` map written `inc0` then rebound and written `dbl`, changes the
two functions' set decisions: without that block the fixture's `u` refuses as above. A fix here
is not graded by that fixture alone; the witness above is the grading cell.
