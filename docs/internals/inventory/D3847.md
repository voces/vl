### D3847 — a top-level `let` alias of a hole lambda, called and then reassigned, is refused at emit for want of a function-value signature

**loud emit reject · found in review of #3441 (`l9`) · filed 2026-10-08 against master `52c8e492d`**

Repro:

    const c = (y) => y + "C"
    const e = (y) => y + "E"
    let d = c
    print(d("a"))
    d = e
    print(d("b"))
    // vl check: rc 0.  vl run: emit error `a function-value call has no interned signature — parameter 1 of type `` has no representation in the function-value ABI`

Want:

    aC
    bE

#### Mechanism

Not yet located. The same program inside a function runs since D3833. At module scope `d` is a
global whose closure signature comes from the hole-typed initializer, and resolving the alias
to `c` alone does not give the call a signature.
