**closed 2026-11-09 · runs, prints `3`, `4`, `30` · was loud emit reject, clause 2, `vl check` rc 0, then `emitProgram: a generic function taken as a value reaches no call that fixes its type` · closed in emit_elab.vl: a copy's reads were taken either as calls only (`elabCallOnlyAlias`) or as hand-ons only (`elabAliasSetFwd`), and a copy read both ways matched neither. Repro:

    function add(a, b) { return a + b }
    function mul(a, b) { return a * b }
    function apply2(g) {
      print(g(1, 2))
      print(g(1.5, 2.5))
    }

      const hh = h

#### Mechanism

`apply2` calls its argument at two signatures, so `hh` has to be bound per call as `h` is.
A call through `hh` is read as a call through `h` only when every read of `hh` is a call
(`elabAliasReadsOk`). A hand-on of `hh` forwards `h` only when every read is a hand-on
(`elabAliasSetFwd`). `hh` has one read of each kind, so neither path took it.
