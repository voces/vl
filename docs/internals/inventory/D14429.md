### D14429 — a choice of generic functions called in two generic instances gets one closure signature, minted by the first instance

**closed 2026-10-31 · runs, prints `6` `ss` (the Repro) · was loud emit reject, `a function-value call has no interned signature`, `vl check` rc 0 · fixed: `ftInOpenFn` (check_fn_tag.vl) no longer leaves a set untagged because its holder sits in a generic function, so the set {kg, idg} is tagged and each instance's call dispatches to the member's instance at its own tuple; the half for a function with an un-annotated parameter stays ([D14430](D14430.md)) · pins: `tests/cases/closures/generic-choice-in-generic-body-at-each-instance.vl` · found grading c-3's un-annotated stamp against the annotated face · filed 2026-10-27 against master `41c611055`**

Repro:

    function idg<T>(t: T): T { return t }
    function kg<T>(t: T): T { return t + t }
    const c = [1].length > 0
    function listedAtV<T>(v: T): T {
      const fs = [if c { kg } else { idg }]
      print(fs[0](v))
      return v
    }
    function field<T>(v: T): T {
      const r = { h: if c { kg } else { idg } }
      print(r.h("s"))
      return v
    }
    listedAtV(3)
    field(1)

Want:

    6
    ss

#### Mechanism

The set {kg, idg} is held as a closure in both instances. Its closure signature comes from the
name-keyed flow pin, and the first instance to reach the set (`listedAtV<i32>`, calling at
`i32`) fixes it for every instance. `field<i32>` then calls `r.h("s")` through a
`call_indirect` at `(structref, i32) -> i32`, passing a string. The signature belongs to the
call's tuple in each instance, which is the per-instance mint.
