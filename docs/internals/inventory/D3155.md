### D3155 — a scalar-valued map read through an un-annotated parameter's instance yields the raw zero on a miss

**check-clean silently wrong · clause 1 · open · found grading lane TT's map-field grid, beside [D3130](D3130.md) · the same on master `b1794003a` · filed 2026-09-29 against master `b1794003a`**

Repro:

    type H = { m: {[i32]: i32} }
    function mk(): H {
      const v: {[i32]: i32} = Map()
      v[3] = 7
      { m: v }
    }
    function use(r) {
      const e = r.m
      const x = e[9]
      print(x)
    }
    use(mk())
    // PRINTS 0

Want:

    null

#### Mechanism

A bare read of an `i32`- or `f64`-valued map has no spare value to mean a miss, so the concrete
read builds the `i32 | null` box (`mapReadScalarBoxKindTy`). That classifier reads the
receiver's recorded type, which in the hole instance is the hole's variable, so the instance
reads the raw scalar and a miss is the rep's empty value; a `boolean` map's miss reads `0`,
which prints as the number. A `== null` test of the same read,
or of a binding of it, has no box to test and refuses loudly: `emitProgram: bare null needs a
struct-typed context`.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the parameter annotated `r: H` | prints `null` | **yes** (the hole) |
| `e[3]`, a hit | prints `7` | **yes** (the miss) |
| an `f64` map value | prints `0` | no |
| a `boolean` map value | prints `0` | no |
| `print(x == null)` | loud emit reject | no (the same unboxed read, refused) |
