### D4859 — `is P` over an element of an inferred mixed literal whose record arm is spelled anonymously has no interned arm

**loud emit reject · clause 2 · found grading D4858's matrix, independent of `+` · filed 2026-10-15 against master `0e1ea34b1`**

Repro:

    type P = { x: i32 }

    const v = xs[2]

    // vl check: rc 0.  vl run: emitProgram: `is` names a declared union member with no interned arm representation (deferred value-union composition)

#### Mechanism

The literal's element is inferred as `{ x: i32 } | string`, whose record arm is the anonymous
shape rather than `P`. `is` is structural (D3885), so the checker accepts `is P`, but the
emitter looks for an interned arm named `P` in the box row and finds none.
