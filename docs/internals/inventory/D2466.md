### D2466 — a bare scalar-valued map read consumed directly (`print`, `==`, `is`) read a miss as the rep's empty `0`, not `null`

**closed 2026-09-25 — the filed repro RUNS and prints `null`, `null`, `null` · was check-clean silently wrong (printed `0`, `0`, `null`) · design doc `collections-representation-design.md` §10 F3 (`critic-learn/t1.vl`) · filed 2026-09-25 against master `086466d1a`**

Repro:

    const m: {[string]: i32} = Map()
    print(m["zz"])
    print(m.get("zz"))
    const v = m["zz"]
    print(v)
    // PRINTS null

#### Mechanism

`m[k]` over a map whose value is `i32`, `i64`, `f64`, `f32` or a numeric literal union is typed
`V | null`, but the scalar has no spare bit, so `emitMapGet` yields the rep's empty value on a
miss. Every DELIVERY (binding, argument, return, field, element, capture) goes through
`emitUnionCoerce`, whose `mapReadScalarBoxKind` arm boxes the read with a tag chosen by the probe.
The CONSUMERS that dispatch on the expression itself never reached that arm: `print` took the
scalar sink, `==`/`!=` compared the raw `0` (so `m[miss] == 0` was `true`), and `is`/`match`
refused with "`is` test but no union type declared". An `f32` map was worse: its miss arm pushed
a `ref.null` into an `f32` blocktype (check-clean invalid wasm). The fix reads the probe's hit
flag in each consumer (`emitPrintScalarMapRead`, `emitScalarMapReadEq`, `emitScalarMapReadIs`),
so no box is built, and `emitMapGetTail` gives an `f32` miss its `0.0`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the read bound first (`const v = m[k]; print(v)`) | printed `null` before the fix | **yes** — a direct consumer |
| value `string` / `boolean` (a niche) instead of a scalar | printed `null` before the fix | **yes** — a scalar value |
| `m.get(k)` instead of `m[k]` | the same `0` | no — one read |
| key `i32` instead of `string` | the same `0` | no |
| value `f64` / `i64` | the same `0`; `f32` was invalid wasm | no |
