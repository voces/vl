#### Mechanism

A member call on a hole whose name is a map or set method (`holeMapMethod`) makes the hole the demanded
map, unless a `self`-function of that name is in scope (D2518's `holeMethodIsSelfFn`). A record whose
field holds a closure of that name is not consulted: the record is the call site's argument, which the
body is checked before. So `a.get()` is checked as the map's `.get(k)`, which takes one argument.
Where the call's arity cannot be the map method's (`get` with none), the field reading is the only one
that types. Where it can (`get(k)`, `has(k)`, `keys()`), the body alone cannot tell them apart, and the
call site's record decides: an inferred interface.
