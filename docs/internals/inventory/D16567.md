### D16567 — a closure field named like a map method, called on an un-annotated parameter at an argument count the map method also takes, forces the parameter to a map

**loud check reject · `argument 1: parameter is used as a map but nothing in the body pins its key or value` · clause 2 · open, parked as L2 acceptance (an inferred interface) · the arity-decidable face runs since the hole demand reads the built-in arity table (`bmTakes`, `check_callee.vl`), named set `d16567-hole-field-call-arity` · the record-field face of [D2518](D2518.md), whose fix covers the `self`-function face only · filed 2026-11-15 against master `059a5a687`**

Repro:

    type G = { get: (k: string) => i32 }
    function t(a) { print(a.get("q")) }
    t({ get: (k: string) => 3 })
    // vl check: argument 1: parameter is used as a map but nothing in the body pins its key or value

Want:

    3

#### Mechanism

A member call on a hole whose name is a map or set method (`holeMapMethod`) makes the hole the demanded
map, unless a `self`-function of that name is in scope (D2518's `holeMethodIsSelfFn`), or no built-in
method of that name takes the call's argument count (`bmTakes`). A record whose field holds a closure
of that name is not consulted: the record is the call site's argument, which the body is checked
before. Where the count can be the map method's (`get(k)`, `has(k)`, `keys()`), the body alone cannot
tell the two readings apart, and only the call site's record can decide: an inferred interface.

#### Closed face

The filed witness, `a.inc(); print(a.get())` over `{ inc: () => void, get: () => i32 }`, was refused
with `get expects 1 argument, got 0` and now prints `1`. So do `keys(1)`, `values(2, 3)`, `clear(4)`,
`set(5)`, `add()`, `has()`, `push()` and `pop(1)` over fields of those arities. The built-in arms read
their argument counts from the same table. A real wrong-count call on a hole now refuses at the call
site (`expected {push: _}, got i32[]`) where it refused in the body (`push expects at least 1
argument, got 0`). Fixture: `tests/cases/generics/member-call-hole-arity-no-builtin-takes-is-field.vl`.
