### D7080 — a labelled block left by a `break` inside a nested loop, with an uncalled hole function as its value, is refused at emit

**closed 2026-10-25 · was a loud emit reject, `vl check` rc 0, clause 2, CAPABILITY · `lvRewriteAt` carries a choice among hole functions declared outside the loop as the `i32` index of the one chosen and names each after the loop, so the call that reads the block pins each one · pinned by `tests/cases/closures/hole-fn-labelled-block-left-by-nested-break.vl` · neighbours [D12840](D12840.md), [D12841](D12841.md) · filed 2026-10-19 against master `969979f58`**

Want:

    1

#### Mechanism

From the code path. A `break` inside the `for` ends no branch of the block's value, so
`lvRewriteAt` (`emit_rewrite.vl`) still stores it into a carrier `let $lvN: T;` whose `T` is the
hole function's open signature, and the i32 floor refuses a declaration with no initializer.
Making the block its own value needs a carrier whose type the call that reads it pins.
