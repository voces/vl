#### Mechanism

The list's element slot gets its type back from the stored spelling of `FF`
(`rlInternNameTy`, emit_union_atoms.vl). That re-resolves it as a fresh structural copy of
`A16` rather than `A16` itself. The copy owns no rep slot (`repSlotOfTy` answers -1), so
[D9784](D9784.md)'s arena rung declines and the call falls back to the name lookup. Past the
spelling cap, that lookup takes the first `{l, r}` row, `A1`. The producer belongs to the
element-name tables' lane and is not changed here.
