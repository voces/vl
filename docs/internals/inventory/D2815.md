#### Mechanism

`z == null` pushes a narrowing that pins `z` to `null`, with no member set. The inner `!= null`
asked the live narrowing for the set to subtract from: `currentNarrowSetIdAt` answered the pin's
missing set, and the rendered fall-through subtracted `null` from `null`, leaving "", so no
narrowing was pushed. The inner read then took the outer pin, the `null` arm, and emitted the box
ref where the add wants an `i32`. The pin is a hint: a call, a closure or a write may have put a
value in the place since. A `!= null` test (then-arm, and the else of `== null`) over a name
pinned to `null` now masks that pin (`maskNarrowFor`, #3212's lift) while it reads the set, so it
strips `null` from the declared set. A member path already read the declared set, and an index
cell's `indexCellCurSet` already declined a `null` pin, which is why `w.f` and `xs[0]` ran.
