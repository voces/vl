### D2174 — a tail `if` joining a struct write with a scalar write makes the recursive struct a union arm with no field rep

**loud emit reject · clause 2 · filed 2026-09-23 against master `a453c09c5`, found closing [D2170](D2170.md) · re-graded 2026-09-26: the filed statement call `insert(root, 3)` runs since D2631 makes an unread result `void`, so the witness now reads it**

Repro:

    type Node = { v: i32, left: Node | null }
    function insert(n: Node, v: i32) {
      const m: Node = { v: v, left: null }
      if n.left == null {
        n.left = m
      } else if n.v < 0 {
        n.v = 0
      } else {
        insert(n.left, v)
      }
    }
    const root: Node = { v: 5, left: null }
    const r = insert(root, 3)
    print(root.left?.v ?? 0)

#### Mechanism

Not ablated. The arms yield `Node` and `i32`, so the checker infers `Node | i32`, and registering
that union makes `Node` an arm; `Node`'s own `left: Node | null` field is then typed by an arm,
which the field-rep ladder refuses. The same join of a non-recursive struct is the case to grade
first, to separate the recursion from the join.

#### Grading list

The same join where the struct has no self-reference; the same arms with the result used.
