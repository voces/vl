### D8321 — a list of a generic constructor's undeclared record, handed to a hole or `U[]` parameter, has no monomorphization pin

**closed 2026-10-20 by lane mono-rows · runs, prints `1` · was loud emit reject · clause 2 · the pin ladder (`monoArgTyNameRep`, `emit_mono.vl`) pins a list literal whose record element has no committed name at the list's own spelling, since a generic constructor's `#anon` row does not exist before its instance; the `#anon0[]` pin of the non-generic face then met [D4710](D4710.md), closed with it · pins: `tests/cases/generics/generic-ctor-record-list-into-hole-param.vl` and its annotated twin · present on master `cb1894c33` · found running the `generic-ctor-record-list-two-pins` matrix (its un-annotated `early_return_guard` cell) · filed 2026-10-20 against master `cb1894c33`**

#### Mechanism

Traced as far as `emit_mono.vl`, which is lane L1's, and left there. The refusal is
`monoArgTyFail`, the floor for a parameter no argument pin closes (five call sites in the
binding of a generic call's arguments; which one fires was not narrowed). D4710's face, the same
list of an inline literal or of a NON-generic constructor (`function pc(x: i32) { { a: x } }`),
gets a pin, and it is spelled `#anon0[]`: the instance's parameter TypeRef carries that name
with no arena type (`nodeTyIxOf` is `-1`), so the valtype ladder in `emit_sections.vl` has no
rung for it. A bare `#anon0` pin (`g(pc(1))`, read `v.a`) runs, so the gap is the pin's list
spelling, not the row; where mono should resolve `#anon0[]` was not traced. Nothing in the collect
pass is missing: the element's row exists, since `const xs = [pc(1)]` then `xs[0].a` prints `1`.

The ablation has the shape of [D4710](D4710.md), where a list literal of an
undeclared record pins a `T[]` parameter, but the refusal is monomorphize's rather than the
valtype ladder's: the argument's element is the constructor instance's record, which has a row
only at the instance and none the callee's pin can name. A declared record of the same fields,
or an annotated parameter, gives the pin a type it can name. The same list of an inline literal
(`g([{ a: true }])`) meets D4710's internal floor instead.
