### D8321 — a list of a generic constructor's undeclared record, handed to a hole or `U[]` parameter, has no monomorphization pin

**loud emit reject · clause 2 · open · present on master `cb1894c33` · found running the `generic-ctor-record-list-two-pins` matrix (its un-annotated `early_return_guard` cell) · filed 2026-10-20 against master `cb1894c33`**

      print(v[0].a)

#### Mechanism

Not traced. The ablation has the shape of [D4710](D4710.md), where a list literal of an
undeclared record pins a `T[]` parameter, but the refusal is monomorphize's rather than the
valtype ladder's: the argument's element is the constructor instance's record, which has a row
only at the instance and none the callee's pin can name. A declared record of the same fields,
or an annotated parameter, gives the pin a type it can name. The same list of an inline literal
(`g([{ a: true }])`) meets D4710's internal floor instead.
