#### Mechanism

The return set joins `(T | null)[]` and `i32[]`, and at `T := boolean` the call is typed as the
one list `(boolean | null)[]`: `if v is i32[]` is refused as `can never match`, and the `[7, 8, 9]`
arm's `8` is read as the niche's null sentinel `2`. [D2800](D2800.md)'s rule keeps `T[]` apart
from `i32[]` at the pin; the nullable element `T | null` is the same question one layer down,
and the pin rule did not reach it: `tyParamsPart` parted a bare parameter, or a parameter's hole,
from a concrete type under a constructor, but compared `T | null` against `i32` only as two
nullables, so the declaration's own return read `(T | null)[]` and dropped the `i32[]` arm. The concrete spelling (`t: boolean`) is the union and runs,
since #3222 gave `(boolean | null)[]` its own tag (code 18).
