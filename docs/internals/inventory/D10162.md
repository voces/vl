### D10162 — a scalar-result lambda for a generic's `() => T[] | i32` parameter beside a `T`-typed parameter has no instance

**loud emit reject · `vl check` rc 0 · `emitProgram: monomorphize: unsupported argument type for f in a call to len` · clause 2 · CAPABILITY: the same call with a list-result lambda runs, and so does the lambda annotated as the union · present on master `6bb8a329f` · found closing [D10133](D10133.md) · filed 2026-10-22 against master `6bb8a329f`**

Repro:

    function len<T>(f: () => T[] | i32, x: T) {
      const t = f()
      if t is i32 { t } else { t.length }
    }
    print(len(() => 7, 0))
    // vl check: rc 0.  vl run: emitProgram: monomorphize: unsupported argument type for `f` in a call to `len`

Want:

    7

#### Mechanism

Not traced. The lambda's result `i32` is the union's fixed member, so D10133's binding through
the function result binds nothing and no adapter boxes the result; `x` binds `T` to `i32`, but
the monomorphizer still has no function type to name for `f`, whose own type `() => i32` is
not the parameter's `() => i32[] | i32`.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| a list-result lambda, `len(() => [1, 2], 0)` | runs, `2` | **yes** |
| the lambda annotated, `(): i32[] \| i32 => 7` | runs, `7` | **yes** |

#### Grading list

Both ablation rows, and the same call without `x: T`, where nothing binds `T`.
