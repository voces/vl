### D15649 — a named generic handed as a record literal's field to one callee and as a list element, called at two types, to another is refused at emit

**loud emit reject · clause 2 · `a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type` · found closing D15645 · filed 2026-11-10 against master `0898379e`**

Repro:

    function dbl(v) { return v + v }
    function cf(r, x) { return r.f(x) }
    function bothD(g) { return cf({ f: g }, 2.5) }
    function c3(r, x) {
      print(r[0](1))
      return r[0](x)
    }
    function bothG(g) { return c3([g], 2.5) }
    print(bothD(dbl))
    print(bothG(dbl))

Want:

    5
    2
    5

#### Mechanism

Unmeasured. A record field holding a named function is a closure while a list element holding
one is a set's id ([D15640](D15640.md)'s split), and `dbl` handed to `bothG` is called at two
types, so it stays generic; the emitter finds no call fixing the instance the record delivery
needs.

| --- | --- | --- |
| no `print(bothD(dbl))` | runs, `2` `5` | **yes** |
| no `print(r[0](1))` in `c3` | runs, `5` `5` | **yes** |
