### D15649 — a named generic handed as a record literal's field to one callee and as a list element, called at two types, to another is refused at emit

**closed 2026-11-11, runs and prints `5` `2` `5` · was loud emit reject, clause 2, `a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type` · found closing D15645 · filed 2026-11-10 against master `0898379e` · closed in the elaboration and the late tag decision: a call through a field of a parameter its callers forward a hole into notes no fact (the forward note gives the set), but it now records that the parameter takes the set (`mintParamSetNote`) and makes the set a candidate of the decision after the elaboration (`mintFwdFieldSetNote`, `elabMintParamRowFactAt`, emit_elab.vl; tried in `fnTagDecide`, check_fn_tag.vl). `bothD`'s `g`, handed on only inside `{ f: g }`, then holds `{dbl}`'s id, so `dbl` is not delivered as a closure · the same holds where the callee calls the field at two types with no list beside it; the two functions' literals of the set's record then share one row ([D15701](D15701.md)) · fixture `tests/cases/functions/hole-handed-on-only-in-record-called-at-two-types.vl`**

Repro:

    function dbl(v) { return v + v }
    function cf(r, x) { return r.f(x) }
    function bothD(g) { return cf({ f: g }, 2.5) }
    function c3(r, x) {
      print(r[0](1))
      return r[0](x)
    }
    function bothG(g) { return c3([g], 2.5) }
    print(bothD(dbl))
    print(bothG(dbl))

Want:

    5
    2
    5

#### Mechanism

Measured 2026-11-11 with a probe on the late tag decision. `bothD` never calls `g`, so the
only calls through `{dbl}` from `bothD`'s side are `cf`'s `r.f(x)`, a field read of a parameter
`bothD` forwards a hole into. `elabMintParamRowFactAt` skips that call (the forward note gives
`cf` the set, and a fact there splits the literal's row), so no fact names the set, and nothing
recorded that `cf`'s parameter takes it. The decision after the elaboration then refused the hand
`bothD(dbl)` (`ftLateParamOk`), `{dbl}` stayed a closure, and `bothG`'s calls at two types had no
one signature. Noting the fact instead tags the set but builds the literal and `cf`'s parameter
at two struct types of one layout: invalid wasm.
