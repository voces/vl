### D9340 — an un-annotated function inside a list or record literal pushed or map-stored into an annotated container takes no pin from the annotation

**loud emit reject · `vl check` rc 0 · `cannot take the generic function … as a value` · clause 2 · found closing [D9301](D9301.md) · present on master `22c2f5c4f` · filed 2026-10-21 against master `22c2f5c4f`**

Repro:

    function h(u) { return u + 1 }
    const xs: ((u: i32) => i32)[][] = []
    xs.push([h])
    print(xs[0][0](3))
    // vl check rc 0.  vl run: emit error: emitProgram: cannot take the generic function `h` as a value

Want:

    4

#### Mechanism

Not traced. An annotated destination pins an un-annotated function delivered straight to it
(`xs.push(h)`, `m["k"] = h`, `const r: {xs: …} = { xs: [h] }` all run), but not one nested a
level down inside a list or record literal handed to `.push` or written to a map key. The
expected type of the push argument or map store is not carried into the literal's elements.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the inner literal (`xs.push(h)` into `((u: i32) => i32)[]`) | runs, `4` | **yes** |
| `.push` (an annotated `const` bound to the literal) | runs, `4` | **yes** |
| the list (a record `{ f: h }` pushed into `({f: (u: i32) => i32})[]`) | same refusal | no |
| `.push` for a map store (`m["k"] = [h]`, annotated map) | same refusal | no |
| the un-annotated parameter (`h(u: i32)`) | runs, `4` | **yes** |

#### Grading list

The `array_push` rows (both faces) and the annotated `map_value`, `map_set` and
`map_value_place` rows of matrix `hole-fn-list-in-record-field`, and the record and map-store
spellings in the ablation.
