### D16336 — a hole parameter bound to a declared hole function that hands its own parameter on to a call at another type is typed from that function's local calls only

**loud check reject · clause 2 · bucket (c), L2 inferred interfaces: annotating any one of the three holes runs · the direct call `lap((a) => a * 10)` runs and prints `11` · beside [D16335](D16335.md), whose close types the call · filed 2026-11-15 against master `b09064cee`**

Repro:

    function other(f) { return f(2.5) }
    function lap(g) { const o = other(g); return g(1) + 1 }
    function use(k) { return k((a) => a * 10) }
    print(use(lap))
    // vl check: argument 1: expected i32, got f64 (the call of `f` at the call's argument types)

#### Mechanism

The call `k((a) => a * 10)` with `k` bound to `lap` is typed as `lap`'s direct call
(`holeDeclCallInst`, check_relate_core.vl). The lambda takes the types of `lap`'s own calls of `g`
(`ftParamCallsAt`): `(i32) => i32`. `lap`'s body is then typed at that, and `other(g)` calls it
at `f64`. The direct call joins every call the lambda reaches. Before D16335's close this was a
loud emit reject (`a generic function taken as a value reaches no call that fixes its type`).
