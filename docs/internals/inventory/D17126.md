#### Mechanism

`b == z` routed `unionRight`. `unionEqAtomKindOf` read the narrowed `b` at its storage's arm, a
bool atom, and `i32 | null` has no bool arm, so the compare took the "no arm has the operand's
rep" fold, a constant `false`. The same family, keyed by the other side's rep: a `string | null`,
`i32[] | null` or `boolean | null` other built an invalid module; a record `P | null` other was an
emit reject (`struct equality over a non-struct operand`); `f64 | null` and `i32 | string | null`
folded to `false`. A `null` unit, a `null`-returning call, or `(x = null)` against `i32 | null`
built an invalid module (`expected i32, found nullref`).
