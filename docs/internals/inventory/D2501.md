### D2501 — a function that calls a `() => S[] | null` parameter is refused at emit, even when nothing calls it

**loud emit reject · "function-value call arity has no interned signature" · clause 2 · filed
2026-09-25 against master `dec16071c`, found by the review of #3162 (its `cbn` column), which
leaves it as it was**

Repro:

    type S = { a: i32 }
    function runN(cb: () => S[] | null): S[] | null { cb() }
    print("ok")

#### Mechanism

The call through `cb` looks up an interned function signature for the parameter's type, and none
is interned for a `() => S[] | null` result. The declaration alone reaches the lookup, so an
unused helper blocks the whole program while `vl check` accepts it. Not yet ablated: which other
nullable ref-array results miss the intern is the first question.
