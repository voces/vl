#### Mechanism

`__deliver` is a plain function returning `__gen(...)`'s result, a record of one closure per
signature. The check keeps it refused (`letCstrBundleServed` declines a function handing back
another call's result). With the refusal lifted the module fails to validate inside
`__deliver`: its result type and the call's disagree (`current function requires result type
[(ref $28)] but callee returns …`), the clause-1 case that must close before this position lifts.
