### D1902 — [CLOSED 2026-09-07] the totality rule read a bare block's tail as an implicit return, so the emitter padded a live path with `unreachable`

**now a loud check reject (that is the CLOSE) · was check-clean invalid wasm at five spellings (`wasm trap: unreachable`, exit 70) · filed and closed 2026-09-07 against master `fbe0b0f01` · 5 silent -> loud, 0 runs lost · fixtures `tests/cases/soundness/missing-return-bare-block-tail-reject.vl`, `…-wraps-if-reject.vl` and `…/bare-block-tail-that-diverges-sound.vl`**

Repro:

    function k(): i32 { { 5 } }
    print(k())
    // vl check: rc 0.  vl run: wasm trap, `unreachable` instruction executed

#### Mechanism

`emitFuncBody` pads a body that does not end in a return with an explicit `unreachable`, and
`bodyEndsInReturn` says why that is allowed: *"sound because the typechecker proved that path
dead."* `nodeIsTotal` is that proof, and its `Block` arm recursed into a nested block and then
answered the tail question of the block's own last node — so `{ 5 }` reported an implicit
return that nothing emits. Three subsystems disagreed about one program: the checker's totality
said total, `isStmtNode` (D1901) said a bare block is a STATEMENT so inference said `void`, and
`drwBareBlock` lowered it to an else-less `if true` whose value `emitFuncBody`'s tail ladder
drops. The emitted body is `(if (i32.const 1) (then (drop (i32.const 5)))) (unreachable)`.

The fix is one place: a body whose last statement is a bare block is total only if that block
DIVERGES, so `nodeIsTotalAt` carries the position (`tail`) and `nodeIsTotal` is the body entry
that turns it off under a block. Were a bare block to become an expression, that arm reads
`nodeIsTotalAt(last, true)` and the row reopens as a lowering.

#### Ablation

| spelling | before | after |
| --- | --- | --- |
| `function k(): i32 { { 5 } }` | **check-clean, traps** | check refuses |
| `function k(): i32 { { { 5 } } }` | **check-clean, traps** | check refuses |
| `function k(): i32 { { if true { 5 } else { 6 } } }` | **check-clean, traps** | check refuses |
| `function k(): string { { "hi" } }` | **check-clean, traps** | check refuses |
| `const f = (): i32 => { { 5 } }` | **check-clean, traps** | check refuses |
| `function k(): i32 { { return 5 } }` | runs | runs |
| `function k(): i32 { { while true { return 7 } } }` | runs | runs |
| `function k(): i32 { { if c { return 1 } else { return 2 } } }` | runs | runs |
| `function k(): i32 { { 5 } return 9 }` | runs | runs |
| `function k(): i32 \| null { { 5 } }` | runs | runs |
| `function k(): i32 { if true { { 5 } } else { 6 } }` | runs | runs |
| `function k2(): i32 { if true { 5 } }` | check refuses | check refuses |
| `function k() { { 5 } }` (un-annotated) | check refuses, `void` | check refuses, `void` |

The type is not an ingredient (`i32` and `string` behave alike) and neither is the nesting
depth. The ingredient is the POSITION: a bare block at the body's tail. A bare block at an `if`
ARM's tail still delivers its value, which is D1903.

#### Grading list

* `function k(): i32 { if true { { 5 } } else { 6 } }` and its `else`-arm and two-deep twins —
  these RUN, and a totality rule wide enough to refuse them loses working programs. Pinned by
  `tests/cases/soundness/bare-block-tail-that-diverges-sound.vl` and filed as D1903.
* The un-annotated face `function k() { { 5 } }`, which must stay `void` (D1901's ruling).
* `function k(): i32 | null { { 5 } }`, which runs through `elseLessNullableTail` and must not
  be swept up by a rule keyed on the block rather than on the return type.
