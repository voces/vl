#### Mechanism

`v`'s set `{id}` is tagged, so its cell is `id`'s id. `ys`'s write widens the list's set to
`{id, inc}`, which stays untagged, and mono pins its element at `(i32) => i32`
(`monoUncalledListElems` here, `monoPinListElems` when a call goes through `ys`), retyping the
read `v` to it. The literal is then built as a
list of closures from an i32 id. The tag decision records such a delivery as a member's closure
(`fnCloCoerceNote`) only at a closed type it saw, and the closed type here is mono's.
