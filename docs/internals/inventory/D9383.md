### D9383 — a second un-annotated function returning the same generic drops the first one's per-destination copies

**closed · runs, prints `q` `2` `3` · was loads then traps, clause 1, `vl check` rc 0, `wasm trap: indirect call type mismatch` · found closing [D9282](D9282.md) · filed 2026-10-21 against master `a28f82fcb` · closed by refusing the generic read a return pinned at two signatures carries, so the emit-error re-plan copies its function per signature even when another delivery already instanced the generic (`monoRetCopyReads`, emit_state.vl, read by `monoStubValueOk`; `monoAskRetCopies`, emit_mono.vl) · fixtures `closures/generic-returned-by-two-functions.vl` and `closures/generic-returned-litunion-to-string.vl`, matrix `fn-value-generic-returned-beside-copies` (0 → 48 of 48)**

Repro:

    function same<T>(k: T): T { k }
    function d9() { return same }
    const v9: (k: i32) => i32 = d9()
    const w9: (k: string) => string = d9()
    print(w9("q"))
    print(v9(2))
    function d1() { return same }
    const v1: (k: i32) => i32 = d1()
    print(v1(3))
    // vl check rc 0.  vl run: wasm trap: indirect call type mismatch

Want:

    q
    2
    3

#### Mechanism

A return the flow table pins at two signatures asks the fn_split plan for a copy of `d9` per
signature, and the driver re-plans only when the first compile fails at emit. Alone, the bare
`same` read in `d9` reaches a stub slot, which refuses it, so the plan runs. With `d1`
instancing `same` at `(i32) => i32`, that instance owns `same`'s slot, the read in `d9` emits it
without a refusal, the compile succeeds, and no copies are made. The read is now recorded when
the copies are asked for and refused like the stub, so the plan runs whatever else instanced
the generic. A `const s = same; return s` alias records the initializer's read.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `d1` and its call | runs, `q` `2` | **yes** |
| `d1`'s binding (`print(d1()(3))`) | still traps | no |
| `d1` bound at `(k: string) => string` | still traps after `q` | no |
| the second destination of `d9` | runs | **yes** |
