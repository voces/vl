### D9383 — a second un-annotated function returning the same generic drops the first one's per-destination copies

**loads then traps · clause 1 · `vl check` rc 0 · `wasm trap: indirect call type mismatch` · found closing [D9282](D9282.md) · present on master `a28f82fcb` · filed 2026-10-21 against master `a28f82fcb`**

Repro:

    function same<T>(k: T): T { k }
    function d9() { return same }
    const v9: (k: i32) => i32 = d9()
    const w9: (k: string) => string = d9()
    print(w9("q"))
    print(v9(2))
    function d1() { return same }
    const v1: (k: i32) => i32 = d1()
    print(v1(3))
    // vl check rc 0.  vl run: wasm trap: indirect call type mismatch

Want:

    q
    2
    3

#### Mechanism

Not traced. Alone, `d9` bound at `(k: i32) => i32` and `(k: string) => string` is split into
one copy per destination and runs. With `d1` also returning `same`, the module holds a single
`d9` returning one instance of `same`, so one of the two calls through it is typed against the
other instance's signature.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `d1` and its call | runs, `q` `2` | **yes** |
| `d1`'s binding (`print(d1()(3))`) | still traps | no |
| `d1` bound at `(k: string) => string` | still traps after `q` | no |
| the second destination of `d9` | runs | **yes** |
