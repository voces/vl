### D15351 — a record whose field is a list of an un-annotated function, written whole with another member, is refused at emit

**closed · runs, prints `2` then `2.5` · was a loud emit reject (`emitProgram: ref valtype with no interned shape`), clause 2 · one call type, one member, or a slot write ran · found checking D15234's mechanism against D15335's residue · filed 2026-11-04 against master `9a45989d`**

Repro:

    function id1(a) { return a }
    function id2(a) { return a }
    let r = { f: [id1] }
    r = { f: [id2] }
    print(r.f[0](2))
    print(r.f[0](2.5))

Want:

    2
    2.5

#### Mechanism

Not D15234's. The scan plans `{id1, id2}`, then `ftPlan` refuses at its member-leaf check:
`id2`, written only inside the list literal of the record written whole, has no leaf type
(`t < 0` with no sub-set to bring it), so the set stays untagged and `r`'s global keeps
`{f: ((_) => _)[]}`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the second call type | runs | **yes** |
| `id2` (`r = { f: [id1] }`) | runs | **yes** |
| the whole-record write → a slot write `r.f[0] = id2` | runs | **yes** |
| module scope → inside a function | still refuses | no |
| the write as a value `if` of two such records (D15335's residue) | still refuses | no |

#### Close

`ftRecWriteJoins` (check_fn_tag.vl) joins each element of a list literal that is a direct field
of the record written whole into the set, and re-types the list literal to the field's list of
the set, so it is built as the `i32` list the binding's field holds. Residue: D15380 (the write
an `if` of records), D15381 (the list a record deeper), D15382 (the field a list binding).
