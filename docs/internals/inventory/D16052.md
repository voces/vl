### D16052 — a row-less member slice keeps its members' canon spellings as an atom column that readers decide by

**closed 2026-11-14 — the witness runs; a row-less slice keeps member types and literal flags only, and the atom column is deleted · was: row-less slice atoms read in 5,576 programs of the sweep population · filed 2026-11-13 against master `68eb4f40`**

Repro:

    type A = { v: i32 }
    function F(z: { h: A | i32 | string }) { if z.h is A { print(z.h.v) } else { print(z.h) } }
    const x: { h: A | i32 | string } = { h: "s" }
    F(x)

Want:

    s

#### Mechanism

`msFreeSliceOfTy` (emit_union_registry) builds the member slice of a union type that no registry
row keys. It takes the members from `canonUnionMembersLitsInto`, which returns each member's canon
spelling beside its type, and `msFreeSlicePush` (emit_rep) stores those spellings as the slice's
atom column. The contract this row carries: a row-less slice's atoms are its canon member
spellings. Two readers consume them. `msRenderSet` joins them into the set's text (5,669 programs),
and `msMemberAtomsOfSet` hands them to callers (5,576 programs). A caller that compares or parses
those spellings decides by text, which is the defect this row tracks.

#### Callers of `msMemberAtomsOfSet` that reach a row-less set

Each site was tagged and probed over 24,020 corpus and witness files. "Decides by text" means it
compares or parses the spelling rather than only passing it on.

| site | programs reaching a row-less set | use of the atoms | owner |
| --- | --- | --- | --- |
| `unionTyArms` (emit_map_twins) | 5,499 | passes atoms and types on; `unionTyHasAtom` decides by text | G, per caller |
| `unionArmsOfSetTy` fallback (emit_union_registry) | 85 | passes on | G |

| `sharedUnionFieldPlan` (emit_classify) | 2 | reads atoms beside types | coordinator to assign |

The other eleven call sites never received a row-less set in that population:
`msSetHasAtom` (emit_fn_scans), `setArmTysInto` (emit_map_twins), `unionArmsOfSetTy`'s row path,
and in wasmEmit `unionBoxHasNoRow`, `emitUnionUnionEq` ×2, `emitMapGetOrUnionBox`,
`emitBoxAtomRetag` ×2, `staleBoxFrom` and `emitStaleBoxRetag`.

#### Close

Convert the reaching callers to `msMemberTysOfSet` and type tests, and stop keying set identity
on the rendered set text. Then `msFreeSliceOfTy` takes `canonUnionMemberTysOf` plus the literal
flags, and the free slice's atom column (`msFreeAtoms`) is deleted.

Done 2026-11-14 across lane G's PRs #7876 to #7928 and this one. The last reader,
`sharedUnionFieldPlan`, counts member types and tests `null` by type. The set text
(`msSetText`, `msRenderSet`, `msTextOf`) went with it: `msSetIntern` matches sets by mask, so
the text was never part of set identity. `msFreeSliceOfTy` takes `canonUnionMemberLitsOf`, and
its kind column answers `null` from the type. The `msFreeSliceOfTy` floor is retired. The
`canonUnionMembersWalk` floor stays, because `canonUnionMembersInto`'s label callers still read
the walk's atoms.
