### D15069 — a written binding of generics listed in an inferred list, spread into a push onto a list of a closed function type, is refused at emit

**closed 2026-11-03 · runs, prints `1` `s` `40`, with the split plan on and off · was a loud emit reject, clause 2 · `fvaListSetCopy` (check_assignable.vl) rewrites a list of a function set copied into slots of a closed function type to `src.map(($e): T => $e)`, so each element passes through its adapter; wired at a spread into `push` and at every readonly list delivery (`assignableExpr`, `fvaAdapt`) · fixture `tests/cases/closures/fn-set-list-copied-into-closed-list-slots.vl` · the positions still refused are D15132 · filed 2026-11-03 against master `6c4f4444`**

Repro:

    function id<T>(x: T): T { return x }
    function loud<T>(x: T): T {
      print("loud")
      return x
    }
    function main() {
      let f = id
      print(f(1))
      print(f("s"))
      const ys: ((x: i32) => i32)[] = []
      const zs = [f]
      ys.push(...zs)
      f = loud
      print(ys[0](40))
    }
    main()
    // vl check: rc 0.  vl run, before: emit error, with the split plan on and off

Want:

    1
    s
    40

#### Mechanism

The inferred list `zs` holds the set `{id, loud}` as one value type. Spreading it into `ys`
copies each element into a closed `(i32) => i32` slot, which needs an element-converting copy
(the D965 family) that builds the binding's instance at that type per element. No such copy
exists for a list of a set, so the set stays one closure called at two types.
