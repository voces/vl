### D14495 — a fresh record from an inferred fn builds at its own row when one call site is a list element, so its widened argument site gets the wrong struct

    0

#### Mechanism

`recFnBuiltAtDst` adopts an inferred fn's literal at its destination only when every call site
lands there, and `recSitesLandAt` serves a read-only site only through `recNullWidened` +
`recReadInPlace`. A site that is an element of a list literal (`[mkcall()]`) passes neither, so
the literal keeps its own row `{r: null}`. The `sink(mkcall())` argument then delivers that row
where `Circle`, which stores `r` as a nullable box, is expected, and nothing copies it there.
