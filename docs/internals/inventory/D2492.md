### D2492 — `for x in xs` over a list of maps or sets refuses at emit: unsupported for-in iterable

**loud emit reject · found by #3158's review (`rv3158-p/pre2.vl`, `pre3.vl`) · identical on master · filed 2026-09-25 against master `0a0d24ac9`**

Repro:

    const xs: {[string]: i32}[] = [Map()]
    xs[0]["k"] = 1
    for s in xs { for k in s.keys() { print(k) } }
    // vl check: rc 0.  vl build: emitProgram: unsupported for-in iterable

#### Mechanism

Not ablated. The for-in lowering has no arm for a ref list whose element is a map struct
(`rlElemKindTbl` kind 3); an index loop over the same list runs. `Set<string>[]` fails the same
way, because a set is the same map struct.

#### Grading list

* `const xs: Set<string>[] = [Set()]; xs[0].add("a"); for s in xs { print(s.length) }`.
