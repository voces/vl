### D3324 — references to an imported name mix the defining module's ranges into the entry document's list, with no file attached

**closed by #3331 (lane HV): `referencesAt` on `L` in the entry now answers `1:9` alone, and a position query resolves only the entry document's occurrences · the program runs today and must keep running · was: `0:13`, `1:38` and `1:9`, with `lib.vl`'s declaration and its read inside `lf` presented as ranges of the entry · found in the #3296 round-4 review (`lsp2.ts`) · filed 2026-09-29 against #3296 head `fcb70b50e`**

Repro:

    // file: lib.vl
    export const L = 0xFFFFFFFF
    export function lf(x: i64): i64 { x + L }
    // file: entry.vl
    import { L, lf } from "./lib"
    print(lf(L))

#### Mechanism

Confirmed by the close. The symbol table records occurrences from every module the check walks,
keyed by token, with each module's own line and column. `symOccAt` matched a cursor against all of
them, and `symRefFillAt` listed every occurrence of the binding, so `referencesAt` returned other
modules' occurrences as bare ranges that the host placed in the requesting document. The same
missing filter made hover answer with another module's name at the same coordinates (#3331's
review: `BIG` in `import { SIZE, BIG }` hovered as util's `SIZE`). Both now keep only the entry
module's occurrences (`compiler/check_query.vl`; the `symOccAt` half is also D3476's, fixed
independently in #3333 with the same line). The member-access lookup (`symMemIxAt`, and the
getter walk in `symGetterDefAt`) had the same hole: member hover answered `string` for the entry's
`rr.longname` because util's `p.s` sat at its coordinates. `symMemInEntry` closes it.
`tests/lsp_exact_const_hover_test.ts` pins this witness and the member one. What stays: references from an importer list the importer's uses only. The
defining module's uses come from the cross-file crawl, which the server runs only when
`referencesAt` finds nothing.

| `L` declared in the entry document | all ranges are the entry's | **yes** (the import) |
