### D4916 — an element read under `is K[]` on an un-annotated parameter holding a string list is invalid wasm

**closed 2026-10-15 — now prints `y` · was check-clean invalid wasm, clause 1 · an element read and a `for` over a narrowed list now ask the list's own rep, which is the string list here, before its narrowed type · found closing D4906 · filed 2026-10-15 against master `23dcd80be` · pin: `tests/cases/unions/inferred-string-list-is-atom-list.vl`**

Repro:

    type K = "x" | "y"
    function t(a) {
      if a is K[] { print(a[0]) } else { print("no") }
    }
    t(["y"])
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `t`: type mismatch: expected i32, found (ref $3); $3 is `string`

Want:

    y

#### Mechanism

The parameter's instance is `string[]`, and the narrowed `a` read its
element as a `K` atom (`i32`) while the list holds strings; the annotated `a: string[]` read
the same element correctly. `idxRecvIsStrList` and `forInVarIsLitAtom` asked the narrowed
type before the list's rep.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `function t(a: string[])` | prints `y` | **yes** (an un-annotated parameter) |
| `print(a.length)` in place of `a[0]` | prints `1` | **yes** (an element read) |
| `type K = 0 \| 1`, `t([1])` | prints `1` | **yes** (a string literal union) |
| `a is K` over `t("y")` | prints `y` | **yes** (a list) |

#### Grading list

`for k in a` in the then-branch, and a generic `function t<T>(a: T)`.
