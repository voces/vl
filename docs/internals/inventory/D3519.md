### D3519 — a lambda returned from a generic instance, joining a record, a scalar and `null`, boxes into a union no pass registered

**loud emit reject · was invalid wasm on master at the declared spelling · clause 2 · found by lane CL's D3506 grid (4 of 459 cells) · filed 2026-10-03 against master `b2238d2c6`**

Repro:

    type Rec = { x: i32 }
    const r7: Rec = { x: 7 }
    function F<P, Q>(k: i32, a: P, b: Q) {
      () => { if k == 0 { a } else if k == 1 { b } else { null } }
    }
    print(F(2, r7, 4)() == null)
    // vl check: rc 0.  vl run: emit error, "a record value delivered into a union box this program never registered has no tag"

Want:

    true

#### Mechanism

The lambda's result at the pin is the box union `{x:i32}|i32|null`, but nothing registers a
row for it: `collectU` runs before the pin exists, and the mono pass registers the unions an
instance's own RESULT mints (`monoRegisterPinUnion`), not those of a lambda the instance
returns. With no row the record arm has no tag, and `emitUnionCoerce` passed the raw record
ref into the box (invalid wasm). It now refuses loudly (`unionBoxHasNoRow`). The fix is to
register the returned lambda's pinned result union where the instance's result is registered.
