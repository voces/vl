### D12701 — a list of hole functions handed a frame's forwarded hole function and a value has no interned signature

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same loop handed the named `add` runs ([D10700](D10700.md)) · found closing [D10700](D10700.md) · filed 2026-10-25 against master `a448ccb42`**

Repro:

    function add(a, b) { return a + b }
    function apply2(g, s) {
      print(g(1, 2))
      print(g(s, s))
    }
    function apply3(g, s) {
      print(g(10, 20))
      print(g(s, 0.25))
    }
    function inner(k, h) {
      for f in [apply2, apply3] { f(h, k) }
    }
    inner(0.5, add)
    // vl check: rc 0.  vl run: emitProgram: a function-value call has no interned signature — parameter 1 of type `` has no representation in the function-value ABI

Want:

    3
    1
    30
    0.75

#### Mechanism

`h` is a hole parameter of `inner` bound to `add`, which each element calls at two types. The
element typing reads `h`'s pins only for an argument that names the function itself; reading a
forwarded parameter's pins under the elements' value binding put its slots out of order and
built invalid wasm, so it is declined and the call has no signature.
