### D4264 — a record literal delivered into a union is refused when its arm's field is a nullable integer literal set

**loud check reject · clause 2 · the same on master `f6ee50929` · found by the D4056 inline-literal grid · filed 2026-10-12 against master `f6ee50929`**

Repro:

    type A = { v: 1 | 2 | null }
    type B = { w: boolean }
    function f(u: A | B): string {
      if u is A { return "A" }
      "B"
    }
    print(f({ v: 2 }))
    // vl check: rc 1, "argument 1: expected A | B, got {v: i32}"

Want:

    A

#### Mechanism

The literal's field is typed by its own value, `i32`, and matched against each arm of the
destination union. An integer literal set with `null` does not take the `2` back as a member
there, though the same literal delivered to a lone `A` does. The string literal set and the
plain `i32 | null` arm both match.
