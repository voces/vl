### D6120 — a hole parameter bound by an un-annotated empty-`[]`-or-`null` join is typed as a non-null list, so the `null` arm traps at the call

**loads then traps · clause 1 · `wasm trap: null reference` at the call · found closing the L2 `/narrowed` listRep family, while re-grading [D2226](D2226.md) · filed 2026-10-17 against #4051's head `d225cdd35`**

Repro:

    function take(a) {
      print(a == null)
    }
    const c = 1 == 2
    const x = if c { [] } else { null }
    take(x)
    // vl check: rc 0.  vl run: wasm trap: null reference, at `take(x)`

Want:

    true

#### Mechanism

From the ablation and the disassembly. `take`'s instance takes its parameter as `(ref $list)`, which is non-null. The call wraps the join in `ref.as_non_null`, which traps on the `null` arm. The body folds `a == null` to `false`. So the instance binds the hole at the list without the `| null`. The arm `[]` has no element type of its own, and that is what the join needs. With `[1]` in its place the same program prints `true`.
