#### Mechanism

Not localised past the ablation. The third call pins every parameter at `boolean`, so its join is
`boolean`, while the two earlier instances build `o` over a union box. The trap is the third
instance's read of `o.v`, which casts to a row the instance did not build: the record literal's
row looks shared between instances whose joins differ.
