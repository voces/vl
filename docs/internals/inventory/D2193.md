### D2193 — `.map` has no result list for a nullable union-arm or nullable-list element, so the copy the container rule suggests for those pairs does not build

**loud emit reject · clause 2 · 2 element kinds · filed 2026-09-23 against master `66e74235a`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    const cs: Circle[] = [{ r: 7 }]
    const w: (Circle | null)[] = cs.map((x): Circle | null => x)
    print(w.length)
    // vl check: rc 0.  vl run: emit error, unsupported .map/.filter element type

#### Mechanism

`mfResultKindOf` names a result list for a callback returning a struct row (bare or, since
[D2161](D2161.md)'s close, nullable), a variant, a union, a string and the scalars. A callback
returning `Circle | null` where `Circle` is a union ARM classifies `nulvariant`, and one
returning `i32[] | null` a nullable list; neither has an arm, so `.map` refuses at emit. The
container rule's refusal of `Circle[]` into `(Circle | null)[]` names exactly this `.map` as its
second fix (the first, `readonly (Circle | null)[]`, builds), so the suggested copy is refused
one stage later.

#### Ablation

| spelling | outcome | needed? |
| --- | --- | --- |
| the witness (`Circle \| null`, an arm of `Shape`) | emit reject | — |
| `C \| null` with `C` a plain record, no union around it | runs | the arm: **yes** |
| `i32[] \| null` from an `i32[][]` | emit reject | element kind: no |
| `Shape \| null` (the whole union, nullable) | runs | **yes** |

#### Grading list

The witness, and `ls.map((x): i32[] | null => x)` over `ls: i32[][]`, which is the copy the
refusal names for `i32[][]` into `(i32[] | null)[]`.
