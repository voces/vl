### D17165 — the IR misses a record field holding a list of lists of hole functions read at its length

**runs today and must keep running · an IR coverage defect · filed 2026-11-24 against master `aef0be317` by lane IR-N2 (census class `start: field read coercion`, family L, 2 cells)**

Repro:

    function inc0(a) { return a + 1 }
    const r = { f: [[inc0]] }
    print(r.f.length)
    // VL_IR_SHADOW=1 vl build: `start uncovered field read coercion` (kid rep list → list)

Want:

    1

#### Mechanism

`buildMember` (`ir_build_ref.vl`) declines a plain struct field read when the field's kid rep is
not the read's rep: here two different list reps (measured with a probe build naming both). Legacy
builds the read; which decision gives the read its rep is the fix's to establish.
