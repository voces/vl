### D4262 — `is B` over overlapping record arms does not narrow the then arm, so a `B` delivery there is refused

**loud check reject · clause 2 · follows D4056: before it the union itself was refused · filed 2026-10-12 against master `f6ee50929`**

Repro:

    type A = { v: i32 | string }
    type B = { v: string }
    function asB(b: B): string { b.v }
    function pick(f: boolean): A | B {
      if f { return { v: 1 } }
      const a: A = { v: "s" }
      a
    }
    const u = pick(false)
    if u is B { print(asB(u)) } else { print("A") }
    // vl check: rc 1, "argument 1: expected B, got A | B"

Want:

    s

#### Mechanism

`is B` tests the value, so it passes an `A` whose `v` holds a string (D4056). That value is laid
out as `A`, and `B` is laid out apart, so the checker keeps `A | B` in the then arm rather than
claim a narrowing the emitter cannot deliver (`recIsFitsAcrossTags`, `typecheck.vl`). A close
needs a converting delivery: copying the fields into a fresh `B` when the value sits under `A`'s
tag, at every position a narrowed `B` can be delivered, before the checker narrows.

#### Ablation

| variant | outcome |
| --- | --- |
| this witness | check refusal |
| `print(u.v)` in the then arm (no delivery) | runs, prints `s` |
| disjoint arms `{ v: i32 } \| { v: string }` | runs, the then arm narrows |
