### D13082 — a labelled block handing over a hole function that reads the loop variable of the loop it is declared in is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the annotated twin `inner(s: string)` / `ask(s: string)` prints `a!q` · the residue of [D12841](D12841.md) · found closing [D12841](D12841.md) · filed 2026-10-25 against master `0adbf4b86`**

Repro:

    function ask(s) { return s + "?" }
    function g(xs: string[]) {
      const x = @B {
        for v in xs {
          function inner(s) { return s + "!" + v }
          if v == "q" { break @B inner }
        }
        ask
      }
      print(x("a"))
    }
    g(["p", "q"])
    // vl check: rc 0.  vl run: emitProgram: local declaration needs an initializer

Want:

    a!q

#### Mechanism

From the code path. The block's value is a function of an open signature, so its carrier cannot
be a binding of that type (D6990), and [D12841](D12841.md)'s index carrier names the chosen
function after the loop. A function that reads `v` is a different value at every iteration,
which an index cannot rebuild (`lvReadsScopeLocal`, emit_rewrite.vl), so the block falls back to
the `let $lvN: T;` carrier the `i32` floor refuses. Carrying the closure itself needs a binding
whose type is the hole function's signature, bound once per call of `x`.
