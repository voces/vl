### D16220 — record literals of un-annotated functions handed to an un-annotated parameter, beside a bound record `if` sharing those functions, are refused at emit

**open · loud emit reject · `emitProgram: this record `if` stores functions of different signatures in one field, and a call through the joined record is lowered at one of them` · clause 2 · split from [D15809](D15809.md), whose inline-join witness now runs · filed 2026-11-14 against master `293074baf` · bucket (a), slot store (the 2026-11-14 clause-2 map)**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function two() { [1, 2].length }
    function take(r) { return r.f(3) }
    function take2(n, r) { return r.f(n) }
    const q = if two() > 5 { { f: half } } else { { f: inc0 } }
    print(take(q))
    print(take2(3, { f: inc0 }))
    print(take2(2.5, { f: half }))

Want:

    4
    4
    1.25

#### Mechanism

As [D15809](D15809.md) traced it: a record literal handed to `take2` is built at a closed
closure record, which pins `inc0` and `half` at two signatures, and `q`'s join holds both, so the
floor (`joinCloSigSplitField`, wasmEmit.vl) refuses it. Not the inline-argument mechanism: each
literal bound to a `const` first refuses the same way.

#### Ablation

| every call at one type, `take2(3, { f: inc0 })` and `take2(3, { f: half })` | loud emit reject |
| without `take(q)` | runs |
