### D3201 — a `??` over a `boolean`-valued map read with an `i32` default builds invalid wasm, or refuses at emit when printed

**check-clean invalid wasm · clause 1 · open · found by the #3282 round-4 review's `genx` grid (its annotated twins `w4a`, `w1a`) · the same on master `2771214c7` · filed 2026-09-29 against master `2771214c7`**

Repro:

    type R = { m: {[i32]: boolean} }
    function use(p: R) {
      const r = p.m[1] ?? 3
      print("done")
    }
    const mm: {[i32]: boolean} = Map()
    mm[1] = true
    use({ m: mm })
    // vl check: rc 0.  vl run: invalid module inside `use`, expected (ref $type)

Want:

    done

#### Mechanism

Not localised. The `??` joins the map's `boolean` value with the `i32` default into
`boolean | i32`, a value-union box. The fused map read lowers at the map's own niche rep, an
`i32` with `2` meaning a miss, and the binding takes the box, so the two disagree. Printed
directly instead of bound, the same read refuses loudly:
`emitProgram: narrowed union atom has no value box` (`print(p.m[9] ?? 3)`, the review's `w1a`).

#### Ablation

| ingredient changed | outcome on master `2771214c7` | needed? |
| --- | --- | --- |
| `print(p.m[9] ?? 3)` instead of the binding | loud emit reject, `narrowed union atom has no value box` | no (the same join, refused) |
| `?? false`, a default of the value type | runs | **yes** (the mismatched default) |
| `function use(p)`, un-annotated | runs, `done` | **yes** (the annotation) |

#### Grading list

The review's `w4a` and `w1a`, and the `genx` grid's annotated `boolean`/`boolean \| null` cells
with an `i32` default: each must print its value.
