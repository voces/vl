### D2874 — `.length`, `u[i]` and `for v in u` over a union of lists refused, though every member is a list

**closed 2026-09-27 · was loud check reject, clause 2, on master `460a67010` · filed 2026-09-27 · fixtures `tests/cases/unions/list-union-read-ops.vl`, `tests/cases/unions/error-list-union-index-write.vl`, `tests/cases/unions/error-list-union-declined-shapes.vl`**

Repro:

    function mk(b: boolean): string[] | i32[] {
      if b { return ["a", "bc"] }
      [1, 2, 3]
    }
    const u = mk(false)
    print(u.length)
    print(u[1])
    for v in u { print(v) }

Want:

    3
    2
    1
    2
    3

#### Mechanism

The checker's member arm asked `sharedUnionFieldTy`, which knows only record members, so
`.length` over `string[] | i32[]` said "not on every member"; the index arm and the for-in arm
had no union rung at all. The real pass now rewrites each read in place, as `match` does, into an
`is` chain over a `const` holding the receiver (annotated at the union, which D2875 needs), so
it lowers exactly as the narrowed spelling does: `.length` is `i32`, `u[i]` is the element union
kept apart (`f64[] | i32[]` reads `f64 | i32`, delivered through a `const` at that union so no
arm widens), and `for v[, i] in u` is a `while` over the chain that re-reads the length each
pass as a list's own loop does. A write through the index stays refused, with its own sentence,
since the value would have to fit every member. A union-typed if-expression arm ending in a
`never` call (the chain's `else`) now lowers as the scalar join's already did (D1972). A generic
body's `T[] | i32[]` is not rewritten (D2876), nor a union with a readonly member (D2887) or a
literal element (D2886), whose narrowed reads do not lower; a write to `.length` and every
method (`slice`, `map`, `push`) keep their refusals.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the second list member (`: i32[]`) | runs | **yes** |
| a non-list member (`string[] \| i32`) | still refuses, by design | **yes** |
| the call receiver (a bound `const u`) | refused on master | no |
