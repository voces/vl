### D2171 — an explicit `return` of a field write has no value lowering

**loud emit reject · clause 2 · filed 2026-09-23 against master `a453c09c5`, residue of [D2170](D2170.md), whose close spills only a tail write**

Repro:

    type Node = { v: i32, left: Node | null }
    function insert(n: Node, v: i32) {
      if n.left == null { return n.left = { v: v, left: null } }
      insert(n.left, v)
    }
    const root: Node = { v: 5, left: null }
    insert(root, 3)
    print(root.left?.v ?? 0)
    // vl check: rc 0.  vl run: emitProgram: ref valtype with no interned shape

#### Mechanism

D2170's spill (`const v = r; t = v; v`) rewrites a block's tail; the argument of a `return` is
not one, so `return t = r` with a field target still reaches `emitBinExprNode`'s `=` arm, which
refuses anything `assignTargetReReads` does not admit (`only an identifier assignment is a value
expression` when the result has a row; here the anonymous literal's type has none first). The
same spill before the `return` statement would deliver it.

#### Grading list

`return o.x = 5` over `{ x: f64 }`; `return xs[i] = 5` with a computed index.
