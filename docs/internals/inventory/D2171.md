### D2171 — an explicit `return` of a field write has no value lowering

**closed · runs, prints `3` · was loud emit reject, clause 2 · fixed 2026-11-13: a `return` or function-level `let` that yields a field or element write spills it before the statement, as D2170 spills a tail · the operand, call-argument and module-level positions are [D16015](D16015.md) · filed 2026-09-23 against master `a453c09c5`, residue of [D2170](D2170.md), whose close spills only a tail write**

Repro:

    type Node = { v: i32, left: Node | null }
    function insert(n: Node, v: i32) {
      if n.left == null { return n.left = { v: v, left: null } }
      insert(n.left, v)
    }
    const root: Node = { v: 5, left: null }
    insert(root, 3)
    print(root.left?.v ?? 0)

Want:

    3

#### Mechanism

D2170's spill (`const v = r; t = v; v`) rewrites a block's tail; the argument of a `return` is
not one, so `return t = r` with a field target still reaches `emitBinExprNode`'s `=` arm, which
refuses anything `assignTargetReReads` does not admit (`only an identifier assignment is a value
expression` when the result has a row; here the anonymous literal's type has none first). The
same spill before the `return` statement would deliver it.

#### Grading list

`return o.x = 5` over `{ x: f64 }`; `return xs[i] = 5` with a computed index.

#### Closed (2026-11-13)

`spillValueWrites` (emit_rewrite) walks each function body, through `if` arms and loop bodies,
for a `return` (in a function that yields) or a `let` whose value is a field or element write.
It reuses D2170's `spillWrite`, so the receiver, the index and the value are each evaluated once,
in source order, before the write, and the statement yields the spilled value. Graded on the
candidate, all running and printing the stored value:
- the witness;
- `return o.x = 5` over `{ x: f64 }`;
- `return xs[i + 1] = 5`;
- `return xs[i] = 5`;
- a `return` in a `while` loop;
- `return mk().x = 5` (`mk` runs once);
- `return xs[next()] = 50 + k` (the index is evaluated before the value);
- a lambda's `return xs[i] = i * 10`;
- a lambda's record write;
- a function-level `const y = xs[i] = 5`.

Unchanged: an `f64` field, a literal index, `+=`, a `null` right side, a declared record, a
nested block and a bare tail. Test: `tests/cases/expressions/returned-field-or-element-write-yields-its-value.vl`.
