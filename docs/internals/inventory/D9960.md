### D9960 — a type alias whose body is a list of a function type is read as a union, so measuring a value of it is refused

**loud check reject · clause 2 · pre-existing, the same on master `0f0face1e` · a sibling of [D3298](D3298.md), whose alias body is a list of a union · found writing the `diamond-record-fn-alias` fixture for [D9891](D9891.md) · filed 2026-10-22 against master `0f0face1e`**

Repro:

    type FF = (x: i32) => i32
    type L = FF[]
    const fs: L = [(x: i32): i32 => x]
    print(fs.length)
    // vl check: field 'length' is not on every member of L — narrow with `is` first (((i32) => i32)[] is a list, not a record)

Want:

    1

#### Mechanism

Not traced. The refusal names `((i32) => i32)[]` as a member of `L`, so the alias's body is
taken for a union whose one member is the list, as D3298's list of a union is; the member
check then asks for `length` on a record and finds a list.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const fs: FF[]`, no list alias | runs, prints `1` | **yes** |
| `type L = ((x: i32) => i32)[]`, the function type inline | refuses the same | no |
| `print(fs[0](4))` and a `for` over `fs` instead of `.length` | refuses | no |
| `type L = H[]` with `type H = {v: i32}` | runs | **yes**, a function element |
| `type L = (string)[]` | runs | **yes** |
| `type L = (i32 \| string)[]` | refuses, D3298 | — |
