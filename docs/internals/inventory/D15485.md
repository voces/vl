#### Mechanism

The join is the only ingredient that matters. Each destination reports a different message:

- `r(2)` and a closed parameter say the generic reaches no fixing call;
- a hole parameter says the call has no interned signature;
- a generic parameter says `unsupported argument type`.

So the call that would fix the instance is not traced back through `??` to either operand, while
it is traced through a value `if`.
