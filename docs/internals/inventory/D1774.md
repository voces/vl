### D1774 — `is <union alias>` has no interned arm representation, so a `vl check`-clean arm test refuses at emit

**loud emit reject · found 2026-09-06 while closing D1744, which was masking it with a
checker refusal · clause 2**

Repro:

    type U = i32 | string

    function f(d: U | boolean) {
      if d is U { print(1) }
    }
    f(1)
    // vl check: rc 0.  vl run: emitProgram: `is` names a declared union member with
    // no interned arm representation (deferred value-union composition)

#### Mechanism

`U` is a member of `U | boolean` under its own name, so `checkIsExprNode`'s arm gate admits
it. The emitter then asks `variantIndexOf` for the arm, and a union whose member is itself a
value union has no interned row for that member — the arm exists in the type and not in the
rep — so `wasmEmit.vl`'s `is` ladder falls to `emitFail`. Nothing about the alias's own
member kinds matters: the same refusal stands for `type J = null | boolean | f64 | string |
J[] | {[string]: J}` at `is J` over `J | i32`, and for a union of declared structs
(`type AB = A | B`) at `is AB` over `AB | boolean`. The sibling spellings all lower — `is A`
and `is B` over `AB | boolean` run, `d as? U` over `U | boolean` runs, and `is C` for a
struct alias `C` over `C | boolean` runs — so what is missing is one arm rep, not the test.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the arm's alias is a struct, not a union (`is C` over `C \| boolean`) | runs | **yes — the arm must be a union alias** |
| `is` replaced by `as?` | runs | **yes — only the arm test needs the row** |
| the outer union (`d: U`, `d is U`) | still refuses, at the ladder's sibling `` `is` names a type that is not a union variant `` arm | no |
| a deep-`is` site elsewhere in the module | refuses identically | no — independent of D1744 |
| the alias's member kinds (`J`'s six, `AB`'s two structs) | refuses identically | no |

#### Grading list

* `tests/cases/unions/error-deep-is-site-beside-value-union-alias-arm.vl`, which pins this
  refusal at the `J | i32` spelling and graduates the day the arm rep exists.
* D1744's own witness (`is K` over `K | i32`, a literal-union alias), which runs and must
  keep running — the literal-union rep already interns its arm, so this row is about the
  value-union one.
* Both `emitFail` sentences in `wasmEmit.vl`'s `is` ladder, since the whole-union self-test
  reaches the other one: a fix that clears only the message this row names leaves `d is U`
  over `d: U` refusing.
