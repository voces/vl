### D2701 — a join of two maps that store alike is the wider map, so `is` against the narrower one is false for a value built as it

**closed · runs: `is` over a map against a narrower map tests every value (owner ruling, option (4), 2026-11-02) · the `isn` cells of the #3194 review's join grid for the same-storage pairs (`str_strnul`, `bool_boolnul`, `circ_circnul`, `arr_arrnul`) · filed 2026-09-26 against master `1a3088c65`**

Repro:

    function mk(): {[string]: string} {
      const m: {[string]: string} = Map()
      m["a"] = "x"
      return m
    }
    function mkw(): {[string]: string | null} {
      const m: {[string]: string | null} = Map()
      return m
    }
    const c = mk().length > 0
    const r = if c { mk() } else { mkw() }
    print(r is {[string]: string})

Want:

    true

#### Mechanism

D2666 made a join of two maps that store alike the wider map, so the join above types `r` as
`{[string]: string | null}`. A bare map carries no member tag, so `is {[string]: string}` was
answered from the static type, and answered false. Owner ruling, option (4): the checker, when
it types an `is` of a map against a map with the same key and a narrower value, mints the test's
content check onto the node (`IsExpr.isFit`, `mapFitBuild`): a loop over the map's values,
true when each is the narrower value, so an empty map passes. The elaboration re-checks it per
instance and the emitter lowers it in place of the test. The narrowing it gives follows the
list rule (D4926, D4928): the values read at the narrower type until a store through any alias
or a call that may write ends it, and the map is never delivered as the narrower map.
`n ?? w` over the same pair was invalid wasm before any `is` (D15050); since that close the
`coalesce` cells print `true` too.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the same storage (`{[string]: i32}` for the second map) | prints `true` | **yes** |
| the join (`const r: {[string]: string} \| {[string]: string \| null} = mk()`) | prints `true` | **yes** |
