### D16120 — an inferred union return with a packed list arm is floored: the return-atom walk has no packed rung

**closed 2026-11-14 — the witness runs and prints `2` · was: loud check reject · `` 'f' infers the union return type u8[] | string — type-valid, but an inferred return of this shape is not yet supported by codegen; annotate the return type `` · clause 2 · filed 2026-11-14 against master `84b0f334`**

Repro:

    function f(b: boolean) {
      if b { const x: u8[] = [1, 2]; return x }
      return "s"
    }
    const v = f(true)
    if v is u8[] { print(v[1]) } else { print(v) }

Want:

    2

#### Mechanism

`inferRetFloorUnsupported` (`check_inferred_return`) accepts an inferred union when
`valueUnionRetName` names it. That walks the leaves with `retAtomKindOf` (`check_ty_rep`), whose
list arm knows `i32`, `boolean`, `null`, `f64`, `string`, `i64` and `f32` elements but no packed
element. A `u8[]` leaf therefore answers -1, `valueUnionFromAtomKinds` declines, and the union
falls to the `TyUnion` floor. The other packed widths reach the same floor.

| `i16[]`, `u16[]` or `i8[]` in place of `u8[]` | the same refusal, naming the width | no |
| `i32` in place of `string` | the same refusal | no |

#### Grading list

- Each packed width beside `string`, beside `i32`, and two widths in one inferred union.
- The `return_inferred` cells of `packed-list-union-arm-{u8,i8,u16,i16}.matrix.vl`, refused in
  both faces today.

#### Close

`retAtomKindOf` answers 13 for a list of any packed width. The checker asks only whether a leaf
is one atom, so the four widths share `u8[]`'s kind there. The emitter keys each width's tag
by its row (D16046). The `return_inferred` cells of
`packed-list-union-arm-{u8,i8,u16,i16}.matrix.vl` grade it.
