#### Mechanism

An empty literal has no element, so the union box classifies it `i32[]` (`cak = 7`). The box
then re-maps a list with no `i32[]` arm onto the union's `i64[]`, `f64[]` or `f32[]` arm, and
had no `u8[]` rung, so the packed arm was tagged and built as an i32 list. The rung builds
the packed backing (`pendingListKind = 10`) and tags the box `u8[]`.
