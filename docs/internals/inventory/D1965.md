### D1965 — a closure that `.push`es / `.pop`s / `.clear`s a list CAPTURED from an enclosing function's local was refused at emit: the list-op receiver resolver knew locals and globals and had no capture arm

**closed 2026-09-22 — the witness prints `2` · was a loud emit reject (`emitProgram: .push receiver is not a list local`, `vl check` rc 0), clause 2 · reported by plumb (PL-004) · filed against master `a8a104432` · 490 of 896 grid cells loud → runs, 0 runs lost · fixture `tests/cases/closures/capture-list-mutation.vl`**

Repro:

    function main() {
      const out: u8[] = []
      const put = (s: string) => {
        const b = s.bytes()
        for i in 0 until b.length { out.push(b[i]) }
      }
      put("hi")
      print(out.length)
    }
    main()
    // was: vl check rc 0, vl build: emitProgram: .push receiver is not a list local
    // now: prints 2

#### Mechanism

`listOpRecvLocal` (`compiler/wasmEmit.vl`), the one receiver resolver `.push`, `.pop`, `.clear`
and `.get(i)` share, resolved a bare identifier to a frame local, else a module global (staged
through `emitExpr` into the op frame's `recvRef` slot), else refused. A captured name is neither:
inside the lifted closure it is an env field. The fix gives the resolver a capture arm that stages
the name exactly as a global is staged — `emitExpr` reads the env field, which holds the maker's
own list wrapper, so the op mutates the SAME list (lists are reference values,
`docs/guide/collections-design.md` §value-semantics). The scratch collector must reserve the
staging frame for the same receivers, so `listOpRecvStages` (`compiler/emit_classify.vl`) asks the
one new predicate `identIsEnvCapture`; without that half a captured `.pop()` compiled to
`unknown local` invalid wasm. A captured NULLABLE list narrowed inside the closure also recovers
`ref.as_non_null` at the stage (`capturedNulListCellRead`, the capture twin of
`globalNulListCellRead`), else the non-null `recvRef` slot refuses the nullable env field.

| ingredient removed | outcome | needed? |

| `.push` → `.pop()` / `.clear()` | still refused | no |

| `out` a PARAMETER of the maker instead of a local | still refused | no |
| `const` → `let` | still refused | no |
