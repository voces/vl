**closed 2026-11-16 · runs, prints `8` `a!` · was loud check reject, `vl check` rc 1, `operator '*' is not defined for string and i32 (the call's argument types)` · clause 2 · fixed in check_demands.vl: a module-scope operator bound recorded inside a lambda written as an argument of another call of the same callee is that call's, and is not judged at this one (`cstrSiteOfOtherCall`, read by `solveRule`); unary `-`/`~` bounds now record their node so the guard can place them · the argument spelling (`dbl(x)` in the lambda) is [D16873](D16873.md), closed beside it · pins: `tests/cases/generics/lambda-to-generic-at-one-call-judged-at-another-call.vl`, `tests/cases/generics/lambda-to-generic-own-call-still-judged.vl` · found grading the D16412 fix · filed 2026-11-16 against master `868f9c296`**

Repro:

    function sel<A>(f: (x: A) => A): (x: A) => A { return f }
    print(sel((x) => x * 2)(4))
    const g = sel((s: string) => s + "!")
    print(g("a"))
    // vl check: rc 1, operator '*' is not defined for string and i32 (the call's argument types)

Want:

    8
    a!

#### Mechanism

The first call's un-annotated lambda takes `sel`'s open parameter type `(x: A) => A`, so its body
records `A * i32` at module scope (owner -1). A module-scope bound is judged at every call, and the
second call substitutes its own `A` (`string`) into it. A row recorded inside a function is owned by
that function and never met this.
