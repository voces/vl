### D16855 — an un-annotated lambda handed to a generic at one call is checked at another call's closed lambda parameter type

**loud check reject · `vl check` rc 1, `operator '*' is not defined for string and i32 (the call's argument types)` · clause 2 · either call alone is accepted · found grading the D16412 fix · filed 2026-11-16 against master `868f9c296`**

Repro:

    function sel<A>(f: (x: A) => A): (x: A) => A { return f }
    print(sel((x) => x * 2)(4))
    const g = sel((s: string) => s + "!")
    print(g("a"))
    // vl check: rc 1, operator '*' is not defined for string and i32 (the call's argument types)

Want:

    8
    a!

#### Mechanism

Not located yet. The second call binds `sel`'s `A` at `string` through its annotated lambda, and
the first call's un-annotated lambda body is judged at it, although that lambda is not the second
call's argument. It has the same shape as D16814 and D16831, at a lambda literal handed straight
to the generic.
