#### Mechanism

`collectU` registers every union an annotation reaches. Each function's return and parameters, each
`let`, each declared field, and each inferred union hands its arena type to `collectTyReachRegister`.
That function recurses up to depth 16 through records, lists, maps, functions and union arms, and at
every union it meets it asks `registerInlineUnionAt`. The first thing that asks is `unRowOfTyKey`,
which renders the type's key text. Nothing remembered that a type had already been walked, so a
record mentioned by two hundred signatures was walked, and each of its unions keyed, two hundred
times. On diderven `src/game.vl`, `collectTyReachRegister` was 42.9% inclusive of a build, and
`unRowOfTyKey` beneath it was 27.0%. After the change, `collectU` no longer appears in the top
inclusive frames.

A repeat walk at a depth no greater than one that already completed meets only types the first walk
met, each with at least as much depth left, so every registration it would attempt was already made
or already declined. The memo has one column per `underFunc` because the name a union is keyed by
depends on that position. A walk that returns `-1` is not recorded. The memo is off while the union
A/B shadow is armed, because the shadow counts every call. It is dropped in `collectUReset`.
