#### Mechanism

D16440's no-build arm (`recListSpreadsApartRefuse`, check_bind_adopt.vl) answered only for a bare
record element (`tyAt(le) is TyObj`); with `{x: f64} | null` it neither built the `const` there
nor refused, so the list was stamped nowhere: an invalid module in every position. It now compares
a nullable element by its record and refuses the spread with the shared-record contract.

Building there, as D16440 does for a bare record, runs the list (scratch: `[...s, {x: 2.5}]`,
`const v: ({x: f64} | null)[] = [...s]`, `[a, ...s]` all print `1.25`) but not `s`'s own
nullable-element reads: `const e = s[0]` is `ref valtype with no interned shape` at emit,
`s[0] ?? { x: 0 }` an invalid module, and `(s[0] ?? { x: 0.0 }).x` a `cast failure` trap. The
rebuilt binding's `{x: f64} | null` element has no read row; until it does the build would be
clause 1.
