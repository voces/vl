#### Mechanism

The hole-parameter face of [D3613](D3613.md). At top level `r2` is `i64 | f64` and the checker
refuses `*` against an `f64` under the numeric-join ruling's pair rule. In the hole body `r2`
was the `??` hole, the template admitted the operator, and the instance-time check asked only
whether the operator is defined over numerics, so `emitNumUnionBin` was the first to see the
`i64`-`f64` pair. The pin now runs the top level's own pair rule (`numBinPairRefusal`) over
the substituted operands, with the operator's node so a literal adapts as it does there.
