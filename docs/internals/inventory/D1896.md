### D1896 — a list whose element is a NULLABLE STRUCT has no interned shape at a generic pin, so `indexOf` over it refuses in the emitter

**loud emit reject · `emitProgram: ref valtype with no interned shape` · `vl check` rc 0 ·
clause 2 · filed 2026-09-07 against master `8bdd886af` as the spelling [D1836](D1836.md)'s close
moved rather than fixed · 0 corpus cells**

Repro:

    import { indexOf } from "std:array"

    type S = { w: i32 }
    function mk(i: i32): S | null {
      if i == 0 { return null }
      { w: i }
    }

    function cells() {
      const rs = [mk(1), mk(2)]
      const rd = mk(2)
      print(rs.indexOf(rd))
    }

    cells()
    // vl check: rc 0.  vl run: emitProgram: ref valtype with no interned shape

#### Mechanism

Before [D1836](D1836.md) this program refused one step EARLIER, in the monomorphizer's
argument reader, with `expected an array argument for 'self'` — the ungrouped
`S|null[]` spelling no reader could see an array through. With the grouping rule in place the
reader sees `(S|null)[]`, the instance is minted, and the refusal moves to the emitter: the
element's own valtype has no interned shape.

So this is a spelling D1836 UNCOVERED rather than one it broke; both states are refusals and
the program has never run. What it now needs is the nullable-struct element's shape at the pin,
which is a different question from the name the mono reader reads.

Not measured: whether the same element outside a generic (`rs[0].w` with no `indexOf`) reaches
the same floor, and whether a nullable UNION element behaves like this or like the nested-list
one D1836 closed.
