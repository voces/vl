### D3022 — a block-scoped `type` used as an annotation is an unknown type once the program imports `std` (string interpolation is enough)

**closed · was loud check reject, clause 2, the same on master `cac5e4ad5` · the merge's character-scanner rename (`modTypeRenamed`) now treats `$` as part of a name, so a minted `U$b1` declaration renames as one segment, as its references already did through the spelling tree · fixtures `tests/cases/types/body-scope-type-decl-with-std.vl`, `tests/cases/modules/body-scope-type-in-imported-module/` · found writing the [D3021](D3021.md) fixture · filed 2026-09-28**

Repro:

    function local() {
      type U = { ty: i32 }
      const u: U = { ty: 3 }
      print(u.ty)
    }
    local()
    print("n \{2}")
    // vl check: unknown type 'U'.  Without the interpolation it prints 3, then nothing else

Want:

    3
    n 2

#### Mechanism

A body-scoped `type` is minted under a unique name (`U` → `U$b1`, D1045) and hoisted into
`progStmts`. Importing std (an interpolation is enough) runs the module merge, which renames every
top-level name of a module to `name$mN`, the hoisted declaration included. A reference is renamed
through its spelling tree, where `U$b1` is one `TS_NAME` and becomes `U$b1$m0`. The declaration's
own name is renamed by `modTypeRenamed`, a character scanner whose segments were `nameIdentChar`
runs, so `U$b1` split at the `$` into `U` and `b1`, neither in the rename map, and the declaration
stayed `U$b1`. Every annotation then named a type that no longer existed. Any block-scoped type
kind, any nesting depth, in a function or a top-level block, and in the entry or an imported
module failed the same way; a generic declaration's base (`modRwDeclBase`) went through the same
scanner. The scanner now continues a segment across `$`, so both renames agree.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the interpolation (the `std` import) | prints 3 | **yes** |
| the annotation `: U` | prints 3 and `n 2` | **yes** |
| the order (interpolation first) | still refused | no |
| the function (a bare top-level block instead) | still refused | no |
| the record (`type U = i32`) | still refused | no |
| the interpolation, for `import { padStart } from "std:str"` | still refused | no |
