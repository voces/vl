#### Mechanism

`const wideJ: J = mk()` builds `mk`'s record at `J`. Every other call of `mk` has to be served
from that build. Today, a call queued for no delivery is served only when `recReadInPlace` says
it is read for a field. That is the `|| !recReadInPlace(c)` term in `recSitesLandAt`
(check_fit_rules.vl). Deleting that term (the rip) is what closes D14509 and D14512. With the term
gone, each slot that holds a `mk()` result has to take the row the callee builds (`J`), not the
declared row of the same shape looked up by name (`II`). The witness is residue kind 1: the slot
is an un-annotated parameter, a hole pinned per instance, so its rep waits on the per-instance
mint (slice c, behind holes-close).
