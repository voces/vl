### D16919 — a record binding re-pointed at another record binding of a different function set builds an invalid module

**check-clean invalid wasm · clause 1 · found by lane AE on the [D16916](D16916.md) position matrix · filed 2026-11-17 against master `4e9738079`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    let r = { f: [inc0] }
    const q = { f: [dbl] }
    r = q
    print(r.f[0](3))
    // vl check: rc 0.  vl run: invalid module, a `(ref $q's row)` stored where `(ref null $r's row)` is wanted

Want:

    6

#### Mechanism

Not yet located. `q`'s record is built at its own row, of its own set `{dbl}`; the binding `r`
holds the joined set `{inc0, dbl}` at another row, and the write `r = q` stores `q`'s struct
into `r`'s cell without a conversion.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `r = { f: [dbl] }` (a literal, not a binding) | runs, `6` | **yes** (a binding written) |
| `const q = { f: [inc0] }` (the same function) | runs, `4` | **yes** (another set) |
| `let r = [inc0]`, `const q = [dbl]` (no record) | runs, `6` | **yes** (a record) |
| `print(r.f.length)` (no call) | runs, `1` | **yes** (a call through `r`) |
| `print(q.f[0](3))` (the call through `q`) | runs, `6` | **yes** (a call through `r`) |
| `let q` | invalid module | no |
| a scalar field beside `f` | invalid module | no |

#### Grading list

- `let r = { f: [inc0, dbl] }`, `const q = { f: [dbl] }`, `r = q`, `print(r.f[0](3))`: the same
  invalid module; want `6`.
- `const q = { f: [dbl] }` declared before `let r = { f: [inc0, dbl] }`, then `r = q`: the same.
