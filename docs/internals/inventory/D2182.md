### D2182 — a function of 1,000 nested bare blocks exhausts the compiler's call stack

**closed 2026-09-23 — the host runs every compiler-seed engine on a 512 MiB wasm stack backed by a thread of its own, so nesting is bounded by memory: 10,000 levels of bare blocks, labelled loops, `if`s and a mix each check and run in about half a second, and 100,000 run · was a compiler trap (`vl check` rc 0, then the call stack exhausted) at ~950 levels for `vl run`, ~750 for an `if` nest · filed 2026-09-23 against master `a453c09c5` · residues D2189 (the editor's V8 stack), D2190 (four passes quadratic in the depth, fixed with this)**

Repro:

      acc

#### Mechanism

The compiler walks a nested statement recursively in every pass (a `--names` seed at 10,000
mixed levels shows about fifty functions recursing once per level: `capScan`, `checkNode`,
`checkBlockNode`, `emitStmts`, `collectLocals`, `hoistScanBlock`, `parseBlock`, the rewrite and
collect walkers), at roughly half a KiB of wasm stack per level on the deepest path. wasmtime's
default `max_wasm_stack` is 512 KiB, which is the whole ceiling. Converting fifty walkers to
explicit stacks is not what closed it: `seed_engine_sized` raises the cap to `SEED_WASM_STACK`
(512 MiB) and `main` runs the host on a thread whose native stack holds it, committed only as
deep as a compile goes. 10,000 levels need under 8 MiB. User programs keep the default stack.

Ceilings per shape, `vl` on the shared host and seed of `66e74235a`, against this change:

| shape | `vl run` before | `vl check` before | `vl fmt` before | after, `run` and `check` at 10,000 |
| --- | ---: | ---: | ---: | --- |
| nested bare blocks | 950 | 2,950 | 1,550 | 0.5 s |
| nested labelled `while` loops | 950 | 1,475 | 1,112 | 0.3 s |
| nested `if`s | 750 | 737 | 1,300 | 0.5 s |
| the three mixed | 950 | 1,375 | 1,300 | 0.4 s |

Past the target: at 50,000 levels every shape but bare blocks still runs; a bare block's `const`
takes a wasm local each, and 50,000 exceed the engine's per-function local limit. `vl fmt` at
10,000 levels runs out of GC heap rendering its output, which is quadratic in the depth (each
level indents once more); it formats 5,000.
