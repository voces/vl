### D13740 — an `if` of two un-annotated functions whose results differ, handed to a callee that calls it, traps on the indirect call

**trap after load · `wasm trap: indirect call type mismatch` in `only` · `vl check` rc 0 · clause 1 · with both arms annotated, `twice(s: string)` and `lenOf(s: string)`, the checker refuses the call (`called value is not a function`), and with `only`'s `f` annotated `(s: string) => string | i32` it runs and prints `3` · open · found closing [D13620](D13620.md) · pre-existing: a seed without that change traps too · filed 2026-10-25 against master `36bb58995`**

Repro:

    function only(n, f) {
      return f(n)
    }
    function twice(s) { return s + s }
    function lenOf(s) { return s.length }
    let k = false
    print(only("abc", if k { twice } else { lenOf }))
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch

Either `3` or the refusal the fully annotated spelling gets would be right; a trap is not.

#### Mechanism

Not ablated to a line. The two arms instance at `string` to different results (`string` and
`i32`), so the choice holds two function types. With the arms annotated, the checker sees the
union and refuses the call. With them un-annotated, the call checks, and the choice's value
reaches an indirect call typed for one arm only.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the arms' differing results (`lenOf` replaced by `inner(s) { return s }`) | runs | **yes** |
| the un-annotated arms (both annotated `s: string`) | check reject | **yes** |
| the un-annotated callee (`f: (s: string) => string \| i32`) | runs, `3` | **yes** |
