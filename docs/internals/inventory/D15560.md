### D15560 — a returned binding of a call's record, beside a record of another function set, compiles to invalid wasm

**open · check-clean invalid wasm · clause 1 · the same pair with a record literal for the binding runs since [D15559](D15559.md) · found closing D15559 · filed 2026-11-08 against master `2a59f035`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function mk() { return { fs: [dbl] } }
    function pick(b) {
      const c = mk()
      const a = { fs: [inc0] }
      if b { return a }
      return c
    }
    print(pick(false).fs[0](3))
    print(pick(true).fs[0](3))

Want:

    6
    4

#### Mechanism

`c` holds `mk`'s result, whose row is `mk`'s own: its set is `{dbl}`, and `mk` has other callers, so it cannot take `pick`'s joined set. The return of `c` needs a record copy at `pick`'s result row, or a ruling that the two rows, which differ only by a set whose ids are decided together, are one row.
