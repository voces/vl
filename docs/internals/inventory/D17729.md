### D17729 — an un-annotated list a generic body pushes a generic function onto is refused when the body has two instances

**loud emit reject · `ref valtype with no interned shape` · clause 2 · open · `vl check` rc 0 · one instance runs · found grading [D16699](D16699.md)'s close · filed 2026-11-27 against master `b71fd7b8f` by I8-PREP**

Repro:

    function id<T>(x: T): T { return x }
    function run<T>(_x: T) {
      const rs = []
      rs.push(id)
      return rs
    }
    print(run(3)[0](3))
    print(run("ab")[0]("ab"))
    // vl check: rc 0.  vl run: emitProgram: ref valtype with no interned shape

Want:

    3
    ab

#### Mechanism

Not traced past this: with two instances the function map holds one `run` whose binding `rs`
stays at the open `((T) => T)[]`, so its list has no row; one instance closes it at
`((i32) => i32)[]` and runs with D16699's close.
