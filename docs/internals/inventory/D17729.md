#### Mechanism

Mono splits `run` into `run` and `run$1` (a closed `sq` pushed instead runs at both), but in each
instance the elaboration's type for `rs` (`nodeTyAt(rs, instance)`) stays the open
`((T) => T)[]`: the element's type is `id`'s own `T`, which only a caller's use of the result
closes, `run(3)[0](3)` at `(i32)`. With one instance the template itself is closed there and
D16699's close builds it; with two, no delivery carries each caller's call through the
returned list's element back to its own instance's `rs`, so neither closes and the instance's
result has no ref-list row.
