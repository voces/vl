### D2253 — a nullable-valued map's `??` default emits an invalid module through the fused get

**check-clean invalid wasm · `vl check` rc 0, then the emitted module fails validation
inside the module's top-level code, clause 1 · found while extending the D2247 value-type
grid to a map whose OWN value type is already nullable · filed 2026-09-23 against master
`3330dcaa3`**

Repro:

    const m: {[string]: i32 | null} = Map()
    m["a"] = null
    const d: i32 | null = 99
    const r1 = m["a"] ?? d
    print(r1 ?? -1)
    // vl check: rc 0.  vl run: invalid module,
    // "type mismatch: expected i32, found (ref $type)"
    // f64 | null in place of i32 | null (map, store and default) fails identically.

#### Mechanism

`emit_rewrite.vl`'s D2247/D2248 desugar (`m[k] ?? d` → `if m[k] != null { m[k] } else { d }`)
only fires when the map's OWN value type EXCLUDES null
(`nodeTyMapValExcludesNull(mdRead.idxArr)`); here it already admits null, so the guard
declines and the read falls to the FUSED single-evaluation lowering, `emitMapGetOr` →
`emitMapGetOrUnionBox`'s `scalar | null` arm (`wasmEmit.vl:7877-7902`). That arm opens an
`i32`-blocktyped `if` (`valBlockTypeOfKind(ak)`) on the map's own null tag and asks
`emitExprAsKind(body, defIx, ak, fnIx)` to deliver the default AS the raw scalar — which
is correct when `defIx` is a plain non-nullable expression, but `d`'s own declared type is
`i32 | null`, so `d`'s value arrives in whatever ref/box representation that type uses and
needs its own null check and payload read before it is a raw scalar. `emitExprAsKind` does
not perform that second unwrap here, so the `if` arm leaves a ref where its blocktype
demands a raw `i32`. Not yet confirmed by disassembly which representation `d` actually
carries; a prediction, to be graded by the close.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the default `d`'s nullability (`i32` instead of `i32 \| null`) | runs | **yes** |
| the map's value type nullability (`i32` instead of `i32 \| null`, `d` still nullable) | runs | **yes** |
| storing `null` vs. a real value into `m["a"]` (only the declared types matter) | still invalid wasm | no |

#### Grading list

D2254 reaches the same `emitMapGetOrUnionBox` scalar arm from the other side (a
re-readable-key guard rather than this row's value-excludes-null guard) with the same
message — one fix to `emitExprAsKind`'s scalar coercion (or to `emitMapValDefault`'s

covers only maps whose value type EXCLUDES null; this row's witness is a candidate for a
block where the map's own value type does not.
