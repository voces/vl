### D17783 — a `const` lambda called with an `if` join of two functions whose results differ traps at run time

**trap after load · clause 1 · `wasm trap: indirect call type mismatch` in the lambda · `vl check` rc 0 · found grading D15777 · filed 2026-11-28 against master `0d0ff1e2` by COV-CALL**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function two() { return [1, 2].length }
    const take = (r) => r(3)
    const q = if two() > 5 { half } else { inc0 }
    print(take(q))
    // vl check: rc 0.  vl run: wasm trap, indirect call type mismatch

Want:

    4

#### Mechanism

Not traced. The joined value is called through the lambda's parameter at one closure signature,
while `inc0` and `half` return `i32` and `f64`; a declared `take` dispatches on the set.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the lambda (`function take(r)`, at module scope or nested) | runs | **yes** |
| differing results (`dbl` for `half`) | runs | **yes** |
| the join (`take(inc0)`) | runs | **yes** |
| the call through `take` (`q(3)`) | runs | **yes** |
| module scope (inside `main()`) | still traps | no |
