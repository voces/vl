#### Mechanism

The first object literal the initialiser emits, the call argument `{ p: 9 }`, is built as `Cat`'s variant struct and its field `c` is missing; D2302 turned the invalid module that produced into this refusal. The probe names the binding's arm annotation as the source, but the un-annotated `const x = take({ p: 9 })` refuses the same way.
