### D15863 — a module-scope bundle holder read into an annotated binding inside a function is refused at emit

**loud emit reject · clause 2 · `a function-value call has no interned signature — parameter 1 of type `` has no representation in the function-value ABI` · found closing [D15749](D15749.md) · filed 2026-11-12 against master `84e28554d`**

Repro:

    function lap(f) {
      f(2.5)
      f(3)
      return f
    }
    const c = lap((a) => a + 1)
    function main() {
      const m: (f64) => f64 = c
      print(m(4))
      print(c(3))
    }
    main()

Want:

    5
    4

#### Mechanism

Unmeasured. `elabTypedReadsHold` admits an annotated read in the holder's function or a lambda
nested in it; a module holder's read inside a named function is neither.

| spelling | outcome | needed? |
| --- | --- | --- |
| the binding at the top level, `c` called only through it | runs (D15749) | **yes** |
| the holder local to `main` | runs (D15749) | **yes** |
