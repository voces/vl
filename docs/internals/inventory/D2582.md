#### Mechanism

The map's value type is filled from the stored join, and its members are the anonymous shapes
`{r:i32}` and `{q:string}`, not `A` and `B`. A bound read now takes the union row its arena
type resolves to (D5113), so its `is A` complement finds `A` to subtract. The place read
`m["k"]` does not pass through that slot naming, so its complement still subtracts nothing.
The same at module scope. A prediction for where: the path-key narrowing of a map place, which
keys on the slot's structural spelling.
