### D2582 — an un-annotated `Map()` filled with a record join types its value structurally, so an `is` complement of the read cannot narrow

**loud emit reject · `vl check` rc 0, then `emitProgram: field access receiver is not a struct`, clause 2 · found by the `coalesce-record-join-elimination` position matrix while closing [D2565](D2565.md) (`map_value` and `map_value_place`, un-annotated face) · the same on master `216770428` · filed 2026-09-26 against master `216770428`**

Repro:

    type A = { r: i32 }
    type B = { q: string }
    function mkA(n: i32): A | null { if n == 0 { return null } return { r: n } }
    function mkB(s: string): B | null { if s == "" { return null } return { q: s } }
    function go() {
      const m = Map()
      m["k"] = mkA(0) ?? mkB("b")
      const x = m["k"]
      if x == null { print("null") } else if x is A { print(x.r) } else { print(x.q) }
    }
    go()
    // vl check: rc 0.  vl run: emit error, "field access receiver is not a struct"

#### Mechanism

The map's value type is filled from the stored join, and its members are the anonymous shapes
`{r:i32}` and `{q:string}`, not `A` and `B`: the value slot, the read's union name and the
cell's null narrowing all spell `{r:i32}|{q:string}|null`, which no union row holds. The
`is A` complement then finds no `A` to subtract, the failure [D2565](D2565.md) closed for a list
element, whose type kept its nominal members. A prediction for where: the hole-fill that types
an un-annotated `Map()` from its first write.
