### D15127 — a function result or a record literal's field holding a built container's read is emitted at a narrow row interned elsewhere

**open · check-clean invalid wasm · clause 1 · the residue of [D15126](D15126.md) · filed 2026-11-03 against master `7ea18bb0e`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const xs = [mk()]
    const plain = { f: 5 }
    function first() { return xs[0] }
    const v = first()
    print(v.f)
    print(wideJ.f ?? 0)
    // vl check: rc 0.  vl run: invalid module

Want:

    4
    4

#### Mechanism

`v`'s held row comes from `letCallHeldTy` (emit_classify.vl), which reads the checker's
store-rep column (`storeLetBuiltOf`). That column records a call only for the bindings whose
field writes it queued, so a function returning a read of `xs` reports nothing and `v` takes the
narrow row `plain` interns. A record literal's field, `const w = { f: xs[0] }; const v = w.f`,
falls the same way through the literal's own row.
