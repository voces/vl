### D9765 — an inline nested list of an un-annotated function handed to an un-annotated parameter builds invalid wasm

**closed · runs, prints `4` `3.5` · was check-clean invalid wasm, `vl check` rc 0, `type mismatch: expected (ref null $type), found (ref $type)`, clause 1 · found closing [D9711](D9711.md) · filed 2026-10-22 against master `e8163edd5`, present there · closed by pinning a nested list argument's inner element from the parameter's slot two levels down (`monoOpenFnNestedListPin`, emit_mono.vl), and by giving an inert nested list the stub `(() => void)[][]` row by row (`monoInertParamStubPin`) · fixture `closures/hole-fn-nested-list-handed-open.vl`, matrix `hole-fn-nested-list-read-open` (its 2 SILENT cells now run) · with [D9710](D9710.md) closed**

Repro:

    function inc(a) { return a + 1 }
    function take(v) {
      print(v[0][0](3))
      print(v[1][0](2.5))
    }
    take([[inc], [inc]])
    // vl check rc 0.  vl run: invalid module: type mismatch: expected (ref null $type), found (ref $type)

Want:

    4
    3.5

#### Mechanism

The hole parameter's pin cascade had an arm for a flat list of functions (`monoOpenFnListPin`) and
none for a list of them. A nested list fell through to `monoArgPinName`, which named the parameter
`i32[][]` from the checker's open element, while the argument was built as lists of closures, so
the parameter and the argument disagreed in the module. The flat arm now hands a nested list to
`monoOpenFnNestedListPin`, which pins the inner element at `["e","e"]` and records the inner lists
at that type; when every read names its generic, the inert stub is built row by row instead.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the nesting (`take([inc, inc])`, `v[0](3)`, `v[1](2.5)`) | runs, `4` `3.5` | **yes** |
| the second call type (`take([[inc]])`, `v[0][0](3)` only) | invalid wasm | no |

#### Grading list

The same argument inside a function body, two different functions in one row, an `f64` function,
the parameter aliased (`const w = v`), and an early-return guard before the reads.
