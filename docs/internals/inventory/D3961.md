### D3961 — a `let` seeded with a generic function and written with another generic traps when called

**closed 2026-10-11 by lane SC (D3979) · runs · pins: `tests/cases/functions/let-of-generic-written-generic-called-runs.vl`, `tests/cases/functions/let-of-generic-written-lambda-called-runs.vl` · was loads then traps · found by the D3960 matrix (`gen_generic_*`, 24 cells) · filed 2026-10-10 against master `eb81bdd89`**

Repro:

    function inner<U>(u: U) { print("I"); print(u) }
    function other<V>(v: V) { print("O"); print(v) }
    function main() {
      let k = inner
      k = other
      k(1)
    }
    main()
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch

Want:

    O
    1

#### Mechanism

Not located. The call `k(1)` instances the seed `inner` at `(i32) => void`, but the write
`k = other` of a declared generic that no closure captures is not instanced at that signature,
so the call reaches `other`'s default instance. D3951 is its capture-cell twin with a hole-lambda seed;
this row needs no closure and no hole lambda.
