### D6881 — an uncalled hole function handed to a parameter nothing calls is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the `<F>` twin of `apply3` runs, `2` · found closing [D6830](D6830.md) · the same on master `cbd8ffec5` · filed 2026-10-18 against master `cbd8ffec5`**

Repro:

    function apply3(g) { print(g(1, 2)) }
    function run(f) { print(2) }
    run(apply3)
    // vl check: rc 0.  vl run: emitProgram: monomorphize: unsupported argument type for `f` in a call to `run`

Want:

    2

#### Mechanism

From the ablation only. `run`'s hole parameter is instanced at the argument's type, and a hole
function nothing calls has no instanced type to hand it; the stub that serves an uncalled value
since D6830 is not offered at a call argument.
