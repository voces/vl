#### Mechanism

`validateBmCstrs` re-checks the body's deferred `push` constraint at each call's argument
types, and the `assignableExpr` it asks stamps the template literal's build type
(`nodeRepTyIx`) with that call's type. The last call wins, and every instance's clone of
`[x]` falls back to the template's stamp in `litRepTyAt`.
