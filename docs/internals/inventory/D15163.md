### D15163 — a local alias of a map written two functions of different result types, captured by a closure, is refused at emit

**loud emit reject · `emitProgram: index receiver is not an array or string` · clause 2 · open, target `1.5` · found closing [D15137](D15137.md): the same alias at top level, and the list spelling, run · filed 2026-11-03 against master `b813a46b`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const m = Map()
    m.set("a", inc0)
    m.set("b", half)
    function w() {
      const c = m
      const f = () => {
        const g = c.get("b")
        if g != null { print(g(3)) }
      }
      f()
    }
    w()
    // Want: 1.5

#### Mechanism

The closure's `c.get("b")` reaches `emitIndex` (wasmEmit.vl), the list and string ladder, so the captured local alias is not classified as the map it copies. A top-level alias, an alias read in the function without a closure, and `c[0]` over a widened list all run (measured 2026-11-03).
