#### Mechanism

Eleven join sites did `const tc = joinVariantTys(a, b); tpJoinUnions[tc] = 1`, and `markTpJoinApart` and
`tpJoinCarry` set a mark on a row already in use. `joinVariantTys` can return `a` or `b` itself, so
a union the program wrote took the join's re-join rule for every holder of that row. The mark is now
the row's own field, set only by the mint (`mkJoinUnionTy`, `mkJoinNullableTy`), and a writer that
marks a row it did not mint gets a marked copy (`tyJoinMarked`). Whether a program relied on the
leak is the question this pin keeps open: none of the graded populations did.
