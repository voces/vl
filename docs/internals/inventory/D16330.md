### D16330 — after a re-check, the redundant-annotation hint fires on a named function delivered at a wider function type and names the annotation as the inferred type

**runs today and must keep running · message quality · the hint is wrong where it fires, not the program · found closing [D16310](D16310.md), whose re-check reaches `closures/fn-value-adapter-at-wider-type.vl` · filed 2026-11-14 against master `495c1ff80`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }

      if s is Circle { return s.r }
      0
    }
    const f1: () => Shape = mkC

    function tk0(w: { x: i64 }) { print(w.x) }

    7

#### Mechanism

Not traced. The last three lines only make the program re-checked (a record adoption pin). With
them removed, no hint fires. Un-annotated, `f1` is `() => Circle`, so the hint's "inferred as" is
false, and the first pass, which judges the annotation load-bearing, disagrees with the re-check.
