### D3744 — `??` directly over an index read of an un-annotated parameter pinned to `(i32 | null)[]` is refused at emit

**closed · was loud emit reject · clause 2 · pre-existing, the same on master `42c4d4c10` · found by lane UA grading D2218's element kinds · fixture `tests/cases/generics/hole-param-coalesce-nullable-scalar-element.vl` · filed 2026-10-06 against master `42c4d4c10` · closed by lane S5**

Repro:

    function take(a) {
      print(a[1] ?? 0)
    }
    const l: (i32 | null)[] = [null, 4]
    take(l)
    // vl check: rc 0.  vl run: emitProgram: `??` over this nullable value is not supported
    // yet — narrow it first, e.g. `if v != null { … }`

Want:

    4

#### Mechanism

The D1828 arm of `emitCoalesceGo` (wasmEmit.vl) unboxes a nullable scalar element read, and took
its result kind from `nodeTyIxOf` of the `??` node. An un-annotated function's body records that
node at its hole, so the kind was -1 and every arm declined. The operand itself is recorded at the
instance's type (`i32 | null`), so only the result was missing. The same arm now reads the `??` at
`nodeTyPinIxOf`, as the box-result arms above it already do. `coalRetypedDead` compared against
the hole the same way, so the non-null face (`a: i32[]`, `a[1] ?? 0`) refused too; it now
compares against the pin and folds. A hole two instances pin to different types stays a loud
refusal, filed as [D3796](D3796.md).

Graded after: `i32`, `f64`, `i64` and `f32` elements, the null hit and the present read, a
return, two instances pinning the same type, and the non-null `i32[]`, `i64[]` and `f64[]` faces
all run with the right values. The `f32[]` non-null face is [D3797](D3797.md). The first notes,
kept for the record: The `??`'s left operand is an index read whose receiver is a hole
parameter, and the emitter's nullable-scalar `??` lowering does not recognise the `i32` niche
through the instance's pin, while it does once the read is bound to a local first. The
`string | null` element (a ref niche) runs at the same spelling, so the scalar niche is the
ingredient.
