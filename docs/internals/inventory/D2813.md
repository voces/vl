### D2813 — a relayed two-list return of one storage answers `is boolean[]` for the `i32` arm

**check-clean silently wrong · clause 1 · found by the #3211 review · the same on master `2bbc5c412` · filed 2026-09-27 against master `2bbc5c412`**

Repro:

    function g(u: boolean, c: boolean) {
      if c { return [u] }
      [1, 2]
    }
    function h(c: boolean) { return g(true, c) }
    const q = h(false)
    if q is boolean[] { print(q[0]) } else { print(-1) }
    // PRINTS true

#### Mechanism

`boolean[] | i32[]` is stored as the one i32 list with no tag, so `is boolean[]` answers from
the static type and the `[1, 2]` arm prints as `true` where `-1` is right. The direct call
(`const q = g(true, false)`) answers the same way, which is [D2769](D2769.md); the relay adds
nothing but a second delivery position, and closes with it. The generic twin is
[D2800](D2800.md).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the relay (`g(true, false)` directly) | prints `true` (D2769) | no |
| the shared storage (`u: string`) | prints `-1` | **yes** |
