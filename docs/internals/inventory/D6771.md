### D6771 — a lambda capturing a copy of a scalar narrowed out of a union box stores the box in the env field and reads it as the scalar

**closed 2026-10-18 by lane L6 · runs, prints `4` · was check-clean invalid wasm · `vl check` rc 0 · clause 1 · an un-annotated binding initialised from a number or boolean narrowed out of a box takes the scalar cell, asked of the checker's type, so the capture's env field and the frame agree; the `print(g())` spellings in a module block and in a function frame, an `f64 \| boolean` narrowed by `is f64`, and a generic `T \| null` narrowed by `!= null` run too · pins: `tests/cases/closures/capture-narrowed-copy-in-module-block.vl` · found closing [D6730](D6730.md) · filed 2026-10-18 against master `1e7bc12cb`**

Repro:

    function q(): i32 | null { return 3 }
    if true {
      const mw = q()
      if mw != null {
        const v = mw
        const g = () => v
        const r: i32 = g()
        print(r + 1)
      }
    }
    // vl check: rc 0.  vl run: invalid module, expected (ref $0), found i32; $0 is `union box`

Want:

#### Mechanism

The narrowed read of `mw` unboxes to `i32`, so `v` holds a scalar, but the cell kind of the
un-annotated `v` was decided from its initializer's declared box and the env field was typed
as the box. Where the result is printed the program is refused instead, because the print
asks the box's tag dispatch of a value with no arms.
