### D6704 — a `const` copy of a written `let` holding generics, called, traps on an indirect call of the wrong type

**closed 2026-10-18 by lane L1 · runs, prints `W`, `6` then `false` · was loads then traps · `vl check` rc 0 · clause 1 · the checker's mark on a written `let` holding generics now carries to a `const` seeded from it, so the copy holds the adapted writes as the `let` copy does ([D5160](D5160.md)) · pins: `tests/cases/closures/const-copy-of-written-let-holding-generics.vl` · found closing [D6472](D6472.md) · filed 2026-10-18 against master `ca2adfdc7`**

Repro:

    function s<A, B>(_a: A, _b: B) { print("S") }
    function w<B>(a: i32 | string, b: B) {
      print("W")
      print(a)
      print(b)
    }
    function main() {
      let k = s
      k = w
      const k2 = k
      k2(6, false)
    }
    main()
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch, in `main`

Want:

    W
    6
    false

#### Mechanism

Not located. A `let` copy reads the adapted write [D5160](D5160.md) built; the `const` copy of
the same written binding is called through a slot of another signature, which the engine
refuses at the call.
