### D16600 — a narrowing cast over a value join of in-range literals is fallible, since the bound proof has no join arm

**closed 2026-11-15 · runs, prints `255` · was a loud check reject, clause 2, ```as u8` propagates null out of the enclosing function, and there is none here`` · bucket (f), ruling 4.3 (one rule for every join form) · closed by bounding a value join by its widest tail in `castBoundBits` (check_cast_bound.vl), so a cast whose every tail fits is the infallible cast a bounded bare operand is · fixture `tests/cases/numerics/cast-join-bounded-tails.vl` · found by lane T against the oracle while closing D16473 · filed 2026-11-15 against master `d31ab4440`**

Repro:

    let c = true
    c = !c
    print((if c { 1 } else { 0xFF }) as u8)
    // vl check: `as u8` propagates null out of the enclosing function, and there is none here

Want:

#### Mechanism

A bare `as` to a narrower domain propagates `null` on a miss, so at module scope, or in a
function that returns no `null`, it is refused unless the checker proves it cannot miss. A
constant operand is decided at its value (`castConstDecide`), and a shaped one (`&`, `>>>`,
`%`) by `castBoundBits`. A value join is neither, so it fell to the fallible reading even when
every tail is a literal the domain holds.

and `as i32` over a join with a bounded `i64` tail.
