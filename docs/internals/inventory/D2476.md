### D2476 — the emitter re-derives which rung a member call took, and calls a `self`-function where the checker typed the built-in method or the field

**closed 2026-09-25 — the witness prints `1` then `he` · was check-clean silently wrong, clause 1 · filed 2026-09-25 against master `0a0d24ac9` while grading [D2475](D2475.md) · fixtures `tests/cases/methods/builtin-method-wins-over-reachable-self-fn.vl`, `tests/cases/methods/self-fn-not-shadowed-controls.vl`**

Repro:

    function push(self: i32[] | string, x: i32) { print(99 + x - x) }
    function slice<T>(self: T, a: i32, b: i32): string { "user" }
    const xs: i32[] = []
    xs.push(1)
    print(xs.length)
    print("hello".slice(0, 2))
    // vl check: rc 0.  vl run, filed: prints 99, 0, user; now 1, he

#### Mechanism

The checker resolves `recv.name(args)` built-in method first, then field, then `self`-function;
the emitter's dispatch rewrite (`drwWalk`, `emit_rewrite.vl`) asked only "is there a field"
and "is there a `self`-function of this name and arity", so on a list, map/set or string
receiver it rewrote a call the checker had typed as the built-in into a call of the function.
[D2475](D2475.md) refuses the declarations EVERY receiver shadows; these two are legal
because some receiver reaches them (a `string` for the union `self`, anything for the type
parameter), so the disagreement stayed. A third face: `function x(self: P | null): string`
with `pn.x()` on a `P | null` receiver — the checker took the function (the nullable type
has no field), the emitter found `P`'s struct row, saw its field `x`, and emitted the field
call: check-clean invalid wasm.

The close: the checker banks, per member-call node, the rung it resolved through
(`memberCallRungAdd`, `MC_RUNG_BUILTIN` / `MC_RUNG_SELF_FN`), and the rewrite reads it: a
built-in site is never rewritten to a function, a `self`-function site is rewritten even when
the struct row has the field, and D1522's `m.get(k)` → `m[k]` fold is skipped where the
checker took a `self`-function (a `Set` receiver, [D2477](D2477.md)). An unbanked site keeps
the old derivation.

#### Ablation

| --- | --- | --- |

| the receiver's built-in (`(3).slice(0, 2)`) | prints `user`, correctly | **yes** |
