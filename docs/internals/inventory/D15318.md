### D15318 — a `??` over a read of a container built wider, defaulted to an un-annotated parameter, joins two storages

**open · check-clean invalid wasm · `type mismatch: expected (ref null $1), found (ref $5)` · clause 1 · the annotated parameter is refused at check (D15241) · found closing D15241 · filed 2026-11-04 against master `019d4cdd8`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const m = Map()
    m.set("a", mk())
    const wm: {[string]: J} = Map()
    wm.set("a", mk())
    function pick(d) { (m.get("a") ?? d).f }
    print(pick({ f: 1 }))

Want:

    4

#### Mechanism

D15241's: the read is stored at J, the parameter at the record its call pins, and the join holds
both. D15241's check refusal reads the default's own type, which for an un-annotated parameter is
its hole until a call pins it, so it does not see this spelling. A refusal (or D15241's converting
copy) has to read the pinned type of the instance.
