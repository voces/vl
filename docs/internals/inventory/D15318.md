**closed 2026-11-04 by lane destringify · now a loud check reject, `a ?? whose default is a parameter or an annotated binding, stored apart from the J a read of a container built wider holds, is not yet supported` · folded into D15241's capability row: the refusal (`storeCoalescesResolve`) also takes a hole-typed parameter default, whose storage cannot be compared before a pin, and D15241's converting copy retires both · built invalid until then at every pin, the parameter pinned at J included · fixture `soundness/error-built-read-default-hole-param.vl` · named set `d15318-hole-param-default` · found closing D15241 · filed 2026-11-04 against master `019d4cdd8`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const m = Map()
    m.set("a", mk())

    4

#### Mechanism

D15241's: the read is stored at J, the parameter at the record its call pins, and the join holds
both. D15241's check refusal reads the default's own type, which for an un-annotated parameter is
its hole until a call pins it, so it does not see this spelling. A refusal (or D15241's converting
copy) has to read the pinned type of the instance.
