### D1681 — an UN-ANNOTATED binding of a `?.` whose leaf is a REF list gets no interned shape, while the annotated spelling runs

**loud emit reject · filed 2026-09-06 against master `294417dc2` · found while D1676 built
the ref-list arm, which serves the annotated face and not this one · clause 2: `vl check`
returns 0 and the refusal names an interning failure, not anything the design forbids**

Repro:

    type S = { w: i32 }
    type B = { y: S[] }
    function mk(): B | null { { y: [{ w: 4 }] } }
    const b = mk()
    const v = b?.y
    if v != null { print(v[0].w) } else { print(0) }
    // vl check: rc 0.  vl run: emit error,
    // emitProgram: ref valtype with no interned shape

#### Mechanism

`b?.y` over an `S[]` field yields `S[] | null`, and the standalone `?.` arm builds it as the
ref list's own wrapper (D1676). The ANNOTATED spelling — `const v: S[] | null = b?.y` — runs
and prints `4`, and the checker calls that annotation redundant, so the two spellings agree
about the TYPE and disagree about the REP. The un-annotated binding's CELL is what does not
resolve: `exprNullableRefArray`, `refListElemNameOfExpr` and `exprEmittedRefListSlot` were
each taught the `?.` twin of their `Member` arm and the cell still takes no ref-list row, so
the local is declared at a valtype the module never interned.

The remaining rung is the binding's own cell kind (`globalCellKind` / the local's declared
kind), which reads the initialiser through a different resolver than the three above.

Only the ref list is affected: every scalar list (`i32[]`, `string[]`, `f64[]`, `i64[]`,
`f32[]`, `u8[]`) and the already-nullable `i32[] | null` field run un-annotated.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the annotation (`const v: S[] \| null = b?.y`) | runs, prints `4` | **yes** — the rescue |
| the ref element (an `i32[]` field) | runs, prints the element | **yes** |
| the `?.` (`const c: B = …` then `const m = c.y`) | runs, prints `5` | **yes** |
| the receiver's shape (a call, a name) | refuses identically | no |

#### Grading list

The annotated spelling is this row's rescue and must keep printing `4`; the ten scalar and
scalar-list leaf kinds D1676 closed are pinned by
`tests/cases/expressions/optchain-standalone-leaf-reps.vl`, which a fix here must not move.
