### D10891 — a `.map` over a hole function's list of a record has no ref-list row at the instance

**loud emit reject, `vl check` rc 0 · clause 2 · found grading D10794 (the record spelling of its witness) · present on master `b84cf89cb` · filed 2026-10-23 against master `b84cf89cb`**

Repro:

    type P = { x: i32 }
    function t(x) {
      const m = [x].map((e) => e)
      print(m.length)
    }
    const a: P = { x: 1 }
    t(a)
    // vl check: rc 0.  vl build: emitProgram: a ref list's element row does not resolve

Want:

    1

#### Mechanism

At the hole instance `[x]` is a list of `P`, a ref list, but the `.map` call's source list
row is looked up from the template's open element type, which the ref-list collection never
saw, so the lookup misses. The declared-`T` spelling collects the row and runs. Where the
hole instance's `.map` source row should be keyed by the instance's element type is not yet
located.
