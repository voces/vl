### D14421 — a call through a returned choice of functions whose results differ by numeric width emits each member's own result

**closed · was check-clean invalid wasm (`type mismatch: expected f64, found i32`), `vl check` rc 0 · clause 1 · found grading the S3b let-write join · filed 2026-10-27 against master `fff894751` · closed by `emitFnTagDispatch` widening each member call to the call's joined numeric result (wasmEmit.vl) · fixture `closures/fn-choice-returned-results-widen-called.vl`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const c = [1].length == 1
    function get() {
      return if c { inc0 } else { half }
    }
    print(get()(3))
    // master: vl check rc 0, vl run: invalid module, type mismatch: expected f64, found i32.  now: 4

#### Mechanism

`get()(3)` goes through a tagged set (`fnTagDecide`), and `holeSetCallRet` types it as the
join of its members' results at `(i32)`: `i32` and `f64` join to `f64`. `emitFnTagDispatch`
built the `if` at `f64` and emitted each member call as itself, so `inc0`'s `i32` landed in
an `f64` arm. Only a union result was converted (boxed). Each member call is now emitted
through the widening helper of the call's own numeric kind.
