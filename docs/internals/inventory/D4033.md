#### Mechanism

Localised at the close. The pin re-asked `x.grow` as a plain field read of `Circle` and refused
it (`memberFloorMsg`), never consulting the type-bound rung `ufcsCalleeOf` reaches for a concrete
receiver. Past the pin, the rung's answer was banked once per call site, so a second instance
whose type lives in another module re-used the first module's `grow`: a refusal at check, and
for an element receiver (`xs[0].grow`) a wasm that failed to validate. Each instance now asks
its own receiver type, in the checker's re-check and in `monoPinMemberCall`.
