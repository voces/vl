### D1431 — an unbounded `<T>` is an entirely open hole, so its member reads defer to the call the way an inference hole's do

**runs today and must keep running · the owner ruling of 2026-09-03, landed · closes D1221 and
D1004's unbounded half · ZERO corpus cells**

Repro:

    type Boxed = { tag: () => string }
    function g<T>(x: T): string { x.tag() }
    const b: Boxed = { tag: () => "fld" }
    print(g(b))
    // prints fld

#### Mechanism

`checkMemberNode`'s `TyVar` arm grew a demanded shape only for a `?`-named hole; a declared
parameter fell through to `memberFloorErr`. The ruling is that the two spellings of one
generic answer alike, so an UNBOUNDED parameter (`tpBoundOfName` -1, after both bound rungs
have declined) now mints the same `HD_FLD` derived hole and records a deferred row.

The demand rides `noteMemCstr`, NOT the hole-shape table. That table is keyed by hole NAME,
and two declarations may both spell their parameter `T`; a deferred row keys the receiver's
arena type and stamps the owning declaration, so each generic adjudicates only its own calls.
`substHoleTy` already resolved a derived hole through `bindOf(bNames, …, "T")`, which is why
the body's type needs no new machinery — only the CHECK did.

A bounded `<T: …>` never reaches the rung: `boundMemberTy` and `boundMemberFloorMsg` answer
first, so OQ-5's strict bodies are unchanged and a bound is still the stricter spelling.

What is left at `tpMemberFloorMsg` is exactly `boundObjRootOf` answering -1 — the annotation
is NOT A BOUND. That is four sub-cases and only one of them (`<T: i32>`) has no members: a
struct alias, a FIELD-member alias and an undeclared name all reach it too, because a NAMED
bound is a type declaring METHOD members. The first narrowing said "is not a type with
members", which was false of the two aliases; the sentence now says only `\`Showable\` is not
a bound` and leaves the rule to the instantiation's own diagnostic.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `<T>` (bare `(x)`) | printed `fld` before and after | no — that is the point |
| a bound `<T: { tag: () => string }>` | printed `fld` before and after | no |
| an instantiation that carries `tag` | `argument 1: expected {tag: _}, got {r: f64}` | **yes** |
