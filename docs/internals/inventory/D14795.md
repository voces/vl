instance returning `string`, so a call through the slot reads a string: while
`monoInstanceWidenRet` is set, `monoMakeInstance` takes the slot's result (`monoFnTyRet(expTy)`)
when the substituted one only converts to it. The decision is the emitter's: the elaboration
still records the instance's result as `K`, so a reader of the recorded column (the step-4 flip of
`computeVoidFns` and `computeRetInference` onto it) would build the atom and break the delivery.
