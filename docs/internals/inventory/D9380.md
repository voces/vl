### D9380 — a generic returned from one un-annotated function and bound at two results over the same literal-union parameter traps

**loads then traps · clause 1 · `vl check` rc 0 · `wasm trap: indirect call type mismatch` · found closing [D9282](D9282.md) · present on master `a28f82fcb` · filed 2026-10-21 against master `a28f82fcb`**

Repro:

    type K = "x" | "y"
    function same<T>(k: T): T { k }
    function deliver() {
      return same
    }
    const v: (k: K) => string = deliver()
    const w: (k: K) => K = deliver()
    const z = w("y")
    print(v("x") + "!" + v(z))
    // vl check rc 0.  vl run: wasm trap: indirect call type mismatch

Want:

    x!y

#### Mechanism

The module holds one `deliver` and one `(K) => K` instance of `same`. The two destinations differ
only in their result, and no per-pin copy of `deliver` is made for them, so `v`'s call is typed
`(K) => string` over a function returning the atom. With parameters that differ (`(k: K) =>
string` beside `(k: string) => string`) the copies are made and the program runs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `w` and its call (one destination) | runs, `x!` | **yes** |
| the shared parameter: `w` at `(k: string) => string`, printing `v("x") + "!" + w("q")` | runs, `x!q` | **yes** |
