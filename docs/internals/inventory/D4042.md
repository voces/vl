**closed 2026-10-19 by lane L6 · runs, prints `1` · was check-clean invalid wasm · clause 1 · the module-global and declared-return scans that reserve the string-op scratch frame ask the target's TYPE whether a literal member widens to a string (`tyTakesAtomAsStr`), not its spelling, which names the alias `U` · pins: `tests/cases/unions/litunion-atom-into-record-arm-union.vl` (the unread store, the return position, the both-arms read) · one mechanism with [D7043](D7043.md) and [D7120](D7120.md) · present on master `e55677bd8` · found by lane L2's kind grid (`scripts/twin-agreement.vl` KINDS programs) · filed 2026-10-11 against master `5a9535c91`**

Repro:

    type A = "a" | "b"
    type U = A | { tag: i32 }
    const a: A = "a"
    const u: U = a
    print(1)
    // vl check: rc 0.  vl run: exit 70, invalid module in top-level code:
    //   unknown local 4: local index out of bounds

#### Mechanism

Widening a literal-union value into a union box goes through a scratch local the delivery
never reserves, so the function body indexes past its locals. `u` is never read in the witness:
the store alone is enough, and the target need not even be a literal union (`string | { tag: i32 }`
fails the same way). Traced by lane L6 closing [D7043](D7043.md): the reservation passes,
`globalInitWidensAtomToStr` and `retWidensAtomToStr`, asked `unionTakesAtomAsStr` of the
target's spelling, which is false for an alias.
