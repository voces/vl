### D4042 — a string-literal-union value delivered into a union with a non-string arm reads a local that was never declared

**open · check-clean invalid wasm · clause 1 · found by lane L2's kind grid (`scripts/twin-agreement.py` KINDS programs) · filed 2026-10-11 against master `5a9535c91`**

Repro:

    type A = "a" | "b"
    type U = A | { tag: i32 }
    const a: A = "a"
    const u: U = a
    print(1)
    // vl check: rc 0.  vl run: exit 70, invalid module in top-level code:
    //   unknown local 4: local index out of bounds

#### Mechanism

Widening a literal-union value into a union box goes through a scratch local the delivery
never reserves, so the function body indexes past its locals. `u` is never read in the witness:
the store alone is enough, and the target need not even be a literal union (`string | { tag: i32 }`
fails the same way). Not yet traced to the reservation pass that misses it.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the literal `"a"` delivered directly | runs | **yes** |
| `u` read in both arms of `if u is { tag: i32 } { print(u.tag) } else { print(u) }` | runs, prints `a` | **yes** |
| source spelled inline `const a: "a" \| "b"` | still invalid | no |
| target `string \| { tag: i32 }` instead of `A \| { tag: i32 }` | still invalid | no |
| other arm `i32` instead of `{ tag: i32 }` | still invalid | no |
| return position `function f(a: A): U { return a }` | still invalid, inside `f` | no |
