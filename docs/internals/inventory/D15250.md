#### Mechanism

The checker banks the tested type at the `is` node (`isVarTyIx`), and since D2781 the receiver
member a pattern names. The emitter still resolves the variant from the pattern's spelling in
two callers. `monoStaticIsResult` (`compiler/wasmEmit.vl`) is mono deciding an instance's `is`
result from spelling: it asks `variantIndexOf` of the raw pattern text, and its name cascade
compares the argument's pin name (`monoArgTyName`) with the pattern text. This is the
higher-priority half. `emitIsTestVariant` resolves through `isVariantSpellingAtRecv`, whose
`isVariantSpelling` keys literal-set and generic-pin spellings and whose
`isVariantSpellingOfShape` keys the declared name of an arm a pin minted by shape (D5051).
Retiring the spelling path means the checker stamps those three facts too.

#### Close

`isTestedRowOf(ty, recv)` (`compiler/emit_obj_lit_fits.vl`) answers the row from `isVarTyIx`
alone, first rule with one row name:

1. the row of the tested type's own declared name (`structNameOfTy`, by arena identity: layout
   twins such as `Cat` and `Kot` are one arena type, so their names are what keep them apart);
2. among the receiver union's rows: the very type, then a member (`armRowIsMember`, else
   `tySameSet`), then once a Set is spelled as its boolean map (`tySameSpelled`, D4668);
3. the same three over every row.

`emitIsTestVariant`, `monoStaticIsResult`'s union exclusion (still scoped to a union receiver,
#1310) and `isFitsAcrossTagRows` read it. `isVariantSpellingAtRecv`, `isVariantSpellingOfShape`,
`isVariantSpelling` and `armRowNameOfDeclaredMember` are deleted. Emitted wasm is byte-identical
over the tests and the distilled corpus.
