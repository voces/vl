### D15250 — an `is` test's variant is still resolved by spelling for literal-set, generic-pin and shape-minted arms

**runs today and must keep running · the checker should stamp these as it stamps the receiver member ([D2781](D2781.md)) · filed 2026-11-04 against master `e394c738` by lane column-G1**

Repro:

    function h(v) { v is { a: i32 | string } }
    const w: { a: string | i32 } | string = { a: 1 }
    print(h(w))
    // vl run: true

#### Mechanism

The checker banks the tested type at the `is` node (`isVarTyIx`), and since D2781 the receiver
member a pattern names. The emitter still resolves the variant from the pattern's spelling in
two callers. `monoStaticIsResult` (`compiler/wasmEmit.vl`) is mono deciding an instance's `is`
result from spelling: it asks `variantIndexOf` of the raw pattern text, and its name cascade
compares the argument's pin name (`monoArgTyName`) with the pattern text. This is the
higher-priority half. `emitIsTestVariant` resolves through `isVariantSpellingAtRecv`, whose
`isVariantSpelling` keys literal-set and generic-pin spellings and whose
`isVariantSpellingOfShape` keys the declared name of an arm a pin minted by shape (D5051).
Retiring the spelling path means the checker stamps those three facts too.
