### D9732 — a `for` loop over a list of records of an un-annotated function handing each to an un-annotated parameter that calls the field has no interned call signature

**loud emit reject · `vl check` rc 0 · `emitProgram: a function-value call has no interned signature` · clause 2 · found closing [D9641](D9641.md) · present on master `e8163edd5`, there as `callee is not a function name` · filed 2026-10-22 against master `e8163edd5`**

Repro:

    function inc0(a) { return a + 1 }
    function take2(a) {
      print(a.f(3))
    }
    const xs = [{ f: inc0 }, { f: inc0 }]
    for x in xs { take2(x) }
    // vl check rc 0.  vl run: emit error: emitProgram: a function-value call has no interned signature

#### Mechanism

The flow table sees no call through the list's slot, so `monoPinListRecords` types the list at
the uncalled default `(i32) => i32` ([D9100](D9100.md)) and `inc0` is not instanced there.
[D9644](D9644.md)'s close leaves the element open only for a read `xs[k]` handed straight to the
parameter; a loop variable is not followed.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the loop (`take2(xs[0])`) | runs, `4` | **yes** |
| the hole in `inc0` (`inc0(a: i32): i32`) | runs, `4` `4` | **yes** |

#### Grading list

One element; the loop's body binding `x` to a `const` before the call.
