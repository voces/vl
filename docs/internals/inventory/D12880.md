### D12880 — a lambda pushed onto a list of hole functions from inside a hole function, capturing its hole parameter, reaches the generic-function floor

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same program with `add(k: i32)` runs · found closing [D12800](D12800.md) · filed 2026-10-25 against master `d015bc7dd`**

Repro:

    function snd(a, b) { return b }
    function apply2(g) { print(g("x", 2)) }
    const fs = [apply2]
    function add(k) { fs.push((g) => { print(g("z", k)) }) }
    add(9)
    for f in fs { f(snd) }
    // vl check: rc 0.  vl run: emitProgram: a generic function is passed to a function value whose parameter type names a type parameter this closure does not bind

Want:

    2
    9

#### Mechanism

Not traced. The lambda is an element of `fs` (D12800), and the call through the loop types it
at the top-level frame; its parameter `g` is called with `k`, whose type there is `add`'s
unbound type variable rather than the `i32` of `add`'s one instance, so `snd` is passed at a
type that names a variable no frame binds.
