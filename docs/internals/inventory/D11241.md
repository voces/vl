**closed 2026-10-23 — the filed repro RUNS and prints `1` · was check-clean invalid wasm, `expected (ref null $6), found i32`, and a loud `only i32 locals are supported` inside a function · clause 1 · the box test a binding's collect pass and slot classifier ask of a map read (`mapReadScalarBoxKindTy`, `mapReadNumLitBoxKind`) resolves the receiver of `m.get(k)` as well as `m[k]` (`fusedMapReadRecvIx`), so the binding registers and takes the `N | null` box its null test reads · filed 2026-10-23 against master `c5a14222d` · fixtures `tests/cases/literal-unions/bound-map-read-of-num-litunion-null-test.vl` and `bound-map-read-of-num-litunion-annotated.vl` · the six `map_set` cells of the three numeric `as-trap-*` matrices now run**

#### Mechanism

`__m.get("k")` is `N2 | null`, and a numeric literal union with `| null` reps as the union box.
The binding takes the scalar slot, while the null test reads the binding as that box. The two
reps disagree only when the bound read is tested against `null`. Printing it or testing the read
inline both run. Inside a function the same program is refused loudly with
`only i32 locals are supported`. This is the `map_set` cell of every numeric
`as-*-num-litunion-*` matrix template, whose proof reads the stored value back through this
binding.
