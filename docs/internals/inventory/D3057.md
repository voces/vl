#### Mechanism

Not investigated past the ablation. D3041 serves a declined delivery into a `readonly`
destination with a view when the checker recorded that delivery's source expression
(`refViewReadonlyAt`). The `.set` spelling reaches that record and runs; the index store does
not, so its delivery is still declined. The likely cause is that the index store's value is
checked against the map's value type through a path other than the delivery seam
`noteRefListView` sits in, or with a different source node.
