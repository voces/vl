### D7481 — a generic delivered into a function type compares unequal to the generic's own name read at another instance

**check-clean silently wrong · wrong value · `vl check` rc 0 · clause 1 · under the [D7180](D7180.md) ruling a function value's identity is its declaration, never the instance it was split into, so `f == id` is `true` · two deliveries at ONE signature compare equal since [D7382](D7382.md) · found closing [D7382](D7382.md) · present on master `1c86d0f42` · filed 2026-10-19 against master `1c86d0f42`**

Repro:

    function id(x) { return x }
    print(id(1))
    print(id("s"))
    const f: (x: string) => string = id
    print(f == id)
    // vl run: prints 1, s, then false

Want:

    1
    s
    true

#### Mechanism

Not located. A closure's identity token is the function index of the adapter or instance it
calls, and [D7382](D7382.md)'s close canonicalises it per declaration AND signature. Two
values of one declaration at two signatures still carry two tokens.
