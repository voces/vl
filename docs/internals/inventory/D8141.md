#### Mechanism

`mk`'s literal is built at `Col`'s row. Into a record, the literal is re-seated at the
destination; into a union, the member it would be re-seated at is a `uVariants` row, and the
emitter cannot box a call's struct result as that member. The checker now refuses the call
when the union member differs from the destination and the function builds a literal, which
turns the emit refusal into the check refusal D8020 owns. Running it needs the call's result
built at the member, the same emitter-side instance work as D8020.

Graded 2026-10-20 by lane L1: moving the call's re-seat (`recFnBuiltAtDst`) ahead of that
refusal builds `mk` at the member and brings back the emit refusal (`rebox scratch slot
unreserved`). The union box is chosen from the call's checked row, `Col`, by
`structIndexOfCallExpr` and the `blockHasVariantRebox` scan (emit_classify.vl, emit_fn_scans.vl,
wasmEmit.vl), which never reads the rebuilt row. The close is there, outside lane L1's files.
