### D9644 — a list element record of an un-annotated function and an element of an annotated record list handed to one un-annotated parameter has no interned call signature

**loud emit reject · `vl check` rc 0 · `emitProgram: a function-value call has no interned signature` · clause 2 · found closing [D9570](D9570.md) · present on master `9e81d3ee3`, there as `ref valtype with no interned shape` · filed 2026-10-22 against master `9e81d3ee3`**

Repro:

    type R = { f: (a: i32) => f64 }
    function inc0(a) { return a + 1 }
    function take2(a) {
      print(a.f(3))
    }
    const xs = [{ f: inc0 }]
    take2(xs[0])
    const ys: R[] = [{ f: (a: i32): f64 => 0.5 }]
    take2(ys[0])
    // vl check rc 0.  vl run: emit error: emitProgram: a function-value call has no interned signature

#### Mechanism

Not traced. With `ys` the literals reaching `take2` disagree, so `a.f(3)` is not rewritten to
`inc0(3)` and `inc0` is not instanced at `(i32) => i32`; [D9572](D9572.md)'s close pins it only
when the record literal is the call's argument.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the second call | runs, `4` | **yes** |
| the list `xs` (`take2({ f: inc0 })`) | runs, `4` `0.5` | **yes** |
| the hole in `inc0` (`inc0(a: i32): i32`) | runs, `4` `0.5` | **yes** |
