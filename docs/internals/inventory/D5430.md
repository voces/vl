#### Mechanism

`globalCellKind` (`emit_classify.vl`) picks the global's cell with no arm frame open, so it
reads the arm tail `r?.tag` with `r` out of scope and gets no nullable-string cell. D5333's
start-function frame is withheld from such a global (`globalArmScopeOk`, `emit_sections.vl`)
because opening it there made the emitted value disagree with that cell, which built invalid
wasm. A close classifies the global under the same frame.
