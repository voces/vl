### D12841 — a labelled block left by a `break` inside a loop, handing over a hole function declared inside that loop, is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same block handing over a function declared outside the loop runs with the [D7080](D7080.md) fix · found closing [D7080](D7080.md) · filed 2026-10-25 against master `1e4d22724`**

Repro:

    const xs = [1, 2, 3]
    function ask(s) { return s + "?" }
    const x = @B {
      for v in xs {
        function inner(s) { return s + "!" }
        if v == 2 { break @B inner }
      }
      ask
    }
    print(x("a"))
    // vl check: rc 0.  vl run: emitProgram: local declaration needs an initializer

Want:

    a!

#### Mechanism

From the code path. `lvRewriteAt` (`emit_rewrite.vl`) carries a choice among hole functions as
the index of the one chosen and names each after the loop (D7080), so it declines a function
declared inside the loop body: the name is out of scope there, and a function that captures
the loop's variables has a value the index cannot rebuild. Declined, the block falls back to
a carrier `let $lvN: T;` of the open signature, which the i32 floor refuses.
