### D14600 — an `is` test on a niche local narrowed by a dominating write is tested at run time, because the narrowed-read fact does not say a write produced it

**runs today and must keep running · a performance gap, no wrong value · fixture `soundness/nulvariant-call-boundary` (`assignNiche`) · `-O` folds it · filed 2026-10-28 against master `7673b502b`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    function area(sh: Shape): i32 { if sh is Circle { return sh.r } return 0 }
    function assignNiche(): i32 {
      let c: Circle | null = null
      c = { r: 5 }
      if c is Circle { return c.r }
      return -1
    }
    print(assignNiche())
    print(area({ r: 2 }))

Want:

    5
    2

#### Mechanism

The assignment narrows `c` to `Circle`, and `noteNarrowedRead` records that as the read's
narrowed type. The record does not say whether a write or a test produced the narrowing.
`emitIs` therefore tests the storage (`isTestsStorage`), so the test lowers to
`i32.eqz (ref.is_null (local.get $0))` and not to `i32.const 1`. Trusting test-derived
narrowing is refuted by D2447 and D2801, so the fold needs a new fact rather than a reader. The
deletion target is a write-dominated-narrowing bit, set at `noteNarrowedRead` when a write
dominates the read with no back-edge or possible writer in between; `emitIs` then folds
through `nodeTyAt`. Binaryen's `-O` folds the witness to `i32.const 5`, so the cost is unoptimised
builds only.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `Circle` as a union arm (no `Shape`) | the test folds to `i32.const 1` | **yes** |
| the write (an initialiser `let c: Circle \| null = { r: 5 }`) | runtime test, the same before #5089 | no |
| `is` (`c != null`) | folds | **yes** |
| the `let` (a parameter written in the body) | runtime test | no |
| the local (a module global, read in a function) | runtime test, the same before #5089 | no |
