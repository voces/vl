### D10152 — a list of a generic pushed an `f64` function, handed to an un-annotated parameter and called with an integer literal, passes check and traps

**trap after load · `vl check` rc 0 · `wasm trap: indirect call type mismatch` · clause 1 · DESIGN: the direct call `ys[1](3)` refuses, `push: cannot add (f64) => f64 to ((i32) => i32)[]` · found closing [D10120](D10120.md) · present on master `17b0be5a8` · filed 2026-10-22 against master `17b0be5a8`**

Repro:

    function id<T>(x: T): T { x }
    function half(x: f64): f64 { x / 2.0 }
    const ys = [id]

    function run(a) { print(a[1](3)) }

The owed outcome is a check refusal, as the direct call's.

#### Mechanism

[D10120](D10120.md)'s slot judge (`holeSlotFixedJudge`, check_relate_core.vl) asks only
whether the call's argument types fit each fixed-type function's parameters, and `3` fits
`f64`. The call instances `id` at `i32`, so the slot holds `(i32) => i32` beside
`(f64) => f64`; what the direct spelling refuses is the two function types disagreeing,
which the judge does not compare.
