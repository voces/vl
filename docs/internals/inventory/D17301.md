### D17301 — `??` over an assignment of `null` refuses as a nullable value it cannot coalesce

**loud emit reject · 3 spellings · filed 2026-11-24 against master `fd2d6cd6` by IR-N9, found while grading D17120's `??` cell**

Repro:

    function f() {
      let n: string | null = "x"
      print((n = null) ?? "d")
    }
    f()
    // vl check: no errors.  vl run: emit error, `??` over this nullable value is not supported yet

Want:

    d

#### Mechanism

The coalesce takes its left operand's nullable kind from a read, and an assignment used as a value
is no read it has an arm for, so it refuses with the generic `??` sentence. The value of `n = null`
is the `null` unit (`asgYieldsNullLit`), so the default always applies. Not yet traced to the
coalesce plan's arm list.

#### Ablation

| ingredient changed | outcome | needed? |

| `let n: null = null` | refuses the same | no |
| `const z = (n = null)` then `print(z ?? "d")` | prints `d` | **yes** (the assignment under `??`) |
