### D16944 — a generic's inferred return joins `T | null` with a later concrete return as `T | null`, so that return's value is lost

**closed 2026-11-17 · runs, prints `true` `null` `7` · was check-clean silently wrong · clause 1 · fixed in check_relate_core.vl: `joinRetTys` keeps every member apart when either side holds a hole among its top-level members (`tyTopMemberIsHole`), as it already did for a bare hole, so `T | null` joined with `7` is `T | i32 | null` instead of `joinTys` letting the open `T` absorb the `7` · closes [D4173](D4173.md), its literal-union face · `generic-return-join-after-null.matrix.vl` 48 WRONG cells now run, 48 of 48 · pin: `tests/cases/literal-unions/generic-return-non-member-string.vl` · found closing D4173 · filed 2026-11-17 against master `ae1ac9a5a`**

Repro:

    function g<T>(a0: T, k: i32) {
      if k == 0 { return a0 }
      if k == 1 { return null }
      return 7
    }
    print(g(true, 0))
    print(g(true, 1))
    print(g(true, 2))
    // vl check: no errors.  vl run: PRINTS true null null

Want:

    true
    null
    7

#### Mechanism

The returns join in source order. `T` then `null` is `T | null`, and a later `7` joined into it is
absorbed: `g`'s inferred signature is `(T, i32) => T | null`, where `T`, `7`, `null` in that order
gives `T | i32 | null`. Each instance then builds the result at `T | null`: at `boolean` the `7`
is stored where the niche reads `null`, and at `string` (`return "z"` too) the module fails to
validate. D4173's `K` instance refuses the same join loudly.

#### Ablation

| change from the repro | outcome | needed? |
| --- | --- | --- |
| returns in order `a0`, `7`, `null` | runs, `true null 7`; signature `T \| i32 \| null` | **yes** (`null` before the concrete arm) |
| `null` first, then `a0`, then `7` | wrong, `true null null`; signature `null \| T` | no |
| `a0: boolean`, no type parameter | runs | **yes** (the type parameter) |
| one `if`/`else if` expression returned, or its statement form | wrong, the same | no |
| the `if` bound to a `const` and that returned | runs | **yes** (the inferred-return join) |
| `match` with the same three arms | runs | **yes** |
| `: T \| i32 \| null` written on `g` | runs | **yes** (inference) |
| `return "z"` for `7`, called at `string` | invalid wasm | no |
