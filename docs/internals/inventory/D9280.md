### D9280 — a `.map` over a list of un-annotated functions, returned from an un-annotated parameter's function, has no list type at the caller

**closed · runs, prints `6` · was loud emit reject, `vl check` rc 0, `emitProgram: index receiver is not an array or string` · clause 2 · found closing [D9230](D9230.md) · present on master `e428d97c0` · filed 2026-10-21 against master `e428d97c0` · closed by `holeOpenFnRetAt` (check_relate_core.vl) reading a DECLARED function held in the list at its own signature, not only a lambda, so the caller sees the `.map`'s list · the heterogeneous list this newly types is refused as the bound literal is: `holeSlotJudge` judges each caller's argument of a parameter, and a call through `fs[i]` / `r.f` on a hole now asks it (check_calls.vl) · fixtures `closures/hole-fn-list-map-result-returned-from-param.vl`, `closures/error-hole-fn-list-literal-results-differ-handed-to-param.vl`, `closures/error-hole-fn-list-from-param-result-mistyped.vl`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function take(a) { return a.map((f) => f(3)) }
    const g = [inc0, dbl]
    print(take(g)[1])
    // vl check rc 0.  vl run: emit error: emitProgram: index receiver is not an array or string

Want:

    6

#### Mechanism

`holeOpenFnRetAt` answers the result of a call through an element of a hole parameter only when
the element's function type IS the declaration's node type. A lambda's is; a declared function
read by name is a copy naming the same holes, so the result fell to the open `fnRet` and the
caller saw no list. Comparing with `tyEqSameHoles` reads both. Before the fix (text below kept
as filed):

Not traced. Since D9230 the flow pins `g` at `(i32) => i32` and the `.map` inside the instance
of `take` has a list type (`print(a.map((f) => f(3))[1])` inside `take` runs). The instance's
RETURN is still read from the checker's signature of `take`, whose result is a list of the
lambda's open result, so the caller sees no list. Binding the result instead,
`const r = take(g)` then `r.length`, refuses as `'.length' on a receiver the emitter cannot
classify`.
