#### Mechanism

Not located. The call through `h` keys its signature on `h`'s recorded type with the instance
substituted (`cloInstanceSigKey`), and that type is still the hole. The list spelling of the
alias runs because mono's slot read retypes `fs[0]` at the pinned element type. A field read is
retyped by `monoRetypeFieldReads` only where the field is pinned (`monoPinRecordFields`), and
this field holds a written `let` that the pin's gate does not admit. Dropping that gate (B1 step
4) turns this witness into check-clean invalid wasm, so the alias also needs the pinned type
recorded per instance (the shared read node, D5079).
