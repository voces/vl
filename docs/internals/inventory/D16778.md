### D16778 — a maker with an un-annotated parameter, returning a hole lambda delivered at two function types whose results differ, builds one closure for both

**loads then traps · `vl check` rc 0, prints `5`, then `wasm trap: indirect call type mismatch` · clause 1 · the parameter face of [D16753](D16753.md) · found by the maker/map/relay hunt · filed 2026-11-16 against master `6fb5ac348`**

Repro:

    function adder(n) { return (a) => a + n }
    const v: (a: i32) => i32 = adder(2)
    const w: (a: i32) => f64 = adder(2)
    print(v(3))
    print(w(3) / 8.0)
    // vl check: rc 0.  vl run: prints 5, then wasm trap, indirect call type mismatch

Want:

    5
    0.625

#### Mechanism

Not traced. [D16753](D16753.md)'s close returns a maker's lambda at its wide twin's result (`elabTwinLamRet`); with a hole parameter on the maker the second delivery's twin, or its lambda's key, is not the one the closure is built from.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `n: i32` annotated | runs, `5` `0.625` | **yes**: the hole parameter |
| one delivery (`(a: i32) => f64` only) | runs, `0.625` | **yes**: two results |
| no parameter, `n` captured from the top level | runs, `5` `0.625` | **yes** |
