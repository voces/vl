### D2234 — a tail `if` / `else` value under a declared return type is never checked against it, so a wrong-typed arm is check-clean invalid wasm or a wrong value

**closed · now a loud check reject, "expected i32, got string" at the arm · was check-clean invalid wasm (and, at other arm types, a silent wrong value or a `cast failure` trap) · clause 1 · filed 2026-09-23 against master `5dd67e150` · found grading D2223's tail-`if` delivery · fixtures `tests/cases/soundness/tail-if-arm-checked-against-declared-return.vl`, `tests/cases/soundness/tail-if-arm-legal-returns-run.vl`**

Repro:

    function pick(n: i32): i32 {
      if n == 0 { "i" } else { 2 }
    }
    print(pick(0))
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `pick`: type mismatch: expected i32, found (ref $type)

#### Mechanism

The function body's tail is checked against the declared return through `assignableExpr` only
when it is not a statement node (`checkFuncDeclNode`, the `!isStmtNode(stmts[s])` guard), and an
`if` is a statement node — as is a tail `match`, which desugars to an `if` chain in place before
the guard reads it. Nothing asked whether each arm's value was assignable to the return, so
every shape of arm escaped: then, else, an `else if` link, a nested `if`, a block tail, a bare
block, a `match` arm of either vocabulary, a lambda with a declared result and a `self`-function.
What came out depended on the arm: invalid wasm for a `string` or `f64` arm under `i32`, a wrong
VALUE for a `boolean` arm under `i32` (printed `1`), an `i32` arm under `boolean` (printed
`true`) and a `"c"` arm under `"a" | "b"` (printed `b`), and a `cast failure` trap for a
`string` arm under `i32 | null`. The close walks the tail's value leaves (`tailValueLeaves`)
and checks each against the return at the arm (`checkTailArmsAgainst`), and seeds each with it
first (`seedTailArms`), exactly as the bare tail expression is seeded and checked.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the tail `if` (`return "i"` in the arm) | check reject | **yes** |
| the declared return (`function pick(n: i32)`) | infers the union, runs | **yes** |
| the scalar (a record arm `({ out: "i" })` against `{ out: f64 \| null }`) | check-clean, traps `cast failure` at the field read | no |
