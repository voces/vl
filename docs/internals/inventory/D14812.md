### D14812 — a call in a list literal handed to a generic list parameter, whose result is relayed, compared or stored, is invalid wasm

**open · check-clean invalid wasm, clause 1 · the residue of [D14733](D14733.md) · filed 2026-11-01 against master `efc86b3b`**

Repro:

    type Circle = { r: i32 | null }
    function sink(_x: Circle) { }
    function mkcall() { { r: null } }
    sink(mkcall())
    function first<T>(xs: T[]): T { xs[0] }
    const y = first([mkcall()])
    const b = y
    print(b.r ?? 13)

Want:

    13

#### Mechanism

`sink(mkcall())` builds `mkcall`'s record at `Circle`. The D14733 close lets the list literal
`[mkcall()]` land at `Circle[]` only where `first`'s list parameter takes the rep
(`recListParamTakesRep`) and the call's result is read for a field, handed on by rep, or bound to a
`const` read only for fields (`recRetTakesRep`). Here `y` is handed on to `b`, so the delivery is not
skipped, the two builds of `mkcall` disagree, and `mkcall` keeps its own row. `sink` receives it
as `Circle`: invalid on line 4.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `sink(mkcall())` | prints `13` | **yes** |
| the list: `first<T>(x: T): T { x }` over `mkcall()` | prints `13` | **yes** |
| `const b = y`, reading `y.r` | prints `13` (D14733) | **yes** |

#### Grading list

Each is the Repro's prelude (lines 1 to 4) and `first`, with the last lines replaced. Every one is
invalid wasm on master `efc86b3b`:

* `function g() { first([mkcall()]) }` then `print(g().r ?? 10)`: returned from a function;
* `print(y == y)`: compared;
* `const s = [y]` then `print(s[0].r ?? 20)`: stored in a list;
* `function rd<T>(xs: T[]): i32 { const z = xs[0]` then `8 }`: the element bound in the callee;
* `function keep<T>(xs: T[]): T[] { xs }` then `print(keep([mkcall()])[0].r ?? 12)`: the list
  returned.
