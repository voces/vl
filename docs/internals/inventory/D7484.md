### D7484 — a generic whose function-typed parameters are handed raw generics, binding its type parameter from nothing, meets an internal floor

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same call with one argument delivered first as `(x: i32) => i32` runs, printing `true` · under the [D4551](D4551.md) ruling the type parameter is default-bound and the default is never observable, and a comparison calls nothing · found closing [D7382](D7382.md) · present on master `1c86d0f42` · filed 2026-10-19 against master `1c86d0f42`**

Repro:

    function two<T>(x: T): i32 { return 1 }
    function three<T>(x: T): i32 { return 3 }
    function same<T>(f: (x: T) => i32, g: (x: T) => i32): boolean { return f == g }
    print(same(two, two))
    print(same(two, three))
    // vl check: rc 0.  vl run: emitProgram: internal: a parameter type the valtype ladder has no rung for — every parameter type the checker accepts has one above

    true

#### Mechanism

Not located. Nothing binds `same`'s `T`: both arguments are generic in their own parameter, so
the instance is asked for at an open `T` and its parameter type has no wasm value type.
