Repro:

    type R = { f: (a: i32) => f64 }
    function inc0(a) { return a + 1 }
    const r: R = { f: (a: i32): f64 => 1.0 }
    const p = []

    print(p[0].f(3))

Want:

    4

#### Mechanism

The mechanism of [D9530](D9530.md): the pushed literal was laid out at `R`'s row because its
function field had holes, and once a value of `R` was built the element's call read `inc0`
through `R`'s f64-result signature. The declared row is now refuted for a literal whose
function returns another closed type at the row's parameters, so the element keeps its own row.
