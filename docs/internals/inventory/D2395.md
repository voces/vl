### D2395 — a closure storing a list literal into an element of a captured `(i32 | f64)[][]` traps

**loads then traps · clause 1 · pre-existing on master `3ab3c402f` · filed 2026-09-25 against
`3ab3c402f`, found reviewing [D2387](D2387.md)/[D2388](D2388.md) (#3143)**

Repro:

    function f(): string {
      let c: (i32 | f64)[][] = [[1, 2.5]]
      const k = () => { c[0] = [3.5, 4] }
      k()
      "\{c[0].length}"
    }
    print(f())
    // vl check: rc 0.  vl run: wasm trap in `k`: an `unreachable` instruction — a compiler-emitted trap

#### Mechanism

The element store inside the closure reaches a compiler-emitted `unreachable`: the closure's
view of the captured nested union-element list does not resolve the inner list's rep the way
the defining frame does. Not the D2387 cell: `c` is never reassigned, so it is captured by
value (a `const c` traps identically). Not yet localised further.

#### Ablation
