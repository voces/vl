#### Mechanism

[D2394](D2394.md)'s mechanism at an element target. The closure's value is its tail
assignment, which the checker typed at the literal's own `f64[]`, so the closure's result was
`f64[]`. An element write lowers as a value only by re-reading its target
(`assignTargetReReads`), which needs the target's type to be the assignment's; it was not, so
the tail was emitted as a statement under a result-bearing signature and ended in
`unreachable`. With the assignment typed at the element's type, the tail re-reads the element.
Two consumers had to agree: `criClassify` took a tail assignment's return kind from its right
side and now takes it from the target when the checker typed the assignment there, and
`spillTail` (D1510) spilled the right side into an `f64[]` temporary to yield it, and now
stores the literal unspilled and yields a re-read of the spilled place.
