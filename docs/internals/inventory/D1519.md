### D1519 — an emit refusal raised by a program-wide pass had no cursor to anchor at, and `diagModule` had no emit arm at all, so a cross-module one named the ENTRY file

**loud emit reject — and it must STAY one: this row is about the diagnostic's shape, not about making the program build. FIXED 2026-09-03; the refusal now names `lib.vl:6:15`, where it named `main.vl` with no line at all · reported by the glean session, VL-024 / VL-026, `~/glean/docs/vl-issues.md`**

Repro:

    // file: lib.vl
    export type E = { msg: string }
    type C = { q: i32 }
    type B = { c: C }
    type Z1 = B | E
    type Z2 = C | E
    type A = { f: B }
    export function h(ok: boolean): A | E {
      if !ok { return { msg: "e" } }
      return { f: { c: { q: 1 } } }
    }
    // file: main.vl
    import { E, h } from "./lib"
    print(h(true) is E)
    // vl check --codegen: rc 1, loud emit reject.
    // Was: `at main.vl` — the ENTRY file, and with no line:col at all.
    // Now: `at lib.vl:6:15` — the defining module, at the field with no rep.

#### Mechanism

Two independent holes, one channel.

**No cursor.** `emitFail` is not positionless by design — it anchors at `emitCurStmtIx`, else
`emitCurFnIx`. Both are armed only while a BODY is lowered (`emit_sections.vl`), and
`emitProgram` clears them at entry. So every refusal raised by a program-wide COLLECT pass —
`collectU`, `collectS`, and the type section — had nothing to anchor at, and the host rendered
the diagnostic bare. That is what VL-024's two sentences hit. Fixed by arming `emitCurStmtIx`
to the DECLARATION being registered in `collectU`'s and `collectS`'s statement loops, and
clearing it when the loop ends. `collectVariantFields`'s refusal goes further and anchors at
the offending FIELD's own node through `emitFailAt`, so the caret lands on `f: B` and not on
the union.

**No module arm.** `driver.vl`'s `diagModule` is a three-way ladder — parse diag, type diag,
fall through — and the EMIT diagnostic is the third case its three siblings all handle:
`diagLine`, `diagCol` and `diagEndCol` each resolve it through `emitErrTokIx`. `diagModule`
did not, so it returned 0 and the host printed the ENTRY module's path beside a line and column
that were already the DEFINING module's own. A refusal on `src/mpq.vl:196` printed as
`tools/map-check.vl:196`, past the end of a 120-line entry. **The line and column were never
wrong** — `P.toks` keeps per-module coordinates and `modOfTok` maps a merged token index back
to its module; only the path was. Adding the missing arm is the whole fix, and the check path
(`tests/vl_check_module_diag_test.ts`) was the working reference implementation beside it.

#### Ablation

Seven emit-refusal positions, one program each, graded against a master-source control seed and
the candidate. This is the unit that decides positionlessness: `emitFail` is a shared channel,
so the question is which PHASE armed a cursor, not which of 506 call sites was used.

| phase | before | after |
| --- | --- | --- |
| `collectU` / `collectS` declaration registration | POSITIONLESS | `collect.vl:6:15` |
| VL-024 `f`-first (type section, `pushFieldStorage`) | POSITIONLESS | runs (D1518) |
| VL-024 `g`-first (`collectU`) | POSITIONLESS | runs (D1518) |
| type section, a struct row's field target | POSITIONLESS | POSITIONLESS |
| function body | `body.vl:10:10` | unchanged |
| top-level statement (start function) | `top.vl:11:16` | unchanged |
| cross-module, refusal in `lib.vl` | `main.vl:15:17` (**wrong file**) | `lib.vl:15:17` |

Call-site census, re-derived from the tree: **506 `emitFail` + 17 `emitFailAt` = 523** call
sites (`wasmEmit.vl` 424/13, `emit_collect.vl` 26/1, `emit_bytes.vl` 18/2, `emit_sections.vl`
17/0, `emit_mono.vl` 13/0, `emit_classify.vl` 8/1). Converting them one by one is the wrong
unit twice over: a site in `emit_bytes.vl` inherits whichever cursor its CALLER armed, and
`wasmEmit.vl`'s 424 are overwhelmingly body lowering, already anchored. What a site's own
`emitFailAt` buys is PRECISION (the field, not the function) — worth doing where the offending
node is in hand, which is why `collectVariantFields` took it here.

#### Grading list

* `tests/vl_emit_diag_position_test.ts` — both cases FAIL on a master-source seed and pass on
  the candidate, which is the control the `emitFail`-probe rule demands: `emitFail` records and
  keeps emitting, so a guard whose witness COMPILES reports nothing. Each case asserts the
  refusal fired before asserting anything about its position, and names its own replacement
  work if the witness ever stops refusing.
* **THE TYPE SECTION IS THE NAMED REMAINING GAP**, with a live witness: a struct row whose
  code-15 field targets an arm with no heap twin
  (`type A = { f: { g: B } }` beside `type Z = B | E`) still refuses positionlessly. Its honest
  anchor is the row's declaring statement, and the row has no column for one — `sNames` and
  `uVariants` are each pushed from several places, so a decl-statement column needs a
  single-home push first (`pushFieldRow`'s discipline, one table up). Arming only the variant
  side would be an instrument with no failing control to validate it, since D1518 makes the
  witness that used to fire there RUN.
* The precision of a BODY refusal is unchanged and still names the FUNCTION, not the statement:
  `emitCurStmtIx` is armed only for top-level statements, and arming it per body statement
  moves every in-body emit diagnostic at once. Deliberately out of scope here.
