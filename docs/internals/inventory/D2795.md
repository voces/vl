#### Mechanism

The return's union `Circle[] | i32[]` is registered when the return is pinned (D2768), after
`collectU` and `collectS` have run, so the object literal's field of that union type finds no
row, and the literal is taken for a union variant to box. The annotated return registers the
union in `collectU` and runs. A value union of lists (`string[] | i32[]`) is minted in
`collectU` from the inferred join and runs too. Not yet localised further.
