#### Mechanism

`sel(gid)` binds `A` from no argument and, here, from no destination: the return is inferred,
so `__deliver`'s result keeps `sel`'s `A` open (`(A) => A`). The emitter builds the one closure at
the `i32` instance, and the call `v(1.5)` is typed and lowered at the `f64` signature the
annotation (or, for the list element, the call's own argument) gives the read. The value and the call
disagree on the signature and `call_indirect` traps. `dstBindOpenFnTyParams` binds an open
parameter only at the call whose destination it sees, and an inferred return hands it none.
The emitter's loud check for a disagreeing value call (D15062, the `i32` parameter case) does not
fire, because the call's own signature is the wider one.

#### Loud

`emitCallRefUnder` compares the call's key with the key the closure was built at:
`cloCallBuiltAtOtherSig` (`emit_closure_sites.vl`) follows the read through `const` initializers and
list-literal elements to the generic call that made it. It reads that call's callee instance's
declared return, or what an un-annotated one returns. A built key that differs from both the call's
key and the producer's own checked type is the default instance, and the call is refused rather than
trapping. The matrix moves the two cells from TRAP to emit refuses and changes no other cell.
