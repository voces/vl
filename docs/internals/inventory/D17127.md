### D17127 — an un-annotated function forwarded through a second un-annotated parameter into a record literal builds an invalid module

**check-clean invalid wasm · clause 1 · found by heap identity 4c's position sweep (lane IR-M1) · filed 2026-11-24 against master `80c0a14f`, the same under the IR and the claimless compiler**

Repro:

    function inc0(a) { return a + 1 }
    function mk(f) { return { f: f } }
    function outer(f) { return mk(f) }
    print(outer(inc0).f(3))
    // vl check: rc 0.  vl run: invalid module, `mk`: expected (ref $1), found i32

Want:

    4

#### Mechanism

D16738's neighbour one parameter further. D16738's close (`ftParamStored`) counts `mk`'s read of
`f` into a literal built with a closure field as a store, so `inc0` handed straight to `mk` stays
a closure. Handed to `outer` and forwarded, the tag decision for `outer`'s `f` still takes the id:
`mk` writes the i32 id into the closure field. Not yet located past that.
