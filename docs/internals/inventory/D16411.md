### D16411 — a generic function handed to a generic's function-typed parameter, its type parameter bound only by a call of the returned closure, is refused at emit

**loud emit reject · clause 2 · open · bucket (c), L2 inferred interfaces: `A` is bound only by a call of the returned closure, after `sel` returns; `sel<f64>(gid)`, or an argument that binds `A`, runs · `vl check` rc 0 · `emitProgram: a function value is called at two signatures, and the closure it holds was built for one: this call passes a wider number than its `i32` parameter` · the un-annotated spelling of [D16410](D16410.md) · found by the independent oracle's higher-order generator (`scripts/oracle/gen_hof.ts`, case 8) · filed 2026-11-15 against master `33ef972d7`**

Repro:

    function gid<A>(x: A): A { x }
    function sel<A>(f: (x: A) => A): (x: A) => A { f }
    print(sel(gid)(1.5))
    // vl check: rc 0.  vl run: emit error, a function value is called at two signatures

Want:

    1.5

#### Mechanism

As in [D16410](D16410.md), `gid` reaches `sel` at its `i32` instance; here the later call at
`f64` is a second signature, and the emitter refuses it where D16410's annotation hides it. From
the ablation.
