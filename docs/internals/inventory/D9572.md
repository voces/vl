### D9572 — an un-annotated parameter handed a record of an un-annotated function and a record of an annotated lambda leaves the function unpinned

**loud emit reject · `vl check` rc 0 · `emitProgram: cannot take the generic function `inc0` as a value` · clause 2 · found closing [D9530](D9530.md) · present on master `49a7d0b10` · filed 2026-10-22 against master `49a7d0b10`**

Repro:

    type R = { f: (a: i32) => f64 }
    function inc0(a) { return a + 1 }
    function take(a) {
      print(a.f(3))
    }
    take({ f: inc0 })
    take({ f: (x: i32): f64 => 1.5 })
    // vl check rc 0.  vl run: emit error: emitProgram: cannot take the generic function `inc0` as a value

#### Mechanism

Not traced. `take` is called at two record types, `{f: (_) => _}` and `{f: (i32) => f64}`, and
the first call's instance does not pin `inc0` at `i32`, so taking it as a value finds no
signature to adopt.
