#### Mechanism

The maker is built at `K` (D15719), so `mk` returns `(ref K)`, but the call's checked type is the
union of its two literal records. A module global's initializer unboxes only where every arm is
stored at the cell's heap (`emitNarrowedArmUnboxTo`); a function-scope binding (`emitLetDelivery`)
cast whenever `narrowedArmNeedsUnbox` held, reading a K struct as the box's payload. Both now ask
one guard. An un-annotated holder of the call is a second mechanism, D16978.
