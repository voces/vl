### D15861 — a bundle holder handed to a parameter annotated at one member's type is refused at emit

**loud emit reject · clause 2 · `a function returning a parameter called at two signatures is called where its result is not used at one of them` · found closing [D15749](D15749.md) · filed 2026-11-12 against master `84e28554d`**

Repro:

    function lap(f) {
      f(2.5)
      f(3)
      return f
    }
    function u(f: (f64) => f64) { print(f(4)) }
    function main() {
      const k = lap((a) => a + 1)
      u(k)
      print(k(3))
    }
    main()

Want:

    5
    4

#### Mechanism

Unmeasured. A hand of a holder is admitted only to a parameter its callee's instance binds to
the record or to one member (`elabHandTakesRecord`, `elabHandMemberOf`); an annotated
parameter of a plain function is neither, so the hand is a read the holder cannot account for.

| spelling | outcome | needed? |
| --- | --- | --- |

| `const m: (f64) => f64 = k` then `u(m)`, beside `k(3)` | check reject ([D15860](D15860.md)'s order dependence) | no |
