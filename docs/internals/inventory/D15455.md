#### Mechanism

The `let` widening of a record literal's function fields (`letLitListsWidenAt`, `elabFnFieldTy`)
skipped a generic, so `r.f` never held `b`. Lifting that skip alone made this witness check-clean
invalid wasm: the widening also re-typed each field VALUE node, so `a`'s read carried the field's
wider set while the parameter held its own, the seed note saw one set on both sides, and the wider
set was never decided with the parameter's. A parameter's read now keeps its own type, and the
field's set is decided with it as D15453's list slot is. Measured over 19,292 programs (tests/cases
and the distilled corpus) before the close: a binding and its literal disagree in an instance in 5
programs, all running; this one disagreed only once its field was widened.
