### D7445 — a function whose declared result is one string literal returns an atom where its caller reads a string

**closed 2026-10-20 by lane L6 · runs, prints `circle` · was check-clean invalid wasm · clause 1 · a declared result of one bare string literal is a scalar lone literal, so its rep is `string`, and an atom-repped return value (a one-literal alias, a list element, a record field) widens at the return (`retStrWidenOf`, and `retWidensAtomToStr` reserves its local) · pin: `tests/cases/functions/one-literal-result-widens-atom.vl` · found closing [D7340](D7340.md) · present on master `6aab4c3c9` · filed 2026-10-20 against master `6aab4c3c9`**

Repro:

    type KC = "circle"
    function g(a: KC): "circle" { a }
    print(g("circle"))
    // vl check: rc 0.  vl run: invalid module, expected (ref $0), found i32; $0 is `string`

Want:

    circle

#### Mechanism

The owner's `one-literal-union-rep` ruling makes a one-literal alias, a list element and a
record field of one literal the interned atom, while a lone literal at a scalar position
(a root, a parameter, a result) softens to `string` ([D7440](D7440.md)). A result declared
`"circle"` is that scalar position, so the function's wasm result is `string`; its body's
value is the atom, and the return delivered the i32 unconverted. The return-widen ladder
already widened an atom into a declared `string` result and did not name a bare-literal one.
