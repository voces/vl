### D17874 — a generic maker's literal is stamped at one record per node, so a maker at two instances, or one instance at two differing records, cannot be built where each lands

**loud check reject · clause 2 · `vl check` rc 1, `{f: null, g: i32} is not J: they store field `f` differently (`null` into `i32 | null`), and a record is shared, not copied` · the one-instance case runs ([D17225](D17225.md)) · filed 2026-11-28 against master `2718ac838` by I8-PREP (the remainder of D17225 and [D17228](D17228.md), coordinator ruling)**

Repro:

    type J = { f: i32 | null, g: i32 }
    type K = { f: string | null, g: string }
    function mk<T>(x: T) { return { f: null, g: x } }
    const j: J = mk(8)
    const k: K = mk("s")
    print(j.g)
    print(k.g)
    // vl check: rc 1 at 4:14, they store field `f` differently (`null` into `i32 | null`)

Want:

    8
    s

#### Mechanism

The record solve builds a maker's result where its call lands by stamping the maker's literal
node at the destination's record (`recordRepTyAdopt`). A node carries one stamp, while a generic
maker's body is lowered once per mono instance. The solve therefore admits a generic maker only
with one instance (`recGenericOneInstance`, check_rec_fresh.vl): every call is at the same
argument and result types, and none sits inside a function each instance re-checks. Even then,
its calls must not land on a record other than the destination's and the maker's own row
(`recGenericLandsApart`, check_fit_rules.vl). No converting copy of an instance's result is
lowered, so the non-generic maker's copy path (D17228) does not serve it. Closing this needs a
rep stamp per (maker instance × record): a general IR change, ruled on before it is taken. The
design and its measured yield, zero corpus cells and zero probes beyond this row's own pins, are
in `docs/internals/per-instance-rep-stamps-2026-11.md`. Open and unscheduled (coordinator
ruling, 2026-11-28); `scripts/capability-probes/generic-maker-at-two-instances-at-two-records.vl`
counts it in a sweep.

A probe build admitting several instances turned c1 (`mk(8)` at `J`, `mk("s")` free) into an
emit refusal, `global initializer coercion`, after a clean check. That arose only under the probe
build and is not a master defect, but it is the clause-1 hazard any build of this row must pin.
