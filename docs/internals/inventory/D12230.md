### D12230 — an alias of a captured, reassigned function binding stored in a list literal and called through a hole parameter is refused at emit

**loud emit reject · `vl check` rc 0 · `emitProgram: an alias of a captured, reassigned function binding is stored in a list, whose calls the binding's one signature cannot follow` · clause 2 · CAPABILITY: the same list called directly (`fs[0](3)`) runs, and so does a `const` alias of the binding stored in the list · emit_mono.vl `monoCellAliasListFail` · found surveying emit refusals for L3 family (d) · filed 2026-10-24 against master `84b98d149`**

Repro:

    function inner(x: i32): i32 { x + 1 }
    function other(x: i32): i32 { x * 2 }
    function callI(fs) { fs[0](3) }
    function main() {
      let k = inner
      const flip = () => { k = other }
      const fs = [k]
      flip()
      print(callI(fs))
    }
    main()

#### Mechanism

A `let` a closure writes after capture is rewritten into a one-element capture cell, and each
read of it becomes `k[0]`. The list literal stores that read, and the monomorphizer pins a
hole parameter's calls from the binding's one signature; a list whose element is a cell read
reaching a hole parameter has no pin path, so `monoCellAliasListFail` refuses. Both functions
share the signature `(i32) => i32`, so the program is well-typed and the value is a plain
function reference once read.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the hole parameter (`print(fs[0](3))` in `main`) | runs, prints `4` | **yes** |
| the closure write (`flip`) | runs | **yes** |
| the list (`function callI(f) { f(3) }` takes `k`) | loud emit reject, `emitProgram: call to unknown function` | no |
| a `const j = k` between the cell and the list | runs, prints `4` | **yes** |

#### Grading list

The direct call `fs[0](3)`; the `const` alias spelling; the cell handed straight to the hole
parameter, which refuses with a different sentence and is likely the same missing pin path.
