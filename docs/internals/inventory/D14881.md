### D14881 — a hole lambda a function returns by name, called through the function's result, has no interned signature at emit

**loud emit reject · `vl check` rc 0 · clause 2 · `emitProgram: a function-value call has no interned signature — parameter 1 of type `` has no representation in the function-value ABI` · pre-existing, the same on master `484e98dd8` · found by the mono rung B position grid · filed 2026-11-01 against master `484e98dd8`**

Repro:

    const lam = (x) => x
    function mk() { return lam }
    const q = mk()
    print(q(3))

Want:

    3

#### Mechanism

`mk` takes no argument, so no call binds a hole of its own, and its inferred return is `lam`'s
open signature. The call through `q` reaches emit with that open parameter type, which has no
function-value ABI. A hole parameter carrying the same lambda (`fw(lam)`) is lowered through
mono's flow pin; a return carrying it is not.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `function lam(x) { return x }` (a declared function) | runs, prints `3` | **yes** (a lambda) |
| `function mk(): (x: i32) => i32` | runs | **yes** (the inferred return) |
| `print(mk()(3))` (called inline) | refuses the same | no |
| an extra direct `print(lam(5))` | refuses the same | no |
