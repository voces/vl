### D16373 — a value `if` whose arms are all i32-sized constants, at an i64 or f64 destination, emits invalid wasm

**closed · runs, prints `7` · was check-clean invalid wasm · `type mismatch: expected i32, found i64` · 8 of 46 reduced programs of the oracle's arithmetic fuzz (`scripts/oracle/gen.ts`) · found by the independent oracle · filed 2026-11-14 against master `de4cfa15f` · closed: a value join delivered to a destination its literal tails all adopt is built there with them, its `if` and `match` nodes typed with the literals (`numLitAdoptDeepJoin` → `numLitAdoptTails`, check_num_adopt.vl); a join with a typed tail keeps its own width and its literal tails with it · closed 2026-11-14 on master `4b94dbf0b` by lane N · fixture `literals/if-join-literal-arms-at-destination-width.vl`**

Repro:

    const c = true
    const y: i64 = if c { 7 } else { 9 }
    print(y)
    // vl check: rc 0.  vl run: invalid module, type mismatch: expected i32, found i64

Want:

    7

#### Mechanism

Both arms are constants, so the `if` takes its type from the destination (T2.4, D3054's join
rule), and the checker types it i64. The arms are emitted at their default i32 and nothing
widens the block's result, so the module stores an i32 where the binding's type is i64. One
arm too wide for i32 (`if c { 7 } else { 3000000000 }`) makes the arms themselves i64 and
runs, which is the shape the corpus pins (`tests/cases/literals/literal-tree-width-at-destination.vl`).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the i64 destination (`const y = if c { 7 } else { 9 }`) | prints `7` | **yes** |
| a narrow second arm (`else { 3000000000 }`) | prints `7` | **yes** |
| a typed arm (`else { v1 }`, `v1: i64`) | runs | **yes** |
| a function return as the destination (`function f(c: boolean): i64 { if c { 7 } else { 9 } }`) | prints `7` | no |
| a binding as the destination (an operator peer, `v1 + (if c { 1000 } else { 255 })`) | still invalid | no |
| an f64 destination (`const y: f64 = …`) | still invalid | no |
| an f32 destination with float arms | prints `0.5` | no |
| the condition (`if true`) | still invalid | no |

#### Grading list

The operator-peer spelling, and the f64 destination, from the ablation. A `match` whose arms are all
constants at an i64 destination. [D16371](D16371.md) may share the mechanism: there the constant
arm in parentheses is the one not adopted.
