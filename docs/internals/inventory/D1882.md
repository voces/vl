#### Mechanism

**The price [D1881](D1881.md) named, one position of its matrix.** Before that close the same
two cells were **check-clean invalid wasm** (`expected i32, found (ref $type)` at offset 411):
the box was passed raw into a cell the pin had typed as a scalar. The close makes the value's
rep honest at the delivery, and the monomorphizer then has to spell the hole's type — a
`V | null` over a value union — and refuses.

The ingredient is the parameter having NO annotation. Annotate it (`take(a: V | null)`) and
both cells RUN, so nothing about the box itself is unrepresentable here: what is missing is the
pin's ability to name `V | null` as an argument type, which is the same gap the `argument`
position hits for every value the pin cannot spell.

`early_return_guard` is the second cell only because the matrix builds it as a call to an
un-annotated `__guard(v)` — one mechanism, two positions.
