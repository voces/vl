#### Mechanism

The narrowing collectors key a fact on the tested operand's place, and an assignment has none,
so the test narrowed nothing. The tested value is the target's new value, so the fact belongs
to the target: `asgTestedPlace` (checker) and `asgTestedIdent` (emitter) hand the collectors the
bare name an assignment stores into, for the null tests in both senses and for `is`, and a
nullable struct's null test reads the assignment as its target cell (`exprNullableStruct`).
A field or cell target is not narrowed, since the emitter's place channels are not wired for
it; that program is refused as before.
