### D15284 — a list literal stored or pushed as an element of a list of lists built at a wider record is check-clean invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · open, target `7` · found closing [D15236](D15236.md) · filed 2026-11-04 against master `ee0b51d5`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const ys = [[mk()]]
    ys.push([{ f: 7 }])
    print(ys[1][0].f ?? 0)

Want:

    7

#### Mechanism

Not ablated past the table. `ys`'s inner lists are built at `J[]`. The push and store stamp
(`recLitSlotReceiver`, D15235) takes a list literal only spread into a push, whose elements it
holds; a list literal that IS the element reaches no stamp and is built at its own `{f: i32}[]`.
