### D15284 — a list literal stored or pushed as an element of a list of lists built at a wider record is check-clean invalid wasm

**closed 2026-11-04 · runs, prints `7` · was check-clean invalid wasm, `vl check` rc 0 · clause 1 · found closing [D15236](D15236.md) · filed 2026-11-04 against master `ee0b51d5` · closed by the push and store stamp (`recLitPlaceBuiltTy`) building a list literal that is itself the element at its receiver's inner-list build, read from the outer literal's rep stamp (`recElemOfElemStamp`, D15236, now through a binding of a binding), with the receiver walk shared by a direct and a spread element (`recSlotReceiverOf`) · fixture `tests/cases/soundness/record-list-literal-element-of-built-list-of-lists-runs.vl` · a list of lists SPREAD there is [D15285](D15285.md)**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const ys = [[mk()]]
    ys.push([{ f: 7 }])
    print(ys[1][0].f ?? 0)

Want:

    7

#### Mechanism

`ys`'s inner lists are built at `J[]`. The push and store stamp
(`recLitSlotReceiver`, D15235) takes a list literal only spread into a push, whose elements it
holds; a list literal that IS the element reaches no stamp and is built at its own `{f: i32}[]`.
