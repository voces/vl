### D15167 — a record whose list field is written a function of another result type, handed to an un-annotated parameter that calls the element, is refused at check

**closed · runs, prints `1.5` · was loud check reject, `cannot write 'half' to an element of 'r.xs'` · clause 2 · found closing [D15138](D15138.md): the read in the record's own scope runs · filed 2026-11-03 against master `d467911e` · closed 2026-11-03: the parameter read takes D15138's lift (`holeSlotWidenLift`, check_relate_core.vl), is judged again after the pass when its argument is bound after it (`holeSlotLateRun`), and the instance's call through the field is an elaboration mint fact (`elabMintParamRowFactAt`, emit_elab.vl) · fixture `tests/cases/closures/fn-record-field-list-read-by-param.vl`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function show(o) { print(o.xs[0](3)) }
    const r = { xs: [inc0] }
    r.xs[0] = half
    show(r)
    // Want: 1.5

#### Mechanism

`holeSlotJudge` (check_relate_core.vl) judges a read through a parameter one call argument at a time (`holeSlotArgJudge`), and that path does not take the lift D15138 gives a record whose field `elabFnFieldListTy` widened.

Three pieces were missing, each measured alone: the judge passed no lift for a parameter's
argument; the parameter's body was judged when its declaration was checked, before the argument's
`const` had recorded its widening; and with both, the instance's call reached no mint fact, so the
late fn-tag decision never ran and emit refused (`ref valtype with no interned shape`).
