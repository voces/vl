### D13900 — [CLOSED 2026-10-25] a `??` of an existing record and a wider fresh literal is typed as the existing record widened in place

**closed as `runs` · was check-clean invalid wasm · filed 2026-10-25 against master `de65aca55`**

Repro:

    function rd(a: {r: i32} | null) {
      const g1 = a ?? { r: 1.5 }
      print(g1.r)
    }
    rd({ r: 7 })
    rd(null)
    // now runs and prints 7 then 1.5

#### Mechanism

The checker types `a ?? { r: 1.5 }` as `{r: f64}`: it widens the existing record's field
type in place. Record covariance A (2026-09-29) never widens an existing record, and the
numeric join ruling (2026-09-30, `??` extension 2026-10-03) joins runtime numerics of
different types as a union. So the join is `{r: i32} | {r: f64}`, stored as a union box.
The emitter neither copies nor boxes; it builds the left operand at `{r: i32}` and the
literal at `f64`, and the module is invalid.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the left operand is a param (`h.p`, a field, or `src(true)`, a call result) | same invalid module; the call result also moves `src`'s return row and breaks another caller | no, any non-fresh operand |
| the literal's field is `7` (it adapts to i32) | runs | **yes** |

#### Grading list

The field spelling (`type H = { p: {r: i32} | null }`, `h.p ?? { r: 1.5 }`), and the call-result
spelling, where a second caller `function keep(): {r: i32} | null { src(true) }` must keep
its row. Step 5 of `architecture-target-2026-10.md` closes it by computing the join in the
checker.

#### Close

The checker types the join as `{r: i32} | {r: f64}` and the emitter stores it at that
type's rep, a union box; the emitter's merged-row minting is deleted. The param, field and
call-result spellings, with `keep()` keeping its row, are
`tests/cases/unions/coalesce-existing-record-wider-literal.vl`.
