### D1688 — an inferred anonymous struct return whose field is a union-box or nullable-ref element list is a shape the module never interns, while the annotated spelling runs

**closed 2026-09-06 by the anonymous mint's element key (see below) · filed 2026-09-06
against master `9203d73db` · surfaced while writing D1682's un-annotated fixture · 0 corpus
cells**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    function mk(v: Shape[]) { { xs: v } }
    function f() {
      const b: Shape[] = [{ r: 7 }]
      const sf = mk(b)
      print(sf.xs.length)
    }
    f()
    // vl check: rc 0.  vl run: prints 1 (was: emit error,
    // emitProgram: ref valtype with no interned shape)

#### Mechanism

Nothing here is covariant and nothing is written: `[{ r: 7 }]` is an un-annotated list literal
typed by its declared destination, so it is built at the union-box element row and no
converting copy is in question. What refuses is the anonymous struct `{ xs: Shape[] }` that
`mk`'s inferred return type is: no declaration in the program spells it, so the shape takes no
interned heap type and `fbValtype`'s bounds guard fires (D21's floor).

Three spellings rescue it, and all three give the shape a DECLARATION to be interned from:
annotating the return inline (`mk(v: Shape[]): { xs: Shape[] }`), annotating the binding
(`const sf: Box = mk(b)`), and — with no annotation at either end — merely declaring
`type Box = { xs: Shape[] }` somewhere in the program, which `mk` never spells. That last one
is the sharpest: the gap is the interner's population, not the return position.

The element rep decides. A plain struct element (`Circle[]`) and a bare union VALUE field
(`{ x: Shape }`) both run un-annotated; a union-box element list (`Shape[]`) and a
nullable-ref element list (`(Circle | null)[]`) both refuse. This is D1681's family one
position over — there an un-annotated `?.` binding of a ref list takes no ref-list row, here an
un-annotated anonymous struct takes no shape — and both end at the same message.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the inline return annotation added (`: { xs: Shape[] }`) | runs, prints 1 | **yes** — the rescue |
| `type Box = { xs: Shape[] }` declared but unspelled by `mk` | runs, prints 1 | **yes** — the shape is interned from the declaration |
| the union element (a `Circle[]` field) | runs, prints 1 | **yes** |
| a nullable-ref element (`(Circle \| null)[]`) instead | refuses identically | no (same family) |
| the parameter (the list built inside the literal) | refuses identically | no |
| the explicit `return` instead of a tail expression | refuses identically | no |
| the read (`print(1)` in place of `print(sf.xs.length)`) | refuses identically | no |
| the function (`const sf = { xs: b }` in `f`) | different refusal, `object literal matches no union variant` | — a different mechanism |

#### Grading list

Four cells: the repro at both faces (inline-annotated return runs, inferred refuses) and the
nullable-ref element at both. The controls that must keep running are the three rescues — the
inline annotation, the annotated binding, and the unspelled `type Box` — and
`tests/cases/unions/list-covariant-returned-container-inferred.vl`, whose declared `Box` is
there for this row and cites it. D1681 is the sibling: a fix that reaches the interner's
population should be re-graded against its witness too.
