### D1897 — a `(string | null)[]` argument pins its param as `string[]`, because the pin is read off a REP the two spellings share

**closed 2026-09-07 — the witness prints `1` · was `check-clean invalid wasm`,
`type mismatch: expected (ref $type), found (ref null $type)` in the module's top-level code
with `vl check` rc 0 · clause 1 · filed 2026-09-07 against master `11e35dc40` as the one element
type [D1896](D1896.md)'s close does not move · fixture
`tests/cases/generics/nulstring-list-pin-keeps-null.vl`**

Repro:

    function mkS(i: i32): string | null {
      if i == 0 { return null }
      "a"
    }
    function two<T>(xs: T[], t: T): i32 { return 1 }
    const rs = [mkS(1)]
    print(two(rs, mkS(2)))
    // vl run: 1

#### Mechanism

The same instance shape as [D1896](D1896.md) — one generic carrying both `T[]` and a bare `T`
— but the rung is one step earlier and is not a spelling round-trip. Printed at the pin,

    PROBE arg xs an2=string[] raw=string[] arena=(string|null)[] pinTy=(string|null)[]

the checker's recorded type and the pin's TYPE column both carry the `| null`; only the pin's
NAME loses it. `monoArgTyName`'s `exprStringArray` arm returns the literal `"string[]"`, and
`exprStringArray` is a REP classifier that rightly claims a nullable-string list, because
`(string | null)[]` and `string[]` are ONE wasm type. Two rungs below, the file already says
this about `boolean[]`: a pin is a NAME, not a rep. The close gives the string-list arm the
arena question its neighbours ask — `nodeTyArrayElemIsNullable`, then `monoAnnPinName` of the
render — so the binding keeps its `| null` and the instance's bare `T` is minted nullable.

**"Annotating either argument fixes it" was false, and the control that said so could not tell
the two apart.** Annotating the LIST genuinely fixed it: the instance minted
`(param $1 (ref null $2))`. Annotating `t` left the instance NON-NULL and bought validation
with a `ref.as_non_null` at the call — so `two(rs, t)` with `t = mkS(0)` was
`wasm trap: null reference`, a `runs → traps` cell that graded green only because every value
in the grid happened to be non-null.
