### D2834 — a returned generic if-join of a type parameter's list and a concrete list, at a record or nested-list pin, refuses at emit

**loud emit reject · clause 2 · the concrete spelling runs · the same on master `0eae57b89` · 16 cells of `uj/g2` (`ret_is` at a record or nested-list pin, or beside a record list, `if` form; two of them, `P[]` beside `Q[]`, refuse at the concrete spelling too) · filed 2026-09-27 against master `0eae57b89`, found grading D2832**

    type P = { a: i32 }

      return if no() { xs } else { ys }

#### Mechanism

Not ablated past the message. #3211 types the return set `P[] | string[]` at this pin and the
call reads the union, but the instance's tail `if` delivers its arms into that union through a
path that cannot place a record-list arm. At a nested-list pin (`T := i32[]`) the refusal is
`narrowed ref-array arm has no reflist slot` at the caller's `is` instead, which may be a second
mechanism.
