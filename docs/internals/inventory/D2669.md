### D2669 — a string append outside any loop, reached from a caller's loop, copies the whole string every call

**closed 2026-11-16 · runs, prints `308890` · was a cost row: quadratic, 40,000 calls 0.91–1.02 s on master, now 11–13 ms · fixed by lane AE4: a site outside any loop keeps its buffer and frontier in a pair of module globals minted while its body is emitted · a global appended from a helper goes from 5.9 s to 14 ms at 200,000 calls · exactness: the aliasing fixture `tests/cases/strings/accum-fn-site.vl`, and a 40-seed randomized mix of helper appends, prepends, snapshots, restores, recursion and shared strings agreeing with master line for line (10 seeds again at -O3) · found closing [D2625](D2625.md) · filed 2026-09-26 against master `ea661d2d7`**

Repro:

    import { toString } from "std:fmt"
    type B = { s: string }
    function add(o: B, k: i32) { o.s = o.s + " $t" + toString(k) }
    function build(nt: i32): string {
      const o: B = { s: "" }
      for k in 0 until nt { add(o, k) }
      return o.s
    }
    print(build(40000).length)

Want:

    308890

#### Mechanism

The site-cached append ([D2625](D2625.md)) keeps its buffer and frontier in two LOCALS of the
function holding the site, so they live one call: `add`'s cache is empty on every entry, which is
why a site outside a loop of its own function was not lowered that way at all. The fix keeps
such a site's pair in two module globals. They are minted while the body is emitted, as the
synthetic constants are, because the global section is framed after the bodies. So no typed
pre-pass is needed, despite the original note. DECISIONS.md, "String building is a LOWERING",
states the retention bound.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the helper (the append inside the loop) | linear | **yes** |
| the field (a module global `out = out + …` in the helper) | quadratic | no — the same gap |

#### Grading list

A helper appending to a module global (`function emit(x: string) { out = out + x }`), and to a
field of a parameter; plumb's `src/emit.vl` `indent(st)` is this shape (short strings, no cost today).
