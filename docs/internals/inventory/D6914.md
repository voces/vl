### D6914 — an inline list literal of an uncalled hole function, read for its length, is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same list bound and then measured runs, `1` ([D6830](D6830.md)) · found closing [D6881](D6881.md) · the same on master `43f22053c` · filed 2026-10-19 against master `43f22053c`**

Repro:

    function exclaim(s) { return s + "!" }
    print([exclaim].length)
    // vl check: rc 0.  vl run: emitProgram: cannot take the generic function `exclaim` as a value — a function value carries ONE signature

Want:

    1

#### Mechanism

From the ablation only. A list's `length` is admitted as an inert use only through a binding
initialized with the list; a `.length` read straight off the literal is not.
