### D4349 — an inferred return of a value union with a function arm is floored by the checker

**loud check reject · clause 2 · found grading D4347's matrix (`return_inferred`, both faces) · filed 2026-10-13 against the D3269 branch `2e409d121`**

Repro:

    function r(b: boolean) {
      if b { return (x: i32) => x + 1 }
      return "s"
    }
    const v = r(true)
    if v is (x: i32) => i32 { print(v(7)) } else { print(v) }
    // vl check: 'r' infers the union return type ((i32) => i32) | string — type-valid, but an inferred return of this shape is not yet supported by codegen; annotate the return type

#### Mechanism

Not localised. The checker's inferred-return floor admits no union with a function member;
the annotated return `((x: i32) => i32) | string` runs, so the lowering exists and only the
inferred spelling is refused. Forwarding a call (`function r() { return mk(1) }`) refuses the same way.
