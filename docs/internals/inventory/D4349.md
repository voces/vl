### D4349 — an inferred return of a value union with a function arm is floored by the checker

**closed 2026-10-13 · runs · was loud check reject, clause 2 · found grading D4347's matrix (`return_inferred`, both faces) · filed 2026-10-13 against the D3269 branch `2e409d121` · pins: `tests/cases/closures/fn-arm-union-inferred-return.vl`, `tests/cases/closures/nullable-closure-return-fallthrough.vl`**

Repro:

    function r(b: boolean) {
      if b { return (x: i32) => x + 1 }
      return "s"
    }
    const v = r(true)
    if v is (x: i32) => i32 { print(v(7)) } else { print(v) }
    // vl check: 'r' infers the union return type ((i32) => i32) | string — type-valid, but an inferred return of this shape is not yet supported by codegen; annotate the return type

Want:

    8

#### Mechanism

The checker's inferred-return floor (`typecheck.vl`, the `itt is TyUnion` arm) admitted a struct
union, a list union and a union over a type parameter, and floored every union with a function
member. The emitter had no pin for one either: a named function's un-annotated return was
recorded by `recordInferRet`'s cascade, which has no closure-arm rung for a named function, and
the nullable form `((x: i32) => i32) | null` passed the floor and died in the emitter as
`bare null needs a struct-typed context`.

Fix: `tyIsFnArmUnion` (a union with a function member, or a function type with `null`, no type
parameter) lifts the floor, and `synthNulListRetAnns` pins such a return to its own spelling
(`synthFnArmUnionRet`, registering the union as `collectU` does for the annotation), so it
lowers exactly as the annotated return. That annotated nullable-closure return itself trapped
when its body fell off the end, since `fnRetNullBearing` did not answer for `nulCloFlag`; it now
does, which closes [D2499](D2499.md), [D2645](D2645.md), [D2647](D2647.md), [D3973](D3973.md) and
[D3974](D3974.md) with this row. Matrices `fn-arm-union-call-result` (and its generic
twin) and `alias-fn-arm-union-is` went 62 → 64 of 64, the remaining `return_inferred` cells.
