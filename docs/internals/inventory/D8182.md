### D8182 — `v is i32` is true when an un-annotated or generic parameter is bound at `null`

**check-clean silently wrong · clause 1 · found closing [D8122](D8122.md) · the same on master `da93ef793` · filed 2026-10-20 against master `da93ef793`**

Repro:

    function t(v) {
      if v is i32 { print(0) } else { print(1) }
    }
    t(null)
    // vl check: rc 0.  vl run: prints 0

Want:

    1

#### Mechanism

Not traced. Bare `null` and `i32` may share a representation at the instance, and the test
may read the representation rather than the type.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `v is f64` or `v is boolean` | prints `1` | **yes**, `i32` |
| `const n: i32 \| null = null; t(n)` | prints `1` | **yes**, bare `null` |
| `function t<T>(v: T)` | prints `0` | no |
| `v: null` annotated | check reject, `is` can never match | **yes**, the instance |
| a second call `t(4)` | prints `0` twice | no |

#### Grading list

The generic spelling `function t<T>(v: T)`.
