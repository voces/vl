Repro:

    function half(a) { return a + 2 }
    function run(m: {[string]: (a: i32) => f64}) {
      const g = m.get("b")
      if g != null { print(g(3)) }
    }

    m.set("b", half)
    run(m)
    // vl check: refuses at `run(m)`, "a map is passed as the same storage, so the function type it
    // holds must match exactly"

#### Mechanism

`monoStoredSlotFnTy` (emit_mono.vl) instances a slot's functions at the slot's delivered type,
except where every value agrees on another result: then the slot keeps the values' own type,
`(i32) => i32`, relying on check to refuse a write of the delivered type. Check refuses the
container's delivery at a wider function only for a record holder: `fvaHeldHoleFnDiffers`,
[D15198](D15198.md)'s judge, is gated on `recordHolder`, and it has no map arm. So the map is built
at one map struct and the parameter reads another; the list's arrays share one shape, so it
validates and the call traps. The callee could write a function of the wider result into the
shared container, which its own readers call at the narrower one, so the delivery is refused at
check, as for a list annotated at the narrower type. The annotated twin (`half(a: i32): i32`) is refused at check with
`fvaRefuseNested`'s sentence.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| a list (`const m = [half]`, parameter `((a: i32) => f64)[]`) | trap after load | no: the list is the same defect |
| the parameter `readonly ((a: i32) => f64)[]` | runs, prints `5` (#6042's converting copy) | **yes** (a mutable destination) |
| the container delivered inline (`run([half])`) | runs, prints `5` | **yes** (a bound container) |
| the function delivered bare (`run(half)`, parameter `(a: i32) => f64`) | runs, prints `5` | **yes** (a container) |
| the annotated binding instead of a parameter (`const r: {[string]: (a: i32) => f64} = m`) | invalid module | no |
| the record spelling (`{ f: half }` at `{ f: (a: i32) => f64 }`) | loud check reject, [D15198](D15198.md)'s sentence | n/a (the twin) |
| `half` annotated (`a: i32): i32`) | loud check reject, `fvaRefuseNested` | n/a (the twin) |

#### Grading list

The map and list spellings above, at a parameter and at an annotated binding; the `readonly` and
inline spellings, which run and must keep running; [D16715](D16715.md)'s own witness.
