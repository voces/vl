### D15252 — `is` has no one relation: the checker's narrowing and mono's static answer each decide it their own way

**runs today and must keep running · design row for [D15250](D15250.md)'s `monoStaticIsResult` half · filed 2026-11-04 against master `891fb463` by lane column-G1**

Repro:

    type A = { v: i32 }
    type B = { v: i32, s: string }
    function F(z) {
      if z.h is A { print(z.h.v) } else { print(z.h.s) }
    }
    F({ h: { v: 4, s: "bee" } })
    // vl run: bee

#### Mechanism

The checker narrows an `is` per kind (`collectThenNarrows` / `collectElseNarrows`,
`compiler/check_narrow_flow.vl`): a literal-set meet, a record fit meet, a covering union, a fit
across tags. Mono's static answer (`monoStaticIsResult`, `compiler/wasmEmit.vl`) re-decides the
same question from spellings: the pin's name against the pattern text, its render, a name-keyed
row match. Neither is the checker's `assignable`: an `i32` is assignable to `f64`, but a value at
an `f64` pin never `is i32`, and a `B` that fits `A` takes its own arm (D3235, the witness).

#### Design: `isTestAnswer(operandTy, testTy)` → 1 always, 0 never, -1 the stored value decides

The operand is flattened into its members (`flattenVariantsInto`). The answer is 1 when every
member answers 1, 0 when every member answers 0, and -1 otherwise. A member `m` against `t`,
first rule that applies:

| # | rule | answer | source |
| --- | --- | --- | --- |
| R1 | `m` or `t` is open (a type parameter or a hole) | -1 | the instance answers at its pin (`exactOperandTyOf`, D2753) |
| R2 | `t` covers `m` (`tyUnionCovers`), or the two are one set (`tySameSet`, or a `Set` and its boolean map, `mapTwinSame`) | 1 | `collectThenNarrows` D3360; `monoStaticIsResult` D2753; D2673 |
| R3 | `null`: `m` is `null` and `t` holds `null` | 1; the other null pairings 0 | `collectElseNarrows`' null face (D1243) |
| R4 | literal or literal set on either side: `litSetMeetTy(m, t)` is `m` | 1; no meet and no shared base 0; a partial meet or a base scalar (`litBaseMeetTy`) -1 | `checkIsExprNode` D2205, D3522; `litIsPinNever` D15251 |
| R5 | scalars: one primitive rep | 1 (same rep), 0 (different rep: `i32`/`i64`/`f32`/`f64`/`boolean`/`string` never widen at `is`) | the exact-instance rung (`tySameSpelled`) |
| R6 | records: own type first. A different field-name signature (`objSigSame` both ways) | 0 (D3235: a `B` with more fields is not an `A`) | `recArmFitKind`'s first test, D3235 |
| R7 | records, one signature: `recArmFitKind(t, m)` | 1, 0, or 2 → -1 | D4056, D8300 |
| R8 | a record fitting across tags (`recIsFitsAcrossTags`) or a list across reps (`listIsFitsAcrossReps`) | -1 | `collectThenNarrows` |
| R9 | lists and maps: element and value types by R1-R8 | as the element's answer | `isWholeOfOneListUnion` D6770 |
| R10 | functions: one signature (`tySame`) | 1; otherwise 0 | the sigkey arm D951 |
| R11 | anything else | -1 | |

#### Plan

   deleted. The nine rows above become fixtures, and none of the 38 programs an earlier,
