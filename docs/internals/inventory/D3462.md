#### Mechanism

A literal of N elements that each allocate (a record, a nested list, a boxed union member, a
closure, a string) lowered as ONE `array.new_fixed` over N operands up to the 10,000-operand cap.
Every operand is a GC allocation, so Cranelift sees N safepoints, each with every earlier operand
live on the stack, and its compile of that function grows like N^2.6 in time and N^2 in memory:
records at 1,000 / 2,000 / 4,000 ran 3.5 s / 25 s / 107 s and a 12,345-record literal ran past
300 s, all of it the engine compiling the module (`vl build`, which only validates, took 0.04 s
to 0.4 s). A string or ref literal longer than 256 elements now builds in chunks of 256 (the
`array.new_default` + `array.new_fixed` + `array.copy` form a literal past the cap already used,
`ALLOC_LIT_CHUNK` in compiler/wasmEmit.vl), except as a global's constant initializer, which
cannot chunk through locals and keeps the one `array.new_fixed` within the cap (`gConstExprEmit`).

#### Ablation

`VL_NO_CACHE=1`, box load 8 to 40, so wall times are indicative; a scalar literal of the same
length ran in under a second either way.

| witness | master | after |
| --- | --- | --- |
| 4,000 records, `vl run` | 106.7 s, 737 MB | 1.6 s, 236 MB |
| 12,345 records `{ a, b: f64 }`, `vl run` | past 300 s, 4.4 GB | 5.6 s, 863 MB |
| 4,000 two-element nested lists | 5.9 s, 1.37 GB | 1.9 s, 419 MB |
| 256 records (one chunk) | 0.09 s | unchanged, one `array.new_fixed` |

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| elements are scalar literals | fast at any length | **yes**, an allocating element |
| the literal is a global's constant initializer (`const xs = [{ a: 1 }, …]`, every field a literal) | built once at instantiation, not compiled as a body; keeps one `array.new_fixed` | **yes**, a body or the start function |

#### Grading list

Every ref and string list kind past 256 elements, in a body and at top level, against master's
output: records, declared structs, nullable records with `null`s, nested `i32`/`string`/`f64`
lists, `(i32 | string)[]`, closures, maps, `(string | null)[]`, a variant union (13 kinds, all
identical). A global constant-initializer literal of strings (4,000 elements, 1 to 3 s) still
builds as one `array.new_fixed`.
