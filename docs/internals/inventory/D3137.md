### D3137 — a list annotated with an inline union spelled `null` first, over two other members, has no element rep

**loud emit reject · open · clause 2 · found by the #3279 review's grids (`gL/*_w7_*`, `gN/*_w3_*`: 29 cells) re-graded by lane NC · the same on master `07d414042` · filed 2026-09-29 against master `07d414042`**

Repro:

    type K = "a" | "b"
    const zz: (null | K | i32)[] = ["a", null, 3]
    print(zz.length)
    // vl check: rc 0.  vl run: emitProgram: a nullable-K|i32 list element has no rep; use a
    // non-null element type

Want:

    3

#### Mechanism

Not localised past the ablation. The element spelling is order-sensitive: the same member set
spelled `K | null | i32`, or through an alias, runs. The refusal renders the element as
`nullable-K|i32`, so the `null`-first spelling is peeled as a nullable over a two-member union
instead of being read as the registered three-member box. This is the list-element position of
the reordering [D3099](D3099.md) fixed for a binding's annotation (`annAdoptRegisteredName`).
