### D10151 — a written list of a generic handed back by an un-annotated function into a closed binding is typed by an unrelated call of the generic

**loud check reject · `push: cannot add (i32) => i32 to ((string) => string)[] (the body of `id` at the call's argument types)` · clause 2 · CAPABILITY: without the last line it prints `3` · found closing [D10121](D10121.md) · present on master `17b0be5a8` · filed 2026-10-22 against master `17b0be5a8`**

Repro:

    function id<T>(x: T): T { x }
    function inc(x: i32): i32 { x + 1 }
    const ys = [id]
    ys.push(inc)
    function deliver() { return ys }
    const v: ((x: i32) => i32)[] = deliver()
    print(v[1](2))
    print(id("s"))
    // vl check: push: cannot add (i32) => i32 to ((string) => string)[] (the body of `id` at the call's argument types)

Want:

    3
    s

#### Mechanism

[D10020](D10020.md)'s, at a delivery into a binding. The push row is re-validated at
`id("s")` unless every read of `ys` is one `ctnReadsKept` (check_decl_scan.vl) enumerates,
and neither `return ys` nor `const v: ((x: i32) => i32)[] = ys` is one of them, though the
binding's closed element type is what every call through `v` instances at.
