### D6830 — a hole function taken as a value and never called is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same alias called once, an annotated parameter, or a declared type parameter runs · found closing [D6792](D6792.md) · filed 2026-10-18 against master `608df323a`**

Repro:

    function apply3(g) { print(g(1, 2)) }
    const h = apply3
    print(1)
    // vl check: rc 0.  vl run: emitProgram: call to unknown function

Want:

    1

#### Mechanism

From the ablation only. A hole function is instanced at the types its calls hand it; taken as a
value with no call, it is emitted from its un-instanced template, where the call on its hole
parameter names no function.
