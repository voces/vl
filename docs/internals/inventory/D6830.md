### D6830 — a hole function taken as a value and never called is refused at emit

**closed 2026-10-18 by lane L1 · runs, prints `1` · was loud emit reject · clause 2 · CAPABILITY: the same alias called once, an annotated parameter, or a declared type parameter runs; a value nothing calls is served by the stub an uncalled `<T>` generic already gets, and every use the emitter admits for it is inert (a write, `.length`, a cold record field, an alias whose own uses are inert), so the stub's signature cannot be observed, as D4551 asks of a default; a comparison, a return or a call argument still refuses ([D6881](D6881.md), [D6882](D6882.md)) · pins: `tests/cases/closures/uncalled-hole-fn-value.vl`, `tests/cases/closures/list-of-uncalled-hole-fn.vl` (was the `error-` fixture), `tests/cases/functions/generic-alias-never-called.vl` and, for the `<T>` twin, `tests/cases/generics/uncalled-generic-fn-value-through-alias.vl` · found closing [D6792](D6792.md) · filed 2026-10-18 against master `608df323a`**

Repro:

    function apply3(g) { print(g(1, 2)) }
    const h = apply3
    print(1)
    // vl check: rc 0.  vl run: emitProgram: call to unknown function

Want:

#### Mechanism

From the ablation only. A hole function is instanced at the types its calls hand it; taken as a
value with no call, it is emitted from its un-instanced template, where the call on its hole
parameter names no function.
