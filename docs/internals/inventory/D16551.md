### D16551 — a read of a re-pointed generic `let` handed to a builtin method keeps every function written to it

**closed 2026-11-15 · runs, prints `true` · was loud check reject (`cannot assign (V) => void to (boolean) => void`), clause 2 · fixed in `cwArgDstAnn` (`check_write_scan.vl`) and `letWritesStraightOnce` (`check_narrow_flow.vl`): a `.push` argument's element or a `.set` argument's value, on a receiver annotated with one closed function type, takes the narrowed read, the receiver's annotation resolved even when it is declared after the asking write · fixture `tests/cases/functions/let-of-generic-repointed-read-handed-to-method.vl` · bucket (f), a local fix · the method-argument face of [D16182](D16182.md) · filed 2026-11-15 against master `d534d4226`**

Repro:

    function inner<U>(u: U) { print(u) }
    function plus<V>(v: V) { print(v + 1) }
    function main() {
      let k = plus
      k = inner
      const fs: ((b: boolean) => void)[] = []
      fs.push(k)
      fs[0](true)
    }
    main()
    // vl check: cannot assign (V) => void to (boolean) => void

Want:

    true

#### Mechanism

D16182's close narrows a read handed to a call only where the callee is a function declaration
whose parameter is one function type with no type parameter (`cwArgToClosedFnParam`, check_write_scan). A builtin
method has no declaration to read a parameter off, so the binding keeps its whole set and `plus`
is asked at `boolean`. The cells are `array_push` and `map_set` of
`fn-let-read-after-repoint-generic.matrix.vl`.

#### Closed

The scan reports each handed read's destination annotation and the part of it stored
(`cwArgDstAnn`: a parameter, a `.push` receiver's element, a `.set` receiver's value). The rule is
decided at the binding's first write, which may precede the receiver's declaration, so
`check_narrow_flow` reads each annotation's recorded type or resolves its spelling quietly
(`annTyNow`) before it asks for one closed function type. An un-annotated `Map()` receiver is an open destination and keeps
the whole set, as [D16552](D16552.md)'s open parameter does.
