#### Mechanism

`std:test` fills `CallerLoc` from `__callsite__`, whose column is a UTF-8 byte offset, and
appends it as `at <file>:<line>:<col>`. The extension parsed that column and handed it to
`new Position(line, col - 1)`, which VS Code reads in UTF-16 code units. On a line with a
non-ASCII character before the matcher, the failure marker sat right of the matcher by the
byte excess: `  expect("é€😀").toEqual("x")` reports column 23 where `toEqual` starts at
UTF-16 column 18 (1-based). The gradeable witness is the test file; the program above only
shows the text the column is counted over.
