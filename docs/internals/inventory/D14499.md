### D14499 — a store into a declared place from a read of an open list element, checked before the store that decides the element, is graded against the pinned element

**runs today and must keep running, prints `0.375` · refutation pin for D14497's ruling: a store into a place whose type is declared is a read consumed in place, not a binding · was a compiler trap (`tyAt` on `-1` in `checkAssignStore`) on master `67905160e` · filed 2026-10-27**

Repro:

    function g() {
      let a = __array_new_default__(3)
      let y = 0.0
      y = a[0]
      a[0] = 1.5
      print(y / 4 + a[0] / 4)
    }
    g()

Want:

    0.375

#### Mechanism

`y = a[0]` is checked before `a[0] = 1.5` pins the element. The store is checked against `y`'s
storage type, and the destination is kept beside the store (`oerAsgDst`), so
`resolveOpenElemReads` grades the pinned element against it once the pin is known. Before, the
store read the open element's `-1` as a type and the checker trapped.

#### Ablation

| `let y = 0.0` → `let y = a[0]` | loud check reject (D14497's ruling) | the binding is the refused spelling |
