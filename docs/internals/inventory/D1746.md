### D1746 — an INFERRED union join registers no variant members, so the arena rung and the name ladder answer a nullable arm differently

**closed 2026-09-06 · was a loud emit reject, and check-clean invalid wasm before D1721 ·
D1721's residue · 0 corpus cells**

Repro:

    type A = { r: i32 }
    function mkA(): A | null { return null }
    function mkS(): string | null { return null }
    const v = mkS()
    const w = v ?? mkA()
    if w is string { print(w) } else { print(0) }
    // prints 0

#### Mechanism

`cVariantMemberTyIxs` is the checker's nominal sidecar for "this struct is a union ARM", and
it is filled by the DECLARATION route and by the annotation route (`annRegisterVariantMembers`
exists because the emitter's `uVariants` is fed by both spellings while the registry was not).
An INFERRED join is the third spelling: `registerInferLetMixedUnion` mints its row in
`uVariants`, and no annotation names it, so its members were never registered.

The two readers then answer from different columns. Measured 2026-09-06, one `emitFail` at the
box arm on the row's own witness:

    callee=mkA fe=0 fRetKind=[nulvariant] cloRetValKind=[nulstruct] cloRetValSlot=0
    retAnn=[A|null] retNulVarFlag=1 nulVariantIndexOf=0 base=[A] variantIndexOf=0
    structIndexOfTypeName=-1 exprNulVariant=1 nulVariantIdxOfExpr=-1

`exprNullableVariant` reads `fRetKind`, seeded from the name ladder, which asks
`variantIndexOf("A")` — the emitter's table, where the mint put the arm. `nulVariantIdxOfExpr`
reads `cloRetValKind`, which is `vtKindOfType`, whose arena-first rung (`annRepKindOf` →
`repOfNullable`) declines for a variant member and otherwise answers `nulstruct`. That guard is
right and its input was incomplete: nominality is not in the arena, so the rung can only read
the checker's set. The registration is the fix, not a second comparator — with the members
registered, `repOfNullable` declines, the name ladder owns the kind, and the pair agrees.
