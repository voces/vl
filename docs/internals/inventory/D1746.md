#### Mechanism

D1721's close makes the join `string | A | null` name its registered row, so `??` takes
`emitCoalesceNulRefJoin` and hands the default to `emitUnionBoxArg`. The default is itself a
nullable niche, which `emitUnionBoxNulNiche` boxes by parking it and testing null — but only
once `coalNicheBoxTag` resolves the arm. For a nullable VARIANT it does not: `exprNullableVariant`
answers true off `fRetKind`, while `nulVariantIdxOfExpr`'s Call arm reads `cloRetValKind`, and
the two disagree, so the heap is -1 and the tag lookup declines. The value then falls to the
value-atom ladder, which classifies a niche as no atom at all and asks for the `i32` value box
a struct-bearing union never mints. A kind without its companion column, one table over.

Measured 2026-09-06, one `emitFail` in the box arm: `un=[string|A|null] heap=-1 nulvar=-1
nulstruct=0` — the struct table answers where the variant table does not, and its row is a
layout twin of the arm, not the arm's own heap.
