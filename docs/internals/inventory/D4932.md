### D4932 — a structurally spelled `{ x: i32 }[] | i32[]` return delivered into an anonymous object's field matches no array arm

**loud emit reject · clause 2 · found closing D4930 · the same on master `bb21e081b` · filed 2026-10-15**

Repro:

    type P = { x: i32 }
    function wrapA(t: { x: i32 }): { x: i32 }[] | i32[] { [t] }
    const o = { f: wrapA({ x: 4 }) }
    const g = o.f
    if g is P[] { for e in g { print(e.x) } } else { print("N") }
    // vl check: rc 0.  vl run: emitProgram: array value does not match any array member of the union (leaf-scalar widening across a nested array is unsupported)

Want:

    4

#### Mechanism

Not localised past the ablation. The refusal is at the return `[t]` (2:10), and only when the
function's result is also delivered into an object field, so the field's delivery changes
which union the return is boxed into. D4930's row sharing runs only after monomorphization and
does not reach a non-generic function; whether the same aliasing closes this is untested.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the object field (`const g = wrapA({ x: 4 })`) | runs, prints `4` | **yes** |
| the structural spelling (`t: P`, `: P[] \| i32[]`) | runs, prints `4` | **yes** |
