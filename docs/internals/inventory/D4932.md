### D4932 — a structurally spelled `{ x: i32 }[] | i32[]` return delivered into an anonymous object's field matches no array arm

**closed · was a loud emit reject (`emitProgram: array value does not match any array member of the union`), the same on master `bb21e081b` · fixture `tests/cases/unions/shape-list-union-return-into-field.vl` · filed 2026-10-15**

Repro:

    type P = { x: i32 }
    function wrapA(t: { x: i32 }): { x: i32 }[] | i32[] { [t] }
    const o = { f: wrapA({ x: 4 }) }
    const g = o.f
    if g is P[] { for e in g { print(e.x) } } else { print("N") }
    // vl check: rc 0.  vl run: emitProgram: array value does not match any array member of the union (leaf-scalar widening across a nested array is unsupported)

Want:

    4

#### Mechanism

The field's delivery interned the union's record arm by its shape spelling `{x:i32}`, a ref-list
slot of its own, while `[t]` is built under the declared `P`'s slot, so the return's array
matched neither arm. Closed in `emit_classify.vl`'s `rlInternNameTy`: a record spelled by shape
that exactly one declaration has (`rlDeclTwinTy`, `nominalStructSoleOfTy`) interns as that
declaration, so the two spellings of one
type share one slot. The same mint is D4966's.
