#### Mechanism

D15568's witness with the two parameters bound to different generics. The list's element is the set
`{id, id2}`; D15568's close takes the list as a holder only when the instance binds both parameters
to one set, so here neither parameter's set is noted at the calls through `xs[0]` and no instance of
either generic is fixed. The close is the step-4 join: a call through the set dispatches by tag, each
member instanced at the call's argument types.
