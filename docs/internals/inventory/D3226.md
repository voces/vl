### D3226 — a float literal handed through a hole to an `f32` parameter reaches it as an `f64`

**check-clean invalid wasm · clause 1 · the one cell of lane BI's scalar grid where the hole column still disagrees with the direct call after D3225 · the same on master `94670f728` · filed 2026-09-29 against master `94670f728`**

Repro:

    function H(h, v) {
      return h(v)
    }
    print(H((x: f32) => x, 1.5))
    // vl check: rc 0.  vl run: invalid module inside `H`: type mismatch

Want:

    1.5

#### Mechanism

Not localised past the ablation. The direct call `((x: f32) => x)(1.5)` adopts the literal at
`f32`; through the hole, `v` is pinned at the literal's own `f64` and nothing converts it
where it meets `h`'s `f32` parameter. The same shape as D3171 (a literal typed by its
context, transitively), at a float width rather than a literal union.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |

| `const d: f64 = 1.5`, passed | check reject (D3225) | **yes** (the literal) |
| `3`, an integer literal | prints `3` | **yes** (the float literal) |
| `(x: f64)` | prints `1.5` | **yes** (the `f32` parameter) |
