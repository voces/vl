### D4124 — an element of a list of a generic function, read as a value instead of called, refuses at emit

**loud emit reject · clause 2: `vl check` is clean · found by lane SC while grading a matrix of generic functions written into list elements · filed 2026-10-11 against master `8411b89d5`**

Repro:

    function inner<U>(u: U) { print(u) }
    const fs = [inner]
    const k = fs[0]
    k(3)
    // vl check: rc 0.  vl run: emitProgram: a function-value call has no interned signature — parameter 1 of type `` has no representation in the function-value ABI

Want:

    3

#### Mechanism

From the ablation only. A call written directly through the element, `fs[0](3)`, instances
`inner` at `i32`. A binding of the element carries the generic function type to a call that
nothing instances. The refusal is the same sentence as [D4120](D4120.md)'s. That is a message
match, not a shared mechanism.
