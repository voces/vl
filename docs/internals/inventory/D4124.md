#### Mechanism

From the ablation only. A call written directly through the element, `fs[0](3)`, instances
`inner` at `i32`. A binding of the element carries the generic function type to a call that
nothing instances. The refusal is the one [D4123](D4123.md) added for a value of a generic
function no call instances.
