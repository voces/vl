#### Mechanism

A prediction until a close confirms it. `emitCoalesceNulBoolJoin` refuses when
`unionHasAtomTy(joinSet, "boolean")` is false or the `i32` value box is unreserved. At an
element position the result union is named off the list's element row, which carries no
boolean arm (or no value box was reserved for it), so the refusal fires on a legal program.
