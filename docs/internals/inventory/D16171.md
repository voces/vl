### D16171 — an inferred union return of a list of maps or sets beside a scalar floors at check, while the map list's annotated twin runs

**loud check reject · clause 2 · `` 'pick' infers the union return type {[i32]: i32}[] | i32 — type-valid, but an inferred return of this shape is not yet supported by codegen; annotate the return type `` · found closing D16047 (lane F) · filed 2026-11-14 against master `a1e5fe53d`**

Repro:

    function pick(c: boolean) {
      if c {
        const m: {[i32]: i32} = Map()
        return [m]
      }
      return 1
    }
    print(pick(true) is {[i32]: i32}[])

Want:

    true

#### Mechanism

`inferRetFloorUnsupported` (check_inferred_return.vl) admits a `TyUnion` return only when a
recorder names it (`valueUnionRetName`, `mapUnionRetName`, `structUnionRetName`) or it is all lists
or has a function arm. A list of maps or sets beside a scalar is none of those, so it floors, though
the emitter lowers the annotated `: {[i32]: i32}[] | i32` spelling. D16047's settled shapes
(`[Map()]` or `[Set()]` beside `1`) reach the same floor once their elements settle.

#### Ablation

| spelling | outcome |
| --- | --- |
| this repro | loud check reject |
| `: {[i32]: i32}[] \| i32` written on `pick` | runs, `true` |
| `Set<i32>` elements in place of the map | the same refusal; the annotated twin is D16172 |
| `[Map()]` beside `1`, no annotation (D16047's settled shape) | the same refusal, naming `{[i32]: i32}[] \| i32` |
