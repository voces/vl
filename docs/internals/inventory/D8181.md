### D8181 — an un-annotated parameter two calls bind apart, one at `i32 | "a" | "b" | null`, builds invalid wasm in its body

**check-clean invalid wasm · clause 1 · found closing [D8123](D8123.md) · the same on master `da93ef793` · filed 2026-10-20 against master `da93ef793`**

Repro:

    function take(v) {
      if v is i32 { print(0) } else { print(v) }
    }
    const r: i32 | "a" | "b" | null = "a"
    take(r)
    take(7)
    // vl check: rc 0.  vl run: invalid module inside `take`, expected (ref $N) string, found (ref $M) union box

Want:

    a
    0

#### Mechanism

The two calls pin the hole apart, so the body is compiled per hole instance. The instance's
binding for `v` renders the inline literal members as `string`, so the read after `is i32` is
`string | null` rather than `"a" | "b" | null`. The print takes the box for a nullable
string. The binding is made in `emit_mono.vl`, outside lane L6.
