### D8020 — an unused record type of a literal's exact field set still stops a literal-building call widening when it passes through a type parameter

**closed · was a loud check reject · clause 2 · the same program printed `15` once the unused `type Col` was deleted · the literal-argument face is [D7941](D7941.md) · filed 2026-10-20 against master `981320f30` · closed 2026-10-20 by lane L1**

Repro:

    type Col = { r: i32, g: i32, b: i32 }
    type J = { r: i32 | null, g: i32, b: i32 }
    function idn<T>(v: T): T { v }
    function mk() { { r: 15, g: 1, b: 2 } }
    const m: J = idn(mk())
    print(m.r ?? 0)
    // master: {r: i32, g: i32, b: i32} is not J: they store field `r` differently ... only a fresh record widens

Want:

    15

#### Mechanism

`mk`'s literal was built at `Col`'s row because `Col` spells its field set, so the call was
refused as an existing record (`recBuiltAtDeclared`). Closed in two halves. In the checker,
`recAdoptNote`'s pass-through branch (check_fit_rules.vl) builds the call at the record it lands
on when that argument alone pins the instance and the destination is a record, not a union
member; `recFnBuiltAtDst` also follows a returned identity call over the same function, for the
inferred-return position. In the emitter, `monoRebuiltLitRetName` (emit_mono.vl) names the
identity's instance by the row the function's literals were rebuilt at, not by the checked
result. Without that rung the instance was shared with a `Col` delivery and was invalid wasm.

The `generic-identity-fresh-call-beside-declared-row` matrix goes from 28 to 58 of 64 cells
running, with 0 silent and 0 runs→not-runs. The 6 that still refuse each call `mk` twice; that
shape refuses with no type parameter too, and is [D8201](D8201.md). A second identity level
inside the function is [D8202](D8202.md). Both keep the literal half of [D7800](D7800.md)'s
`ambient` guard load-bearing.

#### Ablation

| change | outcome | needed? |
| --- | --- | --- |
| delete `type Col` | prints `15` | **yes** |
| deliver directly, `const m: J = mk()` | prints `15` | **yes**, the type parameter |
| `function mk(): J` | prints `15` | **yes**, the inferred result |
| `mk` called a second time into an un-annotated binding, `Col` deleted | prints `15` | no |
