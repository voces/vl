### D3911 — an outer parameter named like a function declared deeper, called from a frame nested below that declaration, refuses `captured variable not found`

**loud emit reject · found reviewing #3480/#3481 · filed 2026-10-09 against master `097937914`**

Repro:

    function a(f: i32) {
      function b() {
        function f(y: i32) { print(y) }
        function c() { f(9) }
        c()
      }
      b()
      print(f)
    }
    a(10)
    // vl check: rc 0.  vl run: emit error at 2:12, `captured variable not found in enclosing frame`

Want:

    9
    10

#### Mechanism

Not located. The refusal is positioned on `b`. Calling `f(9)` from `c`, a frame below `f`'s
declaration, is what triggers it; calling `f(9)` directly in `b` runs. The outer parameter `f`
is needed, so the lookup for the capture appears to meet `a`'s `f` by name rather than `b`'s own
function.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `c` (call `f(9)` directly in `b`) | runs, prints `9` then `10` | **yes** |
| the outer parameter renamed (`g`) | runs, prints `9` then `10` | **yes** |
| the final `print(f)` in `a` | still refuses | no |

#### Grading list

The outer name as a `const` rather than a parameter, a generic `f`, and D3910 (the opposite
direction of the same name collision).
