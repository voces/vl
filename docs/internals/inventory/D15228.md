#### Mechanism

A list literal's element type joins its elements' function sets only for a bare function or a list of them (`elabFnJoinTy`, `elabFnJoinListTy`), not through a record, so the literal is typed at its first element's set; a binding of it is widened by `letLitListsWidenAt`, a returned one by nothing, and the recorded row join sees two element signatures.
