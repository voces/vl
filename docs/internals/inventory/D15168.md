### D15168 — a nested record's list field written a function of another result type is refused at check

**loud check reject · `cannot write 'half' to an element of 'r.inner.xs'` · clause 2 · open, target `1.5` · found closing [D15138](D15138.md): a field of the binding's own record literal runs · filed 2026-11-03 against master `d467911e`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const r = { inner: { xs: [inc0] } }
    r.inner.xs[0] = half
    print(r.inner.xs[0](3))
    // Want: 1.5

#### Mechanism

`letFieldListsWiden` (check_statements.vl) widens only a list field of the record literal the binding is initialised by, one level down.
