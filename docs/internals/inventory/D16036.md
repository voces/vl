### D16036 — a standalone `?.` whose leaf field is a function value has no rep

**loud emit reject · clause 2 · ``emitProgram: a standalone `?.` has no rep for a closure leaf field`` · split from [D1680](D1680.md), whose sentence named the map and closure leaves together · filed 2026-11-13 against master `f11a3e11`**

Repro:

    type B = { y: () => i32 }
    function mk(): B | null { { y: () => 3 } }
    const v = mk()?.y
    if v != null { print(v()) } else { print(-1) }

Want:

    3

#### Mechanism

Not traced past the site. `emitOptMemberValueGo` (compiler/wasmEmit.vl) has an arm for every
leaf rep but a function value. The nullable closure rep (`nulclosure`) exists for a binding, so
the open question is whether a function field's closure struct can serve as the niche directly,
as a record or map field does.
