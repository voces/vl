### D16036 — a standalone `?.` whose leaf field is a function value has no rep

**closed 2026-11-13 · runs, prints `3` · a standalone `?.` function-value leaf is the closure fat pointer's own nullable ref, the list arm's shape over `cloStructIdx` · was loud emit reject · clause 2 · split from [D1680](D1680.md), whose sentence named the map and closure leaves together · filed 2026-11-13 against master `f11a3e11`**

Repro:

    type B = { y: () => i32 }
    function mk(): B | null { { y: () => 3 } }
    const v = mk()?.y
    if v != null { print(v()) } else { print(-1) }

Want:

    3

#### Mechanism

`emitOptMemberValueGo` (compiler/wasmEmit.vl) had an arm for every leaf rep but a function value.
A closure cell, nullable or not, is `(ref null $clo)` over the one closure struct
(`cloStructIdx`). So the close is the list arm's shape over that heap: a null chain yields
`ref.null $clo`, and a live one reads the field. `?.f ?? (() => d)` is [D3373](D3373.md)'s `??` over
a nullable function value, not this row. Test cells: `tests/cases/expressions/optchain-standalone-fn-leaf.vl`.
Position matrix: `scripts/capability-probes/matrix/optchain-fn-leaf.matrix.vl`, 0 → 66 of 66.
