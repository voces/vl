#### Mechanism

Not traced. No function value is involved: the builder fails on its own, so the defect is in
how the un-annotated locals' record literals get a struct row at this depth. It is not in the
`$fnsig` lookup that [D9784](D9784.md) fixed. `A15` is spelled in about `7·2^15` characters,
past the 4096-character cap where `repNameCanonId` declines, so a name-keyed row lookup is the
first suspect. Depth 16 does not fail, so the cap alone does not decide the outcome.
