### D17676 — an empty list delivered to a generic's `V[][] | string` parameter from inside a function traps at the `is f64[][]` test

**trap after load · clause 1 · the in-function face of [D15763](D15763.md), whose top-level spelling prints `1` · found by COV-IS while picking a `box ladder` witness · filed 2026-11-26 against master `2dd28397e`**

Repro:

    function probe<V>(v: V[][] | string) {
      if v is f64[][] { return 1 }
      return 0
    }
    function pr() { return probe([]) }
    print(pr())
    // vl check: rc 0.  vl run: wasm trap, cast failure in `probe` (with VL_IR=0 too)

Want:

    1

#### Mechanism

Not yet traced. The `[]` argument is built where `pr`'s frame instantiates `probe`, and the
`is f64[][]` test in that instance casts it to a heap it is not on. The same call at top level
takes D15763's empty-fit arm (`emitListEmptyFitArms`) and prints `1`.
