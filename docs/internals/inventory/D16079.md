### D16079 — a generic function returned through a hole parameter, called there at two parameter lists, builds one instance or none: the call names an unknown function

**loud emit reject · clause 2 · found by lane I closing D16077 · filed 2026-11-14 against master `6800e3df`**

Repro:

    function inc(x) { x + 1 }
    function run(f) {
      if f()(1.5) > 9.0 { return 0 }
      return f()(41)
    }
    print(run(() => inc) + 1)
    // vl run: emitProgram: call to unknown function

Want:

    43

#### Mechanism

`f()`'s result is called at `(f64)` and at `(i32)`, so the generic read the argument lambda returns
has two deliveries that disagree on their parameters. D16077's closing gives the lambda one closed
type only where every delivery agrees, so here it keeps its hole type, `run` has no closure type for
`f`, and `f()` names no function. The design owes one instance of `inc` per parameter list, and so
a lambda value whose result is a set of two instances. The refusal's sentence names a mechanism,
not a contract.
