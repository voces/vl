#### Mechanism

An un-annotated place takes its type from its initialiser, and a later `null` write is checked
against that type. A numeric widening of a `let` is adopted (`let x = 1; x = 1.5` runs, `1.5`), a
numeric widening of a literal's field is refused with a sentence naming the default, and a `null`
write is refused at a `let`, a field and a list element alike. No DECISIONS.md entry rules whether
a later write may widen an un-annotated place to `T | null`. [D3470](D3470.md) grades a `null` into
a captured list cell as an owed refusal, which is the nearest prior judgment. The `Want` above is
the answer if the ruling is "widens"; if it is "the initialiser fixes it", this row closes as
owed, with the annotated spelling as the way to write it.
