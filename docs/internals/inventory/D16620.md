### D16620 — a tail `if`/`match` whose arm values are pure was discarded without the A2 warning, and its caller got no `--fix`

**closed · the return-rule position matrix · filed 2026-11-15 against master `69a976170`**

Repro:

    function f(x: i32) {
      if x > 0 { 1 } else { 2 }
    }
    f(1)
    print(0)
    // before: vl check rc 0 and no diagnostic; the arm values are dropped silently.
    // now: the warning `discarded-tail-value`, whose --fix writes `return if …`.

Want:

    0

#### Mechanism

`blockTailRefuse` warned only when `tailIsPure` held, which tested the tail node itself: an
identifier, literal, member, index, operator or literal container. A statement `if` or `match`
is none of those, so a function ending in one whose arms yield pure values discarded them
silently. That is the old-rule spelling of a value-returning function, so the flag day turned
it `void` with nothing said. `voidCalleeTail` likewise named only a `Call` tail, so a caller
using the value got a bare "expects a value, got void". Both now accept an `if`/`match` tail:
the warning when every yielding arm is pure, the caller's note and fix when the tail has a value.
