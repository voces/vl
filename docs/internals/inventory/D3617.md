### D3617 — a numeric literal-union `is` over a lambda's call returning a number box is refused: the box has no re-readable receiver

**loud emit reject · open · clause 2 (prints `false false` on master, wrong at `F(1, 2.5, 1)`) · found by lane LR re-grading the #3344 review's `is` grid (`il__lamjoin__f-one`) · filed 2026-10-04 against master `0c087fb3c`**

Repro:

    type L = 1 | 2
    function F<A, B>(k: i32, x: A, y: B) {
      const g = () => { if k == 0 { x } else { y } }
      print(g() is L)
    }
    F(0, 2.5, 1)
    F(1, 2.5, 1)
    // vl check: rc 0.  vl run: emit error, "`is` names a type that is not a union variant"

Want:

    false
    true

#### Mechanism

With [D3520](D3520.md) the call returns the box `f64 | i32`, and `is L` over a box tests each
member literal against the payload, which re-reads the receiver once per member. A call cannot
be re-read, and the numeric literal ladder has no arm that reads a box once into a slot (an
`i32` receiver has one, D3570), so it falls to the name fold, which refuses. On master the
call was typed at its first member, `f64`, and answered `false` for `1`. A string literal union
over a box with no string arm answers `false` after one read.
