### D15105 — a generic nested in a generic function and capturing its parameter, handed to a type-parameter parameter, gets no function-value signature

**loud emit reject · clause 2 · `vl check` rc 0 · found as destringify's N1 (the per-encloser witness for the carried-generic consumer's fence) · filed 2026-11-03 against master `38b424262`**

Repro:

    function mid<F>(a: F) {
      print(a("x"))
    }
    function outer<U>(u: U) {
      function same<T>(k: T): T {
        print(u)
        k
      }
      mid(same)
    }
    outer(7)
    // vl check: rc 0.  vl run: emitProgram: a function-value call has no interned signature — parameter 1 of type `` has no representation in the function-value ABI

Want:

    7
    x

#### Mechanism

Not located. The nested `same` is instanced per instance of `outer` (it captures `u`), and handing it to `mid`'s `F` parameter reaches the function-value ABI with a parameter type left empty (``), so no signature is interned. The non-capturing spelling and the non-generic encloser both run, so the empty type is the capture's type in the encloser's instance, not `same`'s own.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `same` captures nothing (drop `print(u)`) | runs | **yes** |
| `outer` not generic (`u: i32`) | runs | **yes** |
| `mid` un-annotated (`mid(a)`) | still refuses: no function value of type `(i32)=>i32` reaches this call | no (a different refusal) |
| a second encloser instance, or a recursion in `mid` | still refuses | no |

#### Grading list

- destringify's N1 (two `outer` instances, `mid` recursing in swapped positions), which their carried-generic consumer fences;
- the two-parameter spelling, `mid(same, same)` with `a("x")` and `b(1)`.
