### D4013 — a wider record passed to a recursive function that swaps two record parameters is refused

**open · loud check reject · clause 2 · found by the #3516 review (w22) · filed 2026-10-11 against master `4d0501a9e`**

Repro:

    type Pos = { x: f64, y: f64 }
    type A = { k: i32, y: f64, x: f64 }
    type B = { y: f64, s: string, x: f64 }
    function ping(p: Pos, q: Pos, n: i32) { if n > 0 { p.x = p.x + 1.0; ping(q, p, n - 1) } }
    const a: A = { k: 7, y: 3.0, x: 0.0 }
    const b: B = { y: 3.0, s: "q", x: 100.0 }
    ping(a, b, 5)
    print(a.x)
    print(b.x)
    print(b.s)
    // vl check: an object value of shape A flowing into Pos drops the field `k`

Want:

    3
    102
    q

#### Mechanism

The two parameters share `Pos`, which declines D3992's rewrite (D4011); with them made
generic separately, the recursive call `ping(q, p, …)` still swaps the two type parameters, so
each instance calls the other and the pair closes only as one instance per ordered pair of
shapes. That is the part D4011's fix alone does not give.
