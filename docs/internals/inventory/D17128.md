#### Mechanism

`eqRouteOf` took an operand's `exprUnion` as a union box (`unionLeft` / `unionRight`), but a value
`if` joined at a record's row is written as that record (`ifJoinsAtRecord`, D17026), so the box
compare met a record. Closed by counting such an operand as a record (`eqRouteOf`) and reading its
struct row from its join (`binEqSideRow`), so the compare is legacy's field-wise struct `==`.
