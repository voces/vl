### D3858 — a reassigned module-scope binding called at a second argument type reaches the initializer's later instance and prints its value

**now a loud emit reject (2026-10-08, lane SC) · was check-clean silently wrong on master `09e133eb4` (#3447), a loud emit reject before it · module-scope two-type programs from lane SC's `gen4.py`, 4 of 600 · filed 2026-10-08 against master `09e133eb4` · pins: `tests/cases/closures/error-module-alias-called-at-two-types.vl`**

Repro:

    const x = "a"
    const n = 4
    const e = (y) => y + y + y
    const g = (y) => y
    let d1 = e
    let i3 = 0
    while i3 < 2 { d1 = g; i3 = i3 + 1 }
    print(d1(x))
    let d2 = e
    print((() => d1(n))())
    print(d2(n))
    // vl check: rc 0.  vl run: prints `a`, `12`, `12`
    // PRINTS a

Want:

    a
    4
    12

#### Mechanism

#3447 let a module-scope `let d1 = e` name `e` (`fieldValueFeOfIn`), so a call through `d1` folds
to `e`'s instance like an un-written binding's. `d1` is written. The closure's call `d1(n)` hit
the registry instance of `e` at `i32` that `d2(n)` had already built. That path renames the
callee to the hit instance without asking whether the binding is reassigned, so it called `e`
where `d1` held `g`. The miss path already refused a reassigned binding called at a second
argument type. The registry hit now refuses it too, and a binding written anywhere on its
alias chain counts as reassigned in both. A call through a written binding found by
`identClosureFeAt` also keeps its `call_ref` (D3849's rule).

Running at both types needs one closure signature per type for the one binding, which the
language does not have. The function-scope spelling was invalid wasm on master and is refused
the same way now.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the loop's write (`d1` never reassigned) | runs, each call its own instance | **yes** |
| `d2(n)` (no earlier `i32` instance of `e`) | refused loudly, the miss path | **yes** (the registry hit) |
| module scope (the same lines in a function) | invalid wasm on master (the closure's capture makes `d1` a cell); refused loudly now | no |
