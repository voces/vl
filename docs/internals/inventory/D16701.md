### D16701 — a list literal spread into a list of a union or nullable element builds a module that fails to validate

**closed 2026-11-16 · runs, prints `1` · was check-clean invalid wasm, `vl check` rc 0, `vl run` invalid module, `type mismatch: expected (ref null $type), found (ref $type)` · clause 1 · fixed in wasmEmit.vl: `emitSpreadGroupBoxed` builds a list literal source at the union-box row it is spread into, as a plain run beside it is; before it read the literal as its own scalar list while `elabSpreadNote` had it built at the destination · pin: `tests/cases/lists/spread-literal-into-union-list.vl` · the record-union spelling is [D16702](D16702.md) · found closing [D16696](D16696.md) · filed 2026-11-16 against master `7de7196e2`**

Repro:

    const u: (i32 | null)[] = [...[1]]
    print(u.length)
    // was: vl check rc 0, vl run invalid module

#### Mechanism

`elabSpreadNote` links a list literal spread operand to the literal holding it, so `emitArr`
builds it at the destination's type: a list of union boxes. `emitSpreadGroupBoxed` read every
spread source by its own kind, an `i32` list, and stored the literal into a slot of that type
before boxing a copy, so the module did not validate.
