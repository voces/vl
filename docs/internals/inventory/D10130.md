### D10130 — a generic's `k?.get(key) ?? d` over a nullable map of `V` has no lowering at a scalar pin

**loud emit reject · `vl check` rc 0 · `emitProgram: ?? over this nullable value is not supported yet` · clause 2 · CAPABILITY: the same function without the type parameter runs, and the generic runs at `string` · found closing [D10030](D10030.md) · present on master `3931f9468` · filed 2026-10-22 against master `3931f9468`**

Repro:

    function f<V>(k: {[string]: V} | null, d: V): V {
      k?.get("a") ?? d
    }
    const m: {[string]: i32} = Map()
    m["a"] = 5
    print(f(m, 0))
    // vl check: rc 0.  vl run: emitProgram: `??` over this nullable value is not supported yet — narrow it first, e.g. `if v != null { … }`

Want:

    5

#### Mechanism

Not traced. With D10030 closed the `?.get` is the guarded index read `k["a"]`, and at the `i32`
pin its result is the nullable `V`, an `i32 | null`; the `??` emitter finds no rep it can
coalesce for that operand in the instance. A plain `k ?? d` over `V | null` at the same pin
runs, so the miss is the guarded read's nullable result, not `??` over a pinned `V`.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the type parameter, `{[string]: i32} \| null` and `d: i32` | runs, `5` | **yes** |
| the pin `string`, `f(m, "z")` over `{[string]: string}` | runs, `s` | **yes**, a scalar value |
| the map read for a parameter, `f<V>(k: V \| null, d: V) { k ?? d }` | runs, `5` | **yes** |
| `??` for `const r = k?.get("a")` then `if r == null { d } else { r }` | refuses as `bare null needs a struct-typed context` | no |
