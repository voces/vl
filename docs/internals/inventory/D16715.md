### D16715 — [CLOSED 2026-11-18] an un-annotated map of two hole functions with different results, handed to a parameter annotated at a map of functions, fails at emit with an internal message

**closed 2026-11-18 · now a loud check reject (DESIGN: a mutable container is invariant) · `a `{[string]: (_) => _}` cannot be used as `{[string]: (i32) => f64}` here: a map is passed as the same storage …` since [D16996](D16996.md)'s judge, 2026-11-18 · was loud emit reject, `emitProgram: internal: a function slot pinned at one signature has no one …`, after a clean `vl check` · the un-annotated-parameter spelling in the grading list still fails at emit with that message, an open join of two results in one map (lane F2's family B) · found re-ablating [D15161](D15161.md) for the L2 S3 plan · filed 2026-11-16 against master `078e4116`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function run(m: {[string]: (a: i32) => f64}) {
      const g = m.get("b")
      if g != null { print(g(3)) }
    }
    const m = Map()
    m.set("a", inc0)
    m.set("b", half)
    run(m)
    // vl check: refuses at `run(m)`, "a map is passed as the same storage, so the function type it
    // holds must match exactly"

#### Mechanism

The delivery is the defect: `run` could write a function returning `f64` into the shared map, which
`inc0`'s readers call at `i32`, so it is refused at check as a map annotated at the narrower type
is ([D16996](D16996.md)). Before that judge: The map's element is a slot holding two hole functions. One instance of
`inc0` returns `i32`, the slot's delivered type `(i32) => f64` wants `f64`, and the elaboration
finds no single closed type for the slot. Declared the same way, a binding read in its own scope
runs, so the parameter delivery is the ingredient.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `inc0` (one function only) | runs, prints `1.5` | **yes** |
| the differing result (`a + 1.0`) | runs, prints `1.5` | **yes** |
| the parameter delivery (an annotated binding read in place) | runs, prints `1.5` | **yes** |
| the holes of `inc0`/`half` (annotated `a: i32`) | loud check reject (the first write pins the map at `(i32) => i32`), a separate decision | n/a |

#### Grading list

which fails with the same message.
