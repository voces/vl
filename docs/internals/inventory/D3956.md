### D3956 — a generic function passed from a closure to another closure's `T`-typed parameter has no instance

**loud emit reject · clause 2 · on master the program traps · found in review of #3498 (`rv3498/round4/d12`, `d16`) · filed 2026-10-10 against master `429e7b093`**

Repro:

    function other<V>(v: V) { print("O"); print(v) }
    function a<T>(x: T) {
      const w = (g: (t: T) => void) => { g(x) }
      const w2 = () => { w(other) }
      w2()
    }
    a(1)
    // vl check: rc 0.  vl run: emitProgram: a generic function is passed to a function value whose parameter type names a type parameter this closure does not bind

Want:

    O
    1

#### Mechanism

`w2` names no `T` of its own and is lifted once; its call `w(other)` goes through a function
value whose parameter type `(t: T) => void` names `a`'s type parameter, which nothing in `w2`'s
frame binds, so `other` is never instanced and the call traps on master. #3498 refuses it
(`monoGenArgAtOpenParam`); the capability is to instance `other` per instance of `a`.

| --- | --- | --- |

| `other` stored into a capture cell by `w` | the same refusal (`round4/d10`) | no |
