#### Mechanism

D10701's close copies the list once per function type its calls take, and each call reads its
type's copy. Here both calls read one element through one read of the list (the loop's
iterable), so no copy can serve them; each element would have to carry an instance per call
type, as owner ruling D3975 has a function binding called at several types do.
