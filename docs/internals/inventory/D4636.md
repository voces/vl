### D4636 — an un-annotated map whose value is a record literal shaped like an anonymous union arm interns no map value slot

**loud emit reject · clause 2 · the `map_value` and `map_set` un-annotated cells of `tagged-arm-nullable-field.matrix.vl` · filed 2026-10-14 against master `536c4c79e`**

Repro:

    type U = { q: i32 } | { r: i32 }
    const m = Map()
    m["k"] = { q: 4 }
    print(m.length)
    // vl check: rc 0.  vl run: emitProgram: unsupported map value type (no rep for a union-member struct, …)

Want:

    1

#### Mechanism

Not localised past the ablation. The map's value type is inferred from the stored literal as
`{q: i32}`, which is an anonymous arm of the declared union `U` and so has no plain struct row,
only a variant row. The map value-slot interner has no slot for a union-member struct, and the
declaration refuses. Naming the arm (`type R = { q: i32 }`, `U = R | …`) gives it a struct row,
and the same program runs.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the union | runs | **yes** |
| the arm is a named alias (`type R = { q: i32 }`, `U = R \| { r: i32 }`) | runs, `1` | **yes** |
| the literal matches the other arm (`{ r: 4 }`) | still refuses | no |
| the union is mixed (`{ q: i32 } \| string`) | still refuses | no |
| the arm is tagged with a nullable field (the matrix's `{ kind: "a", q: i32 \| null }`) | still refuses | no |
| `m.set("k", …)` instead of the index store | still refuses | no |
| inside a function | still refuses | no |
