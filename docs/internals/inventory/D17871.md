### D17871 — a generic parameter copied into a binding of a concrete type parameter and also called directly at another type is closed at the direct call

**loud check reject · clause 2 · filed 2026-11-28 against master `544daecc0` by COV-CLOS-3 (found pinning D17324)**

Repro:

    function plus100(k: i32): i32 { return k + 100 }
    function other<T>(k: T): T { return k }
    function mid<F, G>(a: F, a1: G) {
      const b: F = a1
      print(b(3))
      print(a1("s"))
    }
    mid(plus100, other)
    // vl check: cannot assign (string) => string to 'b' of type (i32) => i32 (parameter `a1` of `mid`, used at 4:16)

Want:

    3
    s

#### Mechanism

Not traced. `G` is bound to `other`'s generic signature, so the copy into `b: F` instances it at
`F`'s `(i32) => i32` and the direct call at `string`. The check closes `G` at the direct call's
`string` and then grades the copy against that closed type.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `a1("s")` | runs, prints `3` | **yes** |
| `a1(4)`, at `F`'s own type | runs | **yes** |
