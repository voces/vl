**closed 2026-09-29 · was check-clean invalid wasm, clause 1, on master `94670f728` · closed by the owner's ruling (A), 2026-09-29, that a union holding a type parameter is gradual: the literal is typed `(T | i32)[]` and `print(l[0] + 1)` at `f(3)` runs, so the 56 cells of the named set `d3079-apart-join-price` that #3275's candidate lost all run · [D3103](D3103.md) and [D3106](D3106.md) are the same collapse at an `if`-join and at a concrete list parameter · found grading [D3062](D3062.md)'s close · filed 2026-09-28 against master `bae51e6b7` · fixture `tests/cases/generics/gradual-type-parameter-union.vl`**

Repro:

    function f2<T>(x: T) {
      const l = [x, 7]
      print(l.length)
    }
    f2("s")
    // vl check: rc 0.  vl run: invalid module inside `f2`

Want:

    2

#### Mechanism

Not localised past the ablation. The direct spelling `function f2(x: string)` runs and prints
`2`, so the literal's element is `string | i32` there; at the instance the element the literal
is built with and the one its reader expects disagree.

| `k[0]` of an un-annotated global in place of `7` | invalid wasm | no |
