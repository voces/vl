### D3079 — an inferred list literal joining a type parameter with a literal builds the wrong element inside a generic instance

**check-clean invalid wasm · clause 1 · open · found grading [D3062](D3062.md)'s close · the same on master `bae51e6b7` · filed 2026-09-28 against master `bae51e6b7`**

Repro:

    function f2<T>(x: T) {
      const l = [x, 7]
      print(l.length)
    }
    f2("s")
    // vl check: rc 0.  vl run: invalid module inside `f2`

Want:

    2

#### Mechanism

Not localised past the ablation. The direct spelling `function f2(x: string)` runs and prints
`2`, so the literal's element is `string | i32` there; at the instance the element the literal
is built with and the one its reader expects disagree.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `function f2(x: string)`, the direct spelling | prints `2` | **yes** (the type parameter) |
| `const l: (T \| i32)[] = [x, 7]`, annotated | prints `2` | **yes** (inference) |
| `k[0]` of an un-annotated global in place of `7` | invalid wasm | no |
