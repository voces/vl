Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const m = Map()
    m.set("a", mk())
    const wm: {[string]: J} = Map()

Want:

#### Mechanism

`m.get("a")` reads a record of `J`'s storage, and the default literal is built at its own `{f: i32}`.
A `const` initialised so is built at the read's record (the store column, `recCoalesceLitAdopt`); a
function's returned value is resolved by `storeRetsResolve`, which takes no `??` leaf, so `g`
returns one of each storage.
