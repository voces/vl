### D16401 — a declared record return of a rewritten parameter refuses the wide instance, which undoes the rewrite

**loud check reject · clause 2 · `an object value of shape … flowing into P drops the field …` · the `returned` cell (annotated face) of `record-param-width-before`/`-between` · found by lane I in L3 PR A · filed 2026-11-15 against master `3d526470a`**

Repro:

    type P = { name: string }
    function pass(p: P): P { p }
    const v: { age: i32, name: string } = { age: 3, name: "a" }
    print(pass(v).name)
    // vl check: rc 1, the field-dropping refusal at `pass(v)`

Want:

    a

#### Mechanism

The rewrite makes `p` a row slot, and the instance at the wider row returns that row where `: P`
is declared. `P` and a row that is not a prefix of it are unrelated WasmGC struct types, so a
caller holding the declared `P` cannot read the returned row's fields: the return needs a
converting store, the accessor view's job. The instance therefore reports the field drop,
`wsNoteInstErr` undoes the rewrite, and the call's refusal stands. It waits for the storage view,
with D16402; an un-annotated return, which hands the row back as the row, runs.
