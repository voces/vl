#### Mechanism

`checkBinExprNodeReal`'s coalesce tail answers `joinTys(innerFull, rt)` when the default does
not fit the left operand's non-null type, so `v` is checked as `i32 | string` and the program
is admitted. The emitter never builds that join: the left half decides the slot, the default's
string ref is staged into it, and the module fails to validate. Either the join is a rep the
emitter owes or the checker owes the refusal — the one thing it cannot be is accepted and
mis-lowered.
