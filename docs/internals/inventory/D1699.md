### D1699 — a `??` whose default does not fit the left operand's non-null face types as the join and lowers as the left half, so `i32 | null ?? "x"` stages a string ref into an i32 slot

**closed 2026-09-06 — the `??` result's rep is the type the CHECKER recorded for the node, so a
joining default boxes and a widening one widens · filed against master `ffa049fdc` · found
while building D1693's `??` arm · residues D1702, D1703 · 0 corpus cells**

Repro:

    function ns(): i32 | null { return null }
    const a = ns()
    const v = a ?? "x"
    print(v)
    // prints x since the close; before it, `vl check` rc 0 then exit 70,
    // the emitted module failed to validate: type mismatch: expected i32, found (ref $type)

#### Mechanism

`checkBinExprNodeReal`'s coalesce tail answers `joinTys(innerFull, rt)` when the default does
not fit the left operand's non-null type, so `v` is checked as `i32 | string` and the program
is admitted. The emitter never builds that join: the left half decides the slot, the default's
string ref is staged into it, and the module fails to validate. Either the join is a rep the
emitter owes or the checker owes the refusal — the one thing it cannot be is accepted and
mis-lowered.

#### Grading list

The four ablation rows at all three spellings — direct, annotated parameter, and the
monomorphization pin — plus the fitting-default control, which must keep running: a close that
teaches the emitter the join must not cost the common case its unboxed slot.

The close reads `nodeTyIxOf` for the `??` node and turns the whole arm on it, because the
checker was already right and only the lowering was not: a fitting default records `i32`, a
nullable one `i32 | null`, a `"x"` one `i32 | string`, and a `1.5` one the widened `f64`. The
first stays unboxed, the middle two take the boxed shape the nullable-default branch already
had (tags are global atom codes, so the operand's own box needs no re-tagging), and the last
widens the unboxed operand up to the result. Six default kinds move from check-clean invalid
wasm to `runs`; a STRUCT default still refuses because the join is a MIXED union
`isValueUnionName` declines (D1703), and the un-annotated PARAMETER face still refuses because
the `??` hole is never substituted, so nothing banks its pin (D1702).
