#### Mechanism

A spread of a pushed list ties the two lists' roots (`mfrTied`, emit_mono.vl, D9482), so the
write of `inc` into `ys` declines `xs`'s read plan too, and `xs`, called at two types, reaches
`monoPinListElems` with two pins. The tie is what keeps a written host sound; separating the
lists would need the host typed at the written value while the source stays open.

Still refuses after the close of [D9791](D9791.md) and [D9853](D9853.md) (2026-10-22): those
follow a binding that only ever holds one generic, and `ys` holds `inc` too, so no flow source
names one generic here. What it needs is a converting copy at the spread, not a wider source.
