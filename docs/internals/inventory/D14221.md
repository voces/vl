Repro:

    const a: { r: { c2: i32 } } | { r: { s2: i32 } } = { r: { c2: 1 } }

    if x is { c2: i32 } { print(x.c2) }

#### Mechanism

`a.r` reads the field both record arms share (the Q4 ruling makes that legal), and its type is
the union `{ c2: i32 } | { s2: i32 }`. Bound at module scope, the global `x` needs a value type
for that union and the emitter finds no interned shape for it. Not localised past that.
