### D14651 — two choices of names handed to two split parameters of one call refuse at emit

**loud emit reject · `monomorphize: `g` is called at two instances of the function handed to it in a call to `lapBack`` · clause 2 · open · one choice beside a name runs (D14439) · filed 2026-10-31 against master `bd1631f9`**

Repro:

    function wrap(a) { return [a] }
    function wrap2(a) { return [a, a, a] }
    function pair(a) { return [a, a] }
    function lapBack(g, h, x) {
      print(h(g(x)).length)

      return 0
    }
    const c = true
    lapBack(if c { wrap } else { wrap2 }, if c { pair } else { wrap }, 4)

#### Mechanism

The checker asks the split plan (D6210) for a copy of `g` and of `h` per instance, and each
argument is a choice of names. The plan hands a choice to the copies by running it once ahead of
the call (D13360), and it may run a choice ahead only when every argument before it stays put or
is bound ahead in order (`fsChoiceArgStmt`). The second choice has the first ahead of it, so the
plan declines the whole call (`fsPlanHoles`, the call loop), and the first compile's refusal stands.
