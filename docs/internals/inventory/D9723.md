### D9723 — a call returning a generic as its trailing expression, written as a list element called at two types, refuses

**loud emit reject · `vl check` rc 0 · `a generic function taken as a value reaches no call that fixes its type` · clause 2 · found closing [D9650](D9650.md) · present on master `4fce2a127` · filed 2026-10-22 against master `4fce2a127`**

Repro:

    function id<T>(x: T): T { x }
    function mk() {
      print("mk")
      id
    }
    const xs = [mk()]
    print(xs[0](2))
    print(xs[0]("abc"))
    // vl check rc 0.  vl run: emit error: emitProgram: a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type

Want:

    mk
    2
    abc

#### Mechanism

Not traced. [D9592](D9592.md)'s close notes inert each `return` operand of the called function
(`monoFlowNoteCallRets`, emit_mono.vl), and a trailing expression is not a `return`. The same
function with `return id` runs. Bound to a `const` first, the trailing form runs too.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the trailing expression (`return id`) | runs, `mk 2 abc` | **yes** |
| the list (`const c = mk()`, `c(2)`, `c("abc")`) | runs, `mk 2 abc` | **yes** |
