### D1950 — a non-exhaustive `is`-chain in an INFERRED-return function passes check and traps `unreachable` on the untested variant — the totality check ran only for an annotated return

**now a loud check reject 2026-09-08 — was check-clean invalid wasm (runtime `unreachable` trap), `vl check` rc 0, clause 1 · found by the design red-team (functional/type-theory lens) · the D1902 family, its inferred-return case · fix in `checkTrailingChainTotal` (`compiler/typecheck.vl`); fixtures `tests/cases/soundness/inferred-is-chain-no-else-{reject,returns}.vl`**

Repro:

    type A = { a: i32 }
    type B = { b: i32 }
    type C = { c: i32 }
    type ABC = A | B | C
    function get(x: ABC) {
      if x is A {
        return x.a
      } else if x is B {
        return x.b
      }
    }
    print(get({ c: 3 }))
    // vl check: rc 0.  vl run: wasm trap, unreachable (in `get`, the C path)

#### Mechanism

`checkFuncDeclNode`'s trailing-statement soundness check — an else-less `is`-chain that does not
cover every variant lets a value fall off the end — lived only in the `else` (annotated-return)
arm of `if inferring`. The inferred arm skipped it. Inference infers `i32` from the two covered
`return` arms and treats the chain as covering, so the emitter writes `unreachable` on the
uncovered `C` path. The annotated case (`get(x: ABC): i32`) already refuses; a redundant-annotation
hint even fires ("inferred as i32"), proving the checker computed the same type yet applied the
totality rule only under the annotation. The fix runs the same check for the inferred return,
using `inferObserved` (the join of the returns walked) as the return type — the tail
if-statement's own type is void for an all-returning chain, so it cannot be the one checked.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the return-type annotation (add `: i32`) | already refuses (the annotated D1902 case) | **yes** |
| the missing arm (add `else if x is C { return x.c }`) | runs, prints `3` | **yes** |
| the `is`-chain (a plain `if k == 0 { return 1 }`) | falls through to `null`, no trap | **yes** |
