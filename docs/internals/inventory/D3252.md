### D3252 — a `??` whose right operand is a type parameter is never re-checked at the pin against the destination

**closed 2026-09-30 — now a loud check reject at the pin, the direct spelling's `cannot assign f64 | boolean to 'v' of type f64` · was check-clean silently wrong (`0.25`) · clause 1 · closed by typing a `??` over a hole default as a derived hole (`HD_COALD`) the pin answers with the concrete tail — the left's face when the default fits it, else their join — so every destination's deferred constraint re-asks it · the `string` face refuses the same way, and an un-annotated or union destination of the join (`infer`, `union`, check-clean invalid wasm on master) now runs · fixtures `tests/cases/generics/error-coalesce-hole-default-at-pin.vl`, `tests/cases/generics/coalesce-hole-default-at-pin.vl` · found by the #3294 review (`rv3294-k7q2`) · filed 2026-09-29 against master `313a071b4`**

Repro:

    function gco<T>(x: T) {
      const o: f64 | null = null
      const v: f64 = o ?? x
      v / 4.0
    }
    print(gco(3 > 2))
    // PRINTS 0.25

Want:

    check reject: cannot assign

#### Mechanism

A prediction. The body checks `o ?? x` against `f64` while `x` is a hole, so the fit is vacuous,
and no deferred constraint is recorded for the `??` result the way one is for a bare `x` (the
`letCstr` table, which `ab1` below shows refusing at the pin). At `T = boolean` the `boolean`'s
i32 `1` is delivered into the `f64` slot and read as `1.0`. At `T = string` the same program is
check-clean invalid wasm (`expected i32, found (ref $type)` inside `gco`).

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| direct spelling, `const v: f64 = o ?? b` over a `boolean` binding | loud check reject | **yes** (the hole) |
| `const v: f64 = x`, no `??` | loud check reject at the pin | **yes** (the `??`) |
| `return o ?? x` into a declared `: f64` return | prints `0.25` the same way | no |
| `o` non-null (`2.0`), so the right operand is never read | prints `0.5`, correct | the read |
| `gco("hello")` | check-clean invalid wasm | no, a second face |

#### Grading list

The `return o ?? x` spelling above, and the `string` face (`gco("hello")`), which must refuse
at the pin rather than build.
