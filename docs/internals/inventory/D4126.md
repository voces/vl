### D4126 — a generic function with no parameters, called through an un-annotated list, refuses at emit

**loud emit reject · clause 2: `vl check` is clean · found closing [D4123](D4123.md) · filed 2026-10-11 against master `efd3c3f15`**

Repro:

    function z<U>() { const r: U[] = []; print(r.length) }
    const fs = [z]
    fs[0]()
    // vl check: rc 0.  vl run: emitProgram: a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type

    0

#### Mechanism

From the ablation. A call through the element passes no argument, so it binds no type
parameter and instances nothing. `z` is pruned to the no-parameter `void` stub, whose signature
is `z`'s own. Before [D4123](D4123.md) closed, the call therefore validated and ran the empty
stub: the program printed nothing and exited 0. That silent wrong value is now this loud
refusal. `U` is bound by nothing at any call of `z`, and `z()` called directly prints `0`, so
the instance the element wants is the one a direct call already builds.
