### D15643 — two choices of records whose function sets share a member, handed to hole callees, intern no signature

**loud emit reject · clause 2 · `emitProgram: a function-value call has no interned signature — no function value of type \`(i32)=>i32\` reaches this call to intern its signature` · found closing D15330 · filed 2026-11-10 against master `deea236c`**

    function id1(a) { return a }

    function h(r) { return r.f(2.5) }

#### Mechanism

Each `const` holds a choice of two records, whose field sets `{id1, id2}` and `{id1, dbl}` share
`id1`. Alone, either choice is tagged and dispatched in its callee; together, neither is, and the
field calls find no closure of their signature.
