### D15211 — a bundle record held in a local and returned has no member fact at the caller

**closed 2026-11-03 · now runs, prints `5` · was loud emit reject · clause 2 · `emitProgram: a function returning a parameter called at two signatures is called where its result is not used at one of them` · found planning [D15146](D15146.md) (lane destringify) · filed 2026-11-03 against master `f49fe0052` · closed by #6146 (lane bundle), which keeps a holder the function returns whole**

Repro:

    function lap(f) {
      f(2.5)
      f(3)
      return f
    }
    function mk(k: i32) {
      const r = lap((a) => a + k)
      return r
    }
    const v = mk(1)
    print(v(4))

Want:

    5

#### Mechanism

`lap` returns its parameter's record (one closure per signature, [D15144](D15144.md)). `r` holds
it whole, as D15144's holder does, and `mk` returns the holder. The refusal fires at the `lap`
call inside `mk`, where `emitBundleResultPick` (wasmEmit.vl) has neither a member fact for the
call's value nor a holder keeping the record whole (`elabCallKeepsRecordAt`). `mk`'s caller then
calls the returned value at one signature.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `const r` (`return lap(...)` directly) | runs, prints `5` | **yes** |
| `return r` (`r` called in `mk` instead) | runs | **yes** |
| `mk` made generic (`gen<T>(t: T, k: i32)`) | still refuses | no |
| the second call of `f` in `lap` | runs | **yes** |

#### Grading list

* `returned-bundle-record-generic.matrix.vl`: its value is this shape (a holder returned from a
  generic). On `f49fe0052` 27 of its 33 un-annotated cells refuse with this sentence; the other six
  are `return_annotated`, `argument`, `struct_field_assign`, `array_element_assign`,
  `map_value_place` and `early_return_guard`.
* `v` called at both signatures (`print(v(4))`, `print(v(1.5))`): the same refusal.
