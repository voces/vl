### D2438 — an assignment's `i32` value into a box that also holds a literal union or a record is the box

**closed 2026-09-25 by [D2398](D2398.md)'s close — the witness prints `9` · was check-clean invalid wasm, clause 1 · filed 2026-09-25 against master `a20d69104`, the
review residue of [D2391](D2391.md)'s close**

Repro:

    type K = "a" | "b"
    let v: K | i32 = 3
    function k() { v = 9 }
    print(k())
    // vl check: rc 0.  vl run: invalid module, top-level code: type mismatch: expected i32, found (ref $type)

#### Mechanism

Closed by [D2398](D2398.md)'s close: the value tail becomes `const t = 9; v = t; t`, so
the value is `t`, an `i32`, whatever the box also holds. The record spelling (`Circle |
i32`) and the local binding `const r = (v = 9)` run too.

D2391's close narrows the re-read only when the target's union is a value union
(`isValueUnionName`). A union carrying a literal-union alias arm or a record arm is boxed too,
but fails that test, so the value stays the box while the checker types it `i32`.
