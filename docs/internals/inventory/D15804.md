### D15804 — a `for` loop over a list a record's field holds, whose records' function field holds functions returning different types, is refused at check, where an index read of the same list runs

**loud check reject · `cannot store 'half' in 'mk().a[].f': called at (i32) it returns f64, where 'inc0', also stored in it, returns i32 — every function a call through 'mk().a[].f' may run must return one type` · clause 2 · open · found closing D15801's list-in-a-record family · filed 2026-11-12 against master `b0219f456`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function mk() { return { a: [{ f: inc0 }, { f: half }] } }
    for e in mk().a { print(e.f(3)) }

Want:

    4
    1.5

#### Mechanism

The one-result judge's field lift (`holeSlotFieldLift`) reads a place whose last two steps are an
element and its field. For a list a record holds, it is not applied to a read rooted at a `for`
loop's element (`holeSlotLoopRooted`). Lifted, the program passes check and emit refuses
`emitProgram: field access receiver is not a struct` at `e.f`. The loop walks the list at the
record's own field row, while the tag decision builds the list's records at its rep.

#### Ablation

| spelling | outcome |
| --- | --- |
| the witness | loud check reject |
| bound first, `const r = mk(); for e in r.a { … }` | loud check reject |
| an index read, `mk().a[i].f(3)` | runs (D15801) |
| the list not in a record, `for e in [{ f: inc0 }, { f: half }] { … }` | runs (D15791) |
