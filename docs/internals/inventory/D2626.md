### D2626 — an un-annotated function whose tail `if` assigns a closure-captured union binding needs that assignment as its value

**closed by D2631 · was a loud emit reject (`emitProgram: only an identifier assignment is a value expression`) on a `vl check`-clean program · filed 2026-09-26 against master `7c572571f`**

Repro:

    function src(): i32 | string { return 3 }
    function g() {
      let x: i32 | string = src()
      const k = () => x
      if x is string { x = "t" }
    }
    g()
    print("ok")

#### Mechanism

`g` has no return annotation, so its tail `if` is its implicit return and the else-less `if`
types as `string | null`. The emitter then lowers the arm's assignment `x = "t"` as a value, and
the capture rewrite has turned `x` into its shared cell, a target `assignTargetReReads` does not
re-read. Nothing reads `g()`'s result, so the value was never needed: D2631 makes such a function
`void`, and the tail is lowered as a statement. The annotated `: void` spelling always ran.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the closure `k` capturing `x` | runs | **yes** |
| the missing return annotation (`: void`) | runs | **yes** |
| a caller reading the result (`print(g())`) | still refuses | no — a second spelling, still open |

#### Grading list

`print(g())`, where the result is read: the captured cell's assignment is still not a value
expression, and still refuses loudly.
