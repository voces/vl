### D2449 — a path re-test inside the arm of an `if` whose condition holds the writing call is refused

**loud check reject · clause 2 · filed 2026-09-25 against master `20651a88b`, the path twin of
[D2408](D2408.md), found by the review of #3150 · open**

Repro:

    type W = { value: f64 | boolean }
    function mutate(w: W): boolean {
      w.value = true
      true
    }
    function f(v: W): f64 {
      if v.value is f64 {
        if mutate(v) {
          if v.value is f64 { return v.value }
          print("flipped")
        }
      }
      0.0
    }
    print(f({ value: 1.5 }))
    // vl check: rc 1, "'v.value' was narrowed by a guard, but the call to 'mutate' on line 8
    // can write it — re-test 'v.value' after the call", at the re-test's own operand

#### Mechanism

A path a call ends reads its declared type only once the call's statement has closed
(`npSettledAt`), because the emitter retires it after that statement. The arm is inside the
statement, so the re-test's operand is refused, and the refusal asks for the very re-test it
refuses. Same shape as D2408's bare name.

#### Ablation

Graded on #3150's compiler, which lets a path read its declared type after the call's statement.

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the call in the condition (`mutate(v)` as its own statement, then `if true`) | runs | **yes** |
| the outer narrowing | runs | **yes** |

#### Grading list

The index cell `xs[0]`; a `while` condition holding the call. Candidate fix, shared with
D2408: exempt an `is` test's operand, once the emitter's lowering of that test is shown to read
the stored value rather than the narrowed rep (and after [D2447](D2447.md), which it is not).
