### D14814 — a fresh call handed to a generic whose type parameter a held argument pins narrower, while another delivery builds the call's record wider, is invalid wasm

**closed · now a loud check reject, `{r: null} is not Circle: they store field r differently`, at `sink(mkcall())` · was check-clean invalid wasm, clause 1 · found gridding [D14812](D14812.md) · filed 2026-11-01 against master `3e96b47e`, re-scoped 2026-11-01 to the direct spelling · closed 2026-11-01 against master `431d2f30`: a call delivered at its own type to an instance a held argument or a held list element pins, or a call's written type arguments pin, counts as landing apart (`recHeldPinnedArg`, read by `recSitesLandAt` and the D8301 refusal, check_fit_rules.vl) · fixture `soundness/error-fresh-call-at-instance-a-held-argument-pins.vl` · the program is design-legal: a converting delivery that makes it run is [D14817](D14817.md)'s · a FRESH literal pinning `T` is [D14816](D14816.md)**

Repro:

    type Circle = { r: i32 | null }
    type K = { r: null }
    function sink(_x: Circle) { }
    function mkcall() { { r: null } }
    sink(mkcall())
    function both<T>(a: T, b: T): i32 { 1 }
    const k: K = { r: null }
    print(both(mkcall(), k))

Want:

    1

#### Mechanism

`sink(mkcall())` builds `mkcall`'s record at `Circle`. `both`'s `T` is also bound by `k`, a held
`K`, so the instance is `both@K`, and `mkcall()` is delivered there at its own type. The
two-storages rule (D8301, `recSitesLandApart`) counts a landing apart only when it differs from
both the destination and the record's own type. A landing at `K`, which is `mkcall`'s own type, is
exempt, so `mkcall` is built at `Circle` and handed to `both@K`. Invalid on line 8.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `sink(mkcall())` | prints `1` | **yes** |
| `k` replaced by `mkcall()` | prints `1` | **yes**, the held argument |
| `first<K>(mkcall())` in place of `k` | refused | no, the written type argument is refused |
