**closed · now runs, prints `1` · was check-clean invalid wasm, clause 1, then a loud check reject from its close against master `431d2f30` (`recHeldPinnedArg`) · found gridding [D14812](D14812.md) · filed 2026-11-01 against master `3e96b47e` · runs since 2026-11-01: a held-pinned call delivered at its own type as a direct argument to a parameter typed `T` is built wide and copied into its own record, where every field it narrows is `null` (`recHeldPinBare`, `recCopyNarrows`, check_fit_rules.vl; the `null` arm of `emitRecCopy`; DECISIONS.md §"A fresh record converts at one delivery point") · fixtures `soundness/error-fresh-call-at-instance-a-held-argument-pins.vl` (the list-element cell, still refused) and `soundness/fresh-call-copied-at-instance-a-held-argument-pins-runs.vl` · the list and element cells keep the refusal, and are [D14818](D14818.md)**

Repro:

    type Circle = { r: i32 | null }
    type K = { r: null }
    function sink(_x: Circle) { }
    function mkcall() { { r: null } }
    sink(mkcall())
    function both<T>(a: T, b: T): i32 { 1 }
    const k: K = { r: null }
    print(both(mkcall(), k))

Want:

    1

#### Mechanism

`sink(mkcall())` builds `mkcall`'s record at `Circle`. `both`'s `T` is also bound by `k`, a held
`K`, so the instance is `both@K`, and `mkcall()` is delivered there at its own type. The
two-storages rule (D8301, `recSitesLandApart`) counts a landing apart only when it differs from
both the destination and the record's own type. A landing at `K`, which is `mkcall`'s own type, is
exempt, so `mkcall` is built at `Circle` and handed to `both@K`. Invalid on line 8.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `sink(mkcall())` | prints `1` | **yes** |
| `k` replaced by `mkcall()` | prints `1` | **yes**, the held argument |
| `first<K>(mkcall())` in place of `k` | refused | no, the written type argument is refused |
