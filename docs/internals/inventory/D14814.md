### D14814 — a list literal of calls built at a wider record, handed to a generic whose type parameter something else pins narrower, is invalid wasm

**open · check-clean invalid wasm, clause 1 · found gridding [D14812](D14812.md) · filed 2026-11-01 against master `3e96b47e`**

Repro:

    type Circle = { r: i32 | null }
    type K = { r: null }
    function sink(_x: Circle) { }
    function mkcall() { { r: null } }
    sink(mkcall())
    function pick<T>(a: T[], d: T): T { if a.length > 0 { a[0] } else { d } }
    const k: K = { r: null }
    print(pick([mkcall()], k).r ?? 1)

Want:

    1

#### Mechanism

`sink(mkcall())` builds `mkcall`'s record at `Circle`, so the literal `[mkcall()]` holds
`Circle`s. `pick`'s `T` is also bound by `k`, a `K` that is not fresh, so the instance takes
`K[]`. The invalid module fails at the call on line 8, not at `sink`. This row groups its cells by
that failure site and by the narrow pin. Each cell has not been ablated to one mechanism yet.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `sink(mkcall())` | prints `1` | **yes** |
| `k` replaced by `mkcall()` | prints `1` | **yes** |

#### Grading list

Each is the Repro's first five lines with the rest replaced. Every one is invalid wasm at the call:

* `function both<T>(a: T[], b: T[]): i32 { a.length + b.length }`, `const k: K = { r: null }`,
  `const ks: K[] = [k]`, `print(both([mkcall()], ks))`: a second list pins `T`;
* `function first<T>(xs: T[]): T { xs[0] }`, `const k: K = { r: null }`,
  `print(first([mkcall(), k]).r ?? 6)`: a `K` element in the same literal;
* `function first<T>(xs: T[]): T { xs[0] }`, `const y = first<K>([mkcall()])`,
  `print(y.r ?? 16)`: an explicit type argument.
