### D17340 — a module-level `const` initialized by an assignment to a literal-union field or element has no value lowering

**loud emit reject · clause 2 · `vl check` rc 0; `vl run` rc 1, `emitProgram: an assignment used as a value whose type is not its target's has no value lowering` · claimed and claimless alike · found by V2 (queue) verifying #9912 (D17260) · filed 2026-11-24 against master `2ae11435` by lane IR-N11, owner IR-N11**

Repro:

    type K = "zz" | "ww"
    const o: { f: K } = { f: "zz" }
    const c = (o.f = "ww")
    print(c)
    // vl check: no errors. vl run: rc 1, the emit refusal above.

Want:

    ww

#### Mechanism

Not yet located. Legacy refuses the value of an assignment to a literal-union place (`o.f`,
`ks[0]`) when that value initializes a module-level binding. The same assignment inside a function
lowers, as does a `string` field at module level. D16183 (closed) covered the same refusal in a tail
position.

#### Ablation

| ingredient | outcome | needed? |
| --- | --- | --- |
| the binding inside a function (`const c = (o.f = "ww")` in `h()`) | runs | **yes**: module level |
| the field `string` for `K` | runs | **yes**: a literal-union place |
| an element `ks[0] = "ww"` for the field | still refuses | no: a field or an element |
| `c` read from a function or a closure for `print(c)` | still refuses | no |
| a claimless compiler | still refuses | no: legacy's |
