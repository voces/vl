### D4981 — a bare type parameter narrowed by `is K[]` is delivered as `K[]` at an instance whose list cannot be one

**closed · now a loud check reject · was check-clean silently wrong, clause 1 · owner ruling (c) (D4928) applied at the instance: a list that passes `is K[]` only by an empty list's value fit is never delivered as `K[]` where it can be written or kept, and its read-only uses stay legal (`narConvListDelivery`, check_narrow_flow.vl, read by `assignableExprIn` and an un-annotated binding; the instance's arm is live, `isListFitsWhenEmpty`, check_operators.vl) · pins `soundness/list-value-fit-instance-delivery-reject.vl` and `soundness/list-value-fit-instance-read-only.vl` · DECISIONS §"A value-fit list is not delivered at an instance" · filed 2026-10-15 against master `d826b6339`**

Repro:

    function pushOne(xs: f64[]) { xs.push(1.5) }
    function g<V>(v: V) {
      if v is f64[] { pushOne(v) }
      print(v.length)
    }
    const e: i32[] = []
    g(e)
    // PRINTS 0

Want:

    a check error at `pushOne(v)` at the `V = i32[]` instance, naming the copy: the list passes `is f64[]` only as an empty list does, and is still an `i32[]` there

#### Mechanism

`v is f64[]` over a bare `V` narrows the whole value, since `V` may be `f64[]` or a union
holding one, and the delivery is right at those instances. At `V = i32[]` the test is true
for an empty list (D4771), and the arm hands `pushOne` a list the caller does not hold, so
the push is lost. A `V[]` receiver is refused by the checker (D4928), but that refusal would
cost a bare `V` every instance where the delivery is sound, such as `V = f64[] | string`,
so the answer has to come from the instance.

#### Ablation

| change | outcome | needed? |
| --- | --- | --- |
| `function g(v)` (un-annotated) for `g<V>(v: V)` | prints `0` | no, same defect |
| `v: V \| string` for `v: V` | prints `0` from `print(0)` in place of the length | no, same defect |
| `const e: f64[] = []` | prints `1` | **yes** |
| `v: V[]` for `v: V` | check refuses (D4928) | **yes** |
| the concrete `i32[] \| string` receiver | check refuses (D4928) | **yes** |

#### Grading list

- `function g<V>(v: V) { if v is f64[] { pushOne(v) } }` with `const f: f64[] = []` and `g(f)` must keep printing `1`.
