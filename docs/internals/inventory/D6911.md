### D6911 — the result of a function returning an uncalled hole function, handed to a parameter nothing calls, is refused at emit

#### Mechanism

From the ablation only. A returned hole function is served by the stub only when every call of
the returning function drops its result or binds it where its uses are inert. A call result
handed straight to a parameter is neither, and the inert-parameter rung takes only a function's
name as the argument.
