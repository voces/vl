### D6911 — the result of a function returning an uncalled hole function, handed to a parameter nothing calls, is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same result bound unread, or bound and measured in a list, runs ([D6882](D6882.md)); the hole function handed by name runs, `3` · found closing [D6882](D6882.md) · the same on master `43f22053c` · filed 2026-10-19 against master `43f22053c`**

Repro:

    function exclaim(s) { return s + "!" }
    function get() { return exclaim }
    function run(f) { print(3) }
    run(get())
    // vl check: rc 0.  vl run: emitProgram: monomorphize: unsupported argument type for `f` in a call to `run`

Want:

    3

#### Mechanism

From the ablation only. A returned hole function is served by the stub only when every call of
the returning function drops its result or binds it where its uses are inert. A call result
handed straight to a parameter is neither, and the inert-parameter rung takes only a function's
name as the argument.
