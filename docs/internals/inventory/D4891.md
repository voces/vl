### D4891 — an un-annotated list of a written `let` of a generic stores the instance another binding's call picked

**closed 2026-10-16 · runs today and must keep running · was loud emit reject (`a function-value call has no interned signature`), and clause 1 before the L9 `fnNestUsed` gate · closed by L1 (`monoWrittenGenLetFrame` counts a write already delivered at the binding's pin as a write of a generic) · fixture `tests/cases/closures/written-let-of-generic-pinned-write-beside-other-type.vl` · found while closing D3975 · filed 2026-10-15 against master `5be21bb0a`**

Repro:

    function k<T>(x: T): T { return x }
    function main() {
      let f = k
      f = k
      print(f("s"))
      let g = k
      g = k
      const fs = [g]
      print(fs[0](1))
    }
    main()
    // vl check: rc 0.  vl run: emit error, a function-value call has no interned signature

Want:

    s
    1

#### Mechanism

`g` is written and then delivered into an un-annotated list, so the list's element type is
inferred from `g` and no destination fixes the instance `g` holds. Both written bindings of
`k` share the generic's instances, and `g` is stored at `f`'s `string` instance while
`fs[0](1)` calls it at `i32`. Not reached by D3975's split: `g` is called at one type only.

`fs[0](1)` is keyed `>v`, the key of a nullary void function. It was invalid wasm while
`main`'s own `() => void` signature was interned and the call found it. Since the L9
`fnNestUsed` gate, a program with no nested frame interns only the signatures of functions used
as values, so `>v` is missing and the call refuses. The mis-keyed call is the defect in both
outcomes.

#### Close

The write `g = k` is delivered at `g`'s one pin `(i32)` first (D3957's local-write arm), which
renames it to `k`'s `i32` instance. `monoWrittenGenLetFrame` then no longer counted `g` as a
written `let` of generics, because the write no longer named a generic, so the list's pin pass
skipped `[g]` and its seed stayed at `k`, the `string` instance `f`'s call made first. A write
naming an instance of a generic now counts. Ablation: reverting that one test refuses the
fixture again. The later deliveries were graded too:

| position | before | after |
| --- | --- | --- |
| list element `[g]` (the witness) | emit reject | runs, `s 1` |
| two elements `[g, g]` | emit reject | runs |
| a closure `() => g(3)` | check-clean invalid wasm | runs |
| an annotated parameter `ap(g)` | runs | runs |
| a record field `{ q: g }` | emit reject | emit reject, [D5061](D5061.md): a `const` alias fails too |
| returned from an un-annotated function | emit reject | emit reject, [D5062](D5062.md) |
