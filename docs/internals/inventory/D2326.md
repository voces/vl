### D2326 — a value-union local's member set resolves to a DIFFERENT sibling block's binding of the same name, in the narrowing complement's field access

**CLOSED 2026-09-24 — `unionNameOfIdentAt` (the positioned twin of `unionNameOfIdentSid`,
same shape as D2316's `identClosureFeAt`) resolves the function-scope rung through
`parentLetOfAt` instead of `parentLetOfSid`, and skips the param rung while a block shadows
it (`fnBlockShadowsAt`, D2325's guard) rather than answering the OUTER param unconditionally.
`unionDeclTyIxOfIdentAt` and `startBlockLetRowOfAt`/`startBlockLetOfAt` got the same
treatment, and every one of the roughly thirty callers across `emit_classify.vl` and
`wasmEmit.vl` was threaded a real arena position — the reader's own node where one call has
it, or the nearest enclosing statement/condition node where the name is a re-derived string
(a narrowing-stack path key, a `match`/`if` join row) rather than a fresh `Ident` read. Two
callers (`currentNarrowSetOf`/`currentNarrowSetIdOf` and their struct-union twins) grew `*At`
siblings of their own so the position reaches `unionNameOfIdentAt` through them too.**

`unionNameOfIdentSid`, `unionDeclTyIxOfIdentSid` and `startBlockLetRowOfSid` (all in
`compiler/emit_classify.vl`/`emit_base.vl`) resolve "which value union does a name denote"
through `parentLetOfSid` — the UNPOSITIONED primitive D2316 built `parentLetOfAt` beside,
precisely because `parentLetOfSid` collapses two sibling blocks binding one name onto
whichever the scan visits first. Unlike D2325's ladder (`calleeCloSigKeyAt`), none of these
three callers were repositioned in that fix; `unionNameOfIdentSid` does not even take a
position argument.

Repro:

    type A = { x: i32 }
    type B = { y: string }
    type C = { z: boolean }

    function f(): string {
      let out = ""
      {
        const u: A | B = { x: 5 }
        if u is A { out = "\{u.x}" } else { out = "\{u.y}" }
      }
      {
        const u: C | B = { z: true }
        if u is C { out = out + "|inner" } else { out = out + "|\{u.y}" }
      }
      out
    }
    print(f())
    // vl check: rc 0.  vl run: emit error at the inner else-arm's `u.y`:
    //   emitProgram: field access receiver is not a struct

#### Mechanism

The `else`-arm of `if u is T { … } else { … }` reads the narrowing COMPLEMENT: the receiver's
member set minus `T`. Building that complement needs the receiver's CURRENT union name, read
through `unionNameOfIdentSid`. For the second (inner) block's `u`, that lookup runs
`parentLetOfSid(fn.fnBody, sid("u"))`, which returns whichever `const u` the scan recorded
FIRST — the outer block's `A | B`, not the inner block's `C | B` — regardless of which block
the `else` arm actually sits in. The complement of `A | B` minus `C` is nonsensical (`C` is
not even a member), so the field-access lowering for the survivor member (`B`, but keyed
against the WRONG union's layout) fails with "field access receiver is not a struct" rather
than reading `u.y` off the inner binding.

No parameter is needed — this reproduces with two ordinary sibling blocks, the same shape
D2316 already fixed for the closure-signature ladder. The union ladder was simply never
threaded through `parentLetOfAt` when D2316 landed.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the inner `else` arm's `u.y` field read (kept only the `is`-boolean tests) | runs, `5\|inner` | **yes** |
| a closure-typed parameter of the same name (`union-min.vl`: param `u: i32 \| string`, inner block `u: boolean \| string`) | also emit-rejects the same way — the param path shares the mechanism but is not required to reproduce it | no |

#### Grading list

`tests/cases/unions/sibling-blocks-narrow-else-field-read.vl` (this row's own witness) plus a
six-fixture matrix, all of which are `check-clean invalid wasm` or a loud emit reject on the
PRE-FIX seed and RUN with the correct value on the fixed one (verified both ways against a
fetched pre-fix `seed-latest`): `nested-block-shadow-then-revert.vl` (a function-top-level
union shadowed by a nested block, then read again after it closes),
`if-else-arms-different-unions.vl` and `match-arms-different-unions.vl` (the name bound once
per arm to a different union), `sibling-blocks-one-in-loop-body.vl` (one binding inside a
`for` body), `param-shadowed-by-block-const.vl` (a union-typed PARAMETER shadowed by a
block-local `const` of a different union — this row's mechanism plus D2325's), and
`sibling-blocks-value-union-narrow-read.vl` (the VALUE-union / scalar-atom unbox path in
`wasmEmit.vl`, which pre-fix did not merely emit-reject but produced a check-clean **invalid
module** — a clause-1 trap, not just clause-2 hygiene). Every fixture reads its narrowed
value through `is` and a field/atom access; the match/if-else fixtures additionally read
through the shared name a second time in the arm.

#### Positions threaded

Every caller with an arena node uses it directly (`sidOfNode(ix)`, `ix`) — the `Ident`/`Index`/
`Member` receiver itself, or (for the three field-chain walks collecting a dotted path
root-first) the root `Ident`'s own index, tracked through the walk and used instead of the
bare `rootName` string it used to hand to the unpositioned primitive. One walk
(`unionStructArmMapListElemIndex`) had a SECOND root shape — `t0[i].f` indexed through an
element — whose root ident lived in a different local (`rin`, off `cn.idxArr`) than the one
the Member-chain arm reused (`cur`); the position and the sid must come from the same node,
so that walk got its own `rootIx`. A handful of callers have no fresh node at all: the
post-guard join rung (`pushPostGuardNarrow`, keyed on a join row's bare name) and the
null-compare narrowing rungs (`setNarrowFromCond(Else)`, keyed on a receiver name already
extracted by an inner helper) use the enclosing statement/condition node instead — sound
because the binding a join or a null-compare answers for necessarily precedes that node in
the same block, per `parentLetCoversAt`'s own coordinate-space contract. The CAPTURE channel
(`capturedUnionName`) is untouched, same as D2325: it resolves a DIFFERENT function's frame,
a coordinate space this row's `atIx` does not belong to.
