### D16851 — a maker with an annotated parameter, its two call bindings handed to parameters annotated at two signatures, builds invalid wasm

**open · check-clean invalid wasm · clause 1 (`vl check` rc 0) · the one-instance face of [D16850](D16850.md), and the clause-1 face of [D16845](D16845.md) · filed 2026-11-16 against master `a8512d420`**

Repro:

    function adder(n: f64) { return (a) => a + n }
    function take(a: (a: i32) => f64) { print(a(3)) }
    function half(a: (a: f64) => f64) { print(a(0.5)) }
    const x = adder(2)
    take(x)
    const z = adder(2.25)
    half(z)
    // vl check: rc 0.  vl run: invalid module inside `__lambda_0`, type mismatch

    5
    2.75

#### Mechanism

Not traced. `adder` has one instance, whose returned lambda is built at one parameter type, while
the two annotated destinations convert its closure at two signatures; [D16845](D16845.md) refuses
the un-annotated-destination spelling of the same one closure at two signatures.
