### D1935 — a non-null field-source capture with an unguarded read is check-clean invalid wasm when a sibling nullable field-source capture shares the module

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · filed 2026-09-08, surfaced by D1933's fix (a nullable field-source capture no longer refuses, so a sibling's emission is now reached)**

Repro:

    type Rec = { name: string, n: i32 }
    type MaybeRec = Rec | null
    type Two = { label: string, m: i32 }
    function mkval(k: i32): MaybeRec { return { name: "ada", n: k } }
    function mktwo(k: i32): Two { return { label: "z", m: k } }
    if true {
      const srcBox = { it: mkval(3) }
      const held = srcBox.it
      const get = () => held
      const v = get()
      if v != null { print(v.n) } else { print(0) }
    }
    if true {
      const srcBox = { it: mktwo(9) }
      const held = srcBox.it
      const get = () => held
      const v = get()
      print(v.m)
    }
    // vl check: rc 0.  vl run: invalid module, expected (ref $type), found (ref null $type)

#### Mechanism

A field-source capture is classified `nulstruct` (D1476 folds `inner: S` and `inner: S | null`
onto one `(ref null $S)` hop), so `v = get()` reps nullable while the checker types it non-null
`Two`. The unguarded `v.m` is emitted as a non-null field access; its `ref.as_non_null`
recovery holds for the capture ALONE (`two_alone` runs) but a sibling nullable field-source
capture in the same module perturbs it into a `(ref $Two)`-expected / `(ref null $Two)`-found
mismatch. A distinct struct type does not avoid it, so it is not anonymous-shape sharing.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the nullable-witness block (the second block alone) | runs, prints `9` | **yes** |
| the non-null read's block (the first block alone) | runs, prints `3` | **yes** |
| a distinct struct type for the second block | still invalid wasm | no |

#### Grading list

The two blocks each RUN in isolation and must keep running. A fix makes the whole module run
(prints `3` then `9`) by recovering the non-null read to `(ref $Two)` — or, more likely, by
classifying the non-null field-source capture consistently with its unguarded read.
