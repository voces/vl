### D15777 — D15775's record `if` handed to a `const` lambda declared inside a function is refused at emit

**loud emit reject · clause 2 · `emitProgram: this record `if` stores functions of different signatures in one field, and a call through the joined record is lowered at one of them` · the nested named function runs · found closing [D15775](D15775.md) · filed 2026-11-12 against master `b6945ade`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function two() { [1, 2].length }
    function main() {
      const take = (r) => r.f(3)
      const q = if two() > 5 { { f: half } } else { { f: inc0 } }
      print(take(q))
    }
    main()

Want:

    4

#### Mechanism

`ftHoleArg` (check_fn_tag.vl) takes a module-scope `const` lambda's call as a hand to the
lambda's parameter (D15775). Taking a local one the same way tags the set, but emit then refuses
with `a lambda's dispatch arm has no instance built for this call's signature`, so the local case
is left out of D15775's close. Unmeasured beyond that.
