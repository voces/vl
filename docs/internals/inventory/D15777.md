### D15777 — D15775's record `if` handed to a `const` lambda declared inside a function is refused at emit

**loud emit reject · clause 2 · `emitProgram: this record `if` stores functions of different signatures in one field, and a call through the joined record is lowered at one of them` · the nested named function runs · found closing [D15775](D15775.md) · filed 2026-11-12 against master `b6945ade` · bucket (a), slot store, secondary (c) (the 2026-11-14 clause-2 map)**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function two() { return [1, 2].length }
    function main() {
      const take = (r) => r.f(3)
      const q = if two() > 5 { { f: half } } else { { f: inc0 } }
      print(take(q))
    }
    main()

Want:

    4

#### Mechanism

`ftHoleArg` (check_fn_tag.vl) takes a module-scope `const` lambda's call as a hand to the
lambda's parameter (D15775). Taking a local one the same way tags the set, but emit then refuses
with `a lambda's dispatch arm has no instance built for this call's signature`, so the local case
is left out of D15775's close. Unmeasured beyond that.

#### Attempts (2026-11-27, COV-CLOS-2)

Widening `ftCallDeclOf` (check_fn_tag.vl) from module-scope to function-local `const` lambdas,
D15775's rule, gets `{inc0, half}` tagged as in D15775. The witness still refuses: the late
decision tags the one-member set `{take}`, and the dispatch through it meets a lambda arm mono
never instanced (`lambdaArmUnbuilt`, `tag dispatch lambda arm`). Two proxies for "a one-member set
with no dispatch site stays closures" were measured over the 9,813 `tests/cases` programs and
refused. Do not retry them:

| proxy in `ftTry` | runs → not-runs |
| --- | --- |
| every call through the set at one callee type | about 300 |
| at most one call and no mint rows | 26 |

A hole member reached through a container needs ids so each call selects its instance
(`fn-tagged-id-list-three-levels.vl`). The close is the dispatch-site fact: a set needs ids when
some call through it must select the member's instance at the call (coordinator ruling,
2026-11-27).
