### D15777 — D15775's record `if` handed to a `const` lambda declared inside a function is refused at emit

**closed 2026-11-28 — an open argument of a call inside a function nothing enclosing can instance is a hole handed on, as at module scope, so `take(q)` is no call through a one-member set `{take}`; and a function's `const` lambda is the call's declaration in `ftCallDeclOf` (D15775's rule), so `{inc0, half}` is tagged · the I8 holdout leaves the list · filed 2026-11-12 against master `b6945ade`, closed by COV-CALL**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function two() { return [1, 2].length }
    function main() {
      const take = (r) => r.f(3)
      const q = if two() > 5 { { f: half } } else { { f: inc0 } }
      print(take(q))
    }
    main()

Want:

    4

#### Mechanism

Closed (COV-CALL, 2026-11-28). `holeSetCallRetOf` (check_relate_core.vl) noted a call with an open
argument as "a call at a type parameter, typed at each instance of its function" whenever the
cursor was inside any function; at module scope it noted none. Inside `main`, which takes no
parameter, `take(q)` was noted through the set `{take}`, which the late decision tagged with no
instance built for its lambda arm (`tag dispatch lambda arm`). The rule now asks whether a function
enclosing the call can have instances (`holeSetCursorInstanced`); with that, COV-CLOS-2's widening
of `ftCallDeclOf` to a function's `const` lambdas tags `{inc0, half}` as D15775 does. Neither
proxy below was used. Witnesses: `named/d15777_*` (a `const`, a `let`, the other branch, a nested
lambda). Not moved: an enclosing function with an un-annotated parameter (D17782).

#### Mechanism at filing

`ftHoleArg` (check_fn_tag.vl) takes a module-scope `const` lambda's call as a hand to the
lambda's parameter (D15775). Taking a local one the same way tags the set, but emit then refuses
with `a lambda's dispatch arm has no instance built for this call's signature`, so the local case
is left out of D15775's close. Unmeasured beyond that.

decision tags the one-member set `{take}`, and the dispatch through it meets a lambda arm mono
never instanced (`lambdaArmUnbuilt`, `tag dispatch lambda arm`). Two proxies for "a one-member set
with no dispatch site stays closures" were measured over the 9,813 `tests/cases` programs and
