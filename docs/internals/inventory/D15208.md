### D15208 — an expression-bodied arrow whose result is a record holding a list of un-annotated functions is refused at emit

**loud emit reject · `emitProgram: ref valtype with no interned shape` · clause 2 · open · the block-bodied twin (`() => { return [{ fs: [inc0] }] }`) runs since [D15203](D15203.md); a record holding one function runs · found closing [D15203](D15203.md) · present on master `ee1ab028` · filed 2026-11-03 against master `aaf9ba5c`**

Repro:

    function inc0(a) { return a + 1 }
    const mk = () => ({ fs: [inc0] })
    print(mk().fs[0](3))

#### Mechanism

Not traced. The record result of an expression-bodied arrow does not reach the row its body builds, where a block body's `return` does.
