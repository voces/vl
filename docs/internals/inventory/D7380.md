#### Mechanism

`monoPinListElems` gives an un-annotated list the one function type the flow table pins its
element slot at. Its caller ran it only for a list one of whose elements named a generic by
name, a written `let` seeded by one, or a hole lambda (`monoListInitHoldsGeneric`), and an `if`
is none of those, so the arms' generics reached no call that fixed their type. The pin now runs
for every un-annotated list. A pin the flow table can give only at an instance's own template
is not written on a declaration a generic's instances share (`monoDeclPathPinsPerInstance`):
each instance's reads are typed at its own instance there, as before.
