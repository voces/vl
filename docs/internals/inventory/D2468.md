#### Mechanism

`canonEmitNameTs` rewrites a `Map<K, V>` / `Set<T>` application to the index signature it
denotes (#3155), so the union's inline arm lands in the variant table as `{seen:{[string]:i32}}`.
`canonEmitTypeNames`'s `IsExpr` arm rewrites the tested spelling through the generic-application
and transparent-alias rungs only, so `is { seen: Map<string, i32> }` named a variant the table
does not hold. The fix runs `builtinCollNorm` on the tested spelling first.
