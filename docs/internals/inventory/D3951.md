### D3951 — a capture cell seeded with a hole lambda and written with a generic function traps when called

**loads then traps · found in review of #3498 (`rv3498/p17`) · filed 2026-10-10 against master `429e7b093`**

Repro:

    function other<V>(v: V) { print("O"); print(v) }
    function main() {
      let k = (x) => { print("L"); print(x) }
      const flip = () => { k = other }
      k(1)
      flip()
      k(2)
    }
    main()
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch

Want:

    L
    1
    O
    2

#### Mechanism

Not located. The call through the cell pins the hole-lambda seed at `(i32) => void` (D3845),
but the write `k[0] = other` of a declared generic is not instanced at the binding's signature
on that path, so the second call reaches `other`'s default instance.
