#### Mechanism

The elaboration keys a callback's parameter by the list's build (`elabCbAtBuild`), not its
result. A `map` result holding the record would need the result list's storage too, a second
late fact. A parameter annotated `{ f: null }` has no hole and no `#r.0` entry the key could
carry. Both stay refused by `recBuiltCallbackRefuse` (`recCbTakesBuild`).
