### D16099 — a function returning a choice of un-annotated functions whose results agree, its result handed to a generic `(x: T) => R` parameter, is refused at emit

**loud emit reject · clause 2 · ``emitProgram: monomorphize: unsupported argument type for `g` in a call to `app``` · found grading [D16093](D16093.md) · filed 2026-11-14 against master `e5bfe3d6c`**

Repro:

    function inc(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function app<T, R>(g: (x: T) => R, v: T): R { return g(v) }
    function pick2(c: boolean) { return if c { dbl } else { inc } }
    print(app(pick2(true), 3))
    // vl run: the emit refusal above

Want:

    6

#### Mechanism

Not ablated to a line. Where the members' results differ, the same spelling runs: the set is
tagged and the call dispatches. Where they agree, the set is not tagged and the monomorphizer
finds no pin for `g` from the call result (`monoArgTyFail`).
