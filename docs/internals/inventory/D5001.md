### D5001 — a closure in a generic body that calls a generic function at an explicit `<V>` has no parameter valtype

**loud emit reject · clause 2 · found closing [D4982](D4982.md) · filed 2026-10-15 against master `2f625f31e`**

Repro:

    function lenG<W>(xs: W[]) { xs.length }
    function t<V>(a: V[]) {
      const k = () => lenG<V>(a)
      print(k())
    }
    t([1])
    // vl check: rc 0.  vl run: emitProgram: internal: a parameter type the valtype ladder has no rung for

#### Mechanism

The explicit type argument names the enclosing function's type parameter, and the call
inside the lambda reaches the parameter valtype ladder with `V` itself rather than its
instance's binding, so `lenG`'s instance has no parameter type to lower. The inferred call
binds through the argument and runs.

#### Ablation

| change | outcome | needed? |
| --- | --- | --- |
| `lenG(a)` for `lenG<V>(a)` | prints `1` | **yes** |
| `print(lenG<V>(a))` with no closure | prints `1` | **yes** |
| a local `function h() { return lenG<V>(a) }` for the lambda | prints `1` | **yes** |
| `lenG<i32>([2])` in the lambda | prints `1` | **yes** |
