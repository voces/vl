Repro:

    function inc0(a) { return a + 1 }
    const m = Map()
    m["k"] = inc0
    const x = m["k"]
    if x != null { print(x(3)) }
    // vl check rc 0.  vl run: emit error: emitProgram: unsupported map value type (no rep for a union-member struct, ...)

#### Mechanism

Not traced. The map's type is `{[string]: (_) => _}`: the value type keeps the
function's hole signature, because nothing pins it where the value is written, and the
map value layer has no slot for an open function type. A list literal holding the same
function is pinned at its element and runs; a write into a list does not, so this reads
as one gap at writes into an un-annotated container rather than a map-only one.
