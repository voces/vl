#### Mechanism

D1627's residue at one rep. That row gave the anonymous-literal mint a niche rung —
`anonNulFieldCodeOfTy`, which peels a `TyNullable` and codes its inner — and every other
nullable REF rep now mints a row through it. A nullable MAP does not: the rung's first test is
`t is TyNullable` and the recorded type of `{[string]: i32} | null` is not one, so the rung
declines, `anonTySpellable` declines a map too, and the field codes `-1`. With no field code
the whole literal gets no row, and the global's cell asks `fbValtype("struct", -1)` against an
empty struct table — the same one refusal D1627 wore, at the one rep left.

The missing code is 29, whose companion is the mv slot's value name, and both halves already
exist for the ANNOTATED spelling: `shapeFieldElemName`'s code-29 arm reads
`mapValNameOf(nulMapInnerName(ftxt))` off the `| null` text. What the inferred path has is a
type, and the question this row owes is what shape the checker actually records for a nullable
map — a `TyNullable` over `TyMap` would make the fix two arms, and anything else is the real
finding.

A speculative code-29 arm was written and reverted during D1627's close, because it fired for
no cell: dead code in a ladder is worse than an open row.
