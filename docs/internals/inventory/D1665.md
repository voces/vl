#### Mechanism

**The filed mechanism was wrong, and one probe refuted it.** It said the recorded type of
`{[string]: i32} | null` is not a `TyNullable`, so `anonNulFieldCodeOfTy`'s niche rung never
sees a nullable map. An `emitFail` at the top of `anonFieldCode`, then a second one INSIDE the
rung's own `TyMap` arm, printed:

    PROBE anonFieldCode kind=TyNullable<TyMap> emitName={[string]:i32}|null repKind=TyNullable<TyMap>
    PROBE anonNulFieldCodeOfTy TyMap arm REACHED inner={[string]:i32} valName=i32

The recorded type IS a `TyNullable` over a `TyMap`, the rung IS reached, and the arm was a
NAMED EMPTY one carrying the wrong sentence. The second probe is the control the first could
not be: `emitFail` keeps only the first message, so a probe at the caller hides one at the arm.
This is the same shape D1691 closed one element kind over — a niche ladder whose empty arm
reads as an argument.

Three sites, not one. The code alone was never the whole rep: an mv slot's identity is its
(key, value) pair, so the row a nullable-map field belongs to is decided by its value NAME as
well, and both resolvers that ask carried the plain code 19 and not the niche.

* `anonNulFieldCodeOfTy`'s `TyMap` arm returns 29, gated by `mapTyValKindLowerable` — the
  type-taking form of the gate the annotated field position already applies, so a map value the
  mv layer cannot lower keeps refusing loudly. `anonFieldElemName` and `anonFieldElemKeyI32`
  supply the value name and the key column, and `anonCodeAdmitsValue` admits the code once the
  companion resolves.
* `structIndexOfObjCtx`'s map arm was `vc == 19`; two `#anon` rows sharing a field name and
  disagreeing about the map's value type merged onto one layout. Without this the fix moved
  the twin-holders spelling **loud → check-clean invalid wasm**, which the matrix caught.
* `shapeFieldTypeCompatK`'s name-side twin had a `want == 19` arm and no `want == 29`, so the
  same two rows collided again when an un-annotated MAP resolved its value row by rendered
  shape name — the `map_value` position, and the only cell of the twin-holders matrix that was
  still silent after the first two sites were built.
