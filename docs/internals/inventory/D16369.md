#### Mechanism

`const n = pick(false)` makes the module's quiet pre-pass infer `pick`, before `ap2` and `ap3`
have results that type `f(add)`, and the pre-pass publishes `pick`'s result as an unsolved hole.
A call of `pick` reached that hole and, the result not being pending, never checked `pick`'s body,
so `m["k"] = pick(true)` stored a value of no type. The call now treats a published result
holding a hole as provisional while pass 2 has not checked the body, and checks it first, as it
does a pending one. Fixture: `tests/cases/closures/hole-relay-set-map-store-declared-after-the-call.vl`.
