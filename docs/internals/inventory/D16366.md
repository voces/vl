#### Mechanism

`fieldCodeOfTyCovered` codes a field that is a list of an integer-literal union as an `i32`
list, but a list of one integer literal is a `TyLit` element, not a union, so no rung coded it.
A lone integer literal now counts as its one-member union (`nfcIsIntLitUnion`). One past `i32`,
`9000000000[]`, is coded as an `i64` list, its base.
