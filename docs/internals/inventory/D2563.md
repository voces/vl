### D2563 — a join of two instances of one generic record is invalid wasm even under an annotation that names it

**check-clean invalid wasm · clause 1 · found grading [D2373](D2373.md)'s close, which leaves generic instances out of the joins it registers · filed 2026-09-26 against master `71571e409`**

Repro:

    type Box<T> = { item: T }
    function mkX(): Box<i32> | null { return null }
    function mkY(): Box<string> | null { return { item: "y" } }
    function go() {
      const y: Box<i32> | Box<string> | null = mkX() ?? mkY()
      print(y == null)
      if y is Box<string> { print(y.item) }
    }
    go()
    // vl check: rc 0.  vl run: invalid module, inside `go`:
    // "type mismatch: expected (ref null $type), found (ref null $type)"

#### Mechanism

A prediction until a close confirms it, and it may need a ruling first. The same union is
refused by a DESIGN rule when a literal is built into it (`const y: Box<i32> | Box<string> =
{ item: "w" }` reports `arms Box<i32> and Box<string> share a field-name set and no
literal-typed field distinguishes them`), yet the annotation itself is accepted, a plain call
into it runs, and a `??` or an `if` joining the two instances is emitted at one instance's
niche. D2373's close registers only joins whose records are declared (`cStructTyIxSet`), so a
generic instance is outside it by construction. Question for the owner: is a union of two
instances of one generic record legal at all? If not, the checker owes the refusal at the
annotation, not only at the literal; if so, the join needs a row and a discriminant the
instances do not carry.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| a plain call into the annotated binding (`= mkY()`) | runs, `y` | **yes** |
| the `??` as an `if` joining the two calls | loud emit reject, `` `is` test but no union type declared `` | no |
| a non-null `Box<string>` default | loud emit reject, the same | no |
| an object literal into `Box<i32> \| Box<string>` | check reject, the design rule above | no |

#### Grading list

Each ablation row, and the un-annotated `const y = mkX() ?? mkY()`, which is the same
check-clean invalid wasm.
