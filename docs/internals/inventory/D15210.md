    function sink(_x: Circle) {}

#### Mechanism

`c` is built at `Circle` and `k` at `K`, so the call's rep row is mixed (`callBindRepMixedAt`).
`[k]` is built at `K[]`, but the instance stored its parameter at `Circle[]`. A `T[]` annotation is
pinned through the instance's one `T`, which `c` binds at `Circle`, while `{ f: T }` takes the
composite path and is pinned at the elaboration's own type for the parameter; that is why the
field reach ran. And `callArgRepTy` widened the list to the row's `Circle[]`, which a body reading
`b[0]` used. The body never touches `_b`, so no relation is needed: this is not D15129's.
