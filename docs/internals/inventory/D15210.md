### D15210 — a generic instanced mixed at a list reach, a bound fresh call wider at one parameter and a held record inside a list literal at another, builds the list at the wrong record

**open · check-clean invalid wasm · clause 1 · found closing [D15129](D15129.md) · filed 2026-11-03 against master `6e694945e`**

Repro:

    type Circle = { r: i32 | null }
    type K = { r: null }
    function sink(_x: Circle) {}
    function mkcall() { { r: null } }
    const c = mkcall()
    sink(c)
    const k: K = { r: null }
    function ignore<T>(a: T, _b: T[]): T { a }
    print(ignore(c, [k]).r ?? 6)

Want:

    6

#### Mechanism

`c` is built at `Circle` and `k` at `K`, so the call's rep row is mixed (`callBindRepMixedAt`).
At a record-field reach (`{ f: k }`) the mixed instance pins each argument at its rep and runs.
At a list reach the list literal `[k]` is built at the instance's element record, not at `K`,
while its element is read as `K`. The body never touches `_b`, so no relation is needed: this
is a build-site defect, not D15129's.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `sink(c)` (`c` not built wider) | runs | **yes** |
| `[k]` → `[c]` (one record) | runs | **yes** |
| `_b: T[]` → `_b: { f: T }` (field reach) | runs | **yes** |
