### D3056 — a record list the program writes is refused as a `readonly` list of a union holding its record, though a view of it is now built

**loud check reject · clause 2 pending a ruling · the ref twin of [D3040](D3040.md) · found closing [D3041](D3041.md) · filed 2026-09-28 against master `6c2dafc0b`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    let a: Circle[] = [{ r: 1 }, { r: 2 }]
    const b: readonly Shape[] = a
    a[0] = { r: 7 }
    const e = b[0]
    if e is Circle { print(e.r) }
    // vl check: a Circle[] cannot be assigned to readonly Shape[] here: the list is WRITTEN
    // THROUGH (line 6), and a covariant list assignment is read-only.

Want:

    7

#### Mechanism

`covarWriteThrough` refuses a record list delivered as a list of union boxes wherever
`covarValueWriteState` answers 1, because D791's copy was a snapshot. Since D3041 the emitter
builds a view for such a delivery, and the view reads through its source, so for a `readonly`
destination the refusal names a copy that is no longer made. The same program with the source a
parameter of a callee (`function view(xs: Circle[]): readonly Shape[] { return xs }`) is
accepted and prints `7`. The message reads as a rule ("a covariant list assignment is
read-only"), so lifting it is the same language question as [D3040](D3040.md): does a
`readonly` view of a wider element observe writes to its source? Recommendation: yes, lift it
for a `readonly` destination only, and keep the mutable one refused by DECISIONS.md A9. Not
lifted here. `noteRefListView` runs after the refusal returns, so lifting it also means
recording these deliveries.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| no write after the delivery | runs, prints `1` | **yes** |
| the same `a` delivered through a callee's `return xs` (`view(a)`) | runs, prints `7` | **yes** (a root the analysis does not follow) |
| a `.push` instead of an index store | same refusal | no (store form) |
| destination `Shape[]`, not `readonly` | refused by design (A9) | the `readonly` destination is the case |
