### D2750 — a field read of an element of a list literal built for a union destination has no lowering

**closed 2026-10-26 — now prints `3` `3` · was loud emit reject, clause 2 · the checker adopts the literal at `Shape[]` and the element read takes the record arm from its stamp, so the destination lookahead that built a box list behind the checker is deleted · filed 2026-09-26 against master `92bed043d` · pin: `tests/cases/lists/list-literal-adopts-union-list-read-as-record.vl`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    function sum(xs: Shape[]): i32 { xs.length * 3 }
    const out = [{ r: 3 }]
    print(out[0].r)
    print(sum(out))
    // vl check: rc 0.  vl run: emitProgram: field access but no struct type declared

#### Mechanism

`out` checks as `{r: i32}[]`, so `out[0].r` is a record field read, but the destination scan
builds `out` as a `Shape` box list for `sum` (`letRefListDestSlot`). The element read yields
the box, and the field read lowers against a record the value is not: at module scope the
read is emitted anyway, inside a function the struct-field rung finds no row and refuses. The
generic spelling `first(out).r` reached the same read once D2747 pinned `first` at `Shape[]`,
and moved from invalid wasm to the loud refusal. A read of an element known to be the arm the
checker says it is needs the payload cast the `is`-narrowed read already emits.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `Shape[]` destination (`sum(out)`) | runs | **yes** |
| the enclosing function (module scope) | the same loud emit reject (invalid wasm before [D3093](D3093.md)) | no |
| `out[0]` bound first (`const e = out[0]`, `e.r`) | loud emit reject | no |
| the index read through a generic `first<T>(xs: T[]): T` | loud emit reject | no |

#### Grading list

The in-function spelling (`function f() { const out = [{ r: 3 }] … }`), the bound element,
and `first(out).r`.
