### D16484 — `??` over a list cell whose index has a side effect is refused at emit

**loud emit reject · clause 2: `vl check` rc 0, then emitProgram: ?? over this nullable value is not supported yet; the re-readable index runs since D16483 · found closing D16483 · filed 2026-11-15 against master `713bc0259`**

Repro:

    import { F32x4, splatF32 } from "std:simd"
    let n = 0
    function idx(): i32 {
      n = n + 1
      0
    }
    const xs: (F32x4 | null)[] = []
    xs.push(splatF32(1.0))
    print((xs[idx()] ?? splatF32(0.0)).x)
    print(n)

Want:

    1
    1

#### Mechanism

The null test D16483 lowers to reads the cell twice, so an index that is not re-readable
(`exprReReadable` refuses a call) cannot take it. It needs the cell stashed once, as the
value-union box arm does for a call operand whose result is a box. Not yet ablated past that.
