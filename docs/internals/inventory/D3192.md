### D3192 — a generic or hole instance calling a record's nullable `() => boolean` field prints its result as an i32

**closed · a call through a hole reads its pin's function through a `| null` (`holePinReadAt`, and `substHoleTyReal` for a generic instance), so the call's result is the function's own return · fixture `tests/cases/generics/hole-call-through-nullable-function-field.vl` · was check-clean silently wrong · clause 1 · pre-existing, the same on master `36d233f66` · found by the #3286 review (`rv3286-2159/g/c0123_bool_same_bool_n_i32_hole.vl`, `c0124_…_generic.vl`) · filed 2026-09-29 against master `36d233f66`**

Repro:

    type R = { v: i32, f: (() => boolean) | null }
    function F(z) { print(z.f()) }
    F({ v: 7, f: () => true })
    // PRINTS 1

Want:

    true

#### Mechanism

The literal is laid out at `R`'s row, so the instance binds `z` to a record whose `f` is
`(() => boolean) | null`. The call's type is an `HD_RET` hole over the field, and both readers
of it, `holePinReadAt` (a hole instance) and `substHoleTyReal` (a generic instance's re-check),
asked for a `TyFunc` and got the nullable, so the result stayed a hole and `print` fell to the
`i32` sink. A call runs only through the function, so both now read the non-null face (`callPinFnTy`),
except where the function's result is a nullable literal union, which is
[D3198](D3198.md) and stays as on master. The record bound at a nullable field and called
without a null test is [D3197](D3197.md).

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `type R` removed | prints `true` | **yes** (a row whose field is the nullable function) |
| `R`'s `f: () => boolean` (not nullable) | prints `true` | **yes** |
| `print(x.f())` on a module binding, no function | prints `true` | **yes** (an instance) |
| `function F<Z>(z: Z)` in place of the hole | prints `1` | no |
| `const r: { v: i32, f: (() => boolean) \| null } = …; F(r)`, no declared `R` | prints `1` | no |
| `function F(z: R)`, the body null-testing `z.f` before calling it | prints `true` | **yes** |
