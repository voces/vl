### D1764 — a `??` over a nullable STRUCT-UNION box named its result through a producer that excludes an all-variant union

**closed 2026-09-06 · was a loud emit reject · filed against master `e9c5665c6` · 0 corpus cells**

Repro:

    type A = { r: i32 }
    type B = { s: i32 }
    type Sh = A | B
    function lhs(): Sh | null { return null }
    function dflt(): A { return { r: 7 } }
    const w = lhs() ?? dflt()
    if w is A { print(w.r) } else { print(0) }
    // prints 7

#### Mechanism

A re-readable operand never reaches the emitter as a `??`: `emit_rewrite` desugars it to an
`if`, gated on `exprReReadable`. A CALL operand keeps the `??` and needs the box arm, which
coerces the default into the RESULT union and declines when that union has no name. Measured
2026-09-06, one `emitFail` at the floor:

    nulBox=46 isNulBox=1 coNm=[] lhsUn=[A|B|null] nulVar=0 nulStruct=0 nulStr=0

The arm IS entered and the OPERAND's union resolves; only the `??` node's own name is empty.
The two faces read two producers: the desugared face falls through to `nodeRegisteredUnionName`,
while the fused face stopped at `nodeMixedUnionName`, which excludes an ALL-variant join
(`A | B`) by design because it wants a value atom beside the variant. `nodeVariantUnionName` is
the sibling that asks only for a variant arm, and is what `coalesceResultUnionName` — the one
home for "the union a `??` result reps as" — already uses. The fused arm now falls through to
it, so both faces name the join from one producer and `exprUnion` answers true for the node.

**A candidate was refused first, and its price is recorded**: coercing the default into the
OPERAND's union instead makes the arm fire and moves the cell from a loud refusal to
check-clean invalid wasm, because the consumer's cell is still not the box. That is D969's
shape one union kind over, and it is what says the close is the RESULT NAME.
