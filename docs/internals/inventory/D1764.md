### D1764 — a `??` over a nullable STRUCT-UNION box with a call LHS names no result union, so the box arm declines

**loud emit reject · filed 2026-09-06 against master `e9c5665c6` · 0 corpus cells**

Repro:

    type A = { r: i32 }
    type B = { s: i32 }
    type Sh = A | B
    function lhs(): Sh | null { return null }
    function dflt(): A { return { r: 7 } }
    const w = lhs() ?? dflt()
    if w is A { print(w.r) } else { print(0) }
    // vl check: rc 0.  vl run: exit 1,
    // emitProgram: `??` over this nullable value is not supported yet — narrow it first, e.g. `if v != null { … }`

#### Mechanism

A re-readable operand never reaches the emitter as a `??` at all: `emit_rewrite` desugars it
to an `if`, gated on `exprReReadable`. A CALL operand keeps the `??` and needs the box arm
(D960), which coerces the default into the RESULT union — and declines when that union has no
name. Measured 2026-09-06, one `emitFail` at the floor:

    nulBox=46 isNulBox=1 coNm=[] lhsUn=[A|B|null] nulVar=0 nulStruct=0 nulStr=0

The arm IS entered (`isNulBox=1`) and the OPERAND's union resolves (`A|B|null`); only the
`??` node's own union name is empty. `Sh | null` joined with `A` is a pure STRUCT union, which
`nodeMixedUnionName` excludes by design (it wants a value atom beside the variant) and which
`nodeRegisteredUnionName` reaches only through the canon index.

**A candidate was refused, and its price is this row's.** Falling back to the OPERAND's union
name — the fallback the sibling re-readable arm already takes, since box tags are
program-global — makes the arm fire, and the cell moves from a loud refusal to **check-clean
invalid wasm**: the consumer's cell is not the box, because `exprUnion` still answers false for
this node. That is D969's shape one union kind over, and it says the close is the RESULT
NAME, not the coercion target.

#### Ablation
