### D2674 — a `T | null` parameter pinned at a union `T` lowers as the first member's nullable niche

**closed 2026-09-26 — the filed repro RUNS and prints `true` · was check-clean invalid wasm · clause 1 · closed with D2734: `T | null` at a union argument binds `T` to the argument's members, so the pin is the union and its value box · found grading D2493's close (the #3189 reviewer's `pin/p15`) · filed 2026-09-26 against master `525837973` · fixture `tests/cases/generics/pin-inferred-from-union-argument.vl`**

Repro:

    type R = { a: i32 }
    type S = { b: i32 }
    const v: R | S = { a: 1 }
    function k<T>(u: T | null): boolean { u is R }
    print(k(v))
    // vl check: rc 0.  vl run: invalid module — type mismatch: expected (ref null $type), found (ref $type)

#### Mechanism

At `T := R | S` the instance's parameter `T | null` is the union `R | S | null`, whose rep is the
value box; the instance lowers it as a nullable niche of one member (a `(ref null $R)` for records,
`(ref null $map)` for maps), and the caller hands it the box. The direct spelling
`function j(u: R | S | null)` runs, so the defect is the pin's respelling of `T | null`, not the
union.
