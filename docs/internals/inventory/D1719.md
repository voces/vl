### D1719 — a narrowed union arm READ AT AN INDEX PLACE is check-clean invalid wasm: the receiver ladder keys an `Ident` and a `Member` and not an element

**closed 2026-09-06 · filed as a missing list-element rep, which the disassembly refuted:
the element rep is the box and it is stored correctly · 0 corpus cells**

Repro:

    type A = { r: i32 }
    function st(): A { return { r: 8 } }
    function pick(b: boolean) { if b { return st() } return 7 }
    const xs = [pick(true)]
    if xs[0] is A { print(xs[0].r) } else { print(0) }
    // prints 8

#### Mechanism

The element rep was never missing. `array.new_fixed` stores the `(ref $uBox)` `pick` returns
into a `(ref null $uBox)` element slot, which is a legal subtype; the failing instruction is
the `struct.get $A 0` the READ emits on a box it never unwrapped, and the elided sentence is
`expected (ref null $A), found (ref $uBox)`.

An `is`-narrowed struct arm is the one narrowed rep whose read does not unbox, so every
consumer recovers the payload itself (D1031). All four functions that answer "which arm is
this receiver narrowed to" keyed an `Ident` name or `memberPathKeyOf`, and neither answers for
`xs[0]` — so the nine already-wired delivery boundaries and `emitNarrowedMem` all declined.
They ask `placeNarrowKeyOf` now, the keyer D1014 added for exactly this.
