#### Mechanism

Every other delivery of a mixed union works — a binding, an argument, a relayed return, a
declared struct field and an anonymous struct field all print `8` — and a VALUE union in the
same list position runs. The element is where it stops: the list's element slot and the value
the literal stores disagree by one nullability, `(ref null …)` against `(ref …)`.

**It is not D1709's registration.** Declaring `type M = i32 | A` and annotating the binding
`const xs: M[]` refuses identically, so the row exists and the element rep is still missing —
which is what separates this from the family D1709 closed, where the annotation was the whole
difference.
