#### Mechanism

`const c = x` under `x is boolean` holds the unboxed arm: the binding boundary replays the
narrowing and reads the box's payload. A closure capturing `c` asks two classifiers what `c` is,
neither under that narrowing. The env field (`captureValKind`) classifies `c`'s initializer in
the owning frame, and a module frame has no locals, so `x` resolves to the global's union and the
field is the box; in a function frame the locals are not registered either, so a `string` arm
fell to the classifier's `i32` default. Return inference for `() => c` classifies the same way,
so a closure yielding `c` declared a box result. The close gives each captured binding set from a
narrowed read its arm's annotation (`synthNarrowedReadAnn`, widened from the numeric arms to
`boolean` and `string`, and asking the arena through the `let` chain when the frame cannot
resolve the name) in a pass that runs before return inference (`synthCaptureReadAnns`).
