### D4346 — calling a record FIELD narrowed to the function arm of a value union refuses at emit

**open · loud emit reject · clause 2 · found grading D3269's fix, the same on master `c87e4eef8` · filed 2026-10-13**

Repro:

    function mk(b: boolean): (() => i32) | string { if b { return () => 7 } return "s" }
    type H = { f: (() => i32) | string }
    const hh: H = { f: mk(true) }
    if hh.f is () => i32 { print(hh.f()) } else { print("else") }
    // vl check: rc 0.  vl run: emitProgram: callee is not a function name

Want:

    7

#### Mechanism

Not localised. The `is` test itself lowers (the matrix's `struct_field_init` cells run); the
call through the narrowed member read has no callee lowering. [D2016](D2016.md) is the same
message for a function-typed field of a narrowed union ARM, which is a different receiver.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the field (a local `const f = mk(true)`) | runs, `7` | **yes** |
| the declared alias (inline union, as here) | still refuses | no |
| the call (`print(2)` in the arm) | runs | **yes** |
