### D4346 — calling a record FIELD narrowed to the function arm of a value union refuses at emit

**closed 2026-10-13 · runs · was loud emit reject, clause 2 · found grading D3269's fix, the same on master `c87e4eef8` · filed 2026-10-13 · pins: `tests/cases/closures/narrowed-fn-arm-place-call.vl`, `scripts/capability-probes/matrix/narrowed-fn-arm-place-call.matrix.vl`**

Repro:

    function mk(b: boolean): (() => i32) | string { if b { return () => 7 } return "s" }
    type H = { f: (() => i32) | string }
    const hh: H = { f: mk(true) }
    if hh.f is () => i32 { print(hh.f()) } else { print("else") }
    // vl check: rc 0.  vl run: emitProgram: callee is not a function name

Want:

    7

#### Mechanism

`exprIsClosure` answered false for a place (`h.f`, `xs[0]`, `m["a"]`), so the call took the
direct-callee path and found no function name. It now answers true for a place whose
narrowing key is narrowed to the bare-closure arm, and for a member read the checker typed
as the function arm at a receiver no narrowing key reaches (`hs[0].f`); that read channel
(`memReadCheckerAtomKind`/`memReadBoxedAtomKind`, [D209](D209.md)) now names the closure atom.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the field (a local `const f = mk(true)`) | runs, `7` | **yes** |
| the declared alias (inline union, as here) | still refuses | no |
| the call (`print(2)` in the arm) | runs | **yes** |
