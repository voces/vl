### D16172 — `is Set<T>[]` over a union of a list of sets and a scalar has no interned arm

**closed 2026-11-16 · runs, prints `true` · was loud emit reject, `emitProgram: is names a declared union member with no interned arm representation (deferred value-union composition)` · clause 2 · fixed in wasmEmit.vl: a list of Sets shares its element slot with the boolean-map list, so `isArmTagOfTy` gives it no tag; at the receiver its slot's tag names it where the receiver's union holds it and no other member at that slot (`isArmTagOfTyAt`, which reads the slot and never mints one) · pins: `tests/cases/unions/is-set-list-arm-of-union.vl`, `tests/cases/unions/is-set-list-arm-beside-bool-map-list.vl` · found closing D16047 (lane F) · filed 2026-11-14 against master `a1e5fe53d`**

Repro:

    const s: Set<i32> = Set()
    const u: Set<i32>[] | i32 = [s]
    print(u is Set<i32>[])

Want:

    true

#### Mechanism

`isArmTagOfTy` declines every list of Sets (D2753): its element slot is shared with the
boolean-map list, so the slot's tag alone could be either. The receiver's union decides it: where
the union holds the Set list and nothing else at that slot, the tag is the Set list's.
