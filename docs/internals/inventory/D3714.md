#### Mechanism

The lift is decided per declaration and keyed by `(frame, let)`, while a callback
specialisation (and a generic or `.map` clone) emits the same `LetDecl` from a second
frame. Re-enabling it needs the decision to hold in every frame that emits the declaration:
key the binding by the declaration alone (`cloLiftLetFe` ignoring the frame for a shared
node), check that each emitting frame binds every capture by the same name, and decline when
`monoBakeCallback` rewrote the lambda's own body (it captures the callback), since the
lifted slot then no longer is the function that frame calls.
