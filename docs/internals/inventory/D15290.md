### D15290 — a value `if` whose arms are records holding a list of one un-annotated function, returned or bound, has no interned rep shape at emit

**closed · runs, prints `4` · was loud emit reject `emitProgram: ref valtype with no interned shape` · clause 2 · found closing [D15208](D15208.md) · filed 2026-11-04 against master `306ef2b8` · closed by lane G2 with [D15300](D15300.md): a value `if` or `match` arm's tail record is a holder where the choice holds the set**

Repro:

    function inc0(a) { return a + 1 }
    function mk(b: boolean) { return if b { { fs: [inc0] } } else { { fs: [inc0] } } }
    print(mk(false).fs[0](3))

Want:

    4

#### Mechanism

fn-tag tags a list of a function set only where every holder above it sits in a place that reads the set's ids (`ftHoldCtxOk`). A value `if`'s arm is a `Block` whose own type is not the record's, and an arm is no function body's tail, so the record in each arm is no holder, the set stays untagged, and its untagged list field has no field code (`anonFieldCode` -1): the record gets no row.

#### Close

`ftHoldCtxOk`'s `Block` arm now accepts an `if` or `match` arm's tail where the choice itself
holds the set, and an `else if` link where its outer choice does (`ftArmTail`,
`ftHoldsDecided`), so the choice is the holder in its place and its own position is judged one
level up as any holder's is.
