### D4340 — `==` against a literal refuses over a union whose literal arm is a declared ALIAS beside a record arm; the inline spelling runs

**closed 2026-10-13 · runs today and must keep running · was loud emit reject · clause 2 · found porting `regress.py` (`pathKind(p) != "file"` over `FileKind | IoError`) · filed 2026-10-13 against master `656c92059`**

Repro:

    type E = { code: i32 }
    type K = "a" | "b"
    const v: K | E = "a"
    print(v == "a")

Want:

    true

#### Mechanism

The union-against-concrete compare (`emitUnionConcreteEq`, `compiler/wasmEmit.vl`) gated on the
box being a value union, a value union carrying a litunion arm, or the operand's atom having a
banked arm. `K | E` is none of the three: the record arm makes it no value union, and the alias
arm `K` has no banked `string` kind. The box nonetheless carries `K` as its member string, which
`unionTakesAtomAsStr` already answered for the static-false fold below the gate, so the gate
refused a compare the lowering serves. Fixed by asking that question before the gate.
`scripts/capability-probes/matrix/alias-litunion-record-union-eq.matrix.vl`: 64 of 64 cells
run (both faces), all `emit refuses` before. Fixtures:
`tests/cases/unions/alias-litunion-record-eq-literal{,-unann}.vl`.
