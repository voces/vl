### D4340 — `==` against a literal refuses over a union whose literal arm is a declared ALIAS beside a record arm; the inline spelling runs

**loud emit reject · found porting `regress.py` (`pathKind(p) != "file"` over `FileKind | IoError`) · filed 2026-10-13 against master `656c92059`**

Repro:

    type E = { code: i32 }
    type K = "a" | "b"
    const v: K | E = "a"
    print(v == "a")
    // vl check: rc 0.  vl run: emitProgram: `==` over a struct union is not supported yet

Want:

    true

#### Mechanism

Not yet localised between the two `struct union` refusals in the union `==` lowering
(`compiler/wasmEmit.vl`). The literal arm reaches the compare as the alias name `K` rather than
as its members, so the literal operand `"a"` is not recognised as an arm the box carries; the
same union spelled inline, `"a" | "b" | E`, runs and prints `true`. Every std caller comparing
`pathKind(...)` (`FileKind | IoError`) to a literal hits it.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the alias (`"a" \| "b" \| E` inline) | runs, `true` | **yes** |
| the record arm (`v: K`) | runs | **yes** |
| `==` replaced by `if v is K { print(v == "a") }` | runs, `true` | **yes** |
| the binding (a function returning `K \| E`) | still refuses | no |
| `==` → `!=` | still refuses | no |

#### Grading list

`import { pathKind } from "std:fs"` then `print(pathKind("x") != "file")`; the same compare with
the literal on the left (`"a" == v`); a `K | E | null` box.
