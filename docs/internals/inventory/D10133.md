#### Mechanism

The call's argument check bound `T` only where the argument spelled the union itself
(`bindGenUnionArm`, top level only), so for `() => i32` against `() => T | string` the instance
read `f()` as the box `i32 | string` while the lambda was emitted at its own result `i32`, with
no adapter between them. `bindGenFnRetUnionArm` (check_relate_core.vl) descends a function
type's result and binds the open member from the argument's result where that result fits no
other member. With the binding in hand, `checkCallOnFuncTy` (check_calls.vl), outside a quiet
re-check, re-delivers the argument at the bound function type through `fvaAdapt`, which wraps
it as `(): i32 | string => f()`.
