### D14001 — an `if` of `{f: 1}` and `{f: t}` in a generic body builds the literal record at the pin's field type

**trap after load · clause 1 · open · was check-clean invalid wasm until the emitter stored the `{f: t}` arm in the field's union box · found grading [D14000](D14000.md)'s arm-order grid · filed 2026-10-26 against master `01cfbcdeb`, pre-existing (invalid in both arm orders before and after D14000)**

Repro:

    function g<T>(t: T, b: boolean): i32 {
      const v = if b { {f: 1} } else { {f: t} }
      print(v.f)
      0
    }
    print(g("s", true))
    // vl check: rc 0.  vl run: wasm trap: cast failure at `print(v.f)`

Want:

    1
    0

#### Mechanism

Two halves, ablated by probe on `2f8428da3`.

**Check.** The if-join records its kept-apart join for every pin to re-check (`noteTpJoinRow`,
D2832), but only when that join is a union. The record arms merge fieldwise, to `{f: i32 | T}`,
so no row was written; and the pin filters (`tpIfPinCheck`, `tpIfCmpNode`) asked for a union of
LISTS, while the pinned record join is `{f: i32 | string}`. Both filters now ask whether the
pinned join reaches a union of any kind, so the annotated `{f: T}` cells and the runtime-arm
cells at `T := string` are refused (at the call, and at the `r` arm respectively).

**Read, open.** The `{f: t}` arm now stores `t` in the field's union box and the module
validates. The read then traps: the template join drops `{f: 1}`, so the checker types `v` as
`{f: T}`, `v.f` is `string` at the pin, and the read unboxes the box to `string`. With
`b = false` the box holds the string and the program runs
(`tests/cases/generics/if-join-record-literal-string-pin-else-arm.vl`). [D14021](D14021.md) stays open for the join.

**Emit, still open.** The un-annotated witness re-checks clean at the pin — `{f: i32 | string}`
is a legal type for `v` — and the emitter has no struct row for that join, because a widened
record join is minted only when the checker's `recordJoinMinted` flag is set, and the
type-parameter join never sets it. That half is [D14021](D14021.md), and this witness closes
with it. The `T := f64` half is closed: the if blocktype read the template's raw rep stamp,
`{f: T}`, in every instance, and it now reads the per-instance rep type (`nodeRepTyAt`), so the
un-annotated and `{f: T}`-annotated cells at `f64` run in both arm orders
(`tests/cases/generics/if-join-record-literal-f64-pin.vl`).
