### D3396 — an `else if` link whose arms all exit is typed `void`, so a binding of the chain cannot be filled

**loud check reject · clause 2 · most of the #3315 review's `agrid.py` refusals · filed 2026-09-30 against master `8df60e472`**

Repro:

    type R = { x: i32 }
    function t(n: i32) {
      let w = if n == 1 { null } else if n == 2 { return } else { return }
      w = { x: 7 }
      print((w ?? { x: 9 }).x)
    }
    t(1)
    t(2)
    // vl check: cannot assign {x: i32} to void | null

Want:

    7

#### Mechanism

Not traced. The join leaves out an arm that always exits (D3222), but an `else if` link both of
whose arms exit is itself typed `void`, and the outer join then takes `void` as an arm's value
rather than leaving the link out. The binding is `void | null`, and the fill is refused. The
same chain written as a nested `else { if … }` is left out and runs.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `else { if n == 2 { return } else { return } }` | runs, `7` | **yes** (an `else if` link) |
| `else { return }`, one exiting arm | runs, `7` | **yes** |
