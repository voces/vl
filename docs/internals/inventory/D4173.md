### D4173 — a generic's returned join of a `K` pin, `null` and a non-member string prints the string as a member

**check-clean silently wrong · clause 1 · open · the same on master `faabd3e87` · found by the D3336 position matrix (`{nullarm,matchnull}_generic_ret_un`) · filed 2026-10-11**

Repro:

    type K = "a" | "b"
    function g<T>(a0: T, k: i32) {
      if k == 0 { a0 } else if k == 1 { null } else { "z" }
    }
    const x0: K = "a"
    print(g(x0, 0))
    print(g(x0, 1))
    print(g(x0, 2))
    // vl check: rc 0.  vl run: prints `a`, `null`, `b`

    a
    null
    z

Not traced. The result is read as the `K | null` niche, so `"z"` is an atom id printed as a
member of `K`.
