**now a loud emit reject · clause 2 · open · silently wrong on master `faabd3e87` · found by the D3336 position matrix (`{nullarm,matchnull}_generic_ret_un`) · filed 2026-10-11**

Repro:

    type K = "a" | "b"

      if k == 0 { a0 } else if k == 1 { null } else { "z" }
    }

#### Mechanism

The instance's result is the `K | null` niche the checker's `T | null` result synthesises
(D2037), so the gradual `T` absorbs the `"z"` arm and the join is read as an atom. Since #3572
the return lowers a `string | null` join into that niche arm by arm and refuses a string leaf
naming no member, rather than writing its id; clause 2 stays open until the instance's result
is `string | null`.
