### D15923 — a call's list of records whose function field holds un-annotated functions returning different types, stored in a record literal's field, has no shape at emit

**loud emit reject · `emitProgram: ref valtype with no interned shape`, no position · clause 2 · open · found by w320 beside [D15804](D15804.md); a neighbour of [D15194](D15194.md) and [D15303](D15303.md) · filed 2026-11-12 against master `22d35fe47`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function mk() { return { a: [{ f: inc0 }, { f: half }] } }
    const w = { f: mk().a }
    print(w.f[0].f(3))

Want:

    4

#### Mechanism

Not traced. The list reaches the record literal from a call: the same list literal written in
the field runs, as does the call's list bound to a name and read directly. The functions'
differing results are needed, since the one-result twin runs. w320 reports the same message
when the list is returned through a second function or stored as a map value.

#### Ablation

| spelling | outcome |
| --- | --- |
| the witness | loud emit reject |
| the literal in the field, `const w = { f: [{ f: inc0 }, { f: half }] }` | runs, `4` |
| the call's list bound, `const xs = mk().a; xs[0].f(3)` | runs, `4` |
| one result type, `half(a) { return a * 2 }` | runs, `4` |
