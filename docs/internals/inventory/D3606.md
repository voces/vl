### D3606 — `x ** y` said "expected an expression but found STAR", with no pointer to `powF64` (sunpa SP-031)

**now a loud check reject, raised at the parse stage (parse error), that names `powF64` with the author's operands (fixed 2026-10-04) · the refusal was always right, because VL has no power operator; its message named a token · filed and closed by lane SC against master `c473889d1` · fixture `tests/cases/parser/power-operator-error.vl`**

Repro (`vl check` must refuse at 2:9 with "VL has no `**` operator; use `powF64(c, 2.2)` from `std:math` (or `powF32`)"):

    const c = 0.5
    print(c ** 2.2)
    // master: parse error "expected an expression but found STAR" at 2:10, then "expected `,` but found `2.2`"

#### Mechanism

The lexer has no `**` token, so `c ** 2.2` lexes as `*` `*`, and the second `*` reached
`parsePrimary` as an operand. `parseBinary` (`compiler/parser.vl`) now checks, at a `*`, whether
the next token is a `*` or a `*=` written directly after it (`powOpTail`). If so,
`parseNoPowOp` raises one diagnostic spanning both tokens and parses the right operand so it
raises nothing more. When every token of both operands is a name, a number or plain punctuation,
the message spells the call with the author's operands (`powF64(xs[0], 2.0)`), and for `**=` the
assignment (`x = powF64(x, 3.0)`). Otherwise it reads `powF64(a, b)`. A parse diagnostic could
span only its anchor token, so the end token is kept in a sparse side table
(`dgMarkSpanEnd`/`dgSpanEndTok`, `compiler/ast.vl`), which `diagEndTok` (`compiler/driver.vl`)
reads. No token kind was added.

#### Ablation

| spelling | message |
| --- | --- |
| `c ** 2.2` | `powF64(c, 2.2)`, spans `**` |
| `c **= 3.0` | `**=`, `c = powF64(c, 3.0)`, spans `**=` |
| `(a + b) ** 2.0`, `a ** -1.0`, `xs[0] ** 2.0 + 1.0` | the operands spelled; the `+ 1.0` is not taken |
| `a ** "x".length as f64` | `powF64(a, b)` |
| `a ** a ** a` | one diagnostic at each `**` |
| `a * *a` (a space between) | unchanged: "expected an expression but found STAR" |
| `a * b`, `a *= 3` | unchanged |
