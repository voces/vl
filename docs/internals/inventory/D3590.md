### D3590 — `e is L` over an `i64` literal union, where `e` is not a re-readable place, folds to `false` without evaluating `e`

**check-clean silently wrong · clause 1 · open · the `i64` residue of [D3570](D3570.md) · filed 2026-10-03 against master `7073d9d03`**

Repro:

    type B = 5000000000 | 6000000000
    type C = 1 | 3000000000
    function fi(x: i64): i64 { x }
    function fm(): i64 { 1 }
    print(fi(5000000000) is B)
    print(fi(7) is B)
    print(fm() is C)
    // vl run: false, false, false

Want:

    true
    false
    true

#### Mechanism

[D3570](D3570.md)'s: the membership test reads its receiver once per member and so claims only a
re-readable place, and anything else falls to `monoStaticIsResult`'s name fold, which answers
`false`. D3570 reads an `i32` receiver once into a fresh slot; an `i64` receiver needs a fresh
`i64` slot, which the lazy frame does not yet mint.
