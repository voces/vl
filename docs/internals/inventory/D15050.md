    const a: {[string]: string} = Map()

#### Mechanism

Not traced. The join of `{[string]: string}` and `{[string]: string | null}` is the wider map
(D2666), and the value `if` spelling of the same join runs, so the `??` lowering delivers its
left operand at the narrower map's own struct where the binding holds the wider one. The
validator reads `expected (ref null $3), found (ref $4)` at the `??`.
