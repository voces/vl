### D16839 — a list of un-annotated functions held below the top of a generic's argument is refused at emit

**open · loud emit reject · clause 2 (`vl check` rc 0) · split from [D16739](D16739.md) by ablation: a list held in a record, a list in a list, or a list an `if` chooses · filed 2026-11-16 against master `551ddc056`**

Repro:

    function id(x) { return x }
    function inc0(a) { return a + 1 }
    const r = id({ l: [inc0] })
    print(r.l[0](3))
    // vl check: rc 0.  vl run: emit error, `monomorphize: unsupported argument type for `x` in a call to `id``

Want:

    4

#### Mechanism

Not traced. The list of hole functions is written as a part of the argument, not as the argument
itself: the same list handed to `id` directly (`id([inc0, half])`) runs, so the argument type is
asked of a list rep nested below the argument's top.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the list as the argument itself (`id([inc0])`) | runs, `4` | **yes**: the nesting |
| no generic (`const r = { l: [inc0] }`) | runs | **yes**: the generic parameter |
| `inc0` annotated (`(a: i32): i32`) | runs | **yes**: the hole function |
| a list in a list (`id([[inc0, half]])`) | the same message | no |
| a list an `if` chooses (`id(if c { [inc0, inc1] } else { [inc1, inc0] })`) | the same message | no |
| two functions of different result types | the same message | no |

#### Grading list

- `id([[inc0, half]])`, read `xs[0][1](3)`.
- `id(if c { [inc0, inc1] } else { [inc1, inc0] })`, read `xs[1](3)`.
