### D4656 — a function returning a union with two exits never makes its tail call

**closed 2026-10-14 · runs — the witness prints `done` · `emitTailCallRet` no longer declines a function that takes the union-box return sink · fixture `tests/cases/functions/tail-call-depth-void-union-indirect.vl` · was trap after load (call stack exhausted) · filed 2026-10-14 against master `43c852e79`**

Repro:

    function walk(n: i32): i32 | string {
      if n == 0 { return "done" }
      return walk(n - 1)
    }
    print(walk(1000000))
    // vl check: rc 0.  was, vl run: wasm trap, call stack exhausted in `walk`

Want:

    done

#### Mechanism

A function whose result is a union box routes its returns through a sink: the box's fields go
to two locals and a branch to one exit block. A returned call has no box to sink, so that exit
already ended in a plain `return`, but `emitTailCallRet` refused every function with the sink,
so the call was never rewritten. The callee returns the same box type, so `return_call` is
valid there exactly as `return` was.
