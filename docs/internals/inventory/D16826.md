### D16826 — a maker's nested record holding an un-annotated function, read without a binding, is refused at emit with "object literal field count does not match struct"

**loud emit reject · clause 2 · found closing [D16738](D16738.md) · filed 2026-11-16 against master `c25e97852`**

Repro:

    function inc0(a) { return a + 1 }
    function mk2(f) { return { r: { f: f } } }
    print(mk2(inc0).r.f(3))
