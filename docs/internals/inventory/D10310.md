#### Mechanism

Not traced. Emit finds no pin for the argument of `run`'s function parameter when the generic
reaches it through an un-annotated function's return or through two list reads
(`const xs = [id]`, `const ys = [xs]`, `run(ys[0][0], 2)` refuses the same way, though
`const ys = [[id]]` runs), while a `const` alias or one
list read pins it.
