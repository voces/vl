### D2761 — `is A` over a union whose arm is spelled by its shape (`{v:i32}`) finds no variant named `A`

**loud emit reject · clause 2 · the annotated structural spelling, and D2727's un-annotated literal once it builds · identical on master · filed 2026-09-27 against master `f6db92e0d`**

Repro:

    type A = { v: i32 }
    function f() {
      const x: ({ v: i32 } | string)[] = [{ v: 2 }, "s"]
      const y = x[0]
      if y is A { print(y.v) }
    }
    f()
    // vl check: rc 0.  vl run: emitProgram: `is` names a declared union member with no interned arm representation

#### Mechanism

The checker accepts `y is A` because `A` and `{v: i32}` are one type structurally. The emitter
registers the union with the arm spelled as written, `{v:i32}`, and the `is` lowering asks
`variantIndexOf("A")`, a name lookup, which has no row. `variantRowOfTy` deliberately has no
structural rung (two same-shape variants are different variants), so the fix is not a
structural fallback at the test: the likely close is registering an arm that equals a declared
struct under that declaration's name, as the annotated `(A | string)[]` spelling does. A
structural fallback at the `is` alone was tried and reached the next layer (`field access
receiver is not a struct` in the narrowed arm), because narrowing asks by name too.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the declared `A` (`is string` instead) | runs | **yes** |
| the shape spelling (`(A \| string)[]`) | runs | **yes** |
| the annotation (D2727's `[{ v: 2 }, "s"]`) | the same refusal | no |
