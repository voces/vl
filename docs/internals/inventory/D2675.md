Want:

#### Mechanism

`i32MapSpellingLowerable` (emit_collect) admits an integer-keyed map as a binding, parameter,
return, union member, array element, closure RESULT, map value or field, and refuses every other
spelling it meets. A function-type annotation is split only for its result, so an integer-keyed
map among its PARAMETER types reaches the refusal. A closure literal whose own parameter is the
same type lowers (`const g = (x: IM | string) => x is IM` runs), so what is refused is the
spelled function type, not the closure.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the integer key (`{[string]: i32}`) | runs | **yes** |
| the spelled function type (a closure literal `(x: IM \| string) => …` instead) | runs | **yes** |
| a union around the map (`(IM \| string) => boolean`, the reviewer's form) | the same refusal | no |
| the generic (the reviewer's `k<T>(u: T, f: (T) => boolean)` at `T := IM \| BM`) | the same refusal | no |
