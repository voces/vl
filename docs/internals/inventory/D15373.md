### D15373 — a fresh literal a generic builds wider and hands back, handed on at its own type, is refused or not by whether the write scan's index is built

**loud check reject · `this {y: i32, x: i32} is stored at V … type-valid but not supported yet` · clause 2 · open, target `2` then `9` · found by the bundle lane measuring [D15185](D15185.md)'s verdict pin · filed 2026-11-04 against master `98f227f3`**

Repro:

    type V = { y: i32, x: i32 | string }
    function k(v: V) { v.y }
    function back<T>(v: T): T {
      k(v)
      v
    }
    function f(q: { y: i32, x: i32 }) { q.x }
    print(back({ y: 2, x: 9 }).y)
    print(f(back({ y: 2, x: 9 })))

Want:

    2
    9

#### Mechanism

Not ablated past the table. The program is type-valid, as the refusal says. Whether it is refused
depends on whether the write scan's node index (`cwIxUp`, `cwIxUpKind`, `cwIxUpAux`, `cwIxParent`)
is built when a checker reader asks: several readers guard with `x < cwIxUpKind.length` and answer
"no" on an unbuilt index. A build where every reader builds the index first runs the program and
prints `2` then `9` (measured by the bundle lane; not landed, +21% peak live). The reader whose
answer flips is not yet named.
