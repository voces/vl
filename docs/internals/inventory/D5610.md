### D5610 — a void generic returned bare from an un-annotated function is delivered with no value on the stack

**closed 2026-10-17 — now prints `6` · was check-clean invalid wasm · `vl check` rc 0 · clause 1 · the same on master `7fe51e77c` · pin: `tests/cases/generics/void-generic-value-returned-bare.vl` · `fn-value-generic-instance.matrix.vl`, `return_inferred`, un-annotated face · found closing [D5400](D5400.md) · filed 2026-10-17 against master `7fe51e77c`**

Repro:

    function show<T>(x: T) { print(x * 3) }
    function d() {
      return show
    }
    const v = d()
    v(2)
    // vl check: rc 0.  vl run: invalid module, type mismatch: expected a type but nothing on stack

Want:

    6

#### Mechanism

From the ablation only. The generic's result type is the ingredient: the same delivery of a
value-returning generic runs, and so does a concrete void function. `monoCoerceRetAtPin` does
deliver the value at `(i32) => void`, so the invalid code is emitted after the delivery, where
`d`'s inferred result is lowered with a value expected from a void-typed return.

The disassembly shows where it is: `$d` returns the closure and the `call_indirect` is at the
void `$fnsig`, but the statement `v(2)` is followed by a `drop` with nothing to drop. The
statement's drop decision asks `calleeReturnsVoidAt`, whose key ladder
(`calleeCloSigKeyAt`, `emit_classify.vl`) read the binding's initializer `d()` and returned
its type's key unconditionally. That type is the generic's uninstantiated `(x: T) => void`,
which renders no key, and an empty key reads as "returns a value". The call itself is keyed
by `cloCallSigKey`, which falls back to the callee node's own type, `i>v`, so the two
disagreed. Fixed there: the initializer rung and the copy rung (`const w = v`, which recursed
into the same empty answer) answer only with a non-empty key and otherwise fall through to
the callee's own type. Graded by `fn-value-generic-instance.matrix.vl` (`return_inferred`
un-annotated SILENT before, RUNS after; 0 runs → not-runs, 0 → silent).
