### D16019 — a record value whose own row is not its place's record has no value lowering as an assignment's value

**closed · runs, prints `2` · was loud emit reject, clause 2 · fixed 2026-11-14: the write moves ahead of its statement and the statement reads the value at its own record · residue of [D16016](D16016.md) · filed 2026-11-14 against master `1c8a267ef`**

Repro:

    type A = { x: i32 }
    type B = { x: i32, y: i32 }
    type H = { p: A | null }
    const h: H = { p: null }
    const b: B = { x: 1, y: 2 }
    function yOf(q: B): i32 { return q.y }
    print(yOf(h.p = b))

Want:

    2

#### Mechanism

The assignment yields `b` at `B`. The place stores `A`'s record, a narrower row, so neither its
re-read nor its parked cell is a `B`: delivering the value needs it kept in a local of `B`'s own rep
before the store converts it. D16016's record rung yields the cell only when the value has no row
of its own or the place's row, so this is refused rather than delivered at `A`'s rep.

#### Closed (2026-11-14)

D2398's move of a value-position write to a wider name (`assignValueSpill`, `compiler/emit_rewrite.vl`)
now takes a field or element write too: a named record value whose record is not the place's
(`asvPlaceRecordMoves`) moves ahead of its statement as `spillWrite` spills it, receiver, index and
value in source order, and the statement reads the spilled value at `B`. Operands passed before the
target still bound the move. A right-hand side that reassigns the receiver stores into the object
read first. Graded on `scripts/capability-probes/matrix/wider-record-write-value.matrix.vl`: 8 of
54 to 54 of 54, 0 silent.

A write whose right-hand side changes an operand read before the target
(`print(k + yOf(h.p = nb()))`, `nb` writing `k`) does not move, and keeps the loud refusal.
