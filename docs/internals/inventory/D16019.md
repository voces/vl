### D16019 — a record value whose own row is not its place's record has no value lowering as an assignment's value

**loud emit reject · clause 2 · residue of [D16016](D16016.md) · filed 2026-11-14 against master `1c8a267ef`**

Repro:

    type A = { x: i32 }
    type B = { x: i32, y: i32 }
    type H = { p: A | null }
    const h: H = { p: null }
    const b: B = { x: 1, y: 2 }
    function yOf(q: B): i32 { return q.y }
    print(yOf(h.p = b))

Want:

    2

#### Mechanism

The assignment yields `b` at `B`. The place stores `A`'s record, a narrower row, so neither its
re-read nor its parked cell is a `B`: delivering the value needs it kept in a local of `B`'s own rep
before the store converts it. D16016's record rung yields the cell only when the value has no row
of its own or the place's row, so this is refused rather than delivered at `A`'s rep.
