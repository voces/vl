#### Mechanism

Two DECISIONS rules meet here: an assignment yields its right side, and a literal is built at the
width of the position that reads it (D2617). The arms adopt the `i64` cell's width for the STORE,
but the assignment's VALUE is the value `if` at its own type, the 32-bit pattern: every neighbour
below prints `-2` while the cell holds `4294967294`. Only this spelling fails, so the tail's value
is lowered at the stored width where the closure's result is the `i32` join: `cboxYieldTail`
(a captured name) and `spillWrite` (a field or element) yielded the temp the cell's width built.
The same tail into an `f64` cell is D14797.
