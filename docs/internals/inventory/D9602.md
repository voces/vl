### D9602 — a list built from an un-annotated function parameter, returned from two calls and read by `.map` at two types, has no list type

**closed 2026-10-22 by lane-D9553 · runs, prints `4` `2.5` · was loud emit reject, `index access but list type not collected`, `vl check` rc 0 · clause 2 · closed by reading a call's list result from the return annotation its instance was given at its pin when the callee resolves to that instance (`monoInstAnnRetTy` from `monoPinnedRetAnnTy`, emit_mono.vl) · fixture `closures/hole-fn-list-returned-read-at-two-types.vl` · with [D9553](D9553.md) and [D9601](D9601.md) · found closing [D9552](D9552.md) · filed 2026-10-22 against master `8789642ad`**

Repro:

    function inc(a) { return a + 1 }
    function deliver(g) { return [g, g] }
    const v = deliver(inc)
    print(v.map((f) => f(3))[1])
    const w = deliver(inc)
    print(w.map((f) => f(1.5))[0])
    // vl check rc 0.  vl run: emit error: emitProgram: index access but list type not collected

Want:

    4
    2.5

#### Mechanism

Traced. The two calls do take two instances of `deliver`, `deliver` and `deliver$1`, and each
is given a return annotation at its own pin: `((i32) => i32)[]` and `((f64) => f64)[]`. The
second `.map` resolves its receiver's call to `deliver$1` itself, and `monoPinnedRetAnnTy`
answered -1 for any callee with a return annotation, so the receiver had no list type and the
lambda kept its open instance. The first call resolves to the template and was read through
[D9552](D9552.md)'s `monoCallInstRetTy`, which is why it alone ran.

#### Grading list

Two functions of different types, `deliver(inc)` read at `i32` and `deliver(half)` with
`half(a) { return a / 2.0 }` read at `f64`, refuse the same way. On master both spellings
refuse earlier, with `call to unknown function`, as [D9552](D9552.md). So does the list of a
generic `function id<T>(x: T) { x }` handed in (`sel(id)`) and read by `.map` at `i32` and at
`string`, bound or inline, now with `string index access but string list type not collected`.
