### D2630 — a closure that stores an object literal into a module binding of a struct union emits invalid wasm

**check-clean invalid wasm · clause 1 · open · filed 2026-09-26 against master `06930fb68`, found
by the review of #3184 (the same on both seeds)**

Repro:

    type A = { r: i32 }
    type B = { s: string }
    function src(): A | B { return { r: 3 } }
    let x: A | B = src()
    function go() {
      const k = () => { x = { s: "b" } }
      k()
      if x is B { print(x.s) }
    }
    go()
    // vl check: rc 0.  vl run: the module fails to validate inside `k`
    // (expected (ref $type), found (ref $type))

#### Mechanism

Not yet ablated to the rung. The write inside the closure builds `{ s: "b" }` at a heap type that
is not the one the module global of `A | B` stores; the same write in the body of `go` runs, and
so does the same closure over a local. No narrowing is needed.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| a local `let x: A \| B` in `go` | runs, prints `b` | **yes** (a module binding) |
| the write in `go`'s body, not a closure | runs | **yes** (a closure) |
| an `is A` narrowing around the closure | invalid wasm the same way | no |
