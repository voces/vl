### D2919 — a generic call on a hole list literal's element prints a `boolean` pin as `1`

**check-clean silently wrong · clause 1 · open · 1 cell of the lane TR grid (`lit__gen__bool`) · the same on master `0284dc2a8` · filed 2026-09-27 against master `0284dc2a8`**

Repro:

    function id<T>(t: T): T {
      return t
    }
    function h(x) {
      const l0 = [x]
      print(id(l0[0]))
    }
    h(true)
    // vl check: rc 0.  vl run: prints `1`

Want:

    true

#### Mechanism

Not localised. The argument `l0[0]` is typed at the hole's variable, so `id` is instantiated, or
its call typed, at that variable and `print` reads the `i32` rep. The same read bound to a local
first, or `x` passed directly, prints `true`.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const z = l0[0]` then `id(z)` | runs, `true` | **yes** |
| `print(l0[0])` without `id` | runs, `true` | **yes** |
| `h<U>(x: U)` | runs, `true` | **yes** (the hole) |
