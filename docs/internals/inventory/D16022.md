### D16022 — a record-list literal argument whose element type is open pins by its element's name, since no spelling of its type exists

**runs today and must keep running · carried past step 7 as a floor (coordinator, 2026-11-13) · 7 programs (8 decisions) of the sweep population · filed 2026-11-13 against master `32ab5241`**

Repro:

    function inc0(a) { return a + 1 }
    function take(a) { print(a.f(3)) }
    function use(v) { take(v[0]) }
    use([{ f: inc0 }])

Want:

    4

#### Mechanism

`monoArgTyNameRep`'s record-list literal arm pins the argument at the literal's own list type
(#7762). Here that type is open: `{f: (_) => _}[]`, the hole function `inc0` not yet bound. No
speller names an open type, so the arm falls back to `arrElemSuffixed` of the element's name,
`#anon0[]`: a row handle that `nameToTy` parses back into the pin's type. The elaboration does
not close it at this site either:
- at the top level (`fnIx` -1), `elabNodeTyAt` answers `_`;
- in a generic template, `((U) => void)[]` still holds the enclosing type parameter.

#### Ablation

| spelling | element type at the pin | outcome |
| --- | --- | --- |
| the witness | `{f: (_) => _}[]` | element-name fallback; runs `4` |
| `inc0` annotated `(a: i32): i32` | closed | the arm is not reached (an earlier rung pins it); runs `4` |
| `generic-fn-value-at-enclosing-type-param.vl`, a function list inside a generic | `((U) => void)[]` | element-name fallback; runs |

#### Grading list

Closing it needs a closed type for the literal from a later stage. For a hole function, that is
the parameter type of the callee instance that the call's elaboration key fixes (`callKey`). For
an enclosing type parameter, it is the enclosing instance's binding (`monoInstBindTyOf`).
