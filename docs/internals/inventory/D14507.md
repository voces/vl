#### Mechanism

The read-back delivery gated on the read's base being a map, so `c["k0"]` delivered `c` but
`g1[0]`, a list read, delivered nothing. The literal kept its own row while `gp` was typed
`Circle`. The rule is now one rule over containers. The un-annotated spelling (`const gp =
g1[0]`) ran before and still does, because the read's annotation is the only `Circle` the
program delivers to.
