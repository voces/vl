### D15186 — a map of hole-typed function values stored in a record field and read back is refused at emit

**loud emit reject · `emitProgram: ref valtype with no interned shape` · `vl check` rc 0 · clause 2 · open, target `1.5` · found closing [D15163](D15163.md) by the `captured-alias-of-hole-fn-map` matrix (its `struct_field_init` position, un-annotated face) · sibling of [D15187](D15187.md) · filed 2026-11-03 against master `13529861`**

Repro:

    function half(a) { return a / 2.0 }
    const fnMap = Map()
    fnMap.set("b", half)
    const w = { f: fnMap }
    const v = w.f
    const g = v.get("b")
    if g != null { print(g(3)) }
    // Want: 1.5

#### Mechanism

The value read back out of the record field has no interned ref shape for a map whose function value type has holes, so the emitter refuses the read. The same map read through a plain local alias runs, and so does the record field read when the function is annotated.

| the annotation-free face (annotate `{ [string]: (f64) => f64 }`) | runs | **yes** |
