### D3438 — a closure's null test of a scalar field a write narrowed to non-null is refused at emit

**closed 2026-09-30 — the witness prints `false` · was loud emit reject, clause 2, pre-existing on master `c00198389` · the #3321 review's `h/r3d` · filed 2026-09-30 against master `c00198389`, closed against master `47aa2950b` by the change that closes [D3419](D3419.md) · fixture `tests/cases/closures/closure-reads-cell-at-checker-narrowing.vl` (its cell twin)**

Repro:

    function g(x: i32) {
      const q: { s: i32 | null } = { s: null }
      q.s = x
      const f = () => q.s == null
      print(f())
    }
    g(7)
    // vl run: emitProgram: bare null needs a struct-typed context

#### Mechanism

Not localised past the ablation. The checker reads `q.s` inside the closure at its declaration,
since the write's narrowing does not reach a nested function; the emitter replays the field's
narrowing into the closure (`capNarrowReplays`) and lowers `== null` over the unboxed `i32`.
The `<T>` spelling ran on master only because its instance lost the write's narrowing.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `print(q.s == null)` outside the closure | prints `false` | **yes** (the closure) |
| `() => q.s ?? 0` | prints `7` | **yes** (a null test) |
| a bare name `let s: i32 \| null` | prints `false` | **yes** (a field) |
| a `string \| null` field | prints `false` | **yes** (a scalar field) |
| the same at module scope | the same emit refusal | no |

#### Close

Closed by [D3419](D3419.md)'s change: the checker banks the field key whose write narrowing it
drops in the closure, and the emitter no longer replays that narrowing there, so `q.s == null`
lowers over the field's box.
