#### Mechanism

`monoBindCols` (emit_mono.vl) binds an instance's type parameters per parameter with
`bindGenWalk` and then `bindGenUnionShapedArmInto`, which binds the open member `U[]` of a
union-shaped parameter from the argument. That second step matched only a parameter whose own
type is the union, so through a function type's result the narrowed complement `T[]` had no
binding in the instance, and the receiver classifier found no list for `t.length`. It now
descends a function type's parameters and result and binds wherever the argument's position is
itself a union. Where the argument is narrower (an un-annotated `() => [1, 2]`, result `i32[]`),
it binds nothing, as before: that function's result is not the box the instance reads, and
binding `T` there turned the loud refusal into invalid wasm.
