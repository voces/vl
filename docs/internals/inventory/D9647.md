### D9647 — a list literal of a record of an un-annotated function handed to an un-annotated parameter that passes the element on leaves the function unpinned

**loud emit reject · `vl check` rc 0 · `emitProgram: cannot take the generic function `inc0` as a value` · clause 2 · found closing [D9570](D9570.md) · the un-annotated `argument` cell of matrix `hole-fn-record-list-element` · present on master `9e81d3ee3` · filed 2026-10-22 against master `9e81d3ee3`**

Repro:

    function inc0(a) { return a + 1 }
    function take(a) { print(a.f(3)) }
    function use(v) { take(v[0]) }

#### Mechanism

Not traced. `use` is pinned at `{f: (_) => _}[]`, so the instance of `take` it calls is handed
an open field and nothing pins `inc0`.
