### D17480 — a generic body's overloaded member call picks again at an instance whose receiver is `<error>`, so a second, wrong ambiguity refusal rides beside the real error

**loud check reject, fixed 2026-11-24 by lane O2 · the program is still refused, now with only the redundant cast's error · `ovPinCheck` (compiler/check_demands.vl) records an `<error>` receiver's instance with no pick and reports nothing of its own · fixtures `tests/cases/methods/error-overload-local-error-receiver-instance.vl`, `tests/cases/methods/error-overload-local-wider-receiver-instance.vl` (the control: a real ambiguity still reports), `tests/cases/methods/error-overload-local-undeclared-argument-instance.vl`, `tests/cases/modules/err-overload-error-receiver-instance/` · filed 2026-11-24 against master `cea354ff6`, found by IR-V3 verifying #9946**

Repro:

    type A = { x: i32 }
    type B = { y: string }
    function describe(self: A): string { return "A" }
    function describe(self: B): string { return "B" }
    function show<T>(v: T) { print(v.describe()) }
    show({ x: 2 } as A)
    // vl check: rc 2; was two errors, now only the second:
    //   `.describe(…)` on <error> matches more than one of `describe(self: A, …)` (`A` first)
    //   and `describe(self: B, …)` (`B` first): the receiver's shape is declared under more
    //   than one name — rename one import with `as` (parameter `v` of `show`, used at 5:32)
    //   this value is already `A` here, so the `as` cast does nothing — drop it

#### Mechanism

The redundant `as` makes the argument `<error>`, so the call pins `show`'s `T` at the error type.
`ovPinCheck` (compiler/check_demands.vl) still picks from the set for that instance:
`ovPickFor(row, <error>)` finds every candidate accepting the error type, so it answers `*`,
and `ovRefuseMsg` reports an ambiguity. The advice is wrong twice: there is no import to
rename, and the receiver has no shape. The pin should stay silent on an `<error>` receiver,
the way the other instance checks defer to the error that made it. The same row shows with
two imported candidates (O1), so it predates the intra-module extension.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `as A` (pass a declared `const a: A`) | runs, prints `A` | **yes** (any error-typed argument does it: `show(nope)` shows it too) |
| the second candidate `describe(self: B)` | only the cast error | **yes** |
| the generic (`function show(v: A)`) | only the cast error | **yes** |

#### Grading list

The two-import spelling (`import { A, describe } from "./a"`, `import { B, describe } from
"./b"`), and `show(nope)` with an undeclared argument: each must report only its own error.
