#### Mechanism

`(string | null)[]` and `string[]` share one rep, the string list, so they share one box tag
(kind 9). `emitListIsAcrossReps` had an element test for a shared tag only when the tested list
has a literal-union leaf (`LIST_ARM_ATOMS`); with a `string` leaf it declined, and the plain
tag test answered `true` for any `(string | null)[]` value.

| an argument literal `f(["b", null])` in place of the binding | the same wrong `true` | no |
