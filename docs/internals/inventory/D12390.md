### D12390 — `??` over a generic nullable map with a map default is not read as a map inside the generic

**loud emit reject · `vl check` rc 0 · `emitProgram: index receiver is not an array or string` · clause 2 · open · found on lane L1 measuring `coalesceOfNulMapIsMap` · present on master `8a21c79bc` · filed 2026-10-24 against master `8a21c79bc`**

Repro:

    function h<T>(o: Map<string, T> | null, d: T) { const z = o ?? Map<string, T>(); z["a"] ?? d }
    print(h(null, 3))
    // vl check rc 0.  vl run: emit error: emitProgram: index receiver is not an array or string

Want:

    3

#### Mechanism

Not traced. The value is `Map<string, T> | null` coalesced with a `Map<string, T>`. Inside
the generic, the result is not classified as a map. `coalesceOfNulMapIsMap` (emit_classify.vl)
is gated on `exprNullableMap` of the left side. Asking the instance's type there, with
`nodeTyAt` in place of `nodeTyIxOf`, moves none of the spellings below, so that read is not
the gap.

#### Grading list

`h(mk(1), 2)` and `h(null, "s")` with a generic `mk<T>(v: T): Map<string, T>`. The
un-annotated `function h(v, d, c: boolean)` building `o` by an `if` over `mk(v)` and `null`.
