#### Mechanism

A `push` or `set` whose value's function set differs re-pins the closed element with the join
(`elabFnRecJoin` and `elabFnRecJoinDeep`, through `tyPinElem`/`tyPinVal` in `check_member_call.vl`
and `check_operators.vl`, D15929, D15806). A row shared by structure would carry one holder's set to
every holder of the same type. The close keys the element on its set id (S2b), so the join mints a
row rather than writing one.
