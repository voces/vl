Repro:

    // vl check: rc 0.  vl run on master: invalid module, "type mismatch: expected (ref null $type), found (ref $type)"

#### Mechanism

A union-valued map (mv value kind 2) stores each value as the module's one shared union box, so
its vals list is the same whatever the union's members are. The checker agrees: both values are
the boxed storage class, so the delivery shares the map. But `repMapValSlotsTwin` twinned two
kind-2 slots only when their canonical value ids matched, so `i32 | string` and
`i32 | string | f64` minted two map structs and the shared map was the wrong one at the
destination. The close twins every pair of kind-2 slots of one key rep, so they are one struct;
where two such maps meet in a union, D2690's per-type tags tell them apart.
