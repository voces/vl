### D9172 — a list of un-annotated functions with different results, called inside a `.map` callback, is refused at emit and not at check

**closed 2026-10-29 · runs, prints `1.5`: the element's set joins the function written into it, and a call through the element runs the member it holds ([D14646](D14646.md), D3975 A) · was a loud check reject from 2026-10-21, `cannot write 'half' to an element of 'xs'`, and before that loud emit reject, `emitProgram: call to unknown function`, `vl check` rc 0 · clause 2 · DESIGN: the annotated twin is refused at check (`cannot assign (i32) => f64 to (i32) => i32`) · found closing [D9093](D9093.md) · filed 2026-10-21 against master `c2df9510f` · closed by letting D9060's judge read a `.map` / `.filter` callback's parameter as an element of the receiver (`cwElemCallbackRecv` and its `cwSlotPath` arm, check_write_scan.vl; `holeLetReadsOf`, `holeSlotJudge`, check_relate_core.vl) · fixtures `closures/hole-fn-list-results-differ-called-in-callback.vl`, `closures/hole-fn-list-literal-results-differ-called-in-callback.vl`, `closures/error-hole-fn-let-repointed-results-differ-called-in-callback.vl`, `closures/error-hole-fn-record-list-results-differ-called-in-callback.vl`, `closures/error-fn-list-param-write-other-result.vl`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const xs = [inc0]
    xs[0] = half
    print(xs.map((f) => f(3))[0])
    // vl check: cannot write 'half' to an element of 'xs': called at (i32) it returns f64,
    // where 'inc0', also written to it, returns i32

#### Mechanism

D9060's judge refuses a write whose function returns another type when the element is called
directly; the call inside a `.map` / `.filter` callback was not one it read, so the program
reached emit, where D9093's agreement check declined the pin. A lambda's first parameter
handed to `.map` / `.filter` is now a read path `<receiver>[]`, so the judge collects the
callback's calls as reads of the element and refuses with the same sentence a direct call
gets.

The annotated twin (`inc0(a: i32): i32`, `half(a: i32): f64`) is refused at check with
`cannot assign (i32) => f64 to (i32) => i32`, so the program is ill-typed and the refusal is
the checker's.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `.map` (`print(xs[0](3))`) | check refuses | **yes** |
| `half` (`dbl(a) { return a * 2 }` in its place) | runs, `6` | **yes** |

#### Grading list

The literal `[inc0, half]` read by `.filter`, a re-pointed `let xs = [inc0]; xs = [half]`, a
write through a parameter `put(ys) { ys[0] = half }` and records `[{ f: inc0 }, { f: half }]`
read by `rs.map((r) => r.f(3))` (`cannot store 'half' in 'rs[].f'`) are all refused at check.
`dbl` in `half`'s place still runs.
