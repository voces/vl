    function id<T>(x: T): T { return x }

      const rs: ((x: T) => T)[] = []
      rs.push(...[id])

#### Mechanism

Not traced past the ablation. The spread source `[id]` is a list literal of a generic function name.
Its element is typed at the generic body's `(T) => T`, and no instance fixes it. A pushed `id` and
a pushed `[id]` onto a list of lists are both built per instance (D16235).
