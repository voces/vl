### D16572 — a generic function name spread as a list element into a generic body's list of `T`-functions is refused at emit

**loud emit reject · `a generic function taken as a value reaches no call that fixes its type` · clause 2 · open · found beside [D16235](D16235.md) · filed 2026-11-15 against master `4b8e8d264`**

Repro:

    function id<T>(x: T): T { return x }
    function run<T>(x: T) {
      const rs: ((x: T) => T)[] = []
      rs.push(...[id])
      return rs
    }
    print(run(3)[0](3))
    // vl check: rc 0.  vl run: emitProgram: a generic function taken as a value reaches no call that fixes its type

Want:

    3

#### Mechanism

Not traced past the ablation. The spread source `[id]` is a list literal of a generic function name.
Its element is typed at the generic body's `(T) => T`, and no instance fixes it. A pushed `id` and
a pushed `[id]` onto a list of lists are both built per instance (D16235).
