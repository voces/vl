### D12101 — a type parameter inferred from a string argument, beside a record arm, delivers the string where an i32 is expected

**check-clean invalid wasm · filed 2026-10-24 against master `492ea9482`**

Repro:

    type C = {x: i32}

    function g<T>(v: T | C) {
      print(1)
    }

    const s: string = "s"
    g(s)
    // vl check: rc 0.  vl run: invalid module, expected i32, found (ref $1) `string`

Want:

    1

#### Mechanism

D12100's binding with a string in place of the integer. The call site lowers the argument
for an instance whose scalar arm is `i32`, so the string reference reaches an `i32` slot and
the module fails validation instead of refusing. One call, one instance: the `i32` is not a
second instance's leftover.

#### Ablation

| change | outcome | needed? |
| --- | --- | --- |
| `g<string>(s)` (explicit type argument) | runs, prints `1` | **yes** (inference) |
| `g("s")` (literal argument) | same invalid module | no |
| `g(n)` with `n: i32` | loud emit reject (D12100) | **yes** (the string) |
| `g({x: 2})` | runs | **yes** |

#### Grading list

D12100's witness, both directions: a fix for one binding must not move the other into a
miscompile.
