**closed 2026-09-27 — the repro RUNS and prints `1` · was check-clean invalid wasm, the same on master `829bd497c` · closed by letting the boxing spread read the union-box row a destination threads as a ref list at a slot (`LBK_REF_AT_SLOT` / `LBK_REF`), not only as `LBK_UNION` (`spreadBoxDestRow`) · fixture `tests/cases/lists/spread-boxes-nested-and-pushed.vl` · found closing D2869 · filed 2026-09-27 against master `8e10ef58b`**

#### Mechanism

D2869's boxing spread fires where the destination threads its list of union boxes into the
literal. A binding, argument, return or field threads it as `LBK_UNION`; an element of an outer
list literal, a `push` argument, a cell write and a map value thread the same row as a ref list
at a slot (`LBK_REF_AT_SLOT`), which `spreadBoxDestRow` did not read, so the spread was built
at its source's `i32[]` and stored where `(i32 | null)[]` is expected. With an extra element
the literal typed itself as the union list and refused loudly instead (`[[...a, null]]`).

| --- | --- | --- |

| `xs.push([...a])` instead of the literal | still invalid | no |

#### Grading list

Closed at `(i32 | null)[][]`, `(string | i32)[][]`, `(S | i32)[][]` with a record source,
`(f64 | null)[][]` with a `null` element, three levels deep, and in an outer literal, `push`,
`xs[0] = …`, `m.set`, a return, an argument, a field and a captured `push`. A widening source
into a union element (`i32` into `(f64 | null)[]`) keeps D2882's plain copy.
