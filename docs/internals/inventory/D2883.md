### D2883 — a spread nested in a list literal, or pushed, into a list of union-element lists is copied unboxed

**check-clean invalid wasm · clause 1 · found closing D2869 · the same on master `8e10ef58b` · filed 2026-09-27 against master `8e10ef58b`**

Repro:

    const a: i32[] = [3]
    const xs: (i32 | null)[][] = [[...a]]
    print(xs[0].length)
    // vl check: rc 0.  vl run: invalid module in the top-level code

Want:

    1

#### Mechanism

D2869's boxing spread fires where the destination threads its list of union boxes into the
literal (`pendingListKind == LBK_UNION`). An element of an outer list literal and a `push`
argument do not thread the inner row, so the spread is built at its source's `i32[]` and stored
where `(i32 | null)[]` is expected. With an extra element the literal types itself as the union
list and refuses loudly instead (`[[...a, null]]`).

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the spread bound first (`const q: (i32 \| null)[] = [...a]; [q]`) | runs | **yes** |
| `xs.push([...a])` instead of the literal | still invalid | no |

#### Grading list

The same at `(string | i32)[][]`, `S[][]` with a record source, and `(f64 | null)[][]`.
