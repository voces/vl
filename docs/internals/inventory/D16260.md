### D16260 — a generic call handed a `never` call's result is refused at monomorphization

**loud emit reject · `emitProgram: monomorphize: unsupported argument type for `x` in a call to `id`` · clause 2 · the same call handed `7` runs · filed 2026-11-14 against master `c522f8dd`**

Repro:

    function fail(): never { __trap__() }
    function id<T>(x: T): T { x }
    function k(n: i32): i32 {
      if n > 5 { id(fail()) }
      n
    }
    print(k(3))
    // vl check: rc 0.  vl run: the refusal above, at `fail()`

Want:

    3

#### Mechanism

The checker infers `T` as `never` from the argument and accepts the call. The monomorphizer's
argument-type pin (`emit_mono.vl`, the `unsupported argument type` refusal) has no instance for a
`never` argument, although the call never runs past `fail()`. Found while measuring which reads
can be checked `never` (lane P, `exprReadsDeadNever`).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `fail()` as the argument (`7` instead) | runs, prints `3` | **yes** |
