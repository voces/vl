### D15207 — an un-annotated function returning a list of records that hold a list of un-annotated functions, whose result no caller consumes, is refused at emit

**closed · runs, prints `1` · was loud emit reject, `emitProgram: ref valtype with no interned shape`, clause 2 · found closing [D15203](D15203.md) · filed 2026-11-03 against master `aaf9ba5c` · the mechanism was not an unconsumed result (`mk().length` failed too): mono pins an un-annotated `let` of a list of records of functions at the flow table's types (an uncalled function at its default), a returned literal was pinned by nothing, so its field kept the open `(_) => _` element and minted no row; fixed by pinning a function's returned or tail list literal through the binding's own core (`monoPinRecordListAt`); residue [D15291](D15291.md), [D15292](D15292.md), [D15293](D15293.md); the pin's move to elaboration is [D15294](D15294.md); named set `d15207-ret-list-pin`**

Repro:

    function inc0(a) { return a + 1 }
    function mk() { return [{ fs: [inc0] }] }
    print(1)

Want:

    1

#### Mechanism

An unconsumed result is voided (`computeVoidFns`), but the returned literal is still built as a dropped value, and its `[inc0]` has no closed type: nothing calls `inc0` at a known signature, so the literal mints no row (`anonFieldCode` -1). There is no stamp to read and no signature to give it without guessing one. The direction is not to build a dropped value's list at all.
