### D10294 — a mutually recursive generic pair's bound join of `T | null` and an `f64` reads the `i32` arm as `f64`

**check-clean silently wrong · clause 1 · found closing [D10280](D10280.md) · present on master `d5ec7f160` · filed 2026-10-22 against master `d5ec7f160`**

Repro:

    function ga<T>(q: T | null, d: f64, n: i32) {
      if n > 0 { gb(q, d, n - 1) }
      const r = if q != null { q } else { d }
      print(r is i32)
    }
    function gb<T>(q: T | null, d: f64, n: i32) { ga(q, d, n) }
    const a: i32 | null = 5
    ga(a, 1.5, 0)
    // PRINTS false

Want:

    true

#### Mechanism

`njGateScan` (check_nj_gate.vl) gates every name an open body mentions unless it is a helper
`njHelperShapeOk` admits; `gb` mentions `ga` and is not such a helper, so `ga` is gated and
the pin's re-join (`joinPinnedArmLit`) widens the join while the checker's generic body typed it
`T | f64`. The single-function self-call, D10280, no longer gates itself; a cycle through a
second generic still does.
