### D5880 — a literal a forwarder hands through another function's hole is retyped once for every function the forwarder is called with

**loud check reject · clause 2 · found closing [D5840](D5840.md) · filed 2026-10-17 against master `60c4d1c43`**

Repro:

    function two(a: i32, b: f64[][]): i32 { a + b.length }
    function twoI(a: i32, b: i32[][]): i32 { a + b[0][0] }
    function apply(g, x, y) { return g(x, y) }
    function outer(h) { return apply(h, 3, [[1]]) }
    print(outer(two) + outer(twoI))
    // vl check: rc 1, argument 2: expected i32[][], got f64[][] (the call of `g` at the call's argument types)

Want:

    8

#### Mechanism

From the ablation only. [D5840](D5840.md)'s close retypes the literal `[[1]]` at the
parameter the demand reaches. Here the demand moves out of `outer` to each of its callers, and
both callers retype the same literal node, so the second caller's check reads the first
caller's type. The direct spelling, where `outer` calls `h` itself, instances the literal per
caller and runs. Before that close the program was check-clean invalid wasm.
