### D2974 — a `string | i32` join delivered where `(string | i64)[]` is wanted builds a list the reader casts wrongly

**closed 2026-09-28 — the filed repro prints `b 2 7 2` · was loads then traps, clause 1, the #3247 review · closed by retagging the box on delivery: the checker's delivery seam records, beside D2690's map rows, each scalar member the destination union holds only widened (`recordWidenRetag`), and `emitMapRetag` rebuilds a box under that member's tag with the payload converted; an argument to a parameter whose type names a type parameter is left as built, since that instance holds the member unwidened · filed 2026-09-28 against master `fe1fa1bec`**

Repro:

    function take(xs: (string | i64)[]) { print(xs[0]); print(xs.length) }
    function go(a: string, c: boolean) { const r = if c { a } else { 7 }; take([r, r]) }
    go("b", true)
    go("b", false)
    // vl check: rc 0.  vl run: prints `b` `2`, then traps with `wasm trap: cast failure`

Want:

    b
    2
    7
    2

#### Mechanism

Not a list defect: any delivery of a union box into a union that lacks one of its scalar members
but holds one it widens to (`i32` into `i64` or `f64`, `f32` into `f64`). `emitUnionCoerce` passed
a union value raw, so the box kept the `i32` tag and payload, and the destination's dispatch read
it as its own member: a cast failure when it unboxed an `i64`, a wrong arm where the tag chain fell
through (`string | i32 | boolean` into `string | i64 | boolean` printed `7` as `true`), and `null`
for `i32 | null` into `i64 | null`. The language accepts the delivery, since `i32` widens to `i64`
as a value, so the answer is a converting delivery rather than a refusal. A literal `[r, r]`
builds each element at the destination, so it takes the same retag. A list VALUE of those boxes
is a container widening, which the design refuses when the list is mutable ([D2982](D2982.md));
the readonly view is [D2999](D2999.md).

The retag is declined for an argument whose parameter type names a type parameter
(`recv<T>(x: T, v: T | string)` at `T = i64`): the generic is emitted once, over the member
unwidened, so a retagged box traps there. On master that program prints `7`, and it still does.
