### D15291 — a list literal of records holding a list of an uncalled un-annotated function, as a bare statement, is refused at emit

**loud emit reject · `emitProgram: object literal but no struct type declared` · clause 2 · open · the same literal bound (`const rs = …`) or returned runs since [D15207](D15207.md); the elaboration's held type ([D15294](D15294.md)) closes the literal, but no reader records it on a statement: the anon-shape mint reads only the literal's own type · found closing [D15207](D15207.md) · filed 2026-11-04 against master `112ae73e`**

Repro:

    function inc0(a) { return a + 1 }
    function go() {
      [{ fs: [inc0] }]
      print(1)
    }
    go()

Want:

    1

#### Mechanism

mono pins an un-annotated list of records of functions only where a binding or a function's result holds it (`monoPinRecordListAt`); an expression statement is held by neither, so its record keeps the open `(_) => _` element, `anonFieldCode`'s code 5 has no element companion, and the record mints no row. Moving the pin to elaboration ([D15294](D15294.md)) would type it where it is checked.
