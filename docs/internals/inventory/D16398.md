#### Mechanism

A function field is a closure reference whatever its signature, so `{f: () => string}` and
`{f: () => f64}` share one storage row, recorded at the first's type. Delivering the literal into
the union looks its arm up (`unionArmVariantForObj`); the arm's own type matches the literal's,
but the field check behind it (`objNestedFieldCompat`) tests field `b`'s literal against the
shared row, whose recorded `f` is `() => string`, and `fnFieldTyFits` refuses the signature. With
no arm found the literal is emitted as a bare record where the union box wants `{tag, ref}`
(`wasm-dis`: `global.set` of a `struct.new $record` into a `(ref null $box)` global).
