### D14655 — a union with a nullable member is not assignable to a nullable target that holds every member

**closed · runs, prints `2.5` · was a loud check reject, clause 2 · the flat spelling of the same source union ran · filed 2026-10-31 against master `79392113`**

Repro:

    const x: (boolean | null) | f64 = 2.5
    const y: boolean | null | f64 = x
    print(y)
    // vl check: cannot assign boolean | null | f64 to 'y' of type boolean | f64 | null

Want:

    2.5

#### Mechanism

`assignableGo`'s nullable-target arm checked a union source against the target's inner type, with `null` stripped. A member that is itself nullable (`boolean | null`) then failed, since `null` does not fit the stripped inner. The arm now checks a `null` or nullable member against the whole target, and every other member against the inner through `assignableUnionSrc`, which keeps D2611's numeric rule. A generic instance builds the same source: `T | f64` at `T = boolean | null` (D3149's witness, refused by the error channel's re-check).
