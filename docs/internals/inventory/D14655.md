### D14655 — a read's variant row cannot come from its type while a record with a struct row of its own is stored in a variant cell

**runs, prints `1` `1` `1` — CLOSED 2026-11-01: `exprVariantIndex`'s Ident arm reads the variant row of the type the binding is stored at (`readHeldTyOf`, its `letBindTy`), so the cell-first rungs `declaredVariantIndex`, `capturedVariantIndex` and `globalReadVariantIndex` are deleted · was a refutation pin for reading that arm off the read's own type · found moving the variant Ident arm onto `repOf` · filed 2026-10-31 against master `cb178881`**

Repro:

    type J = { r: i32 | null }
    function idn<T>(v: T): T { v }
    function d1() { return idn({ r: 1 }) }
    const v: J | string = d1()

    print(g.r)
    function main() {

      print(q.r)
      function inner() { print(q.r) }
      inner()
    }
    main()

    1
    1

#### Mechanism

`d1`'s inferred return is the variant row of `J`'s arm in `J | string`, so every binding of
`d1()` (a module global, a local, a capture) gets a `variant` cell. The binding's type is `J`,
which has a struct row of its own, and `repVariantShapeRowOf` excludes such a type. Both rows
are the same wasm heap (one `struct (field (mut (ref $box)))`); only the emitter's kind label
differs. A reader that takes the variant row off the read's type answers -1, the struct
ladder answers -1 for a `variant` cell, and the member read refuses. So `exprVariantIndex`'s
Ident arm reads the cell's row first (`declaredVariantIndex`, `capturedVariantIndex`,
`globalReadVariantIndex`) and the type only where no cell answers.

The type the arm needed was the one the binding is STORED at, not the read's own. `d1()`'s
checker type at each binding is the literal's `{r: i32}`, whose shape has no variant row, while
`letBindTy` holds the binding at `J`'s arm record. And `J` has no declared struct row: as a union
arm it is collected only as an anonymous `{r:i32|null}` shape row (`sRowDecl` 0) beside its
variant row, on one heap. Reading the held type first lets the type answer every cell the three
rungs answered.
