### D2588 — a boolean survivor of `is T` then a null test over a nullable value union lowers at the box, not the boolean

**check-clean invalid wasm · clause 1 · 42 cells of the #3177 review's elimination grid (`eg`,
every `… boolean …` union with the `is` first) · the same on master `c189dfb28` · filed

Repro:

    function go(x: string | boolean | null) {
      if x is string { print(x + "!") } else if x == null { print("null") } else { print(!x) }
    }
    go(true)
    // vl check: rc 0.  vl run: invalid module, inside `go`:
    // "type mismatch: expected i32, found (ref $type)"

#### Mechanism

A prediction. The checker types the last arm's `x` as `boolean`. The emitter's complement chain
leaves `boolean | null` after the `is string` else, and the null test's else then reads the box
where a boolean `i32` is expected: the survivor push declines for a `boolean` atom, which is the
one member whose unboxed rep is an `i32` the box stores differently. A bare name, not only a
place: the same holds for a map, list or field cell.
