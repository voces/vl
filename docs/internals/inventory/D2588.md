#### Mechanism

The filed prediction was wrong about where: the survivor read was right, the null TEST was not.
After the `is string` else the checker types `x` as `boolean | null`, and `exprNulBool`'s typed
fast path took that recorded type as the rep, so `x == null` lowered as the niche compare
(`local.get` of the box, `i32.const 2`, `i32.eq`) against a value that is still the union box.
`boolean | null` is the one pair whose niche is an `i32`, which is why no other member showed
it. The close asks the read's own rep first (`narrowedBoxPlace`); D2590 then makes a bare
name's, field's and cell's read convert to the niche, and the two agree.
