### D6703 — a binding annotated with one type parameter and seeded from a parameter of another is accepted by the checker and builds invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · found closing [D6523](D6523.md) · filed 2026-10-18 against master `ca2adfdc7`**

Repro:

    function same<T>(k: T): T { k }
    function mid<F, G>(a: F, a1: G) {
      let b: F = a1
      print(a("x"))
      print(b(3))
    }
    mid(same, same)
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `mid`: type mismatch: expected (ref $type), found i32

#### Mechanism

Not located. Two distinct type parameters are not assignable to each other in a generic body, so
`let b: F = a1` is ill-typed at its declaration whatever `mid` is called with; the checker
accepts it and the emitter builds `F` and `G` at different instances.
