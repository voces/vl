### D12453 — a generic join with a `??` arm is refused at an instance whose `T` is nullable

**closed 2026-10-30 — runs, prints `n` then `null`: the template's join keeps the type parameter's arm (D14649), so the instance's box carries the `null` and the refusal no longer fires · CAPABILITY, the program is type-valid · filed 2026-10-24 against master `b861c1d9f`**

#### Mechanism

At `T := string | null` the join of `a ?? 5` and `b` keeps the `null` that the checked return dropped, so the instance's value-atom return box cannot carry it and the call refuses (#3236; D2934 extended the same refusal to an alias chain). Under the gradual-union ruling the instance's join is `string | i32 | null` and no operation on it fails, so the program is type-valid.
