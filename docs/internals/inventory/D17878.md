### D17878 — a choice handed back by a generic identity and copied into a second binding before the call is refused at check as one that must return one type

**loud check reject · clause 2 · 9 un-annotated cells of `tagged-choice-identity.matrix.vl` · beside [D17107](D17107.md) and [D17105](D17105.md) · owner CENSUS · filed 2026-11-28 against master `caffc73f9`**

Repro:

    function inc(a) { return a + 1 }
    function str(_a) { return "s" }
    function id<T>(t: T): T { return t }
    function flag(): boolean { return 1 > 0 }
    const g = if flag() { str } else { inc }
    const w = id(g)
    const v = w
    print(v(4))
    // vl check: cannot choose 'str' here: called at (i32) it returns string, where 'inc', also chosen here, returns i32 — every function a call through the choice may run must return one type

Want:

    s

#### Mechanism

The set stays untagged when its only call runs through a binding copied from the identity's
result, so the choice is judged as a closure that needs one result. A call through the identity's
own result binding tags it. Unlocated beyond that: the copy is not traced back to the set.

| ingredient | outcome |
| --- | --- |
| `const w = g` in place of `id(g)` | runs, `s` |
| `print(w(4))` in place of the copy and its call | runs, `s` |
| `const w: (a: i32) => i32 \| string = id(g)` | runs, `s` |
| `const v: (a: i32) => i32 \| string = w` | still refuses |
| a `print(g(5))` added | still refuses |
| the same statements inside a function | still refuses |
