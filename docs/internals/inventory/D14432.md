### D14432 — a binding of a map entry of a set of un-annotated functions refuses its map value

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the entry read through `??` without a binding runs, and so does the annotated face · deleted by the rep-keyed nullable slice, which makes the nullable lowering read the inner value's rep · found building the container write-join · filed 2026-10-27 against master `efb1a8105` · pinned by `tests/cases/maps/error-fn-set-map-get-binding.vl`**

#### Mechanism

The map's writes join to one set {inc, dbl}, whose tag rep is the i32 id. A `??` over an
entry reads the id directly. A binding of the entry holds `F | null`, and the nullable lowering
picks its rep from the inner TYPE's kind rather than its rep: `repOfNullable`'s function arm
answers the nullable closure, `nssScalarOf` splits only by primitive name, and the `null` test
lowers as `ref.is_null`. Tagged, the binding stores an i32 id into a closure ref local, which is
invalid wasm, so `ftNulOk` leaves a set whose entry is bound untagged and the map refuses its
value as master does. When the nullable lowering reads the inner rep, `F | null` is the boxed
`i32 | null`, `ftNulOk` accepts the binding, and this row closes.
