### D5158 — assigning a literal-union field every arm shares, through the union, is refused at emit

**loud emit reject · clause 2 · found closing D5105 · filed 2026-10-16 against master `9518cc8f5`**

Repro:

    type N = { k: "a" | "b", v: i32 } | { k: "a" | "b", w: boolean }
    function g(n: N) { n.k = "a"; n.k }
    const x: N = { k: "b", w: true }
    const y: N = { k: "b", v: 1 }
    print(g(x))
    print(g(y))
    // vl check: rc 0.  vl run: emitProgram: field assignment but no struct type declared

Want:

    a
    a

#### Mechanism

Not ablated past the table below. The read of the same shared field runs; the write has no
lowering through the union box when the field is stored as a literal-union atom, while the
same write over an `i32` or `string` field runs.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the field `k: string` in both arms | runs, `q` `q` for `n.k = "q"` | **yes** |
| the field `k: i32` in both arms | runs | **yes** |
| the second arm's set `"a" \| "end"` | still refuses | no |
