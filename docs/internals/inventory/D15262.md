#### Mechanism

`monoKeyPinSeg` (emit_mono.vl) keys a pin by `monoPinRowClass` when `monoPinIsRecord` says the pin
is a record, and `monoPinRowClass` answers only a record or a nullable record: a list, a map, a
function type over records, or a pin named by a spelling `cUserTypes` does not hold, keys by its
spelling. Two spellings of one row inside a container therefore build two instances of one
elaboration key, which a per-key fact is then read for.
