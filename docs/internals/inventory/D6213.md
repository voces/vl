### D6213 — a generic handed to a hole parameter nothing reads has no instance

**loud emit reject · `vl check` rc 0 · clause 2 · found closing [D6191](D6191.md) · the same on master `3805fcf57` · filed 2026-10-17 against master `3805fcf57`**

Repro:

    function outer(g) { return 4 }
    function neg(a) { return 0 - a }
    print(outer(neg))
    // vl check: rc 0.  vl run: emitProgram: cannot take the generic function `neg` as a value — a function value carries ONE signature, and parameter `a` is un-annotated (it would default to i32). No call site pins `neg`, so there is no inferred signature to adopt

Want:

    4

#### Mechanism

From the ablation only. A hole lambda handed to a parameter nothing reads takes an unobservable
`i32` default ([D5934](D5934.md), [D6112](D6112.md), [D6191](D6191.md)). A generic declared
function has no such default, so the value reaches emit with no call to instance it at. The
default is unobservable for the same reason: nothing calls it.
