### D9008 — a re-pointed `let` of un-annotated functions with different results, returned and called by the caller, traps

**loads then traps · `vl check` rc 0 · `wasm trap: indirect call type mismatch` · clause 1 · found closing [D9003](D9003.md) · present on master `145cabbc6` · filed 2026-10-21 against master `145cabbc6`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function get() {
      let f = inc0
      f = half
      return f
    }
    print(get()(3))
    // vl check rc 0.  vl run: wasm trap: indirect call type mismatch

#### Mechanism

Not traced. D9003's refusal reads the binding at the parameter types it is called at, and
every such call names the binding. Returned, the value is called as `get()(3)`, whose callee
names no binding, so neither function written to `f` is read at `(i32)`. `get`'s result type
is `inc0`'s signature.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |

| the widening (`dbl(a) { return a * 2 }` for `half`) | runs, `6` | **yes** |
| the return (`f(3)` inside `get`) | loud check reject | **yes** |
