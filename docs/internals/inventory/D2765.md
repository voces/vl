### D2765 — a record VALUE joined with a differently-typed record of the same field names needs a converting copy the join has nowhere to make

**loud emit reject · clause 2 · every non-literal face of D2731's join: an `if` or `match` tail, a `return` and a return tail, a list literal's element, a `??` operand, at every position the join is then delivered to (the #3209 review's grid) · on master a loud emit reject in most faces (`union \`A|B\` cannot be discriminated`) and invalid modules in the rest · filed 2026-09-27 against master `f6db92e0d`**

Repro:

    type A = { f: i32 }

#### Mechanism

Since D2731 the join is the record `{f: i32 | string}`. A literal arm is built at that row; a
record VALUE arm (`a`, pinned to `A`'s row by its annotation or a parameter) holds a bare `i32`
field where the joined row holds a union box, and the two are unrelated wasm structs. A record
is shared, not copied, so this is [D2100](D2100.md)/[D2160](D2160.md)'s converting-copy gap at
each place a join's value is made. One pass (`auditRecordJoinLeaves`, after the struct rows exist)
visits every join of records, the tails of a value `if` or `match`, the elements of a list
literal, the operands of a `??`, and every value a function returns against its declared or
pinned return row, and refuses any leaf that is a record VALUE built at a row whose fields are
stored differently (`recordRepDiffers`, through nested records). A literal leaf is built at the
join's row and runs. So the refusal is at the value, whatever the join is delivered into
afterwards. An un-annotated record variable that adopts the joined rep is built at that row and
runs. The binding position with no join (`const sx: { f: i32 | string } = a`) is still D2160.

| parameters `a: A, b: B` in place of locals | the same refusal | no |
