### D3523 — a two-width integer-literal union is refused delivery into `f64`, and into `i64` once it joins an `i32`, though every member converts exactly

**closed 2026-10-03 — the witness prints `0.5` · was a loud check reject, clause 2 · 84 cells of lane WD's D3517 matrix (`lit_f64_*`, and `lit_i64_d2_*` where the default is a non-member literal) · found by lane WD · filed 2026-10-03 against master `4c55f1b6a`, closed by lane LC against master `f6e17953b` · fixture `tests/cases/unions/litunion-mixed-width-into-wider-number.vl`**

Repro:

    type D = 9000000000 | 1
    function f(a: D): f64 { a }
    print(f(1) / 2)
    // vl check: rc 1, "expected f64, got D"

Want:

    0.5

#### Mechanism

Confirmed. A numeric union delivers into a wider number through `numUnionConverts`, which asks
`numUnionMembersOf`; a literal union's members are `TyLit`, so it answered no members. `D` into
`i64` passed because every literal fits `i64`, which neither `f64` (a variable `i64` there is
lossy) nor the join `D | i32` satisfied. `assignableExpr` now also asks `litNumUnionConverts`:
every literal is a value the destination holds exactly (`intLexHeldBy`: `i32` range, any `i64`,
`intLexemeIsExactF64`/`F32`) and every plain number widens to it. The emitter's per-member
conversion (`emitNumUnionConvert`) reads the box's members through `njLitBasesOf`, which now
asks `litNumUnionBasesOf`, so the `i32` member of `D | i32` converts beside the literals. A
nullable destination (`f64 | null`) is not admitted here: its box retags members, and an `i64`
member has no retag into `f64` (D3530).

A box of literals over two bases delivered into a wider UNION (`1 | "s"` into `i64 | string`)
trapped on master with a cast failure: `widenMemberPairs` compared the box's literal leaves
with the destination's members, found no widening, and recorded no retag. It now takes each
literal at its base, as the box holds it. The same missing retag made `const z: i64 | null =
pick(0)` (`pick(0)` is `1`) print `null` on master, check-clean silently wrong; it prints `1`.
