### D15281 — a fresh record binding annotated wider at one delivery and pushed into a list of its own type is check-clean invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · open, target a check reject naming both deliveries, or `6` · found grading [D15238](D15238.md)'s refusals · filed 2026-11-04 against master `7338b7d2`**

Repro:

    type J = { f: i32 | null }
    const r = { f: 6 }
    const w: J = r
    const zs = [{ f: 1 }]
    zs.push(r)
    print(w.f ?? 0)

Want:

    6

#### Mechanism

Not ablated past the table. `w: J = r` adopts `r` at `J`, so `r` is built as `J`, and the push
hands that struct to a list of `{f: i32}`. Handing `r` to a `{f: i32}` parameter is refused
(`argument 1: expected {f: i32}, got J`); the push is not.
