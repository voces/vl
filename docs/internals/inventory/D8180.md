### D8180 — a `const` copy of a null-narrowed `i32 | K | null` box refuses to print the arm `is i32` leaves

**closed 2026-10-20 by lane L6 · an un-annotated binding whose slot holds a box at a set with `null` its initializer's type has not reads at that set less `null`; the repro prints `b`, pinned by `tests/cases/literal-unions/null-narrowed-box-copy-litunion-arm.vl` and `null-narrowed-litunion-box-copy{,-generic}.matrix.vl` · was loud emit reject · clause 2 · found closing [D8122](D8122.md), the `map_value` and `map_set` un-annotated cells of `nullable-litunion-arm-of-generic-box.matrix.vl` · filed 2026-10-20 against master `da93ef793`**

Repro:

    type AB = "a" | "b"
    const r: i32 | AB | null = "b"
    if r != null {
      const v = r
      if v is i32 { print(0) } else { print(v) }
    }
    // vl check: rc 0.  vl run: emitProgram: print of a union value whose arms the tag dispatch cannot classify

Want:

    b

#### Mechanism

The copy's type is the narrowed `i32 | AB`, while its cell holds the source's `i32 | AB | null`
box. Nothing narrowed the copy, so `is i32`'s else narrowed it to `AB | null`. With
an alias's literal members, `narrowedBoxRenderOf` cannot render the smaller box either, since
`i32 | AB` is no value-union name. `print` then found no arm set for `AB | null` against a
type of `AB`. The same read handed on was check-clean invalid wasm: passed to an `AB`
parameter, bound at `: AB`, returned, or delivered from a value `if`.

`pgLetNarrow` (emit_classify.vl) now runs after the declaration. It pushes the slot's set
less `null`, as a `!= null` guard does for the source.

The same box handed to an un-annotated PARAMETER still refuses: [D8281](D8281.md).
