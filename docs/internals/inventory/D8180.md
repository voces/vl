### D8180 — a `const` copy of a null-narrowed `i32 | K | null` box refuses to print the arm `is i32` leaves

**loud emit reject · clause 2 · found closing [D8122](D8122.md), the `map_value` and `map_set` un-annotated cells of `nullable-litunion-arm-of-generic-box.matrix.vl` · the same on master `da93ef793` · filed 2026-10-20 against master `da93ef793`**

Repro:

    type AB = "a" | "b"
    const r: i32 | AB | null = "b"
    if r != null {
      const v = r
      if v is i32 { print(0) } else { print(v) }
    }
    // vl check: rc 0.  vl run: emitProgram: print of a union value whose arms the tag dispatch cannot classify

#### Mechanism

Not traced. The copy's type is the narrowed `i32 | AB`, while its cell holds the source's
`i32 | AB | null` box. `is i32` then narrows the copy to `AB`, and `print` finds no arm set
for that read of the wider box.
