### D15640 — a callee handed a record of a hole function at another type, and elsewhere a record of a named function, cannot instance the named function

**loud emit reject · clause 2 · `a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type` · was a loud check reject before [D15638](D15638.md) · found closing D15638 · filed 2026-11-10 against master `20775a7d`**

Repro:

    function dbl(v) { return v + v }
    function call0(r, x) { print(r.f(x)) }
    const r = { f: dbl }
    call0(r, 4)
    function both(g) {
      print(g(1))
      call0({ f: g }, 2.5)
    }
    both(dbl)

Want:

    8
    2
    5

#### Mechanism

A record field holding a named function is a closure, never a tagged set, while a list
element holding one is a set's id. So `call0` has a closure-record instance and a set-record
instance, and `dbl`, handed to `both`, finds no call in the elaboration that fixes it at `f64`.
