#### Mechanism

Bare `as` PROPAGATES the non-matching arm out of the enclosing function, and the ruling
(`docs/error-handling-design.md` §Trio) requires the enclosing return to have a declared home
for it: `` `as i32` propagates null — annotate the enclosing function's return type so the
propagation has a declared home `` is the annotated spelling's check reject, and
`castPropagationFits` is what enforces it.

At a HOLE parameter the checker never reaches that arm — the operand is a `TyVar`, so
`checkCastNode` falls to the numeric ladder and `castPropagationFits` is never asked. D1251
then taught the EMITTER to take the union arm anyway (from the monomorphizer's pin), and its
`as` lowering emits the early exit unconditionally. In a VOID function that exit is a bare
`return`, so the null is swallowed: the disassembly is `struct.get 0 0` / tag compare /
`local.get 1` + `return`, and `return` is stack-polymorphic so the pushed box is simply
discarded. The remainder of the body never runs.

This is the price of D1251's close, and it is a smaller one than what it replaced — the same
program was check-clean INVALID WASM at both values before, so no `runs` cell was lost. But
the two faces of one program now disagree about legality rather than about a rep, which is a
different and worse kind of disagreement, and it is why this is filed rather than folded into
D1251's status line.
