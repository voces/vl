Repro:

    function inc(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function deliver(_n) {
      let u = [[inc], [dbl]]
      return u
    }
    function take(a) { print(a[1][0](3)) }
    take(deliver(1))
    // vl check rc 0.  vl run: emit error: emitProgram: monomorphize: unsupported argument type for `a` in a call to `take`

Want:

    6

#### Mechanism

`monoRetListLitOf` maps a returned identifier to the list literal it is bound to, which is how the
argument pin reads the returned list's elements. It accepted only a `const`. A `let` that nothing
writes whole and no capture cell writes holds the same value at the return, so it is now accepted
too. A `let` written whole before the return is left refused, as [D9764](D9764.md).
