### D2609 — a write under a narrowing that only widens into the narrowed member keeps the narrowing, and the read unboxes the member the value is not

**closed 2026-09-26 — the filed repro runs and prints `5` · was check-clean, then a wasm trap
(`cast failure`) at the read, clause 1 · filed 2026-09-26 against master `e289f84d7` · fixture
`tests/cases/soundness/narrowed-write-lands-on-its-own-member.vl`**

Repro:

    function src(): i32 | f64 { return 1.5 }
    function go() {
      let x: i32 | f64 = src()
      if x is f64 { x = 5; print(x) }
    }
    go()
    // now prints `5`

#### Mechanism

The checker kept a narrowing across a write it admitted (`!assignable(rt, narrowed)`), and an
`i32` is assignable to `f64` by widening, so `x` stayed `f64`. The emitter stores the value by
its own type into the declared `i32 | f64` box, so the cell held the `i32` member, and the read
cast the payload to the `f64` box and trapped. A union-typed value had the same fault the other
way: `i32 | f64` landed on `f64`, the only member it is assignable to as a whole. The close
decides where a write lands by the member the value IS before one it widens to, member by member
for a union value (`writeMemberTy`, `unionMemberOfWrite`), keeps the narrowing only when the
value lands within it (`writeLandsWithin`), and applies the rule to fields, list cells and map
cells as well as names. A loop that may make such a write ends the narrowing before it starts
(`crLoopLeavingWrite`, `crLoopPathPreRetire`); one whose value needs the loop to type it is
refused as the loop barrier refused it before (`writeLeavesLoopEntry`).

#### Ablation

| ingredient changed | outcome on master | needed? |
| --- | --- | --- |
| the write stores `2.5`, the narrowed member | runs, `2.5` | **yes** (a value of another member) |
| no narrowing around the write | runs, `5` | **yes** |
| the value is an `i32` binding, not a literal | traps the same way | no |
| `let x = src()`, un-annotated | traps the same way | no |
| the read after the `if`, not inside it | runs, `5` | **yes** (a read under the kept narrowing) |
| `string \| f64`, which has no `i32` member | runs, `5` | **yes** (a member the value is) |
| a field, a list cell or a map cell for the name | traps the same way | no |
