### D2912 — a generic body returning a binding of a value `if` with a `??` arm returns the template's rep into its pinned union box

**closed 2026-09-27 · was check-clean silently wrong, clause 1, on master `0284dc2a8`, a regression of #3233 (a loud emit reject on `829bd497c`) · found by the GJ lane's `g3` grid · filed 2026-09-27 against master `0284dc2a8` · fixture `tests/cases/generics/returned-join-with-coalesce-arm.vl`**

Repro:

    function g0<T>(a: T, b: T, c: boolean) {
      const r = if c { a ?? 5 } else { b }
      r
    }
    print(g0(true, false, true))
    // vl check: rc 0.  vl run on master: prints 1

Want:

    true

#### Mechanism

#3233 annotates an instance's inferred return that is a union of value atoms at its box
(D2895), here `boolean | i32`, while the returned binding `r` kept the template's `T` rep. The
join is now re-typed to that box where its binding is only returned or printed and the box
holds the same members. At a `string | null` pin the checked return is `string | i32`: the
template's join absorbed the `null` arm, so no box without `null` carries the value. The box
is withheld when a binding the body returns or prints joins, at the pin, other members than the
box holds (`monoPinBoxUncovered`), back to the loud reject of `829bd497c`. A binding read
anywhere else is D2916; the `i32 | null` pin is D2915.

#### Ablation

| ingredient removed | outcome on master | needed? |
| --- | --- | --- |
| the binding (`if c { a ?? 5 } else { b }` as the tail) | prints `true` | **yes** |
| the `??` (`if c { a } else { b }`) | prints `true` | **yes** |
| the `if` (`const r = a ?? 5; r`) | prints `true` | **yes** |
| the tail name (`return r`) | prints `1` | no |
| the `boolean` pin (`g0(3, 4, true)`) | prints `3` | **yes** |

#### Grading list

`return r` in place of the tail prints `true`. The `string | null` pin,
`g0(u0, w0, true)` with `u0: string | null = "n"` and `w0: string | null = null`, is a loud
emit reject (`union atom has no value box`, invalid wasm on master); it runs only once the
checked join keeps the `null`, and that is a separate change. The `i32 | null` pin is invalid
wasm, the same before #3233, on master and here.
