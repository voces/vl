### D15755 — a function's returned binding of a list of an un-annotated function, bound at an annotated list of functions, is refused at emit

**closed · runs, prints `7` · was loud emit reject, clause 2 (a containment of clause-1 invalid wasm) · fixed 2026-11-14: a `const` of functions returned by name has its initializer's list rows minted before the result's token is read · filed 2026-11-12 against master `6cb5dd90`**

Repro:

    function inc0(a) { return a + 1 }
    const inner = [inc0]
    function deliver() {
      return inner
    }
    const v: ((a: f64) => f64)[] = deliver()
    print(v[0](6))

Want:

    7

#### Mechanism

`deliver`'s recorded result is the open `((_) => _)[]`. `frsValuesBuiltTy` reads the returned
binding's slot fact `((f64) => f64)[]`, but that list's row was not yet minted when the result's
token was read, so the fact had no token, the result columns stayed `i32`, and the ref list
returned missed them. `frsMintRetLits` now also mints the literals of each `const` of functions a
function returns by name, so the fact has its row and the result is built at it.
