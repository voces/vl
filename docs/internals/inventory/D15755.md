#### Mechanism

Not yet traced. It is D15752's shape with a function's return between the binding and the
annotation. The element slot of `inner` reaches its annotated destination through a delivery
`elabWrittenDest` follows (a binding, a written parameter, a written result, and since D15752 a
push or a map `set`). A return from a function whose result is not written is none of those. So
the slot stays uncalled, its closure is built at the empty signature, and the annotated read
meets it. D15753 (unfiled: D15753, filed in #7442) is the map join's sibling at the same seam.
