### D9533 — a record of an un-annotated function bound to a `const` and then set into an un-annotated `Map()` has no map value rep

**loud emit reject · `vl check` rc 0 · `emitProgram: unsupported map value type` · clause 2 · found closing [D9470](D9470.md) · present on master `1cf53e320` · filed 2026-10-22 against master `1cf53e320`**

Repro:

    function dbl(a) { return a * 2 }
    const m = Map()
    const r0 = { f: dbl }
    m.set("b", r0)
    const r = m.get("b")
    if r != null { print(r.f(3)) }
    // vl check rc 0.  vl run: emit error: emitProgram: unsupported map value type (no rep for a union-member struct, ...)

#### Mechanism

Not traced. The map's value type is pinned from the `set` argument; the inline literal
`m.set("b", { f: dbl })` runs, so the bound record's type reaches the map without the
shape the literal gives it.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the binding (`m.set("b", { f: dbl })`) | runs, `6` | **yes** |
| the map (`const l = []`, `l.push(r0)`, `l[0].f(3)`) | runs, `6` | **yes** |

#### Grading list

A record built by a call (`function mk(g) { return { f: g } }`, `m.set("b", mk(dbl))`),
same refusal; and the same set after an inline `m.set("a", { f: inc0 })` of one result.
