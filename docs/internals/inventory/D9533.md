Repro:

    function dbl(a) { return a * 2 }
    const m = Map()
    const r0 = { f: dbl }
    m.set("b", r0)
    const r = m.get("b")
    if r != null { print(r.f(3)) }
    // vl check rc 0.  vl run: emit error: emitProgram: unsupported map value type (no rep for a union-member struct, ...)

Want:

    6

#### Mechanism

Not traced. The map's value type is pinned from the `set` argument; the inline literal
`m.set("b", { f: dbl })` runs, so the bound record's type reaches the map without the
shape the literal gives it.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the binding (`m.set("b", { f: dbl })`) | runs, `6` | **yes** |
| the map (`const l = []`, `l.push(r0)`, `l[0].f(3)`) | runs, `6` | **yes** |

same refusal, and still refusing as [D12340](D12340.md); and the same set after an inline
`m.set("a", { f: inc0 })` of one result, which runs with this row.
