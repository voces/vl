### D3593 — an inferred union that spells an anonymous record by a declared struct's name makes that struct an arm to the name registry and a plain record to the arena

**closed 2026-10-03 — the witness builds and prints `0`, `4.5` · was check-clean invalid wasm, clause 1 (with `-O3`, wasm-opt's "return value should be a subtype") · sunpa SP-025 · filed 2026-10-03 against master `90212cc5a`, closed in the same change · fixtures `tests/cases/maps/untyped-record-literal-stored-beside-narrowed-get.vl`, `tests/cases/unions/narrowed-nullable-arm-record-delivered.vl`**

Repro:

    type B = { x: f64, lean: f64 }
    let brains: Map<i32, B> = Map()
    function brainOf(id: i32): B {
      const got = brains.get(id)
      if got != null { return got }
      const b: B = { x: 0.0, lean: 0.0 }
      brains[id] = b
      b
    }
    export function home(id: i32, x: f64) {
      const b = brains.get(id)
      if b == null { brains[id] = { x, lean: 0.0 } } else { b.x = x }
    }
    export function g(id: i32): f64 { brainOf(id).x }
    print(g(1))
    home(2, 4.5)
    print(g(2))
    // vl check: rc 0.  vl build: "failed to validate inside `brainOf`: expected (ref $type), found (ref null $type)"

Want:

    0
    4.5

#### Mechanism

`home` has no return annotation and its tail is an `if` whose arms are `brains[id] = { … }`
(the record) and `b.x = x` (an `f64`), so its inferred return is a union of an ANONYMOUS
record and `f64`. The checker records that return under the name `B|f64`
(`variantBoxUnionRetName` maps the anonymous member to the declared struct of the same shape),
and the emitter registers that name, so `B` became a union arm in `uVariants` and lost its
struct row. The checker's arena set of arm types (`cVariantMemberTyIxSet`) held only the
anonymous member, so `nodeTyIsVariant` said `B` was a plain struct. The two disagreed about
every `B` they each classify: `brainOf`'s `: B` result read `struct` from the arena, while the
un-annotated `got` read `nulvariant` from the name (`letIsNulVariant` →
`nulVariantIndexOf("B | null")`). The return boundary's recover compares the result's niche
(`nulstruct`) with the value's (`nulvariant`), found them different, and emitted no
`ref.as_non_null`. Both are one heap (D280's merge), so the module is wrong only in nullness.

The fix registers the declared twin wherever the inferred-return name is recorded under the
struct-union or variant-box rung (`inferRegisterNominalTwins`, committed directly because the
named-function recorder runs after `annCommitVariantMembers`). `B` is then an arm in both
registries, as it already was when the literal was typed (`const q: B = { … }`) or the union
declared. That moves these programs into the declared-union world, whose matrix had two holes
of its own, fixed in the same change: a narrowed `B | null` whose source classifies it at the
other niche (a `B[]`'s `.get`, `nulstruct`) delivered to a `variant` argument
(`emitNonNullParamRecover` and `exprIsNulNicheOf` now take either record niche,
`exprNullableRecord`), and a value `if` whose deciding arm is a narrowed `nulvariant` local,
which fell to an `i32` blocktype (`ifExprRefKindOf`).
