### D4192 — a null-only list literal as a `??` default builds no list, annotated or not

**loud emit reject · clause 2 · ``??` over a list whose default is a list of another storage builds no single list at this type argument` · filed 2026-10-12 against master `040ff8a3d` · found by the review of [D1832](D1832.md)'s close; a sibling of [D4190](D4190.md)**

Repro:

    function g(): (i32 | null)[] | null { null }
    const xs = g() ?? [null]
    print(xs.length)
    // vl check: rc 0.  vl run: emit error at 2:24.  Should print 1.

#### Mechanism

Not yet ablated to a rung. The `??` operand's own type, `(i32 | null)[]`, is the default's
destination, so D1832's refusal lets the literal through, but the default is built at its own
`null[]` storage. Annotating the binding (`const xs: (i32 | null)[] = g() ?? [null]`) gives the
same emit reject.
