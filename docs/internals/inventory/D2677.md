### D2677 — `as?` / `as!` over a union with a `null` member refuses a member as "not a member"

**loud check reject · clause 2 · found by #3193's review · identical on master · filed 2026-09-26 against master `525837973`**

Repro:

    type R = { a: i32 }
    type S = { b: i32 }
    type U = R | S | null
    const v: U = { b: 2 }
    const q = v as? S
    print(q == null)
    // vl check: rc 1 — `as S` names a type that is not a member of R | S | null

#### Mechanism

`checkCastNode` tests the target against the operand's union for membership and reports the
false sentence only when the union has a `null` member; the same cast over `R | S` runs. The
likely cause, not yet traced, is that `| null` wraps the union in a `TyNullable` the member walk
does not look through.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `null` member (`type U = R \| S`) | runs | **yes** |
| the records (`{[string]: i32} \| {[string]: string} \| null`, two maps) | the same refusal | no |
| `as?` for `as!` | the same refusal | no |
