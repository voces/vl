### D15296 — a list of records holding a list of an un-annotated function, built inside a generic function, is refused at emit when a call reaches that function through the list

**loud emit reject · `emitProgram: ref valtype with no interned shape` · clause 2 · open · the same body with the stored function never called runs since [D15293](D15293.md) · found closing [D15293](D15293.md) · filed 2026-11-04 against master `b19b5895`**

Repro:

    function inc0(a) { return a + 1 }
    function mk<T>(x: T) { return [{ fs: [inc0], x: x }] }
    const r = mk(5)
    print(r[0].fs[0](4))

Want:

    5

#### Mechanism

The elaboration stamps an instance's record-list literal at its held type (`elabHeldListFacts`, [D15293](D15293.md)) only where no call through a function value reaches the stored set. Stamped where one does, the instance builds the literal at the closed row while a second row of the same shape is interned with its function-list field at the outer list's type, and the module fails to validate inside `mk`; declining keeps the refusal loud.

#### Ablation

| spelling | outcome |
| --- | --- |
| the witness | loud emit reject |
| the call made inside `mk` on a bound copy | loud emit reject |
| `mk("s")` or `mk(5.5)` for `mk(5)` | loud emit reject |
| `const g = r[0].fs[0]` with no call, then `print(r[0].x)` | runs, `5` |
| `function mk()` without `T`, `x: 5` | runs, `5` |

#### Grading list

The two-instance spelling `mk("s")` called, then `mk(2)` called with `q[0].x` (`5`, `s`, `3` once fixed); the field order `{ x: x, fs: [inc0] }`.
