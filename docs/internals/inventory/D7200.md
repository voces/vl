#### Mechanism

`monoCellAliasListFail` refuses a list literal whose element names a captured, written binding,
because a call through the list would not follow the cell's later writes. It asked only whether
the element named such a cell, never whether the list could hold a function at all. At
`mid(3, 4)` the list is `i32[]`.
