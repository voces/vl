### D16324 — a record `is` whose tested type narrows a field to something other than a literal set is refused at emit

**closed · runs, prints `true` then `false` · was a loud emit reject (``emitProgram: `is` over a record tests a field that is not a literal set narrowed from the declared field, which has no lowering yet``), clause 2 · found from the `--sites` ZERO rows · filed 2026-11-15 against master `5683d3b2c` · fixed 2026-11-15: a record test the shared predicate answers partly is minted as a test of each field it narrows at that field's own type (`recFieldFitBuild`, check_annot_resolve.vl), so a nested record recurses through its own check; a union operand's partial arm, `match` and `as?`/`as!` take the same check. Matrices `record-is-narrows-union-field`, `record-cast-narrows-union-field`, `record-match-narrows-union-field`. Fixture: `tests/cases/narrowing/record-is-narrows-non-literal-field-runs.vl`. Probe: `record-is-test-narrows-non-literal-field.vl`**

Repro:

    type A = { x: i32 | string }
    type B = { x: i32 }
    function g(a: A) { a is B }
    print(g({ x: 1 }))
    print(g({ x: "s" }))

Want:

    true
    false

#### Mechanism

The emitter lowered a record test only when every narrowed field was a literal set over the
declared field (`emitRecordFitIs`); the checker minted a content check only for a union
operand whose arm narrowed by literal sets (`recPartFitBuild`). A narrowed field of any other
kind reached the emitter's refusal.

On master `5683d3b2c`.
