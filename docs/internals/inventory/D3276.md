### D3276 — an object literal written as a `match` arm or `if` branch body got no diagnostic naming the parentheses

**closed 2026-09-29 as a diagnostic: the witness is now a loud check reject that names the parentheses (a keyed statement `a: 1` is one parse diagnostic naming `({ a: … })`; a `void` or non-object error whose subject is a recorded arm's value names that arm and the parentheses) · the parse is design (an arm's braces are a block, as an `if` body's), only the diagnostics changed · found by the #3299 review grid · filed against master `296e1141d` · fixtures `tests/cases/match/object-arm-keyed-value.vl`, `tests/cases/match/object-arm-needs-parens.vl`**

Repro:

    function h(b: i32) { match b { 3 => { a: { b } }, _ => { a: { b } } } }
    print(h(3).a)
    // before loop values the arm was void (`… on non-object void`, with the same note)
    // now: member access '.a' on non-object i32; the braces at 1:37 are a block, not an
    //      object literal; parenthesize an object there: `({ … })`
    // Since loop values landed a labelled block is a value, so `{ a: { b } }` there is `b`
    // and `const v = h(3)` binds it; a use of it as an object is what takes the note.

#### Mechanism

`match` arms and `if` branches call `parseBlock` directly, so an object literal there must be
parenthesized. Two failures followed, neither naming that: `{ a: 1 }` was
`expected an expression but found COLON` once per field, and `{ a: { b } }` parsed as a labelled
block, so the arm was `void` and a use far away said so. `parseStmt` now refuses `name: value`
(a name and `:` before anything but a loop or `{`) once and skips the body's remaining fields.
The parser records a non-empty arm or branch brace that `looksLikeObject` (`objLookMark`; an
empty `{}` is a block and is never recorded), and `mkFunc` names the function whose tail `if` or
`match` the arm ends. `tErrPush` appends the parentheses to a `void` or non-object error only
when its subject is that arm's value: the arm lies inside the error's node, or the node calls
the function the arm ends. The note cites that arm. Nothing runs per block.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `=> ({ a: { b } })` parenthesized | runs | **yes** |
| the arm in an `else` body | object literal, runs | **yes** (an `else` body admits one) |
| `{ b }` shorthand arm | block, `.b on non-object i32`, no note | design (shorthand is a block in every body) |
