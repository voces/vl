### D3618 — an annotated `A | B | null` read through `??` at a `boolean`/`string` pin traps on the `null` arm

**trap after load · open · clause 1 · the same on master `0c087fb3c` · found by the #3368 review's generator (`p2.vl`, the `*_nul_bs_coal_in` cells) · filed 2026-10-04 against master `0c087fb3c`**

    function F<A, B>(k: i32, a: A, b: B) {
      const v: A | B | null = if k == 0 { a } else if k == 1 { b } else { null }

#### Mechanism

Not localised. At `(boolean, string)` the binding is the box `boolean | string | null`, and the
`??` result, a join of that box's non-null members with the literal `9`, is read as a value the
`null` arm's payload cannot be cast to. The un-annotated binding runs, and so does the same
annotation at `(i32, string)`.
