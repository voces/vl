### D3693 — a record-pattern generic instantiated for a record whose pattern field is not its first field, beside a second instance, is invalid wasm

**check-clean invalid wasm · clause 1 · the un-annotated spelling is the same on master `56af0f07e` · found by the #3385 review (`rv85`, `ga/t3_x_reorder`) · filed 2026-10-05**

Repro:

    function getX<T>(r: { x: T }): T { r.x }
    const a = { y: 5, x: true }
    print(getX(a))
    print(getX({ x: 1 }) + 1)
    // vl check: rc 0.  vl run: invalid module, type mismatch: expected (ref $type), found (ref $type)

Want:

    true
    2

#### Mechanism

Not traced. Each instance pins its parameter at the substituted pattern (`{ x: boolean }`,
`{ x: i32 }`), and a record whose `x` is not its first field is not a wasm subtype of
`{ x: … }`. With `x` first the same pair of calls is refused loudly (the argument's row holds
another field kind than the instance's), so the reordered field is what slips past that guard.
One call alone runs.
Since [D3674](D3674.md) the declared spelling (`type W2 = { y: i32, x: boolean }`, `const a: W2`)
reaches this too: one cell of the `rv85` `ga` grid moved from a loud emit reject to this invalid
module, the price D3674 records.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| no second call `getX({ x: 1 })` | prints `true` | **yes** (two instances) |
| `{ x: true, y: 5 }` (`x` first) | loud emit reject, `a record argument's fields name a row that holds another field kind` | **yes** (the reordered field makes it silent) |
| `const a: W2` declared | same invalid module (since D3674; emit reject on master) | no |
