### D2926 — a hole function's lambda returning a list of, a read of, or a call reaching a `string | null` null traps

**loads then traps · clause 1 · open · found by the #3237 review grids · the same on master `e91e04a8f` · filed 2026-09-27 against master `a41bd80e8`**

Repro:

    function F(x) {
      const c = () => [x]
      print(c().length)
    }
    const v: string | null = null
    F(v)
    // vl check: rc 0.  vl run: wasm trap: null reference

Want:

    1

#### Mechanism

Not localised. Each shape returns, from a lambda cloned per instance, a value whose type is the
hole's variable at the template: `[x]`, `xs[0]` of a hole list captured, or `c()` of another
lambda (`const d = () => c()`). Its return is inferred as a non-null `string`, and a null traps.
[D2878](D2878.md) pins the return of a lambda that returns the hole parameter, or a field of it,
and is only called directly. That pin is withheld from these shapes, because a lambda read from
inside another lambda sees the template's signature (the #3237 review's `min_loss`).

#### Grading list

must also re-grade the #3237 review's `min_loss`, which runs at a non-null value.
