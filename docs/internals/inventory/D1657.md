Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    type Box = { xs: Shape[] }
    function other() {
      const w: Shape[] = []
      w.push({ s: 3 })
      print(w.length)
    }
    function d0() {

      print(s0.xs.length)
    }

#### Mechanism

`covarValueWriteState` is memoised per (root name, frame), so each covariant binding in a
program is one query, and each query ran `cwGrow`, `cwEscapedFields` (once per closure round
and again for the write pass), `cwClaimed` twice, `cwWrites`, `cwSplitStorage`, `cwElemRead`
twice, `cwTwoUnions` and `cwProgramHasWrite` — twelve `while i < P.nodes.length` walks, each
asking `covarRootFrame` of the nodes it passed. That resolver is the second multiplier:
`cwFrameOfUse` walked out along the frame chain asking `cwFrameDeclares`, a LINKED LIST of
the frame's declarations, and module scope's list is one row per top-level name. On the
1,000 x 1,000 shape program `cwFrameDeclares` is **70.9% of guest self time** and
`cwFrameOfUse` 75.6% inclusive, with `cwEscapedFields`, `cwGrow` and `cwClaimed` its three
callers — the scans supplied the outer factor and the chain the inner one.

Both halves are now table reads. The declarations go into one open-addressed `(frame, sid)`
membership table, built at the end of the frame walk, so `cwFrameDeclares` is a probe rather
than a walk. And `cwIxBuild` — the per-arena occurrence index D1628 introduced — grew the
facts the rest of the family needs: what CONSUMES each node (`cwIxUp` / `cwIxUpKind`, one of
twelve roles), the first `FuncDecl` per interned name, and the list writes whose receiver
roots at no name. Every query above now walks the set's own occurrence chains: a use of a
member name, a read back out of a container the set escaped into, and a call of a function
the closure rooted at. `cwClaimed`'s whitelist is the same whitelist, asked of one node
instead of the arena — a role with no arm is `CW_UP_NONE`, which reads as unaccounted, so a
form nobody modelled still gives the `2` answer rather than a guess.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |

| the struct-field delivery (`print(b0.length)` instead) | still one query per binding | no |
| the filler bindings | still quadratic, smaller constant | no |
