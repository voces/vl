### D6481 — a `let` lambda handed to an un-annotated parameter that calls it with a generic function is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the direct call `lap(id)` runs, so the parameter delivery is a monomorphization the emitter has not built (lane L1) · found closing [D6421](D6421.md) · filed 2026-10-18 against master `b21da3d5d`**

Repro:

    function id(a) { return a }
    const lap = (g) => { print(g(1) + 1); return g("s") }
    function use(k) { return k(id) }
    print(use(lap))
    // vl check: rc 0.  vl run: emitProgram: monomorphize: unsupported argument type for `k` in a call to `use`

#### Mechanism

From the ablation only. `use`'s parameter `k` is an inference hole bound to a lambda value
whose own parameter is a hole, and the monomorphizer has no argument type to instance `use`
at.

#### Ablation

| spelling | outcome | needed? |
