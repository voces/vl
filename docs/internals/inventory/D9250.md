#### Mechanism

`synthRetAnnots` (emit_rewrite.vl) runs before the monomorphizer and gives a lambda's
un-annotated result the checker's inferred type, here `{m: {[string]: (_) => _}}` with its
holes open. `monoPinReturnedObj` pins a returned record literal only when the function has
no result type, so the lambda kept the open record, and `cloRetValSlot` read it to type the
closure's signature. `monoRetRecordOf` treats a result that is still open, outside a generic
instance, as unwritten: when every `return` is a record literal (or a `const` bound to one,
D9251) that closes alike, it re-pins the result to that record. The call's binding then takes
it through `monoPinCallRecord` as for a declared function.
