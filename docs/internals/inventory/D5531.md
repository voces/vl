### D5531 — a generic returned from an un-annotated function, called at two types through two results, binds one instance

**loud emit reject · `vl check` rc 0 · clause 2 · the same on master `380feb42d` · found closing [D5400](D5400.md) · filed 2026-10-17 against master `380feb42d`**

Repro:

    function k<T>(x: T): T { return x }
    function mk() { return k }
    function main() {
      const a = mk()
      print(a(1))
      const b = mk()
      print(b("s"))
    }
    main()
    // vl check: rc 0.  vl run: emitProgram: a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type

Want:

    1
    s

#### Mechanism

From the ablation only. D5360 delivers the returned generic at the one pin past `mk`'s return;
two results called at two types give that return two pins, and the delivery takes none. The
alias spelling `const g = k; return g` refuses the same way.
