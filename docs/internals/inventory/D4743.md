### D4743 — a declared alias of one-list members stored into a nullable record field keeps its union box where the field wants the list

**closed 2026-10-14 — the witness prints `false` · was check-clean invalid wasm, clause 1 · a union of 2+ lists whose members all render one list (`oneListUnionRender`, `compiler/typecheck.vl`) is that list at every position: `isValueUnionBox` declines it, a declared alias of it renders and canons as the list and registers no union row (`collectU`), and `repOfTyFlat`/`repOfNullable`/`rtNulDiscOf` give it the list's rep, so the bound alias and the `A | null` field agree · `const n: A | null = a` and an inline `(i32[] | K[]) | null` binding, this row's grading list, now run (`false`) · the alias template `scripts/capability-probes/matrix/union-of-one-list-members-alias.matrix.vl` grades 66 of 66 · fixture `tests/cases/unions/one-list-member-union-positions.vl` · filed 2026-10-14 against master `3a8eb2b61`**

Repro:

    type K = 0 | 1
    type A = i32[] | K[]
    type R = { g: A | null }
    const a: A = [1]
    const r: R = { g: a }
    print(r.g == null)
    // vl check: rc 0.  vl run: invalid module, expected (ref null $6) list, found (ref $1) union box

Want:

    false

#### Mechanism

A declared union alias is registered by its member set (`i32[]|K[]`, never deduped), so a
binding annotated `A` is a union box `{i32, anyref}`. The field type `A | null` renders
through the arena, whose union arm collapses the duplicate member spellings to `i32[]`, so
the field is a nullable list. The store hands the box to a slot typed as the list with no
unwrap: two producers disagree about one type's rep (D4742 is the arena side).

#### Grading list

`const n: A | null = a` with the same `A` refuses at emit with `bare null needs a struct-typed
context`, as does an inline `(i32[] | K[]) | null` binding: the nullable of the collapsed
union, one position over. Re-grade both when this closes.
