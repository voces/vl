### D3531 — a declared literal union of an integer and a string, read through `??`, traps with a cast failure when delivered into `i64 | string`

**loads then traps · clause 1 · open · found by lane LC's literal-union grid (12 of 5,632 cells, `str_co5_i64s_*` and `w2s_co5_i64s_*`) · the same on master `f6e17953b` · filed 2026-10-03 against master `f6e17953b`**

Repro:

    type U = 1 | "s"
    function mk(): U { 1 }
    const x = mk()
    const r: i64 | string = x ?? 5
    print(r)
    // vl check: rc 0.  vl run: trap, cast failure, "a value was not an instance of the type it
    // was narrowed to"

Want:

    1

#### Mechanism

Not confirmed. The box holds `1` under the `i32` tag, and `i64 | string` has no `i32` member,
so the delivery owes the retag `widenMemberPairs` records (since D3523 it reads a literal leaf
at its base, which is what made the same delivery without `??` run). Through `??` the retag is
recorded against the expression's value tails (`valueTailLeaves`), and with the DECLARED alias
`U` the tail's type apparently reaches it in a form whose leaves do not widen; the inline
spelling `1 | "s"` runs. The `??` is a no-op here (`U` has no `null`), so the defect is the
alias seen through the join, not the default.
