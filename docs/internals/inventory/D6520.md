### D6520 — a binding seeded with a generic and written with a hole parameter called at another type calls the seed's instance

**loads then traps · `vl check` rc 0 · clause 1 · found closing [D6470](D6470.md) · filed 2026-10-18 against master `d9c8431e5`**

Repro:

    function same<T>(k: T): T { k }
    function mid(a) {
      let b = same
      b = a
      print(a("x"))
      print(b(3))
    }
    mid(same)
    // vl check: rc 0.  vl run: prints x, then wasm trap: indirect call type mismatch at `b(3)`

Want:

    x
    3

#### Mechanism

From the ablation only. `b` is seeded with `same` and then holds `a`, which is called at
`string`; the call `b(3)` goes through a signature built for one of the two values, and the
other is what arrives. D6470's copy split does not reach it, because `b` is not a copy of `a`
at its declaration.
