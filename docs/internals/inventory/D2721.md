### D2721 — a generic that calls itself at a larger type passes `vl check` and has no finite set of instances

**loud emit reject · clause 2 · found by #3202's review (a6b, a6c) · was a hang on master: `vl check` rc 0, `vl run` never returns · filed 2026-09-26 against master `74bd044d7`**

Repro:

    function f<T>(u: T | null, n: i32) {
      if n == 0 { print(u == null) } else { f<T[]>(null, n - 1) }
    }
    f<i32>(1, 2)
    // vl check: rc 0.  vl run: emitProgram: monomorphize: `f` instantiates itself at a new type on every call, so it has no finite set of instances

#### Mechanism

Monomorphization mints one instance per pin, and walking the instance at `T` finds a call at
`T[]`, whose instance finds `T[][]`, without end. On master the monomorphizer never returned.
#3202 bounds how many instances of one template are walked one inside another (32), so the hang
became this refusal. A repeated pin hits the registry, so recursion at one type never counts.
The design owes the refusal at `vl check`: polymorphic recursion that grows the type argument
cannot be monomorphized, and the checker can see the growth at the call.
