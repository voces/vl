### D3994 — a `let` seeded with a hole lambda, in a function body, written with a generic and called traps

**closed 2026-10-12 by lane SC with D3961 (#3570): the generic written over the hole-lambda seed is instanced at the call's signature · runs · was loads then traps · found in review of #3508 (`rv3508/e01`; 12 cells of the D3960 matrix, `hole_generic_*` in function scope) · filed 2026-10-11 against master `4d0501a9e`**

Repro:

    function other<V>(v: V) { print("O"); print(v) }
    function main() {
      let k = (u) => { print("H"); print(u) }
      k = other
      k(7)
    }
    main()
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch

Want:

    O
    7

#### Mechanism

Not located. The call pins the hole-lambda seed at `(i32) => void`, but the generic written over
it is not instanced at that signature, so the slot holds `other`'s default instance. A seed that
names a declared generic (`let k = inner`) is instanced at the call (D3961's close, #3517); a hole-lambda
seed reaches another rung.
