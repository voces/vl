### D15700 — a hole its function never calls, handed on in a `const` record to a callee that calls the field at two types, is refused at emit

**loud emit reject · clause 2 · `a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type` · found closing D15649 · filed 2026-11-11 against master `94b382ce`**

Repro:

    function dbl(v) { return v + v }
    function call0(r, x) {
      print(r.f(1))
      print(r.f(x))
    }
    function both(g) {
      const r = { f: g }
      call0(r, 2.5)
    }
    both(dbl)

Want:

    2
    5

#### Mechanism

Unmeasured. D15649's close makes a call through a field of a record literal handed straight to
the callee name the set to the late decision; a `const` of the literal is not forwarded
(`holeBindArgListsHole` and `elabRecLitFwdTargets` follow a record only as the argument itself,
[D15639](D15639.md)), so `call0` takes `r` at a closure record called at two types.

#### Ablation

| spelling | outcome | needed? |
| --- | --- | --- |
| the literal as the argument, `call0({ f: g }, 2.5)` | runs, `2` `5` (D15649) | **yes** |
| one call `r.f(x)` in `call0` | runs, `5` | **yes** |
| a list, `const r = [g]` with `r[0](x)` | runs, `2` `5` | **yes** |
