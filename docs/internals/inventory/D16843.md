#### Mechanism

`eplCallResultFlow` draws a call through a function value from each member's result place,
keyed `eplKeyOfFn(member)` under the call's instance. The member here is the lambda `() => g`,
made in `wrap`'s instance, which `mid`'s instance reaches by its call `wrap(a)` but which is minted
at the root, not under `mid`'s; `eplKeyOfFn` looks only among the calling instance's ancestors,
finds none and draws nothing. So `w()(3)` is not a call
through `a`, and mono sees `a` called at one type. The refusal moves, it does not lift; the
fixture is `tests/cases/functions/error-generic-handed-to-bare-param-comes-back-in-returned-closure.vl`.

A first fix made the compile of this program hang, and was reverted. The closing fix draws from
each instance of the member's frame nested in or reached (`elabReaches`, a visited walk) from the
calling instance, once per (frame key, member, call); the build mints no instance, so those triples
are finite and the pass ends. The witness, the input that hung, compiles in seconds under `timeout`.
