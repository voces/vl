### D16812 — a named or returned list of un-annotated functions, an element of a list of lists of a wider set, has no interned shape at emit

**loud emit reject · clause 1 (check accepts what emit refuses) and clause 2 · found closing [D16805](D16805.md) · filed 2026-11-16 against master `34980f8bf`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const q = [half]
    const xs = [[inc0], q]
    for x in xs { print(x[0](3)) }
    // vl check: rc 0.  vl run: emit error, "emitProgram: ref valtype with no interned shape"

Want:

    4
    1.5

#### Mechanism

Not yet located. The tag plan re-types an element literal of a smaller set to the list's element
(`ftInnerLeaves`, `compiler/check_fn_tag.vl`), but takes an element that names a list, or calls
a function returning one, only when it already holds the whole set (`ftInnerLit`): `q` holds
`{half}`, so the plan refuses and the list is held as closures over hole functions.

#### Grading list

- Returned: `function mk() { return [half] }`, `[[inc0], mk()]`.
- Pushed: `xs.push(q)`, `xs.push(mk())`, `xs.push(ys[0])`.
