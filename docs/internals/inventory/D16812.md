### D16812 — a named or returned list of un-annotated functions, an element of a list of lists of a wider set, has no interned shape at emit

**closed 2026-11-16 — the witness runs and prints `4` then `1.5` · was: loud emit reject · clause 1 (check accepts what emit refuses) and clause 2 · found closing [D16805](D16805.md) · filed 2026-11-16 against master `34980f8bf`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const q = [half]
    const xs = [[inc0], q]
    for x in xs { print(x[0](3)) }
    // vl check: rc 0.  vl run: emit error, "emitProgram: ref valtype with no interned shape"

Want:

    4
    1.5

#### Mechanism

The tag plan (`compiler/check_fn_tag.vl`) re-typed an element literal of a smaller set to the
list's element (`ftInnerLeaves`), but took an element that names a list, or calls a function
returning one, only when it already held the whole set (`ftInnerLit`). Such an element of a set
within the list's, of the element's shape, now has that set decided with the list's
(`ftListElemOk`), whose ids are the same; a set already tagged apart is still refused. The
smaller set's own plan takes the list pushed onto the wider list of lists (`ftListListOfWider`
for a `push`), as it already took it in a literal.

#### Grading list

- A returned list, a three-level returned list, the name read on its own before and after, the
  name shared by two lists of different wider sets, a list of two members: run.
- Pushed: `xs.push(q)`, `xs.push(mk())`: run.
- An element read pushed, `xs.push(ys[0])`: still refused.
