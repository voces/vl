### D2851 — a record-typed parameter whose field is a type parameter cannot be pinned from a literal argument

**closed · the monomorphiser pins an anonymous-row argument at its spelled shape ([D3123](D3123.md)) · fixture `tests/cases/generics/anon-record-arg-to-record-pattern.vl` · was a loud emit reject · clause 2 · identical on master `7323baf55` · found by the #3220 round-2 review (`lu_gen`) · filed 2026-09-27, closed 2026-09-28 against master `a29230611`**

Repro:

    function g<T>(o: { k: T }) { print(o.k) }
    g({ k: 3 })
    // vl check: rc 0.  vl run: emitProgram: monomorphize: unsupported argument type for `o` in a call to `g`

#### Mechanism

Not ablated to a rung. The parameter's annotation is a composite riding `T`, so
`monoInstantiateCall` binds `T` from `monoArgPinName` of the argument. For an object literal
argument that pin needs the literal's row, and a literal delivered to a `{ k: T }` destination
has none at emit time. `g(r)` with a declared `R` argument goes past the pin.
