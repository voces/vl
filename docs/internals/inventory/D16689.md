#### Mechanism

A list test is settled from its pins (`settleListIsPins`, check_operators.vl) for an operand that is
a bare hole or type parameter, or a parameter, field or annotated `let` of a list of one, and the
arms it guards are dead and unlifted. One node answer serves every instance, so three spellings
keep the emptiness answer (`emitListEmptyFitIs`, D4910): a test another call hands a fixed list
that meets it (the witness, `h(e)` beside `h([2.5])`), a union operand (`v: V[] | null`), and a
test whose function also receives an empty literal or a defaulted list
(`listTestOwnerHasOpenCall`). Each needs a per-instance answer and per-instance dead arms.
