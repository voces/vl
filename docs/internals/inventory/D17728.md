### D17728 — a map read of a null-field record whose shape is a union arm's builds a non-null ref into a nullable cell

**check-clean invalid wasm · filed 2026-11-27 against master `2675cec5` · owner CENSUS**

Repro:

    type Circle = { r: i32 | null }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    const m: {[string]: {r: null}} = Map()
    m["k"] = { r: null }
    const n: {r: null} | null = m["q"]
    print(n == null)
    // vl check: rc 0.  vl run: invalid module, "type mismatch: expected (ref null $type), found (ref $type)"

Want:

    true

#### Mechanism

A map whose value is a record holding only `null` fields, with a declared union arm (`Circle`) that
the record's shape is narrower than, stores and reads its values at that arm's variant row. The
miss read `m["q"]` into a `{r: null} | null` cell yields the row's non-null ref where the cell is
the nullable one, and the module fails validation. Found grading the narrow-arm rep rule (the
census map-read family, branch census-maprow), which does not change it.
