#### Mechanism

`emitAsNulNiche` (`compiler/wasmEmit.vl`) asks `nulNicheCastWiredTy` whether the payload's cell is
wired, and a function type is not. A nullable closure is the closure struct's own nullable ref
(`cloStructIdx`, as [D16036](D16036.md)'s standalone `?.` leaf reads it). So `as!` is
`ref.as_non_null` over that ref and `as?` the identity, once the consumers read the cast node's
closure type.
