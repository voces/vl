### D14281 — a module-scope `let` with no initializer has no global cell, at every type

**closed 2026-10-26 (`globalIsNonConst` in `compiler/emit_query.vl` answers true for a binding with no initializer, so its cell is the non-constant global's, nullable and zero-initialised, and its reads assert non-null; `globalRunsInStartFn` runs no initializer for it; `globalPromotable` promotes it like any other binding) · was loud emit reject · clause 2 · the module-scope face of [D3242](D3242.md) · read before the first write is [D14360](D14360.md) · filed 2026-10-26 against master `c32dd5c14` · fixture `tests/cases/globals/uninit-let-module-cell.vl`**

Repro:

    let r: i32
    if (true) { r = 1 } else { r = 2 }
    print(r)
    // vl check: rc 0.  vl run: emitProgram: module global has no initializer

Want:

    1

#### Mechanism

The global section's cell loop in `compiler/emit_sections.vl` refuses any `LetDecl` with no
initializer before it asks `globalIsNonConst`, and the start-function promotion (G2c, rule P3)
declines a binding with no initializer, so the binding gets neither a global cell nor a
start-function local. A non-constant global is already declared nullable and zero-initialised,
which is the cell this binding needs.
