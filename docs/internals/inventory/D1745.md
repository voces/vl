### D1745 — the per-rep value BOXES are minted at union REGISTRATION, so an inferred join whose atoms no declared union shares has no box to coerce into

**closed 2026-09-06 — an unregistered value-union join opens the union type block the way a
declaration does, from `collectA`'s node walk, flag-only and order-blind · was a loud emit
reject, clause 2 · filed against master `114b3f835`, closed against `1a5955551` · residue
D1767 · 0 corpus cells**

Repro:

    const c = true
    print(if c { "green" } else { 7 })
    // vl check: rc 0.  vl run: exit 1,
    // emitProgram: union atom has no value box

#### Mechanism

MEASURED, and the row's own sentence was half of it. `markValueUnionAtoms` sets `vbI32Used`
and friends at `registerValueUnionName`, so a join that exists only as an inference sets
nothing — that much the row had right. But setting those flags is **not** what a close needs,
which a candidate that set them and nothing else proved: it left the witness `check`-clean
**invalid wasm**, `expected struct type at index 0, found (array (mut i32))`. The whole union
type block in `mAssignTypeIndices` — the variant structs, `uBoxIdx = mAllocType()`, AND the
per-rep boxes — sits inside `if uDeclared { … }`, so with `uDeclared` false none of it is
allocated and the coerce writes a `struct.new` at an index that was never assigned, which
resolves to 0, the i32 array.

**Ordering was never the obstacle**, which an earlier reading of that candidate got wrong:
`collectA`'s node walk runs before `mAssignTypeIndices`, so a mark placed there is in time.
`uDeclared` is the gate, and only registration or this mark opens it.

The close is one arm on `collectA`'s existing node loop for an `IfStmt` whose recorded arena
type is a `TyUnion` with no registered row (`unRowOfCanon(ty) < 0`): it opens `uDeclared` and
calls `markValueUnionAtoms` off `arenaEmitName(ty)`. Flags and a gate, no registry row and no
member order, so it does not touch the question D1712 is filed on. The declared spelling is
unchanged — registration already opens the same gate — and the two now emit programs that
print the same thing.
