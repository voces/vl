### D1745 — the per-rep value BOXES are minted at union REGISTRATION, so an inferred join whose atoms no declared union shares has no box to coerce into

**loud emit reject · filed 2026-09-06 against master `114b3f835` · the half of D1733 that a
`print` classifier cannot reach · 0 corpus cells**

Repro:

    const c = true
    print(if c { "green" } else { 7 })
    // vl check: rc 0.  vl run: exit 1,
    // emitProgram: union atom has no value box

#### Mechanism

`markValueUnionAtoms` sets `vbI32Used` / `vbI64Used` / `vbF64Used` / `vbF32Used` and the
list/string type flags, and it runs at `registerValueUnionName` — that is, when a union is
DECLARED. `mAssignTypeIndices` then interns exactly the reps those flags name. A join that
exists only as an inference registers nothing, so `vbHeapIdxOfKind` answers -1 for its `i32`
arm and `emitUnionCoerce` refuses.

Declaring the same union anywhere in the program is the whole difference: with
`type U = string | i32` present, the identical `print(if c { "green" } else { 7 })` runs and
prints `green`. The declaration is not consulted at the print site — it only mints the box.

This is a TYPE-section mint, not a registry row: the flags are per atom KIND and carry no
member order, so closing it invents no ordering and does not touch the question D1712 is filed
on. What it needs is a walk that reaches an inferred join in a position with no binding — the
argument position has neither the binding hook D1709 added nor the inferred-return one
`collectU` already had.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the inference (`type U = string \| i32` declared anywhere) | runs, prints `green` | **yes** |
| the direct argument (bind it, then `print` the binding) | runs, prints `green` | **yes** |
| the mixed arms (`if c { 3 } else { 7 }`) | runs | **yes** |

#### Grading list

The three ablation rows at both faces, `tests/cases/unions/print-if-expression-join.vl` (which
declares the union and must keep running), and D1733's own bound control. A close should also
grade an inferred join in the two other positions with no binding — a call argument to a
user function, and a `return` — since the mint has to reach all three or the family only moves
at `print`.
