### D1491 — the registry key FUSES a declared alias with its inline spelling, and the A/B counter called that a disagreement

**runs today and must keep running · 1,499 of 1,587 counted `differ` reaches · filed 2026-09-03 against master `fd95c79f`**

Repro:

    type C = { a: i32 }
    type D = { b: i32 }
    type U = C | D
    function pick(x: C | D): i32 {
      if x is C { return x.a }
      return 1
    }
    const u: U = { a: 5 }
    print(pick(u))
    // prints 5. Two registry rows, `U` and `C|D`, one `unKey`.

#### Mechanism

`canonUnionKeyText` is the member SEQUENCE, so a declared alias and the inline spelling of the
same members mint ONE key — that is the equivalence the design asks for (§2's `flat.vl` and
#2406-d2 are the same property). `unRowOfKey` scans `unKey` and returns the FIRST row with that
key, so the id side names the alias where the spelling named the inline row.

`unABProbe` had six outcomes and no way to say that, so every such reach landed in `differ`.
Measured over the 2,790-program corpus with the arena key on the id side, step 4a reported
**1,587 differ**; separated, **1,499 are key-EQUAL siblings** and **88 really disagree** — and
87 of the 88 are the three WRITE-seam sites (`collectU/inferLetTy` 50, `nliInferIfLet` 32,
`nliInferOptChainLet` 5), whose probe is `unABTyProbe`, a `repCanonId` comparison of two arena
TYPES at a mint that the key never re-keys. **One reach in the whole corpus is a read seam
naming a different row**, and it is 4a's miss #3 (`null|f64` against `f64|null`).

The reach counts are unchanged by any of this — `agree` 30,245, `neither` 990,200, `no-ty`
33,188 — and every module the corpus builds is byte-identical. What moved is the sentence.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |

| the `is C` narrowing | still two rows, still one key | no |
| distinct member sets between the two spellings | different key, no merge | **yes** |

#### Grading list

The fused pair must stay interchangeable, which is `keySweep/merge-diffvar` (D1492) and not
`merge-diffset`: both rows here hold the variant slice `[C, D]`, so either answers. Step 5's
switch re-grades this program and D1492's, in that order.
