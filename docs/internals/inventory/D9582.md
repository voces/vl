#### Mechanism

An anonymous lambda's empty `[]` result has no element type of its own, so it builds only
when a contextual adoption rung in `inferredReturnOf` (`check_inferred_return.vl`) takes the
expected return as the lambda's. The rung for a list of records is `structElemListRetName`
(`check_ret_name_shapes.vl`), gated on `structElemFieldsPlain(t.aElem, 4)`, whose depth
budget of 4 declines a record whose fields nest four records deep. No other rung admits a
list of records, so `inferRetEmptyListFloor` refuses.
