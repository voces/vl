### D1903 — an `if` arm delivers a bare block's tail value, so the same block is an expression in one position and a statement in the other

**runs today and must keep running · filed 2026-09-07 against master `fbe0b0f01`**

Repro:

    function k(): i32 { if true { { 5 } } else { 6 } }
    print(k())
    // vl run: 5

#### Mechanism

`emitStmtTail` routes EVERY `IfStmt` in tail position through `emitIfTail`, which lowers each
arm's last statement tail-aware; `drwBareBlock` has already turned the arm's `{ 5 }` into
`if true { 5 }`, so the arm emits `return (i32.const 5)` and the value arrives. `emitFuncBody`'s
own tail ladder is the same walk one position up and does NOT have that arm — it takes an
else-less `if` only when the return type is nullable (`elseLessNullableTail`) — which is why the
identical block at the body's tail dropped its value (D1902). One walk, two functions, only one
of which hands back: the `kind-ladder-split` shape.

So the language today says a bare block is a statement (D1901's `isStmtNode`, and inference
answering `void`) while three delivery positions treat it as an expression. Which one is right
is the owner's open bare-block-as-expression question; this row exists so that whichever way it
is answered, the cells that RUN today are re-graded rather than quietly lost. The un-annotated
face already shows the disagreement inside one program: `function k() { if true { { 5 } } else
{ 6 } }` infers `void | i32`.

#### Ablation

| ingredient | outcome |
| --- | --- |
| the block in an `if`-THEN arm (`if true { { 5 } } else { 6 }`) | runs, `5` |
| the block in the ELSE arm (`if false { 6 } else { { 5 } }`) | runs, `5` |
| two blocks deep (`if true { { { 8 } } } else { 6 }`) | runs, `8` |
| the block holding a prelude (`{ 5 \n 7 }`) | runs, `7` — the TAIL, not the first |
| the same block at the function BODY's tail | check refuses since D1902 |
| the un-annotated face of the arm spelling | `void \| i32` |

#### Grading list

Whoever answers the bare-block question re-grades all six rows above plus D1902's table. If a
bare block becomes an expression, D1902's arm reads `nodeIsTotalAt(last, true)` and every cell
here keeps running; if it stays a statement, these five stop running and that price is the
thing to measure and name.
