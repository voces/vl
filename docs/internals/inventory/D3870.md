### D3870 — `is` between two same-shaped declared records tests the shape, so a `B` tests as `A`

**closed (2026-10-08, lane SC) · owner ruling (C): records are structural, so `A` and `B` of one shape are one type and `is A` holds of a `B`; runs as designed · found grading the narrowing matrix of #3460 · filed 2026-10-08 against master `36aa1ab1e`**

Repro:

    type A = { x: i32 }
    type B = { x: i32 }
    function f(v: A | B) { if v is A { "A" } else { "B" } }
    const b: B = { x: 2 }
    print(f(b))
    // vl check: rc 0.  vl run: prints A

Want:

    A

#### Mechanism

The question this row asked was whether `is` between same-shaped records should tell them
apart. The owner ruled that VL is structural: `type A = { x: i32 }` and `type B = { x: i32 }` are
two names for one type, `A | B` is `A`, and both `is A` and `is B` hold, with no run-time tag.
The program prints `A` and that is the answer. What the ruling changed is the one place the
two names were still told apart, a `self`-function on each: that is now a duplicate binding
(D3871).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the shared shape (`type B = { y: i32 }`) | prints `B` | **yes** |
| the union (`f(v: B)`, still `v is A`) | prints `A` | no |
