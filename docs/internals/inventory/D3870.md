### D3870 — `is` between two same-shaped declared records tests the shape, so a `B` tests as `A`

**check-clean silently wrong value · found grading D3869's narrowing matrix · filed 2026-10-08 against master `36aa1ab1e`**

Repro:

    type A = { x: i32 }
    type B = { x: i32 }
    function f(v: A | B) { if v is A { "A" } else { "B" } }
    const b: B = { x: 2 }
    print(f(b))
    // vl check: rc 0.  vl run: prints A

Want:

    B

#### Mechanism

Not located. The checker narrows by the declared name: in the `is A` branch the value is `A`,
and a generic pinned there takes `A`'s instance (D3869). At run time the two records are one
struct, so the test cannot tell them apart and answers for the first arm. Either `is` carries
a tag the shared struct lacks, or the checker refuses an `is` that cannot discriminate, which
is a design ruling rather than a lowering fix.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the shared shape (`type B = { y: i32 }`) | prints `B` | **yes** |
| the union (`f(v: B)`, still `v is A`) | prints `A` | no |
