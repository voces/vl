### D15751 — a field read through a hole receiver bound to a union, whose arms hold that field as two different records, has no instance union to read the next field off

**closed 2026-11-12, runs and prints `4` · the instance-only union of the field records gets its row (`monoRegisterElabJoinRows`), and the shared-field box plan types the read at its instance (`nodeTyAt`, not the template's hole) · was a loud emit reject, clause 2, `emitProgram: field access receiver is not a struct` (`emitMemStructRead`); the annotated spelling ran, so a mechanism · w315's emit-reject group E (`d15314_d315`) · found by lane w321 · filed 2026-11-11 against master `1a4c60bf`**

Repro:

    type K = { h: { f: i32 } }
    type J = { h: { f: i32 | null } }
    const u: K | J = { h: { f: 4 } }
    function take(a) { print(a.h.f) }
    take(u)
    // vl run: emit error, field access receiver is not a struct

Want:

    4

#### Mechanism

In `take` at `a: K | J`, `a.h` is typed `{f: i32} | {f: i32 | null}` at the instance (`nodeTyAt`),
a union of two records. Its template type is the hole. The checker registers no union row for
it. A scratch probe showed that registering the instance's row in
`monoRegisterElabJoinRows`, beside #7278's `??` case, is not enough.
`sharedUnionFieldPlan` for `.f` still declines: `exprUnion(a.h)` answers no through
`readRepOf`, and `unionNameOfExpr`'s `Member` arm (`memberUnionFieldNameRead`) names no row.
So the outer read falls to `emitMemStructRead`, whose receiver has no struct row. With
`a: K | J` written, the checker types `a.h` at that union, registers the row `{f:i32}|H`, and
the shared-field plan reads `.f` off both arms.

#### Closed

Two layers. `monoRegisterElabJoinRows` registers the union row of a field read whose template
type is no union and whose instance type is one, beside #7278's `??` case. And
`sharedFieldArmStructTag`, `sharedFieldStructBoxPlan` and `sharedFieldStructBoxName` take the
read's type at its instance (`nodeTyAt(readIx, fnIx)`) from their callers. Before, they read the
template's hole, so the plan found no union to box the two records into. Graded by
`scripts/capability-probes/matrix/nested-field-of-union-of-field-records.matrix.vl`.
