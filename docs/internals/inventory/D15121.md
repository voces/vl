#### Mechanism

The swapped recursion of D6240 now runs without the split plan for a top-level generic: a
forwarded bare-only type-parameter read is rewritten to the generic its parameter carries
(`elabParamCarriedInstAt`), which the generic-pin arm pins at the destination's close. The
rewrite is fenced to a generic with no enclosing function. A nested one is built per encloser, and
no reader maps the carried elaboration key to mono's instance before per-instance-identity M2/M3,
so the rewrite declines and the split plan builds this program. With the split plan off it is a
loud emit reject at the recursive call, not a miscompile.
