#### Mechanism

The swapped recursion of D6240 runs without the split plan for a top-level generic: a forwarded
bare-only type-parameter read is rewritten to the generic its parameter carries
(`elabParamCarriedInstAt`), which the generic-pin arm pins at the destination's close. That
rewrite is a NAME, and a generic nested in another function is no name inside the recursion's
frame: renaming the read to it makes mono look for it as a capture of `mid` (measured: `captured
variable not found in enclosing frame`, with the split plan on). So the rewrite is fenced to a
generic with no enclosing function, and the split plan builds this program. Closing it needs the
carried nested generic delivered as a VALUE, the forwarded closure re-pinned at the destination's
close, not a name rewrite. With the split plan off it is a loud emit reject at the recursive call,
not a miscompile.
