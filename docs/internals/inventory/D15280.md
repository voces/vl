### D15280 — a record literal chosen by an `if` and assigned into a binding held at a wider record is check-clean invalid wasm

**closed 2026-11-04 · runs, prints `6` · was check-clean invalid wasm, `vl check` rc 0 · clause 1 · found closing [D15239](D15239.md) · filed 2026-11-04 against master `a6255cea` · closed by both assignment stamps reaching an `if` or `match` arm's literal through one walk of the assigned value's leaves (`tailValueLeaves`): D15188's (`recAsgBindInit`, which climbs the index's arm links to the assignment and keeps the literal only among those leaves) and D15239's (`storeAsgLitsBuild`, since folded into `recLitPlaceBuiltTy` by [D15282](D15282.md)) · fixture `tests/cases/soundness/record-literal-arm-assigned-into-built-binding-runs.vl`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const xs = [mk()]
    let y = xs[0]
    const c = wideJ.f == 4
    y = if c { { f: 6 } } else { { f: 7 } }
    print(y.f)

Want:

    6

#### Mechanism

`y` is held at `J`, the build of `xs[0]`. A record literal assigned
into it is built at `J` (D15188 for a built read, D15239 for a built call), but both stamps take
only a literal standing as the assignment's whole right-hand side, so the arms of an `if` are
built at their own `{f: i32}`.

#### Ablation

| spelling | outcome |
| --- | --- |
| this repro (binding of a built read) | invalid wasm |
| `let y = mk()` (binding of a built call) | invalid wasm |
| `y = { f: 6 }` | runs (D15188, D15239) |
| `else if` chain, `match` arms, a call or built-read arm beside the literal | runs |
| a fresh record `const` arm beside the literal | runs ([D15238](D15238.md)) |
