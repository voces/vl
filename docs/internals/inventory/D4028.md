### D4028 — a string-literal-union argument beside a bare `null` refuses at emit when the destination binds `T` to `string | null`

**open · loud emit reject · clause 2 · found by the #3535 review (`rv3535/x04`); a check reject on master before D4024 · filed 2026-10-11 against master `1df3c8f91`**

Repro:

    function pair<T>(a: T, b: T): T[] { [a, b] }
    const k: "a" | "b" = "b"
    const ps: (string | null)[] = pair(null, k)
    const e = ps[1]
    if e != null { print(e + "!") }
    // vl check: rc 0.  vl run: emitProgram: literal-union string widening with no members

Want:

    b!

#### Mechanism

D4024 binds `T` to the destination's `string | null`, beside the `null`, from an argument of the
literal union `"a" | "b"`, which `string | null` holds. The emitter's literal-union-to-string
widening at that argument finds no members to widen from, and refuses. On master the checker
bound `T` to `null` and refused the second argument instead.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `k: string` in place of the literal union | runs | **yes** |
| `pair(k, k)` into `string[]`, no `null` | check reject: a container never widens (a design rule) | **yes** |
