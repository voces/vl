#### Mechanism

`objShapeAdapterless` withdraws D938's nested-width-pair refusal when the source is an
un-annotated binding of an object literal, because such a binding has no pinned wasm type and
the emitter lays it out at the shape it flows into. `srcIsUnannotatedObjBinding`
(`compiler/typecheck.vl`) answered that question by walking `P.nodes` from index 0 and taking
the FIRST `LetDecl` whose `letName` spells the identifier, with no scope test — so any earlier
binding of the name, in any function body, decided. It now reads a depth-tagged mark table
through `lookupDepth`, the idiom `bindingCollapsed` already used, recorded where the binding is
declared: in the pass-1.5 hoist for a module global, so a body reading a global declared below
it resolves the same way, and at the pass-2 declaration for every other frame. The two directions are one defect: an
un-annotated decoy above an annotated const withdraws a refusal that is owed (clause 1, the
witness above), and an annotated decoy above an un-annotated const raises a refusal that is not
(clause 2 — `nested-width-pair-unannotated-decoy.vl` was refused on master and runs here).
