### D4084 — a record narrowed by `is` escapes as `B` while an `A`-typed alias can still write a field `B` narrows

**parked pending an owner ruling (2026-11-01) · check-clean silently wrong value · clause 1 · found reviewing the D4058 close (#3549) · filed 2026-10-11 against master `5a9535c91`**

Repro:

    type A = { x: i32 }
    type B = { x: 1 | 2 }
    const keep: B[] = []
    function stash(a: A) { if a is B { keep.push(a) } }
    const a: A = { x: 1 }
    stash(a)
    a.x = 7
    const y: 1 | 2 = keep[0].x
    print(y)
    // vl check: rc 0.  vl run: rc 0
    // PRINTS 7

#### Mechanism

A record is shared, not copied. Delivering a `B` as an `A` is refused when the `A` is then
written (`a B cannot be delivered as A here: the assignment on line 5 writes a widened field`),
because the wider value would sit in the `B`. The narrowing `a is B` builds the same alias in
the other direction: the then-arm hands the record on as a `B` (a push, a `const bb: B = a`,
a return) while the caller's `A` still writes it. Retiring the narrowing (D4083) cannot fix
this, because the write happens after the narrowed scope has ended.

#### Ablation

| variant | outcome |
| --- | --- |
| pushed into a `B[]`, written through the caller's `A` (the repro) | prints 7 |
| `const bb: B = a` in the arm, then `al.x = 7` | prints 7 |
| operand declared `a: A \| B` | prints 7, on base too |
| `const bb: B = …; const a2: A = bb; a2.x = 7` | check reject (widened-field write), correct |

#### Grading list

Every escape position of the narrowed binding: a push, a binding, a return, an argument, a
struct field, each with the `A` write after it.

#### Parked

Parked pending an owner ruling (2026-11-01): the record twin of ruling (c) would refuse D14752's correct fixture. Two options:

1. **Refuse, consistently with ruling (c) for lists (D4928).** A record narrowed by `is B` from a
   type that stores a field wider than `B` is read as `B` but never delivered as one. Every escape
   position refuses and names the copy `{ x: a.x }`. An un-annotated copy binds at the declared
   type, and `as B` from such a union is refused. This closes D4084, D4133 and D4134. Across 17,493
   tests and corpus files, the delivery rule moved one file: D14752's
   `tests/cases/unions/layout-family-literal-set-beside-string.vl`, a correct program that would
   need the copy.
2. **Keep correct no-later-write programs.** The three rows stay open until a write-aware rule
   exists.
