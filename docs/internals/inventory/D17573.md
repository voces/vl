### D17573 — a value read back from a map whose slot is a union of bundle records has no dispatch

**loud emit reject · clause 2 · `vl check` rc 0 · `emitProgram: a function returning a parameter called at two signatures is called where its result is not used at one of them` at the first store · the read half of [D17106](D17106.md), queued after family C (coordinator ruling 2026-11-26) · filed 2026-11-26 against master `622281876` by SOUND**

#### Mechanism

D17106 stores each value in a slot typed at the union of the records the stores return
(`elabSlotUnionNote`), but only for a map no use of which reads a value. A read keeps today's
refusal. Closing it adds the read side alone: a `ref.test` on the union box's payload row, then the
member pick at the call's signature, as a single-record slot's read takes. Calling a value at a
signature some stored record has no member for is a type error the design forbids, and the checker
refuses it before this row is reached (coordinator ruling 2026-11-26).
