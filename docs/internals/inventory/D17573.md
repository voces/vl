#### Mechanism

D17106 stores each value in a slot typed at the union of the records the stores return
(`elabSlotUnionNote`), but only for a map no use of which reads a value. A read keeps today's
refusal. Closing it adds the read side alone: a `ref.test` on the union box's payload row, then the
member pick at the call's signature, as a single-record slot's read takes.

A call at a signature some stored record has no member for is decided here, not in a separate
check fix (coordinator ruling 2026-11-26, deferred into this row while every value read refuses).
The checker types the value `(_) => _` and knows no bundle's signatures, which elab gathers from the
calls inside the callee. The ruling's order:
* first, the call through the stored value joins the bundle's signature set, so `g(true)` adds a
  `(boolean)` member and the program runs;
* else, teach the checker bundle signature sets;
* never an emit-phase refusal.
