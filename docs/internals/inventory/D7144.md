### D7144 — a record of a type-parameter `let` copy that a closure writes has no struct type

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same copy written directly, `b = c`, runs (`tests/cases/closures/typaram-let-copy-written-in-record.vl`) · found closing [D7100](D7100.md) · the same on master `8e787a973` · filed 2026-10-19 against master `8e787a973`**

Repro:

    function mid<H>(a: H, c: H) {
      let b = a
      const w = () => { b = c }
      w()
      const r = {f: b}
      print(r.f)
    }
    mid(3, 4)
    // vl check: rc 0.  vl run: emitProgram: object literal but no struct type declared

Want:

    4

#### Mechanism

Not located. The binding is a captured cell once the closure writes it. The record pin's walk
to the copy's initializer (`pinnedParamTyAt`) is not where it stops: a probe there fires for
the direct-write control and is never reached for the witness, so the literal's struct is
lost before that walk is asked. The needed ingredients are a generic frame, a closure that
writes the binding, and the binding read into the record.
