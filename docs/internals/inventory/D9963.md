#### Mechanism

Not traced. No value in the program is typed `Node`, so its declaration should not change the
map's value type; that it does suggests the literal's type is read as `Node` somewhere (the
structural-record rule) while the mv slot is minted for the literal's own spelling, or the
other way round.
