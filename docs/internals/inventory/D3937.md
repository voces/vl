### D3937 — a generic parameter typed as a record holding a generic record application over the type parameter is refused

**loud emit reject · clause 2 · found in review of #3491 (`rv3491/residue/b02b_nocomp`; `b02c_inline` is the control) · filed 2026-10-10 against master `00bf1871f`**

Repro:

    type A = { x: i32 }
    type Box<T> = { v: T }
    function rd<T>(e: { v: Box<T> }): T { e.v.v }
    const o: { v: Box<A> } = { v: { v: { x: 6 } } }
    print(rd(o).x)
    const p: { v: Box<i32> } = { v: { v: 3 } }
    print(rd(p))
    // vl build: emitProgram: nested-struct field element type is not interned

Want:

    6
    3

#### Mechanism

Not located. `rd<T>(e: { v: Box<T> })` pins `e` at `{ v: Box<A> }` and `{ v: Box<i32> }`; the
nested application is not interned as a struct element at either instance. The inline spelling
`{ v: { v: T } }` runs.
