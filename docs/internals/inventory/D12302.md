### D12302 — an exported generic written to a place two steps deep that no call reads still passes the checker and refuses at emit

**loud emit reject · `vl check` rc 0 · `emitProgram: exported function `id` is generic over `T` and nothing in the program calls it` · clause 2 · DESIGN: the same write one step deep is refused at check ([D12237](D12237.md)), as is the export with no read (D3817) · value_reach.vl, `vrPlaceRoot` · found closing D12237 · filed 2026-10-24 against master `43ea89c8c`**

Repro:

    export function id<T>(x: T): T { x }
    const r = { a: { f: id } }
    r.a.f = id
    print(1)

#### Mechanism

D12237's close follows a write `r.f = id` to the reads of `r.f` when `r` is a `let` bound to a
literal. It takes one step only: the inner literal of `{ a: { f: id } }` may be shared with
another binding, so following `r.a.f` would need to know the inner literal is not aliased.
Without that, value reach keeps the write as one that may reach a call, the checker passes the
export, and the monomorphizer refuses it at the floor.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| one step (`const r = { f: id }; r.f = id`) | check reject, D3817 | **yes** |
| a call reading the place (`print(r.a.f(7))`) | runs, prints `7` | **yes** |
| `export` | runs | **yes** |
