### D12302 — an exported generic written to a place two steps deep that no call reads still passes the checker and refuses at emit

**now a loud check reject · was a loud emit reject (`emitProgram: exported function `id` is generic over `T` and nothing in the program calls it`) after `vl check` rc 0 · clause 2 · DESIGN: the same write one step deep is refused at check ([D12237](D12237.md)), as is the export with no read (D3817) · closed 2026-10-24 by lane L3 (d): value reach follows a write through any number of field and element steps of a `let` bound to a literal whose containers on the way are fresh literals, unless a use of the binding may re-point one of them · moved: `const r = { a: [id] }; r.a[0] = id` ran with `id` exported at `i32` and is now refused, as the same record with no write already was · residue: a container another binding shares ([D12332](D12332.md)) · pins: `tests/cases/functions/error-exported-generic-written-two-fields-deep-uncalled.vl`, `error-exported-generic-written-two-elements-deep-uncalled.vl`, `error-exported-generic-written-to-list-in-record-uncalled.vl`, `exported-generic-written-deep-or-repointed-called.vl` · found closing D12237 · filed 2026-10-24 against master `43ea89c8c`**

Repro:

    export function id<T>(x: T): T { x }
    const r = { a: { f: id } }
    r.a.f = id
    print(1)

#### Mechanism

D12237's close followed a write `r.f = id` to the reads of `r.f` when `r` is a `let` bound to a
literal. It took one step only, and did not ask whether `r` was re-pointed, so a `let r` assigned
another binding's literal before the write was refused although that binding's field was called.
`vrPlaceRoot` now walks every step, requires a fresh literal at each container on the way
(`vrLitStep`), and declines when a use of the binding may write or call a method on a container
above the last step (`vrRepointable`).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| one step (`const r = { f: id }; r.f = id`) | check reject, D3817 | **yes** |
| a call reading the place (`print(r.a.f(7))`) | runs, prints `7` | **yes** |
| the fresh inner literal (`const inner = { f: id }; const r = { a: inner }`) | loud emit reject, D12332 | **yes** |
