#### Mechanism

In each instance of `a`, the elaboration's record of `k` (`elabWalkTy`) is `(_) => void`: it
leaves open the hole that `k(x)` binds. `monoPinnedTyOf`'s substitution closes it, to `(i32) =>
void` at `a(1)`. So the store is not yet a full replacement for mono's pins: here mono knows a
closed type the store does not hold. The elaboration closing the captured lambda's hole at the
instance closes this row ([mono-pin survey](../mono-pin-survey-2026-11.md), groups C/D).
