### D17672 — `recValRetag` compared the struct ROW a record temp is built at with a struct HEAP index, so a right retag was refused wherever a twin row shifts rows past heaps

**closed 2026-11-26 (lane COV-START) · runs today and must keep running · filed 2026-11-26 against master `9fce35f4d`**

Repro:

    type Z1 = { z: i32 }
    type Z2 = { z: i32 }
    const z1: Z1 = { z: 1 }
    const z2: Z2 = { z: 2 }
    print(z1.z + z2.z)
    type J = { f: i32 }
    type K = { j: J | null }
    type W = { k: K }
    function mk() { return { k: { j: { f: 4 } } } }
    const y = mk()
    print(y.k.j.f)
    // vl check: rc 0.  vl run: prints 3, 4.

Want:

    3
    4

#### Mechanism

`irVarHeapNote` records the struct ROW a struct literal's temp is built at (`builtAtRow` passes
`row`), while `irRecHeap` holds HEAP indices (`recHeapOf`, `structRowHeap`). `recValRetag`
compared the two directly (`h == heapNotedOr(f.irRecHeap, dst)`). A heap is a wasm type index
(`mAllocType`) and a twin row takes its representative's heap, so after the twin pair `Z1`/`Z2`
the inner literal of `mk` is built at row 4 on heap 3, into a destination (the twin `W` row) on heap 3. The
comparison read 4 ≠ 3 and refused a retag whose heap agrees. The converse (a row number equal to
another row's heap) would accept a retag on the wrong heap. The fix compares `structRowHeap(row)`.

A probe at `recValRetagNoted` over all 27,421 programs reaches the comparison 9 times, 3 with row ≠
heap, and none flips the answer there; the repro flips it (old refuse, new accept). `mk` still
misses later on `return coercion nested twin`, so the repro's claim does not move. The verifier
selftest `value-retag-built-heap` now notes rows past heaps 1 and 2 (`selfRowsOnHeaps`) and fails
on the old comparison (`want rule 0, got rule 2`).

#### Ablation

| ingredient removed | recValRetag on `mk`'s literal | needed? |
| --- | --- | --- |
| the twin pair `Z1`/`Z2` | row 2 = heap 2: same answer both ways | **yes** |
| `type W` (the twin the literal is retagged into) | not reached | **yes** |
| a `const w: W = mk()` use | still reached, still flips | no |
