### D2932 — a lambda capturing a local bound to a hole value, at an `f32` pin, prints through the `i32` import

**check-clean invalid wasm · clause 1 · open · the #3239 review's `cap` and `capx` cells at `f32` · the same on master `cab9694f8` · filed 2026-09-28 against master `cab9694f8`**

Repro:

    function h(x) {
      const l = [x]
      const y = l[0]
      const k = () => y
      print(k())
    }
    const v: f32 = 1.5
    h(v)
    // vl check: rc 0.  vl run: invalid module inside `h`

Want:

    1.5

#### Mechanism

[D2918](D2918.md)'s residue at `f32`. The env field of `y` is `f32` since that close, but the call
`k()` is typed at the hole's variable and the lambda's return at the template's `i32`, so `print`
calls the `i32` import on an `f32`. `const y = x` captured at `f32` is invalid the same way.
