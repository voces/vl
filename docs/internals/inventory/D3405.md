### D3405 — an else-less `if` whose arm yields `null`, bound and never filled, finds no value box

**loud emit reject · the `constun` cells of the #3315 review's `agrid.py`; with an interpolation in the arm the module fails to validate instead · filed 2026-09-30 against master `8df60e472`**

Repro:

    function t(n: i32) {
      const w = if n == 1 { print("a1") null }
      print(w ?? -1)
    }
    t(1)
    t(2)
    // vl check: rc 0.  vl run: emitProgram: narrowed union atom has no value box

Want:

    a1
    -1
    -1

#### Mechanism

Not traced. An else-less `if` used as a value is `T | null`, and with a `null` arm `T` is the
`null` type, so the binding is never a null hole the way `if c { null } else { null }` is (that
spelling runs, and so does a two-link chain `if … { null } else if … { null }`). The binding
reaches the emitter as a one-member box whose member is `null`. With the arm's `print` taking an
interpolation (`print("a1=\{n}")`) the same program is check-clean invalid wasm, `expected (ref
null $type), found i32` inside the `std:fmt` instance.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `else { null }` added | runs | **yes** (no else) |
| a second link, `else if n == 2 { print("a2") null }` | runs | **yes** (one link) |
| the arm prints an interpolation | invalid wasm | no (the clause-1 face) |
