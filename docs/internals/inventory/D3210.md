#### Mechanism

`checkUnaryNode` accepts `-x` over a type parameter because `isNumeric` answers true for a
`TyVar`, and unlike the binary operators it recorded no deferred constraint, so no pin asked
whether its binding is numeric. A `string` or `boolean` pin was lowered as an `i32` negation.
It now records one under `OP_NEG`, re-asked at every pin in the direct spelling's words
(`unary '-' expects a numeric type, got string`), for a bare parameter and a gradual union alike.
