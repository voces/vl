### D6741 — a binding annotated with one type parameter and seeded from another, delivered to a concretely typed function parameter, is checked at the first type parameter's instance

**loud check reject · `vl check` rc 1 · clause 2 · UNDECIDED: the same binding called directly, `b(3)`, runs ([D6703](D6703.md)) · found closing [D6703](D6703.md) · filed 2026-10-18 against master `73713bacf`**

Repro:

    function same<T>(k: T): T { k }
    function twice(f: (x: i32) => i32): i32 { f(f(1)) }
    function mid<F, G>(a: F, a1: G) {
      let b: F = a1
      print(a("x"))
      print(twice(b))
    }
    mid(same, same)
    // vl check: argument 1: expected (i32) => i32, got (string) => string

#### Mechanism

From the ablation only. At the call `mid(same, same)` the checker reads `b` as `F`'s instance,
the one `a("x")` takes at `string`, so the delivery to `twice` is refused; a direct call `b(3)`
is not, and after [D6703](D6703.md) runs at `a1`'s instance. The two answers disagree about one
binding, and which one the design owes is not settled.
