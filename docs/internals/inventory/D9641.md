### D9641 — a `for` loop over a list of function-field records handing each to an un-annotated parameter that calls the field refuses

**loud emit reject · `vl check` rc 0 · `emitProgram: callee is not a function name` · clause 2 · found closing [D9570](D9570.md) · present on master `9e81d3ee3` · filed 2026-10-22 against master `9e81d3ee3`**

Repro:

    function inc0(a: i32): i32 { return a + 1 }
    function take2(a) {
      print(a.f(3))
    }
    const xs = [{ f: inc0 }]
    for x in xs { take2(x) }
    // vl check rc 0.  vl run: emit error: emitProgram: callee is not a function name

#### Mechanism

Not traced. The loop variable reaches `take2`, whose call `a.f(3)` is lowered as a direct call
of a named function, and the loop variable's field names none.
