### D9641 — a `for` loop over a list of function-field records handing each to an un-annotated parameter that calls the field refuses

**closed · runs, prints `4` · was loud emit reject, `vl check` rc 0, `emitProgram: callee is not a function name`, clause 2 · found closing [D9570](D9570.md) · filed 2026-10-22 against master `9e81d3ee3` · closed by pinning a loop variable read from a list of closed inline records at the record's shape rather than at `i32` (`monoLoopVarRecordPin`, emit_mono.vl) · fixture `closures/loop-var-inline-record-handed-to-param.vl` · the grading list's un-annotated `inc0` is filed open as [D9732](D9732.md)**

Repro:

    function inc0(a: i32): i32 { return a + 1 }
    function take2(a) {
      print(a.f(3))
    }
    const xs = [{ f: inc0 }]
    for x in xs { take2(x) }
    // vl check rc 0.  vl run: emit error: emitProgram: callee is not a function name

#### Mechanism

The pin of a loop variable handed to an un-annotated parameter took only a nominal record, so
`x`, typed at the inline `{ f: (a: i32) => i32 }`, pinned `take2` at `i32` and its call
`a.f(3)` was lowered as a direct call of a named function.
