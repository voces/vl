### D4989 — a same-shape `A | B` value delivered into `A | B | null` is stored as the bare record where the slot wants the union box

**check-clean invalid wasm · clause 1 · open · `expected (ref null $0), found (ref $1)` · the same at #3876's head `4a0ad8832` · found by the L6 fifth switch's fallback-site probes · filed 2026-10-15 against `4a0ad8832`**

Repro:

    type A = { tag: i32, v: i32 }
    type B = { tag: i32, v: i32 }
    function pick(n: i32): A | B {
      const b: B = { tag: 2, v: n }
      return b
    }
    let u: A | B | null = null
    u = pick(4)
    if u != null { print(u.v) }
    // vl check: rc 0.  vl run: invalid module, `$0 is struct {mut i32, mut i32}; $1 is union box`

#### Mechanism

`A` and `B` have one shape, so the arena collapses `A | B` to that one record, while
`A | B | null` keeps a union box. The value produced by a `A | B`-typed call reaches the
nullable slot as the bare record, and the delivery emits no box around it: the global is
declared as one rep and stored as the other.
