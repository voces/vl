### D3502 — a declared `A | B` substituted with a nullable pin keeps a nullable inside the union

**loud emit reject · clause 2 · open · `print of a union value whose arms the tag dispatch cannot classify`; read by `== null` the same instance fails to validate inside `F` (clause 1) · the same on master `04ec2ef6f` and with #3337 · the wrapper-less sibling of [D3499](D3499.md) · found by #3337's review · filed 2026-10-03 against master `04ec2ef6f`**

Repro:

    const ns: string | null = "n"
    function F<A, B>(a: A, b: B): A | B { b }
    print(F(ns, "s"))
    // vl check: rc 0.  vl run: emitProgram: print of a union value whose arms the tag dispatch cannot classify

Want:

    s

#### Mechanism

D3499's, with no nullable wrapper to fold into. `substTyDeep` rebuilds the union `A | B` with
`A := string | null` as a member, `(string | null) | string`, which no reader has a rep for:
`print` refuses the box it reads as two string arms, and `== null` on the result builds a value
box no collect pass registered (`expected struct type at index 0, found (array (mut i32))`, as
D3499 did). D3499's fold lives in the nullable arm only; this union has no such arm.
