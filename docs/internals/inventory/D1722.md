#### Mechanism

The checker's `placeKeyOf` recurses through its own result, so every link of a place —
`Ident`, `Member`, `OptMember`, `Index` — extends the key and `ys[0][0]` narrows. The
emitter's keyer is a hand-split pair, and `indexPathKeyOf` accepts only an `Ident` or a
`Member` receiver: one level of subscript keys, two keys "". So the checker admits the
narrowed read and the emitter has no arm narrowed, which after D1719 is the only remaining
route to the un-unwrapped box.

The naive widening is what makes this its own row. `emitStmt`'s index-write arm retires
narrowings on the stated invariant that "`indexPathKeyOf` mints no key for a nested receiver,
so no prefix leg can catch it" — so a keyer that minted `ys[0][0]` would leave that key LIVE
across a write to `ys[0]`, which is a stale narrowing rather than a missing one.
