#### Mechanism

Not yet ablated. The refusal is `emitAsNulNiche`'s payload floor: `nulRefNichePayloadTy`
reads the operand's recorded type, which in the generic body is the template's `T | null`
rather than the instance's `string | null`, so it finds no ref payload. The instance at a
struct `T` refuses with the same sentence, on master and with D1812 closed alike. On master a
program that also casts a concrete `S | null` with `as! S` at an un-annotated destination
refuses first with D1812's sentence instead, which hides this one; closing D1812 uncovers it.
