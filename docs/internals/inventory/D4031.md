### D4031 — `x as! T` over a `T | null` parameter in a generic function is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · found while closing D1812's struct niche for diderven DV-1201 · filed 2026-10-11 against master `98a4ed71b`**

Repro:

    function ms(): string | null { "s" }
    function gen<T>(x: T | null): T { x as! T }
    print(gen(ms()))
    // vl check: rc 0. vl run: emitProgram: `as T` needs a BOXED union operand or a
    // nullable-REF one; this `| null` is a value niche whose null is a spare scalar

#### Mechanism

Not yet ablated. The refusal is `emitAsNulNiche`'s payload floor: `nulRefNichePayloadTy`
reads the operand's recorded type, which in the generic body is the template's `T | null`
rather than the instance's `string | null`, so it finds no ref payload. The instance at a
struct `T` refuses with the same sentence.
