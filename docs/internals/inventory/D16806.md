### D16806 — a record field holding a list of lists of lists of un-annotated functions has no interned shape at emit

**closed 2026-11-16 — the witness runs and prints `4` then `1.5` · was: loud emit reject · clause 1 (check accepts what emit refuses) and clause 2 · found closing [D16742](D16742.md) · filed 2026-11-16 against master `e056e7cea`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const r = { f: [[[inc0]], [[half]]] }
    print(r.f[0][0][0](3))
    print(r.f[1][0][0](3))
    // vl check: rc 0.  vl run: emit error, "emitProgram: ref valtype with no interned shape"

Want:

    4
    1.5

#### Mechanism

The tag pass stamped the binding `r` with its rep (`{ f: i32[][][] }`) but left the record
literal and its list field at their own type, whose function lists key no row; at two levels the
inner rows existed anyway. `fnTagHeldNote` (`compiler/check_elab_cap.vl`) now builds a bound
record literal at the rep's record and stamps each list-of-lists literal in its fields, and its
inner literals, with the rep's field, as a bound list of lists already was.

#### Grading list

- Four levels, two list fields, a field beside a number, a nested record's field, the field read
  through a binding and walked: run.
- Returned, held in a list, re-pointed, pushed into: still refused, [D16821](D16821.md).
