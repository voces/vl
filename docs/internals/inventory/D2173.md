### D2173 — an object literal with a `null` field and no declared row that matches has no rep

**closed — an inferred `null` field is the `null` unit type, which D4671 gave a `nullref` struct-field slot, so the literal interns a row · graded by `tests/cases/types/null-unit-heap-positions.vl` · filed 2026-09-23 against master `a453c09c5`, found closing [D2170](D2170.md)**

Repro:

    const q = { v: 1, left: null }
    print(q.v)
    // vl check: rc 0.  vl run: emitProgram: ref valtype with no interned shape

Want:

    1

#### Mechanism

The literal's own type is `{v: i32, left: null}`, and a field of type `null` has no struct-field
rep, so no row is interned for the shape. With a declared `type Node = { v: i32, left: Node |
null }` in the program the field set resolves onto `Node` and the same literal runs, which is why
D2170's witness does. The bare `null` field wants the `nulnone` rep a `null`-typed local already has.

#### Grading list

The same literal as a function's return value; as an argument to an un-annotated parameter.
