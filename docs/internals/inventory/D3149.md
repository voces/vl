#### Mechanism

Not localised past the ablation. `boolean | null` is a niche rep elsewhere, as `string | null`
is (D3140), and the callback's substituted return keeps it as a member of a box. The same pin
handed back as a list of `T | f64` is invalid wasm in `g`, even with no type parameter at all.
Read in place it prints, and `T | boolean` read in place, by index or `.length`, is refused with
`.filter result is a ref list but ref list type not collected`. At `i32 | null` every face runs.

#### Close

Localised past the filed ablation: the return's union-list seed (`pendingListKind`) reached the
receiver literal `[x]`, which then built a box list the loop read as an `i32` one, at every pin and
with no type parameter at all (`function g(x: string): (string | f64)[]`). The `.length` face was
D3140's substitution. A returned `.map` whose un-annotated result the collect pass typed as a union
list, while its callback returns a niche at the pin, is refused loudly (D3186).
