### D4778 — `is K[]` against a union whose other arm is not a list refuses at emit

**loud emit reject · clause 2 · found closing D4771 · the same refusal on master before D4771's close · filed 2026-10-14 against master `bd9e38039`**

Repro:

    type K = 0 | 1
    function f(x: i32[] | string) {
      if x is K[] { print(1) } else { print(0) }
    }
    f([5])
    // vl check: rc 0.  vl run: emitProgram: `is` names a type that is not a union variant

Want:

    0

#### Mechanism

`x` is a box union of `i32[]` and `string`, and `K[]` is not one of its arms, so the box's
tag test finds no variant. Under D3885 and D4771's ruling the test is the `i32[]` arm's tag
followed by the element-wise fit test against `K`; the emitter has the second half only for
a receiver that is a list.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `x: i32[]` | prints `0` (D4771's element test) | **yes** (a box union) |
| `x is i32[]` | prints `1`, which is right | **yes** (the tested type is not an arm) |
