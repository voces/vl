### D15828 — a fresh call delivered into a record field typed as a union of a wider record is refused as an existing record

**loud check reject · clause 2 · open · found closing D8141 · filed 2026-11-12 against master `544adb4cb`**

Repro:

    type Col = { r: i32, g: i32 }
    type J = { r: i32 | null, g: i32 }
    function mkU() { { r: 15, g: 1 } }
    type W = { f: J | string }
    const w: W = { f: mkU() }
    const v = w.f
    if v is J { print(v.r ?? 0) }
    // vl check: rc 1 — {r: i32, g: i32} is not J: they store field `r` differently … only a fresh
    //   record widens

Want:

    15

#### Mechanism

D8141 builds a fresh call delivered into a union of a wider record at the member it lands on, at
a binding, an argument, a return, a list or map element and the rest of
`scripts/capability-probes/matrix/fresh-call-into-union-of-wider-record.matrix.vl`. As a record
literal's field, or the value of a field write, the call is still refused (`recInRecordField`,
check_fit_rules.vl): without that guard the call is built at the member, but the literal around
it is built at a row whose field holds the member raw, so the field is not boxed (check-clean
invalid wasm). The refusal's sentence names D2996's contract, which does not apply to a fresh
call, so it is a capability refusal.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const u: J \| string = mkU()` (a binding) | runs | **yes**, the field |
| `type W = { f: J }` (no union) | runs | **yes**, the union |
| `w.f = mkU()` on a `W` built from a literal | the same refusal | no |

The matrix's `struct_field_init` (annotated), `struct_field_assign` (both faces) and
`struct_field_place` (annotated) cells; with the guard removed, each was check-clean invalid wasm.
