### D5111 — the complement `else` read of a generic's inferred `T[] | i32[]` lowers through the scalar union path

**loud emit reject · `vl check` rc 0 · clause 2 · found closing D5083 · the same on master `4af9eb956` at `T = string` and `boolean` (a record pin refused earlier there, as D5083) · filed 2026-10-16 against master `4af9eb956`**

Repro:

    function w<T>(t: T, b: boolean) {
      if b { return [t] }
      [1, 2, 3]
    }
    function ex<T>(t: T, b: boolean) {
      const u = w(t, b)
      if u is T[] { print(0) } else { print(u.length) }

#### Mechanism

Inside the generic `ex`, the `else` arm of `if u is T[]` reads `u.length` over the union the
instance pins (`string[] | i32[]`). That read reaches the scalar union-coerce path
(`wasmEmit.vl`, the `union atom has no value box` refusal) rather than the list-arm unbox the
`then` arm and a non-generic caller take. Not ablated past the ingredients below.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the read in the `then` arm instead (`if u is T[] { print(u.length) }`) | runs | **yes** |
| `ex` not generic (`t: string`) | runs | **yes** |
| `T` pinned to a record literal instead of `string` | still refuses | no |
