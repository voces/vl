### D2535 — a closure returning a nullable integer literal union yields a boxed value that a narrowed `print` reads as the i32 atom

**closed 2026-09-25 — the filed repro RUNS and prints `2` · was check-clean invalid wasm · clause 1 · found by #3168's review (the concrete twin of its `l2` witness) · filed 2026-09-25 against master `15be0d1b8` · fixture `tests/cases/literal-unions/closure-nullable-lit-union-result.vl`**

Repro:

    type LI = 1 | 2 | 3
    function mkGet(xs: (LI | null)[]): (i32) => LI | null {
      return (i: i32) => xs[i]
    }
    const s: (LI | null)[] = [null, 2]
    const g = mkGet(s)
    const r = g(1)
    if r != null { print(r) }

#### Mechanism

The closure's result `LI | null` is a boxed reference, while `r` narrowed to `LI` is read at the
i32 atom rep, so `print(r)` receives the box: `expected i32, found (ref $type)`. A plain function
returning `LI | null` from the same list runs, so the closure-call result is the ingredient. The
generic spelling (`mkGet<V>(xs: (V | null)[])`) reaches the same site, and was refused at the
instance by `monoLamNulUnionListCheck` (D2525's boundary) until this row closed.

The closure's `$fnsig` keys a `K | null` result as the union box whatever the spelling, and the
consumer read the call as the box only where the callee had an annotation naming the union
(`unionRetOfFnType`). An un-annotated lambda (`(i) => s[i]`), a closure a factory hands back,
and the generic's per-instance getter have none, so the call fell to the checker's type, which
reads as the niche. `unionNameOfExpr` now takes the call's own `$fnsig`: a boxed result is the
union the key names (`fnRetEmitName`, shared with `sigKeyOfTy`), and `exprNulLitUnion` declines
the niche for it. The guard is lifted, so `IdTable<LI>` and `mkGet<LI>` run inside a generic
that declares a lambda.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the closure (a function returning `xs[1]` directly) | runs | **yes** |
| the literal union (`i32` elements) | runs | **yes** |
| the factory (`const g = (i: i32): LI \| null => s[i]`) | runs | **yes** |
| the annotation on the binding (`const g: (i32) => LI \| null = mk()`) | runs | **yes** |
