### D2407 — a path narrowing captured by a closure that outlives the guard reads the stale member after the path is written

**loads then traps · clause 1 · filed 2026-09-25 against master `a277bf7b0`, found grading
[D2402](D2402.md)'s path spelling · open — needs an owner ruling (below)**

Repro:

    type O = { v: string | null }
    function f(o: O): () => i32 {
      if o.v != null {
        return (): i32 => o.v.length
      }
      (): i32 => 0
    }
    const o: O = { v: "abc" }
    const r = f(o)
    o.v = null
    print(r())
    // vl check: rc 0.  vl run: wasm trap: null reference

#### Mechanism

A lambda body is checked where it is written, under the path narrowings live there, and the
emitter replays them into the lifted body (`capNarrowRecord`). The lambda runs later. For a bare
name D2402's close decides whether the capture can be falsified before the lambda runs: only a
function that writes the binding can, and one exists or not. A field, element or map value can
be written by any code holding an alias of its object, after the function that made the lambda
has returned, so no analysis of that function bounds it. D2402's close refuses the in-function
case (a writing call after a nested function read the path); an escaping lambda is not refused.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the write `o.v = null` | runs, prints `3` | **yes** |
| the escape (the lambda called inside `f`, before any write) | runs | **yes** |
| the path (a bare local `v`, no function writes it) | runs, no writer can exist | **yes** |

#### Ruling needed

Whether a path narrowing flows into a nested function at all. The sound rule is that inside a
nested function a captured path reads at its declared type, except in a lambda handed straight
to an array's `map`/`filter` (which D2402's close already models) — but that refuses the common
`if o.v != null { const f = () => o.v.length … }`, so it is a language decision, not a fix.
Recommendation: apply it only to a nested function that escapes (the D2402 escape test:
unbound, or its handle used other than as a callee in the body that makes it); one called by
handle keeps the narrowing, with D2402's in-function check guarding it.

#### Grading list

The index-cell (`xs[0]`) and map-value (`m["a"]`) spellings; a lambda stored in a struct field
rather than returned; the same with the write done by a function the caller calls.
