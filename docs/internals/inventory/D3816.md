### D3816 — an optional `self`-function call as the left of `??` leaves the call's nullable result where the `??` lowering expects a non-null ref

**check-clean invalid wasm · filed 2026-10-07 against master `dfe8e92b3` (found by lane OV)**

Repro:

    function describe(self: string): string { "string " + self }
    function f(n: string | null): string { n?.describe() ?? "none" }
    print(f("nn"))
    print(f(null))
    // vl check: rc 0.  vl run: invalid module, `expected (ref $type), found (ref null $type)` inside `f`

Want:

    string nn
    none

#### Mechanism

Not yet located. The optional call `n?.describe()` is a `self`-function lowered through the
UFCS rewrite's optional guard; placed directly as the left operand of `??`, the emitted
module hands the guard's nullable result to a slot typed non-null. Bound to a `const` first,
the same call runs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `??` (bind `const r = n?.describe()`, then `r ?? "none"`) | runs | **yes** |
| the module boundary (one file) | still invalid | no |
| the function wrapper (module scope `print(n?.describe() ?? "none")`) | still invalid | no |
