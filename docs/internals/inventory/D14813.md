### D14813 — a call in a list literal handed to a generic that hands the list back is invalid wasm

**closed · now runs, prints `12` · was check-clean invalid wasm, clause 1 · split from [D14812](D14812.md) by ablation · filed 2026-11-01 against master `3e96b47e` · the element bound in the callee runs since 2026-11-01 (`recElemTakesRep`; fixture `soundness/record-call-element-bound-in-generic-list-callee-runs.vl`) · closed 2026-11-01 against master `88e31332`: a list parameter handed back whole takes the rep where the callee has no other call and the call's result is only measured or indexed for a field, directly or through an un-annotated `const` (`recListRetTakesRep`, check_fit_rules.vl) · fixture `soundness/record-call-list-handed-back-by-generic-runs.vl` · a second call of the callee and an annotated binding of an element are [D14890](D14890.md)**

Repro:

    type Circle = { r: i32 | null }
    function sink(_x: Circle) { }
    function mkcall() { { r: null } }
    sink(mkcall())
    function keep<T>(xs: T[]): T[] { xs }
    const k = keep([mkcall()])
    print(k[0].r ?? 12)

Want:

    12

#### Mechanism

`sink(mkcall())` asks for `mkcall`'s record at `Circle`. The list literal `[mkcall()]` is queued as
a delivery at its own type to `keep`'s `T[]`. The D14812 close stops that delivery from landing
the elements only where the callee hands back one element (`recElemPinLit`). `keep` hands back the
list itself, so the delivery lands `mkcall` at its own row. `sink` then receives it as `Circle`:
invalid on line 4.

#### Notes

The arm is taken only where `keep` has no other call. With `keep(ks)` beside it, over `const ks:
K[]` and `type K = { r: null }`, mono reuses `keep<K>` for the literal's call and the result is
held at `K[]`, so that spelling stays refused.
