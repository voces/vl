### D14813 — a call in a list literal handed to a generic that hands the list back is invalid wasm

**open · check-clean invalid wasm, clause 1 · split from [D14812](D14812.md) by ablation · filed 2026-11-01 against master `3e96b47e` · the element bound in the callee runs since 2026-11-01 (`recElemTakesRep` takes an element initialising an un-annotated `const` read only for fields, or not read; fixture `soundness/record-call-element-bound-in-generic-list-callee-runs.vl`)**

Repro:

    type Circle = { r: i32 | null }
    function sink(_x: Circle) { }
    function mkcall() { { r: null } }
    sink(mkcall())
    function keep<T>(xs: T[]): T[] { xs }
    const k = keep([mkcall()])
    print(k[0].r ?? 12)

Want:

    12

#### Mechanism

`sink(mkcall())` asks for `mkcall`'s record at `Circle`. The list literal `[mkcall()]` is queued as
a delivery at its own type to `keep`'s `T[]`. The D14812 close stops that delivery from landing
the elements only where the callee hands back one element (`recElemPinLit`). `keep` hands back the
list itself, so the delivery lands `mkcall` at its own row. `sink` then receives it as `Circle`:
invalid on line 4.

#### Ablation

| --- | --- | --- |

| the list: `keep<T>(x: T): T { x }` over `mkcall()` | prints `12` | **yes** |
| `keep` returning `xs[0]` as `T` | prints `12` (D14812) | **yes** |

#### Notes

Accepting the list handed back where the call's result is only measured or indexed for a field
runs the Repro. It turns `keep(ks)` beside `keep([mkcall()])`, with `const ks: K[]` over
`type K = { r: null }`, from a loud refusal into invalid wasm: mono reuses `keep<K>` for the
second call. So that arm was not landed.
