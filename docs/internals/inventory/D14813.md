### D14813 — a call in a list literal handed to a generic that binds an element or hands the list back is invalid wasm

**open · check-clean invalid wasm, clause 1 · split from [D14812](D14812.md) by ablation · filed 2026-11-01 against master `3e96b47e`**

Repro:

    type Circle = { r: i32 | null }
    function sink(_x: Circle) { }
    function mkcall() { { r: null } }
    sink(mkcall())
    function keep<T>(xs: T[]): T[] { xs }
    const k = keep([mkcall()])
    print(k[0].r ?? 12)

Want:

    12

#### Mechanism

`sink(mkcall())` asks for `mkcall`'s record at `Circle`. The list literal `[mkcall()]` is queued as
a delivery at its own type to `keep`'s `T[]`. The D14812 close stops that delivery from landing
the elements only where the callee hands back one element (`recElemPinLit`). `keep` hands back the
list itself, so the delivery lands `mkcall` at its own row. `sink` then receives it as `Circle`:
invalid on line 4.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `sink(mkcall())` | prints `12` | **yes** |
| the list: `keep<T>(x: T): T { x }` over `mkcall()` | prints `12` | **yes** |
| `keep` returning `xs[0]` as `T` | prints `12` (D14812) | **yes** |

#### Grading list

Each is the Repro's first four lines with the rest replaced, and is invalid wasm on line 4:

* `function rd<T>(xs: T[]): i32 { const z = xs[0]` then `8 }` and `print(rd([mkcall()]))`.
