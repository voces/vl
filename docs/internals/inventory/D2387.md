#### Mechanism

A binding a closure assigns is boxed by `captureBoxRewrite` (`emit_rewrite.vl`): the `let`
becomes a one-element list and every read becomes a synthetic `cell[0]`, an `Index` node with
no checker-recorded type. The emitter's read of that node honours the `is` narrowing and
unboxes the right member, but the scalar classifiers that decide what the unboxed value IS
(`exprIsBool`, `exprIsF64`, `exprIsI64`, `exprIsF32`, `exprListRep`) have typed-IR fast paths
the synthetic node cannot use, and their `Index` arms asked about the LIST instead: a boolean
read classified as i32 (reboxed under tag 0, printed `0`) unless the cell's initializer literal
was a boolean, and an i32 read over a `true` initializer printed `true`. Only `exprString`
asked the narrowed place (`indexUnionReadKind`). Every classifier's `Index` arm now asks it
first, and `indexListRep` maps a narrowed list atom to its list rep.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the closure's write (`v = false` inline; or the closure only reads `v`) | runs, `v` is not boxed | **yes** |

| the `for ... in` loop (a plain `let v: boolean \| string = "a"`) | still prints `0` | no |
| the initializer's member (`true` instead of `"a"`) | prints `false`: the list arm guessed right from `[true]` | **yes, for the wrong value** |
