### D14163 — an un-annotated parameter captured by an index-signature record's `"[]"` function has no interned shape

**closed 2026-10-26 · runs, prints `99` · fixed by the slice 2 fact-only record build rows: a record literal is built at the checker's own build fact (`recBuildTyOf`), and the destination walk that picked a declared row by field names is deleted · was loud emit reject · `emitProgram: ref valtype with no interned shape` · clause 2 · found ablating the G12 field-set-scan cells · pre-existing on master `bbdd4e720` · filed 2026-10-26 against master `bbdd4e720`**

Repro:

    function wrap(x) { "[]": (_k: i32) => x }
    const wi = wrap(99)
    print(wi[0])
    // vl check: rc 0.  vl run: emit error, ref valtype with no interned shape

Want:

    99

#### Mechanism

`wrap`'s parameter is inferred, and the returned record's `"[]"` function captures it, so the
record's type is known only through the parameter's inferred type. The same record with
`x: i32` written, with `wrap<T>(x: T)`, or with a plain key interns its shape. With the
inferred parameter behind an index key, the record's type reaches emit with no interned
shape. The read is not needed: building the record already refuses.
