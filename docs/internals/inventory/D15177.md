#### Mechanism

`elabSetArgBind` binds the hole of a parameter handed a tagged function to the set's own type,
the rep its id has. That type names holes, so the root row pass's second loop and the hand-back
pass (`elabSoleRekey`, through `elabParamTyClosed`) read it as open and closed it to the argument's
sole-instance signature, minting a second key the call then resolved to (`elabCallInstFrom` keeps
the last). The instance mono builds is the set's; pinning from that closure-signature binding, as
D15174's PR does for a list or map of the set's ids, regressed this witness, [D6002](D6002.md) and
[D15039](D15039.md) to invalid wasm, which is why the argument-derived pin stands; it is deleted with [D15260](D15260.md).
