#### Mechanism

A wider record into a declared record parameter is lowered by D3992's width rewrite, which
re-checks the program after `checkRestart`. The restart rebuilds the type arena, but
`fnTyFactsReset` left `fnSlotCallArgs` and `fnSlotAnnTys`, which a pass fills with type indices,
so the next pass read a tuple of the cleared arena's types (`fnSlotCallArgsAt`, from
`elabBindingCallArgs`) and `tyAt` trapped. The lambda bound first is what has a call through a
binding slot noted before the restart.
