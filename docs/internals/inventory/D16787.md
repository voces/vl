    type J = { f: i32 | null }

    const dA: J = mk2()

    function show(z: { f: null }) { print(z.f) }

#### Mechanism

The loop local holds a `J` struct. The binding `z` is laid out at its checker type
`{ f: null }` once `show` is instanced at `J` for the argument `z` (D14532, read through
`recBuiltReadTyAt`'s binding arm into the loop variable). An index alias (`const z = src[0]`)
runs because the index read is stamped at the build and the binding takes it. A loop-variable read
has no such stamp, so the binding's local and the value it holds disagree.
