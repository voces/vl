### D16008 — the `else` arm of a record `is` test over an un-annotated parameter reads a scalar remainder at the whole argument type

**closed 2026-11-13 by minting the `HD_GNOT` remainder for a record tested type on a bare parameter name (`check_narrow_flow.vl`), routing a field read off it to the base hole (`gnotRecordBase`, check_access.vl) and registering no guard alternative for it (`ifNoteGuardAlts`) · runs, prints `5` · was: loud check reject, `` `F` prints its type parameter here: print expects one scalar or string value (i32 | i64 | f32 | f64 | boolean | string), got A | i32 `` · clause 2 · found closing [D16004](D16004.md) · filed 2026-11-13 against master `7b0b9d8ac` · neighbour [D3216](D3216.md) · fixtures `inference/hole-param-is-record-else-remainder.vl`, `inference/error-hole-param-is-record-else-remainder.vl`**

Repro:

    type A = { v: i32 }
    function F(h) { if h is A { print(h.v) } else { print(h) } }
    const x: A | i32 = 5
    F(x)
    // vl check: `F` prints its type parameter here: print expects one scalar or string value (i32 | i64 | f32 | f64 | boolean | string), got A | i32
    // Should print 5; annotating `h: A | i32` does.

Want:

    5

#### Mechanism

A hole's `else` remainder (`HD_GNOT`) is not minted for a record tested type
(`holeElseRemainderOk`), so the `else` arm reads `h` at the whole pin `A | i32`, and `print`, `+`
and other scalar uses refuse it. D16004 closed the field-read form through the argument's
member-by-member demand check. A scalar use is not a demand on the argument, so that check does
not reach it. Minting the remainder for a record type moves field demands off the argument
check (D16004's refuted first attempt). This row's fix must keep them there. D3216 is the same
shape over a hole's field.

#### Close

The remainder is minted for a record `T` only on a bare name; a field path keeps the hole as its
fact (D3420). A field read off the remainder demands its field of the base hole, so it stays on the
argument check as before, member by member (D16004). `.length` reads the remainder, re-asked at
the pin. The remainder is not a guard alternative: an open type would accept any argument, which
`!(v is { foo: string }) { v.bar }` would show. A pin whose every member is the record (`F(a)`
with `a: A`) leaves the arm dead, which is D16006(b).
