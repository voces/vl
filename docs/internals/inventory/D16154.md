### D16154 — a generic function over a recursive generic alias spelled with `| null` has no instance pin

**closed 2026-11-14 with [D16153](D16153.md) · runs, prints `2` · was a loud emit reject, clause 2 · found closing [D16069](D16069.md) · filed 2026-11-14 against master `5e7c7527f`**

Repro:

    type LL<T> = { v: T, n: LL<T> } | null
    function len<T>(l: LL<T>): i32 {
      let k = 0
      let c = l
      while c != null {
        k = k + 1
        c = c.n
      }
      return k
    }
    const a: LL<i32> = { v: 1, n: { v: 2, n: null } }
    print(len(a))
    // prints 2 since D16153; before it, vl run: emitProgram: monomorphize: unsupported argument
    // type for `l` in a call to `len`

Want:

    2

#### Mechanism

Not yet located. The instance `LL<i32>` is the tied nullable `{ v: i32, n: LL<i32> }?`
(`gaUnionUnwrap`), so the application row is the nullable while the narrowed loop variable is its
record; substituting the record walks its fields into a fresh copy rather than re-applying the
alias, and the copy has no closed pin.
