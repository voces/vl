### D15365 — an element of a widened list of functions of different results, bound inside an un-annotated function and called, traps

**trap after load · `vl check` rc 0, `wasm trap: indirect call type mismatch` · clause 1 · open, target `1.5` · found closing [D15364](D15364.md) · filed 2026-11-04 against master `73062b831`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function run(xs) {
      const g = xs[1]
      print(g(3))
    }
    const xs = [inc0]
    xs.push(half)
    run(xs)

Want:

    1.5

#### Mechanism

Not ablated past the table. Calling the element in place, `xs[1](3)`, runs. Binding it to a
`const` first and calling the binding traps at the `call_ref`, so the binding's function type is
probably the first member's signature rather than the set's.

#### Ablation

| spelling | outcome |
| --- | --- |
| this repro | trap after load |
| `xs[0]` bound and called | runs, prints `4` |
| `print(xs[1](3))` in place | runs |
| the same binding at module scope | runs |
| the list a literal `[inc0, half]` handed straight in | runs, with [D15363](D15363.md) |
