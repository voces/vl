### D5285 — `as` over an operand already narrowed to its target refuses to compute an empty remainder

**closed · was loud check reject · clause 2 · eardstap EV-006 follow-up · filed 2026-10-17 against master `3f6a785db`**

Repro:

    type NodeKind = "a" | "b"
    type Wide = NodeKind | "event"
    function pick(k: Wide): NodeKind { if k == "event" { "a" } else { k as! NodeKind } }
    print(pick("b"))
    print(pick("event"))

Want:

    b
    a

#### Mechanism

`checkCastNode` computes the propagated remainder `subtractTy(operand, target)` and refused
when it was empty, which is exactly the case where the cast cannot miss. An operand wholly of
the target now types as the target (or its nullable for `as?`) with no remainder. Lowering the
cast itself is D5286.
