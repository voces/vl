### D17793 — `.map` returning a list-of-records element unchanged into a list annotated at a closed function field is refused at emit

**open · loud emit reject · clause 2 · `vl check` rc 0, `emitProgram: the compiler cannot yet lower this top-level code (map plan)` · filed 2026-11-28 against master `2693ffdcf` (lane START-2)**

Repro:

    function id(a) { return a }
    function deliver() { return [{ f: id }] }
    const v: { f: (a: f64) => f64 }[] = deliver().map((r) => r)
    print(v[0].f(2.5))
    // vl check: rc 0.  vl build: loud emit reject (map plan)

Want:

    2.5

#### Mechanism

The map's plan has no arm for an element whose record holds a hole function delivered whole into
a list whose element type closes that field; with a closed function in the literal
(`function inc(a: i32)`) the same spelling runs.
