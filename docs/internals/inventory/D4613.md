### D4613 — a record literal reassigned to an un-annotated function local is built as a declared union arm of the same field names

**closed 2026-10-14 — the witness prints `4` · `emitAssign`'s local arm seeds an arm (`variant`) cell's variant index for an object-literal right-hand side, as `emitLetDeclStmt` seeds the binding's initializer, so the literal builds the bare arm struct instead of the union box · fixture `tests/cases/unions/unann-local-reassign-arm-literal.vl` · template `tagged-arm-nullable-field.matrix.vl` runs 56 → 57 of 66, silent 1 → 0, 0 runs → not-runs · was check-clean invalid wasm · clause 1 · the `local_assign` un-annotated cell of `tagged-arm-nullable-field.matrix.vl` · filed 2026-10-14 against master `56e06d91c`**

Repro:

    type U = { q: i32 } | { kind: "b" }
    function f() {
      let v = { q: 4 }
      v = { q: 4 }
      print(v.q)

Want:

    4

#### Mechanism

A literal binding whose fields match a union arm is a `variant` cell holding the bare arm
struct, and `emitLetDeclStmt` seeds that cell's variant index so its initializer builds it.
`emitAssign`'s local arm had no such seed: `unionNameOfIdentAt` answers no union for the
inferred arm cell, so the right-hand side reached `emitObjLitNode` unseeded, which in a program
that declares a union boxes it, and the `local.set` stored the box into the arm-struct local.
