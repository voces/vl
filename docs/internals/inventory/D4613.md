### D4613 — a record literal reassigned to an un-annotated function local is built as a declared union arm of the same field names

**check-clean invalid wasm · clause 1 · the `local_assign` un-annotated cell of `tagged-arm-nullable-field.matrix.vl` · filed 2026-10-14 against master `56e06d91c`**

Repro:

    type U = { q: i32 } | { kind: "b" }
    function f() {
      let v = { q: 4 }
      v = { q: 4 }
      print(v.q)
    }
    f()
    // vl check: rc 0.  vl run: type mismatch: expected (ref $type), found (ref $type)

Want:

    4

#### Mechanism

The local's own literal and the reassigned literal are resolved to different heap types: one
as the plain anonymous record the binding inferred, the other as the variant struct of the
union arm whose field names it matches, so the `local.set` stores one into a local of the other.
