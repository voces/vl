### D4200 — a write inside an arm a literal test narrowed does not re-narrow the binding when the written value is a single literal member

**closed 2026-10-12 by lane CK · runs · was check-clean invalid wasm · found reviewing #3577 · filed 2026-10-12 against master `0bf4c3bb6` · pins: `tests/cases/literal-unions/write-in-narrowed-arm.vl`**

Repro:

    type M = 1 | "a" | "b"
    function pm(i: i32): M {
      if i == 0 { return 1 }
      if i == 1 { return "a" }
      "b"
    }
    function f(i: i32) {
      let x = pm(i)
      if x is 1 {
        x = "a"
        print(x + "!")
      }
    }
    f(0)

Want:

    a!

#### Mechanism

`pushNarrowWriteReNarrow` (`compiler/emit_classify.vl`) re-narrows a binding after a write by
looking the written type up in the member-set pool (`asgReadNarrowSet`). A single literal has no
row there, so it pushed nothing and `x + "!"` read the box as a string. A write of one literal
member now pushes that member's own rep (`pushNarrowLitMember`).
