### D5921 — an un-annotated binding of a complement-narrowed union of three or more value members is check-clean invalid wasm

**check-clean invalid wasm · clause 1 · lane L2 · pre-existing, the same on master `60c4d1c43` · found closing [D5890](D5890.md) · filed 2026-10-17 against master `f619864ee`**

Repro:

    function f(k: string | i32 | f64): f64 {
      if k is string { return 1.0 }
      const rest = k
      if rest is i32 { return 2.0 }
      rest + 0.5
    }
    print(f(1))
    // vl run: invalid module — inside f: type mismatch: expected f64, found (ref $type)

Want:

    2

#### Mechanism

Not located. The binding `rest` takes the checker's narrowed `i32 | f64`, and the final read of
its own `is i32` complement expects an unboxed `f64` where the emitted local still holds the box.
An annotated binding, or no binding at all, runs, so the binding's rep and the narrowing pushed
on it disagree.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const rest: i32 \| f64 = k` | runs | **yes** (no annotation) |
| the first `is string` test removed | runs | **yes** |
| `k` read directly, no binding | runs | **yes** |
| the final `rest + 0.5` replaced by `0.0` | runs | **yes** |
| the first test written `k == null` over `i32 \| f64 \| null` | still invalid wasm | no |
| the first test written `k == "a"` over `"a" \| i32 \| f64` | still invalid wasm | no |

#### Grading list

The `== null` and the literal complements above, each then bound; `rest ?? 0` over a bound
nullable remainder, a loud emit refusal today (`?? over this nullable value is not supported yet`).
