### D2210 — an un-annotated binding of a value `if` over a ref list is classified as no list at all

**closed 2026-09-23 — the witness prints `3` · was `loud emit reject`, `emitProgram: .push receiver is not a list` with `vl check` rc 0 · clause 2 · found by D2209's position grid · filed against master `99d1f4fdd` · fixture `tests/cases/arrays/empty-list-join-arm.vl` (`bind`)**

Repro:

    type P = { x: i32 }
    function falsy() { 1 == 2 }
    const ps: P[] = [{ x: 1 }, { x: 2 }]
    const v = if falsy() { ps } else { ps }
    v.push({ x: 3 })
    print(v.length)
    // before the close: vl check rc 0, then `emitProgram: .push receiver is not a list`

#### Mechanism

`exprRefArray`, `refListElemNameOfExpr` and `exprStringArray` had no `IfStmt` arm. A
`string[]` join got through anyway, on `exprStringArray`'s typed fast path (type kind 7).
A ref-list join, and a `(string | null)[]` join (a different type kind, the same string-list
rep), matched no classifier, so the binding's cell, the `.push` receiver, `.length` and the
inferred return all fell to the i32 default. The close asks the join's own classifier,
`ifExprRefKind`, and takes the element row from `ifExprRefSlot`, the same pair the blocktype is
emitted from.

#### Grading list

The inferred-return spelling (`function d() { return if falsy() { ps } else { ps } }` read
into `const v: P[] = d()`, which was check-clean invalid wasm), the generic tail
(`function g<T>(xs: T[]) { if 1 == 2 { xs } else { xs } }`, likewise), and the
`(string | null)[]` binding (`.length` refused). All three run after the close.
