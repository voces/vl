#### Mechanism

`projDests` (`check_rec_fresh.vl`) follows a typed read's root back through un-annotated
aliases (`aliasRoot`) to the fresh binding. A root bound to a call's result (an inferred result,
a generic pass-through such as `idg(c)` or std's `reverse([c])[0]`) or to an element read of
another literal (`const g1 = c[0]`) ends that chain, so the read names no destination.
