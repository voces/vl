#### Mechanism

A `let x = null` that a lambda captures is a captured `null` cell. The assignment used as a value
(`x = null` as `print`'s argument) takes legacy's value-assignment arm, which has no lowering for a
target whose type is the `null` unit, where the uncaptured binding's assignment-of-null arm writes
the store and yields the unit (D17118). D16183 is the `return` spelling of the same refusal;
D17340 the module-level literal-union one.

| the assignment moved inside the lambda (`() => { print(x = null) }`) | still refuses | no |
