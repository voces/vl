### D13320 — a forwarded hole function called over a `const`-bound list whose elements call it at two keys has no interned signature

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same list written inline in the `for` header runs · found by lane L1 closing [D13200](D13200.md) · present on master and after lane L1's D13200 PR · filed 2026-10-25 against master `ea2c435a3`**

Repro:

    function add(a, b) { return a + b }
    function apply2(g, s) {
      print(g(s, s))
    }
    function apply4(g, s) {
      print(g(s, 2))
    }
    function innerThree(k, h) {
      const gs = [apply2, apply4]
      for f in gs { f(h, k) }
    }
    innerThree(0.5, add)
    // vl check: rc 0.  vl run: emitProgram: a function-value call has no interned signature — parameter 1 of type `` has no representation in the function-value ABI

Want:

    1
    2.5

#### Mechanism

Not measured past the ablation. The inline spelling `for f in [apply2, apply4] { f(h, k) }`
builds since lane L1's D13261/D13200 PR, so the split round handles the list when it is the
loop's own header. Bound to a `const` first, the loop's call does not reach the list group's
two keys (`c:f64,f64,` and `c:f64,i32,`), and the apply round refuses at `innerThree(0.5, add)`.
