### D17722 — a map read of a tagged function set's id, handed straight to an un-annotated parameter the callee null-tests and calls, has no instance argument type

**closed 2026-11-28 by I8-PREP · runs, prints `4` · was: loud emit reject · clause 2 · `emitProgram: monomorphize: unsupported argument type for \`g\` in a call to \`callIt\`` · `monoPinHoleParam` (emit_mono.vl) takes a bound type that is a tagged set's value or its nullable, pinned at the nullable of the id rep (`monoPinRepTyOf`) · filed 2026-11-27 against master `3a8246bde` (lane COV-CLOS, a position probe of RTagClo/RCloTag #10536)**

Repro:

    function inc(a) { return a + 1 }
    const m = Map()
    m["k"] = inc
    function callIt(g, x) { if g != null { print(g(x)) } }
    callIt(m["k"], 3)
    // vl check: rc 0.  vl run: monomorphize: unsupported argument type for `g` in a call to `callIt`

#### Mechanism

The argument is a map read typed `F | null`, `F` a tagged set's function type. The callee's
un-annotated `g` is null-tested and called, so its instance needs the argument's type, and the
monomorphizer finds none for a map read of a tagged set at a hole parameter. The same call with
`g` annotated runs, and so does handing `inc` itself. Bound to a `const` first, the read gets
past the monomorphizer and stops at the IR's `null test operand`, a second gap.

#### Outcome (2026-11-28, I8-PREP)

The family is a tagged set's value that may be `null`, not map storage: the narrowed read, a list
element and `??` already ran, and a nullable list element refused the same way. The elaboration
binds the callee's hole to `F | null` (`elabCallParamBoundTy`); `monoPinHoleParam` pinned a bound
tagged set at its id rep but read `F | null` as no set, and `monoPinRepTyOf` had no rep for it.
Both now take the nullable at the nullable of the id rep. The read bound to a `const` first (the
`null test operand` gap above) runs by the same change. Pinned by
`tests/cases/maps/tagged-set-map-read-handed-to-a-null-testing-hole-parameter.vl`: the witness, a
missing key, `get`, a second member, the bound read, an instanced frame, an `f64` member and two
calls.

The check's tag decision does not decide a nullable set value handed to a hole parameter; the
decision after the elaboration decides it (the pin's `{inc,dbl}` and `{half}` late tag rows, which
master's witness logs too).
