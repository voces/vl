### D3489 — `is Rec` over an inferred generic join of two type parameters and `null` at a record pin is refused at emit

**loud emit reject · clause 2 · open · `` `is` names a declared union member with no interned arm representation (deferred value-union composition) `` · pre-existing, the same on master `59d72ed63` · found grading D3487 · filed 2026-10-03 against master `59d72ed63`**

Repro:

    type Rec = { x: i32 }
    function two<A, B>(k: i32, a: A, b: B) { if k == 0 { a } else if k == 1 { b } else { null } }
    const v = two(1, 1, { x: 7 })
    if v is Rec { print(v.x) }
    // vl check: rc 0.  vl run: the emit refusal above

Want:

    7

#### Mechanism

Not localised past the ablation. The annotated return `: A | B | null` runs and the inferred one
does not, so the instance has the capability and the inferred join, a flat union of the two
parameters and `null`, reaches the `is` with no arm registered for the record member at the pin.
With the record as `A` the same grid cells refuse with `` `is` names a type that is not a union
variant ``; they are counted here until an ablation says otherwise.
