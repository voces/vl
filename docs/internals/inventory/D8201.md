### D8201 — a literal-building function called twice into a wider record is refused beside an unused record of its fields

**closed 2026-10-20 by lane L1 · the witness prints `15` · was a loud check reject · clause 2 · present on master `be738c9f0` · fixture `tests/cases/generics/fresh-call-at-several-sites-built-at-delivery.vl` · the calls that land on different storage are [D8302](D8302.md) · found closing [D8020](D8020.md) · filed 2026-10-20 against master `be738c9f0`**

Repro:

    type Col = { r: i32, g: i32 }
    type J = { r: i32 | null, g: i32 }
    function mk() { { r: 15, g: 1 } }
    let v: J = mk()
    v = mk()
    print(v.r ?? 0)

Want:

    15

#### Mechanism

`recFnBuiltAtDst` (check_fit_rules.vl) re-seated a fresh function's literal at the destination
only when the function had one call site. With two, `mk`'s literal stayed at its own type, and
`Col` names that type, so `recBuiltAtDeclared` refused each call as an existing record. Closed
by `recSitesLandAt`: several call sites are one build when every one is a plain call and each is
queued for a delivery that lands it on the same field storage (`recQueuedLandingOf` follows the
pending deliveries through generic identities that only that argument pins, and through the
fields and elements of literals).
