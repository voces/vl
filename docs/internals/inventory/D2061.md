#### Mechanism

The v1 walk refuses loops and recursion, and every getter here is loop-free and the getter
graph is acyclic, so each body passes on its own. Nothing sums the work of the calls a body
makes. The #3039 amendment's formula has the same hole: straight-line code is `Bounded(0)` and a
call adds only its callee's bound, so this chain scores 0 against a budget of 64. The contract's
stated promise ("a getter read costs a load or a short, bounded sequence") is false for it.
Re-measured for the synthesis: the doubling shape `g_k = g_{k-1} + g_{k-1}` to depth 30, read
three times from a loop variable (so no constant folding), took 5.6 s wall on `dist/vl`.

#### Grading list

The doubling shape at depth 20 and 30; the same shape through a non-getter helper once S2 lets
getters call getter-eligible functions; the std effects baseline (effects §E4), which must record
the same measure or a std export can raise a user getter's cost while its recorded bound stays 0.

#### Close

The owner ruled the metric (2026-09-23): the contract counts ABSTRACT STEPS. A getter read costs
1 plus the read getter's cost, a compare with a string literal its length (D2062), an `if` or
`match` its condition plus its dearest arm, and arithmetic, field reads, conversions and the
admitted intrinsics 0. A loop would multiply its body by its trip count; no loop is admitted, so
that is a hook in `gcNode`, not a rule. The budget is `GETTER_STEP_BUDGET` = 16, one named
constant in `compiler/typecheck.vl`.

`getterBudgetCheck` runs after the body walks and the cycle check. `getterCost` memoises per
registry row, so the witness is costed in nine body visits, not 4^8, and a cycle's back edge
costs 0 (the recursion rule still refuses it, unchanged). Each row keeps its heaviest contributor
— the getter read most expensively and how often, or its string-literal compares — so the
refusal prints the path that made the total. A chain is one error: only an over-budget getter
that no over-budget getter reads is refused, here `a8`; `a2` (20 steps) is the first to cross.

Costs in the witness: `a0` 0, `a1` 4·(1+0) = 4, `a2` 4·(1+4) = 20, …, `a8` 87,380. Fixtures:
`tests/cases/getters/getter-step-budget-rejects.vl` (this witness, a branch whose dearer arm is
17, a 17-character literal compare, a two-literal `is` totalling 17) and
`getter-step-budget-allows.vl` (a three-level chain, a branch whose arms sum to 24 while each is
12, a compare with a 16-character literal). Getters calling non-getter helpers are not admitted
yet (effects design S2), so the grading list's helper case has nothing to cost today; the std
effects baseline (effects §E4) must record this same measure when it lands.
