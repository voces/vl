### D16540 — a constant tree argument at a type parameter an `f32` destination pins is typed at the tree's own default, and refused

**loud check reject · clause 2 · ``f64 doesn't fit in f32 — the conversion is lossy and must be made explicit with `as` `` · a lone float literal argument at the same position runs · found grading D16414's positions · filed 2026-11-15 against master `f88ee38dd` · bucket (f), a local fix: the constant tree is typed before the destination pins `T` (by ablation, 2026-11-15)**

Repro:

    function g<T>(x: T): T { return x }
    const y: f32 = g(0.1 + 0.2)
    print(y)
    // vl check: f64 doesn't fit in f32 at `g(0.1 + 0.2)`

Want:

    0.30000001192092896

#### Mechanism

Not traced. A lone literal argument takes the destination's `f32` through `T`, so `g(1.5)`
runs; a constant tree, or a lone integer literal, binds `T` at its own default (`f64`, `i32`)
first, and the `f32` destination then refuses the call's result. Owner ruling D16410 has a
destination bind a type parameter no argument binds; here a constant argument binds it, though
E9.1 types a constant where it is used. From the ablation.
