### D1635 — the nullable-VARIANT resolvers had no frame-`let` rung, so a code-15 field read classified as no field at all

**closed · filed 2026-09-05 against master `abecf8da` · closed against `d040e263`**

`nulVariantIdxOfExpr` and `exprNullableVariant` gained the function-frame and module-frame
`let` rungs their `globalLetOfIn` leg already had. Both faces of the witness run.

Repro:

    type Inner = { p: i32 }
    type S = { i: Inner, n: i32 }
    type Other = { o: string }
    type U = S | Other
    function g(n: i32): S | null {
      if n == 0 { return { i: { p: 5 }, n: 1 } }
      null
    }
    function __frame() {
      const src = g(0)
      if src != null {
        const __c: Inner = src.i
        const __f = () => {
          const v = __c
          print(v.p * 2)
        }
        __f()
      }
    }
    __frame()
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `__frame`:
    // type mismatch: expected (ref $type), found (ref null $type)

#### Mechanism

The probe named the rung, one hop below where the row was filed. `captureValKind`'s
annotated arm at both scopes reads:

    CLO2CAP name=__c annK=struct niche=nulstruct initK=struct    nulRef=F memCode=-1  (frame)
    CLO2CAP name=__c annK=struct niche=nulstruct initK=nulstruct nulRef=T memCode=15  (module)

So the D1632 niche check IS asked and IS right; what differs is `letInitCellKind`, and under
it `memberFieldCode(src.i)` — code 15 at module scope, **-1 inside a frame**. `U` gives `S` a
variant row and no struct row, so the field code comes from `memRecvNulVariantIndex` →
`nulVariantIdxOfExpr`, whose Ident arm reads the declared-locals table, the params, the
capture set and the globals registry. `src` is the frame's own `let` and in none of them, so
the read classified as no field, the binding kept the annotation's non-null kind, and the env
struct was declared `(ref $Inner)` over a `(ref null $Inner)` local.

The index moves with its kind (D21): `structIndexOfExpr`'s own code-15 variant rung is gated
on `exprNullableVariant` as well, so lifting the index alone traded the silent module for
`ref valtype with no interned shape` at the un-annotated face — measured, then paired.
