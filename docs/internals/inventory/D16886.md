#### Mechanism

A bound `const m = Map()` nothing writes settles at its declaration (`defaultReadOnlyContainer`):
the value takes the default, and the first key read pins the key (`pinReadKey`, which only pins a
row so registered). An inline `Map()` or `Set()` read in place has no binding, so its row stayed
open: its key never pinned (`Set().has(1)`), or it repped as no map at all (`Map().has("a")`). A
container a call builds and a read takes in place has no place a write could reach, so it now
settles the same way at the read. The receiver is evaluated where it sits: only its type changes.

#### Ablation

| ingredient changed | outcome on master | needed? |
| --- | --- | --- |
| bound (`const m = Map(); m.has(1)`) | runs | **yes**: the inline receiver |
| a call returning an annotated map (`mk().has(1)`) | runs | **yes**: the open container |
| `Set().has("a")` | runs | no for `Set()` reads at `string` |
| `Map()[2.5] ?? 1`, `Set().has(true)` | a check reject, bound or inline (an unsupported key type) | n/a |
