### D3185 — `??` with a string default over a call returning `boolean | null` is refused

**loud emit reject · clause 2 · the plainest spelling of the [D2418](D2418.md) family · found by the #3284 review (`rv3284-24850`) · the same on master `a0b9acaf8` · filed 2026-09-29 against master `995bbc74e`**

Repro:

    function g(n: i32): boolean | null {
      if n > 0 { return true }
      return null
    }
    print(g(1) ?? "N")
    // vl check: rc 0.  vl build: emitProgram: `??` joins a nullable value into a union with no
    // arm for the value's own type

Want:

    true

#### Mechanism

Not localised past the ablation. `g(1) ?? "N"` is typed `boolean | string`, a value union, and
its box has no arm for the `boolean` the niche holds, so the join refuses. D2418 is the same
refusal with the join as a list-literal element. An `i32 | null` value, or a `boolean`
default, runs.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `i32 \| null` in place of `boolean \| null` | runs | **yes** (the boolean niche) |
| `g(0) ?? false`, a `boolean` default | runs | **yes** (the widening default) |
| `const v = g(1)`, then `v ?? "N"` | the same refusal | no |
