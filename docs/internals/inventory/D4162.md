### D4162 — `??` over a nullable string-literal union with a number default has no lowering, at the direct spelling and the generic one

**closed 2026-10-20 by lane L6b · runs, prints `5` then `a` · the nullable atom beside a number default joins into the box at both spellings ([D7967](D7967.md)) · was loud emit reject · clause 2 · pre-existing at the direct spelling on master `5e770df5b` · found by the review of the D3423 fix · filed 2026-10-11 against master `5e770df5b`**

Repro:

    type K = "a" | "b"
    function g(s: K | null) {
      print(s ?? 5)
    }
    g(null)
    g("a")
    // vl check: rc 0.  vl run: emitProgram: `??` over this nullable value is not supported yet

Want:

    5
    a

#### Mechanism

The result of `s ?? 5` is the join `K | i32`, a value union whose box `emitCoalesceGo` has no arm
to build from a `K | null` atom niche: the atom arms (`coalesceLitUnionFits`,
`coalesceNulAtomToStr`) need a member or string default, and the value-union box arm needs a boxed
operand. The generic spelling (`s` written from a `T` and pinned at `K`) reached this refusal with
the D3423 fix; on master it was a check reject of the later `r == 5`, typed at the wrong pin.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `s: string \| null` | runs, prints `5`, `a` | **yes** (a literal-union operand) |
| default `"b"` or `"n"` | runs | **yes** (a number default) |
| result bound as `const r: string \| i32` | same refusal | no |
