**closed · runs, prints `4` then `1` · was loud emit reject, clause 2 · found by lane KJ's ablation of [D3568](D3568.md) (one type parameter for both values) · filed 2026-10-03 against master `7073d9d03` · closed by [D10231](D10231.md), which mints the pinned join's box row per instance so the `null` arm has a rep · fixture `generics/generic-if-null-join-coalesce-scalar.vl`**

    function F<A>(k: i32, a: A, b: A) {
      const v = if k == 0 { a } else if k == 1 { b } else { null }
      print((v ?? 0) + 1)

#### Mechanism

With two parameters (`F<A, B>`) the same program runs since [D3568](D3568.md). Over one
parameter the join `A | null` pins to `i32 | null`, a box no annotation or non-generic inference
registered for the instance, so the `null` arm had no rep. D10231 mints that row per instance.
