#### Mechanism

`mk`'s list literal is built once; the annotated call needs it at `J[]`, the second
call at its own `{f: i32}[]`. A call made once builds at its destination (D3444) and a record
result made twice is copied (`recFreshCallCopy`), but neither covers a list result. The kept
function's own-type calls were refused only where a part is boxed apart (`recBoxApart`), which
counts a `| null` or number widening as served, as a record's copy serves it; no copy serves a
list, so the own row went into the destination's slot.
