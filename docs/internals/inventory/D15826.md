### D15826 — a function returning a list literal of records, called into a list of a record storing a field otherwise and called again un-annotated, is check-clean invalid wasm

**check-clean invalid wasm · clause 1 · open · found grading D15825 · the same on master `4e65bd710` · D14385's spelling (a union field) is refused; this one, a nullable or widened number field, is not**

Repro:

    type J = { f: i32 | null }
    function mk() { [{ f: 4 }] }
    const _k: J[] = mk()
    const y = mk()
    print(y[0].f)
    // vl run: invalid module inside the module's top-level code

Want:

    4

#### Mechanism

Not traced. `mk`'s list literal is built once; the annotated call needs it at `J[]`, the second
call at its own `{f: i32}[]`. A call made once builds at its destination (D3444) and a record
result made twice is copied (`recFreshCallCopy`), but neither covers a list result, and D14385's
refusal fires only where the element's field is a union.
