### D4140 — a list spelled with a recursive alias's members unfolded is refused where the alias's own list is accepted

**loud emit reject · clause 2 · found closing D4038 · the emitter refused it on master `efd3c3f15` with `a nullable-string|J[] list element has no rep`; the checker refused it from D4038 until D14656 made the unfolded element assignable to `J`, and the emitter refuses it again with `array value does not match any array member of the union` · filed 2026-10-11**

Repro:

    type J = null | string | J[]
    const ys: (null | string | J[])[] = ["a"]
    const k: J = ys
    print(k is J[])
    // vl check: rc 0.  vl run: emitProgram: array value does not match any array member of the union

#### Mechanism

`(null | string | J[])[]` is `J[]` with `J` unfolded once, so the delivery is no widening,
but its element is a separate union row from `J` and has its own (absent) list rep. The
widening walk, which D4038 made see through the cycle, now compares the two element rows and
refuses at check; before it the emitter refused. Either spelling of the element should
resolve to `J`'s rep. Since D14656 the checker relates the two rows, so the refusal is the
emitter's again.
