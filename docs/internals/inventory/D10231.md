### D10231 — a generic's `if` with a `null` arm, bound and then coalesced, refuses at a scalar pin

**open · loud emit reject, `vl check` rc 0, `bare null needs a struct-typed context`, clause 2 · found closing [D10130](D10130.md), as its ablation's last row · present on master `a66b67b20` · filed 2026-10-22 against master `a66b67b20`**

Repro:

    function f<V>(c: boolean, x: V, d: V): V {
      const r = if c { x } else { null }
      r ?? d
    }
    print(f(true, 5, 0))
    // vl check: rc 0.  vl run: bare null needs a struct-typed context

Want:

    5

#### Mechanism

D10130's fix rewrites an `if` with a `null` arm when it is the `??`'s own left operand, which
only an optional chain's desugared `if` is by emit time. Here the `if` initialises a binding, so
`r` is a `V | null` local at an `i32` pin and the bare `null` arm has no rep to land at. A
written `(if …) ?? d` is lifted into the same kind of local before emit (a probe on the rewrite
saw an `Ident` operand), so it is this defect too.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `function f(c: boolean, x: i32, d: i32): i32` | prints `5` | **yes**, the type parameter |
| `print(f(true, "s", "t"))` | prints `s` | **yes**, the scalar pin |
| `(if c { x } else { null }) ?? d`, no binding | refuses, `` `??` over this nullable value is not supported yet `` | no, a written `if` is bound anyway |
| `(if c { null } else { x }) ?? d`, the mirror | refuses, the same | no |

#### Grading list

The four spellings above; the two refusing ones must print `5`.
