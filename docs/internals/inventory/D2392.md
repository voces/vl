#### Mechanism

`collectInlineUnions` registers an un-annotated binding whose initializer infers a value
union (an `if` expression, an optional chain, a filled `let x = null`) in the `nli` table,
keyed by its `LetDecl`, before any rewrite runs. `captureBoxRewrite` then turns the `let` into
its cell, `let v = [if c { 1 } else { "s" }]`, and the `nli` row still named the binding's
union: `emitStmt`'s `let` arm read it through `nliNameOf` and union-coerced the cell LITERAL
into `i32|string`, which has no list member. The annotated face never has an `nli` row, and
`let v = mk()` infers through the call rather than the table. The close drops the row when
the binding becomes a cell (`nliForgetLet`): the union stays registered, and the cell is the
list of it that the annotated face already builds.
