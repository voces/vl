### D2392 — an un-annotated binding initialized by an `if`-expression union cannot be boxed for a closure that assigns it

**loud emit reject · clause 2 · filed 2026-09-25 against master `3ab3c402f`, found grading
[D2387](D2387.md)/[D2388](D2388.md)'s un-annotated face**

Repro:

    function f(c: boolean): string {
      let v = if c { 1 } else { "s" }
      const k = () => { v = 2 }
      k()
      "done"
    }
    print(f(true))
    // vl check: rc 0.  vl run: emit error: array value does not match any array member of the union (leaf-scalar widening across a nested array is unsupported)

#### Mechanism

`captureBoxRewrite` turns the `let` into its cell, `let v = [if c { 1 } else { "s" }]`, typed
as a list of the initializer's recorded type. The cell literal is then delivered as if the
binding were still the union itself, and the union coercion finds no array member to box the
list under. The un-annotated face that initializes from a union-returning call instead
(`let v = mk()`) runs, and so does an annotated `let v: i32 | string = if ...`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the closure's write (`k` only reads `v`) | runs, `v` is not boxed | **yes** |
| the `if` initializer (`let v = mk()`, `mk(): i32 \| string`) | runs | **yes** |
| the annotation's absence (`let v: i32 \| string = if ...`) | runs | **yes** |
| the member pair (`f64 \| boolean`, `boolean \| string`) | still refuses | no |
| a later read of `v` | still refuses | no |
