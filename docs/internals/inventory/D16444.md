### D16444 — a spread of a call's fresh record list beside a part at a wider record is refused, though the call could be copied

**loud check reject · clause 2 · `this list holds elements built as {x: f64} where line 2 gives them, and elements held at their own {x: i32} here` · built an invalid module before [D16440](D16440.md) · found closing [D16441](D16441.md) · filed 2026-11-15 against master `30248860f` · open**

Repro:

    function mk() { return [{ x: 1 }] }
    const l = [{ x: 2.5 }, ...mk()]
    print(l[1].x)
    // vl check: this list holds elements built as {x: f64} where line 2 gives them, and elements held at their own {x: i32} here

Want:

    1

#### Mechanism

Not yet located in the emitter. The call's list is fresh, so its records could be copied into the
list's element, as `recFreshCallCopy` copies a list call element by element where it lands
(`listCopyTyIx`). Recording that copy on the spread's call builds an invalid module: the spread's
lowering does not read the copy. Until it does, D16440's refusal stands.

#### Ablation

| `const s = mk(); [{ x: 2.5 }, ...s]` | the same refusal | no |
| `listCopyTyIx` recorded on the spread's call (scratch) | invalid module | — (the emitter) |
