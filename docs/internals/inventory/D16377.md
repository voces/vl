### D16377 — a function testing `is C` on an `A | null` parameter, called with a `C` value and with `null`, refuses at emit

**closed 2026-11-15 · runs, prints `true` then `false` · was a loud emit reject, clause 2, bucket (b), `emitProgram: `is` test but no union type declared` · a row slot only a `null` reaches binds its record, not `never`, so the `null` call is the declared parameter's instance (`elabNullOnlyPin`, `check_calls.vl`) · found beside [D16370](D16370.md) by the independent oracle · filed 2026-11-15 against master `6c486842e`**

Repro:

    type A = { v: i32 }
    type C = { v: i32, s: string }
    function f(a: A | null): boolean { a is C }
    const x: C = { v: 1, s: "a" }
    print(f(x))
    print(f(null))

Want:

    true
    false

#### Mechanism

The two calls make two instances of `f`: one at the `C` record and one at bare `null`. The
refusal comes from an `is` rung that expects a union-typed receiver. Each call on its own runs, and
so does `f({ v: 2 })` with `f(null)`, so the `null` instance beside a `C` one is the ingredient.
The two instances are the record-width rewrite's (D3992): the wider `C` makes the `A | null`
parameter generic at its row slot, so the `null` call instantiated the slot at `null`, where the
`is` rung found no union.

#### Grading list

`f(x)`, `f({ v: 2 })` and `f(null)` together, and the same with `p is A` in place of `p is C`.

#### Closed

A call that binds none of a generic's type parameters is keyed at their defaults
(`elabUnboundCallNote`), and a parameter only a `null` reaches binds `never` (D3178): `never |
null` is `null`, so the slot's `null` call built an instance taking `nullref`, whose `is` has no
union to test. A row slot ranges over its record's rows, so only-`null` binds it at that record
and the instance is the declared `A | null` function, which the `is` lowering already serves.

`record-param-width-is-nullable.matrix.vl` (master fixpoint `417397629` vs the fix): 8 → 24 of 24
graded cells, runs → not-runs 0, silent 0. `record-param-width-{before,between,after,inline}`
unmoved.
