### D16377 — a function testing `is C` on an `A | null` parameter, called with a `C` value and with `null`, refuses at emit

**loud emit reject · `emitProgram: `is` test but no union type declared` · found beside [D16370](D16370.md) by the independent oracle · filed 2026-11-15 against master `6c486842e`**

Repro:

    type A = { v: i32 }
    type C = { v: i32, s: string }
    function f(a: A | null): boolean { a is C }
    const x: C = { v: 1, s: "a" }
    print(f(x))
    print(f(null))
    // vl check: rc 0.  vl run: emit error, `is` test but no union type declared

Want:

    true
    false

#### Mechanism

The two calls make two instances of `f`: one at the `C` record and one at bare `null`. The
refusal comes from an `is` rung that expects a union-typed receiver. Each call on its own runs, and
so does `f({ v: 2 })` with `f(null)`, so the `null` instance beside a `C` one is the ingredient.
It is not yet ablated further.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `f(null)` call | prints `true` | **yes** |
| the `f(x)` call | prints `false` | **yes** |
| `x` replaced by `{ v: 2 }` | prints `false`, `false` | **yes** |
