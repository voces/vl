### D3930 — a reassigned binding of generic functions handed to a function-typed parameter traps

**loads then traps · found in review of #3490 (`rv3490/q5_reassign_toplevel`, `q4`) · filed 2026-10-09 against master `255fc7a6c`**

Repro:

    function call(f: (n: i32) => void) { f(1) }
    function inner<U>(u: U) { print(u) }
    function other<V>(v: V) { print("O"); print(v) }
    function main() {
      let k = inner
      k = other
      call(k)
    }
    main()
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch

Want:

    O
    1

#### Mechanism

Not located. `k` holds `inner`, then `other`, both generic; neither write instantiates its generic
at the parameter's type, so `call` receives a function at another signature. No nesting or
capture is needed (q4 is the nested form). Without the write it runs.
