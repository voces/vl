### D16006 — an `is` test that covers its operand's whole type leaves the `else` arm reading the operand at that type, so an operation the arm can never reach is refused

**closed 2026-11-14 · runs, prints `5`, with the warning `this \`else\` can never run (\`p\` is always \`i32\`)` · was loud check reject, `operator '+' is not defined for i32 and string` · clause 2 · owner ruled (a) 2026-11-14 (DECISIONS) · found closing [D16004](D16004.md) · filed 2026-11-13 against master `7b0b9d8ac` · (a) fixed by narrowing a covering test's dead arm's operand to `never` (`subtractLeavesNothing`, check_relate_core.vl), a bottom operators and member reads pass through, and recording the arm (`deadArmNote`) so the arm is neither collected nor emitted · (b) closed by #7910 · residue [D16092](D16092.md) · fixtures `narrowing/covering-test-dead-arm-reads-never.vl`, `narrowing/error-covering-test-dead-arm-other-names-checked.vl`**

Repro:

    function take(p: i32) {
      if p is i32 { print(p + 1) } else { print(p + "!") }
    }
    take(4)
    // vl check: operator '+' is not defined for i32 and string
    // The else arm cannot run; `take` should print 5.

Want:

    5

#### Mechanism

`subtractTy(i32, i32)` leaves nothing, and the `else` arm keeps `p` at `i32` rather than at no
type, so the arm's `p + "!"` is checked as if it could run. The un-annotated spelling shares it at
each pin: `function take(p)` called as `take(4); take("s")` is refused at the `i32` pin, while
`p: i32 | string` runs, because the instance at `i32` is this program. The `HD_GNOT` remainder
answers an empty subtraction with the whole pin for the same reason ("a pin it cannot reduce
keeps itself").

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the operation in the `else` arm — `print(p)` | prints `5` | **yes** |
| the covering test — `p: i32 \| string` | prints `5` | **yes** |

#### Split

* **(b) closed — the un-annotated spelling.** A deferred demand (operator, argument, member)
  over the `HD_GNOT` remainder of an `is` test is vacuous at a pin whose every member is the tested
  type, matching the instance elaboration's dead-arm drop. `take(4); take("s")` with `take(p)`
  prints `5` and `s!`; a single `take(4)` pin also runs. A live `else` arm is still checked at its
  pin. Pinned by `tests/cases/inference/hole-param-is-dead-else-at-pin.vl`.
* **(a) closed — the annotated spelling (owner ruling).** A test the operand's whole closed type
  passes leaves the other arm dead: the operand reads as `never` there, every use of it checks,
  and the arm carries a dead-test warning. This covers the `is` complement, the `==` complement
  over a literal type, the then arm under `!`, and `match`'s `_` after every member is named. Any
  other name in the arm is checked as usual. An instance's dead arm is the elaboration's (D932),
  so no instance narrows to `never`.
