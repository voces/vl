### D9322 — a `const` bound to an `if` of generic functions whose `else if` condition calls is refused at two types

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same binding with only its first condition calling runs ([D9161](D9161.md)) · found closing [D9161](D9161.md) · present on master `bc09f9670` · filed 2026-10-21 against master `bc09f9670`**

Repro:

    function idg<T>(t: T): T { return t }
    function kg<T>(t: T): T { return t + t }
    let n = 0
    function pick(): boolean {
      n = n + 1
      return n > 5
    }
    const h = if pick() { kg } else if pick() { idg } else { kg }
    print(h(3))
    print(h("x"))
    print(n)
    // vl run: emitProgram: a binding of an `if` choosing generic functions is delivered at two function types — annotate the binding

#### Mechanism

[D9161](D9161.md)'s close evaluates only the first condition (or the scrutinee) once before the
binding, which is sound because it always runs. A later condition runs only when the earlier
ones fail, so it cannot be hoisted the same way, and the split (`fsHoistsCond`, fn_split.vl)
declines. Running it needs the whole choice evaluated once into an arm index that each per-type
copy selects by, or one binding holding a value per instance of the chosen generic.
