#### Mechanism

The twin build gives each twin of a plain maker an instance of its returned hole lambda at the
twin's signature (`monoPinValueLambda`, `emit_mono.vl`, through `monoInstanceFor`). That instance's
body keeps the call `inc0(a)` with `inc0` unresolved per instance, and the emitter reads it as a
generic function taken as a value. One twin alone keeps the clone path, which does instance it.
