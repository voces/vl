### D3204 — a hole or generic body reads a member through a record field typed `H | null` at a pin, which the direct spelling refuses

#### Mechanism

The direct spelling, `function F(z: R)`, refuses `member access '.v' on non-object H | null`.
A member read off an inference hole grows the hole's shape (`holeMemberTy`), and a read off an
unbounded `<T>` records a `memCstrTy` row, but a read off a hole's own FIELD (`?fld.h.z`) did
neither check at the pin: the argument check compares the parameter's shape, not a field's, so
`H | null` reached `.v` and trapped on `null`. The landed rule (D3287) records the row for a read off a hole's field,
element, call result or `is` remainder, and the pin asks it only whether the receiver admits
`null`; the parked candidate asked every floor, which refused the `is`-else reads whose
remainder the body cannot compute (D3216). A null test narrows the field, so a guarded read runs.
