### D16483 — `??` read straight off an element of a list of nullable vectors is refused at emit

**closed 2026-11-15 · runs, prints `2` · was a loud emit reject, clause 2: `vl check` rc 0, then emitProgram: ?? over this nullable value is not supported yet; the same read bound to a `const` first ran · fixed 2026-11-15 by lane L: a re-readable list cell's `??` lowers as the null test it spells, the arm a pinned instance's cell already took (`emitCoalesceNullableRefs`, wasmEmit.vl) · a side-effecting index is D16484 · found by the v128-list design's baseline · filed 2026-11-15**

Repro:

    import { F32x4, splatF32 } from "std:simd"
    const xs: (F32x4 | null)[] = []
    xs.push(splatF32(2.0))
    print((xs[0] ?? splatF32(0.0)).x)

Want:

    2

#### Mechanism

The `??` lowering had no arm for an index read whose element is a union box holding a `v128`,
whose result is the bare vector rather than a box. A local of the same type is rewritten to the
null test before emission. A pinned instance's list cell already took that null test (D8820);
the fix takes it for any re-readable list cell. A general re-readable arm was tried first and
refused: it turned D3172's narrowed box read from a loud emit reject into invalid wasm.
