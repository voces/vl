### D4034 — a receiver-overload set whose candidates return their own type parameter is refused at a type-parameter receiver, blaming the receiver

**closed 2026-11-14 · runs, prints `S` then `1` · was a loud check reject, clause 2, the refusal named the wrong cause · closed by binding a candidate's return type from the explicit arguments (`ovArgBoundRet`, `check_member_call.vl`) · found in the #3538 review (lane DV, D4030) · filed 2026-10-11 against master `98a4ed71b`**

Repro:

    // file: s.vl
    export function tag<T>(self: string, v: T): T { print("S"); return v }
    // file: a.vl
    export function tag<T>(self: i32[], v: T): T { print("L"); return v }
    // file: entry.vl
    import { tag } from "./s"
    import { tag } from "./a"
    function d<R, T>(r: R, v: T): T { return r.tag(v) }
    print(d("a", 1))
    // vl check (before the close): `.tag(…)` cannot choose between `tag` from "./s" (a `string` first) and
    // `tag` from "./a" (a list first) for a receiver each call supplies, because a
    // candidate's return type depends on its receiver — annotate the receiver

Want:

    S
    1

#### Mechanism

`ovHoleCallTy` (`compiler/check_member_call.vl`) types a call through an overload set at a
receiver each instance supplies by the one return type every candidate shares. It refused any
candidate whose return type held a type variable, saying "depends on its receiver", although a
variable an explicit argument binds does not. `ovArgBoundRet` binds each candidate's type
parameters from the arguments' types (`bindGenWalk`, as the receiver-concrete path does) and
compares the substituted returns. A return variable no argument binds, or one `self` names, keeps
the receiver sentence, now true; disagreeing bound returns get "the candidates return different
types".

#### Grading list

The four-instance spelling (`d("a", 1)`, `d([1], "x")`, `d("b", 2.5)`, `d([2], true)`,
want `S 1 L x S 2.5 L true`), and a set whose candidates return different instantiations
of their own `T`, which should still refuse, with a sentence that names that cause.
