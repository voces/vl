### D2663 — an un-annotated map binding initialized by an `if` expression is refused at its index read

**loud emit reject · `emitProgram: index receiver is not an array or string` · found while respelling D30's recursion witness for D2654 · filed 2026-09-26 against master `979323f83`**

Repro:

    type S = { a: i32 }
    function mkR(v: i32): {[string]: S} {
      const m: {[string]: S} = Map()
      m["a"] = { a: v }
      return m
    }
    function early(): boolean { false }
    let gc = if early() { mkR(8) } else { mkR(7) }
    const gcv = gc["a"]
    if gcv != null { print(gcv.a) }

#### Mechanism

`vl check` accepts the program and types `gc` as the map, but the emitter takes the binding's
rep from its initializer's syntax, and a value `if` over two map-returning calls yields no map
shape, so `gc["a"]` is refused as an index into a non-array. A clause-2 violation, at a module
global and a function local alike. Annotating the binding runs; so does routing the `if`
through a function (`let gc = pick()`), which is the spelling
`maps/inferred-map-return-if-arm-tail-caller.vl`'s recursion witness uses.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `if` expression (`let gc = pick()` over the same arms) | runs, prints `7` | **yes** |
| the missing annotation (`let gc: {[string]: S} = if …`) | runs, prints `7` | **yes** |
| the module level (the same three lines inside a function) | still refuses | no |
