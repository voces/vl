### D2663 — an un-annotated map binding initialized by an `if` expression is refused at its index read

**closed 2026-09-26 — the witness prints `7` · fixture `tests/cases/maps/if-expression-map-binding.vl` · was loud emit reject · `emitProgram: index receiver is not an array or string` · found while respelling D30's recursion witness for D2654 · filed 2026-09-26 against master `979323f83`**

Repro:

    type S = { a: i32 }
    function mkR(v: i32): {[string]: S} {

#### Close

`exprMap` and `mapShapeOfExpr` had no `IfStmt` arm, although the if-expression lowering already
had a map join (`ifExprRefKind`'s `map` answer, with its slot read off `ifRepArmValueIx`). Both
now answer from those: a value `if` is a map when its join's rep is, with the shape of the arm
the rep is read off. Graded at module scope, as a local, captured by a lambda, returned, with
`else if`, `null` beside a map arm, ident arms, string, `i32`-valued and `i32`-keyed maps, and
with a later key write, `.keys()`, `.has` and `.length`.

#### Mechanism

`vl check` accepts the program and types `gc` as the map, but the emitter takes the binding's
rep from its initializer's syntax, and a value `if` over two map-returning calls yields no map
shape, so `gc["a"]` is refused as an index into a non-array. A clause-2 violation, at a module
global and a function local alike. Annotating the binding runs; so does routing the `if`
through a function (`let gc = pick()`), which is the spelling
`maps/inferred-map-return-if-arm-tail-caller.vl`'s recursion witness uses.
