#### Mechanism

Inside the arm `z.h` is a read of `B` at its own type out of the union box the field holds, and
the read owes the box's payload cast. Off a parameter or local receiver of the same type the
cast is written (D17025); off a module-level `const` whose record is a union member it is not,
and the box reaches the `B` destination. A field read through it (`z.h.s`) runs.
`globalReadStructIndex` answers -1 for a global whose cell is a variant, so `boxedArmOfMember`
found no receiver row and named no member.
