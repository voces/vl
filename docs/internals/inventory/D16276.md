### D16276 — an empty `Map()` delivered to a union with two map arms is boxed as a scalar arm

**open · check-clean invalid wasm · `vl check` rc 0, `type mismatch: expected i32, found (ref $type)` · clause 1 · found closing [D16275](D16275.md) · filed 2026-11-14 against master `a2e10b45b`**

Repro:

    type U = null | f64 | { [string]: f64 } | { [string]: U }
    const j: U = Map()
    print(j == null)
    // vl check rc 0.  vl run: the emitted module failed to validate: type mismatch: expected i32, found (ref $type)

#### Mechanism

`unionMapArmOf` answers -1 when a union has two map arms, so the empty `Map()`'s holes stay open
and the emitter boxes it through the value-atom route, as [D16275](D16275.md) did. An empty `[]`
is pinned to a union's first list member; whether an empty map takes its first map arm or the
delivery is refused as ambiguous is the open question.
