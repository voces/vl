### D16276 — an empty `Map()` delivered to a union with two map arms is boxed as a scalar arm

**closed · runs, prints `false` · was check-clean invalid wasm · `vl check` rc 0, `type mismatch: expected i32, found (ref $type)` · clause 1 · found closing [D16275](D16275.md) · filed 2026-11-14 against master `a2e10b45b` · closed 2026-11-14 on master `4b94dbf0b`: an empty map delivered to a union takes its first map arm, as an empty list takes the first list arm (`unionMapArmOf`, check_relate_core.vl), by the coordinator's ruling: it is a value of either · fixture `unions/empty-map-into-union-of-two-map-arms.vl`**

    type U = null | f64 | { [string]: f64 } | { [string]: U }
    const j: U = Map()

    // vl check rc 0.  vl run: the emitted module failed to validate: type mismatch: expected i32, found (ref $type)

Want:

    false

#### Mechanism

`unionMapArmOf` answers -1 when a union has two map arms, so the empty `Map()`'s holes stay open
and the emitter boxes it through the value-atom route, as [D16275](D16275.md) did. An empty `[]`
is pinned to a union's first list member; an empty map now takes the first map arm the same way.
