### D2576 — an un-annotated `Map()` holding a `(P | null)[]` reads the list's elements at the wrong rep

**loads then traps · clause 1 · found by lane Y's D2572 position matrix (`map_value`, three cells) · filed 2026-09-26 against master `3e43afa90`**

Repro:

    type P = { x: i32 }
    const src: (P | null)[] = [null, null]
    const m = Map()
    m["k"] = src
    const v = m["k"]
    if v != null { print(v[0] == null) }
    // vl check: rc 0.  vl run: wasm trap: null reference

#### Mechanism

Not located. The map's value type is inferred from the write, and the element read of the list
read back from it takes a non-null struct path: `v[0] == null` traps, and narrowing the element
before a field read (`const e = v[0]; if e != null { print(e.x) }`) is a loud emit reject,
`field access receiver is not a struct`. Annotating the map runs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the inferred map (`const m: {[string]: (P \| null)[]} = Map()`) | runs, prints `true` | **yes** |
| the record element (`(string \| null)[]`) | runs, prints `true` | **yes** |
| the nullable element (`P[]`, `print(v[0].x)`) | runs | **yes** |
| the element read (`print(v.length)`) | runs | **yes** |
