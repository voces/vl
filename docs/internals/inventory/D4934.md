#### Mechanism

`emitListEmptyFitIs` (wasmEmit.vl) hands a reading arm an empty `K[]` in the receiver's place,
but a push through it would have had to land in the caller's list, an `i32[]` that holds no
`f64`. `listFitGrowScan` now gives such an arm a `fitGrow*` local: the first test that fits
stores a fresh `K[]` there, a later test answers from it, the arm's reads and pushes go to it,
and a `.length` outside the arm reads it once set. That holds only where every other use of the
receiver is one of those reads (`listFitGrowUsesOk`).

#### Grading list

The unbound face: `function s<T, U>(a: T[]) { const q: U[] = []; if q is f64[] { q.push(1.5) }
print(q.length); print(a.length) }` with `s([1])` now prints `1` and `1`: `U` takes the D4551
default, the arm is entered, and an `f64` default would print the same. It printed `0` and `1`
while the push kept `U` unbound. A closure that pushes onto the capture,
`const k = () => { q.push(1.5) }` in the arm over `q: V[]`, is a check reject at the instance
(`push: cannot add f64 to i32[]`).
