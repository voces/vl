### D17681 — a hole parameter captured by a lambda whose call result reaches an annotated parameter is refused at check as an undeclared name

**loud check reject · 1 spelling · filed 2026-11-26 against master `9044360b6` by COV-CLOS, found writing D17676's positions**

Repro:

    function use(j: i32) { return j }
    function id(y) {
      const b = () => y
      return use(b())
    }
    print(id(3))
    // vl check: error 3:19 undeclared identifier 'y'.  Want: runs, prints 3

Want:

    3

#### Mechanism

Not ablated past the table. The lambda's capture of the hole parameter `y` resolves while the
checker infers `id`'s hole from the annotated parameter its closure's result reaches; at that
point the lambda's body no longer sees `y` in scope.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |

| `const r = b(); use(r)` | still refused | no |
| no closure, `use(y)` | runs, `3` | **yes** |
