### D3284 — a two-way join of two type parameters at `K` and `i32 | null` builds invalid wasm

**check-clean invalid wasm · clause 1 · open · the same on master `569caa36c` · found by the #3297 round-3 review (`gB3/n2__k_in__none__print.vl`; the `k_in__none` cells of `gB3`, all positions, two and three parameters) · filed 2026-09-29**

Repro:

    type K = "a" | "b"
    function g<T, U>(a: T, b: U, k: i32) {
      const r = if k == 0 { a } else { b }
      return r
    }
    const x0: K = "a"
    const x1: i32 | null = null
    function use(k: i32) {
      print(g(x0, x1, k))
    }
    use(0)
    use(1)
    // vl check: rc 0.  vl run: invalid module inside `g` (type mismatch: expected i32, found (ref $type))

Want:

    a
    null

#### Mechanism

Not localised past the ablation. The join is two bare parameters with no literal arm (D2760 keeps
them apart). At `T := K`, `U := i32 | null` the instance lowers the join at the literal union's
`i32` atom while the `U` arm is the nullable box.

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `function g(a: K, b: i32 \| null, …)`, the direct spelling | prints `a null` | **yes** (the type parameters) |
