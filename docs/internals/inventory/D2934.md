#### Mechanism

#3236 withholds an instance's value-atom return box when a binding that reaches the return joins
other members at the pin than the box holds; at a `string | null` pin the join keeps the `null`
the checked return dropped, so the box is withheld and the call refuses loudly. The bindings that
reach the return are found by following bare-name initializers back from the returned name, and
that walk stopped after eight rounds. Past eight aliases the join's binding was not reached, the
box was minted, and the scalar join was stored into it. The walk now runs until a round adds no
name, which the finite set of names in a body bounds.
