### D9642 — a list element built by a call returning a record of an un-annotated function leaves the function unpinned when handed to an un-annotated parameter

**loud emit reject · `vl check` rc 0 · `emitProgram: cannot take the generic function `inc0` as a value` · clause 2 · found closing [D9570](D9570.md) · present on master `9e81d3ee3` · filed 2026-10-22 against master `9e81d3ee3`**

Repro:

    function inc0(a) { return a + 1 }
    function take2(a) {
      print(a.f(3))
    }
    function mk() { return { f: inc0 } }
    const xs = [mk()]
    take2(xs[0])
    // vl check rc 0.  vl run: emit error: emitProgram: cannot take the generic function `inc0` as a value

#### Mechanism

`inc0` is taken as a value in `mk`'s returned literal, typed at the open record, and no call
pins it there. [D9640](D9640.md)'s close follows a list element only to a record literal or a
`const` record binding (`monoOpenFnRecSrcPin`, emit_mono.vl); a call's result is not followed
to the literals its `return`s hold. `take2(mk())` without the list runs, printing `4`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the call (`const xs = [{ f: inc0 }]`) | runs, `4` | **yes** |
| the hole in `inc0` (`inc0(a: i32): i32`) | runs, `4` | **yes** |

#### Grading list

`take2(mk())` without the list.
