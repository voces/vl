#### Mechanism

`same` carries a type variable, so the checker's adapter for a function value delivered at
another function type (`fvaAdapt`) does not wrap it, and the conversion is the emitter's. Past
the return of `deliver`, `monoCoerceRetAtPin` instanced `same` from the flow pin's parameters
alone, giving a `(K) => K` instance whose result is the i32 atom, while the call through `v` is
typed `(K) => string` and `call_indirect` checks the signature. The instance is now built with
the pin's `string` result, keyed apart from the `(K) => K` one. Its body's `k` then has to widen
to its member text at the return, and that widening is gated on the program using a literal
union: `anyLitUnionUsed` counted a function type's result but not its parameter, and here `K`
appears only as `v`'s parameter.
