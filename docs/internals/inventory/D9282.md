### D9282 — a generic function returned from an un-annotated function and bound at a literal-union parameter traps

**loads then traps · clause 1 · `vl check` rc 0 · `wasm trap: indirect call type mismatch` · found grading [D9230](D9230.md) (matrix `fn-value-litunion-result-as-string-generic`, `return_inferred`, annotated) · present on master `e428d97c0` · filed 2026-10-21 against master `e428d97c0`**

Repro:

    type K = "x" | "y"
    function same<T>(k: T): T { k }
    function deliver() {
      return same
    }
    const v: (k: K) => string = deliver()
    print(v("x") + "!")
    // vl check rc 0.  vl run: wasm trap: indirect call type mismatch

Want:

    x!

#### Mechanism

Not traced. The destination's literal-union parameter pins `same` at `K` when it is bound
directly; through the un-annotated `deliver` the returned function is instanced at a type the
call through `v` does not match.

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the literal union (`(k: string) => string`) | runs, `x!` | **yes** |
| `deliver` (`const v: (k: K) => string = same`) | runs, `x!` | **yes** |
| the annotation on `v` (matrix un-annotated face) | runs, `x!` | **yes** |
