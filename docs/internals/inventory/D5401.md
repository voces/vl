### D5401 — a generic returned from an un-annotated function and handed to an un-annotated parameter is not instanced at the calls the body makes

**loud emit reject · `vl check` rc 0 · clause 2 · found closing [D5360](D5360.md) (`generic-bare-return-inferred.matrix.vl`, `argument` and `early_return_guard`, un-annotated face) · filed 2026-10-17 against master `9c7d1b92d`**

Repro:

    function k<T>(x: T): T { return x }
    function mk() { return k }
    function use(f) { print(f(3)) }
    function main() { use(mk()) }
    main()
    // vl check: rc 0.  vl run: emitProgram: monomorphize: unsupported argument type for `f` in a call to `use`

Want:

    3

#### Mechanism

From the ablation only. `monoHoleGenFnTy` instances a generic handed to an un-annotated
parameter when the argument names it or an alias of it (D5361); a call result is neither, so the
parameter has no pin, though the checker bound it (`tyIsForeignGenericSig`).
