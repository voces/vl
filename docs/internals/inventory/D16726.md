### D16726 — an element read straight off a generic identity's empty `Set()` or `Map()` result does not pin the open element, so a non-string key is refused

**closed 2026-11-16 by lane AE — the witness prints `false` · a container a call builds, read in place by a key read, settles as a bound one only read does (`defaultReadOnlyContainer`, then the read's key pins it: `memberCallMapTy`, `checkIndexNode`) · matrix `inline-empty-container-receiver-read.matrix.vl` 78 of 78 graded run (0 on master) · fixture `tests/cases/maps/inline-empty-container-receiver-read.vl` · the non-generic face is [D16886](D16886.md) · was a loud emit reject, `emitProgram: map key is not a string` (`take(Set()).has(1)`, `take(Map()).has(1)`, `take(Map())[1] ?? 0`) · clause 2 · refused on master `2a0b71c1a` and with D15040's close alike · filed 2026-11-16 against master `2a0b71c1a`**

Repro:

    function take<B>(b: B): B { return b }
    print(take(Set()).has(1))
    // vl check: rc 0.  vl run on master: emit error, map key is not a string

Want:

#### Mechanism

The read's argument types the element (`1` is an `i32`), but the read is of the call's result,
whose open container the call closes at the literal's own build (a `string` key or set element,
D15040). A bound result pins: `const t = take(Set()); print(t.has(1))` runs. The key argument
of a read off the call itself does not reach the argument literal.

#### Ablation

| `take(Set()).has("a")` | runs, `false` | **yes** (a non-string key) |
| `const t = take(Set()); print(t.has(1))` | runs, `false` | **yes** (the read off the call) |
