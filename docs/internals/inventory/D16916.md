### D16916 — a record re-pointed at a literal whose function list holds fewer of its set's members is refused at emit

**closed 2026-11-17 by lane AE — the witness prints `6` · a strict subset adds nothing to the set, so the field widener records no widening and the record solve never built the re-point's literal at the binding's record: `recAsgFnWidenedTy` (`compiler/check_fit_rules.vl`) now takes a literal written whole where it differs from the binding only in function fields, and `recFnFieldsWiden` compares a list of functions at its element · fixture `tests/cases/closures/record-repointed-at-subset-of-its-fn-set.vl` · the list-of-lists and nested-record spellings are [D16920](D16920.md) · was: loud emit reject · clause 2 · `emitProgram: object literal field count does not match struct` · the list-literal twin of [D16242](D16242.md) · found by lane AE on the D16834 matrix · filed 2026-11-16 against master `846d9d9e9`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    let r = { f: [inc0, dbl] }
    r = { f: [dbl] }
    print(r.f[0](3))
    // vl check: rc 0.  vl run: emit error, "emitProgram: object literal field count does not match struct"

Want:

    6

#### Mechanism

The field widener (`elabFnFieldTy`) widens a binding only where a write adds a member to its set;
a strict subset adds none, so no widening is recorded, `recAsgFnWidenedTy` answered -1, and the
re-point's literal kept its own type, `{f: [{dbl}]}`, for which no struct row was minted.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `r = { f: [dbl, inc0] }` (the whole set) | runs, `6` | **yes** (a strict subset) |
| `let r = { f: [inc0] }`, `r = { f: [dbl, inc0] }` (a superset) | runs, `6` | **yes** |
| `r.f = [dbl]` (a field write) | runs, `6` | **yes** (the record written whole) |
| `let r = [inc0, dbl]`, `r = [dbl]` (no record) | runs, `6` | **yes** |
| `print(r.f.length)` (no call) | runs, `1` | **yes** (a call through the field) |
