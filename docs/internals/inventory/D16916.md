### D16916 — a record re-pointed at a literal whose function list holds fewer of its set's members is refused at emit

**loud emit reject · clause 2 · `emitProgram: object literal field count does not match struct` · the list-literal twin of [D16242](D16242.md) (a list binding held in the field) · found by lane AE on the D16834 matrix · filed 2026-11-16 against master `846d9d9e9`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    let r = { f: [inc0, dbl] }
    r = { f: [dbl] }
    print(r.f[0](3))
    // vl check: rc 0.  vl run: emit error, "emitProgram: object literal field count does not match struct"

Want:

    6

#### Mechanism

Not yet located. The written literal's list holds a strict subset of the binding's set, and the
record literal is built against a row whose field count differs from its own.
