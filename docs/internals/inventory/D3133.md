### D3133 — an un-annotated `let` of a value narrowed to `K | null` out of a box, then reassigned, is invalid wasm

**check-clean invalid wasm · clause 1 · found by the #3279 review (`rv3279-28945/p/u9.vl`) · the same on master `a29230611` · filed 2026-09-28 against master `a29230611`**

Repro:

    type K = "a" | "b"
    function skn(k: K | null): string {
      if k == null { return "N" }
      return k
    }
    function t(v: K | null | i32) {
      if !(v is i32) {
        let c = v
        c = null
        print(skn(c))
      }
    }
    t("a")
    // vl check: rc 0.  vl run: invalid module inside `t`: type mismatch: expected i32, found
    // (ref $type)

Want:

    N

#### Mechanism

Not localised past the ablation. [D3118](D3118.md) gives the un-annotated binding the atom
niche and converts its initializer; the reassignment is a second store into that cell, and it
still writes the box (or a value typed for it) where the niche expects the atom. The record twin
fails the same way at the `nulvariant` cell of [D3107](D3107.md).

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| no reassignment (`let c = v; print(skn(c))`) | runs, prints `a` | **yes** (the store) |
| `let c: K \| null = v` | runs, prints `N` | **yes** (the un-annotated binding) |
| `c = "b"` instead of `c = null` | the same invalid module | no |
| `Circle \| null \| string` narrowed by `!(v is string)`, `c = null`, then `g(c)` | invalid module inside `t`, `expected (ref null $type)` | no (the record twin) |

#### Grading list

Both reassigned values (`null` and a member), the record twin, and an assignment inside a
closure that captures `c`.
