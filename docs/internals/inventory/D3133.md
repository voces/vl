### D3133 — an un-annotated `let` of a value narrowed to `K | null` out of a box, then reassigned, is invalid wasm

**closed · an un-annotated binding that took a narrowed cell names no union box, so a later store writes that cell's rep · fixture `tests/cases/unions/narrowed-nullable-copy-reassign.vl` · was check-clean invalid wasm · clause 1 · found by the #3279 review (`rv3279-28945/p/u9.vl`) · the same on master `a29230611` · filed 2026-09-28 against master `a29230611`, closed 2026-09-29 against master `07d414042`**

Repro:

    type K = "a" | "b"
    function skn(k: K | null): string {
      if k == null { return "N" }
      return k
    }
    function t(v: K | null | i32) {

        let c = v
        c = null

Want:

    N

#### Mechanism

`emitAssign` boxes a store whenever `unionNameOfIdentAt` names a union for the target, and for an
un-annotated `let` that is `letUnionNameOf`, which read the initializer's union: the wide box
`K | null | i32`. The cell was the atom niche ([D3118](D3118.md)), or for the record twin the
`nulvariant` niche ([D3107](D3107.md)), so `c = null` stored a box into it.
`letInitBindsNarrowedCell` (`emit_classify.vl`) names every narrowed cell an un-annotated binding
can take (the arm, its nullable niche, the `K | null` atom niche, the softened `string`), and
`letUnionNameOf` answers "" for one, so the store takes the cell's own seed.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| no reassignment (`let c = v; print(skn(c))`) | runs, prints `a` | **yes** (the store) |
| `let c: K \| null = v` | runs, prints `N` | **yes** (the un-annotated binding) |
| `c = "b"` instead of `c = null` | the same invalid module | no |
| `Circle \| null \| string` narrowed by `!(v is string)`, `c = null`, then `g(c)` | invalid module inside `t`, `expected (ref null $type)` | no (the record twin) |

#### Grading list

Both reassigned values (`null` and a member), the record twin, and an assignment inside a
closure that captures `c`.
