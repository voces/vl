### D16218 — a record parameter the width rewrite made generic hovers as the rewrite's own type parameter

**closed 2026-11-15 · runs, prints `2` · was an editor hover naming `__W0` for the parameter, the function and its calls · closed by printing the parameter's row slot as its record (`tvSlotSet`, `check_row_param.vl`) · found by lane I in L3 PR A · filed 2026-11-15 against master `3d526470a`**

Repro:

    type P = { y: i32 }
    type W = { x: i32, y: i32 }
    function f(p: P): i32 { return p.y }
    const w: W = { x: 1, y: 2 }
    print(f(w))
    // hover over `p`: `__W0`; over `f`: `(p: __W0) => i32` (before the close)

Want:

    2

#### Mechanism

The record-width rewrite (D3992) re-checks `f` as `f<__W0>(p: __W0)`. The checker types the
parameter by that type parameter, and the editor's hover prints whatever the binding holds. The
rewrite now gives the parameter a row slot bound by `P` and printed as `P`, so every reader of
the type names the record.
