### D3383 — a lambda capturing a `const` of a module-scope `if` value block calls an unknown function

**loud emit reject · clause 2 · open · found building the [D3073](D3073.md) adapter · the same on master `3291e99e1` · filed 2026-09-30 against master `3291e99e1`**

Repro:

    function mk(): () => i32 { return () => 5 }
    const v: () => i32 = if true { const fv = mk(); () => fv() } else { mk() }
    print(v())
    // vl check: rc 0.  vl run: emitProgram: call to unknown function

Want:

    5

#### Mechanism

Not localised past the ablation. The `const` lives in a block of a module-scope value `if`, and
the lambda calls it as a captured function value. Inside a function the same program runs, so
the module frame's capture of a block-scoped binding is the ingredient. The adapter avoids this
shape by passing the value as a lambda parameter instead.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the same statement inside a function body | runs, prints `5` | **yes** (module scope) |
| `((fv: () => i32): () => i32 => (): i32 => fv())(mk())` | runs, prints `5` | **yes** (a block `const`) |
