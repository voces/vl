### D15040 — an empty `Set()` handed to a type parameter nothing else types pins the parameter at `i32`

**now a loud emit reject · clause 2 · was check-clean invalid wasm until the pin cascade lost its `i32` catch-all (D23, 2026-11-07) · the set twin of [D1887](D1887.md) · filed 2026-11-02 against master `e10fcca1d`**

Repro:

    function one<B>(b: B) { [b].length }
    print(one(Set()))
    // vl check: rc 0.  vl run: emitProgram: monomorphize: unsupported argument type for `b` in a call to `one`

Want:

    1

#### Mechanism

The argument's type is a set whose element is a hole. The pin cascade has no spelling for it:
it used to floor it to `i32` while the call site built a set, and now refuses at the call.
D1887's close pins an empty `Map()` at the map it is built at. It leaves a set out, because a
set's emit spelling carries no set flavour, so the spelling alone cannot name the set the call
site builds.
