### D15040 — an empty `Set()` handed to a type parameter nothing else types pins the parameter at `i32`

**check-clean invalid wasm · clause 1 · the set twin of [D1887](D1887.md) · filed 2026-11-02 against master `e10fcca1d`**

Repro:

    function one<B>(b: B) { [b].length }
    print(one(Set()))
    // vl check: rc 0.  vl run: the emitted module failed to validate in the module's top-level code

Want:

    1

#### Mechanism

The argument's type is a set whose element is a hole, and the pin cascade floors it to `i32`
while the call site builds a set. D1887's close pins an empty `Map()` at the map it is built
at. It leaves a set out, because a set's emit spelling carries no set flavour, so the
spelling alone cannot name the set the call site builds.
