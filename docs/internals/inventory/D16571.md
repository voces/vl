### D16571 — a list literal holding a record of a generic function name, spread into a push in a generic body, is built at one instance only

**check-clean invalid wasm · `type mismatch: expected (ref $type), found i32` · clause 1 · open · found beside [D16235](D16235.md) · filed 2026-11-15 against master `4b8e8d264`**

Repro:

    function id<T>(x: T): T { return x }
    function run<T>(x: T) {
      const rs: {f: (x: T) => T}[] = []
      rs.push(...[{ f: id }])
      return rs
    }
    print(run(3)[0].f(3))
    print(run("ab")[0].f("ab"))
    // vl check: rc 0.  vl run: invalid module, type mismatch: expected (ref $type), found i32

Want:

    3
    ab

#### Mechanism

Not traced past the ablation. Only the second instance breaks, and it breaks at emit. So the spread
source's record field `id` is built once for every instance: one instance's emitted adapter or
reference is read where the other instance's field type is wanted. A pushed record (D16235) is
delivered per instance. The same record as a spread element is not.
