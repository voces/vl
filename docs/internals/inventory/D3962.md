### D3962 — a `let` seeded with an alias of a generic function and written with another generic builds invalid wasm

**closed 2026-10-11 by lane SC (D3979) · runs · was check-clean invalid wasm · clause 1 · found by the D3960 matrix (`alias_match_*`, `alias_generic_*`, 50 cells) · filed 2026-10-10 against master `eb81bdd89`**

Repro:

    function inner<U>(u: U) { print("I"); print(u) }
    function other<V>(v: V) { print("O"); print(v) }
    function main() {
      const al = inner
      let k = al
      k = other
      k(1)
    }
    main()
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `main`

Want:

    O
    1

#### Mechanism

Not located. The written-let rung that instances the seed resolves a generic by name and does
not follow a `const` alias to it, so the binding keeps the generic's un-pinned type; with the
seed named directly the same program reaches D3961's trap instead.
