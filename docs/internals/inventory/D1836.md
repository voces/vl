#### Mechanism

The annotated face of this program is [D1835](D1835.md) and now runs. Dropping the three
annotations refuses instead, and earlier: the monomorphizer's argument reader does not see
`rs` as an array, so the instance is never minted and the emitter refuses by name.

The checker disagrees with that reading — it infers `rs` as `(i32[][] | null)[]` and emits a
`redundant type annotation` HINT on the annotated face saying so. The hint is the checker
agreeing about the TYPE; the monomorphizer needs the ARRAY-ness of the argument, and reads a
different producer to get it. So the annotation is rep-load-bearing while being reported
redundant, which is why D1835's fixture declares its three hints rather than deleting them.

Not measured yet: whether the reader is blind to the inferred type generally, or only to one
whose element is a nullable ref list. The plainest neighbouring spelling to run first is an
un-annotated `(i32[] | null)[]` — one nesting level down, which D1835's ablation shows is a
separate ingredient.
