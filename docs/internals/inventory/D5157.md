### D5157 — `is` over inline arms that differ only in a lone-literal field finds no arm

**loud emit reject · clause 2 · found closing D5143 · filed 2026-10-16 against master `9518cc8f5`**

Repro:

    type N = { tag: "a", v: i32 } | { tag: "b", v: i32 }
    function f(n: N): i32 { if n is { tag: "a", v: i32 } { return 100 } 1 }
    const x: N = { tag: "a", v: 1 }
    const y: N = { tag: "b", v: 1 }
    print(f(x))
    print(f(y))
    // vl check: rc 0.  vl run: emitProgram: `is` test but no union type declared

Want:

    100
    1

#### Mechanism

Both inline arms soften their lone literal to `string`, so they lay out as one record and the
emitter declares no union for `N` at all; the `is` has no row to test and no discriminant to
read. With a third arm (`| { w: i32 }`) the two softened arms share one row and the test
refuses with `` `is` names a type that is not a union variant ``, since
`armRowNameOfDeclaredMember` declines a row holding two members. A close needs the `is`
lowered as the row test plus a compare of the tag field's value. Naming each arm by an alias
runs, and so does `n.tag == "a"`.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| each arm named by an alias, `n is A` | runs, `100` `1` | **yes** |
| the test spelled `n.tag == "a"` | runs, `100` `1` | **yes** |
| a third arm `{ w: i32 }` | refuses, `is` names a type that is not a union variant | no |
