#### Mechanism

The parentheses are the deciding ingredient: `const k = id` runs, `const k = (id)` refuses, and
so does the direct call `(id)(3)`. The callee's parameter type reaches the emitter as an
un-instanced type-parameter hole (it is spelled ``), so whatever instances a bare function name
taken as a value does not look through the parentheses. That reading is from the ablation; the
rung's input has not been printed. A non-generic `id` refuses too, with a different clause
(no function value of type `(i32)=>i32` reaches the call), so it is not only the instancing.
