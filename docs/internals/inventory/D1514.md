`vl check` on the corpus case below · the seed is byte-identical, so no decision moved**

#### Mechanism

`collectAnonShapes` runs four mark passes over the `??`-merge family, and every question they
ask is keyed by a NAME. Each was answered by a fresh `while i < P.nodes.length` with a string
compare per node, and they NEST: `anonLeafCloSlotMark` asks `anonLeafParamFnTarget` of every
callback-typed parameter; that asks `anonLeafParamFnTargetAt` of every `Param` sharing the
name; that scanned every `Call` in the arena calling `anonLeafCallMayTarget`, which asks
`anonLeafOneDeclNamed` — itself a whole-arena scan — per candidate. Cubic in the node count,
and the count is the MERGED module's, so a program's own length says nothing about what it
pays. The compiler's own source declares no callback-typed parameter, which is why
`scripts/self-compile-time.sh` never saw it and `#2429`'s seven shape axes had no axis for it.

The fix is `anonLeafIxBuild`: one index, built once per program before the first mark pass,
holding the same nodes in the same ARENA ORDER — name to `FuncDecl` count and list, name to
its binding nodes, callee name to its calls, body node to its owning declarations, param name
to its (owner, position) slots, plus flags for callee position and for a name spelled as a
VALUE. Every reader takes a list by key instead of scanning. D1100's own two-column
declaration index answered the same two questions by linear scan and is folded in and deleted.

TWO PRUNES MAKE THE CALL-SITE LISTS SMALL, and both are exact rather than heuristic. A call
whose callee is declared exactly once can only target THAT name. And a WILD call — one through
a binding this cannot resolve from its spelling — can only reach a name that some `Ident`
spells outside callee position, because every non-empty answer the delivery resolvers give
comes from a write, an argument or a return expression, and none of those is a callee.

Neither import alone is slow: it is the merged module's callback-typed parameter count times
its node count. The corpus case that found it is
`tests/cases/literal-unions/litunion-order-cross-module-alias.vl` — 38 lines, `vl check`
0.08 s, `vl build` 7027 ms before and 31 ms after.

#### Grading list

* **The seed, byte for byte.** `compile(candidate, master's compiler source)` must equal
  `compile(master, master's compiler source)`: 2,046,160 bytes, identical. A pure re-indexing
  cannot move a decision, and the compiler's own emission goes through this family.
* **`tests/vl_scaling_shape_test.ts`'s `callback slots` axis** — N higher-order functions each
  taking a callback against N/K taking the same N callbacks over K call sites. 2.06 / 1.03 /
