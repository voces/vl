#### Mechanism

The `??` joins `N` with `f64`, so its pin is not `N`'s scalar base and the instance's
dead-default fold (`coalRetypedDead`, emit_classify.vl) declined; the fold returns the operand
unconverted. `coalRetypedDeadJoinIf` covers every instance whose operand is proven non-null but
whose pin differs: it builds `if true { l } else { d }` with the `??`'s pin as the `if`'s type,
so the `if`-join lowering converts the operand to the pin, a box or a wider scalar alike.
