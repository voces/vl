#### Mechanism

Once `Circle` is a member of a declared union, `Circle | null` reps as the `nulvariant` niche,
`(ref null $uVarHeap[vi])`, and `repSigTokOfKind` had no token for it, so `cloParamTok` keyed
"" and `emitClosureValueCore` refused. The kind now has the token `W` with a variant slot, folded
through `repVariantSlotRep` as `V` is (`repSigNulVariantTok`), minted by `cloParamTok`,
`cloRetKeySuffix`, the annotation name path (`annUnionSigKind`) and the arena path
(`paramTokOfTy`/`retTokOfTy`'s `TyNullable` arm). The arena arm matters: the name path renders
`Circle` as its field set, which keys the inline struct row as `nulstruct` against a lambda that
declares `nulvariant`. At a value call (`emitCallRef`) the `W` parameter seeds the arm's variant
index and a `null` argument's heap, and unboxes a value narrowed out of a box, the same three
seeds the direct call's argument rung gives it. A literal-union argument into a box
parameter (`K` into `K | i32`) stages its atom in the string-op frame, which
`callWidensAtomToStr` now reserves for any box parameter of a value call. Before, the frame was
reserved only for a `string` parameter, so the box build wrote to a local the function never
declared. This was unreachable on master for an inline union, because the union was never
registered ([D3075](D3075.md)); 27 cells of the #3273 review, fixture
`tests/cases/closures/value-call-literal-into-box-param.vl`.
