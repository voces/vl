### D3074 — a function value whose parameter is a nullable union arm (`Circle | null` with `Circle` a member of `Shape`) has no function-value signature

**loud emit reject · clause 2 · 25 cells of the lane-LP lambda grid carry this refusal (a message count), and 17 more of its `Circle | null` cells fail otherwise and are not ablated: 14 `ref valtype with no interned shape`, 11 from a value narrowed out of `Circle | null | string` and 3 from an un-annotated parameter pinned from a walk, and 3 validation failures from a narrowed walk variable · the same on master `67ca68cf3` · filed 2026-09-28 against master `67ca68cf3`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    const f = (w: Circle | null) => w == null
    print(f(null))
    // vl check: rc 0.  vl run: emitProgram: a function value's signature is not yet supported —
    // parameter `w` of type `Circle|null` has no representation in the function-value ABI

Want:

    true

#### Mechanism

Not investigated past the ablation. Once `Circle` is a member of a declared union, `Circle | null`
reps as the nullable-variant niche, and the function-value ABI has no signature token for that
rep. [D2414](D2414.md) and [D2718](D2718.md) are the same gap for a nullable record list result
and a nullable map parameter.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| no `type Shape = Circle \| Sq` | runs, prints `true` | **yes** (a union arm) |
| a named `function g(w: Circle \| null)` called directly | runs | **yes** (a function value) |
| `const f = g` for that named function | the same refusal | no |
| the parameter un-annotated, pinned from a walk over `(Circle \| null)[]` | loud emit reject, `ref valtype with no interned shape` | not ablated |
