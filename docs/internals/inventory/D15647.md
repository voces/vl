### D15647 — a choice of `boolean`-returning hole functions in a record literal builds invalid wasm where any `(i32) => i32` type is written

**closed 2026-11-10, runs and prints `true` `true` · was check-clean invalid wasm, clause 1, `the emitted module failed to validate inside \`callP$1\`: … type mismatch: expected i32, found f64` · found closing D15642 · filed 2026-11-10 against master `ee66b4ec` · closed in the elaboration: a call through a record field of a parameter bound to a record holding a set of hole functions mints each member's instance at the call's argument types where none exists yet (`elabMintParamRowFactAt`, emit_elab.vl), as it already did for a lambda, so the fact is noted, the late decision tags the set and the call dispatches by tag · the `odd` spelling runs and prints `true` `false` · `callP`'s instances test the id and call each member's instance directly in the repro's `--names` build, no `call_indirect` · fixture `functions/set-of-boolean-fns-in-record-handed-to-hole-callee.vl`**

Repro:

    function keep(f: (i32) => i32) { print(f(1)) }
    function pos(v) { return v > 0 }
    function big(v) { return v > 1 }
    function callP(r, x) { print(r.f(x)) }
    function run(b) {
      const g = if b { pos } else { big }
      callP({ f: g }, 3)
      callP({ f: g }, 2.5)
    }
    run(false)

Want:

    true
    true

#### Mechanism

Without `keep`, this is [D15644](D15644.md): the field call refuses because no function value of
its signature is interned. `keep`, never called, writes a closure type of the same wasm
signature (`boolean` and `i32` are both an `i32`), so the guard finds one, the set stays a
closure record, and `callP`'s `f64` instance calls it at `f64`. The guard tests that a
signature exists, not that this call's value has it.

Measured at the close: `elabMintParamRowFactAt` found no instance of the member at the field
call's argument types (no direct call reaches `(f64)`), so it noted no fact and the set stayed
a closure; the numeric spelling had such an instance from another route.
