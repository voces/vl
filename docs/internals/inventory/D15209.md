### D15209 — a function returning two list literals of records holding different un-annotated functions is refused at emit

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function pick(b: boolean) { if b { return [{ f: inc0 }] } return [{ f: dbl }] }

#### Mechanism

Each literal is built at its own row, keyed by its element's function set, so the returned values name two rows; the result's recorded row (`fRetRListRow`, [D15203](D15203.md)) is "no single row" and the type section refuses by name. The fix is a row that holds both records, not a stamp read.
