### D15209 — a function returning two list literals of records holding different un-annotated functions is refused at emit

**loud emit reject · `emitProgram: ref valtype with no interned shape` · clause 2 · open · one literal holding both functions (`[{ fs: [inc0, dbl] }]`) runs since [D15203](D15203.md) · found closing [D15203](D15203.md) · present on master `ee1ab028` · filed 2026-11-03 against master `aaf9ba5c`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function pick(b: boolean) { if b { return [{ f: inc0 }] } return [{ f: dbl }] }
    print(pick(false)[0].f(3))

Want:

    6

#### Mechanism

Each literal is built at its own row, keyed by its element's function set, so the returned values name two rows and the result reads neither. The fix is a join of the two rows, not a stamp read.
