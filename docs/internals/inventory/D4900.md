### D4900 — a hole function joining `return [t]` with a tail `[1]` is typed as the `i32` list at an `f64` pin

**check-clean invalid wasm · clause 1 · found grading D4889's positions · identical on master `687f37dd5` · filed 2026-10-15**

Repro:

    function w(t, b: boolean) {
      if b { return [t] }
      [1]
    }
    print(w(2.5, true)[0])
    // vl check: rc 0.  vl run: invalid module inside `w`: type mismatch: expected (ref $type), found (ref $type)

Want:

    2.5

#### Mechanism

The instance is emitted as `(param f64 i32) (result (ref $3))` with `$3` the `i32` list, and
the returned `[t]` is an `f64` list. The literal `[1]` adapts to `f64` in the `<T>` face, so
one of the two faces records the tail's own `i32[]` as the join where the other adapts it.
