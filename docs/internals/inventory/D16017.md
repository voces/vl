### D16017 — a map entry write used as a value has no value lowering

**closed · runs, prints `9` `9` · was loud emit reject, clause 2 · fixed 2026-11-14: a map entry write used as a value yields the value its set stashes · residue of [D16015](D16015.md) · filed 2026-11-14 against master `c2e3dca0a`**

Repro:

    const m = Map()
    m["a"] = 1
    let k = "a"
    print(m[k] = 9)
    print(m["a"] ?? 0)

Want:

    9
    9

#### Mechanism

A map store (`emitMapSet`) scans for the key and writes or appends the value; it parks no value
the assignment could yield, and a re-read would scan again with a key that may have an effect.
D16015's parked-cell rung covers list elements and fields only.

#### Closed (2026-11-14)

A set evaluates its value once, before the probe, and keeps it in the set's value stash (an mv
slot's own local, else the map frame's slot 14). When the assignment's value rung asks, the set
keeps it there on both paths, tees it ahead of a per-shape store helper's call, and records the
stash as the parked value (`mapSetParked`). The index store that ran the set owns that park. The
rung compares a map entry's type by the map's value type, since a read of the entry is that type
or `null`. Graded on `scripts/capability-probes/matrix/map-write-value.matrix.vl`: 0 of 50 to 50 of
50, 0 silent. Hand cells:
- string-, `f64`- and record-valued maps run;
- `f(m[k] = 7, m[k] ?? 0)` prints `77`;
- `m[k] = xs[i] = 6` runs;
- two writes in one expression run.

A union- or nullable-valued map's entry stores a value typed apart from the assignment's: that is
[D16016](D16016.md).
