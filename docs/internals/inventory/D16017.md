### D16017 — a map entry write used as a value has no value lowering

**loud emit reject · clause 2 · residue of [D16015](D16015.md) · filed 2026-11-14 against master `c2e3dca0a`**

Repro:

    const m = Map()
    m["a"] = 1
    let k = "a"
    print(m[k] = 9)
    print(m["a"] ?? 0)

Want:

    9
    9

#### Mechanism

A map store (`emitMapSet`) scans for the key and writes or appends the value; it parks no value
the assignment could yield, and a re-read would scan again with a key that may have an effect.
D16015's parked-cell rung covers list elements and fields only.
