Repro:

    function id<T>(x: T): T { x }
    function inc(x: i32): i32 { x + 1 }
    function run<U>(a: ((x: U) => U)[], u: U): U { a[1](u) }
    print(run([id, inc], 2))
    // vl check rc 0.  vl build: internal: a parameter type the valtype ladder has no rung for

#### Mechanism

The argument binds `U` to `id`'s own type variable (first use wins, as in
[D10150](D10150.md)), so the instance of `run` emit builds has a parameter type still carrying
a type variable. A bare open function argument was already bound after the others
(`argOpenMeetsTyVar`); a list literal holding one was not.

| `inc` first, `run([inc, id], 2)` | runs, `3` | **yes** |
