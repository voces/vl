#### Mechanism

Not located. The binding, argument and return positions are copied through `fvaListSetCopy`
(D15069). These five deliver the same list twice, or through a record or list literal, and one
of the reads is not rewritten, so the list's holder declines the set and it stays one closure
called at two types. The same happens when one program both copies a list of the set at the top
level and hands the set to a hole parameter that lists it (D15131's shape): the hole parameter
keeps the set closures and the top-level copies need it tagged.
