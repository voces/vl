### D16425 — a bound list of records with an empty list field, handed to an un-annotated parameter whose body pushes another such record, builds the body's field at its own element

**closed 2026-11-15 — the witness runs and prints `0.5` · was: check-clean invalid wasm, clause 1, then a loud check reject (D16427's refusal) · the argument written at the call runs (D16422) · found grading D16422's close · filed 2026-11-15**

Repro:

    function t(a) {
      a.push({ ys: [] })
      a[0].ys.push(0.5)
      print(a[0].ys[0])
    }
    const l = [{ ys: [] }]
    t(l)
    // vl check: rc 0.  vl run: invalid module inside `t` (as filed)

Want:

    0.5

#### Mechanism

A binding's list is not a pin row at the call, so the body's pushed `{ ys: [] }` met nothing and
kept an element of its own, which built an invalid module. Since this row's first close, a record
a deferred push delivers into a bound list's record element shares its open list fields
(`tyLinkRecLists`, in `cnhPinBmElem`'s not-a-pin-row arm). A caller's later write to `l[0].ys`
or `l[1].ys` now runs. The body's own write is checked by `checkCalleeWrites` against the list's
final element, which was the body literal's default, so it was refused: [D16427](D16427.md)'s
family. D16427's close pins that inner list at scope close, and the witness runs.
