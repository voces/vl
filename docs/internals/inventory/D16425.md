#### Mechanism

A binding's list is not a pin row at the call, so the body's pushed `{ ys: [] }` met nothing and
kept an element of its own, which built an invalid module. Since this row's first close, a record
a deferred push delivers into a bound list's record element shares its open list fields
(`tyLinkRecLists`, in `cnhPinBmElem`'s not-a-pin-row arm). A caller's later write to `l[0].ys`
or `l[1].ys` now runs. The body's own write is checked by `checkCalleeWrites` against the list's
final element, which is the body literal's default, and refused: [D16427](D16427.md)'s family.
