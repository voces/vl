#### Mechanism

#3211's return-set rule keeps a type parameter's list apart from a concrete one by joining the
return values one by one (`joinRetTys`), and a returned `if` contributes each arm; a returned
`match` contributes its own value, which the body typed as the collapse (`string[]` here), so the
call reads one list. D2832's re-check now refuses the call instead of building it. The predicted
close is to seed the return set with the match's apart join (`tpIfJoinAt`), as the arms of an
`if` are, so the call re-joins it at each pin; the `.length` above is then refused in the concrete
spelling's words, and an `is` read runs.
