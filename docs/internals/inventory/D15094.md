### D15094 — a record literal inside a binding's literal, wider than a union arm of its field, is refused

**closed · runs, prints `1` then `4` · was a loud check reject, clause 2 · the inner literal is built at its own row, which declares the arm's row its supertype (#5956), and boxed under the arm's tag at the field store; the check refuses only a literal whose arm fields are not the first of its own · the drop-only twin of D3566, whose own witness also widens a field (D15093) · filed and closed 2026-11-03 against master `464e83ad7`**

Repro:

    type A = { k: i32, legs: i32 }
    type B = { s: string }
    type Pet = A | B
    type Box = { pet: Pet }
    let n = 0
    function f(): boolean { n = n + 1; return true }
    function mk(): Box {
      const sv = { pet: { k: 1, legs: 4, purr: f() } }
      return sv
    }
    const b = mk()
    print(n)
    const p = b.pet
    if p is A { print(p.legs) }
    // was: vl check rc 1, "an object value of shape {k: i32, legs: i32, purr: boolean} flowing
    // into A (reached through {pet: …} into Box) drops the field `purr`"

Want:

    1
    4

#### Mechanism

The record solve builds `sv` at `Box`, so its inner literal is a field value of `Box.pet`, a
union none of whose arms declares `purr`. `recBuildArmDropRefuse` refused every such literal. Its
own row `{k, legs, purr}` already declares arm `A`'s row its WasmGC supertype (#5956's
`armSuperOf`), so the literal is built at that row and boxed under `A`'s tag
(`emitUnionWideArmBox`, which skipped every object literal and now skips only one naming an arm).
A literal whose arm fields are not the first of its own (`{a, k, legs}`) has no such edge and is
still refused.

#### Ablation

| variant | outcome |
| --- | --- |
| this witness, before the close | refused |
| `legs: i64` in `A` (a widening too) | refused, D3566 / D15093 |
| `{ a: true, k: 1, legs: 4 }` (arm fields not a prefix) | refused |
| `const sv = { k: 1, legs: 4, purr: f() }` delivered as `Pet` (#5956) | runs |
