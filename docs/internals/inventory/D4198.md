### D4198 — an `if` join enters a place at a narrowing taken inside one of its arms

**closed 2026-10-12 by lane CK · runs · was check-clean silently wrong (`wrap`) · clause 1 · found building D4059 (the native fixpoint's stage 4 refused `d as f64` once `n.asMode == "wrap"` narrowed) · filed 2026-10-12 against master `0bf4c3bb6` · pins: `tests/cases/literal-unions/arm-join-enters-at-head.vl`**

Repro:

    type Mode = "prop" | "wrap"
    type Cast = { mode: Mode }
    let nodes: Cast[] = []
    function note() {
      if nodes.length > 0 { nodes[0].mode = "prop" }
    }
    function f(n: Cast, flag: boolean): string {
      if flag {
        if n.mode is "wrap" {
          note()
          return "early"
        }
        return "flag"
      }
      if n.mode is "wrap" { return "wrap" }
      "prop"
    }
    print(f({ mode: "prop" }, false))
    // vl run: prints prop

Want:

    prop

#### Mechanism

`applyArmJoins` (`compiler/typecheck.vl`) started a place the condition does not test at its
first ledger row's before-type. When that row sits under a narrowing taken inside the arm (the
inner `is` here), the before-type is the narrowed member, so the fall-through path of the outer
`if` was joined as though it held `"wrap"` too, and the later `is "wrap"` folded to true. The
join now reads the place as it stood at the `if`'s head: in-place retirements and path
invalidations go through a journal (`narSetScope`/`narSetInv`) that `narHeadTy` undoes and redoes.

#### Ablation

| variant | outcome before |
| --- | --- |
| as filed | prints `wrap` |
| no `note()` call | prints `prop` |
| no `return "flag"` | prints `prop` |
| `note()` prints instead of writing the path | prints `prop` |
| outer `while` instead of `if` | prints `prop` |
| a bare `let m: Mode` with `m = "wrap"` in place of `note()` | prints `wrap` |
| the write after an exiting guard in the arm, arm falls through | refused: "m is always "prop" here" |

#### Grading list

A path and a bare name; a call and a write as the row; the arm diverging and falling through.
