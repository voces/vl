### D4614 — a tagged inline union arm loses its record type at the discriminant narrow when a declared record of the same shape is an arm of another union

**closed · runs · closed by the slice that reads a field's receiver narrowing from the checker's narrowed-read fact instead of the emitter's name stack · was loud emit reject · clause 2 · found writing D4601's fixture · filed 2026-10-14 against master `56e06d91c`**

Repro:

    type U = { kind: "a", q: i32 } | { kind: "b" }
    type A = { kind: "a", q: i32 }
    type N = A | { kind: "c" }
    const m: U = { kind: "a", q: 5 }
    if m.kind == "a" { print(m.q) }

Want:

    5

#### Mechanism

The narrow `m.kind == "a"` resolves the arm of `U` through a row keyed by the arm's shape, and
the named `A`, registered as an arm of `N`, holds that shape under its own name, so the read of
`m.q` finds no struct for the narrowed binding. D1473's close covered the inline arms alone.

#### Ablation

| --- | --- | --- |

| the field read (`print(m.kind)`) | runs | **yes** |
| the tag's value (`"zz"` for `"a"`) | still refuses | no |
