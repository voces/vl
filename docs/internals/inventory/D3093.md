### D3093 — a module-scope list literal re-seated at a `readonly Shape[]` destination's row is read at its own element's row

**closed · `refListElemNameOfExpr` names a ref-list global by the row its cell was declared at, as a local names its slot's · fixture `tests/cases/arrays/readonly-record-view-inferred-global.vl` · was check-clean invalid wasm · clause 1 · 73 cells of the #3271 review's grids · the un-annotated face of [D3059](D3059.md)'s fixture · the same on master `505bb44e0` · filed 2026-09-28 against master `505bb44e0`, closed 2026-09-28 against master `e1e40ac99`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    function rd(r: readonly Shape[]) { return r.length }
    const l = [{ r: 1 }]
    print(rd(l))
    l.push({ r: 2 })
    print(rd(l))
    // vl check: rc 0.  vl run: invalid module in the top-level code: type mismatch

Want:

    1
    2

#### Mechanism

An un-annotated list literal bound to a declared destination is built at the destination's row
([D381](D381.md)'s `letRefListDestSlot`), so `l` is a `Shape[]` of boxes, and its global cell
says so. The push resolved the receiver's row through `refListElemNameOfExpr`, whose global arm
read the literal's own element spelling, `{r: i32}`, and pushed a bare `Circle` into a list of
boxes. A local is read through its slot's recorded row, so the same program in a function ran.
The global arm now asks the cell's own row (`letRefListSlot`) first.
