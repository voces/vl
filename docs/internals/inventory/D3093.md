### D3093 — an inferred record-literal list delivered as `readonly Shape[]` and then written is invalid wasm

**check-clean invalid wasm · clause 1 · 73 cells of the #3271 review's grids · the un-annotated face of [D3059](D3059.md)'s fixture · the same on master `505bb44e0` · filed 2026-09-28 against master `505bb44e0`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    function rd(r: readonly Shape[]) { return r.length }
    const l = [{ r: 1 }]
    print(rd(l))
    l.push({ r: 2 })
    print(rd(l))
    // vl check: rc 0.  vl run: invalid module in the top-level code: type mismatch

Want:

    1
    2

#### Mechanism

Not investigated past the ablation. [D3059](D3059.md) views a written fresh literal whose binding
is annotated `Circle[]`. Without the annotation the literal's element is the inferred shape
`{r: i32}`, and the delivery reaches the view with a source row the view was not minted for.
