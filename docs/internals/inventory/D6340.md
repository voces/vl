#### Mechanism

From the ablation only. A `function mk() { return k }` maker is followed to the binding its
result initializes, so the call `a(1)` pins `k`. A lambda maker is not followed, so `k` meets
no call that fixes its type. Nothing about instances is involved: one call at one type refuses.
