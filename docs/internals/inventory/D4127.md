### D4127 — an un-annotated list of a generic function, used other than for its length and never called through, refuses at emit

**closed 2026-10-19 by lane L1 · runs, prints `9` · was loud emit reject · clause 2: `vl check` is clean · the value-flow question follows a `for` over the list to its loop variable, and an unread one reaches no call, so the element is not a value needing a signature · pins: `tests/cases/closures/list-of-generic-iterated.vl` · found closing [D4123](D4123.md) · filed 2026-10-11 against master `efd3c3f15`**

Repro:

    function inner<U>(u: U) { print(u) }
    const fs = [inner]
    for f in fs { print(9) }
    // vl check: rc 0.  vl run: emitProgram: a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type

#### Mechanism

From the ablation. Nothing calls through the list, so nothing instances `inner` and the element
is the pruned stub. [D4123](D4123.md) admits a stub value only where its readers cannot call
it: a binding read only for `.length`, or a binding write. A loop variable, a return value and
an alias are uses that rule does not follow, so they are refused. On master the loop, the alias
and `mk().length` built a module no engine parses or validates; `const fs = mk()` was already a
loud emit reject, `ref valtype with no interned shape`.
