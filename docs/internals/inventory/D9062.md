### D9062 — an un-annotated `Map()` written as a record field's literal, then given an un-annotated function through the field, has no value slot

**loud emit reject · `vl check` rc 0 · `emitProgram: map value type has no interned slot` · clause 2 · found closing [D4579](D4579.md) and [D9040](D9040.md) · present on master `16cf779bd` · filed 2026-10-21 against master `16cf779bd`**

Repro:

    function inc0(a) { return a + 1 }
    const r = { m: Map() }
    r.m["k"] = inc0
    const x = r.m["k"]
    if x != null { print(x(3)) }
    // vl check rc 0.  vl run: emit error: emitProgram: map value type has no interned slot

#### Mechanism

Not traced. The D9040 close types a map from the writes to its own binding
(`monoPinMapValues`, emit_mono.vl); this map has no binding, only the record field
`m`, so its value type stays the function's hole signature.

| ingredient removed | outcome | needed? |
| --- | --- | --- |

| the record (`const m = Map()`, `m["k"] = inc0`) | runs, `4` | **yes** |
