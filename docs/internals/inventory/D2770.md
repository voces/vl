### D2770 — a lambda whose un-annotated parameter is the callee, called from inside another lambda, is a call to an unknown function

**loud emit reject (`emitProgram: call to unknown function`) · 189 cells of the #3207 round-2 review's grid · filed 2026-09-27 against master `f6db92e0d`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    function sum(xs: Shape[]): i32 { xs.length * 3 }
    function f() {
      const out = [{ r: 3 }]
      const ap = (g) => g(out)
      const run = () => ap(sum)
      print(run())
    }
    f()

#### Mechanism

`ap` is specialized per callback at the call that hands it one, and the call `ap(sum)` inside
`run` is not one the specialization reaches: the call to the un-annotated parameter `g` inside
`ap` is left with no function to call. Not yet localised further.
