#### Mechanism

A call to a recursion-group member whose return is not yet published records `TY_ERR` and is
queued (`selfCallPendIx`) to be re-recorded once the member publishes (`selfCallsRecordAt`). Only
the call node is re-recorded: a node whose type was derived from it while it was `TY_ERR` — the
binary it is the left operand of, a unary over it, a `const` it initialises — keeps the type it
was given then. Legacy emits from the operand types and runs; the IR shadow reads the recorded
type and fails verification or refuses the rep. The member-call spelling shares this since D17073.
