#### Mechanism

`b = a` is checked while both maps are open, so it is noted as a link, not judged.
`b["k"] = 1` then pins `b`'s value to `i32` and `a["j"] = "s"` pins `a`'s to `string`. The
link resolution only fills an open side, so it never sees two closed sides that disagree,
and `b = a` stands between two different map types. The direct annotated twin
(`let a: {[string]: string}`, `let b: {[string]: i32}`, `b = a`) is refused at check, so the
design owes this one the same refusal at the link, as D3742's recommendation put it.
