#### Mechanism

`tyHasTyVar` answered `true` once it ran out of depth (12), so a pin twelve maps deep read as
still holding a type variable. The explicit type argument was dropped from the instance's
bindings, the parameter's union `P | string` was never registered, no union box type was minted,
and the body's `struct.get $box` read type 0, a list. Three more walks had the same cliff at
sixteen levels: `tySameSet` (answered "different"), `tyCanonKey` (keyed by the lossy render) and
`tyToStr` (rendered `…` past nine). Each now reads an acyclic type whole and cuts only a type it
is already inside, with a far cap (256) as a backstop. The lane's ladders print the right values
at every depth from 1 to 19.
