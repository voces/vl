### D10702 — a hole-function loop inside a generic, handed a lambda, is refused beside another call handed a lambda

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: a neighbouring spelling runs (the ablation) · found closing [D7846](D7846.md) · present on master `d23840b00` · filed 2026-10-23 against master `d23840b00`**

Repro:

    function apply2(g) { print(g(1, 2)) }
    function apply3(g) { print(g(10, 20)) }
    function gen<T>(x: T) {
      const gs = [apply2, apply3]
      for f in gs { f((a, b) => a + b) }
    }
    gen("z")
    function v2() {
      apply2((a, b) => a * b)
    }
    v2()
    // vl check: rc 0.  vl run: emitProgram: a function value's signature is not known at this call — the type it was given takes fewer parameters than the call passes

Want:

    3
    30
    2

#### Mechanism

Not traced. The message is the `g(1, 2)` call inside an instance of `apply2`: the type that
instance's `g` was given takes fewer parameters than two. The error position the emitter reports
is the program's last statement, not that call.
