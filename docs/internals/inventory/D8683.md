### D8683 — a record literal handed to a hole beside a union member of its field names takes a declared record that boxes the field

**check-clean invalid wasm · clause 1 · open · present on master `a0af58b15` · found closing [D8620](D8620.md) · filed 2026-10-20 against master `a0af58b15`**

Repro:

    type J = { r: i32 }
    type N = { r: i32 | null }
    const a: J | string = { r: 5 }
    function take(b) { return b.r + 1 }
    print(take({ r: 7 }))
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `take`: expected i32, found (ref $type)

Want:

    8

#### Mechanism

With `J` a member of a union, the literal `{ r: 7 }` is built at `N`, which boxes `r`, and
`take`'s instance returns a box where its body adds an `i32`. D8620's close refuses `N` for a
literal whose field a hole reads, and this literal is still built there, so the row is chosen
on a path that close does not reach, one that runs when the exact record is a union member.
Not yet traced past that.

| `take(b: { r: i32 })` | prints `8` | **yes**, the hole |
