#### Mechanism

The annotation closes the record's function field at `(a: i32) => i32`, but the
literal sits in `deliver`'s return, where nothing delivers that signature to it: no call reaches
`inc0`, so mono emits the template's closure: its returned-literal coercion read the literal's
open checker type. The close stamps the literal at the one closed type every call of its function
is delivered to, and mono reads that stamp. A literal whose calls hand it to a hole parameter (the
D9952 records) keeps its rep, since each instance keys its pinned row.
