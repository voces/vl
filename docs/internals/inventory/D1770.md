### D1770 — a user-defined binary operator dispatched only in a SINGLE-FILE program, because both the checker's and the emitter's lookups asked the UNMANGLED name a merge had renamed

**closed 2026-09-06 — the witness prints `3` · was a loud check reject,
`operator '+' is not defined for V and V` · clause 2 · ROADMAP A-OPMOD, ranked first in the
2026-09-06 re-grade · probe
`scripts/capability-probes/operator-dispatch-under-std-import.vl` · fixture
`tests/cases/modules/operator-dispatch-under-import/entry.vl`**

Repro:

    import { toString } from "std:fmt"
    type V = { x: i32 }
    function "+"(self: V, b: V): V { return { x: self.x + b.x } }
    const a: V = { x: 1 }
    const b: V = { x: 2 }
    print(toString((a + b).x))
    // vl check: rc 0.  vl run: prints 3.

Delete the import line and the identical program always printed `3`; keep it and the checker
said `operator '+' is not defined for V and V`. **Any** import does it — the roadmap only ever
demonstrated a LOCAL one, and `std:fmt` reaches nearly every real program.

#### Mechanism

A merge renames every declaration, appending `$m<N>`. An operator SITE is `a + b`, which
carries no name a merge could rewrite, so both lookups asked the plain spelling.

**Instrumented, because the roadmap's attribution was explicitly inferred.** A probe in
`opSelfFnTy` printing the key it asks, the keys `fnDeclIx` holds, and each key's own answers:

| face | key length | that key's `declIx` / `lookup` | `lookup("+")` |
| --- | --- | --- | --- |
| single file | 1 | 11 / 46 | 46 |
| local import | **4** | 18 / 49 | **-1** |
| `std:` import | **4** | 3667 / 492 | **-1** |

The declaration is present and typed under its mangled key — length 4, which is `+` plus
`$m0` — and only the unmangled ask misses. The roadmap's attribution is confirmed in
substance; the first reading of the probe was not, since the key RENDERS as `+` and only its
length settles it.

Two lookups, one per phase, and both had to move or the fix ships a clause-1 miscompile:
`opSelfFnTy`'s `lookup(op)` in the checker, and `emit_rewrite`'s `drwSelfFnOf(n.binOp, 2)`
plus the `mkIdent(n.binOp)` it builds the call with. Lifting only the checker's produced
`check`-clean **invalid wasm** at every face — measured, not predicted, and the reason the
emit half is in the same change.

Both now resolve through **one** resolver. `ufcsMergedDeclOf` was already that resolver for
the UFCS `self`-name gate (D1654); it is renamed `mergedDeclKeyOf` for the general contract,
the operator lookup takes it, and the emit rewrite asks the same function rather than
re-deriving the answer over `fnStmts` — which would have been a whole-program scan per
operator site, the shape `arena-scan-outside-pass` refuses.
