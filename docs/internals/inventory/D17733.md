### D17733 — a binding holding an element of a list literal, delivered to a union, converts a box to the arm's record

**loud emit reject · 1 witness (b000858 reduced) · filed 2026-11-27 against master `d29f3434`**

Repro:

    type Circle = { r: i64 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    function rd() {
      const dd = [{ r: 7 }][0]
      const gp: Shape = dd
      print(if gp is Circle { gp.r } else { 0 })
    }
    rd()
    // vl check: rc 0.  vl run: emit error (convert box -> record)

#### Mechanism

The delivery to the union stamps the inline list literal at the arm, while the binding of its
element read is held as the union's box; the conversion from that box to the arm's record has no
lowering. The named-list spelling holds the binding at the list's built element and runs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the list literal, named first (`const xs = [..]; xs[0]`) | runs | **yes** |
| `gp: Shape` replaced by `gp: Circle` | runs | **yes** |
