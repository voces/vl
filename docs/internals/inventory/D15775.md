### D15775 — D15808's `if` of records bound to a `const` before it is handed to a `const` lambda is refused at emit, where a named function runs it

**loud emit reject · clause 2 · `emitProgram: this record `if` stores functions of different signatures in one field, and a call through the joined record is lowered at one of them` (#7517's floor; was `cannot take the generic function `half` as a value`) · the named-function spelling runs · found containing [D15808](D15808.md) · filed 2026-11-12 against master `96590b46`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function two() { [1, 2].length }
    const take = (r) => r.f(3)
    const q = if two() > 5 { { f: half } } else { { f: inc0 } }

    4

#### Mechanism

Unmeasured. `function take(r) { return r.f(3) }` runs this and prints `4`. The judgment at check
now reads the lambda's arguments through its `const` (D15808), and accepts the bound record as it
does for the named function, so the difference is downstream, where the record's functions are
pinned at the lambda's calls.
