### D16236 — a `for` straight over a generic maker's bound list of generic-function records loses the first instance's signature

**closed 2026-11-15 · runs, prints `3`, `ab` · was a loud emit reject, `a function-value call has no interned signature — no function value of type (i32) => i32 reaches this call`, clause 2, `vl check` rc 0 · found ablating [D16234](D16234.md) · filed 2026-11-15 against master `55151b054` · closed with D16234, whose mechanism it is with no write · fixture `generics/generic-maker-bound-list-of-generic-fn-records-walked.vl`**

Repro:

    function id<T>(x: T): T { return x }
    function run<T>(x: T) {
      const rs = [{ f: id }]
      return rs
    }
    for r in run(3) { print(r.f(3)) }
    for r in run("ab") { print(r.f("ab")) }
    // vl check: rc 0.  vl run: emit error at the first loop's call, no interned signature

Want:

    3
    ab

#### Mechanism

[D16234](D16234.md)'s: a generic instance's bound record-list literal was not built at the
instance's own slot fact, so both instances shared one element type and the `i32` call found no
closure of its signature. The filed ablation took its "runs" rows from an inline `return [{ f: id
}]` maker, not the bound local; re-measured with the bound local, below, only the ingredients
D16234 names decide it.
