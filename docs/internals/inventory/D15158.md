#### Mechanism

The refusal is `fbValtypeNullable`'s bounds guard, raised while `emitGlobalSection` writes the
global's cell, outside any statement or function body, so `emitFail` has no anchor. The
global's declaration is in hand there (`globalStmts[gi]`). The witness is
[D14082](D14082.md)'s since D15159's, D15391's, D15394's and D15395's run (2026-11-12); when that
closes, this row needs another refusal with no shape and no anchor.

#### Fix

`emitGlobalSection` (`compiler/emit_sections.vl`) arms `emitCurStmtIx` at each user cell's
declaration while it writes that cell, and clears it after the loop, as `collectU`/`collectS` do
for their declarations ([D1519](D1519.md)). Every refusal in that loop (the valtype guards, the
constexpr init) now names its cell. The row's earlier Want, the call `len(() => p)`, is where the
shape went missing, but the refused object is the cell, and no table in the section records the
call.
