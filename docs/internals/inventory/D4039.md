Repro:

    type Look = "knife" | "fork"
    type Alt = "none" | "spoon"
    function src(k: i32, a: Look, b: Alt) { if k == 0 { a } else { b } }
    print(src(1, "knife", "none"))
    // vl check: rc 0.  vl run: invalid module, type mismatch: expected (ref $string), found i32

#### Mechanism

The join of two literal-union arms of different types is accepted, but at an un-annotated
function's implicit tail the inferred return is a string while the tail delivers the joined
value as an i32 atom. Binding the join first (`const v = if …; v`) runs. A closure body takes the same
path and, instead of failing validation, prints the atom index (`1` for `"none"`), so the
closure spelling is check-clean and silently wrong.
