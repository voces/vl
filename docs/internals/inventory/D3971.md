### D3971 — a capture cell seeded with a hole lambda in a generic body is refused at two instances

**loud emit reject · clause 2 · found closing D3951 (`scw/c06`) · filed 2026-10-10 against master `56f77d80f`**

Repro:

    function other<V>(v: V) { print("O"); print(v) }
    function run<T>(x: T) {
      let k = (y) => { print("L"); print(y) }
      const flip = () => { k = other }
      k(x)
      flip()
      k(x)
    }
    run(1)
    run("s")
    // vl check: rc 0.  vl run: emitProgram: the reassigned function binding `k` holds functions called at more than one argument type

Want:

    L
    1
    O
    1
    L
    s
    O
    s

#### Mechanism

The hole lambda that seeds the cell names no `T` and is lifted once for the generic body, so the
`i32` and `string` instances call one lambda, which can hold one signature. A single instance
runs since D3950's close; two that disagree are the binding conflict, refused. D3952 is the same
one-binding-across-instances shape for a closure call. The capability is a per-instance copy of
the lambda.
