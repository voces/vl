#### Mechanism

The refusal is at `k`'s initialiser. The alias is elided only while every read of `k` is a
call. The comparison reads `k` as a value, so the binding was built as a closure of `id` and met
the floor. Two passes asked that question: the emitter's `nameUsedAsValueIn` and, before it,
mono's `monoNamesUsedAsValue`, which kept `k`'s instance set open. Exempting the bare operand in
the first alone moved no cell; the close exempts it in both, and the emitter's read of an
elided alias in a comparison reads the declaration's identity token.
