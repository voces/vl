### D3793 — a generic over a READONLY list of a declared record keeps the lossy structural pin, so a union-arm or recursive element field emits invalid wasm

**closed · was check-clean invalid wasm · clause 1 · the readonly face of D3792 · fixture `tests/cases/generics/generic-pin-declared-record-readonly-list.vl` · filed 2026-10-06 against master `a37097b64` (#3407 review) · closed by lane S5**

Repro:

    import { toString } from "std:fmt"
    type Hit = { tick: i32, kind: "hit" }
    type Miss = { reason: string, kind: "miss" }
    type St = { key: i32, evs: (Hit | Miss)[] }
    type H = { ro: readonly St[] }
    function g<T>(x: readonly T[]): T { return x[1] }
    function mk(k: i32): St { return { key: k, evs: [{ tick: k, kind: "hit" }] } }
    const a: St[] = [mk(1), mk(2), mk(3)]
    const h: H = { ro: a }
    const r = g(h.ro)
    const e = r.evs[0]
    if e is Hit { print(r.key.toString() + ":hit " + e.tick.toString()) } else { print("miss") }

Want:

    2:hit 2

#### Mechanism

D3792's `monoDeclRecListPinName` pins a generic's list argument by the element's declared
record name, but returns `""` for a readonly list (`t.aRead == 1`), so `readonly St[]` keeps the
structural render: `kind: "hit"` becomes `string` and the instance's row is not `St`'s, which
the validator rejects inside `g$m0`. Nothing says why readonly is excluded.

Closed by pinning the view at `S[]` too. That is sound because a view and its list are one rep
(`RO_MARK`, tyname.vl: `repCanonId` reads the element alone), and the checker admits no wider row
into a view: `const ro: readonly A[] = bs` with `bs: B[]`, `B` one field wider, is a check error
("drops the field `y`"). So a `readonly S[]` value holds `S`'s rows exactly as an `S[]` does. The
pin spells the plain list, not `readonly S[]`, because the emitter has no list rep under that
spelling ("only i32[] arrays and struct/union element arrays are supported").

Graded on both seeds, with base = #3407's head. Only the field position failed. A bare binding,
an inferred view (`const ro = view()`), a parameter, a call result, a closure capture and a global
already pinned by name, and they still run.
