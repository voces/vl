#### Mechanism

Under ruling B2 the write is accepted and each call drops `retV`'s result. Mono instances the
written functions at one signature per binding (`monoLetPinTake`), and the two calls pin two, so
it refuses (`monoBindSigFail`) and asks the split plan, which gives each call its own instance.
Without the plan the refusal stands.
