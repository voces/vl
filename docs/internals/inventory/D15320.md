### D15320 — two returned records of members of different signatures in one program refuse at emit

**open · loud emit reject · clause 2 (`emitProgram: ref valtype with no interned shape`) · owned by lane bundle · found grading D15149 · filed 2026-11-04 against master `f5014ce43`**

Repro:

    function lap(f) {
      const _a = f(2.5)
      const _b = f(3)
      return f
    }
    function lap2(f) {
      const _a = f(true)
      const _b = f(3)
      return f
    }
    const k = lap((a) => a + 1)
    print("\{k(4)} \{k(1.5)}")
    const j = lap2((a) => a)
    print("\{j(4)} \{j(true)}")

Want:

    5 2.5
    4 true

#### Mechanism

Not yet measured. Each record alone runs: `lap`'s record of `(f64)` and `(i32)` closures, and
`lap2`'s of `(boolean)` and `(i32)`. Together the module has no interned shape for one of them.

#### Ablation

| spelling | outcome |
| --- | --- |
| `j` removed | runs, prints `5 2.5` |
| `k` removed | runs, prints `4 true` |
| both held in record fields (`{ f: lap(...) }`, `{ f: lap2(...) }`) | refuses at emit, `a call through a held record matches none of its signatures` |
| both held in list elements | the same refusal at the second |
