### D4203 — a literal test on a generic parameter typed `T | 1` refuses at emit: the union has no recorded members

**closed 2026-11-10, runs and prints `one` then `t` · was loud emit reject · `emitProgram: literal `is` over a union with no recorded members` · clause 2 · the `==` spelling and the `i32` pin alone run too · found reviewing #3577 · filed 2026-10-12 against master `0bf4c3bb6` · closed where a name read's union is resolved (`unionNameOfRead`, emit_classify.vl): it names the row its storage type keys, here the instance's `string | 1`, where the walk of its declaration named the template's `T | 1`, which no row holds · fixture `generics/literal-test-on-param-joined-with-a-literal.vl`**

Repro:

    function f<T>(x: T | 1) {
      if x is 1 { print("one") } else { print("t") }
    }
    f(1)
    f("q")

Want:

    one
    t

#### Mechanism

`vl check` accepts the program. The emitter then refuses with "literal `is` over a union with
no recorded members" (with `==`: "union box atom test on a union with no recorded members").
The member set is registered for a declared union, and the pinned instance `T | 1` at `T =
string` is never registered. This is clause 2: the program is legal. Both spellings refuse
identically on master and on #3577.

#### Grading list

The `==` spelling, and `T` pinned to `i32` (`f(1)` alone).
