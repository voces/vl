### D12840 — a value-`if` whose arm block ends in a local binding of an uncalled hole function is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same program with `exclaim(s: string)` and `ask(s: string)` runs, printing `a!`, and so does each arm written as the function's name · found closing [D7080](D7080.md) · filed 2026-10-25 against master `1e4d22724`**

Repro:

    function exclaim(s) { return s + "!" }
    function ask(s) { return s + "?" }
    const on = [1].length == 1
    const x = if on {
      const lv = exclaim
      lv
    } else {
      ask
    }
    print(x("a"))
    // vl check: rc 0.  vl run: emitProgram: cannot take the generic function `exclaim` as a value — … No call site pins `exclaim`

Want:

    a!

#### Mechanism

From the outcome, not yet the code. The checker types both arms `(_) => string` and the call
`x("a")` pins `_` to `string`, but the call reaches the arms through the if-of-generics path
in `emit_mono.vl`, which follows an arm that NAMES a function and not one whose value is a
binding of one, so `exclaim` is taken as a value with no pin.
