#### Mechanism

The escape step decides by wasm TYPE, not by call site: a struct type that any field, array
element, global or table can hold is never a per-call struct, so `kept: Quat[]` removes every
`Quat` producer from the choice, and `reader`'s two calls allocate as `keeper`'s does. Record
types of the same field shape share one wasm struct type, so a different record with `Quat`'s
five fields held anywhere does the same. That
is sound (the step only chooses what to inline) but coarse. Per-call-site escape is what the
ruling (B) ABI would give (a multi-value variant used where the result is only read, the
struct-returning one where it escapes); inlining cannot express it, because `--no-inline` is
per callee. Recommendation: file with D3262's ABI, not separately.
