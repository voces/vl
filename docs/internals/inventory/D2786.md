### D2786 — a closure capturing a copy of a copy of a `for-in` variable inside a generic stores it as `i32`

**closed 2026-09-27 — the repro RUNS and prints `p` · was check-clean invalid wasm inside `run`, identical on master `781f68091` · D2763's residue, filed 2026-09-27 from the #3209 review**

Repro:

    function run<T>(xs: T[]) {
      for x in xs {
        const c = x
        const d = c
        const f = () => d
        return f()
      }
      xs[0]
    }
    print(run(["p", "q"]))

#### Mechanism

D2763 types a captured bare copy of a loop variable as the loop variable. `d` is a copy of `c`,
which has a binding of its own, so the redirect stopped at `c` and the env field was classified
through `c`'s initializer with no loop in scope, falling to `i32`. Closed by following the chain of
bare copies (`captureLoopCopySrcAt`, bounded) to the loop variable at its end.
