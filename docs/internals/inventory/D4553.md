### D4553 — a variadic `.push` onto a nullable or literal-union list is refused

**loud emit reject · 5 hand probes · filed 2026-10-13 against master `eb2603843`**

Repro:

    type K = "a" | "b"
    const xs: K[] = ["a"]
    xs.push("a", "b")
    print(xs.length)
    // vl check: rc 0.  vl run: emitProgram: a nullable or literal-union list takes one `.push` argument at a time

#### Mechanism

`emitPush` lowers a one-argument push element by element, and routes several arguments or a
spread to `emitPushMany`, which builds the arguments as one list literal and appends it with
`array.copy`. That literal is built without the element seeds a literal-union atom, a
`boolean | null` sentinel or a nullable string slot need, so `emitPushMany` refuses those
receivers outright.

#### Ablation

| receiver element | two arguments | spread |
| --- | --- | --- |
| `K` (string literal union) | refuses | refuses |
| `K \| null` | refuses | — |
| `string \| null` | refuses | — |
| `boolean \| null` | refuses | — |
| `i32 \| null` | runs | — |

#### Grading list

`xs.push(...ys)` over `ys: K[]`, and every row of the ablation. Probe:
`scripts/capability-probes/push-many-literal-union-list.vl`.
