#### Mechanism

The first pass narrows `g` for the rest of the block after `if !(g is string[]) { return 0 }`, the
post-guard complement narrowing it applies to any `is`. The deep `is` rewrite
([D1190](D1190.md), `jwArmBlockOf`) binds the converted copy only in an arm the test guards, and a
negated test with no `else` has none. The statements after the guard read the raw place, and the
re-check reads it at the declared `Json`.

| the read in an `else` arm of the same test | runs | **yes** (the post-guard statements) |
