#### Mechanism

The first pass narrows `g` for the rest of the block after `if !(g is string[]) { return 0 }`, the
post-guard complement narrowing it applies to any `is`. The deep `is` rewrite
([D1190](D1190.md), `jwArmBlockOf`) binds the converted copy only in an arm the test guards, and a
negated test with no `else` has none. The statements after the guard read the raw place, and the
re-check reads it at the declared `Json`.

The close binds the copy after the guard when the arm the test sends a failing value to exits
(`stmtAlwaysExits`, the shared rule), the arm it sends a passing value to did not end the
narrowing, and, for an `else if` link, every arm before the link exits too. `jwPolarity` now
reads an `||`: it is false only when each operand is, so a negated test in either one is the test.

#### Grading list

- A guard that `break`s or `continue`s inside a loop, ends in a `return` after other statements,
  tests `!(g is T) || …` or `!(g is T && …)`, is an `else if` link, sits in a lambda, or is
  followed by a write or a shadowing block: all run since the close.
- The close leaves no diagnostic only the second pass raises. A narrowing-form grid (then, `else`,
  value `if`, guard `return`/`continue`/`break`, `&&`, `||`, `else if`, nested, `!!`, lambda,
  `while`, `match`) found every deep form agreeing with its shallow spelling, except `match` on a
  deep type pattern, which the first pass refuses (`match pattern `string[]` is not a member of
  Json`). So the editor parity test now checks a clean file, and check-within's `(deep is)` guard,
  which no program can trip any more, is deleted with its case (the kill-matrix rule).
