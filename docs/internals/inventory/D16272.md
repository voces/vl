### D16272 — a `for` over a call that returns an empty list literal, which nothing else pins, does not bind its loop variable

**open · loud check reject · `undeclared identifier 'x'` · clause 2 · found closing [D2508](D2508.md) · filed 2026-11-14 against master `495c1ff80`**

Repro:

    function f() { return [] }
    for x in f() { print(x) }
    print("done")
    // vl check: undeclared identifier 'x'

Want:

    done

#### Mechanism

Not traced. The call's type is `f`'s return, a list whose element is a hole every caller of `f`
shares, so the read-only default [D2508](D2508.md)'s close gives a literal iterated in place
cannot be taken here: another caller may push into its own copy and pin the element.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const r = f(); for x in r` | runs, prints `done` | **yes** |
| a second caller `const a = f(); a.push("s")` | runs | **yes** |
| `for x in []` (the literal itself) | runs since [D2508](D2508.md) | **yes** |
