### D1814 — an optional CALL `p?.f()` typed its callee as a value, so a nullable method was "not a function"

**closed 2026-09-06 — the witness prints `42` then `0` · was a loud check reject
(`called value is not a function ((() => i32) | null)`, and `no field 'f' on P` at the UFCS
spelling) · filed 2026-09-06 against master `57b54ccdd` · ROADMAP row 17 (A5) · matrix
`scripts/capability-probes/matrix/optcall-self-function.matrix.vl` and six siblings · fixture
`tests/cases/expressions/optional-call-guard.vl`**

Repro:

    type P = { f: () => i32 }
    function mkP(c: boolean): P | null {
      if c { return { f: () => 42 } }
      return null
    }
    const p = mkP(true)
    print(p?.f() ?? 0)
    const q = mkP(false)
    print(q?.f() ?? 0)
    // was: check reject, `called value is not a function`. Now prints 42 then 0.

#### Mechanism

`checkCallNode` dispatched a `Member` callee to `checkMemberCallNode` and had no arm for an
`OptMember` one, so the callee fell through to `checkNode(n.callFn)` and was typed as a
VALUE — `(() => i32) | null` for a callable field, `TY_ERR` for a free `self`-function, whose
own `?.` arm had already refused `no field 'f' on P` because UFCS is resolved at the call and
not at the member read.

`p?.f(args)` is one guard over the receiver with the whole call inside it, so the callee and
the arguments now resolve against the receiver's NON-NULL type (`checkOptCallNode`, sharing
`checkMemberCallNode` with the plain spelling through a receiver-type override) and the result
is that call's own return behind a single `| null`. At emit, `drwWalk` swaps the callee for
the plain member read and wraps the rewritten call in `if recv != null { call } else { null }`,
so UFCS, a callable field and the builtin methods each lower through the path they already
had, and the emitter's own narrowing recovers the receiver non-null inside the guard.

The guard names the receiver twice, so only a re-readable one is desugared — the `??`
desugar's rule (D962). A call or operator receiver keeps the `?.` callee and is refused by
name at emit.
