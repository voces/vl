### D16461 — a float constant tree whose IEEE value is an infinity is typed `f64` at an `f32` use, and refused

**loud check reject · clause 2 · ``f64 doesn't fit in f32 — the conversion is lossy and must be made explicit with `as` `` · the same tree at `f64` prints `Infinity` · found grading D16414's positions · filed 2026-11-15 against master `f88ee38dd`**

Repro:

    const z: f32 = 1.0 / 0.0
    print(z)
    // vl check: f64 doesn't fit in f32 at `1.0 / 0.0`

Want:

    Infinity

#### Mechanism

Not traced. E9.1 makes a float division by zero IEEE's Infinity or NaN, and the fold keeps a
tree whose value is no finite double whole (`cexFrac`), so the tree is checked as the operator
it is; at an `f32` use that operator is typed at the literals' `f64` default rather than adopting
the use's `f32`. A finite constant past `f32`'s largest value is an owed refusal (the coordinator's
reading of Q9); an infinity the arithmetic produces is not. From the ablation.
