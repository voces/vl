### D15561 — a returned list-of-records binding, beside a list of another function set, that is also handed to an un-annotated function compiles to invalid wasm

**closed 2026-11-08 — the filed repro prints `20`, `6`, `20`, `4` · was check-clean invalid wasm, clause 1 · a binding holding a function set's ids, handed to a generic call inside a generic function's instance, pinned that call at its closed type's render, which drops the set and spells the closure list; it now pins at the row its own type is built at (`monoTaggedRowPin`, emit_mono.vl) · fixture `tests/cases/closures/list-of-tagged-records-handed-to-a-generic-call-in-an-instance-runs.vl` · found closing D15559 · filed 2026-11-08 against master `2a59f035`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function useL(r) { return r[0].fs[0](10) }
    function passed(b) {
      const c = [{ fs: [dbl] }]
      print(useL(c))
      const a = [{ fs: [inc0] }]
      if b { return a }
      return c
    }
    print(passed(false)[0].fs[0](3))
    print(passed(true)[0].fs[0](3))

Want:

    20
    6
    20
    4

#### Mechanism

`passed` takes a hole parameter, so its body is emitted per instance. In the instance the binding `c` holds the closed type the elaboration stamps its literal at, `{fs: ((i32) => i32)[]}[]` over the set `{dbl}`. `monoArgTyNameBound`'s binding arm pinned `useL` at `monoClosedTyPin` of that type. No row records it, so the pin fell to its render, which has no set, and `useL`'s parameter became a list of closures while `c` was built as `#anon0[]`, a list of the set's ids. Outside an instance the same binding pins `#anon0[]` from its literal.

#### Ablation

The minimal witness needs no second set and no second return:

    function dbl(a) { return a * 2 }
    function useL(r) { return 1 }
    function passed(b) {
      const c = [{ fs: [dbl] }]
      print(useL(c))
      return c
    }
    print(passed(false)[0].fs[0](3))

| spelling | outcome before |
| --- | --- |
| the minimal witness | check-clean invalid wasm |
| `passed(b: boolean)` | runs |
| `useL(r: { fs: ((a: i32) => i32)[] }[])` | runs |
| no `useL(c)` call | runs |
| `passed(false).length` read instead | runs |
| `passed(false)` with its result discarded | emit reject (`no interned signature`), runs now |

The ingredients are a generic enclosing function, a set-holding list-of-records binding, and a generic callee.
