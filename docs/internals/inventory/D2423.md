### D2423 — an un-annotated record literal takes a declared row with the same field names whatever its field's layout

**closed 2026-09-25 — the witness runs and prints `1.5` then `2` · was check-clean invalid wasm, clause 1 · the family of [D2208](D2208.md) and [D2215](D2215.md) (a declared shape captures an anonymous literal) · found grading D2382, filed 2026-09-25 against master `a277bf7b0` · fixture `tests/cases/objects/declared-row-field-layout-no-capture.vl`**

#### Mechanism

`structIndexOfObjCtxGo` matches an object literal to a row by field names, then refutes per
field. Against an anonymous row every code mismatch refutes (`anonValueFitsField`), but against
a DECLARED row a differing code was lenient, on the ground that a declared field's code can
differ through adoption — refuted only between a string list and a named-heap slot (D1704). So
`{ k: xs }` with `xs: f64[]` took the `{ k: i32[] }` annotation's row and stored an `f64` list into
an `i32`-list slot. `declRowFieldFits` now also refutes a differing code between a named-heap
slot (record, record list, its `| null`) and a self-contained one, between a record and a record
list, and between two scalar or string lists; the caller asks it on every code mismatch against a
row the literal's own destination does not name. That destination is where adoption lives, so a
literal re-encoding into its own declared row is untouched.

Grid of a literal field against a declared or annotated field of the same name, 13 cells: an
`f64[]` against `i32[]` and back, in and out of a function; a literal `[1.5]` against `i32[]` and
`[7]` against `f64[]`; `["s"]` against `i32[]`; a record list against `i32[]` both ways and
against `f64[]`; a record against `i32`, `string` and a record list. **0 of 13 ran before** (7
invalid wasm, 6 loud emit rejects: `field access receiver is not a struct`, `nested struct fields
are not supported`), **13 of 13 after**. The destination-adoption controls (`R = { k: f64[] }`
fed `[2]`, `{ k: P[] }` fed `[]`, `{ k: f64 }` fed `2`, a literal returned as `R`) ran before and
after.
