### D1827 — a narrowed MAP READ in an if-expression bound to a LOCAL is check-clean invalid wasm

**check-clean invalid wasm · filed 2026-09-06 against master `57b54ccdd` · found while
closing D1814, whose optional-call desugar excludes a map receiver because of this row · the
same if-expression in RETURN or tail position runs**

Repro:

    type P = { n: i32 }
    function twice(self: P) { self.n * 2 }
    const m: {[string]: P} = Map()
    m["k"] = { n: 21 }
    function la() {
      let v: i32 | null = if m["k"] != null { m["k"].twice() } else { null }
      print(v ?? 0)
    }
    la()
    // vl check: rc 0. Then: the emitted module failed to validate inside `la`:
    // type mismatch: expected i32, found (ref $type)

#### Mechanism

Not yet ablated to a rung. The ingredients are: the receiver is a MAP READ (a list element in
the same shape runs), the delivery is a LOCAL binding inside a function (the same
if-expression as a `return` or as the function's tail expression runs), and the narrowed arm
calls through the read. The value the arm leaves is the map's struct ref where the binding's
cell wants the `i32 | null` box, so the arm's result is not being boxed at the join for this
one destination.

The same shape at MODULE scope runs, which is why the D1814 position matrix finds it only
inside a function.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the map read (a `(P \| null)[]` element instead) | runs | **yes** |
| the local binding (`return` the if-expression) | runs | **yes** |
| the local binding (the function's tail expression) | runs | **yes** |
| the enclosing function (the same binding at module scope) | runs | **yes** |
| the annotation on `v` | still invalid | no |
