### D15658 — a list join of a generic named function and an annotated one, handed to a hole callee, is check-clean and traps

**closed 2026-11-11, runs and prints `2` · was loads then traps, clause 1, `vl check` rc 0, then `wasm trap: indirect call type mismatch` · found closing D15643 · filed 2026-11-11 against master `09b00b57` · closed with [D15659](D15659.md): the hole callee was not needed, `pickB`'s hole `c` makes it generic and mono delivered no function name inside its instance's literal arm (`monoElabDeliver`) · fixture `tests/cases/functions/list-or-record-join-of-generic-and-annotated-member-in-generic-fn.vl`**

Repro:

    function id1(a) { return a }
    function id3(a: i32) { return a }
    function gl(r) { return r[0](2) }
    function pickB(c) {
      const k = if c { [id1] } else { [id3] }
      print(gl(k))
    }
    pickB(true)

Want:

    2

#### Mechanism

Not ablated. The set `{id1, id3}` is left a closure, and `gl` keeps one closure instance
calling `(i32) => i32`. No call fixes `id1`'s instance, so `id1` is emitted with no
parameters or result. Its closure thunk calls it at `(structref)`, and the indirect call traps.
With two generic members (`id2` for `id3`), the set is tagged and the program runs.
