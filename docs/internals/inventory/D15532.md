#### Mechanism

`n` is a map of records holding the set `{id}`, so the tag rule stamps its binding with a held rep
whose value is the record of the set's ids, and `Map()` and `n["k"]` read the map at that rep. A
helper pinned at the rep interned it as a side effect, so a map handed to one ran, while a map
written only directly had no mv slot for it: tagged, it was invalid wasm or `no interned shape`, so
the set stayed untagged and mono had no instance to pin for two types.
