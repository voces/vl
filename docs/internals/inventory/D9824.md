#### Mechanism

`emitCallRefArg` (wasmEmit.vl) seeds each argument's context from the parameter's `$fnsig`
token. A `boolean | null` parameter keys `i`, the same token as `i32`, so the arm that seeds the
nullable string, closure, list and none contexts from the token has nothing that says nullable
boolean, and the bare `null` reaches the struct-context floor. Running it needs the callee's
parameter type read from the arena, as `cloCallParamLitUnion` (emit_closure_sites.vl) does
for a literal union.
