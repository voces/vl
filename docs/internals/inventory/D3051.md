#### Mechanism

`vl check` is clean, then the emitter traps (`allocation size too large`). A seed built with
`--names` shows the recursion: `exprIsF64` → `letIsF64` → `exprIsF32` → `binMixHardF64` →
`exprHasHardF64` → `exprIsF64` …, ending in `repOfTy`. An identifier naming a module const
re-classifies that const's initializer. Each level mentions the previous const twice, so the
walk is 2^depth, and nothing memoises it the way `globalCellKind` is memoised (D1513). The same
chain stopped at `A9` compiles and prints `786432`. #3262's const fold is not in the trace: its
256-node budget declines these consts from `A6` on (A5 expands to 188 nodes), and they keep their start-function cells.

#### Grading list

The same chain at `f64` (`const A0 = 3.0`), and at depth 20.
