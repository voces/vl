    function exclaim(s) { return s + "!" }

#### Mechanism

From the ablation only. A call through a binding of an `if` of hole functions instances each
arm at the call (D6991). Here the binding is read by a `return`, and the call is of the returned
value in another frame, which the call-through rule does not follow back to the binding.
