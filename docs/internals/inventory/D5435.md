#### Mechanism

A prediction from the ablation: the closure's env field for `__c` is typed off its
initializer from the start function's frame, where the arm local `t` is not bound, so the
arm tail gets no nullable-string kind. D5332's declaration rung answers a parent local, not an
arm local; D5430 is the same frame gap for a global.
