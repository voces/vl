Repro:

    let v: f64[] | string = "a"
    const k = () => { v = [1.5, 2.5] }
    print("ok")
    // vl check: rc 0.  vl run: invalid module inside `k`: type mismatch: expected (ref $type), found (ref $type)

#### Mechanism

Not the lambda and not the module frame: the witness is one of 31 check-clean-invalid cells of a 42-cell grid over
{module global, local, parameter} x {binding, function tail, lambda tail} x six members (seven shapes, the rest running). An
assignment is an expression yielding its right side, and the checker types `v = e` at `e`'s
type. The emitter lowers the value as store-then-re-read of the target, and for a name whose
cell is a value-union box the re-read pushed the BOX, while every consumer (a binding, the
caller of a function whose tail is the assignment, the `$fnsig`) took the checker's member
type. The witness is the one cell where the disagreement is inside `k` itself: `k`'s
functype result was classified from the right side (`f64[]`) and its body returned the box;
with `i32[]`, `string[]` or a scalar the functype was the box and the break moved to the
caller, so the filed ablation's `runs` rows were only unused results.

The close lowers the re-read under a narrowing to the member the checker typed the value at
(`asgReadNarrowTy`, the same set selection the post-write re-narrow uses), and every
classifier that answered for an `=` node by its target now answers by `asgReadNode` — the
right side when the re-read is narrowed. A function whose result is still the cell (a tail
`if` whose arms assign different members) keeps the box on both sides (`asgIsCellTail`).

#### Ablation

On master `a277bf7b0`, each cell printing the value it read back; the family grid is 42 cells.

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the value's use (`k()` as a statement, any member but `f64[]`) | runs | no — the use is where it breaks; `f64[]` breaks inside `k` |
| the lambda (`function k() { v = … }`, result used) | still invalid | no |
| the module frame (a local or a parameter cell, result used) | still invalid | no |
| the box (a closure-captured local, whose cell is a list) | runs | **yes** |
| a single member (a tail `if` assigning `2` and `"s"`) | runs | **yes** |
