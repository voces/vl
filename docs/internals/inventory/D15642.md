### D15642 — a choice of named functions in a record literal, called at two types in the callee and also delivered to a closed function type, builds invalid wasm

**check-clean invalid wasm · clause 1 · `the emitted module failed to validate inside \`call0$1\`: … type mismatch: expected i32, found f64` · found closing D15641 · filed 2026-11-10 against master `deea236c`**

Repro:

    function id(v) { return v }
    function dbl(v) { return v + v }
    function call0(r, x) { print(r.f(x)) }
    function keep(f: (i32) => i32) { print(f(1)) }
    function run(b) {
      const g = if b { id } else { dbl }
      call0({ f: g }, 3)
      call0({ f: g }, 2.5)
      keep(g)
    }
    run(true)

Want:

    3
    2.5
    2

#### Mechanism

`keep(g)` delivers the set to a closed function type, so the decision after the elaboration
leaves it a closure (`ftEscBuilt`). The record is then a record of closures of one signature,
and `call0`'s instance at `f64` calls that closure at `f64`.
