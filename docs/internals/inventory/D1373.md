### D1373 — the bare-`as` swallow survives at a COPIED hole binding: `const c = a` moves the cast off the parameter the call site pins

**check-clean silently wrong · clause 1 · `vl check` rc 0, the program runs and prints NOTHING
— not the cast's value and not the statements after it · the `as` suffix only · ZERO corpus
cells · filed 2026-09-03 as the delivery [D1342](#d1342)'s rung deliberately excludes,
measured on this worktree's seed**

Repro (`vl check` rc 0, runs, prints nothing at all — the annotated
`function take(a: i32 | null)` twin is the loud check reject D1342 made the hole's own answer):

    function mk(n: i32): i32 | null {
      if n == 0 { return 5 }
      return null
    }

    function take(a) {
      const c = a
      print(c as i32)
      // PRINTS
      print(99)
    }

    take(mk(1))

#### Mechanism

D1342 parks the cast's propagation obligation on the hole and re-asks it at the call that PINS
the hole. The pin describes the PARAMETER, so the rung adjudicates only a DIRECT read of it —
`castOperandIdent` must answer, and the answer must equal the DECLARED parameter name. `c` is
a different ident, so nothing is adjudicated and the emitter's D1251 lowering emits the
propagation exit into a VOID function, where a bare `return` discards the pushed box.

**THE EXCLUSION IS MEASURED, NOT CAUTIOUS, and one program is why.** Widening the rung to any
ident holding the hole's arena row refuses `function take(a) { const b = a ?? 0; print(b as
i32) }`: `??` over a hole does not retype it, so `b` holds the very same `TyVar` while its
VALUE can never be null — and that program runs today, its annotated twin runs, and refusing
it would be a `runs` cell lost for no design reason. `a = 7` before the cast is the same shape
without an overlay to carry it (a hole has nothing to narrow FROM), which is why the write is
recorded separately (`noteCastClobber`).

So the honest root is the one D1341 already named: the checker solves an un-annotated
parameter from its BODY while the monomorphizer solves it from the ARGUMENT, and every rung
that reads the pin has to say which reads of the hole the pin still describes. A copy does;
a coalesce does not; the arena row is identical for both.
