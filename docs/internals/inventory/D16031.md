### D16031 — a number-literal `| null` field read through an un-narrowed record union is refused when the literal arm comes first

**loud emit reject · clause 2 · `emitProgram: field access receiver is not a struct` · found checking the variant field-type predicate's alias edge (lane E) · filed 2026-11-13 against master `e39d632e`**

Repro:

    type R = { x: 1 | null }
    type S = { x: i32 | null }
    function f(u: R | S) {
      const y = u.x
      if y == null { print("null") } else { print(y) }
    }
    const n: R = { x: null }
    f(n)

Want:

    null

#### Mechanism

Not traced. It is the number-literal sibling of D15882, a string `K | null` field. In both, the
read is a field of an un-narrowed union of records, and the field's storage is a literal set
beside `null`. Here the union's member order decides: `S | R` names the same type and runs.

#### Ablation

| spelling | outcome |
| --- | --- |
| this repro | loud emit reject |
| `u: S \| R` (the `i32 \| null` arm first) | runs, prints `null` |
| `const n: R = { x: 1 }` | loud emit reject |
| `x: 1 \| 2 \| null` in `R` | loud emit reject |
| `x: K1 \| null` with `type K1 = 1 \| 2` | loud emit reject (as the inline set) |
| both arms `x: 1 \| null`, one with an extra field | loud emit reject in either order |
| both arms `x: i32 \| null`, one with an extra field | runs |
| `R`'s field without `null` (`x: K1` beside `x: i32`) | runs |
| module level: `const u: R \| S = n; print(u.x == null)` | loud emit reject |
