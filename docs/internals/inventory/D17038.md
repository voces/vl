### D17038 — a claimed function returns a block body's last `if` arm's value where legacy falls off to `null`

**closed · check-clean silently wrong under the shipped claim on master `6851d881` · filed 2026-11-20**

Repro:

    let n = 0
    function tl(a: i32) {
      if a > 5 {
        return 1
      } else {
        n = n + a
      }
    }
    print(tl(2))
    print(tl(9))
    print(n)
    // PRINTS 2 1 2 (one per line) as shipped; $VL_IR_SHADOW=1 (legacy's bytes) prints null 1 2

Want:

    null
    1
    2

#### Mechanism

A block body returns a value only through `return`: legacy's `emitFuncBody` takes a block body's
last statement as its tail only when it is a `return`, and writes any other last statement as a
statement, with the fall-through pad after it (`fallThroughPadOf`). The IR's `tailReturn` asked
`lastStmtIsValueIf` of a block body's last `if` and built it as a tail `if`, so the `else` arm's
`n = n + a` became the returned value. The armed shadow reported the function as covered and not
matched (`bytes: prefix or locals`), but the shipped claim builds without the shadow and wrote the
IR's bytes. `tailReturn` now builds a block body's last statement as a statement for every kind.
