### D4644 — an un-annotated record literal whose field is a value `if` of union-arm literals mints no field row

**closed · runs, prints `5` · was loud emit reject · clause 2 · the `struct_field_init` and `struct_field_place` un-annotated cells of `if-expr-anon-arm-literals.matrix.vl` · filed 2026-10-14 against master `536c4c79e` · closed by step 5a: the checker stores each literal as the type it is delivered to (`recordRepTyAdopt`), and the emitter builds it at that type (`litRepTyAt`)**

Repro:

    type U = { q: i32 } | { r: i32 }
    function pickQ(n: i32): boolean { n > 0 }
    const w = { f: if pickQ(1) { { q: 5 } } else { { q: 6 } } }
    print(w.f.q)
    // vl check: rc 0.  vl run: emitProgram: object literal matches no union variant

Want:

    5

#### Mechanism

Not localised past the ablation. The outer literal `{ f: … }` is matched against the declared
records by its field types, and the field's value is a join whose every arm is an arm of `U`.
A plain arm literal or an arm-typed local in the same field runs, so the join is what the
outer literal's shape lookup cannot answer.
