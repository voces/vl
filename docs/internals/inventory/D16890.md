### D16890 — a lambda whose result is an anonymous record, handed to a generic's bare type parameter, is refused at monomorphization

**loud emit reject · `emitProgram: monomorphize: unsupported argument type for `x` in a call to `id`` · clause 2 · open · `vl check` rc 0 · found probing producers of a closure with a union result · probe `scripts/capability-probes/generic-identity-of-record-result-lambda.vl` · filed 2026-11-16 against master `c4052ed4e`**

Repro:

    function id<T>(x: T): T { return x }
    const f = id(() => ({ a: 5 }))
    print(f().a)
    // vl check: rc 0.  vl run: emit error, the refusal above

Want:

    5

#### Mechanism

Not traced. The monomorphizer finds no argument type to bind `T` when the argument is a lambda
whose result is an inline record literal. A named function with the same result, and a lambda
whose result names a declared record type, bind `T` and run.

#### Ablation

| spelling | outcome | needed? |
| --- | --- | --- |
| the witness | emit reject | — |
| `(x: i32) => ({ a: x + 5 })`, a parameter added | the same emit reject | no |
| the lambda bound first, `id(k)` | the same emit reject | no (a lambda, not a literal position) |
| a named `function mk(x: i32) { return { a: x } }` handed instead | runs | **yes** (a lambda) |
| the lambda's result annotated `: P`, `type P = {a: i32}` | runs | **yes** (an anonymous record) |
| the result a list `[x]` or a string | runs | **yes** (a record) |

#### Grading list

`id((x: i32) => ({ a: x + 5 }))` handed on to a parameter of type `(i32) => {a: i32} | f64`.
