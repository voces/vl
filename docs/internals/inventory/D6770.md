### D6770 — `is` over an element of a list of `i32[] | K[]` folds to false at the list both members rep as

**closed 2026-10-18 by lane L6 · runs, prints `3` · was check-clean silently wrong · `vl check` rc 0 · clause 1 · an `is` testing a value of a union of lists that all spell one list against that list, with a plain scalar leaf, folds to true: every value of the union fits it; `is K[]` still tests the elements · pins: `tests/cases/unions/union-of-int-list-and-literal-union-list.vl` · found closing [D6732](D6732.md) · filed 2026-10-18 against master `1e7bc12cb`**

Repro:

    type K = 0 | 1
    const xs: (i32[] | K[])[] = [[1, 0, 1]]
    const v = xs[0]
    if v is i32[] { print(v.length) } else { print(-1) }

#### Mechanism

`K[]` shares `i32[]`'s rep, so the element holds no tag saying which member spelled it. The
static `is` fold compared the operand's union type with `i32[]` as two type sets, found them
unequal and answered false, where the runtime path has nothing to dispatch on either.
