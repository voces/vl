Repro:

    type J = { f: i32 | null }
    type K = { j: J }
    function mk() { { j: { f: 4 } } }
    const k: K = mk()
    const y = mk()
    print(y.j.f)

Want:

    4

#### Mechanism

`mk`'s result is delivered to `K`, whose field `j` stores `f` as `i32 | null`, and is also kept at
its own `{j: {f: i32}}` by `y`. The emitter builds the result one way and hands it to `k`'s
global as the other: `expected (ref null $K), found (ref $#anon)`. The flat twin, one record
level, runs.
