### D4998 — an un-annotated module global copied from a same-shape `A | B` value refuses a field read

**loud emit reject · clause 2 · open · `field access receiver is not a struct` · the same on master `2f625f31e` before D4989's fix · found closing D4989 (its matrix's un-annotated `global_*`, `array_*` and `struct_field_init` cells) · filed 2026-10-15 against master `2f625f31e`**

Repro:

    type Pa = { tag: i32, val: i32 }
    type Pb = { tag: i32, val: i32 }
    function pick(n: i32): Pa | Pb {
      const b: Pb = { tag: 2, val: n }
      return b
    }
    const g = pick(4)
    const v = g
    print(v.val)
    // vl check: rc 0.  vl run: emitProgram: field access receiver is not a struct

Want:

    4

#### Mechanism

Not localised past the ablation. `Pa | Pb` is one record in the arena and a union box in the
emitter (the same-shape collapse, D4989). A module global bound to another such global's value,
or to an element of an `(Pa | Pb | null)[]`, reads as neither the box nor the record when its
field is read.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the copy (`const v = pick(4)`, `print(v.val)`) | runs, prints `4` | **yes** |
| module scope (both bindings inside a function) | runs, prints `4` | **yes** |
| un-annotated (`const v: Pa \| Pb = g`) | runs, prints `4` | **yes** |
| the box source (`const xs: (Pa \| Pb \| null)[] = [pick(4)]`, `const v = xs[0]`, read under `v != null`) | still refuses | no |
