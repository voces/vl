### D4998 — an un-annotated module global copied from a same-shape `A | B` value refuses a field read

**closed 2026-10-19 by lane L6 · runs, prints `4` · was loud emit reject, `field access receiver is not a struct`, clause 2 · closed by step 4 of the union registry by type (a twin-record union is the record, with no box) · pin: `tests/cases/unions/same-shape-union-global-copy.vl`, matrix `scripts/capability-probes/matrix/same-shape-record-union.matrix.vl` · found closing D4989 (its matrix's un-annotated `global_*`, `array_*` and `struct_field_init` cells) · filed 2026-10-15 against master `2f625f31e`**

Repro:

    type Pa = { tag: i32, val: i32 }
    type Pb = { tag: i32, val: i32 }
    function pick(n: i32): Pa | Pb {
      const b: Pb = { tag: 2, val: n }
      return b
    }
    const g = pick(4)
    const v = g
    print(v.val)
    // vl check: rc 0.  vl run: emitProgram: field access receiver is not a struct

Want:

    4

#### Mechanism

Not localised past the ablation. `Pa | Pb` is one record in the arena and a union box in the
emitter (the same-shape collapse, D4989). A module global bound to another such global's value,
or to an element of an `(Pa | Pb | null)[]`, reads as neither the box nor the record when its
field is read.
