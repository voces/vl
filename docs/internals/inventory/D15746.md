### D15746 — a `const` copy of a copy of a hole lambda's bundle, handed to a parameter called at two types, is refused by mono

**loud emit reject · clause 2 · `monomorphize: unsupported argument type for \`b\` in a call to \`take\`` · found closing [D15741](D15741.md) · filed 2026-11-11 against master `7d0f985f`**

Repro:

    function lap(f) {
      f(2.5)
      f(3)
      return f
    }
    function take(b) {
      print(b(4))
      print(b(1.5))
    }
    const c = lap((a) => a + 1)
    const v = c
    const u = v
    take(u)

Want:

    5
    2.5

#### Mechanism

Unmeasured. D15741's close admits a holder's copies (`elabResCopies`); a copy of a copy is no
holder's copy, so its hand is noted nowhere.
