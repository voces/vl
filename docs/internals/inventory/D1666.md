#### Mechanism

against the compiler's message literals. Re-derived 2026-09-05, `emitFail` / `emitFailAt`
have **533** call sites and the predicate matches **16**; the other **517 (97%)** say nothing
about whether the refused program was legal, so no wording-keyed count can see them. A seeded

inside clause 2 — and the sixteen the predicate does match were witnessed as floors in the

This is an umbrella row. The population it stands for is
`scripts/capability-probes/live-sites.json`, one refusal literal per row with a probe that
reaches it; the measurement is `docs/internals/emit-refusal-wording-2026-09.md`. The witness
above is the plainest of the 21: the 2026-09-02 ruling that an else-less `if` used as a VALUE
is `T | null` reached the binding position and not the argument position.
