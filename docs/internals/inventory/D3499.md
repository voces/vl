### D3499 — a declared `A | B | null` substituted with a nullable pin nests the pin's null inside the union

**closed 2026-10-03 — the witness prints `n`, `s`, `null` · was check-clean invalid wasm inside `F`, clause 1 · pre-existing on master · found by #3336's review (the `ann` rows at a `string | null` pin) · filed and closed against master `04ec2ef6f` · fixture `tests/cases/generics/annotated-param-union-at-nullable-pin.vl`**

Repro:

    const ns: string | null = "n"
    function F<A, B>(k: i32, a: A, b: B): A | B | null { if k == 0 { a } else if k == 1 { b } else { null } }
    print(F(0, ns, "s"))
    print(F(1, ns, "s"))
    print(F(2, ns, "s"))
    // vl check: rc 0.  vl run: invalid module inside `F`, "expected struct type at index 0, found (array (mut i32))"

Want:

    n
    s
    null

#### Mechanism

The annotation `A | B | null` is a nullable wrapping the union `A | B`. `substTyDeep` rebuilt the
union with `A := string | null` as a member, so the instance's return type was
`(string | null | string) | null`: a union with a nullable inside it and two `string` arms. The
emitter read that as a value box nobody had collected, and `struct.new` named the string array's
type index; the caller's type was the same nested shape, which `vl check` then refused to assign
to `string | null`. Substituting the wrapper's inner now folds a null the binding put inside it
out to the wrapper and keeps each member once (`nullableFlatInner`): one type alone is the plain
nullable, `string | null`, and more stay a union, `(string | Rec) | null`. Only a union that
holds a null or a nullable member changes, so every other substitution keeps its arena identity
and its box's member order.

A first attempt spread the binding into the union arm itself; it moved the member order of
inferred joins that already built (`U[A, B, null]` at `A := string | null`), and #3336's grid
lost 98 runs, so the fold is confined to the nullable wrapper.
