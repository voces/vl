### D6763 — a generic handed to a type-parameter parameter the body never reads is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same parameter un-annotated, or handed a concrete function, runs · found closing [D6741](D6741.md) · filed 2026-10-18 against master `bd096729d`**

Repro:

    function same<T>(k: T): T { k }
    function mid<G>(a1: G) { print(1) }
    mid(same)
    // vl check: rc 0.  vl run: emitProgram: a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type

Want:

    1

#### Mechanism

From the ablation only. Nothing in `mid` calls or delivers `a1`, so no instance of `same` is
asked for, and the value has none to be built at; which instance it takes cannot be observed.
Beside a second parameter that the split divides, the refusal is a different one.
