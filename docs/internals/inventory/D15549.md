### D15549 — a generic instance's returned list of records holding a called set is built at another instance's record row

**check-clean invalid wasm · `the emitted module failed to validate inside `mk`` · clause 1 · open · one instance, or no call of the set, runs · found closing [D15297](D15297.md) · filed 2026-11-08 against master `82072a24`**

Repro:

    function inc0(a) { return a + 1 }
    function mk<T>(x: T) { return [{ fs: [inc0], x: x }] }
    print(mk(5)[0].fs[0](1))
    print(mk("s")[0].x)

Want:

    2
    s

#### Mechanism

Each instance's element literal carries its own closed type (`{fs: ((i32) => i32)[], x: string}`
on the string copy), but the module holds two record rows that both read `{ref $fs, i32}`: the
string instance builds its row with `x: i32`. The row of a record whose function set a call
reaches is keyed without the instance (the slot key of the template literal), so the two
instances share one field layout.
