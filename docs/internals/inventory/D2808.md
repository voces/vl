### D2808 — an alias-named union argument into `T | string` prints through a tag dispatch that cannot classify it

**loud emit reject · clause 2 · `gPr/al0_gnar`, `gPr/al1_gnar` of #3208's review · pre-existing on master `2bbc5c412` · filed 2026-09-27 against master `2bbc5c412`**

Repro:

    type U2 = i32 | string
    function k<T>(v: T | string) {
      print(v)
    }
    const x: U2 = 5
    k(x)
    // vl check: rc 0.  vl run: emitProgram: print of a union value whose arms the tag dispatch cannot classify

#### Mechanism

Not ablated to a rung. The same argument spelled `i32 | string` runs and prints `5`, as does
`k<T>(v: T)` with the alias. A prediction from the code, not a measurement: the alias reaches the union parameter's binding
(`exactBindWalk`/`bindGenUnionArm`) unexpanded, so `T` is bound to the alias as one member and
the instance's `v` is `U2 | string`, a member set the print plan's atom list does not flatten.
