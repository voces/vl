#### Mechanism

D9390's rung answers a union of records and value scalars; `A | null` has no scalar member,
so `sigParamTokOfTy` still renders the parameter with `tyToEmitName`, `7·2^depth` characters,
and `annParamKindTy` classifies that spelling. A depth-16 `--names` profile puts the cost under
`sigKeyOfTy` → `sigParamTokOfTy` → `annParamKindTy`, in `nullablePartOf`, `nameIsNulI32List`,
`nulScalarListKind`, `isUName` and `annUnionSigKind` → `structIndexOfTypeName` over the
`{..} | null` render. Its answer is the `nulstruct` token of the record's row. Under the null
collector the spelling outgrows the 64 MiB object cap at depth 22, which
`tests/vl_compile_gc_test.ts` uses as its trap witness.

#### Grading list

ratio stops being about 2^3. Re-grade `tests/vl_compile_gc_test.ts`, whose null-collector
trap witness is this row's at depth 22, and D9390's `A | null | string` face.

record owning its struct row gets that row's `nulstruct` token, the answer `annUnionSigKind`
gives its render. The render's scan returns the first row with the same field names whose
nested-record fields are compatible, so the rung declines unless no other scanned row can
match: `sigRowHasNoTwin` compares field names and, for a nested-record field, the canonical
