### D3580 — a generic's `q ?? b` over `q: A | null` with an `f64` default is invalid wasm at an `i32` pin

**closed 2026-10-04 — the witness prints `7` · was check-clean invalid wasm, clause 1 · the numeric face of [D2562](D2562.md) · found by the #3353 review (`dis/src/gb6.vl`) · filed 2026-10-03 against master `3b9319528`, closed against master `32b753681` · fixture `tests/cases/generics/coalesce-param-default-keeps-its-type.vl`**

Repro:

    function g<A>(q: A | null, b: f64) { q ?? b }
    function h2(): i32 | null { 7 }
    print(g(h2(), 2.25))
    // vl check: rc 0.  vl run: invalid module inside `g`: expected i32, found f64

Want:

    7

#### Mechanism

In a declared parameter's body the `??` returned the left operand's non-null type whenever the
default was assignable to it, and a type parameter takes anything, so `q ?? b` typed as `A`;
`coalJoinApart` also declined every generic body (D2562's hold). The operator now joins as the
`if` it spells (`coalParamDefault`, then `joinArmLit`), the generic body's runtime default joins
apart, and so does the pin's recheck, so the instance returns the `i32 | f64` box.
