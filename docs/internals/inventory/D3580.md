### D3580 — a generic's `q ?? b` over `q: A | null` with an `f64` default is invalid wasm at an `i32` pin

**check-clean invalid wasm · clause 1 · open · the numeric face of [D2562](D2562.md) · found by the #3353 review (`dis/src/gb6.vl`) · the same on master `3b9319528` and with #3353 · filed 2026-10-03 against master `3b9319528`**

Repro:

    function g<A>(q: A | null, b: f64) { q ?? b }
    function h2(): i32 | null { 7 }
    print(g(h2(), 2.25))
    // vl check: rc 0.  vl run: invalid module inside `g`: expected i32, found f64

Want:

    7

#### Mechanism

As D2562: the instance types the `??` at the pin's bare `A`, so it lowers the result as the
`i32` operand and hands the `f64` default to an `i32` result. The numeric-join ruling would make
the result `i32 | f64`; #3353 keeps `??` in a generic body at master's typing until this closes.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `q` an un-annotated parameter | prints `7` | **yes** (the declared type parameter) |
| `A` pinned at `f64` (`h2(): f64 \| null`) | runs | **yes** (a pin the default does not fit) |
