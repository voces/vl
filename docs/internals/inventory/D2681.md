### D2681 — [CLOSED 2026-11-17] a union a generic pin mints inside a record field annotation (`{ v: V | M }`) has no struct row for its literal

**closed 2026-11-17 · was loud emit reject · clause 2 · found grading D2676's positions · filed 2026-09-26 by the W2 lane · fixed by giving a record a pin mints a row of its own, its fields' rows first (`monoPinMintedUnion`) · fixture `tests/cases/generics/record-field-union-minted-by-pin.vl` · matrix `pin-minted-union-in-record-field` · a list-of-union field is [D16947](D16947.md)**

Repro:

    type IM = {[i32]: i32}
    function g<V>(x: IM) {
      const b: { v: V | IM } = { v: x }
      return b.v is IM
    }
    const im: IM = Map()
    print(g<string>(im))
    // vl run: emitProgram: object literal but no struct type declared

Want:

    true

#### Mechanism

The inline shape `{ v: string | IM }` exists only because the pin minted it,
and `collectS` (like `collectU` before D2657) ran before the monomorphizer, so the shape has no
struct row for the literal to build; D2678's list twin was the same gap one level up. The
direct spelling `{ v: string | IM }` runs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the pin (the direct spelling `{ v: string \| IM }`) | prints `true` | **yes** |
| the explicit type argument (`g<V>(y: V, x: IM)`, `g("s", im)`) | same refusal | no |
| the map member (a record, `{ v: V \| R }`) | `ref valtype with no interned shape` | no |
