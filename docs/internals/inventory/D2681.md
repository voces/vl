### D2681 — a union a generic pin mints inside a record field annotation (`{ v: V | M }`) has no struct row for its literal

**loud emit reject · clause 2 · found grading D2676's positions · identical on master `525837973`
· filed 2026-09-26 by the W2 lane**

Repro:

    type IM = {[i32]: i32}
    function g<V>(x: IM) {
      const b: { v: V | IM } = { v: x }
      b.v is IM
    }
    const im: IM = Map()
    print(g<string>(im))
    // vl run: emitProgram: object literal but no struct type declared

#### Mechanism

Not yet measured. The inline shape `{ v: string | IM }` exists only because the pin minted it,
and `collectS` (like `collectU` before D2657) ran before the monomorphizer, so the shape has no
struct row for the literal to build; D2678's list twin was the same gap one level up. The
direct spelling `{ v: string | IM }` runs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the pin (the direct spelling `{ v: string \| IM }`) | prints `true` | **yes** |
| the explicit type argument (`g<V>(y: V, x: IM)`, `g("s", im)`) | same refusal | no |
| the map member (a record, `{ v: V \| R }`) | `ref valtype with no interned shape` | no |
