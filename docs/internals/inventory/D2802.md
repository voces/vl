### D2802 — a generic's `v != null` refuses at a pin that cannot be null

**loud emit reject · clause 2 · found by #3208's review (`gPr` `gnnar` cells) · identical on master · filed 2026-09-27 against master `b586b6063`**

Repro:

    type LS = "a" | "b"
    function k<T>(v: T) {
      if v != null { print(v) } else { print(v) }
    }
    const x: LS = "a"
    k(x)
    // vl run: emitProgram: bare null needs a struct-typed context

#### Mechanism

Not ablated to a rung. `v != null` over a type parameter is admitted by the checker, and at a pin
with no `null` member (a literal union, `string`, `i32`) the instance lowers the comparison's
`null` operand with no nullable rep to type it, so the emitter refuses instead of answering the
comparison `true` statically. A nullable pin (`i32 | null`) runs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| a nullable pin (`k<i32 \| null>`) | runs | **yes** |
| the literal union (`k(5)`, `k("a")`) | still refuses | no |
| the `else` print | still refuses | no |
