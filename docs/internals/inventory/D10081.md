#### Mechanism

Not traced. Both lists take their element from the one binding `v`, so the emitter's plan for
`xs` (an instance per call type) and the write into `ys` meet at `v`, and the write fixing
`ys`'s element is read as fixing `v`'s. Listing `id` directly in either list runs.
