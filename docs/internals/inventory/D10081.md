#### Mechanism

Both lists take their element from the one binding `v`, and the flow table joins every slot
listing it, so the write into `ys` reached the pins of `xs`. The emit flow pass now plans a
literal-index read of an ungrown literal whose element is a `const` alias of a generic as a read
of that generic, an instance per call type. `xs`'s slot is then left with no live call, and
`monoPinListElems` asks no element instance for it. Listing `id` directly in either list ran
before.
