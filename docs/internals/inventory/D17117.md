### D17117 — a generic function handed to one type parameter and bound to a binding of another is refused at emit as reaching no call that fixes its type

**loud emit reject · clause 2 · `vl check` rc 0 · owner FREE · fixture `generics/error-binding-of-one-typaram-seeded-from-another-generic.vl` · found by IR-N7 triaging `narrowed read` · filed 2026-11-24 against master `1784a86d`**

Repro:

    function same<T>(k: T): T { return k }
    function twice<T>(k: T): T { return k }
    function mid<F, G>(a: F, a1: G) {
      let b: F = a1
      print(a("x"))
      print(b(3))
    }
    mid(same, twice)
    // vl check: rc 0.  vl run: emitProgram: a generic function taken as a value reaches no call
    // that fixes its type

#### Mechanism

The checker instantiates `F` and `G` per call (`mid(1, "s")` is refused at check, `mid(1, 2)`
runs), so `let b: F = a1` is accepted where the two arguments agree. The binding is seeded from a
parameter of another type parameter, and the emitter's flow walk finds no call that fixes the
seeded generic's type before mono's seeded-binding check runs. The design permits the program: the
refusal is emit's.

#### Ablation

| ingredient | outcome |
| --- | --- |
| `mid(1, 2)`, scalars for `F` and `G` | runs, prints `2` |
| only `print(b(3))`, `a` uncalled | runs, prints `3` |
| `mid(1, "s")`, the two disagree | refused at check, as the design owes |
