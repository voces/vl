#### Mechanism

The member read's receiver is the value `if` itself. Its node type is the union the narrowed arm
reads as, so legacy's field read finds no struct row for the receiver, though the join is written
at the record's own row (`ifJoinsAtRecord`, D17026) and a binding of the same `if` reads `.v`
from that row.
