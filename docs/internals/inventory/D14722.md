#### Mechanism

`holeLetWritesDisagreeAt` judges a call whose argument types are closed. Inside `run` the
argument's type is `U`, so the call is open, and the deferral it takes then
(`holeSlotDeferring`) judges only slot reads, not a re-pointed `let`. So nothing judges the
writes at `run`'s instance, `U = string`.

| un-annotated `id0(a)` / `one0(a)` | check reject | **yes** (generics) |
