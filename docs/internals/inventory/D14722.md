**closed 2026-11-01 — the filed repro is now a loud check reject, the refusal the design owes: `cannot write 'one' to 'f': called at (string) it returns i32, where 'idg', also written to it, returns string` · was check-clean invalid wasm (clause 1) · `holeChoiceWaits` records a call at open parameter types through a re-pointed `let` of generics (`holeLetHoldsGenerics`) as a demand, so the pin judges it at each instance's closed types as D12214 judges the top-level spelling · fixtures `tests/cases/closures/generic-let-writes-disagree-in-generic-body-refused.vl` and `generic-let-writes-agree-in-generic-body-runs.vl` (agreeing generics still run at each instance) · DESIGN: the top-level spelling is refused at check since D12214 · found closing D12214 · filed 2026-10-31 against master `38db0cb87`**

Repro:

    function idg<T>(t: T) { return t }
    function one<T>(t: T) { return 1 }
    function run<U>(x: U) {
      let f = idg
      if "ab".length < 5 { f = one }
      print(f(x))
    }
    run("s")
    // vl check: rc 1, cannot write 'one' to 'f' (was: rc 0, the emitted module fails to validate in `run`)

#### Mechanism

`holeLetWritesDisagreeAt` judges a call whose argument types are closed. Inside `run` the
argument's type is `U`, so the call is open, and the deferral it takes then
(`holeSlotDeferring`) judges only slot reads, not a re-pointed `let`. So nothing judges the
writes at `run`'s instance, `U = string`.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the call at top level, `f("s")` | check reject (D12214) | **yes** (the open `U`) |
| the condition false (`f` stays `idg`) | runs, `s` | **yes** (`one` runs) |
| un-annotated `id0(a)` / `one0(a)` | check reject | **yes** (generics) |

#### Grading list

The witness at `run(5)`, where the results agree (`i32`) and it must keep running, and
the same call through `app(f, x)`.
