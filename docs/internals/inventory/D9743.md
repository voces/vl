#### Mechanism

The parameter is a nullable whose inner type is a function, and no arena rung of
`sigParamTokOfTy` (emit_sig_tokens.vl) answers it: `sigFuncParamIsClosure` and
`sigFuncParamOfCompositeIsClosure` take a bare function type, and `sigUnionParamIsBox` only a
union. So it is rendered with `tyToEmitName`, `7·2^depth` characters, and classified by
`annParamKindTy`. A depth-15 `--names` profile puts the samples under `annParamKindTy`, in
`tyTopIndexOf` reached from `nameIsRefArray`, `canonUnionKeyOfName`, `annUnionSigKind` and
`nameIsNulI32List`, from `sigKeyOfTy` → `calleeRetKindAt` in the start function.

#### Close

`sigTyIsNulFunc` answers a nullable whose inner type is a function, with a non-empty render,
before the render is built: the parameter keeps the empty token and the result the
`nulclosure` token `annUnionSigKind` gave the render. `sigUnionMemberClass` gives a function
member the render class of its grouped arrow, so `sigUnionParamIsBox` answers a union such as
`((x: A) => i32) | string` too. A validating seed that computed both answers and trapped on any
disagreement built the 11,239 buildable corpus files with none, and a control seed trapping
where the new rungs fire trapped on 64 of them and on the witness.
