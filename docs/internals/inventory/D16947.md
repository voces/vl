#### Mechanism

The record `{ v: (string | IM)[] }` exists only at the instance. D2681's fix gave a pinned record a
row of its own, but not one holding a list of such a union, because the literal `[x]` then built its
elements bare against a boxing row and the program built invalid wasm. The bare build was
[D16953](D16953.md)'s stale rep-tree node for the list type; with the tree rebuilt once the pin
registers the union, the record takes its own row and the literal builds its elements boxed.
