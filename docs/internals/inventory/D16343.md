### D16343 — an assignment to a `K | null` record field, used as a value, yields the atom where its result is the string

**open · check-clean invalid wasm · a `type mismatch` (an `i32` where the string is wanted) inside `set` · clause 1 · the field face of [D16184](D16184.md), whose fix covers a local target only · found closing D16184 · filed 2026-11-15**

Repro:

    type K = "ww" | "zz"
    type R = { k: K | null }
    function set(r: R) { return r.k = "zz" }
    print(set({ k: null }))

Want:

    zz

#### Mechanism

Not yet ablated past its ingredients. A field target is not re-read for the assignment's
value (`assignTargetReReads` asks for a target typed as the assignment, and `K | null` is not
`"zz"`), so the value comes from another lowering, which yields the atom stored; D16184's
fix counts a re-read `K | null` target as an atom and does not reach this one.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `| null` on the field | runs, `zz` | **yes** |
| the write and the read apart (`r.k = "zz"; return r.k`) | runs, `zz` | **yes** (the value) |
| a local for the field (D16184) | runs, `ww` | **yes** (the field) |
