### D16343 — an assignment to a `K | null` record field, used as a value, yields the atom where its result is the string

**closed · runs, prints `zz` · was a module that failed to validate (an `i32` where the string is wanted inside `set`), clause 1 · the field face of [D16184](D16184.md), whose fix covers a local target only · found by D16184's fix · filed 2026-11-15 · fixed 2026-11-15 by lane L: a field or element write in value position is spilled into a `const` now typed `K | null` with the value's own type recorded (`spillTypeByTarget`, emit_rewrite.vl), and a `K | null` place counts as re-read (`assignTargetReReads`, emit_classify.vl), so the module-level `print(r.k = "ww")` is no longer an emit reject. Fixture: `tests/cases/literal-unions/asg-into-nullable-atom-field-value-runs.vl`**

Repro:

    type K = "ww" | "zz"
    type R = { k: K | null }
    function set(r: R) { return r.k = "zz" }
    print(set({ k: null }))

Want:

    zz

#### Mechanism

A field target is not re-read for the assignment's
value (`assignTargetReReads` asks for a target typed as the assignment, and `K | null` is not
`"zz"`), so the value comes from another lowering, which yields the atom stored; D16184's
fix counts a re-read `K | null` target as an atom and does not reach this one.
