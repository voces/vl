### D2194 — a list relayed through a function with no return annotation is treated as inferred, so the readonly-only rule lets the retired converting copy through it

**loud emit reject · clause 2 (the checker owed the container refusal) · filed 2026-09-23 against master `66e74235a` · narrowed the same day to this one origin: a literal wrapping an annotated list, a re-pointed `let`, a generic with a concrete result, a generic handed a map of lists and a literal `const` whose contents are stored into are now refused at check**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    const circles: Circle[] = [{ r: 7 }]
    function relay() { circles }
    const s: Shape[] = relay()
    circles.push({ r: 8 })
    print(s.length)
    // vl check: rc 0.  vl run: emit error, covariant list delivery
    // Without the push it runs through the hidden converting copy the ruling retired.

#### Mechanism

The readonly-only list rule ([D2161](D2161.md)) follows each widened list to its ORIGIN
(`listOriginExpr`): a list literal is built at the type it flows into, so it is exempt, while an
annotated list inside it, a re-pointed `let`, a generic with a concrete declared result and a
generic handed an existing list (directly, or inside a map or record argument) are judged like
any annotated list. One origin is still taken on trust: a call of a function with no return
annotation (`callResultIsInferred`). That is too wide: `relay()` has no annotation but hands
back `circles`, an annotated `Circle[]`, so the delivery is exactly the implicit widening the
ruling refuses. The checker stays silent and the emitter takes the D791 copy (read-only) or
declines it (written, the witness). Deciding it needs the provenance of every value the
function returns, which the check has not reached when the call is delivered.

#### Ablation

#### Grading list

The witness must become the container rule's check reject, and `relay()` returning a fresh
literal must keep running. Deciding it needs the return's own provenance (is every returned value
itself inferred?), not the annotation's absence.
