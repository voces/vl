### D2194 — a list relayed through a function with no return annotation is treated as inferred, so the readonly-only rule lets the retired converting copy through it

**loud emit reject · clause 2 (the checker owed the container refusal) · filed 2026-09-23 against master `66e74235a`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    const circles: Circle[] = [{ r: 7 }]
    function relay() { circles }
    const s: Shape[] = relay()
    circles.push({ r: 8 })
    print(s.length)
    // vl check: rc 0.  vl run: emit error, covariant list delivery
    // Without the push it runs through the hidden converting copy the ruling retired.

#### Mechanism

The readonly-only list rule ([D2161](D2161.md)) leaves alone a value whose type inference chose,
because an un-annotated list literal is BUILT at the type it flows into: no second handle is
narrower, so nothing widens (`srcIsInferredCtn`). It recognises such a value syntactically — a
name bound without an annotation to a list, object or map literal, a generic call no list goes
into, or a call of a function with no return annotation. The last is too wide: `relay()` has no
annotation, but it hands back `circles`, an annotated `Circle[]`, so the delivery is exactly the
implicit widening the ruling refuses. The checker stays silent and the emitter takes the D791
copy (read-only) or declines it (written, the witness).

#### Ablation

| spelling | outcome | needed? |
| --- | --- | --- |
| the witness | emit reject | — |
| `relay(): Circle[]` annotated | check reject, the container rule | the missing annotation: **yes** |
| `relay()` returning a fresh `[{ r: 7 }]` | runs, built at `Shape[]` | the annotated source: **yes** |
| the push removed | runs, through the converting copy | the write: no (only the outcome) |

#### Grading list

The witness must become the container rule's check reject, and `relay()` returning a fresh
literal must keep running. Deciding it needs the return's own provenance (is every returned value
itself inferred?), not the annotation's absence.
