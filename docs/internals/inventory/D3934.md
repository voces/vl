#### Mechanism

Not located. It traps at one instance, so it is not D3928's sharing. The alias delivered as a
callback argument, a binding or a store runs; `h` itself in the list runs; and without the first
call `h("s")` it runs. A list or record literal element reads the alias without the binding's
signature the call fixed.
