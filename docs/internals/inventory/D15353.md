### D15353 — a map of two un-annotated functions iterated by its keys and called is refused at emit

**closed 2026-11-12, runs and prints `7` then `3` · a map's `keys()` is one of the slot ops a holder of the set is read by (`ftSlotOp`, check_fn_tag.vl), since it hands out no value · was a loud emit reject, clause 2, `emitProgram: unsupported map value type`; a read by a literal key ran, so a mechanism · found grading D15233 · filed 2026-11-04 against master `73062b83`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const fnMap = Map()
    fnMap.set("a", inc0)
    fnMap.set("b", half)
    for k in fnMap.keys() {
      const f = fnMap.get(k)
      if f != null { print(f(6)) }
    }

    7
    3

#### Mechanism

Not yet probed. The same map read by a literal key (`fnMap.get("b")`) runs; the read by a key from `keys()` leaves the map's set untagged.
