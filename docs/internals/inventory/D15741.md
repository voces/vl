### D15741 — a `const` copy of a hole lambda's bundle handed to a hole parameter called at two types is refused by mono

**loud emit reject · clause 2 · `monomorphize: unsupported argument type for \`b\` in a call to \`take\`` · found grading w315's emit-reject grouping (cell `bundle_copy_closure_handed`) · filed 2026-11-11 against master `f570d7f7`**

Repro:

    function lap(f) {
      f(2.5)
      f(3)
      return f
    }
    function take(b) {
      print(b(4))
      print(b(1.5))
    }
    const c = lap((a) => a + 1)
    const v = c
    take(v)

Want:

    5
    2.5

#### Mechanism

Unmeasured. `take(c)` runs: the bundle pin (`monoBundlePin`, emit_mono.vl) reads the call
that made `c`. A `const` copy of `c` is a read it does not follow, so the argument falls to
the unsupported-argument floor. The fix is in emit_mono.vl (lane w317's file).
