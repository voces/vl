#### Mechanism

The same slot-nullability test as [D2247](D2247.md), reached with a default that is nullable
but not the `null` literal, so the fold does not apply: the fused get-with-default classified
and lowered the result as the non-null value. The D2247 change to `coalesceStaysNullable` and
`emitMapGetOr` serves every ref value. A SCALAR value's `T | null` is the value box, which the
fused read never builds, so the rewrite pass desugars a re-readable read of a `{[K]: V}` map
with a nullable default to `if m[k] != null { m[k] } else { d }` — the D962 shape, whose join
every value rep lowers. Between two plain record-or-null values (not map reads) `??` already ran.
