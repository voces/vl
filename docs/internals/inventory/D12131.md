### D12131 — a generic record alias that names itself at a larger type argument exhausts the checker's stack

**closed 2026-11-14 · now a loud check reject, provisional: `the generic type \`L\` uses itself at a larger type argument (\`L<L<i32>>\`) inside its own definition, so each instance needs a bigger one and they never end` · `applyGenAliasArgs` refuses an application whose argument holds the open application's argument under a constructor (`gaGrowsOpen`, check_relate_core.vl), or the 32nd nested application of one alias · whether a non-regular alias is legal is an open owner question (open-rulings.md §E, `D12131`); the refusal stands until it is ruled · fixture `tests/cases/generics/error-nonregular-alias.vl` · was compiler trap at check: the checker itself trapped, `vl check` rc 70 with the "compiler itself trapped" banner, where it owed a refusal naming the alias · found by the L3 legality sweep beside D2721 · filed 2026-10-24 against master `bc8b191a4`**

Repro:

    type L<T> = { v: T, next: L<L<T>> | null }
    const x: L<i32> = { v: 1, next: null }
    print(x.v)
    // was: vl check rc 70, the compiler itself trapped (call stack exhausted)

#### Mechanism

The alias is non-regular: expanding `L<i32>` needs `L<L<i32>>`, which needs `L<L<L<i32>>>`,
without end, and the checker expands it eagerly through two mutually recursive functions with
no depth bound. It is the type-level twin of D2721 (a generic function that calls itself at a
larger type argument), which the checker now refuses. A non-regular alias has no finite
structural expansion, so the checker owes a refusal naming the alias, not a trap.

Graded 2026-11-14. Declared and never used, it runs: the alias is never expanded, as D2721's uncalled growing generic runs. `L<T[]>` and the reordered fields are refused the same way. `L<T | null>` is refused too: it trapped before, but `(i32 | null) | null` interns apart from `i32 | null`, so its instances do grow. The regular `L<T>` keeps D3328's emit refusal, and `P<T> = { a: P<i32> | null, v: T }` keeps its own.

#### Grading list

A non-regular alias that is declared and never used; a nesting through a list (`next: L<T[]>[]`).
