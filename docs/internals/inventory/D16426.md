    t([{ ys: [] }])
    function t(a) { a.push({ ys: [] }); a[0].ys.push(0.5); print(a[0].ys[0]) }
    // was: vl check rc 0, vl run: invalid module inside `t`

Want:

#### Mechanism

With the declaration first, D16422's close links the body's pushed record to the literal's
element at the call, replaying the body's deferred writes. Above the declaration the body is
checked after the call, so there is nothing to replay, and the replay's pins were also withheld
there (D16424). Checking the body first restores the replay; lifting the withheld pins alone, or
checking the body inside the call rather than before the statement, leaves the same invalid
module. The check is limited to a body that writes an element into an un-annotated parameter:
checking every such callee first breaks `closures/fn-map-get-through-hole-param.vl` and
`closures/fn-list-pop-get-through-hole-param.vl`, whose parameters take their facts from the call.
