### D1728 — an if-EXPRESSION joining a hole parameter's atom with a member literal builds the string join over the atom slot, and is check-clean invalid wasm

**closed 2026-09-06 — a HOLE arm absorbs the join, so the `if` records one arm's type and the four classifiers that read it are blind together · filed against master `5530f6132`, closed against `25a59b496` · residue of [D1545](D1545.md), whose close fixed the INLINE face of this same join and left the alias one · 0 corpus cells**

Repro:

    type K = "red" | "green"
    const src: K[] = ["green", "red"]
    function take(a) {
      const b = if a == "green" { a } else { "red" }
      print(b)
    }
    take(src[0])
    // vl check: rc 0.  vl run: rc 0, prints green

Was: `invalid module`, `type mismatch: expected i32, found (ref $type)`.

#### Mechanism

Measured, where the row filed it as predicted — and the filed guess was right about the arms
and wrong about who could see it. `joinTys` collapses on mutual assignability and a hole is
assignable both ways, so `joinTys(<hole>, "red")` returns the HOLE: the `if` records the
PARAMETER's type, which the pin then resolves to `K`. Probed at `ifExprRefKind`, the recorded
join type reads `recTy=65 recKind=-1 recName=[]` against the annotated body's `recTy=5
recKind=3 recName=[string]`, with `thenAtom=1 elseStr=1` in both.

Four classifiers ask that one signal as `tyKindOf(nodeTyIxOf(ifIx)) == 3`, and all four are
blind together: `ifExprRefKind` (the blocktype, which then takes the numeric path and stages a
string ref into an `i32` block), `exprString`'s `IfStmt` arm, `exprHasStrOp`'s, and
`exprString`'s **Ident** arm, where `unionIdentReadKind` claims the binding because
`unionNameOfExpr` reads that same recorded type and answers `K`. Each now asks the ARMS when
the recorded type cannot say — one arm an atom, the other a string means the string ref, and
the atom arm widens.

**Fixing it in the checker instead was measured and REFUSED.** Minting the join as a deferred
join (`joinRetTys`, the return path's existing machinery) makes `substTyDeep` re-fold it at the
pin — and costs **three `runs` cells** and two new wrong VALUES, because the deferred join
escapes to an emitter with no rep for it. Lifting the checker before wiring the emit side is
the shape D965 names; the arm-read is the narrow fix that ships.
