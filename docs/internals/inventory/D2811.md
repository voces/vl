### D2811 — `v128` had no token in the function-value ABI, so no function value could take or return a vector

**closed 2026-09-27 — the filed repro RUNS and prints `9` · plumb PL-051 · closed by giving `v128` the `$fnsig` token `X` at every producer (the AST, annotation and arena ones) · filed 2026-09-27 against master `2bbc5c412` · 192-cell grid (arity 1/2/4/8 × all-v128 / v128+i64 interleaved / plumb's `(i64,i64,i64,i64,v128,v128,v128,v128)` × result i64/boolean/v128 × named fn, lambda, un-annotated lambda, closure capturing a v128, list element, record field, local binding): 192 emit refusals on master, 192 RUNS with the expected value after**

Repro:

    import { toString } from "std:fmt"
    function lane0(v: v128): i64 { __extract_lane_i32x4__(v, 0) as% i64 }
    function runWith(fn: (v128) => i64): i64 { fn(__splat_i32x4__(9)) }
    print(toString(runWith(lane0)))
    // master: emitProgram: a function value's signature is not yet supported — parameter `v` of type `v128` has no representation in the function-value ABI

#### Mechanism

A function value is called through an interned `$fnsig`, keyed one token per parameter and
one for the result (`repSigTokOfKind`, decoded by `repKindOfSigTok`). `v128` had no token, so
`cloSigKeyExt` answered "" for any function with a vector in its signature and
`emitClosureValueCore`'s floor refused the value. At a call through an annotated function
type the annotation producers (`annParamKind`/`annRetKind`, `paramTokOfTy`/`retTokOfTy`)
also answered "", so the call fell to the all-i32 arity functype: `function-value call arity
has no interned signature` when none of that arity existed, check-clean invalid wasm when one
did (D2810). The valtype writer already knew `v128`; only the token was missing.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the vector (an `i64` parameter instead) | runs | **yes** |
| the function value (call `lane0` directly) | runs | **yes** |
| the named function (a lambda instead) | refuses | no |
| the result (a `(v128) => void` sink) | refuses | no |
