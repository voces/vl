### D16952 — [CLOSED 2026-11-18] a field read across record arms whose shared field is a list of records in one arm has no struct receiver

**closed 2026-11-18 · was loud emit reject, `emitProgram: field access receiver is not a struct` · clause 2 · found grading [D16951](D16951.md) · filed 2026-11-17 against master `586cc6b4c` · fixed by boxing a record list under its list's arm tag (`refListArmTagOfTy`, the tag the `is` test reads) · fixture `tests/cases/records/shared-field-read-record-list-arm.vl` · matrix `shared-field-read-record-list-arm`**

Repro:

    function q(b: boolean): {f: i32} | {f: {a: i32}[]} {
      if b { return { f: 5 } }
      return { f: [{ a: 9 }] }
    }
    const v = q(false).f
    if v is i32 { print(v) } else { print(v[0].a) }
    // vl check: rc 0.  vl run: emit error, the refusal above

Want:

    9

#### Mechanism

The read's type `i32 | {a: i32}[]` is a value-union box, and its row has no variant arms: a record
list rides it under its ref-list slot's tag (`refArrSlotTag`), the tag `isArmTagOfTy` tests. The
shared read's boxing plan (`sharedFieldArmsBoxable`) took a list by its box kind (D16951), which a
record list has none of, and a record by its union arm (D16949), which this union has none of, so
the plan declined and the read fell to the plain struct read. The arm tag is now one function,
`refListArmTagOfTy`, read by the `is` test and by both list arms of the plan; the nullable arm
(`sharedFieldArmNulListTag`) answers a tag rather than a kind, so `{a: i32}[] | null` boxes a null
ref under the null tag and any other under the list's.
