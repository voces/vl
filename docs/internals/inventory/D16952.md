### D16952 — a field read across record arms whose shared field is a list of records in one arm has no struct receiver

**loud emit reject · `emitProgram: field access receiver is not a struct` · clause 2 · found grading [D16951](D16951.md) · filed 2026-11-17 against master `586cc6b4c`**

Repro:

    function q(b: boolean): {f: i32} | {f: {a: i32}[]} {
      if b { return { f: 5 } }
      return { f: [{ a: 9 }] }
    }
    const v = q(false).f
    if v is i32 { print(v) } else { print(v[0].a) }
    // vl check: rc 0.  vl run: emit error, the refusal above

Want:

    9

#### Mechanism

Not traced. The shared read boxes a list arm under its kind's tag (D16951), but a list of records
is a ref list, whose box kind the plan does not take: the read declines to the plain struct read
as before. The nullable spelling `{f: {a: i32}[] | null}` is refused the same way on master,
where a nullable scalar list runs.
