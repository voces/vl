### D3259 — a function ending in a labelled block whose body returns was refused as able to fall off its end

**closed 2026-09-29 (a labelled block is total when its body is and no `break :B` leaves it, `nodeIsTotalAt` / `breaksToLabel` in `compiler/typecheck.vl`) · was a loud check reject of a legal program, clause 2, new with #3293 · filed against #3293's landing head `febbf67e9` · fixture `tests/cases/loops/labelled-block-total.vl`**

Repro:

    function f(c: boolean): i32 {
      @B { return 1 }
    }
    print(f(true))
    // was: check reject, not all code paths return a value
    // now: prints 1

Want:

    1

#### Mechanism

`nodeIsTotalAt` answered `false` for every labelled block, because it can end early with a
`break :B`. A block with no such break completes exactly when its body does, so it now reads
the body's totality and scans the body for a `break` naming its label. A bare `break` cannot
leave a block (E0695), so the label is the only way out.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| a `break :B` before the `return` | check reject (correct: it can fall off) | **yes** |
| no block (`return 1` bare) | runs | **yes** |
