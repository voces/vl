### D16292 — a hole lambda a function returns by name, called inline on the call's result, has no interned signature at emit

**loud emit reject · clause 2 · `vl check` rc 0 · the inline face of [D14881](D14881.md), whose close covered the bound spelling only · found ablating [D16291](D16291.md) · filed 2026-11-14 against master `94f5055d`**

Repro:

    const lam = (x) => x
    function mk() { return lam }
    print(mk()(3))
    // vl check rc 0.  vl run: emit error 3:14: emitProgram: a function-value call has no
    // interned signature — parameter 1 of type `_` has no representation

Want:

    3

#### Mechanism

D14881's close builds the maker at the signature its result is called at when the result is a
`const` that is only called (`const q = mk(); q(3)`). A call whose callee is itself a call
(`mk()(3)`) is not such a binding, so the maker keeps the lambda's open signature and the call
reaches emit with a hole parameter type.

#### Ablation

| spelling | outcome | needed? |
| --- | --- | --- |
| the witness | emit reject | — |
| `const q = mk()`, `print(q(3))` | runs, prints `3` | the inline call: **yes** |
| `function mk() { const l = (x) => x + 1; return l }`, `print(mk()(5))` | emit reject | where the lambda is bound: no |
| the same maker with hole parameters (`compose(f, g)` returning a bound `h`), called inline | emit reject | no |

#### Grading list

The witness, the in-body binding spelling, and the hole-parameter maker, each called inline and
called twice inline at two types.
