### D17564 — the IR's claimed call of an un-annotated function read from a `Map()`, in a string interpolation hole, passes the wrong valtype

**closed 2026-11-25 by lane COV-CALL · runs under `VL_IR_STRICT=1`, prints `i=6` · was check-clean invalid wasm under `VL_IR_STRICT=1`, the IR's claim invalid inside `go` (expected i32, found the `string` ref) · clause 1 · the call through the map's function is a tagged set's dispatch, whose set-id stash (`RTagStash`) the IR wrote above the string literal the concatenation writes first; where a box leads the dispatch (`irBoxLeadBox`) its head also jumped the literal. `irBStageLeads` now stages an earlier operand below a tag stash (`tagStashFrom`), as `tagStashEffect` writes it, and declines (`dispatchBoxFrom`) where a led box holds one, so the concatenation, a call's argument, a list element and a record field miss cleanly; binary arithmetic stages its left operand the same way · fixture `closures/tag-dispatch-call-after-an-operand-positions.vl` · found by COV-START's Q58 sweep · owner SOUND, closed by COV-CALL · filed 2026-11-25 against master `b126d3fe`**

Repro:

    function inc(a) { return a + 1 }
    const m = Map()
    m["k"] = inc
    function go() {
      const f = m["k"]
      if f != null { print("i=\{f(5)}") }
    }
    go()
    // VL_IR_STRICT=1 vl run: invalid module inside `go`, expected i32, found (ref $3) (`string`)

Want:

    i=6

#### Mechanism

`m["k"]` holds a tagged function set of one member, so `f(5)` is legacy's `emitFnTagDispatch`: the
callee's set id stashed (`tagStashTail`), then the member's direct call. In the hole, the call is
boxed into `toString`'s union and concatenated after the literal `"i="`. Legacy writes the literal,
then the box's tag, then the stash, the call and the payload. The IR wrote the stash (`RTagStash`)
as a statement above the literal: `irBStageLeads` staged an earlier operand only below a valued
`if`, a `??` or a field stash. The box over the dispatch writes its head ahead of the dispatch
(`dispatchBoxHead`), which also put the head above the literal. The armed shadow read
`mismatch bytes: call at 0x23 vs 0x41`.

#### Ablation

All under `VL_IR_STRICT=1` on master `b126d3fe`.
