### D16446 — a spread of a `const` holding one of several calls of a fresh record list maker, beside a part at a wider record, is refused

**loud check reject · clause 2 · `this list holds elements built as {x: f64} where line 4 gives them, and elements held at their own {x: i32} here` · found closing [D16445](D16445.md) · filed 2026-11-15 against master `314123b83` · open**

Repro:

    function mk() { return [{ x: 1 }] }
    const s = mk()
    const t = mk()
    const l = [{ x: 2.5 }, ...s]
    print(l[1].x)
    print(t[0].x)
    // vl check: this list holds elements built as {x: f64} where line 4 gives them, and elements held at their own {x: i32} here

Want:

    1
    1

#### Mechanism

Not yet located in the emitter. A maker called more than once keeps its own record, so the call
`s` holds must be copied into the literal's element (`recFreshCallCopy`, `listCopyTyIx`). The
binding's row is read from its initialiser (`listRowOfExpr`, emit_classify.vl), the call's own
list, so a copy recorded there builds an invalid module (scratch); D16445 takes only the one-call
maker, which is built where its call lands instead.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const t = mk()` removed | prints `1` since D16445 | **yes** (the second call) |
| `const n: { x: i32 }[] = mk()` as the second call | the same refusal | no |
| the copy recorded on `s`'s initialiser (scratch) | invalid module | — (the binding row) |
