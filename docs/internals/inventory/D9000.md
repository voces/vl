### D9000 — an un-annotated function handed to a generic whose result wraps the arrow's result type (`U[]`) leaves that result open

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same call with an annotated destination `const ys: i32[] = m([3], inc0)` runs, and so does an annotated `inc0(a: i32)` · found closing [D8981](D8981.md) · present on master `da95613f6` · filed 2026-10-21 against master `da95613f6`**

Repro:

    function inc0(a) { return a + 1 }
    function m<T, U>(xs: T[], k: (a: T) => U): U[] { return xs.map(k) }
    print(m([3], inc0)[0])
    // vl run: emitProgram: index receiver is not an array or string

#### Mechanism

Not traced past the checker. [D8943](D8943.md)'s close reads the handed function's body at the
bound parameter types and substitutes the result into the call's result only when that result
is the bare type variable (`holeFnRetSubst`, `compiler/check_relate_core.vl`): `R` closes, `U[]`
stays `_[]`, and no instance is taken at the element.

#### Grading list

The `const` lambda and `const` alias spellings of the repro, and a result wrapping `U` in a
nullable (`U | null`) or a record field.
