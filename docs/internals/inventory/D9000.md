### D9000 — an un-annotated function handed to a generic whose result wraps the arrow's result type (`U[]`) leaves that result open

**closed · runs, prints `4` · was loud emit reject, `emitProgram: index receiver is not an array or string`, `vl check` rc 0 · clause 2 · found closing [D8981](D8981.md) · filed 2026-10-21 against master `da95613f6` · closed by substituting the handed body's result through the whole parameter result, not only a bare type variable (`holeFnRetSubst`, check_relate_core.vl) · fixtures `closures/hole-fn-to-generic-fn-param-wrapped-result.vl`, `closures/error-hole-fn-to-generic-fn-param-wrapped-result-mistyped.vl`, matrix `hole-fn-to-generic-fn-param-wrapped-result` · [D9002](D9002.md) closed by the same change**

Repro:

    function inc0(a) { return a + 1 }
    function m<T, U>(xs: T[], k: (a: T) => U): U[] { return xs.map(k) }
    print(m([3], inc0)[0])
    // vl run: emitProgram: index receiver is not an array or string

#### Mechanism

[D8943](D8943.md)'s close reads the handed function's body at the bound parameter types and
substituted the result into the call's result only when that result was the bare type
variable (`holeFnRetSubst`, `compiler/check_relate_core.vl`): `R` closed, `U[]` stayed `_[]`,
and no instance was taken at the element. The close walks the whole result, through lists,
nullables, maps, records, functions and unions.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the hole (`inc0(a: i32)`) | runs, `4` | **yes** |
| the result wrapping `U` (`apply<T, R>(h: (T) => R, x: T): R`) | runs ([D8943](D8943.md)) | **yes** |
| the annotated destination, added (`const ys: i32[] = ...`) | runs, `4` | **yes** |
| `xs.map(k)`, for a loop pushing `k(x)` | same emit refusal | no |
| the list argument, for `m(x: T, k): U[] { return [k(x)] }` | same emit refusal | no |
| the `[0]` index (`.length`) | emit refuses, `'.length' on a receiver the emitter cannot classify` | no |
| the name, for a `const` lambda `(a) => a + 1` | same emit refusal | no |

#### Grading list

The `const` lambda and `const` alias spellings of the repro, and a result wrapping `U` in a
nullable (`U | null`) or a record field.
