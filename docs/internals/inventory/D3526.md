### D3526 — a value delivered into a `Box<i32> | i32` union after its initialiser is built at the union's scalar rep

**check-clean invalid wasm · clause 1 · open · the same on master `331f5e998` · found by the #3342 review (its `gu/` grid, `u6__let` and `u6__map`) · filed 2026-10-03 against master `331f5e998` by lane LJ**

Repro:

    type Box<T> = { v: T }
    let u: Box<i32> | i32 = 1
    u = { v: 7 }
    print(u is Box<i32>)
    // vl check: rc 0.  vl run: invalid module, "type mismatch: expected i32, found (ref $type)"

Want:

    true

#### Mechanism

Not localised past the ablation. The arm is a generic application (`Box<i32>`); with a plain
record of the same shape every position runs. The initialiser builds the box (`let u: Box<i32>
| i32 = { v: 7 }` runs), so it is the later deliveries that take the union as a scalar: an
assignment of a literal or a variable, and a map `set`. Not the lambda join of
[D3520](D3520.md); it was graded with [D3521](D3521.md) for want of an id.

#### Grading list

Every row of the ablation table: the positions that refuse loudly are the same union's
clause-2 face, and a fix that builds the box at one delivery has to grade the others.
