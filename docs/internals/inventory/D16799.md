### D16799 — a hole lambda returned by a function with an un-annotated parameter, called at an `i32` and an `f64` argument, builds one lambda for both

**loud emit reject · `vl check` rc 0, then `emitProgram: a function value is called at two signatures, and the closure it holds was built for one` at the `f64` call; filed as a module that failed to validate inside `__lambda_2`, moved loud by master's hole-maker refusal (re-graded against master `1082f975e`) · still open, clause 2 · found grading [D16778](D16778.md) · filed 2026-11-16 against master `eaa93e525`**

Repro:

    function adder(n) { return (a) => a + n }
    const v = adder(2)
    print(v(3))
    const x = adder(1.5)
    print(x(2.0))
    // vl check: rc 0.  vl run: emit error, a function value is called at two signatures

Want:

    5
    3.5

#### Mechanism

Not traced. The two calls pin `n` at `i32` and at `f64`, two instances of `adder`; the lambda each
returns reads its instance's `n`, so each instance needs its own lambda instance, and the module
holds one lambda built for both.
