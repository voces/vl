### D14797 — a closure whose tail writes a value `if` of hex literals into a captured `f64` cell builds invalid wasm when its result is read

**check-clean invalid wasm · clause 1 · open · pre-existing on master `0af3bcd8b` · found beside D14796 · filed 2026-11-01 against master `0af3bcd8b`**

Repro:

    function g(c: boolean) {
      let d: f64 = 0
      const setd = () => {
        d = if c { 0xfffffffe } else { 1 }
      }
      print(setd())
      print(d)
    }
    g(true)

Want:

    -2
    4294967294

#### Mechanism

D14796's shape at an `f64` place: the tail's temp holds the value the cell built (`f64`), and the
closure yields it where its result is the `i32` join. D14796's fix yields the `i32` pattern of an
`i64`-held temp; an `f64`-held one needs its own conversion back to the 32-bit pattern, which a
`wrap` cast does not give.
