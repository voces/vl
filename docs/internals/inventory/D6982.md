### D6982 — an uncalled hole function's name as the last statement of an else-less `if` that ends a function is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same program with `exclaim(s: string)` runs, and the `if` followed by any statement runs ([D6960](D6960.md)) · found closing [D6960](D6960.md) · present on master `641dc8172` · filed 2026-10-19 against master `641dc8172`**

Repro:

    function exclaim(s) { return s + "!" }
    function f() {
      if true {
        print(1)
        exclaim
      }
    }
    f()
    // vl check: rc 0.  vl run: emitProgram: cannot take the generic function `exclaim` as a value — a function value carries ONE signature

Want:

    1

#### Mechanism

From the ablation only. The else-less `if` is `f`'s tail, so its value is `f`'s result, a
nullable function, and the name is a value use, not a discarded statement. Nothing reads `f()`'s
result, but the inertness walk does not follow an unread call result back into the callee's tail.
