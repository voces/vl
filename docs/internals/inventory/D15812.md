### D15812 — an `if` of record literals delivered to a generic's `{f: i32} | {f: T}` at a `string` instance builds both arms at the `i32` arm's struct

**check-clean invalid wasm · clause 1 · the `string` face of [D15042](D15042.md) · filed 2026-11-12 against master `487d86004`**

Repro:

    function g<T>(b: boolean, t: T) {
      const v: {f: i32} | {f: T} = if b { {f: 1} } else { {f: t} }
      print(v.f)
    }
    g(true, "x")
    g(false, "y")
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `g` (expected i32, found (ref $1))

Want:

    1
    y

#### Mechanism

D15042's close reads a literal whose checked type holds a type parameter at the instance's
elaborated type, which builds the `f64` instance's `{f: t}` at its own arm. At a `string`
instance the value `if`'s lowering (`emitUnionIfValue`) still builds both arms with the
`{f: i32}` struct and tag 0, so a reader on that path keeps the template's default rep. Not yet
located.
