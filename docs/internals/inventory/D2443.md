### D2443 — an alias of a local or parameter that shadows a module function takes the function's cell

**check-clean invalid wasm · clause 1 · found in review of #3148, the same on master `a20d69104` · filed 2026-09-25 against master `a20d69104`**

Repro:

    function w(): string { return "top" }
    function g() {
      const w = 1
      const r = w
      print(r)
    }
    g()
    // vl check: rc 0.  vl run: invalid module, inside `g`:
    // "type mismatch: expected (ref $type), found i32".  Expected: 1

#### Mechanism

A prediction until a close confirms it. `r`'s cell is classified from its init `w`, an `Ident`,
through a rung that reads `w` as the module FUNCTION (a function value, the closure cell)
before asking whether a binding of the frame shadows it. The value read of `w` itself is right
(`print(w)` runs), so only the binding's cell classifier is unpositioned. A parameter `w`
(`function g(w: i32) { const r = w … }`) and an `f64` module function fail the same way.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| no module function `w` | runs, `1` | **yes** |
| `print(w)` instead of the alias | runs, `1` | **yes** |
| `w` a parameter instead of a local | still invalid | no |
| the module function returning `f64` | still invalid | no |
