### D2995 — a record literal bound inside a nested block is not re-seated at the wider declared record it is handed to

**check-clean invalid wasm · open · identical on master `b34730ad9` · found by lane WD's D2987 read grid · filed 2026-09-28**

Repro:

    type D = { v: f64 }
    const x: i32 = 3
    function g(d: D) { print(d.v / 2.0) }
    if true {
      const q = { v: x }
      g(q)
    }
    // vl check: rc 0.  vl run: invalid module — type mismatch

Want:

    1.5

#### Mechanism

Not localised past the ablation. The D2933 use walk (`objLitBindDestRow`) re-seats `q` at `D`
when `q` is bound at the top of a function body or the module; bound one block deeper, at the
module or inside a function, the argument is built at `q`'s own `{v: i32}` record. The walk's
scope root (`dsScopeRootOf`) or the local's slot type, decided before the arena is final, is
the likely seam.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |

| module scope (the block inside a function) | same invalid wasm | no |
| the parameter (a `{[string]: D}` map store instead) | same invalid wasm | no |
