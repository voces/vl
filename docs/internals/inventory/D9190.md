### D9190 — a generic function held in a list element, a record field or a call result, called inside a generic body whose type parameter shares the callee's name, is check-clean invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · `type mismatch` inside `f` · clause 1 · found closing [D9160](D9160.md) · present on master `8747b6432` · filed 2026-10-21 against master `8747b6432`**

Repro:

    function idg<T>(t: T): T { return t }
    function kg<T>(t: T): T { return t + t }
    const c = [1].length > 0
    function f<T>(v: T): T {
      const fs = [if c { kg } else { idg }]
      print(fs[0]("s"))
      return v
    }
    print(f(3))
    // vl check rc 0, vl run: invalid module, the emitted module failed to validate inside `f`

#### Mechanism

Not traced. It is [D9160](D9160.md)'s ingredient at three more delivery positions: the
enclosing instance binds `T` to `i32`, and the callees' own `T` is closed by that binding
because the two share a name. D9160's fix keeps the callees' open signature at a binding, an
inline choice, a generic argument and a `.map` callback. It does not reach a list element, a
record field or a call result, which are typed by other paths.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the name clash, for `f<S>(v: S): S` | runs, `ss` `3` | **yes** |
| the generic body, for `f(v: i32): i32` | runs, `ss` `3` | **yes** |
| the choice, for `[kg]` | runs, `ss` `3` | **yes** for a list element |
| the list, for `const h = if c { kg } else { idg }` | runs (D9160's fix) | **yes** |

#### Grading list

- The same list called at the body's own parameter, `print(fs[0](v))`. It loads, then traps with
  `indirect call type mismatch`.
- The choice held in a record field, `const r = { h: if c { kg } else { idg } }; print(r.h("s"))`,
  for both an `if` and a `match`.
- The callee returned by a function and called in the body:
  `function pick() { return kg }` then `print(pick()("s"))`. This fails even with no choice.
- Arms whose type parameters have different names (`idg<U>`, `kg<T>`) in a list element.
