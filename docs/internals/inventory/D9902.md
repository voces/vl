### D9902 — a returned local nested list of an un-annotated function, bound from a call with an argument and read at two types, has no interned shape

**loud emit reject · `vl check` rc 0 · `ref valtype with no interned shape` · clause 2 · found closing [D9763](D9763.md) · present on master `23ac8244a` · filed 2026-10-22 against master `23ac8244a`**

Repro:

    function inc(a) { return a + 1 }
    function deliver(_n) {
      const u = [[inc]]
      return u
    }
    const w = deliver("s")
    print(w[0][0](3))
    print(w[0][0](2.5))
    // vl check rc 0.  vl run: emit error: emitProgram: ref valtype with no interned shape

#### Mechanism

Not traced. [D9763](D9763.md)'s close lets the flow-read rewrite follow `return u`, and the same
program with no parameter on `deliver` now runs, so the argument is what differs: the call
`deliver("s")` instantiates the un-annotated `deliver` at `string`, and the nested row type of
that instance is a reference type the interner never built. The message carries no node, so the
failing site is not yet located.
