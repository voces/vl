### D15370 — a fresh list of record lists, bound and delivered whole to a list of lists of a wider record, is check-clean invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · open, target `7` · found closing [D15287](D15287.md), whose original nested witness this row now carries verbatim · filed 2026-11-04 against master `b7e08d5a`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const ys = [[mk()]]
    const more = [[{ f: 7 }]]
    ys.push(...more)
    print(ys[1][0].f ?? 0)

Want:

    7

#### Mechanism

Not ablated past the table. A fresh list binding delivered whole to a list of a wider record adopts
that list (`recAdPushDecl` with `elem`), one level deep. A list of record LISTS bound and delivered
to `J[][]` is not adopted at the inner level, so its inner lists stay `{f: i32}[]` and are handed to
a list of `J[]`. The spread witness above is that whole delivery through a push.
