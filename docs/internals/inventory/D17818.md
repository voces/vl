#### Mechanism

The destination is closed and names the signature the hole function is taken at, so the design
permits the program. The non-null spelling (`else { inc }`, delivered at `(x: i32) => i32`) runs:
a function value delivered at a closed function type is pinned there. The nullable choice's arm
is not, so the hole function reaches emit with no call that fixes its type. This is independent of
the wider result: the same refusal holds at `(x: i32) => i32 | null` and at the wider
`((x: i32) => i32 | f64) | null`, where D17816's nullable adapter (`fvaAdaptNullable`) declines
an open source and leaves it to this path.
