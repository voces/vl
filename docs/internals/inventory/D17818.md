### D17818 — a nullable choice of an un-annotated or generic function, delivered at a closed nullable function type, is not pinned by that type and is refused at emit

**loud emit reject · clause 2 · `emitProgram: cannot take the generic function \`inc\` as a value — a function value carries ONE signature, and parameter \`a\` is un-annotated` (a generic member: `a generic function taken as a value reaches no call that fixes its type`) · `vl check` rc 0 · filed 2026-11-28 against master `e68eafd9a` by I8-PREP (D17816's nullable face, coordinator ruling)**

Repro:

    function inc(a) { return a + 1 }
    function two() { return [1, 2].length }
    const h = if two() > 1 { inc } else { null }
    const z: ((x: i32) => i32) | null = h
    if z != null { print(z(3)) }
    // vl check: rc 0.  vl run: emit error at `inc` (cannot take the generic function `inc` as a value)

Want:

    4

#### Mechanism

The destination is closed and names the signature the hole function is taken at, so the design
permits the program. The non-null spelling (`else { inc }`, delivered at `(x: i32) => i32`) runs:
a function value delivered at a closed function type is pinned there. The nullable choice's arm
is not, so the hole function reaches emit with no call that fixes its type. This is independent of
the wider result: the same refusal holds at `(x: i32) => i32 | null` and at the wider
`((x: i32) => i32 | f64) | null`, where D17816's nullable adapter (`fvaAdaptNullable`) declines
an open source and leaves it to this path.

#### Ablation

Graded on master `e68eafd9a` and on D17816's nullable-face head.

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `null` arm (`else { inc }`, a non-null destination) | runs, prints `4` | **yes** |
| the hole (`inc(a: i32)`) | runs, prints `4` | **yes** |
| the wider result (`(x: i32) => i32 \| null`) | still refuses | no |

#### Grading list

- A generic member: `function id<T>(x: T): T`, `if c { id } else { null }` at `((x: i32) => i32) | null`: `a generic function taken as a value reaches no call that fixes its type`.
- The wider-result spelling, `((x: i32) => i32 | f64) | null`, which D17816's adapter then takes.
