### D5282 — `==` over a recursive record, through a list of itself, has no compare core

**loud emit reject · `vl check` rc 0 · clause 2 · OPEN · found closing D5281 · filed 2026-10-17 against master `3f6a785db`**

Repro:

    type N = { v: i32, kids: N[] }
    const a: N = { v: 1, kids: [{ v: 2, kids: [] }] }
    const b: N = { v: 1, kids: [{ v: 2, kids: [] }] }
    print(a == b)
    // vl check: rc 0.  vl run: emitProgram: list compare over an element rep with no core

Want:

    true

#### Mechanism

The record's field-wise compare core is generated by walking its fields, and the `N[]` field
asks for the list core of `N`, which in turn asks for the record core still being generated.
The core registry has no forward entry for a core under construction, so the walk declines and
the list compare refuses. A mutually recursive pair (`A { bs: B[] }`, `B { as: A[] }`) refuses
with the same sentence.
