#### Mechanism

Not traced. The function value's result resolves to `A1`'s struct rather than `A10`'s, so the
function type the call goes through is keyed by something that loses the record at ten levels
of doubling. A renamed `A10` (`Top`) fails the same way, so the name is not the key. When the
call's result is read at once (`f(1).l.l…`) or the value is bound (`const f: (x: i32) => A10 = mk`),
the same loss is a loud `field access receiver is not a struct` instead.
