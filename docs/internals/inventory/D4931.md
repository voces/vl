### D4931 — a generic forwarding its `V[] | i32[]` parameter to another generic's `W[] | i32[]` binds no `W`

**loud emit reject · clause 2 · found closing D4922 · the same on master `bb21e081b` · filed 2026-10-15**

Repro:

    function len<W>(a: W[] | i32[]) { a.length }
    function fwd2<V>(a: V[] | i32[]) { print(len(a)) }
    fwd2(["z"])
    // vl check: rc 0.  vl run: emitProgram: monomorphize: unsupported argument type for `a` in a call to `len`

Want:

    1

#### Mechanism

Not localised past the ablation. Inside `fwd2`'s instance the argument is `string[] | i32[]`,
and the inner call's binding of `W` against it fails, though the same call from a concrete
`fwd2(a: string[] | i32[])` binds `W := string` (D4922's `bindGenUnionShapedArmInto`). The
forwarded argument reaches `monoBindCols` in a shape that walk does not read as a union.
