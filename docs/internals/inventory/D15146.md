### D15146 — a function's inferred return of a bundle record checks at one member's signature, so an annotated destination refuses it

**loud check reject · capability, not design · narrowed 2026-11-04: an annotated binding read by calls now takes the member a returned record of members names (`bundleMemberFits`, `letCstrBundleServed`, check_assignable.vl), and every position still refused says so (`… taking the member this destination names is not yet supported at this position`) · this witness stays refused because `mk` hands back another call's result, the `return_inferred` position (generic twin [D15243](D15243.md)); the other positions are [D15242](D15242.md) · filed 2026-11-03 against master `dce58665` by lane bundle-value, found grading `returned-bundle-record-generic.matrix.vl`**

Repro:

    function lap(f) {
      f(2.5)
      f(3)
      return f
    }
    function mk(k: i32) {
      return lap((a) => a + k)
    }
    const v: (x: f64) => f64 = mk(1)
    print(v(4))
    // vl check: rc 1, `cannot assign (i32) => i32 to 'v' of type (f64) => f64 (the callee's
    // body at the call's argument types)`, at `lap(...)` inside `mk`.

#### Mechanism

`lap` calls its parameter at `(f64) => f64` and `(i32) => i32`, so its value is a record of one
closure per signature (D15144). Where `lap(...)` is annotated directly
(`const v: (x: f64) => f64 = lap(...)`) the checker accepts it, and emit picks the `(f64)` member.
Through `mk`, the checker reads `mk`'s inferred return from its body at the call's argument types
and gets one member, `(i32) => i32`. In this witness that is the signature of `lap`'s last call
of `f`; which member it picks in general is not yet measured. That member is not assignable to
the annotated `(f64) => f64`. The program is type-valid: the same value at the
neighbouring spelling runs.

#### Ablation

| spelling | outcome |
| --- | --- |
| this witness, `v` annotated `(x: f64) => f64` through `mk` | check refuses |
| `const v: (x: f64) => f64 = lap((a) => a + 1)` (no `mk`) | runs, prints `5` |
| `const v = mk(1)` (no annotation) | runs, prints `5` (#6143) |
| `mk` annotated `: (x: f64) => f64` | emit refuses: no member pick at an annotated return |
| `mk` generic, holding the record and returning it | check refuses, same message |
