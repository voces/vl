#### Mechanism

`narrowedValueAtomOf` (`emit_start_block.vl`) decides what a narrowed read of a value-union box
unboxes as. Its literal-union leg tested the narrow's rendered name with `nameIsLitUnionType`,
which answers only for a name that a declared alias registered. The declared spelling
(`type K = "aa" | "bb"; x is K`) therefore unboxed to the string the box stores, while the inline
spelling with different members fell through to `""` and the read delivered the box itself where
`print` and `+` wanted a string.
