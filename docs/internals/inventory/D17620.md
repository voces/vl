### D17620 — a function parameter called at two signatures, returned from a closure and handed on, meets a call key the tag decision's arrow facts lack

**loud check reject · clause 2 · `internal: an instance call through a function set the check decided from the arrow facts meets a key those facts lacked` · found by COV-CALL's Q58 sweep of captured bundle parameters · owner unassigned · filed 2026-11-25 against master `4fbb6097`**

Repro:

    function take(b) { print(b(7)) }
    function ret(f) {
      print(f(2.5))
      const h = () => f
      take(h())
    }
    ret((a) => a + 1)
    // vl check: rc 1 (the emit refusal, reported by check).  vl run: emit error

Want:

    3.5
    8

#### Mechanism

`emit_sections.vl` refuses an instance call whose function set the check decided from the arrow
facts when it meets a key those facts did not record. `f` is called at `(f64)` in `ret` and at
`(i32)` in `take`, so it is a bundle of two instances. Handed straight to `take`, it runs. Read back
out of a closure's result (`h()`), the value reaching `take`'s `b(7)` carries no key the arrow facts
banked for that set.

#### Ablation

| spelling | outcome |
| --- | --- |
| `take(h())`, `h = () => f` | refused |
| `const g = h(); take(g)` | refused |
| `take(f)` | runs, `3.5` then `8` |
| `f` handed through a closure's capture (`const k = () => take(f); k()`) | runs |
