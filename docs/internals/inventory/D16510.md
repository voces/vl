#### Mechanism

`empty` has one instance per callback, and each instance's `[]` must be built at that callback's
parameter type: `f64[]` for `ef` and `string[]` for `es`. The second instance's list is built as
the first's storage, so its call to `es` hands a `f64[]` where the callee's signature reads a
`string[]`. One callback, or two callbacks of the same element type, run. So does a non-empty
literal, whose element fixes its type, and so does the same pair through a forwarder (`apply(h, 3,
[])`), the face D5880 closed with a per-instance copy of the literal.
