### D1730 — `xs[i]` with a `const i` accepts the `is` test and then refuses the read it narrowed, telling the author to do the thing they did

**loud check reject · filed 2026-09-06 against master `5530f6132` · found grading D1719's
close; 12 of that grid's 104 cells · 0 corpus cells**

Repro:

    type A = { r: i32 }
    type M = i32 | A
    function st(): A { return { r: 8 } }
    function pick(b: boolean): M { if b { return st() } return 7 }
    const xs: M[] = [pick(true)]
    const i = 0
    if xs[i] is A { print(xs[i].r) } else { print(0) }
    // vl check: rc 1,
    // field 'r' is not on every member of M — narrow with `is` first (i32 is not an object)

#### Mechanism

A narrowing key is a SPELLING. `placeKeyOf`'s index arm takes `subscriptKeyTextOf`, which
answers only for an integer or string LITERAL — deliberately, since the key is compared as
text and `xs[0]` and `xs[00]` are two keys rather than one. A name subscript answers "", the
place has no key, and no narrowing is recorded for it.

**Whether a NAME may key a place is a design question this row does not decide.** Both
directions have a real argument: a `const` binding of an integer literal is as stable a
cell address as the literal is, and the emitter's own `retireNarrowForIndexCells` already
handles a write invalidating a cell — against which, a key derived from a name needs a
definite-assignment argument the narrowing stack does not make today, and `let i` would need
to be excluded by a rule that does not exist yet.

**The MESSAGE is wrong either way, and that half is not a design question.** The `is` test is
accepted — the same program with `print(8)` in the then-branch runs — so the checker admits
the narrowing expression and then tells the author to write it.

#### Ablation

| spelling | outcome |
| --- | --- |
| `xs[0]` (an integer literal subscript) | **runs**, prints `8` |
| `xs[i]` with `const i = 0`, read in the branch | check reject, `narrow with `is` first` |
| `xs[i]` with `let i = 0`, read in the branch | check reject, identical message |
| `xs[i]` with `const i = 0`, `print(8)` in the branch | **runs**, prints `8` |
| `const v = xs[i]` then `if v is A { v.r }` | **runs**, prints `8` |

#### Grading list

The five ablation rows. A message-only close keeps the refusal and must still name what is
wrong — that the subscript is not a literal — rather than prescribing the `is` the program
already has. A close that admits the name has to state its rule for `let i`, for a
re-assigned `i`, and for a write to `xs` between the test and the read.
