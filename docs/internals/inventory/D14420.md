#### Mechanism

An arithmetic, bitwise or comparison operator over a `never` operand has no value, so it types
as `never` and the path ends there. D16006 had the rule only in a dead arm. A short-circuit
operator (`&&`, `||`, `??`) keeps its own typing, since its right operand may not run, and so
does a string concatenation, which already takes `never` as a string.

#### Grading list

`"s" + fail()` must keep running; `fail() + 1`, `1 - fail()`, `fail() < 2` and a `never` lambda
call as either operand.
