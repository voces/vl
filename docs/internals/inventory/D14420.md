### D14420 — arithmetic refuses a `never` operand that string `+` accepts, although `never` is assignable to everything

**loud check reject, clause 2 · named in D2027's grading list, re-run while closing D1971/D1973/D2025–D2027 · filed 2026-10-26 against master `3f27774a4`**

Repro:

    function fail(): never { __trap__() }
    function a(c: boolean): i32 { if c { return 1 } 1 + fail() }
    print(a(true))
    // vl check: rc 1, operator '+' is not defined for i32 and never

#### Mechanism

Not yet ablated. Numeric operators refuse `never` as an operand type, while string `+` does not,
so `"s" + fail()` checks and runs. A `never` operand ends the path before the operator runs, so
the expected rule is that the operator types as it would with the other operand's type.

#### Grading list

`"s" + fail()` must keep running; `fail() + 1`, `1 - fail()`, `fail() < 2` and a `never` lambda
call as either operand.
