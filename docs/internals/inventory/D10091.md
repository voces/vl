#### Mechanism

`emitCoalesceGo` (wasmEmit.vl) lowers `m.get(k) ?? d` and `m[k] ?? d` through
`emitMapGetOr`, which builds its result at the map's value kind; the checker types the `??`
`f64`, so the `f64` default lands in an `i32` slot. D10060 fixed the record-field arm by taking
the checker's result kind and widening the read. Outside a recursive function D10061's join
types the result `i32 | f64` and this arm is not reached; the recursion is what keeps the
checker at `f64` ([D10090](D10090.md)), so closing that row may hide this one rather than fix it.
