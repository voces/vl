### D14739 — a value read out of a built container and handed on through a `??` with a literal default, or to a parameter that stores it, refuses

**closed · now runs, prints `40` then `4` · was loud check reject, clause 2 · filed 2026-10-31 against master `68aa8887` · closed 2026-11-01 against master `1d98f35a`: a `??` whose default is a fresh record literal builds the literal at the read's record (`recCoalesceLitBuilt`) · fixture `soundness/built-container-read-coalesced-with-literal-handed-by-rep-runs.vl` · the parameters that store, capture or return the value are [D14754](D14754.md)**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    function g(r: { f: i32 }) { r.f * 10 }
    const wideJ: J = mk()
    const m = Map()
    m.set(1, mk())
    print(g(m.get(1) ?? { f: 0 }))
    print(wideJ.f ?? 0)

Want:

    40
    4

#### Mechanism

`m`'s values are built at `J`. The read `m.get(1) ?? { f: 0 }` joins a `J` box with a literal its
own type builds at `{f: i32}`, so the join has no one rep to hand `g`'s by-rep instance
([D14532](D14532.md)), and `recBuiltReadRefuse` keeps the refusal for a `BinExpr` read. The same row
holds a parameter, hole or annotated, record or list, that stores, captures, returns or rebinds
the value it receives (`soundness/error-built-container-read-handed-to-hole-that-stores-it.vl`):
each is a position whose lowering does not yet take the rep.
