### D3497 — a join of two un-annotated parameters drops a `null` arm joined after them, so the null arm fails the caller's cast at a pin

**closed 2026-10-03 — the witness prints `1`, `s`, `null` · was loads then traps, clause 1 · the hole spelling of [D3487](D3487.md), which #3336 closed for declared type parameters only · found by #3336's review (the `hole` rows of its 2,939-cell grid: 49 traps, 34 wrong values) · filed and closed against master `04ec2ef6f` · fixture `tests/cases/generics/hole-param-join-keeps-null-arm.vl`**

Repro:

    function F(k: i32, a, b) { if k == 0 { a } else if k == 1 { b } else { null } }
    print(F(0, 1, "s"))
    print(F(1, 1, "s"))
    print(F(2, 1, "s"))
    // vl check: rc 0.  prints `1`, `s`, then `wasm trap: cast failure` at the third call

Want:

    1
    s
    null

#### Mechanism

D3487's fix is `paramJoinDropsNull`: `joinTys` refuses to collapse a `null` into a side holding a
type parameter and no null, and `paramNullJoin` keeps the null as a flat member. It recognised a
declared parameter (`tyIsDeclaredParam`) and not the hole of an un-annotated parameter, which is
gradual in its own body exactly as a declared one is (owner ruling; `joinTyParamNull` already
treats it so for a bare hole beside `null`, D3303). So `a | b` beside `null` still collapsed to
`a | b`, the caller typed the call `i32 | string`, and the instance's null-tagged box failed the
caller's cast. The predicate now also accepts a parameter's hole in the body declaring it
(`tyIsNamedParamHole` and `tyParamOfInnermostBody`, the condition `joinTyParamNull` uses), and
`paramNullJoin` records the hole as one a join kept apart (`noteHoleTpJoin`).

A hole function whose result another un-annotated function forwards (`function F(k, a, b) {
H(k, a, b) }`) re-folds that join at the call with the caller's holes, outside the body that
declared them, where the rule does not hold, so the null was dropped again: `F`'s return was
typed without it while `H`'s instance now kept it, which turned master's loud refusal into a
wrong `false` and invalid wasm at #3337's first round. `refoldJoinUnion` now keeps the null of a
join `paramNullJoin` made (`paramNullJoins`). The same repair runs the declared spelling
(`H<A, B>` forwarded through a hole function), which was wrong on master.
