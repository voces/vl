### D3985 — a `let` annotated with a function type over an anonymous record, written and called, is refused at emit

**closed 2026-10-25 by lane L6 (#4739) · runs, prints `Q`, `5` · was loud emit reject, clause 2, and check-clean invalid wasm on #4739 before its last commit · the function-value adapter's parameter annotation drops the space after `:` and `,`, so the instance pins at the record and not at `{}` · pin: `tests/cases/generics/generic-fn-value-at-anonymous-record-slot.vl` · found in review of #3500 (`rv3500/r5/y_anon_fixed`, the spelling `check --fix` writes for `y_anon`) · filed 2026-10-10 against master `56f77d80f`**

Repro:

    function inner<U>(u: U) { print("I") }
    function cAnon(p: { b: i32 }) { print("Q"); print(p.b) }
    function main() {
      let k: ({b: i32}) => void = inner
      k = cAnon
      k({ b: 5 })
    }
    main()
    // vl run: emitProgram: ref valtype with no interned shape

Want:

    Q
    5

#### Mechanism

`inner` delivered to `({b: i32}) => void` is wrapped by the checker's function-value adapter
(`fvaAdapt`, `check_assignable.vl`), whose lambda parameter is annotated with `tyToStr`'s
spelling `{b: i32}`. Mono pins the instance from that spelling, and the spaced record name
resolves to the empty record `{}`, so `inner` is instanced at `{}` while the binding's signature
holds `{b:i32}`. Before L6 nothing interned `{}` and emit refused; L6's shape walk interns it,
and the module failed validation inside `k` (`expected (ref $11) {}, found {b:i32}`). A named
record type (`cRec(p: P)`) runs because its name has no space. The same mechanism made a generic
whose result is `U` at an anonymous-record slot check-clean invalid wasm on master (D12640).

#### Fix

`fvaSepTight` (`check_annot_resolve.vl`) drops the space after each `:` and `,` outside a string
literal, and `fvaTight` applies it with the pipe and arrow tightening, so the adapter's
annotation is spelled as a written one is. It subsumes `fvaMapTight`, which did the same for a
map's value type only. Ablated on #4739: the PR without its shape-walk change (D6) keeps the
filed refusal, so D6 is what turned the refusal into invalid wasm; the field-reader moves and
the memo stamp do not move it. The pin covers a written `let` reassigned with a concrete
function, a `const`, a parameter, a return, a module global, a two-field record and a result
typed by the type parameter. The un-annotated spelling (`let k = inner; k = cAnon`) is a check
refusal under the generic-let ruling and is not this row.
