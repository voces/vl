### D9761 — a declared function with an un-annotated parameter, passed to `.map` over a list of an un-annotated function, is refused as an unknown function

**loud emit reject · `vl check` rc 0 · `call to unknown function` · clause 2 · found closing [D9712](D9712.md) · present on master `e8163edd5` · filed 2026-10-22 against master `60aaa08c0`**

Repro:

    function inc(a) { return a + 1 }
    const v = [inc]
    function ap(r) { return r(5) }
    print(v.map(ap)[0])
    // vl check rc 0.  vl run: emit error: emitProgram: call to unknown function

Want:

    6

#### Mechanism

Not traced. The lambda spelling (`v.map((r) => r(5))`) runs, and so does `ap` with `inc`
annotated, so the gap is a declared generic over a function-valued parameter whose instance is not
asked for when it is passed by name to a built-in callback. The nested twin (`[[inc]]`,
`function ap(r) { return r[0](5) }`) refuses with `callee is not a function name`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the un-annotated parameter of `inc` (`inc(a: i32): i32`) | runs, `6` | **yes** |
| the declared callback, for a lambda (`(r) => r(5)`) | runs, `6` | **yes** |
