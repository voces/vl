handed to an annotated record parameter, gets an instance of the callee at `J`; the container
itself is a list, and the argument-rep fact (`recArgRepNote`) and mono's pin take records only, so
`recBuiltReadRefuse`'s element arm refuses. The same row holds the other members D14532's close
left refusing, each pinned by a fixture:

  default at its own row;
- a parameter, hole or annotated, that is stored in a record or list, captured, returned or handed
  to another annotated parameter (`soundness/error-built-container-read-handed-to-hole-that-stores-it.vl`),
  each a position whose lowering does not yet take the rep.
