### D15655 — a `const` holding a call's record, as a part of a list literal beside a part built at a wider record, refuses

**open · loud check reject · clause 2 · `this record, returned by a call, is fresh and type-valid here, but not supported yet: it is not built where a list holding elements built as J (line 7) takes it` · found closing D15652 · filed 2026-11-10 against master `793f92c7`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const xs = [mk()]
    function os0() { { f: 1 } }
    const o = os0()
    const ws = [xs[0], o]
    print(ws[1].f ?? 0)

Want:

    1

#### Mechanism

Not ablated past the table. D15652's close copies a call part into the list's build; a `const`
holding the call is a record another read can reach, so a copy would split it, and the part is
refused (`recListPartsApartRefuse`). Building the binding itself at the list's record, as a `const`
holding a literal is (`recHeldLitPartStamp`, D15372), has no stamp to give: the call's record is
built in its function.
