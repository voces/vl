Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const m = Map()
    m.set("a", { f: inc0 })
    m.set("b", { f: half })
    const r = m.get("b")
    if r != null { print(r.f(3)) }
    // vl check rc 0.  vl run: emit error: emitProgram: unsupported map value type (no rep for a union-member struct, ...)

#### Mechanism

`holeSlotJudge` judges a call through a place by the slot path from its root binding
(`l[].f` for `l[1].f(3)`) and every value written there. A call through a record bound
first (`const r = m.get("b")`, `r.f(3)`) rooted at `r`, whose initialiser is not a literal,
so the judge declined and the disagreement reached the emitter. A call through `?.` was not
a slot read at all: neither the call checks nor `cwSlotPath` knew `OptMember`. A pushed
record was collected only when the path ended at the element, so `l[].f` never saw it; on
master `l.push({ f: half })` then `l[1].f(3)` was a runtime trap, `indirect call type
mismatch`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `inc0` write | runs, `1.5` | **yes** |
| the record (`m.set("a", inc0)`, `x(3)`) | loud check reject ([D9311](D9311.md)) | **yes** |
| the map (`const l = [{ f: inc0 }, { f: half }]`, `const r = l[1]`, `r.f(3)`) | same family, `cannot take the generic function` | no |
| the binding, on a list literal (`l[1].f(3)`) | loud check reject | **yes** |

#### Why the refusal is owed

The design rule is the in-place list read's and [D9311](D9311.md)'s: a call through the
field of a record read from the container may run any function stored in that field, and
a call has one result type, so every such function must return one type at the call's
argument types. `inc0` returns i32 and `half` f64 at `(i32)`. Annotating the field type
(`type R = { f: (a: i32) => f64 }`, `Map<string, R>`, `R[]`) with functions that return f64
(`inc0` as `a + 1.0`) is the spelling that runs, printing `1.5` (an `inc0` still of i32
result traps there, [D9471](D9471.md)); records of one result (`inc0` and `dbl`) or of a
single function are not refused, through `.get`, `?.`, an index read, an alias of the
binding, or a push.

#### Grading list

Graded after the close, each a loud check reject: the map's `?.` read
(`print(m["b"]?.f(3) ?? 0)`), the index write (`m["a"] = { f: inc0 }`), the pushed list
(`const l = [{ f: inc0 }]`, `l.push({ f: half })`, `print(l[1].f(3))`), the literal list
read through a binding, an alias `const s = r`, a `for` loop and a `.map` callback over
the pushed list, an empty list filled by two pushes, and a record nested in a field
(`o.xs.push({ f: half })`). A record bound before it is written (`m.set("b", r0)`) is
[D9470](D9470.md).
