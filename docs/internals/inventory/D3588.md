### D3588 — an `as` cast over a constant was graded by its operand's TYPE, so `255 as u8` was fallible and `300 as u8` refused only at run time

**closed 2026-10-03 — the witness prints `1` · was loud check reject (`as u8` propagates null, which the enclosing function cannot return) · follows the owner's exact-constant ruling (2026-09-30, A: a literal-only tree is exact and typed per use; a use that cannot hold it is a check error) · sunpa SP-024 · fixtures `tests/cases/numerics/as-cast-constant-fits.vl`, `tests/cases/numerics/error-as-cast-constant-misfit.vl` · filed against master `766a860ea`**

Repro:

    export function f(): i32 {
      let px: u8[] = []
      px.push(255 as u8)
      px.length

    print(f())

Want:

    1

#### Mechanism

`checkCastNode`'s numeric arm asked only `numCastCanFail(source type, domain)`, and `i32 → u8`
can fail, so every bare `as u8` owed the enclosing function a `null` whatever its operand was.
The close asks first whether the operand is a constant tree (`cexTreeShape`, the same literals,
literal consts and operators the exact fold reads) and, if so, evaluates it exactly
(`cexEvalAt`). A value the domain holds makes the cast infallible in every mode: the type is
the target, and a fallible `u8`/`i32` cast is rewritten into the `i32` literal of the value
(an `i64` one gets its operand rewritten into the integer literal), so the emitter lowers no
range test. A value the domain does not hold is a check error naming the value and the range;
`as!`/`as?` over it would trap or be null on every run, so they refuse too. `as%` is untouched.
A float domain rounds by ruling, so only a value past its finite range (`1e39 as f32`) misfits
there; `0.1 as f32` still rounds. A radix pattern whose top bit is set at its own width stays the
width-dependent reading the ordinary cast takes.

#### Grading list

A 2,130-cell matrix — 23 constants (0, 255, 256, -1, the i32 and i64 bounds and one past each,
0.5, 0.1, 3.0, 3.5, `200 + 55`, `200 + 56`, a literal const `K` and `K + 1`, `0xFF`, `1 << 40`,
`1e39`, `(2 - 3)`) × u8/i32/i64/f32/f64 × `as`/`as!`/`as?` × push, binding, return, argument,
field and module binding, plus `as%` on the integer pairs — graded every in-range cell RUNS with
the right value in every mode and every out-of-range cell a check error. Against master, 176 cells
went runs → check error, all of them misfits: 164 `as?` over a constant it cannot hold (null on
every run) and 12 `1e39 as f32`/`as! f32` (infinity); no in-range cell was lost. A literal past
the i64 range cast to a float (`9223372036854775808 as f64`) is refused as before, by the
literal's own overflow check.
