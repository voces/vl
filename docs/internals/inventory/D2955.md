### D2955 — an `is` test for a list type over a union with a type-parameter member builds invalid wasm at every pin

**check-clean invalid wasm · clause 1 · open · identical on master `e9fdc10d9` · the #3243 review, 136 cells of its `g50` grid · filed 2026-09-28 against master `e9fdc10d9`**

Repro:

    function h<T>(a: T, c: boolean) {
      const r: T | i32 = if c { a } else { 5 }
      if r is i32[] { print(r.length) } else { print("no") }
    }
    h(true, true)
    // vl check: rc 0.  vl run: invalid module inside `h` (expected struct type), exit 70

Want:

    no

#### Mechanism

Not localised past the ablation. `r is i32[]` over `T | i32` passes the check, since `i32[]` is
assignable to `T` in the body. At the pin the union is `boolean | i32`, which has no list member,
and the instance lowers the test as a struct cast over the box.
