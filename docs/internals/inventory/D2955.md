### D2955 — an `is` test for a list type over a union with a type-parameter member builds invalid wasm at every pin

**closed 2026-09-28 · was check-clean invalid wasm, clause 1, on master `03dcbcfac` · the #3243 review, 136 cells of its `g50` grid · fixture `tests/cases/generics/is-test-a-pin-cannot-hold.vl`**

Repro:

    function h<T>(a: T, c: boolean) {
      const r: T | i32 = if c { a } else { 5 }
      if r is i32[] { print(r.length) } else { print("no") }
    }
    h(true, true)

Want:

    no

#### Mechanism

`r is i32[]` over `T | i32` passes the check, since `i32[]` is assignable to `T` in the body.
At the pin the union is `boolean | i32`, which has no list member. The instance lowered the test
as a runtime tag compare that can never be true, so the dead-arm skip, which reads the emitted
condition for a constant, did not fire. The `then` arm was lowered with `r` narrowed to `i32[]`,
a list type the module never declared. Closed in `emitIsTest`: when no arm of the receiver's
box can carry the tested tag, the test over a bare name is the constant `0`, and the arm is
skipped. An arm counts when it claims another value tag, or is a record, whose variant tag is
below every value tag. A union with an arm that claims no tag keeps the runtime compare.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the list type (`r is string`) | runs since D2950, prints `no` | **yes** |
| the type parameter (`a: boolean`, `r: boolean \| i32`) | loud check reject, `not a variant` | **yes** |
| the scalar pin (`h(rec, true)` with `rec: Rec`) | same invalid wasm | no |

#### Grading list

`r is string[]` at the same pins. The `g50` grid's `*_i32L_*` and `*_strL_*` cells, at every
pin: all 140 of its invalid-wasm cells now run, with the 32 loud emit rejects of the record pin.
