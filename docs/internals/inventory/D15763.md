### D15763 — `is K[][]` over a `V[][] | string` box receiver in a generic instance answers false for an empty list

**check-clean silently wrong value · clause 1 · the nested-list face of [D4912](D4912.md) · reachable where [D4937](D4937.md)'s spelling is refused · filed 2026-11-12 against master `c7474c370`**

Repro:

    function probe<V>(v: V[][] | string) {
      if v is f64[][] { return 1 }
      0
    }
    const e: i32[][] = []
    print(probe<i32>(e))
    // PRINTS 0

Want:

    1

#### Mechanism

An empty list fits any list type, as D4912 settled at depth 1 (`emitListEmptyFitIs` guards the
emptiness test under the list arm's tag). At depth 2 the box receiver's `is` keeps the
instance's static fold from the `i32[][]` arm, so the empty list answers false. The same
receiver spelled `V[][] | null`, or bare `V[][]`, prints `1`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `string` arm: `V[][] \| null` | prints `1` | **yes** |
| the union: bare `V[][]` | prints `1` | **yes** |
| the nesting: `V[] \| string`, an `i32[]` | prints `1` | **yes** |
| the emptiness: `[[1]]` | prints `0`, which is right | **yes** |
| the explicit pin: `probe(e)` | refused at emit (D4937) | no |
| the binding: `probe<i32>([])` | prints `0` | no |
