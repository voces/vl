#### Mechanism

`print` picks its renderer from `exprIsBool`, whose `??` arm answered true only for a list's
checked read. Inside an instance the `??` node carries the template's type, not `boolean`, so
the typed fast path missed and the value printed as the `i32` it rides in. The niche is known
from the instance's parameter annotation (`exprNulBool`), and a `boolean | null` coalesced with
a boolean default is a boolean, which is the rung added.

#### Ablation

| ingredient changed | outcome on `ed81f8d55` | needed? |
| --- | --- | --- |

| `print(!(a ?? true))` | prints `false`, correctly | **yes** (the print of the `??` itself) |
| `const b = a ?? false; print(b)` | prints `1` | no |
