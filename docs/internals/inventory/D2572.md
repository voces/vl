### D2572 — a generic that binds a slice or filter of `[x, null]` and returns the binding builds the wrong list rep

**check-clean invalid wasm · clause 1 · pre-existing on master `dcc88a350` · found by #3174's review · filed 2026-09-26**

Repro:

    function g<T>(x: T) {
      const q = [null, x].slice(1)
      return q
    }
    const r = g("s")
    print(r.length)
    // vl check: rc 0.  vl run: invalid module inside `g`, "expected struct type at index 0,
    // found (array (mut i32))" (master: the engine fails to parse the module at all)

#### Mechanism

Not located. The concrete spellings run: `function g(x: string) { const q = [null, x].slice(1);
return q }` prints `1` and `false`, and `x: i32` prints `1`. Inside a generic, the local `q`
that holds the slice is built at the plain `i32` list rep while its uses expect the nullable
element list, at every instance tried. #3174's review graded the generic bind-then-return of a
`[x, null]` / `[null, x]` slice or filter as silent in 22 of 23 cells on master.
