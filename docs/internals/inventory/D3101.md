#### Mechanism

Each generic's call to the next re-records the callee's constraints under the caller, so the
`k`-th declaration from the bottom owns about `k` rows per family, and every validation scans
the whole table. Checking the chain in `tests/vl_scaling_shape_test.ts`'s `generic chain depth`
shape costs 3.86e7 / 1.67e8 / 1.60e9 guest fuel at depth 30 / 60 / 120 on master callee-first.
Before [D3062](D3062.md) closed, the caller-first order skipped the work, which was the defect;
after it, caller-first reads 5.48e7 / 3.24e8 / 3.63e9, about depth^3.5 between 60 and 120.

lower when this row closes.
