### D2688 — an un-annotated list const walks every occurrence of its NAME in the program, in every function

**closed 2026-09-26 — runs today and must keep running · the defect was its cost: `n` functions each binding `const out = [...]` un-annotated built quadratically in `n` (9.34G fuel at n=800 against 3.78G when each function names its list differently); the occurrence index now chains rows per (name, frame), and the shared spelling costs 3.61G, linear · filed 2026-09-26 against master `f8709e41c`**

Repro:

    function a(n: i32): i32[] {
      const out = [n, n + 1]
      out
    }
    function b(n: i32): i32[] {
      const out = [n]
      out
    }
    print(a(1).length + b(2).length)
    // prints 3; `b`'s `out` is checked against every `out` occurrence in `a` too

#### Mechanism

`constStoresForeignList` (compiler/typecheck.vl), asked by `listOriginExpr` of a `const`
whose initializer is a literal, walks the occurrence chain `cwIxChain(nm)` — one chain per
interned NAME across the whole program — and filters each row with `cwSameFrame`. A common
local name therefore costs every function's occurrences of it, once per binding: the n=400
profile has `constStoresForeignList` 24.7% inclusive and `cwSameFrame` 10.8% self. The
index (D1628) keys the question on the pair (name, frame) but files its rows by name only.
Closed by a second chain per (name, frame) (`cwIxPairEnsure`, compiler/typecheck.vl), built
for a name on its first frame-keyed question and dropped with the rest of the index. A reader
keyed on frame `fr` walks two cursors, the pair's own rows (`cwIxFrHead`/`cwIxFrNext`) and the
`CW_FR_UNKNOWN` pair's (`cwIxUnkHead`), taking the larger row each step, which visits exactly
the rows the name chain filtered by `cwSameFrame` did, in the same order. A reader asked with an
unknown frame, or before the index is built, filters the name chain as before. Nine readers
whose every use of a row sat under that filter moved to the cursors: `constStoresForeignList`,
`cwSetOccs`, `cwLambdaDeclOf`, `cwContainerAliases`, `cwEscapedHandleNodes`,
`cwBoundOnceSealed`, `cwContainerSealed`, `rcwConstInit` and `rcwNameWrites`. The
other six read rows no frame filter covers (calls, method calls, declarations) and keep the
name chain. Building the pair table for every name up front cost the self-compile +0.22G
fuel; built lazily it costs nothing measurable.

#### Grading list

The ladder above; the same K sibling bindings in ONE function, which pay it within one frame
(1.4x the annotated spelling at 1,200 bindings); plumb's units, which rebind short names
(`m`, `x`, `y`, `r`, `t`) in every function.
