### D17322 — a generic function whose type does not fit a type parameter's binding is accepted when the binding's type stays generic

**check-clean invalid wasm · clause 1 · filed 2026-11-24 against master `13753236` by lane N10 · found ablating D17117**

Repro:

    function same<T>(k: T): T { return k }
    function twice<T>(_k: T): string { return "tw" }
    function mid<F, G>(a: F, a1: G) {
      let b: F = a1
      print(a("x"))
      const n = b(3)
      print(n + 1)
    }
    mid(same, twice)
    print(twice(5))
    // vl check: rc 0.  vl run: invalid module inside `mid`, expected i32, found (ref $5)

#### Mechanism

`let b: F = a1` is checked per call. Where both functions are called at one closed type,
`(i32) => string` does not fit `(i32) => i32` and the call is refused, as the design owes. Here
`F` is `same`'s generic type, called at two types, so no closed instance of `F` is compared with
`G`, and `<T>(T) => string` is accepted into a binding of `<T>(T) => T`. The design forbids this
program: the check owes a refusal at `mid(same, twice)`. Today it reaches emit, and is refused
there (D17117's sentence) or, with `twice` instantiated elsewhere, written invalid (D17321).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `a("x")`: `a` called at `i32` only | refused at check, `cannot assign (i32) => string to 'b' of type (i32) => i32` | **yes** |
| non-generic functions `(i32) => i32` and `(i32) => string` | refused at check | **yes** |
| the other call `print(twice(5))` | loud emit reject (D17117's) | no: the check is still clean |

#### Grading list

A close of D17117 or D17321 must not run this program: it must be refused at check first.
