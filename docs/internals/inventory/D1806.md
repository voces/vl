### D1806 — the covariant-write closure ends at a read-only PARAMETER and at nothing else, so a container FIELD typed `readonly T[]` still files an escape and the intermediate-name shape keeps refusing

**loud emit reject · filed 2026-09-06 against master `4805d8fae` · D1686's residue, from the `readonly T[]` view landing · 0 corpus cells**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    type Inner = { xs: readonly Shape[] }
    type Outer = { inn: Inner }
    function __other() {
      const w: Shape[] = []
      w.push({ s: 3 })
      print(w.length)
    }
    function f() {
      const a: Circle[] = [{ r: 7 }]
      const b: Shape[] = a
      const o: Outer = { inn: { xs: b } }
      const q = o.inn
      print(q.xs.length)
    }
    f()
    // vl check: rc 0.  vl run: emit error, covariant list delivery.

#### Mechanism

The read-only view licenses a covariant delivery by ending the alias closure: a value handed
to a `readonly T[]` parameter cannot be written through, so `cwGrowCall` stops there instead
of following it into a body it cannot read. That rule is written at ONE edge, the argument
edge, and the same fact is true of every other read-only destination — a struct field, a map
value, a list element typed `readonly T[]`.

Here `b` is stored into `Inner.xs`, which IS declared `readonly Shape[]`. Nothing can write
that field's list, so the escape need not be filed at all — but `cwEscapeByLit` files it at
`o` under the path `inn.xs` regardless, `q.xs` spells no such key, and `cwChainSealed`
refuses to claim a path whose intermediate was given a name of its own. The closure answers
`2` and the delivery is declined, on a program in which no write is reachable.

Closing it is the same one-line rule at the other destinations: a store whose declared slot
is a read-only list files no escape. What makes it a separate row is that each of those
edges reads the slot's declared type from a different place — an object literal's field
annotation, a map's value type, an element type — where the parameter edge had a `Param`
node to ask.
