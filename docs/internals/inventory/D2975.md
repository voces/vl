### D2975 — a generic `is i32` at a function-type or anonymous-record pin refuses as `is` with no union declared

**loud emit reject · clause 2 · open · the #3247 review · filed 2026-09-28 against master `fe1fa1bec`**

Repro:

    function h<T>(a: T, c: boolean) {
      const r: T | i32 = if c { a } else { 5 }
      if r is i32 { print("int") } else { print("other") }
    }
    h(() => 1, true)
    h(() => 1, false)
    // vl check: rc 0.  vl run: emitProgram: `is` test but no union type declared

Want:

    other
    int

#### Mechanism

Not localised. At a function-type pin the union `(() => i32) | i32` is a box, but no union is
registered in the program. The `is` lowering reaches its variant ladder, whose first rung
refuses when no union is declared.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the function-type pin (`h(true, true)`) | runs | **yes** |
| an anonymous-record pin for the function type (`h({ x: 9 }, true)`) | same refusal | no |

#### Grading list

Both pins, and each with an `is` over the pin's own type, `!is i32`, and a value `if`.
