### D2975 — a generic `is i32` at a function-type or anonymous-record pin refuses as `is` with no union declared

**closed 2026-10-25 by lane L6 (#4739) · runs, prints `other`, `int` · was loud emit reject, clause 2 · the function-type pin's union arm now interns under the walk's nominal name · pin: `tests/cases/generics/generic-is-over-function-type-pin.vl` · the anonymous-record pin in the ablation below is D12641, still open · the #3247 review · filed 2026-09-28 against master `fe1fa1bec`**

Repro:

    function h<T>(a: T, c: boolean) {
      const r: T | i32 = if c { a } else { 5 }
      if r is i32 { print("int") } else { print("other") }
    }
    h(() => 1, true)
    h(() => 1, false)
    // vl check: rc 0.  vl run: emitProgram: `is` test but no union type declared

Want:

    other
    int

#### Mechanism

Not localised. At a function-type pin the union `(() => i32) | i32` is a box, but no union is
registered in the program. The `is` lowering reaches its variant ladder, whose first rung
refuses when no union is declared.

#### Fix

L6's shape walk (`shapeWalkName`, `emit_shape_intern.vl`) keys each shape it interns by the
type's nominal name, and the `is` lowering then finds the function-type arm of
`(() => i32) | i32`. Ablated on #4739: the PR without that walk change still refuses (by then
with `` `is` names a declared union member with no interned arm representation ``); the
field-reader moves and the memo stamp do not move it. The pin covers the statement, negated
and value `is`, a typed-parameter function and a read narrowed by the test.
