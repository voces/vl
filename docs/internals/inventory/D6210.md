### D6210 — a hole function called on its own result through a hole parameter, at two instances, is emitted at one

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · found closing [D6190](D6190.md) · the same on master `3805fcf57` · filed 2026-10-17 against master `3805fcf57`**

Repro:

    function wrap(a) { return [a] }
    function lap(g, x) {
      print(g(g(x)).length)
      return 0
    }
    lap(wrap, 4)
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `lap`: type mismatch: expected i32, found (ref $type)

Want:

    1

#### Mechanism

From the ablation only. The inner call needs `wrap` at `i32` and the outer call needs it at
`i32[]`. The split plan keys each call of `g` by its argument's type, and the outer call's
argument is the hole's own result, which prints `_`, so both calls get one key and one
parameter. `lap` is emitted with one instance of `g`, and the outer call hands it a list.
