### D16821 — a record of a list of lists of lists of un-annotated functions, returned, held in a list, re-pointed or pushed into, has no interned shape at emit

**closed 2026-11-16 — the witness runs and prints `1.5` · was: loud emit reject · clause 1 (check accepts what emit refuses) and clause 2 · found closing [D16806](D16806.md) · filed 2026-11-16 against master `fae99e93f`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function mk() { return { f: [[[inc0]], [[half]]] } }
    const r = mk()
    print(r.f[1][0][0](3))
    // vl check: rc 0.  vl run: emit error, "emitProgram: ref valtype with no interned shape"

Want:

    1.5

#### Mechanism

The tag plan (`ftScan`, `compiler/check_fn_tag.vl`) noted list literals and un-annotated
bindings as holders, whose rep `fnTagHeldNote` stamps, but not a record literal: a returned one,
or one in a list, stayed at its own type, whose function lists key no row past two levels. A
record literal whose type holds a list of lists in a field, or in a nested record's, is a holder
now, built at its rep with its list fields ([D16806](D16806.md)'s `fnTagHeldRecFields`). The
narrowing keeps every other record literal where the record joins place it.

#### Grading list

- Held in a list (`[{ f: [[[inc0]], [[half]]] }]`): runs; was `object literal field count does
  not match struct`.
- Pushed into the field: runs.
- A `let` re-pointed: still refused, [D16834](D16834.md).
