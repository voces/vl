#### Mechanism

Not yet located. The record literal bound directly runs ([D16806](D16806.md)): the binding's
stamp builds the literal and its list field at the rep. A returned literal is built at its
function's result, which this stamp does not reach.

#### Grading list

- In a list: `const rs = [{ f: [[[inc0]], [[half]]] }]`, `rs[0].f[1][0][0](3)`
  (`object literal field count does not match struct`).
- A `let` re-pointed: `r = { f: [[[dbl]]] }`.
- Pushed into: `r.f.push([[dbl]])`.
