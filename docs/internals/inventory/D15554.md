Repro:

    function id(a) { return a }
    function mk<T>(x: T) { return { fs: [id], x: x } }
    const r = mk(1)
    const s = mk("s")
    print(r.fs[0](2))
    print(s.fs[0]("q"))

Want:

    2
    q

#### Mechanism

Two ingredients, both needed: a record literal with a field at the caller's type (a type parameter, or an un-annotated parameter), and a field holding a generic function value called at two types. `mintPinnedObjLit` takes its tagged-set arm (`fnTagHoldsTy` holds), finds the literal's rep `{f: (_) => _, x: i32}` still holding a hole, and mints an id row from the literal (`sLitIdRow`); the instance's result struct the global's cell reads is never found, so the cell has slot -1. Bound in a function body instead, the literal itself reports `object literal but no struct type declared`.
