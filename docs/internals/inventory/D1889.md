a union-member struct, a nullable list over an unnamed element rep, a nullable litunion-result
closure — and `Branch` is none of them. Its tail clause ("any other value type here interned no
mv slot") is the one that fires, so the list is a description of the cases somebody checked, not
of the gap.

**The recursion is the ingredient, and the sampler's control says so rather than the sample's
silence.** The recursive records ship with `rec_flat`, a non-recursive record of the same field
shape and the same reads. Over 186 pairs on the four new records, `rec_node` (self-recursive,

(37) was **all AGREE-RUNS**, and only `rec_mutual` disagreed. A table with no flat twin could
not have told "recursion" from "this field shape".

**Mutual, not self.** The same un-annotated map carrying the self-recursive
`{ v: i32, next: Node | null }` runs, so what the mv interner cannot close over is a cycle that
runs through TWO declarations — neither name closes on its own.
