### D3091 — three hole functions, one with a nested named function, one capturing a local and one handing a lambda to a `<T>` generic, refuse together though each runs alone

**closed 2026-10-04 · was a loud emit reject (`emitProgram: a function-value call has no interned signature`), clause 2 · filed 2026-09-28 against master `d408f2da4`; closed by lane LF with D3608 · fixture `tests/cases/scope/nested-function-name-outside-its-scope.vl`**

Repro:

    function o(n) {
      function k(_x: i32) { return n }
      return k(1)
    }
    print(o(2))
    function capRead(x) {
      const y = x
      const k = () => y
      print(k())
    }
    capRead(4)
    function appG<T>(g: () => T): T {
      return g()
    }
    function viaG(x) {
      print(appG(() => x))
    }
    viaG(5)
    // master: vl check: rc 0.  vl run: emit error at `viaG(5)`, a function-value call has no interned signature

Want:

    2
    4
    5

#### Mechanism

Not localised past the ablation. Each pair of the three functions runs, so the refusal is a
per-program table that one function's lambda fills and another's reads (a "runs alone, fails in
company" shape): the lambda handed to `appG` finds no interned signature for its result.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `o` removed | prints `4` `5` | **yes** |
| `capRead` removed | prints `2` `5` | **yes** |
| `const k = () => x` in `capRead`, no local | prints `2` `4` `5` | **yes** (the captured local) |
| `print(appG(() => true))`, no `viaG` | prints `2` `4` `true` | **yes** |

#### Close

Not a per-program table after all: a name. `capRead`'s `k()` is a call of its local closure,
but the emitter's callee lookups that hold only the name (`fnIndexOfSid`) consulted the flat
function map, which holds `o`'s nested `k`. So `capRead`'s call was classified as a direct call
of `o`'s `k`, and the closure signatures the other two functions intern were left without the
one `appG`'s lambda needed. Removing `o` removed the second `k`; removing the captured local
made `k` not a closure. Since D3608's close those lookups ask the block-local scopes
(`fnIndexOfNode`, `compiler/emit_classify.vl`), and no block-local `k` covers `capRead`'s call.
