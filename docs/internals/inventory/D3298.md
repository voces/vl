#### Mechanism

`singleAliasMemberTyIx`'s list arm, which decides when a one-member alias denotes its list, had
no rung for a union or nullable leaf, so `R` kept its own one-member union row (the same arm as
[D9960](D9960.md)'s function leaf). The alias's body `(H | null)[]` is a list, and spelling the same type inline at
the parameter (`z: (H | null)[]`) runs; through the alias the checker sees a union, and
`.length` refuses as `field 'length' is not on every member of R — narrow with 'is' first
((H | null)[] is a list, not a record)`, which names the list as a member of `R`.
