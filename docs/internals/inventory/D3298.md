### D3298 — a type alias whose body is a list of a union is read as a union, so indexing or measuring a value of it is refused

**loud check reject · clause 2 · pre-existing, the same on master `e70102886` · found by the NF2 lane writing an element probe for D3287 · filed 2026-09-29 against master `e70102886`**

Repro:

    type H = { v: i32 }
    type R = (H | null)[]
    function F(z: R) {
      const e = z[0]
      if e != null { print(e.v) }
    }
    F([{ v: 4 }, null])
    // vl check: cannot index non-array R

Want:

    4

#### Mechanism

Not yet located. The alias's body `(H | null)[]` is a list, and spelling the same type inline at
the parameter (`z: (H | null)[]`) runs; through the alias the checker sees a union, and
`.length` refuses as `field 'length' is not on every member of R — narrow with 'is' first
((H | null)[] is a list, not a record)`, which names the list as a member of `R`.

#### Ablation

| `type R = (i32 \| null)[]` or `(string \| null)[]` | same refusal | no (a record element) |
| `type R = (A \| B)[]`, no `null` | same refusal | no (`null`) |
| `type E = H \| null` and `type R = E[]` | same refusal | no (the parentheses) |
| `print(z.length)` instead of the index | refused, `field 'length' is not on every member of R` | no (the index) |
