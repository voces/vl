### D9094 — a `let` list of un-annotated functions written with another function that agrees is refused at emit

**closed · runs, prints `6` · was loud emit reject, `emitProgram: cannot take the generic function inc0 as a value`, `vl check` rc 0 · clause 2 · found closing [D9060](D9060.md) · filed 2026-10-21 against master `361494943` · closed by typing a `let` list literal from its re-point literals and its element writes as a `const` one is, declining when two stored functions disagree at the pin (`monoPinListElems`, `monoLetRepointLits`, `monoListStoresAgree`, emit_mono.vl), and typing an element write through an un-annotated parameter from the element's function type (`monoConcreteFnTyName` at the `=` index arm) · fixtures `closures/hole-fn-list-written-then-called.vl`, `closures/generic-fn-list-written-then-called.vl` · also closes [D4012](D4012.md), the same `let` list of generics inside a function · [D9170](D9170.md) filed for the re-point to another list binding**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    let xs = [inc0]
    xs[0] = dbl
    print(xs[0](3))
    // vl check rc 0.  vl run: prints 6

#### Mechanism

The monomorphizer types a list literal of hole functions from the pins its calls record and
writes that type into the binding's annotation, but read the literal only from a `const`
initialiser: a `let` was skipped, so its re-point literals and element writes were never
compared and the literal's element stayed un-instanced. A write made through an
un-annotated parameter (`put(ys) { ys[0] = dbl }`) had no element type at the store either.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `let` (`const xs = [inc0]`) | runs, `6` | **yes** |
| the write (`let xs = [inc0]`, `xs[0](3)`) | runs, `4` | **yes** |

#### Grading list

The write made through a parameter, `put(xs)`, prints `6` for a `const` and a `let`. A
re-pointed `let xs = [inc0]; xs = [dbl]` prints `6`. With `half` in place of `dbl` every
spelling stays refused: at check where D9060's judge sees the write, and otherwise at emit.
