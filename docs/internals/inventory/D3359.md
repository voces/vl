Repro:

    type P = {x: i32}
    type U = P | string
    function g<T>(a: T) {
      print(a is U)
    }
    const p: P = {x: 1}

#### Mechanism

Not localised past the ablation. At `T := P` the instance tests a bare record against a union
alias one of whose members it is. The static fold reads the pin as no member of `U`, where `P`
is one. The direct spelling is D3360's refusal.
