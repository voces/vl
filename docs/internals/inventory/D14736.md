### D14736 — a call handed through a hole identity into an annotated wider record is built at its own row while the identity's instance hands back the wider record

**open · check-clean invalid wasm, clause 1 · found closing [D14730](D14730.md), whose grading list names it · filed 2026-10-31 against master `8af49501`**

Repro:

    type Circle = { r: i32 | null }
    function id(x) { return x }
    function mkcall() { { r: null } }
    const w: Circle = id(mkcall())
    print(w.r ?? 6)

Want:

    6

#### Mechanism

The delivery `const w: Circle` reaches `mkcall()` through `id` (`recLandingIn` follows a hole
identity since the D14730 close), yet `mkcall` is built at its own row `{r: null}` while `id`'s
copy hands back `Circle`. Invalid inside `id`. The generic face, `id<T>(x: T): T`, runs
([D14530](D14530.md)'s fixture), so the two identities disagree on where a lone delivery lands.

#### Ablation

| change | outcome | needed? |
| --- | --- | --- |
| `function id<T>(x: T): T { x }` | prints `6` | **yes**, the hole |
| `const w = id(mkcall())` | prints `6` | **yes**, the annotation |
| `const w: Circle = mkcall()` | prints `6` | **yes**, the identity |
