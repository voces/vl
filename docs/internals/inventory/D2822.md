#### Mechanism

`emitUnionIfArm` and `emitVariantIfArm` lower an arm only when its tail passes
`stmtIsTailValue`, which has no `IfStmt` arm; the numeric and ref joins ask `ifArmIsValue`,
which does. So an arm whose value is itself an `if` (a `match` arm, an `else { if … }`, an
arm with a prelude then an `if`) fell to `ifArmNoValueFail`. The close lowers such a tail as
the SAME join — `emitUnionIfValue` / `emitVariantIfValue` over the inner `if` with the outer
union — so every leaf boxes once at the outer rep, whatever the inner `if` alone would type.
The ref join gains the twin for an inner else-less `if` (D2040), and the sunk union return's
else-less link returns the function's null instead of refusing.
