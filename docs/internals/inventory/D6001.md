### D6001 — an un-annotated lambda passed to an un-annotated parameter and returned has no monomorphization pin

**loud emit reject · `vl check` rc 0 · clause 2 · found closing [D5972](D5972.md) · the same on master `200c89ff8` · filed 2026-10-17 against master `200c89ff8`**

Repro:

    function fw(f) { return f }
    const lam = (x) => x
    const q = fw(lam)
    print(q(3))
    // vl check: rc 0.  vl run: emitProgram: monomorphize: unsupported argument type for `f` in a call to `fw`

Want:

    3

#### Mechanism

From the ablation only. A top-level function `id` passed to `fw` the same way runs, so the
pin for `fw`'s parameter is found for a function declaration and not for a lambda whose
parameter is a hole.

#### Ablation

| spelling | outcome | needed? |
| --- | --- | --- |
| the witness | loud emit reject | — |
| `function id(x) { return x }` in place of `lam` | runs | **yes** |
| `const q = lam`, no `fw` | runs | **yes** |
| `q("w")` in place of `q(3)` | loud emit reject, the same | no |
