### D1733 — an if-EXPRESSION joining a STRING arm with a NUMERIC arm has no join rep, and `print` of it directly is check-clean invalid wasm

**check-clean invalid wasm · `vl check` rc 0, `vl run` exit 70 · clause 1 · filed 2026-09-06 against master `25a59b496` · the residue [D1728](D1728.md)'s 96-cell arm-pair grid leaves, minimised past every ingredient that grid varied · 0 corpus cells**

Repro:

    const c = true
    print(if c { "green" } else { 7 })
    // vl check: rc 0.  vl run: invalid module

Bind it first — `const b = if c { "green" } else { 7 }` then `print(b)` — and the same join
runs, printing `green`. So the join HAS a rep; `print`'s direct route is the half that has no
arm for it.

#### Mechanism

Predicted, not probed. The checker types the join `string | i32` (the annotated destination
`const b: string | i32 = …` is accepted, and the litunion face's refusal names that spelling),
so the value is a two-atom value union. The BINDING position lowers it — a bound `string | i32`
prints `green`. `print`'s own dispatch ladder reaches `printUnionPlan` before `exprString`, and
for the direct if-expression argument nothing in that ladder classifies the join, so it falls
through to `__print_i32__` with a ref on the stack.

**No literal union, no hole parameter, no annotation and no declared union is required** — that
is what separates this from [D1728](D1728.md), which needed all of the parameter, the alias and
the atom arm. The atom-armed cells below are the same join with the string arm narrowed to a
litunion, and they are a WRONG VALUE rather than invalid wasm, so this row does not claim them
as one mechanism until someone ablates them.

**A MISSING REGISTRY ROW IS NOT THE BLOCKER, measured rather than argued.** #2749's decline
placed it there — registration being declaration-driven, so `string | i32` is never minted.
Declaring the row does not move the witness: with `type U = string | i32` in the same program,
`print(if c { "green" } else { 7 })` is check-clean invalid wasm at the same validator sentence
(measured 2026-09-06 against master `114b3f835`). And an INFERRED all-atom join needs no mint
in the first place — `const w = mkS() ?? mkI()` over `string | i32 | null` runs un-annotated.
The gap is `print`'s classification of a DIRECT if-expression argument, which is what this
row's own ablation already says; a mint would not reach it.
