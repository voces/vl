### D16610 — an index read of a record list beside a wider record part in a list literal is refused at emit, though binding the read first runs

**loud emit reject · clause 2 · `emitProgram: this branch hands over a record whose field types differ from the record the branches join to, and a record is shared rather than converted` · a refusal in the wrong phase, and its neighbour runs · found by lane J's discovery grids (D16449's ablation) · filed 2026-11-15 against master `59155c7df` · open**

Repro:

    const s = [{ x: 1 }]
    const v = [s[0], { x: 2.5 }]
    print(v[0].x)
    // vl check: rc 0.  vl run: emit error, this branch hands over a record whose field types differ

Want:

    1

#### Mechanism

Not yet located. The list stamp treats a part reading a binding (`const a = s[0]; [a, ...]`)
as held at the build, as D15372/D16441 build it; an `Index` part, `s[0]` inline, is neither a
fresh part nor a binding, so the check passes it and the emitter meets the `{x: i32}` record at
the `{x: f64}` join. If the design owed a refusal it would be at check, with the shared-record
contract; it does not, since the bound spelling runs.
