#### Mechanism

The field-code vocabulary had one code, 35, for both `u8[]` and `u8[] | null`:
`nulScalarListFieldCode` answered 35 for the niche, while every other nullable list leaf has
its own code (31 to 34) whose slot is `(ref null …)`. An inferred record field asks
`anonNulCodeIsSelfContained`, which listed 31 to 34 and so admitted no code for the byte-list
niche, leaving the row un-interned. The same sharing made a declared `u8[] | null` field a
non-null `(ref …)` slot (D2249) and read every non-null `u8[]` field as the niche. The fix is
code 36, and the translation that failed here is gone: each integer table naming a list rep
(ref-list element codes, field codes, the generic-compare alphabet, the list-build codes) has
one `_`-less encoder from the rep (`rlElemCodeOfListRep`, `fieldCodeOfListRep`,
`eqListKindOfListRep`, `listBuildKindOfVKind`), and its readers decode through it, so a list rep
with no row in some table is a compile error.
