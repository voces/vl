### D3269 — a union DECLARED with `type` whose member is a function type loses the function arm's rep: the call through the arm is invalid wasm and `is` answers wrong

**check-clean invalid wasm · open · clause 1 · found 2026-09-29 by the PL-060 (function-type parameter names) position grid · the same on master `569caa36c` · filed 2026-09-29 against master `569caa36c`**

Repro:

    type U = ((i32) => i32) | string
    function dbl(x: i32) { x * 2 }
    function run(v: U): i32 {
      if v is string { return 0 }
      v(4)
    }
    print(run(dbl))
    print(run("s"))
    // vl check: rc 0.  vl run: invalid module inside `run`:
    // type mismatch: expected i32, found (ref $type)

Want:

    8
    0

#### Mechanism

Not localised past the ablation. The same union written inline in the annotation runs, so the
fault is in how a `type`-declared union registers a function-typed member, not in the union's
lowering: the declared member set does not carry the closure arm's rep, so the narrowed arm is
read as an `i32` atom (the call) and the `string` arm's test misreads its tag (`is string`
answers false for `"s"` once the call is removed). Parameter names play no part: every
spelling here is unnamed.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the union written inline, `function run(v: ((i32) => i32) \| string)` | runs, `8` `0` | **yes** (the `type` declaration) |
| the member spelled through an alias, `type F = (i32) => i32` then `type U = F \| string` | the same invalid module | no (the parentheses are scenery) |
| the call `v(4)` replaced by `1`, called with `"s"` only | runs, prints `1` — `is string` answered false | no (a second face, silently wrong) |
| two function members, `type U = ((i32) => i32) \| ((string) => string)`, tested `is (i32) => i32` | runs, the test answers false for both | no (a third face) |
| the member set `F \| null` (a nullable alias) | runs | **yes** (a second non-null member) |
| `v` bound at module scope, `const v: U = dbl`, then the same `is` / call | loud emit reject, `narrowed union atom has no value box` | no (the emit-side face) |

#### Grading list

The witness; the `is string`-only spelling (must print `0`); the two-function-member union
under `is (i32) => i32` (must print `int` then `str`); the module-scope binding; the alias
spelling of the member (`type F = …; type U = F | string`).
