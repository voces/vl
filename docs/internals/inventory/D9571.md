Repro:

    type R = { f: (a: i32) => f64 }
    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const m: Map<string, R> = Map()
    m.set("a", { f: half })
    const p = []
    p.push({ f: inc0 })
    print(p[0].f(3))
    const q = { f: inc0 }
    const p2 = []
    p2.push(q)
    print(p2[0].f(4))

Want:

    4
    5

#### Mechanism

The element type of the empty list `p2` was resolved to a row by its field set
(`structRowOfObjFieldSetK`), whose function-field test `declRowFnFieldFits` agreed with any
declared row once the field's function had holes, so `p2` was laid out at `R`'s row while `q`
was built at its own. The test now asks every field value checked at that hole type what it
returns at the row's parameters, as [D9530](D9530.md)'s literal test does, and refutes `R`.
