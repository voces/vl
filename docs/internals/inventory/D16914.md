### D16914 — a record of two list fields of different un-annotated functions builds an invalid module

**check-clean invalid wasm · clause 1 · found by lane AE grading the D16834 position matrix · filed 2026-11-16 against master `6cd505a50`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    const r = { f: [inc0], g: [dbl] }
    print(r.f[0](3))
    // vl check: rc 0 (one warning, `r.g` never read).  vl run: invalid module, type mismatch in the top-level code

Want:

    4

#### Mechanism

Not yet located. Each field's list holds a one-member set of its own (`{inc0}`, `{dbl}`), and the
validator reports a `(ref $type)` mismatch where the record is built; the literal and the read
appear to disagree on the field's list rep.
