### D4895 — a list of a string list and an anonymous-record list refuses to box the record list into the union

**loud emit reject · clause 2 · the annotated spelling runs · found closing [D4894](D4894.md), whose fix moved the literal spelling `[["a"], [{x: 1}]]` here from a module that did not validate · filed 2026-10-15 against master `8b65df0a7`**

Repro:

    const a = ["a"]
    const b = [{x: 1}]
    const v = [a, b]
    print(v.length)
    // vl check: rc 0, v is (string[] | {x: i32}[])[].  vl run: emit error, array value does not match any array member of the union

Want:

    2

#### Mechanism

The record list's own ref-list slot is the anonymous row (`#anon0`), while the union's
`{x: i32}[]` arm resolves to the slot keyed by the shape's spelling, so
`unionHasRefArrayArmSlot` finds no arm with the value's slot and `emitUnionCoerceUnder` fails.
One of the anonymous-row twin-slot family.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the anonymous record (`type P = {x: i32}` declared) | runs | **yes** |
| un-annotated (`const v: (string[] \| {x: i32}[])[] = [a, b]`) | runs | **yes** |
| the names (`[["a"], [{x: 1}]]`, `[[{x: 1}], ["a"]]`) | same refusal | no |
| the string list (`[[{x: 1}], [{y: "s"}]]`) | same refusal | no |

#### Grading list

The literal spellings in the ablation, and the two-record list.
