#### Mechanism

The `??` joins `W` with the literal `0` at `5000000000 | i32`, a union of two widths. `W` reps
as a value box, so the instance's dead-default fold (`coalRetypedDead`, emit_classify.vl), which
takes an operand at the `??`'s own pin or repped as it, declined and the nullable-value arm
refused. `coalRetypedDeadJoinIf` lowers the dead `??` as `if true { l } else { d }` recorded at
the pin, which delivers the box through the existing `if`-join conversion. Arithmetic on the
result (`(f() ?? 0) + 1`) is the matrix's `TYPE i64` cell and runs by [D9563](D9563.md)'s close.
