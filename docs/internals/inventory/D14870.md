### D14870 — a bare record literal whose field set names a union arm, but whose own type is narrower, is built as the arm and read as a struct

**loud emit reject · `vl check` rc 0 · clause 2 · `emitProgram: field access but no struct type declared` · pre-existing, the same on master `07d4d42a4` · found while ablating J-B's field-set scan · filed 2026-11-01 against master `07d4d42a4`**

Repro:

    type Circle = { r: i32 | null }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    const dd = { r: null }
    print(dd.r == null)

Want:

    true

#### Mechanism

`dd`'s type is the literal's own `{ r: null }`, which no declaration names, and no destination
adopts it. The emitter picks the literal's layout by field set: `r` names the arm `Circle`, so the
literal is built as that variant's bare struct. The field read takes the plain struct path
(`emitMemStructRead`). That path needs a declared struct row, and a program whose only records are
union arms has none. A literal whose type is the arm itself (`{ r: 5 }`), or whose binding is
annotated, reads through the arm and runs.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `Circle` declared alone, no union | runs, prints `true` | **yes** (an arm) |
| `{ r: 5 }`, read `dd.r == 5` | runs | **yes** (a narrower literal type) |
| `const dd: Circle = { r: null }` | runs | **yes** (no annotation) |
| an unrelated standalone `type Tri = { t: i32 }` | runs | **yes** (no struct row at all) |
| `print(({ r: null }).r == null)` (read in place) | refuses the same | no |
| `r: string \| null` | refuses the same | no |
| `print(dd is Circle)` | refuses, ``is` receiver is not a union value`` | the same family |

#### Grading list

The read-in-place, string-field and `is` spellings above; the same literal returned from an
inferred-result function and bound (`const dd = mkcall()`), which refuses identically; and the
distilled cells J-B's scan rescues by field set (b000418, b000498, b021395–b021474), whose
receivers are the same narrower literal type beside an arm that does have a row.
