#### Mechanism

Two ways the walker minted the row again. `collectAnnShapes` runs twice, once from `collectS`
and once from `runEmitPasses`, and the second walk re-interns every annotation. Its dedup,
`annShapeIndexOf`, never matches a row with a ref-list field: the element-name check compares
the row's element name with the field's text, which are different strings for those codes,
and that comparison is kept conservative because unifying it merges rows the rep fuzzer shows
unsound. So `{ f: { x: i32 }[], n: i32 }` written twice owned four rows. Separately,
`synthRetAnnots` pins a closure's result to `tyToEmitName`, which spells an inline literal
union by its hidden alias, so D10770's record was interned a third time under that spelling.

The new rung asks only for the row whose canonical type and field codes are already this
annotation's. A second row of the same spelling was never reachable by name, since
`structIndexByName` answers the first, so only the type-keyed readers ever saw it. Found by
type, a literal's `#anon` row is not reused: `g<T>(b: { m: T })` called with `{ m: xs }`
then built the value against one `#anon` row and passed it as another, and the module failed
to validate (`tests/cases/generics/anon-record-arg-to-record-pattern.vl`). Found only by
name, the closure's hidden-alias spelling of D10770's record misses the declared row, and
D10770 comes back once the element-key arm is gone.

#### Residue

The remaining duplicates come from other mint paths, led by declared types (`Buf` in 61
fixtures) and the corpus's `{r: …}` rows. They are not traced here.

#### Grading list

D10770's element-key arm of `structFieldCodesEq` is removed. A probe that recorded whenever
it decided fired on the D10770 fixture on master and on none of the 16,727 fixture, corpus
and self-compile programs under this rung before its `#anon` exclusion was added; the final
rung was graded with the arm already removed, by the identity sweep below. With the arm gone, the D10770 fixture prints
its nine lines, and D10770's six-position, seven-field-type grid runs 42 of 42, as on master.
Over the identity sweep's 16,472 files, 20 modules differ from master by a few bytes each,
with the same type count and the same output.
