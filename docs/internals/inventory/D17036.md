### D17036 — `r.k ?? d` over a `K | null` field writes its operand twice, so an effectful receiver runs again when the field is present

**closed 2026-11-21 · the witness prints `b`, `1` · a `??` over a `K | null` or `boolean | null` field of an effectful receiver stashes the operand once (`coalLhsStashes`) · was check-clean silently wrong, clause 1 (`f().k ?? "a"` called `f` twice) · found by lane F2 checking IR-REV's question on the `litUnion` re-read · filed 2026-11-20 against master `afb9ab3eb` · fixture `tests/cases/null/coalesce-niche-field-receiver-once.vl`**

Repro:

    type R = { k: "a" | "b" | null }
    let calls = 0
    function f(): R {
      calls = calls + 1
      return { k: "b" }
    }
    const v = f().k ?? "a"
    print(v)
    print(calls)
    // vl check: rc 0.  vl run: prints b, then 2

Want:

    b
    1

#### Mechanism

`emitCoalesceNiche`'s `litUnion` arm stashed only a `Call` or `if` operand (`lhsReEval` false) in
`coalesceCallBoolSlot`; any other operand was written once for the `-1` test and again in the present
arm. A field read whose receiver is a call, or a method call, is not effect-free, so the receiver
ran a second time whenever the field was present. The `boolean | null` arm shared the flag and the
re-read. Closed by one shared predicate, `coalLhsStashes` (`emit_query.vl`): a call, an `if`, or a
field read whose receiver is no re-readable place (`unionEqOperandOk`). The stash-slot scan
(`coalChainHasCallLhs`) and `emitCoalesceNiche` both ask it, so the slot is reserved wherever it is
written.

#### Ablation

| spelling | outcome | needed? |
| --- | --- | --- |
| the witness | prints `b`, `2` | — |
| the field null (`{ k: null }`) | prints `a`, `1` | **yes** (the present arm re-reads) |
| a method receiver, `o.m().k ?? "a"` | prints `b`, `2` | no (any effectful receiver) |
| an element with an effectful index, `xs[g()] ?? "a"` | prints `b`, `1` | **yes** (a field read) |
| the operand a call, `g() ?? "a"` | prints `b`, `1` | **yes** (a call is stashed) |
| a `??` nested in the default, `g(0) ?? (g(1) ?? "a")` | prints `b`, calls counted once each | no |

#### Grading list

The method spelling `o.m().k ?? "a"`; a receiver that is an `if` or a `??`; the other re-reading niche
arms of `emitCoalesceNiche` (the `boolean | null` select, the `string` arm), which re-evaluate the
same way; and the IR's `litUnion` arm, which must stash the receiver rather than match the re-read.
