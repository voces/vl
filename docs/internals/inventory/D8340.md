**closed 2026-10-20 by lane emit-collect · runs, prints `1` · was loud emit reject · `vl check` rc 0 · clause 2 · an annotation the D831 wider-row rule serves now records that row against its arena type, and `retStructRowIndex` reads it (`internInlineShapeTyGo`, `emit_shape_intern.vl`; `retStructRowIndex`, `emit_nullable_rets.vl`) · pins: `tests/cases/generics/identity-literal-into-record-union-then-own-row-call-unann.vl` and its annotated twin; matrix `generic-identity-literal-into-record-union-then-own-row-call` · present on master `38ea07302` · the reversed order of [D8203](D8203.md) · filed 2026-10-20 against master `38ea07302`**

#### Mechanism

The second call's instance takes a parameter of the literal's own type `{r: i32}`, and no
struct row exists for it: the valtype that refuses is kind `struct` at row `-1`. The first
literal is built at `J`'s row because the union delivery pins it there (D8021), and nothing
else in the program mints `{r: i32}`. The post-mono annotation pass mints `J`'s arm twin
`{r: i32 | null}` from the `idn<J>` clone's `J`, and `annShapeWiderRowOf` then handed that
twin to `one`'s `{r: i32}` parameter as a wider row without aliasing the parameter to it, so
the parameter's valtype found no row: `retStructRowIndex` resolves a parameter by its
rep slot, then by name, and no row carries the spelling `{r: i32}`. The wider branch now
aliases the annotation's arena type to the row it hands back, and `retStructRowIndex` reads
that alias before its nullable-base rung. Restricting the rule to a literal's own `#anon`
row fixed this witness too, and lost 28 distilled classes that need the arm twin to serve.
