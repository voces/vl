### D16350 — a generic function's returned record literal, holding an un-annotated function field called at two types, is emitted at the template's row and has no shape for a reference-typed parameter

**loud emit reject · `emitProgram: ref valtype with no interned shape`, at the call · clause 2 · open · found by lane E grading the stage 3a field-code shadow's template rows (`d15270_generic_mk`) · filed 2026-11-15 against master `314123b83`**

Repro:

    function id1(a) { return a }
    function mk<T>(x: T) { return { f: id1, x: x } }
    const r = mk([1, 2])
    const g = r.f
    print(g(2))
    print(g(2.5))
    // vl check: no errors.  vl run: emit error 3:7, `ref valtype with no interned shape`

Want:

    2
    2.5

#### Mechanism

Traced as far as the row. The stage 3a shadow (`compiler/emit_fc_shadow.vl`, armed) shows the
scalar twin (`mk(1)`) emitted at one anonymous row, `#anon0`. That row is minted for `mk`'s
template, and its field `x` records the template's open `T` as its storage type. Its field code
follows the instance:
- `FC_I32` at `mk(1)`;
- `FC_F64` at `mk(2.5)`;
- `FC_STR` at `mk("hi")`;
- `FC_I64` at a 64-bit literal.

So a scalar instance runs. A reference-typed instance needs that field's valtype to name an
interned heap row, and the template's row interns none. The guard in `fbValtypeNullable` /
`fbValtype` (`emit_bytes.vl`) turns the out-of-table index into this refusal. It is not yet traced
why the polymorphic function field keeps the program on the template's row: without it, each
instance mints its own shape row and runs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the witness | loud emit reject | |
| `T` a scalar: `mk(1)`, `mk(2.5)`, `mk("hi")` | runs | **yes** (a list or a record refuses) |
| `g` called at one type only | runs, `2` | **yes** |
| `mk` not generic: `mk(x: i32[])` | runs, `2 2.5` | **yes** |
| `id1` annotated `(a: i32): i32` | runs | **yes** |
| the field order, `{ x: x, f: id1 }` | still refuses | no |
| the call through the field, `r.f(2)` / `r.f(2.5)` | still refuses | no |
| a field write first, `r.f = id0` | still refuses | no |
