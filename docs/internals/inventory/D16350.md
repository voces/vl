### D16350 — a generic function's returned record literal, holding an un-annotated function field called at two types, is emitted at the template's row and has no shape for a reference-typed parameter

**closed 2026-11-15 — the witness runs and prints `2 2.5` · was: loud emit reject · `emitProgram: ref valtype with no interned shape`, at the call · clause 2 · found by lane E grading the stage 3a field-code shadow's template rows (`d15270_generic_mk`) · filed 2026-11-15 against master `314123b83`**

Repro:

    function id1(a) { return a }
    function mk<T>(x: T) { return { f: id1, x: x } }
    const r = mk([1, 2])
    const g = r.f
    print(g(2))
    print(g(2.5))
    // vl check: no errors.  vl run: emit error 3:7, `ref valtype with no interned shape`

Want:

    2
    2.5

#### Mechanism

`anonMintRowFor` (`emit_collect.vl`) mints the literal's anonymous row once per instance. But it
recorded each field's storage type from the template's row type, so field `x` held the template's
open `T`.
- **Scalar instance:** the field's code came from the instance's type, through D15554's prim-only
  rule, so the row ran.
- **Reference-typed instance:** a list or record `T` got no code. The row was not minted, and the
  field's valtype had no interned heap row. The guard in `fbValtypeNullable` / `fbValtype`
  (`emit_bytes.vl`) turned that into this refusal.
- **Why the function field matters:** without the un-annotated function field called at two
  types, the literal takes the shape-interning path, which mints at the instance's type.

**Closed by** reading, for each field whose template type is open, the closed type the
elaboration recorded for that instance (`elabNodeTyAt`, keyed by the instance key). It is used for
the field's storage type, its code (through `nameFieldCodeTy`), and a record field's row
(`anonStructRowOfTy`). Nothing is re-derived in mono or emit. The 3a field-code shadow shows the
row's fields agreeing with the code their storage type's rep derives
([measurements](../refactor-notes/2026-11-15-rep-adt-d16350.md)).
