### D3034 — a generic union alias over a generic record does not resolve its own type parameter

**loud check reject · clause 2 · identical on master `cac5e4ad5` and on #3259 · found by the #3259 review · filed 2026-09-28**

Repro:

    type Box<T> = { v: T }
    type U<T> = Box<T> | { z: i32 }
    const u: U<i32> = { v: 3 }
    print(u is { z: i32 })
    // vl check: unknown type 'T' within 'Box<T>' in union 'U<T>', then unknown type 'U<i32>'

Want:

    false

#### Mechanism

Not yet located. The union's member `Box<T>` is resolved without the alias's own parameter `T`
in scope, so the member fails and the whole alias is unregistered, which is why its use
`U<i32>` cascades. The union-member resolution is the first place to print which type-parameter
scope it reads.
