### D3034 — a generic union alias does not resolve its own type parameter, whatever its members

**closed 2026-11-14 · runs, prints `false` · a generic union declaration registers as a generic alias, and each application fills its own union under the parameter bindings · was a loud check reject, clause 2, for every generic union alias whose member mentions a parameter (`type O<T> = T | null`, `type U<T> = { v: T } | { z: i32 }`), not only one over a generic record · found by the #3259 review · filed 2026-09-28**

Repro:

    type Box<T> = { v: T }
    type U<T> = Box<T> | { z: i32 }
    const u: U<i32> = { v: 3 }
    print(u is { z: i32 })
    // prints false since the close; before it, vl check: unknown type 'T' within 'Box<T>' in
    // union 'U<T>', then unknown type 'U<i32>'

Want:

    false

#### Mechanism

Pass 0a registered a generic union declaration like a plain one, so pass 0b resolved its members
with no parameter in scope, and `U<i32>` named nothing. The scope was broader than filed: the same
refusal met every generic union alias whose member mentions a parameter.

#### Close

A generic `UnionDecl` registers in the generic-alias registry (`check_top_level.vl`), and
`applyGenAliasTys` mints a union placeholder for each application and fills it with
`fillUnionDeclMembers` under the bindings, so the null fold, collapse and never rules are the
declaration's own. A one-member instance (`T | null` folds to `T?`) is that member, as the inline
spelling is, so a generic function over `O<T>` binds `T` to the argument (`gaUnionUnwrap`). The
emitter skips the declaration; each instance is a union type the annotation walks register by
type. A recursive instance nested in a render is named by its application
(`nestedCyclicUnionApp`), since its cycle can close at a member no application names.

Matrix, each a fixture under `tests/cases/generics/`: record arms, two parameters, a nested
generic arm, a record and a generic instance, declared after use (`generic-union-alias-record-arms`);
list, map and function members and a `match` (`-member-kinds`); `T | null` and generic functions
over the alias (`-nullable`); a recursive alias through a list arm and a recursive generic record as
an arm (`-recursive`). Left open: [D16069](D16069.md), [D16150](D16150.md), [D16151](D16151.md).
