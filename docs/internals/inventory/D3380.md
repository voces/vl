### D3380 — a call through a function value, delivered as a `readonly` union-record list, returns the source list unconverted

**closed · the call result's row is its function type's result row, so the delivery becomes the view · fixture `tests/cases/closures/fn-value-call-result-readonly-view.vl` · was check-clean invalid wasm · found building the [D3073](D3073.md) adapter · filed 2026-09-30 against master `3291e99e1`, closed 2026-09-30 against master `3291e99e1`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    function k(fv: () => Circle[]): readonly Shape[] { return fv() }
    print(k(() => [{ r: 1 }]).length)
    // vl check: rc 0.  vl run: invalid module, inside `k`: type mismatch

Want:

    1

#### Mechanism

`emitRefListWidenSite` converts a record list delivered as a `readonly` union list into the
[D3041](D3041.md) view, and needs the source's ref-list row from `exprEmittedRefListSlot`. That
function answered a call only when the callee is a declared function (`fnRetRefArrayNameSid`),
so a call through a parameter, a local or a captured function value had row -1, which the site
reads as "not a widenable pair": the raw `Circle[]` wrapper reached the `readonly Shape[]`
result. A call through a function value now answers the row of its function type's result
element (`rlSlotOfTy`).

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `fv` a declared `function h(): Circle[]`, called as `h()` | runs, prints `1` | **yes** (a value callee) |
| the result `readonly Circle[]` | runs, prints `1` | **yes** (the widening) |
| a local `const fv = (): Circle[] => …`, or a lambda's captured parameter | the same invalid wasm | no |
