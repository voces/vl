### D3328 — any use of a recursive generic record `Node<T>` is refused at emit, with or without a hole callee

**loud emit reject · clause 2 · found by #3306's review, filed there as a hole-callee defect · the same on master `b6378e95b` · filed 2026-09-30 against master `b6378e95b`**

Repro:

    type Node<T> = { val: T, next: Node<T> | null }
    const n: Node<i32> = { val: 1, next: { val: 2, next: null } }
    print(n.val)
    // vl check: rc 0.  vl run: emitProgram: recursive generic type `Node<i32>` is not supported — its expansion has no finite type name

Want:

    1

#### Mechanism

`guardFiniteUserTypes` (`emit_collect.vl`) refuses every declared generic-alias instance whose
expansion has no finite name, before any function is emitted. It is a pinned floor:
`tests/cases/generics/recursive-generic-alias-nullable.vl` expects exactly this message, and
DECISIONS.md names it as an inherited gap. The review's premise, that the refusal needs a hole
callee (`len(n.next)` over `Node<i32>`), does not hold: a program that only builds the value and
prints a field refuses. The design question is whether a recursive generic record is legal, since
the checker accepts it and the direct declared `type Node = { val: i32, next: Node | null }` builds
(though see the hole ablation below). Under the standing goal a refusal is owed only if the design
forbids the type, and no ruling says it does.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the review's `len(q)` hole callee added, called at `n.next` and `n` | still refuses | no |
| a hole `first(q)` returning `q.val` | still refuses | no |
| `len<T>(q: Node<T> \| null): i32` annotated | still refuses | no |
| `Node<string>` in place of `Node<i32>` | still refuses, naming `Node<string>` | no |
| `Node` not generic, `val: i32` | builds; see below | **yes** (a generic record) |
| a non-recursive `Box<T> = { val: T }` with a hole reader | runs, `4` | **yes** (the recursion) |

#### Grading list

A close re-grades every recursive-generic fixture under `tests/cases/generics/`
(`recursive-generic-alias-*.vl`), which pin the refusal today, and the non-generic recursive
list with a hole callee, which builds and runs (`depth(o)` prints `2`; it trapped with `null reference`
before #3306, [D3330](D3330.md)).
