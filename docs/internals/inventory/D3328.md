### D3328 — any use of a recursive generic record `Node<T>` is refused at emit, with or without a hole callee

**closed 2026-11-14 — a recursive generic instance's struct is keyed by its type, its finiteness is a
cycle check over the type graph, and substitution re-applies a cyclic application · was a loud emit
reject, clause 2 · found by #3306's review · filed 2026-09-30 against master `b6378e95b`**

Repro:

    type Node<T> = { val: T, next: Node<T> | null }
    const n: Node<i32> = { val: 1, next: { val: 2, next: null } }
    print(n.val)
    // prints 1 since the close; before it, vl run: emitProgram: recursive generic type
    // `Node<i32>` is not supported — its expansion has no finite type name

Want:

    1

#### Mechanism

`guardFiniteUserTypes` (`emit_collect.vl`) refuses every declared generic-alias instance whose
expansion has no finite name, before any function is emitted. It is a pinned floor:
`tests/cases/generics/recursive-generic-alias-nullable.vl` expects exactly this message, and
DECISIONS.md names it as an inherited gap. The review's premise, that the refusal needs a hole
callee (`len(n.next)` over `Node<i32>`), does not hold: a program that only builds the value and
prints a field refuses. The design question is whether a recursive generic record is legal, since
the checker accepts it and the direct declared `type Node = { val: i32, next: Node | null }` builds
(though see the hole ablation below). Under the standing goal a refusal is owed only if the design
forbids the type, and no ruling says it does.

#### Close

The struct row for an instance is minted and found by its arena type (`sTyRow`), and a field
naming an instance still being minted is a struct field resolved lazily by type, so the shape walk
stops at the cycle. `guardFiniteUserTypes` now refuses only a cycle that passes through no record,
list or map (`tyCycleSkipsRecord`). `L<i32>` is a display spelling: the renderers answer it at a
revisit and in messages (`genAppSpellOfTy`), where the memo key `L<#5,>` used to leak.
`substTyDeep` re-applies a cyclic application to its substituted arguments (`substCyclicApp`), so
`cons<T>` at `i32` returns the one shared `L<i32>`; and `rcwCovs` meets a cycle once, asking a
fresh coinductive run whether the revisited pair differs. Both faces above run (`1`; `2`, `2.5`);
the fixtures `recursive-generic-alias-{nullable,array,mutual,cons,union-arm,two-instances}.vl` run,
and `recursive-generic-alias-widened-write.vl` pins that a genuinely wider instance still refuses a
write two links down.
