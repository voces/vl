### D3053 — `as% i64` reads a singly negated hex literal at 64 bits and a longer chain at 32

**closed 2026-09-30 — the owner's exact-constant ruling (A): a chain of negations over a hex literal is a constant, folded to `-0xFFFFFFFF` before the cast reads it, so every negation parity reads the same value under `as% i64` (`-4294967295`), on a `const`, a `let` and a function tail alike; at an `i32` it keeps its pattern reading (`1`), and `0xFFFFFFFF as% i64` is `4294967295` · fixture `tests/cases/expressions/wrap-cast-negated-hex-chain.vl` · was check-clean silently wrong · the same on master `0b618d160` and on #3265 · found by the #3265 review · filed 2026-09-28 against master `0b618d160`**

Repro:

    const b = (-(-(-0xFFFFFFFF))) as% i64
    print(b)
    // PRINTS 1
    // while `(-0xFFFFFFFF) as% i64`, the same negation parity, prints -4294967295

Want:

    -4294967295

#### Mechanism

The checker adopts a literal tree at a cast to i64 only when the cast is not the wrap cast
(`checkCastNode`: "the wrap cast keeps the 32-bit reading it names"), so under `as%` every
chain is typed i32 and `0xFFFFFFFF` is the pattern -1. The emitter's cast arm (and #3262's
const fold, `constFoldCast`) reads a bare or singly negated literal under any cast at its full
magnitude, so `(-0xFFFFFFFF) as% i64` is -4294967295 while the triple negation takes the
checker's i32 reading and prints 1. The two spellings of the same negation parity disagree,
so at most one of them follows the language. Which one is the ruling on whether `as%` to a
WIDER type names a 32-bit reading at all; under the checker's written rule both print `1`.

#### Ablation

| spelling | outcome |
| --- | --- |
| `(-0xFFFFFFFF) as% i64`, one negation | -4294967295 (full magnitude) |
| `(-(-(-0xFFFFFFFF))) as i64` (not the wrap cast) | -4294967295, agrees with the single negation |
| `(-(-(-0xFFFFFFFF)))`, no cast | 1 (i32) |
| `(-(-0xFFFFFFFF)) as% i64` | -1 (i32 reading) |

#### Grading list

`0xFFFFFFFF as% i64` (bare), the same casts on a `let`, and the `as%` arm of `constFoldCast`.
