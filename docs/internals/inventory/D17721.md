#### Mechanism

Two elaboration steps each instanced `inc0` at `string`; a stack from a build that traps at the
refusal named both. The instance re-check (`monoRecheckBegin`) did not renew `retNatural`, so the
second instance's first `return` joined the first instance's result, and a join of a hole function
with a closed one instances the hole function at the closed one (D10797, D15331). And a bound
call result called later (`const q = mk2(ex); q("x")`) delivered the maker's returned parameter at
the call's argument types to every value that parameter is passed by any call, `inc0` among them.
