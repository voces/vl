**closed 2026-11-05, runs, prints `9 a 9 1`, with the split plan on and off · was a loud emit reject without the plan, `monomorphize: unsupported argument type for `f` in a call to `both``, clause 2 · the bundle (D14841) takes a function nested in non-generic functions with annotated parameters as it takes a lambda: the elaboration notes the signatures a parameter bound to such a function is called at (`elabNestedInClosed`, emit_elab.vl), mono builds its closure at each (`monoBundleNamedPin`), and a choice of such reads pins the one record and builds its taken arm's (`emitBundleChoiceArg`, wasmEmit.vl) · a nested function of a generic or hole-parameter encloser keeps its loud refusal, its one body serving every encloser instance (D14842) · a choice whose other members are top-level generics is bundled with the nested one, whose set is no tagged set's · the `const`-bound choice is D15451, unchanged, and the same generic also handed alone is D15446 · fixtures `tests/cases/closures/choice-of-nested-capturing-function-handed-to-hole-param.vl` and `nested-capturing-fn-or-choice-handed-to-param-called-at-two-types.vl`, matrix `nested-fn-or-choice-handed-to-param-called-at-two-types` · filed 2026-11-05 against master `6474c12f`**

Repro:

    function both(f) {
      print(f("a"))
      print(f(1))
    }
    function nested(c: boolean, n: i32) {
      function inner(s) {
        print(n)
        return s
      }
      function ask(s) { return s }
      both(if c { inner } else { ask })
    }
    nested(true, 9)

Want:

    9
    a
    9
    1

#### Mechanism

`both`'s `f` is called at `string` and at `i32`, so a value handed to it is either a tagged set's
id dispatched per call or one closure per signature (a bundle, D14841). `inner` reads `n`, so its
id would have to carry `nested`'s environment and the tag decision leaves `{inner, ask}` untagged.
The `if` value is then one closure, and with the split plan off mono finds no single signature for
it at the hand. The split plan runs it by giving each of `both`'s calls its own copy.

#### Ablation

| ingredient changed, split plan off | outcome | needed? |
| --- | --- | --- |
| `inner` prints `9`, not the captured `n` | runs | **yes** (the capture) |
| `ask` captures `n` too | refuses the same way | no |
| `both` calls `f` at one type | runs | **yes** (two signatures) |
| `both(inner)`, no choice | refuses: `cannot take the generic function `inner` as a value` | **yes** (another refusal) |
| the choice bound to a `const` first | refuses the same way, and with the plan on too (D15451) | no |

#### Grading list

D15451 (the `const`-bound spelling, which the split plan does not serve either); D14841's bundle
fixtures, since a bundle of `{inner, ask}`'s closures at the two signatures is the close.
