### D15333 — a value `if` of records whose arms swap two un-annotated functions between two fields called at two types is refused at emit

**open · loud emit reject · `emitProgram: a function value is called at two signatures, and the closure it holds was built for one` · clause 2 · the arms not swapped run · found grading D15301 M2 · filed 2026-11-04 against master `6f1693f5`**

Repro:

    function id1(a) { return a }
    function id2(a) { return a }
    const c = 1 > 0
    function g(r) { return r.f(2) + r.g(1.5) }
    print(g(if c { { f: id1, g: id2 } } else { { f: id2, g: id1 } }))

Want:

    3.5

#### Mechanism

Each field is called at one signature (`f` at `i32`, `g` at `f64`), so each arm's
function takes the instance of its own field. Swapped, `id1` is one field's value in one arm
and the other field's in the other, so it is a value at two signatures. The refusal reads as if
one closure were called at both.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the swap (both arms `{ f: id1, g: id2 }`) | runs | **yes** |
| the choice (`g({ f: id1, g: id2 })`) | runs | **yes** |
