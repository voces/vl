### D16673 — a constant integer division by zero is accepted, and traps at run time, when the tree holds a radix literal

**loads then traps where D2.3 refuses · clause 1 · open · `vl check` rc 0 · D2.3 and DECISIONS ("Division or remainder by an integer zero has no value and is a check error") make no exception for a radix literal · the decimal spelling `7 % 0` is refused with `division by zero in a constant expression` · found by the independent oracle's arithmetic generator (fuzz cells `ar_s37_0026`, `ar_s82_0153`); first seen grading E6.2 and D2.3 in #8441 · filed 2026-11-15 against master `f195dacbc`**

Repro:

    print(0xFF % 0)
    // master: vl check rc 0; vl run traps: integer divide by zero

Want:

    error: division by zero in a constant expression

#### Mechanism

Not ablated to a compiler function. The constant fold that refuses a zero divisor is not
reached for a tree with a radix leaf (ruling A computes those at the use's width), so the
division is emitted and traps.

#### Ablation

| spelling | master | want |
| --- | --- | --- |
| `7 % 0`, `7 % (~(-1))` | refused | same |
| `0xFF % 0`, `0xFF / (1 - 1)`, `(0xFF + 0) / 0` | rc 0, traps | refused |
| `7 / (0xFF & 0)`, `7 / (0x100 - 0x100)` (radix divisor) | rc 0, traps | refused |
| `0xFF % (~(-1))` | rc 0, traps | refused |

#### Grading list

- Every rc-0 row of the ablation table is refused with the decimal spelling's words.
