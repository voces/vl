### D16860 — a list of records whose nested record holds un-annotated functions of different result types, handed to an un-annotated parameter, traps at the call through the field

**open · now a loud check reject · clause 2 · was a clause-1 trap (`wasm trap: indirect call type mismatch` inside the parameter's function) · narrowed 2026-11-16 by lane WIDTH: a field read through a record nested in a list's element, made through an un-annotated parameter, is judged unlifted (`holeSlotElemRecField`, `holeSlotJudge`'s parameter arm), so the call no longer runs `half` at `inc0`'s signature but is refused, `cannot store 'half' in 'rows[].a.f'` · must run: the parameter's instance has to read the nested field at the argument's joined set, as the binding's own read does · probe `nested-fn-record-list-through-hole-param.vl`; matrix `list-of-nested-fn-records.matrix.vl` `argument` (un-annotated) TRAP → check refusal · the `argument` cell (un-annotated face) of `list-of-lists-of-nested-fn-records.matrix.vl`, the same before D16835 · found by lane WIDTH closing D16835 · filed 2026-11-16 against master `06f1673d5`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const rows = [{ a: { f: inc0 } }, { a: { f: half } }]
    function take(a) { print(a[1].a.f(3)) }
    take(rows)
    // vl check: rc 1, cannot store 'half' in 'rows[].a.f' (was rc 0 and a trap: indirect call type mismatch)

Want:

    1.5

#### Mechanism

The check accepts the call through `a[1].a.f`, whose functions return `i32` and `f64`; the
parameter's instance calls `half` at `inc0`'s signature. A list of the records themselves
(`[{ f: inc0 }, { f: half }]`) handed to the same parameter runs, and so does the read through
`rows` with no parameter, so the gap is a field of a record nested in a list's element read
through an un-annotated parameter: the judge neither refuses it (`holeSlotArgJudge`) nor does the
instance read it at the joined set. Not ablated past the table below.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the parameter (`print(rows[1].a.f(3))`) | runs, prints `1.5` | **yes** |
| the nested record (`[{ f: inc0 }, { f: half }]`, `a[1].f(3)`) | runs, prints `1.5` | **yes** |
| the second result type (`half` → `function dbl(a) { return a * 2 }`) | runs, prints `6` | **yes** |
| the list (`take({ a: { f: half } })` and `take({ a: { f: inc0 } })`) | emit refusal, `monomorphize: unsupported argument type` | not graded |

#### Grading list

`argument` (un-annotated face) of `list-of-lists-of-nested-fn-records.matrix.vl`; a list of lists of
the nested records handed to the parameter, `a[1][0].a.f(3)`, which traps the same way.
