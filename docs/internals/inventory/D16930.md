### D16930 — a record element of a union of lists read through an un-annotated parameter is refused at its pin: the per-arm delivery has no record row

**loud check reject · clause 2 · split from [D16897](D16897.md) step 2a, which declines a record-bearing element union at the pin (`luPinDeclines`) because its per-arm read reached the coercion with no struct row and built invalid wasm · filed 2026-11-17 against master `534f3eda2`, pre-existing**

Repro:

    type P = { x: i32 }
    function px(a) {
      const v = a[1]
      if v is P { return v.x }
      return 1000
    }
    const p1: P[] | string[] = [{ x: 3 }, { x: 4 }]
    print(px(p1))
    // vl check: rc 1, "cannot index non-array P[] | string[] (parameter `a` of `px`, used at 3:13)"

Want:

    4

#### Mechanism

Step 2a lowers a pinned element read per list arm by overriding the receiver's and the read's
types (`luOvEnter`) and the receiver's local (`luOvLocalEnter`), then hands the read to
`emitUnionCoerce`. A record arm's coercion asks `structIndexOfExpr`, whose `Index` arm reads the
receiver's ref-list slot and rep (`structIndexOfIndexStore`, `readRepOf`), neither of which sees
the override, so it finds no row and passes the bare struct ref where the box is wanted. The
check side therefore declines record-bearing element unions and the pin floor refuses the read.
