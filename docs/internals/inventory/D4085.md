### D4085 — `b is A` over `B | D` is refused when every member is contained in `A`

**loud check reject · clause 2 · found reviewing the D4058 close (#3549) · filed 2026-10-11 against master `5a9535c91`**

Repro:

    import { toString } from "std:fmt"
    type A = { x: i32 }
    type B = { x: 1 | 2 }
    type D = { x: 3 | 4 }
    function g(b: B | D): string { if b is A { return "A " + b.x.toString() } "no" }
    print(g({ x: 1 }))
    print(g({ x: 3 }))
    // vl check: rc 1, "`is` check type 'A' is not a variant of B | D"

Want:

    A 1
    A 3

#### Mechanism

Under D3885 (A) `is` tests whether the value fits. Every value of `B | D` fits `A`, so the test
is true. The checker still asks whether `A` names a member of the operand's union and refuses
when it does not. The one-record spelling (`b: B`, `b is A`) is accepted, so the refusal is a
mechanism, not a design rule. An always-true test may deserve a hint, as the dead null test
has; it does not deserve a refusal naming membership.

#### Ablation

| variant | outcome |
| --- | --- |
| `b: B \| D`, both contained in `A` (the repro) | check reject |
| `b: B`, `b is A` | runs |
| `b: B \| C`, `C = { z: string }`, `b is A` | check reject |

#### Grading list

The `match` spelling of the same test (D4087), and the `B | D | null` operand.
