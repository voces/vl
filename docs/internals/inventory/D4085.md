### D4085 — `b is A` over `B | D` is refused when every member is contained in `A`

**closed · runs, prints `A 1` then `A 3` · was a loud check reject, clause 2 · found reviewing the D4058 close (#3549) · filed 2026-10-11 against master `5a9535c91` · fixed 2026-11-14: the one test predicate `tyTestMemberFit` (check_fit_rules.vl) answers covered / partly / none for each member of the operand, and `is`, `as` and `match` all ask it: `tyTestMayFit` is `is`'s gate, `tyTestNamesMembers` and `tyTestMeet` are the cast's arms, and `matchPatCover` marks a pattern's members, replacing `markUnionCover`, the cast's `unionCoversTy` test and the `is` gate's own assignability rule; a record test over a union of records it contains tests their union (`tyTestMeet`, which D4062's one-member `recFitMeetTy` was), which the emitter answers true where it is the whole operand. The `as A` and `match` spellings run too. Fixture: `tests/cases/narrowing/type-test-one-predicate-is-as-match-runs.vl`**
Repro:

    import { toString } from "std:fmt"
    type A = { x: i32 }
    type B = { x: 1 | 2 }
    type D = { x: 3 | 4 }
    function g(b: B | D): string { if b is A { return "A " + b.x.toString() } return "no" }
    print(g({ x: 1 }))
    print(g({ x: 3 }))
    // vl check: rc 1, "`is` check type 'A' is not a variant of B | D"

Want:

    A 1
    A 3

#### Mechanism

Under D3885 (A) `is` tests whether the value fits. Every value of `B | D` fits `A`, so the test
is true. The checker still asks whether `A` names a member of the operand's union and refuses
when it does not. The one-record spelling (`b: B`, `b is A`) is accepted, so the refusal is a
mechanism, not a design rule. An always-true test may deserve a hint, as the dead null test
has; it does not deserve a refusal naming membership.

#### Ablation

| variant | outcome |
| --- | --- |
| `b: B \| D`, both contained in `A` (the repro) | check reject |
| `b: B`, `b is A` | runs |
| `b: B \| C`, `C = { z: string }`, `b is A` | check reject |
