#### Mechanism

Traced, not fixed. As in D17778, the write widens `t.f`'s set to `{inc0, dbl}`, which is tagged,
and the written value `dbl` is built as that set's id (probe: source `i32`), but the written
record literal is stamped with a closure at `f` (`(i32) => i32`). Unlike D17778's list field, the
bare value's own type is not restamped by the widening, so `elabStampKeepsTagged` finds no tagged
type to keep; neither the binding's checker type nor its held rep (`heldRepOf`) carried one when
probed.
