#### Mechanism

Traced. `monoWalk`'s `=` arm delivers a write to a name only at `identFnTypeAnnName`, a
binding whose annotation is a function type, or at the binding's own slot pin, which a list
has none of. A write to an element or a field went on to `monoDeliverLitAtPlace`, which
delivers each function in a literal at its slot's pin or, failing that, at the slot's own
closed function type; a write to the name did not. It now does.
