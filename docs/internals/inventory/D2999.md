#### Mechanism

A readonly list is covariant, so the checker delivers the source list as a view, as D965 does for
`i32[]` into `readonly i64[]`. For a scalar element D965 builds a converting copy. For a union
element nothing does: the view shares the `string | i32` boxes, and a read of the `i32` member as
the destination's `i64` casts the wrong box. The fix is D965's converting copy extended to a union
element (each box rebuilt under the widened member, as D2974's delivery retag does). Refusing it
would be a capability refusal, since D965 serves the scalar twin.
