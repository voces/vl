### D3109 — an un-annotated function whose `is` test cannot pass at a nullable-record pin keeps the branch the call type dropped

**check-clean invalid wasm · clause 1 · 40 cells of the #3273 review's `d94` grid in the walk spelling (loud on master only because the walk variable had no binding, [D3096](D3096.md)) and every index and binding spelling on master · the same on master `d408f2da4` · filed 2026-09-28 against master `d408f2da4`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: string }
    type Shape = Circle | Sq
    const zs: (Circle | null)[] = [{ r: 4 }, null]
    function g(w) {
      if w is i64 { return w }
      return 0
    }
    print(g(zs[0]))
    print(g(zs[1]))
    // vl check: rc 0.  vl run: invalid module in the top-level code: type mismatch

#### Mechanism

`w is i64` over a hole defers to the pin. With `w: Circle | null` annotated, the checker refuses
the test (`'i64' is not a variant of Circle | null`). Over the hole, the call's type drops the
guarded branch ([D3094](D3094.md)), but the instance still returns it, so the call's consumer and
the instance disagree about the result.

Closed in the same PR for a RECORD test: `validateIsCstrs` re-asks a record `is` test over a
hole at each call whose pin is a nullable record, and refuses it with the annotated spelling's
sentence. A nullable record carries no tag, so that test reads the layout and answered `true`
for `{ r: 4 } is Sq` ([#3273](https://github.com/voces/vl/pull/3273)'s review, 52 cells). The
fixture is `tests/cases/inference/hole-record-is-nullable-pin-rejected.vl`. The scalar test is
left open because the same refusal costs running programs: a scalar test over a nullable record
answers `false` and runs today (`is string` prints `0`, `0`), and refusing every such test lost a
distilled class and 85 grid cells that run. A record test over a TAGGED union pin
(`Circle | Sq`, `i32 | Circle`) is left alone for the same reason.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `w` annotated `Circle \| null` | loud check reject | **yes** (the hole) |
| the guard `is Sq` (a record) | loud check reject since the close above | **yes** (a scalar guard) |
| `is string` with a `return "g"` branch, into an `i32` accumulator | the same invalid wasm | no |
| `is string` with `return 1` | runs, prints `0`, `0` | **yes** (the branch's result type) |
