### D3194 — compiling N functions that each read an un-annotated record's string-keyed map with `?? lit` costs fuel quadratic in N

**runs today and must keep running · the witness runs under `vl run`; the defect is the compile cost as N grows, which the grader does not measure · found by the #3282 round-3 review's fuel probes · the same on master `934f169f4` · filed 2026-09-29 against master `934f169f4`**

Repro (runs, prints `0` and `1`):

    type R = { a: {[string]: i32} }
    const mm: {[string]: i32} = Map()
    function u0(p) { p.a["k"] ?? 0 }
    print(u0({ a: mm }))
    function u1(p) { p.a["k"] ?? 1 }
    print(u1({ a: mm }))

#### Mechanism

Not localised. Each function is an un-annotated parameter's instance whose body reads a
string-keyed map field with a literal default. `vl build` guest fuel (`$VL_FUEL=1`) with the
same shape repeated N times, on master `934f169f4` and #3282's head alike:

| N | fuel |
| --- | --- |
| 25 | 0.12G |
| 50 | 0.45G |
| 100 | 1.70G |

Each doubling of N costs about 3.7x, so something walks work proportional to N once per
instance. Which pass does it is not yet measured.
