### D16486 — an assignment to a vector field of a list element, used as a value, is refused at emit

**loud emit reject · clause 2: `vl check` rc 0, then emitProgram: an assignment used as a value stores a cell no local can hold its value from · found closing D16485 · filed 2026-11-15 against master `6bbad19bf`**

Repro:

    import { F32x4, splatF32 } from "std:simd"
    type R = { v: F32x4 }
    const rs: R[] = [{ v: splatF32(1.0) }]

#### Mechanism

Not yet ablated past its ingredients. The value of a field write through a list element is
re-read or spilled at the field's rep, and no arm covers a `v128` field reached that way; the
same write through a record local runs.
