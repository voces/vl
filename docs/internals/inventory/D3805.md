#### Mechanism

`emitForInList` emits the iterable as an ordinary list literal (header and backing). After
`-O3` the header is gone, but the loop reads the backing at a variable index, so
`--heap2local` cannot turn the array into locals. When every element is a numeric (or
boolean) constant and the literal is the `for`'s iterable, nothing else can reach the
list. It can then be one immutable module global, built once, whose backing the loop reads,
and every entry to the loop costs nothing. Elements that are not constants (`[a, b, c]`,
`[3, h - 4]`) keep today's lowering, or could unroll.

#### Ablation

| iterable | allocations per entry |
| --- | --- |
| `[120.0, 280.0, 560.0]` (the witness) | 1 |
| a module `const RS: f64[] = [120.0, 280.0, 560.0]`, `for r in RS` | 0 |

#### Grading list

The witness at `-O` and `-O3`. An `i32` (`[0, 1]`) and a `boolean` element type. A literal
with a `break` and a `continue` in the body. A literal whose elements are not constants,
which must keep its order of evaluation.
