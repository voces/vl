### D17226 — a value `if` delivered at a written record type does not build its maker-call arm at that record, so emit refuses the branch

**closed 2026-11-28 by I8-PREP · runs, prints `null` `7` at every delivery position · was: loud emit reject · clause 2 · `this branch hands over a record whose field types differ from the record the branches join to` · `adoptArmAt` (check_fit_rules.vl) pends a call arm at the join's record as a name arm is (coordinator ruling, DECISIONS.md) · filed 2026-11-25 against master `c2878db6` by IR-N5 (found grading [D17224](D17224.md)'s audit controls)**

Repro:

    type J = { f: i32 | null, g: i32 }
    function mk2() { return { f: null, g: 7 } }
    const m = true
    const j: J = if m { { f: 1, g: 7 } } else { mk2() }
    print(j.g)
    // vl check: rc 0.  vl run: emit error at 4:49, this branch hands over a record whose field types differ

Want:

    7

#### Mechanism

`mk2()` delivered straight to `J` (`const j: J = mk2()`) is built at `J`'s row by the delivery's pend
(`recPend` → `recAdoptNote` → `recKeptFnPush`). Delivered as an arm of a value `if` whose type is
`J`, the call keeps its literal row `{ f: null, g: i32 }`, and the record-join audit
(`auditRecordJoinLeaves`) refuses the arm. A local arm (`const t = { f: null, g: 7 }`) is built at
`J`, and so is the call when the same `if` is the `return`s of an inferred result
([D17224](D17224.md)), so the miss is the call arm of a value `if` delivered at a written type.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const j: J = mk2()`, no `if` | runs, `7` | **yes**, a value `if` |
| the arm a local (`const t = { f: null, g: 7 }`) | runs, `7` | **yes**, a call arm |
| both arms maker calls (`mk1()` / `mk2()`) | refused the same | no |
| the `if` a written result's `return` (`function pick(m: boolean): J`) | refused the same | no |
| the `if` an inferred result's `return` | runs, `7` | **yes**, a written destination |
| the written result's `return`s as statements, not a value `if` | runs, `7` | **yes**, a value `if` |
