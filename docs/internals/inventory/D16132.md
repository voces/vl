### D16132 — a kept maker's union field printed at its own one-member type reads no members from its type, so the print plan declines and the box is printed as a scalar

**closed · clause 1 · 37 SILENT cells of `kept-maker-delivery-null-field.matrix.vl`; first bad 8dab0af41 (#7690), its parent e0d8c7f17 good · found by lane I grading D15933 · filed 2026-11-14 against master `3c8cbdc9`**

Repro:

    type J = { f: i32 | null }
    function mk2() { { f: null } }
    const dA: J = mk2()
    const v = mk2()
    print(v.f)

Want:

    null

#### Mechanism

`mk2()` is kept at `J`, so `v.f` is stored in `J`'s `i32 | null` box. Its own type is `null`.
#7690 made `printUnionPlanCode` take the members from the read's type, or from the box of a
`??`'s left operand, and fall back to the name rung only when neither set holds members. The
one-member set of `null` holds one, so the plan saw fewer than two members and declined. The
print then lowered the box as an `i32` (`type mismatch: expected i32, found (ref $7)`). The name
rung is now asked whenever the type's sets give fewer than two members.
