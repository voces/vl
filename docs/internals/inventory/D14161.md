### D14161 — a record literal in a generic instance, annotated with a nullable function field of the type parameter, is built at a function type the field does not hold

**check-clean invalid wasm · clause 1 · found ablating the G12 field-set-scan cells · pre-existing on master `bbdd4e720` · filed 2026-10-26 against master `bbdd4e720`**

Repro:

    function a<T>(x: T) {
      const r: { f: ((t: T) => void) | null } = { f: (t) => {} }
    }
    a("s")
    print(1)
    // vl check: rc 0.  vl run: invalid module inside `a`, expected (ref $type), found (ref $type)

Want:

    1

#### Mechanism

The record's field type depends on the instance (`T`) and admits `null`, so the field's slot
is a nullable function box at `T = string`. The literal's lambda is stored into that slot as
a value of another function type. Each ingredient below is required, and none of
[D13967](D13967.md) (a declared record result, where the bound-in-body spelling runs) or
[D13968](D13968.md) (the `{ f: null }` pin) carries all four.
