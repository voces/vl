### D15558 — a function returning a list of records of an `i32` and an `f64` function, beside another function returning the same shape, resolves no element row at the call

**open · loud emit reject · `emitProgram: a ref list's element row does not resolve` · clause 2 · each function alone runs · found closing [D15555](D15555.md) · filed 2026-11-08 against master `ea3c74ca`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function half(a) { return a / 2.0 }
    function last(b) {
      const a = [{ fs: [inc0] }]
      if b { return a }
      return [{ fs: [dbl] }]
    }
    function mixed(b) {
      const a = [{ fs: [inc0] }]
      if b { return a }
      return [{ fs: [half] }]
    }
    print(mixed(false)[0].fs[0](3))
    print(last(true)[0].fs[0](3))

Want:

    1.5
    4

#### Mechanism

Not yet ablated. Both functions' bound `[{ fs: [inc0] }]` have one checked type; the call `mixed(false)[0]` reads an element row that no table entry resolves, so the two functions' rows for that type collide. On master the same pair refuses identically; `mixed` beside a value-`if` function of the same shape refuses at the literal instead (`object literal field count does not match struct`).
