### D16733 — a union alias that names itself as a direct member exhausts the compiler's call stack

**compiler trap · found checking that type hash-cons 6b-2's visited sets terminate on cyclic types · filed 2026-11-16 against master `aed6c5377`**

Repro:

    type N = N | null
    // vl check: the compiler itself trapped, "wasm trap: call stack exhausted"

The outcome owed is a check diagnostic or a program that runs, never a trap. `N` is a union whose
member is itself, so the alias has no content of its own to stand for; the fix decides whether such
an alias is refused or reduced to its other members.

#### Mechanism

Not located. Some walk over the alias's members recurses through the member `N` back into the alias
with no visited set and no cut. The trap happens at `vl check`, before emit.
