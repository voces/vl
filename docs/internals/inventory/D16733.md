### D16733 — a union alias that names itself as a direct member exhausts the compiler's call stack

**now a loud check reject (fixed 2026-11-16 by lane H) — the program stays illegal and the trap is gone: `fillUnionDeclMembers` refuses a union alias that reaches itself through bare members (`unionNamesItself`, `check_relate_core.vl`) with `Type `N` is a member of itself — a type can refer to itself only inside a list, a map, a record field or a function` at the declaration · was a compiler trap · found checking that type hash-cons 6b-2's visited sets terminate on cyclic types · filed 2026-11-16 against master `aed6c5377` · fixtures `tests/cases/types/union-self-member-refused.vl` and `tests/cases/types/union-self-member-in-container-runs.vl`**

Repro:

    type N = N | null
    // vl check: was a compiler trap, "wasm trap: call stack exhausted"; now the declaration's error

The outcome owed is a check diagnostic or a program that runs, never a trap. `N` is a union whose
member is itself, so the alias has no content of its own to stand for; the fix decides whether such
an alias is refused or reduced to its other members.

#### Mechanism

The union's row listed itself as a member, so `flattenVariantsInto` (`tyquery.vl`) recursed through
it without end. `type D = D` was already refused, but only when that is the whole body. The fix
refuses at the declaration whenever following bare members through union aliases leads back to it.
On refusal the members stay empty, as for `type D = D`, so no walk meets the cycle. A member inside
a list, a map, a record field or a function is not followed; that recursion runs.
