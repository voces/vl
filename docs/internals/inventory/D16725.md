#### Mechanism

`elabHoleContainerClosed` closes the parameter's binding through the list, so the instance is
`one<Set<string>[]>`, but the inner literal `Set()` (or `[]`) is a node of its own whose recorded
type stays open: the outer list literal has no row for an open element. The bound and
top-level forms close (D15040, D16207); the inner literal is not reached.
