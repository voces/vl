### D15229 — a function returning a list literal beside a bound list of records holding another un-annotated function is refused at emit

**closed · runs, prints `6` · was loud emit reject, `emitProgram: the lists this function returns are built at different rows, so its inferred list result has none`, clause 2 · found closing [D15209](D15209.md) · filed 2026-11-04 · fixed with [D15294](D15294.md): the returned binding's record list is built at the elaboration's held type, the same row the returned literal joins**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function pick(b: boolean) {
      if b { return [{ f: inc0 }] }
      const xs = [{ f: dbl }]
      return xs
    }
    print(pick(false)[0].f(3))

Want:

    6

#### Mechanism

[D15209](D15209.md) builds each returned LITERAL at the joined result; a returned binding is built at its own initialiser's type, which holds only its own set, so the two returns keep two rows.

| the witness | loud emit reject |
| `return [{ f: dbl }]` for the binding | runs, `6` |
