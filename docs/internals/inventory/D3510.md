### D3510 — a parameter default naming a module `const` that holds `null` passes the global's nullable box ref where the parameter takes a non-null one

**closed 2026-10-03 — the witness prints `null` · was check-clean invalid wasm, clause 1 · found by lane LU's literal-union grid (3 of 1,040 cells) · filed against master `878f6ebe8`, closed against master `b2238d2c6` · fixture `tests/cases/functions/default-param-module-const-null.vl`**

Repro:

    const bv: i32 | null = null
    function g(d: i32 | null = bv) { print(d) }
    g()
    // vl check: rc 0.  vl run: invalid module, "type mismatch: expected (ref $type), found (ref null $type)"

Want:

    null

#### Mechanism

A module `const` whose value is not a constant expression (a `null` value box, a closure, a
read of another const) lives in a start-initialised cell, nullable in wasm, and every read
of it recovers the non-null value with `ref.as_non_null`. `emitIdentNode` read a substituted
parameter default (`isDefaultGlobalRef`) through its own early arm, which mirrored only the
`string | null` rule and skipped that recovery. Closed by one shared `emitGlobalReadRecover`
that both the identifier read and the default read call.
