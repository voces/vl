### D4937 — `is K[][]` over a `V[][] | string` receiver is refused at emit in a generic instance

**loud emit reject · clause 2 · the nested-list face of [D4912](D4912.md) · pre-existing on master · filed 2026-10-15 against master `3a371d739`**

Repro:

    function probe<V>(v: V[][] | string) {
      if v is f64[][] { return 1 }
      0
    }
    const e: i32[][] = []
    print(probe(e))
    // vl check: rc 0.  vl run: emitProgram: `is` test but no union type declared

Want:

    1

#### Mechanism

The instance's receiver is the box union `i32[][] | string`, but `emitIs` finds no declared
union for it, so the test is refused before the element-fit path is reached. Its `V[] | string`
sibling (D4912) runs.
