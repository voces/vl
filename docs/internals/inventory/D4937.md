### D4937 — `is K[][]` over a `V[][] | string` receiver is refused at emit in a generic instance

**closed 2026-11-12, prints `1` · was loud emit reject, clause 2 · the nested-list face of [D4912](D4912.md) · filed 2026-10-15 against master `3a371d739` · closed with [D15762](D15762.md): the instance registers its `V[][] | string` union when `V` is inferred, so the delivery boxes and the empty-list fit (D15763) answers · fixture `tests/cases/generics/union-param-inferred-nested-list-arm-registers-its-union.vl`**

Repro:

    function probe<V>(v: V[][] | string) {
      if v is f64[][] { return 1 }
      0
    }
    const e: i32[][] = []
    print(probe(e))

Want:

    1

#### Mechanism

The delivery of `e` is refused: `unionHasRefArrayArmSlot` reads the generic row's `V[][]` arm,
which has no slot for `i32[][]`. Asked of the type, the delivery boxes, but the instance body is
then invalid ([D15762](D15762.md)). Spelled `probe<i32>(e)`, the program runs and prints `0`
([D15763](D15763.md)). Its `V[] | string` sibling (D4912) runs.
