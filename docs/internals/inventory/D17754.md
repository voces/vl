### D17754 — an un-annotated local read from a record field of type `null` breaks the IR verifier's null-unit read rule

**loud emit reject · `internal compiler error: the IR built for this top-level code breaks verifier rule 2 (a null-unit place read's null does not carry exactly its read)` · clause 2 · `vl check` rc 0 · 22 cells: `fn-value-enclosing-param-into-generic-nullable` and `-open`, every struct, list and map position the checker accepts · filed 2026-11-27 against master `d0a03be50` by I8-PREP (sibling sweep of the closure matrices)**

Repro:

    const w = { f: null }
    const v = w.f
    print(v == null)
    // vl check: rc 0.  vl run: internal compiler error (verifier rule 2)

Want:

    true

#### Mechanism

Not traced: the read `w.f` of a field whose type is the unit `null`, held by a local, builds a
null-unit place read whose null is not the read's own. The neighbouring field of type `"a"` read
the same way is D17752 (invalid wasm); whether it is one unit-typed-field mechanism is open.
