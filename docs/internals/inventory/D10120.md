### D10120 — a list of a generic pushed a fixed-type function, handed to an un-annotated parameter called at another type, passes check and traps

**trap after load · `vl check` rc 0 · `wasm trap: indirect call type mismatch` · clause 1 · found closing [D10080](D10080.md) · present on master `3931f9468`, unchanged by D10080's close · filed 2026-10-22 against master `3931f9468`**

Repro:

    function id<T>(x: T): T { x }
    function inc(x: i32): i32 { x + 1 }
    const ys = [id]
    ys.push(inc)
    function run(a) { print(a[1]("s")) }
    run(ys)
    // vl check rc 0.  vl run: wasm trap: indirect call type mismatch, in `run`

The owed outcome is a check refusal: `inc` reaches a call at `string`, which `vl check` refuses with `run` inlined.

#### Mechanism

[D10080](D10080.md)'s, at a hole. Its close judges the push row at the type a delivery
fixes, and an un-annotated parameter fixes none: `a` takes `((T) => T)[]` from the argument,
and the element call `a[1]("s")` in `run`'s body binds no `T` of `id`'s at a call the row is
re-validated at.
