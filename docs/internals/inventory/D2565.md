### D2565 — a record join stored as a list element and read back is refused where an `is` narrows it by elimination

**loud emit reject · `vl check` rc 0, then `emitProgram: field access receiver is not a struct`, clause 2 · found by the review of #3173 · filed 2026-09-26 against master `dcc88a350`**

Repro:

    type A = { r: i32 }
    type B = { q: string }
    function mkA(n: i32): A | null { if n == 0 { return null } return { r: n } }
    function mkB(s: string): B | null { if s == "" { return null } return { q: s } }
    function go(ka: i32, sb: string) {
      const xs = [mkA(ka) ?? mkB(sb)]
      const x = xs[0]
      if x == null { print("null") } else if x is A { print(x.r) } else { print(x.q) }
    }
    go(0, "b")
    // vl check: rc 0.  vl run: emit error, "field access receiver is not a struct"

#### Mechanism

A prediction until a close confirms it. The element's union row is minted since
[D2373](D2373.md)'s close (on master the same program refuses earlier, with `` `is` test but no
union type declared ``). What still fails is the last arm: `x` is narrowed to `B` only by
eliminating `null` and `A`, and the field read under that narrowing does not resolve `B`'s
variant when the binding's value came from an element read, while the same chain over a
binding of the join itself runs.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the join bound directly (`const x = mkA(ka) ?? mkB(sb)`) | runs, `b` | **yes** |
| an explicit `if x is B { print(x.q) }` | runs, `b` | **yes** |
| `print(xs[0] is B)`, no field read | runs, `true` | **yes** |
| the list annotated `(A \| B \| null)[]` | runs, `b` | **yes** |

#### Grading list

Each ablation row, and the same shape through a three-record join.
