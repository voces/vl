### D2565 — a record join stored as a list element and read back is refused where an `is` narrows it by elimination

**closed 2026-09-26 — the filed repro RUNS and prints `b` · was loud emit reject, `vl check` rc 0, then `emitProgram: field access receiver is not a struct`, clause 2 · found by the review of #3173 · filed 2026-09-26 against master `dcc88a350`**

Repro:

    type A = { r: i32 }
    type B = { q: string }
    function mkA(n: i32): A | null { if n == 0 { return null } return { r: n } }
    function mkB(s: string): B | null { if s == "" { return null } return { q: s } }
    function go(ka: i32, sb: string) {
      const xs = [mkA(ka) ?? mkB(sb)]
      const x = xs[0]
      if x == null { print("null") } else if x is A { print(x.r) } else { print(x.q) }
    }
    go(0, "b")
    // vl check: rc 0.  vl run: emit error, "field access receiver is not a struct"

#### Mechanism

The list literal's element slot was spelled by `nulRefElemEmitName`, which rendered a nullable
join of declared records structurally, `{r:i32}|{q:string}|null`. The union row the checker's
join produced is registered under the nominal `A|B|null`, so the binding's set was a spelling
no row holds: the `is A` complement found no `A` in it, subtracted nothing, and the last arm
read `x.q` over a two-member set. The element now takes the nominal spelling when that names a
registered row. The position matrix then showed the same capability missing at three PLACE
receivers (`xs[0]`, `h.f`, `m["k"]`), annotated faces included and on master too: their null
compares narrowed only value unions, and a map cell's `is` complement had no arm. Both now
cover a struct union with `null` and two or more arms.
