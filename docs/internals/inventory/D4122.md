### D4122 — a generic function passed through a generic identity call into an annotated binding is called at the wrong signature

**closed 2026-10-17 by lane L1 · runs, prints `3` · was loud emit reject · clause 2 · the checker binds `F` to `id`'s open signature, and the generic now takes the one pin the flow table carries past the hole, the annotation on `k` (`monoHoleGenFnTy`, `fnFlowDeclPinTys`, [D5612](D5612.md)'s close) · pins: `tests/cases/closures/generic-hole-fn-value-pinned-past-hole.vl` · `a generic function taken as a value reaches no call that fixes its type` since [D4123](D4123.md)'s refusal (#3569); was clause 1 before it**

Repro:

    function id<T>(x: T) { x }
    function sel<F>(f: F) { f }
    const k: (x: i32) => i32 = sel(id)
    print(k(3))
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch, at `print(k(3))`

Want:

    3

#### Mechanism

The un-annotated spelling ([D4121](D4121.md)) refuses at emit; the annotation gives the call
`k(3)` a concrete `(i32) => i32` signature, so the call is emitted, but the value stored in `k`
is not an `i32` instance of `id`, and the indirect call's type check fails at run time. From the
ablation; the stored value's function type has not been printed.

#### Ablation

| spelling | outcome | needed? |
| --- | --- | --- |
| the witness | loads then traps | — |
| no annotation on `k` | loud emit reject ([D4121](D4121.md)) | **yes** |
| `function sel(f: (x: i32) => i32)`, not generic | runs, `3` | **yes** |
| `const k: (x: i32) => i32 = id` | runs, `3` | **yes** (the pass-through call) |

#### Grading list

The witness must run and print `3`, or be refused by the checker if a ruling says a generic
function cannot pass through a type parameter un-instanced; [D4121](D4121.md) is graded with it.
