#### Mechanism

The classifiers outside `retLocalCellKind` kept `parentLetOf(fn.fnBody, name)`, the first
binding anywhere: `mapRetExprShape` and `retIsMapLocal` read the dead `Map<string, string>`,
so the result named that map's shape while the body returned the other. A record return
(`structIndexOfExpr` through `frameLetOf`) took the dead `Q`'s row and `r.x` was refused as an
unknown field; a function-value shadow (`exprIsClosureNoLocal` through `frameBindingNode`)
typed an `i32` caller's result as a closure. Each now resolves the read's own node through
`bodyLetReadAt` (by name only where the position cannot decide), and a parameter is asked
after the positioned `let`, not before it.
