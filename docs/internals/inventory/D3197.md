### D3197 — a hole or generic body calls a record's nullable function field at a pin that admits `null`, which the direct spelling refuses

**now a loud check reject · the pin re-check records a call through a hole as a constraint and refuses a callee that is not a function at the call's argument types, in the direct spelling's words · fixtures `tests/cases/generics/error-hole-call-through-nullable-field.vl`, `tests/cases/generics/hole-guarded-call-through-nullable-field.vl`, `tests/cases/generics/hole-guarded-call-through-null-typed-field.vl` · was loads then traps · clause 1 · pre-existing, the same on master `2771214c7` · found by the RF4 lane while grading D3192 · filed 2026-09-29 against master `2771214c7`, fixed 2026-09-29 against master `94670f728` · coordinator decision: refuse an unguarded call, as the direct spelling does (D3158's precedent), and exempt a guarded call at a `null`-typed pin; the runs it costs are recorded in the NF lane's PR**

Repro:

    type R = { v: i32, f: (() => boolean) | null }
    function F(z) { print(z.f()) }
    const r: R = { v: 7, f: null }
    F(r)
    // vl check: called value is not a function ((() => boolean) | null) (the body of `F` at the call's argument types)

#### Mechanism

The direct spelling, `function F(z: R) { print(z.f()) }`, refuses `called value is not a
function ((() => boolean) | null)`. A call through a hole (`checkCallNode`'s `TyVar` arm) minted
an `HD_RET` hole and recorded no constraint, so the re-check at the call's argument types never
asked whether the pin is callable. The arm now records a `memCstrTy` row (prop `()`), and
`validateMemCstrs` refuses a pin that is not a function in the direct spelling's words
(`callFloorMsg`). A guarded call stays legal because a null test on a hole's field now narrows
it (`placeFieldTy` reads the field a member read off the hole derived), so the callee is the
hole's non-null face (`HD_GNOT`), which substitutes to the function. A guarded call whose pin
types the field as the `null` type itself is a dead branch and is not refused (prop `?()`),
though the direct spelling refuses it (coordinator decision): an instance may be more permissive
than its annotated twin where that loses no run and admits no trap. The price is every program
that ran only because its `f` held a function.
