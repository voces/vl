#### Mechanism

`letFieldListsWiden` (check_statements.vl) widens the list fields of the record literal a binding is initialised by, through nested record literals. A record that is an element of a list literal was reached through an element step, which the walk did not take, so the field kept its literal's set and `holeSlotJudge` compared the results.
