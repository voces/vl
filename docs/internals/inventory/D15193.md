### D15193 — a record in a list literal whose list field is written a function of another result type is refused at check

**loud check reject · `cannot write 'half' to an element of 'rs[].xs'` · clause 2 · open, target `1.5` · found closing [D15168](D15168.md): a record bound to a name, at any depth of nesting, runs · filed 2026-11-03 against master `d467911e`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const rs = [{ xs: [inc0] }]
    rs[0].xs[0] = half
    print(rs[0].xs[0](3))
    // Want: 1.5

#### Mechanism

`letFieldListsWiden` (check_statements.vl) widens the list fields of the record literal a binding is initialised by, through nested record literals. A record that is an element of a list literal is reached through an element step, which the walk does not take, so the field keeps its literal's set and `holeSlotJudge` compares the results.
