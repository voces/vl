### D17795 — two written global record lists, one taking a two-return maker's result and one another maker's, refuse when no call pins the first list's functions

**closed 2026-11-28 by COV-UNION · runs, its witness prints its expected value · was a loud emit reject, `cannot yet lower this statement (convert list -> list)` · a call's result is read at the callee's built result rep: an un-annotated function whose result type is open and whose every returned value is a list or record literal stamped at one closed type is built at that type (`monoFnBuiltRetLitTy`, emit_mono.vl, read by `resultTy`, ir_build.vl), so `w = mk2()` reads the stamped rep `w`'s slot holds · pinned by `tests/cases/closures/maker-result-read-at-its-built-rep.vl`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function pick(b) {
      const a = [{ fs: [inc0] }]
      if b { return a }
      return [{ fs: [dbl] }]
    }
    let g = [{ fs: [dbl] }]
    g = pick(true)
    function mk2() { return [{ fs: [inc0] }] }
    let w = [{ fs: [dbl] }]
    w = mk2()
    print(w.length)
    // vl check: rc 0.  vl run: emit error at 8:5, "convert list -> list"

Want:

    1

#### Mechanism

Probed, not fixed (2026-11-28). The IR's miss is at the write `w = mk2()`: the call's result
is read at `mk2`'s open return rep, `[{fs: [closure(1 param) -> unsup]}]`, while `w`'s slot is
the closed `[{fs: [(i32) => i32]}]` every literal of the program is stamped at. The stamp pass
closes `mk2`'s returned literal; nothing closes the call's result rep. (The reported position, 8:5,
is not the miss's node.) Under the onesig rule the same refusal fires on the filed test even though it calls
`h`'s functions (an unrelated global of the same shape), which is how master pins them.
