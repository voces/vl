#### Mechanism

`computeRetInference` classifies `g`'s result from the `.map` call before the callback's
annotation resolves at the pin, so the result is a union ref list (`fRetKind` `reflist`), while
the body, emitted at the pin, builds the `string | null` list the callback returns. The annotated
spelling `function g<T>(x: T): (T | string)[]` runs. `emitReturnValue` refuses the disagreement
(`retMapBuildsOtherList`) rather than emit it.
