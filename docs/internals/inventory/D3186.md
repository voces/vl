#### Mechanism

`computeRetInference` classifies the function's result from the `.map` call before the callback
resolves at the pin, so the result is a union ref list (`fRetKind` `reflist`), while the body,
emitted at the pin, builds the list the callback returns there, a scalar or niche list.
`emitReturnValue` refuses the disagreement (`retMapBuildsOtherList`) rather than emit it; on
master the same cells were invalid wasm or refused with another sentence.

`T := string | null`, is loud as on master (`a ref list's element row does not resolve`); it
