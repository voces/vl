### D16834 — a `let` record of a list of lists of lists of un-annotated functions, re-pointed at another record literal, has no interned shape at emit

**closed 2026-11-16 by lane AE — the witness prints `6` · `ftRecWriteJoins` (`compiler/check_fn_tag.vl`) joins each element of a list literal whose element is the set, however deep in a record literal written whole, so the re-point's member is a leaf and the joined set is tagged as the one-level field's is · fixture `tests/cases/closures/record-list-of-lists-of-hole-fns-repointed.vl` (depth 2, depth 3, a nested record, a `const` of the read) · the residue with no call through the set is [D16915](D16915.md) · was: loud emit reject · clause 2 · found closing [D16821](D16821.md) · filed 2026-11-16 against master `4947de739`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function dbl(a) { return a * 2 }
    let r = { f: [[[inc0]], [[half]]] }
    r = { f: [[[dbl]]] }
    print(r.f[0][0][0](3))
    // vl check: rc 0.  vl run: emit error, "emitProgram: ref valtype with no interned shape"

Want:

    6

#### Mechanism

The checker widens the binding's set at every depth (`letLitListsWidenAt`, `elabFnFieldTy`), but
the tag decision found no leaf for the member the re-point writes: `ftRecWriteJoins` descended the
written record's nested list literals and recursed into the member name itself, which is no
literal, so `dbl` in `r = {f: [[dbl]]}` was never a leaf, the set stayed untagged, its widened
record kept an open function type, and no struct row was minted for the binding.
