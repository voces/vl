### D6992 — an `if` expression of an uncalled hole function handed to a parameter nothing reads is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same program with `exclaim(s: string)` runs, and `g(exclaim)` runs ([D6881](D6881.md)) · found closing [D6981](D6981.md) · present on master `4ad81c0e0` · filed 2026-10-19 against master `4ad81c0e0`**

Repro:

    function exclaim(s) { return s + "!" }
    function g(p) { print(1) }
    g(if true { exclaim } else { exclaim })
    // vl check: rc 0.  vl run: emitProgram: monomorphize: unsupported argument type for `p` in a call to `g`

Want:

    1

#### Mechanism

From the ablation only. An argument handed to an un-annotated parameter is typed by the
instancer from the argument's own shape, and a bare name of a hole function is recognised there
as one an unread parameter can take. An `if` expression of the name is not, so the call has no
argument type to instance `g` at.
