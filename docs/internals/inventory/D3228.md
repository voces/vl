### D3228 — a generic `return x` into `string | null` has no members to widen with when another instance pins a literal

**loud emit reject · clause 2 · pre-existing, the same on master `94670f728` · found by the #3290 round-2 review (`rv3290-4029/tw2/m2.vl`) · filed 2026-09-29 against master `94670f728`**

Repro:

    type K = "a" | "b"
    function h<T>(x: T): string | null {
      return x
    }
    const k: K | null = "b"
    print(h(k) ?? "n")
    print(h("q") ?? "n")
    // vl check: rc 0.  vl run: emit refuses "literal-union string widening with no members"

#### Mechanism

Not localised past the ablation. Each instance alone runs, so the `"q"` instance reads a
widening decision the `K | null` instance left behind.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| only `h("q")` | prints `q` | **yes** (both instances) |
| only `h(k)` | prints `b` | **yes** |
| `k: K` (no `null`) | prints `b`, `q` | **yes** (the nullable pin) |
