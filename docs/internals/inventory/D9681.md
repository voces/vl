### D9681 — a block-local binding that shadows a module list and reads it through an un-annotated alias traps the compiler

**closed · runs, prints `2` · was compiler trap, `vl check` rc 0, clause 2 · CAPABILITY: the same program with the alias annotated `const v: i32[] = w`, or the local renamed, prints `2` · found writing the [D9632](D9632.md) matrix, whose proof named a local `w` · filed 2026-10-22 against master `abe12f20f` · closed by resolving a read the checker's resolver bound to a module global or a start-block binding to that binding before asking the live scope (`identReadsGlobal`, emit_classify.vl; `startBlockLetBoundOf`, emit_start_block.vl) · fixture `scope/global-alias-read-under-a-shadow.vl`, matrix `global-alias-read-under-a-shadow` (29 → 34 of 34) · with [D9750](D9750.md) and [D9751](D9751.md) filed open**

Repro:

    const w = [1, 2]
    const v = w

      const w = v[1]
      print(w)

    // vl run: the compiler itself trapped (wasm trap: call stack exhausted)

#### Mechanism

The emitter types the un-annotated alias `v` by chasing its initializer `w`, and that chase
runs inside the reader's frame. `globalLetOfSidIn` and `startBlockLetOfAt` asked the live
scope by NAME first, found the inner `w`, and answered with it; its initializer reads `v`, so
`letUnionNameOf` → `unionNameOfIdentAt` cycled until the stack ran out. The record face cycled
through `nulVariantIdxOfExpr` and the map face through `exprMap`'s `declaredMap`. The same
name-first read gave non-cyclic wrong answers when the local was another kind: `map key is not
a string`, `unknown struct field`, and invalid wasm for a map or list local of another value
rep. The resolver already binds every Ident to its declaration (`identDeclOf`); the classifiers
now trust it when it names a module global or a start-block binding, in `globalLetOfSidIn`,
`startBlockLetOfAt`, `structIndexOfIdentExpr`, `refListElemNameOfIdent`, `exprMap` and
`mapShapeOfExpr`. No cycle guard: with the read bound to its own declaration the chase can no
longer reach a binding declared after it.
