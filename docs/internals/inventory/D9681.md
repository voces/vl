### D9681 — a block-local binding that shadows a module list and reads it through an un-annotated alias traps the compiler

**compiler trap · `vl check` rc 0 · clause 2 · CAPABILITY: the same program with the alias annotated `const v: i32[] = w`, or the local renamed, prints `2` · found writing the [D9632](D9632.md) matrix, whose proof named a local `w` · present on master `abe12f20f` · filed 2026-10-22 against master `abe12f20f`**

Repro:

    const w = [1, 2]
    const v = w
    if true {
      const w = v[1]
      print(w)
    }
    // vl run: the compiler itself trapped (wasm trap: call stack exhausted)

Want:

    2

#### Mechanism

Not traced. The alias `v` carries no annotation, so its type is read from its initializer
`w`; inside the block the inner `w` is in scope and its own type is read from `v[1]`. The
trap is consistent with that read resolving the name `w` to the shadowing local rather than
the module binding the alias was declared against, and so recursing. The backtrace has only
function indices; a `--names` seed would name the frames.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the alias annotated `const v: i32[] = w` | runs, prints `2` | **yes** |
| the local renamed `const u = v[1]` | runs, prints `2` | **yes** |
| the alias an unrelated list `const v = [3, 4]` | runs, prints `4` | **yes** |
| the local read `v.length` instead of `v[1]` | same trap | no |
| the inner `w` never read | runs | **yes** |
| the block a function body instead | same trap | no |
| scalars (`const w = 5`, `const w = v + 1`) | runs, prints `6` | **yes** |

#### Grading list

The `if`, function and bare-block scopes; a map and a record in place of the list; the
alias read once before the block.
