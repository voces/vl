### D16311 — an all-`null` list literal at a record field of `(boolean | null)[]` is built at a ref list where the field stores the boolean niche

**check-clean invalid wasm · clause 1 · bucket (f) · 2 of the 16 unsound fuzz findings of 2026-11-14 (one program, read and construct-only) · filed 2026-11-14 against master `fe9585a72`**

Repro:

    const v: {f: (boolean | null)[]} = {f: [null]}
    print(v.f.length)

Want:

    1

#### Mechanism

A `boolean | null` element is stored as the `i32` niche, so the field's list is an `i32` list.
The literal `[null]` holds no member that names that rep: its own element type is `null`, and it is
built as a list of `nullref`, which the record field's `i32` slot then receives. A literal with a
`true` in it, a bare binding of the list, and every other niche element (`i32`, `f64`, `string`)
are built at the field's rep.
