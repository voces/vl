### D3108 — an un-annotated list of function values over a nullable union arm has no signature

**loud emit reject · clause 2 · found by the #3273 review · the same outcome, with a different message, on master `d408f2da4` · filed 2026-09-28 against master `d408f2da4`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    const f = (w: Circle | null): i32 => if w == null { 0 - 1 } else { w.r }
    const fs = [f]
    print(fs[0](null))
    // vl check: rc 0.  vl run: emitProgram: a function-value call has no interned signature

Want:

    -1

#### Mechanism

Not investigated past the ablation. The element's key is rendered from the checker's element
type, which spells `Circle` as its field set `{r:i32}`, so the call asks for
`({r:i32}|null)=>i32`, a signature no lambda interns. The lambda keys its own parameter at
the `nulvariant` token `W` ([D3074](D3074.md)).

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const fs: ((Circle \| null) => i32)[] = [f]` | runs | **yes** (the un-annotated list) |
| no `type Shape = Circle \| Sq` | runs | **yes** (a union arm) |
| a result `Circle \| null` instead of the parameter | the same refusal | no |
| `app(c, f)` through `app<A>(x: A, h: (A) => i32)` | runs | no (the generic runs) |

#### Grading list

The un-annotated list at the parameter and at the result, and a list held in a record field.
