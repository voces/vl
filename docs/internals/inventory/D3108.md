### D3108 — an un-annotated list of function values over a nullable union arm has no signature

**closed · a list slot's un-interned key yields to the callee's interned arena key · fixture `tests/cases/closures/nullable-arm-function-list.vl` · was loud emit reject · clause 2 · found by the #3273 review · the same outcome, with a different message, on master `d408f2da4` · filed 2026-09-28 against master `d408f2da4`, closed 2026-09-28 against master `f14a8cca2`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    const f = (w: Circle | null): i32 => if w == null { 0 - 1 } else { w.r }
    const fs = [f]
    print(fs[0](null))
    // vl check: rc 0.  vl run: emitProgram: a function-value call has no interned signature

Want:

    -1

#### Mechanism

The list slot's key is rendered from the checker's element type, which spells the arm
`Circle` as its field set, so the call asked for `({r:i32}|null)=>i32`, which no lambda
interns (the lambda keys its parameter at the `nulvariant` token). `cloCallSigKey`'s indexed
arm now overrides an un-interned slot key with the arena key of the callee's own type
(`sigKeyOfTy`) when that one is interned, as the `Ident` resolver already does. An interned
slot key is never replaced.

#### Grading list

The un-annotated list at the parameter and at the result, and a list held in a record field.
