### D4915 — an empty list in a box union's list arm does not fit a disjoint list arm under `is`

**closed 2026-10-15 — now prints `K` · was check-clean silently wrong value, clause 1 · `is L` over a box union now tests a list arm in a disjoint rep by its length, and a local or global binding narrowed by it is re-boxed as an empty `L`; a capture, field or element receiver is not, and its narrowed read traps ([D4939](D4939.md)) · found closing D4906 · related to D4771 (an empty list fits every list type) · filed 2026-10-15 against master `23dcd80be` · pin: `tests/cases/unions/empty-list-is-disjoint-list-arm.vl`**

Repro:

    type K = "x" | "y"
    function f(a: i32[] | K[]) {
      if a is K[] { print("K") } else { print("i32") }
    }
    const e: i32[] = []
    f(e)
    // vl check: rc 0.  vl run: prints i32

Want:

    K

#### Mechanism

D4771's ruling makes `is` over a list test every element, so an empty list fits every list
type. A box union tests a list arm by its tag, and the `i32[]` arm's tag never names `K[]`.
The element-wise test D4779 added covers only arms whose elements can fit (`string` into a
string literal union); an arm whose elements never fit still fits when it is empty. Admitting
it makes the then-branch's narrowed list a different arm's rep; the close re-boxes a narrowed
binding as an empty list of the tested arm instead (D4939 for the receivers it cannot store to).

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const e: i32[] = [7]` | prints `i32`, which is right | **yes** (empty) |
| `a: i32[] \| string[]`, `is string[]` | prints `i32`, want `string` | no (any disjoint list arms) |
| `type K = 0 \| 1` (one list, no box) | prints `K` (D4771's element test) | **yes** (a box union) |
