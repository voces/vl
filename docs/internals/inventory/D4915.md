### D4915 — an empty list in a box union's list arm does not fit a disjoint list arm under `is`

**check-clean silently wrong value · clause 1 · found closing D4906 · `i32[] | string[]` gives the same answer on master before D4906's close; `i32[] | K[]` printed `K` there, because that union had no box and every list answered `K` · related to D4771 (an empty list fits every list type) · filed 2026-10-15 against master `23dcd80be`**

Repro:

    type K = "x" | "y"
    function f(a: i32[] | K[]) {
      if a is K[] { print("K") } else { print("i32") }
    }
    const e: i32[] = []
    f(e)
    // vl check: rc 0.  vl run: prints i32

Want:

    K

#### Mechanism

D4771's ruling makes `is` over a list test every element, so an empty list fits every list
type. A box union tests a list arm by its tag, and the `i32[]` arm's tag never names `K[]`.
The element-wise test D4779 added covers only arms whose elements can fit (`string` into a
string literal union); an arm whose elements never fit still fits when it is empty. Admitting
it makes the then-branch's narrowed list a different arm's rep, so the then-branch has to keep
the union, as D4779's does.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const e: i32[] = [7]` | prints `i32`, which is right | **yes** (empty) |
| `a: i32[] \| string[]`, `is string[]` | prints `i32`, want `string` | no (any disjoint list arms) |
| `type K = 0 \| 1` (one list, no box) | prints `K` (D4771's element test) | **yes** (a box union) |
