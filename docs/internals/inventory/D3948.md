### D3948 — a `const` alias of a written capture cell holding a generic function, returned, builds invalid wasm

**check-clean invalid wasm · clause 1 · found in review of #3498 (`rv3498/p19`) · filed 2026-10-10 against master `429e7b093`**

Repro:

    function inner<U>(u: U) { print("I"); print(u) }
    function other<V>(v: V) { print("O"); print(v) }
    function mk(): (n: i32) => void {
      let k = inner
      const flip = () => { k = other }
      flip()
      const r = k
      return r
    }
    mk()(4)
    // vl check: rc 0.  vl run: the emitted module failed to validate

Want:

    O
    4

#### Mechanism

Not located. `k` is a capture cell; D3939 instances the cell at a type it is delivered or
called at, and `return k` is such a delivery. `const r = k` copies the cell read into an
un-annotated alias first, and the alias's delivery at the return type does not reach the cell
it was read from, so the cell keeps the generic's un-pinned element type.
