### D3948 — a `const` alias of a written capture cell holding a generic function, returned, builds invalid wasm

**closed 2026-10-10 by lane SC · runs · was check-clean invalid wasm · clause 1 · pins: `tests/cases/closures/captured-cell-alias-of-read-delivered.vl` · found in review of #3498 (`rv3498/p19`) · filed 2026-10-10 against master `429e7b093`**

Repro:

    function inner<U>(u: U) { print("I"); print(u) }
    function other<V>(v: V) { print("O"); print(v) }
    function mk(): (n: i32) => void {
      let k = inner
      const flip = () => { k = other }
      flip()
      const r = k
      return r
    }
    mk()(4)
    // vl check: rc 0.  vl run: the emitted module failed to validate

Want:

    O
    4

#### Mechanism

`k` is a capture cell; D3939 instances it at a type it is delivered or called at. `const r = k`
copies the cell read into an un-annotated alias first, and the alias's delivery did not reach the
cell. A delivered name whose chain of un-annotated aliases, never written after their
initializer, ends at a cell read is now read as that cell (`monoCoerceAliasOfCell`), so the cell
is instanced at the delivered type.
