#### Mechanism

`gaeEnsure` minted an application's row from its spelling, substituting the argument text into each declared field (`gaeApplyFieldTy`). It refused a `(V | null)[]` field once `V` was bound to a generic record application, because the substituted element spelling keyed no ref-list slot and the literal's `null` element would build at the wrong rep (D2525's boundary for a generic record). The application now interns at its checked instance type through the inline-shape interner, which keys the field's slot from the type, and the refusal is gone.
