#### Mechanism

A spread copies its operand's elements into the new literal, so no list is shared and no
aliasing rule applies. The literal is typed `f64[]`, but the spread of an `i32[]` operand is
lowered as a copy between two lists of one storage. The `f32[]` operand runs (`[...f32s,
2.5]` prints `0.75` for `1.5`), so the `i32` to `f64` element conversion is the missing arm.
Not yet localised in the emitter.
