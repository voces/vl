### D3089 — a hole function's `.map` or `.filter` over a list literal of its parameter traps on a `null` at a `string | null` pin

**loads then traps · clause 1 · open · the residue of [D3066](D3066.md)'s close: the `mcapidx`, `mcapx` and `nested` `nsnull` cells of the lane HL grid, and 9 `snN` cells of the #3237 review grid (`lamList`, `litFilter`, `litMap`), which were invalid wasm on master · filed 2026-09-28 against master `d408f2da4`**

Repro:

    function f(x) {
      print([x].map((e) => x)[0])
    }
    const v0: string | null = null
    f(v0)
    // vl check: rc 0.  vl run: wasm trap: null reference

Want:

    null

#### Mechanism

Not localised past the ablation. The literal now builds at the `(string | null)[]` pin, and the
callback's result list, or the read of its element, still treats the element as a non-null
string, so the `null` reaches a non-null cast. The same shape at `i32 | null`, a non-null
string, or the `<T>` spelling prints the right value, as long as the module declares no
string-literal union; with one declared, other pins trap too ([D3092](D3092.md)).

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const m = [x].map((e) => x)` then `print(m[0])` | traps | no |
| `(e) => e` in place of `(e) => x` | traps | no |
| `.filter((e) => true)` in place of `.map` | traps | no |
| `const v0: string \| null = "s"` | prints `s` | **yes** (the `null`) |
| an `i32 \| null` pin, no string-literal union declared in the module | prints `null` | **yes** (with one declared, a `cast failure` trap: [D3092](D3092.md)) |
| `function f<T>(x: T)` | prints `null` | **yes** (the hole) |
