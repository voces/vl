### D2570 — `??` over a string literal union `LI | null` with a default outside `LI` refuses

**loud emit reject · clause 2 · pre-existing on master `dcc88a350` · filed 2026-09-26 from #3171's review sibling `rv3171r2/min/p4.vl`, where a let-bound lambda is scenery**

Repro:

    type LI = "a" | "b"
    const v: LI | null = "b"
    print(v ?? "none")
    // vl check: rc 0.  vl run: emitProgram: `??` over this nullable value is not supported
    // yet — narrow it first, e.g. `if v != null { … }`

#### Mechanism

Not located. The coalesce's result is `LI | "none"`, which widens to `string`, while the left
operand is the `LI | null` niche, whose non-null value is an interned atom id. A default inside
`LI` (`const w: LI = v ?? "a"`) runs and prints `b`, so the missing piece is the atom-to-string
widening of the left operand at a `??` whose result is `string`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the default outside `LI` (`v ?? "a"` into an `LI`) | runs, prints `b` | **yes** |
| the lambda of `p4.vl` (a plain binding, as above) | still refuses | no |
| the binding (`function f(p: LI \| null) { return p }` called) | still refuses | no |
