### D3382 — a `K | L | null` box delivered as `string | null` is not converted

**check-clean invalid wasm · clause 1 · open · found narrowing [D3208](D3208.md) · the same on master `3291e99e1` · filed 2026-09-30 against master `3291e99e1`**

Repro:

    type K = "a" | "b"
    type L = "c" | "d"
    function g(): K | L | null { return "c" }
    function w(): string | null { return g() }
    print(w() ?? "n")
    // vl check: rc 0.  vl run: invalid module, inside `w`: type mismatch

Want:

    c

#### Mechanism

A union of two literal-union aliases and `null` is the `{tag, anyref}` box, whose payload for
`"c"` is the string. `string | null` is the nullable string niche. The return delivers the box
with no conversion (`return_call` of the box-returning `g`), and nothing unboxes the payload or
maps the null tag to `ref.null`. The `K | L` spelling (no `null`) is an atom and converts through
the atom-to-string ladder; `print(g() ?? "n")` is refused at emit instead (`` `??` over this
nullable ``…), the same missing conversion met by another operator.
