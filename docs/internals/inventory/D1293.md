  refusal's own inputs: `ftxt=[Inner[]|null]`, `nameIsArray(np)=T`, `nameIsRefArray(np)=F`.

  spelling was never affected, because its array arm ends in a table-free `return 5`. The
  arena is not blind to it, so `fieldCodeOfSpelling` asks it LAST, where no name arm can move.

* **AND THE ELEMENT NAME HAS THE SAME ORDER PROBLEM ONE LAYER ON.** With the code, the type
  section then read `nullable ref-list field element type is not interned`:
  `fieldRefElemName`'s code-28 arm used the non-deferred resolver under a comment asserting
  "this path runs after the struct/union tables exist", which the variant recorder made false.
  It takes `refArrElemKeyDeferred`, exactly as the shape-text recorder's arm already did.
