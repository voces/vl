### D6931 — a hole function called by name and also handed to a parameter that only aliases it is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · UNDECIDED: without the direct call the same program runs, `2` ([D6912](D6912.md)); with it the function has one instance, `(i32) => i32`, that the alias could take · found closing [D6912](D6912.md) · present on master `43f22053c` and at #4153's head · filed 2026-10-19 against master `2dcd6d29f`**

Repro:

    function inc(x) { x + 1 }
    function run(f) {
      const k = f
      print(2)
    }
    run(inc)
    print(inc(4))
    // vl check: rc 0.  vl run: emitProgram: cannot take the generic function `inc` as a value — a function value carries ONE signature, and parameter `x` is un-annotated (it would default to i32). Call sites pin `inc` at (i32)

Want:

    2
    5

#### Mechanism

From the ablation only. The inert-parameter stub serves only a function no call instances, since
a called function has a body the stub would replace. Once `inc(4)` instances it, the argument
takes the ordinary value pin, which refuses a hole function its call sites pin at one type
rather than adopting that type.
