### D2906 — a generic value join that is a union at the pin is read at the template's type outside a print or a binding read only there

**closed 2026-09-29 · was check-clean silently wrong, clause 1, on master `94670f728` · closed by the owner's ruling (A), 2026-09-29: a type parameter inside a union is gradual · residue of D2893 and D2787, from the GJ lane's generic-join grid · filed 2026-09-27 against master `829bd497c` · fixture `tests/cases/generics/gradual-type-parameter-union.vl`**

Repro:

    function g0<T>(a: T, c: boolean) {
      const r = [if c { a } else { 5 }]
      print(r[0])
    }
    g0(true, false)
    // vl check: rc 0.  vl run: prints true

Want:

    5

#### Mechanism

The instance lowers a generic body at its template's node types substituted through the pin,
and `if c { a } else { 5 }` is typed `T` in the template, so at `boolean` the list literal is a
`boolean[]` and stores the `5` as `true`. The checker's re-check at the pin types the join
`boolean | i32`. The instance re-types the join to that union only where the value is
delivered to a `print` argument or a binding every read of which is one (`monoPinSink`),
because every other consumer (a list or object literal, a capture, a return, a generic call's
argument, an `is` test, an `==` whose other side is still read at `T`, a lambda's tail) reads
the template's `T` and lowered the union as invalid wasm or a wrong comparison when re-typed.
Unlike D2916, whose join is typed with an inference hole that pins to the union at every node,
here the template's join absorbs the
`5` into `T` itself, so the binding, its reads and the call site's result are all typed `T` and
pin to `boolean`. The annotated-return twin (`function g<T>(a: T, c: boolean): T`) is refused at
the call's re-check (`expected boolean, got i32`); the un-annotated one is not.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the list literal (`print(if c { a } else { 5 })`) | prints `5` | **yes** |
| the type parameter (`a: boolean`) | prints `5` | **yes** |
| the literal of another type (`if c { a } else { false }`) | prints `false` | **yes** |

#### Grading list

The other consumers, each wrong or invalid at the `boolean`, `string` and `i32 | null` pins:
`const r = J; const f = () => r; print(f())`; `const r = J; r` as the tail, printed by the
caller (D2787's `retbind` and annotated-return spellings); `print(id0(J))` over a generic
`id0`; `const r = J; if r is string { … }` (D2787's grading list); `const f = () => J`.
The literal-arm binding returned by name at a `boolean` pin, `const r = if c { a } else { 5 }; r`
with `g0(true, false)`, prints `true` (want `5`), the same before #3233. An `==` against the parameter, `f<T>(t: T | null) { const r = t ?? 2.5; print(r == t) }` with
`f(7)`, which must print `true` (invalid wasm on master; the concrete spelling is a check
reject). From the #3234 review, identical on master: a captured join printed inside a lambda
prints `1` for `true`; `id(a)` in a lambda arm is `unsupported argument type`; and a lambda
tail `if` at a `string | i32` pin is the inferred-union refusal. Grids: the GJ lane's `g2`
(`bindlist`, `bindret`, `capture`, `eqa`, `idcall`, `lambda`, `list`, `neq` positions) and
`g3` (`coalif`).

**Closed by ruling (A) (owner, 2026-09-29).** `joinTys` types a declared parameter beside a
concrete type as their union, kept apart (`tpJoinUnions`), and two such unions join by their
members rather than by the parameter's assignability. A union holding a declared parameter is
gradual (`tpGradualView`): a binary or unary operator, a member or index read, a built-in method
call, a template hole and a concrete argument are checked in the body against its concrete
members and recorded, and each pin re-checks the whole substituted union in the direct
spelling's words. The instance re-types the join at the substituted union wherever it goes,
registers its box, re-types every read of such a binding and both sides of an `==` against it.
Measured against master on the CK lane's 2,880-cell generic-join grid (graded against each
cell's concrete twin): 0 cells that ran lost, 165 moved to the right value, and 41 that master
ran while their direct twin is refused are now refused at the call (the ruling's price, e.g.
`-r` at a `boolean` pin). The six body-operation probes the CK lane measured run at every
well-typed pin.
