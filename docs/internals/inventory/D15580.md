#### Mechanism

`elabListMemberSigs` walks each call through a list element whose set is untagged and holds a
capturing lambda, and mints each member at the closed parameter types the call gives it.
`elabMemberCallSig` refused a lambda (`fnName == ""`), and typed the argument of the member's
own calls through a hole parameter by the check alone, where a captured `k` of a hole encloser
is still open.
