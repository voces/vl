### D3193 — a generic or hole instance calling a record's field function whose result is a literal union prints the member's atom

**check-clean silently wrong · clause 1 · pre-existing, the same on master `36d233f66` · found by the #3286 review (`rv3286-2159/g2/k0287_s7_i32_none_generic.vl` and seven siblings) · filed 2026-09-29 against master `36d233f66`**

Repro:

    type R = { v: i32, f: () => "a" | "b" }
    function F<Z>(z: Z) { print(z.f()) }
    const r: R = { v: 1, f: () => "a" }
    F(r)
    // PRINTS 0

Want:

    a

#### Mechanism

Not localised past the ablation. The literal-union result reps as its interned `i32` atom, and a
call through the field inside an instance is printed at that atom instead of rendered as its
member; outside an instance, and at an annotated parameter, the call renders `a`. No row claim
and no nullable are involved, which is what keeps it apart from D3192.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `print(r.f())` at module scope, no function | prints `a` | **yes** (an instance) |
| `function F(z: R)` | prints `a` | **yes** |
| `function F(z)`, a hole | prints `0` | no |
| `R` without `v` | prints `0` | no |
