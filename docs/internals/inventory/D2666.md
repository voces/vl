Repro:

    function m32(): {[i32]: i32} {
      const m: {[i32]: i32} = Map()
      m[3] = 30
      return m
    }
    function m64(): {[i64]: i32} {
      const m: {[i64]: i32} = Map()
      m[3 as i64] = 64
      return m
    }
    let ga = m32()
    let gb = m64()
    function fc(c: boolean) {
      if c { ga = m32() } else { gb = m64() }
    }
    const r = fc(false)
    print(gb[3 as i64] ?? -1)
    print(ga[3] ?? -1)
    // vl check: rc 0.  vl run on master: invalid module, `fc` fails validation

#### Mechanism

The checker's `joinTys` collapsed two types to the wider whenever one was assignable to the
other, and map assignability is covariant in key and value, so `{[i32]: i32}` joined into
`{[i64]: i32}` (and `{[string]: i32}` into `{[string]: i32 | null}`, a string literal-union value
into `string`). Where the key or value is STORED differently, that collapse is the implicit
container widening a delivery refuses, and the narrower arm pushed its own struct where the wider
one's was declared. The join now keeps such a pair apart as their union (`joinWidensMap`, asking
`containerElemClassDiffers` of the key and the value, as the delivery's map arm does, with a
numeric literal union stored as its base); a same-storage pair (`boolean` / `boolean | null`,
`string` / `string | null`, `1 | 2` / `i32`) still collapses to the wider map, which is a legal
delivery. The union lowers as the annotated spelling does: the inferred return is recorded
through the map-union rung and passes the floor, an assignment-armed tail `if` returns the box
rather than a cell (`fnAssignRetKind`, `criClassify`), an `if` or `??` join registers its union,
a value `if` over such a join is the box rather than its then arm's map (`ifExprRefKind`), and a
nullable map boxes through `br_on_null` into the map arm or the null (or `??`'s default).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the differing key or value rep (both arms `{[i32]: i32}`) | runs | **yes** |
| the `if` (a straight tail `gb = m64()`) | runs | **yes** |
| the assignment arms (value arms `m32()` / `m64()`) | same invalid wasm | no |
| the function (a top-level `const r = if c { … } else { … }`) | same invalid wasm | no |
| the key rep, keeping a value rep (`i32` vs `i32 \| null`, `"a" \| "b"` vs `string`, `i32[]` vs `string[]`) | same invalid wasm | no |
