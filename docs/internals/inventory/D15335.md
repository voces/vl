### D15335 — a value `if` of record literals written into a binding or slot widened by its function fields is refused at emit

**closed · runs, prints `2` then `2.5` · was a loud emit reject (`emitProgram: cannot take the generic function id2 as a value`), clause 2 · found grading D15307 · filed 2026-11-04 · fixed in the field widener's write scan: `cwSlotDescend` (check_write_scan.vl) descends a value `if` or `match` into each arm's value, as `cwFvAddValue` already does, so the binding's field is widened by every arm's function and `recAsgFnWidenedTy` answers each arm's literal. Two widened bindings of one set, one writing its initialiser's function back from an arm, is [D15337](D15337.md)**

Repro:

    function id1(a) { return a }
    function id2(a) { return a }
    function id3(a) { return a }
    const c = 1 > 0
    let r = { f: id1 }
    r = if c { { f: id2 } } else { { f: id3 } }
    print(r.f(2))
    print(r.f(2.5))

Want:

    2
    2.5

#### Mechanism

The field widener collects what a binding's writes store at a slot through `cwSlotDescend`, which
had no `if` or `match` arm and gave up on the whole binding: it was never widened, so
`recAsgFnWidenedTy` answered no arm (a probe read `place=r, result=-1` for both arms). With the
arm, a fn-tag change is not needed: built without it, the same cells run.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the choice (`r = { f: id2 }`) | runs (D15306) | **yes** |
| binding → field slot (`h.r = <choice>`) | still refuses | no |
| `id3` (arms `{ f: id2 }` and `{ f: id1 }`) | still refuses | no |

The capability matrix's slot rows (`if-arm-record-fn-field-two-members`) are not this row: they
write into a container annotated at a closed function type, which is D15301's.

Still refused, each loud before and after: an arm reading a `const` record (`if c { q } else …`,
D15308's shape), and a list-valued field (`{ f: [id2] }`, `ref valtype with no interned shape`).
