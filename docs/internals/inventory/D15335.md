### D15335 — a value `if` of record literals written into a binding or slot widened by its function fields is refused at emit

**open · loud emit reject · `emitProgram: cannot take the generic function id2 as a value — a function value carries ONE signature` · clause 2 · a plain literal written there runs since D15306/D15307 · found grading D15307 · filed 2026-11-04 against master `23c9f7db`**

Repro:

    function id1(a) { return a }
    function id2(a) { return a }
    function id3(a) { return a }
    const c = 1 > 0
    let r = { f: id1 }
    r = if c { { f: id2 } } else { { f: id3 } }
    print(r.f(2))
    print(r.f(2.5))

Want:

    2
    2.5

#### Mechanism

`recAsgFnWidenedTy` answers each literal written whole into a widened place, `if` arms
included, but the arms' literals are not built there: the choice's own type is a join of the
arms', and fn-tag's write join reads the written value only as a literal (`ftRecWriteJoins`
peels no `if`).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the choice (`r = { f: id2 }`) | runs (D15306) | **yes** |
| binding → field slot (`h.r = <choice>`) | still refuses | no |
| `id3` (arms `{ f: id2 }` and `{ f: id1 }`) | still refuses | no |

The capability matrix's slot rows (`if-arm-record-fn-field-two-members`) are not this row: they
write into a container annotated at a closed function type, which is D15301's.
