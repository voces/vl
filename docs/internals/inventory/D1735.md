### D1735 — a map whose value is OBJECT-shaped has no narrowed place read, so D1734's guard declines it and the cell keeps its `V | null`

**loud check reject · filed 2026-09-06 against master `6de9fd11a` · found by D1734's
value-rep sweep, which is what bounded the gate · 0 corpus cells**

Repro:

    type Hit = { msg: string }
    type Miss = { why: string }
    type R = Hit | Miss
    function mkA(): Hit { return { msg: "a" } }
    const m: { [string]: Hit } = Map()
    m["k"] = mkA()
    if m["k"] != null { print(m["k"].msg) } else { print("null") }
    // vl check: rc 1,
    // member access '.msg' on non-object Hit | null

#### Mechanism

D1734 gives a map read place the `!= null` narrowing a list place has, and its value-rep
sweep found the reps the guarded READ can honour: `i32`, `boolean`, a list, a value union and
a nullable scalar all run. An OBJECT value does not. Lifting the gate for it produced
check-clean invalid wasm rather than a run, so `mapValIsObjShape` holds the cell at the
refusal it already had — the gate is the row, not a second defect.

The bound is the SHAPE and not "is the value a union arm", which is the finer line the
witnesses actually draw and which the checker cannot see: a plain struct value ran and an ARM
value did not. Both are excluded because `placeElemTy` has no way to tell them apart.

| the union `R` (a plain struct value) | refuses identically under the gate | no |

#### Grading list

The three ablation rows that run. A close lifts `mapValIsObjShape` and must show the arm
witness above RUNNING rather than going silent — the `is` spelling of it runs today, and is a
pin. It should also re-grade the STRING value's `.length`, the second rep the sweep found
unwired: `if m["k"] != null { print(m["k"].length) }` over `{ [string]: string }` is
`emitProgram: '.length' on a receiver the emitter cannot classify as a list, string, map or
set`, while `print(m["k"])` and `m["k"] + "c"` at the same place both run.
