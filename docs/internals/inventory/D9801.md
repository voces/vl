#### Mechanism

The checker types `a ?? 0.5` at the `i64 | null` pin as the `i64 | f64` box. The emitter asks
the instance's type of a hole-typed node through `holePinReadAt`, which had no arm for the
`HD_COAL` hole, so the arithmetic saw no numeric union and emitted `i32.add` over the box,
and the inline `(a ?? 0.5) + 1` did the same through `njMembersOf`.
