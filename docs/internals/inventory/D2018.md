### D2018 — mutually recursive un-annotated void functions whose tail `if`/`else` has one value arm and one void-call arm trap `unreachable` on return

**closed — the tail-`if` arm rule [D1995](D1995.md) states: a tail `if`/`else` is the function's value only when every arm that completes yields one, so `doTree` below is `void` in the checker and the emitter alike · was loads then traps (`vl check` rc 0, then `wasm unreachable` in `doTree`, clause 1) · reported by plumb (PL-011), whose CFG structurer (`doTree` / `nodeWithin` / `doBranch` / `emitBlock` in `src/emit.vl`) carried a trailing `return` in each function as the workaround · filed and closed 2026-09-22 against master `af07f4ae0` · `tests/cases/conditionals/tail-if-value-less-arm.vl`**

Repro (runs, prints `5`):

    const out: string[] = []
    function ln(s: string) { out.push(s) }
    function doTree(x: i32) {
      if x % 2 == 0 {
        ln("h")
        nodeWithin(x)
        ln("}")
      } else {
        nodeWithin(x)
      }
    }
    function nodeWithin(x: i32) {
      if x <= 0 {
        ln("leaf")
        return
      }
      doTree(x - 1)
    }
    doTree(3)
    print(out.length)
    // vl check: rc 0.  vl run: wasm trap, unreachable, in `doTree`

#### Mechanism

`ln`'s tail `out.push(s)` yields the new length, so `ln` is `(string) => i32`, and the then-arm of
`doTree`'s tail `if` ends in a value; the else-arm ends in `nodeWithin(x)`, which a bare `return`
pins `void`. The checker joined the arms to `i32 | void` and the emitter's `ifTailIsValue` asked
whether ANY arm is a value, so `doTree` got `(result i32)` and its void arm fell into the padding
`unreachable`. PL-011's smaller probe (`vl-probes/tailif/c.vl`) ran because its value arm was an
assignment and every function in its cycle agreed on `i32`. The recursion is scenery: the same
mixed tail traps in a plain top-level function, which is D1995's family.
