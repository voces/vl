### D3422 — a record delivered through a type parameter at a pin that stores a field differently is not refused, and a declared type of its shape makes it invalid wasm

**check-clean invalid wasm · clause 1 · open · pre-existing, the same on master `5e277ab52` · 84 cells of lane NW's `nw/g4` grid · filed 2026-09-30 against master `5e277ab52`**

Repro:

    type R = { v: i32, f: string | null }
    type N = { v: i32, f: string }
    function rd(q: R) { print(q.v) }
    function F<Z>(w: Z) {
      rd(w.r)
    }
    F({ r: { v: 1, f: "abc" } })
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `F`

#### Mechanism

Not localised past the ablation. The direct spelling refuses the delivery by the record storage
rule (`{v: i32, f: string} is not R: they store field f differently … only a fresh record
widens`). At the pin the source is a field of the parameter, not fresh, and D3250's pin
re-check asks `objShapeAdapterlessAt` of it, which declines there, so no rule refuses; the
instance then builds the argument at the declared `N`'s row and hands it to `rd`'s `R`.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `function F(w: { r: { v: i32, f: string } })` | check refuses (record storage) | **yes** (a type parameter or hole) |
| `type N` removed | prints `1` | **yes** for the invalid wasm; the missing refusal stays |
| `function F(w)` | invalid wasm | no |
| a callee that writes `f` | check refuses at the pin (D3250) | **yes** (no widened write) |
