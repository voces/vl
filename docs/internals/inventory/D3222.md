### D3222 — an if-expression or `match` arm that always exits joined `void` into the value's type

**loud check reject · filed 2026-09-29 against master `94670f728` · a legal program refused, clause 2**

Repro:

    function r(n: i32): i32 {
      const y = if n == 4 { return 99 } else { n }
      y + 1
    }
    print(r(4))
    print(r(5))
    // vl check: operator '+' is not defined for void | i32 and i32

Want:

    99
    6

#### Mechanism

`checkIfTail` returned `joinTys(thenTy, elseTy)` for an `if` with an `else`, and an arm block
ending in `return`, `break` or `continue` has the tail type `void`, so the join became
`void | i32`; the three `match` joins do the same per arm. A fix leaves such an arm block out
of the join, and must then give the emitter an arm with no value: ending each noted arm with a
dead `never` value (`__trap__()`), the tail every rep's arm lowering already accepts (D1972), is
the shape the loop-values follow-up to #3293 carries, graded on the grids below.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `return` (arm is `{ 99 }`) | runs | **yes** |
| `return` replaced by `break` inside a loop | same refusal | no, any exit |
