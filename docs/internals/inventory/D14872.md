### D14872 — an un-annotated binding initialised by a value `if` of record literals is not built at the record it is delivered to

**check-clean invalid wasm · clause 1 · found grading D3389's bound-first spelling · filed 2026-11-01 against master `8cc44be99`**

Repro:

    type J = { f: i32 | null }
    function g(x: i32) {
      const n = if x > 0 { { f: 5 } } else { { f: 4 } }
      const b: J = n
      print(b.f ?? 70)
    }
    g(3)
    // vl check: rc 0.  vl run: invalid module inside `g`: type mismatch: expected (ref $0), found (ref $1); $0 is `J`, struct {mut (ref $3)}; $1 is `#anon1`, struct {mut i32}

Want:

    5

#### Mechanism

The record solve builds an un-annotated binding at the record it is delivered to only when its
initialiser is an object literal (`recAdoptNote`'s `Ident` arm, `recBuildPush`). A value `if`
whose arms are record literals is neither adopted nor built there, so both literals are built at
`{f: i32}` and the read is stored into the `J` slot unconverted.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const n = { f: 5 }` (a plain literal) | runs, `5` | **yes** |
| `const n: J = if …` | runs, `5` | **yes** |
| an arm `null`, `const b: J \| null = n`, print `b?.f ?? 70` | same invalid wasm | no |
| delivered as `const b: J = n ?? { f: 6 }` with an arm `null` | same invalid wasm | no |
| `b.f = null` written after the delivery | loud check reject (a widened field written through a shared record) | — |
