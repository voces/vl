### D14872 — an un-annotated binding initialised by a value `if` of record literals is not built at the record it is delivered to

**closed 2026-11-02 · runs, prints `5` · was check-clean invalid wasm, clause 1 · fixture `tests/cases/objects/join-binding-adopts-union-field-record.vl` · found grading D3389's bound-first spelling · filed 2026-11-01 against master `8cc44be99`**

Repro:

    type J = { f: i32 | null }
    function g(x: i32) {
      const n = if x > 0 { { f: 5 } } else { { f: 4 } }
      const b: J = n
      print(b.f ?? 70)
    }
    g(3)

Want:

    5

#### Mechanism

The record solve builds an un-annotated binding at the record it is delivered to only when its
initialiser is an object literal (`recAdoptNote`'s `Ident` arm, `recBuildPush`). A value `if`
whose arms are record literals is neither adopted nor built there, so both literals are built at
`{f: i32}` and the read is stored into the `J` slot unconverted.

The record-covariance ruling (DECISIONS.md, D2996) adopts a FRESH binding into the record it is
delivered to, and finds the binding through `if`, `match` and block tails. `recFreshDeclOf` found
one only when its initialiser was itself a literal, so a binding of a value join of literals
never adopted; an `f64` field ran only because a numeric width adopts on another path. It now
also counts a join whose every tail is an object literal, or every tail a list literal
(`recJoinOfLits`), so the binding adopts and each arm is built at the destination. Not closed by
this: the same binding also read at its own type before the wider delivery
(`print(n.f + 1)` beside `const b: J = n`) stays invalid wasm, as it was; the single-literal
binding runs there.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const n = { f: 5 }` (a plain literal) | runs, `5` | **yes** |
| `const n: J = if …` | runs, `5` | **yes** |
| an arm `null`, `const b: J \| null = n`, print `b?.f ?? 70` | same invalid wasm | no |
| delivered as `const b: J = n ?? { f: 6 }` with an arm `null` | same invalid wasm | no |
| `b.f = null` written after the delivery | loud check reject (a widened field written through a shared record) | — |
