#### Mechanism

`voidValueErr` (check_relate_core.vl) names an un-annotated callee whose block body discards its
last call and records where `--fix` writes the `return`. A value slot, `==` and the binary
arithmetic refusal already raised through it; the ordering comparison (`checkBinCmpTail`), unary
`-`/`~` (`unTyOfArg`) and `!` (`checkUnaryNode`) raised a bare `tErr`.

`vl check --fix` over that file inserting both `return`s.
