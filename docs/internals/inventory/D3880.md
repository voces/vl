### D3880 — a call through a module-scope alias of a hole lambda, beside a local `const` that rebinds the lambda's name, is refused

**loud emit reject · the local-binding neighbour of D3861 · filed 2026-10-08 against master `a1c9be3c4` with D3861's fix**

Repro:

    const c = (y) => y + "C"
    const d = c
    function k(s: string) {
      const c = 1
      d(s)
    }
    print(k("z"))
    // vl check: rc 0 (unused-variable warning).  vl build: emitProgram: a function-value call
    // has no interned signature — parameter 1 of type `` has no representation in the
    // function-value ABI

Want:

    zC

#### Mechanism

Not located. With the rebinding a parameter, D3861's close pins `c` through the chain and
keeps the call through `d`; with it a local `const`, the call still reaches the emitter with no
signature for the lambda.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the local (`const c = 1`) | runs, `zC` | **yes** |
| the local as a parameter (`function k(c: string, s: string)`) | runs | **yes** |
