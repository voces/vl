### D5260 — union `==` union decodes a literal-union alias arm with no payload kind

**open · loud emit reject · `vl check` rc 0, clause 2 · found by lane L6 while probing `emitUnionUnionEq`'s member lists · filed 2026-10-17 against master `3f6a785db`**

Repro:

    type K = "x" | "y"
    const a: K | i32 = "x"
    const b: K | i32 = "x"
    const c: K | i32 = 3
    print(a == b)
    print(a == c)
    // vl check: rc 0.  vl run: emitProgram: union `==` atom has no value box

Want:

    true
    false

#### Mechanism

`emitUnionUnionEq` intersects the two operands' member atoms and compares each shared arm's
payload by the arm's value-atom kind. The arm `K` names a literal-union alias, which rides
the box as its member string (D3347), but its kind is `valueAtomKind("K")`, -1. So
`emitUnionPayloadUnbox` finds no value box for it and refuses.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the alias (`"x" \| "y" \| i32` spelled inline) | runs | **yes** |
| the scalar arm (`K \| null`) | runs | **yes** |
| `i32` replaced by `f64` | still refuses | no |
| a declared `type KI = K \| i32` instead of the inline union | still refuses | no |
| the right operand made a literal (`a == "x"`) | runs | **yes** |
