### D9410 — a list literal of un-annotated functions returned from an un-annotated function and called inside a `.map` callback takes no pin

**loud emit reject · `vl check` rc 0 · `cannot take the generic function … as a value` · clause 2 · found closing [D9340](D9340.md) · present on master `efdcd15d0` · filed 2026-10-21 against master `efdcd15d0`**

Repro:

    function inc(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function deliver() {
      return [inc, dbl]
    }
    const v = deliver()
    print(v.map((f) => f(3))[1])
    // vl check rc 0.  vl run: emit error: emitProgram: cannot take the generic function `inc` as a value

Want:

    6

#### Mechanism

Not traced. The same list called by index (`v[1](3)`) runs, so the call inside the `.map`
callback is what fails to pin the literal across the return.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `.map` callback (`print(v[1](3))`) | runs, `6` | **yes** |
| un-annotated `v` (annotated `((a: i32) => i32)[]` instead) | same refusal | no |

#### Grading list

Matrix `hole-fn-list-called-in-callback`, `return_inferred` in both faces.
