### D2039 — a payload `match` over a local declared in the same value-`if` arm is refused by the emitter

**loud emit reject · clause 2 · pre-existing on master · found by D1991's grid (the nested-arm cells) · filed 2026-09-22 against master `ee4c28b60`**

Repro:

    type Ci = { r: i32 }
    type Sq = { s: i32 }
    type Sh = Ci | Sq
    function f(u: Sh, b: boolean) {
      const res = if b {
        const m = u
        match m {
          Ci{r} => "c\{r}"
          Sq{s} => "s\{s}"
        }
      } else {
        "no"
      }
      print(res)
    }
    f({ s: 4 }, true)
    // vl check: rc 0.  vl run: emit error, `emitProgram: field access receiver is not a struct`

#### Mechanism

Not yet located. The arm prelude's `const m` is a local of the value-`if` arm, and the payload
reads `m.r` / `m.s` sit in the arms of the chain the inner `match` desugared to; the emitter does
not see `m` narrowed to the variant at those reads. D1991 reaches this shape whenever it binds a
computed scrutinee inside an enclosing match arm and the inner match binds payload fields.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the arm's own binding (`match u` directly, prelude kept) | prints `s4` | **yes** |
| the payload clauses (`Ci => "c"`, `Sq => "s"`) | prints `s` | **yes** |
