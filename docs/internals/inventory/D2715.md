### D2715 — a function value returning a union of two same-struct maps, delivered as one returning one of them, traps at the call

**loads then traps · clause 1 · found in the #3198 review · identical on master `fdd0050af` ·
filed 2026-09-26 by the NR lane**

Repro:

    type A = {[string]: string}
    type B = {[string]: string | null}
    function uA(): A | B {
      const a: A = Map()
      a["k"] = "x"
      a
    }
    const f: () => B = (): A | B => uA()
    print(f().length)
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch

#### Mechanism

Not yet measured. The checker accepts `() => A | B` as `() => B` because the result is
assignable, but the lambda's signature returns the union box and the call site's `$fnsig`
returns the bare map, so `call_ref`'s signature check fails at run time. A converting wrapper
(the void-twin shape) or a refusal of a result whose rep differs is the choice.
