#### Mechanism

`modExportsHas(m, name)` walked all of `expMod`/`expName`, then all of `reExpMod`/`reExpPublic`,
comparing strings. `modVisit` asks it for every import of every module, and `modBankUfcsScope` asks it
for every rename row whose target is a `self`-function, so a graph with E export rows and I imports
paid E string compares per import. Every root of a `vl check <dir>` rebuilds the graph, so the cost
repeats per root. `modNoteUfcsImportCand` ran the same scan over `expName` once per `self`-function.
The index maps a name to the modules exporting it, kept separately for declared and re-exported
names so the declared-only reader keeps its own answer.
