### D3020 — a declaration shadowing a narrowed name hides a call's write to the narrowed binding, and the read after the block traps

**closed · now a loud check reject, as its unshadowed twin is: `'g' is no longer narrowed to G: the call to 'k' on line 6 may reassign it` · a call that may write a narrowed binding hidden by an inner declaration retires the binding's narrowing layers under the shadow, and banks the emitter's retirement after the statement holding the shadowing block · fixtures `tests/cases/soundness/call-ends-shadowed-narrowing.vl` (runs) and `tests/cases/soundness/call-ends-shadowed-narrowing-refused.vl` · was loads then traps · found grading [D3019](D3019.md) · filed 2026-09-28, closed 2026-09-28 against master `cac5e4ad5`**

Repro:

    type G = { name: string }
    function mk(): G | null { { name: "a" } }
    let g: G | null = mk()
    function k() { g = null }
    if g != null {
      if true { const g = 5; k(); print(g) }
      print(g.name)
    }
    // vl check: rc 0.  vl run: prints 5, then wasm trap: null reference (before the close)

#### Mechanism

At `k()` the outer `g` is live-narrowed and `k` writes it, so D2390 would retire the narrowing.
But the retirement works on the name's innermost binding: `crRetire` walks `crChainWidest`, which
stops at the first scope layer that is not a narrowing, and here that layer is the inner
`const g`. Nothing is retired, nothing is banked for the emitter, and when the inner block ends
the outer `g` reads as `G` again. The close (`crRetireShadowed`) asks the call about each
narrowed binding under a shadow with the shadowing layers hidden, retires its layers in the
checker at once, and banks the emitter's by-name retirement after the statement holding the
shadowing block, where the name resolves to the outer binding again. Its arm-join row names
that binding's scope depth (`narClobBind`), so a join closing inside the shadow, where the name
reaches the shadowing binding, does not take the row as that binding's.
