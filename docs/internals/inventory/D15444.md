    function mul(a, b) { return a * b }

#### Mechanism

`apply2`'s call `g(1, 2)` goes through `{add}` in one instance and `{mul}` in another. The
partial pass asks whether every instance of `apply2` binds the call's set, and marks partial the
one set `elabMintSets[c]` holds, which is the last instance's. The other set stays taggable, so
whichever function the first alias call hands is the one tagged. Here that is `{mul}`, which
`viaFor` never hands, and the program runs; with `k(add)` first `{add}` is tagged and
`viaFor(add)` hands its id into the `{apply2}` closure (D15443). A decision that is a function of
the program's facts marks every set a call goes through in some instance, or none.
