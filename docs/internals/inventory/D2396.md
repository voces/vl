#### Mechanism

`criClassify` decides an un-annotated function's result kind from its return expression, and
a returned LOCAL's collected kind does not exist yet during that global pass. A returned
element `c[0]` whose element is a ref list (`(i32 | f64)[]`) reached no classifier that could
answer, so the result defaulted to i32 while the body produced the list. A new rung asks the
recorded arena type: an array type whose element names a ref-list row is that ref list.
