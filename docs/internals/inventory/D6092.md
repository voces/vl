### D6092 — a `const` alias of a hole function handed to two hole parameters at two types has no monomorphized argument type

**loud emit reject · `vl check` rc 0 · clause 2 · found closing [D5611](D5611.md) · the same on master `933755731` · filed 2026-10-17 against master `933755731`**

Repro:

    function same(k) { k }
    function take(a) {
      print(a("x"))
    }
    function take2(a) {
      print(a(3))
    }
    const h = same
    take(h)
    take2(h)
    // vl check: rc 0.  vl run: emitProgram: monomorphize: unsupported argument type for `a` in a call to `take`

Want:

    x
    3

#### Mechanism

From the ablation only. A `const` alias of a hole function carries one pin, so handing it to
two holes that call it at two types leaves one of them without an argument type. The
explicit generic `function same<T>(k: T): T` takes the alias's per-call path and runs. The
message names no source position.
