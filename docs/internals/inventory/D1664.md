### D1664 — an INFERRED container over an un-annotated parameter has no closure element or field kind, so reading the value back is not a callable

**closed 2026-09-06 — the monomorphizer annotates the binding per instance, the way it
already annotates an inferred return list · filed against master `213504611` · closed against
`40334c8cf` · residue D1749 · 0 corpus cells**

Repro:

    function take(a) {
      const xs = [a]
      print(xs[0](54))
    }
    take((n: i32) => n + 1)
    // vl check: rc 0.  vl run: rc 0, prints 55

#### Mechanism

D1626's second floor. A closure delivered as an un-annotated parameter arrives with a
`PIN_SIGKEY` payload the monomorphizer wrote on the parameter; the ref-list element kind and
the inferred struct-field kind are classified from the INITIALIZER, and the checker leaves the
parameter's node the inference hole. Probed at `exprRefArray`, the two faces differ exactly
there and agree about the pin:

    un-annotated  arrTy=TyArray<TyVar>  cen=[]              e0ty=TyVar   sig=[i>i]  isRef=0
    annotated     arrTy=TyArray<TyFunc> cen=[((i32)=>i32)]  e0ty=TyFunc  sig=[i>i]  isRef=1

**The pin is a fact about the FRAME, and the body is SHARED between instances** — which is
what decides where the fix goes. Threading the pin into the classifiers was tried and got as
far as a reflist CELL over an i32 BACKING: the element's row has to be interned before
`mAssignTypeIndices`, and the collect pass that holds a frame (`collectLocals`) runs inside
the code section, long after. The classifiers that run early enough (`arrLitIsRef`,
`arrLitElemKind`, `arrLitElemName`, `anonFieldCode`) take no frame at all, so no per-instance
answer can reach them.

`monoCloneBody` is the one place that holds both, and it already mints an annotation there:
an inferred return list's `const out = []` becomes `const out: f64[]` per instance. The
closure-pinned container takes the same rung — `[a]` becomes `((i32) => i32)[]`, `{ f: a }`
the matching inline shape — and every downstream classifier then reads the ANNOTATED spelling,
which ran at the filing seed. All four sentences close with one rung, because none of them
was ever about the read.

**A name match reaches a SHADOW, and that was measured, not reasoned about.** A body-local
`const a = 7` inside a function whose parameter is `a` took the pin and made an i32 list a
closure one — `runs` → check-clean invalid wasm on a program that had nothing to do with the
row. The guard is the same fact the mechanism rests on: a read the checker TYPED is not the
hole parameter, so only a `TyVar` node reads the pin.
