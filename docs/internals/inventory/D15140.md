### D15140 — a bundle parameter handed whole to a callee that reads its parameter other than by calling it has no record to take

**closed 2026-11-03 — the repro now RUNS. Was: check-clean invalid wasm on master `dc1bb1f1`, then a loud emit reject (#6039)**

Repro:

    function keep(g) { const q = g; print(q(7)) }
    function lap(f) {
      print(f(2.5))
      print(f(3))
      keep(f)
    }
    function go(k: i32) { lap((a) => a + k) }
    go(1)

Want:

    3.5
    4
    8

#### Mechanism

`lap`'s parameter is called at two signatures, so it holds a record of one closure per
signature. `keep` copies its parameter into a binding, so `monoBundlePin` builds it to take one
closure at a closed type, while the call site still handed the whole record. The forward join
already adds that closed type to the record (`elabBundleOwnSigs`), so the elaboration now notes,
per instance and call argument, which member the hand takes (`elabCallHandMember`). Mono carries
the fact onto the instance's argument, and emit hands that member (`emitBundleMemberArg`).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `keep` copies `g` (it calls `g` directly) | runs | **yes** |
| `lap`'s second signature | runs | **yes** |
| the capture of `k` (a top-level `lap((a) => a + 1)`) | check reject, `a` not inferred | **yes** |
| the hand to `keep` (`lap` copies `f` itself) | runs | **yes** |
