#### Mechanism

Closed: every resolver below now takes the read and `globalLetOfSidIn` has no caller left; the
text that follows is the floor as filed.

`globalLetOfRead(fnIx, readIx)` returns the module global a read denotes from the read's own
declaration, and asks the frame's name rungs (`identBoundAt`) only for a minted read, which has
no declaration. `globalLetOfSidIn` is its sid-keyed form. When `atIx` is a read of `sid` it
defers to `globalLetOfRead`. Otherwise it asks `identBoundAt` with `atIx` as a position only.
Three resolvers keep it because some of their paths hold no read of the name:

- `identLetOfAt`, reached with `atIx = -1` from `identClosureFeSid` and
  `identFnTypeAnnNameSid`.
- `calleeCloSigKeyAt`, which asks at a minted callee's call position (`posAt`) and follows a
  copy chain with `copyAt = -1` when its own read is unplaced.
- `unionNameOfIdentAt`, whose callers all pass the read today but which shares the sid
  signature with the other two.

#### Grading list

The witness: the generic's instances mint the reads of `g` and `n`, and a sibling block shadows
both names with other types, so a global lookup answered by the block's binding builds the
wrong valtype or calls a string.
