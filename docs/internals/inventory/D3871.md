### D3871 — a union of two same-SHAPED records `A | B` resolves un-narrowed method dispatch and a generic's method call to its FIRST member, so a `B` value typed `A | B` answers with `A`'s method

**check-clean silently wrong · found by the rv3461 review of #3454–#3461 (c/c29.vl and neighbours) · related to the open design question D3870 (unfiled: D3870), whose ruling may decide the fix · filed 2026-10-08 against master `862c99b79`**

Repro:

    // file: r1.vl
    export type A = { x: i32 }
    export function d(self: A): string { "RA" }
    // file: r2.vl
    export type B = { x: i32 }
    export function d(self: B): string { "RB" }
    // file: entry.vl
    import { A, d } from "./r1"
    import { B, d } from "./r2"
    function h<T>(x: T): string { x.d() }
    const b: B = { x: 2 }
    function f(v: A | B): string { v.d() + h(v) }
    print(f(b))
    // vl check: rc 0 (hints only).  vl run: rc 0
    // PRINTS RARA

Want:

    RBRB

#### Mechanism

`A` and `B` have the same field set, so the union `A | B` is one runtime shape, and the checker
resolves `v.d()` through the union's first member: `v: A | B` dispatches to `A`'s `d` whatever the
value is. The generic `h(v)` instantiates at `T = A | B` and its `x.d()` resolves the same way. The
union with the members swapped (`B | A`) answers `RB` for the same `b`, so the answer follows member
ORDER and not the value's type. An `A` value typed `A | B` answers `RA`, which is right, so only
the second member is lost. With record members of DIFFERENT shapes the checker refuses instead
(`.d(…) cannot choose between d from "./q1" (A first) and d from "./q2" (B first): the receiver's
type A | B does not determine one`), so the silent path is exactly the one where the members are
indistinguishable at runtime. What the right answer is turns on D3870: runtime `is` between
same-shape records tests only the shape, so `v is B` cannot tell the two members apart either, and
a ruling there may decide whether this is refused at the call, dispatched on a tag, or the two
records are made distinct. The `Want:` above is the answer if the call is accepted at all.

#### Grading list

The narrowed spelling prints `RB` today, but `is` between same-shape records tests only the shape
(D3870), so a `v is A` guard on the same `b` is the control to run with it: the close has to say
what `is` answers there before it can say what the call answers. Programs that run correctly today
and must keep running: `h(b)` and `b.d()` on a plainly `B`-typed value, the `B | A` ordering, and
the different-shape union, which stays a loud check reject. Grade it at the annotated `f(v: A | B)`
above and at a parameter whose union type is inferred.
