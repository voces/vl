#### Mechanism

Not located. The closure's tail `if` has a value in both arms, the assignment's function value,
and the lifted lambda's result is built from it in a generic frame whose cell type names `T`; a
statement after the `if`, or a `void` annotation on the closure, makes the lambda's result
`void` and the program runs. Same outcome on the step-2 seed, so not a regression of step 3.
