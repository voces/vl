### D10170 — a record-valued map's miss read into a wider nullable union is not `null`

**closed · runs, prints `true` · was check-clean silently wrong, prints `false`, clause 1 · present on master `6bb8a329f` and `9ca7e7751` · found closing [D10140](D10140.md), whose map-union read had to bind the member's own `P | null` first · filed 2026-10-22 against master `6bb8a329f` · closed in `emitUnionArmValueBox` (wasmEmit.vl): a record-valued map read names its record arm through `exprVariantIndex`, so the miss was boxed under the record's tag holding null; a read that can still be null and is classified a nullable variant now takes the branch that tests for null before tagging, at `.get`, `[k]`, a string key, a second record arm and the generic face · fixture `maps/record-map-miss-into-wider-union.vl`, new matrices `map-get-record-miss-into-wider-union` (30 → 66 of 66), `map-index-record-miss-into-wider-union` (30 → 66), `map-get-record-miss-into-variant-union` (30 → 66), the open twin `map-get-record-miss-into-wider-union-open` (25 → 66), and the neighbour guard `nullable-record-sources-into-wider-union` (a nullable field and a nullable list element, 66 → 66, never affected)**

Repro:

    type P = { x: i32 }
    const c: {[i32]: P} = Map()
    const a: i32 | P | null = c.get(2)
    print(a is null)
    // prints false before the fix

Want:

    true

#### Mechanism

`emitUnionBoxArgGo` asks `emitUnionArmValueBox` before the coercion that holds the null niche.
A map read of a record value answers `exprVariantIndex` with the record's arm, so the box took
that arm's tag around whatever the read produced, null included: `is null` read the tag and
said `false`, and `is P` then cast the null and trapped. Through an intermediate `P | null`
binding the source is a local, not a map read, and goes to the niche branch instead. A nullable
field, a nullable list element, a `P | null` local and a function returning `P | null` never
reached the arm branch. A map of an inline record value took another path and printed `true`.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const a: P \| null = c.get(2)` | prints `true` | **yes**, the wider union |

| `string \| P \| null` | prints `false` | no |
| `const e: P \| null = c.get(2)` then `const f: i32 \| P \| null = e` | prints `true` | **yes**, the direct delivery |
