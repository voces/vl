### D10170 — a record-valued map's miss read into a wider nullable union is not `null`

**check-clean silently wrong · prints `false`, want `true` · clause 1 · present on master `6bb8a329f` · found closing [D10140](D10140.md), whose map-union read had to bind the member's own `P | null` first · filed 2026-10-22 against master `6bb8a329f`**

Repro:

    type P = { x: i32 }
    const c: {[i32]: P} = Map()
    const a: i32 | P | null = c.get(2)
    print(a is null)
    // prints false

Want:

    true

#### Mechanism

Not traced. The miss of a record-valued map delivered straight into a union that also holds a
scalar does not land as the union's null; through an intermediate `P | null` binding it does.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const a: P \| null = c.get(2)` | prints `true` | **yes**, the wider union |
| `c[2]` in place of `c.get(2)` | prints `false` | no |
| `string \| P \| null` | prints `false` | no |
| `const e: P \| null = c.get(2)` then `const f: i32 \| P \| null = e` | prints `true` | **yes**, the direct delivery |
