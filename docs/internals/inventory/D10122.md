### D10122 — a module-scope index write of a fixed-type function into a list of a generic is never judged at a call through it

**closed · now a loud check reject, `cannot write 'inc' to an element of 'ys': a call through it at (string) runs it, and it is (i32) => i32` · was trap after load, `vl check` rc 0, `wasm trap: indirect call type mismatch`, clause 1 · found closing [D10080](D10080.md) · present on master `3931f9468` · filed 2026-10-22 against master `3931f9468` · closed with [D10120](D10120.md): a call through the element judges the index-written value (`holeSlotFixedJudge`, check_relate_core.vl), and an index write outside every generic keeps a row only a delivery of the binding judges (`noteElemLetCstr`, `CSTR_DELIVERY_ONLY`, check_cstr_rows.vl), so an unrelated call of the generic does not judge it · fixtures `closures/error-generic-list-index-written-at-module-scope.vl` and `closures/error-generic-list-index-written-returned-into-inferred-binding.vl` · new matrices fn-value-generic-list-index-written-at-string-refused 2 trap and 7 emit refuses → check refuses, fn-value-generic-list-index-written-at-i32 44 → 44 runs, fn-value-generic-list-index-written-open 46 → 46 runs**

Repro:

    function id<T>(x: T): T { x }
    function inc(x: i32): i32 { x + 1 }
    const ys = [id]
    ys.push(id)
    ys[1] = inc
    print(ys[1]("s"))
    // vl check rc 0.  vl run: wasm trap: indirect call type mismatch

The owed outcome is a check refusal, which the same lines inside a function body give:
`cannot assign (i32) => i32 to (string) => string (the callee's body at the call's argument types)`.

#### Mechanism

Not traced. The index write `ys[1] = inc` is a deferred `letCstr` row inside a function
body, re-validated at the call `ys[1]("s")`; at module scope no row reaches that call, so
the write is never judged against `string`. [D10080](D10080.md)'s close reads the same rows
and does not refuse the delivered spelling either (`function run(a: ((string) => string)[])`
with `run(ys)` traps the same).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the lines wrapped in `function main() { … }` and `main()` | check refuses, `cannot assign` | **yes** |
| `ys.push(id)`, writing `ys[0] = inc` and calling `ys[0]("s")` | loud emit reject, `a generic function taken as a value reaches no call` | no |
| `ys[1]("s")` replaced by `ys[1](2)` | runs, `3` | **yes** |

#### Grading list

- `run(ys)` with `function run(a: ((string) => string)[]) { print(a[1]("s")) }` after the write: traps today.
