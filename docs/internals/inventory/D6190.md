### D6190 — a generic called on its own result through a hole parameter, where the two calls need two instances, is refused at emit and not at check

**loud emit reject · `vl check` rc 0 · clause 2 · found closing [D6111](D6111.md) · filed 2026-10-17 against master `c6cd62ec1`**

Repro:

    function tos(a) { return "v" + a }
    let lap = (g, x) => x + 1
    lap = (g, x) => g(g(x))
    print(lap(tos, 4))
    // vl check: rc 0.  vl run: emitProgram: monomorphize: unsupported argument type for `g` in a call to `__lambda_0`

Want:

    vv4

Or, failing that, the check reject the direct spelling gets.

#### Mechanism

From the ablation only. The inner call makes `tos` an `i32` instance and the outer call hands
it that instance's `string` result, so the two calls disagree and no single instance exists.
The direct spelling `print(tos(tos(4)))` is a loud check reject, so the hole spelling owes the
checker's refusal at least.

#### Ablation

| spelling | outcome | needed? |
| --- | --- | --- |
| the witness | loud emit reject | — |
| `const lap = (g, x) => g(g(x))` | loud emit reject, same message | no |
| `function lap(g, x) { return g(g(x)) }` | loud emit reject, same message | no |
| `print(tos(tos(4)))` | loud check reject | **yes** |
| `neg` (`0 - a`) for `tos` | runs, `4` ([D6111](D6111.md)) | **yes** |
