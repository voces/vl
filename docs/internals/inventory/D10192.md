#### Mechanism

The close of [D10021](D10021.md) runs the binding's choosing call once, as the index of the
generic it returns, and gives each call type a slot that selects by that index. A write takes
a slot write per type only from a name, a lambda or a peer binding (`fsValuePeer`,
fn_split.vl), and a second choosing call is none of these, so the whole let plan declines.
Left open by the lane that closed [D10202](D10202.md) and [D10204](D10204.md): the split
plan (`fsPlanMember`), which the checker changes there do not reach.
