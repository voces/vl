#### Mechanism

The instance re-check types `fs[0](1.5)` with a callee typed at the tagged list's rep, an i32
id, so the call reads `<error>`; `fnTagInstanceArms` found no set for the callee (its type is the
rep, not the set) and returned no arms to type it from. The dispatch then emitted the member
calls into an i32 result, and `print` chose `__print_i32__`, against `half`'s `f64`.
