### D2621 — a declared `__…__` intrinsic named as a value (not called) is check-clean and has no emit lowering

**loud emit reject · filed 2026-09-26 against master `06930fb68` (found reviewing PL-043)**

Repro:

    const f = __load_i32__
    print(f(0))
    // vl check: rc 0.  vl run: emitProgram: identifier is not a parameter, local, or global

#### Mechanism

The dunder intrinsics are `declare`d into the checker's global scope with a function type
(`__load_i32__`, every `simdTableBuild` row, every atomic, the saturating truncations), so an
identifier naming one outside callee position types as an ordinary function value. The
emitter lowers them only as a callee (`emitCall`'s by-name arms); as a value there is no
function index, closure or wrapper to read, so a binding reports `identifier is not a
parameter, local, or global` and a `.map` callback `.map/.filter callback signature is not
interned`. The bare numeric intrinsics (`sqrt`) are not declared and refuse at check instead.

#### Ablation

| spelling | outcome |
| --- | --- |
| `const f = __load_i32__` | check rc 0, emit refuses (as filed) |
| `const f = __add_f32x4__` (SIMD row) | check rc 0, same emit refusal |
| `const f = __atomic_load_i32__` (atomic row) | check rc 0, same emit refusal |
| `[1.5].map(__trunc_sat_f64_s_i32__)` | check rc 0, `callback signature is not interned` |
| wrapped: `const f = (a: i32) => __load_i32__(a)` | runs, prints 0 |
| `const f = sqrt` (bare numeric intrinsic) | check refuses: undeclared identifier |

The ingredient is a declared intrinsic in a non-callee position; the family is every
declared dunder, not one table. Wrapping it in a lambda always runs, so the capability
exists and only the value position lacks a lowering (clause 2). Open question for a ruling:
synthesise a wrapper function per intrinsic used as a value, or refuse the value position
at check as `sqrt` already is. Recommendation: synthesise the wrapper, since a lambda of the
same signature already compiles.

#### Grading list

- `const f = __add_f32x4__` then `f(a, b)`, and the atomic and trunc_sat spellings above.
- `[1.5].map(__trunc_sat_f64_s_i32__)` must print `1`.
- A value reference inside a function body and in a struct field of function type.
