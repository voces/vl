    type XYN = "x" | "y" | "z" | null

#### Mechanism

The close: with the new `monoArgTyName` arm switched off, the filed repro prints `0` again.
Before it, not localised past the ablation. D2978's close reads the pin of a `K | null` spelling, a nullable
wrapper over a literal-union alias. A union that is itself nullable (a whole alias, or the inline
`"a" | "b" | null`) is not monomorphized at its spelling: the generic is emitted once over the
`i32` rep, so `print` takes the `i32` import. A `null` value prints `-1`. Where the argument is
widened to a string pin instead, the call refuses (`literal-union string widening with no
members`), which is the loud half.
