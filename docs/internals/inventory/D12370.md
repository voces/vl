### D12370 — an exported generic written into a record a function returns, which no call reads, still passes the checker and refuses at emit

**now a loud check reject · was a loud emit reject (`emitProgram: exported function `id` is generic over `T` and nothing in the program calls it`) after `vl check` rc 0 · clause 2 · DESIGN: the same write into a record literal bound directly is refused at check ([D12302](D12302.md), [D12332](D12332.md)) · closed 2026-10-24 by lane L3 (d): value reach follows a binding initialised by a call to a declared, non-generic function into each list, record or name the function returns, and declines anything else it returns · moved: `function mk() { [id] }; const r = mk(); r[0] = id; print(1)` ran and is now refused, as its direct spelling `const r = [id]; r[0] = id` already was · pins: `tests/cases/functions/error-exported-generic-written-into-returned-record-uncalled.vl`, `error-exported-generic-written-through-returned-holder-uncalled.vl`, `exported-generic-written-into-returned-record-called.vl` · found closing D12332 · filed 2026-10-24 against master `845bd1bdf`**

Repro:

    export function id<T>(x: T): T { x }
    function mk() { { f: id } }
    const r = mk()
    r.f = id
    print(1)

#### Mechanism

Value reach follows a written place to the bindings whose literal it may land in, and a binding
initialised by a call has no literal it can see: the record `mk` returns is built in `mk`'s body.
The write is kept as one that may reach a call, and the monomorphizer's floor refuses the export.
The close is following a call's result to the literal its callee returns, or treating a write
into a call's result as reaching only the reads of that binding.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the function (`const r = { f: id }`) | check reject, D12302 | **yes** |
| the write (`r.f = id`) | check reject, D3817 through `mk`'s body | **yes** |
| a call reading the record (`print(r.f(3))`) | runs, prints `3` | **yes** |

#### Grading list

The same with `mk` returning `[id]` and `r[0] = id` (refused since the close); `mk` returning a
binding (`function mk() { inner }`), a record holding one, or its parameter, each with a call
that reads the record, which run.
