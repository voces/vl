### D4551 — a local typed by a type parameter no call binds, passed to a generic, is invalid wasm

**check-clean invalid wasm · 4 hand probes · filed 2026-10-13 against master `eb2603843`**

Repro:

    function inner<V>(v: V) {
      return 1
    }
    function opT<T, U>(a: T[]) {
      const q: U[] = []
      return inner(q) + a.length
    }
    const a = [1]
    print(opT(a))
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `opT`

#### Mechanism

No parameter of `opT` names `U`, so an inferred call to `opT` leaves `U` unbound in the
instance. `q: U[]` is then a list over a hole, and the call `inner(q)` pins `inner` at an
element rep the caller's local does not carry. The checker's uninferable-type-parameter rule
(`checkRetTyParamBound`) refuses `U` only when the callee's return or a body function's
parameter names it; a body LOCAL naming it is admitted, and runs while it stays local.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the type parameter `T` (`opT<U>()`) | still invalid wasm | no |
| the call `inner(q)` (`q` stays local) | runs | **yes** |
| the inferred call (`opT<i32, i32>(a)`) | runs, prints 2 | **yes** |

#### Grading list

`opT<i32, i32>(a)` must keep running. Decide first whether an inferred call binds an unnamed
type parameter at all (refuse in the checker, as `checkRetTyParamBound` does for a return or a body function's parameter) or defaults it.

Re-graded 2026-10-14 against master `56e06d91c`: still as filed. D4552 closed by refusing a
body function's RETURN that names an unbound type parameter; the same refusal over a body
LOCAL was tried and withdrawn, because `tests/cases/generics/error-inferred-return-type-param-no-parameter-binds.vl`
(D1819) accepts `countOf<T>()`, whose local `xs: T[]` is read only through `.length`, and
that program runs. A local `U` fails in more than the filed spelling: `let q: U | null = null`
alone, a closure capturing `q`, `[q]`, `inner<U[]>(q)` and a list-typed `inner`. So the close
needs the decision above: refuse every body-local `U` and re-rule D1819's accept set, or bind
an unbound `U` to a default at the call (it has no values in the body, so any rep is sound).
