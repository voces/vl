#### Mechanism

`emitArrSpread` builds each run of plain elements as a synthesized literal (`spreadRunLit`),
which has no recorded type, so `emitArr`'s string arm never sees `nodeArrayElemIsNulStr` and
does not seed `pendingNulString` for the `null`. Seeding it from the spread literal's own type
was tried and turned the refusal into invalid wasm (the run then built at the `i32` list), so
the run has to be built at the string list's rep and the niche together.
