### D4643 — a map read's `??` default that is ANOTHER arm of the destination union is built as the map's value type

**loud emit reject · clause 2 · found closing [D4638](D4638.md), and present before it · filed 2026-10-14 against master `536c4c79e`**

Repro:

    type R = { q: i32 }
    type U = R | { r: i32 }
    const m: Map<string, R> = Map()
    m["k"] = { q: 4 }
    const u: U = m["k"] ?? { r: 1 }
    print(u is R)
    // vl check: rc 0.  vl run: emitProgram: object literal is missing a union-variant field

Want:

    true

#### Mechanism

Not localised past the ablation. The checker types `m["k"] ?? { r: 1 }` as the join of the
map's value type `R` and the default's `{ r: i32 }`, which is `U`. The emitter builds the
fused map read's default against the map's own value slot, so the `{ r: 1 }` literal is
asked for `R`'s fields and refuses. A nullable local in place of the map read runs.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the default is the map's own arm (`?? { q: 1 }`) | runs, `true` | **yes** |
| the read is hoisted (`const w = m["k"]`, then `w ?? { r: 1 }`) | runs, `true` | **yes** |
| a `R \| null` local in place of the map read | runs, `true` | **yes** |
| the arm is anonymous (`Map<string, { q: i32 }>`, `U = { q: i32 } \| { r: i32 }`) | still refuses | no |
| delivered as an annotated function's tail (`function f(): U { … }`) | still refuses | no |

#### Grading list

The anonymous-arm spelling and the return-position spelling from the ablation.
