### D4643 — a map read's `??` default that is ANOTHER arm of the destination union is built as the map's value type

**closed 2026-10-14 — the witness prints `true` · a `??` over a map read whose result is a union box the map's value type is not (`coalesceMapReadJoins`) no longer takes the fused read-with-default: a ref value joins through the nullable-niche arm, a scalar value boxes its hit and builds the default as the union (`emitMapGetOrScalarJoin`), and the classifier stops reporting the map value slot's rep for it · fixture `tests/cases/unions/map-read-coalesce-other-arm.vl` · templates `coalesce-map-read-other-arm-record.matrix.vl` loud → runs and `coalesce-map-read-other-arm-scalar.matrix.vl` silent → runs (both faces) · was loud emit reject for a record value, and check-clean invalid wasm for a scalar, string or list value or a variable default · clause 2 · found closing [D4638](D4638.md), and present before it · filed 2026-10-14 against master `536c4c79e`**

Repro:

    type R = { q: i32 }
    type U = R | { r: i32 }
    const m: Map<string, R> = Map()
    m["k"] = { q: 4 }
    const u: U = m["k"] ?? { r: 1 }
    print(u is R)
    // vl check: rc 0.  vl run: emitProgram: object literal is missing a union-variant field

Want:

    true

#### Mechanism

`emitCoalesceGo` took the fused map read-with-default (`emitMapGetOr`) for every `m[k] ?? d`
and `m.get(k) ?? d`, which builds `d` at the map's value type, and `coalesceMvSlot` classified
the `??` as the map value slot's rep. When the checker types the `??` as a union box the value
type is not, the default is another arm: a record literal refuses, and a scalar map read with a
string default (or a named-record variable default) is check-clean invalid wasm.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the default is the map's own arm (`?? { q: 1 }`) | runs, `true` | **yes** |
| the read is hoisted (`const w = m["k"]`, then `w ?? { r: 1 }`) | runs, `true` | **yes** |
| a `R \| null` local in place of the map read | runs, `true` | **yes** |
| the arm is anonymous (`Map<string, { q: i32 }>`, `U = { q: i32 } \| { r: i32 }`) | still refuses | no |
| delivered as an annotated function's tail (`function f(): U { … }`) | still refuses | no |
| the default is a named `S` variable rather than a literal | invalid wasm | no |
| an `i32`-valued map with a `"x"` default into `i32 \| string` | invalid wasm | no |

#### Grading list

The anonymous-arm and return-position spellings; the `.get` form; a miss key; an inferred
destination; a scalar, string, `f64`, `i64`, `boolean` and list value with another-arm default;
a key with a side effect (read once). [D3201](D3201.md), a `boolean`-valued map with an `i32`
default, is the same mechanism and closed with it. An atom-valued map with a non-atom default is refused by
the checker instead and is [D4750](D4750.md).
