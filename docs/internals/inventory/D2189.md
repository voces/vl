#### Mechanism

D2182 was closed on the native host by giving the compiler's wasm engine a 512 MiB stack. The
editor runs the same seed under V8, whose stack an embedder cannot raise per module, and the
compiler still recurses once per nesting level in about fifty walkers (parser, checker, collect,
classify, rewrite, emit, `capScan`). A cold instance (Liftoff code, larger frames) holds fewer
levels than a warm one:

| shape | cold V8, `66e74235a` | cold V8, D2182's close | warm V8 |
| --- | ---: | ---: | ---: |
| nested bare blocks | 931 | 912 | 1,712 |
| nested labelled `while` loops | 818 | 818 | 1,587 |
| nested `if`s | 818 | 818 | 1,587 |
| the three mixed | 943 | 987 | 1,712 |

The fix is D1990's, generalised: every walker that recurses into a nested block keeps an
explicit stack instead. A nested block has no spine to loop along, so each walker needs a
work list rather than D1990's `elseIfLink` loop.
