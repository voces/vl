### D1625 — a closure array from an un-annotated inferred return, bound at MODULE scope, mis-reps its element

**closed · filed 2026-09-05 against master `8a7b2872` · closed against `243df088`**

`globalKind`'s ref-array rung grew an arena twin. The matrix `@@SKIP@@` is deleted and
`container-read-callee` grades 54 of 54 with 0 skipped and 0 silent.

Repro:

    function deliver() {
      return [(n: i32) => n + 1]
    }
    const v = deliver()
    const g = (m: i32) => v[0](m)
    print(g(54))
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `g`

#### Mechanism

The same program written INSIDE a function runs, and that is the whole ablation: wrap the
last three lines in `function go() { … }` and it prints 55. So the ingredient is the binding
being a module GLOBAL rather than a frame local, over an element whose rep came from an
UN-ANNOTATED inferred return.

What it is NOT: neither the resolved `$fnsig` key nor the ref-list element slot differs from
the working spellings. Probing both at the tail-value decision reads `key=[i>i] rlSlot=0` for
this cell, for the annotated-return control that runs, and for the plain-local witness that
runs — all three identical. So the disagreement is downstream of the call's own resolution.

MEASURED at the global cell, which is where it is. Instrumenting `globalCellKindGo`'s
un-annotated fall-through:

    D1625RUNG name=v globalKind=i32     letIsRefArray=F   (the witness)
    D1625RUNG name=v globalKind=reflist letIsRefArray=T   (the annotated-return control)

`globalKind`'s ref-array rung is `exprRefArray`, a syntactic predicate that resolves the
element only from a return ANNOTATION; without one the ladder falls to its `i32` guess and
the element read then wants `(ref null $type)`. The arena records the array type either way,
so the rung is one structural read (`nodeTyIsFuncArray`) beside the syntactic one — the same
shape D1620 and D1621 took at their own ladders.

The companion slot needed nothing: `globalRefListSlot` already resolves, and the proof is a
module carrying THREE distinct closure-array wrappers, each global printing its own element's
value rather than the first wrapper's.

**This row recorded a price D1623 paid.** Before D1623 the spelling was a loud
`emitProgram: bare call statement is not supported`; D1623 routed the tail through
`emitReturnExit` and made the mis-rep reachable. That price is repaid here rather than carried.

The element rep is the tight half — struct, string, i32 and f64 arrays all ran, because
`exprRefArray` and the scalar-list arms already claim them. The multi-wrapper rows are what
prove the companion slot: with a `0` fallback each would print another block's element.
