### D3666 — a local function declared in a module-scope block is never lambda-lifted

#### Mechanism

`cloLiftDecide` declines a slot whose `fnParent` is -1: the declaring frame is the module's
start function, whose statements are `startStmts` rather than a `FuncDecl` body, so the use
walk and the binding search have nothing to walk, and `cloLiftLetFe` keys the skipped binding
by a frame position the start function does not have. Lifting it needs both to accept the
start function as a frame: walk `startStmts` (with top-level `let`s being globals, not
captures) and record the binding under a start-frame key.
