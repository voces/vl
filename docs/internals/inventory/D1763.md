### D1763 — a `??` whose LHS is a CALL was gated out of the `string | null` arm, so it fell past every niche to a lowering with the wrong heap

**closed 2026-09-06 · was check-clean invalid wasm, filed against master `e9c5665c6` ·
0 corpus cells**

Repro:

    type A = { r: i32 }
    function mkS(): string | null { return null }
    function mkD(): A { return { r: 7 } }
    const w = mkS() ?? mkD()
    if w is A { print(w.r) } else { print(0) }
    // prints 7

#### Mechanism

The nullable-ref-niche `??` core evaluates its operand ONCE — `br_on_non_null` consumes it,
and the join arm tees it into the stash `stashHitAt`'s `optrecv` case already reserves — so a
CALL operand needs no re-read. The `string | null` arm was nonetheless gated on `lhsReEval`, a
leftover from the re-read shape that arm replaced. Gated, a call fell past every niche arm to
the value-union-box arm and then to the floor, with a heap the box does not have.

A 60-cell grid over six nullable-ref LHS niches x five default kinds x fused/bound, graded
2026-09-06, shows the axis is exactly four cells wide and names them:

| cell | bound | fused |
| --- | --- | --- |
| `nulstr` x scalar default | runs | **check-clean invalid wasm** |
| `nulstr` x struct default | runs | **check-clean invalid wasm** |
| `nulstr` x nullable-variant default | runs | **check-clean invalid wasm** |
| `nulvariant` x struct default | runs | loud emit reject (D1764) |

Every other pair — `nulcoll`, `nulrefarr`, `nulstruct`, `nulmap` at all five defaults — already
agreed between the two spellings, which is what says the gate and not the core is the defect.
The gate excluded an IF-EXPRESSION operand by the same flag, so removing it also closes D1302,
which had predicted the gate was stale and asked for exactly this measurement.
(`nulcoll` and `nulrefarr` with a nullable-variant default are invalid wasm at BOTH spellings:
a different family, off this axis.)
