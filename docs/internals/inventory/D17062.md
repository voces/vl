### D17062 — a lambda literal returned at a generic's `() => U | string` result is checked at its first instance's type in every later instance

**closed 2026-11-23 · runs, prints `false` `false` · was loud check reject, clause 2 · fixed in check_fn_decl.vl: a call's re-check of the generic's return (`litPinAssignable`) queued the lambda with the first instance's result, and `lamRetApply` wrote it as the annotation of the node every instance shares. `lamRetQueue` no longer queues under one instance's bindings (`coerceRecordOpen`); the template pass queues the open result (`U | string`) when it names only the enclosing generic's parameters and the lambda's own return is not already it, spelled where `U` is in scope and read at each instance's binding (`mintedAnnTy`); and `fvaAdapt` builds no adapter over a lambda literal in that re-check, as it already did not for a named generic (D6501) · pins `generics/lambda-returned-at-open-union-result-at-two-instances.vl`, `…-at-three-instances.vl`, `…-union-typed-param.vl` · filed 2026-11-23 against master `9852c3da9`**

Repro:

    function keep<U>(x: U): () => U | string { return () => x }
    print(keep(true)() == null)
    print(keep(3)() == null)
    // vl check: rc 1. return type mismatch: expected boolean, got i32 (parameter `x` of `keep`)
    // and expected () => i32 | string, got () => boolean | string (the return of `keep`)

Want:

    false
    false

#### Mechanism

The second instance (`U = i32`) checks the returned lambda at the result type the first
instance (`U = boolean`) gave it, so its own `() => i32 | string` result refuses it. The
lambda is needed and the capture is not: `() => "s"` refuses the same way, while a nested
`function g(): U | string { return x }` returned by name runs. The literal's type was kept as
an annotation the first call's return re-check wrote on the shared lambda node.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| a second instance at the same `U` (`keep(3)`, `keep(4)`) | runs | **yes**, two distinct instances |
| result `() => U` (no union) | runs | **yes**, the union result |
| result `U \| string`, returning `x` (no closure) | runs | **yes**, a closure result |
| the lambda returns `"s"` (no capture) | still refuses | no |
| a nested named function returned in place of the lambda | runs | **yes**, a lambda literal |
| `(y: i32) => x` (a parameter) | still refuses | no |
| a `null` instance first (`keep(null)`, `keep(3)`) | still refuses | no |
