#### Mechanism

`cloCallUnionResultUnrepresentable` (emit_closure_sites.vl) refuses a closure call whose result
is a scalar-plus-composite value union unless the union-box (`>u`) sig is interned. Only a
producer lambda interned it: `collectTyReachCloSigsArm` (emit_collect.vl) skipped every type
whose result `funcRetUnrepresentable` names, which includes the mixed union. So an uncalled `u`
had no producer and no sig. A second arm refused an indexed closure-list callee whose union has a
value-union-element list arm whenever no Ident producer could be read, though every producer
stored at that element type is converted to the union result where it is stored.
