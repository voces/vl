### D1723 — a narrowed struct arm passed as an ARGUMENT is check-clean invalid wasm when its union is INFERRED, and runs when the same union is declared

**check-clean invalid wasm · filed 2026-09-06 against master `557c3081e` · found grading

Repro:

    type A = { r: i32 }
    function st(): A { return { r: 8 } }
    function pick(b: boolean) { if b { return st() } return 7 }
    function takeA(a: A) { print(a.r) }
    const p = pick(true)
    if p is A { takeA(p) } else { print(0) }
    // vl check: rc 0.  vl run: exit 70,
    // the emitted module failed to validate:
    // type mismatch: expected (ref $type), found (ref $type)

#### Mechanism

A narrowed struct arm stays the `{tag, payload}` box, so an argument boundary recovers the
payload itself. `emitCall`'s arm does that under `cVi >= 0` — the PARAMETER's variant row,
resolved from the annotation `a: A` through `variantRowOfTy`. With `type M = i32 | A`
declared, `A` has a variant row and the unbox is emitted; with the union only inferred, the
row `A` gets is not the one that lookup answers with, `cVi` is -1, and the box goes in whole.

`cVi` and not the `exprUnion` gate beside it, because the BINDING boundary runs on the same
value and asks that gate too (`narrowedArmNeedsUnbox`), so it answers true here. And it is
the union's spelling and not the receiver's: the same cell is SILENT with `p` an `Ident`, an
index place, a map value and a struct field alike, and RUNS at all four once `type M` is written.
