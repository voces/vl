#### Mechanism

The `if` is lowered arm by arm into the binding's union local, and each arm is boxed at the
union's rep. The `__trap__()` arm is typed `never`, which no union atom names, so the box lookup
found no atom. A `never` arm leaves nothing to store and is now built as the trap alone.
