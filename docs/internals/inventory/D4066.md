### D4066 — a declaration named like an ambient function is called by some calls and not others, and checked against the ambient signature

**open · check-clean silently wrong value · found writing `docs/spec/modules.md` (lane SPEC) · filed 2026-10-11 against master `98a4ed71b`**

Repro:

    const print = (x: i32): i32 => x
    print(5)
    // vl check: rc 0, no diagnostic.  vl run: rc 0
    // PRINTS 5

#### Mechanism

`print`, `fromCodePoint`, `fromCodePoints`, `Map` and `Set` are ambient: visible in every
module with no import (`docs/spec/modules.md` §M5.3). A program may declare one of these
names, and nothing refuses it, but the declaration only half replaces the ambient one. A
`function print` is the function a call runs, while the call's TYPE is still the ambient
signature (`void` for `print`, `string` for `fromCodePoint`). A `const print = …` lambda is
not reached at all: the call runs the ambient `print`, so the repro prints `5` where its
author's lambda prints nothing. Whether the declaration should shadow or be refused is
`docs/spec/OPEN-QUESTIONS.md` Q11; either answer removes this row's outcome.

#### Ablation

| variant | outcome |
| --- | --- |
| top-level `const print = (x: i32): i32 => x`, `print(5)` | the ambient `print` runs, prints 5 (wrong) |
| the same `const` inside a function | the ambient `print` runs, prints 5 (wrong) |
| `function print(x: i32): i32 { x + 100 }`, `const y: i32 = print(3)` | refused, "cannot bind the void result of 'y'" (wrong) |
| `function print(x: string) { n = n + 1 }`, `print("hidden")` | the user's function runs, nothing printed |
| `function fromCodePoint(x: i32): string { "mine" }` | the user's function runs, prints `mine` |
| `function fromCodePoint(x: i32): i32 { x + 1 }`, `fromCodePoint(65) + 1` | refused, "'+' is not defined for string and i32" (wrong) |
| `type Map = { a: i32 }`, `const m: Map = { a: 1 }` | accepted |
| `const i32 = 3` | accepted |

#### Grading list

Once Q11 is ruled, every row of the table should follow the one answer: either each
declaration is refused, or each shadows the ambient name for both the call and its type.
