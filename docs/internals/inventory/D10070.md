### D10070 — a union of maps delivered into a wider map-valued slot is refused when its handle reaches a second container store, though nothing writes a widened slot

**loud check reject · clause 2 · present on master `6691b1395` · found closing [D10042](D10042.md), whose index store now meets the same delivery check `.set` does · filed 2026-10-22 against master `6691b1395`**

Repro:

    const s: {[string]: string} = Map()
    s["k"] = "x"
    const us: {[string]: string} | {[string]: string | null} = s
    const hm: {[string]: {[string]: string | null}} = Map()
    hm.set("p", us)
    hm.set("q", us)
    print(hm.length)
    // vl check: rc 1, `... cannot be delivered as {[string]: string | null} here: the call to
    //   `hm.set` on line 6 writes a widened field`

Want:

    2

#### Mechanism

The record-write analysis (`rcwWriteHits`, check_program.vl) marks every slot of a union
source as written by any store at the handle's slot, so the second `.set` of the same source
counts as a write of a widened field. The delivery's own store is exempt since D10042; a
second store of the source, or of an alias bound from it, is not.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| one `hm.set("p", us)` only | prints `1` | **yes**, the second store |
| `s` stored twice in place of `us` | prints `2` | **yes**, the union source |
| `const w: {[string]: string \| null} = us` then one `hm.set("p", w)` | refuses identically | no |
| `hm["q"] = us` for the second store | refuses identically | no |
