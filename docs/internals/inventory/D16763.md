#### Mechanism

The `filter` call is stamped at the list of `J`, the record its receiver's elements are stored at
(`elabSameSlotsAtBuild`, `emit_elab.vl`), so its value is a `J[]`. The annotated binding's storage
is `{ f: null }[]`, a different struct, and the checker's floor for a built container
(`recBuiltReadErr`) walks reads of list bindings, not a stamped call's result delivered to an
annotated slot. Nothing converts or refuses, so the emitter stores a `J[]` where a
`{f: null}[]` is declared. The un-annotated binding takes the stamped type and runs.
