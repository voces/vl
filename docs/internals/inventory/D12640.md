#### Mechanism

D3985's mechanism with the record in the result. The checker's function-value adapter annotates
its lambda parameter `{b: i32}`, mono pins `U` from that spaced spelling at the empty record
`{}`, and the adapter's result type is the slot's `{b:i32}`, so the call into `id`'s instance
returns the wrong struct. A void result (D3985) refused at emit on master; this spelling was
already invalid wasm there, and #4739's shape walk without the adapter fix leaves it so.
