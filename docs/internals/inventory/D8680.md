### D8680 — a record literal a hole's body returns is built at a declared record that boxes its field, and handed to an annotated binding of the literal's own record

**closed 2026-10-21 · runs, prints `5` · was check-clean invalid wasm · clause 1 · inside an instance, a literal whose field is typed at a type parameter passes over a declared row that boxes the field where the instance binds it to a bare scalar, and takes that row only when no other row fits (`litPinnedInInstance`, `structIndexOfObjCtxGo`, `emit_classify.vl`) · pin: `tests/cases/soundness/record-literal-returned-from-hole-beside-boxed-row.vl` · matrix `record-literal-returned-from-hole-beside-boxed-row` 30 → 62 of 64 · present on master `a0af58b15` and `3f8abb772` · found closing [D8620](D8620.md) · filed 2026-10-20 against master `a0af58b15`**

Repro:

    type J = { f: i32 | null }
    function bump(n) { return { f: n + 1 } }
    const v: { f: i32 } = bump(4)
    print(v.f)
    // vl check: rc 0.  vl run: the emitted module failed to validate inside the module's top-level code: expected (ref null $1), found (ref $0); $1 is `{f:i32}`, $0 is `J`

Want:

    5

#### Mechanism

The literal `{ f: n + 1 }` is built inside `bump`'s instance, where the field's type comes from
the hole. Emit maps it to a declared row by field names, and `J` is the only record with field
`f`, so the instance returns a `J` with the field boxed. The binding is annotated `{ f: i32 }`,
whose row stores the field bare, and the returned `J` is stored there unconverted. D8620's close
moves a literal off a boxing row only when it is handed to a hole that reads the field; this
literal is the hole's result, so it is not covered. The close is in emit's row choice for a
literal inside an instance whose result lands at an annotated record.

#### Grading list

The same with a generic constructor, `function mk<T>(n: T) { return { f: n } }` and
`const k: { f: i32 } = mk(6)`, invalid wasm on master `a0af58b15`, prints `6` at the close. The
hole identity `function f(v) { return v }` returning a literal into `const a: A = f({ d: 3 })`
beside `type A = { d: i32 | null }` and `type II = { d: i32 }` is a different defect, filed as
[D8800](D8800.md).

#### Close

The rule is narrower than the checker's `recBuiltAtDeclared`. Asking every declared row for
field storage equal to the literal's own, with no reader condition, closed this row and
[D8684](D8684.md) but lost 267 corpus classes (8,443 census cells) on `regress.vl`. In those
cells the name match is what puts a literal in an un-annotated `Map()` or list at the row a later
delivery fixes. So the close asks only inside an instance. Two cells still need a row that was
never minted (`argument` and `early_return_guard`, un-annotated, filed under [D8682](D8682.md)):
there the row choice falls back to the boxing row, as before, and the first stays invalid wasm
while the second now refuses loud.
