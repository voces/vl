### D17854 — a list literal holding an un-annotated function beside `null` has no element rep

**loud emit reject · clause 2 · `emitProgram: the compiler cannot yet lower this statement (box pass)` · `vl check` rc 0 · filed 2026-11-28 against master `06f4dfec2` by I8-PREP (found closing D17722, coordinator ruling)**

Repro:

    function inc(a) { return a + 1 }
    function two() { return [1, 2].length }
    const xs = [if two() > 1 { inc } else { null }]
    const f = xs[0]
    if f != null { print(f(3)) }
    // vl check: rc 0.  vl run: emit error (box pass)

Want:

    4

#### Mechanism

Not located. The list's element is `((_) => _) | null`, the nullable of a hole function that no
call through the list closes before the element is stored. The same list with `inc` annotated, or
with no `null` element, runs. The family's spellings refuse at different sites:

- the element read and called after a null test: `box pass`;
- the element handed to an un-annotated parameter that null-tests and calls it: `box pass` (was
  `monomorphize: unsupported argument type` before D17722);
- `[inc, null]` handed there: `convert i32 -> closure` (was `a generic function taken as a value
  reaches no call that fixes its type` before D17722);
- the element handed to a parameter annotated `((x: i32) => i32) | null`: `ref valtype with no
  interned shape`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the hole (`inc(a: i32): i32`) | runs, prints `4` | **yes** |
| the `null` (`else { inc }`) | runs, prints `4` | **yes** |
| the choice (`[inc, null]`) | refuses (`convert i32 -> closure`, on master too) | no |
