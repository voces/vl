### D15656 — a list literal holding a binding of a join whose every arm is a kept maker's call has no row for its element

**loud emit reject, check-clean, an internal message · clause 1 · `emitProgram: ref valtype with no interned shape` · found closing D15654 · filed 2026-11-11 against master `8b88b166`**

Repro:

    type J = { f: i32 | null }
    function mk2() { { f: 1 } }
    const dA: J = mk2()
    print(dA.f ?? 0)
    const k = 1
    const b = if k > 0 { mk2() } else { mk2() }
    const xs = [b]
    print(xs[0].f ?? 0)

Want:

    1
    1

#### Mechanism

Not ablated past the table. `b` is built at `J`, as each arm hands over a `J` (D15654), but the
list literal's element row is asked of `b`'s checked type `{f: i32}`, which names no row; with a
declared `{f: i32}` row the list is built at that row and the module fails to validate.
