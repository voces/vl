#### Mechanism

`elemReadStep` (`check_rec_fresh.vl`) gives no step for a read of a binding that
`bindSlotWritten` reports, and a store whose value is not a fresh literal counts. `c["k0"] = lv1`
stores the walk's own fresh binding, so `c` counts as slot-written. Its typed read then names no
destination, and `lv1` keeps its own widening.
