### D2383 — a `??` whose left operand is a `boolean | null` and whose default is a ref lowers as the boolean niche

**check-clean invalid wasm · clause 1 · found in review of #3135 · filed 2026-09-24 against master `d522108b6`**

Repro:

    type A = { r: i32 }
    function mkA(): A | null { return { r: 1 } }
    function mkB(): boolean | null { return null }
    function go() {
      const x = mkB() ?? mkA()
      print(x is A)
    }
    go()
    // vl check: rc 0.  vl run: invalid module, inside `go`:
    // "type mismatch: expected i32, found (ref null $type)"

#### Mechanism

A prediction until a close confirms it. The join is `boolean | A | null`, a box, but the `??`
lowers through the boolean niche's `i32` (null is the value 2): the default's ref arrives where
the niche's `i32` block type is expected. Unlike the two-record `mkA() ?? mkB()` join filed in #3132, annotating the binding does not help, so
the lowering, not the binding's cell, picks the niche. The same family as that row and
[D2260](D2260.md): a `??` joining a niche to a member of another rep, with no box built.
