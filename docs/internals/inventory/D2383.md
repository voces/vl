### D2383 — a `??` with a `boolean | null` left operand and a default of another type lowers as the boolean niche instead of the union box

**closed 2026-09-25 · was check-clean invalid wasm · clause 1 · found in review of #3135 · filed 2026-09-24 against master `d522108b6`**

Repro:

    type A = { r: i32 }
    function mkA(): A | null { return { r: 1 } }
    function mkB(): boolean | null { return null }
    function go() {
      const x = mkB() ?? mkA()
      print(x is A)
    }
    go()
    // vl check: rc 0.  vl run (before the close): invalid module, inside `go`:
    // "type mismatch: expected i32, found (ref null $type)".  Now prints `true`.

#### Mechanism

`coalesceNicheJoinsToBox` (`emit_classify.vl`) decided whether a `??` joins its niche to a
default of another type, so the result is the union box. It recognised only the nullable-REF
niches (`coalesceNulRefNicheOperand`), so a `boolean | null` operand, which is the i32 niche
whose null is the value 2, always took `emitCoalesceGo`'s two boolean-niche arms (ident and
call), whose `if` has the `i32` block type. Every default that is not a boolean then landed a
ref or a float in that `i32` block, and the binding's cell, classified by the same predicate
through `letInitJoinsToUnionBox`, was the niche's `i32` too. The close adds the boolean niche
to the predicate and one lowering, `emitCoalesceNulBoolJoin` (`wasmEmit.vl`): the operand is
evaluated once into a scratch slot, 2 takes the boxed default (`emitUnionBoxArg`), and a
present 0/1 is boxed under the union's boolean arm. The cell, `exprUnion` and the lowering all
read the one predicate, so they agree.
