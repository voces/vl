### D14889 — an inline `if` joining an empty `Map()` with `null`, handed to a type parameter, is built with an `i32` result

**check-clean invalid wasm · clause 1 · found closing D1887 · filed 2026-11-01 against master `355cc64c`**

Repro:

    function p1<B>(b: B): i32 { return 1 }
    print(p1(if true { Map() } else { null }))

Want:

    1

#### Mechanism

The instance pins `B` at `{[string]: i32} | null` (D1887's close). The caller's value `if` takes
its block result type from its own node type, `{[_]: _} | null`, which still reaches an inference
hole, so it is emitted as `(if (result i32) ...)` around a map struct and `ref.null`.

#### Ablation

| --- | --- | --- |

| a concrete parameter `m: {[string]: i32} \| null` | runs | **yes** (the type parameter) |
| `[]` for `Map()` | runs | **yes** (the map) |
| `[1]` for `Map()` | runs | **yes** |
