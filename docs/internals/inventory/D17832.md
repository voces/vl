### D17832 — an annotated lambda converting a set's record field, called with a list element no other call through the set reads, builds the field at the default instance and traps

**open · loads then traps · clause 1 · `vl check` rc 0, `wasm trap: indirect call type mismatch` · filed 2026-11-28 against master `b3f4defbe` (lane START-2)**

Repro:

    function id(a) { return a }
    function deliver() { return [{ f: id }] }
    const k = (r): { f: (a: f64) => f64 } => ({ f: r.f })
    print(k(deliver()[0]).f(1.5))
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch

Want:

    1.5

#### Mechanism

`k`'s parameter `r` is a hole parameter receiving a record whose field's storage depends on whether
the set is tagged. Untagged, `deliver`'s literal stores `id`'s default (i32) closure (the only `id`
instance in the module), `k` copies it, and the call through its (f64) result mismatches. The (f64)
pin from `k`'s annotated result never reaches `deliver`'s returned literal through the hole
parameter when the argument is a call result. `VL_LATE_DEMANDS=1` shows `demand <lambda>` for the
trap only; the named spelling has none. Lead: the named function's re-check pins the call result's
holes; a `const`-bound hole lambda's call gets no such re-check. Handed to COV-CLOS-3 (hole-lambda
pin machinery, beside D17820). Ruled out: #10765's `$rep` key (one call, nothing to key), and a
`calleeFnDeclOf` rung in `callFtyPinCstrs` making the call own the lambda's deferred return.

#### Ablation

| spelling | outcome |
| --- | --- |
| this repro | trap after load |
| the same body as `function k(r): …` | runs (`1.5`) |
| the lambda on a binding's element (`const xs = [{ f: id }]; k(xs[0])`) or a record binding | runs (`1.5`) |
| the lambda on `const x = deliver()[0]; k(x)` | trap after load |
| a function-typed result (`(r): (a: f64) => f64 => r.f`) | trap after load |
| an i32 call through the set beside it | runs (the set is tagged) |
| `const x: { f: (a: f64) => f64 } = { f: deliver()[0].f }` | runs (`1.5`) |
| `k({ f: id })` | loud emit reject |
