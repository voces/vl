#### Mechanism

`emitIs` tests a union's tag only where it can reach the raw box: a frame slot
(`identSlotIsUnionBox`, which excludes globals on purpose), a narrowed member path, or an
operand whose own type is still a union. A narrowed read of any other union place — a module
global, an index cell `xs[0]`, a closure-written local (rewritten to the cell read `v[0]`) — is
already unboxed to the member, so it misses every tag rung and reaches `monoStaticIsResult`.
That fold asks `monoArgTyName`, which does not see narrowing and answers the declared spelling
(`f64|boolean`, printed by an `emitFail` probe on each of the witness, the index cell, the
closure-written cell and D2442's witness), and the fold answers 0. `const w = v` fails the same
way: `w` is a plain `f64` local, but its pin name comes from the union it was initialised from.

The fix answers the checker's tautology first. When the operand's checker type is not a union,
is the same type as the tested one, and the emitter also reads the operand unboxed
(`!exprUnion`), the test is true of every value the operand can hold and `emitIs` pushes 1 (a
non-name operand is still evaluated and dropped). That rung existed, guarded by `!uDeclared`,
for the collapsed same-shape union of #1672; it now runs before the storage rungs. Two
exclusions were found by the suites, not by reading: a `match` scrutinee is ONE node that every
arm's desugared test reads, so its recorded type is whichever arm the checker typed last
(`matchScrutAt` marks it; without the mark `match/payload-binding-dispatch.vl` trapped on a cast),
and reading a name under the rung could trap on its own rep recovery
(`match/payload-binding-shapes.vl`, a null through `ref.as_non_null`). The cell rewrite gives the
`c[0]` read under an `is` the type of the name it replaces, so the same rung answers for a
closure-written local.
