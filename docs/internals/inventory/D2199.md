### D2199 — an `if` value joining two differently-typed literal values into a declared literal-union binding is refused by the emitter

**closed — a value `if` meeting a literal-union destination hands the destination to each arm, so the atom arm stays the atom and the one-literal arm is narrowed where it is produced, and an arm's prelude runs outside that context · was loud emit reject · `emitProgram: literal-union atom narrowing needs a re-readable receiver` · `vl check` rc 0 · ran (printed `x`) on the seed built before #3056 · found writing the D2198 fixtures · filed 2026-09-23 against master `66e74235a` · closed 2026-09-23 with [D2204](D2204.md) and [D2206](D2206.md) · `scripts/capability-probes/matrix/litunion-if-join-arms-disagree.matrix.vl` (64 of 64; 11 on the #3062 head), `tests/cases/literal-unions/if-join-arms-disagree-into-atom-destination.vl`, `tests/cases/literal-unions/const-literal-compare-allowed.vl`**

Repro (runs, prints `x`):

    const A: "x" | "y" = "x"
    const B: "y" = "y"
    function join(c: boolean) {
      const M: "x" | "y" | "z" = if c { A } else { B }
      print(M)
    }
    join(true)

#### Mechanism

Two producers disagreed about the join. The staging-slot reservation (`exprStagesAtomNarrow`)
asks the `if` node's recorded TYPE, and since #3056 registers every inline literal union, a join
of `"x" | "y"` with `"y"` records the atom arm's own registered type, so the scan said "already an
atom, reserve nothing". The emitter's `pendingLitUnion` hook asks the arms' REPS
(`exprIsLitAtom` recurses into both arms), and the `"y"` arm is a one-literal string value, so it
called the join string-repped and staged it into the slot nobody reserved. Before #3056 the join
was an unregistered inline union, both said "stage", and the program ran through a
string round trip. The fix removes the question: a value `if` with an `else` at an atom
destination (`ifJoinNarrowsPerArm`, asked by both) is lowered as `if (result i32)` with the
atom context kept for each arm's value, and the scan asks each arm's value instead of the join.
An arm's prelude statements now run with the context cleared, because a `let` in a prelude
reset it and the arm's value then lowered as a string (check-clean invalid wasm under the first cut).
D2206 then makes a join whose recorded type is registered an atom outright, lowered the same way
from `emitIfExpr`, so the hook's per-arm branch is left for a join the checker minted fresh.
