### D14222 — a shape-spelled record reads the ref-list slot of the FIRST declaration of its shape, so a later same-shape declaration's slot is never found

**closed · 3 named cells (`d361e003101`, `d361e003143`, `d361e003185`) · filed 2026-10-26 against master `32d371fef`**

Repro:

    type Cir2 = { c2: i32 }
    type Sq2 = { s2: i32 }
    type Shape2 = Cir2 | Sq2
    type Dot = { r: Shape2 }
    type Circle = { r: Shape2 }
    function rd() {
      const lv1: Circle[] = [{ r: { c2: 1 } }, { r: { s2: 1 } }]
      const c: Circle[][] = [lv1]
      if (c[0][0]).r is Cir2 { print(7) } else { print(0) }
    }
    rd()

Want:

    7

#### Mechanism

`rlSlotOfTy` answers a record spelled by shape through `rlDeclTwinTy`, which names the first
declaration of that shape (`Dot`). Only `Circle`'s slot is interned, so the inner list of the
`Circle[][]` slot has no slot and the collector refuses with `a list-of-lists element has no
inner list shape`. On a miss there, the slot table is now scanned for an interned record of
the same shape.
