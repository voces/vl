#### Mechanism

`joinTys` and its siblings mint a union with `mkUnionTy` and then mark the row's index:
`tpJoinUnions` (a join of parameters kept apart, 1 or 2), `tpParamLitJoins`, `joinHoleUnions`,
`apartHoleJoins` and `noteHoleTpJoin` (`check_relate_core.vl`, `check_tp_join.vl`,
`check_fit_rules.vl`). A pin then re-joins a marked union's members apart. The mark is a second key on
the row: a union minted with the same members for another reason, shared by structure, takes the
join's re-join rule, and `v is i32` reads the `i32` arm as another number. The close puts the mark in
the mint's key, so a join union and a written union with the same members are different rows.
