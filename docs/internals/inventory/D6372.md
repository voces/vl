#### Mechanism

From the ablation and D6200's close. That close gives the parameter the emitter refuses a type
parameter of its own, and declines when the parameter is read other than as a direct argument
of a named function: the checker accepts a read of the new type parameter where the old one is
annotated, so the plan cannot tell from the re-check alone which instance the annotation names.
Splitting the annotation as well, here `b`, needs the reads followed through bindings.
