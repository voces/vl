#### Mechanism

The checker typed `f(__add)`, with `f` a `const` value-`if` of two hole relays, as an open hole,
so it accepted any destination: `const z: string = __pick(true)` checked clean too. The join of a
call through a function set (`holeSetCallRetOf`) holds both sets, `{__ap2, __ap3}` and
`{__add}`. It treats an argument carrying a set as closed, but it asks each member's result from
`holeLamRetAt`, which refused any open parameter type, so the join gave up. `holeLamRetAt` now
treats a set-carrying parameter as closed too, and each relay's body is typed calling `__add`
through its set. Stage 6 of the slot store, which reads both sets from the classes, subsumes it.
