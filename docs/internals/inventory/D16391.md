### D16391 — a list literal of a `u8[]` spread and `null` passes check, though its element `u8 | null` is no value type, and stops at an emit refusal

**closed 2026-11-15 · now a loud check reject (`a list literal mixing a `u8[]` spread with other elements has no element type`), as the design requires · was loud emit reject, clause 1 (`vl check` accepted a program the design refuses) · bucket (f) · fixed by joining a `u8` spread with `null` into the same u8-mix refusal as every other element · fixture `tests/cases/lists/error-u8-spread-null-mix.vl` · found probing the unprobed `--sites` row `wasmEmit.vl:13694` · filed 2026-11-15 against master `5683d3b2c`**

Repro:

    const s: u8[] = [1]
    const d = [...s, null]
    print(d.length)
    // vl check: a list literal mixing a `u8[]` spread with other elements has no element type

#### Mechanism

`u8` is a storage type: a list may hold it, a value may not, so `u8 | null` is refused as a
type (``u8` is a storage type, not a value type`). The checker also refuses every other mix of a
`u8[]` spread with other elements (`a list literal mixing a `u8[]` spread with other elements has
no element type`). A `null` element is the one mix that slips past that rule, so the literal
reaches the emitter with an element it cannot box and the emitter refuses. The design refuses
this program; the fix is the check refusal, not a lowering.
