### D3944 — a generic function written into a function-or-string union slot is never instanced, and the call traps

**closed — a write to a local whose annotation names no single function type delivers at the one signature the flow table pins the binding at (L1 step 4, eleventh part), so `b` is instanced at the slot's function member in each frame · graded by `tests/cases/closures/generic-written-into-function-or-string-union-slot.vl` · was loads then traps · found in review of #3494 (`rv3494/e_union_string`) · filed 2026-10-10 against master `00bf1871f`**

Repro:

    function b<U>(y: U) { print("G"); print(y) }
    function c<U>(y: U) { print("C"); print(y) }

    function a<T>(x: T) {
      let h: ((t: T) => void) | string = "q"
      h = b
      print("assigned")
      if h is string { print("str") } else { h(x) }
    }
    a(1)
    a("s")
    // vl check: rc 0.  vl run: prints assigned, then wasm trap: indirect call type mismatch

Want:

    assigned
    G
    1
    assigned
    G
    s

#### Mechanism

Not located. The slot `((t: T) => void) | string` is a union with a function member; the write
of the generic `b` is coerced at no member, so the narrowed call reaches the template.
