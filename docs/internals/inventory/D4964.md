### D4964 — a generic record's list field that `is K[]` fits as an empty list of another element is refused at emit

**loud emit reject · clause 2 · the type-parameter face of [D4939](D4939.md) and [D4949](D4949.md), which serve a field of a record declared at a concrete type · filed 2026-10-15 against branch `d4934-empty-arm-push` over master `e2efbc0af`**

Repro:

    type Box<V> = { items: V[] }
    function g<V>(b: Box<V>) {
      if b.items is f64[] { b.items.push(1.5) }
      print(b.items.length)
    }
    const e: Box<i32> = { items: [] }
    g(e)
    // vl check: rc 0.  vl run: emitProgram: this `is` arm reads an empty list at an element type it was not built with, and only a variable read directly in its own function can be handed one

#### Mechanism

`emitListEmptyFitIs` (wasmEmit.vl) hands an arm the empty `K[]` only through a named
variable's shadow local, and refuses with `LIST_FIT_SHADOW_MSG` when the receiver is a field.
D4949's store-back writes the tested arm into a field whose declared type is a union; here the
field is `V[]`, whose instance rep is `i32[]` and cannot hold the `f64[]`.
