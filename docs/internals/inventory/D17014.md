#### Mechanism

Once the decision tags the set (D14433's decision half), the elaboration plans the helper at the set
(`V=Fn#…`) while mono pins its map argument at the stored map of ids and walks the instance at
`V=i32`. The rep-keyed instance runs a helper that only hands the value on (`pick`), but a body that
calls `V` calls an `i32`; and the demand at `V=i32` is a late key the run did not foresee. The
set-keyed instance (`elabCallArgSetTy` binding `V` to the set) runs this witness `4 3.5`, but its
`return m.get(k)` lowers the read at the rep while its `V | null` signature is the union box, an
invalid module. Design: `docs/internals/refactor-notes/2026-11-19-f2-set-keyed-map-instances.md`.
