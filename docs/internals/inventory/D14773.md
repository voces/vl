### D14773 — a `null[]` write or result an instance builds at `T = null` carries no rep stamp of the cell it lands in

**closed 2026-11-01 · runs, prints the Want · the D4671 floor in `nullOwnAt` is deleted: each of the four sites now reads the elaboration's stamp of its cell · was a refutation pin for that deletion (with the floor gone and no fix, the witness's module failed to validate inside `filled`, `expected i32, found nullref`) · D14640's family · filed 2026-11-01 against master `7aa71dbba`**

Repro:

    function put<T>(self: T[], v: T) { self[0] = v }
    function id<T>(x: T): T { return x }
    const xs: null[] = [null, null]
    put(xs, null)
    print(xs[0] == null)
    print(id(xs[1]) == null)
    // vl check: rc 0.  vl run: prints true, true

Want:

    true
    true

#### Mechanism

A `null` landing in a `null[]` cell is stamped with the rep type of the `(boolean | null)[]`
list that cell rides (`stampNullUnitCell`, check_fit_rules.vl, D4771), so `nullOwnAt` builds
the sentinel 2 from the stamp. Inside an instance at `T = null` the write is a node mono mints in
the clone (`self[0] = v` rewritten, std's `insert`), which the checker never checks, and an
instance's returned value (`id<T>` at `T = null`, reached through `filled`) is delivered to
the return storage mono chose. Neither carries a stamp, so `nullOwnAt` still takes the
destination's `nulBool` seed there: the floor's last uses, beside D14640's.

#### Ablation

Measured over all tests/**/*.vl with the floor deleted: the only file that moves is
`types/null-unit-heap-positions.vl` (rc 0 → 70). A probe at the floor names four sites, none
with a stamp or a contextual type:

| site | node the emitter lowers | why no stamp reached it |
| --- | --- | --- |
| `put`'s `self[0] = v` | the spill read `asg#N#v` | `spillLocal` minted it after the elaboration stamped `v` |
| std `insert`'s `self[at] = v` | the spill read `asg#N#v` | the same |
| std `insert`'s `self[i] = self[i - 1]` | mono's remade `self[i - 1]` | `monoExprRemake` noted no source for an `Index` |
| std `filled`'s `__array_new__(n, v)` | the template's `v` | a fill argument was not a `null[]` cell |

#### Fix

`spillLocal`'s read and `monoExprRemake`'s node note the node they copy (`nodeSrcNote`), so the
elaboration's per-instance stamp answers for them. `nullUnitListCell` counts `__array_new__`'s
fill, and the intrinsic's check stamps a `null` fill. Every tests/**/*.vl builds byte-identical
before and after the floor goes.
