### D3004 — an alias of a record literal re-seated at a wider declared record reads the field at the wider type

**check-clean silently wrong · clause 1 · on master `b34730ad9` the map store is invalid wasm; on #3253 it runs and prints the wrong value · found by the #3253 review grid · filed 2026-09-28**

Repro:

    type D = { v: f64 }
    const x: i32 = 3
    const c: {[string]: D} = Map()
    const o = { v: x }
    c["k"] = o
    const same = o
    print(same.v / 2)
    // PRINTS 1.5

Want:

    1

#### Mechanism

`same` is an un-annotated alias of `o`, which the map store re-seats at `D`. `o.v / 2` narrows to the checked `i32` on #3253 and prints `1`, but `memReadNarrowOp` asks whether the receiver's binding is an object literal, and `same`'s is an identifier, so `same.v` stays `f64` and divides as one.
