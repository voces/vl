#### Mechanism

D15572's witness with the first generic handed through `fwd`'s hole parameter. D15572's close
computes the joined set `{id, id2}` from the call's argument types (`fnTagListJoinSet`,
check_elab_cap.vl). Here the first argument is `f`, whose type in `fwd`'s template is a type
variable, so the call joins nothing. Its set `{id}` is known only at `fwd`'s instance, and no
instance-side join exists. The same-set spelling `take(f, f)` runs.
