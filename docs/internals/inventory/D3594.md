### D3594 — an annotated `A | B | null` joined with itself at a pin of two number types traps on its `null`

**closed 2026-10-04 — the witness prints `4.5`, `3`, `null` · was loads then traps · clause 1 · the annotated face of [D3569](D3569.md) · found by the #3359 review (its `ar` grid, 54 `self` cells) · filed 2026-10-03 against master `7073d9d03`, closed against master `32b753681` · fixture `tests/cases/generics/written-param-union-self-join-keeps-numbers.vl`**

Repro:

    function F<A, B>(k: i32, a: A, b: B) {
      const w: A | B | null = if k == 0 { a } else if k == 1 { b } else { null }
      const v = if k >= 0 { w } else { w }
      print(v)
    }
    F(0, 4.5, 3)
    F(1, 4.5, 3)
    F(2, 4.5, 3)
    // vl run: prints 4.5, 3, then wasm trap: cast failure

Want:

    4.5
    3
    null

#### Mechanism

`joinArmLit(w, w)` over a written `A | B | null` minted a fresh join (`tpOpenJoin`) with no
runtime-arms mark, so the pin re-joined `f64` and `i32` by widening and `v` took an
`f64 | null` slot beside `w`'s three-tag box. A self-join of runtime arms over a written union
of type parameters now carries the mark, as [D3569](D3569.md)'s join of a marked join does.
