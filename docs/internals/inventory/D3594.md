### D3594 — an annotated `A | B | null` joined with itself at a pin of two number types traps on its `null`

**loads then traps · clause 1 · open · the annotated face of [D3569](D3569.md) · found by the #3359 review (its `ar` grid, 54 `self` cells) · filed 2026-10-03 against master `7073d9d03`**

Repro:

    function F<A, B>(k: i32, a: A, b: B) {
      const w: A | B | null = if k == 0 { a } else if k == 1 { b } else { null }
      const v = if k >= 0 { w } else { w }
      print(v)
    }
    F(0, 4.5, 3)
    F(1, 4.5, 3)
    F(2, 4.5, 3)
    // vl run: prints 4.5, 3, then wasm trap: cast failure

Want:

    4.5
    3
    null

#### Mechanism

Not localised past the disassembly. The annotation is not a kept-apart join, so `v`'s join of
`w` with itself substitutes to `f64 | null` while `w` holds the three-tag `f64 | i32 | null` box.
The delivery into `v` converts every tag other than `f64` as the `i32` arm, and the `null` tag's
empty payload fails that cast. [D3569](D3569.md)'s fix, the kept-apart mark on a self-join, does
not reach a join the checker never kept apart.
