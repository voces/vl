### D1350 — a VOID closure bound in a MODULE-SCOPE block resolves no `$fnsig`, so its statement call `drop`s an empty stack

**closed — `identClosureFeSid` gained the module frame as its third scope, beside a `fnBody` and the globals · was check-clean invalid wasm, clause 1 · ZERO corpus cells · found 2026-09-03 while grading [D1244](#d1244)'s own position matrix, which it was hiding underneath**

Repro (runs, prints `8`; before the close, `vl check` rc 0 then
`Invalid input WebAssembly code: type mismatch: expected a type but nothing on stack`):

    if true {
      const f = () => { print(7) }
      f()
    }

#### Mechanism

`emitCallStmt`'s `Ident` arm drops a call's result unless it can prove the callee is void.
For a closure VALUE that proof is `calleeReturnsVoid` → `calleeCloSigKey` →
`identClosureFeSid`, which resolves the binding in exactly two scopes: `P.nodes[fnIx].fnBody`
when `fnIx >= 0`, and the module GLOBALS. The start function is `fnIx == -1` and its
block-locals are neither, so the key came back `""`, `sigKeyRetIsVoid("")` is false, and the
emitter dropped a value the `>v` functype never left on the stack. Same shape as D945 one
scope over — that row taught this ladder to read a binding whose INITIALIZER is a call; this
one teaches it the third SCOPE. The fix reuses D1244's `moduleLocalLetOf`.

It is [D1244](#d1244)'s layer-mate, not its duplicate: D1244 needs a CAPTURE and this needs
none, and each reproduces on a program the other's ingredients are absent from. D1244's loud
field-access refusal fired first on the matrix cells, which is why this stayed invisible while
its own matrix graded the capability green.
