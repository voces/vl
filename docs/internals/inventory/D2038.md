### D2038 — a computed `match` scrutinee in a conditional or order-sensitive position is still re-evaluated per tested arm

**check-clean silently wrong · clause 1, wrong value · residue of D1991 · filed 2026-09-22 against master `ee4c28b60`**

Repro:

    let n = 5
    function next() {
      n = n + 1
      n
    }
    const ok = true && match next() { 5 => false, 6 => true, 7 => false, _ => false }
    print("\{ok} \{n}")
    // expected `true 6`
    // PRINTS false 8

#### Mechanism

D1991's fix binds a computed scrutinee to a local just before the statement that holds the
match, climbing from the match through parents that evaluate it first and unconditionally.
`hmsStepOk` stops the climb, and leaves the match as parsed, at: the right operand of `&&`,
`||` or `??`; a `while` condition; an `else if` condition; a call argument, list element or
object field after a sibling that is not a literal or a lambda; a named-argument call; the
target of an assignment (`xs[match g() {…}] = v`); a callee, method receiver or index base
that the scrutinee could REBIND — anything but a bare name no `let`, parameter or loop binds
(so a `let` global, `a.b`, `a[i]` are declined; review of #3038); and a value-`if` arm the
emitter's collect pass does not walk (an `if` expression used as an argument). Binding earlier
there would skip the short-circuit, evaluate a loop condition once, run the scrutinee before a
sibling's effect, or read a callee/receiver/base the scrutinee has already replaced. The chain in those positions still tests the
scrutinee node once per arm.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `true &&` (a statement-level `const ok = match next() …`) | prints `true 6` | **yes** |
| the side effect in `next` | prints the right arm | **yes** |

#### Grading list

`while match it.next() { … }`, `if a {…} else if match f() {…} {…}`, `g(x, match f() {…})`,
`xs.push(match g() {…})` over a `let xs`, and the second of two computed matches in one list
literal — each prints the side-effect count. The rebinding pins at the foot of
`tests/cases/match/computed-scrutinee-evaluated-once.vl` must keep their values.
A fix binds the scrutinee inside the construct (an arm-local binding, or a scratch local the
emitter owns), not before the statement.
