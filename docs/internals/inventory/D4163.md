### D4163 — a type-parameter value written into a nullable MIXED literal-union place reads the template's narrowing at a nullable pin

**closed 2026-10-21 · runs, prints the Want · was check-clean silently wrong · clause 1 · fixed with [D3446](D3446.md)'s local write (`tvPlaceWrite`) · pin: `tests/cases/generics/type-param-write-union-local-reads-at-pin.vl` · pre-existing, the same on master `5e770df5b` · found by the review of the D3423 fix · filed 2026-10-11 against master `5e770df5b`**

Repro:

    type M = "a" | 1
    function g<T>(x: T) {
      let s: M | null = null
      s = x
      print(s ?? "n")
      print(s == null)
    }
    const v: M | null = null
    const w: M | null = 1
    const u: M = "a"
    g(v)
    g(w)
    g(u)

Want:

    n
    true
    1
    false
    a
    false

#### Mechanism

`tvPlaceWrite` takes the `HD_TVW` read (the pin decides whether the place is null) only for a
place of one member or of a string-literal union (`tyIsLitUnion`). A mixed `"a" | 1` keeps the
template's non-null narrowing of `s` after `s = x`, so the shared body folds `s ?? "n"` to `s` and
`s == null` to `false` at every pin. The number-literal case is [D4164](D4164.md).
