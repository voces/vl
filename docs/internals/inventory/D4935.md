#### Mechanism

The arm's empty `K[]` is a shadow local that `emitIdentNode` redirects to in the narrowing
function only. A lifted closure reads its capture from its own environment, which holds the
receiver as built, so `emitListEmptyFitIs` refuses (`liftedFnCaptures`) rather than let the
closure read the wrong list.
