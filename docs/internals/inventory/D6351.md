#### Mechanism

From the ablation only. [D6330](D6330.md) judges each operator at each instance when the
callee is a declared function or a `const` lambda, whose body is known at the call. A `let`
binding can be reassigned, so the call does not resolve to the lambda and `"" + 1` at the
`i32` instance is never judged. The checker owes the refusal; a fix should not make the
program run.

not judged per write.
