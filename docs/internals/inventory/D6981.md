#### Mechanism

The inertness walk noted an unread binding's initialiser inert when it was a name, an alias or
a literal of them (`monoNoteInertInit`), but did not look into an `if` expression's branches, so
the hole function kept a value use and had no signature to build at. `monoIfArmValuesOf` now
hands each branch's last statement (an `else if` being one) to both value walks, so every
inertness position (an unread binding, an unread result, a discarded statement) sees through it.
A `match` is lowered to an `if` chain first and is covered by the same rule.
