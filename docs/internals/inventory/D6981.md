### D6981 — an `if` expression whose arms are an uncalled hole function, bound and never read, is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same program with `exclaim(s: string)` runs, and the name bound directly runs ([D6830](D6830.md)) · found closing [D6960](D6960.md) · present on master `641dc8172` · filed 2026-10-19 against master `641dc8172`**

    function exclaim(s) { return s + "!" }

#### Mechanism

From the ablation only. The inertness walk notes an unread binding's initialiser inert when it is
a name, an alias or a literal of them (`monoNoteInertInit`), but not the arm tails of an `if`
expression, so the hole function keeps a value use and has no signature to build at.
