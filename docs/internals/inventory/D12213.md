**check-clean invalid wasm · `vl check` rc 0 · `the emitted module failed to validate inside `__lambda_1`: … expected (ref $4), found i32; $4 is `string`` · clause 1 · one instance, or a non-generic `outer`, runs · found surveying emit refusals for L3 family (d) · filed 2026-10-24 against master `b8e223f93`**

Repro:

    function outer<T>(x: T) {
      function inner<U>(u: U) { print(x); print(u) }
      function inner2<U>(u: U) { print(u); print(x) }
      let k = inner
      const flip = () => { k = inner2 }

#### Mechanism

The closure `flip` writes `inner2` into the captured cell `k`. Both nested generics capture
`x`, whose type differs between `outer`'s two instances, and the validator fails inside the
closure with an `i32` where the `string` instance wants a `string`: the write appears to be
lowered against the first instance's capture. Not traced further.
