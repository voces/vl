### D2645 — a read function whose else-less tail `if` assigns a closure to a global fails validation

**check-clean invalid wasm · clause 1 · found by the review of #3186, identical on master `50c627ce4` · filed 2026-09-26**

Repro:

    let gv: () => i32 = () => 0
    function f(c: boolean, n: i32) {
      if c { gv = () => 5 }
    }
    const r = f(true, 0)
    print(r == null)
    // vl check: rc 0.  vl run: type mismatch: expected (ref null $type), found i32

#### Mechanism

Not ablated past the table. `f`'s result is read, so its inferred return is the tail `if`'s
`(() => i32) | null`, the nullable closure that D2499 (the same program with the result read)
names. The binding `r` and its `== null` test lower that value at an i32 rep while the
function's result is a nullable closure ref.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the closure (`gv: i32`, `gv = 5`) | runs | **yes** |
| the read (`f(true, 0)` as a statement) | runs (D2631 makes `f` void) | **yes** |

#### Grading list

D2499, whose witness is this shape without `n`.
