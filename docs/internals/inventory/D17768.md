#### Mechanism

The defect is the ORDER DEPENDENCE (coordinator, 2026-11-27): what pins `apN`'s hole parameter
must give one answer whatever the statement order, from one settle point, as F1's defaults do.
Not traced to the edge. The checker leaves every type here open (`(_) => _`, `{fs: ((_) => _)[]}`),
so the elaboration's holder classes (`eplHolderTy`, `eplRoot`, emit_elab.vl) close them; the
second holder's class seems to take the first's, leaving `nested.map(apN)`'s element at `_`.
