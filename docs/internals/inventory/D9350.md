#### Mechanism

At module scope the checker's scrutinee hoist does not reach a `match` nested in a value-`if` arm
or a `match` arm of a global initializer ([D2038](D2038.md)), so the lowered chain re-reads
`which()` once per tested arm. The split (`fsMatchOnce`, fn_split.vl) declines that shape rather
than evaluate the scrutinee twice. Called at one type the same binding runs and prints `which`
twice, which is D2038 itself. Hoisting the nested scrutinee at module scope closes both.

| the call in the `if` condition (`if 1 > 2`) | same refusal | no |
| module scope (the binding inside a function) | runs, `e1` `which` `9` `xxx` | **yes** |

#### Grading list

A `match` nested as a `match` arm at module scope (`const e = match which() { 1 => idg, _ => match which() { … } }`); each scrutinee must print once.
