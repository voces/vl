#### Mechanism

`x` holds the one-member set {exclaim}, chosen by an `if`. A call through it is a member call
only when the set is tagged, and with `x` an `==` operand the set stays untagged: the operand
is the one ingredient the ablation names.
The binding then reaches the emitter as a hole function taken as a value, which only the 0-CFA
pin gives a signature. The pin-caller deletion has to serve a set value used as an `==`
operand (compare by member id, or eta it at the operand) before it can delete the callers.
