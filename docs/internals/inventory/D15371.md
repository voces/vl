### D15371 — a list literal spreading a list of lists built at a wider record beside a literal list of lists is check-clean invalid wasm

**closed 2026-11-04 · runs, prints `7` · was check-clean invalid wasm, `vl check` rc 0 · clause 1 · found closing [D15370](D15370.md) · filed 2026-11-04 against master `cebadc86` · closed by the pass-end list stamp asking a spread list literal where its parts are built (`checkSpreadArrayLit` queues it, as a spread-free literal is), a spread part or an element of a built list of lists answering its source's build (`recSpreadPartBuiltTy`, from D15236's outer stamp), and fresh literal parts taking the build the other parts agree on rather than vetoing it (`recListLitBuild`) · fixture `tests/cases/soundness/record-list-literal-mixing-built-and-fresh-parts-runs.vl` · parts that disagree, or a fresh record binding as a part, are [D15372](D15372.md)**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const ys = [[mk()]]
    const ws = [...ys, ...[[{ f: 7 }]]]
    print(ws[1][0].f ?? 0)

Want:

    7

#### Mechanism

The list literal `ws` takes its parts from two spreads: `ys`, whose
inner lists are built at `J[]`, and a literal list of `{f: i32}` lists. No stamp builds a spread
PART of a list literal at the build of the parts beside it, so the second part's inner lists stay
`{f: i32}[]` in a list holding `J[]`.
