### D15371 — a list literal spreading a list of lists built at a wider record beside a literal list of lists is check-clean invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · open, target `7` · found closing [D15370](D15370.md) · filed 2026-11-04 against master `cebadc86`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const ys = [[mk()]]
    const ws = [...ys, ...[[{ f: 7 }]]]
    print(ws[1][0].f ?? 0)

Want:

    7

#### Mechanism

Not ablated past the table. The list literal `ws` takes its parts from two spreads: `ys`, whose
inner lists are built at `J[]`, and a literal list of `{f: i32}` lists. No stamp builds a spread
PART of a list literal at the build of the parts beside it, so the second part's inner lists stay
`{f: i32}[]` in a list holding `J[]`.
