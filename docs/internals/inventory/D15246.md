### D15246 — a record literal written into a nested field of an own-type binding whose record is built wider is built at the binding's own row

**open · check-clean invalid wasm · `type mismatch: expected (ref null $type), found (ref $type)` · clause 1 · found grading D15214 · filed 2026-11-04 against master `39579d12f`**

Repro:

    type J = { f: i32 | null }
    type K = { j: J }
    function mk() { { j: { f: 4 } } }
    const _k: K = mk()
    const y = mk()
    y.j = { f: 5 }
    print(y.j.f)

Want:

    5

#### Mechanism

`mk` is built at `K` for both calls (`recNullWidenedAt` reads `y`'s own row back from `K`'s
storage), so `y` holds a `K` record. The literal written to `y.j` is typed at `y`'s own field
type `{f: i32}` and built there, then stored into a field of `J`'s storage. Not yet ablated past
the grid below.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the nested record (`K = { f: i32 \| null }`, `y.f = 5`) | runs | **yes** |
| `const _k: K = mk()` | runs | **yes** |
| `y.j` read without the write | runs | **yes** |
| `K`'s field nullable (`j: J \| null`) | still invalid wasm, once D15214 builds it at `K` | no |
