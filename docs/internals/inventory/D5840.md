### D5840 — an empty list, a literal-union string or a nested list literal handed through an un-annotated parameter to a function's typed parameter is check-clean invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · found closing [D5790](D5790.md) · filed 2026-10-17 against master `519a09fef`**

Repro:

    function two(a: i32, b: string[]): i32 { a + b.length }
    function apply(g, x, y) { return g(x, y) }
    print(apply(two, 3, []))
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `apply`

Want:

    3

#### Mechanism

From the ablation only. The program is legal: the direct spelling through a value runs, and
so does the same empty list held in an annotated binding. At a direct call the literal takes
its type from the parameter. Through the hole, the instance types `y` from the literal alone,
so `apply` hands `call_ref` a value of another rep than `two` takes.
