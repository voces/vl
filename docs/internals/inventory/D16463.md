### D16463 — a recursive field-write arm's inferred result is built at the literal's record row whenever that row exists

**check-clean invalid wasm · clause 1 · open · found grading D16460's close · filed 2026-11-15 against master `41739762`**

Repro:

    type Node = { v: i32, left: Node | null }
    function insert(n: Node, v: i32) {
      if n.left == null { n.left = { v: v, left: null } } else { insert(n.left, v) }
    }
    const fresh: Node = { v: 1, left: null }
    print(insert(fresh, 3).v)
    const q = { v: 7, left: null }
    print(q.v)
    // vl check: rc 0.  vl run: invalid module inside `insert`: expected (ref $1), found (ref $0); $1 is `#anon1`

Want:

    3
    7

#### Mechanism

The checker records `insert`'s result as the literal's type `{v: i32, left: null}`. With no
record of that shape the result falls to `Node`, the row the field write stores; once another
literal of the shape mints `#anon1`, the result is built at that row while the arms deliver a
`Node`. A generic's returned field write mints the row too: `tests/cases/conditionals/
tail-if-field-assign-arm.vl` spelled with `return` throughout fails here, since its `tagged<T>`
then yields a value.

#### Ablation

| ingredient changed | outcome on master | needed? |
| --- | --- | --- |
| no `const q` literal | prints `3` | **yes** (the minted row) |
| an annotated `: Node` result | runs | **yes** (the inferred result) |
