### D3786 — an un-annotated function whose tail assigns a value `if` to an `i64 | null` local cannot print its result

**loud emit reject · open · found by lane S4 while grading [D3733](D3733.md) · filed 2026-10-06 against master `a37097b64`**

Repro:

    function v(c: boolean) {
      let x: i64 | null = null
      x = if c { 5 } else { 1 }
    }
    print(v(true))
    // vl check: rc 0.  vl run: emit error, print of a union value whose arms the tag dispatch cannot classify

Want:

    5

#### Mechanism

Not yet ablated past the table below. The function's inferred result is the assignment's value
over a nullable cell, and `print` reaches the union-box dispatch with arms it cannot classify. A
bare `x = 5` tail runs, so the `if` join is an ingredient; hex tails are not.
