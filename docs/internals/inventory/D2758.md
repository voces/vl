#### Mechanism

D2733 made two maps whose value unions differ only in member order one type for `is`. A union
that spells both keeps two members with two tags, so a value boxed under one tag answers `true`
for its own spelling and `false` for the other (this prints `true false false true`), while the
type system calls the two patterns one type. The question for the owner: is `U` a two-member
union (so each pattern should test both tags), or should the checker fold the two spellings into
one member, as it does an exact duplicate? Recommendation: fold at the checker, since no program
can tell the two values apart.
