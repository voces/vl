### D9652 — a list of a call-bound generic and a generic read from another list, called at two types beside direct calls of the call-bound `const`, traps on an indirect call type mismatch

**trap after load, `wasm trap: indirect call type mismatch` · `vl check` rc 0 · clause 1 · found closing [D9594](D9594.md) · present on master `92d03ef36` · filed 2026-10-22 against master `92d03ef36`**

#### Mechanism

Not traced. From the ablation only: the trap needs `v` to be read out of a list rather than
named, and both elements of `ys` called. `ys[1]` is called at `i32` through a slot whose
table entry is an instance at another signature, so the two elements' instances are chosen
by two different paths (the list-read path for `v`, the call-bound path for `c`) that do not
agree on which instance the list holds.
