#### Mechanism

At the field receiver no delivery reached `src`'s element (temporary probe: `elabSlotDeliveries`
empty, `pins=0`, the uncalled arm): the delivery walk's spread arm found the receiver's binding
through `elabPushedOnto`, which takes a name only. In the spread initialiser
`const rs: ((x: T) => T)[] = [...src]`, `src` was pinned per instance, but the flow rewrite
(`monoFlowSpreadSet`) replaces the spread with fresh name reads of the generic; in an instance those
carry no elaboration stamp and the literal no slot pin, so `monoCoerceLitPart` built nothing and
both instances read the first one's `id`. Probe: per instance, stamp and pin empty, the
destination's element `(i32) => i32` and `(string) => string`.
