### D2390 — an `is` narrowing survives a call to a closure that reassigns the narrowed binding

**loads then traps · clause 1 · filed 2026-09-25 against master `3ab3c402f`, found grading
[D2387](D2387.md)/[D2388](D2388.md) · was check-clean invalid wasm before that close**

Repro:

    function f(): string {
      let v: boolean | f64 = 1.5
      const k = () => { v = true }
      if v is f64 { k(); "\{v}" } else { "no" }
    }
    print(f())
    // vl check: rc 0.  vl run: wasm trap: cast failure

#### Mechanism

The checker narrows `v` to `f64` for the whole then-arm and does not drop the narrowing at
`k()`, although `k` assigns `v` and is called inside the arm. The emitter reads the cell under
the narrowing and casts the box's payload to the f64 struct, which now holds a boolean. Before
the D2387/D2388 close the read was also mis-classified, so the same program failed validation.
Whether a call to a closure that writes a captured binding should end a narrowing is a
language decision (TypeScript keeps it, unsoundly); until one is made the program is
check-clean and traps.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the call `k()` inside the arm | prints `1.5` | **yes** |
| the closure's write (`k` only reads `v`) | runs | **yes** |
| the write's member (`v = 2.5`) | prints `2.5` | **yes** |
