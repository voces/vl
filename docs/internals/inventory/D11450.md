### D11450 — a generic alias whose field is a list of an inline record, handed as a literal to a generic, has no ref-list slot

**loud emit reject · clause 2 · `vl check` rc 0 · present on master `4e10a2462` · found by the D10930 lane probing its neighbours · filed 2026-10-23 against master `4e10a2462`**

Repro:

    type B<U> = { s: { g: U }[] }
    function f<T>(v: B<T>): i32 { v.s.length }
    print(f({ s: [{ g: 3 }] }))
    // vl check: rc 0.  vl run: emitProgram: ref-list field element type is not interned

#### Mechanism

Not traced. D10930's mechanism suggests the shape: `gaeEnsure` keys a code-5 field's element
by its applied spelling (`arrElemNameRaw(tn)`, here `{g:i32}`), while the second
`collectGenAliasShapes` runs after the literal's `{ g: 3 }` was interned as `#anonN`. Keying
the element by the row's own name instead (as D10930 does for a code-15 field) was tried and
did not move the refusal, so the missing slot is minted elsewhere.
