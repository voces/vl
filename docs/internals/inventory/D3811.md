### D3811 — an un-annotated function whose tail reads a parameter narrowed by an earlier `is` guard's `return` builds its result as the parameter's union

**check-clean invalid wasm · the un-annotated spelling of `unions/list-arm-push-and-shared-member.vl`'s `grow`, which D3800's hint asked for · filed 2026-10-07 against master `79190c15d` (lane DH)**

Repro:

    function grow(x: i32[] | i32) {
      if x is i32[] { return x.length }
      x
    }
    const g: i32 = grow(5)
    print(g + 1)
    // vl check: rc 0, `grow` inferred as `i32`. vl run: rc 70, invalid module inside `grow`:
    // type mismatch: expected (ref $type), found i32.

Want:

    6

#### Mechanism

The checker infers `grow` as `i32`: the early-exit `is` guard narrows the tail read of `x` to
`i32`. The emitter builds the un-annotated result from the tail expression's storage, which is
the parameter's union box, while the `return x.length` arm hands back an `i32`. With the return
annotated the emitter has the declared type and the program prints `5`.
