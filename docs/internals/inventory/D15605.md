### D15605 — a field read off a union of records whose members store it at different value atoms, through an un-annotated parameter, has no value box

**loud emit reject · clause 2 · `vl check` rc 0, then `emitProgram: field access receiver is not a struct` · the annotated parameter runs · D15571's mixed-field neighbour, which D15571's close left standing · filed 2026-11-09 against master `de73ab0c`**

Repro:

    type K = { h: i32 }
    type J = { h: string, z: i32 }
    const k: K = { h: 4 }
    const u: K | J = k
    function take(a) { print(a.h) }
    take(u)
    // vl check: rc 0.  vl run: emitProgram: field access receiver is not a struct

Want:

    4

#### Mechanism

The shared-field plan boxes the read as the field union `i32 | string`, and
`sharedFieldPlanDispatchable` declines because the `i32` value box was never minted
(`vbHeapIdxOfKind(0)` is -1). The union is the read's type only in the instance pinned at
`K | J`; the template node holds the parameter's hole, so the collect pass that marks a value
union's arms (`markValueUnionAtoms`) never sees it. Annotated `a: K | J`, the template node
carries the union and the box is minted.

| the read bound first (`const n = a.h; print(n)`) | still refuses | no |
