### D3266 — a join of three bare type parameters prints the wrong members

**check-clean silently wrong · clause 1 · open · the same on master `569caa36c` · found by the #3297 round-2 review (`m3.vl`) · filed 2026-09-29**

Repro:

    type K = "a" | "b"
    function g<T, U, V>(a: T, b: U, d: V, k: i32) {
      const r = if k == 0 { a } else if k == 1 { b } else { d }
      return r
    }
    const x: i32 | null = null
    const y: K = "a"
    const z: string = "x"
    print(g(x, y, z, 0))
    print(g(x, y, z, 1))
    print(g(x, y, z, 2))
    // today it prints null 0 null

Want:

    null
    a
    x

#### Mechanism

Not localised past the ablation. The chain joins the three parameters apart (D2760) and the
instance lowers it at the first parameter's pin, so the atom of `K` prints as its id and the
string arm is read as the nullable `i32`.

| two parameters (`if k == 0 { a } else { b }`) over `i32 \| null` and `K` | see D3268 | — |
