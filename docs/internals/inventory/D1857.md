#### Mechanism

ROADMAP row 25 migrates nominal `structIndexByName` callers to the structural-tolerant
`structIndexOfTypeName`. `elemNameIsNominalAt` is one of the 25 sites a structural name
reaches, and converting it makes the compiler **trap** (`out of bounds array access`, exit 70)
on this program and on eight `named/d361e0136*` corpus cells.

It is not a gap. The function asks *"is this element name one `repElemKey` keys NOMINALLY —
one a structural row cannot stand in for?"*. `structIndexOfTypeName` answers by matching a
structural shape TO a row, which is precisely the case whose answer must be `false`. The
conversion inverts the predicate, a structurally-spelled element gets a nominally-keyed slot
pointing at its structural twin, and `mAssignTypeIndices` then indexes a table with it.

**Measured at the rung, not read off the code.** With the site left unconverted and a
shadow-gated note beside it, the name it would flip on is
`repAB/elemNominal would-flip -> {r:{c2:i32}|{s2:i32}} x2` — the structural rendering of
`Circle`. The rung's own comment already stated the cost: *"a wrong hint is a silently wrong
slot."*
