### D2408 — a bare-name re-test inside the arm of a condition whose own call ended the narrowing is refused

**loud check reject · clause 2 · filed 2026-09-25 against master `a277bf7b0`, found grading
[D2401](D2401.md) · open**

Repro:

    function f(): f64 {
      let v: boolean | f64 = 1.5
      const k = (): boolean => {
        v = true
        true
      }
      if v is f64 && k() {
        if v is f64 { return v }
        print("flipped")
      }
      0.0
    }
    print(f())
    // vl check: rc 1, "'v' is no longer narrowed to f64: the call to 'k', in the statement that
    // holds this one, may reassign it", reported at the re-test's own operand

#### Mechanism

D2390 retires a bare name at statement granularity: the emitter retires after the statement
holding the call (`callRetireAfterOf`), so a read of the name anywhere else inside that
statement, the arms of an `if` whose condition holds the call included, is refused
(`crReadHook`'s pending rows). The re-test's operand is such a read, so the refusal fires on the
fix its own message asks for. The path twin runs: a path fact in a condition is dropped by
`crFilterCond` rather than pended (D2404's close), and the arm re-tests from the declared type.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the call in the condition (`if v is f64 { if k() { … } }`) | the re-test runs | **yes** |
| the bare name (a path `o.v` the call may write) | runs | **yes** |
| the module binding (a global `g`, a top-level writer, as in D2401) | refuses the same | no |

#### Grading list

The `!(v is f64) || k()` early-return spelling followed by a re-test; a `while` condition
holding the call with a re-test in the body. Candidate fix: exempt an `is` test's operand from
the pending refusal (as D2403's loop read log does), once the emitter's lowering of that test is
shown to read the cell rather than the narrowed rep.
