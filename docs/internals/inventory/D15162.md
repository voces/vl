### D15162 — a map written two functions of different result types inside a function and returned is refused at check

**closed · runs, prints `1.5` · was loud check reject, `cannot write 'half' to an element of 'm'` · clause 2 · found closing [D15137](D15137.md): the same map at the reading scope runs · filed 2026-11-03 against master `b813a46b` · closed 2026-11-03 by D15167's PR: `holeSlotArgJudge`, which judges a returned value as it judges an argument, takes D15137's lift (`holeSlotWidenLift`, check_relate_core.vl) · fixture `tests/cases/closures/fn-widened-slot-returned-read.vl`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function mk() { const m = Map()
     m.set("a", inc0)
     m.set("b", half)
     return m }
    const m = mk()
    const g = m.get("b")
    if g != null { print(g(3)) }
    // Want: 1.5

#### Mechanism

`holeSlotJudge` reads a binding initialised by a call through the call's returned values (`holeSlotRetJudge`), and that path does not take the lift D15137 gives a binding whose slot writes `elabSlotJoinTy` joined.
