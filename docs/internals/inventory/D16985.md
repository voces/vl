### D16985 — an inferred union of an empty list and `null` or a string settles the list's element at the unbound default after a typed read was checked

**check-clean invalid wasm · clause 1 · census row 12 of the no-default ruling (DECISIONS.md §"No default type") · filed 2026-11-18 against master `8c0843c69` by lane F1**

Repro:

    function joined(c: boolean) { return if c { [] } else { null } }
    const a = joined(true)
    if a != null && a.length > 0 { const s: string = a[0]; print(s) }
    print(1)
    // vl check: rc 0.  vl run: invalid module inside `joined`, expected i32

Want:

    1

#### Mechanism

The open list member of an inferred union or nullable is settled at the unbound default `i32` by
`defaultInferredRet` for a return or `settleOpenUnionRows` for a binding (`check_narrow_flow.vl`),
after the narrowed read into a `string` was checked against the open hole. The function then builds
an `i32[]` where the caller's read wants a `string[]`. Under the ruling the typed read fixes the
element.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| no element read, `print(a.length)` | runs, prints `0` | **yes** |

| `return []` / `return null` statements | the same invalid wasm | no |
| `[]` or `"s"` in place of `null`, the read under `is string`'s else | the same invalid wasm | no |
