Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    let f = inc0
    f = half
    print(f(3))
    // master: vl check rc 0, vl run: wasm trap: indirect call type mismatch.  now: cannot write 'half' to 'f': called at (i32) it returns f64, where 'inc0', also written to it, returns i32

#### Mechanism

The binding's type is `inc0`'s signature, `(_) => _`, and a call through it was typed by
`inc0`'s body alone, so `half`'s `f64` was never compared. The annotated spelling (`a: i32` on
both) is refused by the checker, `cannot assign (i32) => f64 to (i32) => i32`, and the
checker owed this one too. `holeLetWritesDisagree` reads every function written to the `let`
(`holeFnArgDecls` over `cwFnValueTargets`, D9001) at the closed parameter types the binding is
called at, and refuses at the write whose body gives another result than the one written
first. It runs at each place those types are known: a direct call, a function-typed
destination, a generic's arrow parameter, and `.map`. A parameter's set is not judged, since
each call of its function instances its own copy; nor a `let` written through one.
