### D9003 — a `let` seeded with an un-annotated `i32` function accepts a write of one widening to `f64`, and the call traps

**loads then traps · `vl check` rc 0 · `wasm trap: indirect call type mismatch` · clause 1 · found closing [D9001](D9001.md) · present on master `f0249c64f` · filed 2026-10-21 against master `f0249c64f`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    let f = inc0
    f = half
    print(f(3))
    // vl check rc 0.  vl run: wasm trap: indirect call type mismatch

#### Mechanism

Not traced. The annotated spelling (`a: i32` on both) is refused by the checker,
`cannot assign (i32) => f64 to (i32) => i32`, so the write is ill-typed and the checker owes
the refusal here too: the binding's type is `(_) => _` and the write is compared against it
without reading `half`'s body at the parameter `inc0` was called at. Same family as
[D8160](D8160.md), which closed the annotated-destination spelling. Handed to a generic
(`ap(f, 3)`, `[3].map(f)`), the same binding is refused loudly at emit since D9001.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the write `f = half` | runs, `4` | **yes** |
| the widening (`dbl(a) { return a * 2 }` for `half`) | runs, `6` | **yes** |
| the holes (`a: i32` on both) | loud check reject | **yes** |
| result annotations (`inc0(a): i32`, `half(a): f64`) | loud check reject | **yes** |
| the straight-line write, for `if [1].length > 0 { f = half }` | same trap | no |

#### Grading list

`ap(f, 3)` with `ap<T, R>(k: (a: T) => R, x: T): R` and `[3].map(f)[0]` over the same binding,
both loud emit refusals today; `const s: string = ap(f, 3)`.
