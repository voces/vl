### D2950 — an `is` test over a union with a type-parameter member is refused as a widening edge

**closed 2026-09-28 · was a loud check reject, clause 2, on master `e9fdc10d9` · found by the CK lane's body-operation probes · fixture `tests/cases/generics/is-test-over-type-param-union.vl`**

Repro:

    function h0<T>(a: T, c: boolean) {
      const r: T | i32 = if c { a } else { 5 }
      if r is string { print("str") } else { print("other") }
    }
    h0("s", true)
    h0("s", false)

Want:

    str
    other

#### Mechanism

`isWidenNotVariant` refuses `x is P` for a primitive `P` that `assignable` admits into a union
through a widening edge rather than as a member. It scans the members for `P` and, finding
none, calls the route a widening. A type-parameter member is assignable from anything inside
the body, so `string` into `T | i32` was admitted through `T` and then reported as a widening.
Closed by counting a type-parameter member as one that may be `P` at a pin. The pin's own
`is` lowering then decides the test.
