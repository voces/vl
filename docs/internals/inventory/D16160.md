### D16160 — a bound list of records whose function field holds un-annotated functions returning different types, handed to an un-annotated parameter, passes `vl check` and is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · the bound twin of [D15802](D15802.md), whose inline literal is refused at check · open · found ablating D15801 · filed 2026-11-14 against master `5a7960cd3`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function take(v) { print(v[1].f(3)) }
    const l = [{ f: inc0 }, { f: half }]
    take(l)
    // vl check: rc 0.  vl run: emit error, "emitProgram: cannot take the generic function `inc0` as a value — a function value carries ONE signature, …"

Want:

    1.5

#### Mechanism

`l` is a planned holder (`ftHoldKind` 6: a list of records whose field carries the set), and a
read of it in place dispatches. The hand-off to `take`'s open parameter does not carry the set: the
call `v[1].f(3)` inside `take`'s instance pins neither `inc0` nor `half`, so both reach the
value floor (`genericFnValueRejectMsg`, emit_mono.vl) unpinned. It is the container twin of
[D16009](D16009.md), a re-pointed `let` handed to an open parameter, which dispatches.
