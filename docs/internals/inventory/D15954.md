#### Mechanism

`repStructRowByShape` resolves a record with no row of its own through `wholeShapeRowOf`, the
first whole-shape row of the same field names whose type equals it. That equality was
`tyEqSoftLits`, which softens the arm's `"a"` to `string`, so `{tag: string, v: i32}` took the
arm's row. The arm's row stores `tag` as the atom (`repFieldLitAsSet`), the record stores a
string, and the struct.new fed a string to an i32 field. The canon key keeps the two apart.
