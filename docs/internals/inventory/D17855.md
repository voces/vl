### D17855 — a holder's storage is closed in two places, `elabHolderStorageTy` and mono's `monoStoredSlotFnTy`, which cannot merge yet

**runs today and must keep running · refactor target · filed 2026-11-28 by COV-CLOS-3 (coordinator ruling: one storage close; the move is blocked, see below)**

Repro:

    function dbl(a: f64): f64 { return a * 2.0 }
    const g = (a) => a + 1
    const m = Map()
    m["a"] = g
    m["b"] = dbl
    function walk(mm) {
      const v = mm["a"]
      if v != null { print(v(3)) }
    }
    walk(m)

Want:

    4

#### Mechanism

Two functions close a holder's storage from its stored values. `elabHolderStorageTy` (emit_elab)
answers a `const` map whose function values agree on one closed signature, and elab keys a hole
parameter by it (D17813). `monoStoredSlotFnTy` (emit_mono) answers every other holder (lists,
records, `let` holders, map value lists) from the slot's pins, its elaboration delivery and the
values' own results. They never both answer one holder: mono asserts it (`a holder the
elaboration closes is closed again`), and the repro above exercises the elab side.

The mono close cannot move into elab, as the ruling wanted, for two reasons:

1. The flow rewrite's repointing runs after the elaboration (`elabRun`, then `mfrLitsRun`,
   emit_sections), and a slot pinned twice is decided by leaving out the calls it repointed
   (`mfrSetCalls`, `mfrRepointed`).
2. Pins are told apart by their spelling (`pinSigOf`, `PIN_DECLINE`, emit_sig_tokens), and
   emit_sig_tokens imports emit_elab, so emit_elab cannot import it. Comparing pins by type
   instead is not provably the same: a spelling folds distinct arena entries.

A shape with only the branch rules in elab and every fact computed in mono was considered and
refused (coordinator ruling): it moves branch logic, not the close, so the drift risk stays.

#### What unblocks it

- moving the flow rewrite's repoint decision before, or into, the elaboration; and
- splitting pin spelling out of emit_sig_tokens into a module emit_elab can import.

Either one alone is not enough: the first unblocks the two-pin case, the second the comparison.
Step-2 / S-series work.
