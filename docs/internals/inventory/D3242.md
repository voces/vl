### D3242 — an uninitialized record `let` assigned in both arms of an `if` is check-clean invalid wasm

**check-clean invalid wasm · filed 2026-09-29 against master `fc1e91d24`**

Repro:

    type Circle = { r: i32 }
    function g(n: i32) {
      let c: Circle
      if n > 2 { c = { r: n } } else { c = { r: 0 } }
      c.r
    }
    print(g(4))
    // vl check: rc 0.  vl run: invalid module, uninitialized local

Want:

    4

#### Mechanism

The binding's wasm local is the non-null `(ref $Circle)`, and wasm counts a non-defaultable
local as set only until the end of the block that set it. Both assignments are inside the
`if`'s frames, so the read after the `if` validates against an unset local. The checker's
definite assignment is right that `c` is assigned; the emitter needs a nullable local read
through `ref.as_non_null`, or the value carried out of the `if`. Found building loop values
(the follow-up to #3293).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the record type (`let c: i32`) | runs | **yes** |
| the `if` (`c = { r: n }` at the function's top level) | runs | **yes** |
