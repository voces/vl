### D16219 — a wider row reaches a declared record parameter only from a direct or member call, not through a forwarding generic, a lambda or a declared return

**loud check reject · clause 2 · `an object value of shape … flowing into P drops the field …` · 6 cells of `record-param-width-before`/`-between` each · found by lane I in L3 PR A · filed 2026-11-15 against master `3d526470a`**

Repro:

    type P = { name: string }
    function show(p: P) { print(p.name) }
    function fwd<T>(t: T) { show(t) }
    const v = { age: 3, name: "a" }
    fwd(v)
    // vl check: rc 1, the field-dropping refusal at `show(t)`

Want:

    a

#### Mechanism

The record-width rewrite notes a parameter as a candidate where a call's argument is checked
(`callFtyArgAssign`) or a member call's receiver is (`ufcsCheckRecvSeam`). A call inside a
generic body is re-asked at the pin (`validateArgCstrs`), which runs before the width phase and
whose constraint row carries the callee's name but not the parameter's position, so it refuses
instead of noting. A lambda is no named declaration the rewrite can respell, and a declared
`: P` return refuses the wide instance's `W` to `P`, which undoes the rewrite.

#### Ablation

| position | outcome |
| --- | --- |
| a direct call, a member call's receiver, an inferred return | runs |
| a forwarding generic (`generic_fwd`, both faces), a forwarding hole (`hole_fwd`) | loud check reject |
| a lambda's record parameter (`lambda_param`) | loud check reject |
| a declared `: P` return of the parameter (`returned`) | loud check reject |

#### Grading list

`record-param-width-{before,between,after}.matrix.vl`: `generic_fwd`, `hole_fwd`, `lambda_param`,
`returned`. `nested_field` is the storage half (a record field holding the wider row).
