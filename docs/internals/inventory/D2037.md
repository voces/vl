### D2037 — a generic function whose inferred return is `T | null` through a fall-through fails validation at its caller

**closed — a generic instance whose template's checked signature returns a concrete `T | null` is pinned to that return, as its own annotation would pin it (`emit_mono.vl`, beside the D1521 union pin); every return-expression rung named only the value arms and missed the fall-through `null` · was check-clean invalid wasm (`vl check` rc 0, then rc 70, the emitted module fails to validate in the module's top-level code, clause 1) · closed 2026-09-22 with the D1995 else-less-arm ruling · filed 2026-09-22 against master `a590f3b0f`, found reviewing #3028 (D1995)**

Repro (runs, prints `1` then `null`):

    function g<T>(c: boolean, x: T) { if c { return 1 } ; if c { 2 } }
    print(g(true, 3))
    print(g(false, 3))
    // vl check: rc 0.  vl run: rc 70, invalid module (type mismatch at the call)

#### Mechanism

Not ablated yet; this is a prediction. An un-annotated generic whose body can fall off the end
infers a nullable return (`i32 | null` here), and the monomorphized instance and its caller
disagree about that nullable's rep, so the call's result does not validate where it is
consumed. The same body without the type parameter runs. `function F<T>(c: boolean, t: T) { if
c { return 5 } }` shows the statement face of the same family: it traps `unreachable`, and
`print(F(true, 1))` is an emit refusal (`narrowed union atom has no value box`).

#### Grading list

A value arm beside a void-call arm reaches this family through [D1995](D1995.md)'s close. On
master it was a check refusal (`print expects a value, got i32 | void`); with #3028 it is
check-clean and fails validation here. No run is lost, but it is a loud-to-silent move:

    function v() { return }
    function g<T>(c: boolean, x: T) { if c { return 1 } ; if c { 2 } else { v() } }
    print(g(true, "a"))
    print(g(false, 3))

And the `print(0)`-arm spelling, bound instead of printed (invalid wasm on master already):

    function g<T>(c: boolean, x: T) { if c { return 1 } ; if c { 2 } else { print(0) } }
    const a = g(true, 3)
    print(9)
