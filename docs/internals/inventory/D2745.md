### D2745 — the return-set join cannot see a `return` inside a loop, a bare block or an `else if` chain, nor any return of a generic function at its pin

**closed 2026-09-26 — the repro RUNS and prints `0.5` · was check-clean invalid wasm · 40 loop cells of the #3204 review's `a/` grid, 336 cells of the lane's return-form grid (loops, bare block, `else if` chain, `match` arm, and the generic face where the returns join to one list) · filed 2026-09-26 against master `92bed043d`**

Repro:

    function f(c: boolean) {
      let i = 0
      while i < 3 {
        if c && i == 1 { return [2] }
        i = i + 1
      }
      return [1.5, 2]
    }
    print(f(true)[0] / 4.0)

#### Mechanism

D2716 builds a disagreeing return set at the checker's joined list type, and decides that the
returns disagree from `a20CollectRets`. That walk read only a body's top-level statements and
the arms of an `if` there: a `return` inside a `while`, `for`, bare block, `match` arm or the
`else` of an `else if` was never collected, so a set whose one disagreeing return sat in a loop
read as agreeing, nothing was banked, and the `[2]` return was built at the `[1.5, 2]` result's
`f64` list as an `i32` list. The walk also read the last statement of a NON-tail `if`'s arm as
a returned value. A generic function was excluded from the banking outright, and its instance's
return annotation was minted from one return (`monoRetJoinDisagrees` then declined it), so a
generic function whose disagreeing list returns join to one list (`[t]` beside `[1.5]` at
`T := i32`) was invalid wasm in every return form. Closed by one
walk (`a20RetWalk`): every valued `return` at any depth but a nested function's, plus the tail
values of tail position only; `monoRetJoinDisagrees` reads the same walk
(`collectValuedReturns`); and an instance whose returns disagree and join to a list takes that
list as its return annotation (`monoInferRetSetListTy`). Where the returns join to two list
types at the pin (`[t]` beside `[1]` at `T := boolean`), the instance is refused at the call
([D2766](D2766.md)): master read the loop-hidden return as the other list and ran.

#### Ablation

| the element kind (`["s"]` beside `[1, "t"]`, `[[1]]` beside `[[1.5]]`, a record list) | invalid wasm | no |
| the loop, in a generic function `f<T>(c: boolean, _t: T)` | invalid wasm | no — same family |
