### D14871 — a list of bare record literals narrower than a union arm has no interned element shape

**loud emit reject · `vl check` rc 0 · clause 2 · `emitProgram: ref valtype with no interned shape` (positionless) · pre-existing, the same on master `d40331563` · the list face of [D14870](D14870.md) · filed 2026-11-01 against master `d40331563`**

Repro:

    type Circle = { r: i32 | null }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    const xs = [{ r: null }]
    print(xs.length)

Want:

    1

#### Mechanism

The list's element type is the literal's own `{ r: null }`, narrower than the arm `Circle`, and no
destination adopts it. The element literal's layout is picked by field set and lands on the arm,
so no struct row of the element type is minted, and the list's ref-array type needs one. With no
union in the program the element mints its own row and the program runs. The same literal bound
alone is D14870, refused at the field read instead.
