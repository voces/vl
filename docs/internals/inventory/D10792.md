#### Mechanism

D10701's close serves a second call type with a `const` copy of the list literal
(`fsPlanLists`, fn_split.vl). A copy made at the declaration does not see the `push`, so a list
read any way other than as a `for` iterable, a called element, its `.length` or an alias's value
declines. A choice element whose condition calls a function declines too, because the copy
would run the call again. Either needs the list to hold an instance per call type in place.
