### D16986 — an empty `Map()` handed to a generic takes the hole default's `string` key, so an `is {[i32]: V}` arm writes a map it never reads back

**check-clean silently wrong · clause 1 · census row 13 of the no-default ruling (DECISIONS.md §"No default type") · filed 2026-11-18 against master `8c0843c69` by lane F1**

Repro:

    function f<T>(x: T) {
      if x is {[i32]: f64} { x[1] = 2.5; return x.length }
      return 0
    }
    print(f(Map()))
    // PRINTS 0

Want:

    1

#### Mechanism

`elabHoleContainerClosed` (`emit_elab.vl`) closes an empty container handed to a bare type
parameter at fixed defaults: a list element `i32`, a map key or set element `string`, a map value
`i32`. `T` is therefore `{[string]: i32}`, and the arm's `is {[i32]: f64}` answers by the
empty value (D4910), handing the arm a fresh map of the tested type that the receiver never reads
back. Under the ruling the arm's write is the use that fixes `T` as `{[i32]: f64}`.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `is {[string]: i32}`, the defaults' own type | runs, prints `1` | **yes** (a type other than the default) |
| the map passed from a binding typed `{[i32]: f64}` | runs, prints `1` | **yes** (the empty literal) |
| a list, `is f64[]` with a push, over `f([])` | runs, prints `1` | **yes** (a map: a list's `is` arm is read back, D4934) |
