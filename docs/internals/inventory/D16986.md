**closed 2026-11-18 — the witness prints `1` · was check-clean silently wrong, clause 1 · a call whose type parameter binds only an empty container pins that argument at the type the generic's `is K` arm writes the parameter at (`callArmWritePinOpen`, `compiler/check_calls.vl`, over `tpArmWriteTy`), so the caller's map is built as `{[i32]: f64}` and the elaboration's hole default never sees it open; a caller write that disagrees is refused at check · fixture `tests/cases/generics/empty-map-argument-typed-by-the-is-arm-that-writes-it.vl`, with `error-empty-map-argument-written-another-way-by-the-caller.vl` · census row 13 of the no-default ruling (DECISIONS.md §"No default type") · filed 2026-11-18 against master `8c0843c69` by lane F1**

#### Mechanism

`elabHoleContainerClosed` (`emit_elab.vl`) closes an empty container handed to a bare type
parameter at fixed defaults: a list element `i32`, a map key or set element `string`, a map value
`i32`. `T` is therefore `{[string]: i32}`, and the arm's `is {[i32]: f64}` answers by the
empty value (D4910), handing the arm a fresh map of the tested type that the receiver never reads
back. Under the ruling the arm's write is the use that fixes `T` as `{[i32]: f64}`.
