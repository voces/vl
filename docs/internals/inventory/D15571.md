#### Mechanism

`a.h` as `i32`, but the field read's receiver node carries the parameter's hole type, and the emit
path that lowers a read off a union box takes that node type rather than the instance's, so it
finds no struct row. The per-instance node-type gap of `docs/internals/mono-pin-survey-2026-11.md`
group A.
