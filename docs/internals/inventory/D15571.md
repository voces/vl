### D15571 — a field read off a union of records, through an un-annotated parameter, is refused at emit

**loud emit reject · clause 2 · `vl check` rc 0, then `emitProgram: field access receiver is not a struct` · the annotated parameter runs · the witness of `INSTANCE_WITNESS` in `tests/vl_emit_diag_position_test.ts` · found replacing [D15568](D15568.md) there · filed 2026-11-08 against master `c755cb319`**

Repro:

    type K = { h: i32 }
    type J = { h: i32, z: i32 }
    const k: K = { h: 4 }
    const u: K | J = k
    function take(a) { print(a.h) }
    take(u)
    // vl check: rc 0.  vl run: emitProgram: field access receiver is not a struct

Want:

    4

#### Mechanism

[D15315](D15315.md)'s gap without its nesting. In the instance pinned at `K | J` the checker types
`a.h` as `i32`, but the field read's receiver node carries the parameter's hole type, and the emit
path that lowers a read off a union box takes that node type rather than the instance's, so it
finds no struct row. The per-instance node-type gap of `docs/internals/mono-pin-survey-2026-11.md`
group A.

| the read bound first (`const n = a.h`) | still refuses | no |
