### D7900 — a declared record return holding `T` beside inline literals, or a `T` pinned to a union, has no interned shape

**closed · was loud emit reject, clause 2 · the residue of [D7040](D7040.md)'s close · filed 2026-10-20 against master `6d9597a6e` · closed by lane L6 against master `981320f30`**

Repro:

    function r<T>(x: T): { v: T | "a" | "b" } { return { v: x } }
    print(r(3).v)
    // vl check: rc 0.  vl run: emitProgram: ref valtype with no interned shape

Want:

    3

#### Mechanism

`monoMakeInstanceRetAnn` (emit_mono.vl) keyed the instance's record result by its substituted
annotation text, which keeps the inline literals (`i32 | "a" | "b"`) and the pinned member
order (`i32 | null | K`). `registerTyReachUnions` registers the field unions under the arena
emit name, which softens the literals beside a non-literal member and reorders the members
(`i32 | string`, `i32 | K | null`). The struct shape intern then found no union for the field
text, so the record had no struct slot and `fbValtype` read a struct with slot -1. The close
keys a record-shaped instance result by `arenaEmitName` of its arena type, the key its field
unions register under.
