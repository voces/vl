### D7900 — a declared record return holding `T` beside inline literals, or a `T` pinned to a union, has no interned shape

**open · loud emit reject · clause 2 · the residue of [D7040](D7040.md)'s close · present on master `6d9597a6e` · filed 2026-10-20 against master `6d9597a6e`**

Repro:

    function r<T>(x: T): { v: T | "a" | "b" } { return { v: x } }
    print(r(3).v)
    // vl check: rc 0.  vl run: emitProgram: ref valtype with no interned shape

#### Mechanism

Not traced. D7040's close registers the unions the instance's declared result reaches, and the
aliased spelling `{ v: T | K }` now builds. The inline spelling does not, so the pinned field
type the shape intern asks for is presumably not the arena type the walk registered. A `T`
pinned to a nullable or a union (`T := i32 | null` beside `K`) refuses the same way, and so
does `T := L | null` beside `i32`.
