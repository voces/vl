### D5663 — a function returning a generic, read as a value beside two results called at two types, is refused

**loud emit reject · `vl check` rc 0 · clause 2 · found closing [D5531](D5531.md) · filed 2026-10-17 against master `a9ede7d84`**

Repro:

    function k<T>(x: T): T { return x }
    function mk() { return k }
    function main() {
      const a = mk()
      print(a(1))
      const b = mk()
      print(b("s"))
      const h: () => (x: i32) => i32 = mk
      print(h()(3))
    }
    main()
    // vl check: rc 0.  vl run: emitProgram: a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type

Want:

    1
    s
    3

#### Mechanism

From the ablation only. Without the value read `h = mk` this is D5531 and runs. Written by
hand with a copy `mk2` for `b`, it runs too. D5531's close declines a function that is also
read as a value: with the copy inserted, the build refuses `main` with "a function-value
call has no interned signature".
