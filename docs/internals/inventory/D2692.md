Repro:

    function take(m: {[string]: boolean | null}) { m.length }
    const a: {[string]: boolean} = Map()
    const u: {[string]: boolean} | {[string]: boolean | null} = a
    print(take(u))
    // vl check: rc 0.  vl run: invalid module in the top-level code, "type mismatch: expected (ref $type)…"

#### Mechanism

The checker accepts the union as the parameter's type because each member is
assignable to it (the two maps share one storage), but the argument is the union box and the
parameter is the bare map struct; no unbox is emitted at the call. The same program with the
join spelled un-annotated (`if c { a } else { b }`) collapses to the wider map and runs.
Measured at every delivery position, not only the argument: a binding, a return, a list, record
or map-value slot and a closure capture all built the same invalid wasm.

The close records the delivery where the checker accepts it (`recordMapUnbox`, at
`assignableExpr`'s seam, walking list and record literals to their elements and fields): a union
whose members are all maps, delivered as one map or its nullable. The emitter then emits the box
and casts its payload to that map's struct (`emitMapUnionPayload`), and `exprMap` and
`mapShapeOfExpr` read the node as that map, so a captured binding's cell takes the map's type. A
member of another struct is refused at emit rather than cast.
