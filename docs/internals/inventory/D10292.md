### D10292 — a generic's un-annotated binding of a map read at a scalar pin drops the miss's `null`

**check-clean silently wrong · clause 1 · found closing [D10291](D10291.md) · present on master `d5ec7f160` · filed 2026-10-22 against master `d5ec7f160`**

Repro:

    function g<V>(m: Map<string, V>, k: string) {
      const x = m.get(k)
      print(x)
    }
    const mm: Map<string, i32> = Map()
    mm.set("k", 5)
    g(mm, "z")
    // PRINTS 0

Want:

    null

#### Mechanism

The binding is typed `V | null`, and at `V = i32` the instance gives it the read's unboxed
`i32` rep, where a miss is `0`. The null is lost at the binding: the direct `print(m.get(k))`
prints `null`, and the annotated `const x: V | null` keeps it.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `m: Map<string, i32>`, no type parameter | prints `null` | **yes** |
| `const x: V \| null` | prints `null` | **yes** (the inferred binding) |
| `print(m.get(k))`, no binding | prints `null` | **yes** |
| `print(x != null)` for `print(x)` | refuses: bare null needs a struct-typed context | no |
| `print(x ?? d)` with `d: V` | refuses: `??` over this nullable value is not supported yet | no |
