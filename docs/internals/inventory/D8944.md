### D8944 — an un-annotated function handed to `.map` over a list is refused at emit

**loud emit reject · clause 2, present on master `30ff8d9b5` · filed 2026-10-21 against master `30ff8d9b5`**

Repro:

    function inc(a) { return a + 1 }
    const r = [3].map(inc)[0]
    print(r)
    // vl run: emitProgram: index receiver is not an array or string

#### Mechanism

Not traced; the refusal is emit-side, outside lane L1. The checker accepts the call.
Without the index, `const ys = [3].map(inc)` with `print(ys.length)` refuses as
"cannot take the generic function `inc` as a value". So the handed hole function is never
instanced at the list's element type, and the result's list type is never collected.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `a: i32` on `inc` | runs, `4` | **yes** |
| the `[0]` index (`print(ys.length)`) | emit refuses, another message | no |
| a widening body (`a / 2.0` for `a + 1`) | same emit refusal | no |

#### Grading list

`const r: i32 = [3].map(half)[0]` with `half(a) { return a / 2.0 }`: the same emit
refusal, which the checker owes as `f64 doesn't fit in i32`.
