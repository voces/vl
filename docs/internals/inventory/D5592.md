#### Mechanism

`foeActs` is un-annotated, so it is inferred before `foeName`'s body is typed. The may-write
query then finds `fs[k]` with no receiver type, falls back to every declared index operator
(std:buffer's `F32View`/`I32View`, present only when some module imports std:buffer), and
`fnWriteShapes` CACHED that answer as settled, because an operator site never counted as
unresolved. The cached `*` then served the later, typed query. An index site whose receiver is
untyped now counts in `weUnres`, so the summary is recomputed once the body is typed. Which
file is the entry mattered only through which modules the graph holds: `vl test` and `vl
check` share one check path, and the test's graph lacked std:buffer.
