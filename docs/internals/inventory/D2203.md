### D2203 — an empty `[]` delivered to an `S[] | S` union emits a module that fails to validate

**check-clean invalid wasm · found beside D2201 · filed 2026-09-23 against master `66e74235a`**

Repro:

    type B = { base: i32, length: i32 }
    function sink(data: B[] | B): i32 {
      if data is B { return 1000 }
      return data.length
    }
    print(sink([]))
    // vl check: rc 0.  vl run: invalid module, `expected (ref $type), found (ref $type)`

#### Mechanism

D2201's shape with a struct element: the empty literal is built as the i32 list where the
`B[]` arm's ref list is expected. Fails at all five delivery positions (argument, annotated
binding, return, assignment, struct field).
