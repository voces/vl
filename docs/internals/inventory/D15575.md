### D15575 — a type-parameter parameter handed a generic and passed on to a generic's function parameter at two types is refused at emit

**loud emit reject · clause 2 · `vl check` rc 0, then `emitProgram: monomorphize: parameter `a` of `take` is called at two function types that no parameter per type separates` · the annotated twin of [D10382](D10382.md), which runs · found closing D10382 · filed 2026-11-08 against master `4a1d010d`**

Repro:

    function id<T>(x: T): T { x }
    function run<U>(f: (x: U) => U, u: U): U { f(u) }
    function take<A>(a: A) {
      print(run(a, 2) + run(a, "ab").length)
    }
    take(id)
    // vl check: rc 0.  vl run: emitProgram: monomorphize: parameter `a` of `take` is called at two function types that no parameter per type separates

Want:

    4

#### Mechanism

Not traced. The un-annotated spelling `take(a)` runs since D10382: mono reads `a`'s instance
binding as the set `{id}` and binds `run`'s `U` from the value arguments
(`monoArgIsHeldGeneric`). Here `a` is bound to the type parameter `A`, and the instance pins
`A` at one function type before either call of `run` is reached.
