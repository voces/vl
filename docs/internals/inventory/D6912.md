### D6912 — a hole function whose default instance builds, handed to a parameter that only aliases or returns it, is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same callee handed `apply3`, which calls its own hole parameter, runs, `2` ([D6881](D6881.md)); `run(f) { print(2) }` handed `inc` runs · found closing [D6881](D6881.md) · the same on master `43f22053c` · filed 2026-10-19 against master `43f22053c`**

Repro:

    function inc(x) { x + 1 }
    function run(f) {
      const k = f
      print(2)
    }
    run(inc)
    // vl check: rc 0.  vl run: emitProgram: cannot take the generic function `inc` as a value — a function value carries ONE signature

Want:

    2

#### Mechanism

From the ablation only. The inert-parameter stub is offered only to a hole function whose
default instance cannot build. `inc` takes the default-instance path instead, which instances
`run` at `inc`'s default signature, and the alias inside `run` is then a value of a function no
call pins.
