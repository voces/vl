#### Mechanism

From the ablation only. The inert-parameter stub is offered only to a hole function whose
default instance cannot build. `inc` takes the default-instance path instead, which instances
`run` at `inc`'s default signature, and the alias inside `run` is then a value of a function no
call pins.
