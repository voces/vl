### D14640 — an instance's elaboration types a join over a literal type argument at the literal, where mono widens the argument

**closed 2026-11-01 · runs, prints the Want · the floor in `nullOwnAt` that kept the destination's seed is deleted: an instance-stamped `null` takes the null its closed instance contextual type names · was a named floor, no wrong value · filed 2026-10-28 against master `add376795`**

Repro:

    type K = "a" | "b"
    function n<T, U>(a: T, b: U, k: i32) {
      const r = if k == 0 { a } else if k == 1 { b } else { null }
      return r
    }
    const y: K = "a"
    print(n("x", y, 0))
    print(n("x", y, 2))

Want:

    x
    null

#### Mechanism

The call binds `T = string` (mono widens `"x"`) and `U = K`, and stores `r` as a `string | null`
ref. The `else if` chain nests, so the `null` leaf belongs to the inner join
`if k == 1 { b } else { null }`. The instance's elaboration stamps the leaf with that join's
type, `"a" | "b" | null`, the atom niche, and lowered from that stamp the arm is the i32 `-1`
where the outer block wants a ref. (The filed reading, a literal `T`, was not what a probe of
the stamp showed: it holds no `"x"`.) `nullOwnAt` kept the destination's seed wherever an
instance stamp and the seed disagreed. Now, where the instance stamped the node, the instance's
own contextual type (`ctxTyAt`, here `string | null`) names the null when it is closed.
