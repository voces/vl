### D16338 — `?.` on an un-annotated parameter handed `null` is refused at check, as if `?.` were `.`

**loud check reject · clause 2 · open · `member access '?.f' on non-object null (the body of `take` at the call's argument types)` · beside [D16333](D16333.md) · found grading D16333's close · filed 2026-11-15 against master `417397629`**

Repro:

    function take(a) { print(a?.f ?? 0) }
    take({ f: 3 })
    take(null)
    // vl check: member access '?.f' on non-object null

Want:

    3
    0

#### Mechanism

`take`'s body is checked at each call's argument types, and at `null` the `?.` read is refused as
a member access on `null`. The point of `?.` is that a `null` receiver yields `null`. Not traced
further; from the witness. The annotated parameter `a: { f: i32 } | null` runs.
