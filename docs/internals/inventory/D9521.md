### D9521 — `??` over the call of an un-annotated parameter bound at a function returning a numeric literal union is refused at emit

**closed 2026-10-22 by lane-D952x · the filed repro RUNS and prints `42` · was loud emit reject · clause 2 · the instance's `??` reads an operand typed `N` against a `??` pinned at `i32`; `coalRetypedDead` (emit_classify.vl) now counts a non-null numeric literal operand whose scalar base is the pin as a dead default, the fold the template makes of a concrete `i32` · the `i32 | N` two-instance spelling (`take(() => a); take(() => 7)`) runs too · fixture `literal-unions/coalesce-hole-call-retyped-dead.vl` · matrix `fn-value-lambda-num-litunion-as-nullable` argument (un-annotated) cell emit refuses → RUNS · residue [D9561](D9561.md) (a mixed-width union), [D9562](D9562.md) (an `f64` default) · found closing [D9491](D9491.md) · filed 2026-10-22 against master `0be192a3f`**

Repro:

    type N = 1 | 2
    const a: N = 2
    const h = () => a
    function take(f) {
      print((f() ?? 0) + 40)
    }
    take(h)
    // vl run: 42

#### Mechanism

The rewrite folds `??` over a non-nullable operand on the TEMPLATE, which an un-annotated
parameter's instance shares, so the instance must fold its own. The emitter's per-instance fold
required the operand's instance type to equal the `??`'s pin. At `() => N` the operand is `N`
and the pin is `i32`, so the fold declined and the nullable-value arm refused. `N` reps as its
scalar, so the two agree on the wasm type and the default is dead. This is the numeric spelling
of [D9522](D9522.md); both are decided by the one helper.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the numeric union (`take(() => 2)`) | runs | **yes** |
| the un-annotated parameter (`f: () => N`) | runs | **yes** |
| the call (`take(x)` with `x ?? 0`, `x` bound at `N`) | runs | **yes** |
| the `const h` (`take(() => a)` inline) | same refusal | no |
