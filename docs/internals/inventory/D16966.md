### D16966 — an `as` cast to one member of a twin-list union has no lowering, since the union is stored as its one list with no tag to test

**loud emit reject · clause 2 · found closing [D16963](D16963.md) · filed 2026-11-18 against master `906520a5d` by lane F1**

Repro:

    type K = 1 | 2
    const q: i32[] | K[] = [5, 2]
    const r = q as! i32[]
    print(r[0])
    // vl run: emitProgram: `as i32[]` needs a BOXED union operand or a nullable-REF one; this `| null` is a value niche whose null is a spare scalar, with neither a tag nor a ref to test

#### Mechanism

`i32[] | K[]` over a numeric literal union `K` is stored as its one list (`oneListUnionRender`,
D4743): no box and no tag, so the cast's member test has nothing to read. The emitter's sentence
then names a `| null` niche the program does not have. An `is i32[]` test on the same value runs
(`if q is i32[] { print(q[0]) }` prints `5`), so the cast could take that test's answer.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `as! K[]`, the other member | the same reject | no |
| `as? i32[]` | the same reject | no |
| `i32[] \| string[]`, not twins | runs, prints `5` | **yes** (twins) |
| `if q is i32[] { print(q[0]) }` | runs, prints `5` | **yes** (the cast) |
