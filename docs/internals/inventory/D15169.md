### D15169 — a record whose list field is written a function of another result type inside a function and returned is refused at check

**loud check reject · `cannot write 'half' to an element of 'r.xs'` · clause 2 · open, target `1.5` · found closing [D15138](D15138.md): the same record at the reading scope runs · filed 2026-11-03 against master `d467911e`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function mk() { const r = { xs: [inc0] }
     r.xs[0] = half
     return r }
    const r = mk()
    print(r.xs[0](3))
    // Want: 1.5

#### Mechanism

`holeSlotJudge` reads a binding initialised by a call through the call's returned values (`holeSlotRetJudge`), and that path does not take the lift D15138 gives a record whose field `elabFnFieldListTy` widened. [D15162](D15162.md) is the map spelling.
