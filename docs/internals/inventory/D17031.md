### D17031 — an `is` test the receiver's nullable niche cannot hold drops the receiver's effects

**check-clean silently wrong · clause 1 · found writing IR-REV's effectful-receiver witness for the IR's `nicheNever` arm · present on master `a42095870` · filed 2026-11-20 against master `a42095870`**

Repro:

    type A = { v: i32 }
    type C = { v: i32, s: string }
    let n = 0
    function mk(): A | null {
      n = n + 1
      return { v: 1 }
    }
    print(mk() is C)
    print(n)
    // today: false then 0 — `mk` is never called

Want:

    false
    1

#### Mechanism

`mk() is C` over the niche `A | null` takes `litIsArmOf`'s `nicheNever` arm, which
`emitIsTestLitArms` writes as `i32.const 0` alone: the test cannot hold, and the receiver is never
evaluated, so its call and the write it makes are gone. The null test's own dead form
(`emitDeadNullTest`) evaluates its operand for its effects and drops it.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `mk() is A` (a test the niche can hold, `nicheTest`) | runs, `true` then `1` | **yes**, the never arm |
| the call bound first (`const r = mk()`, `r is C`) | runs, `false` then `1` | **yes**, an effectful receiver |
| `mk() == null` | runs, `false` then `1` | **yes**, the `is` form |
