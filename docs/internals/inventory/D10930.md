#### Mechanism

inline record, and the list rung finds no struct row for it. Every neighbour that names the
inner record, drops the nesting, or reaches the list without the type parameter runs, so the
missing step is interning the substituted inline shape of an alias application's field. The
interning lives in `compiler/emit_shape_intern.vl`, which another lane was editing when this
was filed.
