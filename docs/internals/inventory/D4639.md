### D4639 — an `if` expression of union-arm record literals assigned to an inferred arm cell joins at an i32 blocktype

**check-clean invalid wasm · clause 1 · found closing [D4613](D4613.md), and present before it · filed 2026-10-14 against master `536c4c79e`**

Repro:

    type U = { q: i32 } | { r: i32 }
    function f(c: boolean) {
      let v = { q: 4 }
      v = if c { { q: 5 } } else { { q: 6 } }
      print(v.q)
    }
    f(true)
    // vl check: rc 0.  vl run: type mismatch: expected i32, found (ref $type)

Want:

    5

#### Mechanism

Not localised past the ablation. The cell is a `variant` (the literal is an anonymous arm of
`U`), and the `if` expression's arms are arm literals, but the assignment emits the `if` with
the scalar default blocktype, so each arm's struct ref lands in an `i32` block. D4613's close
seeds the arm cell's variant index only for an object-literal right-hand side.
