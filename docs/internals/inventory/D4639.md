#### Mechanism

The cell is a `variant` (the literal is an anonymous arm of `U`, which has a variant row and no
plain struct row). D4613's close seeded the arm's variant index into the expression context for
an object-literal right-hand side only. An `if` value under that seed built its first literal as
the bare arm, emitted the join with the scalar default blocktype, and boxed the other arm. The
same literal-only seed stood at the inferred `return`, the map-value store and the list-literal
element. Each of those now hands the value to `emitVariantCoerce`, which already lowers a join
with the arm's blocktype and coerces each arm (literal, narrowed box or bare pass-through).

The un-annotated initializer spellings were loud for a second reason: the classifier asked
`objLitVariantIdxNoStructRow` only about an object literal, so `let v = if … { {q:5} } …`
classified no cell. A value `if`/`match` now denotes the arm's row when every arm does, and a
module-scope initializer of that shape is a `variant` global.
