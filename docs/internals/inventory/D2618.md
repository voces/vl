### D2618 — an `extern` function taken as a value has no function to close over, so it is mistaken for a captured variable

**closed 2026-09-26 — the witness builds and prints `2` · was loud emit reject after `vl check`
rc 0, clause 2 · Reported by plumb (PL-042), the bug half · filed against master `e289f84d7` ·
fixtures `tests/cases/extern/value-beside-local-function.vl` and the `values` units of
`tests/vl_extern_link_test.ts`**

Repro:

    extern function nowMillis(): i64
    function h(): i64 { 2 as i64 }
    function pick(i: i32): i64 {
      const fs = [nowMillis, h]
      fs[i]()
    }
    print(pick(1))
    // plumb's program, with the extern the native host provides in place of plumb's `g1`.
    // vl check: rc 0.  vl build on master: emit error — emitProgram: captured variable not
    // found in enclosing frame

#### Mechanism

A function value is a closure over a lifted function, called with its env as the leading
argument. An extern is a row of the import table and has no `FuncDecl`, so the value path found
no function to close over; capture analysis then recorded the name as a free variable of the
enclosing function, and building `pick`'s env found no such variable. At top level the same read
refused as `identifier is not a parameter, local, or global`. The close is a pass,
`synthExternValues`, after monomorphization: each extern read other than as a callee, and not
shadowed by a binding of its frame, a module local or an enclosing module loop, gets one
capture-free forwarding function `<name>$extv(a0: P0, …): R { name(a0, …) }` built from the
link row's own signature, and the read is respelled to name it, so every classifier sees a plain
function name; the spelling carries a `$`, so no program can declare a function that takes its
place. `capRecord` treats an extern as module-level, like a function or global. The checker
notes whether any identifier naming an extern was typed other than as a callee, and the pass
does nothing when none was, so a unit that only calls its externs pays nothing for it.

On master `e289f84d7`.
