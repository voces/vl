### D16371 — a parenthesised constant arm of an `if` is not adopted at the join's wider type

**check-clean invalid wasm · `type mismatch: expected i32, found i64` · 38 of the 46 reduced programs of the oracle's arithmetic fuzz (`scripts/oracle/gen.ts`) · found by the independent oracle · filed 2026-11-14 against master `de4cfa15f`**

Repro:

    print(if true { 4294967296 } else { (1) })
    // vl check: rc 0.  vl run: invalid module, type mismatch: expected i32, found i64

Want:

    4294967296

#### Mechanism

The two arms join at i64 (T3.6: a constant arm adapts to the other arm). An unparenthesised
constant arm is adopted at that type; the same constant inside parentheses is emitted at its
default i32, so the `if` block yields an i32 where its type says i64. Parentheses must not change
a constant's type (E9.1 lists them among the spellings of a constant).
