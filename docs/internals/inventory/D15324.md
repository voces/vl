### D15324 — a literal holding a holder's record, read once through a copy and once through its place at the other signature, refuses at emit

**open · loud emit reject · clause 2 (`emitProgram: a function returning a parameter called at two signatures is called where its result is not used at one of them`) · owned by lane bundle · found closing [D15323](D15323.md) · filed 2026-11-04 against master `55102709c`**

Repro:

    function lap(f) {
      const _a = f(2.5)
      const _b = f(3)
      return f
    }
    const u = lap((a) => a + 1)
    const w = { f: u }
    const v = w.f
    print(v(4))
    print(w.f(1.5))

Want:

    5
    2.5

#### Mechanism

Measured with a probe build on the field spelling. When the slot fact is noted, `w` carries an
annotation `{f:(f64)=>f64}`, one closure type rather than the record, and the slot fact declines an
annotated binding, so neither `w`'s slot nor the holder `u` gets a fact. The producer is the
checker's record adoption: `recAdPinLet` (check_rec_rows.vl) replaces `w`'s node with one annotated
at the adopted type. A probe that logged every writer of a binding's annotation (each
`.letType =` in emit_collect, emit_mono and emit_rewrite, `mkLet`, and the two node rebuilds in
check_num_lit_state and check_rec_rows) logged that one writer for `w` and no other. The list rows
are not yet probed.

#### Ablation

| spelling | outcome |
| --- | --- |
| `{ f: lap((a) => a + 1) }` stored directly | runs |
| the copy called at both signatures, `v(4)` and `v(1.5)` | runs |
| both calls through the place, `w.f(4)` and `w.f(1.5)` | runs |
| a list, `const xs = [u]; const v = xs[0]`, then `v(4)` and `xs[0](1.5)` | the same refusal |
| the list with both calls in one interpolation, `"\{v(4)} \{xs[0](1.5)}"` | runs |
| the field with both calls in one interpolation, `"\{v(4)} \{w.f(1.5)}"` | the same refusal |
