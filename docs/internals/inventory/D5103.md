### D5103 — an un-annotated list literal of a nullable value-union call stores the box where the list expects an i32

**closed 2026-10-16 as `runs` · was `check-clean invalid wasm` (clause 1), and a loud emit reject behind `if v != null` · `refElemArrName` now groups a nullable record-union element as `(U|null)[]`, the ref list the annotated spelling interns, instead of the ungrouped `U|null[]` that fell to the `i32` list · fixture `tests/cases/unions/inferred-list-of-nullable-union-call.vl`, matrix `nullable-struct-union-call-value` 66 of 66 runs · filed 2026-10-16 against master `d6623fb7a`**

Repro:

    type U = { a: i32 } | { b: i32 }
    function sumU(n: U | null): i32 {
      if n == null { return 0 }
      if n is { b: i32 } { return n.b * 100 }
      return n.a
    }
    function mk(k: i32): U | null {
      const t: U = { a: k }
      return t
    }
    const xs = [mk(2)]
    const v = xs[0]
    print(sumU(v))
    // vl check: rc 0.  vl run: type mismatch: expected i32, found (ref $2) union box

Want:

    2

#### Mechanism

The element of `[mk(2)]` is the call's `U | null`, a boxed value union, but the inferred list
is laid out with an `i32` element, so the box is stored where an `i32` is expected. Testing the
read (`if v != null`) instead refuses loudly at emit: `bare null needs a struct-typed context`.
