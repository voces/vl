### D9010 — a re-pointed `let` of un-annotated functions stored in an un-annotated record field is refused at the call for want of a function-value signature

**loud emit reject · `vl check` rc 0 · `a function-value call has no interned signature` · clause 2 · found closing [D9007](D9007.md) · present on master `464f33df4` · filed 2026-10-21 against master `464f33df4`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    let f = inc0
    f = dbl
    const b = { g: f }
    print(b.g(3))
    // vl check rc 0.  vl run: emit error: emitProgram: a function-value call has no interned signature — parameter 1 of type `` has no representation in the function-value ABI

#### Mechanism

Not traced. The refusal names parameter 1 with an empty type spelling: the call `b.g(3)`
asks the function-value ABI for a signature over a parameter it holds no type for, which
reads as the field carrying the `let`'s hole signature unpinned. The un-re-pointed binding,
a `let` of lambdas and an annotated record type all run.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the write `f = dbl` | runs, `4` | **yes** |
| named functions (lambdas: `let f = (a) => a + 1`, `f = (a) => a * 2`) | runs, `6` | **yes** |
| the un-annotated record (`type W = { g: (a: i32) => i32 }`, `const b: W`) | runs, `6` | **yes** |
| the call `b.g(3)` (`print(1)`) | runs, `1` | **yes** |

#### Grading list

`scripts/capability-probes/matrix/written-let-hole-fns-agree.matrix.vl` refuses this at

`map_set` (`unsupported map value type`). Each must run when this closes, or get its own row.
