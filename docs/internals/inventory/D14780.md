Repro:

    function exclaim(s) { return s + "!" }

#### Mechanism

`@B { exclaim }` is a labelled block that no `break` leaves, so its value is `exclaim`, a hole
function nothing calls. The parameter `_p` is never read. The elaboration's stub priming
(`monoElabDefaultsPrime`) recognises a name, a `const` of one, an `if` choosing between them,
or a call returning one, but not a labelled block. So it leaves `g`'s parameter open
(`elabCallParamTy` is -1). The stub rung's own walk accepts the block and pins `() => void`.
