### D1221 — a generic member call on a type-parameter receiver whose instantiation carries the field is a check reject with a BLANK message, unless a `self`-function of that name is also in scope

**runs today and must keep running · CLOSED 2026-09-03 by the owner ruling that an unbounded
`<T>` is an entirely open hole ([D1431](D1431.md)) — the program compiles and prints `fld`, and
the sentence the intermediate fix wrote is gone with the refusal it worded · found 2026-09-02
while building [D1063](#d1063)'s position matrix, as the `nofn` shape — 7 of its 70 cells**

Repro (prints `fld`):

    type Boxed = { tag: () => string }
    function g<T>(x: T): string { x.tag() }
    const b: Boxed = { tag: () => "fld" }
    print(g(b))

* **THE ABLATION WAS ONE LINE, AND IT IS THE ONE NOBODY WOULD WRITE.** Adding a free
  `function tag(self: Circle): string { "C" }` — for a type the program never instantiates `g`
  at — made the SAME program compile and print `fld`. That is D1002's own witness, which is why
  the shape looked covered: every fixture for the field-dispatch family carries a `self`-function
  because the family is ABOUT the precedence between the two. With no `self`-function there was
  no precedence question at all, and that was the case that refused. Both spellings run now,
  and the ablation line's UN-ANNOTATED twin turned out to be a miscompile — [D1430](D1430.md).

* **IT IS NOT [D1063](#d1063), AND THE MATRIX SEPARATED THEM.** D1063's cells were check-clean
  INVALID WASM at all seven positions and run now; these seven were `check rc 1` and are upstream
  of the emitter entirely. One is an emitter disagreement, the other was never the emitter's.

* **AN EMPTY DIAGNOSTIC IS ITS OWN DEFECT, AND SO IS A LECTURING ONE.** A `[ERROR]:` with no
  sentence cannot be acted on; a sentence explaining a concept and prescribing a declaration
  reads as the compiler arguing with the author. Both were written here, in that order, on
  successive days. The one that survives is the one an argument earns:

      argument 1: expected {tag: _}, got {r: f64}

  — byte-identical to what the un-annotated spelling of the same program already printed.

* **ONE RUNG WITH [D1004](D1004.md), TWO ROUTES TO IT — the ablation said both, twice.** The
  message fix moved one rung and both witnesses; the ruling moved one rung and both witnesses
  again. How each REACHES it is still not shared: D1004 is a bare field read that falls straight
  through `checkMemberNode`'s `TyVar` arm, while this is a member CALL that first tries the
  bounded-member route and then UFCS dispatch, and reaches the arm only when both come up empty.
  That second precondition is this row's own — it is why a `self`-function of the name anywhere
  in the program already made the same program run.

* **THE CAPABILITY HALF WENT THE OTHER WAY, AND THE MESSAGE WENT WITH IT.** The intermediate
  fix (2026-09-03, morning) worded the refusal — "no `tag` on `T` — `T` is a type parameter
  with no bound …". The owner then ruled the program LEGAL, so there is no refusal left to
  word: `x.tag()` on an unbounded `<T>` derives its member the way an inference hole's does
  and the check defers to each call. What survives is the refusal an argument earns —
  `argument 1: expected {tag: _}, got {r: f64}`, the hole's own sentence — which is the
  register the ruling asked for. [D1431](D1431.md) is the mechanism.

* **THE ABLATION LINE IS NOW ITS OWN ROW.** Adding `function tag(self: Circle)` made this
  program compile, and the un-annotated twin of that same program was a check-clean
  MISCOMPILE for the mirrored reason — [D1430](D1430.md), closed in the same change.
