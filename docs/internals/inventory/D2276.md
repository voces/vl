### D2276 — `exprArray` claimed every non-ref literal, so a global `(string | null)[]` took the fused `.get(i) ?? d` read and trapped on a stored `null`

**closed 2026-09-23 — the witness prints `z`, `a`, `z` · was check-clean and trapped after load (`null reference`) on master · fixed by making `exprArray` a projection of `exprListRep` (D2275 moved the other five), so only an i32 or f64 list takes the fused read · found in review of #3098 · filed against master `2d8341305` · fixture `tests/cases/arrays/listget-nullable-string-element.vl`**

Repro:

    const ys: (string | null)[] = ["a", null]
    print(ys.get(1) ?? "z")
    print(ys.get(0) ?? "z")
    print(ys.get(9) ?? "z")
    // vl check: rc 0. vl run on master: wasm trap, null reference, at the first read.
    // Now prints z, a, z.

#### Mechanism

`exprArray` was wide. It answered true for any array literal that is not a ref list
(`!arrLitIsRef`), so string, f64, i64, f32 and u8 literals all counted. It also answered true
for any concat whose left side was not a string or ref list, and for any global whose
initializer was such a literal: `globalIsArraySid` asks `letIsArray`, which asks `exprArray`
of the initializer. Callers that must not see those lists ask the narrower predicates first.
The `xs.get(i) ?? d` fusion in `emitCoalesceGo` does not: it takes
`exprF64Array(recv) || exprArray(recv)`, and `emitListGetOrGo` then re-read a string list as
`ek = "str"` and recovered the element with `ref.as_non_null`. So a module-global string list
got the fused read, and a stored `null` trapped where the default was owed. A local got the
generic nullable read, because `declaredKind` names it `strlist`. As a projection, `exprArray`
claims only what `exprListRep` names the i32 list, so a string list never reaches the fusion,
and its `"str"` arm and `ref.as_non_null` are removed as unreachable.

#### Ablation

| receiver of `.get(i) ?? d` | master | now |
| --- | --- | --- |
| module-global `(string \| null)[]` holding `null` | trap after load (`null reference`) | generic read, runs |
| the same global un-annotated (`const us = ["a", null]`) | trap after load (`null reference`) | generic read, runs |
| function-local `(string \| null)[]` holding `null` | generic read, runs | generic read, runs |
| module-global `string[]` | fused read, runs | generic read, runs |
| module-global `i32[]` or `f64[]` | fused read | fused read |
