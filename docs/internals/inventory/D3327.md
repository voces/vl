### D3327 — a generic that returns an inner `let x = w` while an outer `let x` holds another type is refused at emit

**closed · runs, prints `r` · was loud emit reject, clause 2 · closed by [D10131](D10131.md)'s close in check_emit_queries.vl: the return set at a pin reads each return as the re-check of the body's statements typed it, where the inner `x` is in scope · fixture `generics/shadowed-local-returned-in-generic.vl` · found by #3307's review · filed 2026-09-30 against master `b6378e95b`**

Repro:

    function g<T>(w: T) {
      let x = 7
      if true {
        let x = w
        return x
      }
      w
    }
    const r1 = g({ a: 1, b: "r" })
    print(r1.b)
    // vl check: rc 0.  vl run: emitProgram: field access receiver is not a struct

Want:

    r

#### Mechanism

`monoInferRetSetUnionName` (check_emit_queries.vl) joins the return set at each pin by
re-checking every return node alone after the body's statements have run and their scopes have
closed, so the returned `x` resolved to the outer `let x = 7` and the join was `i32` with the
record. Each return is now read as the statements typed it, where the inner `x` is the
binding in scope.
