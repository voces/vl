### D2597 — a `let x = null` hole filled by a later write is lowered from a name scan of the write, not from the type the checker filled it with

**closed 2026-09-26 — the filed repro RUNS and prints `false` · was check-clean silently wrong,
clause 1 (it printed `null`), with a loud emit reject and check-clean invalid wasm in the same
family · pre-existing on master `483ff4607` · found by lane E's un-annotated `global_assign` cell
of its boolean matrix · fixture `tests/cases/inference/null-hole-filled-by-write.vl`**

Repro:

    function mk(): boolean | null { return false }
    let a = null
    a = mk()
    print(a)
    // vl check: rc 0.  vl run: prints null, where the value is false

#### Mechanism

`let x = null` binds the A-infer-null hole, a `T | null` whose `T` the first non-null write
fills in place. Two halves disagreed about it. The checker filled it only from a NON-null write:
a write whose own type is `T | null` (`a = mk()`) left it open, so the binding was the `null`
type, its cell `nullref`, and every read printed `null` (D1576's rule, applied to a binding
that had been written). The emitter ignored the checker's fill altogether and re-derived it from
the SPELLING of the first write (`nliAtomOfExpr`): a literal or an annotated call's return name,
registered as a value-union box `T|null`. That box is `i32 | null`'s and `f64 | null`'s rep, but
`boolean | null` is an i32 niche, `string | null` a nullable ref, and a record or list has no
atom at all, so those fills refused (`union atom has no value box`), built invalid wasm, or took
no row. The close has the checker fill the hole from a nullable write's non-null part, without
narrowing, and bank each filled hole at scope close (`letNullHoleFilledTy`); the emitter then
synthesizes the binding's annotation from that type (`synthNullHoleAnn`) before the union
registration reads it, so the binding takes its annotated twin's cell at every storage class.

#### Ablation

On master `483ff4607`, `let c = null; c = <write>` then a read through `const v: T | null = c`.
