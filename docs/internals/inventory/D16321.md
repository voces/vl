### D16321 — a union of records returned where a record containing them is declared builds an invalid module

**check-clean invalid wasm · `type mismatch: expected (ref $0)` · clause 1 · found closing D4085 · filed 2026-11-14 against master `f302cdde`**

Repro:

    type A = { x: i32 }
    type B = { x: 1 | 2 }
    type D = { x: 3 | 4 }
    function g(b: B | D): A { return b }
    print(g({ x: 3 }).x)

Want:

    3

#### Mechanism

Not yet ablated past its ingredients. The checker accepts the delivery, since every `B` and
`D` value is an `A`, but the union box is handed to the `A` result unconverted. A test or cast
to `A` over the same operand types its result as `B | D` (`tyTestMeet`) and runs.
