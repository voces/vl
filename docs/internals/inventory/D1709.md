### D1709 — an INFERRED mixed union has no registered row, so a `??` whose join is one cannot be named and its result falls back to the operand's scalar block type

**check-clean invalid wasm · filed 2026-09-06 against master `1f7406139` · D1703's un-annotated
face: the declared spelling of the same program runs · 0 corpus cells**

Repro:

    type A = { r: i32 }
    function mkN(): i32 | null { return null }
    function st(): A { return { r: 8 } }
    const v = mkN()
    const w = v ?? st()
    if w is A { print(w.r) } else { print(0) }
    // vl check: rc 0.  vl run: exit 70,
    // the emitted module failed to validate: type mismatch: expected i32, found (ref $type)

#### Mechanism

D1703's close names the `??` result union off the canon-keyed registry
(`nodeRegisteredUnionName`), which answers only for a union `collectU` registered — and
`collectU` registers what the program DECLARES, plus an un-annotated function's inferred
return. A join that exists only as a `??` result is neither, so the name resolves to "" and the
arm falls to the scalar tail, which puts the struct ref in the operand's `i32` block type.
Adding `type M = i32 | A` and annotating the binding is the whole difference; the checker
already types `w` as `i32 | A` either way and says so in a `redundant type annotation` hint.

The same gap wearing a LOUD sentence is an f32 default: `v ?? sm()` over an `i32 | null`
refuses with `union box atom test on a union with no recorded members: i32|f32` un-annotated,
while its declared `type F = i32 | f32` face runs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the inference (`type M = i32 \| A`, `const w: M`) | runs, prints `8` | **yes** |
| the struct default (`v ?? "x"`, whose join is a VALUE union) | runs, prints `x` | **yes** — a value join needs no registry row |
| the null value (`return 4`, so the default is dead) | refuses identically | no |
| the pin (a `take(a)` parameter instead of a binding) | refuses identically | no |

spelling above — it is the same missing row reported loudly rather than silently, so a close
that mints the row must move both. `tests/cases/unions/coalesce-result-rep.vl`'s declared
