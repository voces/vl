Repro:

    function f<T>(v: {[string]: T}): i32 { 1 }

    // vl check: rc 0.  vl run: emitProgram: monomorphize: unsupported argument type for `v` in a call to `f`

#### Mechanism

Nothing binds `T`: the only argument is an empty `Map()` (or `[]`), whose element type is
open. At the top level that hole closes at the default `i32`, so `f<T>(v: T[])` called with
`[]` runs. Under a composite it does not close, and the monomorphizer has no argument type to
instance the call at. The instance key is open, which the elaboration's closed-key invariant
(architecture-target-2026-10.md, step 2) is meant to rule out.
