#### Mechanism

The map's value is a record `{f: Fn{id, k2}}`. A list of such records is a holder the tag rule
knows (`ftHoldKind` 6), and a map of the set's ids is one (kind 3), but a map whose value is a
record holding the set is neither, so no node of the map is a place an id may stand and the set
is refused. Mono then pins each field at one generic's instance, which one map of two generics
cannot give.
