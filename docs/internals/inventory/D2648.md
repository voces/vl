#### Mechanism

The robustness floor in `checkFnDecl` accepts an inferred union return only when a recorder
names it for the emitter: `valueUnionRetName` (value atoms), `variantBoxUnionRetName` and
`structUnionRetName` (records). None of the three admits a map member (`tyIsValueUnion` declines
it), so the join floors even though the annotated spelling `(): {[i32]: i32} | i32` lowers at
every position. The nullable twin (`{[i32]: i32} | null`) floors through the `TyNullable` arm:
D937 built the inferred nullable-map return for a string key only.

The non-null half passes the floor since D2666's close, through the recorder's map-union rung
(`mapUnionRetName`). The join of TWO maps was worse, and the same missing lowering: `{[i32]: i32} | {[i64]: i32}`
(or `| {[string]: i32}`) passes the floor, and an inferred return or an if-expression join of
the two lowers as whichever map struct the first branch has, so the module is check-clean
invalid wasm (#3189's review P1, identical on master). The floor is the smaller half of this
row; D2666 closed the two-map join.
