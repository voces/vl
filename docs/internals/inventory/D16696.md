### D16696 — a push whose arguments mix a literal and a spread of a list of records or lists is refused at emit

**loud emit reject · `a list literal's element type gives its list no element rep` · clause 2 · open · `vl check` rc 0 · each argument alone runs, and two spreads run · found grading [D16571](D16571.md) · filed 2026-11-16 against master `6356d3e7d`**

Repro:

    const rs: {n: i32}[] = []
    rs.push({ n: 1 }, ...[{ n: 2 }])
    print(rs[1].n)
    // vl check: rc 0.  vl run: emit error: a list literal's element type gives its list no element rep

Want:

    2

#### Mechanism

Not traced. The packing of a push's mixed arguments into one list builds a literal whose element
has no rep when an argument is a literal and another is a spread of a list whose element is a
reference (a record or a list).
