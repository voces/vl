### D16696 — a push whose arguments mix a literal and a spread of a list of records or lists is refused at emit

**closed 2026-11-16 · runs, prints `2` · was loud emit reject, `a list literal's element type gives its list no element rep`, clause 1 (check accepts what emit refuses) and clause 2 · fixed in wasmEmit.vl and emit_elab.vl: a run the emitter mints inside the push's packed list, and a list literal spread there, are linked to the packed list's holder, the receiver, whose type it is built at; before they were linked to the packed list, which has no type · pin: `tests/cases/lists/push-literal-beside-spread-of-references.vl` · found grading [D16571](D16571.md) · filed 2026-11-16 against master `6356d3e7d`**

#### Mechanism

`emitPushMany` packs the arguments into one minted list linked to the receiver, so it is built
at the receiver's type. `emitArrSpread` then splits it around the spread and mints the plain
run `[{ n: 1 }]` linked to the packed list, not to the receiver, and `elabSpreadNote` links the
spread's literal the same way. The packed list has no recorded type, and `arrLitElemKind`
follows one link, so the run had no element rep. A link to an untyped minted run now goes to
that run's holder.
