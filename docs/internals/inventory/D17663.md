#### Mechanism

The last `is` is decided at its storage (`isDecidedPlanOf`: `storage`, arm `static`), so its
receiver is read at its storage: the builder typed that map read as the cell's box, but `mapGetAt`
left `mtWhole` unset, and the lowering re-derived the write-narrowed member read (`string`) into
the box-typed slot. The branch write makes the cell narrowable; the later whole write re-narrows
it. Legacy reads the cell's box (`__map_entry__`, then the box's tag).
