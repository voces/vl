### D3303 — an un-annotated generic joining a parameter with an else-if chain or a non-member literal builds invalid wasm at a literal-union pin

**check-clean invalid wasm · clause 1 · open · the same on master `e70102886` and with the D3281 close; the non-member-literal cells at a `K | null` pin (`g0379`, and its `"c"` twin) were a loud emit reject (`literal-union string widening with no members`) on `313a071b4`, the else-if cells invalid there too · found by the #3303 review's generator (`rv3303-12883/gen`, 31 cells) · filed 2026-09-29**

Repro:

    type K = "a" | "b" | "c"
    function show<T>(x: T) { print(x) }
    function g(a, b, c: boolean) {
      const r = if c { a } else { "z" }
      r
    }
    const u: K | null = "a"
    const w: K | null = "b"
    const v0 = g(u, w, true)
    print(v0)
    const v1 = g(u, w, false)
    print(v1)
    // vl check: rc 0.  vl run: invalid module inside `g`

Want:

    a
    z

#### Mechanism

Not localised past the ablation. The hole spelling's join of the pinned parameter with a string
literal at a `K | null` pin is lowered as a nullable string, and the instance's inferred result
disagrees with it. The else-if cells (`if c { a } else if !c { b } else { "c" }`, at `K` as well
as `K | null`) fail the same way and may be a second mechanism; they have not been ablated apart.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `function g<T>(a: T, b: T, …)`, the generic spelling | prints `a z` | **yes** (the hole) |
| `function g(a: K \| null, b: K \| null, …)`, the direct spelling | a loud emit reject (`literal-union string widening with no members`) | **yes** |
| `"c"` (a member literal) in place of `"z"` | the same invalid wasm | no |
| `u`, `w` typed `K` | invalid wasm in the top-level code | no |
| `print(r)` before `r` | the same invalid wasm | no |
