#### Mechanism

Not localised past the ablation. D3264's close mints the row of a concrete record literal whose
own field is typed at the union a generic instance returns. It reads only the literal's direct
fields, so an inner literal (`{ v: w }` inside `{ o: … }`) reaches the emitter with no row. The
pass is gated on the instance's return, so a join returned inside a record or a list and then
re-delivered is not seen either. Two record pins at one shape (`R | i32` and `Q | i32` in
`{ v: … }`) mint the first shape's row only, and the second `is` finds no interned arm.
