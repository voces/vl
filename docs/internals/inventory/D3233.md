### D3233 — writing a hole field in an `is` test's else arm and then reading the tested member traps in the `<Z>` spelling

Repro:

    type A = { v: i32 }
    type B = { s: string }
    function F<Z>(z: Z) {
      if z.h is A { print(z.h.v) } else { z.h = { v: 9 }
        print(z.h.s) }
    }
    const x: { h: A | B } = { h: { s: "bee" } }

    // vl run: wasm trap in `F`

#### Mechanism

The annotated spelling refuses `no field 's' on A`: the write re-narrows `z.h` to the written
record. The `<Z>` body read the field after the write as its non-null face, and a member read off
a declared parameter's derived hole was never re-asked at the pin, so the emitter lowered the
else arm's remainder `B` over an `A`. A concrete value written into a hole's field now leaves the
place reading as an `HD_HWR` derived hole, the member of the pinned field the value lands on
(`writeMemberTy`), and a member read of it is re-asked at the pin. The hole spelling, a loud emit
reject on master, refuses the same way; the read of the written member (`z.h.v`) runs in both,
where master refused at emit.
