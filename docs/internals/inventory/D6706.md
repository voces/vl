### D6706 — a hole parameter handed two different lambdas, each calling the generic it is given at two types, is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the parameter handed one lambda at every call runs ([D6481](D6481.md)) · found closing [D6481](D6481.md) · filed 2026-10-18 against master `ca2adfdc7`**

Repro:

    function id(a) { return a }
    const lap = (g) => { print(g(1) + 1); return g("s") }
    const lop = (g) => { print(g(5) * 2); return g("o") }
    function use(k) { return k(id) }
    print(use(lap))
    print(use(lop))
    // vl check: rc 0.  vl run: emitProgram: monomorphize: unsupported argument type for `k` in a call to `use`

Want:

    2
    s
    10
    o

#### Mechanism

From the ablation only. The plan that closed [D6481](D6481.md) turns a hole parameter into the
one function every call hands it; given two, it would need a copy of `use` per lambda, and the
copy plan does not take a lambda, which has no declaration to copy.
