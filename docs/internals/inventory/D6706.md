**closed 2026-10-18 by lane L1 · runs, prints `2`, `s`, `10` then `o` · was loud emit reject · `vl check` rc 0 · clause 2 · the hole plan now reads the calls a by-name copy makes through its parameter, and inserts the generic's per-type arguments inside the copy at the planned argument; a third lambda, named functions for the lambdas, an extra parameter, a `const` result and a `boolean` key run too · pins: `tests/cases/functions/hole-param-given-two-lambdas-calling-generic-at-two-types.vl` · found closing [D6481](D6481.md) · filed 2026-10-18 against master `ca2adfdc7`**

Repro:

    function id(a) { return a }
    const lap = (g) => { print(g(1) + 1); return g("s") }
    const lop = (g) => { print(g(5) * 2); return g("o") }
    function use(k) { return k(id) }

#### Mechanism

From the ablation only. The plan that closed [D6481](D6481.md) turns a hole parameter into the
one function every call hands it; given two, it would need a copy of `use` per lambda, and the
copy plan does not take a lambda, which has no declaration to copy.
