### D15821 — a call's record result written into a field of a receiver built wider than its own type is not built at the field's stored record

**closed 2026-11-11 — runs, prints `6` · was check-clean invalid wasm, clause 1 · `storeWritesResolve` builds a written call's result at the field's stored record where the call is its function's only one: its literal results are adopted there and the function is kept at it (`recKeptFnLatePush`); a held binding's other deliveries are taken at the record or refused (`storeHeldArgsAt`), so the parameter spelling below runs too; a callee with another call is refused loudly (D15822) · fixture `tests/cases/soundness/field-write-call-into-wider-built-receiver-runs.vl` · filed 2026-11-11 against master `1d517770` with D15820's fix**

Repro:

    type J = { f: i32 | null }
    type K = { j: J | null }
    function mk() { { j: { f: 4 } } }
    const _k: K = mk()
    const y = mk()
    function mj() { { f: 6 } }
    y.j = mj()
    print(y.j.f)
    // vl check: rc 0.  vl run: invalid module, expected (ref null $J), found (ref ${f:i32})

Want:

    6

#### Mechanism

`y` is stored at `K` (D15214), so field `j` holds a `J`. D15820 builds a written literal at `J`.
A call's result is built where the record solve builds the callee, and the solve does not see a
field write as a delivery, so `mj` is built at its own record and stored into the `J` field. The
same holds for an un-annotated binding that is also handed to a parameter of its own type
(`const v = { f: 5 }; y.j = v; own(v)` with `own(z: { f: i32 })`): its literal is built at `J`
for the write, and the call then receives a `J`. Closing it needs the write to enter the record
solve as a delivery at the field's stored record, so the solve either builds the value there or
refuses the conflicting delivery.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `const _k: K = mk()` | runs, prints `6` | **yes** |
| `| null` on `K`'s field `j` | runs, prints `6` | **yes** |
| `| null` on `J`'s field `f` | loud emit reject (`narrowed union atom has no value box`), another mechanism | **yes** |
| `mj()` replaced by the literal `{ f: 6 }` | runs, prints `6` (D15820) | **yes** |
