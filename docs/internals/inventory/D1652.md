#### Mechanism

`nodeStartTok(ix)` resolved a node's start with `tokIndexAt(nodePos(ix))`, a binary search
over `P.toks` keyed on `start`. `vcLoadToks` APPENDS each module's tokens carrying that
module's own byte offsets, so in a merged program `start` does not ascend and the search is
unsound: it can return a token from another file, or miss. `driver.vl`'s `__callsite__` pass
already said so in a comment and used `nodeToks` for exactly this reason; the diagnostic path
did not. Every witness is a merged compile — an `import`, or the implicit `std:fmt` edge a
template hole pushes — which is why the same three lines with no preamble were reported
correctly and a preamble moved them. `nodeStartTok` now walks back from the node's own
`nodeToks` anchor, a GLOBAL token index, bounded by the node and by `start` rising again,
which is the module's front.
