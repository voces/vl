### D15897 — an un-annotated `const` lambda whose only use is a function slot with a nullable result is check-clean invalid wasm

**check-clean invalid wasm, clause 1, `type mismatch: expected i32, found (ref $4)` inside `v`, `vl check` rc 0 · the same on master `d303c9bcd` · found grading D15896's matrix · filed 2026-11-12 against master `d303c9bcd`**

Repro:

    const dbl = (a) => a * 2
    const v: (a: i32) => i32 | null = dbl
    print(v(5) ?? 0)

Want:

    10

#### Mechanism

The delivery's adapter calls `dbl(p)` at the `i32` result its body gives, but the lambda's
closure is built at the slot's signature, the only one its uses name; with a direct call
`dbl(1)` beside it the closure is built at `i32` and the program runs. The `f64` spelling of the
same mismatch is caught at emit, [D15898](D15898.md).

#### Ablation

| spelling | outcome |
| --- | --- |
| this repro | invalid wasm |
| a lambda literal delivered directly | runs, `10` |
| `(a: i32) => a * 2` | runs, `10` |
| `function dbl(a)` | runs, `10` |
| `print(dbl(1))` before the delivery | runs, `2`, `10` |
| `let dbl` | invalid wasm |
| a parameter `w(f: (a: i32) => i32 | null)` | invalid wasm |
| `i32 | string` for the result | invalid wasm |

#### Grading list

The binding, `let`, parameter and `i32 | string` spellings above.
