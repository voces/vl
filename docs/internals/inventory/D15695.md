### D15695 — a record holding a list built at a kept maker's record, handed to an annotated parameter of its own type, emits invalid wasm

**check-clean invalid wasm · clause 1 · found closing D15690 · filed 2026-11-11 against master `f50936aa`**

Repro:

    type J = { f: i32 | null }
    function mk2() { { f: 1 } }
    const dA: J = mk2()
    print(dA.f ?? 0)
    const xs = [mk2()]
    function use(r: { ys: { f: i32 }[] }) { print(r.ys[0].f) }
    const r = { ys: xs }
    use(r)

Want:

    1
    1

#### Mechanism

Not ablated. `r` is built at `{ys: J[]}`, and the parameter takes `{ys: {f: i32}[]}`, which stores the
element's field differently; no delivery copies or refuses it, so the call hands a struct of the
wrong type.
