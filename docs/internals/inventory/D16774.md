### D16774 — a maker's hole lambda pushed or stored into a record field's list or map keeps its own result at a function type returning `f64`

**closed 2026-11-16 · runs, prints `0.5` · was loads then traps, `vl check` rc 0, `wasm trap: indirect call type mismatch` · clause 1 · fixed in emit_elab.vl: the call search walks a push, `.set`, index or field store's receiver back to its root binding (`elabRecvPath`, `elabHeldRecvReads`) and reads that binding's slot at the receiver's path · the map index-store and `.set` faces run too · pin: `tests/cases/functions/maker-lambda-held-by-field-param-generic-values.vl` · found by the maker/map/relay hunt · filed 2026-11-16 against master `6fb5ac348`**

Repro:

    function deliver() { return (a) => a + 1 }
    type R = { xs: ((a: i32) => f64)[] }
    const r: R = { xs: [] }
    r.xs.push(deliver())
    print(r.xs[0](3) / 8.0)
    // vl check: rc 0.  vl run: wasm trap, indirect call type mismatch

Want:

    0.5

#### Mechanism

The lambda's result is decided by the calls the lambda reaches ([D16711](D16711.md), `elabLamDeliveredRet` in emit_elab.vl), found by the call search `elabSlotClimb` / `elabReadOn`. It follows a value pushed onto, written into, or set into a NAMED binding (`elabPushRecvDecl`, and the index-store and `.set` hops of [D16752](D16752.md)); a receiver that is a field of a binding (`r.xs`, `r.m`) is not walked back to its root, so no call is found and the instance keeps the body's `i32`.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the lambda literal stored directly (`r.m["k"] = (a) => a + 1`) | runs, `0.5` | **yes**: the maker |
| a field written whole (`r.f = deliver()`) | runs, `0.5` | **yes**: a holder in the field |
| `r.m["k"] = deliver()` / `r.m.set("k", deliver())` for the push | the same trap | no: any store into a field's holder |

#### Grading list

The map index-store and `.set` faces (`type R = { m: { [string]: (a: i32) => f64 } }`), both with the read `const v = r.m["k"]; if v != null { print(v(3) / 8.0) }`.
