### D15716 — a binding of a maker's call built at a record that holds its number wider is refused where it is read at its own type

**loud emit reject · check-clean, clause 2 · `emitProgram: a union stored at a wider record's field has no box for its member` · found closing D15715 · present on master `161d481c` · filed 2026-11-11 against master `161d481c`**

Repro:

    type J = { f: i64 | null }
    function mk2() { { f: 7 } }
    const o = mk2()
    const d: J = o
    print(o.f)

Want:

    7

#### Mechanism

Not ablated. `mk2` is called once, so its literal is built at `J`, where `o`'s record holds `f` in
an `i64 | null` box. Reading `o.f` at its own `i32` narrows the box back (`emitBoxAtomRetagAtoms`),
which rebuilds it under the `i32` tag, and no `i32` value box was registered for the program.
