### D4709 — a fresh record literal passed to a generic-alias application parameter (`W<T>`) has no monomorphization pin

**loud emit reject · clause 2 · found grading D4683's second delivery position · the same on master `209f5d1ca` · filed 2026-10-14 against master `209f5d1ca`**

Repro:

    type W<T> = { v: T }
    function getV<T>(w: W<T>): T { return w.v }
    print(getV({ v: 7 }))
    // vl check: rc 0.  vl run: emitProgram: monomorphize: unsupported argument type for `w` in a call to `getV`

Want:

    7

#### Mechanism

Not yet ablated past the table. The checker binds `T` from the literal's field, but the
monomorphizer's argument ladder has no rung that matches a record literal's type against a
generic ALIAS application; the inline spelling of the same parameter has one.
