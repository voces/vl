### D3963 — a capture cell seeded with a hole lambda and written with a concrete `string` function builds invalid wasm

**check-clean invalid wasm · clause 1 · found by the D3960 matrix (`hole_match_str_fn_closure`) · filed 2026-10-10 against master `eb81bdd89`**

Repro:

    function q(s: string) { print("Q"); print(s) }
    function main() {
      let k = (u) => { print("L"); print(u) }
      const w = () => { k = q }
      w()
      k("s")
    }
    main()
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `main`

Want:

    Q
    s

#### Mechanism

Not located. The write in a closure makes `k` a capture cell; the cell's element is built at the
hole lambda's default before the store pins its parameter at `string`, a reference type the
default `i32` slot cannot hold.

#### Ablation

| ingredient changed | outcome on master | needed? |
| --- | --- | --- |
| `k = q` written directly, no closure | runs | **yes** |
| `q(n: i32)`, called with `1` | runs | **yes** |
