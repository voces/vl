### D3963 — a capture cell seeded with a hole lambda and written with another hole lambda called at `string` builds invalid wasm

**check-clean invalid wasm · clause 1 · found by the D3960 matrix (`hole_match_str_fn_closure`) · filed 2026-10-10 against master `eb81bdd89`**

Repro:

    function main() {
      let k = (u) => { print("L"); print(u) }
      const w = () => { k = (s) => { print("Q"); print(s) } }
      w()
      k("s")
    }
    main()
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `main`

Want:

    Q
    s

#### Mechanism

Not located. The write in a closure makes `k` a capture cell; the cell's element is built at the
hole lambda's default before the call pins the written lambda's parameter at `string`, a
reference type the default `i32` slot cannot hold.

| --- | --- | --- |
