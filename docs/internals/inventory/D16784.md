#### Mechanism

The inner list's elements are stored at `J`, and a `for` loop over `srcs[0]` reads them there.
A callback over `srcs[0]` is lowered for elements at the annotated `{ f: null }`: neither the
checker's built-container refusal nor the elaboration's build lookup (`elabListElemBuild`) follows
an index into a list whose elements are themselves built lists. So the callback is neither refused
nor instanced at `J`. An un-annotated callback gets as far as emit and is refused there.
