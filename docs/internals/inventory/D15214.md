### D15214 — a function's record result whose nullable nested record field a wider delivery widens, beside an own-type binding, is built at its own record

**open · check-clean invalid wasm · clause 1 · found grading the nested-field defect step5 handed the destringify lane (a nested record field built wider beside an own-type binding) · filed 2026-11-04 against master `b4bdefff0`**

Repro:

    type J = { f: i32 | null }
    type K = { j: J | null }
    function mk() { { j: { f: 4 } } }
    const _k: K = mk()
    const y = mk()
    print(y.j.f)

Want:

    4

#### Mechanism

`mk` has two call sites, `_k: K` and `y`, so the record solve builds it at `K` only where every
field of `mk`'s own type reads back from `K`'s storage (`recNullWidened`, check_fit_rules.vl).
Field `j` is `{f: i32}` in `mk`'s own type and `J | null` in `K`, a nullable record, which that
rule does not judge; the build is dropped and `_k` is delivered a record of `mk`'s own type.
