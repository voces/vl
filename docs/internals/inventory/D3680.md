#### Mechanism

The step inlines a field only when no read needs the whole record where it would cost an
allocation that sharing the box does not. A read counts as free when it is field-read, held
in a once-set local that is only field-read, or passed straight to a parameter the
multi-value step takes as fields (`field_only_params`). A read RETURNED by its function is
counted as an allocation, but when every caller reads the result's fields the multi-value
step gives the function a result twin and the re-box is deleted there. sunpa's
`Skeleton.rootRotation` (`$23` field 4, 5 of 7 reads) is this shape. The fix asks the
multi-value analysis which producers get result twins and treats a return in one as free.

#### Grading list

The witness at `-O3` must reach 1 `struct.new`; a function whose returned field read escapes
to a store must stay counted.
