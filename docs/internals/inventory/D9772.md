Repro:

    function g(f: ((x: i32) => i32) | null): i32 {
      if f != null { return f(2) }
      0
    }
    const gg = g
    print(gg((x: i32) => x + 1))
    print(gg(null))
    // vl check rc 0.  vl run: emit error: emitProgram: a function value's signature is not yet supported — parameter `f` of type `((i32)=>i32)|null` has no representation in the function-value ABI

#### Mechanism

`sigParamTokOfTy` (emit_sig_tokens.vl) gives a nullable function type no token, so a
signature holding one has no function-value key and the emitter refuses to take the function as
a value. Called directly the same `g` runs, because a direct call needs no key. Running it needs
a token for the nullable closure, the `nulclosure` rep a result of that type already keys.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the alias, `print(g((x: i32) => x + 1))` | runs, `3` | **yes** |
| the `\| null`, `f: (x: i32) => i32` | runs, `3` | **yes** |

#### Grading list

The alias above; `g` passed to `pass(h: (f: ((x: i32) => i32) | null) => i32)`, which refuses
with the same sentence; a lambda of that signature handed to such an `h` and called with
`h(null)`, which refuses as `emitProgram: bare null needs a struct-typed context`.
