### D9720 — a pushed list of a generic whose pushed element is bound to a `const`, called through the `const` and another element at two types, refuses

Repro:

    function id<T>(x: T): T { x }

#### Mechanism

Not traced. From the ablation only: the `.push` and the `const` read are both needed, and
either alone runs. So the inert path for a pushed list (D9441, `monoValsInert`, emit_mono.vl)
seems to reach a list only when each read of it is a direct call. The `const` read is planned
by another path.
