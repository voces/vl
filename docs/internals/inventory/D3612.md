### D3612 — a list literal over a generic helper's nullable join of two type parameters, in a generic caller, drops the second arm

**check-clean silently wrong · clause 1 · found by lane HL's grid (its `list` reader, 6 wrong cells) · filed 2026-10-04 against master `c473889d1` · re-witnessed unchanged against master `32b753681` (lane NJ)**

Repro:

    function G<A, B>(k: i32, a: A, b: B) {
      if k == 0 { a } else if k == 1 { b } else { null }
    }
    function F<A, B>(k: i32, a: A, b: B) {
      const v = G(k, a, b)
      const ys = [v]
      print(ys[0])
    }
    F(1, 3, "u")
    // PRINTS null

Want:

    u

#### Mechanism

Not localised. The call's type in `F`'s template is the collapse of `G`'s deferred join of
`A`, `B?` and `null`, which keeps one arm; `print(v)` reads the call at the pin and prints `u`,
while the list literal's element type is taken from the template's collapsed type, so the
string arm is stored as a miss.
