Repro:

    function take(a) {
      const r2 = a ?? 0.5
      print(r2 + 1)
    }
    const z: i64 = 4
    take(z)
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `take`: expected (ref null $2), found i64; $2 is `union box`

Want:

    5

#### Mechanism

At an `i64` pin the `??` cannot take its default, so `r2` is `i64`, but the
operator over `r2` reads it as the `i64 | f64` join's box, and the body stores the bare `i64`
where the box is expected. A prior call at `i64 | null` moves the failure into `take$1`, the
copy at the never-null pin. The fix computes the operator at the pin (no operand is a box) and
boxes the result where the instance's result is the join: the instance's result annotation is
the checked type at the holes' binding, `i64 | f64` here, `f64` at an `i32` pin.
