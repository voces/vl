### D2170 — a function with no declared result whose `if` tail pairs a field assignment with a recursive call traps `unreachable`

**loads then traps · clause 1 · filed 2026-09-23 against master `2dbc968a9`, found by the third review of #3049 (`r3/ev/v10b.vl`, a recursive BST insert); unrelated to D2060 — it traps identically on master**

Repro:

    type Node = { v: i32, left: Node | null }
    function insert(n: Node, v: i32) {
      if n.left == null { n.left = { v: v, left: null } } else { insert(n.left, v) }
    }
    const root: Node = { v: 5, left: null }
    insert(root, 3)
    print(1)
    // vl check: rc 0.  vl run: wasm trap: wasm `unreachable` instruction executed (in `insert`)

#### Mechanism

Not yet ablated past the table. The `if` is the body's tail, so it is the function's value: its
then-arm is an assignment, whose value is the stored record, and its else-arm is the recursive
call, whose type is the function's own inferred result. The inferred result and the lowering of
that tail disagree, and the arm the first call takes reaches an `unreachable`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the recursive `else` arm | runs, prints `1` | **yes** |
| a declared result, `function insert(n: Node, v: i32): void` | runs | **yes** |
| a trailing `0` after the `if`, so it is not the tail | runs | **yes** |
| the assignment (`print(0)` in the then-arm, recursion kept) | runs | **yes** |
| `const l = n.left` bound first and tested instead | still traps | no |

#### Grading list

Every ablation row; the same shape with a `match` tail and with a `while` body calling itself.
