### D2170 — a function with no declared result whose `if` tail pairs a field assignment with a recursive call traps `unreachable`

**closed — in a function the emitter already gives a result, a tail write to a field or element spills its right-hand side (`const v = r; t = v; v`), so the arm yields the value at the value's rep, and a function whose result the walk left at `i32` takes the struct row of the result the checker gave it · was loads then traps (`vl check` rc 0, then `wasm unreachable` in `insert`, clause 1) · filed 2026-09-23 against master `2dbc968a9`, found by the third review of #3049 (`r3/ev/v10b.vl`, a recursive BST insert) · closed 2026-09-23 against master `a453c09c5` with [D2168](D2168.md); an explicit `return` of a field write is [D2171](D2171.md), and a write whose function is void to the emitter is still [D2019](D2019.md) · `tests/cases/conditionals/tail-if-field-assign-arm.vl`**

Repro (runs, prints `1`):

    type Node = { v: i32, left: Node | null }
    function insert(n: Node, v: i32) {
      if n.left == null { n.left = { v: v, left: null } } else { insert(n.left, v) }
    }
    const root: Node = { v: 5, left: null }
    insert(root, 3)
    print(1)

#### Mechanism

Two defects, each enough to break the witness. First, the then-arm's value: an assignment yields
its right-hand side and the emitter lowered that by re-reading the target, which `assignTargetReReads`
admits only when the target's checked type is the assignment's. `n.left` is `Node | null` and the
literal is `{v: i32, left: null}`, so the arm was lowered as a statement while the recursive arm made
the function yield a value, and the then-arm fell through to `unreachable`. Where the types did agree
the re-read still delivered the storage's rep (`(ref null $Node)` through a narrowed read into a
`(ref $Node)` result). `dispatchRewrite` now spills such a tail in any function the emitter gives a
result. Second, the result valtype: `computeRetInference` classifies a returned local by a kind no
global pass has collected, so an `if` joining two struct locals declared `(result i32)` over a body
yielding the struct. `criStructByFnTy` reads the row off the checker's function type, and
`exprStruct` asks the frame's own `let` the way `structIndexOfExpr` already did.
