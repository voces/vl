### D2531 — an un-annotated binding of `n ?? d` over a numeric literal-union box takes the box cell while the `??` yields the atom

**closed 2026-09-25 — the filed repro RUNS and prints `1` · was check-clean invalid wasm, clause 1 · found by #3167's review · filed 2026-09-25 against master `680b67486`**

Repro:

    let vv: 1 | 2 | null = null
    const z = vv ?? 1
    print(z)
    // vl check: rc 0.  vl run: invalid module, expected (ref null $type), found i32

#### Mechanism

`1 | 2 | null` is a value-union box, so `vv ?? 1` desugars to an if-expression whose join the
checker types `1 | 2`, and `emitIfExpr` lowers it as the unboxed `i32`. `exprUnion`'s if-expression
arm asked `coalesceResultUnionName`, which names the literal union as a value union, so every
consumer classifying through it (a binding's cell, an inferred return, a capture, `==`,
interpolation) took the box. A numeric literal union's rep is the `i32` and never the box; the
if-expression arm now says so first. A mixed one (`1 | "a"`) keeps the box, which its join is.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| an annotation (`const z: 1 \| 2`) | runs | **yes** — un-annotated |
| a non-member default (`?? 3`, joins to `i32`) | runs | **yes** |
| a string literal union | runs: the atom path | **yes** — numeric |
| a mixed union `1 \| "a" \| null` with `?? 1` | runs, the box | **yes** — numeric only |
| the prior narrowing write `vv = 2` | same | no |
| module scope → function scope | same | no |
| `print(vv ?? 1)` directly | runs | **yes** — a classified destination |

#### Grading list

* The binding, a returned `vv ?? 1` (both `return` and a tail), a capture of the binding, `z == 2`,
  and `"\{z}"`.
