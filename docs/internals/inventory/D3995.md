#### Mechanism

A function using the call-LHS `??` stash reserves `(ref $uBoxIdx)` and `(ref null $sTypeIdx)`
slots (`emitFuncCode`'s frame), and so do the union-`as` and atom-staging slots. A module that
mints no union box and no string leaves those indices unassigned, so they hold the previous
compile's values: valid by accident on a fresh instance (index 0), out of range or the wrong type
after another program. An unminted slot is now an `i32`; nothing stores a box or a string there.
