    function src(): i32 | string | null { return 7 }

    // now prints `10`

#### Mechanism

A non-null write to a binding of a null-bearing value union is the assignment narrowing: the
emitter pushes the declaration minus `null` (`pushNarrowComplement`). The checker takes that arm
only when the binding's current type is nullable, and under `is i32` it is not, so the checker
kept `i32` while the emitter pushed `i32 | string` and the read passed the box as an `i32`. The
close banks, at an assignment that kept a guard's narrowing, that it did (`asgKeepsNarrowOf`),
and the emitter skips the complement push there. Under a narrowing that still admits `null`
(`!(x is i32)`), the checker's assignment arm used to narrow to the NARROWING minus `null`
whatever the write stored; a guard's write now re-narrows from the declaration instead.
