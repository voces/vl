### D9750 — an un-annotated alias of a union value read under an `is` narrowing of its source's name is classified as the narrowed arm

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · found closing [D9681](D9681.md) · present on master `dd78f7355` · filed 2026-10-22 against master `dd78f7355`**

Repro:

    function pick(b: boolean): i32 | string {
      if b { return 1 }
      return "s"
    }
    const w = pick(true)
    const v = w
    if w is i32 {
      print(v)
    }
    // vl run: invalid module — type mismatch: expected i32, found (ref $4)

Want:

    1

#### Mechanism

`v` is never narrowed, but its un-annotated type is read by chasing its initializer `w`, and
`unionNameOfExpr`'s Ident arm answers that chase from the name-keyed narrowing table
(`narrowedValueAtomOf(e.identName)`, emit_classify.vl) at the read of `v`, where `w` is
narrowed to `i32`. So `print(v)` lowers the i32 arm while `v` is still the union box. The
narrowing is a fact about the read of `w` at a position, not about every read that reaches
the name `w` through an alias.
