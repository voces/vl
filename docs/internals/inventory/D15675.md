### D15675 — a pinned union parameter's atoms pair with the member types by position, so a ref list spelled before a record is refused as a box union

**closed 2026-11-11, runs and prints `-1` then `4` · was loud emit reject, clause 2, `emitProgram: `is` test but no union type declared` · filed 2026-11-11 against master `f50936aa` · closed in `isVariantBoxUnionOfTy` (emit_collect.vl): each atom of the spelling is paired with the canonical member whose atom spells the same (`unionAtomTysAlignedOf`), and the positional pairing is kept only when some atom has no such member · fixture `tests/cases/generics/pin-union-param-ref-list-before-record.vl`**

Repro:

    type P = { x: i32 }
    type Z = { z: i32 }
    function k<T>(u: T | P) {
      if u is P { return u.x }
      -1
    }
    const zs: Z[] = [{ z: 1 }]
    print(k<Z[]>(zs))
    print(k<Z[]>({ x: 4 }))

Want:

    -1
    4

#### Mechanism

The instance spells its parameter `Z[]|P`. `unionAtomTysOf` gives the n-th non-null atom the
n-th non-null member of the type's canonical sequence, which orders `P` first. So `Z[]` was
typed as the record `P`, and `P` as the list. `isVariantBoxUnionAtoms` then found no
ref-element array beside the struct, and the union was never registered as a box. The `is` test
found no union row.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the type parameter (`u: Z[] \| P` written out, either order) | runs | **yes** |
| the member order (`u: P \| T`) | runs | **yes** |
| the list (`T := Z`, a second record) | runs | **yes** |
| a record element (`T := i32[]`, a value atom) | runs | **yes** |
| a third member (`u: T \| P \| string`) | still refuses | no |

#### Grading list

- `u: T | P | string` and `u: P | string | T` at `T := Z[]`: both refused on master, both run now.
- `u: string | T | P` ran on master and still runs.
- `unionAtomTysOf` pairs by position at two more sites, `emit_collect` (the nul-closure arm's mix test) and `emit_union_tykey`. Neither is changed here.
