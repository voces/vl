### D3198 — a function whose result is a nullable literal union is miscompiled at nearly every call

**loads then traps · clause 1 · open · pre-existing, the same on master `2771214c7` · found by the #3288 review (`rv3288-k7q2/t/d1.vl`–`d8.vl`, `gA` cells `a*_nlu_*`) · filed 2026-09-29 against master `2771214c7`**

Repro:

    const g: () => "a" | "b" | null = () => "a"
    print(g())
    // vl check: rc 0.  vl run: wasm trap, indirect call type mismatch

Want:

    a

#### Mechanism

Not localised. The closure and its call disagree about the result's rep: the call site's
`call_indirect` signature is not the lifted body's, which reads as one side taking the
nullable literal union at its atom niche (`i32`) and the other at a string reference. The same
disagreement shows at every use the review graded:

- `print(r.f())` through a record field at module scope traps the same way.
- In a hole instance, `const x = z.f(); if x != null { print(x) }` is invalid wasm
  (`expected i32, found (ref $type)`), with an inline or an aliased (`type K`) union.
- `print(x ?? "n")` refuses with `` `??` over this nullable value is not supported yet ``.
- `==` against a string is inconsistent. `r.f() == "a"` is accepted at module scope and in a
  generic instance over a `| null` field (`a1105`, prints `true`). In a hole instance over a
  plain field it is refused at the pin, with `operator '==' is not defined for "a" | "b" | null
  and string (the call's argument types)`.
- Interpolating the result refuses everywhere (`an interpolation hole is …`), which the
  direct spelling agrees with.

#1 on the #3288 reviewer's pre-existing list. D3193's and D3192's fixes deliberately leave
this type out: counting it as a used literal union, or reading a `| null` pin's function for
it, moved 54 cells of `rv3288-k7q2/gA` that run on master to invalid wasm or a refusal.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| result `"a" \| "b"` (no `null`) | prints `a` | **yes** |
| result `string \| null` | prints `a` | **yes** (a literal union) |
| through a record field `r.f()` | traps | no |
| in a hole instance `F(z) { print(z.f()) }` | prints `a` | **yes** (the instance does not reach the trapping call) |
