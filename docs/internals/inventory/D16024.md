### D16024 — an inferred union return of a list and a map or `Set` floors at check, while its annotated twin runs

**loud check reject · clause 2 · `'pick' infers the union return type i32[] | {[string]: i32} — type-valid, but an inferred return of this shape is not yet supported by codegen; annotate the return type` · found looking for the `unsupported-lowering` channel's next witness while closing [D16037](D16037.md) · filed 2026-11-14 against master `66bb1b749`**

Repro:

    function pick(c: boolean) {
      if c { return [1] }
      const m: {[string]: i32} = Map()
      return m
    }
    const r = pick(false)
    print(1)

Want:

    1

#### Mechanism

`checkInferredReturn`'s union arm (compiler/check_inferred_return.vl) floors an inferred union
return unless a recorder names it: a struct union (`structUnionRetName`), a union of lists
(`tyUnionAllLists`), a union with a function member, or a map union (`mapUnionRetName`, D2666),
whose members are maps and scalars. A union holding both a list and a map or `Set` matches none
of them. The annotated `: {[string]: i32} | i32[]` runs, so this is a capability gap.

#### Grading list

The union of a list with a map, with a `Set`, and with a nullable map, each un-annotated.
