### D1732 — the generic pin's `+` floor demanded BOTH operands be the `string` prim where `checkBinary` demands one, so a literal union that concatenates at every direct spelling was refused through a hole parameter

**closed 2026-09-06 — the mirror asked for BOTH operands to be the `string` prim where `checkBinary` asks for ONE plus mutual assignability · filed against master `25a59b496`, closed against `15baeb884` · residue of [D1545](D1545.md), carried on [D1725](D1725.md)'s grading list until it had an id · 0 corpus cells**

Repro:

    type K = "red" | "green"
    const src: K[] = ["green", "red"]
    function take(a) { print(a + "!") }
    take(src[0])
    // vl check: rc 0.  vl run: rc 0, prints green!

Was: `argument 1: operator '+' is not defined for K and string (the body of take applies '+' to
this argument)`, while `function take(a: K)` — the annotation naming the very type the pin
substitutes — printed `green!` all along.

#### Mechanism

**The row was filed with the wrong half of this named.** It said the arm needed the SOFTENED
leg the numeric fall-through has; the close measured `checkBinary` and the divergence is its
quantifier, not its softening. The filed evidence — every annotated spelling running while the
pin refused — was right and pointed one line off.

`binOpDefinedFor` is the pin's soundness floor, re-asked after a hole is substituted to its
argument type. Reading `checkBinary`'s own `+` arm settles what the mirror owed: its gate is

    if isStringTy(lt) || isStringTy(rt) {
      if assignable(lt, TY_STR) && assignable(rt, TY_STR) { return TY_STR }

— **ONE** operand being the `string` prim, plus mutual assignability. The mirror asked for
`isStringTy(lt0) && isStringTy(rt0)`, **both**. A string literal union is a `TyUnion` of
`TyLit`s, so `isStringTy` is false of it while `assignable(K, string)` is true: the direct
spelling concatenates it and the pin refused it.

The fix is the direct rule, copied. It is not a literal-union special case — a bare `"red"`
literal TYPE through a hole parameter was refused for the same reason and now runs too.

**The numeric literal union is the control that proves the reading was about the string half
alone.** `const src: (1 | 2)[]` through the same hole parameter with `a + 1` printed `3` before
and after — the numeric fall-through consults the softened pair and never needed this.

Shape: [D691](D691.md)'s "a pin re-asks its floors against the SUBSTITUTED type", where the
floor is stricter than the direct spelling it mirrors — the same disagreement
[D1693](D1693.md) closed for narrowing, at a different floor.
