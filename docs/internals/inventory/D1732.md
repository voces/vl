### D1732 — the generic pin's `+` floor reads the UNSOFTENED operand, so a literal union that concatenates fine at every direct spelling is refused through a hole parameter

**loud check reject · `vl check` rc 1, `argument 1: operator '+' is not defined for K and string` · clause 2: the identical body with the parameter ANNOTATED at the very type the pin substitutes prints `green!` · filed 2026-09-06 against master `25a59b496` · residue of [D1545](D1545.md), carried on [D1725](D1725.md)'s grading list until it had an id · 0 corpus cells**

Repro:

    type K = "red" | "green"
    const src: K[] = ["green", "red"]
    function take(a) { print(a + "!") }
    take(src[0])
    // vl check: rc 1,
    // argument 1: operator '+' is not defined for K and string
    // (the body of `take` applies '+' to this argument)

Write `function take(a: K)` — the annotation naming the very type the pin substitutes — and
the same program prints `green!`.

#### Mechanism

`binOpDefinedFor` is the pin's soundness floor, re-asked after a hole is substituted to its
argument type. Its `+` arm takes both operands **unsoftened** on purpose, to mirror
`checkBinary`'s own order (`isStringTy(lt0) && isStringTy(rt0)` → string concat), and then
falls through to `isNumeric(lt) && isNumeric(rt)` on the SOFTENED pair. A string literal union
is a `TyUnion` of `TyLit`s, so `isStringTy` is false of it; and it is not numeric, so the
fall-through is false too. The mirror is one leg short: `checkBinary` accepts the softened
`string` at the direct spelling, and nothing here consults `softenLitTy`'s answer for the
string half.

**The numeric literal union is the control that proves the reading.** `const src: (1 | 2)[]`
through the same hole parameter with `a + 1` prints `3` — because the numeric fall-through
DOES consult the softened type. Only the string half is missing.

Shape: [D691](D691.md)'s "a pin re-asks its floors against the SUBSTITUTED type", where the
floor is stricter than the direct spelling it mirrors — the same disagreement
[D1693](D1693.md) closed for narrowing, at a different floor.
