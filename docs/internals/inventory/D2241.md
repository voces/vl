### D2241 — interpolating a hole parameter pinned at `string` is refused at the pin as a `toString` argument

**closed · clause 2 · found while closing D2238 · filed 2026-09-23 against master `f2234c2e5`**

Repro:

    function show(a) { print("v=\{a}") }
    show("s")
    // vl check: rc 1: argument of type string flows into `toString` expecting i32 | i64 |
    // boolean | f64 (the call's argument types)

#### Mechanism

An interpolated hole is parsed as a call to `std:fmt`'s `toString`, and `tplHoleHandled`
delivers a `string` hole without it by rewriting the call to a `Paren`. A hole-typed hole
passes that rung undecided, so the ordinary argument check records a deferred `toString`
demand, and the pin re-validated it with plain `assignable`: `string` is outside the
renderer's domain. The refusal was also load-bearing. Lifting it alone exposed two emit-side
faults: the instance still called `toString` on a string (a cast trap in a void body), and a
pinned re-check of the body (`monoRecheckBegin`) ran `tplHoleHandled` at the string pin and
rewrote the SHARED node, so the `i32` instance of the same generic received a string
(invalid wasm). The close is three parts: the demand carries a template flag and admits
`string` beside the renderer's domain (`argCstrFits`, with the direct spelling's sentence on
refusal), the rewrite is suppressed under a pinned re-check (`monoRecheckDepth`), and the
emitter delivers a string- or atom-pinned hole itself (`tplStrHoleOf`).

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `a: string` | runs, `v=s` | **yes** |
| `print("v=" + a)` | runs, `v=s` | **yes** |
| `show(5)` | runs, `v=5` | **yes** |
| the hole a `string[]`, interpolating `a[0]` | same refusal | no |
| `<T>` declared, `show<T>(a: T)`, return the template | same refusal; with only the check lifted, `show("s")` beside `show(5)` is invalid wasm in the i32 instance | the shared-node rewrite |
| `"w".tag()` over `tag<T>(self: T) { print("<\{self}>") }` | ran the pin unchecked and trapped in `toString` | the emitter half |
