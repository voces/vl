#### Mechanism

A depth-12 `--names` profile puts 29% of the samples under `emitStructEq` → `emitStructEqRec`
→ `emitStructEqField` → `emitStructEqNestedField` (wasmEmit.vl), which writes the comparison
of a nested record field inline at the field, so each level's two fields each carry the whole
comparison of the level below: `2^depth` copies. Another 47% is `typeOrderRun` scanning that
code. No spelling is involved; one comparison function per record type, called per field,
would make it linear.

Fuel is `VL_FUEL=1` guest fuel of one `vl build`, which is deterministic. The same witness
reads 961.4M at depth 12 on master `23ac8244a`, so this is not a regression.
