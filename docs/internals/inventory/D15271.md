#### Mechanism

Not a defect. The four share one shape: a slot's set, the functions written into it through
`cwPathFnTargets` or its older siblings, a union, a fresh function type, a memo. A unification would
key one core by (root binding, path) and keep each caller's veto. Whoever does it re-runs this
witness; it exercises every one of the four.
