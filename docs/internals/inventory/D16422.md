### D16422 — a hole parameter whose argument holds a record with an empty list field, written another such record in the body, builds the body's field at its own element

**check-clean invalid wasm · clause 1 · found grading D16365's close (`hole-param-record-empty-list-field.matrix.vl`, cell `index_writes`) · filed 2026-11-15 against master `a058e28f` · open**

Repro:

    function t(a) {
      a.push({ ys: [] })
      a[0].ys.push(0.5)
      print(a[0].ys[0])
    }
    t([{ ys: [] }])
    // vl check: rc 0.  vl run: invalid module inside `t`

Want:

    0.5

#### Mechanism

Not yet located. D16365 links the open list fields of records the body writes to one hole
receiver's element. A record the caller's argument holds is that element's instance type, and
the body's record is checked once for every instance, so it is not linked to it.
