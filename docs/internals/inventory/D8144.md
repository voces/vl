### D8144 — a fresh call through a generic identity, pushed onto a list or set into a map of a wider record, is invalid wasm

**closed 2026-10-20 by lane records · now a loud check reject (D8020's message) · was check-clean invalid wasm on master `f90d0709e` · clause 1 · the clause-2 half, running it, is [D8020](D8020.md) · fixture `tests/cases/soundness/error-record-built-at-its-own-row-positions.vl` · filed 2026-10-20 against master `f90d0709e`**

Repro:

    type Col = { r: i32, g: i32 }
    type J = { r: i32 | null, g: i32 }

    function idn<T>(v: T): T { v }

#### Mechanism

`recBuiltAtDeclared` skipped every argument of a call whose callee is a member, treating it as
a pinned generic argument. The argument of a list's `push` or a map's `set` takes its type from
the receiver, not from itself, so the refusal D8020 gives at a binding was skipped there, and
the call was accepted with the instance taken at `Col`. Those two arguments are now exempt from
the skip (`recAtStoreArg`).
