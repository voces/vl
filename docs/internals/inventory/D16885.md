#### Mechanism

A union's box row is found by its key text (`unRowOfTyKey`), built from its canonical members
(`canonUnionMemberTysOf`). The canonical walk dropped a Set member beside its boolean-map twin as
a repeat (`memberTySame` compares a map's key and value, not its Set flag), so the three-member
union keyed as the two-member `Set<i32>[] | i32` and took that row, which has no boolean-map arm.
The walk now keeps the twins apart; a single Set member still keys as its boolean map, which
generic instances share a row and a tag through (D2720).
