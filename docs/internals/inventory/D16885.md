### D16885 — a boolean-map list boxed into a union beside a list of Sets is refused when the program also has a union of a Set list and a scalar

**open · loud emit reject · `emitProgram: array value does not match any array member of the union (leaf-scalar widening across a nested array is unsupported)` · clause 2 · found closing D16172 · filed 2026-11-16 against master `2a0b71c1a`**

Repro:

    const s: Set<i32> = Set()
    const m: {[i32]: boolean} = Map()
    const u: Set<i32>[] | i32 = [s]
    const w: Set<i32>[] | {[i32]: boolean}[] | i32 = [s]
    const x: Set<i32>[] | {[i32]: boolean}[] | i32 = [m]
    print(1)
    // vl check: rc 0.  vl run: emitProgram: array value does not match any array member of the union

Want:

    1

#### Mechanism

Not traced. A list of Sets shares its element slot with the boolean-map list (D2753). With the
`Set<i32>[] | i32` union in the program, the boxing of `[m]` into the union that holds both finds no
array arm for it; without that union it boxes under its own arm.
