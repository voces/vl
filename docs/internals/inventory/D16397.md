#### Mechanism

D16394 rewrites a record `==` over fields stored apart into one `==` per field pair, in the
checker, where the operands' records are known. A generic body is checked once, over its type
parameters, so the rewrite does not fire there (`recEqFieldsAt` leaves an operand with a type
variable alone). The instance reaches the emitter's struct-equality lowering with two rows, which
it refuses. The instance is known only after the checker: the elaboration re-checks the shared template
quietly and rolls back, so the checker cannot rewrite one instance's node. The close applies the
same compare to mono's per-instance clone. `monoPinBin`'s `==` arm builds the chain at the
instance's operand types (`recEqTypedChain`, which types each node it makes), with a null guard
for a nullable side. Its operands must be names, since each is read once per field. A field,
call or element operand is D16470.
