### D10350 — a generic or hole function read by value, returning its parameter or an `f64`, is invalid wasm at a direct call

**check-clean invalid wasm · clause 1 · found closing [D10290](D10290.md) · present on master `a72f9a7fe` · filed 2026-10-22 against master `a72f9a7fe`**

Repro:

    function g<A>(k: i32, a: A, b: f64) {
      if k == 0 { return a }
      b
    }
    const h = g
    const x: i32 = 7
    const v = g(0, x, 2.5)
    print(v is i32)
    // vl check: rc 0.  vl run: invalid module, `expected (ref null $0), found f64`

Want:

    true

#### Mechanism

`njGateScan` (check_nj_gate.vl) gates `g` because it is read by value. The checker's pin still
types the call `i32 | f64`, a value box. The emitter holds the gated function's return set at
master's widening, through `njFnGated` in the return-set pin join and `joinPinnedArmLit`
(check_emit_queries.vl), so the body returns a bare `f64` where the call site expects the box.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |

| `print(g(0, x, 2.5) is i32)`, unbound | the same invalid wasm | no |
