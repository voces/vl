### D14533 — a struct list literal's element row is spelled by `arrLitElemName`, not read off the arena row: the name carries three facts the row lacks

**open · runs today and must keep running · a destringify row: the witness must still run once the name path is gone · filed 2026-10-27 against master `41c611055`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    const iv = { r: 7 }
    const c = [iv]
    if (c)[0].r == 7 { print(7) } else { print(0) }

Want:

    7

#### Mechanism

`collectAArrayLit` interns a struct list's element row from `arrLitElemName`. It interns the
arena row (`rlRowNameOfTy`) only when the literal's rep stamp builds its records elsewhere
(`arrLitRepElemRow`). The name encodes three facts the arena row does not carry:

* **Arm adoption.** An anonymous `{r: i32}` is spelled `Circle` through the nominal and
  `objVariantName` rungs, and a nullable element is spelled `P | null` where the row is
  `{n: i32} | null`.
* **Literal widening.** A literal-typed field is spelled at its widened type.
* **Hole substitution.** A generic or fn-valued field is spelled through the scope's
  substitution.

Interning only the arena row for every struct element (`internOwnShapeOfTy` on the non-null
element) was measured against `41c611055`. It fails four families, which are this row's grading
list:

* **Arm adoption:** this witness, D2750, `unions/arm-objlit-global-cell-no-twin.vl` and the
  nullable named element. They refuse with `field access but no struct type declared` without
  the own-shape intern. With it they run.
* **Literal widening:** `structs/record-lit-lone-literal-field.vl` fails with `object literal
  matches no union variant`.
* **Hole substitution:**
  * `functions/exported-generic-written-through-shared-container-called.vl`, and the
    `maker-generic-field-*`, `record-generic-field-*` and `maker-result-in-module-record-field-*`
    fixtures, fail with `ref valtype with no interned shape`.
  * `closures/hole-fn-records-one-open-row-two-types.vl` fails with `a ref list's element row
    does not resolve`.
* **Built fields:** the [D14519](D14519.md) list `[w.a, w.b]` is invalid wasm.

#### Close

Give each of the three facts one producer that the row carries: the adopted arm, the widened
field type and the substituted hole type. Do not teach the row to spell a name. Then delete
`arrLitElemName`'s struct path, so the element row is the arena row for every struct list, and
grade on the four families above.
