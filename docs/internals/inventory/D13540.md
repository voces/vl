### D13540 — an `if` of hole functions bound to a `const` inside a function with an un-annotated parameter, passed to a parameter called at two types, is refused at emit

**closed 2026-10-25 · runs, prints `a` · fixed: the split asks for a read in a mono copy of `g` by the parse read it was cloned from (`fsParseReadOf` in `fsAsk`, fn_split.vl), so the bound choice takes D13360's plan · pins: `tests/cases/generics/hole-fn-choice-ahead-loops.vl` · was loud emit reject, clause 2 · `monomorphize: unsupported argument type for `f` in a call to `both`` · found closing [D13461](D13461.md) · filed 2026-10-25 against master `3b12820b5`**

Repro:

    function both(f) {
      print(f("a"))
      return f(1)
    }
    function inner(s) { return s }
    function ask(s) { return s }
    function g(c) {
      const h = if c { inner } else { ask }
      both(h)
    }
    g(false)
    // vl check: rc 0.  vl run: emitProgram: monomorphize: unsupported argument type for `f` in a call to `both`

Want:

    a

#### Mechanism

Not ablated to a line. The un-annotated parameter is the ingredient, not the condition reading
it: a condition reading a module `let` instead still refuses while any parameter of `g` is
un-annotated. A prediction from the code path: `g`'s calls are then planned as a copy's calls,
and `fsPlanHoles` (fn_split.vl) declines a copy's call handing a name declared inside the copy
(D6706), which the bound `const` is.

The prediction was wrong. With a parameter un-annotated, `g` is generic, and its reads reach
the split's `fsAsk` as nodes of `g`'s mono copy, past the parse, which `fsAsk` dropped, so no
plan was asked at all. Mapping a copy's read back to the parse read it was cloned from (same
position, same name, the copy's declaration's origin) closes it.

#### Ablation

| spelling | outcome | needed? |
| --- | --- | --- |
| the witness | loud emit reject | — |

| `function g()` with that condition | runs | **yes** |
| `const h = inner` | runs | **yes** (the choice) |
| `both(if c { inner } else { ask })` | runs | **yes** (the binding) |
