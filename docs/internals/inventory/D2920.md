### D2920 — a list literal of a hole-typed record at a record pin refuses as a struct array

**loud emit reject · clause 2 · open · 11 `rec` cells of the lane TR grid (`lit__*__rec`, `direct__elem__rec`, `direct__push__rec`) · the same on master `0284dc2a8` · filed 2026-09-27 against master `0284dc2a8`**

Repro:

    function h(x) {
      const xs = [x]
      print(xs[0].a)
    }
    const v: { a: i32, b: string } = { a: 3, b: "r" }
    h(v)
    // vl check: rc 0.  vl run: emitProgram: struct array elements are not supported

Want:

    3

#### Mechanism

Not localised. The literal's element is the hole's variable, which no instance binding
substitutes, so the list has no row for the record the pin names. [D2899](D2899.md) and
[D2898](D2898.md) close the nullable, union and list elements by annotating the local at the
instance's list (`monoHoleListLitAnn`) and, for a nullable, re-making the literal at that type.
Taking a record element through the same rung ran the element, bind, push, `==` and generic
cells, but moved `lit__ret__rec` and `lit__cap__rec` from this refusal to check-clean invalid
wasm, so it was pulled.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `h(x: { a: i32, b: string })` | runs, `3` | **yes** |
| `h<T>(x: T)` returning `xs` | runs, `3` | **yes** (the hole) |
| a declared `type R` for the pin | still refuses | no |

#### Grading list

The lane TR grid's `rec` cells at the `lit` face (bind, elem, push, ret, cap, eq, gen) and
`direct__elem__rec`, `direct__push__rec`. A close must re-grade `ret` and `cap`, where the
pulled rung built invalid wasm.
