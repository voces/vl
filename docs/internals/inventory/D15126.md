### D15126 — a `const` of an element of a list holding a built container's read is emitted at a narrow row interned elsewhere

**open · check-clean invalid wasm · clause 1 · found grading [D14819](D14819.md) · filed 2026-11-03 against master `7f8f65fc8`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const xs = [mk()]
    const plain = { f: 5 }
    const keep = [xs[0]]
    const z = keep[0]
    print(z.f)
    print(wideJ.f ?? 0)
    // vl check: rc 0.  vl run: invalid module, expected (ref null $1), found (ref $0), $1 `{f:i32}`, $0 `J`

Want:

    4
    4

#### Mechanism

`keep` is built as a list of `J`, its element being a read of `xs`, whose records are built at
`J`. `z` is emitted at its type's row `{f: i32}` whenever some other value interns that row: an
unrelated record literal of the same shape, or a parameter annotated with it. With no such row
`z` runs. The binding is not read through `keep`'s build (`recBuiltElemIn` asks the build
table, and `keep`'s stamp comes from `recListLitBuild`, not a store).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `const plain = { f: 5 }` | runs | **yes** |
| `plain` as `{ g: 5 }` | runs | **yes** |
| `keep` (`const z = xs[0]`) | runs | **yes** |
| `z` (`print(keep[0].f)`) | runs | **yes** |

#### Grading list

* `plain` replaced by `function take(v: { f: i32 }) { v.f }`, uncalled: also invalid wasm.
* `const keep = [back(xs[0])]` with `function back(r) { return r }` (D14819's spelling).
