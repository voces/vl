### D3178 — a `null` argument to a generic `Z | null` parameter is refused at emit

**closed 2026-11-06 — the filed repro prints `true` · was a loud emit reject, clause 2 · closed by owner ruling (B): a type parameter whose only argument is a `null` its bare `Z | null` parameter takes binds `never`, and the instance's guarded reads and calls through it are unreachable · the list and record spellings closed with [D15530](D15530.md) · fixture `tests/cases/generics/null-only-type-param-binds-never.vl` · found by the #3283 review (`rv3283-3186/w/n9.vl`, `n10.vl`) · filed 2026-09-29 against master `934f169f4`**

Repro:

    function F<Z>(z: Z | null) {
      if z != null { print(z.f()) }
    }
    F({ f: () => true })
    F(null)
    // vl check: rc 0.  vl build: emitProgram: callee is not a function name

Want:

    true

#### Mechanism

Not localised past the ablation. The instance `F(null)` makes still lowers the guarded member
reads of its body: a member call refuses as `callee is
not a function name`, a field read as `field access receiver is not a struct`. The guard makes
both reads unreachable in that instance.

#### Owner question: what `F(null)` binds `Z` to (ruled (B), 2026-11-06)

`F(null)` binds no type parameter, so D4551 gives it the default instance `F<i32>`, in which
`z.f()` is ill-typed. When the elaboration keys that call at its default instance (the unbound-T
alignment, 2026-11-06), `vl check` reports `member access '.f' on non-object i32` at `z.f()`, a
type the program never wrote. The alignment therefore leaves an unbound call unkeyed when its
default instance does not check, and this row stays as filed. The fix it points at is a language
choice: a call whose only argument is `null` could bind `Z` from the program's other calls of `F`
instead of the default. That choice is the owner's.

The ruling: `Z` binds `never`. The checker's unbound-call note and the elaboration's demand bind it
(`elabNullOnlyTp`, `elabNullOnlyBind`); mono spells it `never`; an instance re-check reads a member
of `never` and calls a `never` value as `never`; the emitter lowers such a call or field read as
`unreachable`, as it does a `null` callee (D3197). [D15530](D15530.md) extends it to any `X | null` parameter naming the type parameter, with
`never` inside a list or record repping as the default `i32`.
