### D14302 — the complement of `is Tag` over a declared union with a generic-application arm finds no variant row for the arm it leaves

**closed · runs, prints `2` · was a loud emit reject, `field access receiver is not a struct` · test `tests/cases/generics/alias-union-generic-application-complement-read.vl` · filed 2026-10-26 against master `2f9786dae`**

Repro:

    type Box<T> = { v: T }
    type Tag = { t: i32 }
    type U = Box<i32> | Tag

    let w: U = { v: 2 }
    if w is Tag { print(w.t) } else { print(w.v) }
    // vl check: rc 0.  vl run: emit error, field access receiver is not a struct

Want:

    2

#### Mechanism

The variant row of `U`'s first arm records the arm's shape `{v: i32}`. The `else` narrowing
banks the survivor as the nominal `Box<i32>` instance, which is a different arena index of the
same type (D3870). `narrowVariantRowFor` looked the row up by arena index, found none, and
the field read fell through to the plain struct read. It now finds the row by shape when the
narrowing was cut from a union box. A `X | null` peel stores `X` itself and keeps the exact
lookup.

#### Grading list

`alias-union-generic-application-nullable-twin.vl` is the control the shape lookup has to
leave alone: a `{v: i32} | null` binding, null-peeled beside `U`, is a plain struct read.
