#### Mechanism

A fresh `Map()` delivered to a union is pinned to the union's one map member
(`constrainEmptyD` → `unionMapArmOf`, D2649). A recursive alias `null | f64 | {[string]: U}` is
recorded as a union whose one member is the union `f64 | {[string]: U} | null`, and
`unionMapArmOf` read only the outer members, so it found no map arm and the `Map()`'s holes stayed
open. The emitter then saw no map and boxed it through the value-atom route. The emitted module built the empty map (`{[string]: i32}` storage), then converts it
with `f64.convert_i32_s` and boxes it under the `f64` arm's tag, so the delivery picked the scalar
arm for a map value. `Json` (`null | boolean | f64 | string | Json[] | { [string]: Json }`) is such
a union, so `const j: Json = Map()` is the common spelling.
