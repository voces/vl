### D16275 — an empty `Map()` delivered to a union of `null`, a scalar and a recursive map arm is boxed as the scalar arm

**open · check-clean invalid wasm · `vl check` rc 0, `type mismatch: expected i32, found (ref $type)` · clause 1 · found closing [D1198](D1198.md) · filed 2026-11-14 against master `63c8d7a67`**

Repro:

    type U = null | f64 | { [string]: U }
    const j: U = Map()
    print(1)
    // vl check rc 0.  vl run: the emitted module failed to validate: type mismatch: expected i32, found (ref $type)

Want:

    1

#### Mechanism

Not traced. The emitted module builds the empty map (`{[string]: i32}` storage), then converts it
with `f64.convert_i32_s` and boxes it under the `f64` arm's tag, so the delivery picked the scalar
arm for a map value. `Json` (`null | boolean | f64 | string | Json[] | { [string]: Json }`) is such
a union, so `const j: Json = Map()` is the common spelling.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `null` removed (`f64 \| { [string]: U }`) | runs | **yes** |
| the scalar removed (`null \| { [string]: U }`) | runs | **yes** |
| a non-recursive map arm (`{ [string]: f64 }`) | runs | **yes** |
| `i32`, `boolean` or `i64` in place of `f64` | invalid wasm the same | no |
| `string` in place of `f64` | loud emit reject, `union atom has no value box` | a neighbour |
| a map bound first (`const m: { [string]: U } = Map(); const j: U = m`) | runs | **yes** |
| an argument (`f(Map())`) or an assignment (`j = Map()`) | invalid wasm the same | no |
| `[]` into `null \| f64 \| U[]` | runs | **yes** |
