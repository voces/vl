### D9660 — a local bound to a list of un-annotated functions, returned from a function with an un-annotated parameter, has no function-value signature

**closed · runs, prints `6` · was loud emit reject, `vl check` rc 0, clause 2 · found closing [D9553](D9553.md) · filed 2026-10-22 against master `abe12f20f` · closed with [D9662](D9662.md): the instance takes its own copy of the returned binding, and `monoPinListElems` annotates it as this instance's alone (`monoInstOwnNameList`, emit_mono.vl) · fixture `closures/hole-fn-bound-list-returned-from-hole-param.vl`**

Repro:

    function inc(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function deliver(n) {
      const w = [inc, dbl]
      return w
    }
    const v = deliver(1)
    print(v[1](3))
    // vl check rc 0.  vl run: emit error: emitProgram: a function-value call has no interned signature

Want:

    6

#### Mechanism

The same root as [D9662](D9662.md), at a flat list. The instance of `deliver` wrote the local's
open type as its return annotation, `((_) => _)[]`, and the call `v[1](3)` was emitted at that
open element type. The instance now takes its own copy of the returned binding instead
(`MONO_OUT_OWN_COPY`, `monoLetOwnCopy`, emit_mono.vl). `monoPinListElems` annotates that copy at
the instance's pin as this instance's alone, not as a binding its instances share
(`monoInstOwnNameList`).
