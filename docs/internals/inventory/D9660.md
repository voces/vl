### D9660 — a local bound to a list of un-annotated functions, returned from a function with an un-annotated parameter, has no function-value signature

**loud emit reject · `vl check` rc 0 · `a function-value call has no interned signature — parameter 1 of type `` has no representation in the function-value ABI` · clause 2 · found closing [D9553](D9553.md) · present on master `abe12f20f` · filed 2026-10-22 against master `abe12f20f`**

Repro:

    function inc(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function deliver(n) {
      const w = [inc, dbl]
      return w
    }
    const v = deliver(1)
    print(v[1](3))
    // vl check rc 0.  vl run: emit error: emitProgram: a function-value call has no interned signature

Want:

    6

#### Mechanism

Not traced. `deliver` is generic for its parameter alone, and the list it returns is the local
`w`, not a literal. `monoRetListLitOf` resolves a returned `const` to its literal, but the
returned slot's pin from `v[1](3)` does not reach the functions in `w`. The call `v[1](3)` is
then emitted at an open element type. The same function without the parameter runs, so the
instance walk is where the pin is lost.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the parameter (`deliver()`) | runs, `6` | **yes** |
| the local (`return [inc, dbl]`) | runs, `6` | **yes** |
| the un-annotated functions (`inc(a: i32)`, `dbl(a: i32)`) | runs, `6` | **yes** |
| the second function (`[inc]`, `v[0](3)`) | same refusal | no |
| the binding (`print(deliver(1)[1](3))`) | same refusal | no |
