#### Mechanism

`coal`'s `nulnone` arm runs the left for its effect (`nulNoneEffect`) as statement-level drop
nodes where the `??` is built, then returns the default as the value. Legacy writes the whole `??`,
the left for its effect and then the default, where its value is read. A consumer that writes
something first, such as `print`'s nullable-string guard or a nullable compare's guard head, puts
the IR's drops before its guard and legacy's inside it.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the field read (`n() ?? g()` against `u.tags ?? g()`) | still a byte mismatch | no |
| the default's call (`u.tags ?? "d"`) | matched | **yes** |
| the guarded consumer (argument, return, `let`, list element) | matched | **yes** |
| `print` for a nullable compare's left (`(u.tags ?? g()) == s`) | still a byte mismatch | no |

#### Grading list

`print(mk().tags ?? g())`, `print(u.tags ?? g())`, `(u.tags ?? g()) == s`, a `?.` left
(`w?.u.tags ?? g()`), a chain `a ?? b ?? g()` over two `null`-typed operands, and a global
initializer `const x: null = u.tags ?? n()` (`nulNonePayload`), which must stay byte-identical.
