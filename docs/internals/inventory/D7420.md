#### Mechanism

The write scan finds the frame that declares a written name through two open-addressed tables keyed
on the pair (frame, sid): `cwDeclSlotOf` behind `cwFrameDeclares`, and `cwIxPSlotOf` behind the
per-frame name index. Both placed a pair at `(fr + 3) * 1000003 + sid` modulo a power-of-two table
and probed linearly. Sids are minted in order, so a frame's names are consecutive integers and the
additive key laid each frame out as one run of occupied slots. Module scope declares thousands of
names. Every insert that hashed into that run, and every `cwFrameDeclares` miss that `cwFrameOfUse`
asks while it walks out from an inner frame, walked to the run's end. On diderven `src/game.vl`,
`cwDeclSlotOf` was 5.70% of the guest's samples (80% of it under `cwFrameDeclares`). After the change
it no longer appears in the profile. The remaining cost of the index is building it: `cwIxBuild` is
4.5% inclusive, once during `checkNode` (through `calleeTyIsScoped`) and once more from
`rcwRunPending`, because the arena has grown between the two.
