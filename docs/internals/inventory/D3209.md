### D3209 — a lambda argument's nullable literal-union result, returned through `string | null`, has no members to widen with

**loud emit reject · clause 2 · pre-existing, the same refusal on master `94670f728` · found writing the D3198 fixture · filed 2026-09-29 against master `94670f728`**

Repro:

    function wide(f: () => "c" | "d" | null): string | null { return f() }
    print(wide(() => "d") ?? "n")
    // vl check: rc 0.  vl run: emit refuses "literal-union string widening with no members"

#### Mechanism

Passing a lambda literal compiles `wide` as a specialisation whose `f()` call and callee record no
type (`nodeTyIxOf` answers -1 for both, and `cloCallCalleeFnTy` and `paramTypeNode` find no
function type either), so the widening at the return has no member texts. The same function
passed a bound lambda widens correctly.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const k: () => "c" \| "d" \| null = () => "d"`, `wide(k)` | prints `d` | **yes** (a lambda literal argument) |
| `wide` returns `"c" \| "d" \| null` | prints `d` | **yes** (the widening) |
| `const v = f()` then `return v` | prints `d` | **yes** (the call at the return) |
| result `"c" \| "d"` into `string` | prints `d` | **yes** (`null`) |
