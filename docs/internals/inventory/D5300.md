### D5300 — a `?.` read over a nullable union of records, outside a `??`, has no receiver rep

**loud emit reject · clause 2 · found closing D5243 · the same refusal on master `d1b078d59` · filed 2026-10-17 against master `d1b078d59`**

Repro:

    type N = { tag: "a", v: i32 } | { tag: "b", w: i32 }
    const y: N = { tag: "b", w: 2 }
    const q: N | null = y
    const t = q?.tag
    print(t ?? "z")
    // vl check: rc 0.  vl run: emitProgram: `?.` receiver is not a struct chain

Want:

    b

#### Mechanism

Not ablated past the table below. D5243's close desugars `r?.f ?? d` over a union-box
receiver into a null test and a narrowed read, when `f` is never null; a bare `r?.f`, or
one whose field can be null, is not desugared, and the `?.` lowering accepts only a struct
chain as its receiver.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `N` a single record `{ tag: "a", v: i32 }` | runs, `a` | **yes** |
| `print(q?.tag ?? "z")` in one expression | runs, `b` (D5243) | **yes** |
| `const t: string \| null = q?.tag` | refuses, the same | no |
| a nullable field `k: string \| null` in both arms, `print(q?.k ?? "nk")` | refuses, the same | no |

#### Grading list

The annotated binding above; a `?.` read delivered as an argument and as a return value.
