### D17860 — a `let` of an un-annotated function parameter, written again and called at two types, has no instance per call

**loud emit reject · `a generic function taken as a value reaches no call that fixes its type` · clause 2 · `vl check` rc 0 · filed 2026-11-28 against master `8470351db` by COV-CLOS-3 (found ablating D17323/D17324)**

Repro:

    function same(k) { return k }
    function mid(a) {
      let b = a
      b = a
      print(b(3))
      print(b("y"))
    }
    mid(same)
    // vl check: rc 0.  vl run: emit error at 8:5, "a generic function taken as a value reaches no call that fixes its type"

Want:

    3
    y

#### Mechanism

Not traced. The write is the ingredient: the same `let` with no write runs, and so does a
top-level `let b = same; b = same`. A write marks the binding as written, and the per-call
instancing of the parameter's value does not follow a written binding.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the write `b = a` | runs, prints `3` / `y` | **yes** |
| the second call shape (`b(4)`) | runs | **yes** |
| one call | runs | **yes** |
| the parameter (top-level `let b = same; b = same`) | runs | **yes** |
| `same` declared `<T>` | still refuses | no |

#### Grading list

A lambda argument, `mid((k) => k)`, refuses with another sentence,
`monomorphize: unsupported argument type for `a` in a call to `mid``; its close must re-grade it.
Two parameters, `let b = a; b = a1`, is [D17861](D17861.md).
