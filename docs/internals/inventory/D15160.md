### D15160 — a bound call result delivered wider is handed to a generic whose instance a held argument pins at the call's own type, unconverted

**check-clean invalid wasm · clause 1 · 14 of 16 cells of a reach × pin grid (below) · found grading [D14818](D14818.md)'s controls · filed 2026-11-03 against master `b8e3f740`**

Repro:

    type Circle = { r: i32 | null }
    type K = { r: null }
    function sink(_x: Circle) { }
    function mkcall() { { r: null } }
    const k: K = { r: null }
    function both<T>(a: T, b: T): i32 { 1 }
    const c = mkcall()
    sink(c)
    print(both(c, k))
    // vl check: rc 0.  vl run: the emitted module failed to validate inside the module's top-level code: expected (ref $0), found (ref $0); $0 is `K`

Want:

    vl check refuses: c is built as Circle where `sink(c)` delivers it and is handed on at its own type

#### Mechanism

`mkcall` is built at `Circle`, because `c` is delivered to `sink`. `both(c, k)` instances `both` at
`K`, the type the held `k` pins, and hands `c` to it at `K`'s row unconverted. `c` is a binding,
not a fresh call, so [D14817](D14817.md)'s copy does not apply, and DECISIONS.md §"A fresh record
converts at one delivery point" says this spelling keeps [D14814](D14814.md)'s refusal. The
refusal the binding spelling gets (`const d: K = c`: "this value is built as Circle where line 8
delivers it, and it is handed on here at its own type") is not asked of a generic argument whose
instance another argument pins.

| `const c = { r: null }`, a literal, in place of the call | refused | **yes**, the call |
