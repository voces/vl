Repro:

    function id<T>(x: T): T { x }
    const xs = [id, id]
    let i = 1
    const s = xs[i]("abc")
    print(xs[i](2))
    print(s)
    // vl check rc 0.  vl run: emit error: emitProgram: a generic function taken as a value reaches no call that fixes its type

Want:

    2
    abc

#### Mechanism

A computed-index read is rewritten only inside a call statement the plan can order
(`monoFlowCallStmtOf`, `monoFlowRunsFirstIn`, emit_mono.vl). A module-level `const`
initializer is not in a block: the emitter runs it from the global initializers, so
`monoFlowCallStmtOf` found no statement and the read declined; inside `main()` it runs. The
initializer is now its own statement, and the kept-index copy is ordered just before it among
the global initializers (`monoFlowKeepIndex`).
