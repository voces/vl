### D9483 — a computed-index call through a list of a generic as a module-level `const` initializer reaches no call that fixes its type

**loud emit reject · `vl check` rc 0 · `a generic function taken as a value reaches no call that fixes its type` · clause 2 · found closing [D9440](D9440.md) and [D9441](D9441.md) · present on master `0be192a3f` · filed 2026-10-21 against master `0be192a3f`**

Repro:

    function id<T>(x: T): T { x }
    const xs = [id, id]
    let i = 1
    const s = xs[i]("abc")
    print(xs[i](2))
    print(s)
    // vl check rc 0.  vl run: emit error: emitProgram: a generic function taken as a value reaches no call that fixes its type

Want:

    2
    abc

#### Mechanism

Not traced. From the ablation only: a computed-index read is rewritten only inside a call
statement the plan can order (`monoFlowCallStmtOf`, `monoFlowRunsFirstIn`, emit_mono.vl);
the same call as a module-level `const` initializer is not one, and inside `main()` it runs.
