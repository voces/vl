### D2218 — an empty `[]` passed to an un-annotated parameter the callee pins is built as the i32 list

**check-clean invalid wasm · found by D2209's position grid · filed 2026-09-23 against master `327b15510`**

Repro:

    function take(a) {
      a.push("x")
      print(a.length)
    }
    take([])
    // vl check: rc 0.  vl run: invalid module inside `take`, `expected i32, found (ref $type)`

#### Mechanism

The parameter solve reads the call site's argument, an empty `[]` whose element is still
open there. So `take` is instantiated over the i32 list, and then its own `.push("x")` pins
the element to `string`. Ablation: `take(["a"])` runs, and so does `a: string[]` with
`take([])`. Both ingredients are needed: the empty literal, and the element pinned only
inside the callee.

#### Grading list

The `argument` un-annotated cell of D2209's grid's `bare` form, at every element type but
`i32`.
