### D15773 — D15451's `const` choice handed to a hole parameter twice is refused at emit

**loud emit reject · clause 2 · `emitProgram: monomorphize: unsupported argument type for `f` in a call to `both`` · found closing D15451 · filed 2026-11-12 against master `83529fcb`**

Repro:

    function both(f) {
      print(f("a"))
      print(f(1))
    }
    function nested(c: boolean, n: i32) {
      function inner(s) { print(n); return s }
      function ask(s) { return s }
      const g = if c { inner } else { ask }
      both(g)
      both(g)
    }
    nested(true, 9)

Want:

    9
    a
    9
    1
    9
    a
    9
    1

#### Mechanism

`inlineConstRecArgs` writes a pure `const` choice of named functions into its call argument only
when the binding has one read, where `emitBundleChoiceArg` builds the record of the taken arm
(D15450). With two reads the binding stays one closure, which `both` calls at two signatures.
Unmeasured beyond that.
