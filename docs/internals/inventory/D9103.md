#### Mechanism

Not traced. `monoPinFieldContainers` (emit_mono.vl) pins a container held directly in a
field of a `const` record literal, one level deep. A field whose value is itself a record,
spelled inline or through a binding, is not walked, so its row keeps the open field type.
