### D3024 — an un-annotated record literal is built as a union arm whose field names it shares, whatever the fields' scalar kinds

**closed · was check-clean invalid wasm, identical on master `cac5e4ad5` · the arm matcher `objMatchesVariantIdx` now refutes a field whose checked scalar kind cannot be stored at the arm's (`variantFieldKindFits`, the rule `declRowFieldKindFits` already applies to declared records) · fixture `tests/cases/unions/record-literal-other-kinds-not-an-arm.vl` · filed 2026-09-28**

Repro:

    const o = { kind: 1, n: 2 }
    type A = { kind: "a", n: i32 } | { kind: "b" }
    function sh(u: A): i32 { 0 }
    {
      type W = i32
    }
    print(o.n)
    // vl check: rc 0.  vl run: failed to parse WebAssembly module: expected (ref $type), found i32

Want:

    2

#### Mechanism

An un-annotated object literal that no struct row claims asks `objVariantName` for a union arm
with the same field-name signature, and `objMatchesVariantIdx` tightened only map and nested
struct fields. Every scalar field agreed by name alone, so `{ kind: 1, n: 2 }` was built as the
arm `{ kind: "a", n: i32 }`, and `struct.new` stored the `i32` `1` into the arm's string slot.
The block-scoped `type W` in the filed witness is scenery: the program fails the same way
without it, and without the function `sh`. The matcher now reads the field's checked kind off the
literal's type and the arm's off `uVarTyIx`, and refuses a pair `fieldKindWidens` does not admit
(`i32` into `string`, `boolean` into `i32`, `f64` into `boolean`), keeping the widenings a record
may take (`i32` into `f64` or `i64`).

#### Grading list

A 294-cell grid: the literal's `kind` (i32, boolean, string, f64, i64, a string literal) against
the arm's (i32, boolean, `"a"`, string, f64, i64, `"a" | "b"`), at seven positions (module
binding, function binding, return, list element, closure capture, nested field, reassigned
`let`). On master 146 cells were invalid wasm and 148 ran; after the fix all 294 run and print
the literal's own values. The matching cells (`"a"` into `"a"`) still build the arm.
