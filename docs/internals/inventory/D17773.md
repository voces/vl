#### Mechanism

Not traced: `tm` holds a tagged set's member ids and `hm` holds closures, both pinned at
`(i32) => i32`, so the two map types close to one `{[string]: (i32) => i32}` whose layout cannot
be both. D17770's retype leaves a closure record at a signature a tagged record holds as checked,
so this program keeps the refusal rather than an internal error.
