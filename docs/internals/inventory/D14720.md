#### Mechanism

`monoArgTyName`'s closed-type pin spells a record-holding argument by its declared names
(`monoRecordNominalPin`): a declared record or a generic application by its name. Here `z` is the
literal's own structural type `{xs: {n: i32}[]}`, so `z.xs` is `{n: i32}[]`, which no declared
type names, and the pin declines to the cascade, whose rungs have no answer for a list read
through a hole's field. The record's name is its build row, which the checker does not yet stamp
per node (cascade fact 1's blocker, container adoption).
