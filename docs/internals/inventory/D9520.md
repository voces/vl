### D9520 — a lambda taken as returning a string literal union is checked at its tail only, so a non-member early `return` reaches the emitter

**loud emit reject · clause 2 · the checker owes the refusal: a non-member TAIL refuses at check (`cannot assign () => string to 'h' of type () => K`), and an annotated `function h(): K` with the same early `return "z"` refuses at check (`"z"` is not one of K) · found closing [D9490](D9490.md) · present on master `0be192a3f` · filed 2026-10-22 against master `0be192a3f`**

Repro:

    type K = "x" | "y"
    const c = true
    const h: () => K = () => {
      if c { return "z" }
      "y"
    }
    print(h())
    // vl check: rc 0.  vl run: emitProgram: a returned string cannot be shown to be a member of the literal union this instantiation's result is

#### Mechanism

The string literal union rung of the lambda's contextual return adoption (`inferRetAdoptNiche`,
check_inferred_return.vl, `tyIsLitUnion(expRet) || expStrLit`) adopts `K` from the inferred
tail alone, so an early `return` of a string outside `K` passes check and is refused by the
emitter's member proof. The numeric twin (D9490) walks every valued return
(`numLitUnionAdoptsRet`); the same walk here would make this a check refusal.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the non-member early return (`return "x"`) | runs, prints `x` | **yes** |
| the lambda (a `function h(): K` with the same body) | check refuses | **yes** |
| the early return, moving `"z"` to the tail | check refuses | **yes** |
