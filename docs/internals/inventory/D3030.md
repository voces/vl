#### Mechanism

Not yet located. The same field read through the narrowed handle runs in every other consumer:
bound first (`const v = u.x`, then `v ?? 5`), tested (`u.x != null`, `u.x == null`), and the
same `??` over a plain record's field (`type B = { x: i32 | null }`). A `string | null` field
under the same `is` runs too, so the refusal is the `??` lowering's operand ladder missing the
`i32` niche read off a narrowed union arm, the rep the other consumers already reach.
