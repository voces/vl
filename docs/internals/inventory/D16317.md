#### Mechanism

The union's function member, whose result is a list of functions, is never built: the only
value delivered is the scalar. The `is` arm still calls through the member, and that call's
signature (a function returning a list of function values) is not minted, because no closure of
that type exists. The same program runs as soon as any value of the member is built, and runs
when the member's result is a list of scalars or a single function.
