#### Mechanism

The type env (check_scopes.vl) stores one type per declaration: `envDeclTop[decl]` is the
declaration's innermost entry, and each frame maps a name to its entry. A read that holds a node
(an `Ident`, a declaration in hand) reads through the binder's `identDeclOf` and never through a
name, via `identTyOf`, `identDepthOf`, `declTyOf` and `declDepthOf`.

The flow writers still hold only a name. They re-bind it as a layer over whatever the name
reaches now, so `declare(name, ty)` asks `envDeclOfNameForFlow(name)` for the slot to layer.
The by-name readers (`lookup`, `lookupDepth`, `lookupDepthSid`) serve the same
callers. This is the witness's path: the `x != null` narrowing is a `declare("x", i32)`.

Callers of the by-name writer `declare`:

| file | site |
| --- | --- |
| check_capture_widen.vl | the capture widening |
| check_narrow_flow.vl | three narrowing and restore sites |
| check_operators.vl | the two `&&`/`\|\|` narrowing sites |
| check_program.vl | the extern-function bindings (no node declares them; the slot is ambient) |
| check_node_rules.vl | two narrowing sites |

#### Deletion

B2 converts each flow writer to name the declaration it narrows, read from the node it narrows
on. Then `envDeclOfNameForFlow` and the by-name `lookup*` readers are deleted. While the map
stands, no `Ident` path may consult it.
