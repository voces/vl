**closed 2026-11-28 by lane START-2 — the witness prints `7.5` · the tag plan tags a set whose sole call results are fresh record literals (`ftCallFreshLits`), so the result holds ids; the annotated destination builds its record field by field from the call's row (`recFreshConvert`), converting each id to a closure, and a value arm per member at the field's signature (`ftBuildValueArms`, read by `fnTagValueArms`) pins the instance the conversion takes · fixture `tests/cases/functions/returned-record-several-fields-fn-value-converted.vl` · was: loads then traps · clause 1 · `vl check` rc 0, `wasm trap: indirect call type mismatch` · filed 2026-11-27 against master `a1edbdabf`**

#### Mechanism

[D17764](D17764.md)'s converting copy, `{ f: site.f }`, reads its call once only for a record of one
field; a copy of several fields would read the call once per field, so it is not made, and the
result keeps the annotated destination's closure layout. The copy needs the call's value bound
once (a temporary the rewrite introduces) before its fields are read.
