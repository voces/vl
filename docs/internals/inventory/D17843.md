#### Mechanism

`zs` is one storage delivered whole to two mutable list parameters at `(i32) => i32` and
`(string) => string`. Before #10736 the delivery reached emit and was refused (`a generic function
taken as a value reaches no call that fixes its type`); since it, each write of the holder is
adapted through one slot reader and the list is built at the first destination's element, so the
second call reads it at the other signature. The design owes a check refusal here (one storage,
two closed element types: D17819's container contract), not a run at either. Bisected on L1
builds over `d76847374..73e834646`: `f011dc749` emit error, `e68eafd9a` (#10736) trap.
