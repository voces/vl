### D15045 — a `(string | null)[]` spread into a `(string | null | i32)[]` is invalid wasm

**closed 2026-11-02 · runs, prints `3` · was check-clean invalid wasm, clause 1 · `spreadBoxingSource` boxes a string-kind source into a nullable element other than a nullable string, and `emitScalarListBoxTop` boxes a `(string | null)[]`'s nulls as the union's null box (`spreadSrcNulString`) · fixture `tests/cases/lists/spread-nullable-string-list-into-union-list.vl` · [D2969](D2969.md)'s spread-boxing family, found grading it · filed 2026-11-02 against master `a4e00240`, pre-existing**

#### Mechanism

`(string | null | i32)` is a nullable over `string | i32`, and `spreadBoxingSource` let every
string-kind source into a nullable element copy as it is, the rule for `(string | null)[]`, which
shares the string list's rep. Here the destination is a list of union boxes, so the copy handed
string refs where boxes belong. The boxing copy that a `string[]` source already takes had no arm
for a null element, which the union stores as a box with the null tag.
