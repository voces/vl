### D17441 — a null `F | null` stored into a union with a closure arm boxes under the closure tag, so `== null` reads `false`

**closed 2026-11-24 by S2 · runs, prints `true` · was check-clean silently wrong, clause 1, legacy · a nullable closure stored into a union that admits `null` now boxes its null as the union's (`emitUnionBoxNulNiche` and the HoleBox `nulNiche` arm accept `exprNulClosure`; `coalNicheBoxTag` gives the closure arm's tag) · owner S2 · found by the D17380 re-box sweep · filed 2026-11-24 against master `69d0467e`**

Repro:

    type F = (i32) => i32

    function pass(f: F | null) { isNull(f) }
    pass(null)

Want:

    true

#### Mechanism

The store of an `F | null` value into a union box took the plain closure arm: the box was built
with the closure tag over a null payload. A `== null` on the box tests the null tag, so it read
`false`; a narrowing back to `F | null` (D17380's niche read) cast the null payload to the closure
and trapped. The ref-niche store that boxes a null as the union's null (`emitUnionBoxNulNiche`)
took strings, records, variants and lists, never a closure.

#### Ablation

Master `69d0467e` and the fix; a null and a non-null closure stored at each position, then `== null`:

| position | master, null | fix, null | non-null, both |
| --- | --- | --- | --- |
| an argument, a `const`, an assignment, a return, a global, a field, an element | `false` | `true` | `false` |
