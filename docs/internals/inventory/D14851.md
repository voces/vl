#### Mechanism

At `3`, `half` gives `f64` and `dbl` gives `i32`, so the call's result is their union. The call
inside the instance is typed at the list's rep, an i32 id, and the dispatch finds no one result
of its arms (`fnTagArmsOneTy`), so it has no rep to box the union into. `vl check` is clean, so
the refusal is the emitter's (clause 2). Mono demanded the instance at the list's rep, which the
elaboration never ran, so the call was typed nowhere; at the instance the run built, its members'
results join.
