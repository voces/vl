### D14851 — a call through a list element of a set handed to a hole parameter whose members give different results at it has no rep

**loud emit reject · `a call through a function set has a result with no rep` · filed 2026-11-01 against master `909332406`**

Repro:

    function runF(fs) { print(fs[0](3)) }
    function half(u) { return u * 0.5 }
    function dbl(u) { return u * 2 }
    runF([half, dbl])

#### Mechanism

At `3`, `half` gives `f64` and `dbl` gives `i32`, so the call's result is their union. The call
inside the instance is typed at the list's rep, an i32 id, and the dispatch finds no one result
of its arms (`fnTagArmsOneTy`), so it has no rep to box the union into. `vl check` is clean, so
the refusal is the emitter's (clause 2).
