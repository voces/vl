### D2025 — a `: never` function whose body is a `while true` loop with no `break` is refused as able to return

**closed 2026-10-26 with D1973 — the witness prints `2` · a `while true` that no `break` leaves ends a path, so a `: never` body ending in one is total; a `break` or `break @label` out of it keeps the refusal · was loud check reject, clause 2 · residue of D1972 · filed 2026-09-22 against master `af07f4ae0` · fixtures `tests/cases/functions/never-paths-end.vl`, `tests/cases/functions/error-never-function-can-return.vl`**

Repro:

    function spin(): never {
      while true { print(1) }
    }
    print(2)
    // vl check: rc 1, `spin` is declared `never` but can return

#### Mechanism

A `: never` body is graded by `stmtAlwaysExits`, and that rule treats every loop as falling
through, because a `break` in it leaves only the loop. A `while true` with no `break` binding to
it cannot complete, so the function genuinely never returns. Predicted to close with D1973, which
adds exactly that arm to the shared rule.

#### Grading list

D1973's own witness; a labelled `break` out of the loop must keep this refused.
