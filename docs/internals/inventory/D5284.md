### D5284 — the `_` arm of a literal-union `match` sees the whole scrutinee type, not the members left

**closed · was loud check reject · clause 2 · eardstap EV-006 · filed 2026-10-17 against master `3f6a785db`**

Repro:

    type Kind = "a" | "b"
    type Wide = Kind | "c"
    function pick(k: Wide): Kind { match k { "c" => "a", _ => k } }
    print(pick("b"))
    print(pick("c"))

Want:

    b
    a

#### Mechanism

The Q10 ruling narrows `x == L`, but a `match` checked its `_` arm in the enclosing scope, so
the scrutinee there kept its declared type. The arm checker now subtracts every member the
earlier literal (and `null`) arms consumed and pushes that remainder as a narrowing for the `_`
body (`matchRestNarrows`, `check_narrow_flow.vl`). A flat union, a nested alias, a nullable
scrutinee, a member read and a statement `match` all take it. The accepted price is that an arm
for an already-consumed member is refused as redundant.
