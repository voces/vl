### D15092 — `==` between lists of lists whose leaf elements are stored apart is refused

**closed · runs, prints `true` · was a loud check reject, clause 2 · `xrepListPair` recurses through matching list levels and `emitListEqXCore` runs the same loop one level down at the inner reps, each level's frames reserved per side · matrix `xrep-nested-int-list-vs-float-list-eq` · the nested half of D15055's close · filed and closed 2026-11-03 against master `e1eb2e973`**

Repro:

    const a: i32[][] = [[1]]
    const b: f64[][] = [[1.0]]
    print(a == b)
    // was: vl check rc 1, "`==` over i32[][] and f64[][] has no lowering: the two are mutually
    // assignable but store their elements differently"

Want:

    true

#### Mechanism

D15055's cross-storage compare (`xrepListPair`, `emitListEqXCore`) reads one list level. A list
of lists needs the same loop one level down, with a frame per side at each level, and the
inner pair's reps resolved from the outer elements' slots.
