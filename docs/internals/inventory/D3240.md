### D3240 — a place a type-parameter write narrowed to non-null is read as non-null at a nullable pin

**loads then traps · clause 1 · pre-existing on master `d48a56b17` · found by the #3290 round-3 review · filed 2026-09-29 against master `94670f728` · the member-read refusal #3290 tried is parked with item 2 of [D3198](D3198.md)**

Repro:

    function g<T>(x: T) {
      let s: string | null = null
      s = "z"
      s = x
      print(s.length)
    }
    const v: string | null = null
    g(v)
    // vl check: rc 0.  vl run: null-reference trap

#### Mechanism

The shared body narrows `s` to `string` after `s = x`, which holds only at a pin that excludes
`null`. The gradual ruling puts the refusal at the instance's check. #3290 tried an emitter
refusal of a member read of the place at a null-bearing pin; it is parked with item 2 of
[D3198](D3198.md). `g("abc")` prints `3`.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `g("abc")` | prints `3` | **yes** (a nullable pin) |
| `print(s ?? "n")` instead of `.length` | prints `null` (the fold) | **yes** (a use needing non-null) |
| without `s = "z"` | the same trap | no |
