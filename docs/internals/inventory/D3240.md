### D3240 — a place a type-parameter write narrowed to non-null is read as non-null at a nullable pin

**closed 2026-09-30 · now a loud check reject, as the direct spelling · was loads then traps, clause 1, pre-existing on master `d48a56b17` · found by the #3290 round-3 review · filed 2026-09-29 against master `94670f728`, closed against master `5e277ab52` · fixtures `tests/cases/generics/type-param-write-reads-at-pin.vl`, `tests/cases/generics/error-type-param-write-read-at-nullable-pin.vl` · item 2 of [D3198](D3198.md) closed with it, bar the literal-union place ([D3423](D3423.md))**

Repro:

    function g<T>(x: T) {
      let s: string | null = null
      s = "z"
      s = x
      print(s.length)
    }
    const v: string | null = null
    g(v)
    // vl check: rc 0.  vl run: null-reference trap

#### Mechanism

The shared body narrowed `s` to `string` after `s = x`, which holds only at a pin that excludes
`null`. A write of a value typed at a declared type parameter into a place whose declaration
admits `null` (and holds no literal) now leaves the place reading as an `HD_TVW` derived hole: at
each pin it is the member of the declaration the pin lands on (`writeMemberTy`), so a nullable
pin reads the declaration and a non-null one its non-null face. The reads are re-asked at the pin
(`.length`, a field, an argument), the monomorphizer re-types a read of a bare name at the
instance, and the emitter retires the place's narrowing after the write, pushing the landed
member only where the instance's pin excludes `null` (`tvWriteNarrow`). A clone of an assignment
now answers the write's narrowing banks (`carryAsgBanks`), which the instance's element write
lost, and a `??` over an operand an instance re-typed to a non-null type folds, as the template's
rewrite folds a concrete one.

#### Ablation

| ingredient changed | outcome on master | needed? |
| --- | --- | --- |
| `g("abc")` | prints `3` | **yes** (a nullable pin) |
| `print(s ?? "n")` instead of `.length` | prints `null` (the fold) | **yes** (a use needing non-null) |
| without `s = "z"` | the same trap | no |
