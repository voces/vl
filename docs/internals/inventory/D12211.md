### D12211 — an exported generic function read as a value and never called passes the checker's export rule

**now a loud check reject · was a loud emit reject after `vl check` rc 0 · clause 2 · DESIGN: the checker refuses the same export with no read (D3817), so it owed this one · closed 2026-10-24 by lane L3 (d): an export whose every read outside its body reaches no call is uncalled · residue still at the emit floor: [D12237](D12237.md) · pins: `tests/cases/functions/error-exported-generic-read-uncalled.vl`, `error-exported-generic-handed-to-uncalling-param.vl`, `exported-generic-read-through-closure-called.vl` · found surveying emit refusals for L3 family (d) · filed 2026-10-24 against master `b8e223f93`**

Repro:

    export function id<T>(x: T): T { x }
    const g = id
    print(1)

#### Mechanism

`expUncalledExports` (check_pins.vl) treated an export as called when any statement outside
its body named it (`expNameReaders`). A value read that is never called counted as a reader,
so the checker passed the export and the monomorphizer refused at emit_mono.vl's
exported-generic floor. The checker now asks the shared flow analysis: when every read of the
export outside its own body is `vrInert` (`vrOuterReadsInert`, value_reach.vl), nothing calls
it and nothing observes its signature, so D3817 refuses it. A read the analysis cannot prove
inert (a lambda's result, a `Map` write, a field write) still passes, and is
[D12237](D12237.md).

Three programs move from runs to a check reject: `function h(f) { 0 }; print(h(id))`, the
same with `h<F>(f: F)`, and `export function id(x) { x }; const fs = [id]; print(1)`, whose
un-annotated parameter ran on an `i32` guess. In each, no read calls `id`, and the export with
no read is already refused at its direct spelling (D3817).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the read (`const g = id`) | check reject, D3817 | **yes** |
| `export` | runs (an internal generic with no instance is stubbed) | **yes** |
| a call through the read (`print(g(1))`) | runs | **yes** |
| the read at top level (`function u() { const g = id }`, `[id]`) | check reject, as the witness | no |
