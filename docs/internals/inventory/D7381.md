### D7381 — an un-annotated list whose element is an `if` choosing between generic functions, inside a generic called at two types, is refused

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same list in a non-generic function runs ([D7380](D7380.md)), and so does `[a]` in the generic · found closing [D7380](D7380.md) · present on master `622d88f2c` · filed 2026-10-19 against master `622d88f2c`**

Repro:

    function a<V>(v: V) { print("a"); print(v) }
    function b<V>(v: V) { print("b"); print(v) }
    function g<T>(x: T, c: boolean) {
      const fs = [if c { a } else { b }]
      fs[0](x)
    }
    g(3, true)
    g("s", false)
    // vl check: rc 0.  vl run: emitProgram: a function value's signature is not known at this call — the type it was given takes fewer parameters than the call passes

Want:

    a
    3
    b
    s

#### Mechanism

Not located. The slot's pin depends on the instance (`x: T`), so the list's shared declaration
is not given it (`monoDeclPathPinsPerInstance`), and nothing else types the `if`'s arms per
instance: the element keeps the arms' unpinned type, which takes no parameter.
