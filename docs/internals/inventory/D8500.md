### D8500 — a root served from its importer's check reads the importer's use of a top-level record that the root alone never sees

**now a loud check reject on a.vl's check and check-clean on r.vl's, at every worker count, closed by lane writer-guard making a sole-reference grade that fails ask `e` of the name · on master `931fbf266` `vl check a.vl r.vl` found 2 errors at `VL_JOBS=1` (r.vl served from a.vl's check) and 1 at `VL_JOBS=6` · serving consistency · found by lane S5 · filed 2026-10-20 against master `931fbf266`**

Repro:

    // file: s.vl
    export type S = { v: i32 | null }
    export const st: S = { v: 1 }
    // file: r.vl
    import { S, st } from "./s"
    export function g(q: S): i32 {
      if (st.v != null) {
        q.v = null
        return st.v
      }
      return 0
    }
    // file: a.vl
    import { st } from "./s"
    import { g } from "./r"
    print(g(st))
    // vl check a.vl: rc 1, r 5:15 'st.v' is no longer narrowed.  vl check r.vl: rc 0.
    // vl check a.vl r.vl: 1 error at every VL_JOBS; on master 2 at VL_JOBS=1.

#### Mechanism

`st.v` keeps its narrowing across `q.v = null` only while `st` is a sole reference
(`crSoleRefHolds`, check_getter_effects.vl, D2584): a top-level record no statement of the
program hands on cannot be aliased by `q`. That is a whole-program answer. r.vl's own program
never hands `st` on, so r.vl alone is clean; a.vl's program passes it to `g`, so there the
narrowing ends and r.vl reports the error. Both answers are right for their own program, so the
root r.vl must report what its own check reports.

Serving decides whether r.vl's own check would read the same as a.vl's reading of r.vl's
closure through the asks the check recorded (`crAskProg`); the writer guard (`skWriterMoved`,
driver.vl) declines when a name asked `e` of is used as a value outside the closure. The sole
grade asked `e` only when it held (`crSoleRefBinding`); a grade that failed recorded nothing, so
a.vl's `g(st)` was invisible to the guard and r.vl was served a.vl's error. A failed grade now
asks too, and the guard declines.
