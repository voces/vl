### D2913 — `.length` over a union with a list-of-readonly-lists member is invalid wasm

**check-clean invalid wasm · clause 1 · the same on master `1f092d569` · found by the #3235 review · filed 2026-09-27 against master `1f092d569`**

Repro:

    function d(x: (readonly i32[])[] | string[]) {
      print(x.length)
    }
    d([[1, 2], [3]])
    d(["q"])
    // vl check: rc 0.  vl run: invalid module inside `d`

Want:

    2
    1

#### Mechanism

Not localised past the ablation. D2874's list-union rewrite reads `.length` through an `is`
chain over the members, and the arm for a list whose element is a readonly list reads it at a
rep the box's payload cast does not produce. A union with a readonly member beside any member
that holds a readonly list (`readonly (readonly i32[])[] | string[]`,
`(readonly i32[])[] | readonly string[]`) is declined by the rewrite, a loud check reject as
on master, until this is fixed; without a readonly member the rewrite runs as on master.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the inner `readonly` (`i32[][] \| string[]`) | runs | **yes** |
| `.length` (`if x is string[] { print(x[0]) } else { print(x[0][1]) }`) | runs, prints `2` then `q` | **yes** |

#### Grading list

`readonly (readonly i32[])[] | string[]` and `(readonly i32[])[] | readonly string[]` with
`.length` and `for`-in once `luMembers` lets them through; the element types
`(readonly i32[] | null)[]`, `(i32 | readonly i32[])[]` and `(readonly (readonly i32[])[])[]`
beside a readonly sibling are the #3235 round-2 review's grid.
