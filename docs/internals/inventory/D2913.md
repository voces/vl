### D2913 — `.length` over a union with a list-of-readonly-lists member is invalid wasm

**check-clean invalid wasm · clause 1 · the same on master `1f092d569` · found by the #3235 review · filed 2026-09-27 against master `1f092d569`**

Repro:

    function d(x: (readonly i32[])[] | string[]) {
      print(x.length)
    }
    d([[1, 2], [3]])
    d(["q"])
    // vl check: rc 0.  vl run: invalid module inside `d`

Want:

    2
    1

#### Mechanism

Not localised past the ablation. D2874's list-union rewrite reads `.length` through an `is`
chain over the members, and the arm for a list whose element is a readonly list reads it at a
rep the box's payload cast does not produce. The readonly spelling of the outer member,
`readonly (readonly i32[])[] | string[]`, is declined by the rewrite (a loud check reject)
until this is fixed.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the inner `readonly` (`i32[][] \| string[]`) | runs | **yes** |
| `.length` (`if x is string[] { print(x[0]) } else { print(x[0][1]) }`) | runs, prints `2` then `q` | **yes** |
