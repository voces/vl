#### Mechanism

Traced, not fixed. The write widens `t.f`'s set to `{inc0, dbl}`, which is tagged, while the
initializer's `[inc0]` keeps its one-member set: the conversion at the initializer is between two
lists printed `((i32) => i32)[]` whose element types carry different sets (probe: sets 2 and 1,
reps 0 and 2), one stored as the set's ids and one as closures. Giving the record row's untagged
field its value's closed stamp in `objLitTaggedFieldRow` (D15560's widening restamp) does not
close it.
