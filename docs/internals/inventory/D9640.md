### D9640 — a record of an un-annotated function bound to a `const` and then listed leaves the function unpinned when the element is handed to an un-annotated parameter

**loud emit reject · `vl check` rc 0 · `emitProgram: cannot take the generic function `inc0` as a value` · clause 2 · found closing [D9570](D9570.md) · present on master `9e81d3ee3` · filed 2026-10-22 against master `9e81d3ee3`**

Repro:

    function inc0(a) { return a + 1 }
    function take2(a) {
      print(a.f(3))
    }
    const e = { f: inc0 }
    const xs = [e]
    take2(xs[0])
    // vl check rc 0.  vl run: emit error: emitProgram: cannot take the generic function `inc0` as a value

#### Mechanism

Not traced. The literal written inside the list (`[{ f: inc0 }]`) runs since [D9570](D9570.md);
bound first, `inc0` is taken as a value at the binding, which no call pins.

| ingredient removed | outcome | needed? |
| --- | --- | --- |

| the hole in `inc0` (`inc0(a: i32): i32`) | runs, `4` | **yes** |
