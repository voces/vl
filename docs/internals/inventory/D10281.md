### D10281 — a function named like a member any body reads holds its runtime `i32`/`f64` join at `f64`

**closed · runs, prints `0` `true` · was loud check reject, clause 2 · found closing [D10090](D10090.md) · present on master `d5ec7f160` · filed 2026-10-22 against master `cf2f91c99` · closed by no longer recording a top-level member read as a name a call may reach (`njGateScan`, check_nj_gate.vl): a member is recorded only where a lambda body or a generic or hole body mentions it, which a dispatch through it may reach (`njMentionAt`) · fixture `numerics/recursive-generic-joins-runtime-numbers-apart.vl`, new matrices `member-named-fn-runtime-numeric-join` 0 → 48 of 48 and its `-open` twin 0 → 48 of 48**

Repro:

    function get(q: i32 | null, d: f64) {
      const r = if q != null { q } else { d }
      print(r is i32)
    }
    const m: Map<string, i32> = Map()
    print(m.get("a") ?? 0)
    get(5, 1.5)
    // vl check: `is` check type 'i32' can never match a value of type f64

Want:

    0
    true

#### Mechanism

`njGateScan` (check_nj_gate.vl) records every member name the program reads, `m.get` here, as
a name a call may reach other than directly, so `njFnReached` gates the unrelated top-level
function `get` and its join stays at master's widening. The function does not recurse and is
never read as a value.
