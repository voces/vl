#### Mechanism

[D10120](D10120.md)'s slot judge asked only whether the call's argument types fit each
fixed-type function's parameters, and `3` fits `name`'s `i32`. The call instances `id` at
`i32`, so the slot holds `(i32) => i32` beside `(i32) => string`; the two results disagree,
which the judge did not compare.
