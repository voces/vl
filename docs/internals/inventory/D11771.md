#### Mechanism

Emit passes call back into the checker: `collectS` resolves the bound alias `Showable` as a
value type and raises `methodInValuePosMsg`, and `monomorphize` re-asks parked argument
demands at each pin through `argPinRecheck` (D10271's `argument 1: expected () => T, got
() => null`). Both push to `T.diags`. `compileSrc` returns 0 once `emitProgram` succeeds, so
`vl build` and `vl run` ignore them, but `vl check --codegen` and the editor's compile read
every diagnostic and reported them as errors. Over all 3,686 inventory witnesses, these two
are the only verdicts the change moves.
