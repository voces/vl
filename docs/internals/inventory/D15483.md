#### Mechanism

`scripts/late-demands.vl` runs `vl check --codegen` under `$VL_LATE_DEMANDS=1`, and the host
reports a file's late demands only in the `CMD_VALIDATE` round-trip, which the driver issued only
for a compile that returned 0. A program whose emit refuses never reached it, so its late demands
were not counted. In `closures/listed-hole-fn-escaping-list.vl` the emitter demands `use`'s
instance after `elabRun` returned (`vl build` prints `[late] demand use`), and the gate read 0.

The fix hands an emit refusal's bytes over too (`cliCheckCurFile`, cli.vl) and drops the engine's
verdict on them, so the gate measures 6,329 programs where it measured 6,289. The late demand
itself is open: the baseline records it, and a rise fails the gate.
