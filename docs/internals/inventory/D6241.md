### D6241 — two bindings of `fw(lam)`, one per type, are refused at `fw`'s argument

**loud emit reject · `vl check` rc 0 · clause 2 · found closing [D6201](D6201.md) · the same on master `dfcac226b` · filed 2026-10-17 against master `dfcac226b`**

Repro:

    function fw(f) { return f }
    const lam = (x) => x
    const q = fw(lam)
    const r = fw(lam)
    print(q(3))
    print(r("w"))
    // vl check: rc 0.  vl run: emitProgram: monomorphize: unsupported argument type for `f` in a call to `fw`

Want:

    3
    w

#### Mechanism

From the ablation only. D6201's close gives ONE binding of `fw(lam)` a slot per type, each
holding a copy of the lambda. With two bindings each is called at one type, so neither is
split, and `fw` is instanced once with the lambda pinned at one type for both reads.
