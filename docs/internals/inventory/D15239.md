### D15239 — a record literal assigned into a binding initialised from a call built at a wider record is check-clean invalid wasm

**closed 2026-11-04 · runs, prints `6` then `4` · was check-clean invalid wasm, `vl check` rc 0 · clause 1 · found grading [D15237](D15237.md) · filed 2026-11-04 against master `549ac7fc` · closed by the store column, which records the binding held at the call's build (`storeLetsResolve`, D15172), stamping each record literal assigned into it there with D15188's stamp (`storeAsgLitsBuild`, since folded into `recLitPlaceBuiltTy` by [D15282](D15282.md), `adoptLitAt`) · fixture `tests/cases/soundness/record-literal-assigned-into-call-built-binding-runs.vl` · a literal chosen by an `if` is [D15280](D15280.md)**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    let y = mk()
    y = { f: 6 }
    print(y.f)
    print(wideJ.f ?? 0)

Want:

    6
    4

#### Mechanism

`mk`'s result is built at `J`, so `y` holds a `J`, and the literal is
built at its own `{f: i32}`. The pass-end literal stamp (D15188) answers an assignment into a
binding whose initialiser is a built READ (`recBuiltReadTy`), not a call with a recorded build
(`callBuiltTy`), which lives in the store column, after the stamp has run.
