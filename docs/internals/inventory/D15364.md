### D15364 — an un-annotated function returning a call through an element of a widened list of functions of different results is check-clean invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · open, target `1.5` · found closing [D15363](D15363.md), whose lift reaches this from a literal too · filed 2026-11-04 against master `73062b831`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function run(xs) { return xs[1](3) }
    const xs = [inc0]
    xs.push(half)
    print(run(xs))

Want:

    1.5

#### Mechanism

Not ablated past the table. The validator reports `type mismatch: expected i32, found f64` inside
`run`. The instance's inferred return seems to take the first member's result, `i32`, while the call
through the element, which runs the member it reads, hands back `f64`. With the return annotated, or
with the result bound and printed rather than returned, the same call runs.

#### Ablation

| spelling | outcome |
| --- | --- |
| this repro | invalid wasm |
| `xs[0] = half` in place of the push | invalid wasm |
| `big(a) { return a > 1 }` in place of `half` | invalid wasm |
| `run(xs): f64` annotated | runs |
| `const r = xs[1](3); print(r)` in `run` | runs |
| the same list in `run`'s own scope, returned | runs |
