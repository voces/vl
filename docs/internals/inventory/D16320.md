### D16320 — a record test over records it contains that share one tag with a member it does not is refused at emit

**open · loud emit reject · `emitProgram: `is` names a type that is not a union variant` · clause 2 · the whole operand contained runs since D4085's close · found closing D4085 · filed 2026-11-14 against master `f302cdde` with lane L's PR-1 change**

Repro:

    type A = { x: i32 }
    type B = { x: 1 | 2 }
    type D = { x: 3 | 4 }
    type C = { z: string }
    function g(b: B | D | C): i32 { if b is A { return b.x } 0 - 1 }
    print(g({ x: 2 }))
    print(g({ x: 4 }))
    print(g({ z: "q" }))

Want:

    2
    4
    -1

#### Mechanism

Not yet ablated past its ingredients. The checker tests `B | D` (`tyTestMeet`). `B` and `D` share
one tag, told apart by the field's value (D3885), so the emitter's multi-tag chain declines a
variant with a discriminating field, though every member holding that tag is tested.

| --- | --- | --- |
