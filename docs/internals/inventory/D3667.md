### D3667 — a capturing block-local function recursing in tail position overflows the stack: each level rebuilds its closure and calls through the table

**closed by [D3663](D3663.md)'s lambda lifting — the witness prints its Want; on master it trapped with a stack overflow after the closure-per-level recursion through `call_indirect` · lifted, the recursive call is a direct `return_call` · filed and closed by lane CL against master `32b753681` · fixture `tests/cases/closures/lift-local-function-tail-recursion.vl`**

Repro:

    function host(p: i32) {
      const step = p
      function go(n: i32, acc: i32): i32 {
        if n == 0 { return acc }
        return go(n - 1, acc + step)
      }
      print(go(100000, 0))
    }
    host(3)
    // master: wasm trap, call stack exhausted

Want:

    300000

#### Mechanism

A block-local function with a capture was called as a closure: `emitCapturedCall` built a
fresh closure value from the frame's captures and `call_indirect`ed it, so the recursive call
in `go` was never a tail call and each level kept a frame plus two allocations. Lifting turns
the call into `emitDirectCall`, whose tail-position cursor rewrites it to `return_call`.

#### Grading list

The `rec_lfn` and `rec_lfn_tail` spec cells of the lane-CL grid; a recursive block-local
function that ESCAPES (passed as a value) keeps the closure path and the depth limit.
