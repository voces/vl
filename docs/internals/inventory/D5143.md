### D5143 — `is` over an inline record whose field is a lone literal finds no union arm

**loud emit reject · `vl check` rc 0 · clause 2 · found ablating D5105 · filed 2026-10-16 against master `ed42d37ad`**

Repro:

    type N = { v: i32 } | { tag: "end" }
    function f(n: N): i32 { if n is { tag: "end" } { return 100 } 1 }
    const x: N = { tag: "end" }
    print(f(x))
    // vl check: rc 0.  vl run: emitProgram: `is` names a type that is not a union variant

Want:

    100

#### Mechanism

The arm `{ tag: "end" }` is stored with its lone literal field softened to `string`, while the
inline record named by the `is` keeps the literal, so the test finds no arm of the union.
Naming the arm by a declared alias runs. Not ablated past the ingredients below.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the arm named by an alias, `type E = { tag: "end" }`, `n is E` | runs, `100` | **yes** |
| the tested field spelled `string`, `n is { tag: string }` | runs, `100` | **yes** |
| the other arm `{ kind: "a", v: i32 }` | still refuses | no |
| the other arm `{ kind: "a" \| "b", v: i32 }` | still refuses | no |
