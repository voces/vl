### D15129 — a generic instanced mixed, a bound fresh call wider at one parameter and a held binding at its own record at another, relates the two

**open · check-clean invalid wasm · clause 1 · found closing [D15172](D15172.md) · filed 2026-11-03 against master `f4db9d2c6`**

Repro:

    type Circle = { r: i32 | null }
    type K = { r: null }
    function sink(_x: Circle) {}
    function mkcall() { { r: null } }
    const c = mkcall()
    sink(c)
    const k: K = { r: null }
    function rel<T>(a: T, b: { f: T }): T { if true { b.f } else { a } }
    print(rel(c, { f: k }).r ?? 6)

Want:

    6

#### Mechanism

`c` is built at `Circle` (`mkcall`'s literal is delivered into a `Circle` sink) and `k` at `K`.
`rel(c, { f: k })` binds `T` at two records, so the checker marks the call's rep row mixed
(`callBindRepMixedAt`): the instance keeps its own types while each argument is pinned at its
rep, which is `a: Circle` and `b: { f: K }`. A body that never relates `a` and `b` runs that way;
this one joins `b.f` and `a` into one `T`, and the two records meet in the `if`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `if` (`return b.f` alone) | runs | **yes** |
| `sink(c)` (`c` not built wider) | runs | **yes** |
