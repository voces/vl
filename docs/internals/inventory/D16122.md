#### Mechanism

`mvShapeOfMapNodeTy` (`emit_union_atoms`) mints an un-annotated `Map()`'s value slot under
`mapNodeValName`, which is `nodeTyMapValName` and therefore `mapTyValName` (`check_hole_pins`), a
render of the value type. The find side is `mvSlotOfTyKArm` by type. The two agree only while the
render is total and injective for the value. An open value renders to `""`: before D15941 that
was the outer map's refusal, and the pin now closes the value before the mint asks. The second
render-keyed mint found on 2026-11-14, after D16152. The witness runs and grades the path: a map
of maps whose slot is named by the render of `{[string]: (a: f64) => f64}`.
