### D14821 — a string assignment used as a value is invalid wasm as a `print` argument or at module scope

**check-clean invalid wasm · clause 1 · pre-existing on master `0a983e646` · found writing D14820's fixture · filed 2026-11-01 against master `0a983e646`**

Repro:

    let s = ""
    const q = (s = "hi")
    print(q)
    // vl check: rc 0.  vl run: invalid module, the emitted module failed to validate inside the module's top-level code

Want:

    hi

#### Mechanism

Not traced. Two spellings fail and their neighbours run, so it may be two mechanisms; the
ablation below is what is known.

argument) for a name target and a field target.
