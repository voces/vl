### D15805 — a call through a function field of a record nested in a list's element, the functions returning different types, is refused at check; lifted, it builds an invalid module

**closed 2026-11-12 · runs, prints `4` then `1.5` · was a loud check reject, `cannot store 'half' in 'pick()[].r.f': called at (i32) it returns f64, where 'inc0', also stored in it, returns i32 — every function a call through 'pick()[].r.f' may run must return one type`, clause 2, guarding a clause-1 hazard (lifted, it built an invalid module) · found closing D15801's two-returned-literals family · filed 2026-11-12 against master `b0219f456` · fixed by building a nested record of a list's element at the list's rep (bound) or its function's result (returned), and lifting the judge's one-result rule for that path**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function pick(b: boolean) {
      if b { return [{ r: { f: inc0 } }] }
      return [{ r: { f: half } }]
    }
    print(pick(true)[0].r.f(3))
    print(pick(false)[0].r.f(3))

Want:

    4
    1.5

#### Mechanism

The one-result judge (`holeSlotFieldLift`, check_relate_core.vl) lifts a path of an element step
then two or more fields when a record literal builds every record along it, in a bound list's
literal or a later push, or when a call returns the list. Three changes make the lifted
spellings run:

1. A bound list: the tag decision builds the element's records, and those nested in their
   fields, at the list's rep (`fnTagHeldRecLit`, check_elab_cap.vl), and finds a split set in a
   nested record field (`fnTagHasSplitFieldIn`).
2. A returned list: the return join (`elabFnArmJoinAt`) descends a returned list's record into a
   record field as a returned list's record, so that field's function field gets its apart note.
3. A returned list literal keeps the one-level split search, so it is built at its function's
   result. Searched deep, it took a held rep whose outer record (`{r:{f:i32}}`) minted a named
   row, while the result's same-shaped record minted an anonymous one, and `pick` failed to
   validate.
