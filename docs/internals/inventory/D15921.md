### D15921 — a list a function frame binds from a call's record, of records whose function field holds un-annotated functions returning different types, captured by a closure that calls through it, is refused at emit

**loud emit reject · `emitProgram: field access receiver is not a struct` · clause 2 · open · found by w320 beside [D15804](D15804.md) · filed 2026-11-12 against master `22d35fe47`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function mk() { return { a: [{ f: inc0 }, { f: half }] } }
    function fr() {
      const c = mk().a
      const f = () => { print(c[0].f(3) + c[1].f(3)) }
      f()
    }
    fr()

Want:

    5.5

#### Mechanism

Not traced. The capture in a function frame is the ingredient: the same list read in that frame
without a closure runs, as does the closure at module scope. The functions' differing results
are needed too, since the one-result twin runs.

#### Ablation

| spelling | outcome |
| --- | --- |
| the witness | loud emit reject |
| no closure, `print(c[0].f(3) + c[1].f(3))` in `fr` | runs, `5.5` |
| at module scope, the closure kept | runs, `5.5` |
| one result type, `half(a) { return a * 2 }` | runs, `10` |
