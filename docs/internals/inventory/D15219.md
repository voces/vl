### D15219 — a function returning a read of a container built wider at one leaf and a fresh record literal at another returns two records

**open · check-clean invalid wasm · clause 1 · found grading the destringify lane's returned-`??` fix · filed 2026-11-04 against master `1b19cc6b5`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const m = Map()
    m.set("a", mk())
    const wm: {[string]: J} = Map()
    wm.set("a", mk())
    function g(t: boolean) {
      if t { return m.get("a") }
      { f: 2 }
    }
    print(g(false)?.f ?? 0)

Want:

    2

#### Mechanism

`m.get("a")` reads a record of `J`'s storage (`wm` widens `mk`'s result), and the other leaf is a
fresh literal built at its own `{f: i32}`. `storeRetsResolve` (check_store_rep.vl) stamps a function's
result only where every value leaf is a read or call `storeHeldAt` answers, and a fresh literal is
neither, so `g` returns one record of each storage.
