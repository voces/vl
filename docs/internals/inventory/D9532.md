### D9532 — a record literal of an un-annotated function bound inside a function body beside a declared record type of the same field name is refused at emit

**loud emit reject · `vl check` rc 0 · `emitProgram: object literal field count does not match struct` · clause 2 · found closing [D9471](D9471.md) · present on master `1cf53e320` · filed 2026-10-22 against master `1cf53e320`**

Repro:

    type R = { f: (a: i32) => f64 }
    function half(a) { return a / 2.0 }
    function fr() {
      const v = { f: half }
      print(v.f(3))
    }
    fr()
    // vl check rc 0.  vl run: emit error: emitProgram: object literal field count does not match struct

#### Mechanism

Not traced. The same binding at module scope runs; inside a function it does not, and only
while a record type with the field name `f` is declared.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the declaration of `R` | runs, `1.5` | **yes** |
| `R`'s field renamed (`type R = { g: i32 }`) | runs, `1.5` | **yes** |
| the function body (the binding at module scope) | runs, `1.5` | **yes** |
