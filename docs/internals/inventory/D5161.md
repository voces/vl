### D5161 — a written binding that copies another one holding a union-parameter generic is called through the unadapted instance and traps

**loads then traps · `vl check` rc 0 · clause 1 · found closing D4892 · filed 2026-10-16 against master `83752e744`**

Repro:

    function s<A, B>(a: A, b: B) { print("S") }
    function w<B>(a: i32 | string, b: B) { print("W"); print(a); print(b) }
    function main() {
      let k = s
      k = w
      let k2 = s
      k2 = k
      k2(6, false)
    }
    main()
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch

Want:

    W
    6
    false

#### Mechanism

The same gap as D5160, reached through a write. `k2 = k` is one of `k2`'s owner-row writes, but
its right-hand side is the binding `k`, whose value is `w`'s instance taking a boxed
`i32 | string`. D4892's adapter rewrites `k`'s own write `k = w` at `k`'s call types, and `k`
has no call of its own here. Why `k2`'s own recheck does not adapt `k2 = k` is not yet
ablated. The write's right-hand side is a binding rather than a function, `k2` stores the
unadapted instance, and the indirect call at `(i32, boolean)` traps.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `k(6, false)` instead of through `k2` | runs, `W 6 false` | **yes** |
| `let k2 = k` (the initializer instead of a write) | check reject (D5160) | no (changes the outcome) |
