#### Mechanism

D9331's rung answers a record parameter of a function, not a parameter of a function type. A
depth-16 `--names` profile puts the cost under `collectCloSigs` → `collectTyReachCloSigs` →
`sigKeyOfTy` → `sigKeyOfTyGo` → `annParamKindTy`: the function type's own parameter is
rendered with `tyToEmitName`, `7·2^depth` characters, and classified as a spelling. A named
function in place of the lambda, or a lambda alone with no record argument, still doubles.

Fuel is `VL_FUEL=1` guest fuel of one `vl build`, which is deterministic; the fuel is the
same with D9460's close.

#### Grading list

The witness prints `1` at every depth, and the row closes when the depth-12 to depth-16 fuel
ratio stops being a power of two per level. Grade with [D9514](D9514.md), whose function type
takes a list of the record.

**After a function-typed parameter keys the closure fat-pointer from its type, 2026-10-22.**
`sigParamTokOfTy` asks `sigFuncParamIsClosure` after D9460's rung: a function type whose result is absent, `never`, a scalar, a literal, a record, a function or a list gets the `closure` token `annParamKindTy` gives its render, and `tyEmitNameNonEmpty` stands in for the render's "" check. A list result is unambiguous because a list of functions renders parenthesised. A union, nullable or map result declines: its render is also the render of a union or map whose member is the function, which keys another token, and that face is filed as [D9581](D9581.md). `sigRetTokOfTy` asks the same rung, so a function returning a function type closes with it. Two walks that visited the record once per path now visit each arena node once: `collectTyReachCloSigs` remembers the budget and registry generation each node was walked with, and `objNumWidens` the destination each source record was shown not to widen into. Before landing, a validating seed computed both answers wherever a rung fired and trapped on any disagreement, and one control seed per rung trapped whenever it fired: the `closure` parameter rung fired on 343 of 16,247 files under `distilled/` and `tests/cases/`, the `union` rung on 882, the returned-function rung on 133 and the record-list rung of `anonUnionFieldName` on 64. Every file builds byte-identically to master's under both the validating and the final seed, `scripts/rep-fuzz-check.sh` is exact, and the compiler builds itself byte-identically. Fuel, `VL_FUEL=1`, one build each, after:
