### D6251 — a function handed to a hole called on its own result, and used again elsewhere, is refused at check

**loud check reject · `vl check` rc 1 · clause 2 · found closing [D6210](D6210.md) · the same on master `4090ad9df` · filed 2026-10-18 against master `4090ad9df`**

Repro:

    function wrap(a) { return [a] }
    function lapRet(g, x) { return g(g(x)) }
    print(lapRet(wrap, 4)[0][0])
    print(wrap(true).length)
    // vl check: rc 1, argument 1: expected an array, got boolean

Want:

    4
    1

#### Mechanism

From the ablation only. Each line runs alone. Together, the two uses of `wrap` are not kept
apart: the index on `lapRet`'s result reaches `wrap`'s own parameter, and with an annotated
destination it is the other use's `boolean` that reaches `lapRet`'s result. One wrap of the
argument, `g(x)`, keeps them apart.
