### D9312 — a record of an un-annotated function read back from an un-annotated `Map()` dispatches to the function of an earlier same-shaped record literal called at a guessed signature

**check-clean invalid wasm · `vl check` rc 0 · `type mismatch: expected f64, found i32` · clause 1 · found closing [D9065](D9065.md) · present on master `cf1b1a8d3` (loads, prints `1.5`, then traps) · filed 2026-10-21 against master `cf1b1a8d3`**

Repro:

    function half(a) { return a / 2.0 }
    function inc(a) { return a + 1 }
    const b = { f: half }
    print(b.f(3))
    const j = Map()
    j["k"] = { f: inc }
    const a = j["k"]
    if a != null { print(a.f(2)) }
    // vl check rc 0.  vl run: invalid module: type mismatch: expected f64, found i32 (8:16)

Want:

    1.5
    3

#### Mechanism

Partly traced. `{ f: half }` and `{ f: inc }` share one struct row, keyed on field names,
so `a.f`'s closure is found by the shape scan (`fieldClosureFeOfRecv`, emit_classify.vl),
which returns the first literal's. The checker types both field values at the
`(i32)=>i32` it guessed at `b.f(3)` and `a.f(2)`, so the signature filter
(`fieldClosureFeOfWant`) cannot tell `half` from `inc`, and the print takes `half`'s f64
result while the call returns `inc`'s i32.

| --- | --- | --- |

| the order (the map first, `b` last) | runs | **yes** |
