#### Mechanism

The hole parameter is instanced at the two-map union and narrowed to `{[i32]: boolean}`. A read
the narrowing delivers to a slot (`const w = v`) is unboxed there. A map method's receiver has no
slot, so `get` (through `emitMapGetCall`) receives the raw union box where it wants the map's
struct. Re-checked on top of D16708's fix: still fails, so it is a separate seam.
