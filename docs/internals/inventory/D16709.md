#### Mechanism

The parameter is instanced at the two-map union and narrowed to `{[i32]: boolean}`. A narrowed
read of a binding stored as the box is unboxed to its map arm in the identifier read, behind three
gates: a union name for the read, a captured box, or a rebind chain to a map-bearing union. An
instance's parameter, un-annotated or generic, meets none of them, so a map method's receiver got
the raw box. `identReadContainerAt` already answers only for a binding whose storage is the box,
so the arm now unboxes on its answer alone, and the third gate's helper is deleted. Re-checked
on top of D16708's fix first: still failing, so it is a separate seam.
