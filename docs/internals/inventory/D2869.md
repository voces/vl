#### Mechanism

The literal is recorded as the source's `i32[]` and only the destination names the union
element, whose list is a list of union boxes, so `emitArrSpread` copied the source's backing
into a list of another element storage. The close reads the threaded destination: when a
list of union boxes reaches the spread (`pendingListKind == LBK_UNION`), each group is built
at that row — a scalar source boxed per element under its value atom's tag, a record source
by the existing element-converting copy (`emitRefListWidenTop`), a plain run built at the row
— and the groups join as every spread's do. Only when every source is one of those does the
spread take this path (`spreadSrcBoxes`); any other source keeps the plain backing copy, which
is right for a union-box list source (the backing is shared) and still wrong for a widening
scalar source ([D2882](D2882.md)). A position that does not thread its destination
([D2883](D2883.md)) is untouched.
