### D2869 — an `i32[]` spread into a list literal annotated `(i32 | null)[]` builds invalid wasm

**check-clean invalid wasm · clause 1 · found by the #3225 review · the same on master `93b93319e` · filed 2026-09-27 against master `93b93319e`**

Repro:

    const a: i32[] = [3]
    const q: (i32 | null)[] = [...a]
    print(q.length)
    // vl check: rc 0.  vl run: invalid module in the top-level code

Want:

    1

#### Mechanism

The literal is recorded as the source's `i32[]` and only the destination names the nullable
element, whose `i32` list is the sentinel-free box list, so the spread copies the source's
backing into a list of another element storage. The annotated face of [D2868](D2868.md): each
element would need boxing and no copy builds it; `spreadBoxingSource` sees only the literal's
recorded type, so it does not refuse here.
