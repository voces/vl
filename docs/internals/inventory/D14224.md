### D14224 — a list literal binding of two record shapes is not adopted by its record-list destination, and builds at a union box no delivery converts

**closed · 36 of 64 cells of the ident position matrix · filed 2026-10-26 against master `32d371fef`**

Repro:

    type Cir2 = { c2: i32 }
    type Sq2 = { s2: i32 }
    type Shape2 = Cir2 | Sq2
    type Circle = { r: Shape2 }
    const l = [{ r: { c2: 1 } }, { r: { s2: 5 } }]
    l.push({ r: { c2: 9 } })
    const g: Circle[] = l
    print(g.length)

Want:

    3

#### Mechanism

`recAdPushDecl` adopted a literal list binding only when its element type was one record, so
`({r: Cir2} | {r: Sq2})[]` kept its own type and built as a union-box list, which no delivery
into `Circle[]` converts. Where an unrelated same-shape union was declared, the emitter instead
kept the caller's pair and built the literal at `Circle`'s row by shape. Now the binding adopts
when every member lands on one record, and the emitter's thread-keep is deleted.
