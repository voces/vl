### D16825 — a list of records holding an un-annotated function, handed through an un-annotated generic identity and bound, builds an invalid module

**closed 2026-11-16 by lane HASH — the witness prints `4` · `id`'s instance result, `{f: (_) => _}[]`, has no spelling under the naming rule, so the instance inferred its return and lowered it as `i32` while its parameter held the list at the argument's row; a list, record or map handed back whole now returns at that parameter's own pin (`monoRetAtParamPin`, emit_mono.vl) · fixture `tests/cases/functions/hole-identity-returns-list-of-fn-records.vl` · was check-clean invalid wasm, clause 1 · found closing [D16738](D16738.md) (the 6b function-set grid's `id2`) · filed 2026-11-16 against master `c25e97852`**

Repro:

    function id(x) { return x }
    function inc0(a) { return a + 1 }
    const xs = id([{ f: inc0 }])
    print(xs[0].f(3))

Want:

    4

#### Ablation

| ingredient removed or changed | outcome | needed? |
| --- | --- | --- |
| `id` (`const xs = [{ f: inc0 }]`) | runs | **yes** |
| the record (`id([inc0])`, `xs[0](3)`) | runs | **yes** |
| `inc0`'s parameter annotated (`a: i32`) | runs | **yes** |
| `id`'s parameter annotated (`x: { f: (a: i32) => i32 }[]`) | runs | **yes** |
| the binding (`id([{ f: inc0 }])[0].f(3)`) | loud emit reject, "cannot take the generic function `inc0` as a value" | no |
| the list (`id({ f: inc0 })`, bound) | loud emit reject, the same sentence | no |
| the literal bound before the call (`const ys = [{ f: inc0 }]; id(ys)`) | invalid module | no |
| the field read and bound before the call (`const g = xs[0].f; g(3)`) | invalid module | no |
| two elements (`id([{ f: inc0 }, { f: inc0 }])`) | invalid module | no |

The module fails inside `id`: "type mismatch: expected i32, found (ref $4)", where `$4` is the list's
struct. Not D16738's mechanism: its fix (a hole parameter wrapped in a literal inside the callee)
leaves this unmoved, since the literal here is the caller's.

#### Grading list

The four invalid-module spellings above; `.length` alone; a number field beside the function; a
`const` copy of the parameter returned; the list at a second parameter. Through an annotated
`id<T>(x: T): T`, two calls at two functions, a record around the list, or an `if` choosing between
two such lists, the program is [D16739](D16739.md)'s loud emit reject, unmoved.
