### D3027 — a call writing a module binding ends the narrowing of a same-named binding a top-level block declares

**loud check reject · clause 2 · found by the #3260 review grid (`top_innerNar_*`) · the same on master `cac5e4ad5` · filed 2026-09-28 against master `cac5e4ad5`**

Repro:

    type G = { name: string }
    function mk(): G | null { { name: "a" } }
    let g: G | null = mk()
    function k() { g = null }
    if true {
      let g: G | null = mk()
      if g != null {
        k()
        print(g.name)
      }
    }
    print(g == null)
    // vl check: 'g' is no longer narrowed to G: the call to 'k' on line 8 may reassign it

Want:

    a
    true

#### Mechanism

The writer analysis keys a write by name. `k` assigns the module `g`, which is recorded under
`g`, and the block's own `g` is a binding at the root's level too, so `crWriteKey` answers `g`
for it and `callMayWrite` says `k` may write it. The call cannot reach the block's binding. The
fix resolves the queried name to its declaration, as [D3019](D3019.md) did for a callee's own
bindings, and asks whether the writer's target is that declaration.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the block in a function (`function main() { let g ... }`) | runs | **yes** (the root's level) |
| `k` writes another name | runs | **yes** |
| a narrowing of the outer `g` around the block | the same refusal | no |
