### D17222 — a statement assigning `null` to a captured, never-filled `let x = null` in a function writes an `i32` where the cell holds `nullref`

**check-clean invalid wasm · clause 1 · `vl check` rc 0; `vl run`: the emitted module failed to validate inside `f`, `type mismatch: expected i32, found nullref` · claimed and claimless alike · found by IR-N5 ablating D17221 · filed 2026-11-24 against master `1384572c` by IR-N5**

Repro:

    function f() {
      let x = null
      const g = () => x
      x = null
      print(g())
    }
    f()
    // vl check: rc 0.  vl run: invalid module.

Want:

    null

#### Mechanism

A captured `let x = null` in a function body is held in its environment cell as `nullref`, and the
statement write of `null` into it is written as an `i32`. The capture's cell kind and the write's
store disagree.
