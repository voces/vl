### D16033 — `==` between a nullable record and a plain one is refused once any union holding the record is declared

**loud emit reject · clause 2 · `emitProgram: struct equality over a non-struct operand` · found probing `===` operands for D15975 (lane E) · filed 2026-11-13 against master `0260e578`**

Repro:

    type A = { a: i32 }
    type B = { b: i32 }
    type U = A | B
    const x: A = { a: 1 }
    const n: A | null = x
    print(n == x)

Want:

    true

#### Mechanism

Not traced past the site. `emitNulStructEq` (compiler/wasmEmit.vl) looks for an eq row first
through `binEqNulVariantRow`, then through `structIndexOfExpr` of the left operand. With a union
holding `A` declared, neither answers for an `A | null` operand compared against a plain `A`,
and the refusal fires. The union need not be used. It is D57's trigger, a declared but unused union
holding the record, on the nullable path that D57's close did not cover.
