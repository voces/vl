### D16927 — an uncalled unannotated-parameter function stored as a record into a map read back from a map is built at the elaboration's `i32` default, not at the type its body's operator demands

**closed 2026-11-17 · runs, prints `1` · was check-clean invalid wasm · clause 1 · fixed in emit_elab.vl and emit_mono.vl: `elabStoredHoleDefaults` notes each default it mints, `elabOneAt` marks one whose re-check raises a diagnostic, and `elabKeyBodyRefused` answers for a marked key no call reached, which mono builds with an empty body (an `unreachable` past the signature); a call through the slot keys its own instance and still runs · the same default over a member read (`x.n`, `x[0]`, `x.toUpperCase()`) has no result type and stays a loud emit reject at the function-value signature · `record-field-map-of-string-hole-fn-uncalled.matrix.vl` 4 SILENT cells now run · pin: `tests/cases/maps/stored-hole-fn-default-body-refuses-i32.vl` · filed 2026-11-17 against master `534f3eda2`**

Repro:

    function g(x) { return x + "a" }
    const __m = Map()
    __m.set("k", { m: Map() })
    const __mv = __m.get("k")
    if __mv != null {
      __mv.m["k"] = { f: g }
      print(__mv.m.length)
    }
    // vl check: no errors.  vl run: invalid module, the emitted module failed to validate inside `g`

Want:

    1

#### Mechanism

`g` is read as a value and never called, so no call instances it. The elaboration's stored default
(`elabStoredHoleDefaults`, `compiler/emit_elab.vl`) instances such a function with every parameter at
`i32`, and the map-of-records slot pins that instance, so `g` is emitted as `(param i32) (result (ref $5))`,
a string result with a body that concatenates. Check never closes the hole (D16898), and the default
ignores what the body's operator demands: `+ "a"` constrains `x` to `string`, which `i32` does not
satisfy.

#### Ablation

| change from the repro | outcome | needed? |
| --- | --- | --- |
| body `x + 1` | runs, prints `1` | **yes** (a string-constrained hole) |
| body `x + 1.5` or `x * 2.0` | runs, prints `1`, `g` is `(i32) -> f64` | **yes** |
| `const v = __mv` binding between the guard and the write | still invalid wasm | no |
| outer map removed (`const v = { m: Map() }`) | runs, prints `1` | **yes** |
| `m["k"] = g` (no record) | loud emit reject (`unsupported map value type`) | — |
| `{ f: g }` in a record, a list or a plain map | runs | **yes** (the map read back from a map) |
| `r.f("b")` called through the record | runs, prints `ba` | **yes** (no call) |
