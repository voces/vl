#### Mechanism

The call `len(() => x)` was solved twice. The template's check binds `T := U`. The
elaboration's quiet re-check at `outer<U = string>` solved it afresh: `string` against
`T | string` gives `T` no inference, so the D4551 default made it `i32`, and the instance
enqueued was `len<T = i32>` where substitution says `len<T = string>`. The direct spelling
`len(() => "abc")` still solves `T = i32`, since nothing binds `T` at the template there.
