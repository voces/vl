### D16016 — an assignment used as a value whose type is not its target's has no value lowering

**closed · runs, prints `5` `5` · was loud emit reject, clause 2 · fixed 2026-11-14: a member written into a boxed union yields the box's payload, and a record written into an `R` or `R | null` place yields the non-null cell · a record whose own row is not the place's is [D16019](D16019.md) · residue of [D16015](D16015.md) · filed 2026-11-14 against master `c2e3dca0a`**

Repro:

    const us: (i32 | string)[] = [1, "a"]
    let i = 1
    const r = us[i] = 5
    print(r)
    print(us[1])

Want:

    5
    5

#### Mechanism

The assignment yields its right-hand side at the right-hand side's type, here `i32`. The stored
cell is the element's rep, a union box, so neither the re-read nor the parked value (D16015) is
that value: delivering it needs the box opened to the right-hand side's rep, or the value kept in a
local of its own type. D2171's spill does that only before a `return` or a function-level `let`.
The same holds for a row-less record literal written into a `Node | null` field and passed as an
argument (`show(root.left = { v: 3, left: null })`), and for [D2632](D2632.md), whose target is a
closure-shared union cell, and for a union- or nullable-valued map's entry (`m[k] = 5` over
`{[string]: i32 | string}` or `{[string]: i32 | null}`).

#### Closed (2026-11-14)

Two rungs in `emitBinExprNode`'s `=` arm, beside D16015's parked cell:

- **A member of a boxed union** (`asgYieldsBoxedArm`), written into a list element or map entry of
  that union. Its store parks the box, so the rung reads the parked box and opens it to the
  right-hand side's member (`emitUnionUnboxTail(boxTagOfTy(...))`). D2632's closure-shared union
  cell is such an element after the capture rewrite, so it runs too.
- **A record written into an `R` or `R | null` place** (`asgNonNullCell`), where `R` is the record
  the value is built at: the value has no row of its own, or `R`'s. For a field of a name the
  place is re-read; for a list element the stored cell is parked. Either is taken past the `null`
  its type admits. The place's type can read back narrowed to `R` (an un-annotated module
  `const`), so both spellings are accepted.

Graded on the new `scripts/capability-probes/matrix/union-target-write-value.matrix.vl`
(`(uw[uwi] = 5)`, plus a string member, a union-valued map entry and a row-less record field):
0 of 52 to 52 of 52, 0 silent. The element, field and map matrices stay 50 of 50.
