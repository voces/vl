### D7450 — an un-annotated `if` joining a narrowed `K | null` atom and a `string | null` builds invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · open · found closing [D7448](D7448.md) · present on master `573358403` · filed 2026-10-20 against master `573358403`**

Repro:

    type K = "a" | "b"
    const k: K | null = "b"
    const n: string | null = null
    const r = if k != null { k } else { n }
    print(r ?? "rnull")
    // vl check: rc 0.  vl run: invalid module, expected i32, found (ref null $0); $0 is `string`

Want:

    b

#### Mechanism

Not traced past the ablation. The join of `K` and `string | null` is `string | null`, and
the then arm's narrowed atom is not decoded to its string before the join, so the `if`
takes the atom's `i32` rep while its else arm is the nullable string ref.

| `const r: string \| null = …` | runs, prints `b` | **yes**, the un-annotated join |
