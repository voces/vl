### D3706 — a function whose tail value is an optional member read `q?.v` is refused as an unsupported statement

**closed 2026-10-17 as `runs` · was loud emit reject (clause 2) · `stmtIsTailValue` (`emit_classify.vl`) now reads an `OptMember` tail as a value, so the function's implicit return lowers it as one · fixture `tests/cases/unions/optional-member-statement-and-tail.vl` · still refused on master `3d78a8854` · the return-position sibling of [D3009](D3009.md) · found by the #3387 review (`rv87`) · filed 2026-10-05 against master `0948a28e3`**

Repro:

    type V = { x: f64 }
    type Q = { v: V }
    const q: Q | null = { v: { x: 1.5 } }
    function f() { q?.v }
    print(f()?.x ?? -1.0)
    // vl check: rc 0.  vl run: emitProgram: unsupported statement in body

Want:

    1.5

#### Mechanism

Not traced. [D3009](D3009.md) is `r?.v` as a discarded expression statement; here the same node
is a function's implicit return, which is a value. The refusal names the statement lowering, so
the tail is not recognised as a value (`stmtIsTailValue`) and falls to the statement path.
