#### Mechanism

`elabSlotDeliveriesAt` (compiler/emit_elab.vl) recomputes equal sub-queries from sibling
branches: at 16 fields it makes 243,046 queries over 988 distinct (binding, instance, literal
depth, query depth, path) keys, each about 250 times, most at the query-depth cap (8). One branch
per literal field (`/f.g<k>/e/`) asks the outer literal's slot again. The nested memo
(`elabDlvNest`) keys the query depth and sits in `elabSlotDeliveries`, so the direct
`elabSlotDeliveriesAt` calls (write cell, literal holders, outer literal) bypass it. A memo here
must not reuse a result the depth cap or an active-stack cut truncated.
