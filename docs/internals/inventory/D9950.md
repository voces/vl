### D9950 — an element of a list mixing a record of an un-annotated function with a record of an annotated lambda, handed to an un-annotated parameter, calls the wrong signature

**closed · runs, prints `4` `30` · was loads then traps, `vl check` rc 0, `wasm trap: indirect call type mismatch`, clause 1 · found closing [D9731](D9731.md) · present on master `c4fbdc8d1` · filed 2026-10-22 against master `c4fbdc8d1` · closed by the flow walk registering a call through the parameter's field once the instance binds the parameter to a record (`ffBoundObjHasField` in `ffCall`, fn_flow_shadow.vl), so `inc0` is pinned at the slot the call reads; the list-literal face (`use([{ f: inc0 }, { f: (x: i32): i32 => x * 10 }])` relaying `v[0]`, `v[1]`) is closed by the source retype pinning the open field beside a closed function value, refusing the pin unless that value already has the signature (`monoOpenFnRecSrcPin`, emit_mono.vl) · fixtures `closures/hole-fn-record-relayed-to-param-field-call.vl`, `closures/hole-fn-record-list-literal-relayed-to-field-call.vl`**

Repro:

    function inc0(a) { return a + 1 }
    function take(a) { print(a.f(3)) }
    const xs = [{ f: inc0 }, { f: (x: i32): i32 => x * 10 }]
    take(xs[0])
    take(xs[1])
    // vl check rc 0.  vl run: wasm trap: indirect call type mismatch

Want:

    4
    30

#### Mechanism

The flow walk registered `a.f(3)` as a call through a field only when the receiver's own type
was a record; `take`'s `a` is a type variable the instance binds to one, so the call pinned no
slot and the open `inc0` reached the instance unpinned while the lambda's record fixed the
field's signature. The instance called `f` at the lambda's signature and the funcref stored for
`inc0` did not have it. A control seed with every other part of the fix and without the flow
branch still traps; one marking the source retype's closed-value branch never reaches it here.
Relayed from a list literal, the element pin also declined a list whose fields were not all
open functions, which is the second half of the fix.
