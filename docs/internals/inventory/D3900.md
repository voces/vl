### D3900 — an un-annotated inline record beside a `Box<{ x: i32 }[]>` callback refuses to build, though annotating it runs

**loud emit reject · the un-annotated spelling of D3875, found in review of #3473 · filed 2026-10-09 against master `9170959d8`**

Repro:

    function h<T>(x: T) { x.x }
    type Box<T> = { v: T }
    const ba: Box<{ x: i32 }[]> = { v: [{ x: 1 }] }
    print([ba].map((e) => h(e.v[0]))[0])
    const o = { v: { x: 9 } }
    print([o].map((e) => h(e.v))[0])
    // vl check: rc 0.  vl build: emitProgram: field access receiver is not a struct

Want:

    1
    9

#### Mechanism

Not located. D3875 pins a built-in callback over an inline record by the spelling its row is
interned under; with no annotation on `o`, the record's row is interned under a different
spelling, which that rung does not produce. D3875's fixtures all annotate the receiver.
