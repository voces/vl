### D17752 — an un-annotated local read from a record field of a lone string-literal type is held as an i32

**closed 2026-11-27 by COV-UNION · runs, its witness prints its expected value · was check-clean invalid wasm, clause 1 · a module binding whose atom cell holds a single string literal is stored as the atom node typed at that literal (`globalStorage`, ir_build.vl), as a local's cell already is · pinned by `tests/cases/records/unit-field-read-into-module-binding.vl` · `lone-literal-result-of-generic-fn-value` matrix 60 → 62 of 66 runs**

Repro:

    type __W = { f: "a" }
    const w: __W = { f: "a" }
    const v = w.f
    print(v + "x")
    // vl check: rc 0.  vl run: the emitted module failed to validate

Want:

    ax

#### Mechanism

The binding's cell is the literal set's atom (`letBindIsAtom`), declared `i32`. A local's storage
holds a single string literal there as the atom node (`localStorage`'s last atom arm); the module's
`globalStorage` had only the arm for a type whose own rep is an atom, so it kept the field read's
`str` and stored a string into the `i32` global. `print(v)` refused for the same reason.
