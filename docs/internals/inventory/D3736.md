#### Mechanism

S2's cost rule (`flat.rs`) counts an element read held in a local as free only when the
local is set only to such reads or fresh records and is read only for a field or a store
back into the list (`elem_locals`, `inline.rs`). The multi-value step scalarizes a wider set
of locals: one also passed to a parameter it takes as fields, set from a producer call, or
copied into another such local. The emitter lowers `p[0] = base` through a scratch local, so
even a store back was a copy into a local the rule never considered. sunpa `ce4e1c3`'s four
whole reads of `V3[]` (`base` in `fabrik`, `t` in `legsLayer`, `keep` and `was` in
`mantleClip`) are all this shape. The rule now asks the multi-value step's own facts
(`multivalue::field_facts`: its field-only parameters and producers), and grows the local
set from store values and copies before judging it. sunpa's feet check allocates 60,155
`V3` boxes where it allocated 90,113, output identical.
