#### Mechanism

facts. The decision declines at `swap(add)`: `h`'s only read is the initialiser of a written
`let`, and no fact says what that read takes, so the hand is not of a parameter that takes the
set (`ftLateParamOk`). At the template `hh`'s type is a hole; only an instance of `swap` types it,
as `{add, mul}`, so the binding's set is visible to the elaboration and to no check-side walk.
