### D15236 — a binding holding an inner list of a list of lists built at a wider record, reassigned with a list literal, is check-clean invalid wasm

**closed 2026-11-04 · runs, prints `7` then `4` · was check-clean invalid wasm, `vl check` rc 0 · clause 1 · found closing [D15189](D15189.md), its nested spelling · filed 2026-11-04 against master `b30abf13` · closed by `recHeldElemBuilt` answering an element read of a list of lists from the outer list literal's rep stamp one level in (`recElemOfElemStamp`), and reaching it through a binding's initialiser, so the assignment stamp (`recLitPlaceBuiltTy`) and the push stamp build the literal there · fixture `tests/cases/soundness/record-list-of-lists-element-held-by-binding-runs.vl` · a literal delivered as an element of the list of lists is [D15284](D15284.md)**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const ys = [[mk()]]
    let b = ys[0]
    b = [{ f: 7 }]
    print(b[0].f)
    print(wideJ.f ?? 0)

Want:

    7
    4

#### Mechanism

D15189 builds a list literal assigned into a binding that holds a built list at that list, from the
binding initialiser's recorded element build (`recBuiltElemOf`). Here the initialiser is an element
read of a list of lists, `ys[0]`, for which no element build is recorded where the stamp asks, so
the literal is built at its own `{f: i32}[]`.
