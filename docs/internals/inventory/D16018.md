### D16018 — a byte-list element write used as a value yielded the stored low byte, where an assignment yields its right-hand side

**closed · runs, prints `300` `44` · was check-clean wrong evaluation, clause 1 (a literal index printed `44`), and a loud emit reject for a computed index · fixed 2026-11-14: a byte-list element write yields the value its store parks, the right-hand side before the byte store truncates it · found closing [D16015](D16015.md) · filed 2026-11-14 against master `c2e3dca0a`**

Repro:

    const b: u8[] = [1, 2, 3]
    let x = 300
    print(b[1] = x)
    print(b[1])

Want:

    300
    44

#### Mechanism

A byte-list store keeps the value's low 8 bits. DECISIONS ("Assignment is an expression yielding
its right-hand side") rules that `b[1] = x` yields `x`. With a literal index the emitter delivered
the value by re-reading the cell (`assignTargetReReads`), which yields the stored byte, `44`. A
computed index refused. The store parks the right-hand side as a plain `i32` before its
`array.set` (D16015), so a byte-list element now always takes the parked cell, never the re-read.

#### Ablation

| spelling | before | after |
| --- | --- | --- |
| `print(b[1] = x)`, `x` 300 | `44` (wrong) | `300` |
| `print(b[i] = x + 1)` | loud emit reject | `301` |
| `return c[0] = v`, `v` 257 | `257` (D2171's spill) | `257` |
| a tail `c[1] = v`, `v` 511 | `511` | `511` |
| a value that fits, `print(b[1] = 5)` | `5` | `5` |
