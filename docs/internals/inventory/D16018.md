### D16018 — a byte-list element write used as a value has no ruled value: the stored low byte or the right-hand side

**loud emit reject · clause 2 · residue of [D16015](D16015.md) · filed 2026-11-14 against master `c2e3dca0a`**

Repro:

    const b: u8[] = [1, 2, 3]
    let i = 1
    let x = 300
    print(b[i] = x)
    print(b[1])

Want:

    300
    44

#### Mechanism

A byte-list store keeps the value's low 8 bits. DECISIONS ("Assignment is an expression yielding
its right-hand side") says `b[i] = x` yields `x`, here `300`, but the literal-index spelling
`print(b[1] = x)` runs today by re-reading the cell and prints `44`. Which value the assignment
yields is not ruled, so the computed-index spelling is refused rather than pick one. The Want
above follows DECISIONS; a ruling for the stored byte would change it and the literal-index
spelling would stand.
