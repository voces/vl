### D5286 — `as` from a literal-union atom to a narrower literal union has no lowering

**closed · was loud emit reject · clause 2 · eardstap EV-006 follow-up · filed 2026-10-17 against master `3f6a785db`**

Repro:

    type NodeKind = "a" | "b"
    type Wide = NodeKind | "event"
    function pick(k: Wide): NodeKind { match k { "event" => "a", _ => k as! NodeKind } }
    print(pick("b"))

Want:

    b

#### Mechanism

Both unions are registered aliases, so the operand and the result are the same interned i32
atom; `emitAsCast` had arms only for a boxed union operand and a re-readable narrowing
receiver. `emitAsLitAtom` (`wasmEmit.vl`) stashes the id once and compares it against each
target member's atom: `as!` traps on a miss, `as?` selects the `-1` niche, and `as` returns the
miss as the function's atom (or its text, for a `string` return). The classifiers
(`asExprLitAtomCast`) report the result as an atom so every consumer reads it as one.
