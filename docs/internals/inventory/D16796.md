### D16796 — a hole parameter handed a nullable record wider than its `??` default builds an invalid module at a field read

**check-clean invalid wasm · clause 1 · `vl check` rc 0 · found grading the S3.4a floor-removal experiment (two map value shapes through one hole) · filed 2026-11-16 against master `d59e4401`**

Repro:

    const r: {x: i32, y: i32} | null = {x: 5, y: 6}
    t(r)
    function t(q) { print((q ?? {x: 0}).x) }
    // vl check: rc 0.  vl run: invalid module inside `t`, "type mismatch: expected (ref $type), found (ref $type)"

Want:

    5

#### Mechanism

Not located yet. The `??` joins the argument's `{x, y}` with the default's narrower `{x}`. The
join's record and the struct the emitter builds for it disagree. No map and no declaration order
is needed. Through a map's `get` the same join gives "expected (ref null $type), found (ref $type)".
