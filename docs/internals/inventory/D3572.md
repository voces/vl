### D3572 — a list literal of a nullable number beside a number of another type has no value box for its element

**loud emit reject · clause 2 · open · found by the #3353 review (`dis/src/bnd_nullel.vl`) · the same on master `3b9319528` and with #3353 · filed 2026-10-03 against master `3b9319528`**

Repro:

    function x(): i32 | null { 7 }
    function y(): f64 { 2.25 }
    const xs = [x(), y()]
    print(xs[0])
    print(xs[1])
    // vl check: rc 0.  vl run: emitProgram: union atom has no value box

Want:

    7
    2.25

#### Mechanism

The literal types `(i32 | f64 | null)[]`, and the element store looks up a value box for the
nullable member's atom, which this member set has none of. The non-null spelling builds the box
list and runs.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `x(): i32` (not nullable) | prints `7`, `2.25` | **yes** (the nullable element) |
| `x()` bound to a `const` first | still refuses | no (the call) |
| `y(): i64` | still refuses | no (which number) |
| inside a function | still refuses | no (module scope) |
| a third element `null` | still refuses | no |
