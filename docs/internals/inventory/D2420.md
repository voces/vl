### D2420 — the value of an assignment into a module-global struct union is the union, not the record the checker typed it at

**closed 2026-09-25 by [D2398](D2398.md)'s close — the witness prints `2.5` · was loud emit
reject, clause 2 · filed 2026-09-25 against master `a277bf7b0`, found grading
[D2391](D2391.md)'s family on a struct union**

Repro:

    type Circle = { r: f64 }
    type Square = { s: f64 }
    let v: Circle | Square = { s: 1.0 }
    function mkC(): Circle { { r: 2.5 } }
    function k() { v = mkC() }
    const r = k()
    print(r.r)
    // vl check: rc 0.  vl run: emit error: field access receiver is not a struct

#### Mechanism

Closed by [D2398](D2398.md)'s close: the write moves ahead as `const t = mkC(); v = t`, and
the value is `t`, the `Circle` the checker typed it at, so no re-read of the global's union
rep is left. The module-scope spelling `const q = (v = mkC())` prints `2.5` too.

The checker types `v = mkC()` at `Circle`, and the value lowers as a re-read of the global,
whose rep is the struct union's variant ref. D2391's close narrows the re-read only for a
value-union box, so the field read sees a union receiver. A local cell of the same union
already reads back as `Circle`, so the global's re-read is the asymmetry.

#### Ablation

On master `a277bf7b0`, and the same with D2391's close applied.
