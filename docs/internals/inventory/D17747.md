### D17747 — an empty map stored whole into another and read back through it passes check and has no rep at emit

**closed 2026-11-27 — the `??` default pins the stored map's value at every read of it (D17734's pin, no longer only at a fresh-container read), and a read that types nothing is refused at check instead of reaching emit open · filed against master `ba6dff69`**

Repro:

    const cc = Map()
    cc["k0"] = Map()
    const g0 = cc["k0"]
    if g0 != null { print(g0["k0"] ?? 3) }
    // prints 3

Want:

    3

#### Mechanism

A clause-1 gap: `vl check` accepts the program, and emit finds no rep for the inner `Map()`,
whose key and value stay open. Nothing writes the inner map, and its only read supplies a key and
a `??` default, so by D17734 the read should pin both. Bound to a `let` first (`const lv1 =
Map(); cc["k0"] = lv1`), the same program is instead the check floor "cannot infer a type".
