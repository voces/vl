### D9007 — a re-pointed `let` of un-annotated functions with different results, handed to an un-annotated parameter and called there, traps

**loads then traps · `vl check` rc 0 · `wasm trap: indirect call type mismatch` · clause 1 · found closing [D9003](D9003.md) · present on master `145cabbc6` · filed 2026-10-21 against master `145cabbc6`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function w(h) { return h(3) }
    let f = inc0
    f = half
    print(w(f))
    // vl check rc 0.  vl run: wasm trap: indirect call type mismatch

#### Mechanism

Not traced. D9003's refusal reads the binding at the parameter types it is called at: a
direct call, a function-typed destination, a generic's arrow parameter, `.map`. Here the call
is `h(3)` inside `w`, through a hole-typed parameter, so the call site that fixes `(i32)` is
in another body and the binding `f` is never read at it. The annotated destination
(`w(h: (a: i32) => i32)`) is refused by D9003's check.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the write `f = half` | runs, `4` | **yes** |
| the widening (`dbl(a) { return a * 2 }` for `half`) | runs, `6` | **yes** |
| the hole on `h` (`h: (a: i32) => i32`) | loud check reject | **yes** |
| `w(f)` for `f(3)` | loud check reject | **yes** |
