### D17781 — a record holding a three-deep list of one un-annotated function beside an uncalled list of another fails to emit when the deep list is called

**loud emit reject · `ref valtype with no interned shape` · clause 2 · `vl check` rc 0 · filed 2026-11-28 against master `f0b3b7bf` by COV-CLOS-3 (found minimising `closures/record-field-fn-list-three-levels.vl` under the onesig rule)**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    const s = { f: [[[inc0]]], g: [dbl] }
    print(s.f[0][0][0](3))
    // vl check: rc 0.  vl run: emit error at 3:7, "ref valtype with no interned shape"

    4

#### Mechanism

Not traced. The record is bound unannotated; `g`'s function is never called, so its list
takes the uncalled default while `f`'s set is pinned by the call.
