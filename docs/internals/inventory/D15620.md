### D15620 — an element of a hole list parameter bound to a `const` and then handed on to a callee that calls it at two types is taken as a value with no signature

**loud emit reject · clause 2 · `vl check` rc 0, then `emitProgram: a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type` · the element handed on without the binding runs since [D15612](D15612.md) · found closing D15612 · filed 2026-11-09 against master `deeca2a1`**

Repro:

    function id(v) { return v }
    function call1(f, x) { print(f(x)) }
    function call0(fs, x) {
      const h = fs[0]
      call1(h, x)
    }
    function run(g) {
      call0([g], 5)
      call0([g], "s")
    }
    run(id)

Want:

    5
    s

#### Mechanism

Not traced. `elabMintElemFwd` forwards `fs` to `call1`'s parameter only where the element
read is itself the argument; a `const` holding the read is read by `elabMintHandedIn` as a
copy that goes elsewhere, so `fs`'s set is left partial.
