### D5843 — an un-annotated generic handed to an un-annotated parameter and called there at `f64` or `i64` has no interned signature

**loud emit reject · `vl check` rc 0 · clause 2 · found closing [D5791](D5791.md) · filed 2026-10-17 against master `519a09fef`**

Repro:

    function neg(a) { return 0 - a }
    function apply(g, x) { return g(x) }
    print(apply(neg, 2.5))
    // vl check: rc 0.  vl run: emitProgram: a function-value call has no interned signature

Want:

    -2.5

#### Mechanism

From the ablation only. The pin [D5612](D5612.md) closed instances `neg` at the call `apply`
makes, and that instance is found at `i32` and at `string`. At `f64` and `i64` the call through
`g` finds no signature for it. A `const` or `let` hole lambda in place of `apply` gives the
same message.
