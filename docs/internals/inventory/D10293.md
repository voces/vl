    function g(q, d: f64) {
      const r = if q != null { q } else { d }
      print(r is i32)

#### Mechanism

Not yet located. The value is right (`print(r)` prints `5`), so the join's rep keeps the

annotated `q: i32 | null` both print `true`, so the hole parameter's inferred type is the
ingredient, not the numeric-join gate.
