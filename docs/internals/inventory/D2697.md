#### Mechanism

The prediction held. The collect pass's destination pins ask `retLocalLetOfBlock` which
`let` a delivered name denotes, and it answered `parentLetOf(body, "out")`: the first sibling,
whose mixed literal is union-box storage. The `Circle[]` delivery was pinned at that binding's
element rep while the second binding built plain `Circle` storage. It now resolves the read's
own node, and reverting that one lookup alone brings the invalid module back.
