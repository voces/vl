#### Mechanism

`g is string[]` over a `Json` asks `jsonDeepIsSite` (`check_demands.vl`) before any membership
refusal: a target with a JSON shape becomes a deep site, which the rewrite routes through a
generated walker and a converted copy ([D1190](D1190.md)). A `match` type-pattern arm is the same
`IsExpr` node, but `matchTypePatCover` (`check_match.vl`) asks only `tyTestMeet` and the member
cover, so `string[]` meets no member and is refused. `matchLower` then lowers the `match` to an
`if` chain over those same pattern nodes, so a recorded site would be rewritten as any `is` is.
