### D2165 — [CLOSED 2026-09-23] a method-call receiver skipped the argument seam, so a widened container passed as `self` was check-clean invalid wasm

**closed as `now a loud check reject` · was `check-clean invalid wasm` · found 2026-09-23 by the no-implicit-container-widening inventory · filed against master `9fd219de7`**

Repro:

    type K = "a" | "b"
    function jn(self: string[]): i32 { return self.length }
    const ks: K[] = ["a", "b"]
    print(ks.jn())
    // was: vl check rc 0, vl run invalid module. Now: K[] is not string[]: a container never widens implicitly

#### Mechanism

`ufcsCallTy` gated the receiver with bare `assignable`, the dispatch question ("is this
`self`-function a candidate at all"), and never asked `assignableExpr`, the seam every
argument, binding and return delivery goes through and where the element-storage refusal and
the covariant-write refusals live. So `jn(ks)` refused and `ks.jn()` compiled a `K[]` into a
`string[]` slot. A second half hid behind the first: the write-state closure
(`covarValueWriteState`) followed an argument into its parameter but not a receiver into
`self`, so a write through `self` inside a method did not count as a write through the
receiver. Both are closed. The receiver now takes the seam's verdict after dispatch (skipped
where either side is still a hole, which the pin re-asks), and the closure has a receiver
edge (`cwGrowRecv`).
