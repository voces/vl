Repro:

    function lst<T>(xs: T[]): T { return xs[xs.length - 1] }

Want:

#### Mechanism

The written `let` is called directly at two list types, `i32[]` and `string[]`, and its members
take the list at a parameter whose element type is the call's. With the plan on, the split plan
copies the binding per call type. With it off, no copy is keyed and the one binding meets both
call types. The scalar spelling runs without the plan, so the list parameter is what the
binding's one signature cannot hold. Whether that is the members' list parameter or the call's
list argument is not yet separated.
