### D6960 — an uncalled hole function's bare name as a statement whose value is discarded is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same name bound unread runs ([D6830](D6830.md)), and a bare name as a function body's tail runs ([D6882](D6882.md)) · found closing [D6930](D6930.md) · present on master `9379b4491` · filed 2026-10-19 against master `9379b4491`**

Repro:

    function exclaim(s) { return s + "!" }
    exclaim
    print(1)
    // vl check: rc 0.  vl run: emitProgram: cannot take the generic function `exclaim` as a value — a function value carries ONE signature

#### Mechanism

From the ablation only. No position of the inertness walk notes a statement whose value is
discarded. Noting it inert from the walk's block arm and the module statement loop stubs the
function, and the module is then invalid wasm (`expected struct type, found (func)`): the
statement's `drop` of the stub is emitted against a different type, so the fix needs the emitter
to drop the discarded value, not only the walk to note it.
