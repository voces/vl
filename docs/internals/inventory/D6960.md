#### Mechanism

No position of the inertness walk noted a statement whose value is discarded. The walk now
notes one from its block arm and the module statement loop: the statement itself, a
parenthesized name, a list or record literal of names, and through an `if` or a loop, the last
statement of each block it runs. The walk alone stubs the function and leaves the module
invalid (`expected struct type, found (func)`): the statement emitter built a closure for the
stub with a closure type nothing minted, because no other use reads the function as a value.
`stmtIsBareFnName` (wasmEmit.vl) now emits nothing for a discarded bare name the walk noted,
and for any fully annotated function's, which was [D6980](D6980.md).
