### D15237 — a record binding pushed into a list whose elements are built at a wider record is check-clean invalid wasm

**closed 2026-11-04 · runs, prints `6` then `4` · was check-clean invalid wasm, `vl check` rc 0 · clause 1 · found closing [D15235](D15235.md), its binding twin · filed 2026-11-04 against master `891fb463` · closed by the pass end building the fresh `const` where a read of it is pushed or index-stored into a list with a recorded element build (`recHeldLitPlaceAdopt`), through the held-binding adoption D15230 already used (`recHeldBindAdopt`), which refuses a second delivery at its own storage · fixtures `tests/cases/soundness/record-binding-pushed-into-built-list-runs.vl` and `-reject.vl` · the assignment twin is [D15238](D15238.md)**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const xs = [mk()]
    const r = { f: 6 }
    xs.push(r)
    print(xs[1].f)
    print(wideJ.f ?? 0)

Want:

    6
    4

#### Mechanism

D15235 builds a record LITERAL pushed into a list built at `J` at `J`. Here the pushed value is a
binding of a fresh literal, `r`, which was built at its own `{f: i32}` and handed to a list of
`J`'s row. The checker builds such a binding at its destination when the destination's TYPE is
wider (`xs: J[]` runs); `xs`'s width is a recorded build, known only at the pass end.
