### D2539 — an IdTable whose type parameter cannot be inferred is still checked for a widened covariant write, so the real error is followed by a message quoting `std:idtable`'s own line number

**loud check reject · clause 2 (message quality) · found while reviewing `std:idtable` (#3168) · filed 2026-09-25 against master `a09d1f6bc`**

Repro:

    import { IdTable } from "std:idtable"
    type Tex = { w: i32 }
    const t: IdTable<Tex> = IdTable()
    t.set(1, { w: 2 })
    print(t.length)
    // vl check: rc 1, two errors — "cannot infer type parameter `V`", then "a
    // {slots: (V | null)[], length: i32} cannot be delivered as IdTable<Tex> here: the
    // assignment on line 47 of std:idtable writes a widened field. ..."

#### Mechanism

`IdTable()`'s return type names `V` and no parameter does, so inference correctly fails and
reports it — a good, self-contained error. The checker does not stop there: it goes on to
typecheck the declaration against the annotation `IdTable<Tex>` using the unbound `V` it still
has (a raw type variable), and the D2060 covariant-write-through check (`rcwCovs`,
`typecheck.vl`) treats an unbound type-parameter source as "may be any type", so the slot counts
as widened. Finding where that width is WRITTEN walks into `std:idtable.set`'s own body and names
its line — a std internal detail a caller never sees the source of, tacked onto an error that
was already complete.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `.set()` call (nothing writes through the annotated binding) | only the "cannot infer" error | **yes** — the second message needs a write to find |
| the annotation on `t`, with an explicit `IdTable<Tex>()` | 0 errors, checks clean | **yes** — the annotation is what makes inference fail |
| `Tex` a record vs. `V = i32` | same two errors | no — not about the value type |
| `IdTable<Tex>()` (explicit type argument), annotation kept | 0 errors (a redundant-annotation hint only) | **yes** — an explicit argument gives inference nothing to fail at |

#### Grading list

Any generic whose return type alone names an unbound parameter, annotated at its binding and
then written through — the same std-internal-line leak should reach any such site, not just
`IdTable`.
