#### Mechanism

The tag decision tags `{inc0}` when the map sits in a call-returned record, so `mk`'s `Map()` is
built at the id rep, while the record's row comes from the slot fact, which holds the closure.

Parked 2026-11-25 by COV-CLOS (coordinator ruling (c)), beside COV-UNION's adopted-storage-row
family. The IR can build the `Map()` at the row's shape (prototyped as an `RMapNew` with a shape
slot), but that only moves the clash. The row stores the value record at one struct (`f` at
`inc0`'s closure), while every reader types it at another (`f` the hole closure), including `r`,
a module global whose cell the layout declares. The two records do not lower alike, so no retag
bridges them; the fix belongs to the layout family that picks the row.
