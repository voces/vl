### D17015 — a hole function written into a map that a record returned from a call holds, then called through the map, builds a module that fails to validate inside the call

**check-clean invalid wasm · `` the emitted module failed to validate inside `mk`: … type mismatch: expected (ref $type), found (ref $type) `` · clause 1 · the called spelling of D16203; the same record bound directly to a `const` runs, as does a map returned bare from the call · found ablating D16202 · filed 2026-11-19 against master `3b2eb83b3` · slot store**
