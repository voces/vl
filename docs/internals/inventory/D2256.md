### D2256 — a list literal assigned to a `u8[]` function local builds the i32 list

**closed 2026-09-23 — the witness prints `200` · was check-clean invalid wasm (`expected (ref null $type), found (ref $type)`), clause 1 · found by the D2255 position matrix (`local_assign`, annotated face) · filed against master `3330dcaa3` · fixture `tests/cases/maps/u8-list-literal-into-map-value.vl`**

Repro:

    function f(): i32 {
      let v: u8[] = [1]
      v = [1, 200]
      v[1]
    }
    print(f())
    // vl check: rc 0.
    // vl run (as filed): Error: invalid module … type mismatch. Now prints 200.

#### Mechanism

`emitAssign`'s local arm seeds the build kind of a list-literal right-hand side from the
target place, through `exprListCellBuildKind`. That ladder had rungs for the string, f64, i64
and f32 lists and the nullable niches, but none for the packed byte list, so `v = [1, 200]`
built the i32 list into the `u8[]` local. The global-assignment arm reads the declaration
instead and was never affected. The fix adds the `exprU8Array` rung (build kind 10), which
the nullable-collection `??` default shares.
