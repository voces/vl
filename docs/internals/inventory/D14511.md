### D14511 — a record literal joined with a declared record in an inferred list found its arm only by field name

**closed 2026-10-27 · runs, prints `8` then `1` · fixed: `objVariantNameCtx` (emit_classify.vl) finds the arm a literal's rep stamp names by its shape (`variantRowOfRepTy`), as a structural record is found · pins: `tests/cases/unions/inferred-union-anon-arm-row.vl` · was a loud emit reject, clause 2 (`emitProgram: field access receiver is not a struct`), on master · filed 2026-10-27 against master `7f5a84423`**

Repro:

    type Sq = { s: i32 }
    const c: Sq = { s: 1 }
    const ps = [{ p: { r: 8 } }, { p: c }]
    for x in ps {
      const q = x.p
      if q is Sq { print(q.s) } else { print(q.r) }
    }

Want:

    8
    1

#### Mechanism

An inferred list joining `{ r: 8 }` with `c: Sq` types its element as `{ r: i32 } | Sq`, and the
checker stamps the literal with that union's anonymous arm. Emit registers the arm's variant row
under the union's own copy of `{ r: i32 }`, a different arena id with the same shape, so
`variantRowOfTy` on the stamp answered -1. The field-name scan below it then supplied the row at
the top level and missed it inside a field. The stamp is now looked up by shape when its exact id
has no row, through `variantRowOfRepTy`, which already excludes a declared struct with a row of
its own and a `new` brand.
