### D17850 — a `let x = null` a hole parameter fills is read after a join at `null`, so its value is lost once it builds

**closed 2026-11-28 · runs, prints `null` `9` `true` · was a loud emit reject, and under #10795 a build that printed `null null true` · four readers, re-landed with #10795's two halves (the seal fix is safe only after the join fix; coordinator ruling): the if-arm join against `null` keeps the open hole member (check_narrow_flow.vl), a re-check with no open statement installs its joins, `scopeTyAt` does not answer a hole-holding template type for an unrecorded read (emit_capture_frames.vl), and `elabTyWidensTo` counts `null` as a member of a nullable (emit_elab.vl) · pins `unions/hole-param-written-under-an-if-into-a-null-let`, `unions/hole-param-null-let-compared-to-null-at-a-caller`, `unions/hole-param-written-under-an-if-stored-annotated`, `unions/hole-param-into-a-null-let-write-grid` · the copy spelling is [D17845](D17845.md) · filed 2026-11-28 against master `45f879eda` by COV-UNION (coordinator ruling)**

Repro:

    function f(a) {
      let t = null
      if a > 5 { t = a }
      return t
    }
    print(f(1))
    print(f(9))
    print(f(1) == null)
    // vl run: prints null, 9, true

Want:

    null
    9
    true

#### Mechanism

The store is right: the local is `i32 | null` at each instance and the write lands
(`print(t)` after the `if` prints `9`). The type readers after the join are wrong: the checker's
narrowing join of the then-branch's `_` (the open hole the parameter fills) with the else path's
`null` closes to `null`, dropping the open member, so `t ?? -1`, `t == null` and `return t`
read `null`. `scopeTyAt` returns that closed template type when the elaboration recorded nothing
for the read. The unconditional spelling's caller `f(1) == null` folded the same way to `true`
(the call typed `null`). Before #10795 both were loud (the emit seal's ICE, D17844, or a
missing value box, D17831); #10795's seal fix and union registration let them build. The fix keeps
the open member through the join and re-lands both halves with it (coordinator rule: a join
never drops an open member; the seal fix is safe only after the join fix).
