### D17099 — an untagged choice of un-annotated functions handed through a generic identity to a closed function type is delivered as the member's own closure

**trap after load · clause 1 · beside [D17097](D17097.md) and [D17098](D17098.md) · owner S2 · filed 2026-11-24 against master `1603ddda`**

Repro:

    function inc(a) { return a + 1 }
    function str(_a) { return "s" }
    function id<T>(t: T): T { return t }
    function useK(k: (a: i32) => i32 | string) { print(k(4)) }
    function run(c: boolean) {
      const g = if c { str } else { inc }
      useK(id(g))
    }
    run(true)
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch, in `useK`

Want:

    s

#### Mechanism

With no call through an open parameter the choice is not tagged, and no check-time decision
reaches it: the delivery is a call argument, and the set is called through nowhere. `useK`'s
`call_indirect` at `(i32) => i32 | string` then reaches `str`'s closure, which returns a string.

#### Ablation

| ingredient | outcome |
| --- | --- |
| `const k: K = id(g); print(k(4))` in place of `useK(id(g))` | runs, `s` |
| `useK(g)` in place of `useK(id(g))` | loud check reject (`cannot choose 'inc' here`) |
| a `print(ap(g, 3))` call through an open parameter added | runs (D17097's close) |

#### Grading list

- `useK(g)` without the open call is a check reject in D17098's family and grades with it.
