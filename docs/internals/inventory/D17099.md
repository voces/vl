no hole instance for the call site `id(g)` and notes an escape that waits for a tag the check

the adapter. Located by a distinctive `emitFail` in `monoCloCoerceBuild`, controlled on a program
that fires it. Ruled fix (coordinator, option B): the check decides the set at a hand-back
