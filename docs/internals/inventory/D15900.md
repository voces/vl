### D15900 — a list literal of records of an un-annotated function, handed to a parameter or field and read once, beside another list of it called at two signatures, is refused at emit

**open · loud emit reject, `emitProgram: a function value is called at two signatures, and the closure it holds was built for one: …` · clause 2 · the delivery positions D15338's close leaves: an argument, a return, a record field, a list element or push, a local or global assignment, a map value · found closing [D15338](D15338.md) · filed 2026-11-12 against master `133a1b1eb`**

Repro:

    function id(a) { return a }

#### Mechanism

Not yet traced past D15338's. The tag plan takes a list literal bound by an annotated binding as
holding closures; one handed elsewhere first is still read as a holder of the set's ids, so
`{id}` stays closures and the calls through `xs` meet one closure at two signatures. A list of
lists of such records, `const zs = [[{ f: id }]]`, is refused the same way: the walk is one list
level deep, since admitting a nested one trapped the compiler in `rlTwinSigOf` (emit_collect.vl).
