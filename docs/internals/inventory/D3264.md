### D3264 — a returned join of a type parameter with a literal, bound outside the generic and put in an object literal, mints no row

**loud emit reject · clause 2 · open · found by the #3297 review (`g2` grid, `rec__jrev__field` and `k__jrev__field` cells) · filed 2026-09-29 against master `2684da15d`**

Repro:

    type R = { f: i32 }
    function g<T>(a: T, c: boolean) {
      const r = if c { 5 } else { a }
      return r
    }
    const u: R = { f: 1 }
    const w = g(u, true)
    const b = { v: w }
    if b.v is i32 { print("L") } else { print("P") }
    // vl check: rc 0.  vl run: emitProgram: object literal matches no union variant

Want:

    L

#### Mechanism

Not localised past the ablation. `w` is typed `R | i32`, the join D2906 keeps apart, and its
value box is registered only when the monomorphizer pins `g`. The anonymous-row pass runs before
that, so the literal `{ v: w }` finds no box to code its field with and mints no row, and the
emitter then has no row to build it at. On master the join was folded into `T`, so the field
was `R` (invalid wasm at this pin) or, at a `"a" | "b"` pin, the atom (it ran).
