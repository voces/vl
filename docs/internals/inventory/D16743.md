### D16743 — a map written two records whose function field holds un-annotated functions of different results is refused at check

**loud check reject · clause 2 · found closing [D16731](D16731.md) · filed 2026-11-16 against master `71ff99b49`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const m = Map()
    m.set("a", { f0: inc0 })
    m.set("b", { f0: half })
    print(m.get("a")?.f0(3) ?? 0)
    print(m.get("b")?.f0(3) ?? 0)
    // vl check: rc 1, "cannot write 'half' to 'm[].f0': called at (i32) it returns f64, where 'inc0', also written to it, returns i32 — every function a call through 'm[].f0' may run must return one type"

Want:

    4
    1.5

#### Mechanism

Not yet located. The same records in a list literal run at any depth ([D16731](D16731.md)); the
one-result judge does not lift a map's record value written by `set` as it lifts a list's
element. The refusal names a mechanism, not a design rule.

#### Grading list

- The record nested two and three levels in the map's value.
- [D15161](D15161.md), the map handed to a parameter.
