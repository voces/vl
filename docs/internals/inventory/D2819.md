#### Mechanism

The join is typed `string[][] | i32[][]`, as the one-level `xs ?? [1]` is, but the nested default
is not built and boxed as the `i32[][]` arm beside the `string[][]` value: the one-level
spelling runs (D2799) and the nested one does not. Not yet localised further; D2798's
`arrLitElemNameIn` reads a nested literal's own leaf, so the default's row is the next place to
look.
