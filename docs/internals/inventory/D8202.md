### D8202 — a generic identity over a function that returns an identity over a fresh call is built at the declared record of the call's fields

**closed 2026-10-20 by lane L1 · the witness prints `15` · was check-clean invalid wasm · clause 1 · present on master `be738c9f0` · fixture `tests/cases/generics/fresh-call-at-several-sites-built-at-delivery.vl` · the two-identity face is [D8303](D8303.md) · found closing [D8020](D8020.md) · filed 2026-10-20 against master `be738c9f0`**

Repro:

    type Col = { r: i32, g: i32 }
    type J = { r: i32 | null, g: i32 }
    function idn<T>(v: T): T { v }
    function mk() { { r: 15, g: 1 } }
    function wrap() { idn(mk()) }
    const m: J = idn(wrap())
    print(m.r ?? 0)

Want:

    15

#### Mechanism

The checker accepted the delivery of `idn(wrap())` into `J` while `mk`'s literal was still
built at `Col`. Closed on both sides. In the checker, `recFnBuiltAtDst` follows a result leaf
through every generic identity that only its argument pins to the inferred function it calls,
so `wrap`'s leaf hands `J` on to `mk`. In the emitter, `monoRebuiltLitRetName` (emit_mono.vl)
names the row through the same identities and through an argument-free call of another
inferred function, so the outer `idn` instance is taken at the row `mk` is now built at.
