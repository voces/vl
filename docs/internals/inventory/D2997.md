### D2997 — an inline record literal handed to an un-annotated parameter and re-bound inside reads its `boolean` field as `1`

**check-clean silently wrong · clause 1 · identical on master `b34730ad9` · found by lane WD's `boolean` template (`argument`, un-annotated face) · filed 2026-09-28**

Repro:

    function take(a) {
      const v = a
      print(v.v)
    }
    take({ v: true })
    // PRINTS 1

Want:

    true

#### Mechanism

Not localised past the ablation. The instance of `take` pinned by the literal reads the field
correctly through `a`, but through the un-annotated alias `v` the read is printed as an `i32`.
No declared record is involved.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the alias (`print(a.v)`) | prints true | **yes** |
| the inline literal (`const o = { v: true }` then `take(o)`) | prints true | **yes** |
| the parameter's missing annotation (`a: { v: boolean }`) | prints true | **yes** |
| the record (`take(true)`, `print(v)`) | prints true | **yes** |
