### D16100 — a field read off a field or element assignment of a row-less record has no receiver row

**closed · runs, prints `3` `3` · was loud emit reject, clause 2 · fixed 2026-11-14: the assignment's row is its place's when the right-hand side has none · consumer side of [D16016](D16016.md) · filed 2026-11-14 against master `55e8faf3b`**

Repro:

    type Node = { v: i32, left: Node | null }
    const root: Node = { v: 1, left: null }
    print((root.left = { v: 3, left: null }).v)
    print(root.left?.v ?? 0)

Want:

    3
    3

#### Mechanism

Since D16016 the assignment delivers the place's cell, non-null, but a reader asking the
assignment's struct row (`structIndexOfExpr`) asked the right-hand side's rep, a record literal
with no row, and got none, so the field read was refused (`field access receiver is not a
struct`) and a `const` bound to the assignment had no shape. A name target already answered
through its re-read (`asgCellOf`); a field or element target did not.

#### Closed (2026-11-14)

`asgPlaceRowOr` (`compiler/emit_classify.vl`) answers the field or element's row when the
assignment's own answer is none. The element spelling (`(ns[0] = { v: 4, left: null }).v`) and
`const x = root.left = { ... }; print(x.v)` run too. Graded on
`scripts/capability-probes/matrix/assignment-record-field-read.matrix.vl`.
