### D2150 — an inline string-literal union reps as a string ref, so every compare over it walks both strings

**closed 2026-09-23 — every position graded in the PR's table compiles `==`, `!=`, `is` and `match` over the value to one `i32.eq` · was a working program whose compares called `__str_eq__` (a loop), clause 2 under the owner's ruling that comparing two string literals is O(1) · filed 2026-09-23 against master `b5debe165` · fixtures `tests/cases/getters/getter-step-budget-allows.vl`, `tests/cases/literal-unions/inline-litunion-map-callback.vl`**

Repro:

    type K = new { a: "c" | "rectangle-with-a-very-long-name", b: "c" | "rectangle-with-a-very-long-name" }
    get same(self: K): boolean { self.a == self.b }
    const k: K = { a: "rectangle-with-a-very-long-name", b: "rectangle-with-a-very-long-name" }
    print(k.same)

#### Mechanism

A literal union's TYPE did not carry its REP. The emitter's rep question is whether the union's
arena index is a registered alias (`tyIsLitUnionAlias`): a declared `type K = "a" | "b"` is, and
reps as the interned i32 atom; an inline `"a" | "b"` at a field, parameter, return, local, global,
capture or type argument is a fresh `TyUnion` nobody registered, so it repped as a string ref and
every compare over it called `__str_eq__`. `annUnionInnerTy` now registers each inline string
literal set as a hidden alias `#luN` the first time the checker resolves it, and the checker
writes a `UnionDecl` for each one into the program before canon, so every pass that reads
declarations sees exactly what it sees for a written alias. The name never reaches a person:
`demangleMsg` renders `#luN` as its member set. A set first minted during emit keeps the string
rep, since no declaration would carry it (`luSynthDone`). The registry is indexed by member set
(`luPosByKey`), since a scan per lookup made a program's compile quadratic in its distinct sets —
the `literal-union sets` pair in `tests/vl_scaling_shape_test.ts`.

#### Ablation

| spelling | before | after |
| --- | --- | --- |
| inline field, `==` against a literal | `__str_eq__` | `i32.eq` |
| two inline fields, `==` | `__str_eq__`, refused in a getter | `i32.eq`, cost 0 |
| `match` over an inline field | one `__str_eq__` per arm | one `i32.eq` per arm |
| parameter, return, local, module `let`/`const`, capture, generic `T` | `__str_eq__` | `i32.eq` |
| list element, map value, `T \| null` | `i32.eq` | `i32.eq` |
| `"a" \| i32` (a mixed union) | `__str_eq__` on the box payload | unchanged |
