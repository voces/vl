#### Mechanism

[D14817](D14817.md) and [D14818](D14818.md) build a fresh call at the wider row and copy it into its own
record where it is delivered at its own type. `recCopyNarrows` admits the copy only where every field
it narrows is one the own type types `null`, which is the only value it can hold. Here the own type
types `r` as `i32` while the wide row stores `i32 | null`. The copy would have to unwrap a nullable
field, which is sound only because every value `mk5` builds has `r: 5`. That fact is the function's
own result type, but no copy arm reads it.
