### D14437 — a bound list of an un-annotated function is built at the first closed list type the pin meets

**loud emit reject · `cannot take the generic function inc7 as a value` · clause 2 · open · either delivery alone is fine · deleted by deciding a list of a set delivered to an annotated function-list type when the pins retire · filed 2026-10-27 against master `9b5bfd1b8`**

Repro:

    function inc7(a) { return a + 1 }
    function apI(r: (a: i32) => i32) { return r(7) }
    function ap2(r: ((a: f64) => f64)[]) { return r[0](1.5) }
    const v = [inc7]
    print(v.map(apI)[0])
    print(ap2(v))
    // Want: 8, 2.5

#### Mechanism

A `.map` over `v` builds each element at the callback's signature per delivery, but `ap2(v)`
delivers the whole list to a closed function-list type. That delivery would need a converting
copy of the list, which the aliasing ruling does not allow, so the list's element type comes
from the emitter's pin, which settles on the first closed type it meets. A list of a set
delivered to a closed function-list type is a transitional floor until the pins retire.
