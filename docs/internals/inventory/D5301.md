### D5301 — `?.` then `??` over a call returning a nullable union of records has no coalesce

**loud emit reject · clause 2 · found closing D5243 · the same refusal on master `d1b078d59` · filed 2026-10-17 against master `d1b078d59`**

Repro:

    type N = { tag: "a", v: i32 } | { tag: "b", w: i32 }
    function mk(): N | null { { tag: "b", w: 2 } }
    print(mk()?.tag ?? "z")
    // vl check: rc 0.  vl run: emitProgram: `??` over this nullable value is not supported yet — narrow it first, e.g. `if v != null { … }`

Want:

    b

#### Mechanism

Not ablated past the table below. D5243's close desugars `r?.f ?? d` only when `r` can be
read twice (a name, a member or an index chain); a call receiver would be evaluated twice,
so it is left to the `??` lowering, which has no rep for the union-box chain.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const r = mk()` then `print(r?.tag ?? "z")` | runs, `b` | **yes** |
| `N` a single record `{ tag: "a", v: i32 }` | runs, `a` | **yes** |

#### Grading list

The call receiver above; a method-style call receiver; a receiver with a side effect, which
must still run once.
