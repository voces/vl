### D2831 — a generic list pin through an annotated `const w: T` inside an explicit `return` of a nested join builds the outer join at i32

**closed 2026-09-27 — the witness prints `1` · was check-clean invalid wasm (`type mismatch: expected i32, found (ref $type)` inside `h`), clause 1, on master · found by the #3215 round-2 review (`rv3215g/p3/d1.vl`) · filed 2026-09-27 against master `9f11c9c9f` · fixture `tests/cases/generics/if-arm-nested-local-generic.vl`**

#### Mechanism

The monomorphizer rebuilds the returned chain to substitute the annotation `w: T`, and the
rebuilt inner `if` carries no recorded type. The outer join asked the inner one for its list
rep. The if-join gate refuses an `i32` list, and D2825's type-variable exception covered only a
recorded type variable, not a missing type, so the outer blocktype fell to i32. The close
treats a missing recorded type like a type variable. The arms still have to agree
(`ifArmsAgreeOnListRep`).
