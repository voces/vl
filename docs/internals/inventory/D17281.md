### D17281 — a function's single-literal local initialized from an atom field and captured by a closure is emitted with a local the function never declares

**closed 2026-11-24 · runs, prints `circle`, claimed and claimless · was check-clean invalid wasm (clause 1), `unknown local 5: local index out of bounds` in `fr` · fixed in emit_fn_scans.vl: a binding annotated with a lone string literal whose initializer is an atom reserves the string-op scratch frame its widening decodes into (`letWidensAtomToStr`), as a `string` or literal-union annotation already did · grading: the eight annotated capture cells of `record-atom-field-read-as-string.matrix.vl` and `variant-atom-field-read-as-string.matrix.vl` go invalid module → RUNS · found by lane IR-N8 in the `record-atom-field-read-as-string` position matrix (4 capture cells, annotated face) · filed 2026-11-24 against master `156b4dd0c`, the same under the claimless compiler; closed by lane IR-N11 with D17340**

Repro:

    type H = { k: "circle" }
    const h: H = { k: "circle" }
    function fr() {
      const c: "circle" = h.k
      const f = () => { print(c) }
      f()
    }
    fr()
    // vl check: rc 0.  vl run: rc 0, prints the line below.

Want:

    circle

#### Mechanism

`letWidensAtomToStr` reserved the string-op frame only for an annotation `tyTakesAtomAsStr`
accepts. That excludes a lone literal: its member list is the one literal, not `string`. An
uncaptured binding decodes without the frame, but a captured one writes its cell through the
decode tower, which reads scratch slot 0 of a frame the function never declared.

| the closure: `print(c)` in `fr` | runs | **yes** |
| the function: the same lines at top level | runs | **yes** |
