### D17281 — a function's single-literal local initialized from an atom field and captured by a closure is emitted with a local the function never declares

**check-clean invalid wasm · clause 1 · found by lane IR-N8 in the `record-atom-field-read-as-string` position matrix (4 capture cells, annotated face) · filed 2026-11-24 against master `156b4dd0c`, the same under the claimless compiler**

Repro:

    type H = { k: "circle" }
    const h: H = { k: "circle" }
    function fr() {
      const c: "circle" = h.k
      const f = () => { print(c) }
      f()
    }
    fr()
    // vl check: rc 0.  vl run: invalid module, `unknown local 5: local index out of bounds` in `fr`

Want:

    circle

#### Mechanism

Not traced. The emitted `fr` reads or writes a local index past its declared locals, so the cell or
the decode's scratch the capture needs is never declared. The ablation below fixes the ingredients.
