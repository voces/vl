### D2978 — a hole value at a nullable literal-union pin prints its atom id

**check-clean silently wrong · clause 1 · open · the #3242 review's price cells · the same on master `8615a730d` · filed 2026-09-28 against master `264fd86f1`**

Repro:

    type LS = "a" | "b"
    function k(v) {
      const l = [v]
      print(l[0])
    }
    const x: LS | null = "b"
    k(x)
    // vl check: rc 0.  vl run: prints `0`

Want:

    b

#### Mechanism

Not localised. The silent twin of [D2807](D2807.md). A hole read typed at a `LS | null` pin is the
`i32` atom niche (`-1` for null), and no print rung claims it as one, so `print` takes the `i32`
import: `"b"` prints `0` and `null` prints `-1`. [D2942](D2942.md)'s close reads the non-null
literal-union pin only (`tyLitUnionAliasIx`), and the nullable niche needs
`emitPrintNulLitUnion`'s member-or-`null` chain.
