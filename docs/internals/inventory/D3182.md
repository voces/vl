### D3182 — a hole parameter whose body null-tests a function field calls a second record's non-nullable field function at the first record's nullable type, or refuses it

**closed · a closure widens into a `| null` field of an anonymous row only at that field's signature, a declared or annotated row claims no literal whose function field differs, a null test of a value its hole instance binds to a function is the constant `true`/`false`, and a hole read under a null test reads the non-null face of its pin (`holePinReadOf`) · fixture `tests/cases/generics/hole-null-tested-field-function-beside-nullable-one.vl` · was check-clean silently wrong, the second face a loud emit reject · clause 1 · found by the #3285 review (`rv3285-2112/p/x2.vl`) · the same on master `995bbc74e` and `a6cb22568` · filed 2026-09-29 against master `a6cb22568`, closed 2026-09-29 against master `36d233f66`**

Repro:

    function F(z) {
      print(z.v)
      const g = z.f
      if g != null { print(g()) }
    }
    const a: { v: i32, f: (() => i32) | null } = { v: 1, f: () => 2 }
    F(a)
    F({ v: 5, f: () => true })
    // printed 1, 2, 5, then 1 on master

Want:

    1
    2
    5
    true

#### Mechanism

Three steps. The literal `{ v: 5, f: () => true }` joined `a`'s anonymous row, because
`anonValueFitsField` let any closure widen into a `| null` closure field whatever its signature,
so both calls shared one hole instance and read `g()` at `i32`; a closure now widens there only
at the field's own signature. The literal then keys its own instance, where `g`'s hole binds to
a plain function, and `g != null` lowered `null` with no context and refused (the second face,
and the one-call program): `deadNullTestOperand` now also takes an operand its hole instance
binds to a function. Inside the narrowed arm `g`'s type is the deferred `hole minus null`
(`HD_GNOT`), which `holePinReadOf` did not read, so `g()` was keyed but its result printed at
`i32`; it now reads the non-null face of the pin. Without that last step the refusal would have
become the first face's wrong value.

Second face (`rv3285-2112/p/x2.vl`), a loud emit reject:
