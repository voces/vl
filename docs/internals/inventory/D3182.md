### D3182 — a hole parameter whose body null-tests a function field refuses a record whose field is a non-nullable function

**loud emit reject · clause 2 · pre-existing, the same on master `995bbc74e` and `a6cb22568` · found by the #3285 review (`rv3285-2112/p/x2.vl`) · filed 2026-09-29 against master `a6cb22568`**

Repro:

    function F(z) {
      print(z.v)
      const g = z.f
      if g != null { print(g()) }
    }
    const a: { v: i32, f: (() => i32) | null } = { v: 1, f: () => 2 }
    F(a)
    F({ v: "s", f: () => true })
    // vl check: rc 0.  vl build: emitProgram: bare null needs a struct-typed context

Want:

    1
    2
    s
    true

#### Mechanism

Not localised past the ablation. The refusal fires at the second call, whose literal's `f` is
a plain `() => boolean`. The body's `g != null` test is lowered against the `null` literal
with no struct-typed context for a non-nullable function value. The first instance, whose `f`
is `(() => i32) | null`, runs alone.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the second call removed (`F(a)` only) | prints `1`, `2` | **yes** |
| the first call removed (only the literal `{ v: "s", … }`) | same refusal | no (the first instance) |
| second literal's `v: 5` (the same data type as `a`) | prints `1`, `2`, `5`, `1` | **yes** (a second row, though its `true` prints as `1`) |
| `a`'s `f: () => i32` (not nullable) | same refusal | no |

#### Grading list

The witness, the one-call program `F({ v: "s", f: () => true })`, and the `v: 5` spelling,
which runs but prints `1` for `true`.
