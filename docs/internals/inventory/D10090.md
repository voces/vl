### D10090 — in a recursive function a join of a runtime `i32` and a runtime `f64` is typed `f64`, where the same join in a non-recursive function is `i32 | f64`

**loud check reject · clause 2 · found closing [D10061](D10061.md) · present on master `6691b1395` · filed 2026-10-22 against master `6691b1395`**

Repro:

    function g(q: i32 | null, d: f64, n: i32) {
      if n > 0 { g(q, d, n - 1) }
      const r = if q != null { q } else { d }
      print(r is i32)
    }
    g(5, 1.5, 1)
    // vl check: `is` check type 'i32' can never match a value of type f64

Want:

    true

#### Mechanism

Not traced. Under the numeric-join ruling the two runtime arms join as `i32 | f64`, and the same
body without the self-call prints `true`. The `??` spelling (`q ?? d`) is refused the same way,
so the split is recursion against non-recursion, not `if` against `??`. A function whose body
calls the built-in `m.get(k)` and is itself named `get` takes the same widening.
