#### Mechanism

Under the numeric-join ruling the two runtime arms join as `i32 | f64`, and the same body
without the self-call prints `true`. A function that names itself is `njFnReached`
(check_nj_gate.vl), which holds every join in its body at master's widening; that gate is
[D3494](D3494.md)'s, so this row is its non-generic `??` and `if` face. The `??` spelling (`q ?? d`) is refused the same way,
so the split is recursion against non-recursion, not `if` against `??`. A function whose body
calls the built-in `m.get(k)` and is itself named `get` takes the same widening.
