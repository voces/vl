### D15745 — a generic maker returning a `const` that holds a record of a function, its field written, is refused at emit

**closed 2026-11-11, runs and prints `2` `2.5` · was loud emit reject, clause 2, `ref valtype with no interned shape` · found closing [D15743](D15743.md) · closed in the check: `holeSlotCallRetRecs` (check_relate_core.vl) takes a generic maker's returned `const` that the maker's body declares with a record literal, and hands the literal on (`holeSlotRetRecLit`) · a write the maker makes to the `const` before returning it is kept · fixture `tests/cases/generics/fn-record-from-generic-maker-const-field-written.vl`**

Repro:

    function id0(a) { return a }
    function id1(a) { return a }
    function mk<T>(x: T) {
      const o = { f: id1, x: x }
      return o
    }
    const r = mk(1)
    r.f = id0
    print(r.f(2))
    print(r.f(2.5))

Want:

    2
    2.5

#### Mechanism

D15743's close reads a generic maker's returned values only when each is a record
literal (`holeSlotCallRetRecs`); a returned `const` holding the literal is not followed, so the
written field stays a closure of `id1`.
