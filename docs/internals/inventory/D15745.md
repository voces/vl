### D15745 — a generic maker returning a `const` that holds a record of a function, its field written, is refused at emit

**loud emit reject · clause 2 · `ref valtype with no interned shape` · found closing [D15743](D15743.md) · filed 2026-11-11 against master `f570d7f7`**

Repro:

    function id0(a) { return a }
    function id1(a) { return a }
    function mk<T>(x: T) {
      const o = { f: id1, x: x }
      return o
    }
    const r = mk(1)
    r.f = id0
    print(r.f(2))
    print(r.f(2.5))

Want:

    2
    2.5

#### Mechanism

Unmeasured. D15743's close reads a generic maker's returned values only when each is a record
literal (`holeSlotCallRetRecs`); a returned `const` holding the literal is not followed, so the
written field stays a closure of `id1`.
