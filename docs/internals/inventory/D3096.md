#### Mechanism

`forInElemKind` answered `nulstruct` for every nullable struct-element ref list. An arm has no
struct row (`collectS` refuses a variant one), so `forInVarStructIdx` gave -1 and the loop
variable's local hit `fbValtype`'s bounds guard. `const e = z[i]` binds the `nulvariant` niche
through `letIsNulVariant`; the walk now asks `rlElemVariantRow` the same question, and the
three ladders that enumerate walk kinds (`declareForInLocals` twice, `emitForInStmt`'s wrapper
pick) name `nulvariant` beside `variant`, reading its element without a non-null recovery.
