### D4041 — a nullable string-literal-union value delivered into a wider union has no members to widen with

**open · loud emit reject · clause 2 · found by lane L2's kind grid (`scripts/twin-agreement.vl` KINDS programs) · filed 2026-10-11 against master `5a9535c91`**

Repro:

    type U = "a" | "b" | null | { tag: i32 }
    const a: ("a" | "b") | null = "a"
    const u: U = a
    print(u == null)
    // vl check: rc 0.  vl run: emitProgram: literal-union string widening with no members

#### Mechanism

The VALUE is a nullable literal union and the target is a union with a non-string arm, so the
delivery has to widen a `K | null` niche into a union box. The widening asks for the literal
members of the source and finds none, which says the member list is read off a spelling that has
lost them at the nullable wrapper. Same refusal as the generic rows [D3228](D3228.md) and
[D3239](D3239.md), reached here with no type parameter at all; whether it is one mechanism is not
yet ablated.
