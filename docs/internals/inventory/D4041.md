### D4041 — a nullable string-literal-union value delivered into a wider union has no members to widen with

**open · loud emit reject · clause 2 · a returned parameter, and an annotated binding or assignment inside a function, at every spelling of the target; a module global's binding widens since lane L6 step 3 (2026-10-19), and the filed binding witness, `const u: U = a` over an inline `("a" | "b") | null`, prints `false`, pinned by `tests/cases/unions/litunion-nullable-narrow-and-deliver.vl`, and its aliased spelling is [D7043](D7043.md) · found by lane L2's kind grid (`scripts/twin-agreement.vl` KINDS programs) · filed 2026-10-11 against master `5a9535c91`**

Repro:

    type A = ("a" | "b") | null
    type U = A | { tag: i32 }
    function f(a: A): U { return a }
    print(f("a") == null)
    // vl check: rc 0.  vl run: emitProgram: literal-union string widening with no members

Want:

    false

#### Mechanism

The VALUE is a nullable literal union and the target is a union with a non-string arm, so the
delivery has to widen a `K | null` niche into a union box. At a returned parameter the widening's
operand test (`emitUnionCoerceValueAtom`'s `nlParam`) declines a parameter of a function with a
declared return, so it refuses. Same refusal as the generic rows [D3228](D3228.md) and
[D3239](D3239.md), reached here with no type parameter at all.
