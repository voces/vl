### D4720 — a list literal of a string, `null` and a record builds invalid wasm, or is refused when the record comes first

**check-clean invalid wasm · clause 1 · found writing D4688's second delivery position · the same on master `a254c3da4` · filed 2026-10-14 against master `a254c3da4`**

Repro:

    const f = ["t", null, { x: 1 }]
    print(f.length)
    // vl check: rc 0.  vl run: invalid module, type mismatch in the module's top-level code

Want:

    3

#### Mechanism

Not localised past the ablation. The literal's type is `(string | {x: i32} | null)[]`, a union
list whose null member sits beside a record arm. Element order decides which way it fails: a
string first builds invalid wasm, a record first is refused with `emitProgram: bare null needs
a struct-typed context`. Without the `null`, every order runs (D4688).

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the `null` removed | runs, `2` | **yes** |
| the record first, `[{ x: 1 }, null, "t"]` | refused, `bare null needs a struct-typed context` | no (loud, not silent) |
| `type H = { x: i32 }` declared | the same | no |
| annotated `(H \| string \| null)[]`, record first | refused, the same message | no |
| the list as a record field, `{ f: [{ x: 1 }, null, "t"] }` | refused since D4688, invalid wasm before | no |

#### Grading list

The witness; `[{ x: 1 }, null, "t"]` (refused, should print `3`); the annotated
`const f: (H | string | null)[] = [{ x: 1 }, null, "t"]` under `type H = { x: i32 }`.
