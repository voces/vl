**loud emit reject · clause 2 · found grading the D2882 spread matrix's `argument` cell, and not a spread defect · filed 2026-09-28 against master `03dcbcfac`**

Repro:

    function take(a) {
      const e = a[1]
      if e != null { print(e) }
    }
    const src: i32[] = [3, 4]
    take(src)
    // vl check: rc 0.  vl run: emit error: bare null needs a struct-typed context

#### Mechanism

Not localised past the ablation. [D2240](D2240.md) folds a null test over a pinned parameter
whose pin proves it non-null; the same test one read further in, over an element of the pinned
list, reaches the bare `null` with no operand rep to compare against. The annotated parameter
runs, so the element's type is known at the direct spelling and lost at the pin.
