### D12921 — D3154's nested list literal builds invalid wasm once the program also builds a list of the union box

**check-clean invalid wasm · clause 1 · open · [D3154](D3154.md)'s witness is a loud emit reject alone; one more list of the same `i32 | null` anywhere in the program makes it silent · pre-existing on master · found grading D10891's delivery positions · filed 2026-10-25 against master `7ac32ffce`**

Repro:

    const v: i32 | null = 4

    print(k.length)
    function f<T>(x: T) {
      const l = [[x]]

#### Mechanism

Not localised. Alone, the inner `[x]` at the `i32 | null` pin has no box-list row and the
emitter refuses (D3154). The top-level `[v]` interns that row, so the inner literal now
resolves to a list of union boxes while the outer literal keeps the template's `i32[]` row
and stores it as an `i32`. The same gap as D3154, past the point where it was loud.
