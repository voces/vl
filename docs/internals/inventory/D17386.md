### D17386 — a list of a call whose inferred result is `{ r: null }`, beside a union naming a `{ r: i32 | null }` record, has no interned shape

**loud emit reject · clause 1 · `vl check` accepts, `vl run` refuses "emitProgram: ref valtype with no interned shape" · found by lane IR-D1 ablating `distilled/cells/b000498`'s `array element coercion` · filed 2026-11-24 against master `a656a885e`, pre-existing**

Repro:

    type Circle = { r: i32 | null }
    type Shape = Circle | i32
    function mk() { return { r: null } }
    const xs = [mk()]
    print(xs.length)
    // vl check: rc 0.  vl run: emit error: emitProgram: ref valtype with no interned shape

Want:

    1

#### Mechanism

To be measured by the fix. `mk`'s inferred result is the record `{ r: null }`, a twin of
`Circle`'s row. A union that names `Circle` makes that row a variant. The list literal holding the
call's result then reaches the emitter at a reference valtype no shape was interned for. The same
literal written in place, or the call bound and read without a list, runs.
