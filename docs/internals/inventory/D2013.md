**closed — the captured store yields its value, as every other position's does: `assignTargetReReads` admits a captured name's cell `q[0]`, and a literal-index or field write on a named non-map place, as an assignment the emitter lowers by storing and re-reading the target, and `stmtIsTailValue` asks the same predicate · was loads then traps (`vl check` rc 0, then a `wasm unreachable` trap, clause 1) · filed 2026-09-22 against master `5c4fc52ba`, found reviewing [D1998](D1998.md) (#3020) · closed 2026-09-22 against master `af07f4ae0` with [D1995](D1995.md) · `tests/cases/conditionals/tail-if-value-less-arm.vl`**

Repro (runs, prints `5`):

    function k(): i32 {
      let q = 0
      const f = () => q = 5
      f()
    }
    print(k())
    // vl check: rc 0.  vl run: wasm trap, unreachable, in `f`

#### Mechanism

Not D1995's mechanism, though both end in the same `unreachable`. The capture rewrite
(`cboxWalk`) boxes a mutated captured `let q` as a one-element list and spells every use as
`q[0]`, so the closure's `q = 5` reaches the emitter as the INDEX store `q[0] = 5`. The emitter
held every non-identifier assignment to be a statement (`stmtIsTailValue`, and the value arm of
`emitBinExprNode` refused it outright), so the closure's functype had no result while the checker
typed `f` as `() => i32`, and `k`'s tail `f()` fell into the padding `unreachable`. The same rule
made `function s(o: {x: i32}) { o.x = 5 }` void in the emitter and `i32` in the checker, which
failed validation at `print(s(o))`. The filed prose below is the original, pre-close reading.

An assignment is an expression whose value is the assigned value: a binding
(`const r = if a { 1 } else { q = 5 }`), a function body and a closure over a module global all
yield 5. The checker gives a closure whose tail is an assignment to a CAPTURED local that same
type, so it accepts `f()` as an `i32`, but the lowering of the store through the captured cell
leaves no value for the closure's result, and the body ends in the emitter's `unreachable`. The
review witness reached it through an `if`-expression arm; the arm is scenery.

#### Ablation

| spelling | outcome |
| --- | --- |
| `() => q = 5`, `q` a local of the enclosing function (the witness) | traps |
| `() => { q = 5 }` | traps |
| `() => if a { 1 } else { q = 5 }` | traps |
| `() => if a { q = 5 } else { 1 }` | traps |
| `(): i32 => if a { 1 } else { q = 5 }` (annotated return) | traps |
| `() => if a { 1 } else { q = 5` then `q }` (value after the store) | prints 5 |
| `q` a module global: `const f = (a: boolean) => if a { 1 } else { q = 5 }` | prints 5 |
| no closure: `const r = if a { 1 } else { q = 5 }` in a function | prints 5 |
| a function body `function f(a: boolean) { if a { 1 } else { q = 5 } }`, `q` global | prints 5 |

#### Grading list

Re-grade D1995's witness when this closes. The close has to pick one side: either the captured
store yields its value, as every other position does, or the checker refuses the value at every
position, not only in a closure.
