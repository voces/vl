### D16909 — a lambda whose record result has a list-or-boolean field beside a nullable map field written `null` has no type for the union field at emit

**loud emit reject · `emitProgram: a record literal's union field has no type` · clause 2 · open · `vl check` rc 0 · found by the rep fuzzer's multiobs leg, seed 81922145 cases 399 and 400 · filed 2026-11-16 against master `6cd505a50`**

Repro:

    const v: () => {f: f32[] | boolean, z: {[string]: i32} | null} = () => ({ f: [1.5], z: null })

#### Mechanism

Not traced. The lambda's record literal takes its contextual result. With the map field given
`null`, the literal's union field `f` gets no type at emit. Given a map, it gets one.
