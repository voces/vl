### D2856 — a generic nested-list join at a string or boolean pin refuses the narrowed `i32[][]` arm's element read

**loud emit reject · clause 2 · found grading the D2769 position grid (`nest_generic_*` cells) · the same on master `721781075` · filed 2026-09-27 against master `721781075`**

Repro:

    function mk<T>(c: boolean, t: T) {
      if c { return [[t, t]] }
      [[7, 8, 9]]
    }
    const v = mk(false, "x")
    if v is string[][] { print(v[0][0]) } else { print(v[0][0]) }
    // vl check: rc 0.  vl run: emit error — narrowed ref-array arm has no reflist slot

#### Mechanism

Not localised past the ablation. The call types `string[][] | i32[][]` and the `is` test runs;
the element read in the narrowed `i32[][]` arm finds no reflist row for the arm. The concrete
spelling and a parameter annotated with the union both run, so the missing row is the one the
un-annotated binding of a generic join would name. [D2834](D2834.md) reports the same message
at a nested-list pin and suspects a second mechanism there; this may be it.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |

| the un-annotated binding (`use(v: string[][] \| i32[][])`) | runs, prints `7` | **yes** |
| the string pin (`T := boolean`) | the same refusal | no |

#### Grading list

The grid's `nest_generic_{bind,capture,generic}_{elem,for,length}` cells at `T := boolean`. The
`nest_generic_field_*` cells refuse at the object literal instead (`object literal matches no
union variant`, at `T := string` too), which [D2795](D2795.md) reports for a record-list arm;
re-grade them against this row's fix before treating them as one family. The delivery grid's
`field_generic_flat_match_*` cells refuse with that message too, at `T := string` as well.
