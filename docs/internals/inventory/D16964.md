### D16964 — a record literal with a field holding a built read, stored into a nullable record field whose initialiser is a join, builds invalid wasm

**check-clean invalid wasm · clause 1 · open · found grading D16957 (`built-record-read-field-*.matrix.vl`), invalid on master and on the D16957 branch alike · filed 2026-11-18 against master `0ca511a3e` by lane F2**

Repro:

    type J = { f: i32 | null }
    const m = Map()
    m.set("a", { f: 4 })
    const wm: {[string]: J} = m
    const d = { f: 1 }
    const w3 = { k: if d.f == 99 { null } else { { x: { f: 7 } } } }
    w3.k = { x: m.get("a") ?? d }
    print(w3.k?.x.f ?? 0)
    // vl check: rc 0.  vl run: invalid module at the store, type mismatch: expected `#anon1` {mut i32}, found `J`

Want:

    4

#### Mechanism

The stored literal holds a record built at `J` (a read of `m`, which `wm` builds at `J`), so the
binding's field must be built with that field's build. D16957 builds a record binding whose field is
stored that way, but only where the binding's initialiser is a plain record literal, which the build
stamps whole. Here the field's initial value is an `if` join, whose arm literal is not stamped at the
field's build, so the field keeps its own storage and the store writes a `J` record into it.
