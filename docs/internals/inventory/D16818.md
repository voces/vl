### D16818 — a maker's lambda bound to a local `const` and returned is lifted at `i32`, whatever its parameter is pinned at

**closed 2026-11-16 by lane AE — the witness prints `3.5` · a call through a binding of a maker call is typed by the lambda the maker returns through the un-annotated `const` that binds it, as by one it returns directly (`makerCallLamRet`), so the call's `f64` result is no longer read at the `i32` default · matrix `maker-generic-at-two-results.matrix.vl` cells `local_const_wider_pin` and `local_const_wider_pin_hole`, both faces · fixture `tests/cases/functions/maker-local-const-lambda-pinned.vl` · the two-binding spelling, both called, is [D16819](D16819.md) · was check-clean invalid wasm, clause 1 (`vl check` rc 0, no diagnostic) · the local-binding spelling of [D16815](D16815.md) and [D16817](D16817.md) · filed 2026-11-16 against master `fae99e93f`**

Repro:

    function adder(n) {
      const f = (a) => a + n
      return f
    }
    const x = adder(1.5)
    print(x(2.0))
    // vl check: rc 0.  vl run on master: invalid module, top-level code: type mismatch: expected i32, found f64

Want:

    3.5

#### Mechanism

The lambda and the `call_indirect` were built at `(f64) => f64`; the call's result was read at
`i32`. The checker types a call through a binding of a maker call by the lambda the maker returns
(`makerCallLamRet`, D16798), and took only a lambda literal returned directly: `return f` left the
call's result the hole, which the print lowered at the `i32` default.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the call at `i32` (`adder(2)`, `x(3)`) | runs, `5` | **yes**: a pin other than the default |
| the lambda returned directly (`return (a) => a + n`) | runs, `3.5` | **yes**: the local binding |
| a parameterless lambda (`const f = () => n`) | runs | **yes**: the lambda's own parameter |
| a second, unused call `adder(2)` first | the same invalid module | no |
| a second binding at `i32`, called (`const v = adder(2)`, `v(3)` first) | loud emit reject, `parameter 1 of type _` | no: the outcome moves |
