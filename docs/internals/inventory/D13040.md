Repro:

    function exclaim(s) { return s + "!" }
    function ask(s) { return s + "?" }
    function pick(on) {
      return if on {
        exclaim
      } else {
        ask
      }
    }

    // vl check: rc 0.  vl run: emitProgram: cannot take the generic function `exclaim` as a value

#### Mechanism

The returned `if` is coerced to one instance of its arms only when the function returning it
is not itself a hole function. With `on` un-annotated, `pick` is cloned per instance and the
call `f("a")` does not reach the clone's `if` to pin `exclaim`/`ask`, so the value floor
refuses the arm. Not investigated past the ablation below.
