### D4680 — a void function's call through a function value is never a tail call

**closed 2026-10-14 · runs — the witness prints `1000000` · a void function value's `call_indirect` arms the cursor with its signature's voidness, and a void caller's exit rewrites it to `return_call_indirect` · fixture `tests/cases/functions/tail-call-depth-void-arm-value.vl` · was trap after load (call stack exhausted) · filed 2026-10-14 against master `ed7d31d07` with #3748 applied**

#### Mechanism

D4657 armed the tail-call cursor on a `call_indirect`, but `emitVoidTailCall` declined every
armed table call: it decides that the callee hands nothing back from `fRetVoid` of a direct
callee, and a table call has no callee index. The arm now records whether the call's `$fnsig`
key has the void result suffix `>v` (`tailCallVoid`), and the void exit rewrites the call when
it does.
