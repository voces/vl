### D15744 — a hole lambda's bundle returned from a lambda is refused at emit

**loud emit reject · clause 2 · `a function-value call has no interned signature — parameter 1 of type `` has no representation in the function-value ABI` (it read `a function returning a parameter called at two signatures …` until the returned copy was admitted) · found closing [D15740](D15740.md) · filed 2026-11-11 against master `f570d7f7`**

Repro:

    function lap(f) {
      f(2.5)
      f(3)
      return f
    }
    const c = lap((a) => a + 1)
    const g = () => {
      const v = c
      return v
    }
    const w = g()
    print(w(4))

Want:

    5

#### Mechanism

The returned `const` copy closes as [D15747](D15747.md). What is left is the lambda: a returning
lambda is not a function whose result the elaboration follows (`elabRetRecordShape` takes a named
function), so the call through the lambda's result, `w(4)`, is a function-value call whose
parameter has no closed type. It needs a lambda's returned bundle record followed like a named
function's.

#### Ablation

| spelling | outcome | needed? |
| --- | --- | --- |
| `function g() { return c }` | runs (D15740) | **yes** |
| `const g = () => { return c }` | still refuses | no |
| `function g() { const v = c; return v }` | runs (D15747) | **yes** |
