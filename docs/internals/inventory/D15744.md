### D15744 — a hole lambda's bundle returned from a lambda, or as a `const` copy of its holder, is refused at emit

**loud emit reject · clause 2 · `a function returning a parameter called at two signatures is called where its result is not used at one of them` · found closing [D15740](D15740.md) · filed 2026-11-11 against master `f570d7f7`**

Repro:

    function lap(f) {
      f(2.5)
      f(3)
      return f
    }
    const c = lap((a) => a + 1)
    const g = () => {
      const v = c
      return v
    }
    const w = g()
    print(w(4))

Want:

    5

#### Mechanism

Two ingredients, each refused on its own after D15740: a returning lambda is not a function
whose result the elaboration follows (`elabRetRecordShape` takes a named function), and a
returned `const` whose initialiser is a read of another holder is not a returned holder
(`elabRetHolderCall` takes an initialiser that is a call).

#### Ablation

| spelling | outcome | needed? |
| --- | --- | --- |
| `function g() { return c }` | runs (D15740) | **yes** |
| `const g = () => { return c }` | still refuses | no |
| `function g() { const v = c; return v }` | still refuses | no |
