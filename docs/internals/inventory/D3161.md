### D3161 — a closure returning an un-annotated copy of a value narrowed to a nullable string sub-union out of a box is invalid wasm

**closed · an un-annotated binding of a value narrowed to `string | null` out of a box types its capture's env field as the nullable string the frame binds · fixture `tests/cases/closures/capture-narrowed-nullable-string-copy.vl` · was check-clean invalid wasm · clause 1 · found by the #3281 round-2 review (`rv3281r2-5785/a/a17.vl`) · the same on master `b1794003a` · filed 2026-09-29 against master `b1794003a`, closed 2026-09-29 against master `a0b9acaf8`**

Repro:

    type K = "a" | "b"
    function t(e: K | string | null | i32) {
      if !(e is i32) {
        const c = e
        const f = () => c
        const r = f()
        if r == null { print("N") } else { print(r) }
      }
    }
    t("a")
    t("zz")
    t("b")
    t(null)
    // vl check: rc 0.  vl run: invalid module inside `t`: type mismatch: expected (ref $type),
    // found (ref null $type)

Want:

    a
    zz
    b
    N

#### Mechanism

The frame binds `const c = e` at the narrowed `string | null` niche, because its narrowing of
`e` is live while it collects locals. The capture's env field is typed outside that narrowing,
where `letIsUnion` reads `e` as the box, so the env field was the box and the frame's nullable
string went into it. `letInitCellKind` now asks the checker's type first, as D3120's literal
union rung does: an initializer typed `string | null` that reads a box binds `nulstr`
(`letInitTyIsNarrowedNulStr`), and the binding names no union box (`letInitBindsNarrowedCell`).

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const r = c`, no closure | runs | **yes** (the closure) |
| `const c: K \| string \| null = e` | runs | **yes** (the un-annotated copy) |
| `() => e`, no copy | runs | **yes** (the copy) |
| no `K`: `string \| null \| i32` narrowed the same way | the same invalid module | no |

The witness, and the spelling with no literal union.
