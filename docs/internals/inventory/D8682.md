### D8682 — a record literal built inside a hole's instance from the hole is built at a declared record that boxes its field

**check-clean invalid wasm · clause 1 · open · present on master `a0af58b15` · found closing [D8620](D8620.md) · filed 2026-10-20 against master `a0af58b15`**

Repro:

    type A = { d: i32 | null }
    function g(x) {
      const v = { d: x }
      print(v.d + 1)
    }
    g(3)
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `g`: expected i32, found (ref $type)

Want:

    4

#### Mechanism

Inside `g`'s instance the literal's field is typed by the hole, bound at `i32`, and `v.d + 1`
is `i32` arithmetic. Emit maps the literal to a declared row by field names and takes `A`, whose
field is boxed, so the read hands the addition the box. D8620's close covers a literal handed
to a hole; this one is built inside it and read through a binding, so it is not covered. The
close is in emit's row choice for a literal whose field value is a hole-typed operand.
