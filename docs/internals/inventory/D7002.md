### D7002 — a list literal of an uncalled hole function handed to a parameter nothing reads is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: `g(exclaim)` runs ([D6881](D6881.md)), and the list bound and never read runs ([D6914](D6914.md)) · found closing [D6992](D6992.md) · present on master `bfb571e3b` · filed 2026-10-19 against master `bfb571e3b`**

Repro:

    function exclaim(s) { return s + "!" }
    function g(p) { print(1) }
    g([exclaim])
    // vl check: rc 0.  vl run: emitProgram: cannot take the generic function `exclaim` as a value — a function value carries ONE signature

Want:

    1

#### Mechanism

From the ablation and the code path. An unread parameter takes the stub of the hole functions its argument
can be, and the argument walk (`monoInertArgFns`) follows a name, a binding, an `if` and a call,
but not a list literal's elements. So the list is not recognised as holding only such functions.
