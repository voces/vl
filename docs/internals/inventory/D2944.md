### D2944 — a lambda capturing an element read off a hole parameter at a `boolean[]` pin prints `1`

**check-clean silently wrong · clause 1 · open · the #3239 review's `capel` cells · the same on master `cab9694f8` · filed 2026-09-28 against master `cab9694f8`**

Repro:

    function h(x) {
      const y0 = x[0]
      const k = () => y0
      print(k())
    }
    const v: boolean[] = [true]
    h(v)
    // vl check: rc 0.  vl run: prints `1`

Want:

    true

#### Mechanism

Not localised. The call `k()` is typed at the element of the hole's variable. That derived hole is
read at the instance only in the instance's own body, and the call's type does not carry it, so
`print` takes the `i32` path. [D2919](D2919.md) closed the same symptom for a hole value itself.
