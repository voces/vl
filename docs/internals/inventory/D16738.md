### D16738 — an un-annotated function handed to an un-annotated parameter and returned inside a record literal builds an invalid module

**closed 2026-11-16 by lane HASH — the witness prints `4` · the tag decision took `inc0` handed to the hole parameter as its id while `mk`'s record literal was built at the record solve's closed field, a closure; `ftParamStored` (check_fn_tag.vl) now counts a read of the parameter as a field of a literal built with a closure there as a store, so the set stays a closure, as the bound literal's does · fixture `tests/cases/closures/hole-fn-param-into-returned-record.vl` · was check-clean invalid wasm, clause 1 · found by the type hash-cons 6b breadth-and-depth grid (`genrec`) · filed 2026-11-16 against master `15cf11613`**

Repro:

    function inc0(a) { return a + 1 }
    function mk(f) { return { f: f } }
    print(mk(inc0).f(3))

Want:

    4

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `inc0`'s parameter annotated (`a: i32`, result `i32`) | runs | **yes** |
| `mk`'s parameter annotated (`f: (a: i32) => i32`) | runs | **yes** |
| the record (`return f`) | runs | **yes** |
| the record, as a list (`return [f]`) | runs | **yes** |
| the binding (`const r = mk(inc0)`, then `r.f(3)`) | invalid module | no |
| nesting the record deeper (2 to 10 levels) | invalid module | no |

#### Grading list

The record held at depths 2 to 10 and bound (the grid's `genrec_d02` to `genrec_d10`); a `const`
copy of the parameter in the field; a second, non-function field beside it. The nested record
called without a binding, `mk2(inc0).r.f(3)`, is a separate loud emit reject, [D16826](D16826.md).
The same record handed through a generic identity, `id([{ f: inc0 }])`, is a separate mechanism,
[D16825](D16825.md); with a second function of another result type it is [D16739](D16739.md).
