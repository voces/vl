### D16738 — an un-annotated function handed to an un-annotated parameter and returned inside a record literal builds an invalid module

**check-clean invalid wasm · clause 1 · found by the type hash-cons 6b breadth-and-depth grid (`genrec`) · filed 2026-11-16 against master `15cf11613`**

Repro:

    function inc0(a) { return a + 1 }
    function mk(f) { return { f: f } }
    print(mk(inc0).f(3))
    // vl check: rc 0.  vl run: invalid module inside `mk`, "type mismatch: expected (ref $0), found i32"

Want:

    4

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `inc0`'s parameter annotated (`a: i32`, result `i32`) | runs | **yes** |
| `mk`'s parameter annotated (`f: (a: i32) => i32`) | runs | **yes** |
| the record (`return f`) | runs | **yes** |
| the record, as a list (`return [f]`) | runs | **yes** |
| the binding (`const r = mk(inc0)`, then `r.f(3)`) | invalid module | no |
| nesting the record deeper (2 to 10 levels) | invalid module | no |
