### D16460 — a returned value `if` is lowered as one value, where the tail `if` lowers each arm as its own exit

**closed 2026-11-15 · runs, prints `1` · was loud emit reject, clause 2 (`union if-expression arm ends in a void call, which yields no value`; `union atom has no value box` for a returned `??`) · fixed in `emitStmt`'s `RetStmt` arm (`wasmEmit.vl`), which lowers a returned value `if` through `emitIfTail` · fixture `tests/cases/conditionals/return-if-lowers-as-tail-if.vl` · found by lane D's return-rule migration · filed 2026-11-15 against master `41739762`**

Repro:

    function p(xs: i32[], c: boolean) {
      return if c { xs.pop() } else { xs.push(7) }
    }
    print(p([1], true))

Want:

    1

#### Mechanism

The tail `if` is lowered arm by arm (`emitFuncBody` → `emitIfTail`): each arm's last
statement is a return of its own value, delivered to the function's result. A `return` of the
same `if` went to `emitReturnExit`, which builds the join as one value and coerces it, so an arm
whose type the join could not hold refused. The second witness is the same lowering one spelling
over: `return x ?? 5` into `f64` with `x: 9000000000 | 1 | null` refused with `union atom has
no value box`, while its tail spelling printed `5`. The `return` arm now lowers a value `if`
(`lastStmtIsValueIf`) through `emitIfTail`; an else-less chain then returns the nullable
result's `null`, as the tail's function-end pad does, and any other ends in `unreachable`.
