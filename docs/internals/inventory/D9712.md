### D9712 — `.map` over a nested list of an un-annotated function, calling the inner element, is refused as a call with no callee

**loud emit reject · `vl check` rc 0 · `a call statement's callee is neither a name, a member, nor a function value` · clause 2 · found closing [D9662](D9662.md) · present on master `e8163edd5` · filed 2026-10-22 against master `e8163edd5`**

Repro:

    function inc(a) { return a + 1 }
    const v = [[inc]]
    print(v.map((r) => r[0](5))[0])
    // vl check rc 0.  vl run: emit error: emitProgram: a call statement's callee is neither a name, a member, nor a function value

Want:

    6

#### Mechanism

Not traced. The callback's parameter `r` is the inner list, and the call `r[0](5)` is an index
read of it. An index read of the outer list (`const r = v[0]`) and a `for r in v` loop both run,
so the gap is the callback's parameter: the call is not recognised as a call through a
function-value element.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the un-annotated parameter of `inc` (`inc(a: i32): i32`) | runs, `6` | **yes** |
| the `.map` (`const r = v[0]`, `print(r[0](5))`) | runs, `6` | **yes** |
| the `.map`, for a loop (`for r in v { print(r[0](5)) }`) | runs, `6` | **yes** |

#### Grading list

The same callback over the list returned from a function with an un-annotated parameter.
