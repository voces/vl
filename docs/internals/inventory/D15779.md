#### Mechanism

A nested ref-list element whose type is open (a hole function, a type parameter) gets no row
name from `rlRowNameOfTy`, `rlRepRowNameOfTy` or `fieldElemRowName`, so `ensureRefElemTys` falls
to `refArrElemName` of the spelling. A validated probe: the `RLK_REF_LIST` branch is reached by
208 fixtures and the self-build, the spelling leg by 3 fixtures and not the self-build; a type
answer agrees on 2 of the 3, and this program's `((i32)=>i32)` hole element is the third.
`iisPushFieldElem`'s open template element (`(T|K)[]`, D15778) is the same floor. Naming such an
element by its type lets the whole cluster (`refArrShapeKind`, `nameIsRefArray`, `refArrElemName`,
`refArrElemKind`) be deleted.
