### D2159 — a member, method, index or `for` over a value typed as one string literal is refused

**closed 2026-09-23 — the witness prints `2`, `z`, `z` and `zz` · was a loud check reject (`member access '.length' on non-object "zz"`), clause 2 · filed 2026-09-23 against master `b5debe165`**

Repro:

    const j: "zz" = "zz"
    print(j.length)
    print(j[0])
    print(j.slice(0, 1))
    for c in j { print(c) }
    print(j)

#### Mechanism

The member, member-call, index and `for` checkers dispatch on the receiver being `string`, and a
one-literal type fell through to the non-object refusal. `strLitRecvTy` hands those four a
`string` for a one-literal receiver, whose rep is the string. A multi-member literal union
(`k.length` with `k: "a" | "bb"`) is still refused: it reps as the atom, and its members would
have to widen first.

#### Grading list

A `const` bound to a literal (D2157), which is where this was reached from: the compiler's own
source reads `.length` off such constants.
