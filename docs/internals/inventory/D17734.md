### D17734 — design: does a `??` default type the values of a map nothing writes?

**loud check reject · 7 programs (the 6 er-local-narrowed cells and their same-function spelling) · filed 2026-11-27 against master `d29f3434`**

Repro:

    function rd() {
      const cc = Map()
      const g0 = cc["k0"] ?? { r: "" }
      print(g0.r)
    }
    rd()
    // vl check: field 'r' is not on every member of i32 | {r: string}

#### Mechanism

A map that is only read takes the read-only default (D16726): its open value becomes `i32`, so the
read is `i32 | null` and the `??` makes `i32 | {r: string}`. The default operand never fixes the
value. Whether it should is a design question awaiting the coordinator's ruling.
