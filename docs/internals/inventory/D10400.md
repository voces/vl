#### Mechanism

Traced, not ablated. `monoFlowLetMapLeaf` follows the stored value through `monoFlowReadElem`
to the `id` inside `{ f: id }`, rewrites the `let`'s reads to `id` and notes that inner `id`
inert. The store's own operand `w0.f` is a member read, which `monoFlowNoteInertLeaf` does not
take, so `monoValsInert` fails for the slot and the slot gets no type.
