#### Mechanism

**The close.** Two classifiers answered the binding before the one that knows the arm. The
un-annotated ladders (`globalCellKindGo`, `letInitCellKind`, `collectLocals`) ask `letIsNulListInfer` — the i32
`nullist` rung — ahead of `letNulScalarListKind`, and `exprNullableList`'s null-join arm
answered `exprArray(arm)`, which claims every non-ref list literal (`["x"]`, `[1.5]`), so the
slot took `nullist` while the `if` built the leaf's wrapper. That arm now declines whatever
`exprNulScalarListKind` claims, the same ladder order `ifExprRefKind` keeps. For a ref element
the `nulreflist` rung already won, but its slot came from `nulRefArrayInnerSlot`, whose `if` arm
recursed into the arm value and had no rung for a non-null list literal: slot -1, no shape.
It now falls back to `refListSlotOfExpr` of that arm, the row `ifExprRefSlot` gives the `if`.

Matrices (`nullable-list-join-null-{string,i32,f64,i64,struct,nested-list}.matrix.vl`, an
`if` and a `match` join, 64 cells each, both faces): before 285 of 384 RUNS, after 380, 0 runs
lost. The four that do not run are an un-annotated PARAMETER pin, not a binding, and are filed
as [D2237](D2237.md) (struct element) and [D2238](D2238.md) (`i64` element); both are
unchanged by this close.

**As filed:**

The `if` is lowered correctly: its blocktype is `(ref null $5)`, the string-list wrapper, and
the then arm builds `struct.new $5`. The binding's own slot is what is wrong — the global is
declared `(mut (ref null $4))`, where `$4` is the string list's BACKING array
(`array (mut (ref null $str))`), so the `global.set` of the wrapper fails validation. The
annotated spelling (`const f: string[] | null = …`) and every non-binding delivery of the same
`if` (a call argument, a return, a struct-field initialiser) run, and an `i32[]` arm runs, so
the defect is the un-annotated binding's valtype for a nullable non-`i32` list. A ref-element
arm (`[[1]]`, `[{ x: 1 }]`) refuses at emit instead, `ref valtype with no interned shape`.

The #3076 review's own case is not this row: `let w = { f: if 1 == 1 { [] } else { null } }`
then `w.f = ["a", "b"]` is [D2225](D2225.md)'s mechanism at a field — the `[]` arm types the
slot as the `i32` list (`(field (mut (ref null $4)))`, `$4` the `i32` wrapper) and the string
list assigned later disagrees. Its plain-local twin (`let f = if 1 == 1 { [] } else { null }`
then `f = ["a", "b"]`) is D2225's witness with a `string` element.
