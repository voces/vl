### D2236 — an un-annotated binding of a non-`i32` list joined with `null` declares its slot as the BACKING array, not the list wrapper

**check-clean invalid wasm 2026-09-23 — `type mismatch: expected (ref null $type), found (ref null $type)` at the binding · clause 1 · found ablating the #3076 review's reassignment case while fixing D2235 · filed against master `93332fee4`**

Repro:

    const f = if 1 == 1 { ["x"] } else { null }
    print(f != null)
    // vl check: rc 0.
    // vl run: Error: invalid module — "the emitted module failed to validate inside the
    // module's top-level code: type mismatch: expected (ref null $type), found (ref null $type)"

#### Mechanism

The `if` is lowered correctly: its blocktype is `(ref null $5)`, the string-list wrapper, and
the then arm builds `struct.new $5`. The binding's own slot is what is wrong — the global is
declared `(mut (ref null $4))`, where `$4` is the string list's BACKING array
(`array (mut (ref null $str))`), so the `global.set` of the wrapper fails validation. The
annotated spelling (`const f: string[] | null = …`) and every non-binding delivery of the same
`if` (a call argument, a return, a struct-field initialiser) run, and an `i32[]` arm runs, so
the defect is the un-annotated binding's valtype for a nullable non-`i32` list. A ref-element
arm (`[[1]]`, `[{ x: 1 }]`) refuses at emit instead, `ref valtype with no interned shape`.

The #3076 review's own case is not this row: `let w = { f: if 1 == 1 { [] } else { null } }`
then `w.f = ["a", "b"]` is [D2225](D2225.md)'s mechanism at a field — the `[]` arm types the
slot as the `i32` list (`(field (mut (ref null $4)))`, `$4` the `i32` wrapper) and the string
list assigned later disagrees. Its plain-local twin (`let f = if 1 == 1 { [] } else { null }`
then `f = ["a", "b"]`) is D2225's witness with a `string` element.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| annotate the binding `string[] \| null` | runs | **yes** |
| element `string` → `i32` | runs | **yes** |
| element `string` → `f64`, `i64`; arm `["x"]` → a list local `xs` | invalid, same message | no |
| element → `i32[]` or a struct | loud emit reject, `ref valtype with no interned shape` | no |
| `else { null }` removed (else-less `if`, `T \| null`) | invalid, same message | no |
| module scope → function body; `const` → `let` | invalid, same message | no |
| the `if` delivered as an argument, a return, a struct-field initialiser | runs | **yes** (binding only) |
| arms swapped (`null` first) | loud emit reject, `bare null needs a struct-typed context` | not this row's |

#### Grading list

`narrowed-field-value-*` matrices' un-annotated faces (a narrowed read bound without an
annotation); the null-first order, which is [D2226](D2226.md)/[D2227](D2227.md)'s territory;
the field spelling of D2225 quoted above, which a close here must not be credited with.
