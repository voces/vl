### D6532 — a hole function passed to a hole parameter bound to another hole function is refused as a call to an unknown function

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: `lap(id)` runs, and so does `k(inc)` with a concrete `inc` · found closing [D6481](D6481.md) · filed 2026-10-18 against master `698648f78`**

Repro:

    function id(a) { return a }
    function lap(g) { return g(1) + 1 }
    function use(k) { return k(id) }
    print(use(lap))
    // vl check: rc 0.  vl run: emitProgram: call to unknown function (at 2:10)

Want:

    2

#### Mechanism

From the ablation only. The refusal points at `g(1)` inside `lap`: the instance of `lap` that
`use` calls is built with `g` bound to no function, because the argument `id` is itself a hole
function whose instance is chosen only by the call `lap` makes.
