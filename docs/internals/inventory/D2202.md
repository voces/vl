### D2202 — an empty `[]` delivered to a `string[] | S` union builds the i32 list, so the narrowed read traps

**loads then traps · found beside D2201 · filed 2026-09-23 against master `66e74235a`**

Repro:

    type B = { base: i32, length: i32 }
    function sink(data: string[] | B): i32 {
      if data is B { return 1000 }
      return data.length
    }
    print(sink([]))
    // vl check: rc 0.  vl run: wasm trap: cast failure

#### Mechanism

D2201's shape with a string element: the union box classifies the empty literal `i32[]` and its
re-mapping ladder has no `string[]` rung. Traps at all five delivery positions (argument,
annotated binding, return, assignment, struct field).
