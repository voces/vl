### D2102 — a list whose element changes storage, joined with a wider sibling, reaches the join's type with neither a copy nor a refusal

**check-clean invalid wasm · clause 1 · the container rule's twin of [D2060](D2060.md)'s join close · filed 2026-09-23 against master `2dbc968a9`, found by the second review of #3049 (probes `r01`, `r02`)**

Repro:

    const a = [1, 2]
    const b: (i32 | string)[] = ["s"]
    const ls = [a, b]
    ls[0].push("t")
    print(a[2] + 1)
    // vl check: rc 0.  vl run: invalid module — type mismatch: expected (ref $type), found (ref $type)

#### Mechanism

Not yet ablated past the table. The list literal joins `i32[]` and `(i32 | string)[]` into
`(i32 | string)[][]`, and the `i32[]` element is delivered into the joined element type with no
assignment check, so the container rule ("No implicit container widening", DECISIONS.md) never
sees it: at an annotated delivery the same pair is refused ("i32[] is not (i32 | string)[]"). The
emitter stores the `i32[]` handle where the joined list's element type is the boxed list. D2060
made a join operand a delivery for its own rule and stands aside where the element's storage
changes, since that pair is the container rule's to copy or refuse; the container rule does not yet
ask at a join.

#### Ablation

| spelling | outcome |
| --- | --- |
| the witness (list literal join) | invalid module |
| an `if` value join (`const l = if c { a } else { b }` then `l.push("t")`) | loud emit reject `.push receiver is not a list` |
| `const ls: (i32 \| string)[][] = [a, b]` (annotated) | loud check reject, `a container never widens implicitly` |
| a list of records whose fields widen, same join | D2060's refusal at the write |

#### Grading list

Both ablation joins, and the same pairs through `??` and an inferred return; the third review's
`c03` (`??`), `c04` (inferred return), `c05` (a map join), `c08` (`[xs, ys]` over `i32[]` and
`f64[]`) and `c11` (`K[]` beside `string[]`). The close is the container rule's refusal at each
join operand, as at an annotated delivery.
