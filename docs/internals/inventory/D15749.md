### D15749 — a bundle holder read where one member's function type is expected is refused at emit

**loud emit reject · clause 2 · `a function returning a parameter called at two signatures is called where its result is not used at one of them` · found closing [D15748](D15748.md) · filed 2026-11-12 against master `30871c538`**

Repro:

    function lap(f) {
      f(2.5)
      f(3)
      return f
    }
    function main() {
      const k = lap((a) => a + 1)
      const m: (f64) => f64 = k
      print(m(4))
      print(k(3))
    }
    main()

Want:

    5
    4

#### Mechanism

Unmeasured. A holder keeps the bundle record whole and picks a member at each call through it
(D15144), and a copy into an un-annotated binding is followed (D15213); a read delivered where
one closed member type is expected (an annotated binding, an annotated parameter, an annotated
return) is no such use, so no member is picked for it.

#### Ablation

| spelling | outcome | needed? |
| --- | --- | --- |
| `const m = k` (no annotation) | runs (D15213) | **yes** |
| `function u(f: (f64) => f64) { print(f(4)) }` and `u(k)` | refuses | no |
| `function q(): (f64) => f64 { return c }` with `c` a module holder | refuses | no |
