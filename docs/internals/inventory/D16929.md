### D16929 — a generic function handed to a callee that returns it in a closure, and called at a second type, is refused at the top level

**loud emit reject · clause 2 · filed 2026-11-17 against master `4005967cc`**

Repro:

    function same<T>(k: T): T { return k }
    function wrap<G>(g: G) { return () => g }
    print(wrap(same)()(3))
    print(same("x"))
    // vl check: no errors.  vl run: emit error, a generic function taken as a value reaches no call that fixes its type

Want:

    3
    x

#### Mechanism

At the top level `same` is no parameter, so no tagged set carries it and its value read takes one
instance from the call it flows to. The read in `wrap(same)` reaches `(3)` alone, yet with a direct
call of `same` at another type beside it the read is built with no instance and the value-read
refusal in `emitIdentNonLocalRead` (`compiler/wasmEmit.vl`) fires; mono's pin for the read is empty
in both programs. Inside a function the same program runs (D16843), where the handed parameter's
set is tagged.

#### Ablation

| change from the repro | outcome | needed? |
| --- | --- | --- |
| `print(same("x"))` removed | runs, prints `3` | **yes** |
| `wrap(same)()("x")` for the second line | same refusal | no |
| `pass(g) { return g }` for `wrap` | runs, prints `3` and `x` | **yes** (the closure) |
| both lines inside `function mid<F>(a: F)`, `mid(same)` | runs (D16843) | **yes** (the top level) |
