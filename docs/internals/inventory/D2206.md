### D2206 — a module-scope binding of an `if` whose arms carry different literal sets builds an invalid module

**closed — a value `if` whose join the checker recorded as a registered literal union is an atom (`ifJoinTypedAtom`): it lowers every arm in the atom context, and an un-annotated module cell bound to an atom init is the i32 atom cell its reads already assumed · was check-clean invalid wasm (clause 1, `type mismatch: expected i32, found (ref $type)`) · ran (printed `green`) on the seed built before #3056 · found by the D2199 position matrix (`litunion-if-join-arms-disagree.matrix.vl`, 12 un-annotated cells) · filed 2026-09-23 against the #3062 head `57e40f104` · closed 2026-09-23 with [D2199](D2199.md) · `tests/cases/literal-unions/if-join-arms-disagree-unannotated-binding.vl`**

Repro (runs, prints `green`):

    const A: "red" | "green" = "red"
    const G: "green" = "green"
    function one(): i32 { 1 }
    const v = if one() > 0 { G } else { A }
    print(v)

#### Mechanism

The same two producers as D2199, at a module cell. Since #3056 the join of `"red" | "green"` with
`"green"` records `A`'s registered type, so `v` is typed as an atom-rep literal union and
`exprString(v)` says it is not a string. The cell said it was: the un-annotated global ladder has
no atom rung and fell to `globalKind` of the init, a string cell, and `exprIsLitAtom` of the join
asked its arms, one of which is a one-literal string value. `print(v)` then fell to
`__print_i32__` over the string ref. A function's local survived because every read of it asks
the slot flag the one classification wrote. The join is now an atom whenever its recorded type
is a registered literal union, and the global ladder asks `letInitIsLitAtom` first, the rung the
local ladder already had.
