### D17851 — a hole parameter's instance returning an annotated `i32 | null` binding's copy is printed at no rep the caller reads

**closed 2026-11-28 · runs, prints `1` · was `emitProgram: the compiler cannot yet lower this statement (print operand rep)` · a call the checker typed at a hole's nullable bound reads the instance's result where that is narrower, in module scope and inside a function (`callTyAt`, `callNarrowTyAt`, emit_capture_frames.vl) · pin `unions/hole-param-copy-of-annotated-null-let-returned-to-a-caller` · filed 2026-11-28 against master `c1a576d48` by START-2 (cell `copy_always_ret`, annotated face, of `scripts/capability-probes/matrix/null-binding-conditional-write.matrix.vl`; coordinator ruling)**

Repro:

    function f(a) {
      let s: i32 | null = null
      let t = s
      t = a
      return t
    }
    print(f(1))
    // vl run: prints 1

Want:

    1

#### Mechanism

`t = a` narrows the copy `t` to the hole parameter's type, whose bound is `i32 | null` (the
copy's own type), so the checker types `f(1)` at that bound. The instance closes the hole at
`i32` and returns `i32`. The call readers (`nodeTyAt`, `scopeTyAt`) took the instance's result only
where it was open or wider than the checker's, so the caller's `print` planned the nullable arm
over an `i32` operand. Without the copy the checker types the call at the hole, which the
instance closes.
