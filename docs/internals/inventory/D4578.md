### D4578 — an un-annotated list of a generic nested in a record field or in another list has no representation

**loud emit reject · `vl check` rc 0 · clause 2 · found by `fn-value-generic-list-read.matrix.vl` (`struct_field_init`, `struct_field_place`, `array_element`, `array_element_place`, un-annotated face) · filed 2026-10-14 against `bd616c03b`**

Repro:

    function id<T>(x: T): T { x }
    const s = { f: [id] }
    print(s.f[0](2))
    // vl check: rc 0.  vl run: emitProgram: ref valtype with no interned shape

Want:

    2

#### Mechanism

The inner literal's element type is the open `(T) => T`, and the representation of the outer
record or list is interned from that type before any read fixes the instance. The flow reads
rewrite the call `s.f[0](2)`, but the slot's type was already needed to build `s`. A one-level
container (`const s = [id]`) is typed from its reads; two levels are not.
