### D15724 — a fresh call's list of records, delivered at a list whose element stores a field in a union box, is refused although the copy converts it

**closed 2026-11-12, runs and prints `5` then `true` · was a loud check reject, clause 2, `this value is built as W[] where line 5 delivers it, and it is handed on here at its own type …` (D14385's interim refusal) · the refusal skips a delivery the fresh-call copy converts, re-gated on the copy's rule (`recCallCopiedAt`, check_program.vl) · graded by `scripts/capability-probes/matrix/kept-maker-list-result-delivery-union.matrix.vl` · fixture `tests/cases/structs/kept-maker-list-result-union-field-copied-runs.vl` · filed 2026-11-12**

Repro:

    type W = { f: i32 | string }
    function mk() { return [{ f: 4 }] }
    const h = mk()
    print(h[0].f + 1)
    const h2: W[] = mk()
    print(h2[0].f is i32)

Want:

    5
    true

#### Mechanism

`recWideListNote` (check_program.vl) queues every call whose list-of-records result one delivery
takes at another list, and `recKeptFnOwnCalls` refuses the function's other calls wherever the
destination stores a part in a box the result does not (`recBoxApart`). The fresh-call copy
(`recFreshCallCopy`) has already recorded that delivery as a copy element by element, which
leaves the body built at its own type, so the refusal guards a conflict that does not exist.
With `f: i32 | null` the box test does not fire and the same program runs through the copy.

#### Ablation

| spelling | outcome |
| --- | --- |
| this repro | check reject |
| `W = { f: i32 \| null }` | runs, `5` `true` (the copy) |
| `const h = mk()` and its read removed | runs (one site, built at `W[]`) |
| record result `{ f: 4 }` at `W` | runs (the record copy) |

The skip re-gates on `recCopyBoxesOnly`, not on `listCopyTyIx` alone: `recordListCopy` also
writes that table at a call, and D14385's own witness (a list of row unions) carries such a record
without a copy the emitter performs, so a skip keyed on the table alone made it invalid wasm.

#### Grading list

The list-result template at a union-field element, every position; D14385's other member shapes
(a record into a record-union field, a list of numbers into a list of a union, a list of row
unions) must stay refused until the copy converts them.
