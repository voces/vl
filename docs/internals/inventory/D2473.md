#### Mechanism

`callDeclFnIx` found a method's declaration by its plain name, and a `self`-function merged from
another module carries a mangled one, so the lookup missed and the call fell to "an intrinsic",
which writes nothing. `o.bump()` with `bump` imported from a user module is the same row.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the write in `wr` | runs | **yes** |
| the import (the same function declared in this file) | loud check reject | **yes** |

#### Close

`callDeclFnIx` resolves a method through the site's UFCS alias (`ufcsAliasAtSite`), and a record,
list or map receiver whose method resolves to nothing is opaque rather than a built-in; the
function's write shapes then charge `wr` at its argument.
