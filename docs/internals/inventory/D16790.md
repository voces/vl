### D16790 — a relay of a relay of a maker's hole lambda, delivered at two function types whose results differ, is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2: ``emitProgram: `outer` returns one function value and its calls deliver it at two function types, and one function value has one signature — return a separate function for each type`` · the chained spelling of [D16770](D16770.md) · filed 2026-11-16 against master `deed0ee3c`**

Repro:

    function deliver() { return (a) => a + 1 }
    function relay() { return deliver() }
    function outer() { return relay() }
    const v: (a: i32) => i32 = outer()
    const w: (a: i32) => f64 = outer()
    print(v(3))
    print(w(3) / 8.0)
    // vl check: rc 0.  vl build: emitProgram: `outer` returns one function value and its calls deliver it at two function types, ...

Want:

    4
    0.5

#### Mechanism

Not traced. [D16755](D16755.md)'s relay twins (#8591) build a relay per delivered result
only when every value it returns is a maker call; `outer` returns a call of `relay`, itself a
relay, so `outer` is not twinned and its one instance meets the emitter's refusal of one returned
value delivered at two function types. `fvaRelayRows` already carries one relay's result to the
relays it calls (`relaySig`), but only when that result is one; at two it reaches none.
