### D2876 — in a generic body, an `is T[]`-narrowed read of an inferred `T[] | i32[]` in value position is invalid at the pin

**check-clean invalid wasm · clause 1 · found by the D2874 grid (its generic-body position) · filed 2026-09-27 against master `460a67010`**

Repro:

    function w<T>(t: T, b: boolean) {
      if b { return [t, t] }
      [1, 2, 3]
    }
    function inner<T>(t: T, b: boolean) {
      const v = w(t, b)
      const e = if v is T[] { v[0] } else { t }
      print(e)
    }
    inner("z", true)
    // vl check: rc 0.  vl run: invalid module inside `inner` — expected i32, found (ref $type)

Want:

    z

#### Mechanism

Not localised past the ablation. `v` is the kept-apart inferred return `T[] | i32[]`; the
narrowed read inside an if-expression arm is lowered at the instance as an `i32` where the pin
made it a string. At `T := f64` an if-expression over `v.length` in both arms is invalid too
(`expected (ref null $type), found (ref $type)`), where the instance's list is `f64[]`. Because
of it D2874 does not rewrite a union with a type parameter's list, which keeps those reads a
loud check reject.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the value position (`if v is T[] { print(v[0]) }`) | runs, prints `z` | **yes** |
| the type parameter (`inner(t: string, …)`, `is string[]`) | runs | **yes** |
| an annotation on the join (`const e: T = …`) | invalid wasm | no |

#### Grading list

`inner(1.5, …)` with `print(if v is T[] { v.length } else if v is i32[] { v.length } else { __trap__() })`,
and D2874's generic-body grid cells once the rewrite is let through.
