### D2876 — in a generic body, an `is T[]`-narrowed read of an inferred `T[] | i32[]` in value position is invalid at the pin

**closed 2026-09-27 · was check-clean invalid wasm, clause 1, on master `d39c809c1` · found by the D2874 grid (its generic-body position) · filed 2026-09-27 against master `460a67010` · fixtures `tests/cases/generics/generic-body-narrowed-list-read-value.vl`, `tests/cases/generics/generic-body-list-union-read-ops.vl`**

Repro:

    function w<T>(t: T, b: boolean) {
      if b { return [t, t] }
      [1, 2, 3]
    }
    function inner<T>(t: T, b: boolean) {
      const v = w(t, b)
      const e = if v is T[] { v[0] } else { t }
      print(e)
    }
    inner("z", true)

Want:

    z

#### Mechanism

Two faults, one per pin. At a ref pin (`string`, `boolean`), the value `if` kept the template's
recorded join `T` in the instance: the per-instance walk re-made an `if` only when an arm
changed, and a re-made one carried no type at all, so the blocktype was read off the then arm
and came out `i32`. The walk now re-types a link whose join names the parameter and every arm
of which agrees with it (`monoIfChainRebuildPinned`), and a re-made link keeps its original's
type. At `f64`, `w`'s instance returns one `f64[]`, so the instance's own `v is i32[]` folds to
`false` and the arm it guards read `v` as an `i32[]`; a value arm whose `is` test folds dead is
now `unreachable`, as the statement form already skipped it (D932).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the value position (`if v is T[] { print(v[0]) }`) | runs, prints `z` | **yes** |
| the type parameter (`inner(t: string, …)`, `is string[]`) | runs | **yes** |
| an annotation on the join (`const e: T = …`) | invalid wasm | no |
| the `string` pin, for `boolean` | prints `1` for `true` | no, the same join |
| the value arm at `f64`, where `v is i32[]` folds false | `print(if v is i32[] { v.length } else { 0 })` invalid | a second fault |

#### Grading list

`inner(1.5, …)` with `print(if v is T[] { v.length } else if v is i32[] { v.length } else { __trap__() })`,
and D2874's generic-body grid cells once the rewrite is let through.
