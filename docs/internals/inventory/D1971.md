#### Mechanism

`checkIfStmtNode`'s post-guard leg applies the ELSE narrowings when the then-arm exits; there is
no mirror that applies the THEN narrowings when the else arm exits and the then-arm does not,
and `pushPostGuardNarrow` in the emitter has none either. Only the code after the `if` is
affected — inside each arm the narrowing is already right. Both halves must land together
(checker leg, emitter `setNarrowFromCond` leg), gated on the same `stmtAlwaysExits(ifElse)`.
