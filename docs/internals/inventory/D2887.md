Repro:

    function mk(b: boolean): readonly f64[] | string[] {
      if b { return [1.5] }
      ["s"]
    }

#### Mechanism

Not localised past the ablation. The narrowed read of the view member is lowered at a rep the
box's payload cast does not produce. D2874's list-union rewrite reads through this narrowing, so
it declines a union with a readonly member until this is fixed.
