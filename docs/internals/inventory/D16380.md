### D16380 — a write to a narrowed path is refused while a nested function reads it, even when that function is never called after the write

**loud check reject · clause 2 · bucket (f), the narrowing-ended-by-a-write family of D2402 and D2464 · filed 2026-11-15 against master `3d526470a`, the path twin of D2402's per-call rule, found closing [D16297](D16297.md) · open**

Repro:

    const xs: (i32 | string)[] = [1]
    if xs[0] is i32 {
      const c = (): i32 => xs[0] + 1
      print(c())
      xs[0] = "s"
      print(xs[0])
    }
    // vl check: rc 1, "cannot assign string to i32", at the written value

Want:

    2
    s

#### Mechanism

A bare name keeps D2402's contract: the write is allowed, and a later call of a nested function
that read the name under the narrowing is refused, naming the function and the ended narrowing.
A path has no per-call rule. `writeStorageTy` holds the write itself to the narrowing once a
nested function read the path under it (`npCapBy`), and a writing call is refused at the call
(`crCaptureCallCheck`), whether or not the function runs again.

#### Ablation

| spelling | outcome | owed |
| --- | --- | --- |
| the witness: call `c`, then write | check reject at the write | runs |
| write, then call `c` | check reject at the write, `cannot assign string to i32` | the call refused, naming `c` and the ended narrowing |
| call `c`, then a writing call `w()` | check reject at `w()` | runs |
| a bare name `g`, call `c`, then write | runs, prints `2` and `s` | runs |
| a bare name `g`, write, then call `c` | the call refused: "'c', made on line 3, reads 'g' as i32, a narrowing a write since then may have ended" | the same |

#### Grading list

The field spelling `o.v`; the five rows above, path and bare. The fix reuses D2402's per-call
check for paths, so the two share one sentence.
