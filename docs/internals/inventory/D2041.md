### D2041 — a literal-union `L | null` return reached through an else-less tail `if` prints the value, then traps on the fall-through

**loads then traps · `vl check` rc 0, `f(true)` prints `x`, then `f(false)` traps `wasm unreachable`, clause 1 · pre-existing on master `ee4c28b60`, found reviewing #3037 · filed 2026-09-22**

Repro:

    type L = "x" | "y" | "z"
    function f(c: boolean): L | null {
      if c { "x" }
    }
    print(f(true))
    print(f(false))
    // vl check: rc 0.  vl run: prints x, then wasm trap: unreachable

#### Mechanism

Not ablated yet; this is a prediction. A literal union reps as an interned i32 atom with `null`
on a spare sentinel (D1898), and the fall-through of a nullable tail is lowered by the
function-end `null` padding, which seeds its null per return kind. The padding has no rung for
a nullable literal union, so the fall-through ends in the compiler's `unreachable` instead of the
atom's null sentinel. `i32 | null`, `string | null` and struct `| null` returns of the same shape
run.
