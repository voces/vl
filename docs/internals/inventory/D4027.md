### D4027 — a top-level un-annotated read of a `(i32 | null)[]` element narrowed by an index store holds the bare `i32` in a box-typed global

**open · check-clean invalid wasm · clause 1 · found by the #3535 review (`rv3535/x03`, reached by `mk(null)` too once D4024 types it) · filed 2026-10-11 against master `1df3c8f91`**

Repro:

    const ps: (i32 | null)[] = [null]
    ps[0] = 99
    const e = ps[0]
    print(e ?? 0)
    // vl check: rc 0.  vl run: invalid module, expected (ref null $0) found i32 at line 3

Want:

    99

#### Mechanism

The store `ps[0] = 99` narrows the place `ps[0]` to `i32`, and the read emits the unboxed `i32`
payload. The module-scope `e` is declared as a global of the element's `i32 | null` box type,
so the `global.set` receives an `i32`. The same three lines inside a function run: the local
takes the narrowed type its initializer was emitted at. Not located beyond that.
