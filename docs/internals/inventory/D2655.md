### D2655 — a module `let` declared without an initializer is refused by the emitter after `vl check` accepts it

**loud emit reject · `emitProgram: module global has no initializer` · found beside D2652 · filed 2026-09-26 against master `979323f83`**

Repro:

    let g: i32
    g = 3
    print(g)

#### Mechanism

The checker accepts a module `let` with a type and no initializer and tracks its definite
assignment, as it does for a local; the emitter's global section and start function have no arm
for a cell with no initializer and refuse the module. A clause-2 violation: the program is
type-valid and `vl check` returns 0. The build is a zero-initialized cell (the start function
already writes cells in source order), and a read that a function can reach before the first
assignment then belongs to the D2652 guard, keyed on the first assignment rather than the
declaration.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the missing initializer (`let g: i32 = 0`) | runs, prints `3` | **yes** |
| the later assignment (`g = 3` removed) | loud check reject: `g` is used before it is assigned | **yes** |
