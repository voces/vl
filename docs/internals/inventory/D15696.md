### D15696 — a push of a kept maker's call through a record field holding a list built at its record is refused

**loud check reject · clause 2 · `this value is built as J where line 3 delivers it, and it is handed on here at its own type, which stores a field differently` · found closing D15690 · filed 2026-11-11 against master `f50936aa`**

Repro:

    type J = { f: i32 | null }
    function mk2() { { f: 1 } }
    const dA: J = mk2()
    print(dA.f ?? 0)
    const xs = [mk2()]
    const r = { ys: xs }
    r.ys.push(mk2())
    print(r.ys[1].f ?? 0)

Want:

    1
    1

#### Mechanism

Not ablated. D15657's store column names a push into a list-literal binding (`xs.push(v)`), not one
through a field read (`r.ys.push(v)`), so the pushed call is an own-storage delivery and D15180's
refusal fires.
