### D16294 — a lambda literal a maker returns, delivered at two function types, is refused at emit, while the same lambda bound to a `const` and returned is built once per type

**loud emit reject · clause 2 · `vl check` rc 0 · reachable once [D16291](D16291.md)'s close types the literal (a check reject before) · found by the `returned-hole-lambda-identity` matrix · filed 2026-11-14 against master `51f894bf3`**

Repro:

    function deliver() { return (x) => x }
    const f: (x: i32) => i32 = deliver()
    const g: (x: string) => string = deliver()
    print(f(1))
    print(g("s"))
    // vl run: emit error 1:36: emitProgram: this lambda is handed on at two different function
    // types, and one lambda literal has one signature

Want:

    1
    s

#### Mechanism

[D12234](D12234.md)'s close builds a maker delivered at a second closed function type at that
type's twin (`monoMakerTwin`, emit_mono.vl), and reaches it through the maker's returned BINDING. A
returned literal is the value mono's lambda-literal delivery sees instead, and that path holds a
literal to one signature.
