### D16820 — a lambda with an un-annotated parameter that nothing calls, stored in a list nothing reads, is refused at emit

**closed 2026-11-16 · runs, prints `a` · was a loud emit reject · clause 2 · the list face of [D3851](D3851.md) · fixed by lane INIT: `monoFrameNameUnread` reads a list literal's element only as far as the binding the list initializes, so the lambda is unread and pruned as dead · matrix `hole-lambda-uncalled-in-written-cell` (`list_*` cells) · filed 2026-11-16 against master `fae99e93f` · pin: `tests/cases/closures/hole-lambda-uncalled-in-list.vl`**

Repro:

    function mk(x: string) {
      const c = (y) => y + "C"
      const fs = [c]
      print(x)
    }
    mk("a")
    // was: vl check rc 0, then vl build: emitProgram: a lambda with an un-annotated parameter is stored in a list, ...

Want:

    a

#### Mechanism

The lambda is dead: nothing calls it, and the list holding it is never read. The emitter skips the
refusal for a lambda `monoUnreadLamSlots` finds unread (D3851's cell face), but that walk follows a
read only into the bindings it seeds or writes, not into a list literal that initializes an unread
binding, so the lambda counts as read and is refused.
