### D16820 — a lambda with an un-annotated parameter that nothing calls, stored in a list nothing reads, is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2: `emitProgram: a lambda with an un-annotated parameter is stored in a list, or in a variable a nested function writes, and no call fixes its parameter types` · the list face of [D3851](D3851.md), whose cell face runs · filed 2026-11-16 against master `fae99e93f`**

Repro:

    function mk(x: string) {
      const c = (y) => y + "C"
      const fs = [c]
      print(x)
    }
    mk("a")
    // vl check: rc 0.  vl build: emitProgram: a lambda with an un-annotated parameter is stored in a list, ...

Want:

    a

#### Mechanism

The lambda is dead: nothing calls it, and the list holding it is never read. The emitter skips the
refusal for a lambda `monoUnreadLamSlots` finds unread (D3851's cell face), but that walk follows a
read only into the bindings it seeds or writes, not into a list literal that initializes an unread
binding, so the lambda counts as read and is refused.
