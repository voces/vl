### D15367 — a list literal of records holding different un-annotated functions, indexed in place, is refused at emit

**loud emit reject · `emitProgram: a ref list's element row does not resolve` · clause 2 · open, target `6` · bound to a `const` it runs · found closing [D15228](D15228.md), whose element join moved the message from `cannot take the generic function dbl as a value` · filed 2026-11-04 against master `0b4891628`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    print([{ f: inc0 }, { f: dbl }][1].f(3))

Want:

    6

#### Mechanism

Not ablated past the table. The literal's element type now joins both records' function sets
([D15228](D15228.md)), but the literal held by nothing, read in place, has no ref-list row at that
type; a binding or a returned value gives it one.

#### Ablation

| spelling | outcome |
| --- | --- |
| this repro | emit reject |
| `const xs = [...]; xs[1].f(3)` | runs, `6` |
| `function mk() { return [...] }; mk()[1].f(3)` | runs, `6` |
| one record, `[{ f: inc0 }][0].f(3)` | runs |
| no record, `[inc0, dbl][1](3)` | runs |
| a value `if` of the records inside the list | emit reject, [D15301](D15301.md) |
