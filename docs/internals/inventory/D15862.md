### D15862 — an annotated binding of a copy of a bundle holder is refused at emit

**closed 2026-11-12, runs and prints `5` `4` · was loud emit reject, clause 2, `a function returning a parameter called at two signatures is called where its result is not used at one of them` · found closing [D15749](D15749.md) · filed 2026-11-12 against master `84e28554d` · closed in `elabHolderCopiesHold` (emit_elab.vl), which counts a copy's annotated reads and requires each to name a member, and `elabHolderRecordWith`, which records the member for each · fixture `tests/cases/closures/bundle-holder-copy-or-module-const-into-annotated-binding-runs.vl`**

Repro:

    function lap(f) {
      f(2.5)
      f(3)
      return f
    }
    function main() {
      const k = lap((a) => a + 1)
      const v = k
      const m: (f64) => f64 = v
      print(m(4))
      print(k(3))
    }
    main()

Want:

    5
    4

#### Mechanism

Unmeasured. D15749 admits an annotated binding of a holder's read; a copy's annotated read is
counted on the copy (`elabResTypedReads`), and a copy's reads must be calls, hands, returns or
copies (`elabHolderCopiesHold`).
