Repro:

    function inc(a) { return a + 1 }
    function deliver(n) {
      const u = [[inc]]
      return u

    const v = deliver(1)
    print(v[0][0](3))

#### Mechanism

`deliver` is generic for its parameter, and its instance typed its return from the local's
literal (`monoInferListElem`, emit_mono.vl), which the checker leaves open at a function. The
instance wrote that type as its return annotation, `((_) => _)[][]`. The annotation interned a
list-of-lists slot whose inner list had no slot of its own, so `rlElemInnerSlot` read `-1` and
`mAssignRefListPairs` (emit_collect.vl) indexed the per-slot tables with it.

An instance now never writes an open function-holding return annotation
(`monoMakeInstanceRetExpr`). It takes its own un-annotated copy of the returned binding
(`MONO_OUT_OWN_COPY`, `monoLetOwnCopy`), and its walk annotates that copy at the instance's own
pin (`monoPinNestedListElems`, `monoInstOwns`). `mAssignRefListPairs` bound-tests the inner slot
and fails loudly if a list-of-lists slot ever has none again.
