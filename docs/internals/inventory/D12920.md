#### Mechanism

A hole function's instances share the template's nodes, so the literal `{ xs: [x] }` carries
the template type `{ xs: $h[] }`. The collect pass mints a row for a record literal at an
instance only where a field is a bare type variable (read from the value's pin) or where a
pin or exact-instance substitution binds the field. A field whose type holds a hole inside a
list is neither, so no row was minted and the emitter's field-name scan found nothing. Once
the rows exist, two instances' rows share their field names, so the scan cannot pick between
them, and a returned literal also needs `pinSubstObjLitTy` to answer, or the constructor gate
treats the first instance's row as serving the second. Before the emitter's rung was added,
that state was check-clean invalid wasm (`t$1` built the record of `P[]` with an `i32`).
