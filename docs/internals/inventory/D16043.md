### D16043 — `i8`, `u16` and `i16` are unknown types as a list element, though the ruling makes them storage types like `u8`

**open · loud check reject · `unknown type 'i16' within 'i16[]'` · clause 2 · `u8[]` runs and narrows · filed 2026-11-13 against master `57cda2b6`**

Repro:

    const xs: i16[] = [-3, 7]
    print(xs[0] + xs[1])

Want:

    4

#### Mechanism

The arena has a `u8` primitive and no `i8`, `u16` or `i16`. A `u8[]` lowers to a packed `i8`
GC array, written with `array.set` (which truncates) and read with `array.get_u` (which widens).
The other three spellings resolve to nothing, so a list of them is refused by name. The owner
ruling on D15978 (DECISIONS, "A sub-word field of a `flat` record has storage semantics") makes
all four widths storage types, legal as a list element and as a `flat` field.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `u8[]` with `[200, 7]` | runs, `207` | **yes** (the width) |
| `i8[]`, `u16[]` | the same refusal, naming the width | no |
| a binding `const x: i16 = 3` | refused, `unknown type 'i16'`; `u8` there is refused as a storage type | — |

#### Grading list

Each width with a literal and a computed element, read back widened (`i8`/`i16` with
`array.get_s`, `u16` with `array.get_u`). A binding of the bare width must give the same storage-type
refusal `u8` gives. D15978 shares the arena types this row needs.
