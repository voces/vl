#### Mechanism

A capture of a module-frame block local is typed through `parentBindingOf`'s module arm,
`moduleLocalLetOfAt`, which reads the table `mlvBuild` fills ([D1244](D1244.md)). That walk
skipped a top-level `LetDecl` whole, initializer included, and stopped at any expression, so
a value block in an initializer or an argument recorded none of its locals. The capture then
took `captureValKind`'s `i32` default: an `i32` env field, invalid wasm at a string or a list,
and the loud `field access receiver is not a struct` at a record. A function-valued local
captured the same way was the loud `call to unknown function`.
