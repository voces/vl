#### Mechanism

A list of records holding a function set, delivered to an annotated list of records of a closed
function type, is a fresh copy whose elements pass through their adapters, and runs; a list of
lists of functions does too. A list of lists of such records is not copied level by level, so the
emitter is asked for `inc0` itself as a value of the closed type, which an un-annotated function
has no one signature for. The functions' results agree here, so this is not D16824's judge.
