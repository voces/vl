### D16420 — a binding of an un-annotated function, called directly and then handed on, names a function that was never built

**closed 2026-11-15 — the witness runs and prints `4`, `5` · was: loud emit reject · clause 2 · bucket (f) · `emitProgram: call to unknown function` · found ablating D16281's re-graded witness · filed 2026-11-15 against master `295f1e20`**

Repro:

    function inc(t) { return t + 1 }
    function app(g, v) { return g(v) }
    const f = inc
    print(f(3))
    print(app(f, 4))
    // vl check: rc 0.  vl run: emitProgram: call to unknown function

Want:

    4
    5

#### Mechanism

`f(3)` is the call that mints `inc`'s first instance. The first instance reuses the template's
slot and name (`monoMakeInstanceFirst`, emit_mono.vl), and it re-spelled only a call through a
lambda binding. So the callee kept the name `f`, which names no function. A later instance and
a registry hit both re-spell it. When `app(f, 4)` comes first, `f(3)` is a hit, which is the order
dependence. A generic `idg<T>` in `inc`'s place failed the same way, at one type or two.

**Closed.** `monoCallInstByName` is the later-instance rename, lifted out of
`monoMakeInstanceLater`. `monoMakeInstanceFirst` asks it under the guards the hit path uses:
- no captures, and not a reassigned read;
- a lambda callee only at a lambda-call site.

`monoLamCallByName`, which held a copy of that rename for lambdas, is folded into it. Grid
`alias-of-hole-fn-called-then-delivered.matrix.vl`. Fixture
`closures/alias-of-hole-fn-called-then-delivered-runs.vl`.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `f(3)` removed | prints `5` | **yes** |
| `app(f, 4)` before `f(3)` | prints `5`, `4` | **yes** (the order) |
| `inc` and `app` called with `inc` itself, no binding | prints `4`, `5` | **yes** (the binding) |
| `inc` annotated `(t: i32): i32` | prints `4`, `5` | **yes** (the hole) |
| `app`'s `g` annotated `(x: i32) => i32` | the same reject | no |
| `let` for `const`, or all of it inside a function | the same reject | no |
