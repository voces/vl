### D2425 — a generic body's deferred call-argument demand is adjudicated only at a DIRECT call, so the method spelling builds an invalid module

**now a loud check reject · clause 1 · found closing D2424, filed 2026-09-25 against master `a277bf7b0`**

Repro:

    function g(n: i32) { return n + 1 }
    function inc<T>(self: T) { return g(self) }
    print("s".inc())
    // vl check: rc 0.
    // vl run: Error: invalid module … inside `inc$…`.
    // The direct spelling `inc("s")` refuses: argument of type string flows into `g` expecting i32.

#### Mechanism

Two routes. `validateArgCstrs` was called from the direct-call pin and nowhere else: the
UFCS half of `checkCall` re-asked the binary-op, print, nest, return, let and member lists
and skipped this one. It now asks it too. The second route, a generic function value handed
to a generic HOF (`run<T>(cb: (T) => i32, v: T)` with `run(f, "s")`), was an ORDER fault:
the argument loop reached `f` first, bound `run`'s `T` to `f`'s own type variable (first use
wins), and so compared `f` against `(T) => i32` with nothing concrete in it. `checkCall` now
checks a function with an open parameter (a declared generic named as a value, or
a literal with an un-annotated parameter) meeting an arrow PARAMETER position that rides a
type variable after the value arguments (`lambdaLastOrder`, `argOpenMeetsTyVar`); a variable
only in the arrow's return keeps source order, since the callback is what binds it.
Here `T` binds to `string` and `genericFnAssignable` asks the body's demand. The refusal is
the one the direct spelling `f("s")` gives, so it is the design's. Adding the UFCS call
first needed [D2241](D2241.md) closed, or `(5).tag(v: "w", n: "n")` would have refused.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `inc("s")` | loud check reject | the method spelling: **yes** |
| `(3).inc()` | runs, prints 4 | the failing binding: **yes** |
| `run(f, "s")`, generic `f` into generic `run` | same invalid module | the second route |
| `run(f, 3)` | runs, prints 4 | no |
| `run<T>(v: T, cb: (T) => i32)` with `run("s", f)` | already refused | the argument order: **yes** |
