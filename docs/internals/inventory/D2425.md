### D2425 — a generic body's deferred call-argument demand is adjudicated only at a DIRECT call, so the method spelling builds an invalid module

**check-clean invalid wasm · clause 1 · found closing D2424, filed 2026-09-25 against master `a277bf7b0`**

Repro:

    function g(n: i32) { return n + 1 }
    function inc<T>(self: T) { return g(self) }
    print("s".inc())
    // vl check: rc 0.
    // vl run: Error: invalid module … inside `inc$…`.
    // The direct spelling `inc("s")` refuses: argument of type string flows into `g` expecting i32.

#### Mechanism

`validateArgCstrs` is called from the direct-call pin and nowhere else. The UFCS half of
`checkCall` re-asks the binary-op, print, nest, return, let and member lists for the symmetry
D401/D551/D572 bought, and skips this one; a generic function value handed to a generic HOF
(`run<T>(cb: (T) => i32, v: T)` with `run(f, "s")`) reaches neither `validateArgCstrs` nor
`argCstrsHold`, since `cb`'s type rides `T` and `genericFnAssignable` is not asked.

**Adding the UFCS call is not the whole fix, and was measured.** With it, `"s".inc()` refuses as
the direct spelling does, but `function tag<T>(self: i32, n: string, v: T) { "\{n}\{self}\{v}" }`
with `(5).tag(v: "w", n: "n")`, which RUNS today and prints `n5w`, starts refusing: an
interpolated `T` records a `toString` demand that a `string` binding fails, which is
[D2241](D2241.md)'s false reject at the direct spelling. Close D2241 first (the renderer delivers
a string hole without `toString`, so the demand's domain is `string` plus the renderer's), then
add the UFCS call.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `inc("s")` | loud check reject | the method spelling: **yes** |
| `(3).inc()` | runs, prints 4 | the failing binding: **yes** |
| `run(f, "s")`, generic `f` into generic `run` | same invalid module | the second route |
| `run(f, 3)` | runs, prints 4 | no |

#### Grading list

`(5).tag(v: "w", n: "n")` must keep printing `n5w`, and `"w".tag()` over
`function tag<T>(self: T) { "<\{self}>" }` (invalid wasm today) is the same demand at a
one-parameter method.
