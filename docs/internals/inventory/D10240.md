#### Mechanism

Not traced. A function value whose result is the `null` type meets a function parameter whose
result is a nullable, and assignability refuses the result where it accepts a narrower
non-null one. A lambda written at the call adopts the parameter's result and is not
affected; one typed `() => null` first, by a binding or a hole parameter, is.
