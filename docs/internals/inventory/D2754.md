#### Mechanism

`checkCastNode` sends a hole operand down the numeric ladder, where `as?` from an unknown source
cannot fail and is typed `i32`. The body's `v == null` then folded to `false`, and at a union pin
the arm's unbox ran on the miss and trapped. At an `f64` or `i64` pin the emitter lowered a cast
that can fail into a binding typed as a bare `i32`, which is an invalid module; only the `i32` pin
ran. Over a type parameter `as?` may miss at some pin, so it is `N | null` at every one: a union
pin takes the union arm's box, a numeric pin whose cast can fail takes the exact-or-fail box, and
one that cannot fail boxes its value (`emitHoleNumAsOpt`, compiler/wasmEmit.vl).

Review round 1 (#3208): only a numeric target takes the `N | null` rule, so `u as? boolean` and
`u as? string` over a type parameter keep the checker's `as supports numeric conversions only`.
At a pin that is no number (a `boolean`, a `string`, a record) the answer is `null`, read from
the instance's exact pin; the review's 1,400-cell grid has no wrong value and no invalid module.
