#### Mechanism

`ss`'s initializer holds `src`, whose elements are stored at `J`, so `ss` is laid out as a list of
lists of `J`. The reassigned literal `[[{ f: null }]]` is built at its own `{ f: null }` and
stored into that storage unconverted. No build reaches the second literal from the first, and the
check raises nothing. A single level (`let s1 = src`, then `s1 = [{ f: null }]`) is a loud emit
reject instead.
