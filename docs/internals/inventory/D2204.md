### D2204 — `is` over a `const` string literal refuses a test set wider than the literal, though the literal is in it

**closed — a `const` literal tested against a set its value is in takes the `string` it is, the same way a test against a type with a non-literal member already did; only a set it can never be in keeps the D2198 refusal, and a subset keeps the literal type · was loud check reject · `` `is` check type '"debug"|"x"' can never match a value of type "debug" `` · ran (printed `true`) on the seed built before #3056 · found reviewing #3062 · filed 2026-09-23 against the #3062 head `57e40f104` · closed 2026-09-23 with [D2199](D2199.md) · `tests/cases/literal-unions/is-const-literal-overlapping-set.vl`**

Repro (runs, prints `true`):

    const MODE = "debug"
    print(MODE is "debug" | "x")

#### Mechanism

#3056 gave `const MODE = "debug"` the type `"debug"` (D2157), and `checkIsExprNode` requires the
test type to be assignable to the operand's, so a wider test set was refused as one that can
never match. #3062 taught `is` the D2198 rule: a disjoint literal set is refused with the
declaration to write, and a test type with a non-literal member widens the operand to `string`.
The third case, a literal set that meets the const's without being inside it, kept the literal
type and reached the assignability refusal. It now widens too, as `==` already does.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the test set narrowed to `"debug"` (exact, or a subset of a join) | runs | **yes** |
| `==` instead of `is` | runs | **yes** |
| `let` instead of `const` | runs | **yes** |
| the inline set spelled as an alias `type Mode = "debug" \| "x"` | refuses | no |
| the const inside a function | refuses | no |
| a join of two `const` literals tested against a set meeting one of them | refuses | no |
| `const MODE: "debug"` annotated | refuses, and did before #3056 too: [D2205](D2205.md) | no |

#### Grading list

The inline and alias spellings at module and function scope, the then-branch narrowing to the
test set, a generic's `is` over its pinned argument, and a join tested against an overlapping,
a wider and a narrower set, all in the fixture above.
