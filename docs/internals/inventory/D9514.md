#### Mechanism

The function type's parameter is a list of the record, which [D9460](D9460.md)'s rung answers
as a function's own parameter but not as a parameter of a function type. A depth-16
`--names` profile puts the cost under `collectTyReachCloSigs` → `sigKeyOfTyGo`, rendering the
function type's parameter with `tyToEmitName`, `7·2^depth` characters, and under
`collectAArrayLit` → `tyToStrObj` and `monomorphize` for the list literal `[x]`. The list
literal is not needed: a lambda alone still doubles. D9460's close halves this face's fuel at
depth 12 without changing its slope.
