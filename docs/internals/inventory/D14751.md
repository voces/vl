### D14751 — a shared field one record stores as a literal atom and another as an f64 has no read over the union

**runs, prints `b` — CLOSED 2026-11-01 with [D14750](D14750.md): the read boxes the atom arm as its string beside the f64 arm · was loud emit reject, clause 2 · pin: `tests/cases/unions/shared-field-atom-set-beside-scalar-arm.vl` · found ablating [D14746](D14746.md) · filed 2026-11-01 against master `4cb9dd26`**

Repro:

    const u: { k: "a" | "b" } | { k: f64 } = { k: "b" }
    print(u.k)
    // was: vl check rc 0, then emitProgram: field access receiver is not a struct

Want:

    b

#### Mechanism

`u.k` is typed `"a" | "b" | f64`. The first arm stores `k` as the interned atom and the second
as an f64, and no shared-field plan covers that pair, so the read finds no receiver
struct and refuses after `vl check` accepted the program. With `{ k: i32 }` as the second arm
the read builds and prints the atom's id instead ([D14750](D14750.md)).
