### D3532 — an annotated `A | B | null` binding at a pin mixing a literal union with `i32` or `boolean`, printed through `??`, is built at the atom's rep

**check-clean invalid wasm · clause 1 · open · the same on master `331f5e998` · found by lane LJ's literal-union grid (18 cells, the `annif` and `annlam` shapes with the `coalpr` reader) · filed 2026-10-03 against master `331f5e998`**

Repro:

    type K = "a" | "b"
    const x0: K = "a"
    function F<A, B>(k: i32, a: A, b: B) {
      const v: A | B | null = if k == 0 { a } else if k == 1 { b } else { null }
      print(v ?? "b")
    }
    F(1, x0, 3)
    // vl check: rc 0.  vl run: invalid module inside `F`, "type mismatch: expected i32, found (ref $type)"

    3

#### Mechanism

Not localised past the ablation. At `(K, i32)` the annotation is the box `K | i32 | null` and
the `??` result is `K | i32`, a value-union box with a literal-union arm. The pin read that
closed [D3528](D3528.md) finds no registered name for that box (`ifJoinUnionNameIn` asks
`isValueUnionName`, which a literal-union arm is not), so `print` lowers the `if` at the atom's
`i32` while its arms deliver the box.
