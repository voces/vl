### D6371 — a module record whose field holds a maker's generic result, called at two types, refuses when the record is also read whole

**loud emit reject · `vl check` rc 0 · clause 2 · found closing [D6342](D6342.md) · the same on l1-split6 `f4f18b627` · filed 2026-10-18 against l1-split6 `f4f18b627`**

Repro:

    function k<T>(x: T): T { return x }
    function mk() { return k }
    function show(o) { print(o.g) }
    const r = { f: mk(), g: 7 }
    print(r.f(1))
    print(r.f("z"))
    show(r)
    // vl check: rc 0.  vl run: emitProgram: a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type

Want:

    1
    z

#### Mechanism

From the ablation and D6342's close. That close keeps the field at the type its first call
takes and rewrites a call at any other type to call `k` directly, which needs every read of
the record to read a field. `show(r)` hands the record on whole, so the plan declines.
