#### Mechanism

The un-annotated parameter makes `deliver` a template instanced per call, and the `.map`
receiver was typed from what `deliver` returns only when it is not a template
([D9410](D9410.md)), so the callback's call through `f` named no function. Lifting that guard
alone is not enough: `monoRecordOpen` records nothing in a template's frame, so the returned
literal reads open afterwards and the receiver now takes the element type `monoRetFnListTy`
answers directly.
