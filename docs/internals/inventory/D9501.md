### D9501 — a list of un-annotated functions returned from a function with an un-annotated parameter, read in a `.map` callback, calls an unknown function

**loud emit reject · `vl check` rc 0 · `call to unknown function` · clause 2 · found closing [D9450](D9450.md) · present on master `56e51b394` · filed 2026-10-21 against master `56e51b394`**

Repro:

    function inc(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function deliver(n) { return [inc, dbl] }
    const v = deliver(1)
    print(v.map((f) => f(3))[1])
    // vl check rc 0.  vl run: emit error: emitProgram: call to unknown function

Want:

    6

#### Mechanism

Not traced. The un-annotated parameter makes `deliver` a template instanced per call, and the
`.map` receiver is typed from what `deliver` returns only when it is not a template
([D9410](D9410.md)), so the callback's call through `f` names no function.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the parameter (`deliver()`) | runs, `6` | **yes** |
| the un-annotated parameter (`n: i32`) | runs, `6` | **yes** |
| the `.map` callback (`print(v[1](3))`) | runs, `6` | **yes** |
| the `.map` callback (`for f in v`) | runs, `4` `6` | **yes** |
| the binding (`deliver(1).map(...)` inline) | same refusal | no |
| the argument type (`deliver("x")`) | same refusal | no |
