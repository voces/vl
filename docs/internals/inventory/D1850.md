### D1850 — the module-global cell ladder had no `u8` rung, so an un-annotated binding of a `u8[]` spread took the i32 cell

**closed · filed 2026-09-06 against master `180d67365`, closed against `5ab3bb8d8`**

Repro:

    const bs: u8[] = [1, 2, 3]
    const c = [...bs]
    print(c.length)
    // prints 3

#### Mechanism

`u8[]` is the one list whose ELEMENT does not identify its rep: the backing is
`(array (mut i8))` where every other i32-element list is `(array (mut i32))`. `globalKind`'s
`ArrayLit` arm ladders `arrLitIsRef` / `Str` / `F64` / `I64` / `F32` and then falls to the i32
list, and it carried no `u8` rung — correctly, while `letIsU8Array`'s own comment held: *"a
bare array literal always types `u8[]` never, so there is no un-annotated expression whose own
type is `u8[]` to fall through to."* A spread literal is exactly that expression, so the
premise expired when `...` landed and the ladder kept its answer.

The value side was never wrong. `emitArrSpread` resolves the rep from the spread's SOURCE, so
it built the packed wrapper at every spelling; the global's CELL took `list`, and the
`global.set` between them is invalid wasm. Forcing the rung to `u8list` made all eight graded
spellings run in one build, which is what said the cell and not the lowering.

The fix is the missing rung, asking `spreadLitIsU8` — the same `spreadDestKind` oracle the
builder uses, so the cell and the backing cannot disagree. A plain literal still falls to the
i32 list, so nothing that compiled before changes a byte.

#### Grading list

`tests/cases/lists/spread-u8-packed-list.vl` carries all six deliveries: the un-annotated
module-scope binding this row is, its function-scope twin, a rest parameter, `push`, and a
second inferred binding. The blanket checker refusal this row shipped with — which refused a
`u8[]` spread at EVERY spelling and so cost six working ones — is removed by the close, and
the six must keep running. `bs.slice(0)` at module scope is the control that says the packed
global cell works in general. The mixed form `[...bs, 9]` is D1852 and stays a loud emit
reject.
