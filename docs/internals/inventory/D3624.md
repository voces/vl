### D3624 — a fallible numeric cast over an un-annotated lambda parameter lowers with no range test

**check-clean silently wrong · `as!` prints the unconverted value where it must trap · found 2026-10-04 by the review of D3622 · filed 2026-10-04 against master `7eeb9e8c3`**

Repro:

    const k = (x) => x as! u8
    print(k(300))
    // PRINTS 300

#### Mechanism

Not yet traced. A cast whose operand is a hole (an un-annotated lambda parameter) is parked on
the hole by `noteCastDemand` and re-asked at the pin (`castPinWrapCheck` and its siblings),
which re-checks the cast's TYPE at the pinned width; the lowering for the lambda's body takes
no range test for it at any pin. A generic function over the same body (`function k<T>(x: T)`)
traps correctly, so the lambda's hole path is where the test is lost. The neighbouring modes
fail differently: `as?` is an emit refusal (`` `as? i32` has no value box ``) and a bare `as`
from an `i64` pin prints the wrapped value.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the lambda (a generic `function k<T>(x: T)`) | traps, `as! u8 … not exact` | **yes** |
| the hole (`(x: i32) =>`) | traps | **yes** |
| a second pin (`k(5)` first) | still prints 300 | no |
| an `i64` pin (`k(1099511627776)`) | prints `0` | no |
| `as!` → `as?` | loud emit reject (`as? i32` has no value box) | — |
| `as!` → bare `as` from an `i64` pin | prints `0` | — |

`-1` (prints `0` then `-1`), and the 18 lambda cells of D3622's provisional-width grid that
