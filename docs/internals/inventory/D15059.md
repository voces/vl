### D15059 — `==` over a list of `(string | null)[]` lists is refused as having no lowering

**open · loud check reject · clause 2 · the nested-list neighbour of D15054's close · found closing it · filed 2026-11-03 against master `49e25778e`**

Repro:

    const xs: (string | null)[][] = [["x", null]]
    print(xs == xs)
    // vl check: rc 1, "`==` over (string | null)[][] has no lowering"

Want:

    true

#### Mechanism

`eqCmpKindOfArrayElem` refuses a list whose element is a list of `string | null`, because the
nested compare runs the string-list core without its null-guarded mode: the inner kind it
dispatches on (`emitListEqAnyRep`) carries no element nullability. A record field and a top-level
list both pass that mode since D15054.

#### Ablation

| variant | outcome |
| --- | --- |
| this witness | refused with "has no lowering" |
| `string[][]` | runs, prints `true` |
| `(string \| null)[]` alone | runs, prints `true` |
| a record field `(string \| null)[]` in a list of records | runs, prints `true` |
