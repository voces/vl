### D15059 — `==` over a list of `(string | null)[]` lists is refused as having no lowering

**closed · runs, prints `true` · was a loud check reject, clause 2 · the string-list compare core tests every element pair for null wherever it is reached, so the checker no longer refuses the nested list · matrix `nested-nullable-string-list-eq` · the nested-list neighbour of D15054's close · filed and closed 2026-11-03 against master `49e25778e`**

Repro:

    const xs: (string | null)[][] = [["x", null]]
    print(xs == xs)
    // was: vl check rc 1, "`==` over (string | null)[][] has no lowering"

Want:

    true

#### Mechanism

`eqCmpKindOfArrayElem` refuses a list whose element is a list of `string | null`, because the
nested compare runs the string-list core without its null-guarded mode: the inner kind it
dispatches on (`emitListEqAnyRep`) carries no element nullability. The close makes the core
null-aware unconditionally, so no position has to carry it.

| a record field `(string \| null)[]` in a list of records | runs, prints `true` |
