### D6731 — a list literal holding a spread copy of an un-annotated nested-record list is invalid wasm when two declared records share its layout up to a nullable field

**open · check-clean invalid wasm · clause 1 · 1 cell of `spread-literal-nested-record-rows.matrix.vl` (`array_element`, un-annotated), red on master before and after the D6690 close · found grading the L6 type-threading change · filed 2026-10-18 against master `73713bacf`**

Repro:

    type Ax = { v: i32 }
    type Jx = { f: Ax | null }
    type Ix = { f: Ax }
    const src = [{ f: { v: 7 } }, { f: { v: 8 } }]
    const xs = [[...src]]
    const v = xs[0]
    print(v[1].f.v * 10 + v.length)
    // vl check: rc 0.  vl run: invalid module, expected (ref null $6), found (ref $4)

Want:

    82

#### Mechanism

From the ablation only. The inner spread copy keeps the source's row ([D2938](D2938.md)), but
the outer list literal's element type is resolved against a declared record of the same
layout, and `Jx` (whose `f` is nullable) is the one it picks.

#### Ablation

All rows are run on master's seed `73713bacf`.

| variant | outcome |
| --- | --- |
| as filed | invalid module |
| `Jx` removed | runs, prints `82` |
| `Ix` removed | runs, prints `82` |
| `Ix` given a second field `g: i32` | runs, prints `82` |
| `const ys = [...src]` read directly, no outer list | runs, prints `82` |
| `const ys = [...src]` then `const xs = [ys]` | invalid module |
| `const xs = [src]`, no spread | loud emit reject, `a ref list's element row does not resolve` |
| `const xs: Ix[][] = [[...src]]` | runs, prints `82` |

#### Grading list

The matrix's `array_element` row in both faces; the no-spread `[src]` spelling above, which
must print `82`.
