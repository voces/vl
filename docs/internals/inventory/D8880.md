### D8880 — a lambda or nested function whose result is a bare `null` has no rep, so binding the value of a tail `null` write in one is invalid wasm

**check-clean invalid wasm · clause 1 · open · re-filed with the ExpCtx null-family cut: the witness that read `r` (`print(r == null)`) was a loud emit reject only because the `null` operand of `==` refused; master `4d59cc200` already builds this no-read spelling as invalid wasm, so the cut is a price, not a regression · present on master `fe6067cde`, not a regression of [D2497](D2497.md)'s close · filed 2026-10-21 against master `fe6067cde`**

Repro:

    type O = { v: string | null }
    const o: O = { v: "a" }
    const c = () => {
      o.v = null
    }
    const r = c()
    print(1)
    // vl check: rc 0.  vl run: invalid module, at 6:7 the binding finds nothing on the stack

Want:

    1

#### Mechanism

The checker types the lambda's tail `o.v = null` at its right side, so `c` returns `null`. A
top-level function's tail `null` write yields a fresh `null` ([D2497](D2497.md)), but
`assignTargetSpills` declines a `null` write at a lambda's or nested function's tail, so the
lambda lowers void while the checker hands its caller a `null` value. The caller's binding
then expects a value the call does not leave. Reading `r` is not needed; until the null-family
cut the read's `null` operand refused first and hid this.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| binding the call's result (`c()` as a statement, then `print(o.v == null)`) | runs, prints `true` | **yes** |
| the lambda (`function c() { o.v = null }` at top level) | runs, prints `true` | **yes** |
| the write (`const c = () => { null }`) | runs, prints `1` | **yes** |
| a non-`null` tail (`const c = () => { print(2) }`) | check reject, "cannot bind the void result" | **yes** |
| inside a function body (`function g() { … const r = c() … }`) | same invalid wasm, inside `g` | no |
| an `i32[] \| null` field | same invalid wasm | no |
| a captured `let h: i32 \| null` instead of the field (`h = null`), at top level | runs, prints `true` | — |
| the same captured `let`, inside a function body | same invalid wasm, inside the function | no |
