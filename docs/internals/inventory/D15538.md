#### Mechanism

The instance of `filled` at `T := 1 | 2 | 7` has the destination `(1 | 2 | 7)[]`. `arrNewDestKind`
asked `tyListRepKind`, which names no list rep for a numeric literal union element, and then
`tyIsRefListElemTy`, which answers the ref list. A numeric literal union is stored as its base
scalar, so no ref list row exists for it and the emitter refuses. An annotated destination
(`const lits: (1 | 2 | 7)[] = filled(2, 7)`) runs because mono binds `T` at the base `i32`.
