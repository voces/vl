#### Mechanism

A literal is built at the type it flows into, and for an arm of a value `if` or `match` that
type is the join. Three places missed it. The checker's `joinTys` collapsed the two arms
without pinning the empty arm's open element, so the literal kept no element type (and with
the empty arm FIRST the join itself was the hole, which refused `const ms = if k < 0 { [] } else
{ TABLE[k] }` as `cannot infer a type`). `emitArr` built an empty literal no destination threaded
a kind to as the i32 list, never reading the element the checker pinned on it. And the
if-expression's blocktype was classified from the THEN arm alone, which for an empty arm is the
i32 list whatever the else arm holds. The close pins in `joinTys` (both directions), reads the
pinned hole in `emitArr`, lets a non-empty else arm decide the join when the then arm is empty
(`ifListArmValueIx`), threads the join's list kind into an empty arm (which a generic instance
needs: its literal still records the template's `T[]`), and seeds an empty `[]` returned from an
un-annotated function with that function's inferred list kind. The same first-element blind spot
held for an outer list literal whose first element is an empty `[]` (`[[], ["a"]]`), closed by
`arrLitLeadInner`. The union destinations of the same literal are [D2202](D2202.md) and
[D2203](D2203.md), closed together.
