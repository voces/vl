### D4561 — a value-`if` bound to a local, one arm a narrowed record-arm binding, gets an `i32` block type

**closed 2026-10-14 — the witness prints `3` · the local's initializer now goes through `emitVariantCoerce` (D4639), which lowers the join with the arm's blocktype and unboxes the narrowed arm · the un-annotated and parameter-arm spellings run too · fixture `tests/cases/unions/narrowed-arm-value-if-init.vl` · the top-level loud face is [D4645](D4645.md) · was check-clean invalid wasm · `type mismatch: expected i32, found (ref $2)` · filed 2026-10-14 against master `eb2603843`**

Repro:

    type Out = { a: i32 }
    type Err = { msg: string }
    function f(r: Out | Err): i32 {
      const o: Out = if r is Out { r } else { { a: 0 } }
      o.a
    }
    print(f({ a: 3 }))

Want:

    3

#### Mechanism

The value-`if` expression's block type is derived without the arm's narrowing, so an arm
whose value is a union binding narrowed to a record arm yields the union box into a block
typed `i32`. Annotating the destination does not help; the tail-position value-`if` (D4555's
fixture `tailIf`) and an assignment under the narrowing both run.
