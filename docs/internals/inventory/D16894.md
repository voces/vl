### D16894 — an `i32[][]` value delivered into a `K[][] | i32[][] | string` box is refused at emit once the program has a `K[][] | string | null` union

**loud emit reject · clause 2 · `vl check` rc 0 · found building [D14041](D14041.md)'s position matrix · filed 2026-11-16 against master `854e949d9`, pre-existing**

Repro:

    type K = 0 | 1
    function own(x: K[][] | string | null) {
      if x is K[][] { print(x[0][0]) } else { print(9) }
    }
    own([[1]])
    function twin(x: K[][] | i32[][] | string) {
      if x is K[][] { print(x[0][0]) } else { print(9) }
    }
    const five: i32[][] = [[5]]
    twin(five)
    // vl check: rc 0.  vl run: emitProgram: array value does not match any array member of the union (leaf-scalar widening across a nested array is unsupported)

Want:

    1
    9

#### Mechanism

`canonUnionMembersWalk` dedupes `K[][]` against `i32[][]` (`memberTySame` softens numeric
literals), so `K[][] | i32[][] | string` and `K[][] | string` key one box row, and the row's type
is the first registered. With `own` first, the row has no `i32[][]` arm, so
`emitUnionCoerceRefArray` finds no arm for the value's slot.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `own` removed | runs, `9` | **yes** |
| `K[]` / `i32[]` in place of the nested lists | runs, `1` `9` | **yes** (depth two) |
| `own`'s `null` arm dropped | still refuses | no |
