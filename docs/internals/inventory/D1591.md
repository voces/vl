### D1591 — an empty `[]` delivered to an INFERRED return had no destination to pin against, so naming the binding lost the element type

**closed — the four inferred-return deliveries (trailing expression, explicit `return`, tail `if`/`else` arm, `??` default) now pin the hole once the body's return witnesses are all in · `~/glean` VL-041 · filed and closed 2026-09-04 against master `0f43eb89`**

Repro:

    function inferred(r: i32) {
      if r == 6 { return [1, 2, 4] }
      []
    }
    function named(r: i32) {
      if r == 6 { return [1, 2, 4] }
      const none = []
      none
    }
    print(named(7).length)
    print(named(6).length)
    print(inferred(7).length)

    // now: 0 / 3 / 0

#### Mechanism

`constrainEmptyExpr` is the usage-driven pin: it writes an open `[]`'s element (`aElem`) in
place from a destination whose shape is known, and the emitter's hole seed (`emptyArrHoleKind`)
reads that same arena row. It was wired at every position where the destination is known WHEN
THE DELIVERY IS CHECKED — an annotated binding, a `T[]` parameter, an annotated return, a `.push`,
an index store, a struct field, a map value. Under an **inferred** return there is no such
moment: `checkRetStmtNode`'s `want == -2` arm and `checkFuncDeclNode`'s `if inferring` tail arm
both returned after `noteInferredRet`, and the destination — the join of every return — is not
final until the body's last statement has run. The bare `[]` in the same tail position ran only
because it is not a *binding*: nothing records it in `pendNames`, so `flushUninferred` never
grades it.

The close banks each delivery (`noteInferRetWitness`) and pins them once, from
`checkFuncDeclNode`, with the body scope still live — `popScope` is what raises the floor. Two
details decide it. **The join is not the destination**: `joinRetTys` collapses `f64[]` against
an open `[]` by mutual assignability and can keep the open side, so pinning against
`inferObserved` would pin a row against itself; the frame banks the first return witness that is
a shape `constrainEmptyD` descends (`irhConcrete`). And **the arm is not the join**: a tail
`if`/`else` hands `checkFuncDeclNode` the arms' join, a third arena row, so the two arm sites
record their own `blockTailIx`/`blockTailTy` pair instead.

The `??` default is the fourth position and a different shape: its typed destination sits on the
LEFT of the operator, so it is pinned at the operator (`nonNullTy(lt)`), not deferred.
