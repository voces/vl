#### Mechanism

D9181 typed the caller's binding only when every `return` of the callee is a record literal
(`monoPinCallRecord`). A `return r` of `const r = { m: hm }` is now accepted: the literal is
closed at the bindings it reads, every open read of `r` in the function takes that record, and
the callee's result is the record (`monoRetConstRecord`). A `let` is still not followed, since
a later write could store another record.
