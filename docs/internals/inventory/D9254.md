### D9254 — an inline list of un-annotated functions as a record field outside a `const` binding has no element representation

**loud emit reject · `vl check` rc 0 · `emitProgram: ref valtype with no interned shape` · clause 2 · found closing [D9181](D9181.md) · present on master `7ad01b8b3` · filed 2026-10-21 against master `7ad01b8b3`**

Repro:

    function inc0(a) { return a + 1 }
    function mk() { return { xs: [inc0] } }
    const v = mk()
    print(v.xs[0](3))
    // vl check rc 0.  vl run: emit error: emitProgram: ref valtype with no interned shape

Want:

    4

#### Mechanism

Not traced. D9181, D9182 and D9183 close a record literal's open field from a nested record
literal or a read of a closed binding (`monoClosedObjLitTy`, emit_mono.vl). A list literal
of functions written inline in the field is typed only where a `const` binds the record
(`monoPinFieldContainers`), so a record literal delivered anywhere else keeps the open
element. The list-element pins (`monoPinListElems`) are the natural owner.
