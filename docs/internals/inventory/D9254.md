#### Mechanism

`monoClosedObjLitTy` closed a record literal's open field only from a nested record literal or
a read of a closed binding; an inline list literal was typed only where a `const` binds the
record (`monoPinFieldContainers`). It now asks `monoPinFieldContainer` for the list's element
pin at path `f.<field>/e` of the record literal's own flow slot. A record literal delivered
into a list element, a map value, a reassigned `let` or an un-annotated parameter does not go
through `monoClosedObjLitTy` and stays open: [D9301](D9301.md).
