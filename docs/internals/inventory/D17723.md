### D17723 — a maker's parameter is keyed as one function set across its calls, so a hole function handed to it uncalled is lowered at another call's typed signature

**closed 2026-11-27 by lane START-2 (#10610) · runs, prints `hi!` · was a loud emit reject, clause 2 · a maker's call handing an uncalled hole function to a parameter it only hands back is keyed at that function's `i32` default carrying its set, and the hand-back guess is deleted · pinned by `tests/cases/functions/hole-fn-maker-keyed-per-call.vl` · filed 2026-11-27 against master `46119b094` by I8-PREP, the residual of [D17724](D17724.md)'s close**

Repro:

    function inc0(a) { return a + 1 }
    function mk2(f) { return f }
    const p = mk2(inc0)
    function ex(s: string): string { return s + "!" }
    const q = mk2(ex)
    print(q("hi"))
    // vl check: rc 0.  vl run: emit error: emitProgram: the compiler cannot yet lower this statement (operand at string)

Want:

    hi!

#### Mechanism

The emitter keys `mk2`'s parameter as one set holding every function any call hands it, so the
set is `{inc0, ex}` at `ex`'s signature, and `inc0` is lowered at `string`. The elaboration
instances `inc0` there only as a guess (D17724), so check is clean and the refusal lands at
emit. One parameter cell held at two instances is the per-instance binding unit START-2 holds.
