### D1443 — an anonymous struct whose field is a LIST of anonymous structs got no row: the mint had no field code for a struct-ref list, so nothing interned the shape

**closed 2026-09-03 by giving `anonFieldCodeSyn` the code-5 arm its nested-struct sibling
already had, plus the companion column that admits it (`anonFieldElemName`) · was
`emitProgram: ref valtype with no interned shape` / `field access receiver is not a struct` on
a `vl check`-clean program · clause 2 · a 14-cell ladder goes 9 -> 14 runs · zero `runs` lost,
`gate.sh` green on all 20**

Repro (runs, prints `1.5`):

    const w = { f: [{ f: 1.5 }] }
    print(w.f[0].f)

#### Mechanism

`collectAnonShapes` mints an `#anon` row only if EVERY field value has a code, and
`anonFieldCodeSyn`'s `ArrayLit` arm coded only NUMERIC-element lists. An element that is an
object literal fell to `-1`, so the OUTER literal got no row, `structIndexOfObj` answered -1,
and the read went looking for a struct ref at a valtype nothing had interned.

The declared twin `type P = { f: { f: f64 }[] }` never took that path: `fieldCodeOfSpelling`
codes the field 5 (`reflist`) and `shapeFieldElemName` records the element name beside it.
`anonFieldElemName`'s new code-5 arm is that pair asked of the LITERAL — the element's own
`#anon` row name — and it is what admits code 5 to the coder at all, exactly the bargain code
16 struck in [D1242](#d1242). The ordering that makes it work is the one the code-15
nested-struct arm already relies on: the parser interns children before parents, so each
element literal has a row by the time the field is coded.

EVERY element must resolve to the SAME row. A heterogeneous list has no single element heap
type, and coding it 5 would intern a field whose `sFieldElemName` names one arm while its
values build another — so a mixed list declines and keeps failing loudly.

An unused `type` declaration of the OUTER shape was the rescue, and only that one: aliasing
the element (`type R = { f: f64 }`) or the element list (`type Q = { f: f64 }[]`) did not.
