#### Mechanism

On master this is D16077's refusal. The prototype of D16077's close reads only a lambda literal
that is itself the argument. Here the argument is a read
of a binding (`m`) or of a named function (`function mk() { inc }`; that spelling refuses with
"cannot take the generic function `inc` as a value"), so the returned read's delivery through
`run`'s parameter is never asked, and the maker's type keeps its hole.
