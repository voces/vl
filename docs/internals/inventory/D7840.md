#### Mechanism

From the code path. `monoPinListElems` gives a generic's shared list element a type at each
instance's pin, and the pin spells only the parameters. A hole element's result is taken from
its recorded type (`monoHoleLamAtAnnTy`), which here is the hole the parameter binds, so no
closed function type is found and the read keeps the arms' unpinned type. Closing it needs the
element instance's own result at the pin.
