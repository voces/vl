#### Mechanism

`monoPinFieldContainers` (emit_mono.vl) types the record, the reads of it and of
a `const` alias of it, and the values read through the alias's field. The same alias at top
level runs, so the alias declared inside the closure's frame is the one whose value read
keeps its open type.
