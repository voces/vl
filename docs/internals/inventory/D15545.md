### D15545 — an un-annotated record field holding a `Map()` whose record value only a later store names mints its row before that record has one

**closed 2026-11-08 · runs, prints `a` · was loud emit reject, `emitProgram: ref valtype with no interned shape` (`object literal field count does not match struct` inside a block or function body), `vl check` rc 0 · clause 2 · closed by minting such a holder late, beside the empty-list holder D2640 delays (`anonRecordValuedMap`, emit_collect.vl) · fixture `maps/record-field-map-value-row-minted-late.vl` · matrix `record-field-map-of-fn-records` · filed 2026-11-08 against master `be09b8cbc`**

Repro:

    const v = { f: Map() }
    v.f["k"] = { f: (x: i32) => "a" }
    const t1 = v.f["k"]
    if t1 != null { print(t1.f(1)) }

Want:

    a

#### Mechanism

`collectAnonShapes` mints each object literal's row in source order. A `Map()` field is
coded 19 only when `mapTyValKindLowerable` finds a struct row for the map's record value,
and here that record's first literal is the store after the holder, so the field took no
code and the holder no row. The cell then had no struct slot (`fbValtype`'s guard).
