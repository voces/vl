#### Mechanism

`srcs[0]` holds a list whose elements the build stores at `J` (D16784), but the record literal's
field is laid out at the read's own `{ f: null }[]`, so the literal stores a `J` list where its
field is narrow. A record literal holding `src` itself runs, so the literal's part is built at the
build only for a direct read of the built list (D16765), not for an element of a list of lists.
