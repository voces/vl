#### Mechanism

`captureBoxRewrite` runs before `monomorphize`, and a host with a type parameter or an
un-annotated one (monomorphization), or with a parameter whose type reaches a function, even a
nullable one or a record field (callback specialisation, [D3713](D3713.md)), is cloned after it,
so the clone's capturer may not be lifted. `cuChainOk` keeps the cell for any frame chain
holding one. Deciding per clone would need the box decision after monomorphization, or a
lift decision that every clone is held to.

The generic host: `function f<T>(x: T, n: i32): i32 { let k = 0; const bump = (d: i32) => { k += d }; for i in 0 until n { bump(i) }; k }`
