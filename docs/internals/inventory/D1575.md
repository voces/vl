### D1575 — the A-infer-null HOLE reaches five `T.tys[…nInner]` readers unguarded: `const x = null` traps the COMPILER, and `nodeTyIsNulScalarBox` is the rung that owns it

**now a loud emit reject, 2026-09-04, by bound-testing `nInner` at every reader of it in
`compiler/typecheck.vl` · was a compiler trap (`vl check` rc 0, then the seed's own
`out of bounds array access`) · clause 1 · found by the sentinel-index lint (#2499) while
validating its D1440 control, which flagged `nodeTyIsNulScalarBox` at `typecheck.vl:30096` as
carrying D1440's shape unfixed on master · 17 of 35 hand witnesses trapped master, 0 trap now ·
the capability gap under it — a never-filled `x = null` has no rep — is pre-existing and open**

Repro (before: the compiler traps; now: the loud `??` refusal it already owed):

    function go(c: boolean) {
      const x = null
      const y = (if c { x } else { x }) ?? 0
      print(y)
    }
    go(true)

#### Mechanism

`const x = null` binds `mkNullableTy(-1)` — the USAGE-DRIVEN NULLABLE HOLE (A-infer-null): a
`TyNullable` whose inner is not yet a type, filled IN PLACE by the first non-null assignment.
`typecheck.vl` says so at the mint site and again at `noteLitElemCstrs`, which already
bound-tests for exactly this reason, citing D1440. Twenty-two OTHER readers in the same file
did not, and `T.tys[-1]` is an out-of-bounds `array.get`: the compiler dies wearing the seed's
own `out of bounds array access` with anonymous frames, on a program `vl check` accepted.

**THE ASSIGNED SITE IS SHADOWED, and an A/B build is what proves it live.** On master this
witness never reaches `nodeTyIsNulScalarBox` — it dies four rungs earlier, inside
`collectLocals`. Guard the four shadowing siblings and leave `nodeTyIsNulScalarBox` alone, and
the same three witnesses trap THERE instead:

    0:  0xb7765 - vl!nodeTyIsNulScalarBox$m9
    1: 0x1a7110 - vl!emitCoalesce$m19
    2: 0x19f6bf - vl!emitLetDeclStmt$m19

Five rungs, three phases, one hole. `emitCoalesce`'s gate reads
`tyIsNulValueUnionBox(…) || nodeTyIsNulScalarBox(…)`, so that pair had to be guarded together
or the second would only ever be reached by a program the first had already killed.

| rung | phase | witness that reaches it on master |
| --- | --- | --- |
| `nodeTyIsNullableOneRep` ← `nulIfArmNullableValueIx` ← `collectLocals` | emit-collect | the witness above |
| `tyIsNulValueUnionBox` ← `drwWalk` ← `dispatchRewrite` | emit-rewrite | `const h = gNull()[0]` then `h ?? 0` |
| `nullableRetName` ← `checkFuncDeclNode` ← `checkProgram` | **check** | `function f() { let x = null  return x }` |
| `nulListRetName` ← `checkFuncDeclNode` | **check** | the same, once `nullableRetName` is guarded |
| `nodeTyIsNulScalarBox` ← `emitCoalesce` ← `emitLetDeclStmt` | emit | the witness, once the four above are guarded |

The guard is the family rule [D1500](D1500.md) states — a table read whose index came from a
reader with an in-band "no answer" value must be bound-tested — applied at the file that MINTS
the sentinel, so all 22 readers of `.nInner` in `typecheck.vl` carry it. The census
(`scripts/sentinel-census.py`, #2499) falls 386 → 363 and `typecheck.vl:30096` is gone.
