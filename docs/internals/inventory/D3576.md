### D3576 — `as! P` over a nullable struct is an emit refusal

**loud emit reject · clause 2 · found by the #3351 review · filed 2026-10-03 against master `3b9319528`**

Repro:

    type P = { x: i32 }
    function mk(b: boolean): P | null {
      if b { return { x: 1 } }
      null
    }
    const q = mk(true) as! P
    print(q.x)
    // vl check: rc 0.  vl run: "emitProgram: `as P` over a `P | null` is lowered for a
    // string, a list and a union variant; a standalone struct, map or closure cell has no
    // lowering yet at an un-annotated destination"

#### Mechanism

Not ablated. The message names an un-annotated destination, but I tried three ANNOTATED
spellings while filing and all three refused with the same sentence:
`const q: P = mk(..) as! P`, a `: P` function returning `p as! P`, and `const q: P = r as! P`
over `const r: P | null`. So the refusal's scope is wider than its sentence. Grade each
position before narrowing the message.

#### Grading list

Binding (annotated and not), return, argument, field, element, and the `map`/closure-cell
members the sentence names. Each spelling should print `1` and trap on `mk(false)`.
