### D15892 — a fresh call's record field delivered at a union of two records sharing its field names is refused, the copy finding no one member

**closed 2026-11-12, runs and prints `2` then `true` · was a loud check reject, clause 2 (D14385's interim refusal) · `recUnionRecMember` (check_fit_rules.vl) picks, among members sharing the record's field names, the one storing it as it is, else the one the copy's rule admits it into; the copy and the held read (`boxedArmOfMember`) share the pick · graded by `scripts/capability-probes/matrix/kept-maker-delivery-record-union-shared-names.matrix.vl` · fixture `tests/cases/structs/record-copied-into-union-member-sharing-field-names-runs.vl` · found closing [D14385](D14385.md) · filed 2026-11-12**

Repro:

    type A = { x: i32 }
    type B = { x: string }
    type W = { r: A | B }
    function one() { { r: { x: 1 } } }
    const a = one()
    print(a.r.x + 1)
    const w: W = one()
    print(w.r is A)

Want:

    2
    true

#### Mechanism

The copy's rule builds a record field delivered at a union of records at the one member with the
record's field names (`recUnionRecMember`, check_fit_rules.vl). `A` and `B` share `x`, so there
are two and the field is not admitted. The copy's rule (`recCopyBoxesAt`) would admit `{ x: i32 }`
into `A` and not into `B`, so the member is decidable by the rule rather than by names.

delivery picks.
