### D15892 — a hole lambda's bundle handed to an un-annotated parameter that hands it on to a parameter called at two signatures is refused at emit

**loud emit reject · clause 2 · open · `emitProgram: a function value is called at two signatures, and the closure it holds was built for one: this call passes a wider number than its `i32` parameter`; through a `const` copy of the parameter, `monomorphize: unsupported argument type for `a` in a call to `fw`` · found closing [D15744](D15744.md) (cell `argument`/un-annotated of `lambda-bundle-returner.matrix.vl` and its in-function twin) · filed 2026-11-12 against master `bd8092cc`**

Repro:

    function lap(f) {
      f(2.5)
      f(3)
      return f
    }
    function take(b) {
      print(b(4))
      print(b(1.5))
    }
    function fw(a) { take(a) }
    fw(lap((a) => a + 1))

Want:

    5
    2.5

#### Mechanism

The bundle (the record of `lap`'s two instances of the lambda) is delivered whole to a parameter
called at both signatures (`take(lap(…))` runs), but a parameter that only hands it on is not
followed: `fw`'s `a` is one closure, and `take`'s two calls through it reach a closure built
at one signature.

#### Ablation

| spelling | outcome |
| --- | --- |
| `take(lap(…))` | runs |
| `fw(lap(…))`, `fw` calls `a` at one or two signatures itself | runs |
| `fw(lap(…))`, `fw` hands `a` to `take` | refuses (function value at two signatures) |
| `fw` hands `const v = a` to `take` | refuses (mono) |
| the bundle from a named or lambda returner, or a module `const` holder | refuses the same |

#### Grading list

`lambda-bundle-returner.matrix.vl` and `lambda-bundle-returner-in-function.matrix.vl`, cell
`argument`/un-annotated.
