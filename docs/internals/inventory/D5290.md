### D5290 — a generic returned from two inferred-return functions binds its type variable once, by name

**loud check reject · clause 2 · found closing D5062 · filed 2026-10-17 against master `d1b078d59`**

Repro:

    function k<T>(x: T): T { return x }
    function mk() { return k }
    function mks() { return k }
    function apply(f: (x: i32) => i32) { print(f(6)) }
    function main() { const h = mk(); print(h(1)); apply(h); print(mks()("str")) }
    main()
    // vl check: argument 1: expected (i32) => i32, got (string) => string

Want:

    1
    6
    str

#### Mechanism

Each inferred return is `k`'s open `(T) => T`, and a call through either result binds `T`
itself rather than a fresh copy of it. The call `mks()("str")` binds `T` to `string`, and
`apply(h)` then sees `h` as `(string) => string`. Not yet ablated past the rename below.
