#### Mechanism

Printed at the rung: the call reaches `checkCallNode`'s `if ft is TyErr { return TY_ERR }` with
`k` resolved at depth 0 to type 7, `TY_ERR` — the pass-1.5 hoist's placeholder for an
un-annotated global, which pass 1.65 (`globalInitPrePass`) kept because `id`'s type carries
type-parameter holes. The rung returns before the arguments are checked and reports nothing.
The same placeholder reached the call for an annotated lambda (`(x: i32) => x`, skipped as a
lambda) and for an un-annotated function (`function inc(x)`, holes).

Closed in three parts: pass 1.65 types a global whose initializer is a bare top-level function
name even when its type has holes, and records the alias as pass 2 does; it types a lambda
whose parameters are all annotated; and the `TyErr` rung checks the arguments on their own when
the callee is a module global pass 2 has not reached. A lambda with an un-annotated parameter
still reads the placeholder: [D4019](D4019.md).
