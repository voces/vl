### D1720 — a `??` whose operand is a nullable-STRUCT FIELD read traps on null: the read recovers to the non-null rep before the null test the operator exists for can run

**loads then traps · filed 2026-09-06 against master `df777a8b3` · found grading D1714's
position matrix, where it is the FITTING-default control · 0 corpus cells**

Repro:

    type A = { r: i32 }
    function st(): A { return { r: 8 } }
    function mkA(): A | null { return null }
    const w = { f: mkA() }
    const g = w.f ?? st()
    print(g.r)
    // vl check: rc 0.  vl run: exit 1,
    // wasm trap: null reference
    // note: a null value was used where a non-null one was required.

#### Mechanism

`emitCoalesceNulRef` hands its left operand the ambient context, on the stated ground that
these reps "have no self-recovering read". A nullable-struct FIELD read has one: it emits
`ref.as_non_null` to reach the field's non-null rep, and that runs before `br_on_non_null` ever
sees the value. The default is unreachable — the operator traps on exactly the input it exists
to handle.

The string niche's own arm already passes `rawNullRead`, which is what a raw read of the
nullable cell needs; setting the same flag on this wrapper does NOT fix it, so the recover is
not at the `??`'s read but earlier, where the field read is bound.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the field read (a direct `const v = mkA()` operand) | runs, prints `8` | **yes** |
| the anonymous holder (a declared `type W = { f: A \| null }`) | traps identically | no |
| the inline read (`const v = w.f` then `v ?? st()`) | traps identically | no |
| the fitting default (a JOINING `w.f ?? 7`) | traps identically | no |
