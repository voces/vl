### D17124 — a `null`-unit binding read as an `if` arm joined into an annotated `T | null` binding is invalid wasm

**check-clean invalid wasm · clause 1 · found by IR-N4's Q58 sweep for `start: global initializer nulnone`, the same on master and on its branch · owner FREE · filed 2026-11-24 against master `334f6958`**

Repro:

    type In = { v: i32 }
    const n = null
    function arm(f: boolean) {
      const a: In | null = if f { n } else { { v: 9 } }
      return if a == null { -1 } else { a.v }
    }
    print(arm(true))
    // vl check: rc 0.  vl run: invalid module, "type mismatch: expected i32, found nullref" in `arm`

Want:

    -1

#### Mechanism

A binding whose type is the `null` unit (`const n = null`, at module scope or local) read as one
arm of a value `if` that an annotated `In | null` binding receives: the join's block type does not
take the arm's `nullref`. The IR leaves `arm` uncovered (`if arm coercion`), so legacy's bytes
ship.

#### Ablation

| ingredient | outcome |
| --- | --- |
| the arm `null` literal in place of `n` | runs, `-1` |
| `const n: In \| null = null`, the binding typed | runs, `-1` |
| `let n = null` in place of `const` | invalid module |
| `const n = null` local to `arm` in place of the global | invalid module |
| the receiving binding un-annotated | check refuses (type error) |
