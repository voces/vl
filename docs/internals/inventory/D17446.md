### D17446 — a generic's record field or list element joining `A | C` with another type drops that type from the inferred return

**closed 2026-11-25 by SOUND · runs, prints `true` `s` · was check-clean silently wrong, clause 1 · `joinTys` folded a concrete type into a written union of a declared parameter and a concrete member, since the parameter takes anything inside the body; it now keeps such a type apart when the union's concrete members do not take it (`mixedParamUnionBesideConcrete`, check_relate_core.vl), bare or held in a same-field record or a list (`heldMixedParamJoin`, joined fieldwise) · pinned by `tests/cases/generics/join-mixed-param-union-beside-concrete.vl` (record field, nested field, list element, value `if`, no type argument) · found sweeping a generic call that binds no type parameter · owner S2 · filed 2026-11-24 against master `6063a6c1`**

Repro:

    function G<A>(v: A | i32, b: boolean) {
      if b { return { x: v } }
      return { x: "s" }
    }
    const r = G<i32>(5, false)
    print(r.x is string)
    print(r.x)
    // vl check: rc 0, `G` infers `(A | i32, boolean) => {x: A | i32}`.  vl run: prints `false`, then `0`

Want:

    true
    s

#### Mechanism

Not established. The inferred-return join of the two record arms keeps the first field type
`A | i32` and drops `string`. The same happens for every `A | C` (`i32`, `string`, `boolean`)
against every other `X` tried (`"s"`, `true`, `2.5`, `[1]`), through an `if` value, and for a list
element (`[v]` / `["s"]` infers `(A | i32)[]`; built at `G<i32>`, that is invalid wasm inside `G`).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the concrete member (`v: A`, so the field is `A`) | runs, `true` (`{x: A \| string}`) | **yes** |
| the type parameter (`v: i32`) | runs, `true` | **yes** |
| the wrapper (`return v` / `return "s"`) | runs, `s` | **yes** |
| `A \| null` in place of `A \| i32`, the other arm `{ x: 5 }` | runs, `true` (`{x: A \| i32 \| null}`) | `null` is not such a `C` |

#### Grading list

- The list spelling (`[v]` / `["s"]`, read `r[0]`), invalid wasm today, which must run and print `s`.
- `G(5, false)` with no type argument, once a call that binds no type to `A` reads it as `never`.
