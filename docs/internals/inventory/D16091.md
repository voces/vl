Repro:

    function inc(a) { return a + 1 }
    function str(_a) { return "s" }
    function ap(g, x) { return g(x) }
    function run(c: boolean) {
      const fs = [inc]
      if c { fs[0] = str }
      print(ap(fs[0], 3))
    }
    run(true)
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `run`

Want:

    s

#### Mechanism

The element's call dispatches with a joined `i32 | string` result when called directly
(`print(fs[0](3))` prints `s`), but handed to `ap`'s open `g`, `ap`'s result is typed at one
member's while the dispatch at the hand builds the union box, so `run` hands a boxed value where
`i32` is read.
