### D16091 — a list element written with un-annotated functions whose results differ, handed to an open function parameter, builds an invalid module

**check-clean invalid wasm · clause 1 · `vl check` rc 0 · `the emitted module failed to validate inside \`run\`: type mismatch: expected i32, found (ref $8)` · found grading [D16064](D16064.md) · neighbour [D15801](D15801.md) · filed 2026-11-14 against master `b53278055`**

Repro:

    function inc(a) { return a + 1 }
    function str(_a) { return "s" }
    function ap(g, x) { return g(x) }
    function run(c: boolean) {
      const fs = [inc]
      if c { fs[0] = str }
      print(ap(fs[0], 3))
    }
    run(true)
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `run`

Want:

    s

#### Mechanism

The element's call dispatches with a joined `i32 | string` result when called directly
(`print(fs[0](3))` prints `s`), but handed to `ap`'s open `g`, `ap`'s result is typed at one
member's while the dispatch at the hand builds the union box, so `run` hands a boxed value where
`i32` is read.

#### Ablation

| change | outcome |
| --- | --- |
| witness | check-clean invalid wasm |
| `print(fs[0](3))`, called directly | runs, prints `s` |
| members agree (`inc` and `dbl`) | runs |
