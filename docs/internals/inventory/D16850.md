    function adder(n) { return (a) => a + n }

    function half(a: (a: f64) => f64) { print(a(0.5)) }

#### Mechanism

A binding of a maker call read other than as a callee withdraws the maker from twinning, so both
calls are built from the maker's plain instance, whose returned lambda takes one parameter type;
the annotated destinations then call the `f64` one's closure at the `i32` parameter's code.
