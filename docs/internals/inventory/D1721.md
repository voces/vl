#### Mechanism

and D1714's arm boxes both sides into it. A NULLABLE default keeps `null` in the join, so the
result is `string | A | null` — three members, one of them `null` — the join gate reads "" and
the `br_on_non_null` shape stands, with the default's own nullable ref delivered into a block
typed at the operand's heap.
