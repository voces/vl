#### Mechanism

Every other default kind at a nullable-ref niche joins to a union whose rep is the value box,
and D1714's arm boxes both sides into it. A NULLABLE default keeps `null` in the join, so the
result is `string | A | null` — three members, one of them `null` — and no registered row names
it: `isValueUnionName` declines a struct member and the canon-keyed lookup finds nothing minted
for an inference nobody spelled. The join gate reads "" and the `br_on_non_null` shape stands,
with the default's own nullable ref delivered into a block typed at the operand's heap.

The DECLARED face of the same program does not run either, and refuses somewhere else: `is`
names a declared union member with no interned arm representation. So the annotation is not the
difference here, which is what separates this from D1709.
