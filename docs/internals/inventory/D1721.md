### D1721 — a declared union mixing a struct arm with a value atom and `null` is spelled structurally, so no registered row bears its name

**closed 2026-09-06 · was check-clean invalid wasm, filed 2026-09-06 against master `df777a8b3`
· re-characterised in #2760 (the `??` was scenery) · 0 corpus cells**

Repro:

    type A = { r: i32 }
    type U = string | A | null
    function st(): U { return "s" }
    const w: U = st()
    if w is A { print(1) } else { print(0) }
    // prints 0

#### Mechanism

`string | A | null` interns as `TyNullable` over `string | A`, so `type U = …` is a ONE-member
`UnionDecl` whose member is that nullable — a transparent alias by `nulAliasMemberFaithful`.
`collectU` therefore mints no row named `U`, canon rewrites every `U` annotation through
`transparentMemberEmitName`, and its fall-through is the STRUCTURAL render, which spells the
struct arm as its shape. Measured on `114b3f835`, one `emitFail` at the `is` arm per cell:

| declared type | canon's render of `U` | `isUName` | `unRowOfCanon` |
| --- | --- | --- | --- |
| `string \| A` | `U` | 1 | row 0 |
| `A \| null` | `A\|null` (`declaredStructUnionMembers`) | 0 | -1, a niche |
| `string \| i32 \| null` | `string\|i32\|null` | 1 | row 0 |
| `string \| A \| null` | `string\|{r:i32}\|null` | **0** | row 0 |

The row the emitter keys on IS registered — `collectTyReachRegister` mints it from
`tyToNominalName`, under `string|A|null` — so the canon-keyed index finds it and every
name-keyed consumer misses. Two producers of one spelling, and the nominal one was right.
The close is three joins of the two: the transparent-alias render takes the nominal renderer
for a nullable over a union with a declared-struct arm; `nodeRegisteredUnionName` answers for
a `TyNullable`-rooted node, so the inferred face names the same row; and `tyIsMixedUnion` sees
through the nullable, so an un-annotated binding mints the row at all. A `V | null` niche
delivered into such a box then has no tag of its own — `emitUnionBoxNulNiche` parks it once
and lets the null test pick between `null`'s tag and the value's own arm.
