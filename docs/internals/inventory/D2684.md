### D2684 — a generic body's `T | null` local, pinned at a Set or a literal-union map, cannot answer `is` against another map

**loud emit reject · clause 2 · found by #3193's review (k3; the string and numeric literal pairings, and a Set) · on master the same program is a loud emit reject too, with the D2493 sentence · filed 2026-09-26 against master `f8709e41c`**

Repro:

    type L = "p" | "q"
    function g<T>(x: T) {
      let u: T | null = null
      u = x
      print(u is {[i32]: string})
    }
    const m: {[i32]: L} = Map()
    g(m)
    // vl check: rc 0.  vl run: emitProgram: `is` cannot tell which map this instance's nullable value holds …

#### Mechanism

A map beside `null` is a niche with no box tag, so `u is M` over it is answered from the map
type the niche holds. An instance spells a pinned type by name, and a name renders a Set as its
boolean map and a literal-union value by its base (`{[i32]: L}` reads `{[i32]: string}`). A
PARAMETER's test reads the pin itself (`monoParamPinTy`), and so does a `const` local initialized
from one. Any other operand (a `let` copy, a generic identity's return) carries only the
spelling, so the emitter refuses where the answer turns on the exact pinned map: an instance
pinned at a Set or a literal-union map, at another map of the pattern's struct, or serving two
different map pins (a registry hit, marked `-2`).

Instances are keyed by REP, so `Set<i32>` and `{[i32]: boolean}` pins share one instance (the
review's m7, m1, m8; the D2673 collision), and a lifted closure inside an instance sees no pin at
all (m5, which prints `true` for `is {[i32]: boolean}` over an `{[i32]: i32}` niche, as master
does). **Recommended fix, a follow-up:** key an instance by its full pinned type whenever its
body has an `is`, `match` or `as` over a T-derived value. `T` is then concrete per instance, and
every `let`, return and closure follows it without a side table.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the reassignment (`const u: T \| null = x`) | runs, prints `false` | **yes** |
| the literal union (`{[i32]: i32}` for `m`) | runs, prints `false` | **yes** |
| the generic (`u: {[i32]: L} \| null`) | runs | **yes** |
