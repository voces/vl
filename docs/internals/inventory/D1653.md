### D1653 — an `extern function` mints no arena node, so `vl fmt` printed the program without it

**closed 2026-09-05 · `vl fmt` rc 0 returned a DIFFERENT program: the declaration was gone and every call to it became `undeclared identifier` · fixed by recovering the declaration from `P.toks` the way `import` is, and placing it by its own source line · found by widening the fmt sweep to `tests/cases`, where the extern fixtures had never been formatted**

Repro (the program runs; before the fix, `vl fmt` printed it without line 1, and the output
then failed `vl check` with `undeclared identifier 'nowMillis'`):

    extern function nowMillis(): i64

    print(nowMillis() > 0)
    // vl run: true.  vl fmt (before): the `extern` line deleted, rc 0, no diagnostic

#### Mechanism

`parseExtern` banks the declaration in the program-wide manifest (`ast.externAdd`) and
contributes **no statement** — an extern has no body to run and no local index to occupy, so
there is nothing for the arena to hold. `formatProgram` prints from the arena, so the
declaration was invisible to it and simply did not appear in the output. It is the third
construct in that position: `import` and a re-export are consumed without a node too, and both
are recovered from `P.toks` — the extern never was.

The recovery is placed by SOURCE LINE rather than hoisted with the imports. An extern may be
written anywhere at top level, and moving it would be the formatter editing the program rather
than printing it. `emitStatements` flushes every pending extern whose line precedes the next
statement's, then once more after the last statement, which is what an extern-only module needs.

#### Ablation

`vl fmt` on each spelling, before and after. `kept` is whether the declaration survives.

| ingredient | before | after |
| --- | --- | --- |
| `extern function nowMillis(): i64` | **deleted**, rc 0 | kept, rc 0 |
| `export extern function hostEcho(x: i32): i32` | **deleted**, rc 0 | kept, rc 0 |
| the extern written AFTER a statement | **deleted** | kept, still after that statement |
| a parameter list wrapped over lines | **deleted** | kept, rejoined to one line when it fits |
| a trailing `// …` on the declaration | **deleted** with it | kept on its line |
| a comment INSIDE the parameter list | **deleted** with it | kept, via the verbatim path |
| an extern-only module (no statement to precede) | **deleted** | kept |
| `import { … } from "…"` (control) | kept | unchanged |
| `export { … } from "…"` (control) | kept | unchanged |
| `export function f(): i32 { … }` (control) | kept | unchanged |

The ingredient is not the `export` modifier, the arity, the return type or the position: it is
that the construct has no arena node, which is true of every extern.
