### D16807 — a local alias of a hole map parameter, read for a function value the map's inferred type holds as a hole, refuses once the read-only map floor lifts

**loud emit reject · `emitProgram: a union's arm rows were asked of a type no row holds` · clause 2 · `vl check` rc 0 · before L2 S3.4a the read-only map floor ([D16714](D16714.md)) refused it at check in either order · the distilled cell `d16121_argument_unann` · filed 2026-11-16 against master `86273a87`**

#### Mechanism

The emitter refuses in `emitUnionWideArmBox` (`wasmEmit.vl`), asking `unionArmRowsOfTy` of the
alias read's type. A probe seed measured that type as `((_) => _) | null`, the template's open
function type, not the instance's `(i32) => f64`. The same read straight off the parameter runs,
because the emitter re-reads only a parameter at each instance. The shared ingredient with
[D3818](D3818.md) is a non-parameter receiver of a hole parameter. Resolving an alias read through
its declaration in `elabNodeTyAt` changed neither row.
