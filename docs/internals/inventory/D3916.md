### D3916 — a generic function stored into a parameter's list, an inferred local's list or a map's value inside a generic traps with `indirect call type mismatch`

**loads then traps · found in review of #3484 (`rv3484/m`: m01–m07; c01, c03, c05 are the concrete controls) · filed 2026-10-09 against master `09d7de908`**

Repro:

    function c<U>(y: U) { print("c"); print(y) }
    function st<T>(fs: ((t: T) => void)[], x: T) {
      fs[0] = c
      fs[0](x)
    }
    const fs: ((t: string) => void)[] = [(t: string) => print(t)]
    st(fs, "s")
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch, in `st`

Want:

    c
    s

#### Mechanism

The slot roots #3484's store fix leaves out. #3484 coerces a function value stored into a
slot by reading the slot's type off an annotated local's annotation, as the instance spells it.
Three roots name the type some other way, and each traps at one instance:

- a parameter (`fs[0] = c` with `fs: ((t: T) => void)[]`, m01, m02);
- an un-annotated local whose type is inferred (`const fs = [(t: T) => print(t)]; fs[0] = b`, m03, m04);
- a map's value (`m.set("k", b)` or `m["k"] = b` into `Map<string, (t: T) => void>`, m05–m07).
