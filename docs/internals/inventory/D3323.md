### D3323 — a string `const` reached through a copy and used as a parameter default arrives nullable at the call

**check-clean invalid wasm · clause 1 · pre-existing: identical on master `e70102886` · found in the #3296 round-4 review · filed 2026-09-29 against #3296 head `fcb70b50e`**

Repro:

    const K0 = "hi"
    const K = K0
    function f(x: string = K): string { x }
    print(f())
    // vl check: rc 0.  vl run: invalid module at top level,
    // "type mismatch: expected (ref $type), found (ref null $type)".  Expected: hi

Want:

    hi

#### Mechanism

A prediction until a close confirms it. The default is substituted at the call as a read of the
module global `K`, and a module global of a string type initialised from another global is
stored in a nullable slot (its value is set when the module's top level runs). Read directly,
`print(K)` narrows it; substituted as an argument to a non-null `string` parameter it is passed
as the slot's nullable reference without the cast the direct read gets.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const K = "hi"` (no copy) | runs, `hi` | **yes** |
| `print(f(K))` instead of the default | runs, `hi` | **yes** (the default) |
