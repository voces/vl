### D2417 — a boolean-niche `??` join in a value `if` arm lowers at the niche's `i32`

**check-clean invalid wasm · clause 1 · found in review of #3148 (D2383's residue), the same on master `a20d69104` · filed 2026-09-25 against master `a20d69104`**

Repro:

    type A = { r: i32 }
    function st(): A { return { r: 7 } }
    function mkB(): boolean | null { return null }
    function go() {
      const x = if 1 > 0 { mkB() ?? st() } else { null }
      if x is A { print(x.r) } else { print(0) }
    }
    go()
    // vl check: rc 0.  vl run: invalid module, inside `go`:
    // "type mismatch: expected i32, found (ref $type)".  Expected: 7

#### Mechanism

A prediction until a close confirms it. D2383's close keys the box on the `??` node's own
recorded type (`coalesceResultUnionName`). In an arm, that type is the arm's share of the
`if`'s join, so the `??` is not recognised as joining to the box, and the arm lowers through the
boolean niche's `i32` while the `if` block is the box.
