### D4923 — a record of the complement of `is i32[]` over a hole parameter gets no row at a list argument

**closed · was a loud emit reject (`emitProgram: object literal but no struct type declared`), identical on master `c2dbf639e` · fixture `tests/cases/generics/complement-list-record-scalar-and-hole.vl` · filed 2026-10-15**

Repro:

    function h(v) {
      if v is i32[] { print(0) } else {
        const r = { xs: v }
        print(r.xs[0])
      }
    }
    h(["e"])

Want:

    e

#### Mechanism

The field's type is the derived hole `HD_GNOT` (the parameter less `i32[]`), whose pin
`holePinReadOf` answered `-1` for any non-null alternative, so `mintPinnedObjLit` minted no
row and a program with no declared struct refused the literal. Closed with D4899 in
`typecheck.vl`'s `holePinReadAt`, which now reads the base pin less the alternative.

| --- | --- | --- |
