### D6422 — a record literal holding a generic function, handed to a parameter of a narrower declared record, is check-clean invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · found closing [D6371](D6371.md) · filed 2026-10-18 against master `066d19373`**

Repro:

    type G = { g: i32 }
    function k<T>(x: T): T { return x }
    function show(o: G) { print(o.g) }
    const r = { f: k, g: 7 }
    print(r.f(1))
    show(r)
    // vl check: rc 0.  vl run: the emitted module failed to validate inside the module's top-level code: type mismatch: expected (ref $0), found (ref $1); $0 is `G`, struct {mut i32}; $1 is `#anon1`, struct {mut (ref $2), mut i32}

Want:

    1
    7

#### Mechanism

From the ablation only. The argument is delivered as the literal's own wider struct where the
parameter expects `G`, with no conversion between the two, only when the extra field holds a
generic function.
