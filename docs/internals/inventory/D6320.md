### D6320 — a module `const` alias of an un-annotated function, called in a generic body at its type parameter, instanced at two types, is check-clean invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · found closing [D6206](D6206.md) · the same on master `5e3ba8429` and before #4072 · filed 2026-10-18 against master `5e3ba8429`**

Repro:

    function id(x) { return x }
    const q = id
    function g<T>(x: T) {
      print(q(x))
    }
    g("s")
    g(2)
    // vl check: rc 0.  vl run: invalid module, the emitted module failed to validate inside `g`: type mismatch: expected i32, found (ref $2)

Want:

    s
    2

#### Mechanism

From the ablation only. No split is asked: the emitter takes `q`'s one signature from the
first instance and the second instance's call delivers a value of the other type to it,
without a refusal that would start a split round. D6206's per-instance copy closes the
`fw(id)` spelling because that one is refused first.
