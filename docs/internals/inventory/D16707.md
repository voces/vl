#### Mechanism

The instance at `sv`'s record refuses the write, which undoes the parameter rewrite (D3992), and
the call keeps the field-dropping capability sentence. The slot face rewords the same write through
a binding (`slotWriteWords`, "`u` is `sv` itself, whose `pet` also stores `purr`"); the
parameter face has no such step. The refusal is owed (DECISIONS "Width subtyping reaches nested
fields"); the close is a contract sentence at the write.
