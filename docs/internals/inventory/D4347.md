#### Mechanism

`arrElemIsClosureTy` keyed any literal whose element type mentions a function as a closure
list, so `[mk(1)]` over `F | string` stored bare closures and no union arm was interned for
`is`. A value-union element now declines that rung and keys as the union's box, which is the
kind the annotated spelling already had. Even `xs[0] is string` refused before the fix.
