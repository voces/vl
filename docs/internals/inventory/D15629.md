#### Mechanism

At the pin `{ x: i32[] }` the operand is the bare list, not a box, while the test names the
bound's `i32[] | string` arm, which no union row interns, so `emitIsTest` had no arm to test. The
operand's closed type at the pin is the tested type itself, so the test is decided; the
record spelling (`T: { x: A | B }` pinned at `A`, no `A | B` declared anywhere) refused the same
way with `` `is` test but no union type declared ``.
