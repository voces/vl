### D5472 — two calls of a hole callee that push different elements into its own literal's empty list field are refused as a write conflict

**loud check reject · clause 2 · OPEN (needs a per-instance literal row in the monomorphizer, L1) · found closing D5344 (D3745's grading list) · before D5344 the same program was the emit reject `monomorphize: unsupported argument type for \`a\`` · filed 2026-10-17 against `4844bd111` (PR #3980's head)**

Repro:

    function take3(a, e) {
      a.push({ x: 1, ys: [] })
      a[0].ys.push(e)
      print(a[0].ys.length)
    }
    take3([], { z: 2 })
    take3([], "s")
    // vl check: the callee's body writes string into the list passed here, whose element is {z: i32}

Want:

    1
    1

#### Mechanism

Each call builds its own instance of `take3`, but the literal `{ x: 1, ys: [] }` in the body
has ONE type row, shared by both instances. D5344's default (`objFieldHolesToI32`) pins that
row's open `ys` element to the first hole callee's write (`calleeWrittenElem`), and the
second call's write of `string` then fails `checkCalleeWrites`. The refusal names a conflict
that a per-instance row would not have. Moving the default after `checkCalleeWrites` is not a
fix: it builds one row for both instances, and the module fails to validate inside `take3$1`
(`expected (ref $0), found (ref $4)`). The template's literal needs a row per instance.

A per-call copy in the checker alone is not enough either; this was measured while closing
D5470/D5471. Copying the literal's record row at the push pin (`cnhPinBmElem`, one row per call)
clears the write conflict. The emitter then refuses with `emitProgram: internal: a parameter type
the valtype ladder has no rung for`, and it does so for every ONE-call spelling too, so it would
cost a `runs` cell. The copy has no anonymous-struct row, and the instance's cloned literal node
still carries the shared row. The fix needs a per-instance literal type in the monomorphizer:
the per-call shape D5079's `monoFieldReadTys` gives a field read, here applied to a literal. That
is L1's per-call binding machinery.
