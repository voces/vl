### D15037 — a choice handed to a nested function declared before one of its nested arms is refused at a name the program does not write there

**loud check reject · clause 2 · `undeclared identifier 'ask'`, pointing at `f("a")` inside `both` · found by the split-plan census of H-nested · filed 2026-11-02 against master `7e3fea10`**

Repro:

    function inner(s) { return s }
    function nested(c: boolean) {
      function both(f) {
        print(f("a"))
      }
      function ask(s) { return s }
      both(if c { inner } else { ask })
    }
    nested(true)
    // vl check: rc 1, undeclared identifier 'ask' at f("a")

Want:

    a

#### Mechanism

The tag decision builds a call through a tagged set as one direct call per member, by name
(`ftBuildArmsAt`, `mkIdent(name)`), at each call site through the set. `ftMemberSeenAtArms`
admits a nested member when every such site lies inside the member's parent body, but not that
the site comes after the member's declaration; a nested function is not hoisted, so the arm
`ask(...)` built inside `both` resolves to nothing. `ask` is in scope where the value is made.
