#### Mechanism

A call whose function hands back a list of literals is delivered as the list the literals are
built at. `recReturnedOrigins` served only a function with exactly one call site, so a second
call left the literal at its own row while each `sink` call expected `Circle[]`. A function
returning a record already served several sites through `recSitesLandAt`; the list arm now asks
the same rule. Two sites landing on different storages (`Circle[]` and `{ r: string | null }[]`)
are not served, and still build invalid wasm, as on master.
