### D2448 — a closure reading a narrowed module global of a value union is invalid wasm

**check-clean invalid wasm · clause 1 · filed 2026-09-25 against master `20651a88b`, found by the
review of #3150 · open**

Repro:

    let g: f64 | boolean = 1.5
    if g is f64 {
      const c = (): f64 => g * 2.0
      print(c())
    }
    // vl check: rc 0.  vl run: invalid module inside `c`: expected f64, found (ref $type)

#### Mechanism

Not yet ablated to the rung. The checker types `g` inside `c` at the narrowing live where `c` is
written; the lifted body reads the module global directly, as its declared box, and the
narrowing replay (`capNarrowRecord`) records only names the closure captures, which a module
global is not.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the closure (`print(g * 2.0)`) | prints `3` | **yes** |
| the box (`g: string \| null`, `g.length`) | runs | **yes** |
| the module level (the guard inside a function, `g` still global) | invalid the same | no |
