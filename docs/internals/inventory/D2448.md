### D2448 — a closure reading a narrowed module global of a value union is invalid wasm

**closed 2026-09-25 — the witness prints `3` · was check-clean invalid wasm, clause 1 · filed
2026-09-25 against master `20651a88b`, found by the review of #3150, closed against master
`be97589c0` · fixture `tests/cases/closures/capture-narrowed-global-and-cell.vl` · the index-cell
twin is [D2450](D2450.md), closed by the same change**

Repro:

    let g: f64 | boolean = 1.5
    if g is f64 {
      const c = (): f64 => g * 2.0
      print(c())
    }
    // vl check: rc 0.  vl run: prints 3

#### Mechanism

The checker types `g` inside `c` at the narrowing live where `c` is written. The emitter replays
that narrowing into the lifted body from `capNarrowRecord`'s table, and the table held only keys
that are captured names: `capRecord` drops a module global from the capture set, so the global's
narrowing was never banked and the lifted body read the global as its declared box.

The fix banks, per nested body, every narrowing key whose root the body reads — a captured name
or a module global (`cnGlobReads`, collected where `capRecord` drops the global) — and
`capNarrowSeed` replays a key rooted at a global, or any path under a capture, whole. A global
read in the lifted body is the same `global.get` the declaration site makes, so it takes the
same narrowing. A captured name keeps its gate: it replays only when its env field holds the box.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the closure (`print(g * 2.0)`) | prints `3` | **yes** |
| the box (`g: string \| null`, `g.length`) | runs | **yes** |
| the module level (the guard inside a function, `g` still global) | invalid the same | no |
| the narrowing form (`else` of `g is boolean`; a guard `if g is boolean { return }`) | invalid the same | no |
| the closure depth (a closure inside the closure) | invalid the same | no |
| a record union (`A \| B`, `g.a`) | loud emit reject, `field access but no struct type declared` | no — the same missing replay |

member now traps (`cast failure`) where it was invalid wasm; the local and field spellings of
that program already trapped on master. That is [D2402](D2402.md)'s defect, and its grading
