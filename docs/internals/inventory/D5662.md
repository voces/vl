### D5662 — a block-local function returning a generic, called at two types through two results, has no interned signature

**loud emit reject · `vl check` rc 0 · clause 2 · found closing [D5531](D5531.md) · filed 2026-10-17 against master `a9ede7d84`**

Repro:

    function k<T>(x: T): T { return x }
    function main() {
      function mk() { return k }
      const a = mk()
      print(a(1))
      const b = mk()
      print(b("s"))
    }
    main()
    // vl check: rc 0.  vl run: emitProgram: a function-value call has no interned signature — parameter 1 of type `` has no representation in the function-value ABI

Want:

    1
    s

#### Mechanism

From the ablation only. The module-scope spelling is D5531 and runs. Written by hand with a
second block-local `mk2` for the second call, it runs too. D5531's close declines a
block-local function: a copy inserted after it fails to build ("call to unknown function"), so
the copy is not resolved in the block's scope the way the original is.
