### D4088 — `r is B` in a generic body pinned at a record answers `false` when the value fits

**closed 2026-10-24 · the witness prints `true`, `true`, `true` · `emitRecordFitIs` (wasmEmit.vl) takes the operand's type through `nodeTyAt(recv, fnIx)`, so the pin `T = A` tests the value's fields instead of folding on the open `T` · every spelling in the grading list runs (the pin at `A | null` with `null`, `{ x: 2 }` and `{ x: 5 }`, and the then-arm read of `r.x`) · fixture `tests/cases/generics/record-field-literal-is-at-generic-instance.vl` · was check-clean silently wrong value · clause 1 · found reviewing the D4058 close (#3549) · filed 2026-10-11 against master `5a9535c91`**

Repro:

    type A = { x: i32 }
    type B = { x: 1 | 2 }
    function fits<T>(r: T): boolean { r is B }
    function direct(r: A): boolean { r is B }
    const a2: A = { x: 2 }
    const bb: B = { x: 1 }
    print(direct(a2))
    print(fits(a2))
    print(fits(bb))
    // vl check: rc 0.  vl run: rc 0, prints true, false, true

Want:

    true
    true
    true

#### Mechanism

The direct spelling reads the field and answers `true` for `{ x: 2 }`. The generic body pinned
at `T = A` answers `false`, so the pin is not routed through the value-fit rung
(`emitRecordFitIs`) and folds instead. Wrong on base as well, where `direct` already answered
by the declared type.

#### Ablation

| variant | outcome |
| --- | --- |
| generic pin `T = A`, value `{ x: 2 }` (the repro) | `false` (wrong) |
| generic pin `T = B` | `true`, correct |
| direct `r: A` | `true`, correct |

#### Grading list

The pin at `A | null`, and a then-arm read `if r is B { … r.x … }` in the generic body.
