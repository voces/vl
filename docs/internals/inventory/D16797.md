#### Mechanism

`exprListRep` (`emit_classify.vl`), behind every `expr*Array` predicate, read the Paren node's
type, which the instance's elaboration does not record. It now peels the parentheses, so the
`??` it wraps answers at its elaborated `i32[]`.
