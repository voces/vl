### D14752 — two same-tag record arms keep a literal-set field at the string rep, so the set arm has a second layout

**runs, prints its seven lines — CLOSED 2026-11-01 by ruling: a layout family stores a literal-set field at the join of its twins, so `A`'s struct row stores `kind` at the string too and `A` has one layout (`famRelayField`, DECISIONS.md "A layout family stores a literal-set field at the join of its twins") · was a refutation pin for deleting the same-tag demotion, which stays · the residue of [D14746](D14746.md) · filed 2026-11-01 against master `cd15b5eb`**

Repro:

    type K = "circle" | "round"
    type A = { kind: K, r: i32 }
    type B = { kind: string, r: i32 }
    function mk(i: i32): A | B {
      if i == 0 {
        const a: A = { kind: "round", r: 1 }
        return a
      }
      if i == 1 { return { kind: "zzz", r: 2 } }
      { kind: "circle", r: 3 }
    }
    let i = 0
    while i < 3 {
      const v = mk(i)
      print(v.kind)
      if v is A { print("A " + v.kind) } else { print("B " + v.kind) }
      if v.kind == "round" { print("is round") }
      i = i + 1
    }

Want:

    round
    A round
    is round
    zzz
    B zzz
    circle
    A circle

#### Mechanism

`A` and `B` have one field-name set with the same storage outside `kind`, so they share one tag
and one layout, and `is A` tells them apart by `kind`'s value. That shared layout holds
`kind` at the string, because `B`'s plain `string` has no interned id. `A` built on its own
stores `kind` at the atom, so `A` has two layouts: its own, and the shared arm's. Without the
demotion the two arms keep different layouts under one tag, and the read casts a `B` to `A`'s
heap type. Giving `A` one layout here needs the pair laid out apart under two tags, with `is A`
still deciding by value.

Splitting the tags is not enough on its own, measured 2026-11-01. Keeping only two atom-set rows
tag-equal in `variantRowsTagEqual` (a set beside its `string` base gets its own tag) and
deleting the same-tag demotion keeps this witness running except at its last value, and traps
the program below with `cast failure`. `B` narrowed by `kind` in `K` is structurally `A`, so the
checker types the then-arm of `x is A` as `A`, and every consumer there (the read `x.kind`, the
argument `useA(x)`, the binding `const y: A = x`) casts to `A`'s layout while the `is A` test
also admits `B`-tagged values. With `B.r: i32 | string` the narrowed type stays a union and the
read dispatches, which is why D14746's two-tag case runs. Closing this row therefore needs the
narrowing itself to deliver `A`'s layout, by converting a `B` value at the `is` or dispatching at
every narrowed consumer.

    type K = "circle" | "round"
    type A = { kind: K, r: i32 }
    type B = { kind: string, r: i32 }
    function useA(a: A) { print("useA " + a.kind) }
    function f(n: i32): A | B {
      if n == 0 {
        const a: A = { kind: "circle", r: 1 }
        return a
      }
      if n == 1 { return { kind: "zz", r: 2 } }
      const b: B = { kind: "round", r: 3 }
      b
    }
    let i = 0
    while i < 3 {
      const x = f(i)
      if x is A {
        useA(x)
        const y: A = x
        print(y.kind)
      } else { print("B " + x.kind) }
      i = i + 1
    }
