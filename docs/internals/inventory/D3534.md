#### Mechanism

A prediction until a close confirms it: the template types `[a, b, 2.5]` over `A | B` and a literal, and the pin re-joins that union's
members (`rejoinMembers`) one at a time with one apart flag for all of them. It cannot tell the
literal's member from a runtime one, so for `(f32, f64)` beside `5` it would part an `i32` member
the instance's own re-check of the literal (which adapts `5` into the join) never makes. Joining
apart there turned 42 of the twin grid's running generic- and hole-body cells into invalid wasm
and 2 into traps, while 26 that are invalid wasm on master ran. `listJoinApart`
therefore keeps master's widening for a literal element in any function `njFnOpen` names (one
with a type parameter or an un-annotated parameter); without a literal element the same body
joins apart. The `match`-spelled twin of the witness is invalid wasm on master, which is the
literal-arm-at-a-pin family [D3495](D3495.md) holds back.
