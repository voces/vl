### D16815 — a maker's two call bindings at two pins, the wider pin called first or the lambda bound to a local before it is returned, give the later call's closure an open parameter

**open · loud emit reject · clause 2 (`vl check` rc 0) · the order and local-binding residue of [D16799](D16799.md), in the un-annotated maker and the generic one alike · cells `two_pins_f64_first` and `lambda_bound_first` of `maker-generic-at-two-results.matrix.vl` · filed 2026-11-16 against master `05e6da185`**

Repro:

    function adder(n) { return (a) => a + n }
    const x = adder(1.5)
    print(x(2.0))
    const v = adder(2)

#### Mechanism

Not traced. Each binding of a maker call is typed at the pins its call made (`makerCallLamRet`,
D16798), but the closure the later call reads still holds a parameter the elaboration left open
when the earlier, wider pin was built first, or when the lambda was bound to a local before being returned.
