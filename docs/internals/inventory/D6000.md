### D6000 — a module binding of a hole function returned through a hole, called at a second type inside a function, is lowered at the function's other instance

**check-clean invalid wasm · clause 1 · found closing [D5972](D5972.md) · the same on master `200c89ff8` · filed 2026-10-17 against master `200c89ff8`**

Repro:

    function fw(f) { return f }
    function id(x) { return x }
    print(id(3))
    function g() {
      print(q("v"))
    }
    const q = fw(id)
    g()
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `g`: type mismatch: expected i32, found (ref $type)

Want:

    3
    v

#### Mechanism

From the ablation only. A read of `q` inside a function finds no signature of its own for
`fw(id)`; when `id` has another instance (`id(3)`), the call is lowered at that instance's
`i32` signature, and with none the call refuses. A function-local `const q = fw(id)`, or a
read at module scope, runs.
