### D15117 — a record field written one un-annotated function, then read and called at two types, is refused at emit

**open · loud emit reject · `emitProgram: cannot take the generic function id0 as a value — a function value carries ONE signature` · clause 2 · the field read without the write runs · found grading D15116 · filed 2026-11-04 against master `e394c738d`**

Repro:

    function id0(a) { return a }
    const r = { f: id0 }
    r.f = id0
    const g = r.f
    print(g(2))
    print(g(2.5))

Want:

    2
    2.5

#### Mechanism

Not yet ablated past the grid. The write `r.f = id0` is the record-field spelling of the slot
write D15116 closed for a map and a list. `ftCtxOk`'s store arm asks a list or map holder's slot
through `ftSlotHoldsSet`, and has no arm for a field: `ftHoldKind` answers 2 for any record with a
field of any kind, so it cannot say which field holds the set. Two members refuse the same way.
