### D6301 — a generic handed to a hole parameter nothing reads has no instance when its body does not fit `i32`

**loud emit reject · `vl check` rc 0 · clause 2 · found closing [D6213](D6213.md) · the same on master `2ffbe1ed5` · filed 2026-10-18 against master `586fb1cf6`**

Repro:

    function outer(g) { return 4 }
    function len(a) { return a.length }
    print(outer(len))
    // vl check: rc 0.  vl run: emitProgram: '.length' on a receiver the emitter cannot classify as a list, string, map or set

Want:

    4

#### Mechanism

From the ablation only. A function handed to a parameter nothing reads takes an `i32` default
instance ([D6213](D6213.md) for a declared function, [D6112](D6112.md) for a lambda). Nothing
calls it, so any instance its body admits would do, but only `i32` is tried. A body that needs a
list, a string or another type has no instance.
