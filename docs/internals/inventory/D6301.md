### D6301 — a generic handed to a hole parameter nothing reads has no instance when its body does not fit `i32`

**closed 2026-10-18 by lane L3 · runs, prints `4` · was loud emit reject · clause 2 · a function handed to a parameter nothing reads takes the first of `i32`, `i32[]` and `string` its body checks clean at (`unreadHoleDefault`), with a result its parameters leave open read off its constraints; a declared function, a `const` lambda and a lambda literal alike, and a lambda literal no call instances takes the pin in emit · pins: `tests/cases/functions/hole-fn-to-unread-param-default.vl` (`.length`, an index, a push, a string join, a `const` lambda and two literals) · `.push` on a string argument passing check is filed as [D6332](D6332.md) · found closing [D6213](D6213.md) · filed 2026-10-18 against master `586fb1cf6`**

    function outer(g) { return 4 }

    // was: vl check rc 0.  vl run: emitProgram: '.length' on a receiver the emitter cannot classify as a list, string, map or set

#### Mechanism

From the ablation only. A function handed to a parameter nothing reads takes an `i32` default
instance ([D6213](D6213.md) for a declared function, [D6112](D6112.md) for a lambda). Nothing
calls it, so any instance its body admits would do, but only `i32` is tried. A body that needs a
list, a string or another type has no instance.
