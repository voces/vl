### D15188 — an un-annotated binding holding a container read built wider, reassigned with a record literal, is check-clean invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · open, target `7` then `4` · found closing [D15185](D15185.md), whose fixture reassigns a binding holding a generic's hand-back result and runs · the [D15124](D15124.md) shape with one reassignment · filed 2026-11-03 against master `4a6b0a73`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const xs = [mk()]
    let b = xs[0]
    b = { f: 7 }
    print(b.f)
    print(wideJ.f ?? 0)

Want:

    7
    4

#### Mechanism

`b` holds an element of `xs`, whose build stores it at `J`, so its cell is `J`'s row; the
assigned literal is built at its own `{f: i32}` and the local.set does not validate. D15185
builds such a literal at the binding's record (`recAsgBuiltRep`), which serves a binding holding
a hand-back call's result, but not this one: the container read's build is not yet known where
the assignment is checked.
