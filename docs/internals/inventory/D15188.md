### D15188 — an un-annotated binding holding a container read built wider, reassigned with a record literal, is check-clean invalid wasm

**closed 2026-11-04 · runs, prints `7` then `4` · was check-clean invalid wasm · `vl check` rc 0 · clause 1 · found closing [D15185](D15185.md) · the [D15124](D15124.md) shape with one reassignment · filed 2026-11-03 against master `4a6b0a73` · closed by building a record literal assigned into a binding held at a built read at that record in `recListLitBuild`'s pass-end sweep, where the container's build is known; the assignment-seam call D15185 added is deleted · fixture `tests/cases/soundness/binding-holding-built-read-reassigned-with-literal-runs.vl` · a list literal is [D15189](D15189.md)**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const xs = [mk()]
    let b = xs[0]
    b = { f: 7 }
    print(b.f)
    print(wideJ.f ?? 0)

Want:

    7
    4

#### Mechanism

`b` holds an element of `xs`, whose build stores it at `J`, so its cell is `J`'s row; the
assigned literal was built at its own `{f: i32}` and the local.set did not validate. D15185
built such a literal at the binding's record (`recAsgBuiltRep`) at the assignment, which served a
binding holding a hand-back call's result but not this one: the container read's build is not
known until the pass is over. The stamp now runs there, once, for both.
