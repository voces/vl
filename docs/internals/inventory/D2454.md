### D2454 — a bare `null` argument to a lambda's nullable parameter has no heap type

**loud emit reject · clause 2 · pre-existing on master `20651a88b` · filed 2026-09-25 against master `20651a88b`, found reviewing #3154**

Repro:

    const f = (s: string | null) => {
      if s != null { return 1 }
      0
    }
    print(f(null))
    // vl check: rc 0.  vl run: emitProgram: bare null needs a struct-typed context

#### Mechanism

Not ablated. A value call seeds a `null` argument from the parameter's signature token only for
the kinds its argument arms name; a `string | null` or `i32[] | null` parameter of a lambda
bound to a `const` takes no seed, so the `null` literal has no context to pick a heap type
from. [D2399](D2399.md) seeds the distinct-backing nullable lists; the niche kinds are this row.

#### Ablation

| ingredient removed | outcome on `20651a88b` | needed? |
| --- | --- | --- |
| the `null` argument (`f("a")`) | prints `1` | **yes** |
| `string \| null` for `i32[] \| null` | still refuses | no |

#### Grading list

`S | null`, `i32[] | null`, `string | null` and `boolean | null` parameters, each passed `null`.
