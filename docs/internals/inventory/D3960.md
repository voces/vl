Repro:

    function inner<U>(u: U) { print("I"); print(u) }
    function q(n: i32) { print("Q"); print(n) }
    function main() {
      let k = inner
      k = q
      k(true)
    }
    main()
    // vl check: rc 0.  vl run: prints `Q` then `1`; with `k("s")` it traps, indirect call type mismatch

#### Mechanism

`let k = inner` binds `k` at `(U) => void`, and a type parameter is gradual, so the write
`k = q` of an `(i32) => void` was accepted and every later call through `k` was checked against
`(U) => void` at whatever type it passed. The binding holds one function at a time (the emitter
already refuses one called at two types), so after the write a call at `boolean` reached `q`.

The checker now marks a `let` seeded with a function value that has a type variable of its own,
a declared generic or a hole lambda (`fsbMark`). The first write of a function whose only type
variables are the enclosing generic's fixes its type, and a later write must fit it
(`fsbNoteStore`). Every call through the binding and every delivery of it, including a record
literal's field and a list literal's element, is graded against that type, and uses checked
before the write are re-graded when it is seen. An un-annotated alias takes its source's type
until a write of its own replaces it; a write to the alias never types the source. A module
`let` gets its row before the walk (`fsbScanModLets`), so a function declared above it is
graded too; there a literal, a name or a named call's result is the only argument typed. A
literal argument is graded by its own value (`fsbLitFits`), as at a direct call. A pair naming the enclosing type parameter is re-asked at each instance
(`noteLetCstr`). Refusals are reported at the end of the walk, and one on a line another check
already refused is dropped. This is the literal-binding ruling's shape for a function value: a
`let` is typed by what is stored in it.
