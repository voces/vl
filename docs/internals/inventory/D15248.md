#### Mechanism

`recCoalesceHeldInit` (check_fit_rules.vl) takes a default binding only where it is an
un-annotated `const`: a `let` may be reassigned, so building it at the read's record would also
have to build every value written to it there. Nothing refuses it either, so the join is handed a
record of the binding's own row. The call spelling (`let d = mk2()`) behaves the same.
