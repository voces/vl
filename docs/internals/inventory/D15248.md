### D15248 — a `??` default held in a `let` is not built at the read's record, as a `const` default is

**open · check-clean invalid wasm · `type mismatch: expected (ref null $1), found (ref $5); $1 is J` · clause 1 · the `const` spelling runs (D15217, D15240) · found grading D15240 · filed 2026-11-04 against master `ddb0573bc`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const m = Map()
    m.set("a", mk())
    const wm: {[string]: J} = Map()
    wm.set("a", mk())
    let d = { f: 1 }
    const b = m.get("a") ?? d
    print(b.f)

Want:

    4

#### Mechanism

`recCoalesceHeldInit` (check_fit_rules.vl) takes a default binding only where it is an
un-annotated `const`: a `let` may be reassigned, so building it at the read's record would also
have to build every value written to it there. Nothing refuses it either, so the join is handed a
record of the binding's own row. The call spelling (`let d = mk2()`) behaves the same.
