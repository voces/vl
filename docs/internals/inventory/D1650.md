### D1650 — a string accumulator in a STRUCT FIELD is quadratic: the loop-local accumulator lowering reads the BINDING FORM, so the same loop is linear as a `let` and O(n²) as `b.s`

**runs today and must keep running · filed 2026-09-05 against master `63c4a721`**

Repro (runs, prints `400000`):

    type Box = { s: string }
    function build(n: i32): string {
      let b: Box = { s: "" }
      let i = 0
      while i < n { b.s = b.s + "0123456789abcdefghij"; i = i + 1 }
      return b.s
    }
    print(build(20000).length)
    // vl check: rc 0.  vl run: 400000, and 0.30 s CPU against 0.02 s for the same
    //           loop written with a local `let s = ""` accumulator.

#### Mechanism

`strAccScan` / `emitStrAccAppend` (compiler/wasmEmit.vl) recognise `s = s + piece` in a loop
where `s` is a loop-local BINDING and lower it to an append into a growable backing, which is
what makes the append arm of `tests/vl_scaling_shape_test.ts`'s `string append loop` axis
linear. The recogniser is keyed on the binding form, so `b.s = b.s + piece` — the same
statement with the accumulator living in a struct field — falls to the general concatenation
path: every iteration allocates an exact-fit backing and copies the whole prefix again.

The status line says the witness RUNS because it does, and correctly: this is a COST defect,
not a wrong answer. What must keep running is the program; what should change is what it
costs. A module-level global accumulator is the same shape and the same cost, so the fix is
one recogniser reading a wider set of destinations, not two.

The cost class, minimum CPU of three `vl run`s each, 2026-09-05:

| n | struct field | local `let` |
| ---: | ---: | ---: |
| 10,000 | 0.10 s | 0.02 s |
| 20,000 | 0.30 s | 0.02 s |
| 40,000 | 1.69 s | 0.04 s |

Doubling n multiplies the field arm by 3.0 then 5.6 (3.5 and 6.0 net of the ~0.02 s process
floor) and leaves the local arm at the floor — super-linear against linear, which is the
class, and the same class `string append loop` was filed to catch on the local spelling.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the accumulator is a local `let` rather than `b.s` | 0.02 s at 20,000 — linear | **yes** |
| the accumulator is a module-level global | 1.85 s at 40,000 — same cost class | no |
| `n` halved | cost falls ~4x, not ~2x | **yes** (it is the n² term) |
