#### Mechanism

The slot fact closes a function leaf from the calls that read the slot (`fnSlotCallNote`, through one `const` copy) or, failing that, from one call tuple its function set agrees on. Here the record's `f` is reached only through a binding of the map's value and called at two types, so the slot has no tuple of its own and the set's two disagree; only the flow table's union-find over parameters, returns and aliases ties those calls to this slot, and mono reads it. A reader-2 shadow over the 36 files holding such slots (non-halting, a control comparison reading DIFF 105 of 105) graded 23 agree, 0 disagree, and 82 where mono answers and the fact has none: about 27 whose writes run through parameters or handles the elaboration's write scan does not follow, about 35 called with no tuple of the slot's own and the set's disagreeing, and about 6 storing a value that is not a function's name. By path the 82 are 40 map values (`v`), 35 list elements (`e`) and 7 record fields. Refusing the pin on map-value paths alone moves 25 `@run` files under `tests/`, and split by spelling and delta-debugged they are three mechanisms, not one map position: 17 are called slots whose calls reach them only through parameters, returns or aliases; 8 are carried by the uncalled default alone, of which 5 store a generic called elsewhere, so the slot is uncalled while its set is not and only per-slot evidence says so (reading the slot fact there keeps the 3 hole-function files and moves those 5); and a `??` default against a declared non-member keeps a whole set untagged ([D15299](D15299.md)). A record stored as a map value (`o["k"] = { f: inc0 }`, read `ov.f(3)`) runs with the pin refused, so the six files whose first tag refusal is such a store are not shown to be the parked field-chain question; they are graded with this row. When a function value's identity is its type, the checker's ordinary typing carries these calls, and the slot's uncalledness, to the slot, and `monoStoredSlotFnTy`'s pin ladder and the flow table's per-path pins can go.
