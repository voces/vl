### D17580 — a spread copy of a list holding a generic function, built as a record field in a generic instance, keeps the source's closure signature, so the second instance's call through it traps

**trap after load · clause 1 · found by COV-CLOS's Q58 spread sweep · filed 2026-11-25 against master `7aacbeac`**

Repro:

    function id<T>(x: T): T { return x }
    function pField<T>(x: T) {
      const src = [id]
      const r: { fs: ((x: T) => T)[] } = { fs: [...src] }
      print(r.fs[0](x))
    }
    pField(4)
    pField("u")
    // vl check: rc 0.  vl run: prints 4, then wasm trap: indirect call type mismatch

Want:

    4
    u

#### Mechanism

The record field's spread literal is a copy of `src`, a list holding `id`. In the second instance
(`T = string`) the copy's element is still `id`'s closure at the first instance's signature, so the
call through `r.fs[0]` takes the wrong `call_indirect` type. The same program built claimless traps
identically, so the IR's claim does not cause it. Not ablated into the emitter further.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `{ fs: src }`, no spread | runs | **yes** |
| the spread bound to an annotated `const fs` instead of a field | runs | **yes** |
| only one instance, `pField(4)` | runs | **yes** |
