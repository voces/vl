#### Mechanism

`monoStaticIsResult` (`compiler/wasmEmit.vl`) answers through `isTestAnswer` (D15252) when the
`is` node has a banked tested type. When it has none, a pin bound to a function signature key
(D951) answers `sk == isVariant`, the key against the pattern's substituted text. A tested type
banked at the minted node would let `isTestAnswer` answer it.
