#### Mechanism

`monoStaticIsResult` (`compiler/wasmEmit.vl`) answers through `isTestAnswer` (D15252) when the
`is` node has a banked tested type. When it has none, a pin bound to a function signature key
(D951) answers `sk == isVariant`, the key against the pattern's substituted text. A tested type
banked at the minted node would let `isTestAnswer` answer it.

#### Close

`monoSubstIsExpr` (`compiler/emit_mono.vl`) banks the minted node's tested type by substituting
the instance's exact bindings into the original's `isVarTyIx`, where the substituted spelling is
a signature key. `monoStaticIsResult` then answers through `isTestAnswer` like every other pin,
and its `sk == isVariant` arm is deleted. The fallback is scoped to a signature key: unscoped, it
banked a type for an unbound type parameter
(`tests/cases/generics/unbound-type-param-reaching-is-stays-unbound.vl`), which then ran instead
of keeping its D4551 refusal. Fixture: `tests/cases/generics/is-type-parameter-at-signature-pin.vl`.
