### D14644 — a record literal stored into an un-annotated map built at a wider record keeps its own row

**closed · now runs, prints `5` then `4` · was check-clean invalid wasm · filed 2026-10-29 against master `4b53baaec` · closed 2026-10-31 against master `54db9267` by deleting the `recReadInPlace` term · fixture `maps/unannotated-map-stores-literal-beside-aliased-call-built-at-wider-record.vl`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    function main() {
      const wideJ: J = mk()
      const m = Map()
      const a = mk()
      m.set("a", { f: 4 })
      const x = m.get("a")
      if x != null { print(x.f + 1) }
      print(wideJ.f ?? 0)
    }
    main()
    // vl check: rc 0.  vl run: expected (ref $J), found (ref $#anon1)

#### Mechanism

The unused binding `a = mk()` makes the map's value struct `J` (the shape D14643 reads), but the
literal `{ f: 4 }` stored by `m.set` is built at its own row `#anon1` and not converted to `J` at
the store. It is the same at module scope: the module-scope spelling of this witness is invalid
wasm too (`expected (ref null $J), found (ref $#anon1)`), on master and on every compiler since
D14643. `tests/cases/maps/unannotated-map-stores-literal-and-call-built-at-wider-record.vl`, which
runs, stores the call through the binding as well as the literal.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the enclosing function (module scope) | still invalid wasm | no |
| `const a = mk()`, a binding of the call that is never stored | runs | **yes** |
| `m.set("a", { f: 4 })` stores `a` instead | runs (D14643) | **yes** |
