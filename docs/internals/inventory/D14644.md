### D14644 — a record literal stored into an un-annotated local map built at a wider record keeps its own row

**check-clean invalid wasm · filed 2026-10-29 against master `4b53baaec`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    function main() {
      const wideJ: J = mk()
      const m = Map()
      const a = mk()
      m.set("a", { f: 4 })
      const x = m.get("a")
      if x != null { print(x.f + 1) }
      print(wideJ.f ?? 0)
    }
    main()
    // vl check: rc 0.  vl run: expected (ref $J), found (ref $#anon1)

#### Mechanism

The unused binding `a = mk()` makes the map's value struct `J` (the shape D14643 reads), but the literal `{ f: 4 }` stored by
`m.set` is built at its own row `#anon1` and not converted to `J` at the store. At module scope
the same program runs (`tests/cases/maps/unannotated-map-stores-literal-and-call-built-at-wider-record.vl`),
so the store's converting path is reached for a global map and not for a local one.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the enclosing function (module scope) | runs | **yes** |
| `const a = mk()`, a binding of the call that is never stored | runs | **yes** |
| `m.set("a", { f: 4 })` stores `a` instead | runs (D14643) | **yes** |
