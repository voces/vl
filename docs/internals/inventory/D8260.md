### D8260 — a record stored into an un-annotated `Map<string, J | string>()` has no union row to box into

**loud emit reject · clause 2 · open · present on master `8d9a182a7` · found ablating [D8145](D8145.md) (its map-read position) · filed 2026-10-20 against master `8d9a182a7`**

Repro:

    type J = { r: i32 }
    const q: J = { r: 5 }
    const m = Map<string, J | string>()
    m.set("a", q)
    print(m.has("a"))
    // vl check: rc 0.  vl run: emit error, "a record value delivered into a union box this program never registered has no tag"

Want:

    true

#### Mechanism

Not localised past the ablation. The union is spelled only as the constructor's type
argument, and no collect pass registers a row for it, so the `set` that boxes the record finds
no tag. The annotated binding `const m: Map<string, J | string> = Map()` registers it and runs.

#### Ablation

| --- | --- | --- |
| `const m: Map<string, J \| string> = Map()` | prints `true` | **yes**, the type argument as the only spelling |

| `J`'s field `r: i32 \| null`, read by `??` after `is J` | the same emit reject | no |

#### Grading list

The `is J` read of `m.get("a")` at both the bare-variable and the inline-literal store.
