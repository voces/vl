### D7764 — a forward maker of a generic, checked inside its caller's body, has no interned signature

**runs today and must keep running · prints `1` · only reachable with `inferReturnsPrePass`'s whole-module sweep narrowed to recursion groups and pass 2 not ordering a pending callee first, where it is `loud emit reject` (`a function-value call has no interned signature — parameter 1 of type ``…`) · clause 2 · pin: `tests/cases/closures/forward-maker-of-generic-checked-first.vl`, and the three `closures/` fixtures of D5663, D5970 and D5971 · filed against master `573358403`**

Repro:

    function k<T>(x: T): T { return x }
    function one() {
      const a = mk()
      print(a(1))
    }
    function mk() { return k }
    one()

Want:

    1

#### Mechanism

From the ablation only. Without the pre-pass sweep, `mk`'s return is still pending when
`one` is checked. The call `mk()` then demand-infers it, so `mk`'s body gets its real check
nested inside `one`'s. The emitter later finds no signature for the call through `a`: its
callee keeps `k`'s generic parameter. The state that differs inside the nested check was not
located. Pass 2 now checks a later-declared function first when its return is still pending,
just as it already did for an unsettled write summary (`progCheckCalleeFirst`). That keeps the
check at the top level, so the nested check is reached only inside a recursion group.

#### Ablation

Sweep narrowed, without the pass-2 ordering. Master runs every row.
