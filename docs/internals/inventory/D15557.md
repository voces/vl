### D15557 — a bound record holding a list of functions, returned beside a record literal of another set, builds the literal at a sibling row

**open · check-clean invalid wasm · clause 1 · the same pair as a list of records runs since [D15555](D15555.md) · found closing D15555 · filed 2026-11-08 against master `ea3c74ca`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function pick(b) {
      const a = { fs: [inc0] }
      if b { return a }
      return { fs: [dbl] }
    }
    print(pick(false).fs[0](3))
    print(pick(true).fs[0](3))

Want:

    6
    4

#### Mechanism

Both records hold `fs` as the same `i32` list of ids, but the returned literal is built at a struct row of the same layout on another heap (`$3`) where the function's result is the bound record's (`$2`). D15555 closed the list-element twin of this in `arrRefElemTwinRow`; the return delivery of a record has no such step.
