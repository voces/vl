### D15130 — a `const` copy of a hole parameter holding a written binding of generics, pushed onto a list of a closed function type, is invalid wasm

**closed 2026-11-03 · runs, prints `1` · was check-clean invalid wasm, clause 1, `type mismatch: expected (ref $4), found i32` inside `__take` · `ftParamStored` (check_fn_tag.vl) counts a `const` copy of the parameter (`fnTagParamCopyOf`) stored into a holder as the parameter stored, so the set stays a closure as it does for `__ys.push(a)` · fixture `tests/cases/closures/written-binding-of-generics-param-copy-stored-in-closed-holder.vl` · the matrix cell's residue, an inferred list spread with no copy, is D15131 · filed 2026-11-03 against master `6c4f4444`**

#### Mechanism

The call hands the written set `{__id, __k}` to `__take`'s un-annotated parameter. The tag
decision refuses tagging when the body stores a read of that parameter into a holder
(`ftParamStored`), but it matched only reads of the parameter itself, so the copy `v` let the set
be tagged and its i32 id was stored where the closed slot expects a closure.
