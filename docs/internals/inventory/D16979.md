#### Mechanism

The maker is built at `K` (D15719), so the call yields `(ref K)`, and the record solve stamps the
`if` as built at `K`. Its checked type is still the union of the call's literal records and the `K`
literal, which has no ref rep, so `ifExprRefKindOf` answered nothing and the block type fell to
`i32`. An `else if` chain with the maker called in two links is a separate face, D16982.
