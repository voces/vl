### D6543 — an un-annotated lambda handed through a hole to a declared generic's `(T) => U` parameter is refused at emit

**loud emit reject · clause 2 · `vl check` rc 0 · the direct call runs and prints `3` · found closing [D6540](D6540.md) · filed 2026-10-18 against master `fc3856155`**

Repro:

    function app<T, U>(f: (T) => U, v: T): U { f(v) }
    function via(a) {
      print(a((n) => n + 1, 2))
    }
    via(app)
    // vl check: rc 0.  vl run: emitProgram: a function-value call has no interned signature — the callee has no function type to key a signature from

#### Mechanism

From the ablation only. The lambda's parameter is open when the hole's call is read, so `T`
and `U` are not bound from it, and the later argument `2` is not used to bind them either; no
instance of `app` is bound and the emitter has no signature for it.
