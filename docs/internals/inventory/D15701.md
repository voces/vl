Repro:

    function dbl(v) { return v + v }
    function cf(r, x) { return r.f(x) }
    function bothF(g) {
      print(g(1.5))
      return cf({ f: g }, 2.5)
    }
    function bothD(g) {
      print(g(1.5))
      return cf({ f: g }, 2.5)
    }
    print(bothF(dbl))
    print(bothD(dbl))

Want:

    3
    5
    3
    5

#### Mechanism

`{dbl}` is tagged, and `cf` has one instance, at the record of `{dbl}`'s id. Each literal is
built at an anonymous row its own instance mints (`mintPinnedObjLit`). `bothF`'s literal minted
it and aliased its record type there; `bothD`'s record type is a second type index that is
`tySame` but not aliased, so it minted a second row of the same layout. `cf` takes the first,
and `bothD`'s `call $cf` hands it the second.
