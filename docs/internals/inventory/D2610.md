Repro:

      const m: {[string]: i32 | string} = Map()

#### Mechanism

After a write that leaves a narrowed cell's member, the checker re-narrows the cell to the
member stored (D1847), and the emitter's index arm pushes the same member through
`pushNarrowWriteReNarrow`, which needs the element union's registered name. A list cell has one
(`indexElemUnionName`); a map cell has none, so nothing was pushed and the read lowered the box
where the checker had typed an `i32`. The close pushes the member's type for a key that names no
union spelling, as an `is` test of the cell does (`pushNarrowWrittenTy`: a primitive by its
name, a struct by its registered variant). A write of the whole union also leaves the key
present, so the cell reads as the union rather than the map read's `T | null`.
