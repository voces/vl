### D3910 — a parameter named like a function declared in an enclosing scope fails a generic call it is passed to

**loud emit reject · found reviewing #3480/#3481 · filed 2026-10-09 against master `097937914`**

Repro:

    function f<U>(u: U) { print("top f"); print(u) }
    function c<V>(v: V) { print(v) }
    function b(f: i32) { c(f) }
    b(5)
    // vl check: rc 0.  vl run: emit error, `monomorphize: unsupported argument type for 'v' in a call to 'c'`

Want:

    5

#### Mechanism

Not located. The argument `f` is a parameter of type `i32` that shadows the function `f`, and
`V` should bind to `i32`; the refusal says the monomorphizer met an argument type it cannot
instantiate, which is what a function type would be. A non-generic `c` runs, so the parameter's
own type is right and only the generic call's argument typing is affected.

#### Ablation

direction of the same name collision).
