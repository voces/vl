### D3902 — an alias of a capturing nested generic passed as a value, in an enclosing generic instantiated twice, builds invalid wasm

**check-clean invalid wasm · found closing D3887 · filed 2026-10-09 against master `9170959d8`**

Repro:

    function call(f: (n: i32) => void) { f(1) }
    function outer<T>(x: T) {
      function inner<U>(u: U) { print(x); print(u) }
      const k = inner
      call(k)
    }
    outer(7)
    outer("s")
    // vl check: rc 0.  vl run: invalid module

Want:

    7
    1
    s
    1

#### Mechanism

Not located. D3887's close renames the alias's initializer to the frame's instance at the first
call through the alias. With no call through it, the value keeps the first `outer` instance's
closure, whose env holds `x` at that instance's type.

| --- | --- | --- |
