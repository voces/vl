### D6441 — a call writing the map key `,x,` retires the narrowing of the unrelated name `x` in the emitter

**closed 2026-10-18 by lane L5 · runs, prints `2` · was check-clean invalid wasm, `type mismatch: expected i32, found (ref $type)` inside `run` · clause 1 · the capture and narrowing banks are string lists rather than comma-joined strings · pin: `tests/cases/maps/comma-key-call-keeps-name-narrowing.vl` · filed 2026-10-18 against master `066d19373`**

Repro:

    const m: {[string]: i32 | null} = Map()
    m[",x,"] = 2
    function clr() { m[",x,"] = null }
    function run(x: i32 | null) {
      if x != null && m[",x,"] != null {
        clr()
        print(x + 1)
      }
    }
    run(1)
    // vl check: rc 0.  vl build: the emitted module failed to validate inside `run`

#### Mechanism

The after-call retire bank held `,m[",x,"],`, and the emitter's comma split of it produced the
fragment `x`. The emitter retired the narrowing of the parameter `x`, which the checker still
held, so `x + 1` was emitted over the boxed value. Master before `066d19373` printed `2`: its
write summaries did not see the comma key's write at all, which hid this and kept D6440.
