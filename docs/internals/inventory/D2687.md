### D2687 — each call of an inferred-return function rebuilds the calling function's whole let plan

**open — runs today and must keep running · the defect is its cost: in a caller of `n` statements each calling a different function whose list return is inferred, the build is quadratic in `n` (+3.2G fuel at n=800, about 4M per call, against +0.58G linear when each call sits in its own small caller) · filed 2026-09-26 against master `f8709e41c`**

Repro:

    function f0(n: i32) {
      const out: i32[] = [n, n + 1]
      out
    }
    function f1(n: i32) {
      const out: i32[] = [n]
      out
    }
    function main() {
      let total = 0
      total = total + f0(1).length
      total = total + f1(2).length
      print(total)
    }
    main()
    // prints 3; every `fK(…).length` rebuilds `main`'s plan after asking about `fK`'s body

#### Mechanism

The emitter's per-function let plan (`plBuildLetMap`, compiler/emit_base.vl) is a
single-entry cache keyed on the body block (`plCacheBlock`). Emitting a call to a function
whose return is inferred asks about the CALLEE's return binding —
`unionNameOfIdentAt`/`parentLetOfAt` from `exprIsI64`, `exprIsF64`, `exprString`,
`listOpRepOf`, and `identIsBoundClosure`/`parentLetOfSid` from `emitArrLen` — which builds the
callee's plan and evicts the caller's; the caller's next question rebuilds it, an
O(caller) walk per call. The guest profile of the n=400 program puts `plScanStmt` at 16.6%
self, all of it under `plBuildLetMap < parentLetOfAt`/`parentLetOfSid` from those askers.
Not the same mechanism as [D2685](D2685.md). A fix keeps a second built plan (the tables are
array references, so a swap is O(1) per table), or answers a callee's return binding without
building its plan.

#### Ablation

Fuel of one `vl build`; `n` callees of 8 sibling blocks with annotated list bindings, one
call each (the repro scaled up; candidate seed of [D2685](D2685.md)):

| spelling | n=200 | n=400 | n=800 |
| --- | ---: | ---: | ---: |
| return annotated, one caller | 0.93G | 1.87G | 3.80G |
| return inferred, one caller | 1.23G | 2.81G | 7.02G |
| return annotated, a wrapper per call | 0.95G | 1.93G | 3.94G |
| return inferred, a wrapper per call | 1.07G | 2.19G | 4.52G |

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the inferred return (annotate `: i32[]`) | linear | **yes** |
| the one large caller (a wrapper function per call) | linear, +0.7M per callee | **yes** |
