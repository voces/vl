### D2915 — at an `i32 | null` pin, the re-check types a join of `a ?? 5` with `b` as `i32`, dropping `b`'s null

**check-clean invalid wasm · clause 1 · open · identical on `829bd497c`, `0284dc2a8` and #3236 · found in the #3236 review · filed 2026-09-27 against master `0284dc2a8`**

Repro:

    function g0<T>(a: T, b: T, c: boolean) {
      const r = if c { a ?? 5 } else { b }
      r
    }
    const u0: i32 | null = 7
    const w0: i32 | null = null
    print(g0(u0, w0, true))
    // vl check: rc 0.  vl run: invalid module inside `g0`

Want:

    7

#### Mechanism

Not localised past the ablation. The body re-checked at `T := i32 | null` joins the `??` arm
(`i32`) with `b` (`i32 | null`) as `i32`: the arm absorbs `b` and its `null` is lost, so the
instance lowers the join at a scalar while `b` is the nullable box. The same loss is a clause-2
refusal on the reassigning spelling, where the re-check reports `cannot assign i32 | null to
i32 (the body of g0 at the call's argument types)`. At a `string | null` pin the checked return
drops the `null` the same way (D2912 withholds its box there, so that pin is a loud reject).

#### Grading list

The reassigning spelling, `let r = if c { a ?? 5 } else { b }; if !c { r = b }; r` at the same
pin (a check reject at the call). The `string | null` pin's caller annotated wider, invalid
wasm on every seed:

    function g0<T>(a: T, b: T, c: boolean) {
      const r = if c { a ?? 5 } else { b }
      r
    }
    const u0: string | null = "n"
    const w0: string | null = null
    const x: string | i32 | null = g0(u0, w0, false)
    if x == null { print("isnull") } else { print("other") }

With a `"d"` default at a `string | null` pin, `const u: string | null = null`, `w` the same, and
the calls `g(u, w, true)` then `g(u, w, false)`, three spellings of one body disagree, all three
identical on master `03dcbcfac`:

* `if c { a ?? "d" } else { b }` returned directly runs and prints `d`, then `null`.
* `const r = if c { a ?? "d" } else { b }; r` prints `d`, then traps with `null reference`.
* `const r = if c { a ?? "d" } else { b }; const s = r; s` is invalid wasm (`expected i32`).

**Needs the ruling D2906 asks for (CK lane, 2026-09-28).** The re-check is not what drops
the null. Inside the body `a ?? 5` is a deferred `??` result hole, and `joinTys` lets that
hole absorb `b: T`, because a type variable is assignable to anything there. So the template
types the join as the hole, and the pin substitutes the hole to `i32`. Joining a declared
parameter with a `??` result hole as their union (`?coal | T`, re-joined at the pin to
`i32 | null`) runs this witness (`7`), the reassigning spelling (`7` then `null`) and the
`string | null` caller (`isnull`). That is the same honest-join change D2906's ruling decides,
with the same body-reading cost.
