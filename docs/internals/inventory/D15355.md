### D15355 — a map binding written a function outside the set of the map it is then reassigned is refused at emit

**open · loud emit reject · `emitProgram: unsupported map value type` · clause 2 · a write inside the source's set runs since D15233 · found grading D15233 · filed 2026-11-04 against master `73062b83`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const fnMap = Map()
    fnMap.set("a", inc0)
    fnMap.set("b", half)
    function dbl(a) { return a * 2 }
    let m2 = Map()
    m2.set("a", dbl)
    m2 = fnMap
    const g = m2.get("b")
    if g != null { print(g(3)) }

Want:

    1.5

#### Mechanism

`m2` holds `{dbl}` and is reassigned a map of `{inc0, half}`: neither set is within the other, so the two cannot share one id numbering as D15233's pair does; running it needs the binding's set widened to the union, with the source's map built at it.
