#### Mechanism

An `is` test that leaves a `union`-stored field or element at a nullable member
(`boolean | null`, `string | null`) gives the read a read rep with `rrConv` 2: `rrStore`
`union`, `rrRead` the niche (`nulbool`, `nulstr`). The emitter performs no such conversion.
It delivers the box, and the null test reads the box's own tag (D2588). The conversion is
therefore implicit. `exprNulKind` reads the read half, the narrowed view, and `exprUnion`
reads the store half for exactly this conversion (`readHoldsUnionBox`). If the emitter
starts performing the conversion, that is a separate decision, graded on the four programs
below.
