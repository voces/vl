#### Mechanism

Confirmed by the close: [D9890](D9890.md)'s close pins the argument `v[1]` at the element type the list's pin closed
(`monoPinnedListElemPin`), so `id` instantiates. The call `id(v[1])` keeps the result type the
checker gave it, the open `(_) => _`, and the function-value call of that result then finds no
signature. With `const e = v[1]` the binding's type is retyped from the pin, and the call's
result closes through it.
