### D2440 — an assignment's value typed at a nullable sub-union of its box is the box

**check-clean invalid wasm · clause 1 · filed 2026-09-25 against master `a20d69104`, the
review residue of [D2391](D2391.md)'s close**

Repro:

    function pick(c: boolean): i32 | null { if c { 4 } else { null } }
    function g() {
      let v: i32 | string | null = "z"
      const r = (v = pick(true))
      if r != null { print(r + 1) }
    }
    g()
    // vl check: rc 0.  vl run: invalid module inside `g`: type mismatch: expected i32, found (ref $type)

#### Mechanism

The value is typed `i32 | null`, two members of the three-member box. D2391's close narrows
the re-read only to a single member, so the value stays the three-member box while `r` binds
the `i32 | null` rep. A two-member value needs its own rep taken out of the box (a re-box or
the niche), which no narrowing push performs.

On `dist/vl` built from `a20d69104`.
