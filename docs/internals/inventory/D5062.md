### D5062 — a written `let` of a generic returned from an un-annotated function reaches its caller's call as an open type

**loud emit reject · `vl check` rc 0 · clause 2 · found grading D4891's return position · filed 2026-10-16 against master `c604c1179`**

Repro:

    function k<T>(x: T): T { return x }
    function mk() {
      let g = k
      g = k
      return g
    }
    function main() {
      const h = mk()
      print(h(1))
    }
    main()
    // vl check: rc 0.  vl run: emit error, a function-value call has no interned signature

Want:

    1

#### Mechanism

`mk`'s inferred return is `g`'s open `(T) => T`, and nothing in `mk` pins `g`: the call
`h(1)` that fixes the type is in `main`, through a call result. The emitter reaches `h(1)` with
a hole parameter and refuses there, naming the call rather than the return. The never-written
spelling (`const g = k`) refuses earlier and names the position (`a generic function taken as a
value reaches no call that fixes its type`), which is the refusal the design's (c) literal
asks for at every such fall-through.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `mk` annotated `(): (x: i32) => i32` | runs, `1` | **yes** |
| `g` a `const` alias, or a `let` never written | refuses at `mk`'s binding, naming the position | **yes** |
| another binding calls `k` at `string` first, in `mk` | still refuses the same way | no |

#### Grading list

- a call result delivered into a record field or a list before the call
- the same return through a written `let` holding a lambda instead of a generic

#### Left open by L1 (2026-10-16)

Still the same emit reject on master `502f8daa8`. The call that fixes `g`'s type is in the
CALLER, through `mk()`'s result, so pinning it means carrying a pin back across an inferred
return. D5061's close pins a read within the frame that declares the binding. The cheaper half
is the (c) literal: the written spelling should refuse at `mk`'s binding, naming the position,
as the `const` spelling already does.
