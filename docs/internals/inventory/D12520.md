### D12520 — `is` with an arm the instance's record can never match, over a hole parameter bound from a union member's field read, is refused at emit

**loud emit reject · clause 2 · `vl check` rc 0 · `emitProgram: \`is\` receiver is not a union value` · D3311's complement: the same argument and pin, tested against the OTHER member · found closing D3311 · filed 2026-10-24 against master `59cb5d9c1`**

Repro:

    type O = { n: i32 }
    type P = { m: i32, k: i32 }
    type U = O | P
    type W = { w: O }
    function v(q) {
      if q is P { return 1 }
      return 0
    }
    const ww: W = { w: { n: 4 } }
    print(v(ww.w))
    // vl check: rc 0.  vl run: emitProgram: `is` receiver is not a union value

Want:

    0

#### Mechanism

At the instance `q` is `O`, a member of a declared union, so it is held as that member's
variant row with no union box around it. D3311's test `q is O` is now answered as a tautology
from the instance's banked type (`emitIs`, wasmEmit.vl). The test `q is P` can never match an
`O`. The annotated face `function v(q: O)` refuses it at check time, but the generic body is
legal, and nothing at the instance folds the test to `false`. So it reaches `emitIsTest`,
which wants a union box.
