### D1692 — a `type` whose field is an INLINE nested shape carrying a struct-element ref list has no field rep, and the declaration alone refuses even when nothing constructs it

**loud emit reject · filed 2026-09-06 against master `ad287fae7` · found by D1663's position
matrix at `struct_field_init` / `struct_field_assign` · 0 corpus cells**

Repro:

    type A = { r: i32 }
    function ns1(): A[] | null { return [{ r: 4 }] }
    type W = { f: { xs: A[] | null } }
    const w: W = { f: { xs: ns1() } }
    const l = w.f.xs
    if l != null { print(l[0].r) } else { print(0) }
    // vl check: rc 0.  vl run: emit error, at the `type W` line,
    // emitProgram: struct field type `{xs:A[]|null}` has no struct-field rep

Give the inner shape a NAME — `type Inner = { xs: A[] | null }`, `type W = { f: Inner }` —
and the identical program runs and prints `4`.

#### Mechanism

The span is the `type W` line, not the construction, and the ablation says why: **deleting
`const w: W = …` leaves the refusal exactly where it was.** `collectS`'s struct-declaration
pass asks `fieldTypeCode` for each `FieldDef`, and an inline nested shape whose own field is a
struct-element ref list has no code — the inner shape is not interned as a row at that point,
so `nameFieldCode("{xs:A[]|null}")` cannot answer 15 and the pass falls to
`fieldTypeRefusalMsg`. The declaration is refused before any literal is looked at, which is
what separates this from D1674: there a declared row CAPTURES a literal, here no row is minted
at all.

Two sentences, one mechanism, selected by the inner field's code: the `| null` niche (28)
reads `struct field type '{xs:A[]|null}' has no struct-field rep`, and the plain ref list (5)
reads `emitProgram: ref-list field element type is not interned`. Both fall to the inline
spelling and both are rescued by naming the inner shape.

The element KIND is the ingredient and it is narrow — only a struct element:

| inner field | `type W = { f: { xs: … } }` |
| --- | --- |
| `A[] \| null` (struct-element ref list, code 28) | **emit rejects** |
| `A[]` (struct-element ref list, code 5) | **emit rejects**, the sibling sentence |
| `i32[] \| null` | runs `4` |
| `string[] \| null` | runs `hi` |
| `A \| null` (a nullable struct, not a list) | runs `4` |
| `A` (a nested struct) | runs `4` |
| `i32` | runs `4` |
