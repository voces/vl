### D1740 — an INLINE literal union through a hole parameter, in a list literal, reserves no string list — and naming its element rep at the collector trades the floor for invalid wasm

**loud emit reject · `vl check` rc 0, `vl run` rc 1, `emitProgram: string array literal but string list type not collected` · clause 2: the identical program with the parameter annotated prints `green` · filed 2026-09-06 against `#2749`'s tree · the one cell [D1725](D1725.md)'s close leaves, and the REFUSED candidate for it is measured here · 0 corpus cells**

Repro:

    const src: ("red" | "green")[] = ["green", "red"]
    function take(a) {
      const xs = [a]
      print(xs[0])
    }
    take(src[0])
    // vl check: rc 0.  vl run: emit error,
    // emitProgram: string array literal but string list type not collected

Annotate the parameter `a: "red" | "green"` and it prints `green`. Add any other `string[]` to
the module and it prints `green` too — the reservation is module-wide.

#### Mechanism

Predicted, not probed, and one half is measured. [D1545](D1545.md) pins an INLINE member set at
a hole parameter to the softened `string`, so `[a]` classifies as a string list at emit — while
the CHECKER's recorded element is still the literal union, which is neither a `TyPrim` nor a
hole. [D1725](D1725.md)'s pin-resolving element reader is `TyPrim`-gated and so answers "" for
it, and no string list is reserved.

**The obvious close was measured and REFUSED.** Naming a literal-union element's rep by
alias-ness at the collector — an alias is the i32 atom, an inline set is `string`, which is what
the rep layer itself says — reserves the string list and moves this cell from the loud floor to
**check-clean invalid wasm**. The floor is doing its job: the reservation is not what this shape
is missing, and loud-to-silent is the one trade this repo refuses. Whatever closes this row has
to make the whole lowering agree, not just admit it.
