### D15728 — a fresh call's record holding a list of numbers, delivered at a record storing that list's elements as `| null`, builds invalid wasm

**closed 2026-11-12, runs and prints `5` then `true` · was check-clean invalid wasm, clause 1, the same on master · the copy's rule admits a scalar list element boxed into a `| null` holding it or a number it widens to, or a union listing it (`recListElemCopies`, check_fit_rules.vl), and the copy boxes each element (`rcListBoxAtom` and `emitScalarListBoxTop`, wasmEmit.vl) · graded by `scripts/capability-probes/matrix/kept-maker-delivery-list-elem-nullable.matrix.vl` (59 SILENT cells before) · fixture `tests/cases/structs/kept-maker-list-elements-boxed-at-wider-row-runs.vl` · filed 2026-11-12**

Repro:

    type U = { f: (i32 | null)[] }
    function ul() { { f: [4] } }
    const h = ul()
    print(h.f[0] + 1)
    const h2: U = ul()
    print(h2.f[0] != null)

Want:

    5
    true

#### Mechanism

A `(i32 | null)[]` is a list of union boxes, and `i32[]` a list of numbers. The copy's rule
(`recListElemCopies`) admits a list whose element widens or is a record, not one whose element is
boxed, so the delivery is not a copy. D14385's interim refusal does not fire for a `| null`
destination (it is served at every use for a record), so nothing converts, and the call's own
record lands where `U` is wanted.
