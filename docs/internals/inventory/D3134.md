### D3134 — a read of a value narrowed out of `K | J | null`, two literal-union aliases and `null`, is invalid wasm or refused

**check-clean invalid wasm · clause 1 · found by the #3279 review (`rv3279-28945/p/m2a.vl`, `m2b.vl`) · the same on master `a29230611` · filed 2026-09-28 against master `a29230611`**

Repro:

    type K = "a" | "b"
    type J = "c" | "d"
    function t(v: K | J | null) {
      if v is K { print(v) }
    }
    t("b")
    // vl check: rc 0.  vl run: invalid module inside `t`: type mismatch: expected i32, found
    // (ref $type)

Want:

    b

#### Mechanism

Not localised past the ablation. The parameter's value is the box (two aliases and `null` do
not share one atom niche), and a read narrowed to `K` is delivered as the box to `print`'s
atom path. Narrowed by `v != null` instead, the read is refused at emit with `print of a union
value whose arms the tag dispatch cannot classify`, a clause-2 face of the same value.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `print("k")`, the narrowed value not read | runs | **yes** (the read) |
| no `null` member, `v: K \| J` | runs, prints `b` | **yes** (the `null`) |
| a module global `const v: K \| J \| null` | runs, prints `b` | **yes** (the parameter) |
| `K \| string \| null` | runs | **yes** (the second alias) |
| `if v != null { print(v) }` | loud emit reject, `print of a union value whose arms the tag dispatch cannot classify` | no (the other face) |
| `K \| "c" \| null`, `v != null` | the same emit reject | no |

#### Grading list

Both narrowings (`is K` and `!= null`), the read at `print`, an argument and a return, and
the module-global spelling.
