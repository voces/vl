### D15453 — a `const` list seeded from a hole parameter the body also calls directly, its slot written with another, is refused

**open · loud emit reject · `vl check` rc 0, `emitProgram: a function value's signature is not known at this call`, clause 2, with the split plan on and off · the list-slot spelling of D15460, whose written-`let` spelling builds since its fix · found writing the cell-read witnesses after #6383 · filed 2026-11-05 against master `755ba974`**

Repro:

    function go(a, b) {
      const r = [a]
      r[0] = b
      print(r[0](3))
      print(a("x"))
    }
    function same<T>(k: T): T { k }
    function dbl(x) { x }
    go(same, dbl)

Want:

    3
    x

#### Mechanism

Not yet ablated past its ingredients. D15460 closed this shape for a written `let` seeded from
the parameter (`ftLateParamTakes` deciding the let's wider set with the parameter's). Here the
seeded holder is a list slot written through `r[0] = b`, which no seed note covers, so `a`'s
direct call at `string` and the slot's call at `i32` meet at one closure.

#### Ablation

| --- | --- | --- |
| `print(a("x"))`, the direct call | runs | **yes** |
| `r[0] = b`, the slot write | runs, `3 x` | **yes** |

| list → record `{ f: a }` written `r.f = b` | still refuses, `a function value is called at two signatures` | no |
