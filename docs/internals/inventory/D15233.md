### D15233 — a binding reassigned from a map whose function values have hole types is refused at emit

**loud emit reject · `emitProgram: ref valtype with no interned shape` · `vl check` rc 0 · clause 2 · open, target `1.5` · found grading [D15186](D15186.md) · filed 2026-11-04 against master `c8873e91`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const fnMap = Map()
    fnMap.set("a", inc0)
    fnMap.set("b", half)
    let m2 = Map()
    m2.set("a", inc0)
    m2 = fnMap
    const g = m2.get("b")
    if g != null { print(g(3)) }
    // Want: 1.5

#### Mechanism

Not ablated past the table. `m2` is its own `Map()` written `inc0` and then reassigned the
two-function map; the emitter finds no ref shape for one of the two.
