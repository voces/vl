**closed · runs, prints `7`, `w` · was loud emit reject, `vl check` rc 0, `a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type`, clause 2 · CAPABILITY: without the write `ws[0] = id` it prints `7`, `w` · found closing [D10300](D10300.md) · present on master `e811cd6da` and `12d79dbee` · filed 2026-10-22 against master `e811cd6da` · closed: a plain `=` into an element of the list, through its own name or a `const` alias, stores a value the list holds (`monoFlowElemWrites`, emit_mono.vl), so the flow plan counts the write, and plans it only when every value the list holds names one generic; a computed index runs too · fixture `closures/list-of-generic-written-aliased-or-called-in-operands-at-two-types.vl` · new matrices `fn-value-generic-list-written-same-at-two-types-open` 0 → 14 of 46 and `fn-value-generic-list-written-same-at-i32` 46 → 46 · residue: [D10390](D10390.md) (an element that is itself a field or element read, as `[r.f]`, refuses at two types with or without the write)**

Repro:

    function id<T>(x: T): T { x }
    const ws = [id]
    ws[0] = id
    print(ws[0](7))
    print(ws[0]("w"))
    // vl check rc 0.  vl run: emit error: emitProgram: a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type

Want:

    7
    w

#### Mechanism

`monoFlowUsePlanAt` (emit_mono.vl) declined any read of the list that is a write target, so
the element write dropped the list from the flow plan and nothing else gave the literal's `id`
an instance. The values a list holds (`monoFlowElemLeaves`) did not count a written value.

| --- | --- | --- |

| `let ws` instead of `const ws` | same refusal | no |
