### D10340 — a list of a generic whose element is written with the same generic has no instance when called at two types

**loud emit reject · `vl check` rc 0 · `a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type` · clause 2 · CAPABILITY: without the write `ws[0] = id` it prints `7`, `w` · found closing [D10300](D10300.md) · present on master `e811cd6da` · filed 2026-10-22 against master `e811cd6da`**

Repro:

    function id<T>(x: T): T { x }

#### Mechanism

Not traced. The refusal names the list literal's element, so the write of the same generic
declines the flow plan for the list, as a push of it did for a `let` before
[D10300](D10300.md), and nothing else gives the literal's `id` an instance.
