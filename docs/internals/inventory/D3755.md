#### Mechanism

`nulScalarSplit` (emit_rewrite.vl) takes a binding apart only when every use qualifies (a
null test, a narrowed read, or `g ?? d`). Any other use keeps the whole binding as it was:
the box is made at the binding, on every path. A rewrite that kept the split and rebuilt the
box only at the escaping use (`if $np { $nv } else { null }`, typed `S | null`) would cost
the escaping path what it costs today and the others nothing. It was not done because a
value-`if` yielding a nullable scalar takes its rep from the destination, and that needs a
position matrix (argument, return, store into a list or field, capture) before it can be
trusted. A `let` binding and a non-fused producer (a call returning `S | null`) are out of
scope for the same pass and also keep the box.
