#### Mechanism

Not localised past the ablation. The kept-apart join of two bare type parameters (D3268) is
not what types this join: inside a function nested in the generic, or in a generic nested in a
function, the join takes the first arm's rep, and the record arm is then built where an `i32`
(or another record) is expected. D3361 is the scalar face of the nested-generic shape; this
one differs in its ablation because it also fails in a nested function that captures the
parameters, where D3361's scalar members answer right.
