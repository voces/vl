### D4191 — a null-only list literal in a generic record's field never receives the instance's element rep

**loud emit reject · clause 2 · filed 2026-10-12 against master `7bce607c6` · found while
grading [D1832](D1832.md)'s close over typed delivery positions**

Repro:

    type Box<T> = { items: T[] }
    const b: Box<i32 | null> = { items: [null] }
    print(b.items.length)
    // vl check: rc 0.  vl run: emitProgram: bare null needs a struct-typed context.  Should print 1.

#### Mechanism

Not yet ablated to a rung. The destination is annotated, so D1832's refusal correctly lets the
literal through; the non-generic twin `type Box = { items: (i32 | null)[] }` runs, so the
missing seed is the instanced alias's field.
