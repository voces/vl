### D2541 — a literal-union value boxed into a record field has no interned ref shape at emit

**closed 2026-10-16 · was a loud emit reject (`emitProgram: ref valtype with no interned shape`), clause 2, identical on master `74aaec8f9` · fixture `tests/cases/unions/union-field-literal-row-positions.vl` · found by review · filed 2026-09-25 against master `a09d1f6bc`**

Repro:

    let z: 1 | 2 = 2
    const o = { k: z }
    print(o.k)
    // vl check: rc 0.  vl run: emitProgram: ref valtype with no interned shape

Want:

    2

#### Mechanism

A scalar literal-union value (`1 | 2`) reads and prints fine on its own, using the plain `i32`
representation the design says a bare literal union shares with its base type. Placing the same
value into an object-literal FIELD routes the field's value kind through a different rung, one
that resolves to a boxed kind (the `struct`/`variant` family) needing a registered heap-shape
index — and no shape was interned for this literal-union field, so `fbValtype`'s bounds guard
(`emit_bytes.vl`) catches the unresolved index and fails loudly (the same defensive floor named
in D21 and D1562) rather than emitting a wrong type or trapping.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the record wrapper (`print(z)` alone, no `{ k: z }`) | prints `2` | **yes** — the literal union alone is fine |
| the literal-union annotation (`z: i32` instead of `1 \| 2`) | prints `2` | **yes** — an ordinary scalar field is fine |
| the intermediate binding (`const o: { k: 1 \| 2 } = { k: 2 }` directly) | same emit reject | no — not about the separate variable |
| `let` vs `const` for `z` | same emit reject | no |

#### Grading list

Any literal-union value delivered into a record field, a list element, or a map value — the
same "no interned shape" floor is likely reachable from each, since none of them share the
plain scalar's rep path.

Closed by L2 stage 3: the collect pass mints the row of a record literal whose field holds a
union whenever the monomorphized phase is reached (`mintUnionFieldObjRow`), not only when a
generic instance returns the union. The list element, the map value and a nested record field
print `2` as well; all four are in the fixture.
