### D16184 — an un-annotated function whose value is a write of a literal-union member into its own `K | null` local returns the atom where its result is the string

**check-clean invalid wasm · `type mismatch: expected (ref $0), found i32` inside `set` · clause 1 · both spellings, the tail `k = "ww"` and `return k = "ww"` · filed 2026-11-15 against master `3d526470a`**

Repro:

    type K = "ww" | "zz"
    function set() {
      let k: K | null = null
      return k = "ww"
    }
    print(set())

Want:

    ww

#### Mechanism

The write is typed `"ww"`, a lone literal whose result rep is the string, while the local's cell
holds `K | null` as the atom niche. The value lowering re-reads the cell, which yields the atom
`i32`, and the function's result type is the string ref. A captured binding takes the split of
[D16183](D16183.md), which this local does not, since only the capture rewrite builds it.
