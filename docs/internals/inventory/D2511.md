### D2511 — a closure capturing the value name of a `for k, v in m` walk takes the KEY's rep

**closed 2026-09-25 — the filed repro RUNS and prints `4` · was check-clean invalid wasm, clause 1 · pre-existing, identical on master `54fcaf5d8` · found by #3165's review grid · filed 2026-09-25 against master `54fcaf5d8`**

Repro:

    const m: {[string]: i32} = Map()
    m["a"] = 3
    for k, v in m {
      const g = () => v + 1
      print(g())
    }
    // vl check: rc 0.  vl run: invalid module inside `g`, type mismatch: expected (ref $type), found i32

#### Mechanism

`captureLoopVarIterOf` answers the `for` node's iterable for EITHER of its names, and
`captureValKind` / `captureValStructIdx` typed the closure's env field through the element
ladder (`forInElemKind`), which for a map walk is the KEY's kind. The same held for a
sequence's index (`for x, i in xs`, the index typed as the element). The second name now asks
`forInPairElemKind` / `forInPairStructIdx` (`captureLoopVarIsPair`), the ladder
`declareForInLocals` binds the uncaptured local with.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the closure captures `k` instead (`() => k + "!"`) | prints `a!` | **yes** — the value name |
| `const w = v`, then the closure captures `w` | prints `4` | **yes** — the loop name itself |
| `for v in m.values()` instead of the pair walk | prints `4` | **yes** — the pair walk |
| the key `i32` instead of `string` (value `i32`) | prints `4` | **yes** — a key rep unlike the value's |
| the value `string` (key `string`) | prints `s!` | **yes** — as above |
| the value `f64` or `boolean` | still invalid | no |
| a `{ x: i32 }` struct value, read `v.x` | loud emit reject, `field access receiver is not a struct` | no — the loud face |
| the walk inside a function | still invalid (inside `main`) | no |
| `g` created but never called | still invalid | no |

#### Grading list

* The struct-valued spelling, the loud face of the same slot.
* A union-box-valued map (`{[string]: i32 | null}`), which D2503 made readable in the body.
