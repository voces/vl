#### Mechanism

The scalar sibling of [D7340](D7340.md). The checker reads both annotations as one type
(it hints the second is redundant), so the binding needs no conversion. The emitter reps an
inline `"circle" | null` as a nullable string ref and the alias's `KC | null` as the atom's
i32 sentinel niche, so the binding stores one rep into a slot typed by the other. D7340's
close moves the list element to the atom; a nullable scalar of one inline literal is a
scalar position and still softens.
