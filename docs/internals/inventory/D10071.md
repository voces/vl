#### Mechanism

`monoPushedListAnn` (emit_mono.vl) names an empty literal's list type at the pin by
substituting the instance's type-parameter bindings, which an un-annotated parameter does not
have: its type is a hole, bound in `monoCgcHoleN`. The substitution left the hole open, so the
helper declined and the instance built the literal against the template's element row.

| `function f<T>(v: T)` with `const xs: T[] = []` | prints `1` `1` | **yes**, the hole |
