### D3243 — a `null` written into a declared record's function field has no struct-typed context at emit

**loud emit reject · clause 2 · open · pre-existing, the same on master `fc1e91d24` · found by the #3289 split-head review (`rv3289s-28321/p/m6.vl`) · filed 2026-09-29 against master `fc1e91d24`**

Repro:

    type R = { v: i32, f: (() => i32) | null }
    function clr(q: R) {
      q.f = null
    }
    const r: R = { v: 1, f: () => 5 }
    clr(r)
    print(r.f == null)
    // vl run: emitProgram: bare null needs a struct-typed context

#### Mechanism

Not localised. The write's destination is the declared field `(() => i32) | null`, a nullable
closure, but the bare `null` is lowered without the field's type as its context. A `null` held
in a binding of the field's type (`let NF: (() => i32) | null = null; q.f = NF`) builds and runs.

#### Ablation

| ingredient changed | outcome on master | needed? |
| --- | --- | --- |
| `q.f = NF` with `NF: (() => i32) \| null = null` | prints `true` | **yes** (a bare `null` literal) |

#### Grading list

The witness, and the same write through a hole parameter.
