### D1490 — a same-shape union's registry row banks a MEMBER's arena type, and that entry is load-bearing

**runs today and must keep running · 6 of 2,447 registered corpus rows · filed 2026-09-03 against master `fd95c79f`**

Repro:

    type A = { tag: i32, v: i32 }
    type B = { tag: i32, v: i32 }
    function mkB(): B { return { tag: 2, v: 200 } }
    const b: A | B = mkB()
    print(b.v)
    // prints 200 today; the row's `unTyIx` is `A`'s TyObj, and that is what finds it

#### Mechanism

`registerInlineUnion` mints `unTyIx.push(declTyIxOfName(name))`. For a union whose members
share a SHAPE the annotation resolver answers a MEMBER: `annUnionPushDistinctMember` drops the
duplicate (`sameVariantTy` is mutual `assignable`, not index equality) and `annUnionInnerTy`
returns the survivor, so `declTyIxOfName("A|B")` is `A`'s `TyObj` and no `TyUnion` is minted at
all. Six corpus rows are in this state — five `obj`, one `func`
(`(({a:i32,b:string})=>i32)|(({b:string,a:i32})=>i32)`, two closures whose object parameters
differ only by field order) — and `canonUnionKeyOfTy` answers -1 for every one, which is
`keySweep/tykey-none` in `docs/internals/registry-by-type-id.md` §5.

**The obvious fix is refuted by measurement.** Gating the mint so a non-union resolution records
-1 (the column's uncovered value) was built and graded: the corpus goes from 2,289 identical
modules to **2,287 identical + 2 rc 0 → rc 1**. `letUnionNameOf` finds the row through
`unRowOfCanon(annRowOfNode(d.letType))`, and the annotation's own type IS the collapsed member,
so the member type is the row's only working handle. The entry is not a resolver defect; it is
the arena's answer for a spelling the checker deliberately collapses.

What the entry must NOT do is answer the different question "is this arena type a union":
`isUnionOfTy`'s index rung took `unTyIx[u] == ty` and so called the declared struct `A` a union.
That rung is now gated on the row's recorded type being a union SHAPE. Measured over the 2,790
corpus programs against a working control on the same counter — `isUnionOfTy` is entered
**10,485** times and the index rung fires **0** — so the narrowing is byte-identical and inert
there; it is the guard step 5's switch needs, not a fix with a witness.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `B`'s fields made distinct from `A`'s | the row records a real `TyUnion`, key route reaches it | **yes** |
| the `mkB()` call (init by a literal instead) | unchanged — the collapse alone is the trigger | no |
| the declared spelling `type U = A \| B` instead of inline | pass 0b does not dedupe, row records the `TyUnion` | **yes** |
