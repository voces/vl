#### Mechanism

Not traced. The list's element is pinned from its hole functions, and `T` binds from `xs`, but the
index read `v[1]` handed to `x` has no argument type the monomorphizer's pin accepts. This is the
hole-function pinning of [D9766](D9766.md)'s family, at an element read rather than a named function.
