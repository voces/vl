### D16204 — a closed record type interned onto a struct row recorded at an open one is aliased to it silently

**runs today and must keep running · the layout-reuse branch of `internInlineShape` (`emit_shape_intern.vl`) aliases a closed record type to an existing row whose recorded type reaches a hole · found closing D16201 · filed 2026-11-14 against `g52-d16201-record-field-map`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function half(a) { return a / 2.0 }
    function mk() { return { a: [{ f: inc0 }, { f: dbl }] } }

Want:

    6

#### Mechanism

`internInlineShape` finds an existing row by type, then by layout (`annShapeLayoutRowOf`). An open
and a closed function field have the same field code, so a closed type can land on a row minted
from the checker's open type. The row keeps the open type, and every reader of the row's field
types reads open. D16201 was this, refused at emit. This program runs because nothing reads the
field type that differs.
