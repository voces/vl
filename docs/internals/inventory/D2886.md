### D2886 — an if-expression joining an `i32` arm and a literal-union element reads the literal as `0`

**check-clean silently wrong · clause 1 · found by the #3229 review · the same on master `fe1fa1bec` · filed 2026-09-27 against master `8e10ef58b`**

Repro:

    function mk(b: boolean): i32[] | ("x" | "y")[] {
      if b { return [1] }
      ["y"]
    }
    const w = mk(false)
    const e: i32 | "x" | "y" = if w is i32[] { w[0] } else { w[0] }
    print(e)
    // PRINTS 0

Want:

    y

#### Mechanism

Not the join. `i32[]` and `("x" | "y")[]` are both stored as the i32 list (a literal element is
its interned atom index) and both box under value-atom code 7, so the union's two members carry
one tag and `w is i32[]` is true of the `["y"]` list: the `then` arm reads the atom index `0` as
an `i32`. `valueAtomKind`'s own comment assumes the two cannot share a union; the checker lets
them. Two literal-union lists (`K[] | J[]`) collide the same way and print the wrong member.
Closing it needs a tag of its own for each literal-union list arm beside another code-7 arm, as
D2769 gave `boolean[]` code 17, which is why D2874's list-union rewrite declines a literal
element. Re-diagnosed 2026-09-27 against master `829bd497c`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the value position (`if w is ("x" \| "y")[] { print(w[0]) }`) | runs, prints `y` | no — the tag answers `true` for the literal arm too |
| the join (`if w is i32[] { print("int") } else { print("lit") }`) | prints `int` | no |
| the annotation on `e` | prints `0` | no |
| D2952's join boxing (the join of a literal-union member and a scalar), applied | prints `0`, and `w is i32[]` is still `true` | no — the tag collision alone decides it, so D2952 is a different mechanism |

#### Grading list

`type K = "a" | "b"; type J = "c" | "d"` with `mk(): K[] | J[]` returning `["d"]` and
`if w is K[] { print(w[0]) } else { print(w[0]) }`, which prints `b`. `i32[] | (1 | 2)[]`,
which refuses at emit (`union box atom test on a union with no recorded members`). Then
`for v in mk(false) { print(v) }` and `mk(false)[0]` once D2874 lets the literal element through.
