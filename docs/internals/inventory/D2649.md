### D2649 — a `Map()` constructor delivered straight into a union with a map arm has no value shape, at every key rep

**loud emit reject · clause 2 · identical on master at the string key · filed 2026-09-26 against master `19dfb80af`, found grading D2519**

Repro:

    const u: {[string]: i32} | string = Map()
    if u is {[string]: i32} {
      u.set("k", 4)
      print(u.get("k") ?? -1)
    }
    // vl check: rc 0.  vl run: emitProgram: a map value is not a supported union member — use a struct member instead

#### Mechanism

`emitUnionCoerce` boxes a map carrier under the tag of the arm whose shape matches
`mapShapeOfExpr`. For a bare `Map()` whose destination is a union, that shape is `-3` (no value
type the mv layer can intern): the checker binds the constructor's key and value from a plain map
annotation, not from a union arm, so no arm matches and the carrier falls to the loud
`a map value is not a supported union member`. The same constructor bound first
(`const m: {[string]: i32} = Map()`, then `const u: … = m`) runs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the string key (`{[i32]: i32} \| string`) | the same refusal | no |
| the mono value (`{[string]: string} \| i32`) | the same refusal | no |
| the direct delivery (bind the map first) | runs | **yes** |
| the union (`const u: {[string]: i32} = Map()`) | runs | **yes** |
