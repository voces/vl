### D17770 — a container of un-annotated lambdas read through a record a call returns keeps its open element type

**closed 2026-11-27 by COV-UNION · runs, its witness prints its expected value · was a loud emit reject, `cannot yet lower this statement (call of a non-declaration)` · a call the checker left at an open record takes the record literal its callee returns once that literal's fields close, and the reads through it are typed at its fields (`monoCallReturnedRecReads`, emit_mono.vl) · pinned by `tests/cases/closures/hole-fn-container-through-returned-record.vl` · filed against master `dd93db336`**

Repro:

    const f = (a) => a + 1
    const hm = Map()
    hm["k"] = f
    function mk() { return { m: hm } }
    const y = mk().m["k"]
    if y != null { print(y(3)) }
    // vl check: rc 0.  vl run: emit error (call of a non-declaration)

Want:

    4

#### Mechanism

The map binding is pinned at its stored lambda's instance and its own reads are typed there, and
the returned record literal's field closes with it (`monoPinReturnedObj`), but nothing typed the
CALL at that record: the call, `mk().m`, the value read and the `const` bound to it kept the
checker's `(_) => _`, so the call through the narrowed read had no closure signature. A record
literal bound in place (`const w = { m: hm }`) is pinned by its own binding and ran. A container
of a tagged set holds member ids, and is left as checked.
