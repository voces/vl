### D16103 — a field write of a wider record, used as a value after an operand its right-hand side changes, has no value lowering

**closed · runs, prints `10` · was loud emit reject, clause 2 · fixed 2026-11-14: the name reads passed before the write are spilled in order, so the write moves ahead of its statement · the residue [D16019](D16019.md)'s move leaves · filed 2026-11-14 against master `1b5ee5499`**

Repro:

    type A = { x: i32 }
    type B = { x: i32, y: i32 }
    type H = { p: A | null }
    const h: H = { p: null }
    function yOf(q: B): i32 { return q.y }
    let k = 0
    function nb(): B { k = k + 1; return { x: k, y: k * 10 } }
    print(k + yOf(h.p = nb()))

Want:

    10

#### Mechanism

D16019 delivers a wider record written into a narrower field by moving the write ahead of its
statement (`asvMovePlace`). Here `k` is read before the write and `nb()` writes `k`, so moving
the write would read `k` after the call; the move is declined and the value has no lowering
(`an assignment used as a value whose type is not its target's has no value lowering`). Delivering
it needs the value kept in a local of `B`'s rep at the write itself, not ahead of the statement.
The name target is [D16104](D16104.md).

#### Closed (2026-11-14)

D2398's walk (`assignValueSpill`, `compiler/emit_rewrite.vl`) records the slot each passed
operand was read from. When a value-position write it would move is held back by an operand
read before it (a name the right-hand side may write, or any operand that is not a name), the
passed operands are spilled ahead in source order (`asvSpillPassed`) and the write then moves.
A `const` read needs no spill. Where no move is possible, a name's re-read is no longer taken
for a named record stored at another record (`asgNameHoldsOtherRecord`), so the write is
refused loudly rather than built invalid; a write under a short-circuit operand is that residue,
[D16105](D16105.md). Graded on `scripts/capability-probes/matrix/wider-record-write-after-read.matrix.vl`:
0 of 54 to 54 of 54; 52 of the cells were check-clean invalid modules before.
