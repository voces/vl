### D16103 — a field write of a wider record, used as a value after an operand its right-hand side changes, has no value lowering

**loud emit reject · clause 2 · the residue [D16019](D16019.md)'s move leaves · filed 2026-11-14 against master `1b5ee5499`**

Repro:

    type A = { x: i32 }
    type B = { x: i32, y: i32 }
    type H = { p: A | null }
    const h: H = { p: null }
    function yOf(q: B): i32 { return q.y }
    let k = 0
    function nb(): B { k = k + 1; return { x: k, y: k * 10 } }
    print(k + yOf(h.p = nb()))

Want:

    10

#### Mechanism

D16019 delivers a wider record written into a narrower field by moving the write ahead of its
statement (`asvMovePlace`). Here `k` is read before the write and `nb()` writes `k`, so moving
the write would read `k` after the call; the move is declined and the value has no lowering
(`an assignment used as a value whose type is not its target's has no value lowering`). Delivering
it needs the value kept in a local of `B`'s rep at the write itself, not ahead of the statement.
The name target is [D16104](D16104.md).
