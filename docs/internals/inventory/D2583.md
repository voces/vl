### D2583 — a module global holding a record-or-scalar join, narrowed to its scalar arm, is interpolated as the box

**check-clean invalid wasm · clause 1 · found grading [D2564](D2564.md)'s close against the #3173 review grid (`ai__modscope__annrev`) · the same on master `216770428` · filed 2026-09-26 against master `216770428`**

Repro:

    type A = { r: i32 }
    function mkA(n: i32): A | null { if n == 0 { return null } return { r: n } }
    const g0 = mkA(0) ?? 4
    function go() {
      if g0 is A { print(g0.r) } else { print("I:\{g0}") }
    }
    go()
    // vl check: rc 0.  vl run: invalid module, inside `go`:
    // "type mismatch: expected (ref $type), found i32"

#### Mechanism

A prediction. In the else arm `g0` is narrowed to `i32`, and the interpolation hands it to
`std:fmt`'s `toString(self: i32 | i64 | boolean | f64)`, whose parameter is a value-union box.
The validator reports an `i32` where that box was expected: the read unboxes the narrowed
global to its scalar, and the call boundary re-boxes a local read at the same position but not
this global one. The row's own union is scenery apart from making the global a box.

#### Ablation

| the global annotated `A \| i32`, still initialised with the join | still invalid | no |
