### D9450 — a returned list literal of un-annotated functions called in `.map` callbacks at two argument types takes no copy per pin

**loud emit reject · `vl check` rc 0 · `cannot take the generic function … as a value` · clause 2 · found closing [D9410](D9410.md) · present on master `af839a093` · filed 2026-10-21 against master `af839a093`**

Repro:

    function inc(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function deliver() {
      return [inc, dbl]
    }
    const v = deliver()
    print(v.map((f) => f(3))[1])
    const u = deliver()
    print(u.map((f) => f(1.25))[1])
    // vl check rc 0.  vl run: emit error: emitProgram: cannot take the generic function `inc` as a value

Want:

    6
    2.5

#### Mechanism

`monoRetFnListTy` (emit_mono.vl) instances the returned literal at the one pin its element slot
takes. The two callers' callbacks pin that slot at `i32` and at `f64`, so there is no one pin,
the literal stays open, and the functions inside it are refused. The index spelling runs
because the return takes a copy per destination; the `.map` path has no such copy.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the second argument type (`f(4)` instead of `f(1.25)`) | runs, `6` `8` | **yes** |
| the `.map` callbacks (`v[1](3)`, `u[1](1.25)`) | runs, `6` `2.5` | **yes** |
| the return (two module-level `[inc, dbl]` literals) | runs, `6` `2.5` | **yes** |
| the second binding (both callbacks over `v`) | same refusal | no |

#### Grading list

The index and module-level spellings in the ablation, which must keep running, and the
`hole-fn-list-called-in-callback` matrix.
