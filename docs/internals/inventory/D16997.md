### D16997 — a list narrowed by `is K[]` is handed on as `K[]` through an alias, an arm, an inferred return or a record literal

**closed 2026-11-19 — now a loud check reject (`argument 1: expected K[], got i32[] | K[]`) · was a silent wrong value (a `K[]` holding `200`), clause 1 · the owner ruling of 2026-11-19 (DECISIONS.md §"A narrowed list is not handed on as `K[]`, whatever its storage", D16970, D4928): D4928's refusal (`narListDeliveryErr`) fired only where a destination type checked the narrowed name itself. An un-annotated binding and an inferred return now read the list at its declared type (`narListUntypedDelivery`, as D4133 does for a record), and the refusal now walks an `if` or `match` arm's value and an un-annotated record or list literal's members · fixtures `tests/cases/narrowing/error-narrowed-list-handed-on-through-an-arm.vl`, `error-narrowed-list-handed-on-in-a-record.vl`, `error-narrowed-list-alias-handed-on.vl` and `narrowed-list-alias-reads-at-declared-type.vl` · filed 2026-11-19 against master `86d30a394` by lane F1**

Repro:

    type K = 1 | 2
    let keep: K[] = []
    function f(xs: K[]) { keep = xs }
    const a: i32[] = [1, 2]
    const q: i32[] | K[] = a
    if q is K[] { const r = q; f(r) }
    a.push(200)
    print(keep[keep.length - 1])
    // master: prints 200, a non-K in a K[]

#### Mechanism

`narListDeliveryErr` (`check_narrow_flow.vl`) runs from `assignable` at a typed delivery and
refuses when the delivered expression is the narrowed name, or a row of it. It never ran for a
destination without a type, where the value takes the narrowed `K[]` as its own type: an
un-annotated `const r = q` bound `r: K[]`, a function with an inferred return returned `K[]`, and
an un-annotated `{ ks: q }` built a `{ ks: K[] }`. An `if`/`match` delivered as `K[]` reached the
check as the `if` node, not the name. Each then flowed to a `K[]` destination unchecked.

#### Ablation

| spelling, on master | outcome |
| --- | --- |
| `f(q)`, `keep = q`, `const c: K[] = q`, `{ ks: q }` into `Box`, `return q` into `: K[]`, `all.push(q)`, `m.set(k, q)`, `[q]` into `K[][]` | refused (D4928) |
| `const r = q; f(r)` | prints 200 |
| `f(if c { q } else { e })` | prints 200 |
| `return q` from an inferred-return function, then bound `: K[]` | prints 200 |
| `const b = { ks: q }; return b` into `Box` | prints 200 |
| a lambda `() => q` | refused (the lambda reads `q` at its declared type) |
| `[...q]` | runs, a copy |
