### D3231 — printing the else remainder of an `is` record test over a record-and-scalar or record-or-null union is invalid wasm

**check-clean invalid wasm · clause 1 · open · the annotated spelling is invalid wasm on master `94670f728`; the hole spelling is a loud check reject there, and became this invalid wasm under #3289's parked D3216 candidate · found by the #3289 round-2 review (30 cells of its `ga` grid, `nulone_pr_*`) · filed 2026-09-29 against master `94670f728`**

Repro:

    type A = { v: i32 }
    function F(z: { h: A | i32 | string }) { if z.h is A { print(z.h.v) } else { print(z.h) } }
    const x: { h: A | i32 | string } = { h: "s" }
    F(x)
    // vl run: invalid module, inside `F`: type mismatch: expected i32, found (ref $type)

#### Mechanism

Not localised past the ablation. The else arm's type is the remainder (`i32 | string`, or
`null` for `A | null`), but `print` lowers the operand at the scalar i32 sink while the value is
still the union's box (or the nullable record's ref): the emitter's else-narrowing of a union
holding a record does not re-type the place for `print`. The hole spelling is refused at the pin (`print expects one scalar or string value … got A | i32 |
string`); #3289's parked D3216 candidate gave its else arm the remainder and it reached the same
emission, so a landing of D3216 must close this row first.

#### Ablation

| ingredient changed | outcome on master | needed? |
| --- | --- | --- |
| `function F(z)` | check refuses (`print expects one scalar …`) | **yes** (the annotated spelling) |
| `{ h: A \| null }` with `h: null` | the same invalid wasm | no |
| `else { print(z.h.v) }` in place of printing the field | refuses (`field 'v' is not on every member of i32 \| string`) | **yes** (printing the remainder itself) |
