### D14100 — a record binding in a generic instance is handed unconverted to a generic parameter whose field admits null

**check-clean invalid wasm · clause 1 · found grading the `ref valtype with no interned shape` family (D3914) · pre-existing on master `bb79224b2` · filed 2026-10-26 against master `bb79224b2`**

Repro:

    function len<T>(r: { v: T | null }): i32 {
      if r.v == null { return 0 }
      return 1
    }
    function outer<U>(x: U): i32 {
      const r = { v: x }
      return len(r)
    }
    print(outer(5))
    // vl check: rc 0.  vl run: invalid module, expected (ref `{v:i32|null}`), found (ref `{v:i32}`)

Want:

    1

#### Mechanism

At `U = i32` the binding `r` is built at the row `{v:i32}`, whose field is a plain `i32`, and
`len`'s instance at `T = i32` takes `{v:i32|null}`, whose field is a nullable box. The two rows
have different layouts, so the argument needs the field-widening copy. A non-generic caller
gets that copy. A caller that is itself a generic instance passes the binding's reference as
it is. The argument delivery inside an instance does not see that its record argument's row
differs from the parameter's row.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `outer` non-generic (`x: i32`) | runs, prints `1` | **yes** (the caller is an instance) |
| `len` and `outer` both non-generic | runs, prints `1` | **yes** |
| the literal passed inline, `len({ v: x })` | runs, prints `1` | **yes** (a binding) |

#### Grading list

* The witness with `const r: { v: U } = { v: x }`, which annotates the binding.
* A second delivery position: `r` returned from `outer` into a `{ v: i32 | null }` binding.
