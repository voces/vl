Repro:

    type Dot = { x: i32 }
    type Circle = { r: i32 }
    function g<T>(xs: Dot[], t: T): readonly (Dot | T)[] {
      return xs
    }
    const a = g([{ x: 1 }], { r: 2 })
    print(a.length)
    const b = g([{ x: 3 }], { x: 5 })
    print(b.length)
    print(b[0].x)
    // vl check: rc 0.  vl run: invalid module inside `g$1`

Want:

    1
    1
    3

#### Mechanism

`recordListCopy` writes the destination of a list delivery to one column per node, and a generic
body is one set of nodes for every instance. The `T := Circle` pin records the copy of `xs` into
`(Dot | Circle)[]`; the `T := Dot` instance reads that record at the same node and widens a
`Dot[]` whose destination is `Dot[]`. A clone with no record of its own also reads its template's
through `nodeSrc`. Each pin alone runs. The scalar family (`i32[]` into `f64[]`) has the same shape
once it lowers off the record.
