### D10522 — a module-scope un-annotated binding of a generic `T | string` result at a union `T` is narrowed through the wrong rep

**closed 2026-10-22 · runs, prints `3` · was check-clean invalid wasm · clause 1 · `vl check` rc 0, then `type mismatch: expected i32, found (ref $5); $5 is `union box`, struct {i32, anyref}` at the `is` · the same call printed directly is a loud emit reject, `print of a union value whose arms the tag dispatch cannot classify` · found ablating the C1 step-1 probe's union disagreements ([render-parse residue](../render-parse-residue-2026-10.md) §C1) · filed 2026-10-22 against master `ba14205a8`**

Repro:

    function f<T>(u: T): T | string { u }
    const s: f64 | i32 = 3
    const r = f(s)
    if r is i32 { print(r) }

Want:

    3

#### Mechanism

Substitution leaves the bound union nested in the call's recorded type:
`TyUnion[TyUnion(f64, i32), string]`. A narrowed read unboxes its arm only when the read names
its union box. For a module global, that name comes from `letUnionNameOf` → `unionNameOfCall`.
Neither of its sources has a row for this call. The declared return `T | string` names no
registered union, and `nodeUnionName` declines a member that is itself a `TyUnion`. So the
`is` read pushed the raw box where the arm was expected.

Inside a function, `identChainTyBoxedUnion` (the typed-IR net in `emitIdentNode`) catches the
same miss. It reaches the initialiser through `fnLetInitOf`, which has no module-scope case. That
is why only module scope failed.

#### Fix

`unionNameOfCall` (`compiler/emit_classify.vl`) falls back to `nestedUnionRowName`. When the
call's type has a union member, that function returns the `unNames` row holding its flattened
members (`unRowOfFlatMembers`). Fixture:
`tests/cases/generics/union-arg-into-generic-union-return-module-scope.vl`. It covers `const`
and `let` bindings, every arm, an argument position, a closure capture, the annotated and
explicit-argument spellings, and `f32 | i32`, three-member and `i32[] | i32` arguments.
Matrix templates: `generic-union-arm-result{,-narrowed}.matrix.vl`.
