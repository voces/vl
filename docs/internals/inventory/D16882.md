### D16882 — a string or list built-in method called on an un-annotated parameter is refused at the pin as an unmet row demand

**closed 2026-11-16 by lane L2 · runs, prints `he` · `tests/cases/generics/member-call-builtin-on-hole-param.vl` · was loud check reject · `argument 1: expected {slice: _}, got string` · clause 2 · filed 2026-11-16 against master `2a0b71c1a` (L2, sizing the closure-receiver family)**

Repro:

    function take(a) {
      print(a.slice(0, 2))
    }
    take("hello")
    // vl check: argument 1: expected {slice: _}, got string

Want:

    he

#### Mechanism

A member call on an un-annotated parameter with no candidate in scope records a row demand
(`{slice: _}`, a field the pin must carry). At the pin `string` carries no field `slice`, so the
demand fails, though the receiver's built-in method answers the call. The member rule asks the
demand as a field, never as a built-in method at the solved receiver. A list's `.slice` is
refused the same way. A method that is no built-in is rightly refused: a list's `.indexOf` is
`std:array`'s, and it runs once imported.

#### Close (2026-11-16, L2)

`holeDemandOk` already dropped a demanded member the argument answers with a type-bound
`self`-function (`shapeLessTypeBound`). `shapeLessMethodAnswered` now also drops one the argument
answers with a built-in method (`memberRungOnTy` is `MC_RUNG_BUILTIN`), when the demand is a
call or not yet typed. The instance's re-check then asks the built-in's arity and argument types.
A built-in read as a value, or called wrongly, is refused as its direct spelling is
(`error-member-call-builtin-on-hole-param-misuse.vl`). The `<T>` spelling still refuses through
the type-parameter bound path; that is outside this row.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `take(a: string)` annotated | runs, prints `he` | **yes** (the hole) |
| `function take<T>(a: T)` | the same refusal | no |
| `a.indexOf("l")` on a string pin | the same refusal, `{indexOf: _}` | no |
| `a.slice(0, 2)` at a list pin `[7, 8, 9]` | the same refusal, `got i32[]` | no |
| `a.length` (a field read) or `a.push(4)` | runs | **yes** (a method call) |
| `a.indexOf(2)` at a list pin with `import { indexOf } from "std:array"` | runs, prints `1` | n/a (not a built-in) |
