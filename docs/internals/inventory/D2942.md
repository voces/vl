### D2942 — a hole value at a literal-union pin prints its atom `0` through a capture, `id`, `idh` or a lambda chain

**closed 2026-09-28 — the filed repro prints `b` then `s` · was check-clean silently wrong, clause 1, the same on master `8615a730d` · closed by reading a shared node at the hole instance's binding in `exprIsLitAtom`, `litAtomWidenTexts` and the generic-call pin (`monoArgTyName`) · filed 2026-09-28 against master `cab9694f8`**

Repro:

    function h(x) {
      const l = [x]
      const y = l[0]
      const k = () => y
      print(k())
    }
    const a: "a" | "b" = "b"
    h(a)
    const s: string = "s"
    h(s)
    // vl check: rc 0.  vl run: prints `0` then `s` (invalid wasm on master `cab9694f8`)

Want:

    b
    s

#### Mechanism

A literal-union value is an interned `i32` atom. Read back through a capture, a generic call or a
lambda chain, it is typed at the hole's variable. A direct read alone resolves through the
checker's one banked pin, which a second instance makes ambiguous, and a capture alone found no
member texts, so `print` took the `i32` path or refused. `exprIsLitAtom` and `litAtomWidenTexts` now ask `holeOperandTyOf` first, and
`monoArgTyName`'s hole rung pins a generic call's argument at the literal union (`id(l[0])`,
`idh(l[0])`, a nested hole call, a recursive capture), except for the instance's own parameter,
whose annotation channel already pins it: routing that through the rung made a local lambda's
`f(x)` invalid wasm (the `lamparam` cells). Run alone (no second instance) the capture is a loud emit reject
(`print of a literal-union atom whose type carries no member texts`). The `id(l[0])`, `idh(l[0])`
and `chain` spellings print `0` alone too, the same on master.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the `string` instance removed | loud emit reject | no (a different outcome) |
| `print(l[0])` directly, with the `string` instance | prints `0`, `s` (the same on master) | no |
| `print(l[0])` directly, alone | runs, `b` | **yes** (another instance, or a capture) |
