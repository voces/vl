#### Mechanism

The spelling gate (`i32MapPeelWrappers`, `i32MapSpellingUnsupported`, emit_collect.vl) peels a
function type's RESULT, a list layer and a `| null` to reach the map leaf, but never a
function type's PARAMETER, so any annotation that spells an integer-keyed map in a parameter
of a function type is refused before the signature is built. The `$fnsig` key itself has the
token: the same `g` bound to an un-annotated `const` and called with `null` at
`{[i32]: i32} | null` runs.
