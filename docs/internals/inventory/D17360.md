### D17360 — a `let` holding a field read of a record (`let m = holder.v`) of a record of two un-annotated-function records, reassigned under a runtime `if` and returned, builds an invalid module

**check-clean invalid wasm · clause 1 · found by lane IR-M1 next to D17131's fix · filed 2026-11-24 against master `8328c904b`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function mk(k: i32) {
      const holder = { v: { r: { f: inc0 }, s: { f: dbl } } }
      let m = holder.v
      if k > 0 { m = { r: { f: dbl }, s: { f: dbl } } }

#### Mechanism

D17131's shape with the copy made through a field read of a record (`let m = holder.v`) instead of a plain read. D17131's close counts the
writes of an un-annotated `let` whose initialiser is a read of the binding (`fnLetCopiesOf`,
`recLetCopySrcOf`); this initialiser is no such read, so the reassigned literal still builds at its
own row.
