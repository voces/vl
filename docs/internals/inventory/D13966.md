#### Mechanism

The hole-argument judge in `check_calls.vl` runs for an argument that is an `Ident` with two or
more written functions, or one `holeFnReadsSlot` accepts. A call argument is neither:
`holeFnReadsSlot` walked the call's returns to the `let` read, and accepted only slot and choice
reads, not a re-pointed `let`. So `holeLetJudge` never saw the binding. The direct call takes
the call-result path, which judges every read, and refused.
