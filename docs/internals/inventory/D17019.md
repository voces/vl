### D17019 — a named function returning a generic, handed to a hole parameter that calls its result, has no instance

**loud emit reject · `emitProgram: a function-value call has no interned signature — parameter 1 of type _ has no representation in the function-value ABI` · clause 2 · open · `vl check` rc 0 · the same maker written as a `const` lambda runs (D16131); `run`'s parameter annotated runs · split from D16131 · filed 2026-11-19 against master `c68092bea`**

Repro:

    function inc(x) { return x + 1 }
    function mk() { return inc }
    function run(f) { return f()(41) }
    print(run(mk) + 1)
    // vl check: rc 0.  vl run: the refusal above, at `f()(41)`

Want:

    43

#### Mechanism

Closing a named maker as `elabHoleLamsGather` closes a lambda (`elabArgLam` taking a named function
with no type parameters) gives `run` the closed key `() => ((i32) => i32)`, but mono still hands
`mk` through the hole argument's set path as its direct id: the call passes `i32.const` where the
instance takes a closure, an invalid module. A lambda takes `monoDeliverLamLit` and is built as a
closure. Closing the named spelling needs mono's set path to defer to the closed key.
