#### Mechanism

The closing that serves a lambda maker (`elabHoleLamsGather`) takes a named function too only at
the cost of an invalid module: the named `mk` is also a value of its own declaration type, which
its other reads keep, so closing its type at the call's builds two signatures for one function.
