### D2462 — a closure stored outside its narrowing reads a name the same function rewrites afterwards at the stale member

**loads then traps · clause 1 · filed 2026-09-25 against master `2bf40476c`, found grading
[D2448](D2448.md)'s close · open**

Repro:

    function m() {
      let v: f64 | boolean = 1.5
      let c: () => f64 = (): f64 => 0.0
      if v is f64 { c = (): f64 => v * 2.0 }
      v = true
      print(c())
    }
    m()
    // vl check: rc 0.  vl run: wasm trap: cast failure

#### Mechanism

Not yet ablated to the rung. The lambda escapes the guard by assignment to an outer `let`, and
the function that made it writes `v` afterwards, directly rather than through a call, so neither
of D2402's checks fires: the escape test widens a capture some function may write, and the
in-function check refuses a writing CALL after a nested function read the name. The lambda body
is typed at the narrowing and the emitter replays it (`capNarrowRecord`), so `c()` reads the
cell as the f64 member after `v = true`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the write `v = true` | runs, prints `3` | **yes** |
| the escape (`c()` called inside the `if`) | runs | **yes** |
| the local (a module global `g`, written at module scope) | traps the same | no |

#### Grading list

The module-global spelling (`let g`, the same four lines at module scope) and an index cell
`xs[0]` of a `(f64 | boolean)[]` local written `xs[0] = true`: both were check-clean invalid
wasm until D2448/D2450's close made the lifted body read the narrowing, and both trap the same
now. The index cell and a field `o.v` are also [D2407](D2407.md)'s path question, which waits on
a ruling; the bare-name spellings need none, since D2402's escape rule already answers them.
