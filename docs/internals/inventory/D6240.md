#### Mechanism

From the ablation and D6202's close. D6090's close instances `mid` with `a` and `b` each at
their own pin, so the recursive call hands each to a position pinned at the other type. The
un-annotated spelling is split per type by the plan; this spelling is refused at the call
instead of emitting invalid wasm, because a hand-applied split leaves the slot parameter
that is only handed on with no pin under `F`.
