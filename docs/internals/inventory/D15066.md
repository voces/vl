#### Mechanism

A call through a value of a set resolved its callee to no declaration (`CSTR_NODECL`), so its
re-check judged every generic constraint in the program at its argument types. The adapter built
for `f` calls through `{id, loud}`, and `mk`'s binding `k` of the same set was judged at `i32`.
Closed: while such a call's constraints are judged, `cstrOwnedBy` takes only the set's members as
owners (`cstrSetOwners`), when every member is a named function; a lambda member's constraints
belong to its encloser, so a set holding one keeps every owner.
