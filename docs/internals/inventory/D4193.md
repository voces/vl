### D4193 — a null-only list literal that already carries a type error is refused a second time

**loud check reject · `push: cannot add i32 to null[]` · the first refusal is right, the second is the defect · filed 2026-10-12 against master `040ff8a3d` · found by the review of [D1832](D1832.md)'s close**

Repro:

    let xs = [null]
    xs.push(1)
    print(xs.length)
    // vl check: rc 1, "push: cannot add i32 to null[]" at 2:1, then "a list of only `null` has
    // no element type" at 1:10.  Should report the first alone.

#### Mechanism

D1832's refusal runs at program end over every null-only literal no typed destination took,
whatever else the program was refused for. The same pair stacks on `xs = [1]` (`cannot assign
i32[] to null[]`); the review also saw it beside `as`, `==` and a UFCS refusal.
