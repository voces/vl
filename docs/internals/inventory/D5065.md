#### Mechanism

#3830 (`e2d96e401`, D4854) put `valueUnionBoxList` (emit_classify.vl) on the path of every
`exprListRepOf` call that no recorded primitive list answers, ahead of `syntacticListRep`. It
calls `nodeTyInOf` (emit_ty_canon.vl), which walks the node's recorded type for a type variable
(`tyHasTyVarAt`, tyquery.vl) to decide whether to instantiate it, and then `columnListRep`. The
`exprListRep` memo lasts one outermost query, so the walk is repeated by every query that
reaches the node. The self-compile went from 81.47G to 91.06G fuel (+11.77%) across that one
commit; in a `--names` guest profile `nodeTyInOf` went from 0.40% to 6.35% inclusive and
`tyHasTyVarAt` from 0.83% to 6.62%. On `7ce930c32`, `valueUnionBoxList` is 6.12% inclusive.
