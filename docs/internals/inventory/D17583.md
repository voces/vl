#### Mechanism

`m`'s value type is the open hole function, while its mv slot stores `lap`'s two-signature bundle record (D17094). Legacy's index read, `get` and `.has` reach the slot and run. This position asks for the map value's rep off the open type and finds none, so it refuses with the generic map-value sentence. The same refusal happens on the IR side, so it is not the IR's. Not ablated into the emitter further.

Traced 2026-11-25 by SOUND (family A), parked (coordinator). The map side can be accepted: a
`CW_UP_COAL` index read whose `??` result a holder takes whole (`elabSlotHolderOk`). The other operand,
`const d = lap(…)`, is then the refusal: a call-held holder whose read counts (`elabHolderRecordWith`)
have no category for a `??` operand, so `lap`'s call is refused at `d`'s store. A close needs a
coalesce category in the res-holder read classification as well.
