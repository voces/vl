### D14799 — a write's bare string-literal value is recorded as a string but lowered as its place's literal-union atom

Repro:

    type K = "a" | "b"

    function setK() { return (k = "b") }
    const r = setK()
    print(r)
    print(r == "b")

Want:

    b
    true
    b

#### Mechanism

An assignment yields its right side at its own type, so `setK`'s recorded result is the literal
type `"b"`, whose `$fnsig` token is the string's (`>S`). The lowering keys the result at the
place's literal union, the `K` atom (`>i`). Every consumer reads the atom correctly, so the
program runs; the two records disagree only in the token. A setter's tail write
(`self.kind = "a"` in a `"[]="` over a `"a" | "b" | "c"` field) is the same shape with the
result unconsumed.

The recorded-result flip keeps the derivation for a literal result (`srrNamesShape`), which is
why this runs. The pin is for a later flip that reads a literal result from the column: the
token it records has to be the atom the place lowers, or this program stops running.
