### D8121 — the else of `m[k] is i32` over a null-free `i32 | K` map cell has no member set for the `K | null` it leaves

**closed 2026-10-20 by lane L6 · the else of an `is` over a map read registers the read type's own member set, `null` included, and a read whose inline literal members render apart from the value's spelling takes the row that spelling names; the repro prints `b`, pinned by `tests/cases/literal-unions/map-read-is-else-litunion-arm.vl` · was check-clean invalid wasm · clause 1 · found closing [D8120](D8120.md) · filed 2026-10-20 against master `532d50d35`**

Repro:

    type AB = "a" | "b"
    const m: { [string]: i32 | AB } = Map()
    m["k"] = "b"
    if m["k"] is i32 { print(0) } else { print(m["k"]) }
    // vl check: rc 0.  vl run: invalid module, expected i32, found (ref $N) union box

Want:

    b

#### Mechanism

The read's type is `i32 | AB | null`, the `null` a missing key's, while the map's value
union is `i32 | AB`. `pushIndexMapComplement` subtracts `i32` and adds the `null` back,
spelling `AB | null`, and looks for the id of that set in the read type's row. No row is
registered for `i32 | AB | null` in this program, so the narrowing is pushed by name with no
set, `narrowedNulLitAlias` declines it, and `print` takes the checker's `AB | null` to the atom
path over the box. With `null` in the map's value type (D8120) the row exists and it runs.

The close has two halves. `emit_collect.vl` registers the read type's set for the operand of
every `is` over a map read. With the members spelled inline (`i32 | "x" | "y"`) that set's
text renders as `i32|string|string|null` and never equals the survivors `string|null`, so
`pushIndexMapComplement` falls back to the set the value spelling names with `|null` added.
