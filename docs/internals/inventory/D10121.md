### D10121 — a list of a generic pushed a fixed-type function, returned by an un-annotated function into an annotated binding, passes check and traps

**trap after load · `vl check` rc 0 · `wasm trap: indirect call type mismatch` · clause 1 · found closing [D10080](D10080.md) · present on master `3931f9468`, unchanged by D10080's close · filed 2026-10-22 against master `3931f9468`**

Repro:

    function id<T>(x: T): T { x }
    function inc(x: i32): i32 { x + 1 }
    const ys = [id]
    ys.push(inc)
    function deliver() { return ys }
    const v: ((x: string) => string)[] = deliver()

The owed outcome is a check refusal, as `const v: ((x: string) => string)[] = ys` refuses.

#### Mechanism

[D10080](D10080.md)'s close judges the write rows of the binding a delivery's SOURCE names
(`ctnBindingDeclOf`, an identifier or an index of one). Here the source is the call
`deliver()`, whose inferred return carries `((T) => T)[]` from `ys`, and nothing follows a
call to the binding its body returns.
