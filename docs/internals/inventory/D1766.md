#### Mechanism

**The filed mechanism was predicted, not probed, and the probe splits it in two.** Instrumented
at the print ladder, beside the controls that run:

    else-less string  (SILENT) nulStr=0 nulBool=0 unionPlan=0 exprUnion=0 exprStr=1
    else-less boolean (runs)   nulStr=0 nulBool=1 unionPlan=0 exprUnion=0 exprStr=0
    declared string|null(runs) nulStr=1 nulBool=0 unionPlan=0 exprUnion=0 exprStr=0
    bound else-less   (runs)   nulStr=1 nulBool=0 unionPlan=0 exprUnion=0 exprStr=1

`exprNullableString` answers **0** for the direct if-expression and **1** for the bound ident
and the declared call, so the ladder falls past every niche and box arm to `exprString` and
emits the plain-string print over a `(ref null $str)`. Its sibling `exprNulBool` opens with a
typed-IR leg — `if nodeTyIsNulBool(exprIx) { return true }` — and `exprNullableString` had none,
which is exactly why the boolean arm of the identical shape already ran.

**The HOLE-parameter face is a second reader, and it is the pin.** Probed at
`monoArgPinName`:

    else-less string (SILENT)  ladder=[string]       ownTy=[string|null]
    declared string|null(runs) ladder=[string|null]  ownTy=[string|null]
    bound else-less  (runs)    ladder=[string]       ownTy=[string|null]
    else-armed       (runs)    ladder=[string]       ownTy=[string]

The ladder answers the THEN arm where the node records the join, so the instance's parameter
cell is `(ref $str)` and the argument is `(ref null $str)`. The bound spelling survives the same
pin because its local cell is already the niche and the delivery coerces; the direct
if-expression has no such cell. The pin widens to the recorded `T | null` where the ladder chose
its non-null part — the safety argument the channel already uses, since a non-generic function
carrying that annotation lowers the same program, which the declared control proves.

[D1753](D1753.md)'s close put an arena rung inside `monoArgTyName` for any value the checker
recorded as nullable, and it does NOT reach this one: removing the widening leaves the string
face check-clean invalid wasm on a tree that carries it, because an earlier arm of that ladder
claims the if-expression before the arena rung is asked. The widening sits after the ladder,
which is why it catches what the ladder already answered.
