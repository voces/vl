### D1852 — a spread of a `u8[]` mixed with an integer literal joins to `(u8 | i32)[]`, which has no list rep

**loud emit reject · filed 2026-09-07 against master `5ab3bb8d8`**

Repro:

    const bs: u8[] = [1, 2, 3]
    const c = [...bs, 9]
    print(c.length)
    // vl check: rc 0.  vl build: emitProgram: '.length' on a receiver the emitter cannot classify as a list, string, map or set

#### Mechanism

The ordinary list literal never produces a `u8` element: an element READ widens it, so
`[bs[0], 9]` and even `[bs[0], bs[1]]` both type `i32[]` and run. `checkSpreadArrayLit`
contributes the SOURCE's own `aElem` instead, which is the `u8` the packed list really has —
more precise, and the reason D1850's pure-spread case can be classified at all. Mixing the two
then joins `u8` with the literal's `i32` into `(u8 | i32)`, a union with no list rep, and the
receiver falls off every classifier.

The question the row owes is whether an integer literal should ADOPT the packed element the
way it does under an annotation — `const c: u8[] = [...bs, 9]` runs and prints `4` / `9` — or
whether the join is right and the refusal should name the annotation. It is a literal-adoption
rule in a join, not the cell-ladder question D1850 was, which is why it is its own row.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the literal (`[...bs]` alone) | runs | **yes** |
| the spread (`[bs[0], 9]`) | runs — the read widens to `i32` | **yes** |
| the missing annotation (`const c: u8[] = […]`) | runs, prints 4 / 9 | **yes** |
| the `u8` element (an `i32[]` source) | runs | **yes** |

#### Grading list

`tests/cases/lists/spread-u8-packed-list.vl` is the running twin and must keep running: it
covers the pure spread at six deliveries, and a fix here must not disturb them. `[bs[0], 9]`
and `[bs[0], bs[1]]` type `i32[]` and run today, which is the control that says the ordinary
literal widens where the spread preserves — a fix that makes the spread widen too would close
this row by losing D1850's, so the two must be graded together.
