### D15714 — a maker's call delivered where a field is a union of its scalar is kept there, so its calls at its own type are refused

**closed 2026-11-11, runs and prints `6` then `true` · was a loud check reject, clause 2, `this value is built as K where line 3 delivers it, and it is handed on here at its own type` · closed by the copy gate (`recCopyBoxesOnly`, check_fit_rules.vl; `rcWrapKind`, wasmEmit.vl): a scalar field copied into a union listing it is boxed there as into its nullable, so the delivery at `K` copies the call and `mk2` keeps its own record · graded by `scripts/capability-probes/matrix/kept-maker-delivery-union.matrix.vl` · found closing D15691 · filed 2026-11-11 against master `161d481c`**

Repro:

    type K = { f: i32 | string }
    function mk2() { { f: 6 } }
    const wideK: K = mk2()
    const xs = [mk2()]
    print(xs[0].f)
    print(wideK.f is i32)

Want:

    6
    true

#### Mechanism

Not ablated. The fresh-call copy is offered only where `recCopyBoxesOnly` holds: each field stored
as the call stores it, or a scalar boxed into `scalar | null`. `i32` into `i32 | string` is a
scalar boxed into a union that is not its nullable, so `wideK`'s delivery keeps `mk2` at `K` and
the list's call at its own type refuses.
