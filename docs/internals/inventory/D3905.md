### D3905 — an alias of a capturing nested generic first called at one type, then delivered at another, builds invalid wasm

**check-clean invalid wasm · found in review of #3479 (`rv3479-witnesses/e1_firstcall_other_type.vl`) · filed 2026-10-09 against master `ce183bab5`**

Repro:

    function call(f: (n: i32) => void) { f(1) }
    function outer<T>(x: T) {
      function inner<U>(u: U) { print(x); print(u) }
      const k = inner
      k("first")
      call(k)
    }
    outer(7)
    outer("s")
    // vl check: rc 0.  vl run: invalid module inside `outer$1`

Want:

    7
    first
    7
    1
    s
    first
    s
    1

#### Mechanism

D3887 renames the alias's initializer to the frame's instance at the FIRST call through it, here
`inner` at `string`. `call(k)` then delivers that closure where `(n: i32) => void` is wanted.
A value read of the alias needs the instance its delivery type names, as `call(inner)` gets.
The review also found it with `k(2.5)` then an `i32` list, and `k(true)` then a return.
