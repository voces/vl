### D8281 — an un-annotated parameter bound at a null-narrowed `i32 | K | null` box is cloned at the set with `null`, so its `is i32` else refuses to print

**closed 2026-10-20 by lane L1 · the witness prints `b` · was a loud emit reject · clause 2 · the same on master `82bf510a3` · fixture `tests/cases/generics/narrowed-literal-union-box-at-hole-param.vl` · found closing [D8180](D8180.md) · filed 2026-10-20 against master `82bf510a3`**

Repro:

    type AB = "a" | "b"
    function g(v) {
      if v is i32 { print(v + 1) } else { print(v) }
    }
    const r: i32 | AB | null = "b"
    if r != null { g(r) }
    // vl check: rc 0.  vl run: emitProgram: print of a union value whose arms the tag dispatch cannot classify

Want:

    b

#### Mechanism

It is [D8180](D8180.md) at a parameter. The checker types the call's argument at the narrowed
`i32 | AB`. The instance clone's parameter renders `i32 | AB | null`, the set of the box it is
handed. So `is i32`'s else reads the box at `AB | null` against a type of `AB`, and `print`
finds no arm set. D8180's close pushes the binding's set less `null` in a body. A parameter
has no initializer in its body, so the close belongs where the instance binds the parameter
(emit_mono.vl / fn_split.vl).

Closed in `monoNarrowedPinName` (emit_mono.vl): a narrowed argument whose render softens its
literals pins at the union's own arms less `null` (`monoNarrowedNonNullPinName`), registered as
a pin union, when the checker's narrowed type has exactly one arm fewer than the binding's.
