### D16374 — a parenthesised value `if` of constant arms, at a wider destination or beside a wider operator peer, emits invalid wasm

**check-clean invalid wasm · `type mismatch: expected i32, found i64` (or `found f64`, `found f32`) · 18 of 21 reduced programs of the oracle's arithmetic fuzz (8 seeds) carry the spelling · the operator-peer spelling is the one [D16373](D16373.md)'s grading list named · found by the independent oracle (`scripts/oracle/fuzz.sh`) · filed 2026-11-15 against master `6c486842e`**

Repro:

    const c = true
    const y: i64 = (if c { 7 } else { 9 })
    print(y)
    // vl check: rc 0.  vl run: invalid module, type mismatch: expected i32, found i64

Want:

    7

#### Mechanism

D16373's close types an `if` whose tails are all constants at the destination its literals adopt
(`numLitAdoptDeepJoin`). The parentheses hide the `if` from that walk, so it keeps its arms'
default i32 while the checker types the expression at the destination. The same holds when the
parenthesised `if` is an operand: its peer's type (i64, f64, f32) reaches the checker but not the
`if`'s arms.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the parentheses (`const y: i64 = if c { 7 } else { 9 }`) | prints `7` | **yes** |
| the wide destination (`const y = (if c { 7 } else { 9 })`) | runs | **yes** |
| a typed arm (`else { v5 }`, `v5: i32`) beside an i64 peer | prints `12` | **yes** |
| a destination: an i64 operator peer instead (`v2 + (if c { 1000 } else { 255 })`) | still invalid | no |
| i64: an f64 destination (`const y: f64 = (if c { 7 } else { 3 })`) | still invalid | no |
| i64: an f32 peer with float arms (`v + (if c { 3.0 } else { 0.1 })`, `v: f32`) | still invalid | no |

#### Grading list

Each still-invalid spelling above, a `match` of constant arms in parentheses, and
[D16376](D16376.md), which may share the walk.
