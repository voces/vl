### D6707 — a hole function forwarded through a second hole parameter to one that calls it at two types is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: `apply2(add)` called directly runs ([D6481](D6481.md)) · found closing [D6481](D6481.md) · filed 2026-10-18 against master `ca2adfdc7`**

Repro:

    function add(a, b) { return a + b }
    function apply2(g, n: i32 = 1) {
      print(g(n, 2))
      print(g(1.5, 2.5))

#### Mechanism

From the ablation only. The plan reads `apply2`'s parameter as `add` only when each call hands it
`add` by name; `fwd` hands it `h`, a parameter, which the plan does not follow to `fwd`'s own
callers.
