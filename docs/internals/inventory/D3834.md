### D3834 — a generic called from a lambda argument over a nested list or generic record pins `T` to the wrong shape when the callback's own parameter is un-annotated

**closed (2026-10-08, lane SC) · was loud emit reject · 3 shapes found in review of lane SC · filed 2026-10-08 against master `5a281ef27` · pins: `tests/cases/generics/callback-pin-nested-record-list.vl`, `tests/cases/modules/callback-pin-names-nested-record/`**

Repro:

    type A = {x:i32}
    type B = {x:i32}
    function h<T>(x: T) { x.x }
    const a: A = { x: 4 }
    print([[a]].map((xs) => h(xs[0]))[0])
    // vl check: rc 0.  vl run: rc 1, emit error `emitProgram: field access receiver is not a struct`

Want:

    4

#### Mechanism

D3820 (#3431) instantiates an un-annotated callback at the parameter types the checker gives
it, and names each by the type's render, or by a record's declared name only at the top. A list
of records rendered structurally (`{x:i32}[]`), so the element lost its name, and `h(xs[0])` was
instantiated at a pin that is not the record. A same-shaped second record made it decline to
the template path, which was invalid wasm for the `self`-function shapes (a) and (c). The pin
is now spelled by `monoLamPinName`: a declared record by its name at any list depth, and a
generic record's instance by its application (`Box<A>`, and `Box<A[]>` since D3863). An inline
`{ v: A }` beside `{ v: B }` still declines.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the second record `B` of the same shape (`type B` deleted) | still loud emit reject | no |
| the nesting (`[a].map((xs) => h(xs))`) | loud emit reject, same message | no |
| the lambda (`print(h([a][0]))`) | prints `4` | **yes** |
| the callback's annotation (`(xs: A[]) =>`) | prints `4` | **yes** |
| the generic (`h(x: A)`) | prints `4` | **yes** |

#### Grading list

* (a) Two modules each exporting a `d(self:)` for a same-shaped `A` and `B`, `h<T>(x: T) { x.d() }` and `[[b]].map((x) => h(x[0]))`: check-clean invalid wasm inside `h` (`expected (ref $1), found i32`), the four-file program `rvSC/p/a1` reduced.
* (c) The same two modules with `Box<T> = { v: T }`, `[ba].map((x) => h(x.v))` for `ba: Box<A>`: check-clean invalid wasm inside `h` (`expected (ref $0), found i32`), the program `rvSC/p/a4/l1.vl`.
* `[a].map((xs) => h(xs))` at one level: the loud emit reject above, still.
* The review's brief claimed (b) printed `4` without B; on master it is a loud emit reject with and without B.
