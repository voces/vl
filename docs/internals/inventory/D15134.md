#### Mechanism

Measured: it does not need two reps. The top-level copy needs the set tagged (`f` is called at
`i32` and `string`, and a closure carries one signature). A hole parameter delivered at a closed
function type inside its body is pinned there, so the caller converts the id through the eta
adapter and the instance only sees a closure: an argument, binding, return, field, list element
and readonly copy already work so, and a direct `push(a)` does too since `pushHoleFnToConcrete`
judges a bare hole as a binding would. The spread of a `const` list holding `a` is the one gap:
the literal's element, `a`'s read and its parameter share one hole, but pinning that hole at the
spread does not make the caller adapt (the parameter pin is read from the call's arguments), so
`ftParamStored` still keeps the set closures there and the top-level copy refuses.
