### D2101 — a covariant record reaching a function value the checker cannot name a body for is refused, because a record has no read-only spelling to say the callee only reads

**loud check reject · clause 2, the price of [D2060](D2060.md)'s close · the owner has ruled the fix, `{ readonly x }` bounds plus inferred read-only parameters (D-Q4 (c)), not yet built · filed 2026-09-22 against master `80b8c03b8`, witness moved 2026-09-23 when function-typed parameters became followable**

Repro:

    const q = { x: 1 }
    const ks = [(p: { x: i32 | string }) => { if p.x is i32 { print(p.x) } }]
    ks[0](q)
    print(q.x + 1)
    // vl check: rc 1 at `q` — it reaches the call to `ks[…]` on line 3, a function value this
    //   check cannot see the body of.  Before D2060: runs, printing 1 and 2.

#### Mechanism

D2060 refuses a covariant record delivery unless the checker can show nothing it reaches writes
a widened field. It follows a function-typed PARAMETER to every argument its callers pass (a
lambda, a declared function, another such parameter), so `apply(q, (r) => …)` and std's
`sort`/`reduce` callbacks are judged by their bodies. What it cannot follow is a function value
held anywhere else — a list element (the witness), a record field (`h.f(q)`), a lambda bound to
nothing whose callers are unknown, a function also read as a value — and a handle reaching a
consumer the occurrence index does not model, or a chain of calls past the depth limit
(`RCW_DEPTH_LIMIT`, about a thousand nested calls, beyond what the checker compiles today; a
chain of plain `const b = a` aliases is a worklist and has no limit). The
emitter aliases records, so there is no converting copy for an unknown to fall back on, and the
refusal is the only answer that is not silent. This is the record twin of [D1686](D1686.md) and
[D1687](D1687.md), which the owner settled for lists with a `readonly T[]` view; for records the
owner ruled D-Q4 (c): `{ readonly x }` bounds (property-access-design.md F5) plus read-only
parameters INFERRED from the body, so the function value's own type can state it never writes.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the list (`const k = (p: …) => …` then `k(q)`) | runs | **yes** |
| the widened field (`{ x: i32 }` throughout) | runs | **yes** |
| `q`'s record, passed as a fresh `{ x: 1 }` literal | runs | **yes** |
| the list, as a record field `h.f(q)` | still refused | no |

#### Grading list

The witness and its record-field twin must run once D-Q4 (c) is built — with the lambda's
parameter inferred read-only from its body, or spelled `{ readonly x: i32 | string }`.
