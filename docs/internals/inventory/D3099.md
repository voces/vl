### D3099 — a module global annotated with a union of a record, `null` and a scalar is given a struct cell

**loud emit reject · clause 2 · 11 of [D3074](D3074.md)'s un-ablated cells (every lane-LP `nulrec` cell that narrows a `Circle | null | string` binding) · filed 2026-09-28 against master `e1e40ac99`**

Repro:

    type Circle = { r: i32 }
    const q: Circle | null | string = { r: 4 }
    print(q is string)
    // vl check: rc 0.  vl run: emitProgram: ref valtype with no interned shape

Want:

    false

#### Mechanism

Not fixed here. `globalCellKind`'s annotated ladder reaches `letIsStruct` before anything claims
the union: `letIsUnion` (through `letAnnIsUnion`) answers false for the inline
`Circle | null | string` at module scope, and `letIsStruct` then answers from the object-literal
initializer, so the cell is declared `struct` with no row. The same binding inside a function
runs, so the local ladder's classification of the annotation is the reference.
