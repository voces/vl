### D3099 — a module global annotated with a union of a record, `null` and a scalar is given a struct cell

**closed · an inline union annotation spelled in a different member order adopts the registered spelling, so the global cell ladder finds the union · fixture `tests/cases/globals/nullable-record-union-global.vl` · was loud emit reject · clause 2 · 11 of [D3074](D3074.md)'s un-ablated cells (every lane-LP `nulrec` cell that narrows a `Circle | null | string` binding) · filed 2026-09-28 against master `e1e40ac99`, closed 2026-09-28 against master `f14a8cca2`**

Repro:

    type Circle = { r: i32 }
    const q: Circle | null | string = { r: 4 }
    print(q is string)
    // vl check: rc 0.  vl run: emitProgram: ref valtype with no interned shape

Want:

    false

#### Mechanism

`collectInlineUnionsIn` registered `Circle | null | string` as `Circle|string|null`, and the
annotation kept its own spelling, so the module-global ladder's name-keyed union test missed
and `letIsStruct` claimed the cell from the object-literal initializer. `annAdoptRegisteredName`
rewrites a binding's inline annotation to the registered name, so every name-keyed reader
finds the one row the value is boxed at. The grid's generic cells then needed the pin of a
narrowed `Circle | null` out of the wider box, which the whole-spelling membership test could
not see: `monoNarrowedNulRecPinName` pins at it when the record and `null` are both arms.
