#### Mechanism

The callee's write never reaches the binding. A bare `const x = []` handed to the same `take` runs: `calleeWriteRow` names the binding's open list and `flushUninferred` pins it at the body's `string` push (D3746). The join binding's type is `_[] | null`, and nothing looks through the `| null` or into the arms. So the list keeps the default `i32` element, and the body pushes a string into it. The inline spelling `take(if c { [] } else { null })` runs since D6120, because `callSiteOpenListRows` reads the join's rows at the call.
