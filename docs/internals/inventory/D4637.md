### D4637 — a null test of a hole parameter's field has no null rep to compare against at a pin whose field cannot be null

**loud emit reject · clause 2 · the `early_return_guard` and `argument` un-annotated cells of `tagged-arm-nullable-field.matrix.vl` · a sibling of [D2806](D2806.md) and [D2962](D2962.md) · filed 2026-10-14 against master `536c4c79e`**

Repro:

    function g(v) {
      print(v.q == null)
    }
    g({ q: 4 })
    // vl check: rc 0.  vl run: emitProgram: bare null needs a struct-typed context

Want:

    false

#### Mechanism

Not localised past the ablation. [D2240](D2240.md) folds a null test of a pinned parameter
whose pin proves it non-null, and [D2962](D2962.md) is the same test one list read further in.
This is the record twin: the test reads a FIELD of the pinned parameter, the field's pin is
`i32`, and the bare `null` reaches the emitter with no operand rep to take. A pin whose field
is nullable has the rep, and runs.

| the field is read into a local first (`const w = v.q; w == null`) | still refuses | no |
| the argument is a `const` of the literal | still refuses | no |
| a union whose arm carries the field (`{ kind: "a", q: i32 \| null } \| …`, `g({ kind: "a", q: 4 })`) | still refuses | no |

#### Grading list

The matrix's `early_return_guard` un-annotated cell, which tests `v.kind` and then `v.q == null`
over a tagged arm.
