#### Close

Not the storage class the prediction named: the global's cell was already the box, and
`exprUnion` already said so. `A` is a record, so `isArmTagOfTy` has no value tag for it and
`emitIs` fell past the tag rungs to its null-test rung, which answered `w is A` as `w != null`.
That rung now declines a box receiver for any member but `null`, and the variant rung tests the
tag. Which rung spared the in-function control was not traced; the fixture pins both scopes.
Grading it found [D2373](D2373.md), a `??` over two different nullable records.

#### Mechanism

The same program inside a function answers `false` for both, so the defect is the module
global's storage class: the top-level binding of the `string | A | null` join reads `is A`
through a rung that does not test the box's tag. Before #3088 the null `w` also answered
`w == null` false; #3088's null-keeping box fixed that half and left `is A` as it was. A
prediction until a close names the rung.
