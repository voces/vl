#### Mechanism

`scripts/memo-generation-probe.vl --run` snapshots the `compiler/*.vl` files it edits into
`_scratch/memo-probe-backup/`, restores them after the probe build, and deletes the snapshot.
The copy is a read plus a write, but creating `_scratch/memo-probe-backup/` and deleting a
file have no `std:fs` spelling, so both go through `runProgram("mkdir", ...)` and
`runProgram("rm", ...)`, which ties the script to a POSIX userland. The Python it replaced
used `pathlib.mkdir`, `unlink` and `shutil.copy`.

#### Grading list

The row closes when `std:fs` has directory creation and file removal and the script calls
them. `scripts/capability-probes.vl` has the same `spawn("rm", ["-rf", ...])` and is a second
consumer.
