### D2251 — a map `??` read compared to null inline emits an invalid module

**closed 2026-09-23 — the witness prints `true` · was check-clean invalid wasm: the desugared `if` of `m[k] ?? d` took an `i32` blocktype over box arms · filed against master `3330dcaa3` · fixture `tests/cases/conditionals/if-join-nullable-inline-consumers.vl`**

Repro:

    type Err = { code: i32 }
    const arrs: {[string]: i32[] | Err} = Map()
    const moreArrs: {[string]: i32[] | Err} = Map()
    print((arrs["q"] ?? moreArrs["q"]) == null)
    // vl check: rc 0.  vl run: invalid module,
    // "type mismatch: expected i32, found (ref $type)"

#### Close

D2250's mechanism, plus one more step: `emitIfExpr`'s new union rung needs the join's union
NAME, and `unionNameOfExpr` answered `""` for this `if` — its carried type `i32[] | Err | null`
is neither a value-union spelling nor a registered row — while `exprUnion`, which classifies an
`if` by its then arm, said box. `ifJoinUnionName` now names a nullable box join no row names by
its own rendered member set, `null` included, so an arm that is a nullable niche (a `string |
null` default) boxes its null as the union's null. The ablation's `i32[]`-only
row runs on the pre-fix seed as well (that value is a nullable niche, not a box).

#### Mechanism

`m[k] ?? default` over a map whose value type excludes null, with a nullable default,
desugars (`emit_rewrite.vl`'s D2247/D2248 rewrite) to `if m[k] != null { m[k] } else {
default }` so scalar values still get their box. That synthesized if/else is exactly
D2250's shape, and feeding its value directly into an outer `==`/`!=` null compare — rather
than binding it to a local first — fails the same way: likely the same disagreeing rung
between the if/else's value-lowering and the null-compare's operand ladder. Neither the
union member `Err` nor a second map is the ingredient: a plain `{[string]: i32[]}` value type
with a non-map (but still nullable) default reproduces identically.

#### Ablation

| --- | --- | --- |

| the union member `Err` (a plain `i32[]`-only map value type) | still invalid wasm | no |
| the second map (a nullable-typed default variable instead of `moreArrs["q"]`) | still invalid wasm | no |
