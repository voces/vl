### D4308 — a `const` alias of a top-level generic, called inside a closure at the enclosing generic's `T`, builds invalid wasm at a second instance

Repro:

    function other<V>(v: V) { print("O"); print(v) }
    function a<T>(x: T) {
      const w = () => {
        const h = other
        h(x)
      }
      w()
    }
    a(2.5)
    a("s")
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `__lambda_1`: type mismatch: expected (ref $2), found f64

    O
    2.5
    O
    s

#### Mechanism

Not located. The alias `h` lives in a closure lifted for the enclosing generic, and its call
reaches one instance of `other` from both instances of `a`. The annotated spelling
`const h: (t: T) => void = other` is refused instead (`only i32, … or string parameters are
supported`). Same outcome on the step-2 seed.
