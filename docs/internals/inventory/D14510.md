#### Mechanism

One body builds one row, so two calls landing on different field storage cannot both be
served. For a function returning a record, `recSitesLandApart` sees that and refuses at the
literal's own row (D8301). The list-result arm of a call delivery (`recReturnedOrigins`,
check_fit_rules.vl) asks `recSitesLandAt`, which declines, and then adopts nothing and
refuses nothing. The literal keeps its own row, and both `sink` calls emit it where a typed
list is expected (`expected Circle[], found #anon2[]`).

#### Grading list

The record spelling (`mkcall` returning `{ r: null }`, `sink(_x: Circle)`, `sink2(_x: Tag)`)
is the D8301 refusal this row should match.
