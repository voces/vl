#### Mechanism

Not yet located. The instance is pinned at the argument's own non-null type, so the body's
`a != null` compares a non-nullable value with a bare `null` that no operand gives a rep. The
nullable argument (`const b: i32[] | null`) runs, and so does the same body called with one —
D1753 closed exactly that direction, the nullable READ pinned at its non-null half. Over a
non-null pin the test is statically true, which is the lowering it seems to be owed.
