#### Mechanism

The fifth and last of ROADMAP row 25's held-back sites, and the only one whose widening the
corpus and `tests/cases` actually enter. The site is the nullable-struct niche arm of the
paren-union element resolver: `if structIndexByName(nn) >= 0 { return 1 }`. Converting it
resolves an INLINE-SHAPE nullable element to the same kind-1 niche a declared name gets.

**The flip count clears the §11.8 bar** — `WOULD-FLIP` **26** in `tests/cases` and **3** in the
corpus, against `reached-nominal-hit` 177/12 and `reached-both-decline` 508/567. Unlike
`structIndexOfExpr#2`, byte identity here is not vacuous: the population exercises the domain.

**And the conversion gains nothing on its own.** Over 10,801 modules it gains **zero builds** —
`DIFFERING FILES` 1 in `tests/cases` (`differ/output SAME`, a shape-dedup) and **0** in the
corpus — while moving exactly one diagnostic, and moving it the wrong way:

| | message |
| --- | --- |
| base | `a nullable-{f:()=>string} list element has no rep; use a non-null element type` |
| converted | `callee is not a function name` (at line 12) |

Converting lets the element resolve and the program then refuses one layer deeper, at a site
naming neither the shape nor a remedy. **A refusal moved deeper is not a program that runs.**

**What the deeper layer is, measured after this row was first written.** Twelve closure-field
call positions all RUN, so the call layer is built and is not the blocker. The blocker is that
the LAMBDA binding's declared result type interns its element shape under a different rendering
than `structIndexByName` looks up: the same arm sees the identical name
`({f:()=>string}|null)[]` and answers **kind 2** for the lambda spelling against **kind 1** for
the named-function and direct-binding spellings. Any other declaration that interns the shape
under the annotation's own spelling repairs it, before or after — a declared alias does not.
That is the two-renderings family, and it means **this conversion is the right fix for D1922
and worthless only in isolation**: the field-set scan finds the row the exact-spelling lookup
misses. The two land together. (unfiled: D1922 — the composition row lands with that PR.)
