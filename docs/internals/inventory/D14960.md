### D14960 — a spread of an existing list of records hands each element over unconverted where one element alone is converted

**closed · a spread literal is built at its destination's list type where each source list's record element is a declared wasm subtype of the destination's, each group copied from its own backing (`rlRowElemSubOf`, `spreadGroupSubRow`) · fixture `tests/cases/arrays/spread-subtype-record-element.vl`, matrices `spread-literal-subtype-record` and `spread-into-rest-subtype-record` · was check-clean invalid wasm · clause 1 · the numeric-field face of [D13960](D13960.md), which no refusal owes · filed 2026-11-02 against master `5a736baa`, closed 2026-11-02 against master `cd74109e`**

Repro:

    type Shape = { r: f64 }
    type Circle = { r: f64, w: f64 }
    function total(...xs: Shape[]): f64 { xs[0].r }
    const cs: Circle[] = [{ r: 1.5, w: 2.0 }]
    print(total(...cs))
    // vl check: rc 0.  vl run: invalid module, type mismatch: expected (ref $type), found (ref $type)

Want:

    1.5

#### Mechanism

A `Circle` whose extra field is a number is delivered to a `Shape` one element at a time:
`total(c)` with `const c: Circle` runs and prints `1.5`, so the checker owes no refusal (the
width-drop check, `objShapeAdapterless`, finds no adapter needed) and the emitter converts the
element. A spread hands over the same elements, and since D13960 the checker judges each of them
as that single delivery, so it accepts; but the emitter builds the rest list, or a list literal
`[...cs]`, from the `Circle` structs as they are. The fix is the single delivery's element
conversion at a spread's copy. The `name: string` face is refused, as its single delivery is
(D13960).

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| no spread: `total(cs[0])` | runs, `1.5` | **yes** |
| a list parameter: `function total(xs: Shape[])`, `total(cs)` | loud check reject (drops the field `w`) | **yes** |
| `const ys: Shape[] = [...cs]` in place of the rest | still invalid wasm | no |
| the dropped field a `string` (`name: string`) | loud check reject, D13960 | **yes** |

#### Grading list

The `[...cs]` list-literal spelling, and `spread-into-rest-parameter.matrix.vl` with a wider
record element.
