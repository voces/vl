#### Mechanism

**Measured at the binding's cell, one probe.** One ingredient — a
`.pop()` off a list whose element is a UNION — produces two outcomes depending on what consumes
the popped value:

| the popped value is | outcome |
| --- | --- |
| guarded (`if t != null { … }`) | loud: `bare null needs a struct-typed context` ([D1824](D1824.md)) |
| discarded (`const _t = …`) | **silent: check-clean invalid wasm** (this row) |

The wasm says what the two have in common: the miss arm leaves a `(ref null $type)` where an
`i32` is wanted. Over `Circle[]` the null takes the element's own struct type and the same
program **runs and prints `0`**; over `Json[]` the element is itself a union, so there is no
single struct type for the null to be. The guarded spelling reaches a floor that says so; the
discarding spelling reaches no floor at all and writes the module.

**A clause-1 row outranks its loud twin**, which is why this is filed separately rather than as
a line in [D1824](D1824.md): a close for the loud one that leaves this one silent has moved the
family, not resolved it.

Probed at `addLocalName`, the one site that types a declared local, with the two element
types side by side:

    Json[]     PROBE local name=[zt] kind=[i32]       structIdx=-1
    Circle[]   PROBE local name=[zt] kind=[nulstruct] structIdx=0

The `Circle[]` pop binds `nulstruct`, the `(ref null $Circle)` niche. The `Json[]` pop matches
NO arm of the ladder and falls through to the `i32` default, so a `(ref null $uBox)` was stored
into an i32 cell. **The ladder asked the element's TYPE for a kind and none of its arms owns a
value union**, exactly as the brief predicted.

The close is the one the neighbour already uses. `emitMapGetUnionBox` answers the same question
for a union-valued MAP read: a union has no nullable niche, so its `T | null` is the box itself
with `null` riding as the box's TAG. Three rungs, one rep:

* the pop's miss arm builds the null-tagged box (`nullBoxTag()`, `ref.null none`,
  `struct.new $uBox`) and the hit arm recovers non-null, so the value is `(ref $uBox)`;
* the `let` ladder gains an arm before every nullable-niche one, binding kind `union`;
* `unionNameOfExpr` gains a `Member`-callee arm naming the element's union, without which a
  narrowed read of the popped value hands its consumer the raw box ref.

**The third rung was found by running the grid, not by reading.** With only the first two the
`is f64` position went `loud emit reject -> check-clean invalid wasm` — the capability-gap
position matrix's own warning, live in four cells.
