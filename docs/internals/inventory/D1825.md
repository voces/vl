#### Mechanism

**Not instrumented; the pair with [D1824](D1824.md) is what is measured.** One ingredient — a
`.pop()` off a list whose element is a UNION — produces two outcomes depending on what consumes
the popped value:

| the popped value is | outcome |
| --- | --- |
| guarded (`if t != null { … }`) | loud: `bare null needs a struct-typed context` ([D1824](D1824.md)) |
| discarded (`const _t = …`) | **silent: check-clean invalid wasm** (this row) |

The wasm says what the two have in common: the miss arm leaves a `(ref null $type)` where an
`i32` is wanted. Over `Circle[]` the null takes the element's own struct type and the same
program **runs and prints `0`**; over `Json[]` the element is itself a union, so there is no
single struct type for the null to be. The guarded spelling reaches a floor that says so; the
discarding spelling reaches no floor at all and writes the module.

**A clause-1 row outranks its loud twin**, which is why this is filed separately rather than as
a line in [D1824](D1824.md): a close for the loud one that leaves this one silent has moved the
family, not resolved it.

The neighbour to read first is `emitMapGetUnionBox`'s miss arm, which solves the same problem
for a union-valued MAP read by synthesising the null-TAGGED box (`nullBoxTag()`) rather than a
bare `ref.null`. **Probe the decline before believing that reading** — two attributions in this
family have already died to measurement ([D1822](D1822.md)'s and [D1823](D1823.md)'s own).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `Json` element — the same shape over `Circle[]` | runs, prints `0` | **yes** |
| discarding — guard the popped value with `!= null` | loud reject ([D1824](D1824.md)) | **yes** |
| the narrowing depth — the same shape behind a second `is` | silent identically | no |
| `.pop` for `.push`, `.clear` or `.length` | runs since [D1823](D1823.md) | **yes** |
