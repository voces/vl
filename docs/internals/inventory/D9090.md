### D9090 — a list element written with an un-annotated function of another result, read other than by a direct call through it, is called at the first function's signature

**loads then traps · `vl check` rc 0 · `wasm trap: indirect call type mismatch` · clause 1 · found closing [D9060](D9060.md) · present on master `361494943` · filed 2026-10-21 against master `361494943`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const xs = [inc0]
    xs[0] = half
    const g = xs[0]
    print(g(3))
    // vl check rc 0.  vl run: wasm trap: indirect call type mismatch

#### Mechanism

The D9060 judge runs from a call whose callee is the element itself (`xs[0](3)`). Here the
element is read into a binding, by `for f in xs`, or handed to a parameter, and the call is
made through that, so no call reaches the judge and the slot keeps the literal's
`(i32) => i32` while it holds `half`'s `(i32) => f64`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the read into `g` (`print(xs[0](3))`) | check refuses (D9060) | **yes** |
| the second result (`half` replaced by `function dbl(a) { return a * 2 }`) | runs, `6` | **yes** |

#### Grading list

`for f in xs { print(f(3)) }` after the write, and `function apply(f, v) { return f(v) }`
with `print(apply(xs[0], 3))`: both trap the same way on master `361494943`.
