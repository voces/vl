### D3704 — a generic instance where `x as? f64` always converts returns the `f64` of `(x as? f64) ?? n` where its caller holds `i32 | f64`

**check-clean invalid wasm · clause 1 · found grading [D3692](D3692.md)'s positions · the same on master `111064dda` · filed 2026-10-05 against master `111064dda`**

Repro:

    function F<T>(x: T, n: i32) { (x as? f64) ?? n }
    const r = F(2.5, 3)
    print(r is f64)
    // vl check: rc 0.  vl run: invalid module in the top-level code, expected (ref null $type), found f64

Want:

    true

#### Mechanism

Not traced. The checker types the call `i32 | f64` (the numeric-join ruling: a runtime `i32`
default beside an `f64`), and the caller reads a union box. The instance pinned at a number, where
the cast always converts, returns a bare `f64` instead: its result is classified from the
instance's own body, in which the `??`'s left side is never null. A string pin, where the cast
never converts, returns the box and runs.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `F("s", 3)` (a non-number pin) | prints `true` for `is i32` | **yes** (a pin the cast converts) |
| `F(4, 3)` (an `i32` pin) | same invalid module | no |
| the return annotated `: f64 \| i32` | prints `true` | **yes** (an inferred return) |
| `function F(x, n: i32)` (a hole) | prints `true` | **yes** (a type parameter) |
| the `??` bound to a local and tested in `F` | prints `true` | **yes** (the value returned) |
| `q ?? n` over a parameter `q: f64 \| null` | prints `true` | **yes** (an `as?` cast) |
