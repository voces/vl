### D4721 — a nullable record element read from an un-annotated record field's list cannot be compared with `null`

**loud emit reject · clause 2 · found writing D4688's second delivery position · the same on master `a254c3da4` · filed 2026-10-14 against master `a254c3da4`**

Repro:

    const w = { f: [{ x: 1 }, null] }
    const e = w.f[1]
    print(e == null)
    // vl run: emitProgram: struct equality is not supported yet

Want:

    true

#### Mechanism

Not localised past the ablation. The checker types `e` as `{x: i32} | null`, but the emitter
reads the `==` as a comparison of two records, which it refuses, rather than as a null test.
The same list bound to a local, or the field declared through an annotated record type, runs.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the list a local, `const f = [{ x: 1 }, null]` | prints `true` | **yes** (the record field) |
| `const w: W = …` with `type W = { f: ({ x: i32 } \| null)[] }` | prints `true` | **yes** (the un-annotated field) |
| `!=` in place of `==` | refused, the same | no |
| `if e != null { print(e.x) }` on element 0 | refused, the same | no |
| `print(w.f[1] == null)`, no binding | refused, the same | no |
| inside a function body | refused, the same | no |

#### Grading list

The witness, its `!=` twin, and the narrowing `if e != null { print(e.x) }` over `w.f[0]`
(should print `1`).
