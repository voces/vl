### D3151 — a closure returning an un-annotated `let` narrowed out of a box and then reassigned returns a box no print can classify

**loud emit reject · open · clause 2 · found by the #3281 review (`rv3281-5793/h/q02.vl`) · the same on master `fc4b2159f` · filed 2026-09-29 against master `fc4b2159f`**

Repro:

    function t(v: i32 | null | string) {
      if !(v is string) {
        let c = v
        c = null
        print(c == null)
        c = 4
        const f = () => c
        print(f())
      }
    }
    t(7)
    // vl check: rc 0.  vl run: emitProgram: print of a union value whose arms the tag dispatch
    // cannot classify

Want:

    true
    4

#### Mechanism

Not localised past the ablation. `c` binds the `i32 | null` box, and the closure's inferred
result is a box too, but the union it is printed as names no arm the tag dispatch can classify.
The annotated result `(): i32 | null => c` runs, so the defect is the inferred result's union
name, not the capture's rep. With the read handed on rather than printed (`const g = f()` and
then `if g != null { print(g + 0) }`) the module is invalid wasm instead.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `print(c)` in `t`, no closure | runs | **yes** (the closure) |
| `let c: i32 \| null = v` | runs | **yes** (the un-annotated binding) |
| no reassignment at all | runs, prints `7` | **yes** (a store) |
| only `c = 4`, no `c = null` | the same refusal | no |
| `v: i32 \| null` with no narrowing | runs | **yes** (the narrowing out of a box) |
| `const f = (): i32 \| null => c` | runs | **yes** (the inferred result) |
| `const g = f()` then `if g != null { print(g + 0) }` | invalid module inside `t` | no (a second face) |

#### Grading list

The witness, the only-`c = 4` spelling, and the handed-on face.
