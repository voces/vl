#### Mechanism

In `a$1` (the `string` instance) the read of `g` in the list literal names `b$1`, the seed's
instance made for a different `T`, instead of the seed this instance of `a` holds. The flow
table grades it `disagree: a local read names an instance it does not hold | reference`.
