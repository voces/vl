### D3865 — a function-scope `let` alias of a module-scope hole lambda, reassigned to a second module-scope hole lambda nothing else calls, leaves the second at its `i32` default

**check-clean invalid wasm · found by the rv3449b function-scope written-alias probes (5 of 15 programs fail on master) · filed 2026-10-08 against master `09e133eb4`**

Repro:

    const c = (y) => y + "C"
    const e = (y) => y + "E"
    function mk(x: string) {
      let d = c
      d = e
      print(d(x))
    }
    mk("a")
    // vl check: rc 0.  vl run: invalid module inside `e`, `expected (ref $2), found i32; $2 is string`

Want:

    aE

#### Mechanism

`d` is a function-scope `let` holding a hole lambda, and `e` is a hole lambda whose parameter type is
fixed by no call of its own: its only reach is the write `d = e` followed by the call `d(x)`. The call
instantiates the alias's initialiser `c` at `string`, but the lambda written into the alias is not
instantiated, so `e` is emitted at the hole's `i32` default while `d(x)` hands it a string. The nested
writer (`function w(): i32 { d = e; 0 }`, which boxes `d` into a capture cell) is not needed: the plain
write in the same function fails identically, and a write that is never read afterwards (`d = e` as the
last statement) fails too.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the write (`d = e`) | runs | **yes** |
| `e` called directly with a string (`print(e("q"))`) | runs, `qE` / `aE` | **yes** |
| `c` called directly with a string instead | still invalid, inside `e` | no |
| the read `print(d(x))` after the write | still invalid, inside `e` | no |
| the hole on the lambdas (`(y: string) => …`) | runs | **yes** |
| the function scope (`let d = c` and the write at module scope) | runs | **yes** |
| the module scope of the lambdas (both declared inside `mk`) | runs | **yes** |
| the nested writer function (write in `mk` itself) | still invalid, inside `e` | no |
| the write being unconditional (`if f { d = e }`) | still invalid, inside `e` | no |
| the string type (`i32` lambdas) | runs | **yes** |
