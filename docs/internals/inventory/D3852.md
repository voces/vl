### D3852 — a hole lambda delivered to an annotated function-typed parameter through a binding, or returned at an annotated function-typed return, is lowered at the hole's `i32` default

**check-clean invalid wasm · 31 of 600 fresh programs from the rv3445 generator (`gen2.py`, base 7000) · filed 2026-10-08 against master `5b2ec9f85`**

Repro:

    function callIt(f: (y: string) => string, s: string): string { f(s) }
    function mk(x: string) {
      const e = (y) => y + "E"
      const d1 = e

    }
    mk("a")

#### Mechanism

Not yet located. Nothing calls the lambda, so the only thing that can pin it is the contextual
type the checker recorded for it (`monoPinLamFromCheckedTy`). Passed by its own name as the
argument, it runs. Passed through a binding, or returned from a nested function with an
annotated return, it gets no contextual type. Its body is then lowered at the hole's `i32`
default, and the `+` over a string fails to validate.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the binding (`callIt(e, x)`) | runs | **yes** (argument position) |
| `const d1` for `let d1` | still invalid | no |
| the nesting (a top-level `get1` returning a top-level `e`) | runs | **yes** (return position) |
| the call, for the annotated binding `const f: (y: string) => string = e` | runs | that position already works |
