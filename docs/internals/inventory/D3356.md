#### Mechanism

A closure that assigns `y` boxes it into a cell, and the read `print(y)` then goes through the
cell's element, whose recorded type no longer carries the literal union's member texts, so the
print arm for an atom has no strings to print. A read that is not a bare print (`y ?? "none"`)
widens the atom on another path and runs. A `for` loop value of a literal union held by such a
binding meets the same refusal.

| the `null` (`let y: AB = pick(n)`) | runs | **yes** |
| the bare print (`print(y ?? "none")`) | runs | **yes** |
