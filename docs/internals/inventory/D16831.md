#### Mechanism

The refusal is raised in elaboration's instance re-check of `app` (under `elabCapLive`). In the
`string` instance, the call `f(x)` through the parameter `f` ran `holeChoiceArmCstrsAt`.
`holeLetReadsOf` follows a parameter to every call's argument (`cwParamArgs`), so it found `h`'s
`if`, which only the first call hands over. It then judged `hinc` at `string`. With that one judge
disabled, the witness runs.
