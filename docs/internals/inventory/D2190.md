### D2190 — four compiler passes re-walk a nested statement's whole subtree once per level, so compile time is quadratic in nesting depth

**closed 2026-09-23 — each pass answers a level from a memo or an index, output byte-identical · was a compile-time cost, not a miscompile: this witness took 105 s to `vl run` and now takes 2.1 s · found closing D2182, once a large stack let 10,000 levels compile at all · filed 2026-09-23 against master `66e74235a`**

Repro:

    function f(a: i32): i32 {
      let acc = 0
      @@repeat(5000, "if a > 0 { while acc >= 0 { acc = acc + 1; ")@@ @@repeat(5000, "break } } ")@@
      acc
    }
    print(f(1))
    // Prints 5000.

#### Mechanism

Read off a `--names` seed's guest profile at 10,000 levels. Each pass asked a question of a
level's whole subtree, once per level:

* `pushPostGuardNarrow` asked `stmtAlwaysExits` of every guard `if`'s arm before learning whether
  the condition could narrow anything. `condElseMayNarrow` now asks first; only an `is`, a `!`,
  or a `||` / `==` / `!=` condition can.
* The checker's `lookup`, `lookupDepth`, `isConstName` and the two function-node lookups walked
  the scope chain frame by frame. `scopeDepthsOf` inverts it (name to binding depths), kept by
  `declare` and `popScope`.
* `loopHoistOpen` ran `hoistSafeBlock` and `hoistScanBlock` over each loop's whole body. Both
  are memoised per block for one function (`hmSafe`, `hmNoIdx`).
* `emitSrcSection` (every `vl run`, and `--names`) anchored each statement row by walking back
  through the statement's tokens. `satFind` answers the same question from a min-tree over
  token offsets, built for the section and dropped after.

Seconds for `vl run` at 10,000 levels, same host, before and after:

| shape | before | after |
| --- | ---: | ---: |
| nested bare blocks | 18.4 | 0.5 |
| nested labelled `while` loops | 17.0 | 0.3 |
| nested `if`s | 10.0 | 0.5 |
| the three mixed | 16.9 | 0.4 |

All 3,371 `tests/cases` modules and the compiler build to the same bytes under both seeds, with
and without `--names`.
