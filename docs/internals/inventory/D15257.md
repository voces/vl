### D15257 — mono's static inline-shape guard is chosen by the `is` pattern's spelling

**closed 2026-11-04 by lane column-G1 · runs, prints `1` then `0` · the fold was chosen by the pattern's spelling, so a named record never ended its block · found with [D15253](D15253.md) · filed 2026-11-04 against master `d5e4c2946` by lane column-G1**

Repro:

    function g<T>(v: T) {
      if v is { meow: i32 } { print(1) } else { print(0) }
    }
    g({ meow: 3 })
    g(5)
    // vl run: 1, 0

#### Mechanism

`monoStaticIsGuardOf` (`compiler/wasmEmit.vl`) folds an instance's `if v is <shape>` only when
the pattern's text is a whole-span `{…}` shape (`nameIsWholeSpanShape`) and is not a literal
(`isLitVariantName`, which no shape can be). Whether the tested type is a record is a fact
`isVarTyIx` holds.

#### Close

`monoStaticIsGuardOf` asks whether the pattern's own type (`isPatTyIx`) is a record, named or
spelled out. The text test had excluded a named record (`v is Cat`). An instance where that guard
holds and its arm exits therefore lowered the dead tail, where `v is { m: i32 }` ended the block
with `unreachable`. Pinned by `tests/vl_named_record_guard_tail_test.ts`. `isLitVariantName`, the
last reader of a literal pattern's spelling, is deleted.
