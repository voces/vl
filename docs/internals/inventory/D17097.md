#### Mechanism

`g` is a tagged set, held as its member's `i32` id, because `ap` calls it through an open
parameter (D16094). Delivered straight to `(a: i32) => i32 | string`, as `const k: K = g`, it gets
an adapter that dispatches on the id. Handed through `id`, the instance's parameter and result
are the closure struct the destination names, and the id reaches them unconverted. Unablated: the
seam is where the tag decision meets the generic instance's pins.

#### Grading list

- `const k: K = g` and `const r: { k: K } = { k: g }` run on master and must keep running.
- `useK(g)`, the direct spelling, is D17098.
