### D4913 — a `V[] | string` parameter called with a string leaves `V` unbound and the call is refused at emit

**loud emit reject · clause 2 · found on lane D4551 probing [D4910](D4910.md)'s union receiver · not D4551's shape (a parameter names `V`, so its default does not apply) · related to D2717, D2486 · pre-existing on master · filed 2026-10-15 against master `687f37dd5`**

Repro:

    function probe<V>(v: V[] | string) {
      return 0
    }
    print(probe("s"))
    // vl check: rc 0.  vl run: emitProgram: monomorphize: unsupported argument type for `v` in a call to `probe`

Want:

    0

#### Mechanism

The argument fits the `string` arm, so inference binds nothing to `V`, and the instance has
no type for `v`'s `V[]` arm. D2717 and D2486 cover `T | null` and `T | X` with a bare `T`;
here the unbound parameter sits under a list arm.
