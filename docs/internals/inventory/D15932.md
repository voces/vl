### D15932 — a kept maker's call joined or listed beside a part built at its own row is refused, where a copy into that row serves it

**closed · now runs, prints `null` · was a loud check reject, clause 2, D14385's interim refusal `this value is built as J where line 3 delivers it, and it is handed on here at its own type` · filed 2026-11-12 against master `f050912e` · closed the same day: a call of a maker built at a wider record lands at its own row, and so takes the `null` copy, where it is a tail of an `if` or `match` beside a record literal built there (`recJoinBesideOwnLit`) or an element of a list literal beside such a literal or a spread of a list held there (`recElemBesideOwn`, check_fit_rules.vl) · fixture `soundness/kept-maker-call-beside-own-literal-copied-runs.vl` · `kept-maker-delivery-null-field.matrix.vl`'s `if_arm_literal`, `match_arm` and `spread_fresh_beside`, both faces · the rest of the template's refusals are [D15933](D15933.md)**

Repro:

    type J = { f: i32 | null }
    function mk2() { { f: null } }
    const dA: J = mk2()
    const go = [1].length > 0
    const a = if go { mk2() } else { { f: null } }
    print(a.f)

Want:

    null

#### Mechanism

`mk2` is built at `J` for `dA` and kept there, since no queued delivery lands its other call
elsewhere. The `if` joins that call with a literal built at its own row, so the join is the own
row and the call is refused as handed on at its own type. A converting copy at the call serves it.
