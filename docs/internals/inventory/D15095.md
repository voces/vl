### D15095 — a plain struct whose field is a self-recursive union arm has no field rep

**closed 2026-11-03 by lane column-G1 · runs, prints `5` · was a loud emit reject, clause 2, filed 2026-11-03 against master `cfe5c6a1b` · `internArmShapeRow` minted no twin row for a recursive arm, because coding its own field asked about the arm again and the deferred-row check declined the revisit; the mint now keeps a stack of the arms it is minting, a field naming one of them points at the name that arm's row is pushed under, and the mint's own field naming another arm with no row mints that arm first, so a cycle of arms closes on its rows as a declared record's does · fixture `tests/cases/unions/struct-holding-self-recursive-arm.vl` (before and after the arm, `O` and `O \| null`, read, walked, moved back into the union, assigned, returned, listed, nested, a binary tree, mutual and three-way recursion, an arm holder, and the arm in a list and a map) · found closing [D3329](D3329.md)**

Repro:

    type Q = { o: O | null }
    type O = { n: i32, next: O | null }
    type P = { m: i32 }
    type U = O | P
    const o: O = { n: 1, next: { n: 5, next: null } }
    const q: Q = { o: o }
    if q.o != null {
      if q.o.next != null { print(q.o.next.n) }
    }

Want:

    5

#### Mechanism

`collectS` codes `Q.o` through `armFieldStructRow`, which answers with the struct row the arm
shares its heap with. `collectNestedFieldShapes` mints that row from the arm's render ahead of
`collectS`, and for a non-recursive arm it does (the probe
`arm-with-struct-field-held-by-struct.vl` runs). For a self-recursive arm no row the
cross-table guard `variantStructHeapTwinAt` accepts exists, so the field codes `-1`.

Letting `armFieldDeferredRowOk` agree on re-entry (the arm asked about itself) is not the fix:
it codes the arm's own field `15` through the minted row, and the minted row is not the arm's
heap twin, so every program with a recursive arm then refuses with `a union arm's row is not
on the arm's heap`, the arm alone included.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `Q` declared after `O` | still refuses | no |
| `O` imported from another module | still refuses | no |
| `O` not recursive: `type O = { n: i32 }` | runs | **yes** (the recursion) |
| `type U` removed | runs | **yes** (the union) |
| `Q`'s field typed `U \| null` | runs | **yes** (the arm as the field type) |

#### Grading list

The probe `struct-holding-self-recursive-union-arm.vl`; the same holder with `O` imported; a
holder that is itself an arm; a list field `os: O[]` on a plain struct.
