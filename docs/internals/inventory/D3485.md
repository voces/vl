### D3485 — a generic whose `if` chain joins `A`, `B` and `null` is refused at emit when the pins are two number types

**loud emit reject · clause 2 · open · `a join of type parameters pinned at two number types beside a null has no box at this instance` (`compiler/emit_mono.vl`) · the same on master `e5ff25ff9`, which already carries #3327 (numeric joins) · found 2026-10-03 · filed against master `e5ff25ff9`**

Repro:

    function two<A, B>(k: i32, a: A, b: B) { if k == 0 { a } else if k == 1 { b } else { null } }
    print(two(0, 1, 2.5))
    print(two(1, 1, 2.5))
    print(two(2, 1, 2.5))
    // vl check: rc 0.  vl run: the emit refusal above

Want:

    1
    2.5
    null

#### Mechanism

The generic's own return type absorbs the null (`A | B | null`) and at `(i32, f64)` the two number
arms and the null need a box that the instance does not have, so emit refuses at the mono
instance. The non-generic twin `function two(k: i32, a: i32, b: f64) { … }` runs and prints
`1`, `2.5`, `null`, so the capability exists at the direct spelling and is missing at the pin: the
refusal names a MECHANISM, not a contract. The pins that DO run are those with a string arm, up
to the next row (D3487), which fails at run time instead.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `(i32, f64)` as filed | loud emit reject | |
| an explicit `: A \| B \| null` return annotation | same refusal | no |
| only the two number-arm calls, no `k == 2` call | same refusal (it is the instance, not the call) | no |
| only `two(2, 1, 2.5)` | same refusal | no |
| the `null` arm replaced by `b` (`if k == 0 { a } else { b }`) at `(i32, f64)` | runs, prints `1`, `2.5` | **yes**: the null beside two numbers |
| one parameter (`one<A>(k, a)` returning `a` or `null`) at `i32` | runs, prints `1`, `null` | **yes**: two parameters |
| `(i32, i32)`, `(f64, f64)` and `(string, string)` | loud emit reject, a different one: `bare null needs a struct-typed context` | the two pins coincide, so the join reads as one type |
| `(string, f64)`, `(i32, string)`, `(string, i32)`, `(string, boolean)` | check-clean, loads, traps at `two(2, …)` | see D3487 |
| the non-generic `two(k, i32, f64)` | runs, prints `1`, `2.5`, `null` | the capability is built |

#### Grading list

`(i32, f64)` through each position, the un-annotated spelling above first; `(i64, f64)` and
`(i32, i64)`; and the `(i32, i32)` spelling, which refuses with a different sentence at the same
call and should be graded with this row, not apart from it. D3369 (a boolean arm beside a null)
and D3334 (`string`, `i32`, `null` at a generic argument) share the join and should be re-run on
the same instance.
