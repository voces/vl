#### Mechanism

The generic-application bank (`genAppRowOf`, `gaAppHeads`, `genAppCarry`, D949) records which alias
application a row came from by the row's index, and `substCyclicApp` and the renderers read it back.
A row the application did not make, but equal to one it did, answers as that application: a recursive
instance re-applies where it should walk, and a plain list renders under the alias's name. The close
keys the bank on the application (head and arguments), not on the row. Which reader each witness
reaches is settled in the row's prep PR.
