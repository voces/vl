#### Mechanism

[D14817](D14817.md)'s converting delivery copies a fresh call result only where it is a direct
argument to a parameter typed `T` that a held argument also binds (`recHeldPinBare`). A call in a
list literal, beside a held element, is delivered with the list. A copy there would have to rebuild
the list's element, and the list is not built per element. So the D8301 refusal stays
([D14814](D14814.md)).
