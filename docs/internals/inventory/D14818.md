### D14818 — a fresh call's record copied at a held pin only as a direct argument; list, element, type-argument and non-null spellings stay refused where the design permits them

**open · loud check reject · clause 2 · the residue of [D14817](D14817.md) · filed 2026-11-01 against master `77241557`**

Repro:

    type Circle = { r: i32 | null }
    type K = { r: null }
    function sink(_x: Circle) { }
    function mkcall() { { r: null } }
    sink(mkcall())
    function first<T>(xs: T[]): T { xs[0] }
    const k: K = { r: null }
    print(first([mkcall(), k]).r ?? 6)
    // vl check: {r: null} is not Circle: they store field `r` differently

Want:

    6

#### Mechanism

[D14817](D14817.md)'s converting delivery copies a fresh call result only where it is a direct
argument to a parameter typed `T` that a held argument also binds (`recHeldPinBare`). A call in a
list literal, beside a held element, is delivered with the list. A copy there would have to rebuild
the list's element, and the list is not built per element. So the D8301 refusal stays
([D14814](D14814.md)).
