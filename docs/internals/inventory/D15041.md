### D15041 — a numeric join inside a generic instance whose narrow use is the enclosing type parameter is refused

**closed 2026-11-17 by lane L2 · runs, prints `0.25` · `tests/cases/generics/type-param-joins-f64-argument-at-instance.vl` · was loud check reject, `argument 2: expected i32, got f64` (raised by the instance's re-check) · clause 2 · the residue of [D2459](D2459.md)'s close · filed 2026-11-02 against master `4e73b063`, pre-existing · bucket (c), L2 inferred interfaces, secondary (d) (the 2026-11-14 clause-2 map)**

Repro:

    function mix<T>(a: T, b: T): T[] { return [a, b] }
    function w2<U>(u: U, v: f64) { return mix(u, v)[0] / 4.0 }
    const one: i32 = 1
    print(w2(one, 0.5))
    // vl check: rc 1: argument 2: expected i32, got f64 (raised by the instance's re-check)

Want:

    0.25

#### Mechanism

The template checks `mix(u, v)` with `u: U`, which is not a number, so no join is asked and the
call is typed `U`; `w2`'s result follows it. The instance `w2<i32>` re-checks the call with
`u: i32`, where D2459's ruling would join `T` at `f64`. Joining there alone hands back `f64`
from a call the template typed `U`, which built invalid wasm when tried, so an instance joins
only a call its template joined, and this one keeps the first-use refusal it had before.

#### Grading list

The callback twin, `function w<U>(u: U) { return f(u, (i) => i * 1.5) }` with

#### Close (2026-11-17, L2)

The template binds `T` at `u: U`, then meets `v: f64`. A variable an earlier argument bound to the
body's own type parameter now asks the same numeric join a narrower number asks
(`bgWidensDeclaredParam`, check_relate_core.vl). `f64` is the widest number, so the join is `f64`
at every instance whose parameter is a number, and the call is re-checked there, which marks it
joined. An instance joins only a call its template joined, so the instance's re-check now joins
too, and the template and the instance agree on `f64`.

- An instance whose parameter has no join with `f64` is refused at the call: `string`, and `i64`,
  which joins no float (`error-type-param-joins-f64-argument-not-a-number.vl`).
- A number literal (`0.5`) still adapts to the binding beside it rather than asking the join.
- The callback twin runs and prints `1.5`.
