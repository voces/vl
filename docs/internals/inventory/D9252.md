#### Mechanism

Not traced. D9183 types the outer map's record value and the reads through a `const` bound
to one (`monoRetypeRecFieldReads`, emit_mono.vl). A read path whose root is a map value read
(`mm["k"].m`) rather than a binding is not matched by `monoReadsSlotOf`, so the field's reads
keep the checker's open type.
