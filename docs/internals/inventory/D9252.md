#### Mechanism

`monoRetypeMapReads` gave the map value read `mm["k"]` the closed record but stopped there:
the member read `.m` on it and the index read `["k"]` on that kept the checker's open types,
so the call through `x` had no signature. `monoRetypeRecMemberReads` now walks member reads
rooted at a retyped read, nested records included, and `monoRetypeHeldFnReads` types the
index and `.get` reads of a function container found there, and the reads of a `const` bound
to one (nullable for a map read).
