#### Mechanism

Not traced. A read the value-flow rewrite resolves to one function (`mfrChainFns`) is rewritten to
a direct call, which instances the function at its arguments; a read it cannot resolve leaves the
function a value, which the value floor refuses because a hole function carries no one signature.
Instancing a hole function taken as a value at the concrete function type its reads give it is
the general fix; extending the rewrite covers only reads resolvable before running.
