### D16748 — a binding of an element of a hole parameter's list of function lists dispatches through one signature

**closed 2026-11-16 — the witness runs and prints `1.5` · was: check-clean trap · `wasm trap: indirect call type mismatch` · clause 1 · found closing [D16742](D16742.md) · filed 2026-11-16 against master `e056e7cea`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function run(xs) {
      const y = xs[1]
      print(y[0](3))
    }
    run([[inc0], [half]])
    // vl check: rc 0.  vl run: wasm trap, indirect call type mismatch

Want:

    1.5

#### Mechanism

The instance's call facts (`elabMintFactAt`, `compiler/emit_elab.vl`) follow a callee to the
parameter it reads through an element alias (`elabElemCallAlias`) only when the alias is itself
the callee (`y(3)`). Read as the root of a callee chain (`y[0](3)`), the call got no fact and
was built as one closure signature over members whose results differ. The alias now accepts
every read rooting a callee chain, follows a chain off one, and takes an element read off a
`for` loop's element (`const y = x[0]`) back to the list the loop walks.

#### Grading list

- `for x in xs { const y = x; print(y[0](3)) }`: trapped after the first member; runs.
- `const y = xs[1][0]` and `const y = xs[1]` over three levels of lists: trapped; run.
- Members with one result (`inc0`, `dbl`): ran, still run.
