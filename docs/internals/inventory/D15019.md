**check-clean invalid wasm · clause 1 · with the split plan on and off · found ablating `closures/forwarded-hole-fn-to-list-element-value-param.vl` for D15018; with a second member in the hole parameter's list (`[same, quarter]`) the same shape is a loud emit reject with the split plan off, which is what that file still hits · filed 2026-11-02 against master `ebd304ac`, pre-existing**

    function add(a, b) { return a + b }
