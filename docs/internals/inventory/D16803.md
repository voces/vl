#### Mechanism

The emitter lays `w` out at its initialiser's build `J` (`letElemReadHeldTy`, `emit_classify.vl`).
The reassigned `plain[0]` is a `{ f: null }` struct and is stored into that local unconverted.
Nothing compares the reassigned values' storage with the initialiser's. With the order swapped
(`let w = plain[0]`, then `w = src[0]`), it runs.
