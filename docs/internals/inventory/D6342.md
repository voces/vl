### D6342 — a module record field holding a maker's generic result, called at two types, refuses

**loud emit reject · `vl check` rc 0 · clause 2 · found closing [D6322](D6322.md) · the same on master `5e3ba8429` · filed 2026-10-18 against master `5e3ba8429`**

Repro:

    function k<T>(x: T): T { return x }
    function mk() { return k }
    const r = { f: mk() }
    print(r.f(1))
    print(r.f("z"))
    // vl check: rc 0.  vl run: emitProgram: a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type

Want:

    1
    z

#### Mechanism

From the ablation only. A binding of the maker's result called at two types takes a slot per
type, and so does a record field holding `k` directly. A record field holding the maker's
result is followed by neither, so `k` meets no call that fixes its type.
