#### Mechanism

The refusal is D9006's (`monoBindSigFail`), reached through an un-annotated parameter: each
outer call instantiates `w`, and the binding gets one closure signature per instance where it
can hold only one. D9006's close keys a read handed to an un-annotated parameter by the call's
argument types, so the two hands read two `let`s written alike. A direct call after the hands
(`print(f(10))`) keeps the slot its own call type gives it.
