### D2647 — a lambda whose else-less tail `if` assigns a closure traps on `unreachable`

**loads then traps · `vl check` rc 0, then a compiler-emitted `unreachable` in the lambda · clause 1 · the lambda face of D2499 · found by the review of #3186, identical on master `50c627ce4` · filed 2026-09-26**

Repro:

    let gv: () => i32 = () => 0
    const f = (c: boolean) => {
      if c { gv = () => 5 }
    }
    f(true)
    print(gv())
    // vl run: wasm `unreachable` instruction executed, in `f`

#### Mechanism

This is D2499's mechanism at a lambda. The lambda's inferred result is `(() => i32) | null`, and
nothing lowers that return's fall-through `null`, so the end of the function is `unreachable`
padding. D2631 voids a named function called only as a statement, and that spelling runs, but
lambdas are not candidates. A lambda annotated `: void` runs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the lambda (a named `function f`) | runs | **yes** |
| the inferred result (`: void` on the lambda) | runs | **yes** |
