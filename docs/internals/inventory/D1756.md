### D1756 — a hole parameter fed from an INFERRED array of an inline literal union printed the interned atom id, because the pin took the element from the ARRAY's name and that name is `i32[]`

**closed 2026-09-06 — a literal-union array reps as the interned-atom i32 list, so an inferred one is NAMED `i32[]`; the element's own recorded type is exact and the litunion rungs read it instead · filed against master `dcbf7521c`, closed against `709e3e9fb` · found by `scripts/day-one/sample.py` seeds 3001-3005 (2,500 pairs), axis `named_vs_inline` · residue of [D1545](D1545.md) and [D1717](D1717.md) · 0 corpus cells**

Repro:

    function mkval(): "red" | "green" { return "red" }
    const srcArr = [mkval()]
    function take(p) { print(p) }
    take(srcArr[0])
    // vl check: rc 0.  vl run: rc 0, prints red

Spell the return type as a declared alias (`type Color = "red" | "green"`) and the same
program prints `red`; annotate the array (`const srcArr: ("red" | "green")[] = …`) and it
prints `red` too.

#### Mechanism

Probed, where the row filed it as predicted, and the prediction named the right seam and the
wrong reader. `monoArgTyName`'s `Index` arm takes an element's pin from the ARRAY's name:

| | broken (inferred) | annotated array | alias |
| --- | --- | --- | --- |
| `monoArgTyName(srcArr)` | **`i32[]`** | `("red"\|"green")[]` | `Color[]` |
| `monoAnnPinName` of its element | **`i32`** — returns | `""` — falls through | `Color` — returns |
| the ELEMENT's own recorded type | exact, renders `string` | exact | exact |

A literal-union array reps as the interned-atom i32 list, so `exprArray` names an INFERRED one
`i32[]` and that arm pins the atom's raw width before the litunion rungs [D1545](D1545.md) built
are ever reached. The annotated array escapes because its annotation names the member set; the
alias escapes because the element still names `Color`. **The element's own type is right in all
three**, which is why the arm is gated rather than the name repaired.

**The close pays one price, and it is [D1740](D1740.md)'s floor.** Pinning the inline element at
`string` makes a list literal built from that parameter a STRING list, which the collect scan
cannot name and the emit floor refuses. Four routes to that reservation were built and all four
refused on measurement — two produce invalid wasm, two also break a fixture whose declared array
genuinely holds atoms. The price is one cell, it is LOUD, and it is filed as
[D1760](D1760.md).
