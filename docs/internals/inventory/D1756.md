### D1756 — a hole parameter fed from an INFERRED array of an inline literal union prints the interned atom id, because only the annotated array's element carries the softening D1545's close gave the argument

**check-clean silently wrong · `vl check` rc 0, `vl run` prints `0` where `red` is expected · clause 1 · filed 2026-09-06 against master `dcbf7521c`, re-graded as filed on `b35b2a093` · found by `scripts/day-one/sample.py` seeds 3001–3005 (2,500 pairs), axis `named_vs_inline` · residue of [D1545](D1545.md) and [D1717](D1717.md), whose own filed witnesses both RUN on this seed · 0 corpus cells**

Repro:

    function mkval(): "red" | "green" { return "red" }
    const srcArr = [mkval()]
    function take(p) { print(p) }
    take(srcArr[0])
    // PRINTS 0
    // want: red

Spell the return type as a declared alias (`type Color = "red" | "green"`) and the same
program prints `red`; annotate the array (`const srcArr: ("red" | "green")[] = …`) and it
prints `red` too.

#### Mechanism

Predicted, not probed. D1545 closed the INLINE literal union at the monomorphization pin by
giving `monoArgTyName` the `string` soften its alias rung already had, so the argument's own
type reaches the hole parameter and the caller widens the atom to its member text. The
argument here is `srcArr[0]`, whose type comes from the ARRAY's element — and an array built
from a call to an inline-spelled function carries the member set on no node the pin reads, so
the argument falls back to the atom and the parameter is pinned at it. The alias spelling
survives because the element's type still names `Color`; the annotated array survives because
the annotation records the member set on the binding. **Two readers, two classes, exactly as
D1545/D1717 split**: `print` and `return` emit an i32 print of the interned id and are merely
wrong, `==` emits the string compare core against that i32 and the module fails to validate —
`type mismatch: expected (ref $type), found i32`. `p is string` answers `false` for the same
reason, a third wrong value the earlier pair did not name.

Needed: the inline spelling AND the inferred array AND the hole parameter, all three. Not
needed: which reader consumes the atom (that decides the CLASS, not whether it fires), the
scope, or which element is read.
