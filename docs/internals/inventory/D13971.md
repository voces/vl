### D13971 — an un-annotated parameter given a record whose function field is `null` passes `vl check` and refuses at emit, through a guarded call of that field

**closed · runs, prints `none` · was loud emit reject, `vl check` rc 0, `emitProgram: callee is not a function name`, clause 2 · closed in wasmEmit.vl: a call through a callee the instance types `null` itself is the branch its guard leaves dead, and lowers to `unreachable` (D3197) · test `tests/cases/generics/hole-guarded-call-through-null-field-no-declared-row.vl` · found grading the field-set scan's deletion for #4852 · filed 2026-10-26 against master `30a8cca38`**

Repro:

    function F(z) {
      if z.f != null { print(z.f()) } else { print("none") }
    }
    F({ v: 7, f: null })
    // vl check rc 0, then emitProgram: callee is not a function name. Expected: none.

#### Mechanism

The body of `F` is judged at the call's argument type `{v: i32, f: null}`, and the guard
`z.f != null` leaves the call `z.f()` with no function type to call. The checker accepts
that body, so the emitter reaches a call whose callee has no function rep. The same
program at module scope (`const z = { v: 7, f: null }`, the same `if`) is a loud check
reject, `called value is not a function (null)`, so the two faces disagree: either the
checker owes that refusal in the instance too, or the guarded call is dead and both should
print `none`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `F`'s parameter annotated `z: { v: i32, f: (() => boolean) \| null }` | runs, `none` | **yes** |
| the `null` (`f: () => true`) | runs, `true` | **yes** |
| the guard (`print(z.f())` alone) | loud check reject, `called value is not a function (null) (the body of `F` at the call's argument types)` | **yes** |
| the function (module-scope `const z`, the same `if`) | loud check reject, `called value is not a function (null)` | **yes** |
| the field `v` (`F({ f: null })`) | same refusal | no |

Adding an unused `type R = { v: i32, f: (() => boolean) | null }` makes the repro run and
print `none`: the emitter's field-set scan takes `R`'s row for the literal by its field
names. That is the spelling the fixture
`tests/cases/generics/hole-guarded-call-through-null-typed-field.vl` holds.

#### Grading list

A second call `F({ v: 8, f: () => true })` beside the first gives the same refusal, though
the annotated parameter runs both calls.
