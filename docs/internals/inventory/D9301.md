#### Mechanism

D9254 types an inline list literal in an open record field only where the record literal goes
through `monoClosedObjLitTy`, a return or a binding. A record literal stored as a list element
or a map value is typed by `monoPinStoredRecords` (emit_mono.vl). For a field that is not
itself a function, it asks `monoClosedFieldValTy`, which knows record literals and binding
reads but not list literals, so the whole record is left open.

Once [D9300](D9300.md) closed, giving such a field its element slot's pin
(`monoStoredSlotFnTy` over path `…/f.<field>/e`) is enough for the stored spellings. The
`let` reassignment and the un-annotated parameter needed their own pins.
