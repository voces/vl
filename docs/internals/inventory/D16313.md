### D16313 — a parenthesised list literal delivered to a union with a literal-union list member is built as a string list, so `is` that member answers false

**closed · runs, prints `true` · was check-clean silently wrong, clause 1 · bucket (f) · fixed 2026-11-14: a union-coerced list is classified by the literal under its parens · 3 of the 16 unsound fuzz findings of 2026-11-14 · filed 2026-11-14 against master `fe9585a72`**

Repro:

    type K0 = "286" | "rj"
    const t0: K0[] | i32 = (["rj"])
    print(t0 is K0[])

Want:

    true

#### Mechanism

A list literal delivered to `K0[] | i32` adopts the member `K0[]` and is built as a list of the
literal union's atoms. The box's tag came from `coerceValueAtomKind` (wasmEmit.vl), whose list
arms read the delivered node: under parens, that node keeps the literal's own `string[]` type, so
the atom list was boxed under the string-list tag, which `is K0[]` does not match. The list arms
now read the paren-stripped literal, which is the node that adopted the destination's element.
The fuzz generator parenthesises every lambda body, so its three findings were a lambda's tail.

#### Ablation

| spelling | outcome |
| --- | --- |
| the witness | prints `false` |
| `["rj"]` (no paren) | prints `true` |
| `("rj")` at `K0 \| i32` (a scalar) | prints `true` |
| `(["rj"])` at `string[] \| i32` | prints `true` |
| a lambda's tail `(q0) => (["rj"])` at `(i32) => K0[] \| {w: i32}` | prints `false` |
| a function's `return (["rj"])` at `K0[] \| {w: i32}` | prints `false` |
