### D15200 — a list binding of two un-annotated functions, read at a function type with a wider result, passes check and traps

**trap after load, `vl check` rc 0 · `wasm trap: indirect call type mismatch` at the call · clause 1 · open · found grading D15199's controls · present on master `f6b19ca4` · filed 2026-11-03 against master `f6b19ca4`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    const xs = [inc0, dbl]
    const v: readonly ((x: i32) => i32 | f64)[] = xs
    print(v[1](3))

    6

#### Mechanism

Not traced. The annotated twin (`inc1(a: i32): i32` and `dbl1`) is refused at check by `fvaRefuseNested` (the functions inside a value are not converted on the way), so either this program owes that refusal or both owe a converting copy; that is the question pending as [D15093](D15093.md), which this row re-grades.
