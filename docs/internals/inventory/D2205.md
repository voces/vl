### D2205 — `is` over a DECLARED literal type refuses a test set that meets it without being inside it, while the inferred `const` spelling runs

**closed — by owner ruling (2026-09-23): an `is` against a literal set is allowed whenever the set overlaps the operand's literal type, declared or inferred, and the then-branch narrows to the overlap; only a disjoint set is refused, naming the members to declare · was loud check reject · `` `is` check type '"debug"|"x"' can never match a value of type "debug" `` · found closing D2204 · filed 2026-09-23 against the #3062 head `57e40f104` · closed 2026-09-23 · `tests/cases/literal-unions/is-literal-set-overlap-narrows-to-meet.vl`, `is-numeric-literal-set-overlap.vl`, `is-literal-set-disjoint-reject.vl`**

Repro (runs, prints `true`):

    const MODE: "debug" = "debug"
    print(MODE is "debug" | "x")

#### Mechanism

`checkIsExprNode` requires the test type to be assignable to the operand's type, because the
then-branch narrows the operand to it verbatim. A declared literal set therefore refuses a wider
or merely overlapping test set (`m: "x" | "y"` with `m is "y" | "z"` reads `is not a variant of`),
while D2204 lets the INFERRED `const MODE = "debug"` spelling test against any set its value is
in. Whether a declared set should follow is a ruling, not a defect: the rule it would replace
is the one that makes `is` narrowing sound, and an overlap would need to narrow to the
intersection instead.

The close does exactly that. `litSetMeetTy` computes the members of the test set the operand
can hold (string or numeric literals; a `null` in the operand is in neither branch's overlap).
`checkIsExprNode` banks that meet as the test's type, so the emitter tests the overlap (the same
answer for every value the operand can hold), and `collectThenNarrows` narrows the checker's
then-branch to it; the else-branch already subtracted the tested set. An empty meet is refused
in the D2198 message shape. Out of scope and unchanged: a test set with a `null` member, and
`match`, whose literal patterns are checked member by member and which refuses a union mixing
literals with other members.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the annotation (`const MODE = "debug"`) | runs (D2204) | **yes** |
| the test set narrowed to a subset of the declared one | runs | **yes** |
| a parameter `m: "debug"` instead of a const | refuses | no |
| a declared union `m: "x" \| "y"` tested with `"y" \| "z"` or `"x" \| "y" \| "z"` | refuses | no |
