#### Mechanism

A join over `T | null` and `T` has no single answer in the generic body: inside it `T | null`
is gradually assignable to `T`, so `joinTys` hands back `T`, which is unsound at any pin, and
the join rows are banked once per `if` node while the emitter lowers one body per instance.
`applyArmJoins` therefore declines any key whose entry or path type holds a type variable or a
hole, and the key reads at what the arms left it (the entry type). The fix is a per-instance
meet: record the join as a derived hole (`HD_GNOT`'s shape, one row per path) that each pin
resolves, and bank the emitter's push per instance rather than per node.
