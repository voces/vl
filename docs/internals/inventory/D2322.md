### D2322 — an un-annotated binding of an `if` whose then arm is narrowed by an `is` test takes the box cell

**closed 2026-09-24 — the witness prints `3`, `0` · was check-clean invalid wasm inside `f`, clause 1 · filed 2026-09-24 against master `f9c3f41e2` · fixture `tests/cases/conditionals/if-join-narrowed-arm-unannotated-binding.vl`**

Repro:

    function f(x: i32 | string): i32 { const n = if x is i32 { x } else { 0 }; n }
    print(f(3))
    print(f("a"))
    // vl check: rc 0.  vl run: invalid module, inside `f`:
    // "type mismatch: expected (ref $type), found i32"

#### Mechanism

[D2264](D2264.md)'s, under an `is` narrow rather than `!= null`: the join is `i32` and
`emitIfExpr` lowers it as `i32`, but `exprUnion`'s `IfStmt` arm classified the binding's cell
off the then arm `x`, read at its declared `i32 | string` because no narrow is active where the
classifier runs. The arm now answers from the join's own recorded type when that is a bare
primitive. Closed with D2264.

#### Ablation

| --- | --- | --- |
| the binding (`if x is i32 { x } else { 0 }` as the tail) | runs | **yes** |
| the binding's missing annotation (`const n: i32 = …`) | runs | **yes** |
| the narrow (an else arm of another type, `else { "zz" }`, a real union join) | runs | **yes** |
