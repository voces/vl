Repro:

    type AB = { a: i32 } & { b: i32 }
    type P = { a: i32, b: i32 }

    type R2 = { u: P }

    const r1: R1 = { u: { a: 1, b: 2 } }
    print(f(r1))

    type S2 = { u: P[] }
    function g(r: S2): i32 { r.u[0].a * 10 + r.u[0].b }
    const s1: S1 = { u: [{ a: 3, b: 4 }] }
    print(g(s1))
    // vl check: rc 0.  vl run: invalid module, expected (ref R2), found (ref R1)

Want:

    12

#### Mechanism

A non-struct-bodied declaration is a one-member union wrapping its type, so `AB` is a
`TyUnion` over the merged record. The canon key keyed that wrapper as a one-member union set,
apart from the record's own key, and the row dedup is keyed by the canon key, so `R1` and `R2`
kept two heap types. Every other notion that peels the wrapper (`tyEq`, `tySameSet`) equated
them. A lone literal keeps its one-member set, which is how a literal field stores the atom.
