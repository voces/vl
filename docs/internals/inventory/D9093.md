### D9093 — an element of a list of un-annotated functions, called inside a `.map` callback over the list, has no function to call

Repro:

    function inc0(a) { return a + 1 }
    const xs = [inc0]
    print(xs.map((f) => f(3))[0])
    // vl check rc 0.  vl run: emit error: emitProgram: call to unknown function

Not traced. The callback's parameter `f` takes the list's element, a hole function, and the
call `f(3)` inside the lambda finds no instance to call.
