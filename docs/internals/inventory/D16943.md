#### Mechanism

A list member of a value union is boxed under its list's value atom (`valueAtomKind`: 7 for
`i32[]`, 12 for `f32[]`, 13 for `u8[]`). A vector list has no atom code, so neither the box
build nor the `is` test has an arm for it; the delivery stores the bare wrapper where the box is
wanted. The bare vector member (`F32x4 | string`, atom 14) and the nullable vector list
(`F32x4[] | null`, a niche, not a box) both run.
