### D2595 — a map built in a generic at a literal-union `T` stores the argument at the string rep and reads it as the atom

**check-clean invalid wasm · clause 1 · pre-existing on master `ed81f8d55` in the annotated spelling · reached by 3 cells of #3175's review grid (named set `rv3175-generic-return-price`) · filed 2026-09-26**

Repro:

    type Dir = "n" | "s"
    const A1: Dir = "n"
    function f<T>(x: T): {[string]: T} {
      const m: {[string]: T} = Map()
      m["k"] = x
      m
    }
    print(f(A1)["k"] ?? "s")
    // vl check: rc 0.  vl run: invalid module inside `f`, "type mismatch: expected i32, found

#### Mechanism

Not located. The concrete `function f(x: Dir): {[string]: Dir}` runs and prints `n`. At the pin
the map's value slot is the literal union's i32 atom while the parameter `x` arrives at the
string rep, so the store hands a string ref to an i32 slot. The un-annotated `const m = Map()`
was a loud emit reject on master (D2432's mechanism); #3175 types that `Map()` at the pin, so
it reaches this defect too.
