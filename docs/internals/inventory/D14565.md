### D14565 — `U | null` over a union of one map type stores the map's null where the binding expects `U`'s box

**closed · was check-clean invalid wasm · filed 2026-10-27 against master `f84f84159`**

Repro:

    type A = {[i32]: i32}
    type B = {[i32]: i32}
    type U = A | B
    const a: A = Map()
    const y: U | null = a
    print(y != null)
    // vl check: rc 0.  vl run (filed): invalid module, expected i32, found nullref

Want:

    true

#### Mechanism

`U`'s members are one type, so `U | null` holds a single non-null member, and the producers
that ask for that member take the map's own nullable niche, a null ref. `U` still registered a
union box row, and the binding's slot is that box, so the null ref is stored where the box's
`i32` is expected. Two producers answered one question. Closed by one rule, `unionSoleMember`:
a union whose members are all one type denotes that member (the transparent-alias rule widened
from one member), so `U` is the map at every position and no box row is minted.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `B` (so `type U = A`) | runs | **yes** |
| the nullable on `y` (`const y: U = a`, `print(y is A)`) | runs | **yes** |
| `a` as the initializer (`null` instead) | still invalid | no |
