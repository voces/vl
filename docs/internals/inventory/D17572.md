### D17572 — a plain hole lambda stored into a map beside a bundle record is not built as that record

**loud emit reject · clause 2 · `vl check` rc 0 · `emitProgram: a function returning a parameter called at two signatures is called where its result is not used at one of them` at the bundle's store · the closure half of [D17106](D17106.md) · filed 2026-11-26 against master `622281876` by SOUND**

Repro:

    function lap(f) {
      const _a = f(2.5)
      const _b = f(3)
      return f
    }
    const m = Map()
    m["a"] = lap((a) => a + 1)
    m["b"] = (a) => a * 2
    print(m.has("b"))
    // vl check: rc 0.  vl run: emit error at `lap(`, "a function returning a parameter called at two
    // signatures is called where its result is not used at one of them"

Want:

    true

#### Mechanism

The checker types the lambda `(a) => a * 2` at the map's value type, the open function type `lap`
returns, so its parameter takes no type of its own (stored alone, the same lambda is the check
error "cannot infer a type for parameter `a`"). `elabSlotRecordNote` keeps the map's slot at `lap`'s
record only when every store is a call returning that record, so the lambda's store declines the
note and the bundle's store is refused. The design's producer rule
(`docs/internals/bundle-record-value-2026-11.md`, "Producers") builds a lambda literal delivered
where the slot holds a record at each of the record's signatures; the map store is not yet one of
those deliveries. D17106's union storage does not apply: the lambda has no closed type to be a
member of a union. It closes with family C's C2, the container producers, which builds a value as a
bundle's record at the record's signatures (coordinator ruling 2026-11-26).

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the lambda stored alone, no bundle | check error, `cannot infer a type for parameter` | **yes**: the bundle types it |
| the lambda replaced by a second `lap(...)` call | runs, `true` | **yes**: the plain lambda |
| the lambda annotated `(a: i32) => a * 2` | the same refusal | no |
