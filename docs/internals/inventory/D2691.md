### D2691 — a direct delivery of `{[string]: Circle}` into `{[string]: Circle | Sq}` builds invalid wasm

**check-clean invalid wasm · clause 1 · found in the #3194 review · identical on master
`1be1363d9` · filed 2026-09-26 by the W2 lane**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    const m: {[string]: Circle} = Map()
    m["a"] = { r: 3 }
    const w: {[string]: Circle | Sq} = m
    print(w.length)
    // vl check: rc 0.  vl run: invalid module in the top-level code, "type mismatch: expected (ref null …"

#### Mechanism

Not yet measured. The checker lets the delivery through because both values classify as a ref
(`containerElemClassDiffers` is false for `Circle` against `Circle | Sq`), but the `Circle | Sq`
map stores each value as the union box while the source map stores the bare `Circle` struct, so
the two maps are different structs. Either the class comparison should see the box (and refuse,
as the design's no-implicit-widening rule does for scalars), or the delivery needs a converting
copy.
