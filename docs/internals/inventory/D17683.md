### D17683 — `is K[][]` over an empty list whose static element type is disjoint from `K`'s folds to false outside an inferred generic instance

**check-clean silently wrong · clause 1 · the explicit-type-argument and non-generic face of [D4910](D4910.md) / [D15763](D15763.md), which test the value only where the instance's `V` is inferred · against the owner ruling recorded in [D4771](D4771.md) (a): `xs is K[]` is true when every element fits `K`, at every nesting depth, and an empty list fits every list type · related to [D17679](D17679.md), for START-2 · found by COV-IS beside D17679 · filed 2026-11-26 against master `c9b20b30e`**

Repro:

    function probe<V>(v: V[][] | string) {
      if v is f64[][] { return 1 }
      return 0
    }
    print(probe<i32>([]))
    // PRINTS 0

Want:

    1

#### Mechanism

Not yet traced. With `V` written (`probe<i32>`) or with no type parameter at all, the test
keeps the static fold from the receiver's element type (`i32` disjoint from `f64`), which
D4910's value test replaced only in an instance whose `V` is inferred. The checker agrees with the
fold: `vl check` warns "`is` check type 'f64[][]' is not a variant of i32[][] | string, so this
test is always false here", which the D4771 ruling contradicts for an empty list.

#### Ablation

Every spelling below prints `0`, with and without `VL_IR=0`:

| spelling | outcome |
| --- | --- |
| `V[] \| string`, `is f64[]`, `probe<i32>([])` (depth 1) | prints `0` |
| bare `V[][]`, `probe<i32>([])` | prints `0` |
| `V[][] \| null`, `probe<i32>([])` | prints `0` |
| no type parameter: `v: i32[][] \| string`, `probe([])` | prints `0` |
| `const e: i32[][] = []`, `probe(e)` (inferred `V`) | prints `0` |
| top-level `const w: i32[][] \| string = []`, `w is f64[][]` | prints `false` |
| `probe([])`, `V` inferred from the empty literal (D15763's witness) | prints `1` |

#### Grading list

Each spelling in the ablation; the checker's "always false" warning must go where the ruling
makes the test depend on the value.
