### D4607 — every first instance of a generic scans the whole arena for writes to its callee's name, so a program with N generic pins compiles in time quadratic in N

**closed · runs, and the `generic pins` pair no longer pays a whole-arena scan per instance: its fuel ratio is 1.252 at 400 pins against 2.494 · was a compile-time cost, the pair compiling, running and printing the right value at every size · regression since #3449 (D3857) · filed 2026-10-14 against master `56e06d91c`**

Repro (runs, prints `3`):

    function idg<T>(x: T): T x

    type P1 = { w1: i32 }
    type P2 = { w2: i32 }

    print(acc)
    // vl build: each `idg(pK)` mints a first instance, and each one walks every arena node.
    // The cost shows at hundreds of pins: `tests/vl_scaling_shape_test.ts`'s `generic pins`.

#### Mechanism

`monoMakeInstanceGo` (`compiler/emit_mono.vl`) computes `const written =
monoNameWrittenAt(cal3.identName, calleeIx)` for every first instance. #3449 hoisted it out of
the `cal3.identName != fn.fnName &&` short-circuit it used to sit behind, so it now runs for a
direct call by the generic's own name too, where `written` is never read. `monoNameWrittenAt`
walks `monoProgStmts` (`monoTopFrameOf`) and, for a read that resolves to no `let`, tail-calls
`monoDeclIsAssigned`, a scan of all of `P.nodes` comparing every assignment target's name;
#3622 added a declaration identity per name hit. Guest profile of the 800-pin many arm, master's
seed with `--names`, wasmtime 47: `monoDeclIsAssigned` 55.2% inclusive, `monoTopFrameOf`
11.4%, `__str_eq__` 45.8% self beneath them. Predicted fix, not yet measured: test
`cal3.identName != fn.fnName` before computing `written`, or answer it from a per-name write
index built once per arena generation.

#### Fix

The name test now guards the whole block: `written` is computed only for a call through a
binding whose name is not the generic's, which is the only case that ever read it. The refusal
fires on exactly the programs it fired on before, so every program compiles to the same bytes;
the self-built compiler is a byte-identical fixpoint, and the 100–800-pin modules are identical
before and after. Guest fuel of the pair, wasmtime 47, master `313eb4681`'s seed against the
fix:

| pins | many, before | many, after | one | ratio before | ratio after |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 100 | 0.884G | 0.688G | 0.605G | 1.460 | 1.136 |
| 200 | 2.215G | 1.429G | 1.216G | 1.821 | 1.175 |
| 400 | 6.329G | 3.177G | 2.538G | 2.494 | 1.252 |
| 800 | 19.938G | 7.318G | 5.156G | 3.867 | 1.420 |

The many arm still grows a little faster than the one (×2.30 against ×2.03 from 400 to 800).
At 800 pins `monoNameWrittenAt` no longer appears in the profile, and the residue is
diffuse: `monoRebuild` 6.1% inclusive, the 2026-09-05 passes, with `__str_eq__` at 11.0% self
spread over a dozen callers. A per-name write index would not move this axis, so none was
built; a call through a reassigned binding at many types still scans per instance, and no
axis measures that shape.
