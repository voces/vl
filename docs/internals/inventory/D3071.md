#### Mechanism

An un-annotated parameter is a hole, and each call instantiates it at the name
`monoArgTyName` gives the argument. Every rung of that ladder that can name a union reads a
binding: a `let`'s annotation or initializer, a parameter's annotation, an indexed list's
annotation. A `for` walk's variable is bound under no `let`, and the union floor
(`exprUnion`) reads the locals tables that are only built after monomorphisation. So the walk
variable fell through to the scalar catch-all and the instance took `i32`, while the call passed
the box. With a record union, the variant rung named one member first, and the `is` then refused
a receiver that was not a union. A rung ahead of the variant table now asks the arena: a boxed
union (not a numeric literal union, which reps as its base scalar) pins at `monoUnionPinName`,
the pin an annotated parameter already lowers.
