### D14772 — the checker calls a `??` default over a gradual union holding a type parameter dead, though a nullable pin uses it

**closed · runs, prints `n`, and `vl check` reports no dead `??` default · was a false warning on a program that runs: `this ?? default is never used` though the default is live at a `string | null` pin · closed by the column-G1 lane: a `??` over a read of a binding whose written type holds a type variable (`coalGradualRead`, check_coal.vl) is not recorded as dead, since its type is the template's gradual view · fixture `generics/coalesce-over-gradual-union-at-nullable-pin.vl` · filed 2026-11-01 against master `4eb649fbf`, the checker half of [D3421](D3421.md)**

Repro:

    function g<T>(x: T) {
      const s: T | string = x
      print(s ?? "n")
    }
    const v: string | null = null
    g(v)
    // vl check: [WARNING] this `??` default is never used: `T | string` is never null

Want:

    n

#### Mechanism

The checker types `s` at the template's gradual view of `T | string` (`tpGradualView`), its
concrete member `string`, and the dead-default lint reads that view. At `T = string | null` the
default is live: the program prints `n`.
