### D16261 — an un-annotated lambda called with a `never` call's result is pinned at two types

**loud emit reject · `emitProgram: internal: parameter `x` of `__lambda_0` is pinned at another type than the elaboration's at this call` · clause 1 (check passes, then emit fails internally) · the same call handed `7` runs · filed 2026-11-14 against master `c522f8dd`**

Repro:

    function fail(): never { __trap__() }
    function k(n: i32): i32 {
      const f = (x) => x
      if n > 5 { f(fail()) }
      n
    }
    print(k(3))
    // vl check: rc 0.  vl run: the refusal above, at `fail()`

Want:

    3

#### Mechanism

The lambda's parameter takes `never` from its one call. The elaboration and the monomorphizer's
pin (`emit_mono.vl`, the `pinned at another type than the elaboration's` refusal) settle it at
different types, and the emitter refuses the disagreement as internal. Found beside D16260.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `fail()` as the argument (`7` instead) | runs, prints `3` | **yes** |
| the `if` around the call | still refuses | no |
