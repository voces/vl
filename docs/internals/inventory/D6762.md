### D6762 — a parameter copied into an unread binding of another type parameter and handed to a closed function type is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · UNDECIDED: the same binding with `a1(3)` for `twice(a1)` is a loud check reject · found closing [D6741](D6741.md) · filed 2026-10-18 against master `bd096729d`**

Repro:

    function same<T>(k: T): T { k }
    function twice(f: (x: i32) => i32) { f(f(1)) }
    function mid<F, G>(a: F, a1: G) {
      let b: F = a1
      print(a("x"))
      print(twice(a1))
    }
    mid(same, same)
    // vl check: rc 0.  vl run: emitProgram: monomorphize: parameter `a1` of `mid` is called at two function types that no parameter per type separates

Want:

    x
    1

#### Mechanism

From the ablation only. `a1` is used at `F`'s instance, the `string` one `a("x")` takes, through
`b`, and at `i32` through `twice`; the split reads the copy into `b` as unread and declines.
Whether `b: F = a1` should hold `a1` to `F`'s instance is not settled: the checker refuses that
when `a1` is called directly, and accepts it here.
