### D6260 — a generic handed to a hole parameter by a named argument and called at two types is not split

**loud emit reject · `vl check` rc 0 · clause 2 · found closing [D6204](D6204.md) · the same on master `4090ad9df` · filed 2026-10-17 against master `4090ad9df`**

    function add(a, b) { return a + b }

#### Mechanism

From the ablation only. The split plan takes a hole parameter only when every call of its
function passes each argument by position (`fsHoleParamOk` in `compiler/fn_split.vl`). A
named argument is not a positional one, so `g` keeps one type, and the generic reaches the
emitter's floor. Exported or not, the outcome is the same.
