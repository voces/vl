#### Mechanism

Every classifier's `Ident` arm asks the parameter resolvers (`paramMap`, `paramStruct`,
`paramTypeNode`, …) first, by name. While a frame is emitted its scope stack answers first
(`scopeSlotOf`), but the scope-less passes — `computeRetInference` above all — have none, so
the block's `const s` read as the `boolean` parameter and set `fRetBool`. Those arms now ask
the parameter resolver by name and then `paramReadAt`, which answers false where a `let` or
loop variable in scope at the read shadows the parameter. `paramShadowedInBody` caches, per
frame and name, whether any body binding shadows a parameter, so a read that no binding
shadows pays nothing positional. `boundBoolByName` asks the positioned binding before its
parameter scan.
