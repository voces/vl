### D15743 — a function field written into a generic maker's record is refused at emit, at one call type or two

**loud emit reject · clause 2 · `cannot take the generic function \`id1\` as a value` at one type, `ref valtype with no interned shape` at two · found grading w315's emit-reject grouping (cell `d15270_generic_mk`) · filed 2026-11-11 against master `f570d7f7`**

Repro:

    function id0(a) { return a }
    function id1(a) { return a }
    function mk<T>(x: T) { return { f: id1, x: x } }
    const r = mk(1)
    r.f = id0
    print(r.f(2))
    print(r.f(2.5))

Want:

    2
    2.5

#### Mechanism

Unmeasured. The same maker without a type parameter (`function mk(x: i32)`) runs, and so does
the generic maker with no write. The write into an instance's record meets a field built as a
closure of `id1`; at two types, the instance's record has no interned row.

#### Ablation

| spelling | outcome | needed? |
| --- | --- | --- |
| `function mk(x: i32)` | runs, `2` `2.5` | **yes** |
| no `r.f = id0` | runs, `2` `2.5` | **yes** |
| one call, `r.f(2)` | still refuses (the one-type message) | no |
