### D5541 — a record field typed `Pa | Pb | null` over same-shape records has no struct-field rep, and the declaration alone refuses

**closed 2026-10-17 by lane L6 with [D5461](D5461.md) · runs, prints `true` · the field's spelling is canonicalised to `Pa|null`, which the struct-field ladder has a rung for · a duplicate of [D4997](D4997.md), closed with it · pin: `tests/cases/unions/same-shape-nullable-field-and-cell-reads.vl` · was loud emit reject, clause 2 · the annotated `struct_field_place` cell of the `same-shape-union-into-nullable` matrix (its un-annotated face runs) · the same on master's seed · found by lane L6 grading D5461 · filed 2026-10-17 against `244fa2e8c`**

Repro:

    type Pa = { tag: i32, val: i32 }
    type Pb = { tag: i32, val: i32 }
    type H = { p: Pa | Pb | null }
    const h: H = { p: null }
    print(h.p == null)
    // vl check: rc 0.  vl run: emit error at the field, `struct field type `Pa|Pb|null` has no struct-field rep`

#### Mechanism

The field's code is chosen from its spelling (`emit_shape_rows.vl`, the struct-field ladder).
The checker types the spelling `Pa | null` (D4989), but no row is bound to `Pa|Pb|null` and
the spelling is not the nullable record either, so no rung matches. The declaration refuses
even when nothing constructs `H`. [D3138](D3138.md) is the neighbouring row: there `null` is
not spelled last and a third member is present.

#### Grading list

site; [D5540](D5540.md)'s fixture once the field is built, since a field is one more cell
whose rep a row would change.
