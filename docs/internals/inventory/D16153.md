the ref-list arm records no element type for it.

#### Close

The family is wider than the alias: the generic record `type R<A> = { v: A, kids: (R<A> | null)[] }`
refused the same way. A recursive anonymous record has no render to name it at its cycle cut, so
the shape walk minted its row under "" and the ref-list layer, which names its rows by render, had
no element name. The row now takes a synthetic `#anonN` label (`emit_shape_intern.vl`), and an
element no render names is named by its record's row, found by type, `|null` and `[]` marking
the nullable and a list (`rlRowNameOfRecordRow`, read by `rlRowNameOfTy` and the shape field's
element name). `nulFoldTiedTy` re-points a wrapper held in lists and `| null`s at any depth, so
`kids: T[] | null` and `rows: G[][]` tie too. Fixture `tests/cases/soundness/recursive-nullable-alias-list.vl`.
