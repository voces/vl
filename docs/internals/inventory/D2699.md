#### Mechanism

Not yet measured. The same narrowing over an annotated list (`const xs: (M | string)[]`), or a
map of any other value type in this position, runs, whether the loop reads a `const` bound to
the element or the element place itself; so the for-in iterable ladder has no rung for a
closure-valued map whose type came from an inferred list element.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the closure value (`string` in its place) | runs | **yes** |
| the inference (`const xs: ({[string]: (i32) => i32} \| string)[]`) | runs | **yes** |
| the `const v` binding (`for k in xs[0]`, the place) | the same refusal | no |
