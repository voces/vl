#### Mechanism

**Not a price of [D1831](D1831.md)'s close — the same refusal, word for word, stands on the
seed before it.** That close makes the INNER literal's element the nullable-ref niche, which is
what the flat spelling needed; the OUTER literal's element is then a `(P | null)[]` list, and
the row for the inner wrapper is what has no interned shape.

`arrLitElemName`'s nested arm routes a ref inner literal through `arrLitNestedElemName`
(`ensureRefElemTy`, inner-first), and the inner-first walk is what D702 built for exactly this
ordering. The gap is that the inner list's own element is now a niche, so the name the outer
row is keyed on is one the inner walk did not mint.

The ANNOTATED spelling runs — `const e: (P | null)[][] = [[{ n: 42 }, null]]` prints `42`
before and after — so this is the same annotate-everything asymmetry D1831 measured, one
nesting level down.
