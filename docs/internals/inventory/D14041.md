### D14041 — `is` over a list of numeric literals has no arm test: the `K[]` arm is never interned as a union member

**loud emit reject · clause 2 · filed 2026-10-26 against master `76ab07e5e`**

Repro:

    type K = 0 | 1
    function f(x: K[] | string) {
      if x is K[] { print(x[0]) } else { print(9) }
    }
    f([1])
    f("s")
    // vl check: rc 0.  vl run: emitProgram: `is` names a declared union member with no interned arm representation (deferred value-union composition)

Want:

    1
    9

#### Mechanism

`K[]` where `K` is a numeric literal union stores as an `i32[]` (box tag 7), but the union's
arm registry has no entry for it, so the `is` lowering finds no arm to test and refuses. A
tag test alone would be wrong: by the D4771 ruling `b is K[]` tests every element, so `[5]`
must not fit. The fix is the box tag from `boxTagOfTy` plus a per-element literal test, the
same composition `isArmTagOfTy` already declines to `-1` for this type.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `K[]` → `i32[]` (in the type and the test) | runs, `1` `9` | **yes** |
| `K = 0 \| 1` → `K = "a" \| "b"`, partner `i32` | runs, `a` `9` | **yes** (numeric literals) |
| partner `string` → `i32` | still refuses | no |
| test `x is string` instead of `x is K[]` | runs, `1` `9` | **yes** (the `K[]` arm is tested) |
| the parameter → a top-level `const x: K[] \| string` | still refuses | no |
