#### Mechanism

`recCoalesceHeldOf` builds the default at the read's record only where the default's own row reads
back from that record's storage (`recNullWidened`), which an `i32` field does not from an `i64`
one. The default is then neither built there nor refused, so the join holds two storages. The call
spelling (`const d = mk2()`) and a literal written as the default behave the same.
