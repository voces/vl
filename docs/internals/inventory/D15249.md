### D15249 — a `??` default whose record the read's record stores a number wider is not built or refused

**open · check-clean invalid wasm · `type mismatch: expected (ref null $5), found (ref $6); $5 is J, struct {mut i64}` · clause 1 · found grading D15240 · filed 2026-11-04 against master `ddb0573bc`**

Repro:

    type J = { f: i64 }
    function mk() { { f: 4 } }
    const m = Map()
    m.set("a", mk())
    const wm: {[string]: J} = Map()
    wm.set("a", mk())
    const d = { f: 1 }
    const b = m.get("z") ?? d
    print(b.f * 4000000000)

Want:

    4000000000

#### Mechanism

`recCoalesceHeldOf` builds the default at the read's record only where the default's own row reads
back from that record's storage (`recNullWidened`), which an `i32` field does not from an `i64`
one. The default is then neither built there nor refused, so the join holds two storages. The call
spelling (`const d = mk2()`) and a literal written as the default behave the same.
