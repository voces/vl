### D17261 — an assignment of `null` to a literal-union cell, handed as an argument to a `string | null` parameter, is refused as a widening with no members

**closed 2026-11-27 by COV-UNION · runs, its witness meets its Want · was a loud emit reject, clause 2 · already ran on master `8857130b` (the IR builds the argument); pinned by `tests/cases/literal-unions/null-assignment-argument-to-nullable-string.vl`, the global-cell spelling too**

Repro:

    type M = "nn" | "mm"
    function takeS(s: string | null) { print(s == null) }
    function f() {
      let m: M | null = "nn"
      takeS(m = null)
    }
    f()
    // vl check: rc 0.  vl run: emit error, literal-union string widening with no members

Want:

    true

#### Mechanism

The argument is an assignment used as a value whose type is `null`, delivered to a `string | null`
parameter; legacy widens it as a literal-union atom (`emitStrValue` → `emitAtomToStr`) and the
plan's member set is empty, as D17119's `print` spelling was before its fix.

#### Ablation

| ingredient | outcome |
| --- | --- |
| `const r = m = null; takeS(r)`, bound first | runs, `true` |
| a `string \| null` cell | runs, `true` |
| a `M \| null` parameter | runs, `true` |
| the cell a module global | refused, the same |
