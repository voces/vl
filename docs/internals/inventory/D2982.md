#### Mechanism

The container rule (DECISIONS.md §"No implicit container widening") compares element storage
classes, and a `string | i32` box and a `string | i64` box are both references, so the pair
passed as a covariant alias. The boxes differ in what the `i32` member holds, which only a copy
can change, exactly as for `i32[]` into `i64[]`. The refusal names the copy that does it,
`l.map((x): string | i64 => x)`, which runs (each element is delivered, and retagged, on its own).
A map value takes the same refusal. A `readonly` destination does not: D965 serves `i32[]`
into `readonly i64[]` with a converting copy, so refusing the union twin would be a capability
refusal, and its trap stays open as [D2999](D2999.md).
