#### Mechanism

Not traced. The lambda's result is inferred from its body alone (`f64[]`, or `null` for a body
of `null`), and a function type with that result is then refused against the expected
function type, although a list is assignable to its nullable. The `i32[] | null` result has a
rung that adopts the expected return, and the others have none.

| the lambda (`function h(x: i32): f64[] \| null { return [1.5] }`) | runs, `1` | **yes** |

The same refusal, by its own spelling: `string[] | null` with `["a"]`; `P[] | null` for
`type P = {x: i32}` with `[{x: x}]` and with `null`; `{[string]: i32} | null` with `null`.
