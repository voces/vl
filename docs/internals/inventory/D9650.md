### D9650 — a list whose elements are a call returning a generic and the generic itself, called through each element at its own type, refuses

**closed · runs, prints `mk` `2` `abc` `true` `3` · was loud emit reject, `vl check` rc 0, `a list holding a generic function is called through its elements at more than one type`, clause 2 · CAPABILITY: the same list with the call bound to a `const` first ran · found closing [D9592](D9592.md) · filed 2026-10-22 against master `92d03ef36` · closed by counting a call element whose every `return` operand `monoFlowReads` noted inert as an inert value of the list (`monoCallRetsInert`, `monoValsInert`, emit_mono.vl) · fixture `closures/generic-call-and-generic-listed-pushed.vl` · with [D9652](D9652.md) closed**

Repro:

    function id<T>(x: T): T { x }
    function mk() {
      print("mk")
      return id
    }
    const xs = [mk(), id]
    print(xs[0](2))
    print(xs[1]("abc"))
    xs.push(id)
    print(xs[2](true))
    print(xs.length)
    // vl check rc 0.  vl run: emit error: emitProgram: a list holding a generic function is called through its elements at more than one type, so its elements have no one instance — annotate the list's element type

Want:

    mk
    2
    abc
    true
    3

#### Mechanism

The `.push` gives the list's element slot a second pin. `monoPinListElems` (emit_mono.vl)
then takes the path for a list whose every value `monoFlowReads` noted inert, because each
read was rewritten to a generic's name (D9441). That path asked `monoValsInert` for every
held value, and the element `mk()` failed. [D9592](D9592.md)'s close notes the `return`
operands of the called function inert, not the call node, so the call was not counted.

| --- | --- | --- |

| the `.push` | runs | **yes** |

#### Grading list

`mk` must print once. The fixture covers the list called through a `for` loop after the
`.push`, and the control with the call bound to a `const`. The annotated face of
`fn-value-generic-call-element-open`, which this row's filing named, refuses by design, as the
template's header says, and stays refused. A pushed list whose element is bound to a `const`
([D9720](D9720.md)) and a list written with a non-generic ([D9721](D9721.md)) refuse with
the same message without the call.
