**closed 2026-09-25 — the filed repro RUNS and prints `5` · was check-clean invalid wasm · clause 1 · found by #3168's second review (`rv3168r2-probe/m1c.vl`) · filed 2026-09-25 against master `15be0d1b8` · fixture `tests/cases/closures/value-call-narrowed-nullable-arg.vl`**

Repro:

    type Tex = { w: i32 }
    function total(xs: (Tex | null)[], f: (Tex) => i32): i32 {
      let s = 0
      let i = 0
      while i < xs.length {
        const v = xs[i]
        if v != null { s += f(v) }

    }
    const s: (Tex | null)[] = [null, { w: 4 }, { w: 1 }]
    print(total(s, (x: Tex) => x.w))

#### Mechanism

The filed ingredient was wrong: the compound assignment is scenery. A narrowed `S | null`
value keeps its `(ref null $S)` rep, and a direct call recovers it with `ref.as_non_null` at a
`(ref $S)` parameter; `emitCallRef`, the call through a function value, emitted the argument
bare, so `f(v)` failed validation in every position (`return f(v)`, `print(f(v))`,
`s = f(v) + 1`, `s = s + f(v)` in the non-generic filed repro). The generic twin's
`s = s + f(v)` ran only by another path. The recover is now one helper,
`emitNonNullParamRecover`, keyed off the parameter's kind and called by both call paths:
a struct, a list or map wrapper, a closure or a union arm.

| --- | --- | --- |

| a scalar element (`(i32 \| null)[]`) | runs (`k3.vl` through `IdTable<i32>`) | **yes** |
