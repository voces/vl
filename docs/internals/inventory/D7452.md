### D7452 — `??` straight over a closure parameter's call returning a nullable literal union is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · open · found closing [D3207](D3207.md) · present on master `573358403` · filed 2026-10-20 against master `573358403`**

Repro:

    function run(f: () => "a" | "b" | null): string { return f() ?? "n" }
    print(run(() => "a"))
    // vl check: rc 0.  vl run: emitProgram: `??` over this nullable value is not supported yet

Want:

    a

#### Mechanism

Not traced past the ablation. The `??` left operand is a call through a closure parameter
whose result is the nullable atom; the same value bound to a local first, or called through a
module-level binding, reaches the atom-niche `??` and runs.
