### D17720 — a twin-keyed nested list bound or assigned to a union-typed local in a function is stored bare where the union box is due

**closed 2026-11-26 by COV-IS, cov-is-55 · runs, prints `9` then `9` · was check-clean invalid wasm, clause 1 · the IR claims the function: the list is boxed under its twin arm's tag (`refArrTwinArmSlot`, the `refList` plan); check-clean invalid wasm on legacy fallback until I8; the IR claims it (legacy stores the bare list into the box local, and the box shadow's legacy build fails to validate) · the binding and assignment faces of [D16894](D16894.md) · filed 2026-11-26 against master `37a1cc5be`**

Repro:

    type K = 0 | 1
    function own(x: K[][] | string | null) {
      if x is K[][] { print(x[0][0]) } else { print(9) }
    }
    function show(x: K[][] | i32[][] | string) {
      if x is K[][] { print(x[0][0]) } else { print(9) }
    }
    function run() {
      const five: i32[][] = [[5]]
      const b: K[][] | i32[][] | string = five
      show(b)
      let a: K[][] | i32[][] | string = "s"
      a = five
      show(a)
    }
    run()
    // was: vl run: invalid module inside `run`, type mismatch: expected (ref $union box), found (ref $i32[][])

Want:

    9
    9

#### Mechanism

`K[][]` and `i32[][]` share one list wrapper, and `K[][] | string | null` keyed the row first,
so `i32[][]`'s own slot is no arm of `K[][] | i32[][] | string`. The IR missed the function at
the box plan's ladder, and legacy's binding and assignment of the union-typed local store the list
as it stands, with no box. The IR now plans the value under the twin arm's tag and claims `run`.
Legacy alone still writes it bare.
