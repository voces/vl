### D4155 — `as? T[]` inside a generic body is refused as naming a non-member of `T[] | i32`

**loud check reject · clause 2 · the concrete `as? f64[]`, `as? T` and `is` spellings run · filed 2026-10-11 against master `66f24dbe6` · found by #3558's review (probes `ng1`, `ng4`)**

Repro:

    function f<T>(u: T[] | i32, d: T): T {
      const r = u as? T[]
      if r != null { return r[0] }
      d
    }
    print(f([1.5], 0.0))
    print(f(["s"], "d"))
    print(f(3, "e"))
    // vl check: `as T[]` names a type that is not a member of T[] | i32

#### Mechanism

The target `T[]` is literally an arm of the written union, so the refusal's sentence is wrong
of the program. The membership test compares the arm against the target after the type parameter
is opened to a fresh hole on one side only.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `u: f64[] | i32`, `as? f64[]` | runs, `1.5` / `2` | **yes** (the type parameter) |
| `u: T | i32`, `as? T` | runs | **yes** (the list around `T`) |
| `if u is i32 { return d }` then `u[0]` | runs | no — the rescue |
