#### Mechanism

The flattening step decides per wasm array type, and every `V3[]` in a program shares one. A
read whose element is used whole would re-box with `struct.new` where today it shares the
box, so the cost rule refuses the type while any such read is left: a `pop` or `get` (its
`V3 | null` result merges with `ref.null`, which neither the multi-value step nor heap2local
scalarizes), an argument to a parameter the multi-value step does not take as fields, a
generic body's return, or a local that is also read whole. sunpa `ce4e1c3`'s `V3[]` stays
boxed for four such reads in `fabrik` (`src/ik.vl:120`), and its decor outline list for 14.
A read that re-boxes for a `V3 | null` result could instead carry a presence flag (S3), and
a per-function count could replace the program-wide refusal once a re-box is priced against
the stores it saves.
