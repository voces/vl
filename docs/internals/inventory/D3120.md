### D3120 — a closure capturing an un-annotated binding of a value narrowed to a literal union out of a box is invalid wasm

**check-clean invalid wasm · clause 1 · found grading lane NB's position grid (`lit__bind_un_capt__*`) · the same on master `cc890c9f4` · filed 2026-09-28 against master `cc890c9f4`**

Repro:

    type K = "a" | "b"
    function t(e: K | i32) {
      if !(e is i32) {
        const c = e
        const f = () => c == "b"
        print(f())
      }
    }
    t("b")
    // vl check: rc 0.  vl run: invalid module inside `t`: type mismatch: expected (ref $type),
    // found (ref $type)

Want:

    true

#### Mechanism

Not localised past the ablation. The literal-union twin of [D3107](D3107.md) at a capture: `c`
copies the narrowed read of the box, and the closure's capture cell and the frame's value of
`c` disagree about its rep. The same binding read directly in `t` runs.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `print(c == "b")` in `t`, no closure | runs | **yes** (the capture) |
| `const c: K = e` | runs | **yes** (the un-annotated binding) |
| `() => e == "b"`, no binding | runs | **yes** (the binding) |
| `string \| i32` in place of `K \| i32` | runs | **yes** (the literal union) |
| `Circle \| i32`, `() => c.r` | runs | **yes** |
| `e: K \| null` narrowed by `e != null` (no box) | runs | **yes** (the box) |
| the binding at module scope | invalid module inside the closure | no |
| inside a `for-in` over `(K \| i32)[]` in a function | the same invalid module | no |
