### D3120 — a closure capturing an un-annotated binding of a value narrowed to a literal union out of a box is invalid wasm

**closed · an un-annotated binding of a value narrowed to a literal union out of a box types its capture's env field `string`, the cell the frame binds · fixture `tests/cases/closures/capture-narrowed-box-copy.vl` · was check-clean invalid wasm · clause 1 · found grading lane NB's position grid (`lit__bind_un_capt__*`) · the same on master `cc890c9f4` · filed 2026-09-28 against master `cc890c9f4`, closed 2026-09-29 against master `07d414042`**

Repro:

    type K = "a" | "b"
    function t(e: K | i32) {
      if !(e is i32) {
        const c = e
        const f = () => c == "b"
        print(f())
      }
    }
    t("b")
    // vl check: rc 0.  vl run: invalid module inside `t`: type mismatch: expected (ref $type),
    // found (ref $type)

Want:

    true

#### Mechanism

The frame binds `c` with the narrowing in force, where the read unboxes the member's string, so
its cell is `(ref $string)`. The env field is typed in the type section with no narrowing in
force, where `letIsUnion` saw the box and typed the field `(ref $box)`. `letInitTyIsNarrowedLit`
(`emit_classify.vl`) is the rung `letInitCellKind` now asks ahead of the box: an un-annotated
initializer the checker typed as a literal union that is still the box reads as `string`, asked
of the checker's type so the capture agrees with the frame.
