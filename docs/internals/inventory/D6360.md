#### Mechanism

The callback's returns join to `_ | null`, which the per-pin clone keeps as the nullable its
last return gives it (D3125 left this join alone, since taking it cost 8 runs). At `T = i32`
the result is recorded as `(i32 | null)[]`, but only the instance forms `i32 | null`, so no
collect pass registered its box row and the checked-rep column does not cover the list. The
removed map-filter rung answered the i32 list there, which fails later at the callback's
`return null`; with the column the `for` refuses at its iterable. Registering the row is not
enough: with a module-level `(i32 | null)[]` beside the witness, so that the row exists, the
`for` still refuses.

The return expression the clone reads is `return e`, typed at the parameter's hole (`_`),
while the checked signature is `_ | null`; neither is a kept-apart join, so the clone was
annotated at the bare element and its `return null` had nowhere to go. The clone's return is
now the element's type or null whenever the checked signature bears null beside a hole or
type parameter, read from whichever return comes first, and its box row is registered as a
kept-apart join's is. 151 corpus cells move loud emit reject → runs (`d3125_{gen,hole}_{J1,K12}`);
2 move to a trap, filed as [D10794](D10794.md).
