### D17799 — a tag dispatch over a set of lambdas whose callee its place stores as a closure has no closure signature

**loud emit reject, `cannot yet lower this statement (tag dispatch closure key)` · clause 2 · `vl check` rc 0 · filed 2026-11-28 against master `c44bff3b9` by COV-UNION**

Repro:

    function main() {
      const f = (a) => a + 1
      const d = (a) => a * 2
      const two = [f, d]
      const s = two.pop()
      if s != null { print(s(3)) }
      const m = [f]
      print(m[0](3))
    }
    main()
    // vl check: rc 0.  vl run: emit error (tag dispatch closure key) at 6:28

Want:

    6
    4

#### Mechanism

Not traced: in a function body the popped element (and an in-place `two[1](4)`) is read from a
place that stores the set's closures (D17665), so the dispatch calls through the closure at the
signature every member shares (`tagSetCloKey`), which a lambda arm, naming no instance, does
not give. Keying the call at its own closure signature instead (`cloCallSigKey`) was tried and
TRAPS at run time, so the closure's table entry is not at that signature: do not take that route.
