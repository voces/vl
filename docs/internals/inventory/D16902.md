### D16902 — a lambda at a generic's `() => T | {a: i32}`, never called, builds an adapter whose result is the record arm, not the instance's union box

**closed 2026-11-16 — the witness runs and prints `1` · was: check-clean invalid wasm · clause 1 · `vl check` rc 0 · `vl run`: `Error: invalid module` · found by lane SOUND grading #8856 · pre-existing on master `846d9d9e9` · filed 2026-11-16 by lane AE4**

Repro:

    function many<T>(f: () => T | {a: i32}) { return [f].length }
    print(many(() => 5))

Want:

    1

#### Mechanism

The delivery adapter for the lambda is built at the instance's substituted type
`() => i32 | {a: i32}`. With no row registered for that union, its result rep fell back to the
record arm's ref while the lambda returns an `i32`, and the adapter failed validation. Called,
the same program ran.

#### Fix

[D14082](D14082.md)'s close registers every union an instance signature holds
(`elabInstSigTys`), so `i32 | {a: i32}` has its box row and the adapter returns the box.
