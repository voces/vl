### D4152 — a `string[][]` delivered to `readonly (string | string[])[]` is check-clean invalid wasm

**closed 2026-11-02 · runs, prints `true` · was check-clean invalid wasm, clause 1 · fixtures `tests/cases/lists/readonly-union-list-of-scalar-lists.vl` and `tests/cases/lists/error-readonly-union-list-of-scalar-lists-written.vl` · filed 2026-10-11 against master `66f24dbe6` · found by #3563's review (probe `d06`)**

Repro:

    const xs: string[][] = [["a"]]
    const y: readonly (string | string[])[] = xs
    print(y[0] is string[])
    // vl check: rc 0.  vl run: the emitted module failed to validate: type mismatch: expected (ref null $7), found (ref $5)

#### Mechanism

A readonly destination admits covariance in the checker, but the two lists are different
reps (`string[][]` against `(string | string[])[]`) and no copy or view is built at the delivery.
The fresh-versus-named distinction of the record covariance ruling is the open design point:
either the delivery builds the converting copy or the checker owes the container-widening refusal.

#### Close

A build gap, settled the way a record list is. The element-converting copy (D791) and the readonly
view (D3041) boxed only a record row, keyed by its arm. They now take the box tag
(`rlWidenTagOf`): a record's arm tag, or the tag of a scalar list (`i32[]`, `f64[]`, `string[]`,
`i64[]`, `f32[]`) the union holds as a member. The checker's written-through rule
(`covarWriteThrough`) counts such a list element as a row, so a source written after the delivery
is refused at check, as `C[]` into `readonly (string | C)[]` is. A boxing spread of such a list
runs too; it was a loud emit reject.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `readonly` removed | check reject, a container never widens | **yes** |
| `i32[][]` into `readonly (i32 \| i32[])[]` | check-clean invalid wasm, now runs | no (any scalar list) |
| `f64[][]` into `readonly (string \| f64[])[]` | check-clean invalid wasm, now runs | no |
| as an argument, a record field, or a return | check-clean invalid wasm, now runs | no (any position) |
| spread `[...xs, "q"]` into the same destination | loud emit reject, now runs | no |
| `xs[0] = ["b"]` or `xs.push(…)` after the delivery | check-clean invalid wasm, now the written-through check reject | — |
| `string[]` into `readonly (string \| i32)[]` | check reject, a scalar element has no copy | unchanged |

#### Grading list

Grade the delivery at argument, return, field and assignment positions, in both an annotated
and an un-annotated spelling of `xs`.
