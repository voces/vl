#### Mechanism

The emitter declares `V3` a subtype of `V2` because `V2`'s name-sorted fields are a prefix of
`V3`'s (D622), whether or not any `V3` is ever stored where a `V2` is expected. A `V2[]`
element slot can then hold a `V3`, and copying only the slot's two fields would slice it, so
§1 condition 3 refuses `V2`, as S1 does for a `V2` field. The relaxation the design names,
exact-`V2` slots, needs a proof that no `V3` reaches the array: no store whose value's static
type is `V3`, and no cast from a wider type into the slot.

#### Grading list

The witness at `-O3` must reach 0 `struct.new`; a program that does store a `V3` into a `V2[]`
and reads it back with `is V3` must keep printing `true`.
