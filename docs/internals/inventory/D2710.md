### D2710 — a literal shift count at or above the operand's width is taken modulo the width

**closed 2026-09-26 — now a loud check reject: `shift count 32 is out of range for an i32 operand
(0 to 31)` · was check-clean silently wrong, clause 1 · found beside plumb's PL-047 (D2709) ·
filed against master `fdd0050af` · fixture `tests/cases/bitwise/error-shift-count-out-of-range.vl`**

Repro:

    function f(x: i32): i32 { x << 32 }
    print(f(1))
    // vl check: rc 0.  On master it printed 1: wasm's `i32.shl` takes the count modulo 32.

#### Mechanism

Wasm's shift instructions take the count modulo the operand's width, and the checker accepted
any count, so `x << 32` over an `i32` shifted by 0 and `x << 40` by 8. The shift is a refusal the
design owes, as in Rust and Go: a literal count below 0 or at or above the width is refused at
the count. `checkShiftCounts` grades every shift with a literal count once checking is done,
against the final type of the left operand, so a tree of literals is graded at the width its
destination gave it (D2709): `const a: i64 = 1 << 40` is accepted, `const b: i32 = 1 << 40`
and an un-annotated `const c = 1 << 40` are refused. A computed count keeps the wasm modulo.

#### Ablation

On master `fdd0050af`.

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the count 32 → 31 | `-2147483648` | **yes** (a count at or above the width) |
| the count → `-1` | `x << 31` | no (a negative count too) |
| `x: i32` → `x: i64`, count 64 | `1` | no (either width) |
| the count → a variable holding 32 | `1` | **yes** (a literal count; a computed one keeps the modulo) |

#### Grading list

The price, measured with the close: of every `.vl` file in the repo whose source carries a
shift by a literal of 32 or more or a negative one, one refuses —
`tests/cases/numerics/as-pct-wrap-values.vl`'s `(1 << 40) as% i32`, whose `@log 256` recorded
the wrap (`1 << 40` read as `1 << 8`) in the rows illustrating `i64 as% i32`. It now spells
`(1099511627776 + 256) as% i32`. The distilled corpus carries none, nor do the consumers: 206
hand-written files with such a shift across plumb, glean, sunsuz and webcraft, and a seeded
sample of 24 of plumb's generated chunks, all still check clean.
