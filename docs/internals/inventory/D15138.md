### D15138 — a record's list field written a function of another result type is refused at check

**closed · runs, prints `1.5` · was loud check reject, `cannot write 'half' to an element of 'r.xs': called at (i32) it returns f64, where 'inc0', also written to it, returns i32` · clause 2 · split from [D14648](D14648.md) (step 3, the record field) · filed 2026-11-03 against master `097fd927` · closed 2026-11-03: a binding initialised by a record literal widens each list field of functions over the writes into its elements (`letFieldListsWiden`, check_statements.vl; `elabFnFieldListTy`, check_elab_cap.vl), and `holeSlotJudge` lifts its comparison for such a field. A nested record, a parameter read, a return and a parameter write are [D15168](D15168.md), [D15167](D15167.md), [D15169](D15169.md) and [D15190](D15190.md)**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const r = { xs: [inc0] }
    r.xs[0] = half
    print(r.xs[0](3))
    // Want: 1.5

#### Mechanism

`elabFnListLetTy` widens only a list BINDING initialised by a list literal; a field holding a
list literal is not widened, so `holeSlotJudge` keeps its comparison. D14648's row measured the
comparison lifted for every written element: the record field then built `ref valtype with no
interned shape` at emit.
