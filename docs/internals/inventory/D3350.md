### D3350 — a binding holding a literal with a record field, set into a map of a wider record, is invalid wasm when a record of its own fields is declared

**check-clean invalid wasm · clause 1 · open · identical on master `2b30e3674` · found by the #3312 review grid (`onull__ubind__mapval`) · filed 2026-09-30 against master `2b30e3674`**

Repro:

    type O = { v: i32 }
    type I = { f: O }
    type J = { f: O | null }
    const s = { f: { v: 4 } }
    const m = Map<string, J>()
    m.set("a", s)
    const x = m.get("a") ?? { f: { v: 9 } }
    print(x.f?.v ?? 70)
    // vl check: rc 0.  vl run: invalid module, "expected (ref null $type), found (ref $type)"

Want:

    4

#### Mechanism

`s` holds only a literal and would adopt `J`, but its delivery is a method argument, which the
record-covariance rule does not adopt from, and the literal is built at the declared `I` row, so
the map stores an `I` into a `J` slot. The binding spelling of D3342 and D3349.
