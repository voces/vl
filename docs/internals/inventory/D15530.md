### D15530 — a type parameter only a `null` reaches, held inside a list or record `| null` parameter, has no `never` instance

**loud emit reject · clause 2 · the composite face of [D3178](D3178.md) · filed 2026-11-06 against master `22ca42d59`**

Repro:

    function F<Z>(z: Z[] | null) {
      if z != null { print(z[0].f()) }
    }
    F([{ f: () => true }])
    F(null)
    // vl check: rc 0.  vl build: emitProgram: callee is not a function name

Want:

    true

#### Mechanism

[D3178](D3178.md)'s ruling binds a type parameter whose only argument is a `null` to `never`,
but only where the parameter is a bare `Z | null`. Here `Z` sits inside the list, so `F(null)`
still takes the D4551 default `F<i32>`, whose guarded `z[0].f()` calls a member of an `i32`.
Binding `never` here instead gives the parameter the type `never[] | null`, which has no value
type: the valtype ladder refuses it (`a parameter type the valtype ladder has no rung for`), and
`Z[] | null` read only through `.length` stops running. Closing this needs `never` to have a
representation inside a list or record, which is a rep-layer change.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `r: { z: Z } \| null`, `r.z.f()` | loud emit reject, callee is not a function name | no (the record face) |
| `print(z.length)` in place of `z[0].f()` | runs | **yes** (a read through `Z`) |
| bare `z: Z \| null`, `z.f()` | runs, prints `true` ([D3178](D3178.md)) | **yes** (the composite) |
