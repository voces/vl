### D3597 — the redundant-annotation hint fired on exported signatures, and `--fix` ran one round and never removed the imports it orphaned (sunpa SP-026)

**closed 2026-10-03 — the witness runs, and `vl check` reports no hint on the exported return, `const` or `let` · was a `vl check`-clean program whose module API annotations were hinted as redundant and stripped by `--fix` · fixed by an exemption in the hint, plus `--fix` rounds and an unused-import fix**

Repro (runs, prints `6`; `vl check` must report exactly the `g` and `k` hints):

    export function f(x: i32): i32 { x + 1 }
    export const m: i32 = 2
    export let label: string = "k"
    function g(): i32 { 3 }
    const k: i32 = f(m)
    print(k + g() + label.length - 1)
    // vl check (before): five redundant-type hints, the three exported ones among them.

Want:

    6

#### Mechanism

The parser drops `export` from a `let`/`const`, so the checker could not tell an exported
binding from a private one; it now records exported `function`, `let` and `const` nodes
(`exportDeclAdd`/`declExported`, `compiler/ast.vl`) and `recordRedundantAnnot` and
`recordRedundantRet` skip them. The LSP reads the same stream, so the editor drops those
hints too. `--fix` (`compiler/cli.vl`) re-checks after each written round and stops at the
first round that applies nothing, or at 10 rounds with a note. It now also removes unused
import specifiers, taking one comma with each. It removes a whole import only from a `std:`
module, because a module of the program's own runs its top-level statements when imported.
The summary names the rounds and the count of each kind of fix.

#### Ablation

SP-026's probe (`import { Buffer, Buf }`, an exported function, a `let b: Buf`, a `const n: i32`):

| ingredient | before | after |
| --- | --- | --- |
| `export function f(x: i32): i32` | return stripped | kept, no hint |
| `let b: Buf = Buffer(8)` | annotation stripped, `Buf` left unused after any number of runs | annotation stripped in round 1, `Buf` removed in round 2 |
| `const n: i32 = 5` | stripped | stripped |
