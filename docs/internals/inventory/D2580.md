### D2580 — a `??` joining a declared record's niche with an inline record of another shape, bound un-annotated, is refused

**loud emit reject · `vl check` rc 0, then `emitProgram: object literal is missing a struct field`, clause 2 · found grading [D2565](D2565.md)'s close against the #3173 review grid (`aw__bind`, `aw__field`, `aw__ifArm`, `aw__letReassign`, `aw__loop`, `aw__modscope`) · the same on master `216770428` · filed 2026-09-26 against master `216770428`**

Repro:

    type A = { r: i32 }
    function mkA(n: i32): A | null { if n == 0 { return null } return { r: n } }
    function go(ka: i32) {
      const x = mkA(ka) ?? { w: 3 }
      if x is A { print(x.r) } else { print(x.w) }
    }
    go(0)
    go(7)
    // vl check: rc 0.  vl run: emit error, "object literal is missing a struct field"

#### Mechanism

A prediction. The join's type is `A | { w: i32 }`, a record union no declaration spells, and
the refusal reads as the `{ w: 3 }` literal being built against `A`'s row, whose field `r` it
lacks. The same join returned from an un-annotated function
(`function rt(ka: i32) { return mkA(ka) ?? { w: 3 } }`) runs, so the binding route resolves a
different row for the literal than the inferred-return route does.
