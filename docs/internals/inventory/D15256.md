    function f(x: string | null) {
      if x is null { print("null") } else { print(x) }
    }

#### Mechanism

`isVariant == "null"` decides an `is null` test at several emit sites: `wasmEmit.vl`
(`emitIs` and the niche and box arms before it), `emit_atom_kinds.vl` and `emit_rewrite.vl`. The
checker's tested type at the node should answer it (`isNullTy(isVarTyIx)`); confirm the stamp is
there at each site before moving it.

#### Close

The eleven emit sites ask `isTestsNull(ix)` (`compiler/emit_base.vl`): whether the pattern's own
type, `isPatTyIx`, is the null type. A probe of the eleven against that relation found ten
disagreements, every one a `match` arm, where `check_match` had banked no pattern type at all:
it banked `isVarTyIx` for a type pattern but never `isPatTyIx`, and nothing at the `null` arm of
a match over a nullable literal set (D1898). `check_match` now banks both, so the readers #6229
and #6234 added, which read -1 at every match arm until now, see the pattern type there too.
