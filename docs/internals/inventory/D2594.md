#### Mechanism

Not located. `xs.pop()` over a map list is `{[string]: i32} | null`, a nullable map ref, and the
binding holds it at that rep; the function's inferred result is the non-null map, so the
`return` hands a `(ref null)` to a `(ref)` result. The concrete `Set<i32>` and `Set<string>`
spellings are a check refusal on master instead (`infers the nullable return type Set<…> | null`,
conceding codegen). The generic `f<T>(xs: T[])` at a set instance reaches this row's invalid wasm.
The generic `f<T>(xs: T[])` was a loud emit reject on master (`bare null needs a struct-typed
context`); #3175 types its instance at the pin, which reaches this defect.
