### D9360 — an inline list of un-annotated functions and an annotated list handed to one un-annotated parameter whose element is called

**loud emit reject · `vl check` rc 0 · `emitProgram: cannot take the generic function `inc0` as a value` · clause 2 · found closing [D9281](D9281.md) · present on master `22c2f5c4f` as `emitProgram: union atom has no value box` · filed 2026-10-21 against master `22c2f5c4f`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function early(a) {
      if a.length == 0 { return 0 }
      return a[0](4)
    }
    const e: ((x: i32) => i32)[] = [dbl]
    print(early([inc0]))
    print(early(e))
    // vl check rc 0.  vl run: emit error: emitProgram: cannot take the generic function `inc0`
    //   as a value ... No call site pins `inc0`

Want:

    5
    8

#### Mechanism

Not traced. Each call alone runs, and so does the pair when the inline literal is bound to a
name first (`const g = [inc0]`, `early(g)`). The two pins of `early` are one inline literal of a
declared un-annotated function and one annotated list of the same function type; the literal's
function is then left with no pin at emit.

#### Ablation

| variant | outcome |
| --- | --- |
| `early([inc0])` alone | runs, `5` |
| `early(e)` alone, `e` annotated (empty or not) | runs |
| `const g = [inc0]`, `early(g)` beside `early(e)` | runs, `5` then `8` |
| the two calls in the other order | the same emit reject |
| `e` annotated and EMPTY in place of `[dbl]` | the same emit reject (was D9281's third ablation row) |
| `a.map((f) => f(4))[0]` in place of `a[0](4)`, beside `early([inc0, dbl])` | the same emit reject |
