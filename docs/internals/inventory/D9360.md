Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function early(a) {
      if a.length == 0 { return 0 }
      return a[0](4)
    }
    const e: ((x: i32) => i32)[] = [dbl]
    print(early([inc0]))
    print(early(e))
    // vl check rc 0.  vl run: emit error: emitProgram: cannot take the generic function `inc0`
    //   as a value ... No call site pins `inc0`

Want:

    5
    8

#### Mechanism

Traced. `monoOpenFnListPin` instances an inline list's open functions at the one agreed pin of
the parameter's element slot, and that agreement was taken over every walk the flow table made
of `early`. The walk of `early(e)` carries `e`'s annotation pin, which is not a call pin and so
vetoed the agreement; the literal got no pin and `inc0` reached the function-value floor. The
pins are now read in the walk the literal's own call minted (every walk when the call has no
single one), so the other call's pin is never seen.
