#### Mechanism

`viaField`'s hole parameter `y` is stored at `J`'s row (D15173's key), and the lambda returns it
there (D17676). The record field `b` keys its closure's signature by the field's type, whose
result is `{f:null}`'s row, so the call through the field reads a `J` value at `{f:null}`. A
lambda bound to a local is keyed by the lambda (`capRowLetFe`); one held in a field is not.
