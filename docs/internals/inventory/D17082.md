#### Mechanism

The census, not the compiler: see the status line. What follows was the reading before the census fix.

The map holds records built at `J`'s row (D14426). At module scope, the narrowed `mv` bound to
`v` lowers a temp the IR start does not consume in stack order; inside a function the same body
builds and matches. Not yet ablated past the table below.
