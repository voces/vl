### D4024 — a type parameter a bare `null` or a literal-union member binds was not taken from the destination outside `filled`

**closed 2026-10-11 by lane CK · runs · was loud check reject · clause 2 · found closing D3990 and by the diderven consumer (`DV-1002`) · filed 2026-10-11 against master `3667afbf9` · pins: `tests/cases/generics/null-argument-typed-by-destination.vl`, `tests/cases/generics/filled-string-literal-typed-by-literal-union-destination.vl`, `tests/cases/generics/error-string-literal-not-in-literal-union-destination.vl`**

Repro:

    type Item = { n: i32 }
    function mk<T>(x: T): T[] { [x] }
    const xs: (Item | null)[] = mk(null)
    xs[0] = { n: 7 }
    const e = xs[0]
    if e != null { print(e.n) }
    // vl check: a null[] cannot be delivered as (Item | null)[] here

Want:

    7

#### Mechanism

D3990 took `T` from the destination for `filled(n, null)` alone. The same binding is now taken
for any generic call whose arguments binding `T` are bare `null`s, literals, or, beside a
`null`, values the destination's type holds (`pair(null, { n: 2 })`), wherever `T` sits in the
return (`T[]`, `Box<T>`, a bare `T` delivered to `Item | null`). A string literal binds a
literal-union `T` when it is a member, so `const w: Dress[] = filled(4, "none")` is a
`Dress[]`, and a numeric member does the same: `const lits: (1 | 2 | 7)[] = filled(2, 7)`,
which `error-destination-literal-type-param-inexact.vl` had pinned as a refusal, now runs. A destination still being inferred (an un-annotated `Map()` slot) chooses nothing,
and a nullable destination binds a bare `T` only, so `mk(null)` into `(Item | null)[] | null`
reads the list. Graded by `scripts/capability-probes/matrix/dst-*.matrix.vl`: every annotated
position runs but `return_inferred`, which has no destination at the call.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const xs = mk(null)`, no destination | `T` is `null`; storing a record is refused | **yes** |
| `mk({ n: 1 })` in place of `null` | runs on master | **yes** |
| `filled(4, null)` in place of `mk(null)` | runs on master (D3990) | **yes** |
