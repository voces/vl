### D2567 — a lambda literal over `string | i32 | null` (or `K | null`) called in place hands back the union box to a destination that reads it at the i32 rep

**closed 2026-09-26 — the filed repro RUNS and prints `false` · was check-clean invalid wasm · clause 1 · found by #3171's second review (`rv3171r2/min/u2.vl`, `p1.vl`, `p2.vl`) · filed 2026-09-26 against master `cf1c0dff3` · fixture `tests/cases/closures/inplace-lambda-nullable-union-result.vl`**

Repro:

    function gen(r: string | i32 | null): string | i32 | null {
      return ((x: string | i32 | null) => x)(r)
    }
    const a: string | i32 | null = 7
    print(gen(a) == null)

#### Mechanism

`exprUnion`, the emitter's "is this value the union box" predicate, answered a call through
its callee only for an `Ident` or `Member` callee, and otherwise fell back to the checker's
node type. A `string | i32 | null` or `LN | null` result is a `TyNullable`, which
`nodeTyIsUnion` does not claim, while the callee's own `$fnsig` (keyed by its lambda since
#3171) says `>u`. So every destination took the call for a scalar and boxed the box as an
`i32`. Closed by asking `cloCallSigKey`'s result token for a lambda-literal callee and for a
call-result callee (`mk()(x)`), the same key the `call_ref` is emitted against. The lambda's result is the value-union box, and the
destination of the in-place call reads it as an `i32`: `expected i32, found (ref $type)`.
The same lambda bound first (`const f = (p: string | i32 | null) => p; f(7)`) runs, so the
in-place call is the ingredient, not the union. The literal-union twin fails the same way:

    type LN = 1 | 2
    const r: LN | null = ((p: LN | null) => p)(2)
    print(r == null)

and so does the module-scope spelling
`const r: string | i32 | null = ((p: string | i32 | null) => p)(7)`. #3171 clones a lambda
over `T` per instance, so a generic bound at `string | i32 | null` now reaches this site where
master refused it with `unsubstituted type parameter`: those eight cells are the named set
`distilled/named/d2567_*` (block `d2567-lambda-inplace-nuni`), recorded at today's silent
outcome as #3171's price.
