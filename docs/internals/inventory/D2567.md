### D2567 — a lambda literal over `string | i32 | null` (or `K | null`) called in place hands back the union box to a destination that reads it at the i32 rep

**check-clean invalid wasm · clause 1 · found by #3171's second review (`rv3171r2/min/u2.vl`, `p1.vl`, `p2.vl`) · filed 2026-09-26 against master `cf1c0dff3`**

Repro:

    function gen(r: string | i32 | null): string | i32 | null {
      return ((x: string | i32 | null) => x)(r)
    }
    const a: string | i32 | null = 7
    print(gen(a) == null)

#### Mechanism

Not yet located past the rows below. The lambda's result is the value-union box, and the
destination of the in-place call reads it as an `i32`: `expected i32, found (ref $type)`.
The same lambda bound first (`const f = (p: string | i32 | null) => p; f(7)`) runs, so the
in-place call is the ingredient, not the union. The literal-union twin fails the same way:

    type LN = 1 | 2
    const r: LN | null = ((p: LN | null) => p)(2)
    print(r == null)

and so does the module-scope spelling
`const r: string | i32 | null = ((p: string | i32 | null) => p)(7)`. #3171 clones a lambda
over `T` per instance, so a generic bound at `string | i32 | null` now reaches this site where
master refused it with `unsubstituted type parameter`: those eight cells are the named set
`distilled/named/d2567_*` (block `d2567-lambda-inplace-nuni`), recorded at today's silent
outcome as #3171's price.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the in-place call (the lambda bound to `f` first) | runs, prints `false` | **yes** |
| the `null` arm (`string \| i32`) | runs | **yes** |
| the string arm (`i32 \| null`) | runs | **yes** |
| the function (module scope) | still invalid wasm | no |
| an annotated result (`(p): string \| i32 \| null => p`) | loud emit reject, `bare null needs a struct-typed context` | no |
