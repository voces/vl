### D17802 — a list-of-records element converted in an annotated lambda's result beside a loop converting it at another site is refused at mono

**open · loud emit reject · clause 2 · `vl check` rc 0, `emitProgram: monomorphize: unsupported argument type for `a` in a call to `id`` · filed 2026-11-28 against master `77e1160ea` (lane START-2)**

Repro:

    function id(a) { return a }
    function deliver() { return [{ f: id }] }
    const u = deliver()
    print(u[0].f(2))
    const k = (r): { f: (a: f64) => f64 } => ({ f: r.f })
    print(k(deliver()[0]).f(1.5))

#### Mechanism

Parked under D17832 (same mechanism, coordinator ruling 2026-11-28): the lambda's conversion relies
on an i32 call tagging the set; without that call the lambda alone traps (D17832), and beside a
second converting site the call to `id` reaches mono with an argument no pin closes.
