### D13901 — [CLOSED 2026-10-25] a `??` join of an existing record with a fresh literal is refused once the join type is declared elsewhere

**closed as `runs` · was loud emit reject · filed 2026-10-25 against master `de65aca55`**

Repro:

    function rd() {
      let a: {r: i32} | null = { r: 7 }
      const g1 = a ?? { r: null }
      const b: {r: i32 | null} | null = { r: 5 }
      print(0)
    }
    rd()
    // now runs and prints 0

#### Mechanism

The emitter's anonLeaf pass moves storage rows to a merged `#anon` row by the joins it
sees. Declaring `{r: i32 | null}` elsewhere gives the join a named row the merge does not
reach, and the emitter refuses. Which row a join lands on depends on whether some other
line of the program names its type: the storage type is not decided by the checker.
