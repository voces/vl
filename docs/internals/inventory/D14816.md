### D14816 — a fresh call handed to a generic beside a fresh record literal that binds the same type parameter, while another delivery builds the call's record wider, is invalid wasm

**open · check-clean invalid wasm, clause 1 · the fresh-literal residue of [D14814](D14814.md) · filed 2026-11-01 against master `431d2f30`**

Repro:

    type Circle = { r: i32 | null }
    type K = { r: null }
    function sink(_x: Circle) { }
    function mkcall() { { r: null } }
    sink(mkcall())
    function both<T>(a: T, b: T): i32 { 1 }
    print(both(mkcall(), { r: null }))

Want:

    1

#### Mechanism

`sink(mkcall())` builds `mkcall`'s record at `Circle`. `both`'s `T` is bound by both arguments.
The literal `{ r: null }` is fresh, so the D14814 close does not count it as a held pin, and
nothing else builds it at `Circle` beside `mkcall`. The instance and the two arguments disagree
on the row. Invalid on line 7.

| `{ r: null }` replaced by a held `const k: K` | refused (D14814) | the held spelling |
