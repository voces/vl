### D2498 — an else-less tail `if` ending in a map-entry write, under an inferred nullable return with no fall-through `null`, is invalid wasm at a value use

**check-clean invalid wasm · clause 1 · filed 2026-09-25 against master `0a0d24ac9`, found
grading [D2496](D2496.md)'s close, which leaves it as it was**

Repro:

    type Json = null | boolean | f64 | string | Json[] | { [string]: Json }
    function storeIt(v: Json, o: { [string]: Json }) {
      if v is { [string]: Json } { o["x"] = v }
    }
    const o3: { [string]: Json } = Map()
    const m: { [string]: Json } = Map()
    const r = storeIt(m, o3)
    print(r == null)
    // vl check: rc 0.  vl run: invalid module, "expected (ref null $type) but nothing on stack"

#### Mechanism

The checker infers `storeIt`'s return as `{[string]: Json} | null`: the arm's write yields the
narrowed map and the else-less `if` falls through to `null`. No pin gives that return a rep with a
`ref.null` (`synthNulListRetAnns` pins only a nullable list or a nullable declared struct), so
[D2496](D2496.md)'s `inferNullFallsThrough` keeps the function void, as master did, and a caller
that binds the result reads nothing. Called as a statement it runs; that is D1029's fixture
(`maps/narrowed-map-arm-delivery-positions.vl`). The capability is an inferred nullable-map pin:
D937 built one for i32-valued maps; the direct spelling `if c { someMap }` refuses at `vl check`
("infers the nullable return type … not yet supported by codegen").

#### Grading list

The statement-use form in D1029's fixture must keep running; `if c { m[k] = inner }` with
`m: {[i32]: {[i32]: i32}}`, which the checker floors today.
