Repro:

Want:

#### Mechanism

A null-only list literal delivered into a union whose list member holds a literal set's `| null`
is written element by element through the sentinel arm (`arrElemNulSent`), the arm a `null[]`
uses: each `null` is stored as the i32 2. A literal set's `| null` holds its atoms' ids in that
i32, so a read takes the 2 as an atom (`b` of `"a" | "b"`, `z` of `"x" | "y" | "z"`). A
`boolean | null` element's null is 2 already, so it reads right. The IR refused the arm
(`array null sentinel rep`) and legacy wrote the start body. The IR now delivers the `null` at
the element's niche rep, claims the unit, and the read answers `null`.
