#### Mechanism

`cloLiftScan` treats a use of `f` inside any other function as an escape, because inside `g`
the name `f` is a capture: `g`'s capture list holds `f` itself, so the call site in `host`
must pass a value. Lifting `f` as well needs `g`'s captures rewritten transitively — `g`
would capture `c` (what `f` captures) instead of `f`, and the call inside `g` would push
`c` from `g`'s own parameters. The capture lists come from `captureNamesOf`, which does not
know about lifting, so the rewrite belongs in the capture walk, and it must reach a fixpoint
across chains (`h` calls `g` calls `f`).
