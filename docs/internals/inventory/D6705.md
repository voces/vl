### D6705 — a generic handed to hole parameters of a call made inside another function's body is refused where the same call at module scope runs

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: `print(app(id, id))` at module scope runs · found closing [D6481](D6481.md) · filed 2026-10-18 against master `ca2adfdc7`**

Repro:

    function id(a) { return a }
    function app(g, h) { print(g(1) + 1); return h(2) }
    function use(n) { print(n); return app(id, id) }
    print(use(1))
    // vl check: rc 0.  vl run: emitProgram: cannot take the generic function `id` as a value — a function value carries ONE signature, and parameter `a` is un-annotated (it would default to i32). No call site pins `id`, so there is no inferred signature to adopt — annotate the parameter, or call `id` directly by name

Want:

    1
    2
    2

#### Mechanism

Not located. Both of `app`'s parameters take `id` at `i32`, so the refusal is not about two
instances; the call `app(id, id)` sits inside `use`, and a single hole parameter given `id` there
runs.
