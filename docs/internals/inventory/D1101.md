### D1101 — a map op in an expression STATEMENT the frame pre-pass did not name reserves no map scratch frame: `unknown local N: local index out of bounds`

**closed — `blockHasMapOp`'s statement dispatch named `BinExpr` and `Call` and nothing else, so
a tail `mk()["k"]` (an `Index` statement) reserved no frame while `emitExpr` lowered it as a map
GET · was check-clean invalid wasm, clause 1 · THE FILED AXIS WAS WRONG: neither the closure nor
the field is an ingredient · found 2026-09-02 while writing [D1092](#d1092)'s fixture**

Repro (runs, prints `3`):

    function viaMap(m: {f: () => {[string]: i32}}) {
      m.f()["k"]
    }
    function mkMap(): {[string]: i32} {
      const mp: {[string]: i32} = Map()
      mp["k"] = 3
      mp
    }
    print(viaMap({ f: () => mkMap() }))

Was `Invalid input WebAssembly code … unknown local 3: local index out of bounds` in `viaMap`.

#### Mechanism

`blockHasMapOp` is the frame pre-pass that decides whether a function reserves the 15-slot map
scratch frame beyond what `fnHasMap`'s locals/params scan finds. Its statement dispatch named
`LetDecl`, `RetStmt`, `BinExpr`, `Call`, `IfStmt`, `WhileStmt`, `ForIn`, `ForRange` — an
enumerated list, so an expression statement of any OTHER kind was invisible. `m.f()["k"]` in
tail position is an `Index` statement: no frame reserved, while `emitExpr` went on to lower it
as a map GET (`exprMap` answers for a map-typed call result through its `nodeTyIsMap`
fallback) and wrote `local.set` against `mapScratchBase + 2`, a local the header never declares.
The dispatch now keeps the arms that own their own recursion, gains a `Block` arm, and ends in
an else that asks `exprHasMapOp` of the whole statement — which cannot over-reserve, having no
arm for a declaration or a nested `FuncDecl`.

#### Ablation

THE FILED AXIS WAS WRONG. Neither ingredient the title named is one:

| ingredient removed | outcome on master's seed | needed? |
| --- | --- | --- |
| the closure FIELD (`f()["k"]`, a closure param) | `unknown local 3` | no |
| the closure entirely (`mkMap()["k"]`, a named fn) | `unknown local 1` | no |
| the MAP result (`i32[]` instead) | runs | **yes** |
| the statement position (bind it first, then index) | runs | **yes** |
