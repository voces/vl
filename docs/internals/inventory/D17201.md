### D17201 — a value `if` joining an inferred-null binding with a record, passed at a union-of-records parameter, is refused at emit

**closed 2026-11-25 by COV-IS · runs, prints `true`, `false` · was loud emit reject, clause 2; the claimless build still refuses (legacy) · the IR claims `arm`: a `null`-typed name in the join's arm, delivered into the union box, is the null tag and the bottom payload (`RNulNoneBox`), so no arm row is looked up · owner COV-IS · found by IR-N4 closing D17130 · filed 2026-11-24 against master `6bf25409`**

Repro:

    type A = { a: i32 }
    type B = { b: string }
    const n = null
    function isNU(x: A | B | null) { return x == null }
    function arm(f: boolean) { return isNU(if f { n } else { { a: 1 } }) }
    print(arm(true))
    print(arm(false))
    // vl check: rc 0.  vl run: emit error, "ref valtype with no interned shape"

Want:

    true
    false

#### Mechanism

With D17130's checker fix the join is `{ a: i32 } | null`, delivered into the union box of
`A | B | null`. The join's row is read off its `n` arm, the inferred-null binding (`nulnone`),
which has no record row, so the box's arm lookup finds no interned shape. Before D17130's fix the
join was `_ | null` and this printed `true true`.

#### Ablation

| spelling | outcome |
| --- | --- |
| the arm `null` literal in place of `n` | runs, `true false` |
| an annotated `const a: A \| B \| null = if f { n } else { { a: 1 } }`, then `a == null` | runs, `true false` |
| `n` on the else side | refused alike |

#### The close

The IR builds a `null`-typed name read delivered into a union box as legacy's
`emitNulNoneBoxPayload` writes it: the null tag and `ref.null none`, which never asks the join's
arm for a row. The claimed build prints the `Want:`; the claimless build still refuses, so
`scripts/ir-divergence-baseline.txt` lists `arm` as legacy-wrong (O3): `ir-identity.sh
--claimless` reads it as an expected divergence, and `ir-parity.vl` grades the IR-on run on `Want:`.
