### D17201 — a value `if` joining an inferred-null binding with a record, passed at a union-of-records parameter, is refused at emit

**closed 2026-11-24 · runs, prints `true` `false` · was a loud emit reject (clause 2, `vl check` rc 0, "ref valtype with no interned shape") · the IR's claim, not legacy: `deliver` (ir_build.vl) delivers a read of a `null`-typed name at a box with no value of its own, as it does a `null` literal, and `boxTempIn` boxes it as the bottom null (`RNulNoneBox`, no payload), as legacy's `emitNulNoneLeafPayload` writes a name; a claimless compiler still refuses it ([D17202](D17202.md)) · fixture `tests/cases/types/null-hole-join-delivery.vl` · found by IR-N4 closing D17130, new with its checker fix (silently wrong before) · owner IR-N4 · filed 2026-11-24 against master `6bf25409`**

Repro:

    type A = { a: i32 }
    type B = { b: string }
    const n = null
    function isNU(x: A | B | null) { return x == null }
    function arm(f: boolean) { return isNU(if f { n } else { { a: 1 } }) }
    print(arm(true))
    print(arm(false))
    // vl run: true, false (the IR's claim of `arm`)

Want:

    true
    false

#### Mechanism

Legacy refuses this argument for any such join, the `null` literal's spelling included
([D17202](D17202.md)): that spelling ran only because the IR claims `arm`. The binding's spelling
was not claimed: the IR boxes each arm into `A | B | null`, and its box took a `null`-typed value
only as a call, so the read of `n` was a miss ("box of a null-typed value"), legacy lowered `arm`,
and legacy's refusal shipped. With D17130's checker fix the join is `{ a: i32 } | null`; before it
the join was `_ | null` and this printed `true true`.

#### Ablation

| spelling | outcome |
| --- | --- |
| the arm `null` literal in place of `n` | runs, `true false` (the IR's claim; claimless refuses alike) |
| an annotated `const a: A \| B \| null = if f { n } else { { a: 1 } }`, then `a == null` | runs, `true false` |
| `n` on the else side | refused alike |
