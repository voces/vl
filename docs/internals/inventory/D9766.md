### D9766 — an annotated declared callback passed to `.map` over a list of an un-annotated function traps on its indirect call

**trap after load · `vl check` rc 0 · `wasm trap: indirect call type mismatch` in `ap` · clause 1 · found closing [D9712](D9712.md) · present on master `e8163edd5` · filed 2026-10-22 against master `60aaa08c0`**

Repro:

    function inc(a) { return a + 1 }
    const v = [inc]
    function ap(r: (a: i32) => i32): i32 { return r(5) }
    print(v.map(ap)[0])
    // vl check rc 0.  vl run: wasm trap: indirect call type mismatch

Want:

    6

#### Mechanism

Not traced. `ap` calls its parameter at `(i32) => i32`, so the element it receives must be the
instance of `inc` at that type. The list's element is pinned from the calls the flow table sees,
and the call inside `ap`, reached only through `.map`, is not one of them, so the list holds a
closure of another signature. A direct call `ap(v[0])` and an annotated lambda as the callback
both run.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the un-annotated parameter of `inc` (`inc(a: i32): i32`) | runs, `6` | **yes** |
| the `.map`, for a direct call (`print(ap(v[0]))`) | runs, `6` | **yes** |
| the declared callback, for an annotated lambda | runs, `6` | **yes** |
