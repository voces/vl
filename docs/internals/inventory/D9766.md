### D9766 — an annotated declared callback passed to `.map` over a list of an un-annotated function traps on its indirect call

**closed · runs, prints `6` · was trap after load, `wasm trap: indirect call type mismatch` in `ap`, `vl check` rc 0 · clause 1 · found closing [D9712](D9712.md) · filed 2026-10-22 against master `60aaa08c0` · closed by linking a named declared function handed to `.map` / `.filter` to the list's element as a lambda literal is, so the element takes its parameter's pin (`ffIsElemCallback`, `ffCallbackFn`, fn_flow_shadow.vl) · fixture `closures/hole-fn-list-named-callback.vl`, matrix `fn-value-hole-list-named-callback` (0 → 36 of 48, annotated face 24 of 24) · with [D9761](D9761.md) closed, [D9860](D9860.md), [D9861](D9861.md), [D9862](D9862.md) and [D9863](D9863.md) filed open**

Repro:

    function inc(a) { return a + 1 }
    const v = [inc]
    function ap(r: (a: i32) => i32): i32 { return r(5) }
    print(v.map(ap)[0])
    // vl check rc 0.  vl run: wasm trap: indirect call type mismatch

Want:

    6

#### Mechanism

The flow table links a `.map` / `.filter` callback's parameter to the receiver's element class,
so a pin on the parameter reaches every function the list holds. Only a lambda literal took that
link (`ffIsElemCallback`). A named callback was skipped, so `inc` got no pin, emitted as `$inc`
with no parameters, and the `call_indirect` at `(i32) => i32` trapped. The link now takes the
declaration a callback's name resolves to as well.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the un-annotated parameter of `inc` (`inc(a: i32): i32`) | runs, `6` | **yes** |
| the `.map`, for a direct call (`print(ap(v[0]))`) | runs, `6` | **yes** |
| the declared callback, for an annotated lambda | runs, `6` | **yes** |

#### Grading list

`.filter` with the same callback; two un-annotated functions in one list; a list built with
`push`; a list read through a map value or a record field; a nested list; an `f64` and a
`string` element; [D9761](D9761.md), the callback un-annotated.
