### D1372 — the ONE element rep left after [D1340](#d1340): an un-annotated literal whose element is a BOXED nullable scalar (`i32 | null`) still builds the mono i32 list

**check-clean invalid wasm · clause 1 · `type mismatch: expected i32, found (ref $type)` ·
the kind-2 (union BOX) element only — every NICHE element rep runs since D1270 and D1340,
and a null-free union element (`i32 | string`) runs too · ZERO corpus cells · filed
2026-09-03 as the last cell of D1340's 20-cell A/B where the two spellings still disagree**

Repro (`vl check` rc 0; the annotated `const xs: (i32 | null)[] = [f(0)]` prints `1`):

    function f(n: i32): i32 | null {
      if n == 0 { return 5 }
      return null
    }
    const xs = [f(0)]
    print(xs.length)

#### Mechanism

`arrLitNulRefElemName` refuses a kind-2 element outright — `if refArrElemKind(an) == 2 {
return "" }` — and that line is not an oversight: the rungs above it all name a NICHE (a
nullable list, map, closure, struct or variant), whose element is a `(ref null $X)` and whose
slot the ref-list layer already knows how to intern. `i32 | null` is not a niche — an `i32`
has no null representation, so its `| null` is a BOX with a tag, a different rep needing a
different intern. The literal falls to the i32 list default and a `(ref $box)` is stored into
an i32 backing.

The annotated spelling reaches the box by a different road: `refArrShapeKind` answers 2 for
`(i32|null)[]` through `parenUnionArrElemName`, whose `isValueUnionName` gate the niche rungs
do not share, and the ANNOTATION walk interns the union-box element slot. The inferred literal
has no annotation to walk, so nothing interns it. That is the same two-producers shape D1340
closed for the niche, at the one rep whose second producer is the union REGISTRY rather than
the ref-list one — the element has to be registered (`registerInlineUnion`) before a slot can
key on it, and that registration is what the annotation walk performs. A seventh niche rung
therefore cannot reach it.

The null-free union element is the discriminator: `f(): i32 | string` records a `TyUnion`, not
a `TyNullable`, so it never reaches this rung at all and runs today.

#### Grading list

Both faces of the boxed nullable-scalar element (annotated runs, inferred fails) at module and
function scope; the `i32 | string` null-free control and the `string | null` niche control,
both of which run today and must keep running; and D1340's and D1270's element reps — a
candidate that reaches the box by widening the NICHE rungs has broken exactly what the kind-2
exclusion protects.
