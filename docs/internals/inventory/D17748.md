### D17748 — a direct call through a const-bound lambda, general form, blocked by three mechanisms

**runs today and must keep running · a refutation pin: 18 distilled classes the general rule moved to loud emit rejects · filed 2026-11-27 against master `2cd65b2e3`**

Repro:

    function a<T>(x: T) {
      const k = (u) => { print([u].length) }
      k(x)
    }
    a(1)
    a(true)

Want:

    1
    1

#### Mechanism

The general rule: every call through a `const` bound to a lambda that captures nothing, in any
frame, is a direct call of the lambda's function at its signature's rep. Built in `callRhs`, it
moved 18 running distilled classes to loud emit rejects; `regress.vl` names 12 of them, and the
four traced (`d15112_list_length`, `d15110_captured_add_neighbour`, `d3290_r4_gN_n0901_…`,
`bundle_copy_closure_returned`) fail by three mechanisms:

1. **A template slot is not the instance's.** Inside a generic function, `fnStmtsPosOf` on the
   lambda's node names the template's slot; the instance's hole lambda is a clone with its own
   parameters, so the call misses with `argument count` (`d15112_*`, `d15110_*`).
2. **A print operand's rep.** A captured `K | null` read through `??` in a generic instance's
   lambda prints at a rep the print plan does not take (`print operand rep`, `d3290_*`).
3. **A closure result into a closure-rep global.** A lambda returning a closure (a bundle's) is
   called at its signature's result rep, which the global storing the call's value holds at the
   closure rep (`global initializer coercion`, `bundle_copy_closure_returned`).

PR #10646 takes the direct call only where the closure call has no rep (`openCallValue`): the
lambda captures nothing, declares no type parameter, annotates every parameter, the lift does
not take its binding, and its closure key names no scalar result. Those conditions exist only to
avoid the three mechanisms above; each one that closes deletes the conditions it needs.

#### Ablation

Not run. Each mechanism above is read from its traced program's miss under the general rule, not
delta-debugged; an ablation is owed before a close is scheduled against this row.
