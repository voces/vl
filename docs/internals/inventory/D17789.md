### D17789 — an un-annotated lambda's alias read out of a list in a generic's body, called at the instance's type parameter, is refused at emit

**loud emit reject, `cannot yet lower this statement (call of a non-declaration)` · clause 2 · `vl check` rc 0 · filed 2026-11-28 against master `b92b826e8` by COV-UNION**

Repro:

    function run<T>(y: T) {
      const f = (a) => a
      const m = [f]
      const g = m.pop()
      if g != null { print(g(y)) }
    }
    run(2)
    run("t")
    // vl check: rc 0.  vl run: emit error (call of a non-declaration) at 5:28

Want:

    2
    t

#### Mechanism

Not traced: the lambda's parameter takes the instance's `T`, so each instance pins the list's
element at its own signature, and the shared body's alias keeps the checker's open type. D17758's
fix types the alias only at a signature the instances share.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the call at a closed type (`g(3)` over `a + 1`) | runs (D17758) | **yes** |
| `(a)` annotated `(a: T)` | runs | **yes** |
| `m.pop()` replaced by `m[0]` (`print(m[0](y))`) | runs | **yes** |
