### D14564 — a generic's `T` bound to an enclosing generic's `U` records a rep the none reader cannot ask

**runs today and must keep running · refutation pin for converting the `nulnone` reader of `exprNulKind` to the recorded rep · filed 2026-10-27 against master `a52d7c9a4`**

Repro:

    function len<T>(f: () => T | null) { const t = f(); if t == null {0} else {1} }
    function outer<U>(x: U) { print(len(() => x)) }
    outer(null)
    // vl check: rc 0.  vl run: prints 0

Want:

    0

#### Mechanism

The program runs because the `nulnone` arm still answers from the read's storage. When
that arm was made to ask the read's recorded rep instead (the 1c experiment on `nulkind-1c`),
this witness became check-clean invalid wasm, `expected i32, found nullref`: the instance of
`len` whose `T` is bound to `outer`'s `U` (itself bound to `null`) records a rep for `t` that
disagrees with what its storage holds. The producer of that binding's rep is the gap; the
reader is correct.
