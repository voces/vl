### D16328 — `as?` to a literal set is refused, though `is` tests the same set

**closed · runs, prints `2` then `0` · was a loud check reject (`` `as` supports numeric conversions only ``, or ``names a type that is not a member`` over a union), clause 2 · found ablating D16326 · filed 2026-11-15 against master `53a3b13b8` · fixed 2026-11-15: a literal set the operand may hold (`tyTestMayFit`) is the cast's own arm (`castLitSetArm`, check_operators.vl), rewritten as the record casts are, `{ const $rc = x; if $rc is K { const $rh: K = $rc; $rh } else { null } }`. Matrix `literal-set-cast-over-scalar-union`: 0 of 64 cells ran, all 64 run. Fixture: `tests/cases/narrowing/literal-set-over-two-bases-runs.vl`**

Repro:

    type K = 1 | 2
    function h(x: i32) {
      const k = x as? K
      k ?? 0
    }
    print(h(2))
    print(h(3))

Want:

    2
    0

#### Mechanism

The cast's ladder took a scalar target only as a numeric conversion and a union target only
as the members it names, so a literal set, which `is` tests by the shared predicate, had
no route.

On master `53a3b13b8`.
