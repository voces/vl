### D2393 — a two-member nullable local a closure assigns is refused: a `null` write into the cell, a list read out of it

Repro:

    function f(): string {
      let v: string | null = "s"
      const k = () => { v = null }
      k()
      if v is string { v } else { "other" }
    }
    print(f())
    // vl check: rc 0.  vl run: emit error at the closure's `null`: bare null needs a struct-typed context

#### Mechanism

A `string | null` or `i32[] | null` local is a nullable niche, not a value-union box, so the
cell `captureBoxRewrite` makes of it is a list of that niche. The closure's `v = null` is a
store into `cell[0]`, and the store's null finds no typed context (it refuses at the `null`).
The `i32[] | null` spelling refuses at a different site, the narrowed READ: with the closure
writing `[1, 2]` instead of `null`, `if v is i32[] { "\{v.length}" }` refuses with `'.length'
on a receiver the emitter cannot classify` — possibly a second mechanism, graded here together.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the closure (`v = null` inline) | prints `other` | **yes** |
| the `null` write (`v = "t"`) | prints `t` | **yes** |
| the closure's write (`k` only reads `v`) | runs | **yes** |
| the `is` narrowing (`v != null`) | still refuses | no |
| the ref member (`i32 \| null`) | prints `other` | **yes** |
| a value member (`i32[] \| null`, closure writes `[1, 2]`) | refuses at `.length` instead | other site |
