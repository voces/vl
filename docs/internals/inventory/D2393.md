#### Mechanism

Two mechanisms, told apart by ablation. **The `null` store**: the closure's `v = null` is an
element store `v[0] = null` into the cell, a `(string | null)[]`, and the element-store arm of
`emitAssign` seeded the boolean and literal-union niches but not the string one, so the `null`
found no typed context. The closure is scenery: `const xs: (string | null)[] = ["a"]; xs[0] = null` refused
identically on master, filed as [D2288](D2288.md). The store now seeds the string niche, as
the list literal already did.
**The list read**: for `i32[] | null` the cell is a ref list of a nullable scalar list, and
the narrowed read `v[0]` is a synthetic node with no recorded type. `pushIndexNicheNarrow`
pushed no narrowing for a nullable scalar-list element and `indexListRep` refused every
nullable element, so `.length` under `is i32[]` or `!= null` could not classify its receiver.
The narrowing is now pushed, and a nullable element narrowed past `null` reads as its list.
