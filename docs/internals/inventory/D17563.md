### D17563 — a hole identity whose body holds a control-flow statement or an early return is not adopted, so its result, delivered wider, builds invalid wasm

**closed 2026-11-25 by SOUND · runs, prints `1` `5` · was check-clean invalid wasm, clause 1 · `holeUsesOnlyFields` (check_fit_rules.vl) answered false for every control-flow statement, so `recHoleIdentityArg` declined and the literal kept its own row while its result was declared at the destination's; it now walks `if`, `while`, `for`, a block, `break` and `continue`, takes an early `return` of the parameter, and `holeTailName` takes a value `if` every arm of which hands back the parameter · pinned by `tests/cases/records/hole-identity-control-flow-delivered-wider.vl` · found grading D17560's close · filed 2026-11-25 against master `a7ec36a7`**

Repro:

    type A = { d: i32 | null }
    function g(v) {
      if v.d > 3 { print(1) }
      return v
    }
    const c: A = g({ d: 5 })
    print(c.d ?? -1)
    // vl run: 1 5  (was: vl check rc 0, vl run invalid module)

Want:

    1
    5

#### Mechanism

`recHoleIdentityArg` (check_fit_rules.vl) adopts the literal argument at the destination's record
only when every statement before the hand-back uses the parameter as a field's receiver, and
`holeUsesOnlyFields` answers false for every control-flow statement whatever it holds, so the
literal stays at its own row while the checker's `recWidenWalk` lets the result pass as built at
`A`. An early `return v`, or a value `if` whose arms are `v`, ends the body in no single `Ident`
and is declined the same way. The parameter is never shared in these shapes, so the design's
answer is `runs` (D17560 is the shared spelling, refused).

#### Ablation

| spelling of the statement before `return v` | outcome |
| --- | --- |
| `if v.d > 3 { print(1) }` | invalid |
| `let i = 0` then `while i < 2 { i = i + 1 }` (no use of `v`) | invalid |
| `let i = 0` then `while i < v.d { i = i + 1 }` | invalid |
| `if v.d > 3 { return v }` (an early return) | invalid |
| the body `return if v.d > 3 { v } else { v }` | invalid |
| `print(v.d)` or `let i = v.d` | runs |
