### D14601 — the emitter keeps a by-name call index, because an instance's calls are not in the checked arena the occurrence index describes

**runs today and must keep running · a named floor, no wrong value · fixture `generics/hole-param-tail-calls-void-field-function` · filed 2026-10-28 against master `7673b502b`**

Repro:

    export function click(b) { b.onClick() }
    click({ onClick: () => print("A") })
    function tap(b) { b.onClick() }
    tap({ onClick: () => print("B") })
    const k = tap({ onClick: () => 5 })
    print(k)
    print("end")

Want:

    A
    B
    5
    end

#### Mechanism

`fieldClosureFeOfRecvRaw` resolves a hole parameter's field closure through the calls of the
function that declares the parameter, and reads those calls from `callsOfCallee`
(`emit_fn_ret_kinds`), an arena scan keyed by the callee's identifier name. The occurrence
index files the same calls under the callee's `FuncDecl`, but it describes the checked arena.
The monomorphiser mints each instance (`tap` per argument type) and re-points its calls during
emit, so those calls exist only in the larger arena. Read from the index, 4 of the 52 cases
that reach this arm answer differently. With the index re-synced on every growth, L2 fuel rises
2.54%. The deletion target is the monomorphiser filing each call under the instance it
re-points the call to, so the index answers templates and the mint answers instances.


#### The callee resolution beside it

`fnIndexOfInScopeAt(sid, name, fnIx, atIx)` (`emit_local_scope`) is the same floor on the
call's other end. It decides which function a call's callee spelling names, and refuses the
flat answer when a binding of that spelling shadows it: `frameChainBindsName` asks the
frames on the chain by name, and `moduleBlockShadowsAt` asks the module blocks by name. Its
25 callers are in `emit_classify` (11), `emit_mono` (7), `emit_local_scope` (3),
`emit_obj_lit_fits`, `emit_sig_tokens` and `wasmEmit` (1 each). The deletion target is the
same: once every call, template and instance, carries the checker's resolved callee
declaration, the callers read it and the by-name shadow tests go.
