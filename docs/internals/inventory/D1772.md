#### Mechanism

[D1758](D1758.md) gave the capture pair its map arm through `mapFindShapeOfNodeTy`, a find over
the recorded map value type. A NESTED map's value is itself a map — mv kind 6, whose shape is
the inner map's own slot rather than a value row — so the find resolves the shallow map's
shape and the env field is declared one container short of what the closure holds.

The ablation is what says this is D1758's arm and not [D1750](D1750.md)'s `$fnsig` reader: the
same program with a STRUCT-valued inner map is a LOUD `emitProgram: function-value call arity
has no interned signature`, a different outcome from a different rung, so the two are siblings
and one fix moves one of them. The depth is the ingredient — at one container the identical
program runs.

Two neighbouring spellings of the nested map refuse loudly rather than silently and are NOT
graded here, because neither was ablated: the ANNOTATED binding and the plain-module-scope
spelling both reach `emitProgram: the locals vector desyncs from the frame layout at the
map-values output`, and the capture removed reaches `` `??` over this nullable value is not
supported yet ``. Those are message groups, not measured families.
