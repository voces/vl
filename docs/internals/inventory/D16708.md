#### Mechanism

Not localised. `orZero`'s result joins the literal union (stored at `i64` once `5000000000` is a
member) with the `0` default, and `take`'s hole instance reads that value at a width its alias
`v` does not share. Without the alias the same program is a loud emit refusal instead.
