    function orZero(f) { return f() ?? 0 }

Want:

    5000000001

#### Mechanism

`orZero`'s result is `5000000000 | i32`: numbers of no one base, which rep as a union box. A
type parameter or an annotation at that type takes the box. A hole's pin did not: `monoPinWidenTy`
(pin_spell.vl) widens a number literal beside any other member, meant for literals next to strings
or records, so the pin became `i64` and the clone's parameter an `i64` slot. The elaboration had
already walked the body at the union, so every read opened a box the slot was not. The widening
now keeps a union whose members are all numbers with no one base.
