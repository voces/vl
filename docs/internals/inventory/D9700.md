#### Mechanism

The instance's call can be null, so no dead-default fold applies, and the `??` reaches the
call-stash arm (`emitCoalesceCallStash`, wasmEmit.vl). That arm asks `unionNameOfCall` for the
union the call returns, which reads it off the callee's annotation. A call through a hole
parameter names no annotation, so the answer was empty and the nullable-value arm refused.
In a pinned instance the call's own type is the box the bound lambda returns, and
`valueUnionRenderOfTy` names it (`i32|null`).
