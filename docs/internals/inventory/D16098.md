#### Mechanism

The call's generic parameter is instanced at `(i32) => i32 | string`, a closed delivery, so the
read is an escape. The decision left a set of two plain members untagged, `fnTagEtaAgain` vetoed
the binding, and the re-check read it at `inc`'s type, where `holeLetJudge` refused. The decision
now tags it where the members' results split there and each fits `R`. A member whose result
does not fit (`same<T>(g: (x: T) => T, …)`) leaves the set untagged, and the refusal stands. So
does D9003's at a closed `(a: i32) => i32`.
