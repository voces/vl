#### Mechanism

An assignment is a value and an else-less `if` is `T | null`, so every `if` was typed as the join
of its arms wherever it stood, and an un-annotated function's tail was its inferred return even
when no caller read it. A vector in an arm then made a `v128 | null` or `i32 | v128`, which has no
lowering. Now `ucCompute` (typecheck.vl) finds the un-annotated, un-exported top-level functions
whose every call is a statement — following tail calls, and keeping any function named as a value
— and the checker hoists and checks each as `: void`, with `computeVoidFns` and the monomorphizer
agreeing; and `valDiscardAt` marks an `if` that is not its block's value, a loop body, a top-level
statement, or a void body's tail, which then types `void` whatever its arms hold.
