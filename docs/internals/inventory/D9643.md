### D9643 — a list element of an un-annotated function's record read through a function returning it, handed to an un-annotated parameter, has no interned call signature

**loud emit reject · `vl check` rc 0 · `emitProgram: a function-value call has no interned signature` · clause 2 · found closing [D9570](D9570.md) · present on master `9e81d3ee3` · filed 2026-10-22 against master `9e81d3ee3`**

Repro:

    function inc0(a) { return a + 1 }
    function take2(a) {
      print(a.f(3))
    }
    const xs = [{ f: inc0 }]
    function g(i: i32) { return xs[i] }
    take2(g(0))
    // vl check rc 0.  vl run: emit error: emitProgram: a function-value call has no interned signature

#### Mechanism

The flow table sees no call through the slot of `xs`, so `monoPinListRecords` types the list at
the uncalled default `(i32) => i32` ([D9100](D9100.md)) and `inc0` is not instanced there.
[D9644](D9644.md)'s close leaves the element open only when the read `xs[k]` is itself the
argument (`monoRecListFieldCalledAtHole`, emit_mono.vl); here it reaches `take2` through `g`'s
return.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the function (`take2(xs[0])`) | runs, `4` | **yes** |
| the hole in `inc0` (`inc0(a: i32): i32`) | runs, `4` | **yes** |

#### Grading list
