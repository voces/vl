### D17000 — a call through a list of un-annotated functions with different results, before a lambda is written into the list, is typed at one member's result and builds invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · the dispatch's `if (result i32)` takes `half`'s `f64` arm unconverted · clause 1 · found by lane F2 grading [D16937](D16937.md)'s fix · filed 2026-11-19 against master `938930861`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const xs = [inc0, half]
    print(xs[1](3))
    xs.push((x) => x * 3)
    // vl check: rc 0.  vl run: invalid module, "type mismatch: expected i32, found f64"

Want:

    1.5

#### Mechanism

`holeSetCallRetOf` (check_relate_core.vl) gives up on a set whose member is a lambda not yet
checked, "typed by its own callee, and each arm takes its member's result when it is instanced",
so the call is typed at the element's own instance, `i32`. The set is tagged with the lambda,
and the dispatch builds each arm at its member's result: `half`'s `f64` arm has no conversion
into the call's `i32`. The same lambda written before the call runs.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the lambda bound before the call (`const g = (x) => x * 3` above `print`) | runs, prints `1.5` | **yes** (a lambda after the call) |
| a named function pushed (`xs.push(inc0)`) | runs, prints `1.5` | **yes** (a lambda) |
| one result type (`half` → `dbl`) | runs | **yes** |
| a list of records (`[{ f: inc0 }, { f: half }]`, `{ f: g }` with `g` bound after the call) | invalid module | no |
| the record literal written in the push (`xs.push({ f: (x) => x * 3 })`) | invalid module since [D16937](D16937.md)'s close; a loud emit reject before | no |
| an annotated lambda pushed (`(x: i32) => x * 3`) | typed `i32` at check as well | no |

#### Grading list

The four spellings above that build invalid wasm, and the call read after a second push.
