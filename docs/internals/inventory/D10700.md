#### Mechanism

The elements' second parameter `s` is a hole the call fills with the frame's own hole parameter
`k`. When the element typing (`monoElemParamTys`) runs, `s` is still open, so the element type
it gives the callee has a type variable at `s`, and the generic `add` cannot be chosen at it (not
traced further).
