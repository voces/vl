#### Mechanism

A refutation pin. `arrLitElemKindTpl` (`emit_value_sites.vl`) keys a list literal's element by
its shape: here `RLK_MAP`. The step-7 candidate answers `refListElemKindOfTy` of the literal's
recorded element type instead. That type, `LM | IM`, is right. But `rlUnionElemKindOfTy`
(`emit_shape_rows.vl`) collapses a union only when its arms are `tySame`, so it answers
`RLK_UNION`. D15540 stores this union as its one map, so the element wrapper and the backing
disagree, and the module fails to validate. Over the sweep population the candidate moves
exactly these 2 cells `runs → compiler trap`. 4 more cells (class 4>9) build a different module
that prints the same output. Every other cell is byte-identical. The candidate is refused until
the type reader applies D15540's collapse.
