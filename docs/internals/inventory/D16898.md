#### Mechanism

Mono pins `const v`'s annotation and type while it runs. The class readers it asks after that pin
see `v` closed, so `inc0`'s slot closes at a function type and the program builds. Read as of the
freeze before mono, `v` is open, nothing closes `inc0`, and the emit refuses: `cannot take the
generic function inc0 as a value`. The answer this program needs exists only after mono's own pin,
so neither a freeze-time snapshot nor a pin table filled before mono can give it.
