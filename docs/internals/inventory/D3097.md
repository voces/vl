#### Mechanism

`e` is the `{tag, payload}` box, and `!(e is string)` narrows it to `Circle | null` at the type
level only. `narrowedArmNeedsUnbox` recognised a narrowing to one arm (`narrowedStructArmVi`), so
a narrowing to an arm or struct plus `null` delivered the box whole into the `(ref null $Circle)`
parameter. The null tag carries a null payload, so the unbox for that narrowing is the same
`struct.get` followed by `ref.cast null` (`narrowedNulStructArm`, `fbRefCastNull`). Every
existing unbox site now passes its expression so the cast picks its nullability; `emitCallRef`'s
struct and nullable-arm parameters and `emitCapturedCall`'s arguments gained the unbox they
lacked.
