### D9523 — an un-annotated parameter bound at a mixed-width numeric literal union refuses `+` with an `i64`

**loud check reject · clause 2 · CAPABILITY: the same `a + 5000000000` over the union value directly runs, and an annotated parameter `x: W` runs · found closing [D9492](D9492.md) · present on master `0be192a3f` · filed 2026-10-22 against master `0be192a3f`**

Repro:

    type W = 1 | 2 | 5000000000
    const a: W = 2
    function take(x) {
      print(x + 5000000000)
    }
    take(a)
    // vl check: argument 1: operator '+' is not defined for W and i64 (the body of `take` applies '+' to this argument)

Want:

    5000000002

#### Mechanism

Not traced. The operator check of the un-annotated parameter's body at its call-site type does
not apply the numeric literal union arithmetic the direct spelling gets, so `W + i64` has no
operator there. The same refusal reaches a function value: `take(() => a)` with `f() + 5000000000`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the un-annotated parameter (`x: W`) | runs | **yes** |
| the parameter (`print(a + 5000000000)`) | runs | **yes** |
