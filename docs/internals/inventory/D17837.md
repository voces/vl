### D17837 — a null hole is filled by writing the nullable row's inner in place

**runs today and must keep running · refactor target: S2a keeps a nullable row with an open inner out of the intern table because this writer fills it · filed 2026-11-28 against master `9ee417b8d` · owner COV-IS**

Repro:

    let x = null
    x = 4
    print(x ?? 0)
    // vl check: rc 0.  vl run: 4

Want:

    4

#### Mechanism

`nhFillLinked` (`check_relate_core.vl`) writes `t.nInner` of a nullable row whose inner is open,
and of every hole linked to it. The close stores the open inner as a hole code, as list and map
children are (`openChild`), so the pin writes the hole's solution and the row never changes.
