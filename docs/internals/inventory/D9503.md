### D9503 — a returned list of un-annotated functions nested in a list literal or record field has no interned shape

**loud emit reject · `vl check` rc 0 · `ref valtype with no interned shape`, no position · clause 2 · found closing [D9450](D9450.md) · present on master `56e51b394` · filed 2026-10-21 against master `56e51b394`**

Repro:

    function inc(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function deliver() { return [[inc, dbl]] }
    const v = deliver()
    print(v[0][1](3))
    // vl check rc 0.  vl run: emit error: emitProgram: ref valtype with no interned shape

Want:

    6

#### Mechanism

Not traced. The returned literal's functions are delivered at the outer slot's pin, and the inner
list's element slot (`e.e`) is never instanced, so the outer list's element rep names a function
type no shape was interned for.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the nesting (`return [inc, dbl]`, `v[1](3)`) | runs, `6` | **yes** |
| the return (`const v = [[inc, dbl]]` at module level, `.map`) | runs, `6` | **yes** |
| the inner list, as a record field (`return { f: [inc, dbl] }`, `v.f.map(...)`) | runs, `6` | **yes** |
| the nesting inside the callee, moved to the caller (`const w = { f: deliver() }`, `w.f.map(...)`) | same refusal | no |

#### Grading list

The caller-side record field in the ablation, and matrix
`hole-fn-list-returned-called-at-two-types`, un-annotated `struct_field_init`.
