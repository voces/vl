#### Mechanism

`monoRetFnListTy` typed only a flat returned list: it read the pin of slot `e`, which a list of
lists does not take, so the inner list's element slot (`e.e`) was never instanced and the outer
list's element rep named a function type no shape was interned for. The caller-side record field
is a second cause: the call `deliver()` in the field kept its open type, since only a binding's
initialiser was read at what the call returns.
