### D17043 — [CLOSED 2026-11-21] `vl check` reports a binding unused when its only read is a call through a field holding a named function

**closed 2026-11-21 · runs today and must keep running · runs, prints `6`, and `vl check` reports no unused variable · fixed in lint.vl: `checkCallNodeGo` repoints a call through a field of one declared function to that function's direct call, and the parse bank drops the minted callee, so the lint met neither `r.f` nor `r`; `repointedReceiverRead` now reads the receiver and the field off the call's own tokens (`r . f ( … )`), as a `x.m(…)` callee reads them, adding no state · pins `tests/vl_check_field_call_read_test.ts` (CLI; the corpus oracle re-parses for lint and never saw it), `lint/field-call-named-function-no-warn.vl` · filed 2026-11-21 by lane IR-N5 against master `568e22a36`**

Repro:

    function twice(a: i32) { return a * 2 }
    function bound() {
      const r = { f: twice }
      return r.f(3)
    }
    print(bound())
    // vl check: rc 0, with "[WARNING]: Unused variable `r`" at `const r`.  vl run: prints 6.

Want:

    6

#### Mechanism

`checkCallNodeGo` (`compiler/check_calls.vl`) turns a call through a const record's field that
always holds one declared function into that function's direct call, repointing `callFn` to a
fresh identifier that the driver's parse bank later drops. The lint walks the checked tree, where
`r.f` no longer hangs from the call, so no occurrence of `r` resolved to its binding. As filed: the read `r.f(3)` is a call whose callee
is a field holding a declaration's closure value, the unused-variable count did not take the
member call's receiver as a read of `r`, and the same binding read through `const h = r.f`
counted (no repoint happens there).

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `twice` un-annotated (`function twice(a)`) | still warns | no |
| the field holds a lambda `(a: i32) => a * 2` | no warning | **yes** (a named function) |
| the record annotated `const r: R`, lambda field | no warning | — |
| the field read into a local, `const h = r.f; return h(3)` | no warning | **yes** (the call through the field) |
