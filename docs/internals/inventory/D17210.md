### D17210 — a module inferred-null binding filled with a literal-union value is refused at the write

**loud check reject · clause 2 · `vl check` rc 1, "cannot assign AB to _ | null" · the same before and after #9975 · found by V4 verifying #9975 (LAF2); the queue ruled the refusal is not one the design owes · owner IR-N4 · filed 2026-11-25 against master `46179f20`**

Repro:

    type AB = "a" | "b"
    const x: AB = "a"
    let m = null
    function pick(flag: boolean) { return if flag { m } else { x } }
    m = x
    print(pick(false) ?? "none")
    print(pick(true) ?? "none")
    // vl check: rc 1, "cannot assign AB to _ | null" at the write

Want:

    a
    a

#### Mechanism

`let m = null` binds the open hole, which a later write fills (D1576). A write of a
string-literal-union value does not fill it: the write is checked against the open hole as a
destination and refused. The same program with `let m: AB | null = null` runs, so the refusal names
no contract. Not yet ablated past that.
