### D2782 — a generic whose returns join a record list and `i32[]` at the pin is invalid wasm inside the function

**check-clean invalid wasm · 16 cells of the #3207 round-2 grid (`b_G_Circle_*`) · filed 2026-09-27 against master `f6db92e0d`**

Repro:

    type Circle = { r: i32 }
    function h<T>(c: boolean, t: T) {
      if c { return [t] }
      [1]
    }
    h(true, { r: 4 })
    print("ok")
    // vl check: rc 0.  vl run: invalid module inside `h`

#### Mechanism

At `T := Circle` the returns join to `Circle[] | i32[]`. The instance's body does not validate:
the record-list arm and the `i32` list are not both delivered into the result the instance
declares. It fails inside `h`, so every use fails with it, a discard included. The string pin
of the same function builds (D2766). Not yet localised further.

| the disagreeing return (`[t]` both ways) | runs | **yes** |
