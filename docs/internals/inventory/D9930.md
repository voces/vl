#### Mechanism

Four walks treated the record as a tree, so each reached a sub-record once per path to it,
`2^depth` times. `tyDeeperThan` recursed into both fields of every level on every ask. `tyEq`
and `assignable` compared `l` and `r` of each level separately, and the two halves are the
same pair. A record field's element name (`anonFieldElemName`) and a function's record result
token (`sigRetTokOfTy`) were read off the record's spelling, `7·2^depth` characters. The
height is now stamped with `tyMutEpoch` per arena index; a pair answer is kept only when no
cycle guard fired under it and, for `assignable`, no arena write happened during it; the two
emit reads ask the arena type first past depth 8.
