### D15294 — mono writes the closed type of an un-annotated list of records of functions, where the checker or elaboration should produce it and mono read it

#### Mechanism

`monoPinRecordListAt` turns the flow table's pin of each function field into a closed record type and WRITES it: a binding's `letType` and a list literal's `nodeTyRecord`. That makes mono a producer of a type fact the emitter's interners read, against the rule that the checker and elaboration produce and mono and emit only read. The close moves the pin into elaboration, so both become readers of one recorded fact, and a bare statement's literal ([D15291](D15291.md)) is typed where it is checked. The witness must keep running across that move.
