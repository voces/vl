### D17051 — a builder-asked legacy plan that emitFails on a shape legacy routes around first turns a building program into a build failure once shadow coverage reaches it

**runs today and must keep running · filed 2026-11-22 against master `2934a520` · a refutation pin: the build failure appears under a change that widens the IR's coverage**

Repro:

    type K = 1 | 2
    function mk(c: boolean): u8[] | K[] {
      const a: u8[] = [1, 2]
      const b: K[] = [2, 1]
      if c { return a }
      return b
    }
    function go(q: u8[] | K[]) {
      if q is K[] {
        q[0] = 2
        print(q[0])
      }
    }
    go(mk(false))
    // vl run: prints 2. With the IR's listAcross rung built and no arm-write check in elemStore,
    // every mode fails: emitProgram: indexed-assignment target is not an array

Want:

    2

#### Mechanism

The IR builder runs on every function to decide its claim, armed or not, so any legacy plan it
asks runs in every build. `idxStorePlanOf` records a refusal (`emitFail`) when an element
store's target is not a plain array. Legacy never asks it for this store: `emitAssignIndex` first
writes a store through a box of list arms per arm (`emitArmIndexWrite`). The IR's `elemStore`
asked the plan directly. While the IR stopped earlier in `go` (at the `is` rung) the call was
never made. Once the rung was built, the IR reached the store and its call recorded the refusal,
which fails the whole compile. The listAcross PR (`ir-is-rung-arms`) closes this instance by
asking the arm question first (`armIndexWriteArmsOf`). The class stays open.

#### Grading list

- Other builder-asked plans that refuse a shape rather than answer it: `pushPlanOf` (".push
  receiver is not a list"), and `isNulTestImpossible` via `nulNicheIsTestImpossible` ("`is` cannot
  tell"), which `litIsArmOf` also reaches. No reachable witness yet: the narrowed `q.push(1)` is a
  check refusal.
- The instrument that would close the class: a lint that a plan helper the builder asks never
  calls `emitFail`, returning its refusal as a value.
