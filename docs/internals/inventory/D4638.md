### D4638 — a map annotated with an anonymous union arm as its value type builds an i32 map where the record map is declared

**check-clean invalid wasm · clause 1 · the annotated face of [D4636](D4636.md) · filed 2026-10-14 against master `536c4c79e`**

Repro:

    type U = { q: i32 } | { r: i32 }
    const m: Map<string, { q: i32 }> = Map()
    print(m.length)
    // vl check: rc 0.  vl run: type mismatch: expected i32, found (ref $3); $3 is `i32 array (list and map storage)`

Want:

    0

#### Mechanism

Not localised past the ablation. The annotation's value type `{ q: i32 }` is an anonymous arm
of `U`, with a variant row and no plain struct row, so it interns no record map value slot.
The declaration's `Map()` builds the i32 map's storage into a cell laid out for something
else. With a store (`m["k"] = { q: 4 }`) the same program refuses loudly instead, with
`the locals vector desyncs from the frame layout at the map-values output frame`.
