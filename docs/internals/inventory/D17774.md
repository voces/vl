### D17774 — a `.map` lambda over a function's returned record list binds an annotated local of a closed function type from the element's set field, and the closure is stored as the id

**open · loud emit reject · clause 2 · `vl check` rc 0, `emitProgram: a .map/.filter callback needs an instance at the list's element type, and none was built for this call` (lane START-2's guard, 2026-11-28; it built invalid wasm before) · filed 2026-11-27 against master `a1edbdabf` (lane START-2)**

Repro:

    function id(a) { return a }
    function deliver() { return [{ f: id }] }
    const v: { f: (a: f64) => f64 }[] = deliver().map((r) => { const g: (a: f64) => f64 = r.f; return { f: g } })
    const u = deliver()
    print(v[0].f(2.5) + u[0].f(2))
    // vl check: rc 0.  vl build: loud emit reject

Want:

    4.5

#### Mechanism

Not traced. Found writing the list half of [D17764](D17764.md)'s converting copy by hand: the
lambda's element `r` holds the set's id (`u` reads it at `i32`), and the record `{ f: g }` built
at the `f64` closure record receives an `i32` where its closure field is wanted, so the
coercion of `r.f` into `g` is not built.
