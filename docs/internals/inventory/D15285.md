### D15285 — a list of record lists spread into a list of lists held at a wider record is check-clean invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · open, target `7` · found closing [D15284](D15284.md), grading the `nested arrays are not supported` refusal one spelling per row · filed 2026-11-04 against master `930a8aae`**

Repro:

    type J = { f: i32 | null }
    const ys: J[][] = [[{ f: 4 }]]
    ys.push(...[[{ f: 7 }]])
    print(ys[1][0].f ?? 0)

Want:

    7

#### Mechanism

Not ablated past the table. The spread list of `{f: i32}` lists is built at its own row, and its
elements are handed to a list whose inner lists are `J[]`. A spread of a list of records into a
list of records is built at the receiver (D15235), but not one level deeper. The one loud spelling,
an inline literal spread into a list of lists BUILT wider, refuses as `emitProgram: nested arrays
are not supported`; that sentence is false of every plain spelling below.
