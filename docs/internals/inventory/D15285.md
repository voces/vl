#### Mechanism

The spread list of `{f: i32}` lists is built at its own row, and its
elements are handed to a list whose inner lists are `J[]`. A spread of a list of records into a
list of records is built at the receiver (D15235), but not one level deeper. The one loud spelling,
an inline literal spread into a list of lists BUILT wider, refuses as `emitProgram: nested arrays
are not supported`; that sentence is false of every plain spelling below.
