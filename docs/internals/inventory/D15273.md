### D15273 — two bindings of one function's returned record, one written another function, refuse when the unwritten one's field is called

**open · loud emit reject · `emitProgram: cannot take the generic function id0 as a value — a function value carries ONE signature` · clause 2 · either binding alone runs · the read spelling runs · found grading D15270 · filed 2026-11-04 against `lane/g2-d15270-call` `9c379a287`**

Repro:

    function id0(a) { return a }
    function id1(a) { return a }
    function mk() { return { f: id1 } }
    const r = mk()
    r.f = id0
    const s = mk()
    print(r.f(2))
    print(r.f(2.5))
    print(s.f(7))

Want:

    2
    2.5
    7

#### Mechanism

`mk` returns one literal, and both `r` and `s` read it. `r`'s field is widened to `{id0, id1}`
and its calls dispatch through that set (D15270). `s` is not written, so its field call
`s.f(7)` adopts the literal at the call's closed row (`holeFieldCallAdopt`). That re-builds the
literal's field as a closure, the smaller set `{id1}` fails its scan, and `r`'s set stays
untagged. The literal has to be built at the widened row for every reader once one reader is
widened.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `s` (one binding) | runs | **yes** |
| `r`'s write (`r.f = id0`) | runs | **yes** |
| `s.f(7)` (`s` unread) | runs | **yes** |
| `s.f(7)` read as `const h = s.f; h(7)`, `r.f` likewise | runs | **yes** (the direct call) |
| `r` (only `s`, its field called at two types) | runs | **yes** |
