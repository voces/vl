### D15808 — a value whose function field holds un-annotated functions returning different types, handed to an un-annotated parameter of a `const` lambda, is not judged at check, and traps or builds an invalid module

**loud check reject · `cannot store 'inc0' in 'r.f': called at (i32) it returns i32, where 'half', also stored in it, returns f64` · clause 2 · open, as [D15807](D15807.md) is for the named function · was a runtime trap, `wasm trap: indirect call type mismatch`, with `vl check` reporting 0 errors, clause 1, and the list spelling built an invalid module · found closing [D15807](D15807.md) · filed 2026-11-12 against master `0671904bf` · contained 2026-11-12 in `cwParamArgCalls` (check_write_scan.vl): a lambda an unwritten `const` holds is called through that binding, whose reads are now its calls, so the judgment sees the arguments as it does a named function's · the bound spelling is [D15775](D15775.md) · fixtures `tests/cases/closures/error-if-of-records-of-different-results-handed-inline-to-const-lambda.vl`, `error-list-of-records-of-different-results-handed-to-const-lambda.vl`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function two() { [1, 2].length }
    const take = (r) => r.f(3)
    print(take(if two() > 5 { { f: half } } else { { f: inc0 } }))

Want:

    4

#### Mechanism

Not traced. The judgment that refuses these spellings for a named function's parameter
([D15802](D15802.md), [D15807](D15807.md)) reads the parameter's arguments through `cwParamArgs`
(check_write_scan.vl). That finds the calls of a named function only. A lambda is named
`__lambda…` and called through the `const` that holds it, so it has no arguments to read, and
nothing at check sees the functions' results.

#### Ablation

| spelling | outcome |
| --- | --- |
| the witness | runtime trap before the containment; loud check reject |
| a list literal, `const take = (v) => v[two() - 1].f(3); take([{ f: inc0 }, { f: half }])` | invalid module before the containment; loud check reject |
| the record bound first, `const q = if … ; take(q)` | loud emit reject |
| two separate record literals, `take({ f: inc0 }) + take({ f: half })` | runs, `5.5` |
| a named function, `function take(r) { … }` | loud check reject ([D15807](D15807.md)) |
