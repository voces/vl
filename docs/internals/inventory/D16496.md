### D16496 — a join whose constant arm does not fit `i32`, beside an inner join of a typed `i32` arm and a literal arm, builds invalid wasm

**check-clean invalid wasm · clause 1 · open · `vl check` rc 0 · `vl run`: "the emitted module failed to validate inside the module's top-level code: type mismatch: expected i32, found i64" · found by the independent oracle's arithmetic generator once it stopped emitting what the checker folds and refuses (fuzz cell `ar_s42_0050`) · filed 2026-11-15 against master `6f9bafb92`**

Repro:

    let v1: i32 = 5
    let c = true
    const x = if c { 3000000000 } else { if c { v1 } else { 1 } }
    print(x)
    // master: vl check rc 0; vl run: the emitted module failed to validate

Want:

    3000000000

#### Mechanism

Not ablated to a compiler function. The outer join is `i64`, because its constant arm does not
fit the inner join's `i32` (4.3, D3043). The inner join's literal arm has already adopted the
typed arm's `i32`, and the inner join is emitted at `i32` where the outer join reads `i64`.
Either the inner join is not widened, or one of its arms is.
