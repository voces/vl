#### Mechanism

D2652's mechanism at a cell whose zero default is not a value of its type: a `string`, record,
list, map, union box or closure cell is a nullable wasm reference that holds `null` until the
start function reaches the declaration, and the first use of the early read dereferenced it.
The abort was right and the message was the engine's. The D2652 guard runs before the
`global.get`, so the program now stops at the read with the global's name, its declaration and
the reading function, on every host `vl run` uses (the reason streams through the same print
imports `as!` and `__trap__` use, then `unreachable`, exit 1).
