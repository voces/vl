### D15555 — a bound list of records holding a function returned beside a literal of a wider set has no one list row

**open · loud emit reject · `emitProgram: the lists this function returns are built at different rows, so its inferred list result has none` · clause 2 · the bound list returned beside a bare list of functions runs, `[inc0]` / `[inc0, dbl]`, and so does a bound record `{ fs: [inc0] }` · found closing [D15510](D15510.md) · filed 2026-11-08 against master `2a9d12a1`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function pick(b: boolean) {
      const a = [{ f: inc0 }]
      if b { return a }
      return [{ f: dbl }]
    }
    print(pick(false)[0].f(3))
    print(pick(true)[0].f(3))

Want:

    6
    4

#### Mechanism

The returned literal is built at the function's joined result (D15226), but the bound literal keeps its own row, as the ruling for a bound literal requires. A list of functions converts at the return through the tag the two sets share, so `[inc0]` bound beside `[inc0, dbl]` runs; a list of RECORDS has no converting copy: `emitRefListCopy` widens only into a union element (`rlWidenTagOf`), so the two lists' rows stay apart and `fnRetRefListSlot` reads -2. The close is an element-converting `listCopy` at the return delivery that rebuilds each record at the joined row.
