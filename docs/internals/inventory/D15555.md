### D15555 — a bound list of records holding a list of functions, returned beside a literal of another set, has no one list row once the return join widens the set

**closed 2026-11-08 — the filed repro prints `6` then `4` · was a loud emit reject, clause 2 (`emitProgram: the lists this function returns are built at different rows, so its inferred list result has none`), reached on the branch landing [D15510](D15510.md)'s return join; master printed `6 4` because nothing joined the two sets · the two lists were already built at ONE row and only their set fingerprints differed, so the row join accepts a value whose sets the joined set was widened from (`fnWidenedSourceSets`, which decides their ids together), and a record literal element built at a sibling row of the same layout is built at its list's element row (`arrRefElemTwinRow`, wasmEmit.vl) · fixtures `tests/cases/closures/returned-bound-list-of-records-beside-a-joined-literal-runs.vl`, `returned-bound-list-of-records-of-other-results-runs.vl`, `returned-value-if-of-a-bound-list-of-records-runs.vl` · found closing [D15510](D15510.md) · filed 2026-11-08 against master `2a9d12a1`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function pick(b) {
      const a = [{ fs: [inc0] }]
      if b { return a }
      return [{ fs: [dbl] }]
    }
    print(pick(false)[0].fs[0](3))
    print(pick(true)[0].fs[0](3))

Want:

    6
    4

#### Mechanism

The join notes `{inc0}` and `{dbl}` as widened into `{inc0, dbl}`; the returned literal is built at the joined result (D15226) and the bound literal at its own type. Both are list row 0, with `fs` an `i32` list of ids, so no element conversion is owed: `fnRetRefListRowJoin` refused on the set fingerprint (`{fs:s0[],}` against `{fs:s2[],}`), not on the row. With the literal returned FIRST, accepting the fingerprint exposed a second defect: the literal's record was minted at a row of the same layout as, but another heap than, the list's element (`$3` in a list of `$2`), which is invalid wasm.
