#### Mechanism

Not yet located. `recHeldCallPartCopy` copies such a binding's call into the list's build
(D15655), but only once a part built elsewhere sets that build, as in D16441. The refusal that
fires instead is `recStorageErr` (check_fit_rules.vl), whose storage field
(`shapeAdaptRecStorageField`) is unset on this path and whose two types render alike: the pair it
compares is not the pair it names.
