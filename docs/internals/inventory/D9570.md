### D9570 — a list-literal element record of an un-annotated function handed to an un-annotated parameter has no struct row for the parameter's instance

**loud emit reject · `vl check` rc 0 · `emitProgram: ref valtype with no interned shape` · clause 2 · found closing [D9530](D9530.md) · present on master `49a7d0b10` · filed 2026-10-22 against master `49a7d0b10`**

Repro:

    function inc0(a) { return a + 1 }
    function take2(a) {
      print(a.f(3))
    }
    const xs = [{ f: inc0 }]
    take2(xs[0])
    // vl check rc 0.  vl run: emit error: emitProgram: ref valtype with no interned shape

#### Mechanism

Not traced to the end. `take2`'s instance pins its parameter at `{f: (i32) => i32}`, and the
closure signature for it (`emitCloSigFunctype`) finds no interned struct row for that pin,
while the element itself is built at an anonymous row. On master, with a declared
`type R = { f: (a: i32) => f64 }` beside it, the program ran, because both the element and the
pin were laid out at `R`'s row; [D9530](D9530.md) refuses that row for this literal, so with
`R` declared this spelling moved runs → not-runs, prints `4` on master and refuses after.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the list (`take2({ f: inc0 })`) | runs, `4` | **yes** |
| the hole in `inc0` (`inc0(a: i32): i32`) | runs, `4` | **yes** |
| a declared `type R = { f: (a: i32) => f64 }` added (master only) | runs, `4` | masks it |

#### Grading list

The element bound first (`const e = { f: inc0 }`, `const xs = [e]`), which refuses
`cannot take the generic function inc0 as a value`, and the element read by a loop
(`for x in xs { take2(x) }`), which refuses `callee is not a function name`, both present on
master; and the witness with `R` declared, which ran on master.
