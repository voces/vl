Repro:

    function inc0(a) { return a + 1 }
    function take2(a) {
      print(a.f(3))
    }
    const xs = [{ f: inc0 }]
    take2(xs[0])
    // vl check rc 0.  vl run: emit error: emitProgram: ref valtype with no interned shape

#### Mechanism

`take2`'s instance pins its parameter at `{f: (i32) => i32}`. Interning that annotation's shape
found the element literal's `#anon` row with the same fields and returned it, but recorded no
alias from the annotation's arena type to the row, because the row is not aliasable until it is
marked. The closure signature (`emitCloSigFunctype` → `paramStructIdxOf` → `retStructRowIndex`)
then looked the parameter's type up by name and by arena type, found neither, and refused. The
close marks the arena type aliasable before recording it against the `#anon` row, as the
wider-row path below it already does. A declared `R` whose field returns another type is still
never chosen for the literal ([D9530](D9530.md)): the row is the literal's own.
