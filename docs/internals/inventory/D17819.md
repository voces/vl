Repro:

    function id(a) { return a }
    function dbl(a) { return a * 2 }
    function deliver() { return [{ f: id }] }
    const a = deliver()
    const b: { f: (a: f64) => f64 }[] = a
    b[0] = { f: dbl }
    print(a[0].f(2))
    // vl check: rc 0.  vl build: invalid module inside `dbl$1`

#### Mechanism

`b` and `a` are one list. The tag plan refuses the set because `b` holds closures, so the list
holds closures at the signature `a`'s call pins, (i32); a read through `b` calls one at (f64) and
traps, and the written `dbl` is built half at each. No write is needed (the ablation's first row).
