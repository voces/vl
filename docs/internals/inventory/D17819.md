### D17819 — a record written through an annotated list into a binding's set-typed list keeps the annotated rep, and the binding's call reads it at the set's

**open · check-clean invalid wasm · clause 1 · `vl check` rc 0, `the emitted module failed to validate inside dbl$1: type mismatch: expected f64, found i32` · filed 2026-11-28 against master `d76847374` (lane START-2)**

Repro:

    function id(a) { return a }
    function dbl(a) { return a * 2 }
    function deliver() { return [{ f: id }] }
    const a = deliver()
    const b: { f: (a: f64) => f64 }[] = a
    b[0] = { f: dbl }
    print(a[0].f(2))
    // vl check: rc 0.  vl build: invalid module inside `dbl$1`

Want:

    4

#### Mechanism

`b` and `a` are one list. The write through `b` stores `dbl` at `(f64) => f64`; the call through
`a` calls its element at the set's instance, so `dbl$1` is emitted at two reps. Not yet ablated.

#### Ablation

| spelling | outcome |
| --- | --- |
| this repro | invalid module |
| write through `a`, read through `b` | runs (`4`) |
| `const a = [{ f: id }]` in place of `deliver()` | loud check reject (`a` holds only a literal) |
