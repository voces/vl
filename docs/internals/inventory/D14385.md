### D14385 — a function returning a list literal of record rows, called once un-annotated and once into a record-list binding, builds invalid wasm

**closed 2026-11-12, runs and prints `true` then `false` · was a loud check reject, clause 2 (D14385's interim refusal), before that check-clean invalid wasm · closed by the fresh-call copy, not by the backlogged build at the destination: a delivery the copy converts leaves the body at its own type for the other use, so the refusal skips it ([D15724](D15724.md)), and the copy reaches every member shape, a record into a union of records ([D15726](D15726.md)), a list of numbers into a list of a union ([D15729](D15729.md)), and this witness's list of row unions, copied arm by arm by its box's tag (`recListElemRecCopies`, check_fit_rules.vl; `emitRowUnionElemCopy`, wasmEmit.vl) · graded by `scripts/capability-probes/matrix/kept-maker-list-result-delivery-row-union.matrix.vl` · fixture `tests/cases/soundness/inferred-result-kept-at-own-type-copied-runs.vl` (the former must-error pin) · filed 2026-10-26 against master `8d0974164`**

Repro:

    type Cir2 = { c2: i32 }
    type Sq2 = { s2: i32 }
    type Shape2 = Cir2 | Sq2
    type Circle = { r: Shape2 }
    function aliased() {
      const t = [{ r: { c2: 1 } }, { r: { s2: 5 } }]
      t
    }
    const h = aliased()
    print(h[1].r is Sq2)
    const h2: Circle[] = aliased()
    print(h2[0].r is Sq2)

Want:

    true
    false

#### Mechanism

`vl check` accepts the program. Its module fails to validate at the second call (11:7):
`array` is `({r:{c2:i32}}|{r:{s2:i32}})[]` where `Circle[]` is expected. The function body is
built once. The un-annotated call keeps the literal at its own row-union list, and the
annotated call gets that list where a `Circle[]` is wanted, without the element conversion a
record-list delivery needs. With only the annotated call, the program runs.

#### Ruling (2026-11-02): B, backlogged

Owner ruling (B) below: an un-annotated function's result that one use delivers into a wider
record (or a list of them) is built at the destination, and the function's other uses read it at
that storage. The constraint is the alias rule: the intermediate value must not be writable, between
the delivery and a use, in a way that breaks the wider or the narrower type. It is backlogged as
ROADMAP.md §"Backlogged: ruled, waiting to be built", an inferred result built at its destination, with this row and [D14890](D14890.md) as its witnesses. This row waits on it.
DECISIONS.md §"An inferred result one use delivers wider is built at the destination".

#### The question, as filed

The row is one witness of a family. On master `c444e026e`, an un-annotated function whose result
one call delivers into a wider record (or a list of them) and another use reads at the result's
own type is check-clean invalid wasm. The single-record spelling is enough:

    type Cir2 = { c2: i32 }
    type Sq2 = { s2: i32 }
    type Circle = { r: Cir2 | Sq2 }
    function mk() { return { r: { c2: 1 } } }
    const h = mk()
    print(h.r is Cir2)
    const h2: Circle = mk()
    print(h2.r is Sq2)

The second use can be a bare call (`print(aliased().length)`), a call with no read, either call
order, and a literal returned directly instead of through a local. Only the annotated call alone
runs. The checker accepts the annotated delivery as though the returned literal were built at the
destination (`recWidenWalk`'s call branch), and the other use keeps the body at its own type, so
nothing converts.

The neighbouring spellings disagree, so each answer matches one of them:

* **(A) Refuse, as the annotated return does.** `function aliased(): L[]` beside
  `const h2: Circle[] = aliased()` is refused: `L[] is not Circle[]: a container never widens
  implicitly`. The kept-versus-own refusal in `recKeptConflicts` ("kept at its own type at
  another") is the sentence for the un-annotated face. Programs like this row's witness stop
  compiling.
* **(B) Build it at the destination, as a binding is.** `const t = [{ r: { c2: 1 } }, { r: { s2:
  5 } }]`, read as `t[1].r is Sq2` and delivered as `const h2: Circle[] = t`, runs and prints
  `true` and `false`: the solve builds `t` at `Circle[]` and its own-type reads see that. For a
  function, the inferred result is pinned at the destination and the other call's binding is
  typed at it. This is the Want above. It moves a binding's checked type, so it is an inference
  change.

[D14891](D14891.md) took (A) because there the destination keeps two of a field's numbers as one,
so a build at it loses information. Here a build at `Circle` loses nothing, and (B) is open.

#### Interim refusal (2026-11-02)

Until the backlog item is built, the checker refuses the use kept at its own type, with the
kept-versus-own sentence: "this value is built as `<wider>` where line N delivers it, and it is
handed on here at its own type". That is a clause-2 refusal: the program is legal under the
ruling. It fires only where the destination stores some part in a union box the result does not
(a `Cir2 | Sq2` or `i32 | string` field, or a list of row unions into one record's list); a
`| null` widening is already served at every use and still runs. A program whose every use
delivers the result into the same wider type still runs too
(`tests/cases/soundness/inferred-result-delivered-wider-runs.vl`).

#### Narrowed (2026-11-12)

A delivery the fresh-call copy converts leaves the body built at its own type, so the refusal
skips it ([D15724](D15724.md)): a list result whose records box a field (`[{ f: 4 }]` at
`{ f: i32 | string }[]`) runs. A record into a record-union field (`{ r: { c2: 1 } }` at
`{ r: Cir2 | Sq2 }`) is copied at the member with its field names ([D15726](D15726.md)). A list of
numbers into a list of a union (`{ f: [4] }` at `{ f: (i32 | string)[] }`) is boxed element by
element ([D15729](D15729.md)). One member shape has no copy and stays refused: this row's witness
(a list of row unions into `Circle[]`). Two members sharing field names (`{ x: i32 } | { x: string }`)
are refused too: no one member to build at.

#### Closed (2026-11-12)

A list of row unions is copied element by element: each element's box tag picks the arm, and
that arm's record is copied at its own row into the destination record. Two members sharing
field names (`{ x: i32 } | { x: string }`) are still refused where a record is copied into the
union: the copy picks the member by field names and finds two, so it does not convert; that is
its own row, not this one's witness.
[D14890](D14890.md), the backlog item's other witness, is not a fresh-call copy and stays open.
