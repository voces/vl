### D16925 — a lambda's record or map result at a generic's `() => {v: T | boolean}` has no function-value signature

**loud emit reject · clause 2 · `emitProgram: a function value's signature is not yet supported — its result type has no representation in the function-value ABI` · `vl check` rc 0 · pre-existing on master `3f567259f` · found grading [D16918](D16918.md) · filed 2026-11-17 by lane AE4**

Repro:

    function gen<T>(f: () => {v: T | boolean}) { return [f].length }
    print(gen(() => ({v: 3})))

Want:

    1

#### Mechanism

Not traced. The lambda's anonymous record result holds a value union whose member is the type
parameter; the instance has no signature for it. A map result `() => {[string]: T | boolean}` with
`Map()` is refused the same way.
