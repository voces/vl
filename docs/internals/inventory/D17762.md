### D17762 — a returned fresh binding adopted at an `i64` field would stop its `i32` reads wrapping

**runs today and must keep running · a refutation pin: F2's adoption through an inferred result at an `i64` destination printed `2147483648` for the wrapped read · filed 2026-11-27 against master `1faa021d1` by lane CENSUS**

Repro:

    function big() {
      const r = { x: 2147483647 }
      return r
    }
    function takeInc(p: { x: i64 }): void { print(p.x + 1) }
    takeInc(big())
    const c = big()
    print(c.x + 1)

Want:

    2147483648
    -2147483648

#### Mechanism

The reader is `c.x`, a read of the call's result at `big`'s inferred type. Adopting `r` at
`{ x: i64 }` makes that result `i64`, so the `i32` arithmetic the program is typed at no longer
wraps (D14383, D14384). A container never widens implicitly, so an `i64` leaf is no adoption.
