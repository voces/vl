### D9522 — `??` over the call of an un-annotated parameter bound at a function returning `string` builds invalid wasm

**check-clean invalid wasm · clause 1 · the annotated parameter `f: () => string` runs, and `x ?? "q"` over an un-annotated parameter bound at `string` runs · found closing [D9491](D9491.md) · present on master `0be192a3f` · filed 2026-10-22 against master `0be192a3f`**

Repro:

    function take(f) {
      print(f() ?? "q")
    }
    take(() => "y")
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `take`: type mismatch: expected i32, found (ref $1); $1 is `string`

Want:

    y

#### Mechanism

Not traced. The `??` in the parameter's instance at `() => string` builds an `i32`-typed join
for a `string` operand. The `i32` instance (`take(() => 2)` with `?? 0`) runs, and the numeric
literal union instance refuses at emit instead ([D9521](D9521.md)).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the un-annotated parameter (`f: () => string`) | runs | **yes** |
| the call (`take("y")` with `x ?? "q"`) | runs | **yes** |
| the string (`take(() => 2)` with `?? 0`) | runs | **yes** |
