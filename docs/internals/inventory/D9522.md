Repro:

    function take(f) {
      print(f() ?? "q")
    }
    take(() => "y")
    // vl run: y

#### Mechanism

The rewrite folds `??` over a non-nullable operand on the template, which an un-annotated
parameter's instance shares. The emitter's `emitCoalesceGo` already folded the instance's dead
`??` from the instance types (`nodeTyIxOf`/`nodeTyPinIxOf`), but `exprString` and
`exprIsLitAtom` classified the `??` from the template and answered "not a string", so the
caller built an `i32` join around a `string`. The three readers now ask one predicate.
