### D16000 — a recursive union reached through its map alias declared first mints two `unNames` rows for one type

**runs today and must keep running · 2 programs of the sweep population · filed 2026-11-13 against master `32ab5241`**

Repro:

    type JO = { [string]: J }
    type J = null | f64 | JO
    const o: JO = Map()
    print(o.length)
    // vl run: 0. The emitter's union table holds two rows, both named
    // `f64|{[string]:J}|null`, whose types are `tyEq`.

#### Mechanism

Two producers each push a value-union row for `J`'s nullable composite, and the second does not
find the first by type, so the table holds two rows for one type (step 7: one row per type).
Both rows carry the same name, so `unRowBySid` reaches only one of them. No module difference
results: the emitted type section is identical to the swapped declaration order's.
