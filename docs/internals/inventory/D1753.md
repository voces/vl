Repro:

    const m: {[string]: i32} = Map()
    m["k"] = 5
    function take(a) {
      if a != null { print(a) } else { print(0) }
    }
    take(m.get("k"))
    // vl check: rc 0.  vl run: prints 5.

#### Mechanism

An un-annotated parameter is a hole the call pins from the argument, and the pin becomes the
instance's parameter annotation. `monoArgTyName`'s arms each name a NON-NULL rep, and a map
read is an i32-repped niche, so it fell past all of them to the `"i32"` catch-all. An
instrumented build printed the pin each argument gives:

| argument | pin |
| --- | --- |
| `m["k"]` | **`i32`** — the `\| null` dropped |
| `m.get("k")` | **`i32`** |
| `mk(true)`, an `i32 \| null` call | `i32\|null` |
| `loc`, an `i32 \| null` local | `i32\|null` |

The instance's parameter was therefore `i32`, and the body's `a != null` emitted a null the
position could not seed. That is exactly the hazard the catch-all's own comment names — "a
cascade answering `i32` for a rep it did not recognise mints a wrong instance silently, since
the pin becomes the instance's parameter annotation" — surfacing loudly rather than silently.

The rung is the arena, asked once for any value the checker recorded as nullable, placed above
the scalar cascade and routed through `monoAnnPinName` so the pin is a spelling an annotated
parameter already lowers.

**The bare-`null` design rule is untouched.** A literal `null` and a null-only inferred return
have the type `null`, not `T | null`, so this rung declines them and they still refuse — which
is what several templates' own headers state is the language's answer.

#### Ablation

| ingredient removed | outcome then | needed? |
| --- | --- | --- |

| the map read, for a nullable LOCAL | ran, printed `5` | **yes** |
| the `.get` spelling, for the INDEX form `m["k"]` | still refused | no |
| the `i32` value type, for a `string` map | still refused | no |
| the map read, for a `?.` projection | still refused | no |

**This table corrects the row as filed.** It said the axis was "a nullable READ versus a
nullable local or call", with `.get` and `?.` as the witnesses. The INDEX spelling `m["k"]` was
never run in that position and refuses identically, so the axis is not the syntax of the read —
it is any nullable value no pin arm names. Reading `.get` as the ingredient sent one candidate
down a routing rewrite that closed nothing; the index spelling refuting it in one run is what
found the catch-all.
