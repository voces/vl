Repro:

    function id<T>(x: T): T { x }
    function inc(x: i32): i32 { x + 1 }
    const ys = [id]
    ys.push(inc)
    function run(a: ((string) => string)[]) { print(a[1]("s")) }
    run(ys)
    // vl check: push: cannot add (i32) => i32 to ((string) => string)[] (written into `ys`, delivered at ((string) => string)[])

#### Mechanism

The push of `inc` is a deferred row against the list's element `(T) => T`, re-validated only
at a call that binds `id`'s `T`. Once the list is handed to a function, the element call
inside it binds no `T` of `id`'s, so the row was never adjudicated against `string`. The
close binds the list's type variables against the delivery's type and judges every write row
recorded against that binding there. A `let` the program rebinds is skipped, since a later
value may be what is delivered.

| `run` inlined as `print(ys[1]("s"))` | check refuses, `push: cannot add` | **yes** |
