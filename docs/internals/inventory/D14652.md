### D14652 — a choice of names built inside a function from its parameter refuses at a split parameter

**loud emit reject · `monomorphize: `g` is called at two instances of the function handed to it in a call to `lapBack`` · clause 2 · open · the same choice at the top level runs (D14439) · filed 2026-10-31 against master `bd1631f9`**

Repro:

    function wrap(a) { return [a] }
    function wrap2(a) { return [a, a, a] }
    function pair(a) { return [a, a] }
    function lapBack(g, h, x) {
      print(h(g(x)).length)
      print(g(h(x)).length)
      return 0
    }
    function go(c) { return lapBack(if c { wrap } else { wrap2 }, pair, 4) }
    go(true)
    go(false)

Want:

    2
    1
    2
    3

#### Mechanism

At the top level the checker asks the split plan (D6210) for a copy per instance of both `g` and
`h`. Inside `go`, whose `c` is a hole, the plan's round splits only `g`: the call to `lapBack` is
judged under `go`'s open binding, `h` is not asked, and the apply round refuses `g`'s argument as
an unsupported type.
