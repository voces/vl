### D15528 — a parenthesised generic function name held in a record literal field is not instanced

**closed 2026-11-06 — the filed repro prints `3` · was check-clean invalid wasm, clause 1 · found by lane cad (the `monoFlow*` rewrite's B1 chain gate) · the record-field face of [D4120](D4120.md), closed by the same change: a parenthesised bare name is read as the name before the check (`parenNamesCollapse`) · a position matrix over `{ f: (id) }` grades 5 cells SILENT before and runs 46 of 46 graded cells after · fixture `tests/cases/closures/paren-function-name-as-value.vl` · filed and closed 2026-11-06 against master `05e80d97c`**

Repro:

    function id<T>(x: T) { x }
    const o = { f: (id) }
    print(o.f(3))
    // vl check: rc 0.  vl run: the emitted module fails to parse

Want:

    3

#### Mechanism

The emitter instances a generic function taken as a value where its name node stands: `{ f: id }`
runs. The parenthesis put a `Paren` node there, so no pass that renames a function value to its
instance saw the name, and the field kept the template.
