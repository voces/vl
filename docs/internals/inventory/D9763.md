### D9763 — a returned local list of an un-annotated function, bound from a call with an argument and read at two types, is refused at the call

**loud emit reject · `vl check` rc 0 · `a function value's signature is not known at this call — the type it was given takes fewer parameters than the call passes` · clause 2 · found closing [D9711](D9711.md) · present on master `e8163edd5` · filed 2026-10-22 against master `60aaa08c0`**

Repro:

    function inc(a) { return a + 1 }
    function deliver(_n) {
      const u = [inc]
      return u
    }
    const w = deliver("s")
    print(w[0](3))
    print(w[0](2.5))
    // vl check rc 0.  vl run: emit error: emitProgram: a function value's signature is not known at this call

Want:

    4
    3.5

#### Mechanism

Not traced. The inline return (`return [inc]`) runs at both types, and the local read at one type
runs, so the local's binding pins its element at one function type and the second read finds a
signature it cannot call. Without the parameter of `deliver` the program refuses earlier, at `inc`
taken as a value. The nested twin (`[[inc]]`, `w[0][0]`) refuses with `ref valtype with no
interned shape`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the second read (`w[0](2.5)`) | runs, `4` | **yes** |
| the local (`return [inc]`) | runs, `4` `3.5` | **yes** |
| the parameter of `deliver` | refuses, `cannot take the generic function `inc` as a value` | no |

#### Grading list

The nested twin.
