Repro:

    function inc(a) { return a + 1 }
    function deliver(_n) {
      const u = [inc]
      return u
    }
    const w = deliver("s")
    print(w[0](3))
    print(w[0](2.5))
    // vl check rc 0.  vl run: emit error: emitProgram: a function value's signature is not known at this call

Want:

#### Mechanism

The flow-read rewrite (`monoFlowRetVals`, emit_mono.vl) took a function's returned values only
from literal `return` operands, so `return u` left the reads of `deliver(...)` unplanned and the
local's one pin decided the element: the second read found a signature it could not call. Without
the parameter of `deliver` it refused earlier, at `inc` taken as a value; that spelling runs too.
