### D16240 — a `const` alias of an un-annotated function, written into a binding widened to two and read again, is refused at emit

**open · loud emit reject · `emitProgram: cannot take the generic function id2 as a value — a function value carries ONE signature` · clause 2 · read only where it is written it runs since D15308's close · found closing D15308 · filed 2026-11-14 against master `a5624eb2` with lane L's G1 change**

Repro:

    function id1(a) { return a + 1 }
    function id2(a) { return a + 100 }
    const q = id2
    let r = id1
    r = q
    print(r(2))
    print(r(2.5))
    print(q(3))

Want:

    102
    102.5
    103

#### Mechanism

Not yet ablated past its ingredients. D15308's close re-types a written source binding to the
holder's set only where the write is its one read (`cwSoleReadInit`); a second read, a call of
`q`, keeps the binding at its own value, so `id2` is taken as a value at `q`'s initialiser. A
record source read twice (`const q = { f: id2 }`, `q.f(3)` after `r = q`) runs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the read `q(3)` | runs | **yes** |
| `const q = id2` → `const q = { f: id2 }`, reads through `.f` | runs | **yes** (the bare value) |
