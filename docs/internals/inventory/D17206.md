### D17206 — in a loop, an inferred-null binding written with an object literal keeps the read at the loop's top narrowed to `null`

**closed 2026-11-24 · runs, prints `nv` `vv` · was check-clean silently wrong (clause 1), printed `vv` `vv` at an `In | Out | null` destination, and invalid wasm un-annotated · `crLoopLeavingWrite` (check_narrow_flow.vl) now takes a write of a value the loop must type (an object literal) to a binding typed `null` as leaving its `null` narrowing, as it takes a write of a named value, so the read at the loop's top is the binding's open hole; un-annotated, the join over it is then re-asked at the fill ([D17203](D17203.md)) and refused, "annotate the binding" · fixtures `tests/cases/types/null-hole-fill-after-join-runs.vl` (`inLoops`), `tests/cases/types/null-hole-fill-in-loop-refused.vl` · found by IR-N4 while verifying its own D17203 fix, which had turned the un-annotated spelling from invalid wasm into a wrong value · owner IR-N4 · filed 2026-11-24 against master `09e329d2b`**

Repro:

    type In = { v: i32 }
    type Out = { w: string, k: i32 }
    const rec: In = { v: 9 }
    function run(f: boolean) {
      let m = null
      let out = ""
      let i = 0
      while i < 2 {
        const j: In | Out | null = if f { m } else { rec }
        out = out + (if j == null { "n" } else { "v" })
        m = { w: "z", k: 4 }
        i = i + 1
      }
      return out
    }
    print(run(true))
    print(run(false))
    // vl run: nv, vv

Want:

    nv
    vv

#### Mechanism

`let m = null` types the binding `null`. At a loop, `crLoopPreRetire` ends a narrowing that a
write in the loop leaves (`crLoopLeavingWrite`): the write's value is peeked before the loop runs
(`loopWritePeekTy`). A named `Out` value is peeked as `Out`, does not land within `null`, and
retires the narrowing. An object literal peeks as -1, "left to the write itself", but a write to
the inferred-null binding is never refused (it fills the hole), so the read at the loop's top
stayed `null` on every pass, though the second pass reads the record the first wrote.
