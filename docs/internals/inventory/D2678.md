### D2678 — a union a generic pin mints inside a list annotation (`(V | M)[]`) was never registered, so the list's element box had no row

**closed 2026-09-26 by the W2 lane PR — the filed repro RUNS and prints `true` · was check-clean
invalid wasm, clause 1 · found grading D2676's positions · identical on master `525837973` ·
filed 2026-09-26 by the W2 lane**

Repro:

    type SM = {[string]: i32}
    function g<V>(x: SM) {
      const a: (V | SM)[] = [x]
      a[0] is SM
    }
    const sm: SM = Map()
    print(g<string>(sm))
    // vl run on master: invalid module inside `g`, "expected struct type at index 0,
    // found (array (mut i32))"

#### Mechanism

`monoPinMintedUnion` registered the union a pin mints only at the top of an annotation: it
flattened the annotation's own members, and `(V | SM)[]` is a list, so the element union
`string | SM` was never registered and the literal was built at the wrong element rep. The gate
now looks through a list to its element, and the element union registers under its canon
spelling, as a direct `(string | SM)[]` does.

#### Ablation

| the map member (`(V \| string)[]` at `V := Q`, a record) | same invalid wasm | no |
| the pin (the direct spelling `(string \| SM)[]`) | prints `true` | **yes** |
