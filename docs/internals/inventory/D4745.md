### D4745 — an `i32[] | K[]` parameter or return refuses at emit: the box coercion finds no recorded members for the union

**loud emit reject · inline `i32[] | K[]` (a numeric literal union `K`) at an annotated parameter or return · clause 2 · the annotated `argument`, `return_annotated` and `early_return_guard` cells of a capability matrix over `i32[] | K[]`, and `return_annotated`'s un-annotated cell · filed 2026-10-14 against master `3a8eb2b61`**

Repro:

    type K = 0 | 1
    function f(a: i32[] | K[]) {
      if a is i32[] { print(a.length) }
    }
    f([1, 0, 1])
    // vl check: rc 0.  vl run: emitProgram: union box atom test on a union with no recorded members: i32[]

Want:

    3

#### Mechanism

The signature's slot is decided as a union box from the member set, then the argument's
coercion (`emitUnionBoxArgGo` → `emitUnionCoerce` → `unionHasAtomTy`) looks the union up by its
render, `i32[]`, which names a list with no recorded members, so it refuses. The return
position reaches the same coercion. The slot and the lookup read two producers for one type.

#### Grading list

`a.length` on the un-narrowed `i32[] | K[]` is refused by the checker with `field 'length' is
not on every member of i32[] | K[] … (i32[] is a list, not a record)`, though every member is
the same list: a clause-2 refusal of the same collapse. Re-grade it with this row.
