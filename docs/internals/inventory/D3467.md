### D3467 — a method call on a nullable-map list cell refuses at emit, reading it as a call of a value

**loud emit reject · clause 2 · open · pre-existing, the same on master `47aa2950b` · found by lane NW2's `nw2g` grid (`map_cell_*`, every spelling) · filed 2026-09-30 against master `47aa2950b`**

Repro:

    const a: ({[string]: i32} | null)[] = [Map()]
    if a[0] != null { print(a[0].has("k")) }
    // vl check: rc 0.  vl run: emitProgram: callee is not a function name

Want:

    false

#### Mechanism

Not localised past the ablation. A built-in map method whose receiver is a list cell holding
`{[string]: i32} | null` is not dispatched as a map method, so the emitter reads `a[0].has` as a
field holding a function. A non-null map element, or the cell bound to a local first, takes the
map-method path.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const a: {[string]: i32}[]`, no `null` | prints `false` | **yes** |
| `const e = a[0]` then `if e != null { print(e.has("k")) }` | prints `false` | **yes** (the cell receiver) |
| `a[0] = m` (a write) in place of the guard | the same refusal | no |
| `a[0]?.has("k") ?? false` | the same refusal | no |
