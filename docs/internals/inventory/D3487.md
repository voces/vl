### D3487 — a generic `if` chain returning `A`, `B` or `null` traps with a cast failure on the `null` arm at a pin with a string arm

**loads then traps · clause 1 · open · found while grading D3485 · D3116 is the hole-spelling sibling (since fixed) · filed against master `e5ff25ff9` · 2026-10-03**

Repro:

    function two<A, B>(k: i32, a: A, b: B) { if k == 0 { a } else if k == 1 { b } else { null } }
    print(two(0, 1, "s"))
    print(two(1, 1, "s"))
    print(two(2, 1, "s"))
    // vl check: rc 0.  prints `1`, `s`, then `wasm trap: cast failure` at the third call

Want:

    1
    s
    null

#### Mechanism

At a pin where one arm is a `string` the join is a value box and the `null` arm is delivered into
it at the wrong shape; the third `print` casts the result to the type it was narrowed to and the
cast fails. Not read from the emitter, inferred from the ablation: the failure needs the null arm
AND a non-numeric arm AND two type parameters, and fires at the instance for every such pin.
