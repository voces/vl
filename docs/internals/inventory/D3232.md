### D3232 — calling a function field of an `is` remainder in a hole body is invalid wasm

**check-clean invalid wasm · clause 1 · open · pre-existing, the same on master `94670f728` · found by the #3289 round-2 review (`rv3289r2-k7m2/w/d1.vl`) · filed 2026-09-29 against master `94670f728`**

Repro:

    type A = { v: i32 }
    type B = { g: () => i32 }
    function F(z) {
      if z.h is A { print(z.h.v) } else { print(z.h.g()) }
    }
    const x: { h: A | B } = { h: { g: () => 11 } }
    F(x)
    // vl run: invalid module, inside `F`: unknown local 2: local index out of bounds

#### Mechanism

Not localised. The call `z.h.g()` reads a field closure through the else arm's remainder; the
emitter indexes a local the instance never declared. The annotated spelling prints `11`. The
review saw some spellings refused at emit instead.

#### Ablation

| ingredient changed | outcome on master | needed? |
| --- | --- | --- |
| `function F(z: { h: A \| B })` | prints `11` | **yes** (a hole) |
| `function F<Z>(z: Z)` | the same invalid wasm | no |

#### Grading list

The witness, and its `<Z>` and lambda spellings.
