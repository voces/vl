### D3232 — calling a function field of an `is` remainder in a hole body is invalid wasm

**closed · runs, prints `11` · was check-clean invalid wasm, clause 1 · pre-existing on master `94670f728` · found by the #3289 round-2 review (`rv3289r2-k7m2/w/d1.vl`) · filed 2026-09-29 against master `94670f728` · closed by minting the call-ref scratch slot where the call lowers (`callRefNestSlot`, emit_union_casts.vl) instead of predicting it with a body scan that missed a field closure read through an `is` remainder · fixture `closures/is-remainder-field-closure-call-in-hole-body.vl`**

Repro:

    type A = { v: i32 }
    type B = { g: () => i32 }
    function F(z) {
      if z.h is A { print(z.h.v) } else { print(z.h.g()) }
    }
    const x: { h: A | B } = { h: { g: () => 11 } }
    F(x)
    // vl run (before the fix): invalid module, inside `F`: unknown local 2: local index out of bounds

Want:

    11

#### Mechanism

The call `z.h.g()` reads a field closure through the else arm's remainder; the
emitter indexes a local the instance never declared. The annotated spelling prints `11`. The
review saw some spellings refused at emit instead. The frame reserved its call-ref slot only
when a body scan predicted a call-ref, and that scan missed this one; the slot is now minted
where the call lowers.
