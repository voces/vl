### D4779 — `is S[]` over a box union of `string[]` and `S[]` answers by the arm a value was built as

**check-clean silently wrong value · clause 1 · found closing D4771 · the same answer on master before D4771's close · related to D3885 (`is` is structural) · filed 2026-10-14 against master `bd9e38039`**

Repro:

    type S = "a" | "b"
    function f(x: string[] | S[]) {
      if x is S[] { print(1) } else { print(0) }
    }
    const v: string[] = ["a"]
    f(v)
    // vl check: rc 0.  vl run: prints 0

Want:

    1

#### Mechanism

`string[]` and `S[]` are two reps (strings and atoms), so the union is a box and `is S[]`
tests its tag. D4771's ruling makes `is` over a list test every element; a `string[]` whose
elements all fit `S` fits `S[]`, so the `string[]` arm needs the element-wise test too.

| --- | --- | --- |

| `x: string[]` | prints `1` (D4771's element test) | **yes** (a box union) |
