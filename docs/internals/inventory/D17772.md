### D17772 — an annotated callback mapped over a list of a hole function pins the parameter of a later, unrelated hole callback, so the checker's typing depends on statement order

**loud check reject · clause 2 · "called value is not a function (i32)" at `r[0](5)` · a neighbour of D17768 · filed 2026-11-27 against master `dd93db33` by COV-CALL**

Repro:

    function ap(r: (a: i32) => i32) { return r(5) }
    function inc7(a) { return a + 1 }
    print([inc7].map(ap)[0])
    function inc6(a) { return a + 1 }
    const nested = [[inc6]]
    function apN(r) { return r[0](5) }
    print(nested.map(apN)[0])
    // vl check: called value is not a function (i32)

Want:

    6
    6

With the halves swapped it runs and prints the same; a close runs both orders.

#### Mechanism

Not traced. The first `.map` leaves a pin `apN`'s hole parameter reads: with the list of lists
replaced by `[[(a: i32) => a + 1]]` the reject becomes "cannot index non-array (i32) => i32",
the first list's element type, so the parameter takes a type from a call it is not part of.
