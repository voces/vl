### D3029 — `is` against a record shape whose field is an inline string-literal set finds no arm

**loud emit reject · clause 2 · identical on master `cac5e4ad5` · found grading the D3024 union-context grid · filed 2026-09-28**

Repro:

    type A = { x: "a" | "b" } | { y: i32 }
    const u: A = { x: "b" }
    if u is { x: "a" | "b" } { print(u.x) }
    // vl check: rc 0.  vl run: emitProgram: `is` names a declared union member with no interned arm representation (deferred value-union composition)

Want:

    b

#### Mechanism

Not yet located. The checker accepts the test, since the shape is the arm `{ x: "a" | "b" }`. The
emitter looks the tested shape up as a union member and finds no arm row for it. The same test
spelled through an alias (`type L = "a" | "b"`, `is { x: L }`) runs, and so does the other arm's
test (`is { y: i32 }`) with the literal-set arm read in its `else`, so the inline literal set in
the tested shape is what fails to resolve to the arm the declaration registered.
