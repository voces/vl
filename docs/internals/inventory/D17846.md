### D17846 — a function returning a `let x = null` a hole parameter fills is printed at no rep the caller reads

**closed 2026-11-28 · runs, prints `1` · was `emitProgram: the compiler cannot yet lower this statement (print operand rep)` · `elabTyWidensTo` (emit_elab.vl) counts `null` as a member of a nullable, so the caller's print reads the instance's `i32 | null` result · pin `closures/hole-param-into-a-null-let-returned-to-a-print` · filed 2026-11-28 against master `57ced208a` by COV-UNION (D17844's result face, coordinator ruling)**

Repro:

    function f(a) {
      let t = null
      t = a
      return t
    }
    print(f(1))
    // vl run: prints 1

Want:

    1

#### Mechanism

Not traced past the caller. Once the instance re-check's null-hole fill no longer moves the
emit seal (D17844), the build reaches the caller's `print(f(1))`. The instance returns its
own `i32 | null`, but the print's arm is not chosen at that rep: the instance's result rep is
not what the caller reads.
