    function f(a) {

#### Mechanism

Not traced past the caller. Once the instance re-check's null-hole fill no longer moves the
emit seal (D17844), the build reaches the caller's `print(f(1))`. The instance returns its
own `i32 | null`, but the print's arm is not chosen at that rep: the instance's result rep is
not what the caller reads.
