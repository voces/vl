#### Mechanism

D9331's rung answers a plain record parameter, D9420's a nullable one and D9422's a list of a
record-and-scalar union. A list of the record is none of them, so `sigParamTokOfTy` renders
the parameter with `tyToEmitName`, `7·2^depth` characters, and `annParamKindTy` classifies that
spelling. A depth-16 `--names` profile of `g([])` puts the cost under `sigKeyOfTyGo` →
`annParamKindTy`, in `scalarListRepOfName` → `arrElemIs`, `nameIsRefArray` →
`refArrShapeKind` and `refArrElemName` → `structIndexOfTypeName`, each scanning the render
with `tyTopIndexOf`. The nullable list adds `isUName` → `canonUnionKeyOfName`, and a list
literal's walk (`collectAArrayLit` → `arrLitElemKind`, `arrLitElemHintTy`,
`arrLitUnionElemName`) spells it again. Under the null collector the spelling outgrows the
64 MiB object cap at depth 22, which `tests/vl_compile_gc_test.ts` uses as its trap witness.
