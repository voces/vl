### D2213 — a module-scope literal-union atom narrowed to one literal cannot be interpolated

**loud emit reject · `emitProgram: literal-union string widening with no members` · found closing D2205 · filed 2026-09-23 against master `327b15510`**

Repro:

    type M = "x" | "y" | "w"
    let g: M = "y"
    if g is "y" { print("g \{g}") }

#### Mechanism

An interpolation hole renders its value through a call, and an atom argument is widened to its
string by `emitAtomToStr`, whose member ladder (`litAtomWidenTexts`) finds no member texts for
this read. The same read inside a function runs, as do `print(g)` and `"a " + g` at module
scope, and a narrowing to two literals interpolates. D2205's close lets the overlapping
spelling (`g is "y" | "q"`) reach it too, since that narrows to the one literal both sets hold.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| module scope (the same test in a function, over a parameter) | runs | **yes** |
| the narrowing to one literal (`g is "y" \| "w"`) | runs | **yes** |
| interpolation (`print(g)`, `print("a " + g)`) | runs | **yes** |
| `let` (`const g: M = "y"` instead) | refuses | no |
