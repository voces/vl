#### Mechanism

The deep `is` rewrite ([D1190](D1190.md), `jwSubstAtWrite`) cuts its substitution at a statement
that writes the tested place: an assignment statement, a `let` of the root, or (since
[D16274](D16274.md)) a call the checker ended the narrowing at. An assignment nested inside
another expression is none of these, so the rewrite has no cut that keeps the reads before the
write on the converted copy and the reads after it on the place, and it refuses.

The close cuts the statement at the first nested write as it cuts at a retiring call: the reads
that end at or before the write's right-hand side, and a closure made before it, read the copy;
the write's target and everything after read the place. A write in an `if` test cuts the test
the same way and leaves both arms to the place. A `const` or `let` of the root's name in a block
nested in an expression is a different ingredient, the substitution's scoping, filed as
[D16475](D16475.md).
