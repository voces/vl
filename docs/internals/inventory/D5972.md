### D5972 — an annotated local function binding gives its type to a module binding of the same name called through a hole

**loud check reject · clause 2 · found closing [D5660](D5660.md) · filed 2026-10-17 against master `7497c0982`**

Repro:

    function fw(f) { return f }
    function id(x) { return x }
    function g() {
      const h: (x: i32) => i32 = id
      print(h(3))
    }
    g()
    const h = fw(id)
    print(h("w"))
    // vl check: rc 1, cannot assign (string) => string to 'h' of type (i32) => i32 (the body of `h` at the call's argument types)

Want:

    3
    w

#### Mechanism

From the ablation only. The two `h` bindings are in different scopes, and the refusal names
the local's annotation at the module binding's call. The check of a call through a binding
whose value came through a hole appears to find the binding by NAME, not by declaration.
