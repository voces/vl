### D5160 — a `let` initialised with a copy of a written binding that holds a union-parameter generic is refused at the copy's call

**loud check reject · clause 2 · found closing D4892 · filed 2026-10-16 against master `83752e744`**

Repro:

    function s<A, B>(a: A, b: B) { print("S") }
    function w<B>(a: i32 | string, b: B) { print("W"); print(a); print(b) }
    function main() {
      let k = s
      k = w
      let k2 = k
      k2(6, false)
    }
    main()
    // vl check: cannot assign (i32 | string, boolean) => void to (i32, boolean) => void (the body of `k2` at the call's argument types)

Want:

    W
    6
    false

#### Mechanism

D4892's close adapts each WRITE of a marked binding at the call types its binding is called at.
`k2`'s call re-asks `k2`'s own write constraints, and those reach `w`'s fixed `i32 | string`
through `k`, but the adapter only rewrites the binding's own write nodes (`fsbOwnRhs`). `k2`'s
initializer is the identifier `k`, not `w`, so nothing is adapted and the recheck refuses. The
direct call `k(6, false)` runs. The written-copy spelling of the same gap traps instead: D5161.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `k(6, false)` instead of a copy | runs, `W 6 false` | **yes** |
| `w`'s first parameter `i32` | runs, `W 6 false` | **yes** |
| `let k2 = s; k2 = k` (a write instead of the initializer) | loads then traps (D5161) | no (changes the outcome) |
