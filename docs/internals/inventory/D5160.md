### D5160 — a `let` initialised with a copy of a written binding that holds a union-parameter generic is refused at the copy's call

**closed 2026-10-17 — the witness prints `W 6 false` · was loud check reject, clause 2 · a copy of a written binding records its source, so a call through the copy re-asks and adapts the source's writes · the `written-fn-binding-copy-fixed-union` matrix 0 → 57 of 64 runs · found closing D4892 · filed 2026-10-16 against master `83752e744` · pins: `tests/cases/closures/written-let-of-generics-copied-into-another-let.vl`, `scripts/capability-probes/matrix/written-fn-binding-copy-fixed-union.matrix.vl`**

Repro:

    function s<A, B>(a: A, b: B) { print("S") }
    function w<B>(a: i32 | string, b: B) { print("W"); print(a); print(b) }
    function main() {
      let k = s
      k = w
      let k2 = k
      k2(6, false)
    }
    main()
    // vl check: cannot assign (i32 | string, boolean) => void to (i32, boolean) => void (the body of `k2` at the call's argument types)

Want:

    W
    6
    false

#### Mechanism

D4892's close adapts each WRITE of a marked binding at the call types its binding is called at.
`k2`'s call re-asks `k2`'s own write constraints, and those reach `w`'s fixed `i32 | string`
through `k`, but the adapter only rewrites the binding's own write nodes (`fsbOwnRhs`). `k2`'s
initializer is the identifier `k`, not `w`, so nothing is adapted and the recheck refuses. The
direct call `k(6, false)` runs. The written-copy spelling of the same gap traps instead: D5161.

#### Closed by L1 (2026-10-17)

`fsbNoteCopy` records that a binding's initializer or write is another marked binding, and
`fsbRecheckFrom` re-asks a source's owner rows at every call whose binding reaches it through
copies (`fsbOwnerReaches`), so `k2(6, false)` adapts `k = w`. `lookupFnAliasNode` follows an
alias of an alias, so the copy's recheck sees `w`. Each piece removed alone:

| piece removed | D5160 | D5161 |
| --- | --- | --- |
| alias-of-alias rung | check reject | runs |
| `fsbNoteCopy` at a write | runs | loads then traps |
| `fsbNoteCopy` at an initializer | loads then traps | runs |
