### D3234 — an else-if `is` chain over a bare hole parameter demands a shape the union does not have

**loud check reject · clause 2 · open · pre-existing, the same on master `94670f728` · found by the #3289 round-2 review (`rv3289r2-k7m2/w/n3.vl`) · filed 2026-09-29 against master `94670f728`**

Repro:

    type A = { v: i32 }
    type B = { s: string }
    type C = { t: string }
    function F(h) {
      if h is A { print(h.v) } else if h is B { print(h.s) } else { print(h.t) }
    }
    const x: A | B | C = { t: "tee" }
    F(x)
    // vl check: argument 1: expected A | B | {t: _}, got A | B | C

#### Mechanism

A parameter hole's remainder is not minted for a record tested type (`holeElseRemainderOk`), so
the final arm's `h.t` grows the parameter's demanded shape, and the argument check demands
`A | B | {t: _}`. The annotated spelling `function F(h: A | B | C)` prints `tee`, and the same
chain over a hole's FIELD runs.
