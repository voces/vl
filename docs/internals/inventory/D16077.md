### D16077 — a generic function returned by a maker that a hole parameter calls has no instance: the call through the parameter names an unknown function

**closed 2026-11-14 · runs, prints `6` · was a loud emit reject, `emitProgram: call to unknown function` · closed with [D16133](D16133.md) · found by lane I grading D16073's `vrFnValue` · filed 2026-11-14 against master `8f6978b8`**

Repro:

    function inc(x) { x + 1 }
    function run(f) { print(f()(5)) }
    run(() => inc)
    // vl check: rc 0.  vl run: emitProgram: call to unknown function (2:10)

Want:

    6

#### Mechanism

`run`'s hole parameter `f` is called, and its result is called with an `i32`, which pins `inc`
at `(x: i32) => i32`. The close is the prototype's two parts on master: `elabValueCalls`
follows the argument into the callee's calls of that parameter (`elabParamNameCalls`), and
`elabLamHoleTysClose` closes the hole-result lambda's type at its returned generic's delivery in
the instance key. With a second callee, the set path's id contradicted the closure; that is
[D16133](D16133.md), closed in the same change.
