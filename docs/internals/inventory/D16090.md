### D16090 — a re-pointed `let` of un-annotated lambdas whose results differ is refused at the call, where declared functions dispatch

**loud check reject · clause 2 · `cannot assign (i32) => string to (i32) => i32 (the body of \`f\` at the call's argument types)` · the lambda twin of [D16064](D16064.md) · filed 2026-11-14 against master `b53278055`**

Repro:

    function run(c: boolean) {
      let f = (a) => a + 1
      if c { f = (_a) => "s" }
      print(f(3))
    }
    run(true)
    // vl check: rc 1, the refusal above

Want:

    s

#### Mechanism

The binding's type is the first lambda's function type, and a write of a lambda whose body gives
another result at the call's argument types is refused as an assignment of its function type.
D16064's dispatch covers named un-annotated functions only (`holeLetJudge` declines a member that
is not a declaration, and the lambda's write is checked against the binding's type first).
