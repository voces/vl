### D5664 — a generic through an identity call into a binding called at two types, beside a second such binding, has no interned signature

**loud emit reject · `vl check` rc 0 · clause 2 · found closing [D5531](D5531.md) · filed 2026-10-17 against master `a9ede7d84`**

Repro:

    function k<T>(x: T): T { return x }
    function fw(f) { return f }
    const a = fw(k)
    print(a(1))
    print(a("z"))
    const b = fw(k)
    print(b(true))
    // vl check: rc 0.  vl run: emitProgram: a function-value call has no interned signature — parameter 1 of type `` has no representation in the function-value ABI

Want:

    1
    z
    true

#### Mechanism

From the ablation only. Without `b` this is D5531's grading line and runs: `a` takes a slot
per type, the second one holding `k`. With `b` beside it, the first build fails at `fw`'s
parameter with a refusal that asks for no slot, so the split never runs. Written by hand with
the slot, `const a2 = k` for the `"z"` call, it runs.
