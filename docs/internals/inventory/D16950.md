### D16950 — a readonly list of lists over a source whose inner lists may be written elsewhere has no lowering: a copy would miss the write, and no nested view is built

**loud check reject · clause 2 · the design permits the program; the refusal names the mechanism, not a contract · split from [D2196](D2196.md)'s nested face, which runs since 2026-11-17 only where the source is a `const` list literal of fresh lists read nowhere else · filed 2026-11-17 by lane F2**

Repro:

    const x: i32[] = [1, 2]
    const a: i32[][] = [x]
    const v: readonly (readonly f64[])[] = a
    x.push(3)
    print(v[0].length)
    // vl check: rc 1, "… the inner lists may be written through another binding, which a copy
    //   would not see; a nested view is not built yet (D16950)"

Want:

    3

#### Mechanism

A flat `i32[]` delivered as a `readonly f64[]` is copied where nothing writes the source, and is
otherwise a view that reads through it (D3028), so a later write shows. A list of lists has the
copy (`emitListConvTop`, wired at the delivery by D2196's close) but no view: an outer readonly
list whose inner elements are views over the source's inner lists. A copy is sound only where no
inner list can be written after the delivery, which the checker proves for a `const` list literal
of fresh lists (literals, or calls of a function returning only list literals) that nothing reads
but the delivery (`nestedCopyFresh`, check_fit_rules.vl). Every other source is refused.

#### Ablation

| source | outcome | needed? |
| --- | --- | --- |
| the witness: an inner list held by another binding, written after | refused | — |
| `const a = [[1, 2]]`, read only at the delivery | runs | **yes** (the alias) |
| an inner list read out (`const y = a[0]`) and written | refused | no |
| the root written (`a[0].push(3)`) | refused | no |
| a parameter root | refused | no |
| the flat `i32[]` into `readonly f64[]`, written after | runs, through a view | **yes** (the nesting) |

#### Grading list

`readonly-copy-nested.matrix.vl`'s refusing cells: `aliased_inner`, `inner_read_out`,
`written_root`, `param_root`, and the built-in positions that re-bind the root before delivering it.
