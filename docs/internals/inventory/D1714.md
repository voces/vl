### D1714 — the nullable-REF `??` arm takes its block type from the operand's own heap type, so a struct default over an `as?`-produced niche has nowhere to land

**check-clean invalid wasm · filed 2026-09-06 against master `1f7406139`, mechanism corrected
2026-09-06 by disassembly · D1709's close moves the `??`, if-expression and call operand forms
and leaves this one · 0 corpus cells**

Repro:

    type A = { r: i32 }
    function mkU(): i32 | string { return 4 }
    function st(): A { return { r: 8 } }
    const u = mkU()
    const w = (u as? string) ?? st()
    if w is A { print(w.r) } else { print(w) }
    // vl check: rc 0.  vl run: exit 70,
    // the emitted module failed to validate:
    // type mismatch: expected (ref $type), found (ref $type)

#### Mechanism

**Three rows, read off the disassembly and the checker.** The operand `u as? string` is
`string | null`, which is the nulstr NICHE — a `(ref null $str)` — and NOT a box. The default
`st()` is a plain `A`, `(ref $A)`. The type the checker records for the `??` is `string | A`, a
union, so its rep is the value box `(ref $uBox)`. Three different heap types, and the emitted
block declares the first of them.

**So the failing arm is the nullable-REF one, not the stashed box one.** `emitCoalesceGo`
reaches `emitCoalesceNulRefCtx` through `exprNullableString`, and that core hardcodes the block
type as `(ref $heapIx)` — the operand's own — because `br_on_non_null` branches with the raw ref
it just tested. The struct default is then emitted into a string-typed block. Nothing about the
value-union box arm, and nothing about D1709's mint, is involved: the `as?` operand with a
SCALAR default runs (`(u as? i32) ?? "x"` prints `4`), and so does the same niche with a fitting
default (`(u as? string) ?? "x"`).

**A close is the D1699 decision at a third arm** — the result rep is the checker's recorded
type, so a union result must be a box — and the shape it needs is not this core's:
`br_on_non_null` cannot box on the branch it takes, so the boxed form wants a null test and an
`if` whose non-null path re-reads and boxes, which is a value the arm does not currently have a
way to produce from an already-emitted operand.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `as?` operand (a call operand instead) | runs, prints `8` | **yes** |
| the struct default (`(u as? string) ?? "x"`) | runs | **yes** |
| the ref niche (`(u as? i32) ?? "x"`, a scalar operand) | runs, prints `4` | **yes** |
| the inference (`const w: M = …` with `type M = i32 \| A`) | refuses identically | no |
| the null value (`mkU` returning a string) | refuses identically | no |

#### Grading list

The five ablation rows at both faces, and the three operand forms D1709 closed as controls that
must keep running — a call, an if-expression operand and a plain `??`, each with a struct
default. `tests/cases/unions/coalesce-result-rep.vl` carries all three. The OTHER niches this
core serves are the ones a close must re-grade with it, since the block type is hardcoded for
all of them alike: a nullable collection (`i32[] | null`, `string[] | null`, …) and a nullable
struct, each with a default that joins rather than fits.
