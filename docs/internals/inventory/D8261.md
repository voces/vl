#### Mechanism

Not localised past the ablation. The checker narrows the place `xs[0].items`; the emitter's
member-path keyer answers "" for a path rooted at an index (D451), so no container narrowing
is pushed for it and the read hands the field's union box to a consumer typed at the list.
The atom form of the same read runs through the checker-typed arm of
`emitUnionFieldNarrowUnbox` ([D8145](D8145.md)); a container has no such arm. Closed by
keying the place the checker's way: `memberPathKeyOf` (emit_base.vl) now spells an index-rooted
path as `placeKeyOf` does, so the narrowing is pushed and found. A write to the element, the
field or the list between the test and the read drops it, as the checker's own key does (D2390).
