### D15747 — a function returning a `const` copy of a hole lambda's bundle holder is refused at emit

**closed 2026-11-11, runs and prints `5` `2.5` · was loud emit reject, clause 2, `a function returning a parameter called at two signatures is called where its result is not used at one of them` · found working [D15744](D15744.md) · filed 2026-11-11 against master `7d0f985f` · closed in the elaboration: a returned `const` copy of a holder names the holder's initialising call (`elabRetHolderCall`, through one copy), and a holder's copy may be returned (`elabHolderCopiesHold` counts its returns), so the record is kept whole as [D15740](D15740.md)'s returned holder is · fixture `tests/cases/closures/hole-lambda-bundle-returned-as-const-copy.vl`**

Repro:

    function lap(f) {
      f(2.5)
      f(3)
      return f
    }
    const c = lap((a) => a + 1)
    function g() {
      const v = c
      return v
    }
    const w = g()
    print(w(4))
    print(w(1.5))

Want:

    5
    2.5

#### Mechanism

`elabRetHolderCall` took only a holder whose initialiser is a call, and a holder's copies were
admitted only when every read was a call through them or a hand.
