### D15203 — a list of records holding a list of un-annotated functions, returned by a function, has no interned rep shape at emit

**loud emit reject · `emitProgram: ref valtype with no interned shape` · clause 2 · open · the annotated twin (`function inc1(a: i32): i32`) runs, as does a returned record or a returned list of lists · found grading D15201, whose write it is not · present on master `2cde0cf6` · filed 2026-11-03 against master `2cde0cf6`, re-scoped the same day: the three-level list literal it also named was [D15204](D15204.md)'s producer and runs since that fix**

Repro:

    function inc0(a) { return a + 1 }
    function mk() { return [{ fs: [inc0] }] }
    print(mk()[0].fs[0](3))

Want:

    4

#### Mechanism

Not traced. The refusal is the bounds guard of `fbValtype` / `fbValtypeNullable` (emit_bytes.vl): no rep row is interned for the record element of the list the function returns when its field holds an un-annotated function's list; the annotated function's row exists.
