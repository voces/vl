### D15203 — a list of un-annotated functions three list literals deep, or a list of records holding one that a function returns, has no interned rep shape at emit

**loud emit reject · `emitProgram: ref valtype with no interned shape` · clause 2 · open · the annotated twin (`function inc1(a: i32): i32`) runs, as do two levels and a returned record · found grading D15201, whose write it is not: the program refuses with no write at all · present on master `2cde0cf6` · filed 2026-11-03 against master `2cde0cf6`, re-scoped the same day**

Repro:

    function inc0(a) { return a + 1 }
    const xsss = [[[inc0]]]
    print(xsss[0][0][0](3))

Want:

    4

#### Mechanism

Not traced. Both refusals are the bounds guard of `fbValtype` / `fbValtypeNullable` (emit_bytes.vl), so a rep row for the nested list or the returned list of records is never interned for an un-annotated function's element; the annotated function's row exists. The same literal read inline is [D15204](D15204.md).
