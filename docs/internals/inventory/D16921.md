#### Mechanism

The bare list ran once `monoPinListElems` handed a re-pointed list of lists nothing calls to
`monoPinNestedListElems`, which folds each re-point's inner lists into the uncalled slot's type.
D16915's close pins a record field's list of lists of functions at its elements' signature; a
field three lists deep, and a list of lists written at the field (`r.f = [[dbl]]`), are not
pinned there (`monoPinFieldContainer`).

Narrowed 2026-11-17 by lane AE (parked): the bare-list case is any whole re-write of a `let` list of
lists of un-annotated functions nothing calls, the same function included
(`let r = [[inc0]]; r = [[inc0]]; print(r.length)`); `push`, a call, one list level and an
un-re-pointed binding run. Mono's pin of a `let` list of functions (`emit_mono.vl`, the pass that
reads `monoListStoresAgree` and `monoSlotDeliveryTy`) has no list-of-lists analog; one needs the
re-point agreement over the inner lists, more than D16915's field pin did.
