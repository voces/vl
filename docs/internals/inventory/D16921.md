### D16921 — an uncalled list of lists of un-annotated functions three deep in a record, re-pointed as a bare list, or written at the field, is refused at emit

**loud emit reject · clause 2 · the residue of [D16915](D16915.md), whose two-deep record field runs · found by lane AE closing D16915 · filed 2026-11-17 against master `a4b5ff113`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    let r = [[inc0]]
    r = [[dbl]]
    print(r.length)
    // vl check: rc 0.  vl run: emit error, "emitProgram: ref valtype with no interned shape"

Want:

    1

#### Mechanism

Not yet located for the bare list. D16915's close pins a record field's list of lists of functions
at its elements' signature; a bare binding re-pointed between two such lists, a field three lists
deep, and a list of lists written at the field (`r.f = [[dbl]]`) are not pinned there.

Narrowed 2026-11-17 by lane AE (parked): the bare-list case is any whole re-write of a `let` list of
lists of un-annotated functions nothing calls, the same function included
(`let r = [[inc0]]; r = [[inc0]]; print(r.length)`); `push`, a call, one list level and an
un-re-pointed binding run. Mono's pin of a `let` list of functions (`emit_mono.vl`, the pass that
reads `monoListStoresAgree` and `monoSlotDeliveryTy`) has no list-of-lists analog; one needs the
re-point agreement over the inner lists, more than D16915's field pin did.

#### Ablation

| `let r = [inc0]`, `r = [dbl]` (one level) | runs | **yes** (a list of lists) |

#### Grading list

- `let r = { f: [[[inc0]]] }`, `r = { f: [[[dbl]]] }`, `print(r.f.length)`: `ref valtype with no
  interned shape`; want `1`.
- `let r = { f: [[inc0]] }`, `r.f = [[dbl]]`, `print(r.f.length)`: `nested arrays are not supported`
  after D16915's close (master: `ref valtype with no interned shape`); want `1`.
