### D16699 — an un-annotated list in a generic body that a generic function name is pushed onto is refused when returned

**loud emit reject · `a returned container of functions is built at another storage than this function's result` · clause 2 · open · `vl check` rc 0 · the annotated list runs, and so does a pushed record of the name · found grading [D16695](D16695.md) · filed 2026-11-16 against master `05297d752`**

Repro:

    function id<T>(x: T): T { return x }
    function run<T>(_x: T) {
      const rs = []
      rs.push(id)
      return rs
    }
    print(run(3)[0](3))
    // vl check: rc 0.  vl run: emitProgram: a returned container of functions is built at another storage than this function's result

    3

#### Mechanism

Not traced. The list's element is pinned by its first push in the generic body, at the generic
`(T) => T`; the instance builds the returned list at a storage other than the one its result is
built at.
