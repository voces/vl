### D15283 — a fresh record `let` pushed or assigned into a place built at a wider record is check-clean invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · open, target `6` · found closing [D15238](D15238.md) and [D15237](D15237.md), their `let` spelling · filed 2026-11-04 against master `ee0b51d5`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const xs = [mk()]
    let r = { f: 6 }
    xs.push(r)
    print(xs[1].f ?? 0)

Want:

    6

#### Mechanism

Not ablated past the table. D15237 and D15238 build a fresh record binding where it is pushed or
assigned into a place built at `J`, but only a `const` (`recCoalesceHeldLit` takes `letKw ==
"const"`). A `let` stays built at its own `{f: i32}` and is handed to a place of `J`'s row.

#### Ablation

| spelling | outcome |
| --- | --- |
| this repro | invalid wasm |
| `const r` (D15237) | runs |
| `let y = xs[0]; let r = { f: 6 }; y = r` (D15238's spelling) | invalid wasm |
| `let r = { f: 6 }; r = { f: 7 }; xs.push(r)` | invalid wasm |
