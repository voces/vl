#### Mechanism

The refusal is `pushFieldStorage`'s `FC_REF_LIST` arm (emit_bytes.vl): the application's
struct carries the field `xs` at code `FC_REF_LIST` with no ref-list slot (`refSlot < 0`).
So no phase interns a ref-list for the instance's element `i32 | string` when it reaches it
through the alias's parameter. A record element (`Box<R>`) and a primitive element (`Box<i32>`,
`Box<string>`, `Box<f64>`) both get a slot.

The skipped step is the field's spelling, not an interning rung. `gaeEnsure` builds the
application's row from `gaeApplyFieldTy`, which substituted `T` in `T[]` textually and appended
the suffix: `i32|string` + `[]` read as `i32|string[]`, a union with a list member. Its
`arrElemNameRaw` is `""`, so the row recorded no element name, and no slot was interned for it.
