#### Mechanism

The slot-record note (emit_elab) keeps the maker's record whole only when every value written to
the slot is a call returning it, a hole lambda (instanced at each signature, D17572) or a named
function of one closed signature (wrapped, D17700). A generic or hole-parameter named function was
neither, so the note kept nothing, and the maker's call was picked with no member (`bpHeap` -2).
The close widens D17572's producer to any function value whose declaration is instanced per
signature: the elaboration enqueues a named one at each of the record's signatures, the
monomorphizer instances it there, and the IR builds the record. Only a fixed-signature function is
wrapped (D17700).
