### D3828 — a nested `<U>` generic whose tail `if` recurses in one arm and calls a void function in the other is given a result, and traps at `unreachable`

**loads then traps · found closing D3826 · filed 2026-10-08 against master `cab1ee907`**

Repro:

    function outer(x: i32) {
      function inner<U>(u: U, n: i32) {
        if n > 0 { inner(u, n - 1) } else { print(x) }
      }
      inner(1, 2)
    }
    outer(7)
    // vl check: rc 0.  vl run: prints 7, then `wasm trap: wasm unreachable instruction executed` in `inner`

Want:

    7

#### Mechanism

Not yet located. The instance is emitted with `(result i32)` although neither arm yields a value,
and the void arm falls through to the trap the result needs. A `: void` annotation, a
statement-form `if` with an early `return`, or a non-generic `inner` all run.
