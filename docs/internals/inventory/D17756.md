#### Mechanism

Not traced: the push converts the map's function values to the union-result slot, and the
expression the IR builds for that conversion has no emitter arm. The same delivery as a list
literal (`[__fm]`) is a loud check reject, `set: expected (i32) => i32, got (i32) => f64`; the
checker's two answers disagree.
