### D17857 — the outer-scope binding of a function declaration holds a signature minted with a pending return that nothing ever finishes

**runs today and must keep running · a possible stale-type defect, reader not yet found: 10,575 of the self-compile's 24,491 `symDeclInOuter` rows keep `RET_PENDING` to the end of the check (coordinator ruling) · filed 2026-11-28 against master `8109888ab` · owner COV-IS**

Repro:

    function f(x: i32) { return x + 1 }
    const g = f
    print(g(2))
    // vl check: rc 0.  vl run: 3

#### Mechanism

`checkFuncDeclNode` binds the declaration in the outer scope with
`symDeclInOuter(n.fnName, fnIx, mkFuncTy(paramTys, ret), 2)` (`check_fn_decl.vl`) while `ret` is
still pending; the inference patches the hoisted row (D17856), not this one, so the binding column
keeps a signature whose return is no type. Whether any reader (the binding-identity column, the
LSP's symbol table) reads that return is not yet known; the close either binds the finished row or
shows no reader reads the return. S2b keeps such rows out of the intern table.
