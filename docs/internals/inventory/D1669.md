Repro:

    function pick<T>(v: T): T[] {
      const out = __array_new__(1, v)
      return out
    }
    function big(): i64 { 7 }
    print(pick(big()).length)
    // was: vl check rc 0, then exit 70, expected i32 found (ref $type). Now prints 1.

#### Mechanism

`arrNewIntrKind` reads the fill's rep **in a frame**. Inside a monomorphized instance the fill
is a PARAMETER, and its rep lives only in the instance's substituted annotation — which is why
`arrNewNamedKind`'s third source is `arrNewFillAnnKind(callIx, fnIx)`. `collectA`'s arena walk
is a linear pass over `P.nodes` with no enclosing function, so it asked
`arrNewIntrKind(i, -1)`: instrumented on master it answers **0**, the i32 guess, while
`emitArrayNewIntr` — which does have the frame — answers **4**. One question, two answers, and
the difference is the frame, not the program.

Two halves, both needed. `collectArrNewFrames` asks the same rung once per function body in
that body's own frame and interns the scalar pair it names, which is what sets `ia64Used`.
And `exprI64Array` gains the `__array_new__` arm that `exprF64Array` (kind 1), `exprStringArray`
(2), `exprRefArray` (3) and `exprArray` (0) each already carry for their own kind, so the
un-annotated local keeps the slot the intrinsic chose rather than the i32 default.

The frame pass interns SCALAR pairs only. A kind-3 ref fill mints a ROW, which moves slot
numbering, and re-minting it in the framed pass made `refListSlotOfExprStrict` miss at emit
time: `tests/cases/std/array-filled-elements.vl` and
`tests/cases/arrays/array-new-generic-pin-element-grid.vl` both stopped building. Measured,
then scoped, then re-measured at `DIFFERENT 0`.

And it is a PASS-TABLE row, not a tail call inside `collectA`. `collectA` runs before
`collectFns`, so at that point `fnStmts` still holds the PREVIOUS program's node indices — the
multi-compile hazard `emitProgram`'s own header names — and reading `P.nodes[fnIx]` there
trapped the compiler across 1,600 cases of the wasm oracle while every CLI probe was green,
which is the "runs alone, fails in company" shape exactly. The row is
`collectArrNewFrames > collectA#2 collectFns monomorphize`, and the loop is bound-guarded too.
