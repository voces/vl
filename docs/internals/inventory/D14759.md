Repro:

    type V = { y: i32, x: i32 | string }
    function k(v: V): i32 { 1 }
    function g<T>(v: T): i32 { k(v) }
    print(g({ y: 2, x: 9 }))
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `g`: expected (ref $2), found (ref $4); $2 is `V`

#### Mechanism

At the instance `T := {y: i32, x: i32}`, `v` reaches `k`'s `V` parameter, whose `x` is a union box
where the argument's is an `i32`. The argument IS noted for the pins (`rcwPinSrc`, owned by the
call), but `objShapeAdapterlessAt` admits it there: an argument to an annotated parameter that only
reads a field is handed by rep (D14753), as `const a = mk(); k(a)` is and runs. Inside a generic
instance the callee is never instanced at that rep, so the record reaches `V`'s storage
unconverted. The object-literal field (`{ c: v }` into `{ c: V }`) is not noted for the pins at
all. A binding (`const r: V = v`) is noted and refused.
