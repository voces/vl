### D14759 — a type-parameter value delivered as a call argument or a record field, to a record that stores a field differently, is not re-asked at the pin

**open · check-clean invalid wasm · clause 1 · filed 2026-11-01 against master `dc47f5ab`**

Repro:

    type V = { y: i32, x: i32 | string }
    function k(v: V): i32 { 1 }
    function g<T>(v: T): i32 { k(v) }
    print(g({ y: 2, x: 9 }))
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `g`: expected (ref $2), found (ref $4); $2 is `V`

#### Mechanism

At the instance `T := {y: i32, x: i32}`, `v` reaches `k`'s `V` parameter, whose `x` is a union box
where the argument's is an `i32`. A binding in the same body (`const r: V = v`) and a method call
(`v.poke()`) are re-asked at the pin and refused as "stores field `x` differently"; the argument
and the object-literal field (`{ c: v }` into `{ c: V }`) are not, so the record reaches `V`'s
storage unconverted.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the type parameter (`function h(v)`, a hole) | runs `1`: the literal is built at `V` (D14532) | **yes** |
| `x`'s union in `V` (`x: i32`) | runs | **yes** |
| the fresh literal (an annotated `{y: i32, x: i32}` binding) | still check-clean invalid wasm | no |
| `x: i32 | null` in place of `x: i32 | string` | still check-clean invalid wasm | no |

#### Grading list

* The field position: `function g<T>(v: T): i32 { const o: { c: V } = { c: v }; 1 }`.
* The direct non-fresh spelling `const a: {y: i32, x: i32} = …; k(a)` is refused, so a non-fresh
  source at the pin should refuse too; a fresh literal should run, as D14760 asks.
