### D3800 — the redundant-annotation hint compares the annotation with the initializer alone, so it names annotations whose removal breaks the program

**loud check reject · the spelling the hint asks for · 28 of the 3,079 hints the `tests/cases` fixtures produce · filed 2026-10-07 against master `1887307a8` (lane DG)**

Repro:

    function mk() {
      const inner = []
      inner
    }
    print(mk().length)
    // Written `function mk(): i32[]`, vl check hints `mk` is inferred as `i32[]` and the
    // program prints 0. Removed as the hint asks: "cannot infer a type for 'inner'".

#### Mechanism

`recordRedundantAnnot` and `recordRedundantRet` (typecheck.vl) decide the hint from the
initializer's or the body's type, before or without the uses the annotation pins. D3798 closed
one family of this (a `??` default read). Measured by removing each hinted annotation in
`tests/cases` alone and grading the copy against the original (check errors, then run output):
32 hints changed the outcome on master `1887307a8`, 31 after D3798's fix, and 3 of those are a
trap message's column moving, so 29 and 28 are real. The 28, by what removal does:

* 16 hints: the un-annotated program is check-clean and then fails to build or traps (rc 70 or 1),
  a clause-2 defect in that spelling: `closures/capture-mutation-init-kinds`,
  `generics/coalesce-bounded-param-keeps-default` (3), `generics/literal-read-in-place-and-bare-param-result`,
  `literal-unions/fn-value-litunion-arg`, `literal-unions/generic-pin-literal-union-result` (2),
  `maps/untyped-record-literal-stored-beside-narrowed-get`, `unions/as-opt-list-arm`,
  `unions/deep-is-json-shape-walk`, `unions/list-arm-push-and-shared-member`,
  `unions/list-literal-pinned-two-destinations-widen`, `unions/list-literal-two-destination-kinds-widen`,
  `unions/narrowed-nested-index-place`, `unions/narrowed-nullable-arm-record-delivered`.
* 3 hints: a check error on a clean program. The annotation pins an empty `[]` tail
  (`arrays/infer-empty-from-usage`, this witness), or a return whose every path recurses
  (`lint/unconditional-recursion`, `lint/unconditional-recursion-nested-fn`).
* 9 hints, in error fixtures: the error set changes. `arrays/error-list-widening-origins`,
  `functions/error-ufcs-receiver-container-widening`, `generics/error-coalesce-hole-default-at-pin` (2),
  `numerics/error-as-cast-hint-every-return-shape`, `numerics/literal-default-names-declaration`,
  `soundness/unannotated-param-solved-nonmember-reject` (3).

The general fix the brief named is to re-check each hinted binding un-annotated before reporting
it; that costs a check per hint and does not see the 16 build failures.
