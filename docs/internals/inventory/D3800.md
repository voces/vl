#### Mechanism

`recordRedundantAnnot` and `recordRedundantRet` (typecheck.vl) decide the hint from the
initializer's or the body's type, and the checker agrees about the TYPE where the un-annotated
spelling builds a different REP or loses a use the annotation solved. Graded by removing each
hinted annotation in `tests/cases` alone and comparing check errors, then run output, the 28
false hints (31 less 3 trap messages whose column moved) fall in these groups, each now
suppressed by its own rule, with no change to typing:

| group | hints | rule |
| --- | --- | --- |
| a program with check errors (9, all error fixtures: numeric list literals a use retypes, a param solved by the annotation, a `??` over a type parameter, an error measured against the return) | 9 | no redundant hint at all while `T.diags` is non-empty (`checkProgram`) |
| a return whose tail is an empty `[]` the annotation pins | 1 | `retSiteTypedByAnnot`: the return value reaches an empty-collection hole |
| a return whose every path is the function's own call | 2 | `retSiteTypedByAnnot`: a direct self call as the return value |
| a return read through a narrowing (D3811) | 1 | `retSiteTypedByAnnot`: an `Ident` with a live narrowing |
| a return called through a local a nested lambda reassigns (D3812) | 1 | `retSiteTypedByAnnot`: a callee the body assigns |
| a generic call's result holding a union | 6 | `initTypedByAnnot`: generic callee and `tyRepVaries` |
| a record literal in an `if` arm | 2 | `initTypedByAnnot`: `literalTypedByAnnot` over every tail leaf |
| a list literal with a function, union or nullable-list element | 3 | `initTypedByAnnot`: `tyRepVaries` on an element |
| an `as!` to a list | 1 | `initTypedByAnnot`: a cast to more than a scalar |
| an alias to a list of records with two destinations | 2 | `initTypedByAnnot`: an alias whose element is not a scalar |

The rules are conservative: 245 true hints went with them, 64 in error fixtures and 181 in clean
ones, mostly lists of function values and of nullable or union elements. The re-scan on the closing
seed graded 2,811 hints (5 of them the new fixture's controls), 0 of them false; the only movement is the same 3 trap columns.
