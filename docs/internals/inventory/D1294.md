**closed — `emitVariantStruct`'s field-seed ladder grew the `isNulScalarListFieldCode` arm the struct literal's already had · was a loud emit reject at check rc 0, clause 2 · PRE-EXISTING: identical on `seed-latest` · ZERO corpus cells · found 2026-09-03 while grading [D1180](#d1180)'s actual-null case at the arm spelling**

    type A = { d: string[] | null }

  that types a bare `null` is chosen per field CODE, and the variant literal's ladder carried
  codes 5, 18, 28, 29 and the five list build-kinds — every one the struct literal's did
  except the nullable SCALAR-BACKED list family (31 / 32 / 33 / 34).

* **THE SENTENCE NAMED THE WRONG DESTINATION** because it is the ladder's last resort: with no
  seed set, `emitNullLitNode` falls to the struct arm and reports what that arm wanted.

* **Graded.** `{ d: null }` for `string | null`, `Inner | null` and `Inner[] | null` arm fields
  all still build; the plain-struct spelling of the same literal still builds; the arm's
