#### Mechanism

From the ablation only. Each of `a` and `b` is called at ONE type in the body, so neither is
split, and `mid` is instanced with `a` at the string instance and `b` at the i32 one. The
recursive call hands `b` to `a`'s position and `a` to `b`'s, so the instance receives the
wrong function for each parameter. D6091's close covers a parameter handed back to its own
position, which keeps the instance's types.
