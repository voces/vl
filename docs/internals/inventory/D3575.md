### D3575 — `vl build` takes its first argument as the input, so a flag before the file fails

**runs today and must keep running · the defect is the CLI's: `vl build --wat p.vl` fails with ``reading `--wat` `` (exit 1) · found by the #3351 review · filed 2026-10-03 against master `3b9319528`**

Repro:

    print(1)
    // prints 1. `vl build --wat p.vl -o p.wasm` fails with
    //   Error: reading `--wat`
    //   Caused by: No such file or directory (os error 2)
    // while `vl build p.vl --wat -o p.wasm` builds.

#### Mechanism

`build_cmd` reads the input as the first argument after `build`, without skipping flags. A
flag in that position becomes the path it tries to read.

#### Grading list

Each boolean flag before the input, a value flag (`-o x.wasm`, `--compiler s.wasm`) before
the input, and two positional files (which should be refused).
