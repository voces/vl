### D2532 — a lambda returning a guard-narrowed capture its frame writes later gets the box as its return type

**check-clean invalid wasm · clause 1 · filed 2026-09-25 against master `680b67486` while ablating D2529**

Repro:

    function main() {
      let v: i32 | null = 1
      if v != null {
        const h = () => v
        print(h() + 1)
      }
      v = null
      print(v ?? -2)
    }
    main()
    // vl check: rc 0.  vl run: invalid module, the lambda's body yields i32 into a (ref $box) result

#### Mechanism

The later `v = null` makes `v` a shared cell (`cboxByRef`). The checker keeps the guard's narrowing
in `h`, soundly, since every write under the guard is refused and `h` cannot be called after the
block. The body's read replays the narrowing and yields `i32`, but the lambda's result kind is
derived from the captured binding's cell kind, which is the union box. Predicted mechanism, not
yet ablated past the rows below.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the later `v = null` (a by-value capture) | runs | **yes** |
| a return annotation `(): i32 => v` | runs | **yes** — an inferred return |
| the tail `v + 0` instead of `v` | runs | **yes** — the tail is the bare name |
