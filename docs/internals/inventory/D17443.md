**closed 2026-11-24 by S2 · runs, prints `1` · was loud emit reject, clause 2, legacy (the claimless build refused the same) · a call whose result is a union-of-maps box is an arm-site receiver for `.length`, `.has` and an index (`armSiteReads`, the lists-only cut dropped), and a call an arm overrides reads at that arm's map shape (`mapShapeOfExpr`, `luOvTyOf`) · `.get` stays refused, [D17444](D17444.md) · owner S2 · found by the D17102 sweep · filed 2026-11-24 against master `7f2682f0`**

#### Mechanism

The D17102 mechanism over map arms. A call receiver was admitted to the per-arm dispatch
(`armSiteReads`) only when every container arm was a list. Admitting a map arm built invalid wasm:
inside the arm the receiver's value is the arm's map (the call override, D17102), but
`mapShapeOfExpr` typed a call by its callee's declared result (`fnRetMapShapeAt`), not by the arm's
type override, so the size read cast the arm's map to the other arm's struct.

| `a.length` read directly | runs |

#### Grading list

- `.length`, `.has`, `.get` over a union of maps at a call receiver, generic and not.
