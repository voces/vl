### D17443 — a union of maps handed through a call is refused as a `.length` or `.has` receiver

**loud emit reject · clause 2 · found by the D17102 sweep, the same on master and on the D17102 fix · owner S2 · filed 2026-11-24 against master `7f2682f0`**

Repro:

    type MI = { [string]: i32 }
    type MS = { [string]: string }
    function mk(k: i32): MI | MS | i32 {
      if k == 0 { return 0 }
      const m: MI = Map()
      m["a"] = 5
      return m
    }

      if a is i32 { return }

    }
    g(mk(1))

Want:

    1

#### Mechanism

The D17102 mechanism over map arms. A call receiver is admitted to the per-arm dispatch
(`armSiteReads`) only when every container arm is a list: an arm's reads are redirected through
the list override (`luOvLocalOf`), which a map arm's `.length` and `.has` / `.get` do not consult.
Admitted as a list union is, the call runs again inside the arm and the build is invalid wasm.

#### Ablation

| ingredient | outcome |
| --- | --- |
| `id(a).has("a")` in place of `.length` | emit reject (`callee is not a function name`) |
| `a.length` read directly | runs |
| a union of lists through the call (D17102) | runs |

#### Grading list

- `.length`, `.has`, `.get` over a union of maps at a call receiver, generic and not.
