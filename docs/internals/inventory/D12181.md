### D12181 — a `for` range whose next step leaves the i32 range wraps and keeps looping

**check-clean silently wrong · `vl check` rc 0 · clause 1 · a range reaching `2147483647`, or stepping past `-2147483648`, never ends · found folding the `step -2147483648` literal for L3 · filed 2026-10-24 against master `ed5d4f7f7`**

Repro:

    let n = 0
    for i in 2147483646 to 2147483647 {
      n = n + 1
      if n > 5 { break }
    }
    print(n)
    // PRINTS 6

Want:

    2

#### Mechanism

The loop advances the counter with a wrapping `i32.add` and then tests it against the bound.
When the bound is within one step of the type's edge, the add wraps to the other end of the
range, which passes the test again, so the loop never exits. The exit test has to be taken
before the add can overflow (compare the distance left to the step), or the add checked.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the edge as the bound (`2147483645 to 2147483646`) | runs, `2` | **yes** |
| the constant bound (`const hi = 2147483647`, `to hi`) | still `6` | no |
| the constant step (`let st = 3`, `step st`, from `2147483640`) | still `6` | no |
| the direction (`-2147483647 to -2147483648 step -1`) | still `6` | no |
| `to` for `until` | runs, `1` | **yes** |

#### Grading list

`for i in 2147483644 to 2147483647 step 2` (want `2` iterations), the negative-step twin
above, a dynamic step, and a range whose step is `-2147483648`
(`tests/cases/loops/range-step-i32-min.vl` keeps only loops that stop before wrapping).
