### D17116 — a `K | null` place compared to a value-union call that writes it is read after the call

**check-clean silently wrong · clause 1 · found by V7 verifying #9854, the same on master and claimless · owner S2 · filed 2026-11-24 against master `1784a86d`**

Repro:

    type K = "a" | "b"
    type U = i32 | K | null
    let gk: K | null = null
    function setG(k: K | null, r: U): U { gk = k; return r }
    print(gk == setG("a", "a"))
    // PRINTS true

Want:

    false

#### Mechanism

The left operand is a `K | null` place and the right a call returning the value-union box `U`.
Legacy's union compare reads the place after the call (the null leg's test and the decode each
re-read it), so it sees the call's write. The IR leaves this function uncovered ("union compare
null operand"), so legacy's bytes ship.

#### Ablation

| ingredient | outcome |
| --- | --- |
| `n == bump()`, `i32` place and call | right, `false` |
| `s == setS()`, `string \| null` place and call | right, `false` |
| `gk == setGK("a")`, a `K \| null` call | right, `false` |
| `u == gk`, no call | right, `false` |
| `U = string \| K \| null` (no `i32` member) | right, `false` |
| `!=` in place of `==` | wrong, `false` (want `true`) |
| `gk` starting at `"b"`, the call writing `null` and returning `"b"` | wrong, `false` (want `true`) |
| a captured local `lk` in place of the global | wrong, `true` |
| `setG("a", "a") == gk`, the call first | right, `true` |
