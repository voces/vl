### D13520 — a list element shared by two lists that call a forwarded hole at different key sets has no interned signature

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: each list alone runs, and two lists with no element in common run · found by lane L1 closing [D13320](D13320.md) · present on master and after lane L1's D13320 PR · filed 2026-10-25 against master `5477fb0cc`**

Repro:

    function add(a, b) { return a + b }
    function apply2(g, s) { print(g(s, s)) }
    function apply4(g, s) { print(g(s, 2)) }
    function apply5(g, s) { print(g(3, s)) }
    function innerThree(k, h) {
      for f in [apply2, apply4] { f(h, k) }
    }
    innerThree(0.5, add)
    function three(k, h) {
      for f in [apply4, apply5] { f(h, k) }
    }
    three(0.5, add)
    // vl check: rc 0.  vl run: emitProgram: a function-value call has no interned signature — parameter 1 of type `` has no representation in the function-value ABI

Want:

    1
    2.5
    2.5
    3.5

#### Mechanism

Not measured past the ablation. `apply4` belongs to two list groups whose hole keys differ
(`f64, f64` and `f64, i32` against `f64, i32` and `i32, f64`); the refusal is at the second
group's call `three(0.5, add)`. Siblings in one list split together (D13261), so a shared
element plausibly ties the two groups' key lists together without either caller's hole plan
covering the union.
