### D2881 — a record literal in an un-annotated list, later bound to a declared `{ f: i64 | null }[]`, takes an annotated `{ f: i32 }` row

**check-clean invalid wasm · clause 1 · identical on master `8e10ef58b` · found while writing the D2865 fixture · filed 2026-09-27**

Repro:

    const i: { f: i32 } = { f: 4 }
    type I = { f: i64 | null }
    const il = [{ f: 7 }]
    const ic: I[] = il
    print(ic[0].f)
    print(i.f)
    // vl check: rc 0.  vl run: invalid module in the top-level code — expected (ref null $type), found (ref $type)

Want:

    7
    4

#### Mechanism

Not localised past the ablation. The checker adopts `{ f: 7 }` into `I` through the later
binding, but the literal is built at the annotated `{ f: i32 }` row, which its own type names,
so the list holds that row where `ic` expects `I`'s.
