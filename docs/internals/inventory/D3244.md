### D3244 — a `null` bound to a hole parameter and written into a function field has no struct-typed context at emit

**loud emit reject · clause 2 · open · pre-existing, the same on master `fc1e91d24` · found by the #3289 split-head review · filed 2026-09-29 against master `fc1e91d24`**

Repro:

    type R = { v: i32, f: (() => i32) | null }
    function F(z, g) {
      z.f = g
      print(z.f == null)
    }
    const r: R = { v: 1, f: () => 5 }
    F(r, null)
    // vl run: emitProgram: bare null needs a struct-typed context

#### Mechanism

Not localised. The argument `null` binds the hole `g` at the `null` type, and the call site
lowers it with no struct-typed context, although the parameter is written into a nullable
closure field. The review saw the lambda spelling as invalid wasm; on master `fc1e91d24` it
is the same emit refusal (`const k = () => { z.f = g }; k()`).
