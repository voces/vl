### D4875 — an un-annotated record join through a spread of a record literal builds the inner record at its own row

**check-clean invalid wasm · clause 1 · found closing D4871, grading a record element beside its nested-list witnesses · filed 2026-10-15 against master `3affca3dd`**

Repro:

    const v = [...[{a: 1}], {a: 2.5}]
    print(v[0].a / 4.0 + v[1].a)
    // vl check: rc 0.  vl run: invalid module, type mismatch: expected i32, found f64

Want:

    2.75

#### Mechanism

Not yet ablated past the table. The checker joins the element to `{a: f64}`, but the spread
source `[{a: 1}]` is built at its own `{a: i32}` record, so the element the copy delivers does
not have the joined record's layout. The annotated spelling and the spread-free join both run.
