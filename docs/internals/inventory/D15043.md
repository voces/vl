**closed 2026-11-02 · runs, prints `2` · was loud emit reject, clause 2 · `spreadBoxingSource` (emit_classify.vl) treats a nullable element whose null is a niche of the source's own storage as that source's rep, so the source copies as it is · fixture `tests/cases/lists/spread-boolean-list-into-nullable-boolean-list.vl` · a member of [D2969](D2969.md)'s spread-boxing family · filed 2026-11-02 against master `a4e00240`, pre-existing**

#### Mechanism

`spreadBoxingSource` boxed every scalar source spread into a list of a nullable element, on the
premise that a scalar list has no null niche. A `boolean` has one: `(boolean | null)[]` is the
`i32` list `boolean[]` is, with null as a third value. No boxing row exists for it, so the
literal had nowhere to box into and refused.

| a generic `(T | null)[]` at `T := boolean` | same refusal | no |
