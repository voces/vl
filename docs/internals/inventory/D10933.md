### D10933 — a generic's record result delivered as an un-annotated record literal's field has no interned shape

**loud emit reject · clause 2 · `vl check` rc 0 · present on master `8be0b10be` · found by lane D10880 grading the struct-field position of `generic-record-nullable-tyaram-list-field-literal.matrix.vl` · filed 2026-10-23 against master `8be0b10be`**

Repro:

    function mk<T>(x: T): { g: T } { return { g: x } }
    const w = { f: mk("s") }
    print(w.f.g)
    // vl check: rc 0.  vl run: emitProgram: ref valtype with no interned shape

#### Mechanism

Not traced. The outer literal's field type is the generic's inline record result at the call's
binding, a shape no annotation in the program spells, and no pass interns it before the outer
literal's struct is laid out. Annotating `w`, or making `mk` concrete, puts the shape in the
program text and the program runs.
