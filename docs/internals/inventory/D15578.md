### D15578 — a forwarder into a list join, called with a different generic each time, is refused

**loud emit reject · clause 2 · `vl check` rc 0, then `emitProgram: a list holding a generic function is called through its elements at more than one type, so its elements have no one instance` · found closing [D15577](D15577.md) · filed 2026-11-09 against master `92e579e2` plus D15577's close**

Repro:

    function id<T>(x: T): T { x }
    function id2<U>(x: U): U { x }
    function id3<V>(x: V): V { x }
    function use(ys) { print(ys.length) }
    function take(a, b) {
      const xs = [a]
      xs[0] = b
      use(xs)
      print(xs[0]("abc").length + xs[0](2))
    }
    function fwd(f) { take(f, id2) }
    fwd(id)
    fwd(id3)
    // vl check: rc 0.  vl run: emitProgram: a list holding a generic function is called through its elements at more than one type

Want:

    1
    5
    1
    5

#### Mechanism

Not traced. It is [D15577](D15577.md) with the literal's parameter handed through a forwarder
([D15573](D15573.md)). D15577's close keys only ROOT hole-pin rows at the joined set; a row
recorded under `fwd`'s instance keeps its binding, because re-keying those made D15573's
single-call forwarder refuse. So each instance of `fwd` builds `take` at its own pair.
