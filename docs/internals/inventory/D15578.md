### D15578 — [CLOSED 2026-11-09] a forwarder into a list join, called with a different generic each time, is refused

**closed 2026-11-09, runs and prints `1`, `5`, `1`, `5` · was loud emit reject, clause 2, `vl check` rc 0, then `emitProgram: a list holding a generic function is called through its elements at more than one type` · found closing [D15577](D15577.md) · filed 2026-11-09 against master `92e579e2` plus D15577's close · closed by keying a hole-pin row recorded under a forwarder's instance at the joined set too (`elabHoleRowJoinTys`, emit_elab.vl), and by answering that set where a joined argument is open, as the forwarder's parameter is in its template (`fnTagListJoinOpenSet`, check_elab_cap.vl), so the late tag decision still tags the singleton the forwarder holds · fixture `closures/list-of-hole-param-slot-written-forwarded-literal-param-differs-per-call.vl` · its two-level twin is [D15579](D15579.md)**

Repro:

    function id<T>(x: T): T { x }
    function id2<U>(x: U): U { x }
    function id3<V>(x: V): V { x }
    function use(ys) { print(ys.length) }
    function take(a, b) {
      const xs = [a]
      xs[0] = b
      use(xs)
      print(xs[0]("abc").length + xs[0](2))
    }
    function fwd(f) { take(f, id2) }
    fwd(id)
    fwd(id3)
    // vl check: rc 0.  vl run: 1, 5, 1, 5

Want:

    1
    5
    1
    5

#### Mechanism

Each instance of `fwd` recorded its own hole-pin row for `take`, `({id}, {id2})` and
`({id3}, {id2})`, and mono's demand from inside each `fwd` instance took that row's instance. In
each one, the list was called at two types. Keying those rows at the joined set
`{id, id2, id3}` alone broke [D15573](D15573.md): the late tag decision
(`fnTagRedecide`) reads `take(f, id2)` at `fwd`'s template, where `f` is an open hole. So
`fnTagListJoinSetOf` answered -1, and `take`, now bound only at the joined set, no longer took
`{id2}` alone. The plan for `{id}` failed, and `fwd(id)` was refused. With an open argument, the
join reads the union of every call's hands (`fnTagHandsJoinTy`), so both producers agree.
