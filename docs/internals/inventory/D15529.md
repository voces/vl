### D15529 — a list of a hole parameter, pushed and handed on whole, its element called at two types, refuses its `.length`

**loud emit reject · clause 2 · `vl check` rc 0, then `emitProgram: '.length' on a receiver the emitter cannot classify as a list, string, map or set` · the witness of the live-sites row and of six places that used [D15010](D15010.md)'s, which now runs · filed 2026-11-06 against master `3866dd5f`**

Repro:

    function id<T>(x: T): T { x }
    function use(ys) { print(ys.length) }
    function take(a) {
      const xs = [a]
      xs.push(a)
      use(xs)
      print(xs[0]("abc").length + xs[0](2))
    }
    take(id)
    // vl check: rc 0.  vl run: emitProgram: '.length' on a receiver the emitter cannot classify

#### Mechanism

[D15010](D15010.md)'s witness with a push. Without the push the `monoFlow*` chain gate renames each
call through `xs[0]` to `id` and the program runs; with it, `xs[0]` is a literal index into a list
written after its build, so the gate declines (the element at an index can move), the list is built
as closures of one signature, and the `.length` refusal D15010 had stands. The right answer is `2`
then `5`.
