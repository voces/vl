### D12641 — a generic `is i32` over `T | i32` with `T` pinned to an anonymous record finds no interned arm

**closed 2026-10-25 by PR #4749 · runs, prints `other` then `int` · built, not refused: a local's annotation substituted at a pin spells an anonymous-record binding by its shape, as a parameter pin does (`monoSubstLetType` through `monoSubstAnonShapes`, emit_mono.vl), so `{x: i32} | i32` keys a registered union where `#anon0|i32` keyed none and the local fell to a record slot · pins: `tests/cases/generics/generic-is-over-anonymous-record-pin.vl` · was loud emit reject · clause 2 · the anonymous-record residue of D2975 (its function-type pin runs since #4739) · filed 2026-10-25 against master `38bf5d273`, the same on #4739**

Repro:

    function h<T>(a: T, c: boolean) {
      const r: T | i32 = if c { a } else { 5 }
      if r is i32 { print("int") } else { print("other") }
    }
    h({ x: 9 }, true)
    h({ x: 9 }, false)
    // vl check: rc 0.  vl run: emitProgram: `is` names a declared union member with no interned arm representation (deferred value-union composition)

Want:

    other
    int

#### Mechanism

`monoSubstLetType` substituted `T | i32` to `#anon0|i32`, a spelling that parses to no type, and
gave the synthesized annotation no arena type, so `letAnnIsUnion` found no registered union and
the local took the record's slot. The same local without `is` was check-clean invalid wasm
(`expected (ref $0), found i32`), and `const r: T | i32 = 5` refused `only i32 locals are supported`.

#### Grading list

A named record pin, a two-field anonymous record, `!is i32`, a value `if`, and a read narrowed by
the test. In one program with a function-type pin of another generic, the refusal is reported at
that other call (seen once, not ablated).
