### D6501 — a generic named function bound to an annotated `const k: (x: T) => …` in a generic body instanced at two types is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the un-annotated alias `const k = id`, the direct `id(a)` and an annotated lambda all run at both instances (lane L1) · found closing [D6483](D6483.md) · filed 2026-10-18 against master `4d1802f96`**

Repro:

    function id<T>(x: T): T { return x }
    function f<T>(a: T): T { const k: (x: T) => T = id; return k(a) }
    print(f(4))
    print(f("q"))
    // vl check: rc 0.  vl run: emitProgram: a lambda-lifted local function was taken as a value

Want:

    4
    q

#### Mechanism

From the ablation only. The annotation makes `k` a function-typed binding of the body's
`T`; at two instances of `f` the binding needs one function value per instance and the
emitter reaches the lifted-function floor instead of building it.
