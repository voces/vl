### D16920 — a record re-pointed at a smaller function set through a list of lists, or inside a nested record, is refused at emit

**loud emit reject · clause 2 · `emitProgram: object literal field count does not match struct` · the residue of [D16916](D16916.md), whose one-level field runs · found by lane AE closing D16916 · filed 2026-11-17 against master `a4b5ff113`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    let r = { f: [[inc0, dbl]] }
    r = { f: [[dbl]] }
    print(r.f[0][0](3))
    // vl check: rc 0.  vl run: emit error, "emitProgram: object literal field count does not match struct"

Want:

    6

#### Mechanism

D16916's close builds the re-point's literal at the binding's record where they differ only at a
field's list of functions (`recFnFieldsWiden`). One more list level, compared the same way, builds
each literal at its own record row of one layout, two nominal types, and the store fails to
validate, so the comparison stops at one level and these stay refused.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `{f: [inc0, dbl]}` re-pointed at `{f: [dbl]}` | runs, `6` | **yes** (a list of lists or a nested record) |
| `r = { f: [[dbl, inc0]] }` (the whole set) | runs, `6` | **yes** (a strict subset) |
| `let r = { a: { f: [inc0, dbl] } }`, `r = { a: { f: [dbl] } }` | the same refusal | no |

#### Grading list

- `let r = { a: { f: [inc0, dbl] } }`, `r = { a: { f: [dbl] } }`, `print(r.a.f[0](3))`: the same
  refusal; want `6`.
