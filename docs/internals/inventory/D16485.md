### D16485 — a compound write of a vector or record used as a value, over a place with an effect, is refused at emit

**closed 2026-11-15 · runs, prints `2` then `1` · was a loud emit reject, clause 2: `vl check` rc 0, then emitProgram: a compound write used as a value reads and writes a place whose receiver or index has an effect, which would run twice · fixed 2026-11-15 by lane L: the value-position spill's never-run else arm takes a typed `null` where the write's type has no zero, and the emitter lowers a literal-`true` value `if`'s else as dead (`staticValueIfCond`, wasmEmit.vl) · found designing D16484 · filed 2026-11-15 against master `6bbad19bf`**

Repro:

    import { F32x4, splatF32 } from "std:simd"
    let n = 0
    function idx(): i32 {
      n = n + 1
      return 0
    }
    const r = { v: splatF32(1.0) }
    const rs = [r]
    print((rs[idx()].v += splatF32(1.0)).x)
    print(n)

Want:

    2
    1

#### Mechanism

D16217 spills a compound write's effectful receiver and index into `if true { <spills> w }
else { <zero> }`, and the emitter lowered both arms, so the else needed a literal of the write's
type. `nssZero` and `""` cover only the scalars and `string`, so a vector or record write was
refused. The else arm is now dead at emit, and any node typed as the write stands there.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the effect in the index (`rs[0].v += …`) | loud emit reject for another reason ([D16486](D16486.md)) | — |
| the vector (an `f32` field) | runs | **yes** (a type with no zero) |
| the value position (the write as a statement) | runs | **yes** |
