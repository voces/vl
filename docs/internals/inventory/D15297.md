### D15297 — a record holding a list of an uncalled un-annotated function, returned from a generic function, has no interned rep shape

**closed · runs, prints `5` then `s` · was loud emit reject, `emitProgram: ref valtype with no interned shape`, clause 2 · fixed 2026-11-08: `monoPinReturnedObj` records each generic instance's copy at its `elabHeldValTy` · found closing [D15293](D15293.md) · filed 2026-11-04 against master `b19b5895`**

Repro:

    function inc0(a) { return a + 1 }
    function mk<T>(x: T) { return { fs: [inc0], x: x } }
    print(mk(5).x)
    print(mk("s").x)

Want:

    5
    s

#### Mechanism

The elaboration stamps an instance's held type only on a record-LIST literal (`elabHeldListFacts`, [D15293](D15293.md)); a bare record literal's open function leaf was left to the generic type, because `monoPinReturnedObj` declined every generic instance, so no row was minted for it. It now records the instance's copy at `elabHeldValTy`, which keeps the function sets since [D15296](D15296.md).
