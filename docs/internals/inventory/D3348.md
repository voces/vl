### D3348 — `v is K` over a box whose string arm is a plain `string` answers true for every string

**closed 2026-09-30 · was check-clean silently wrong, clause 1, on master `78abe1318` at the direct spelling (`false true true`), and invalid wasm at the generic one · found by the #3310 review (`w2.vl`) · fixture `tests/cases/unions/is-literal-union-over-string-arm.vl`**

Repro:

    type K = "a" | "b"
    type P = {x: i32}
    function g(a: P, b: string, k: i32) {
      const r = if k == 0 { a } else { b }
      print(r is K)
    }
    const p: P = {x: 7}
    g(p, "x", 0)
    g(p, "x", 1)
    g(p, "a", 1)

Want:

    false
    false
    true

#### Mechanism

`is K` compared the box's tag with the string tag a literal-union arm is stored under, which a
plain `string` arm shares, so `"x"` was a `K`. Over a box with no literal-union arm of its own but
a string arm, the test is membership: one tag-gated payload compare per member (`emitUnionLitIs`).
