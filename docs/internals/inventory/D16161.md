### D16161 — a map whose value is a list of records holding an un-annotated function nothing calls has no mv slot for that value

**loud emit reject · check-clean, so clause 1 · `emitProgram: unsupported map value type (no rep for a union-member struct, a nullable list over an unnamed element rep, or a nullable litunion-result closure; any other value type here interned no mv slot)` · found grading D15801's map-value family · filed 2026-11-14 against master `7cdda1fef`**

Repro:

    function inc0(a) { return a + 1 }
    const m = Map()
    m["k"] = [{ f: inc0 }]
    print(m.has("k"))

Want:

    true

#### Mechanism

The map's value type is `{ f: (_) => _ }[]`. Its field holds a generic function whose
instance nothing pins: no call reads it, so no set is tagged and no closure signature is chosen.
The mv slot the map's constructor asks for is minted from the value type. For a record value
(`m["k"] = { f: inc0 }`) and for a list of the function itself (`m["k"] = [inc0]`), the rep falls
back to something the layer names. For a list of records it does not, and the slot is never
interned. A call through the field pins the instance and the program runs.
