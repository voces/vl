### D15922 — a maker that binds a list of records holding a function and returns it in a record is refused at emit when a call reads through the returned record

**loud emit reject · `emitProgram: ref-list field element type is not interned` · clause 2 · open · found by w320 beside [D15804](D15804.md) · filed 2026-11-12 against master `22d35fe47`**

Repro:

    function inc0(a) { return a + 1 }
    function mk() {
      const xs = [{ f: inc0 }]
      return { a: xs }
    }
    print(mk().a[0].f(3))

Want:

    4

#### Mechanism

Not traced. The list bound to a name inside the maker before the record holds it is the
ingredient: the list literal written inline in the returned record runs. The function's
annotation and the number of functions do not matter. With two functions of different results
the message changes to `object literal field count does not match struct`, at the maker's
returned record.

#### Ablation

| spelling | outcome |
| --- | --- |
| the witness | loud emit reject |
| the list inline, `return { a: [{ f: inc0 }] }` | runs, `4` |
| `inc0(a: i32)` annotated | loud emit reject, the same message |
| a record of no function, `[{ n: 1 }]` | runs |
| the record bound, `const m = mk(); m.a[0].f(3)` | loud emit reject, the same message |
| a second element `{ f: half }` of another result, pushed or in the literal | loud emit reject, `object literal field count does not match struct` |
