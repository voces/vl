#### Mechanism

`emitAssignUnder` records the node index of the assignment's right-hand side in the
module-scope `nulWidenWriteRhs`, and `emitNulAtomToStr` refuses to widen an atom with that
index when it is typed at a type parameter or lowered in a pinned instance. Nothing cleared
it between programs. Node indices restart per program, so after D3507 (`v = "s"`), D3419 or
D3423, the stale index named the instance-lowered `kl` atom of this program, which was
refused. `scripts/emitter-state-audit.vl --check` gates only on NEVER-cleared state; this mark
was cleared by an inner function (`emitAssignUnder`), which the audit classes as "inner" and
does not gate, so it read as handled.
