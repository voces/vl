### D9009 — a re-pointed `let` of un-annotated functions with different results, handed to a parameter called at another un-annotated parameter, traps

**loads then traps · `vl check` rc 0 · `wasm trap: indirect call type mismatch` · clause 1 · found closing [D9007](D9007.md) · present on master `464f33df4` · filed 2026-10-21 against master `464f33df4`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function w(h, x) { return h(x) }
    let f = inc0
    f = half

    // vl check rc 0.  vl run: wasm trap: indirect call type mismatch

#### Mechanism

D9007's close judges the functions a hole parameter may hold at the argument types of the
call through it. Here that argument is `x`, itself a hole parameter, so the type is open while
`w`'s body is checked and the judge declines. The type that fixes `(i32)` is `3`, at the call
`w(f, 3)`, in another body.
