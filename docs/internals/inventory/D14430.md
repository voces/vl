#### Mechanism

(γ) slice 1 tags a set held in a list literal, so the list is the i32 list of the set's ids and
an element call dispatches on the id. A set's tag is decided once for the whole program, but a
call inside an instance body reaches its members at a tuple each instance closes on its own.
`ftInOpenFn` therefore leaves every list of a set whose holder sits in a generic function, or
one with an un-annotated parameter, untagged. That list stays a closure list, and the element
pin (`monoPinListElems`) is still the producer of its element signature.

This is the one predicate for that boundary, read once in `ftScan`. The per-instance mint
decides the set inside each instance's own check, and deletes `ftInOpenFn` with the pin reads
it keeps alive. When that lands the witness must still print its Want.
