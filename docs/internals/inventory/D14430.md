#### Mechanism

(γ) slice 1 tags a set held in a list literal, so the list is the i32 list of the set's ids and
an element call dispatches on the id. `ftInOpenFn` left every list of a set whose holder sits in
a generic function, or in one with an un-annotated parameter, untagged, and the element pin
(`monoPinListElems`) produced its element signature.

Two halves are lifted. A generic body's list is tagged, and each instance's call dispatches at its
own tuple. A hole function's list is tagged when no call through the set hands on a function
(`const fs = [inc, dbl]` in `run(v, n: i32)`). What stays is the witness: a call that hands a
member the hole parameter `h`, which the member calls. Tagged, that built invalid wasm (`expected
i32, found f64` inside `apply2`), because the split plan (D6210) copies a forwarded hole parameter
per tuple and the set's arms do not see the copies. `ftCallsHandFn` names the boundary. A set
of named functions handed there is outside it when its every read is an argument of a call
through a set, or of a parameter that only hands it on unread (`ftSetOnlyArgOf`,
`ftParamInert`): each arm keys its member at that set.

#### Plan

Thirteen split-plan dependents share this shape (the increment 3 census's D and I groups:
`forwarded-hole-fn-*`, `forwarded-hole-to-two-list-params`, `hole-fn-list-handed-hole-param`,
`named-generic-hole-called-in-frame`). Admitting the forwarded parameter once every instance binds
it to a tagged set (a mint fact per instance binding), with the parameter read only as an argument
of set calls whose members all take that set, tags both sets; with the split plan on, three of the
thirteen and this row's witness then refuse (`call to unknown function`), since the plan still
copies the forwarded parameter per tuple. The close is two steps: the split plan leaves a forwarded
parameter alone once every instance binds it to a tagged set (an `fsPlanHoles` exclusion read
from the same mint fact), so both builds agree; then the members' instances are keyed at the
forwarded set. Work in progress: branch `claude/inc3-s15`.
