### D17105 — a tagged choice handed back by a generic identity into an un-annotated binding and called is refused at emit

**loud emit reject · clause 2 · found by the D17097 position sweep · beside [D17097](D17097.md) · owner S2 · filed 2026-11-24 against master `dbeb64c7`**

Repro:

    function inc(a) { return a + 1 }
    function str(_a) { return "s" }
    function ap(g, x) { return g(x) }
    function id<T>(t: T): T { return t }
    function run(c: boolean) {
      const g = if c { str } else { inc }
      print(ap(g, 3))
      const h = id(g)
      print(h(4))
    }
    run(true)
    // vl check: rc 0.  vl build: emitProgram: cannot take the generic function `str` as a value — a function value carries ONE signature, and parameter `_a` is un-annotated (it would default to i32).

Want:

    s
    s

#### Mechanism

The binding `h` has no closed destination, so `id`'s instance is reached at the open set. The
call `h(4)` then asks for `str` as a single-signature value rather than dispatching on the id `g`
holds. The refusal names a mechanism. Unlocated.

#### Ablation

| ingredient | outcome |
| --- | --- |
| `const h = g` in place of `id(g)` | runs, `s` `s` |
| `print(ap(g, 3))` removed | runs, `s` |
| `print(ap(h, 4))` in place of `h(4)` | still refuses |
| `const h: (a: i32) => i32 \| string = id(g)` | runs (D17097's case file) |
