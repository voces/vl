### D10894 — a hole-function list element past index 0 whose own calls pass its generic parameter twice, or an element of a `T[]`, is refused an un-annotated lambda

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: a neighbouring spelling runs (the ablation) · found closing [D10796](D10796.md) · present on master `b84cf89cb` · filed 2026-10-23 against master `b84cf89cb`**

Repro:

    function apply2<T>(g, x: T) { print(g(x, x)) }
    function apply3<T>(g, x: T) {
      print(g(x, x))
      print(g(x, x))
    }
    const gs = [apply2, apply3]
    gs[1]((a, b) => a == b, 7)
    // vl check: rc 0.  vl run: emitProgram: monomorphize: unsupported argument type for `g` in a call to `apply3`

Want:

    true
    true

#### Mechanism

D10796's rung, `monoOwnCallOpenPinAt`, reads the parameter's pins in the element's body through
`fnFlowDeclPathOnlyPinCallSkipping`, which answers only when ONE call pins the slot. Two calls at the
same open list are declined. The rung also binds a type parameter only from an argument whose
parameter is spelled by it alone, so `xs: T[]` handed `[7]` binds nothing.
