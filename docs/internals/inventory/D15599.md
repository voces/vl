#### Mechanism

The hole spelling (`function same(k)`) runs since D15598, whose join gives both parameters one
bundle record. With `same<T>(k: T): T` the check's split (`tyParamSplitRun`) dropped `F`, since
both calls hand a named function of one signature, `<1>($0,)$0`. Each parameter became a hole, the
elaboration's join never saw `mid` as generic (`elabBundleSiblingsUnite`), and mono refused the
generic read. A top-level `same<T>` still splits, and runs that way.
