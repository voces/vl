#### Mechanism

As in [D3797](D3797.md), the hole body's `0` kept `i32`, so the `??` node's pin was the numeric
union `f32 | i32`, where the concrete `??` adopts the literal and stays `f32`. The `HD_COAL`
hole carried no record that its default was such a literal, and no arm of the nullable-value
lowering tested an `f32 | null` element and boxed either side into the union. Defaults that
are not literals (a call, a variable) and an `i64` element under an `f64` default do join
apart; the emitter read their join only through the banking resolver, so the classifiers
took the operand's own atom and the let slot, `print` and arithmetic disagreed with the box.
