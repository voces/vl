#### Mechanism

Not localised past the ablation. The returned literal is adopted by the arm `{ q: i32 }` of `U`,
and the inferred return type is that arm joined with `null`. The function's result is emitted at
the arm's non-null reference while the `return null` path delivers a null reference. When the
arm's field is itself nullable the same program refuses instead, with `ref valtype with no
interned shape`.
