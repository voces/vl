#### Mechanism

The result half of the signature key, `sigRetTokOfTy`, has no rung for a union result:
`retTokOfTy` answers "", so it renders the result with `fnRetEmitName`, `7·2^depth`
characters, and `annRetKindTy` classifies that spelling. A depth-16 `--names` profile puts
the cost under `sigKeyOfTy` → `sigKeyOfTyGo` → `annRetKindTy` → `annUnionSigKind` →
`tyTopLevelSplit` / `tyTopIndexOf`, reached from `cloCallSigKey`. The `A | null` result takes
the same path.
