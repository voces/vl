### D3196 — a record literal whose field is an un-annotated parameter holding a function has no row

**loud emit reject · clause 2 · pre-existing, the same on master `36d233f66` · found by the #3286 round-2 review (`rv3286r2-13226/p2/t1.vl`, `t2.vl`) · filed 2026-09-29 against master `36d233f66`**

Repro:

    function wrap(g) { return { v: 1, f: g } }
    print(wrap(() => 1).f())
    // vl check: rc 0.  vl build: emitProgram: ref valtype with no interned shape

Want:

    1

#### Mechanism

Not localised past the ablation. The literal's `f` field is the hole parameter `g`, which the
instance binds to a function, but the record row the literal needs is not interned for that
binding. The refusal comes from the record's value type, not from the call: reading only
`wrap(() => 1).v` refuses too.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `g: () => i32`, annotated | prints `1` | **yes** (the hole) |
| `function wrap<G>(g: G)`, generic | same refusal | no |
| `print(a.v)` only, no call of `f` | same refusal | no |
| `{ f: g }`, no other field | same refusal | no |
| a second call `wrap(() => "x")` (`t2.vl`) | same refusal | no |
