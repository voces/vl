**loud emit reject · `vl check` rc 0 · clause 2 · found closing D5083 (its matrix's `map_value` and `map_set` cells) · the same on master `4af9eb956` · filed 2026-10-16 against master `4af9eb956`**

#### Mechanism

The map's value type comes from the write `m["k"] = w(true)`, not from an annotation. Narrowing
the read to the `P[]` arm needs that arm's reflist slot, and the map's inferred value union
interns none for it. The annotated map (`Map` typed `{[string]: P[] | i32[]}`) runs. The
`#anon` row is not an ingredient: the declared `P` refuses the same way.
