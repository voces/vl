**closed 2026-10-16 — now prints `7` · was loud emit reject, `vl check` rc 0, clause 2 · two causes, one per record spelling: the map's value slot was named by a structural spelling no union row is keyed on, and the member-set pool's negative memo outlived the row registered after it · pins: `tests/cases/maps/inferred-map-declared-record-list-union-narrowed.vl`, `tests/cases/maps/inferred-map-literal-record-list-union-narrowed.vl` · found closing D5083 (its matrix's `map_value` and `map_set` cells) · filed 2026-10-16 against master `4af9eb956`**

#### Mechanism

The `else` of `is i32[]` pushes the complement narrowing, which asks the member-set pool for the
set of the union the read names. That name is the map's value-slot name, and both record
spellings lost the set there. With the declared `P`, the slot was minted under the structural
rendering `{x:i32}[]|i32[]`, and no union row is keyed on it: the row is `w`'s nominal
`P[]|i32[]`. Now a union slot whose spelling has no row takes the row its arena type resolves to
(`unRowOfCanon`, `mvShapeOfValNameArmTyGo` in `emit_union_atoms.vl`), the name the annotated map
already used. With a literal's record, the row is named `{x:i32}[]|i32[]`, but `msSetOfText` had
banked a miss for that spelling before the row was registered, and no row registration cleared
it; #3936 removed that miss cache (D5119), so a miss always goes through the key. Either way the
complement pushed no type, so the arm had no reflist slot.
