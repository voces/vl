    function useIt(p: () => {f: () => i32}) { print(p().f()) }
    print(0)
    // vl check: rc 0.  vl run: emit error, the refusal above

#### Mechanism

Not traced. The closure type is reached only through the parameter annotation. Its result
record is never built, so the field `f` has no closure slot, and the call `p().f()` is not
recognised as a value call.
