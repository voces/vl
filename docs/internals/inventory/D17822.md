### D17822 — a binding's list of a set's records aliased into an annotated list and called at another signature through a parameter or a `.map` callback is not refused

**open · trap after load · clause 1 · `vl check` rc 0, `wasm trap: indirect call type mismatch` · filed 2026-11-28 against master `d76847374` (lane START-2)**

Repro:

    function id(a) { return a }
    function deliver() { return [{ f: id }] }
    function use(xs) { return xs[0].f(2) }
    const a = deliver()
    const b: { f: (a: f64) => f64 }[] = a
    print(use(a))
    print(b[0].f(2.5))
    // vl check: rc 0.  vl run: prints 2, then traps

#### Mechanism

D17819's refusal reads the calls through the binding's own name: an index, a `for` variable,
a `const` bound to an element, a field or the list. A call through a parameter the list is passed
to, or through a `.map` callback's parameter, reaches the same storage unread.

#### Ablation

| spelling | outcome |
| --- | --- |
| this repro (through a parameter) | trap after load |
| `a.map((r) => r.f(2))` | invalid wasm on master; loud emit reject on #10750 |
| `a[0].f(2)` directly | loud check reject (D17819) |
