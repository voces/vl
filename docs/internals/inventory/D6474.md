### D6474 — a capturing hole lambda in a generic body, called first at another type, put into an un-annotated list is check-clean invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · found closing [D3934](D3934.md), whose annotated-list spelling runs · filed 2026-10-18 against master `e4dc869e5`**

Repro:

    function outer2<T>(x: T, y: T) {
      let v = x
      const h = (u) => { print(v); print(u) }
      h("s")
      const fs = [h]
      v = y
      fs[0](3)
    }
    outer2(7, 8)
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `outer2`: type mismatch: expected structref, found i32

Want:

    7
    s
    8
    3

#### Mechanism

From the ablation only. The un-annotated list's element type is inferred from `h`, whose hole
the first call `h("s")` bound to `string`, while the later call `fs[0](3)` passes an `i32`; the
element is read with one signature and called with the other. The annotated list
`((n: i32) => void)[]` runs ([D3934](D3934.md)).
