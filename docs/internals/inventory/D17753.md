### D17753 — a bound list of one generic function delivered as the element of a `(readonly F[])[]` literal is stored as the closure list, not the converted copy

**check-clean invalid wasm · clause 1 · `vl check` rc 0 · `type mismatch: expected (ref $11), found (ref $8)` (`list of i32-represented elements` vs `((i32)=>i32)[]`) · 2 cells: `fn-set-list-converting-copy` and `fn-set-list-converting-copy-generic`, `array_element`, annotated · filed 2026-11-27 against master `2f420604f` by I8-PREP (sibling sweep of the closure matrices)**

Repro:

    function __id<T>(x: T): T { return x }
    const __zs = [__id]
    const xs: (readonly ((x: i32) => i32)[])[] = [__zs]
    print(xs[0][0](41) * 2)
    // vl check: rc 0.  vl run: the emitted module failed to validate

Want:

    82

#### Mechanism

Not traced: the outer literal's element is the bound list `__zs` as built for the lone generic
member, but the slot wants the copy a `readonly` element type converts it to; the copy is not made
at this position.
