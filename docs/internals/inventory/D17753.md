### D17753 — a bound list of one generic function delivered as the element of a `(readonly F[])[]` literal is stored as the closure list, not the converted copy

**closed 2026-11-27 by lane START-2 — the witness prints `82` · the bound list's literal was already built at the readonly closure list its delivery wants (its rep stamp), yet `fvaListSetCopy` also rewrote the read into a `.map` copy over its old id-list type, storing a closure list into an id-list slot; the copy is now made only where the value is not already built at the destination (`fvaListBuiltAt`) · fixture `tests/cases/closures/fn-list-read-once-as-readonly-list-element-built-there.vl` · was: check-clean invalid wasm · clause 1 · filed 2026-11-27 against master `2f420604f` by I8-PREP**

    function __id<T>(x: T): T { return x }

#### Mechanism

Two build decisions for one value: `__zs`'s literal is stamped at the readonly closure list its
one delivery wants (`letBindTy` through `litRepTyAt`), and the checker's converting copy
(`fvaListSetCopy`) still copied the read from its old id-list type. A second read of `__zs` broke
the stamp and so ran. The copy is now skipped wherever the value is already built at the
destination's list.
