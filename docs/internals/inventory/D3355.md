### D3355 — a binding initialized by a `null`-typed join with an exiting arm was annotated `null` and classified by the arm that exits, not by its null hole

**closed · fixture `tests/cases/loops/exit-arm-null-join-binding.vl` · was a loud emit reject (`only i32 locals are supported`, `bare null needs a struct-typed context`) · all 280 cells of the #3293 review grid `h5`'s value family `nul` · filed 2026-09-30 against master `455e553ca`, closed against `4ff12b994`**

Repro:

    function h(n: i32): i32 {
      const y = if n == 4 { return -7 } else { null }
      (y) ?? -1
    }
    print(h(4))
    print(h(2))
    // was: vl check rc 0, then emitProgram: only i32 locals are supported

Want:

    -7
    -1

#### Mechanism

The checker types the join `null` (the exiting arm adds nothing, D3222) and records the binding
as a null hole, exactly as for `const y = null`: a later write fills it with `T | null`, and a
hole nothing fills is the `null` type (D1576). The emitter did not read that record. For a
first arm that exits, `exitFirstLetsAnnotate` wrote the join's own type, `null`, as the
binding's annotation, which no local represents and which is wrong once a write fills the hole;
for any other arm order, `exprIsNulNone` required every arm to be `null` and read the exiting
arm's `never` tail as a value, so the binding took no rep. The annotation now comes from the
hole (the filled `T | null`, or none when unfilled, which is the bare-`null` binding's rep), a
filled hole whose initializer is any construct but a bare `null` is annotated the same way
(`noteFilledJoinLet`), and a `never` arm tail counts as adding nothing (`armIsNulNone`).

Closing it exposed a second defect on the same path, already live on master for a join of two
`null` arms: a `null`-typed binding lowered as `ref.null none` without evaluating its
initializer, so `const y = if c { print("t") null } else { null }` printed nothing, and an
exiting arm never exited. The local and the module-scope binding now evaluate the initializer
for its effects (`emitNulNoneBoxPayload`), as the union-box boundary already did.

A filled hole of a reference type (a record, list, named record or map) then declared a
`ref null` cell while the `if` initializer still lowered at blocktype `i32`, invalid wasm that
the annotated spelling (`let w: A | null = if … { null } else { null }`) builds on master too.
An if-expression whose every arm ends in `null` or exits (`ifChainOnlyNullValues`) now lowers
as the all-`null` join does: its arms for effect, then the destination's own `null`. Arms with a
prelude reached one more gap, also live on master: the string-op frame scan read an `else if`
link as a block and found nothing, so `print("m")` in such an arm used unallocated locals.
