### D1933 — a closure that captures a FIELD-sourced nullable, inside a block, then narrowed, is check-clean invalid wasm: `emitProgram: ref valtype with no interned shape`

**closed 2026-09-08 — the witness prints `3` · was loud emit reject (`ref valtype with no interned shape`), `vl check` rc 0, clause 2 · found by the day-one sampler's narrow×pin records, as a BOTH-FAIL where the pin is scenery (the defect is the closure capture, not the pin) · fix in `captureValStructIdx` (`compiler/emit_classify.vl`); fixture `tests/cases/closures/capture-block-nullable-field-source.vl`**

Repro:

    type Rec = { name: string, n: i32 }
    type MaybeRec = Rec | null
    function mkval(): MaybeRec { return { name: "ada", n: 3 } }
    if true {
      const srcBox = { it: mkval() }
      const held = srcBox.it
      const get = () => held
      const v = get()
      if v != null { print(v.n) } else { print(0) }
    }
    // vl check: rc 0.  vl run: emitProgram: ref valtype with no interned shape

#### Mechanism

The captured value `held` is a `Rec | null` read from a struct FIELD (`srcBox.it`), closed
over by `get`, and the closure's environment shape is minted without an interned shape for the
nullable ref valtype it holds. `vl check` returns 0; the emitter then has no shape to name for
the capture and refuses. It is a four-way cross — all four ingredients are needed, and any one
removed makes it run — which is why no single-feature fixture reached it and the day-one
sampler did.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `if true` block (hoist to module top) | runs, prints `3` | **yes** |
| the field source (`const held = mkval()` directly) | runs, prints `3` | **yes** |
| the closure (`const v = srcBox.it` directly) | runs, prints `3` | **yes** |
| the null narrowing (`(v ?? …).n` instead of `if != null`) | runs, prints `3` | **yes** |
| the value is nullable (a non-null `Rec` throughout) | runs, prints `3` | **yes** |

#### Grading list

The five ablation rows all RUN and must keep running — each is a control that isolates one
ingredient. The non-null twin (`type Rec`, no `| null`, same block+field+closure) runs and is
the sharpest control: it is the nullable ref valtype specifically that has no interned shape.
A fix is a shape interned for the closure's captured nullable ref; grade it by this witness
reaching `runs` while the five controls stay `runs`.

#### Fix

`captureValStructIdx` (`compiler/emit_classify.vl`) classified this cell `nulstruct` through
`letInitProjKind` but had no slot arm for it — a kind with a -1 slot, the `ref valtype with no
interned shape` refusal. The added arm resolves the inner row from the read's recorded
`S | null` type (`nulStructRowOfNodeTy`), the nullable twin of the `letInitTyIsStruct` rung
beside it. The five ablation controls run only in isolation: combining the witness with a
non-null (or generic-pinned) field-source capture of a sibling shape in one module surfaces a
distinct check-clean-invalid-wasm defect this fix newly reaches — filed as D1935.
