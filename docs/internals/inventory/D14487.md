### D14487 — the instance re-check records a type for non-literal nodes that the emitter does not build them at

**closed 2026-10-27 · runs, prints `9` · was a refutation pin (check-clean invalid wasm once `nodeTyAt` read the instance record for every node) · filed 2026-10-27 against master `dd2fe6ba3` · fixed at the instance re-check: `as?` to a number over an operand the template saw open is `N | null`, as at every pin (`checkCastNode`, check_operators.vl), an `is` test at an instance narrows by the instance's own elaborated types, and the emitter's shared-field read takes the instance type (`memReadCheckerAtomKind`, emit_union_casts.vl); `nodeTyAt` now reads the record for every recorded node, and `elabRetypedLit` is deleted · pins: `tests/cases/generics/instance-recheck-agrees-with-template.vl` and the six modules below**

Repro:

    function k<T>(u: T) {
      const v = u as? i32
      print(v)
    }
    k(9)

Want:

    9

#### Mechanism

The instance re-check (`elabOne`, `emit_elab.vl`) banks a type for every node under each
instance key (`elabNodeTys`). The emitter builds most closed nodes from the template's own
facts (its checker type, rep and local slot). Today `nodeTyAt` reads the instance record only
where the checker type is open, or for a number literal some instance retyped
(`elabRetypedLit`), so the two producers never meet. Reading the record for every node makes
them meet, and six `tests/cases` modules then fail validation (rc 0 → 70), e.g. `type mismatch:
expected i32, found (ref $type)` inside `k`. A probe noted every node whose record differs from
its closed checker type. The disagreements fall into three kinds:

* **`as?` over a type parameter, bound to a local.** The template checks `u as? i32` as
  `i32 | null`. The instance records `i32` at `T = i32`, and `<error>` at `T = string` (its
  `LetDecl` gets `void`). The disagreeing nodes are the `AsExpr`, its `LetDecl` and every `Ident`
  read of the binding. The slot is built as the `i32 | null` box and the init is then read as a
  bare `i32`. Files: generics/as-opt-over-type-parameter, numerics/as-opt-over-hole,
  generics/gradual-type-parameter-union (`const q = r as? i32`).
* **A `??` over a cast that can never convert.** At `T = string`, the record for
  `(x as? f64) ?? 99` is `<error>` on the `BinExpr`, the `AsExpr` and the `Paren`, while the
  template is `f64` / `f64 | null`. File: generics/coalesce-cast-returned-from-instance.
* **Record arms that share a field name, over a generic.** An `Ident` narrowed to arm `B` is
  recorded as `A`, and the `Member` read `u.f` is recorded `i32` where the template is
  `string`. Files: unions/record-arms-same-field-over-generic,
  unions/record-arms-same-field-over-param-unann.

The same general read also changed bytes in generics/coalesce-cast-int-default-returns-box
(589 → 567) and literal-unions/coalesce-hole-call-litunion-join.

#### Ablation

Run under a compiler whose `nodeTyAt` always consults the instance record:

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the binding (`print(u as? i32)`) | runs, though the `AsExpr` is still recorded `i32` | **yes** |
| inference at the call (`k<i32>(9)`) | still invalid | no |
| the type parameter (`function k(u)`, a hole) | still invalid | no |
| an `i32` argument (`k("s")`; record is `<error>`) | still invalid | no |
| the `null` test (`v ?? -1` in place of `if v == null`) | still invalid | no |

#### Grading list

The six modules above, and the `k("s")` spelling of the witness (prints `null`). A close
makes the instance record and the emitter's build one producer: the record agrees with what
the slot, rep and box are built as, or the emitter builds from the record. After that,
`nodeTyAt` can drop its literal-only condition.

The instance narrows by its own elaborated types, cross-tag test (D4056) included, so the
emitter's cross-tag guard in `memNarrowVariantIndex` (emit_local_scope.vl) is deleted. The
shared-field read reads the field's type through `nodeTyAt` at the instance, like the boxed read
beside it.
