#### Mechanism

`unit`'s `fallback` is returned unchanged, so it is a field use only inside `unit`'s RESULT
twin, where the exit hands back fields (`fo_param_r`). The step decided which locals to hold
as fields against the plain field-only set (`fo_param`), so `pf`, passed as a fallback, was
kept, and the first `unit` call returned a struct for it. A local's get is now also a field
use when it is an argument the result twin takes as fields at a call whose own result is
held as fields (read by a `struct.get`, or set into a field-only local), because that call
always calls the result twin. The result-twin set is now computed before the locals, which
it depends on only through the plain set.
