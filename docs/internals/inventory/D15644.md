### D15644 — a choice of named functions returning `boolean`, in a record literal handed to a hole callee, interns no signature

**loud emit reject · clause 2 · `emitProgram: a function-value call has no interned signature — no function value of type …` · found closing D15642 · filed 2026-11-10 against master `4e03e7db`**

Repro:

    function pos(v) { return v > 0 }
    function big(v) { return v > 1 }
    function callP(r, x) { print(r.f(x)) }
    function run(b) {
      const g = if b { pos } else { big }
      callP({ f: g }, 3)
      callP({ f: g }, 2.5)
    }
    run(false)

Want:

    true
    true

#### Mechanism

Unmeasured. The numeric spelling (`id`/`dbl` returning their argument) dispatches by tag
(D15641); with a `boolean` result the field call finds no closure of its signature, so the set
is not tagged there.

| spelling | outcome | needed? |
| --- | --- | --- |

| `const g = pos` (one member) | runs, `true` `true` | **yes** |
| `callP({ f: g }, 3.5)` for the `3` call (one type) | still refuses | no |
