### D15644 — a choice of named functions returning `boolean`, in a record literal handed to a hole callee, interns no signature

**closed 2026-11-10, runs and prints `true` `true` · was loud emit reject, clause 2, `emitProgram: a function-value call has no interned signature — no function value of type …` · found closing D15642 · filed 2026-11-10 against master `4e03e7db` · closed in the elaboration: a call through a record field of a parameter bound to a record holding a set of hole functions mints each member's instance at the call's argument types where none exists yet (`elabMintParamRowFactAt`, emit_elab.vl), as it already did for a lambda, so the fact is noted, the late decision tags the set and the call dispatches by tag · `callP`'s instances test the id and call each member's instance directly in the repro's `--names` build, no `call_indirect` · fixture `functions/set-of-boolean-fns-in-record-handed-to-hole-callee.vl`**

Repro:

    function pos(v) { return v > 0 }
    function big(v) { return v > 1 }
    function callP(r, x) { print(r.f(x)) }
    function run(b) {
      const g = if b { pos } else { big }
      callP({ f: g }, 3)
      callP({ f: g }, 2.5)
    }
    run(false)

Want:

    true
    true

#### Mechanism

Before the close: the numeric spelling (`id`/`dbl` returning their argument) dispatches by tag
(D15641); with a `boolean` result the field call finds no closure of its signature, so the set
is not tagged there.

Measured at the close: `elabMintParamRowFactAt` found no instance of the member at the field
call's argument types (no direct call reaches `(f64)`), so it noted no fact and the set stayed
a closure; the numeric spelling had such an instance from another route.
