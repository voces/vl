### D4300 — a `let` rewritten with a generic whose parameter is concrete or nullable, then called at an argument that only fits by widening, calls the wrong instance

**closed 2026-10-25 by lane L6 (#4739) · runs, prints `W`, `1`, `true` · was loud emit reject, clause 2 · pin: `tests/cases/closures/reassigned-let-generic-called-at-widened-argument.vl` · earlier still clause 1 (an indirect call type mismatch at run time) until lane SC held a written `let` at the join of the pins its value flows to (fn-value-flow §(f) step 3), which this call's widened argument is not · found by the function-value flow table in shadow mode (fn-value-flow-design.md §(f) step 1) over the review witnesses (`rv3508/r3`: t02, t03, t06, t08, t10, t11; each `t*_ctl_direct` runs) · filed 2026-10-13 against master `aa43e52ef` with #3542 applied**

Repro:

    type P = { x: i32 }
    function s<A, B>(a: A, b: B) { print("S") }
    function w<B>(a: P, b: B) { print("W"); print(a.x); print(b) }
    function main() {
      let k = s
      k = w
      k({ x: 1, y: 2 }, true)
    }
    main()
    // vl check: rc 0.  vl run: the reassigned function binding `k` holds functions called at more than one argument type

Want:

    W
    1
    true

#### Mechanism

The call through `k` is checked against `w` with the argument widened into `P`, but the
instance written into `k` is chosen from the argument's own spelling, so the table's
`indirect call` names a signature the written function does not have. The flow table grades
t03 `disagree: instance fits no pin | binding` and the other five `undecided: a stub | write`.

#### Fix

L6's shape walk (`shapeWalkName`, `emit_shape_intern.vl`) keys each shape it interns by the
type's nominal name. Ablated on #4739, that change alone moves the row: the PR without it keeps
the filed refusal, and the field-reader moves and the memo stamp do not move it. The path from
the walk to the binding's single closure signature was not traced. The pin adds a second call at an argument that fits `P` exactly. The five `rv3508/r3`
siblings were not re-graded.
