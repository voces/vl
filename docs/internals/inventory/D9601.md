### D9601 — a returned list of un-annotated functions from two calls at two parameter types, read by `.map` at two types, has no list type

**closed 2026-10-22 by lane-D9553 · runs, prints `6` `2.5` · was loud emit reject, `index access but list type not collected`, `vl check` rc 0 · clause 2 · closed by closing a generic callee's result after the call takes its instance rather than before, and by reading an un-annotated instance's result from the returned list literal its own copy of the body instanced (`monoWalk`, `monoInstRetLitTy` from `monoCallInstRetTy`, emit_mono.vl) · fixture `closures/hole-fn-list-returned-read-at-two-types.vl` · with [D9553](D9553.md) and [D9602](D9602.md) · found closing [D9550](D9550.md) · filed 2026-10-22 against master `8789642ad`**

Repro:

    function inc(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function deliver(n) { return [inc, dbl] }
    const v = deliver(1)
    print(v.map((f) => f(3))[1])
    const w = deliver("s")
    print(w.map((f) => f(1.5))[0])
    // vl check rc 0.  vl run: emit error: emitProgram: index access but list type not collected

Want:

    6
    2.5

#### Mechanism

Traced. `deliver` takes two instances, one per parameter type, and each instance's own copy
of the returned literal is instanced at its own element type. The call's result was closed
(`monoCloseRetFnTy`) before the walk gave the call its instance. The callee's name then still
resolved to the first instance, which has no return annotation, so the read fell back to the
template's literal, already closed at the first pin, and recorded the second call at
`(i32) => i32`. The earlier "template frame's slot" reading was a probe of that fallback.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the second parameter type (`deliver(2)`) | runs, `6` `2.5` | **yes** |
| the second `.map` (`print(w[0](1.5))`) | runs, `6` `2.5` | **yes** |
| the first `.map` (`print(v[1](3))`) | same refusal | no |
| both bindings, inline (`deliver(1).map(...)`, `deliver("s").map(...)`) | same refusal | no |

#### Grading list

The inline spelling in either order refuses the same way; with `.length` after the second
`.map` it refuses with `a list of this element kind is read where no such list was built`.
