Repro:

    function add(a, b) { return a + b }
    function apply3(g, s) {
      print(g(10, 20))
      print(g(s, "x"))
    }
    function inner(k, h) {
      apply3(h, k)
    }
    inner(0.5, add)
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `add`: type mismatch: expected (ref $2), found f64; $2 is `string`

Want: a check reject at `inner(0.5, add)`, as the direct spelling refuses:

    error: operator '+' is not defined for f64 and string

#### Mechanism

Measured. The demand `g(s, "x")` moves out to `inner`'s hole `h` as two argument demands, one
per parameter, with no record of the call they came from. With no call to group them,
`judgeFnArgHoleCalls` formed no instance from them at `inner(0.5, add)`, so `add`'s body was
never judged at `(f64, string)`, and the emitter built that instance unchecked.
