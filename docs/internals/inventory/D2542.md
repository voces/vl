### D2542 — inside a generic body, a member call's checked type comes from the same-named self-function while the emitted call is the field, and the two disagree when their return types differ

**check-clean invalid wasm · clause 1 · found while reviewing [D2517](D2517.md) (#3166) · filed 2026-09-25 against master `a09d1f6bc`**

Repro:

    type T = { tag: () => i32 }
    function tag(self: T | string): string { "s" }
    function f<A>(x: A) { print(x.tag() + "!") }
    f<T>({ tag: () => 5 })
    // vl check: rc 0.  vl run: invalid module inside `f`, type mismatch: expected (ref $type),
    // found i32

#### Mechanism

Inside the generic body `x.tag()` is checked before `A` is known to be `T`, so the checker types
it from the only signature it can see: the module-level `tag(self: T | string): string`. That
makes `x.tag() + "!"` a `string + string`, which the surrounding `+` lowers to a ref-typed
concat. At the `f<T>` instance, D2517's per-instance pick (`monoPinBinOps`) correctly prefers
`T`'s own field `tag: () => i32` over the self-function — but nothing re-checks the surrounding
expression against that choice, so the `+` still emits its ref-typed concat over a raw `i32`.
The bug is the disagreement itself, not either resolution alone: the checker's generic-body
typing and the per-instance emit pick are two deciders that do not compare notes when the two
candidates' return types differ.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the generic (`function f(x: T)`, `x` typed as `T` directly) | loud check reject, `+` not defined for `i32` and `string` — correctly caught | **yes** — the deferred generic-body typing is the ingredient |
| the return-type mismatch (field and function both `i32`, `x.tag() + 1`) | runs, prints `6` | **yes** |
| the return-type mismatch (field and function both `string`) | runs, prints `hi!` | **yes** |
| the operator context (`print(x.tag())` alone, no `+`) | runs, prints `5` — the field correctly wins | no — the trigger needs a wasm shape fixed ahead of the pick |

#### Grading list

Any binary operator or other ref-shape-fixing context wrapped around a generic body's member
call whose field and same-named self-function disagree in return type — string concatenation
is one instance, not the only one.
