### D16970 — `is K[]` over a box union's `u8[]` or `i64[]` arm answers by tag, so a fitting or empty arm reads false

**awaiting owner ruling: a non-empty arm in a disjoint rep, tested by tag or by elements · runs today and must keep running, prints `0` until the ruling · the 2026-11-15 refinement of D16047 (DECISIONS.md, in "`is` over a list tests every element") reads "an arm whose element type is fixed is tested by its tag alone", in a sentence about the empty case, and rules the empty case explicitly; no sentence rules the non-empty one, where a `u8[]` or `i64[]` arm's elements can be `K`'s members · only a list of `i32` literals shares the `i32` list's storage, so only that arm is read by its elements (D16894) · related to [D4771](D4771.md) and [D4915](D4915.md) · found measuring D16966's neighbours · filed 2026-11-18 against master `1d067b11e` by lane F1**

Repro:

    type K = 1 | 2
    const a: u8[] = [1, 2]
    const q: u8[] | K[] = a
    if q is K[] { print(1) } else { print(0) }

Want:

    0

#### Mechanism

D4771 rules that `is` over a list fits when every element does, so an empty list fits every list
type, and D4915 extends that to a box union's arm in a disjoint rep, tested by its length. The
`u8[]` and `i64[]` arms are neither D4779's string arm nor one sharing `K[]`'s tag, yet their
elements can be `K`'s members, so they are not the "elements never fit" arm D4915 tests by length:
the test answers by tag alone and reads false for `[1, 2]`, for `[]` and for an `i64[]` `[1]`.

| `i64[] \| K[]`, `a: i64[] = [1]` | prints `0` | no: the `i64[]` arm alike |
| `a: K[] = [1]` held in the union | prints `1` (right) | **yes** (the value in the other arm) |
| `string[] \| K[]`, `["1"]` | prints `0` (right: D4779 tests the strings) | **yes** (an arm whose elements can fit) |
