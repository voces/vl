### D15274 — a second function's returned record holding the same member, its field called directly beside a widened binding, is refused

**open · loud emit reject · `emitProgram: cannot take the generic function id0 as a value — a function value carries ONE signature` · clause 2 · the read spelling runs · either binding alone runs · found grading D15273 · filed 2026-11-04 against `lane/g2-d15273` with D15273**

Repro:

    function id0(a) { return a }
    function id1(a) { return a }
    function mk() { return { f: id1 } }
    function mk2() { return { f: id1 } }
    const r = mk()
    r.f = id0
    const s = mk2()
    print(r.f(2))
    print(r.f(2.5))
    print(s.f(7))

Want:

    2
    2.5
    7

#### Mechanism

`mk2`'s literal is not `mk`'s, so D15273's sibling join does not reach `s`. Its field call
adopts `mk2`'s literal at the call's closed row, and that literal holds `id1`, a member of the
smaller set `r`'s widened set is decided with, so that set fails its scan.

| --- | --- | --- |

| `s` | runs | **yes** |
| `s` from `mk()` (D15273) | runs | **yes** (the second function) |
