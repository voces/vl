### D17283 — an unbounded generic reading a literal-set field its layout family stores as a string, at the literal set, emits an i32 where the string is

**check-clean invalid wasm · clause 1 · found by IR-V3 verifying #9970, filed by lane IR-N8 · filed 2026-11-24 against master `8695362aa`, the same with and without the IR's claims**

Repro:

    type K = "circle" | "round"
    type A = { kind: K, r: i32 }
    type B = { kind: string, r: i32 }
    function mk(n: i32): A | B {
      if n == 0 { return { kind: "round", r: 1 } }
      return { kind: "zz", r: 2 }
    }
    function kindOf<T>(x: T): K { return x.kind }
    const a: A = { kind: "circle", r: 1 }
    print(kindOf(a))
    print(mk(1).r)
    // vl check: rc 0.  vl run: invalid module, inside `kindOf`: type mismatch: expected i32,
    // found (ref $0); $0 is `string`

Want:

    circle
    2

#### Mechanism

Not traced. `B` beside `A` in `A | B` makes the layout family store `A.kind` as the string
(D14752). The `T = A` instance reads that string off `x` and returns it where its result, the
literal set, is held as the atom's `i32`. The ablation fixes the ingredients.

| the result at `string`: `kindOf<T>(x: T): string` | runs | **yes** |
