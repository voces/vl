### D6730 — a lambda in a module-scope block captures a local bound from a narrowed binding at the binding's un-narrowed type

**closed 2026-10-18 by lane L6 · runs, prints `3` · was check-clean invalid wasm · `vl check` rc 0 · clause 1 · a capture env field of a module-block binding asks the binding in scope at the read whether it holds the niche, and a copy of a narrowed binding with no syntactic row takes the struct row the checker recorded for it; the `i32 | null` spelling prints `3` too ([D6771](D6771.md)), and two sibling blocks binding one name each keep their own type · pins: `tests/cases/closures/capture-narrowed-copy-in-module-block.vl` · found grading D6690 · filed 2026-10-18 against master `73713bacf`**

Repro:

    function q(): { n: i32 } | null { return { n: 3 } }
    if true {
      const mw = q()
      if mw != null {
        const v = mw
        const g = () => v
        print(g().n)
      }
    }
    // vl check: rc 0.  vl run: invalid module, expected (ref $0), found (ref null $0)

Want:

    3

#### Mechanism

The closure's env field for `v` is typed from `v`'s declared type, which is the un-narrowed
`{ n: i32 } | null` of `mw`, while the body reads it as the narrowed `{ n: i32 }`. Only a
block-local at module scope is affected: the same program inside a function frame runs.

#### Ablation

| variant | outcome |
| --- | --- |
| as filed | invalid module |
| `let v = mw` | invalid module |
| `const v: { n: i32 } = mw` | invalid module |
| no `if true` wrapper (the binding is a module global) | runs, prints `3` |
| the same body inside `function main()` | runs, prints `3` |
| `const g = () => mw` (capture the narrowed binding itself) | runs, prints `3` |
| `print(v.n)`, no lambda | runs, prints `3` |
| `i32 \| null` in place of the record | loud emit reject, `print of a union value whose arms the tag dispatch cannot classify` |
