### D7041 — a generic `(T | L)[]` bound at a second literal-union alias is not the list of the joined literal set

**closed · was a loud check reject · clause 2 · found by lane L6 step 3's ablations · the same on master `6ca1ebc5c` · filed 2026-10-19 against master `6ca1ebc5c` · closed 2026-10-20 by lane L1**

Repro:

    type K = "a" | "b"
    type L = "x" | "y"
    function l<T>(x: T, o: L): (T | L)[] { return [x, o] }
    const a: K = "a"
    const w: (K | L)[] = l(a, "y")
    print(w[1])
    // master: (K | L)[] is not ("a" | "b" | "x" | "y")[]: a container never widens implicitly

Want:

    y

#### Mechanism

The annotation `(K | L)[]` resolves to the flat literal set `("a" | "b" | "x" | "y")[]`. The
instance's return `(T | L)[]` at `T := K` kept the two aliases as members, and the relation
read them as two element reps although both hold one literal atom; the refusal fired in
`shapeAdapterless` (check_fit_rules.vl). The defect was upstream: `substTyDeep` →
`substUnionRebuild` (check_relate_core.vl) rebuilt `T | L` as a union of two aliases. Closed
there: when every kept member is a literal set (`litUnionFlatMembers`), the rebuild joins them
through `annUnionInnerTy`, the route an annotation takes, so the instance's element is the flat
set. A member that is not a literal set, `T := string` for one, keeps the union, so no boxed
member set is deduplicated. The numeric face was invalid wasm on master and is [D8200](D8200.md).
The matrices `generic-litunion-set-list` and its open-parameter twin
`generic-litunion-set-list-open` each go from 0 to 64 of 64 cells running (master: 5 silent,
34 check refuses and 25 emit refuses in each).
