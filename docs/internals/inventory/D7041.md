### D7041 — a generic `(T | L)[]` bound at a second literal-union alias is not the list of the joined literal set

**loud check reject · clause 2 · found by lane L6 step 3's ablations · the same on master `6ca1ebc5c` · filed 2026-10-19 against master `6ca1ebc5c`**

Repro:

    type K = "a" | "b"
    type L = "x" | "y"
    function l<T>(x: T, o: L): (T | L)[] { return [x, o] }
    const a: K = "a"
    const w: (K | L)[] = l(a, "y")
    print(w[1])
    // vl check: (K | L)[] is not ("a" | "b" | "x" | "y")[]: a container never widens implicitly

Want:

    y

#### Mechanism

The annotation `(K | L)[]` resolves to the flat literal set `("a" | "b" | "x" | "y")[]`. The
instance's return `(T | L)[]` at `T := K` keeps the two aliases as members. The relation compares
the two lists element type by element type, and it reads them as two element reps although both
hold one literal atom. The refusal fires in the checker's `shapeAdapterless` element-pair
check (check_fit_rules.vl), but the defect is upstream of it: `substTyDeep` →
`substUnionRebuild` (check_relate_core.vl) rebuilds `T | L` at `T := K` as a union of two
aliases rather than flattening it to one literal set, so `tyIsLitUnion` is false for the
instance's element. A prototype flatten there made both faces run (lane L6, 2026-10-20); that
file is outside lane L6, so the row stays open for its owner. D7040's close does not move it.
The non-generic spelling, `const x: (K | L)[]` assigned to `(L | K)[]`, runs.
The un-annotated spelling, `const w = l(a, "y")`, is refused at emit instead, with `index receiver
is not an array or string`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the type parameter (a `(K \| L)[]` binding) | runs | **yes** |
| the second literal union (`(T \| i32)[]` at `T := K`) | runs | **yes** |
| the annotation on `w` | emit refuses | no, the refusal moves |
| the argument's annotation (`l<K>("a", "y")`) | still refuses | no |

#### Grading list

The un-annotated face (`const w = l(a, "y")`) must run, not only the annotated one. Re-grade it
with `T := K | null` too (`const w: (L | K | null)[]`), which runs since lane L6 step 3.
