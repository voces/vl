### D10295 — a recursive generic returning its `T | null` parameter's join with an `f64` has no lowering

**closed · runs, prints `7` · was loud check reject, clause 2 · found closing [D10280](D10280.md) · present on master `d5ec7f160`, where the build refused instead (`narrowed union atom has no value box`) · filed 2026-10-22 against master `d5ec7f160` · closed on the merged tree by D10240's change ([D10243](D10243.md)): a call returning the callee's declared `T | X` is no longer flagged as an escaped join (`joinOpensOnlyDeclared`), so the recursive generic's `i32 | f64` return, joined apart at the pin since D10280, is inferred rather than refused**

Repro:

    function g<T>(q: T | null, d: f64, n: i32) {
      if n > 0 { return g(q, d, n - 1) }
      if q != null { q } else { d }
    }
    const a: i32 | null = 7
    const v = g(a, 1.5, 2)
    print(v)
    // vl check: the returns of `g` join to i32 | f64 for this argument — type-valid, but an inferred union return through an un-annotated parameter is not yet supported by codegen; annotate the return type

Want:

    7

#### Mechanism

With the self-call no longer gating `g` (D10280), the pin joins the tail `if` apart as
`i32 | f64`, and an inferred union return through a recursive generic is refused by the checker's
return-inference arm. On master the gate widened the checker's view while the emitter's pin did
not, and the build refused at emit instead. Both refuse a type-valid program.
