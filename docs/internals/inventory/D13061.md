#### Mechanism

The literal is not the ingredient: the body `const l = [[x]]; return l` refused the same way.
Leaving the result un-annotated (`function mk<T>(x: T) { [[x]] }`) ran, so the instance built
the value. The instance's result annotation is synthesized from `monoSubstAnn("T[][]")`, whose
`[]`-run arm substituted the leaf `T` to `i32|null` and appended `[][]` bare: `i32|null[][]`.
That spelling is a union of `i32` and `null[][]`, so no array rung of `collectATypeRef` claims
it and `checkArrName` refuses. `T[]` took the leaf arm's grouped `arrElemSuffixed` already,
and a record leaf needs no group, which is why both ran. [D13060](D13060.md)'s `T[][]`
parameter had the same misspelling.
