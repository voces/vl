### D15175 — an un-annotated function popped off a list handed to a hole parameter is called through a closure built at another signature

**trap after load · `vl check` rc 0, `wasm trap: indirect call type mismatch` · clause 1 · open, target `6` · found planning [D15174](D15174.md) · filed 2026-11-03 against master `1cce3e60a`**

Repro:

    function half(a) { return a * 2 }
    const m = [half]
    run(m)
    function run(m) {
      const g = m.pop()
      if g != null { print(g(3)) }
    }
    // Want: 6

#### Mechanism

The member's instance at the call's argument types, and the call's dispatch, are built only for
reads the function-set machinery follows: an index chain off the parameter (`elabMintFactAt` via
`elabSlotRoot`). A value a nullable read returns (`pop`, `get`), narrowed and called, is not
followed, so the call takes a generic closure path whose closure was built at another signature,
and the indirect call traps. [D15176](D15176.md) is the same read at module scope, which refuses
loudly instead.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the member's annotation (`half(a: i32)`) | runs, `6` | **yes** |
| the hole parameter (read at module scope) | loud emit reject, [D15176](D15176.md) | **yes** |
| `pop`, read by `m[0]` instead | runs, `6` | **yes** |
| the function declared after its call | still traps | no |
