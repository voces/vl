### D3978 — a call through an element of a list the D3977 pin does not follow leaves the generic unconstrained, and a later delivery sets it

**loud emit reject · `vl check` rc 0 · clause 2 · OPEN · in [D4240](D4240.md)'s family since lane SC (2026-10-12) pinned a list holding a written `let` at its element calls: `r` is then called at `i32` by the list and at `boolean` by the delivery, which one binding cannot hold · until then a silently wrong value, clause 1 · found in review of #3505 (`rv3505/r5/f01`, `f02`, `f07`; `r6/p01`, `p02`) · filed 2026-10-10 against master `e5128703a` · pins: `tests/cases/closures/error-written-let-in-list-called-at-another-type.vl`, `tests/cases/closures/list-of-written-let-of-generics-called-through-element.vl`**

Repro:

    function inner<U>(u: U) { print("I"); print(u) }
    function other<V>(v: V) { print("O"); print(v) }
    function cb(f: (b: boolean) => void, b: boolean) { f(b) }
    function main() {
      let r = inner
      const fs = [r]
      fs[0](3)
      r = other
      cb(r, true)
    }
    main()
    // vl check: rc 0.  vl run: the reassigned function binding `r` holds functions called at more than one argument type (master f6ee50929: prints I true O true)

Want:

    I
    3
    O
    true

#### Mechanism

Not located. The family is every list the D3977 pin declines to follow and leaves on master's
path: one whose element is a written `let` (the witness), one with a concrete element ahead of the
generic (`p01`, whose recorded element type is concrete), and one read by something other than an
element call (`p02`). D3977's list pin follows only elements that name a generic by name or through
never-written aliases; `r` is written after the list reads it (`r = other`), so the list keeps the
generic's unpinned value, the element call pins nothing, and the delivery `cb(r, true)` instances
`inner` at `boolean` for the list's element too. Pinning the list at its element calls would be
wrong for the same reason in the other direction once `r` is written before the list reads it
(`rv3505/r5/g04`), which is refused.
