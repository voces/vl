### D7100 — a `let` copy of a type-parameter parameter stored in a record literal gets no struct type at its instance

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same copy bound with `const` runs, `3`, and so does `{f: a}` from the parameter directly · found closing [D6883](D6883.md) · the same on master `6ca1ebc5c` · filed 2026-10-19 against master `6ca1ebc5c`**

Repro:

    function mid<H>(a: H) {
      let b: H = a
      const r = {f: b}
      print(r.f)
    }
    mid(3)
    // vl check: rc 0.  vl run: emitProgram: object literal but no struct type declared

Want:

    3

#### Mechanism

From the ablation only. No function value is involved. A record literal whose field is a
`let` binding seeded from a type-parameter parameter has no struct type declared for the
instance; the same field from a `const` binding or from the parameter itself does.
