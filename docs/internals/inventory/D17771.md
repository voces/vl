### D17771 — a named hole callback mapped over a list-of-lists literal of a hole function is refused at emit, where the same list bound first runs

**closed 2026-11-28 by lane START-2 — the witness prints `6` · a list literal no binding holds is an anonymous binding: the elaboration stamps it at its holder class's value (COV-CALL's lead, `elabHeldFnLitStamps`), and the stamp is the one answer for its element's instance (`monoWalk`'s generic-element path reads `nodeRepTyIxOf`), its `.map` callback's receiver and parameter (`monoCoerceListCbArg`), and the IR's read of it (`exprTyOf`) · fixture `tests/cases/closures/list-of-lists-literal-of-hole-fn-mapped-by-named-callback.vl` · was: loud emit reject · clause 2 · `indirect call` · filed 2026-11-27 against master `dd93db33` by COV-CALL**

Repro:

    function inc6(a) { return a + 1 }
    function apN(r) { return r[0](5) }

    6

#### Mechanism

Traced, not fixed (COV-CALL, 2026-11-28, time-boxed). The elaboration keys `apN` the same way for
the literal and the bound receiver: `?apN.0 = ((_) => _)[]#6` (the set `{inc6}` held open), plus
the closed `?apN.0 = ((i32) => i32)[]` and `?inc6.0 = i32`; the `.map` callback's value key is
the set-keyed instance in both (`elabValueKeys`). The literal is stamped by the same branch of
`elabHeldFnLitStamps` as the bound one's initialiser, and no set is tagged at emit. The refusal is
the IR's: in the set-keyed instance, `r[0](5)` calls a closure whose type stays `(_) => _`, with
no plain call key (`callRefPlainKey`) and no tag arms, so `callRhs` (ir_build.vl) misses as
`indirect call`. With the list bound, the same instance lowers, so the binding's place closes the
element there (the holder classes, `eplPlaceOf`, as in D17768) where the literal's place does
not. Parked (coordinator, 2026-11-28): the bound receiver's epl place closes the element and the
literal receiver's doesn't; find the edge, the holder-class territory of D17768.
