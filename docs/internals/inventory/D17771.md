### D17771 — a named hole callback mapped over a list-of-lists literal of a hole function is refused at emit, where the same list bound first runs

**loud emit reject · clause 2 · `indirect call` at the callback's `r[0](5)` · `vl check` rc 0 · a neighbour of D17768 · filed 2026-11-27 against master `dd93db33` by COV-CALL**

Repro:

    function inc6(a) { return a + 1 }
    function apN(r) { return r[0](5) }
    print([[inc6]].map(apN)[0])
    // vl check: rc 0.  vl run: emit error (indirect call)

Want:

    6

#### Mechanism

Not traced. The bound spelling (`const nested = [[inc6]]; nested.map(apN)`) runs, so the callback's
instance is not keyed to the element set a literal receiver holds.
