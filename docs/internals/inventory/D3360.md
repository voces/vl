    type P = {x: i32}

#### Mechanism

Not localised past the ablation. The `is` checker's "can never match" test compares the receiver
with the named type as a whole, not with the alias's member set, so a union that holds the
receiver's type reads as disjoint from it. The design owes `true` here, or at most a redundant
test hint, never a refusal.
