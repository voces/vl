#### Mechanism

Not yet ablated to a rung. The refusal's column is the literal's, and the `??` is scenery: a
plain `const v = elems[0]` with a `!= null` guard and no `??` anywhere refuses identically. So
what is missing is the element's value box, which `collectU` mints for an inferred
array-element union through `arrLitInferUnionElemName`, and the ANNOTATED spelling of the same
program runs. The `.get(0)` spelling also runs, and a program containing BOTH spellings runs —
`.get` registers the row the subscript then finds, which is the sharpest available statement
that this is a registration gap and not a lowering one.

`boolean` and `string` elements run: each has a niche and needs no box. The family is the
numeric widths that ride the `{tag, anyref}` box, the same population
[D1828](D1828.md) named.
