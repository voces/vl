#### Mechanism

The first arm's write retires the path's narrowing in place and re-narrows to `i32`. The second
arm then finds a retired entry, and its end type for the arm join was `writeReNarrowTy` of the
narrowed `f64` and the written `i32`, which is `f64` (the narrowing names one member and the
`i32` only widens to it). The join of `i32` and `f64` then read the whole declaration. A local
takes its end type from the declaration and ran. The close computes the path's end type as a
bare name's is computed, from the place's declared type (`writeNarrowAfter`).
