### D16702 — a list literal of records spread inside a list literal of a record union builds a module that fails to validate

**check-clean invalid wasm · `vl check` rc 0, `vl run` invalid module, `type mismatch: expected (ref null $type), found (ref $type)` · clause 1 · open · the push spelling and a bound source run · found closing [D16701](D16701.md) · filed 2026-11-16 against master `7de7196e2`**

Repro:

    const u: (string | {n: i32})[] = [...[{ n: 1 }]]
    print(u.length)
    // vl check: rc 0.  vl run: invalid module

Want:

    1

#### Mechanism

Not traced. The outer literal is built at the record row of its spread literal rather than at
the union's row, so the binding receives a list of records. Taking a union build's row in
`spreadFreshDestRow` builds the right row but loses elements of a scalar-union spread literal
(`[0, ...[1, 2], ...["s"]]` prints only two), so that is not the fix.
