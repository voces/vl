### D17674 — a reference-typed parameter respelled for a shadowed capture, then written, leaves its seed local uninitialised

**closed 2026-11-26 by COV-CLOS · runs, prints `w` `x` `w` · was check-clean invalid wasm, clause 1 · closed by building the boxed parameter's cell after its respelling seed, which reads the argument (`cboxRespellSeedOf`, `cboxParamSeed`, emit_rewrite.vl) · fixture `closures/respelled-parameter-capture-positions.vl` (`written`) · found by COV-CLOS writing the position sweep for `callee captures` · filed 2026-11-26**

Repro:

    function written(g: string) {
      function k() { print(g) }
      const inner = (g: string) => {
        k()
        print(g)
      }
      g = "w"
      inner("x")
      print(g)
    }
    written("v")
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `written`: uninitialized local

Want:

    w
    x
    w

#### Mechanism

`k` reads `g` and is reached through `inner`, whose own parameter is `g`, so the
shadow respelling (`shadowRespell`) copies the parameter into a respelled local `g$sN` at the top
of `written`'s body, which `k`'s capture reads (D3025). A write to `g` then leaves that seed local
read before it is set where its type is a reference: the write boxes the parameter, and the
capture-box pass put its cell (`g$cb = [g]`) ahead of the seed, where the read of `g` is the seed's
slot, while the seed itself read the cell. An `i32` parameter read the slot's zero and ran.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| no write to `g` | runs, `v` `x` `v` | **yes** |
| `g` an `i32` (written `3`, `inner(4)`) | runs, `3` `4` `3` | **yes** (a reference type) |
| `inner`'s parameter named `h` (no shadow, no respelling) | runs, `w` `x` `w` | **yes** |
| `inner` a named `function` | still invalid | no |
