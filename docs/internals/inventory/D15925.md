### D15925 — a function whose tail is a value `if` returning records of un-annotated functions is refused at emit, where the same arms as `return`s run

**loud emit reject · `emitProgram: cannot take the generic function` … `as a value — a function value carries ONE signature`, naming `inc0` · clause 2 · open · the record spelling runs since w314's tail-join fix; the list spelling, shared by `return if`, is what remains · found closing [D15805](D15805.md), whose returned-list twin shares it · filed 2026-11-12 against master `22d35fe47`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function two() { [1, 2].length }
    function pick(b: boolean) { if b { [{ f: inc0 }] } else { [{ f: dbl }] } }
    print(pick(two() > 5)[0].f(3))

Want:

    6

#### Mechanism

Traced for the record spelling. A call through the result is judged by `holeRecSrcsOf`
(`check_calls.vl`), which follows a call's returned values through `holeSlotCallRets`:

- For `return if …`, the returned value is the `if` itself, which is no literal or slot, so the
  call builds no records and the tag plan holds the arms.
- For a tail `if`, the walk yields the arms' literals. The call adopts them at its record of
  closed function fields (a closure rep), so the plan finds a field that cannot hold an id.

Two changes make the two spellings agree:

- `holeCallTailIsJoin` declines a callee whose body ends in a value `if` or `match`, as the
  returned `if` is declined.
- The tag plan's body-tail holder (`ftHoldCtxOk`) compares the tail's type with the inferred
  result structurally (`tySame`). The tail's type is an equal copy, not the same arena index.

The list spelling, `if b { [{ f: inc0 }] } else { [{ f: dbl }] }`, is still refused. So are
`return if` and a binding of the same join, so the gap is the join of list literals of records,
not the tail: the tag plan finds no leaf of the join's set (`ftPlan`'s member-leaf exit), since
each arm's list carries its own one-member set.

#### Ablation

| spelling | outcome |
| --- | --- |
| the witness | loud emit reject |
| the arms as `return`s, `if b { return [{ f: inc0 }] } return [{ f: dbl }]` | runs |
| functions of different results, `half` for `dbl` | loud emit reject, the same message |
| a record, not a list, `if b { { f: inc0 } } else { { f: dbl } }` | runs, `6` (was a loud emit reject) |
| the record spelling as a tail `match`, of two results, or bound | runs |
| the list spelling as `return if`, or bound to a `const` and returned | loud emit reject, the same message |
| a record nested in the element, `[{ r: { f: inc0 } }]` | loud emit reject, the same message (since D15805 closed; a check reject before) |
