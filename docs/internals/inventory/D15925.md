### D15925 — a function whose tail is a value `if` returning records of un-annotated functions is refused at emit, where the same arms as `return`s run

**loud emit reject · `emitProgram: cannot take the generic function` … `as a value — a function value carries ONE signature`, naming `inc0` · clause 2 · open · found closing [D15805](D15805.md), whose returned-list twin shares it · filed 2026-11-12 against master `22d35fe47`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function two() { [1, 2].length }
    function pick(b: boolean) { if b { [{ f: inc0 }] } else { [{ f: dbl }] } }
    print(pick(two() > 5)[0].f(3))

Want:

    6

#### Mechanism

Not traced. The value `if` at the function's tail is the ingredient: the same arms as two
`return` statements run. The functions' results do not matter, and a record returned without a
list is refused the same way. The message's "no call site pins" suggests that a call through the
result does not pin the functions a tail `if`'s arms store, as it does for a `return`'s.
