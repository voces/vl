### D2904 — in a generic body, a value `if` whose arm is the parameter narrowed by `is` keeps the template's join at the pin

**closed 2026-09-27 · was check-clean silently wrong, clause 1, on master `ed9f09f7f` · found by the GJ lane's generic-join grid · filed 2026-09-27 against master `ed9f09f7f` · fixture `tests/cases/generics/value-join-at-the-pin.vl`**

Repro:

    function g0<T>(a: T, b: T, c: boolean) { const r = if a is string { b } else { a }; print(r) }
    g0(true, false, true)
    // vl check: rc 0.  vl run on master: prints 1

Want:

    true

#### Mechanism

The per-instance walk re-types a value `if` whose recorded join names a type parameter only
when every arm's recorded type is that join (D2876). The `else` arm reads `a` narrowed by
`a is string`, a derived hole of `T`, so the arms did not agree by name and the link kept the
template's `T`; the binding took the scalar cell and `print` read it as an `i32`. An arm now
agrees when its type substituted at the instance's binding equals the join substituted there.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the narrowing (`if c { b } else { a }`) | prints `false`, right | **yes** |
| the binding (`print(if a is string { b } else { a })`) | prints `1` | no |
| the `boolean` pin (`g0(3, 4, true)`) | prints `3`, right | **yes** |
| an annotation (`const r: T = …`) | prints `true` | **yes** |

#### Grading list

`if a is i32 { b } else { a }` at the same pin, which printed `1` too; and
`if a is string { a } else { a }` at `boolean`, invalid wasm on master, which prints `true`.
