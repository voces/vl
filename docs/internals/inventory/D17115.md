### D17115 — a value `if` whose arm is a union narrowed to a record, passed straight to a record parameter, is written as the union box and fails to validate

**closed 2026-11-24 by S2 · runs, prints `7` · was check-clean invalid wasm, clause 1 · the direct-call argument's variant unbox (`emitDirectArgUnbox`) skips an `if` joined at a record's row, whose arms unbox themselves, as the binding path does (`ifJoinsAtRecord`) · the `.v` read on the same `if` stays D17108 · filed 2026-11-24 against master `7ce478384` by IR-N5**

Repro:

    type A = { k: "a", v: i32 }
    type B = { k: "b", w: i32 }
    function vOf(a: A) { return a.v }
    function f(x: A | B, d: A) { return vOf(if x is A { x } else { d }) }
    print(f({ k: "a", v: 7 }, { k: "a", v: 5 }))
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `f`

Want:

    7

#### Mechanism

At a binding the same `if` is a reference join at the record's row, its narrowed arm unboxed in
the arm (`ifJoinsAtRecord`, D17026). Legacy's direct-call argument path coerces the union-typed
argument through the union box instead, so the record arm is written where the box is expected.
The IR declines the position (`argument union if at a record`) so it keeps legacy's bytes.
