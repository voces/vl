### D14900 — the elaboration records no delivery row: a record built at a delivery wider than its binding keeps the emitter's walk

**runs today and must keep running · the result-kind shadow grades its instance `row: stamped >s0;, lowered >V0;` · open pin · owned by the elaboration (the D3423 lane) · found by the row-stamp shadow's census · filed 2026-11-01 against master `ccbbe7b44`**

Repro:

    type J = { r: i32 | null }
    function idn<T>(v: T): T { v }
    const u: J | string = idn({ r: 4 })
    const k = { r: 5 }
    print(k.r)
    if u is J { print(u.r ?? 0) }

Want:

    5
    4

#### Mechanism

A record result's row follows the rep stamp of every value the function returns
(`criRowByStamp`). The stamp names the row the value is built at only where it is built in
place. An identity or relay instance's value is stamped at its template's open type, which
closes to the binding's row (`>s0`), while the value is built at the delivery's (`>V0`, the
`J | string` box); a plain function returning a call's result (`const k = mk(); return k`) is
built at the callee's delivery. Both keep the body walk, under one predicate: the stamp is open,
or the value is a call or a `const` bound to one (`criBuiltAtCallee`).

The missing fact is the delivery's row, which the elaboration records for no instance, as #5635
records the widened result (`ekRetWide`). Recording it lets that predicate, and the walk it keeps,
be deleted. The row-stamp shadow counted 30 functions on this side on master `352aee4a9`: 25 open
instance stamps and 5 plain call results, the rest of its 30 being the set convention it now folds.

#### Ablation

| ingredient changed | outcome | shadow |
| --- | --- | --- |
| a plain function returning a fresh literal (`function mk() { { r: 4 } }`) | runs | `row agree` |
| the delivery at the record itself (`const u: J = idn({ r: 4 })`) | runs | `row: stamped >s1;, lowered >s0;` |

The second row shows the instance's stamp is not the build fact even where the delivery is not
wider, so the predicate keeps every open instance stamp, not only a widening one.
