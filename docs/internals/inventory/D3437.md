### D3437 — a member read off a type parameter's union-typed field that not every member has is refused at emit, not at the pin

**loud emit reject · clause 2 · open · pre-existing, the same on master `b2a85883d` · found by lane NW beside D3233 · filed 2026-09-30 against master `b2a85883d`**

Repro:

    type A = { v: i32 }
    type B = { s: string }
    function F<Z>(z: Z) {
      print(z.h.s)
    }
    const x: { h: A | B } = { h: { v: 1 } }
    F(x)
    // vl run: emitProgram: field access receiver is not a struct

#### Mechanism

Not localised past the ablation. The direct spelling refuses `field 's' is not on every member of
A | B`. In the `<Z>` body `z.h` is a derived hole and `.s` off it records a shape demand that no
pin validates for a declared type parameter's derivation, so the read reaches the emitter over
the `A | B` box. The checker owes the refusal; a read after a write or call that ended a
narrowing is re-asked since D3233, an un-narrowed one is not.

#### Ablation

| ingredient changed | outcome on master | needed? |
| --- | --- | --- |
| `function F(z: { h: A \| B })` | check refuses | **yes** (a type parameter or hole) |
| `function F(z)` | the same emit refusal | no |
| the value `{ h: { s: "bee" } }` | the same emit refusal | no |
