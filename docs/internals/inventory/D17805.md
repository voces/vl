#### Mechanism

The bound choice is a set value with no one instance, so `fvaAdapt` took the escape route
(`fnTagEscapeNote`); the decision asked for the adapter only for a tagged set, so an untagged one
was built as each member's closure at its own signature: the trampolines
return `i32` and the call through the parameter is made at the union-result type. The inline
choice ran because each arm is delivered alone, through its own adapter. Before the fix: The parameter's result `i32 | string` is wider than the members' `i32`; the call
through `k` is made at the wider signature while the choice's value is the members' own.
