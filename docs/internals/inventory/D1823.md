#### Mechanism

**The row was filed naming the wrong ingredient, and its own witness is what corrected it.** It
read "the `Json` element — the same shape over `Circle[]` — runs, prints `2`", so the gap
looked like a `Json`-element gap. That comparison changed TWO things: the element type AND the
narrowing DEPTH. Held apart:

| shape | depth 1 | depth 2 |
| --- | --- | --- |
| `Circle[] \| string \| Err` | runs | **refused** |
| `Json \| JsonError` | runs | **refused** |

The element type is not the ingredient. **The second narrowing is.**

Probed inside the collect walk, at the `.push` statement, with the two depths side by side:

    depth 1   PROBE collect pushKindRef=1 slot=0 fnIx=-1 narrowTop=1
    depth 2   PROBE collect pushKindRef=0 slot=0 fnIx=-1 narrowTop=1

`narrowTop` is 1 at both — but at depth 2 the one narrow on the stack is the OUTER arm's, not
the inner `is Circle[]`. `startScanIf` pushes each top-level arm's pin around its scan;
`collectRefPushSlotsIf`, which the walk descends into for a nested `if`, does not. So
`callIsPushKind(stmt, fnIx, "ref")` is asked about a receiver still typed as its whole union,
answers no, and `recordRefPushSlot` is never called. `refListSlotOfExpr` reads `slot=0`
correctly at both depths — the slot was never the problem, the classification was.

The close pushes each arm's narrowing around its walk in `collectRefPushSlotsIf` and in its pop
side `collectMemberPopRefSlotsIf`, which had the identical blindness and serves `.pop` and
`.clear` out of the same frame set.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the second `if` (`if zp is Circle[]` at top level) | ran before, runs now | **yes** |
| `Circle[]` for `Json[]` behind the same two guards | refused before, runs now | no |
| module scope — the same shape inside a function body | refused before, runs now | no |
| `.push` for `.clear` | refused before, runs now | no |
| `.push` for `.pop` | refused before, runs now | no |
| `.push` for `.length` or an index read/write | ran before, runs now | **yes** |

The last row is the boundary: `.length`, `zp[0]` and `zp[0] = v` never wanted this frame and ran
at every depth, before and after.
