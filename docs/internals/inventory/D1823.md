#### Mechanism

**Not instrumented beyond the position matrix; the refusal names its own mechanism and the
matrix bounds it.** `.length` and the index read over the same narrowed receiver both RUN — the
first since [D1822](D1822.md), the second at the inline spelling before it — so the receiver
classifies as a ref list at read positions. `.push` is different in kind: it needs the
receiver's ELEMENT type before the body is lowered, and the pass that resolves it runs with no
narrowing stack, so a narrow-only list has no row for it to read.

**This is not [D1822](D1822.md)'s alias split, and the matrix is what settles that.** It refuses
identically at the INLINE spelling (`r4 is Json[]`) and at the alias (`r4 is JsonArr`), at the
inferred and annotated faces alike — four cells, one message — whereas every cell D1822 moved
ran at the inline spelling all along. A name test that cannot read an alias is not what is
happening here; the element row does not exist at either spelling.

The plain user union is the boundary: `u.push({ r: 2.0 })` over `type U = Circle[] | string`
narrowed to `Circle[]` **runs today** and prints `2`. So the gap is not "push onto a narrowed
list arm" in general — it wants the arm whose element type the pre-pass cannot name, which for
`Json[]` is the recursive union element.
