### D16432 — an inline `Set()` stored as a value of an unwritten `Map()` is refused at emit

**closed · runs, prints `1` · was a loud emit reject (`emitProgram: map value slot has no resolved vals wrapper`), clause 2 · the `Set()` twin of [D16341](D16341.md), closed by its fix · fixed 2026-11-15. Fixture: `tests/cases/maps/open-map-value-collection-defaults-runs.vl`**

Repro:

    const m = Map()
    m["k"] = Set()
    print(1)
    // vl check: rc 0.  vl run: emit error, map value slot has no resolved vals wrapper

Want:

    1

#### Mechanism

The outer map's key and value types come from its writes, and the only write stores an inline
`Set()` whose element no write fixes, so the value slot has no rep for the emitter's map-values
wrapper. A named `Set()` binding stored there runs, so the inline literal at the value place is
the ingredient. From the ablation.
