### D15071 — a lambda calling its parameter at two types, called with a generic from a body with a type parameter, builds invalid wasm

**open · check-clean invalid wasm · clause 1 · with or without the split plan · found grading closure-at-delivery item (d) slice 2 · filed 2026-11-02 against master `babb6c41`**

Repro:

    function id(a) { return a }
    const lap = (g) => {
      print(g(1) + 1)
      return g("s")
    }
    function w<T>(t: T) { return lap(id) }
    print(w(1))
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `lap`: type mismatch: expected i32, found (ref $0)

Want:

    2
    s

#### Mechanism

Not yet located. The body of `lap` reads `g` as one rep while the call from `w`'s instance
hands it another. The same call outside a body with a type parameter runs (`function w(t)`), as
does a named `lap`.
