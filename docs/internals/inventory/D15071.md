### D15071 — a lambda calling its parameter at two types, called with a generic from a body with a type parameter, builds invalid wasm

**closed 2026-11-03 · runs, prints `2`, `s` · was check-clean invalid wasm, and check-clean silently wrong where the second call is `g(true)` (it printed `1`) · clause 1 · with or without the split plan · a function with a type parameter was given no instance when its inferred result held a hole that the type parameter does not bind (`elabParamsClosed`'s result clause), so every instance built under it was unkeyed and a lambda's calls through its parameter read the template's types; the clause now asks only that the result name none of the declaration's own type parameters · pin `tests/cases/closures/lambda-called-at-two-types-from-generic-body-with-inferred-result.vl` · found grading closure-at-delivery item (d) slice 3 · filed 2026-11-02 against master `babb6c41`**

Repro:

    function id(a) { return a }
    const lap = (g) => {
      print(g(1) + 1)
      return g("s")
    }
    function w<T>(t: T) { return lap(id) }
    print(w(1))
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `lap`: type mismatch: expected i32, found (ref $0)

Want:

    2
    s

#### Mechanism

`elabEnqueue` refused `w` at `T = i32`: `elabParamsClosed` required the whole substituted
result of a declaration with type parameters to be closed, and `w`'s result is `lap(id)`'s
type, a hole `T` does not bind. Mono's demand for `w`'s instance then answered -1, so the
instances built under it (`lap`'s, `id`'s at each type) were unkeyed and read the template's
types. An annotated result, a void `w`, or a hole parameter in place of `T` each skip the
clause.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `w<T>(t: T)` to `w(t)` | runs, `2 s` | **yes** |
| `w`'s result annotated `: string` | runs, `2 s` | **yes** |
| `lap` a named function | runs, `2 s` | **yes** |
| `lap` calling `g` at one type (`g("s")`) | runs | **yes** |
| `w` called a second time at another type | the same refusal | no |
