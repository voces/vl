#### Mechanism

The reader is not the hint's `tyEq` gate but the seed counter in front of it: the inferred return's
adoption of the annotation's seed counted as consumed when `inferred != preAdopt`
(`check_inferred_return.vl`), a row compare, so a seed that re-pointed the row to a structurally
equal one suppressed the hint (`cbSeedUsed`, `check_statements.vl`). `lbiRedundant`'s `t != a` is
the same compare. Both now compare types (S2-prep d): the six programs that gain the hint print the
same with the annotation removed, so master's silence was the identity accident.
