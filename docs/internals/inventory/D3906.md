### D3906 — an alias of a capturing nested generic beside an inner block's own binding of its name builds invalid wasm

**check-clean silently wrong · found in review of #3479 (`rv3479-witnesses/b9_shadow.vl`); re-graded in review of #3490 (`rv3490/u4_bool_shadow_noval.vl`) · filed 2026-10-09 against master `ce183bab5`**

Repro:

    function call(f: (n: i32) => void, n: i32) { f(n) }
    function outer<T>(x: T, tag: string) {
      function inner<U>(u: U) { print(tag); print(x); print(u) }
      const k = inner

    }

#### Mechanism

D3887 copies a call through an alias per instance only for a name the instance body binds once;
the block's `const k` binds it twice, so the outer alias's calls stay shared between the two
`outer` instances, and the second instance's rename is read by the first.
