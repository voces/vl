### D17182 — a `??` over a literal union's `K | null` niche that a call yields, whose default is a number or a boolean, is refused at emit

**closed 2026-11-24 · runs, prints `b`, claimed and claimless · was a loud emit reject (clause 2), `emitProgram: ?? over this nullable value is not supported yet` · fixed in wasmEmit.vl: `coalNulRefsArmOf`'s `atomJoinStash` arm holds the operand once in a scratch slot, boxes the default on its null and the member string under the union's string arm otherwise, as `emitCoalesceNulBoolJoin` does for `boolean | null`; the IR misses it by name (`coalesce nulRef atomJoinStash`) · pins: `tests/cases/null/coalesce-call-litunion-niche-boxed-{witness,positions}.vl`, matrix `coalesce-call-litunion-niche-boxed.matrix.vl` · filed 2026-11-24 against master `b0bd16950` (found by IR-N3's `coalesce-chain-litunion-links-boxed` sweep for D17401), closed by lane IR-N11**

Repro:

    type K = "a" | "b"
    function g(): K | null { return "b" }
    print(g() ?? 2)
    // vl check: rc 0.  vl run: rc 0, prints the line below.

Want:

    b

#### Mechanism

The left operand is a literal union's `K | null` niche (an atom id with a `-1` null sentinel). A
default of another kind, a number or a boolean, makes the join a value union (`K | i32`). The
re-readable operand already ran: `coalNulRefsArmOf`'s `atomJoinIf` spells the `??` as
`if l != null { l } else { d }`, reading `l` twice. A call cannot be read twice, and no later
arm took it, so emit refused.

Runs today and must keep running (the re-readable spellings):

    type K = "a" | "b"
    function g(): K | null { return "b" }
    const x = g()
    print(x ?? 2)
    const o: { f: K | null } = { f: null }
    print(o.f ?? 2)
    // prints b, then 2
