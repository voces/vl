### D17182 — a `??` over a literal union's `K | null` niche whose default is a number or a boolean is refused at emit

**loud emit reject · clause 2 · `emitProgram: ?? over this nullable value is not supported yet` · filed 2026-11-24 against master `b0bd16950` (found by IR-N3's `coalesce-chain-litunion-links-boxed` sweep for D17401) · owner FREE**

Repro:

    type K = "a" | "b"
    function g(): K | null { return "b" }
    print(g() ?? 2)
    // vl check: rc 0.  vl run: emitProgram: `??` over this nullable value is not supported yet

Want:

    b

#### Mechanism

The left operand is a literal union's `K | null` niche (an atom id with a null sentinel). With a
string default the join is a string and the atom is rendered; with a member literal it stays the
niche. A default of another kind, a number or a boolean, makes the join a value union (`K | i32`),
and no `??` arm boxes a niche atom into it, so emit refuses. The same union built by an `if`, or
the niche narrowed first, runs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the default a string (`?? "s"`) | runs, prints `b` | **yes** |
| the `??` for a null test (`if x != null { print(x) } else { print(2) }`) | runs, prints `b` | **yes** |
| the `??` for an `if` joining `"b"` and `2` at `K \| i32` | runs, prints `b` | **yes** |
| the default a boolean (`?? false`) | same refusal | no |
| the result bound at an annotated `K \| i32` | same refusal | no |
| a chain (`f() ?? g() ?? 2`) | same refusal | no |
