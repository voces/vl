### D2790 — a join of `{ f: 5 }` and `{ f: 2.5 }` handed straight to a parameter or a generic builds the `i32` literal into the `f64` row

**check-clean invalid wasm · identical on master `781f68091` · filed 2026-09-27 from the #3209 review's record-join grid (`if64_param_lit`, `if64_generic_lit`)**

Repro:

    function use(r) {
      print(r.f)
    }
    function go(sel: i32) {
      use(if sel == 0 { { f: 5 } } else { { f: 2.5 } })
    }
    go(0)
    go(1)
    // vl check: rc 0.  vl run: invalid module inside `go`, expected i32, found f64

#### Mechanism

Not localised. The join is the record `{f: f64}` (the wider of the two), and every other
position the grid tries runs: binding, `match`, return, list, field, closure, global. At an
argument the arms are built without the join's row reaching the literal's field store, so
the `2.5` meets a field coded `i32` from the first arm's row, or the reverse.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the argument position (`const r = if …`, then `use(r)`) | runs | **yes** |
| the numeric widening (`{ f: "s" }` in place of `2.5`) | runs since D2731 | **yes** |
