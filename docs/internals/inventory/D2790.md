### D2790 — a join of record literals handed straight to a parameter or a generic is built at a row an arm's field names select, not at the join's

**closed 2026-09-27 — the repro RUNS and prints `5` then `2.5` · was check-clean invalid wasm inside `go`, identical on master `781f68091` · filed 2026-09-27 from the #3209 review's record-join grid (`if64_param_lit`, `if64_generic_lit`)**

Repro:

    function use(r) {
      print(r.f)
    }
    function go(sel: i32) {
      use(if sel == 0 { { f: 5 } } else { { f: 2.5 } })
    }
    go(0)
    go(1)

#### Mechanism

The argument's row was read by `structIndexOfExpr`, whose `if` arm answered the THEN arm's row,
so the parameter's pin (and a generic's `T`) named `{ f: 5 }`'s row, or, where a declared
`{ f: i32 }` row exists, that one: a declared-but-unconstructed shape captured the literal.
The arms were then built at the join's own row and handed to a parameter of the other. The
join is wider than its arms, so it is now its own row there (`joinedRecordRowOf`), found by the
join's arena type or, for an equal join elsewhere in the program, by its spelling
(`joinRowOfTy`), so the pin, the arms and every reader name one struct.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the argument position (`const r = if …`, then `use(r)`) | runs | **yes** |
| the numeric widening (`{ f: "s" }` in place of `2.5`) with a declared `{ f: i32 }` row, a `mkA(): { f: i32 }` or an annotated global | invalid wasm on master, runs now | no |
| a second join of the same types elsewhere (`id(if …)` beside `use(if …)`) | a loud emit reject on master, runs now | no |
