### D17825 — emit readers resolve a binding with `identDeclOf` inside an instance frame, which names the template's binding rather than the instance's

**runs today and must keep running · refactor target (CENSUS measured: 112 sites, 31 witnesses over 10 reader classes, none building wrong) · filed 2026-11-28 against branch `cov-clos-d17808` (c6678bcc8) by COV-CLOS-3 (found closing [D17808](D17808.md))**

Repro:

    function add(a, b) { return a + b }
    function app(g, s) { return g(s, s) }
    function p5(h) {
      const run = (x) => app(h, x)
      const v = run(1.5)
      print(v)
      const u = run(2)
      print(u)
    }
    p5(add)
    // vl run: prints 3 then 4 since D17808. Before, the print arm read `u` through identDeclOf,
    // got the template's binding (its call on the f64 lambda) and chose f64 over the i32 the IR stored.

Want:

    3
    4

#### Mechanism

`identDeclOf(read)` answers the declaration the checker resolved. In an instance frame mono has
cloned the body and redirected calls, so the instance's own binding can differ from the
template's (`identLetOfRead(read, fnIx)` resolves it in the frame). D17808 moved three readers:
`openCallWidth` (wasmEmit), and `openReadTy` and `letOpenCallWidth`'s copy chain (emit_classify).

CENSUS measured the population on master's fixpoint seed: 112 sites, 30 classed "may disagree",
31 witnesses across 10 reader classes. No class gives wrong output, invalid wasm or a trap. An
un-annotated `let` shares its node across instances and takes its per-instance type from elab,
so the template's declaration is harmless when the reader goes through the per-frame or elab
tables. Two clause-2 rows spun off, filed in #10774 ([D17830](D17830.md), [D17831](D17831.md)).

Residual risk: the readers that read the raw template (`recBuild*`, `listLitElemStamp`,
`letOpenCallWidth`, `nodeTyAt(d, -1)`, `letBindTy(d, -1)`, `recBuildTyOf(d)`) would answer wrong
for a future annotated clone.

Refactor target: one "resolve a binding in the current frame" reader that every emit reader takes.
