#### Mechanism

The third of ROADMAP row 25's held-back sites. Converting its nominal fall-through turns four
`structs/*twin*` modules into check-clean invalid wasm and a fifth into a loud
`emitProgram: nested struct fields are not supported`.

**The function's own comment gave a reason, and the measurement refutes it as the operative
one.** It read *"a `-1` here routes on to the concrete-variant lookup, so widening the name leg
would change which arm answers"*. The routing is real — `wasmEmit.vl`'s single caller does
`if elemStructIdx < 0 { elemVariantIdx = variantIndexOf(rlen) }` — but the shadow-gated note on
the unconverted site reports `would-flip-no-variant` for **all five** flipping names and
`would-flip-AND-ROUTES-TO-VARIANT` for **none**. No measured cell pays that hazard.

The operative reason is in the CALLER, one line up: `elemStructIdx` seeds `pendingStructIdx`
*"so a same-field-name sibling struct does not win the field-shape match."* The seed exists to
**override** a field-shape match, so producing it FROM a field-shape match is circular — and
`structIndexOfTypeName` is exactly a field-name-set scan. The five flipping names are nested
renderings whose inner and outer rows share a fieldset (`{f:{f:i64|null}}`,
`{f:{f:{f:f32|string|{q:i64}}}}`), which is the same-field-name sibling case the seed was built
for, so the scan's first match returns the INNER row and the element builds one level short.

The comment is corrected in place; the change is comment-only and the seed is byte-identical.

#### Ablation

Three spellings of the same destination:

| face | base | fall-through converted |
| --- | --- | --- |
| annotated, INLINE shape (`{f: {f: i64 \| null}}[]`) | runs `NULL` | **INVALID WASM** |

| un-annotated (inference pins it) | runs `NULL` | runs `NULL` |

The inline structural annotation is the load-bearing spelling, as in D1858: it is the one face
that hands the ladder a name only the fieldset scan can match. The alias face gives a nominal
name and the inferred face gives a destination, and both are safe.
