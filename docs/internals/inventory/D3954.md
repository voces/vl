### D3954 — a capture cell in a generic body is refused for a shared writer that the program never runs

**loud emit reject · clause 2 · found in review of #3498 (`rv3498/w12`) · filed 2026-10-10 against master `429e7b093`**

Repro:

    function inner<U>(u: U) { print("I"); print(u) }
    function other<V>(v: V) { print("O"); print(v) }
    function a<T>(x: T, w: boolean) {
      let k = inner
      const toO = () => { k = other }
      if w { toO() }
      k(x)
    }
    a(1, false)
    a(true, false)
    // vl check: rc 0.  vl run: emitProgram: the captured binding `k` is written with a generic function inside a closure that every instance of the enclosing generic function shares

Want:

    I
    1
    I
    true

#### Mechanism

D3953's refusal applies to every writer the program names (`monoWriteFrameDead` is syntactic): a
writer called only under a condition that is false at run time still counts, because which
instance's value it would store cannot be decided without running it. Lifting D3953 (a writer
instanced per enclosing instance) closes this too.
