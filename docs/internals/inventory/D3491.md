### D3491 — a function declared to take or return a literal union with a member past `i32` is invalid wasm at its boundary, while a binding, a field and a lambda of the same type run

**check-clean invalid wasm · clause 1 · open · found by lane FR5 while grading the D3320 family · the same on master `937445a42` · filed 2026-10-03 against master `937445a42`**

Repro:

    type D = 9000000000 | 1
    function f(): D { return ds[1] }
    const ds: D[] = [1, 9000000000]
    print(f())
    // vl check: rc 0.  vl run: invalid module, "the emitted module failed to validate inside `f`:
    // type mismatch: expected i32, found (ref $type)"

Want:

    9000000000

#### Mechanism

Unconfirmed past the validator. The ablation places the defect at a DECLARED function boundary
of the literal union, not at the list element read: `return 1` and `return 9000000000` fail the
same way, as does a parameter of type `D`, while the same union as a binding, a record field, a
list element and a lambda's result all run. The mixed-width union has two candidate reps (an
`i32` niche when every member fits, a wider one when a member does not), and the function
signature and its caller's reading of the result disagree about which. This is the same family
as D3320, whose witness is the parameter spelling with an `i64` argument; this row's witness
needs no wide value at all, so the two may close together or apart.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `ds[1]` replaced by the literal `1` (`function f(): D { return 1 }`) | still invalid | no (the element read) |
| `return 9000000000` | still invalid | no |
| `ds` passed as a parameter, `function f(ds: D[]): D` | still invalid | no (the global) |
| a parameter `function g(d: D)` called with `1` or `9000000000` | invalid wasm at the call | no (the return position) |
| `type D = 3 | 1`, or `9000000000 | 8000000000` | runs | **yes** (members of mixed width) |
| `const x: D = ds[1]`, a record field `{ d: D }`, a lambda `(): D => 1` | runs | **yes** (the declared function) |
| `function f() { return ds[1] }` | a loud check reject, "infers the union return type D" | the inferred spelling lands in clause 2 |

#### Grading list

Return, parameter and default spellings together with D3320's two witnesses; `type D = 9000000000 | 1`
returned from a closure declared with `function`; the all-wide and all-narrow unions, which
run and must keep running.
