### D1760 — a list literal built from a hole parameter pinned at the softened `string` reserves no string list, so [D1756](D1756.md)'s close routes one more program into [D1740](D1740.md)'s floor

**loud emit reject · `vl check` rc 0, `vl run` rc 1, `emitProgram: string array literal but string list type not collected` · clause 2 · filed 2026-09-06 against `709e3e9fb` · the PRICE [D1756](D1756.md)'s close pays, and the only cell it loses · 0 corpus cells**

Repro:

    function mkval(): "red" | "green" { return "red" }
    const srcArr = [mkval()]
    function take(p) {
      const xs = [p]
      print(xs[0])
    }
    take(srcArr[0])
    // vl check: rc 0.  vl run: emit error,
    // emitProgram: string array literal but string list type not collected

This RAN before [D1756](D1756.md)'s close, printing `red`. It ran because the parameter was
pinned at the atom's raw width, which is the very defect that close fixes.

#### Mechanism

Measured. [D1756](D1756.md) pins an inline literal-union element at the softened `string`, so
`[p]` inside the callee is a STRING list — and the collect scan classifies a list literal with
no frame, so a parameter element reserves nothing and the emit floor refuses a rep it can name.
It is [D1740](D1740.md)'s mechanism exactly, reached by one more program.

**Three routes to the reservation were built and all three were refused**, each on its own
measurement:

| route | result |
| --- | --- |
| name a literal-union element's rep by alias-ness at the collector | this cell and D1740's go **SILENT invalid wasm** |
| match the element NAME against every parameter annotation in the program | same, plus an `arena-scan-outside-pass` regression |
| the above, with the element-pin reader gated on ALIAS-ness | fixes both, and **breaks `joined-element-adopts-the-annotated-list.vl`** — a declared inline-litunion array genuinely holds atoms |
| the same gate narrowed to a list LITERAL | breaks that fixture anyway, and both cells go silent |

**The floor is standing in front of something the reservation does not fix.** Every route that
lifts it produces invalid wasm somewhere, which is what an `emitFail` floor is for; the reader
that decides whether `xs[0]` is an atom cannot tell a declared litunion array (atoms) from a
list literal built from a `string`-pinned parameter (strings), and both reach it as "an array
whose element pins to a literal union".
