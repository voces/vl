### D3513 — a standalone `?.` of a non-null scalar field refuses when no binding or parameter spells its `T | null`

**closed 2026-10-03 — the witness prints `7` then `null` · was loud emit reject, clause 2 · 11 cells of lane OQ's D3457 matrix and the #3341 review's 8 `print` cells · filed 2026-10-03 against master `878f6ebe8`, closed by lane WD against master `4c55f1b6a` · fixture `tests/cases/unions/opt-chain-scalar-unbound-box.vl`**

Repro:

    type P = { a: i32, b: i32 }
    function f(r: P | null) {
      print(r?.b)
    }
    f({ a: 1, b: 7 })
    f(null)
    // vl check: rc 0.  vl run: emit error, "`?.` yields a nullable scalar but its union box was not collected"

Want:

    7
    null

#### Mechanism

`r?.b` over an `i32` field has type `i32 | null`, whose rep is the value box, and the box's
heap types exist only once some union is registered during collection. A binding registers it
(`nliInferOptChainLet` for `const x = r?.b`), as does any parameter, return or field annotated
`i32 | null`; an expression in any other position (a `print` argument, an operand of
`== 7`) registers nothing, so `emitOptMemberValue` finds no box and refuses. The fix is a
collection walk over EXPRESSIONS that registers the type of every `?.` whose leaf is a
non-null scalar, not one more statement form; `r?.b == 7` refuses the same way with a
different message (`union box atom test on a union with no recorded members`).

Closed as described: `collectU`'s node walk now registers the `T | null` of every `?.` whose
type is a nullable number, and the value union every `??` joins into, and `unionNameOfExpr`
names the `?.` box so `print` and `==` dispatch on its tag. The same unregistered union
refused `print(x ?? 2.5)` over a plain `i64 | null` parameter, with no `?.` at all; that runs
too. Graded: OQ's matrix 325 → 336 of 336, the #3341 `g2` grid 210 → 218 of 218, its `g` grid
unchanged at 972 (its 118 loud cells are map and closure leaves, a different refusal).

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |

| any other `i32 \| null` annotation in the program | prints `7`, `null` | **yes** (no union registered) |

| `print(r?.b == 7)` in place of `print(r?.b)` | refuses, another message | no |
