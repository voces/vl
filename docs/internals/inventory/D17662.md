### D17662 — a `?.` call on an un-annotated parameter handed a nullable record, returned, is typed without its `null`

**check-clean invalid wasm · 1 cell (the `shared member callee nullable receiver` position sweep of lane COV-CLOS) · clause 1 · filed 2026-11-26 against master `d205a3529`**

Repro:

    function p3(a) { return a?.f(5) }
    const none: { f: (x: i32) => i32 } | null = null
    const r = p3(none)
    print(r == null)
    // vl check: rc 0, warns "`r == null` is always false here (r is i32)".  vl run: invalid module inside `p3`: expected i32, found nullref

Want:

    true

#### Mechanism

Not traced. The instance of `p3` at the nullable record types its result `i32`, the called field's
result, without the `| null` the absent receiver yields; the body then returns the chain's
`null` where the signature says `i32`. The same chain bound to a `const` inside the function, or
printed through `??`, is typed `i32 | null` and runs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the annotation's absence (`a: { f: (x: i32) => i32 } \| null`) | runs, `p3(none) ?? -3` prints `-3` | **yes** |
| the `return` (the chain printed through `??` in the body) | runs | **yes** |
