### D7120 — a nullable literal-union value returned into a union that reaches its literal arm through an alias widens with no scratch frame

**closed 2026-10-19 by lane L6 · runs, prints `false` · was check-clean invalid wasm · clause 1 · the declared-return scan that reserves the string-op scratch frame asks the return TYPE whether a literal member widens to a string (`tyTakesAtomAsStr`), not its spelling · pins: `tests/cases/unions/litunion-atom-return-through-alias-union.vl` (a module `const` and `let` source, a local source, a `null` value, a record arm, a non-null `K \| i32` alias) · found closing [D7043](D7043.md) by the `nullable-litunion-through-alias-arm` matrix's `return_annotated` cells · present on master `e55677bd8` · filed and closed 2026-10-19 against master `e55677bd8`**

Repro:

    type A = ("a" | "b") | null
    type U = A | i32
    const ga: ("a" | "b") | null = "a"
    function d(): U { return ga }
    print(d() == null)
    // vl check: rc 0.  vl run: invalid module, inside `d`: unknown local

Want:

    false

#### Mechanism

The return's widening of a literal member into the union box uses the string-op scratch frame.
`retWidensAtomToStr` reserved it only when `unionTakesAtomAsStr` of the return's spelling said
so, and the spelling `U` names an alias, so no frame was reserved. The inline return spelling
`("a" | "b") | null | i32` runs on master. This is [D7043](D7043.md)'s mechanism at the return
scan.
