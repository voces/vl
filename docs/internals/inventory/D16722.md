#### Mechanism

`{ f: if c { [] } else { null } }` records the field's storage type as a list of an unpinned
hole, made nullable. `repOfTy` has no rep for it, so `fieldCodeOfRep` answers -2. The anon
ladder stored a list code instead: 18 (`FC_NUL_I32_LIST`) on this witness's rows. 346 disagreeing reads in 2 files. Stage 3c-ii keeps the stored code for this
class (`fcKeptHoleList`). A scratch compiler that derives the code here fails both files with
`emitProgram: struct field has no storage kind`. The close: the minter records the
use-resolved list type, which is the type the checker should record, and the fallback is deleted.
