Repro:

    function apply2(g) { print(g(1, 2)) }
    function apply3(g) {
      print(g(1.5, 2.5))
      print(g(1, 2))
    }
    const gs = [apply2, apply3]
    gs[1]((a, b) => a + b)
    // vl check: rc 0.  vl run: emitProgram: monomorphize: unsupported argument type for `g` in a call to `apply3`

#### Mechanism

The checker typed `gs[1](...)` through element 0's type, so it bound the lambda's parameters
from `apply2`'s one call and accepted the program. The element named, `apply3`, calls `g` at
`(f64, f64)` and at `(i32, i32)`, and the emitter's rungs found no single parameter list. The
direct spelling `apply3((a, b) => a + b)` runs, so the program is type-valid.
