### D3947 — a list of functions a generic function returns through a local binding and an inferred return type is refused when an element is called

**loud emit reject · clause 2 · found in review of #3495 (`rv3495/p9_after`) · related to D3384 · filed 2026-10-10 against master `f4b15af9c`**

Repro:

    function q(n: i32) { print(n) }
    function mk<T>(x: T) {
      const l: ((n: i32) => void)[] = [q]
      return l
    }
    mk(7)[0](9)
    // vl check: rc 0.  vl run: emitProgram: a call statement's callee is neither a name, a member, nor a function value

Want:

    9

#### Mechanism

Not located. The instance's inferred return type does not reach the call site as a list of
functions, so the element read `mk(7)[0]` is not a function value to the call lowering. In a
value position the same read is `callee is not a function name`; bound first (`const g = a[0]`) it
is `a ref list's element row does not resolve`. D3384 is the single-function twin (`return q`,
then `mk()(9)`), which refuses with no interned signature and needs no generic.
