### D3016 — a hole value at a `string | null` pin joined through an `if` or `match` value traps on `null`

**loads then traps · clause 1 · the LU3 grid's `S_ifjoin_h` and `S_match_h` rows at the `null` string pin, 30 cells · the same on master `59cf3b639` · filed 2026-09-28 against master `59cf3b639`**

Repro:

    function f(x) {
      const y = if x == x { x } else { x }
      print(y)
    }
    const v: string | null = null
    f(v)
    // vl check: rc 0.  vl run: wasm trap: null reference

Want:

    null

#### Mechanism

Not localised past the ablation. The value join's type is the hole's variable, and at the
instance it is typed as the non-null string, so the joined value is cast non-null and a `null`
traps. The `<T>` spelling and a plain `const y = x` both keep the niche.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const y = x` | prints `null` | **yes** (the join) |
| `function f<T>(x: T)` | prints `null` | **yes** (the hole) |
| `"s"` in place of `null` | prints `s` | **yes** |
| `print(if … )` with no local | traps | no |
| an `i32 \| null` pin | prints `null` | **yes** (the string niche) |
| `match 1 { 1 => x, _ => x }` | traps | no (the same defect) |
