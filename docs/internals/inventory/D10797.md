**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the arms swapped run (the ablation) · found closing [D10790](D10790.md) · present on master `277a13d00` · filed 2026-10-23 against master `277a13d00`**

    function apply3(g) { print(g(20)) }

#### Mechanism

Untraced past this point. The `if` value takes its type from the then-arm, which is
`apply3`'s open signature, so the mono pass sees no closed function type to instance `apply3`
at. D10790's `monoCoerceIfArms` serves the arms-swapped spelling only. Instancing at the
else-arm's type instead moves the refusal to the call `f(id)`, which then has no interned
signature: the join's type is the thing that is wrong, not the instancing.
