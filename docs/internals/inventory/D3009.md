### D3009 — an optional member read `r?.v` used as an expression statement is refused as an unsupported statement

**loud emit reject · clause 2 · identical on master `b34730ad9` and on #3253 · found by the #3253 review grid · filed 2026-09-28**

Repro:

    type D = { v: f64 }
    const c: {[string]: D} = Map()
    c["k"] = { v: 1.5 }
    const r = c["k"]
    r?.v
    print("ok")
    // vl check: rc 0.  vl run: emitProgram: unsupported statement in body

Want:

    ok

#### Mechanism

`vl check` accepts the program; the emitter's statement lowering has no arm for an `OptMember` whose value is discarded, so it falls to `emitProgram: unsupported statement in body`. A `?.` read evaluated for effect should lower as its receiver's evaluation and a drop.
