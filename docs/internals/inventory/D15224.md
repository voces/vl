### D15224 — an inferred list result's recorded row compares its returned elements' functions by their syntax, where the checker's tagged-set membership is the fact

**runs today and must keep running · a pin on [D15203](D15203.md)'s witness while `fnRetRefListRowJoin` (emit_collect.vl) fingerprints each returned element by the declarations its field values name (`valueFnSig`), reading element syntax · open · the checker's own fact for which functions a holder may hold is its set membership (`fnTagSetOfTy`, read by `ftHoldKind` and the slot judges), and the join should read that instead · filed 2026-11-04 against master `6b890751`**

Repro:

    function inc0(a) { return a + 1 }
    function mk() { return [{ fs: [inc0] }] }
    print(mk()[0].fs[0](3))

Want:

    4

#### Mechanism

The recorded row is the one every returned value is built at, refused where their functions differ. Which functions an element holds is read from its syntax: a field value naming a function declaration, a list literal of them. A value the syntax does not name, such as one reached through a binding, falls to its type's function sets, so two spellings of one value can fingerprint differently. The checker's set membership answers both alike.
