#### Mechanism

When the tag decision for `{inc0}` declines, the set stays one closure, and its signature is the
`i32` one. A call passing an `f64` then pushes the `f64` where the closure's functype takes an
`i32`. Closed: `emitCallRefArg` refuses a wide number (`f64`, `i64` or `f32`) handed to an `i32`
parameter of a function value. That refusal lets the split plan run, and the plan types each
use, so the program runs. With the plan off it is a loud emit reject, not invalid wasm.
