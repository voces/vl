#### Mechanism

When the tag decision for `{inc0}` declines, the set stays one closure, and its signature is the
`i32` one. A call passing an `f64` then pushed the `f64` where the closure's functype takes an
`i32`: invalid wasm. `emitCallRefArg` now refuses a wide number (`f64`, `i64` or `f32`) handed to
an `i32` parameter of a function value. That refusal lets the split plan run, and the plan types
each use, so with the plan on the program runs. The refusal is an interim floor, a clause-2 emit
reject of a check-clean program. The close is at the escape: the tag decision (or the elaboration)
has to follow the member through the record pushed onto a list of records, a hole helper's push and
the spread, as D15060 follows a direct `push`, so the set is decided whole and no call reaches
the floor.
