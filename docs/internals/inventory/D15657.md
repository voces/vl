### D15657 — a cast to a union arm reads the arm's tag through the type's first declared name, so a same-shape standalone record declared first hides the arm

**loud emit reject · clause 2 · filed 2026-11-11 against master `98b73ba7`**

Repro:

    type CircleC = { r: i32 }
    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    function pick(s: Shape): i32 {
      const c = s as! Circle
      c.r
    }
    const v: Circle = { r: 3 }
    print(pick(v))
    // vl check: rc 0.  vl run: emitProgram: `as Circle` is supported for a value-union arm or a struct-variant arm; this arm is neither

Want:

    3

#### Mechanism

`emitAsUnionCast` asks `unionArmTagsOfTy` for the target's tags. For a record arm it takes
`nominalStructNameOfTy` of the arm's type, the first record declared at that type. `CircleC` and
`Circle` are one type, and `CircleC` is first and is no union arm, so `variantIndexOf` answers -1
and the cast refuses. The cast names `Circle`, and the checker records that declaration on the
cast node (`annDeclPos`); the tag lookup does not read it. This is Family B of the step 7 slot
layer (D3870).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `CircleC` | runs | **yes** |
| `CircleC` declared after `Circle` | runs | **yes** (the first name decides) |
| `as!` → `as?` | still refuses | no |
| the cast → an `if s is Circle` ladder | runs | **yes** |

#### Grading list

The `as?` and `as` spellings; a sub-union target (`as Shape` over `Circle | Sq | E`) with a
same-shape standalone declared first; two unions whose arms share one type (ARM2).
