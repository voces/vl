### D7050 — a generic's `T | B` bound at `T := B` asks a nullable-cell valtype for a `variant` with no row

**closed · was loud emit reject, clause 2 · filed 2026-10-19 against master `6e99938e6` · closed by lane L6 against master `981320f30`**

Repro:

    type B = { x: i32 }
    function orB<T>(v: T): T | B { return v }
    const b: B = { x: 4 }
    print(orB(b).x)
    // vl check: rc 0.  vl run: emitProgram: ref valtype with no interned shape

Want:

    4

#### Mechanism

The refusal was `fbValtype`, reached from `emitOneFuncType` for the instance's parameter
`v: T`, whose `vtKindOfParam` read `variant` with slot -1: `retVariantFlag` asks
`nodeTyIsVariant`, and `cVariantMemberTyIxSet` held `B` because the generic's own annotation
`T | B` registered its members through `annRegisterVariantMembers` (check_inline_lit_union.vl).
At `T := B` the instance's `T | B` is `B` alone, so no union names `B` as an arm and
`variantIndexOf("B")` is -1. The close declines that registration for a member list holding an
open type parameter: such a union exists only in its instances, and an instance that is a
union (`T := C`) registers its own members.
