#### Mechanism

Not ablated to a line. A declared function delivered at `(s: string) => string | i32` reaches the
call through an adapter that boxes its `i32` result into the union; the same function with a
hole parameter is delivered as it is, so the indirect call typed for a union-box result reaches
a function returning `i32`.
