### D13781 — an un-annotated function delivered at a function type with a union result traps on the indirect call

**trap after load · `wasm trap: indirect call type mismatch` in `only` · `vl check` rc 0 · clause 1 · open · the annotated spelling, `function lenOf(s: string): i32`, runs and prints `3`, so the program is legal and must run · found closing [D13740](D13740.md), whose annotated-callee spelling is this row's with a choice in front · present on master `46e8112f6` · filed 2026-10-25 against master `46e8112f6`**

Repro:

    function only(n: string, f: (s: string) => string | i32) {
      return f(n)
    }
    function lenOf(s) { return s.length }
    print(only("abc", lenOf))
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch

#### Mechanism

Not ablated to a line. A declared function delivered at `(s: string) => string | i32` reaches the
call through an adapter that boxes its `i32` result into the union; the same function with a
hole parameter is delivered as it is, so the indirect call typed for a union-box result reaches
a function returning `i32`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the hole parameter (`lenOf(s: string)`) | runs, `3` | **yes** |
| the union result (`f: (s: string) => i32`) | runs, `3` | **yes** |
