### D2221 — an `is` test set containing a float literal answers false for every value

**check-clean silently wrong · `1 | 2.0 | 3` tested with `is 2.0 | 3` prints `false` for `3` and `2.0` · found reviewing D2205's close · filed 2026-09-23 against master `0d5421468`**

Repro (prints `false false false`; right is `true true false`):

    function f(n: 1 | 2.0 | 3) { n is 2.0 | 3 }
    print("\{f(3)} \{f(2.0)} \{f(1)}")
    // PRINTS false false false

#### Mechanism

The same union tested with `is 3` alone answers `true` for `3`, so the failure is the float
literal in the TEST set: its membership compare does not match either member, including the
integer one beside it. D2205's disjoint-set refusal reaches it from the other side: over
`n: 1 | 2`, `n is 2.0 | 3` is refused with the suggestion `declare them in its type: 1 | 2 |
2.0 | 3`, and following it gives this program. Whether `2` and `2.0` should be one literal (and
the suggestion normalise them) is part of the fix.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the float literal in the test set (`n is 3`) | runs, `true` for `3` | **yes** |
| the float literal in the operand (`n: 1 \| 2 \| 3`, `is 2.0 \| 3`) | runs after D2205 (tests the overlap `3`); refused before | **yes** |
| an integer member beside it in the operand (`n: 1 \| 2 \| 2.0 \| 3`) | wrong value | no |
