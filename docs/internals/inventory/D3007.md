### D3007 — a record literal assigned by a bare-name store to a wider declared binding is not built at the binding's record

**check-clean invalid wasm · identical on master `b34730ad9` and on #3253 · found by the #3253 review grid · filed 2026-09-28**

Repro:

    type D = { v: f64 }
    const x: i32 = 3
    let slot: D = { v: 1.5 }
    const o = { v: x }
    slot = o
    print(slot.v / 2.0)
    // vl check: rc 0.  vl run: invalid module — type mismatch

Want:

    1.5

#### Mechanism

#3253 taught the D2933 use walk that a store into an element or field place is a delivery (`rsPlaceStoreTy`), but a bare-name store `slot = o` still goes through `rsElemAssignSafe`, which clears it unless the literal came from the same list. `slot` is declared `D`, so the literal should be built at `D`.
