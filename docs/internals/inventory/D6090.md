Repro:

    function same<T>(k: T): T { k }
    function take(a) {
      print(a("x"))
    }
    function take2(a) {
      print(a(3))
    }
    function mid<F>(a: F, a1: F) {
      take(a)
      take2(a1)
    }
    mid(same, same)
    // vl check: rc 0.  vl run: exit 70, the emitted module failed to validate inside `take2`: type mismatch: expected (ref $type), found i32

Want:

    x
    3

#### Mechanism

From the ablation only. `a` and `a1` share the type parameter `F`, so `mid`'s instance key
gives both one function type, and `take2` receives the `(string) => string` instance where
it calls at `i32`. Each parameter is called at ONE type, so this is not D5611's per-key
split, which reads a single parameter's calls.
