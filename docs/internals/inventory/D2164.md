#### Mechanism

Not yet ablated past the rows below. A list literal is built at the type it flows into, and a
spread element copies its source's elements one by one into the new list; the checker accepts
each spread element against the destination's element type, and the emitted copy appends the
source's elements without converting them. This matters more after the 2026-09-23 ruling (no
implicit container widening): the refusal tells the user to build the list at the wide type or
copy it, and `[...a]` is the first copy most users will write.

#### Grading list

refusal names no `.map` for a nested pair; re-grade it with whichever row closes first.
