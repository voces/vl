### D15978 — a `flat` field's sub-word width has no type: `i8`, `i16` and `u16` check as `u8`, and a computed value is not narrowed

**open · loud check reject · `the literal -3 does not fit a \`u8\` element (0..255)` · clause 2 · a `u8` field and a non-negative `i8` literal under 128 run; offsets and the byte intrinsics on the same declaration run (`tests/cases/memory/flat-sub-word-widths.vl`) · found by lane H grading `flatHasSubWordField`'s contract · filed 2026-11-12 against master `82ca1ef1`**

Repro:

    flat type P = { a: i16, c: i32 }
    const p: P = { a: -3, c: 7 }
    print(p.a)
    print(p.c)

Want:

    -3
    7

#### Mechanism

The arena has a `u8` primitive and nothing for `i8`, `i16` or `u16`. A `flat` field's width
lives only in its spelling: `flatStorageSpellWidth` (`check_leaf_steps`) reads it for the
layout, and `flatHasSubWordField` (`emit_collect`) reads it to mark the record layout-only.
The field's TYPE resolves every sub-word spelling to `u8`, so a literal is range-checked as a
`u8` and the message names `u8`. Nothing in DECISIONS rules whether a layout-only `flat` is a
value at all. Its designed use is offsets plus the byte intrinsics; the checker accepts a
record literal of one, and builds it as a struct of `i32` slots.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `a: u8` with `200` | runs, `200` | **yes** (the width) |
| `a: i8` with `100` | runs, `100` | **yes** (the literal outside `u8`) |
| `a: i16` / `u16` / `i8` with `300`, `60000`, `-3` | the same refusal, naming `u8` | no |
| a computed `i32` (`function mk(v: i32): P { { a: v, c: 7 } }`) with `-300` or `70000`, any width | runs, prints the value unnarrowed | — |
| the same computed `300` pushed into a `u8[]` | runs, `44` | — |

The last two rows disagree: a `u8[]` element narrows a computed value to its low 8 bits, while
a `u8` field of a `flat` value keeps the full `i32`.

#### Grading list

The ruling comes first: either a `flat` holding a sub-word field is layout-only and its record
literal is refused by a sentence naming that contract, or it is a value whose field narrows
like a `u8[]` element. Under the second, the arena needs a type per width, and
`flatHasSubWordField` reads the type rather than the spelling. Re-grade each width with a
literal and with a computed value, a nested layout-only `flat`, and the fixture.
