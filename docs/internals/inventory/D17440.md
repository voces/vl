### D17440 — an imported `new` record type as a union member has no interned shape

**loud emit reject · clause 2 · found by the D17380 niche sweep (the `std:buffer` view arm), the same on master and claimless · owner S2 · filed 2026-11-24 against master `69d0467e`**

Repro:

    import { U8View } from "std:buffer"
    function f(w: U8View | string) { print(1) }
    f("s")
    // vl check: rc 0.  vl run: emit error: emitProgram: ref valtype with no interned shape

Want:

    1

#### Mechanism

Unlocated. The union's struct box asks for the heap shape of its record arm, and a `new` record
declared in another module has none interned when the box is laid out. The same `new` record
declared in the program's own module has one, and so does an imported plain record.

#### Ablation

| ingredient | outcome |
| --- | --- |
| `U8View \| string`, `U8View \| i32`, `U8View \| null \| string`, `F32View \| string` | emit reject |
| a `new` record declared in a local module and imported (`LV \| string`) | emit reject |
| the same `new` record declared in the program's own module | runs, `1` |
| an imported plain record `{ base: i32, length: i32 }` | runs, `1` |
| `U8View \| null` (no second non-null arm) | runs |
| `U8View[] \| string` (the view inside a list) | runs, `1` |

#### Grading list

- Each `std:buffer` view type (`U8View`, `U16View`, `I32View`, `F32View`) beside `string`, `i32`
  and `null`, at a parameter, a narrowed `.length` read and a copy out of the narrowing.
- The D17380 niche sweep's `view` cell (`U8View | null | string` narrowed to `U8View | null` and
  copied out).
