### D3940 — a generic function delivered as an element of a nullable-function list literal or push traps

**loads then traps · found in review of #3494 (`rv3494/k_list_lit_single`, `j_list_*`) and #3493 (`rv3493/f3`; `f3b` is the control) · filed 2026-10-10 against master `00bf1871f`**

Repro:

    function b<U>(y: U) { print("G"); print(y) }
    function a<T>(x: T) {
      const l: (((t: T) => void) | null)[] = [b]
      const e = l[0]
      if e != null { e(x) }
    }
    a("s")
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch

Want:

    G
    s

#### Mechanism

Not located. The element type `((t: T) => void) | null` is nullable, so the list-literal
coercion and the push path, which read a bare function element, do not instance `b` at it
(D3932 peels `| null` at a scalar slot only). The non-null literal runs; pushing an alias into
such a list traps the same way (f3), and pushing `inner` itself runs (f3b).

#### Ablation

| ingredient changed | outcome on master | needed? |
| --- | --- | --- |
| the element non-nullable | runs | **yes** |
| `fs.push(inner)` instead of an alias (f3b) | runs | **yes** |
