### D2416 — a `??` join typed only at a hole parameter's pin is never registered, so it lowers without its union box

**check-clean invalid wasm · clause 1 · found grading D2383's `argument` position (`pin2-coalesce-join-nulbool` matrix) · filed 2026-09-25 against master `a277bf7b0`**

Repro:

    type A = { r: i32 }
    function st(): A { return { r: 8 } }
    function mkB(): boolean | null { return null }
    function take(a) {
      const f = a ?? st()
      if f is A { print(f.r) } else { print(0) }
    }
    take(mkB())
    // vl check: rc 0.  vl run: invalid module, inside `take`:
    // "type mismatch: expected i32, found (ref $type)".  Expected: 8

#### Mechanism

A prediction until a close confirms it. With `a` un-annotated, the join `boolean | A` exists
only in the pinned instance's types, and nothing registers it as a union row or reserves the
value boxes its atoms need. `coalesceNicheJoinsToBox` reads the result through
`coalesceResultUnionName`, which finds no row, so the `??` keeps the niche's own `i32`
lowering and the record default lands in it. The same pin with a `boolean | i32` join finds
the name but no reserved `i32` value box (`vbHeapIdxOfKind`), and refuses loudly. It is not
specific to the boolean niche: a `string | null` operand with an `i32` default refuses with
`union atom has no value box` on the same pin.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `a` annotated `boolean \| null` | runs, `8` | **yes** |
| `a` generic, `a: T \| null` | still invalid | no, a pin either way |
| the default `7` instead of a record | loud emit reject, `` `??` joins a nullable value into a union with no arm for the value's own type `` | no, the other face |
| the operand `string \| null`, the default `7` | loud emit reject, `union atom has no value box` | no |
