#### Mechanism

Three sites key a closure element or slot whose function type is open at the `() => void` stub
(D4551, D4123): `fnElemRowTy` (emit_shape_rows.vl), `arrLitClosureElemTy` (emit_classify.vl) and
the closure-element name in `check_emit_queries.vl`. Giving a function open only at inference
holes D9100's `(i32) => i32` default there (the coordinator's ruling for D17743) cost these two
programs: the stub is the instance key of a hole lambda each instance binds and calls, not an
uncalled default. The uncalled default reaches every uncalled holder through the literal's stamp
instead (`elabHeldFnLitStamps`), so the sites keep the stub until instance keying owns them.
