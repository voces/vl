### D15189 — a list binding holding a list built at a wider record, reassigned with a list literal, is check-clean invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · open, target `7` then `4` · found closing [D15188](D15188.md), its list twin · filed 2026-11-04 against master `dc27d0a9` plus [D15185](D15185.md)**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const xs = [mk()]
    let b = xs
    b = [{ f: 7 }]
    print(b[0].f)
    print(wideJ.f ?? 0)

Want:

    7

#### Mechanism

`b` holds `xs`, whose elements are built at `J`, and the assigned list literal is built at its own
`{f: i32}[]`. D15188's pass-end stamp would build it where `b` is stored, but `recBuiltReadTy`
answers only a record read, never a list, so `recAsgBuiltRep` has nothing to stamp.
