### D16989 — `is K[]` over a box union's record-list arm answers by tag, so an arm whose every record is a `K` reads false

**closed 2026-11-19 by lane F1 · runs, prints `true` · was check-clean silently wrong, clause 1 · the record-list stage of the 2026-11-18 ruling (DECISIONS, "`is K[]` tests a list's contents"); D16970 fixed the numeric lists · closed by testing a record-list arm whose records may each be a `K` by its fields (`listArmRecFits`, `check_fit_rules.vl`) record by record (`emitListRecArmFit`, the single-record field test `emitRecordFitCore` per element), an empty arm fitting; inside the arm the record arm keeps its own type beside `K[]`, so a read at `K` is refused until the in-arm view is ruled, as D16970's · a `W` wider than `K` by a field is no `K` record by record, as a single `w is K` answers · pins: `tests/cases/arrays/is-record-list-over-record-list-arm.vl`, `tests/cases/arrays/error-is-record-list-arm-read-at-narrowed-record.vl` · found by lane F2 grading D16970 · filed 2026-11-18 against master `53ff806b2` by lane F2**

Repro:

    type W = { x: i32 | null }
    type K = { x: i32 }
    const a: W[] = [{ x: 1 }, { x: 2 }]
    const q: W[] | K[] = a
    print(q is K[])
    // was: prints false

Want:

    true

#### Mechanism

`is K[]` over a box union tests a list arm by its elements only for the string and numeric arms
(`listArmFitAcrossReps`, `emitListIsAcrossReps`); a record-list arm stored apart from `K[]` is
tested by its tag alone, so a `W[]` whose every record is a `K` (and an empty one) reads false.
Testing it needs an element `is K` per record, and the in-arm `K[]` value a converting record view
(`rvEmitView`), which waits on the view ruling.

#### Ablation

| change | outcome | needed? |
| --- | --- | --- |
| `a = [{ x: 1 }, { x: null }]` | prints `false` (right) | **yes** (records that fit) |
| `a = []` | prints `false`, where an empty list fits | no |
| `u8[] \| K[]` with `K = 1 \| 2` | prints `true` after D16970 | **yes** (the record arm) |
