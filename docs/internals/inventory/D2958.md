### D2958 — a union of an anonymous record and `i32` makes an `is` over another scalar union refuse at emit

**loud emit reject · clause 2 · found by D2955's fixture · the same on master `fe1fa1bec` · filed 2026-09-28 against master `fe1fa1bec`**

Repro:

    function first<T>(a: T, c: boolean) {
      const r: T | i32 = if c { a } else { 5 }
      if r is i32 { print(3) } else { print("x") }
    }
    const rec = { x: 9 }
    first(rec, false)
    function h(a: f64, c: boolean) {
      const r: f64 | i32 = if c { a } else { 5 }
      if r is f64 { print(r + 0.5) } else { print("no") }
    }
    h(2.5, true)
    // vl check: rc 0.  vl run: emitProgram: `is` names a declared union member with no interned arm representation

Want:

    3
    3

#### Mechanism

Not localised past the ablation. The `is` over `f64 | i32` in `h` reaches the variant ladder at
the foot of `emitIsTest` instead of the box-tag compare, so its union is not read as a box
there. `h` needs no type parameter. What it needs is another function's pin that unions an
anonymous record with `i32`.

#### Grading list

The same program with `h` generic at the `f64` pin (`h<T>(a: T, …)`, `h(2.5, true)`), which
refuses with `is` names a type that is not a union variant, and D2957's early-return guard at
the `f64` pin beside an anonymous record pin.
