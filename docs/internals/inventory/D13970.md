### D13970 — a list literal whose first element holds an un-annotated function joins at that function's open type and refuses a typed record after it

**loud check reject · `a {f: (i32) => i32} cannot be delivered as {f: (_) => _} here: it reaches the call to `l[…].f` on line 5, a function value this check cannot see the body of` · clause 2 · found closing D13969's field-call adoption, which routes [D9534](D9534.md) here · present on master `935da52aa` · filed 2026-10-26 against master `935da52aa`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a: i32): i32 { return a * 2 }
    const r0: { f: (a: i32) => i32 } = { f: dbl }
    const l: { f: (a: i32) => i32 }[] = [{ f: inc0 }, r0]
    print(l[1].f(3))
    // vl check rc 1. Expected: 6.

#### Mechanism

The list literal's own type is the join of its elements, and the first element
`{ f: inc0 }` gives `{f: (_) => _}`, an open function. The covariant-delivery check
(`rcwPendJoins`) then delivers `r0`, a typed record, into that joined element type rather
than into the declared `{f: (a: i32) => i32}[]` the literal is built at. The program is
fully annotated, so nothing the refusal names is a design rule.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| element order (`[r0, { f: inc0 }]`) | runs, `6` | **yes** |
| `inc0` un-annotated (`inc0(a: i32): i32`) | runs, `6` | **yes** |
| a named function (`{ f: (a) => a + 1 }`) | runs, `6` | **yes** |
| the call through the list (`print(l.length)`) | runs, `2` | **yes** |
| `l`'s annotation (`const l = …`) | same refusal | no |
| a typed `r0` (`dbl(a)`, `const r0 = { f: dbl }`) | runs, `6`: `r0` is a fresh literal binding, which the check exempts | **yes** |

With `l` un-annotated as well, that last spelling is [D9534](D9534.md). D13969's field-call
adoption builds `r0` as `{f: (i32) => i32}` there, which gives `r0` a type of its own and
reaches this refusal.

#### Grading list

The second delivery position, a list literal argument to `run(l: { f: (a: i32) => i32 }[])`
with `run([{ f: inc0 }, r0])`, gives the same refusal.
