### D2017 — a closure's capture set is recomputed from its whole body on every capture query before the capture cache is built, so a long closure body compiles in O(n²)

**closed 2026-09-23 — the witness builds in 0.03 s CPU where master `7cb12a61d` took 3.0 s, and the 2,500-arm `match` in 0.14 s where it took 127 s; output byte-identical · was a compile-time cost, not a miscompile: every spelling ran · residue of D1990's close · filed 2026-09-22 against master `ad8712231` + D1990 · residue D2130**

#### Mechanism

`capturedKindOf` (compiler/emit_classify.vl) answers "is `name` a capture of this closure" by
asking `captureNamesOf`, which reads the capture cache only once `capCacheBuild` has run
(`capCacheOn`, set when emission starts). Every classify-phase query before that — one per read
of a name the closure does not bind itself — calls `capComputeNamesOf`, which re-walks the
whole lifted body with `capScan`. A body of n nodes holding n such reads is n walks of n
nodes: at 500 links, 97% of the build's profile is inclusive under `capComputeNamesOf` called
from `capturedKindOf`.
D1990 made the walk iterative, so the chain no longer traps; it did not make it cheaper.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the chain moved into a top-level `function` reading the same global `k` | 0.01 s — linear | **yes** (the closure) |
| every `k` replaced by a literal | 0.01 s — linear | **yes** (a read the closure does not bind is what gets queried) |
| links halved | cost falls ~4x | **yes** (it is the n² term) |

#### Close

`captureNamesOf` keeps each walk in a pass memo while `emitProgram` arms it, which it does for
the passes that either leave the arena and the tables `capScan` reads alone
(`computeRetInference`, `computeRetInference#2`) or report every edit that mints no node
(`dispatchRewrite`, whose `??` fold and default-argument fill call `capMemoNoteEdit`). A memo
answer is dropped when the pass ends, when `P.nodes` grows, or on a reported edit; a recording
walk (`capNarrowBuild`) and a sibling walk under way bypass it. The rewrite pass was the second
half of the cost: memoising the classify pass alone left 2,500 arms at 2.3 s, all of it
`drwWalk` → `structIndexOfExpr` → `capturedKindOf`.
