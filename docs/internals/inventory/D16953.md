### D16953 — a generic list of a pinned union, stored into a pinned record's field, builds invalid wasm: the list literal finds no rep for its instance type

**check-clean invalid wasm · clause 1 · found ablating [D16947](D16947.md) · filed 2026-11-17 against master `a1902979a` (the same on `586cc6b4c`, before [D2681](D2681.md))**

Repro:

    type IM = {[i32]: i32}
    function h<V>(x: IM) {
      const xs: (V | IM)[] = [x]
      const b: { v: (V | IM)[] } = { v: xs }
      return 0
    }
    const m: IM = Map()
    print(h<string>(m))
    // vl check: rc 0.  vl run: invalid module, type mismatch inside `h`

Want:

    0

#### Mechanism

The local `xs` is declared at the list of union boxes `(string | IM)[]` is, but its literal is built
as a list of bare maps. The literal's instance type renders `(string|{[i32]:i32})[]` in both this
program and the one without the record line, which runs; here `repOfTy` of it answers no rep, so
`listBuildOfTy` declines and the literal falls back to its own shape's build (a ref list of maps).
Where the record's delivery of `xs` keeps that type from a rep is not yet traced.
