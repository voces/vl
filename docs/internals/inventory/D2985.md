### D2985 — `idh(l[0])` inside an explicit `<T>` instance at a nullable niche pin prints the niche's `i32`

**check-clean silently wrong · clause 1 · the LU2 grid's `S_s13_g` row at the `AB | null` and `boolean | null` pins · pre-existing on master `4dc94bd23` · filed 2026-09-28 against master `4dc94bd23`**

Repro:

    type AB = "a" | "b"
    function idh(z) { return z }
    function f<T>(x: T) {
      const l = [x]
      print(idh(l[0]))
    }
    const v: AB | null = "b"
    f(v)
    // vl check: rc 0.  vl run: prints `0`

Want:

    b

#### Mechanism

Not localised. The hole callee `idh`, called from an explicit instance with an element of a list
built over `T`, returns the niche's `i32` and `print` takes the `i32` import. The hole spelling of
the caller runs since [D2978](D2978.md), and so does the call without the list, so the missing
link is the explicit instance handing `idh` the pin of a list element.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the caller as a hole (`function f(x)`) | prints `b` | **yes** |
| no list (`print(idh(x))`) | prints `b` | **yes** |
| a non-null `AB` pin | prints `b` | **yes** |
| `ide<T>(z: T): T` in place of `idh` | prints `0` | no |
| a `boolean \| null` pin, `null` | prints `2` | no (the niche twin) |

#### Grading list

The LU2 grid's `S_s13_g` row (`scratchpad/LU2/gen.py`) at the `nab`, `nabn`, `nxyz` and `nbool`
pins.
