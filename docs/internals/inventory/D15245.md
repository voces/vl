### D15245 — a direct call through a call-bound binding's widened function field adopts the returned literal at its one closed instance, so the set stays a closure

**open · loud emit reject · `emitProgram: cannot take the generic function id0 as a value — a function value carries ONE signature` · clause 2 · the bound read (`const g = r.f; g(2)`) runs since D15270 · found grading D15270's two-caller witness · filed 2026-11-04 against master `ccfdb7a33` with D15270**

Repro:

    function id0(a) { return a }
    function id1(a) { return a }
    function mk() { return { f: id1 } }
    const r = mk()
    r.f = id0
    print(r.f(2))
    print(r.f(2.5))

Want:

    2
    2.5

#### Mechanism

The call `r.f(2)` is typed and noted through the widened set `{id0, id1}`; what fails is the
smaller set `{id1}`, which `fnWidenedSourceSets` (D15270) hands `ftPlan` beside it. The member call
runs `holeFieldCallAdopt`, which adopts the receiver's source records, `mk`'s returned literal
among them, at the call's one closed instance, so `ftRecHolds` reads the literal's field as a
closure and `ftCtxOk` fails at `f: id1`. Measured by G2 on a one-level seed; `const g = r.f`
makes no member call and adopts nothing.

| a second, unwritten caller (`const s = mk()`) | still refuses | no |
