### D4877 — an un-annotated list literal of a fresh `i32` list and an existing `f64[]` builds the outer list at the `i32[]` row

**check-clean invalid wasm · clause 1 · found closing D4876, grading an existing list beside its fresh-literal witness · filed 2026-10-15 against master `3affca3dd`**

Repro:

    const fs: f64[] = [2.5]
    const v = [[1], fs]
    print(v[0][0] / 4.0 + v[1][0])
    // vl check: rc 0.  vl run: invalid module, type mismatch: expected (ref null $3), found (ref $7)

Want:

    2.75

#### Mechanism

Not yet ablated past the table. The checker joins the element to `f64[]` (the fresh `[1]`
adapts), but the element row is keyed from the first inner literal's leaf, and an element that
is not a literal has no leaf for that probe to read, so the outer list is built at `i32[]`.
