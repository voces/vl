    function inc(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function deliver() { return [inc, dbl] }
    function take(a) { print(a.map((f) => f(3))[1]) }

#### Mechanism

`take` is instanced at its argument's type, and the call `deliver()` was typed as its open
returned literal, because nothing read the call at the pin its literal takes before `take`'s
instance was minted. The read is declined when the slot takes two pins: a returned literal whose
reads are delivered apart (an index read at `i32` and another at `string`) must stay open, and
closing it there turned a running program into a refusal.
