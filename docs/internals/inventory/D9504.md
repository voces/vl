### D9504 — a returned list of un-annotated functions handed to an un-annotated parameter has no argument type

**loud emit reject · `vl check` rc 0 · `monomorphize: unsupported argument type for `a``, no position · clause 2 · found closing [D9450](D9450.md) · present on master `56e51b394` · filed 2026-10-21 against master `56e51b394`**

Repro:

    function inc(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function deliver() { return [inc, dbl] }
    function take(a) { print(a.map((f) => f(3))[1]) }
    take(deliver())
    // vl check rc 0.  vl run: emit error: emitProgram: monomorphize: unsupported argument type for `a` in a call to `take`

Want:

    6

#### Mechanism

Not traced. `take` is instanced at its argument's type, and the call `deliver()` is typed as its
open returned literal, because nothing delivers the literal's functions at a pin before `take`'s
instance is minted.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the return (`take([inc, dbl])`) | runs, `6` | **yes** |
| the `.map` callback (`print(a[1](3))`) | same refusal | no |
