### D15305 — a function of an un-annotated parameter returning one of two record literals of different un-annotated functions is refused at emit, in words naming a mechanism

**open · loud emit reject · `emitProgram: object literal field count does not match struct` · clause 2 · the parameter annotated runs since D15277 · found grading D15277 · filed 2026-11-04 against `lane/g2-res` `58dda4f44` with D15277**

Repro:

    function id1(a) { return a }
    function id2(a) { return a }
    function mk(c) {
      if c { return { f: id1 } }
      return { f: id2 }
    }
    print(mk(true).f(2))
    print(mk(false).f(2.5))

Want:

    2
    2.5

#### Mechanism

Before D15277's close this refused as its no-parameter twin did (`cannot take the generic
function id1 as a value`). With the returned join holding each return's set, `mk` is still a
generic, its un-annotated parameter a hole, and each instance builds its own returned literal
apart from the join's row. The new sentence names an emitter mechanism (a struct's field count),
not a contract the program broke, so it is a clause-2 floor, not a refusal the design owes.
