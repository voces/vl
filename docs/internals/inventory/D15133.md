### D15133 — the checker owes D2161's refusal for a mutable alias of a list of a function set at a closed function type

**loud emit reject · clause 2 · `the reassigned function binding f holds functions called at more than one argument type` · `vl check` rc 0, so the emitter is the first stage to refuse a program the design forbids · found closing D15069 · filed 2026-11-03 against master `91585f3a`**

Repro:

    function id<T>(x: T): T { return x }
    function dbl<T>(x: T): T { return x + x }
    let f = id
    f = dbl
    print(f("s"))
    print(f(1))
    const zs = [f]
    const ys: ((x: i32) => i32)[] = zs
    print(ys[0](41))
    // vl check: rc 0.  vl run: emit error, with the split plan on and off

#### Mechanism

`ys` is a mutable list bound to the same list as `zs`, whose elements are the set `{id, dbl}`
called at two types. A readonly destination is copied through adapters (`fvaListSetCopy`,
D15069), but a mutable one aliases the source, and a covariant mutable list is refused by design
(D2161). The checker accepts the binding, so the refusal arrives at emit: the checker owes it,
naming the alias and offering `readonly` or an annotated source list.
