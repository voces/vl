### D4922 — a `T[] | i32[]` parameter binds no `T` from a union argument, so a record of its complement matches no row

**loud emit reject · clause 2 · found closing D4899 · identical on master `c2dbf639e` · filed 2026-10-15**

Repro:

    function h<T>(v: T[] | i32[]) {
      if v is i32[] { print(0) } else {
        const r = { xs: v }
        print(r.xs[0])
      }
    }
    const a: string[] | i32[] = ["e"]
    h(a)
    // vl check: rc 0.  vl run: emitProgram: object literal matches no union variant

Want:

    e

#### Mechanism

Check-side. The checker records the parameter `T[] | i32[]` as `T[]` (a `const y: boolean = v`
in the body reports `T[]`), and a union argument binds no `T`: with a `: T[]` return, `h(a)`
types as an unbound `T[]` where `h(["e"])` types as `string[]`. At emit `monoExactBind` walks
`T[]` against `string[] | i32[]` and binds nothing, so no exact row exists and the literal's
field has no pinned type. The hole face of the same program runs since D4899. Same area as
D2859's annotated `: T[] | i32[]` return collapsing to `T[]`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the record (`print(v[0])`) | runs | **yes** |
| the union argument (`const a: string[] = ["e"]`) | runs | **yes** |
| the read (`print(1)` after building `r`) | still refused | no |
| the type parameter (`function h(v)`) | runs | **yes** |
