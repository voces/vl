#### Mechanism

`g` infers `{a: i32[], f: () => i32}`, and the closure is built at `() => i32`. Delivered to a
record destination, the same value is refused by the function-value variance rule ("a call
through that type would…"). Delivered to a union holding that record as an arm, no such check
runs, and the narrowed call dispatches on `() => i64`.
