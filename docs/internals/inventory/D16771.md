### D16771 — a function that binds a maker's hole lambda and returns the binding, delivered at two function types whose results differ, builds one closure for both

**closed · runs, prints `4` `0.5` · was loads then traps · `vl check` rc 0, `wasm trap: indirect call type mismatch` at the second call · clause 1 · the bound face of [D16770](D16770.md); [D16753](D16753.md)'s close does not reach it · filed 2026-11-16 against master `464dfd28c` · closed by [D16755](D16755.md)'s relay twins reaching a returned binding: the checker counts a returned un-annotated `const`, read only there, as the call it holds, and each relay twin builds its own copy of that call · fixture `closures/lambda-maker-relay-bound-at-two-results.vl`**

Repro:

    function deliver() { return (a) => a + 1 }
    function relay() {
      const f = deliver()

    const v: (a: i32) => i32 = relay()

#### Mechanism

Not traced. The direct relay (`return deliver()`) reaches the emitter's refusal of one returned
value delivered at two function types ([D16770](D16770.md)); bound first, the returned value is
the binding `f`, which that check does not see, and one `i32`-returning closure serves both
deliveries, as in [D16753](D16753.md) before its close.
