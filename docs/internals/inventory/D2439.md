### D2439 — an assignment's value into a generic `T | string` box is the box in the `i32` instance

**check-clean invalid wasm · clause 1 · filed 2026-09-25 against master `a20d69104`, the
review residue of [D2391](D2391.md)'s close**

Repro:

    function h<T>(e: T): T {
      let v: T | string = "z"
      return (v = e)
    }
    print(h(5) + 1)
    // vl check: rc 0.  vl run: invalid module inside `h`: type mismatch: expected i32, found (ref $type)

#### Mechanism

The narrowed re-read asks the checker's type of the assignment node, and in a monomorphized
instance body that node carries the type variable, not `i32`, so `asgReadNarrowTy` finds no
member and the value stays the box while the instance's functype says `i32`. A prediction
from the close's code path, not yet probed.
