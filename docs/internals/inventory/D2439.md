### D2439 — an assignment's value into a generic `T | string` box is the box in the `i32` instance

**closed · runs, prints `6` · was check-clean invalid wasm, clause 1 · closed by letting the
value-position write spill (`asvTypeMoves`, emit_rewrite.vl) move a write whose types hold a
declared type parameter, judged at the place's declared type when instances store it apart ·
fixture `generics/assignment-value-into-type-param-union-box.vl` · filed 2026-09-25 against
master `a20d69104`, the review residue of [D2391](D2391.md)'s close**

Repro:

    function h<T>(e: T): T {
      let v: T | string = "z"
      return (v = e)
    }
    print(h(5) + 1)
    // vl check: rc 0.  vl run: invalid module inside `h`: type mismatch: expected i32, found (ref $type)

#### Mechanism

Measured 2026-11-01. The concrete spelling spills the right side (`const asg#N#nv = e; v = nv`)
and yields the spill; `asvTypeMoves` refused any write whose types held a type variable, so the
generic template re-read the place instead, and the `i32` instance returned the `T | string` box.
With two instances that store the place apart (`h(5)` and `h("a")`), the checker's store column
for the shared node is left a hole as well, so the spill has to be judged at the place's
declared type.
