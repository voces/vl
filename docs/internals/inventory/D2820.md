### D2820 — an element of a generic call's boolean list, printed inside another generic's instance, prints as a number

Repro:

    function p<T>(t: T, c: boolean) {
      if c { return [t] }
      [t]
    }
    function k<T>(t: T, c: boolean) {
      print(p(t, c)[0])
      0
    }
    k(true, true)
    // PRINTS true
    // Was: prints 1.

#### Mechanism

`print` picks its rendering from the element read's classification (`exprIsBool` →
`listElemIsBool`), and a call receiver has no rung there: the call node's recorded type is the
template's `T[]`, and the callee's pinned instance, which declares `boolean[]`, is never asked.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the outer generic (`print(p(true, true)[0])` at top level) | prints `true` | **yes** |
| the call (`const r = p(t, c)` then `print(r[0])`) | prints `true` | **yes** |
