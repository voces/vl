    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq

      const other: Shape[] = [{ r: 1 }]
      other.push({ s: 2 })

      const b: Shape[] = a

      print(sf.xs.length)
      print(other.length)
    }
    f()
    // vl check: rc 0.  vl run: prints 1 then 2.

#### Mechanism

`cwClaimed` is a whitelist: every occurrence of an alias-set name must be a binding
initializer, either side of an assignment, a call argument, a member-access object or an index
array, and anything else leaves the set unclaimed and the write state `2` (unknown). A value
delivered to a STRUCT FIELD (`{ xs: b }`), to a NESTED ELEMENT (`[b]`) or out through a RETURN
had no arm, so any unrelated write in the program — which is all `cwProgramHasWrite` asks —
dropped the state to `2`. `rlWidenAllowed` then declined the element-converting copy, since
only a definite 0 overrides the rep-scoped answer, and the emitter went on to build a module
the engine refuses instead of failing loudly. The store twins `w.f = b`, `xs[i] = b`,
`m[k] = b` and `xs.push(b)` are the same delivery one syntax over, and `cwGrow` declined all
four as "the value goes inside something".

The literal and store deliveries are filed as CONTAINER ESCAPES — D852's object-literal edge
widened to an array or map element (under `CW_ELEM_FLD`, a key no field name can spell) and
from a literal to an assignment or a `push` — so a read back out of the container matches the
recorded pair and the write scan sees every handle. The return needed a fourth closure edge:
the value leaves under no name, so the closure roots at the CALL RESULT, and a call of a
function whose return carries a member binds its destination into the set.

`cwClaimed` is the single home of "is this delivery claimed" for all four deliveries, and both
gates live there: the container must be SEALED (bound once, never re-pointed, used only by
projecting out of it), and a return is claimed only where every call of that function delivers
into a destination the closure followed. A second predicate answering either question is what
would let them disagree.
