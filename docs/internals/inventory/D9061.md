### D9061 — an un-annotated map or list of un-annotated functions, held in an un-annotated record field, has no field representation

**loud emit reject · `vl check` rc 0 · `emitProgram: ref valtype with no interned shape` · clause 2 · found closing [D4579](D4579.md) and [D9040](D9040.md) · present on master `16cf779bd` · filed 2026-10-21 against master `16cf779bd`**

Repro:

    function inc0(a) { return a + 1 }
    const m = Map()
    m["k"] = inc0
    const r = { m: m }
    const x = r.m["k"]
    if x != null { print(x(3)) }
    // vl check rc 0.  vl run: emit error: emitProgram: ref valtype with no interned shape

#### Mechanism

Not traced. The map binding now takes `{[string]: (a: i32) => i32}` from its write
(D9040), but the record literal `{ m: m }` is typed from the checker's open field type,
and the call `x(3)` reads through the record. The list spelling fails the same way on
master, so this is the record field holding a container whose element is an open
function, not a map-only gap.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the map (`const xs = [inc0]`, `const r = { xs: xs }`, `r.xs[0](3)`) | same refusal | no |
| the un-annotated map (`const m: {[string]: (a: i32) => i32} = Map()`) | runs, `4` | **yes** |
| the record (`const x = m["k"]`) | runs, `4` | **yes** |

#### Grading list

The list spelling above; [D9062](D9062.md), where the map is the record's own literal.
