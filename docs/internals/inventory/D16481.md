### D16481 — a record literal holding a vector is refused before it widens to an `F32x4 | null` field

**loud check reject · clause 2 (capability): the refusal recommends `v128 | null`, and the declared record already uses it · found by D16480 · filed 2026-11-15 against master `d01496801`**

Repro:

    import { F32x4, splatF32 } from "std:simd"
    type Body = { p: F32x4 | null }
    const b: Body = { p: splatF32(1.0) }
    print((b.p ?? splatF32(0.0)).x)
    // vl check: {p: F32x4} holds a 128-bit vector inside an array, struct field or map, which has
    //   no lowering yet

Want:

    1

#### Mechanism

The literal's own type is `{p: F32x4}`, and `v128NestCheck` refuses it before the annotation
widens the field to `F32x4 | null`. Writing `{ p: null }` and then `b.p = splatF32(1.0)` runs.
Lowering a bare `F32x4` field (D16480's design) closes this too.
