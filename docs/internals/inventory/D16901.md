### D16901 — a lambda's record result at a generic's `() => T | string | null` is refused by monomorphization

**loud emit reject · clause 2 · `vl check` rc 0 · `emitProgram: monomorphize: unsupported argument type for \`f\` in a call to \`get\`` · found grading [D14082](D14082.md) · pre-existing on master `d7a6bf679` · filed 2026-11-16 by lane AE4**

Repro:

    type P = {a: i32}
    function get<T>(f: () => T | string | null) {
      f()
      return 7
    }
    print(get(() => ({a: 2})))

Want:

    7

#### Mechanism

Not traced. The instance's argument type is the lambda's `() => P` handed to
`() => P | string | null`, a union of a record, a scalar and `null`, which monomorphization has
no argument rep for. [D14082](D14082.md)'s `T | string` spelling runs.

#### Ablation

| --- | --- | --- |

| `() => T \| null` | runs | **yes** |
| `get<P>(…)` explicit | runs | **yes** |
| `(): P => ({a: 2})` annotated | still refuses | no |
| `T \| i32 \| null` | still refuses | no |
