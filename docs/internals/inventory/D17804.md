#### Mechanism

The holder path (emit_elab `elabHolderRecordWith`) keeps a call's record whole in a binding only
when every write to it is a call returning the same record, so a write of a function value marked
the binding badly written and the maker's call was picked with no member (`bpHeap` -2). The close
counts a plain write of a named function as one of the binding's writes (`elabResFnWrites`): it
agrees where the function is a producer or a wrap at the record, the holder keeps the record whole
because the write builds it, and the write is registered as the slot note registers its values.
