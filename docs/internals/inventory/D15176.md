### D15176 — an un-annotated function popped off a list at module scope and called has no interned signature

**closed · runs, prints `6` · was loud emit reject, `a function-value call has no interned signature — parameter 1 of type` · clause 2 · found planning [D15174](D15174.md) · filed 2026-11-03 against master `1cce3e60a` · closed 2026-11-03: a list's `pop` and `get` are slot reads of its set (`ftSlotOp`, check_fn_tag.vl), and a read of a tagged set's `F | null` boxes the member id as a nullable `i32` (`popNulTagId`, wasmEmit.vl) · fixture `tests/cases/closures/fn-list-pop-get-un-annotated-member-called.vl`**

Repro:

    function half(a) { return a * 2 }
    const m = [half]
    const g = m.pop()
    if g != null { print(g(3)) }
    // Want: 6

#### Mechanism

The value `pop` returns, narrowed and called, was not followed by the function-set machinery, so
no instance of `half` at the call's `i32` argument is built and the emitter finds no signature
for the call. The map spelling at module scope (`m.get(k)`, narrowed, called) runs, so whatever
follows that read is the producer this one lacks. [D15175](D15175.md) is the same read through a
hole parameter, which traps.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the member's annotation (`half(a: i32)`) | runs, `6` | **yes** |
| `pop`, read by `m[0]` instead | runs, `6` | **yes** |
| a list: a map read by `get` | runs, `6` | **yes** |
