### D15610 — two different hole functions joined in a list literal handed to a callee that calls an element at two types are taken as values with no signature

**loud emit reject · clause 2 · `vl check` rc 0, then `emitProgram: a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type` · the same literal holding one function twice runs since [D15566](D15566.md) · found closing D15566 · filed 2026-11-09 against master `d4901c70`**

Repro:

    function id(v) { return v }
    function dbl(v) { return v + v }
    function call1(fs, x) { print(fs[1](x)) }
    function runTwo(g, h) {
      call1([g, h], 7)
      call1([g, h], "u")
    }
    runTwo(dbl, id)

Want:

    7
    u

#### Mechanism

Not traced. Each hole forwards to `call1`'s list parameter, whose calls go through the joined set
`{dbl, id}`. Neither hole's own set is that join, so the tag decision finds no call that takes
`g`'s or `h`'s set.
