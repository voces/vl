### D13101 — a hole function in a list literal written in a `for` header, called with a hole parameter, types the element's parameter as nothing

#### Mechanism

`monoElemParamTys` typed a value argument naming a declaration by the TEMPLATE's read
(`nodeTyIxOf`), which for `k`, un-annotated, is the hole's type variable, so the element's
parameter had no closed type to instance `apply2` at. Reading the argument at its frame's
instance (`monoElemValArgTy`) answers `f64` in `inner`'s `f64` instance and `i32` in its `i32`
one; for a closed argument the two readers agree.
