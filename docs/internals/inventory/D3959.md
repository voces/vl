### D3959 — a capture cell written with a value `monoCellValueTake` cannot see through is refused as not settled

**loud emit reject · clause 2 · found in review of #3498 (`rv3498/round4/e08`, `e09`, `b02`) · filed 2026-10-10 against master `429e7b093`**

Repro:

#### Mechanism

`monoCellValueTake` instances a value written into a capture cell when it can name the function
the value holds: a generic by name, a never-written alias chain, another cell's read, an `if` or
a block's last statement. The write `k = j` reads an un-captured, reassigned `let` (`j = other`
in `a`'s body), which is none of these, so the value is refused as unsettled. A labelled block's
`break` value (`k = @B { break @B a2 }`, `round4/b02`) is refused the same way, since the take
reads no `break`.
