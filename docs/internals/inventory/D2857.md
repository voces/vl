### D2857 — `u as! S[][]` out of a union box refuses at an un-annotated binding or an inline index

**loud emit reject · clause 2 · found writing D2769's `as?` fixture · a loud emit reject on master `721781075` too, with another message · filed 2026-09-27 against master `721781075`**

Repro:

    function nb(c: boolean): boolean[][] | i32[][] {
      if c { return [[true]] }
      [[4]]
    }
    const u = nb(false) as! i32[][]
    print(u[0][0])
    // vl check: rc 0.  vl run: emit error — index receiver is not an array or string

#### Mechanism

The cast itself lowers since [D2769](D2769.md)'s close (tag test, then the ref-list cast), and
`as?` to the same arm binds un-annotated, because the nullable ref-list classifiers answer an
`as?` node. The non-null ref-list classifiers (`exprListRep`, `refListElemNameOfExpr`) have no
`as!` / `as` arm, so the binding takes no list kind and its index read refuses. On master the
cast refused first (`as i32[][] names no union arm this cast can test`).
