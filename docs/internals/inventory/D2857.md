#### Mechanism

The cast itself lowers since [D2769](D2769.md)'s close (tag test, then the ref-list cast), and
`as?` to the same arm binds un-annotated, because the nullable ref-list classifiers answer an
`as?` node. The non-null ref-list classifiers (`exprListRep`, `refListElemNameOfExpr`) have no
`as!` / `as` arm, so a read of the cast's own value finds no element row and refuses. On master
`721781075` the cast refused first (`as i32[][] names no union arm this cast can test`).

The un-annotated binding (`const u = nb(false) as! i32[][]`, then `u[0][0]`) runs since L2
stage 10: a `let` with no destination takes the row its element type keys, which the cast's
checker type names. `tests/cases/unions/as-bang-nested-list-arm-unannotated.vl` pins it.
