### D17102 — a narrowed union of two list types handed through a generic identity is refused as a `.length` receiver

**closed 2026-11-24 by S2 · runs, prints `3`, `2` · was loud emit reject, clause 2, legacy (the claimless build refused the same) · a call whose result is a union box of lists only is an arm-site receiver for `.length` and an index (`armSiteReads`), read once into the arm stash, and the call writer honours the arm's override (`emitCall`, `luOvLocalOf`) · owner S2 · found by V9 verifying HV1 · filed 2026-11-24 against master `1603ddda`**

Repro:

    function mkT(k: i32): i32[] | f64[] | string { if k == 0 { return "s" } if k == 1 { return [2.5, 3.5, 4.5] } return [4, 5] }
    function id<T>(x: T): T { return x }
    function narrowedCall(a) { if a is string { return -1 } return id(a).length }
    print(narrowedCall(mkT(1)))
    print(narrowedCall(mkT(2)))
    // vl check: rc 0.  vl build: emitProgram: '.length' on a receiver the emitter cannot classify as a list, string, map or set

Want:

    3
    2

#### Mechanism

The receiver is the call `id(a)`, whose instance is built at the narrowed union `i32[] | f64[]`, a
union-of-lists box. `.length` and an index over such a box are lowered per arm (`emitArmSite`),
but `armSiteReads` admitted only a name (or, for `.length`, an element read) as the receiver, so
the call fell to `emitMem`'s floor. Admitting it needed one more step: inside each arm the
receiver is overridden to the arm's unboxed list, an override that name and element reads
consulted and a call did not, so the call ran again and delivered the box (invalid wasm).
