### D17102 — a narrowed union of two list types handed through a generic identity is refused as a `.length` receiver

**loud emit reject · clause 2 · found by V9 verifying HV1, reproduces on base, head and claimless · owner S2 · filed 2026-11-24 against master `1603ddda`**

Repro:

    function mkT(k: i32): i32[] | f64[] | string { if k == 0 { return "s" } if k == 1 { return [2.5, 3.5, 4.5] } return [4, 5] }
    function id<T>(x: T): T { return x }
    function narrowedCall(a) { if a is string { return -1 } return id(a).length }
    print(narrowedCall(mkT(1)))
    print(narrowedCall(mkT(2)))
    // vl check: rc 0.  vl build: emitProgram: '.length' on a receiver the emitter cannot classify as a list, string, map or set

Want:

    3
    2

#### Mechanism

The receiver is the call `id(a)`, whose instance is built at the narrowed union `i32[] | f64[]`.
The `.length` lowering classifies the receiver by its call result and finds no list kind there.
The same union read directly, or bound by a `const` first, is classified and runs. Not yet
located in the emitter.
