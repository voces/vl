#### Mechanism

`recCbTakesBuild` instances a `map` callback at the receiver's build only when its result holds
no record or the callback hands each element back (`fnOnlyReturnsParam`); any other result
holding a record is refused, because the result might hold the element at its own row. A result
whose type holds no part of the element type (`{ g: boolean }`) cannot, so the callback can be
instanced at the build like one building a list.
