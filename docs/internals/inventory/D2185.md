### D2185 — a captured mixed literal-and-scalar union `let` that a closure writes builds an invalid module

**check-clean invalid wasm · clause 1 · filed 2026-09-23 against master `fa5db1bac`, found reviewing the [D2168](D2168.md) close (#3058), which leaves it as filed**

Repro:

    type M = "a" | "b" | i32
    function main() {
      let m: M = "a"
      const set = () => {
        m = "b"
      }
      set()
      print(m)
    }
    main()
    // vl check: rc 0.  vl run: rc 70, `set` fails validation: expected (ref $type), found (ref $type)

#### Mechanism

Not ablated. `M` mixes string literals with `i32`, so it is a value union and reps as the boxed
`{tag, payload}`, not as the atom. The boxed cell's element is the box, and the store through
`m[0]` in `set` lowers the member literal as a different heap type than the cell holds. D2168's
cell typing covers only the atom-repped union; the box needs the same element seed.

#### Grading list

`m = 7` in the closure; the value used, `print(set())`; a module-block binding.
