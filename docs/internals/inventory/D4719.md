### D4719 — a named callback inside a generic or hole body whose returns join a string with its parameter is refused

**loud check reject · clause 2 · the message concedes the program is type-valid · found ablating D3125's `J2` cells · the same on master `a254c3da4` · filed 2026-10-14 against master `a254c3da4`**

Repro:

    function t<T>(x: T) {
      const f = (e: T) => {
        if e == null { return "n" }
        return e
      }
      print(f(x))
    }
    t(4)
    // vl check: the returns of `f` join to string | i32 for this argument — type-valid, but an
    // inferred union return through an un-annotated parameter is not yet supported by codegen;
    // annotate the return type

Want:

    4

#### Mechanism

Not localised past the ablation. The refusal is `validateEscJoins`'s: the call `f(x)` re-folds
the callback's deferred join `string | _` at the pin and finds a union. The same callback
passed inline to `.map` runs since D3125 closed, because the clone takes the deferred join as
its return; a named callback is never cloned that way.
