### D4912 — `is K[]` over a `V[] | string` receiver in a generic instance answers false for an empty list

**check-clean silently wrong value · clause 1 · the union-receiver face of [D4910](D4910.md), which the D4910 value test skips · against the D4771 ruling · related to D4778 · pre-existing on master · filed 2026-10-15 against master `687f37dd5`**

Repro:

    function probe<V>(v: V[] | string) {
      if v is f64[] { return 1 }
      0
    }
    const e: i32[] = []
    print(probe(e))
    // PRINTS 0

Want:

    1

#### Mechanism

`emitListEmptyFitIs` (wasmEmit.vl) declines a union receiver (`exprUnion`), so the test keeps
`monoStaticIsResult`'s fold from the instance's `i32[]` arm. A box-union receiver needs the
emptiness test under its own tag check: the list arm's payload is empty, and the test is false
on the `string` arm.
