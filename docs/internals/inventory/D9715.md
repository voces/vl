#### Mechanism

`monoPinMapSlot` pinned a list value's element one level down (`["v","e"]`). For a nested list
that slot is the inner list, so the inner element stayed open at a function and the value type
had no rep to intern. A new arm before the flat one pins the inner element at `["v","e","e"]`,
records the inner lists and the stored values at that type, and spells the value
`(<fn>)[][]`. The `.set` spelling and a map inside a function body take the same arm.
