### D9715 — a nested list of an un-annotated function stored into an un-annotated map has no map value rep

**loud emit reject · `vl check` rc 0 · `unsupported map value type (no rep for a union-member struct, a nullable list over an unnamed element rep, or a nullable litunion-result closure; any other value type here interned no mv slot)` · clause 2 · found closing [D9662](D9662.md) · present on master `e8163edd5` · filed 2026-10-22 against master `e8163edd5`**

Repro:

    function inc(a) { return a + 1 }
    const m = Map()
    m["k"] = [[inc]]
    const x = m["k"]
    if x != null {
      print(x[0][0](3))
    }
    // vl check rc 0.  vl run: emit error: emitProgram: unsupported map value type

Want:

    4

#### Mechanism

Not traced. The map's value type is the nested list, whose inner element the checker leaves open
at a function. The flat list as the value runs, so the value's element is pinned one level down
and not two.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the nesting (`m["k"] = [inc]`, `x[0](3)`) | runs, `4` | **yes** |
| the un-annotated parameter (`inc(a: i32): i32`) | runs, `4` | **yes** |
| the function (`m["k"] = [[3]]`, `x[0][0]`) | runs, `3` | **yes** |

#### Grading list

The value returned from a function with an un-annotated parameter (`m["k"] = give(1)`), and the
`.set` spelling.
