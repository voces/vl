### D6541 — a declared generic with a `T | null` parameter, handed to a hole, is refused at emit at every call

**closed 2026-10-18 by lane L1 · runs, prints `3` · was a loud emit reject · clause 2 · the value-call union-name reader read the callee's checker type (an open hole) and now reads the hole's pinned instance, as the parameter types already did · pin: `tests/cases/generics/hole-call-of-generic-at-its-own-instance.vl` · found closing [D6540](D6540.md) · filed 2026-10-18 against master `fc3856155`**

Repro:

    function orz<T>(v: T | null, d: T): T { v ?? d }
    function via(a) {
      print(a(null, 3))
    }
    via(orz)
    // vl check: rc 0.  vl run: emitProgram: value-call union parameter has no resolvable union name

#### Mechanism

From the ablation only. The emitter takes the hole's call at the generic's own parameter
`T | null` and finds no union name for it, so the instance the call binds (`i32 | null`)
never reaches the value-call lowering. A `null` argument is not needed: `a(4, 3)` refuses the
same way.
