### D6521 — a second call of a hole function with the same generic re-checks its body at the first call's argument types

**loud check reject · clause 2 · the program is well-typed, and one call runs · found closing [D6470](D6470.md) · filed 2026-10-18 against master `d9c8431e5`**

Repro:

    function same<T>(k: T): T { k }
    function viaResult(a) {
      print(a("x"))
      print(a(3) + 1)
    }
    viaResult(same)
    viaResult(same)
    // vl check: rc 1, 7:11 operator '+' is not defined for string and i32 (the call's argument types)

Want:

    x
    4
    x
    4

#### Mechanism

From the ablation only. The first call runs alone. At the second call, the check of the hole
body's calls through `a` types `a(3)` as `string`, the type of `a`'s first call, so `+ 1` is
refused. The refusal is recorded against the second call's line.
