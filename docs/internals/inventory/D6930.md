### D6930 — a generic function bound unread or returned unread inside a function that is instanced is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same binding or return inside a function with annotated parameters runs ([D6830](D6830.md), [D6882](D6882.md)) · found closing [D6913](D6913.md) · present on master `43f22053c` and at #4153's head · filed 2026-10-19 against master `2dcd6d29f`**

Repro:

    function exclaim(s) { return s + "!" }
    function hold<T>(x: T) {
      const k = exclaim
      print(1)
    }
    hold(1)
    // vl check: rc 0.  vl run: emitProgram: cannot take the generic function `exclaim` as a value — a function value carries ONE signature

#### Mechanism

From the ablation only. The inertness walk answers for a frame the program's tree holds; a
template's body is walked through its instances, which are clones, so the binding's or the
return's inert use is never recorded against the reference the prune reads.
