### D6930 — a generic function bound unread or returned unread inside a function that is instanced is refused at emit

**closed 2026-10-19 by lane L1 · runs, prints `1` · was loud emit reject · clause 2 · CAPABILITY: the same binding or return inside a function with annotated parameters runs ([D6830](D6830.md), [D6882](D6882.md)); the prune's use scan now skips a template body no slot emits, and an instance's return asks the template whether its result is read · pins: `tests/cases/closures/generic-bound-unread-in-instanced-function.vl`, `tests/cases/closures/uncalled-hole-fn-compared-in-callee.vl` · found closing [D6913](D6913.md) · present on master `43f22053c` and at #4153's head · filed 2026-10-19 against master `2dcd6d29f`**

Repro:

    function exclaim(s) { return s + "!" }
    function hold<T>(x: T) {
      const k = exclaim
      print(1)
    }
    hold(1)
    // vl check: rc 0.  vl run: emitProgram: cannot take the generic function `exclaim` as a value — a function value carries ONE signature

Want:

    1

#### Mechanism

Measured with an `emitFail` probe in the prune's use scan. The reference that blocked the prune
is the TEMPLATE's: a template body is walked only through its instances, which are clones, so
the instance's binding was recorded inert and the template's own identical binding, which no
slot emits once the first instance replaces it, was counted as a use.
