#### Mechanism

Not yet ablated past the grid below. The annotated binding builds `mk2`'s result at J (a kept
function, D14385). `mk4` hands `mk2`'s call back, and the join types `mk4`'s result at the other
operand's record, `{f: i32}`, so `mk4` is emitted returning one record while `mk2` builds the other.
No container is built wider here, so this is not D15317's `??` arm.
