#### Mechanism

The provenance was already banked and simply did not survive cloning. `applyGenAliasArgs`
records "this arena index IS the application `head<args>`", and `tyToStrAt`'s nominal mode
already consults it. But `substTyDeep` rebuilds a substituted type through `mkObjTy` and
friends — a FRESH index the bank does not know — so `Box<i32>` reached through a generic
FUNCTION rendered `{v: i32}` while the same type written directly rendered `Box<i32>`. One
type, two names, decided by which door it came through. `genAppCarry`, called at the end of
`substTyDeep`, is the inheritance. Same shape as D926's mark: the monomorphizer clones the node
a bank is keyed by, and the clone has to inherit.

**WHAT THE GRADER CAN AND CANNOT SEE.** `check-filed-witnesses.py` reads the OUTCOME CLASS, and
both compilers answer `check_reject` here — so this row grades `as filed` on either. The
discriminator is the message text quoted in the status line above, and re-measuring it means
building a control (`git archive fef77fc1` self-compiled with the current seed), not re-running
the grader.
