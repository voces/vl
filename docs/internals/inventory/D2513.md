### D2513 — at module scope, a `??` initialiser over a nullable scalar global that a statement assigned is invalid wasm

**closed 2026-09-25 — the filed repro RUNS and prints `1` · was check-clean invalid wasm, clause 1 · pre-existing, identical on master `54fcaf5d8` · found by #3165's review grid · filed 2026-09-25 against master `54fcaf5d8`**

Repro:

    let vv: i32 | null = null
    vv = 1
    const v31 = vv ?? -1
    print(v31)
    // vl check: rc 0.  vl run: invalid module, type mismatch: expected (ref null $type), found i32

#### Mechanism

A module global is classified by `globalCellKind`, and a start-block local by
`collectStartLocals`, with no narrowing replayed, while the start function's lowering replays
the assignment narrowing. After `vv = 1` the checker types the read `i32` and `emit_rewrite`
folds the `??` away, so the binding's cell was typed off `vv`'s declared box and its value was
the unboxed read. `synthNarrowedReadAnn` writes the checker's narrowed scalar type as the
annotation of an un-annotated binding whose initializer is a name read a classifier still sees
as a box; inside a function the narrowing is replayed and it declines.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the program inside a function | prints `1` | **yes** — module scope |
| `vv = 1` removed (initialised `1`) | prints `1` | **yes** — an assigning statement |
| `vv = null` instead of `vv = 1` | prints `-1` | **yes** — a non-null assignment |
| `print(vv ?? -1)` instead of the binding | prints `1` | **yes** — a module binding's initialiser |
| `let v31 = 0; v31 = vv ?? -1` | prints `1` | **yes** — as above |
| a `string \| null` global | prints `a` | **yes** — a scalar box |
| an `f64 \| null` global (`vv = 1.5`, `?? -1.0`) | still invalid | no |
