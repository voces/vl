#### Mechanism

Not yet ablated to a rung. The annotated spelling runs, so the lowering exists and it is the
element's ROW that is missing: without one the `!= null` test falls to the generic struct
comparison, which is what the message names. That is D1830's shape at a different element rep
— D1830's registration mints a value BOX for a nullable numeric element, and a nullable struct
element wants the nullable-ref niche instead, which the literal loop still registers nowhere.

The message is the tell that this is a registration gap rather than a comparison one: nothing
in the program compares two structs.
