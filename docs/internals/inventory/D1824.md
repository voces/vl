#### Mechanism

**Not instrumented; bounded by [D1823](D1823.md)'s grid, which is what separates it from that
row.** `.pop()` over a ref-element list is `T | null` to the checker, and the miss arm
synthesises a bare `null`. Over `Circle[]` that null has a struct-typed context to take —
`Circle` — and the same program **runs and prints `1`** at both narrowing depths. Over `Json[]`
the element is itself a UNION, so the null has no single struct type to be, and the emitter
floors.

**The narrowing depth is not the ingredient, and that is the measurement that matters here.**
[D1823](D1823.md) closed a depth-2-only gap in the ref-list frame collector, which moved these
four cells from that row's message to this one. The DEPTH-1 spelling above hits this same
message on master, before and after that close — so what D1823 did was uncover this refusal,
not cause it.

Neighbours worth reading before probing: `emitMapGetUnionBox`'s miss arm, which solves the same
problem for a union-valued map read by synthesising the null-TAGGED box (`nullBoxTag()`) rather
than a bare `ref.null`, and D962/D969 on the `??` desugaring of a nullable value-union box.
The prediction is that the ref-list pop's miss arm wants that box, and it is a prediction —
**probe the decline before believing it**, since two attributions in this family have already
died to measurement ([D1822](D1822.md)'s and [D1823](D1823.md)'s own).
