### D5932 — a hole lambda calling an un-imported UFCS name, delivered to a typed function parameter, passes `vl check` and is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · found closing [D5881](D5881.md) · filed 2026-10-17 against master `3e78365df`**

Repro:

    function name(b: (n: i32) => string): string { b(7) }
    const f = (n) => "v" + n.toString()
    print(name(f))
    // vl check: rc 0.  vl run: emitProgram: callee is not a function name

Want:

    vl check: rc 1, 'toString' is not imported

#### Mechanism

From the ablation only. The program is ill-typed: `toString` is not in scope. With `n`
annotated the checker says so; with `n` a hole, the member call is deferred to the instance,
the instance is checked at `i32` by nobody, and the emitter meets a call with no function.
