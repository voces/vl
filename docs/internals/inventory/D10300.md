### D10300 — a `let` list of a generic, pushed the same generic, has no signature at a call through an element

**loud emit reject · `vl check` rc 0 · `a function value's signature is not known at this call — the type it was given takes fewer parameters than the call passes` · clause 2 · CAPABILITY: the same program with `const ws` prints `7`, `w` · found closing [D10190](D10190.md) · present on master `d5ec7f160` · filed 2026-10-22 against master `d5ec7f160`**

Repro:

    function id<T>(x: T): T { x }
    let ws = [id]
    ws.push(id)
    print(ws[1](7))
    print(ws[1]("w"))
    // vl check rc 0.  vl run: emit error: emitProgram: a function value's signature is not known at this call — the type it was given takes fewer parameters than the call passes

Want:

    7
    w

#### Mechanism

Not traced. The refusal is the call-site one, not the list-slot one, so the element read off a
`let` list that was pushed a generic reaches the call with no instance at all.
