### D3574 — `vl build` silently accepts an argument it does not know

**runs today and must keep running · the defect is the CLI's: `vl build p.vl "-O3 --names"` (one argv word) or `--bogus` writes an unoptimized, unnamed module at exit 0 · found by the #3351 review · filed 2026-10-03 against master `3b9319528`**

Repro:

    print(1)
    // prints 1. `vl build p.vl "-O3 --names" -o p.wasm` and `vl build p.vl --bogus -o p.wasm`
    // both print `wrote p.wasm (145 bytes)` and exit 0. The flag that was meant is not
    // applied, and nothing says so.

#### Mechanism

`build_cmd` (scripts/vl-host/src/main.rs) tests each flag with `args.iter().any(|a| a == …)`
and never checks the arguments left over. An unknown word is ignored rather than refused.

#### Grading list

Every `vl build` flag spelled once correctly and once misspelled: the misspelling exits 2 and
names the word. Flags that take a value, `--x=v` spellings, and `-o -` still work.
