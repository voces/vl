#### Mechanism

From the ablation only. `mk(n)` is generic, so its return is walked in an instance frame, and
the two pins past it are not found there: the refusal fires with no pin and asks `fn_split` for
nothing. D5531's copy per result pin needs the template's parse node and the pins of each
call, both read from the instance.
