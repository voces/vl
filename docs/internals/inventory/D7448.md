#### Mechanism

The checker refused every non-member default, so a string default, whose join with the
atom is plainly `string`, never reached the emitter. Lifting it exposed three emit seams,
each built here: the fused get-with-default lowers only a member default, the scalar
`K | null ?? string | null` decode refused a nullable default, and the D2248 rewrite
lowered the null test's join of an atom and a nullable string as an atom.
