### D3935 — a generic returning a nullable function, called through a call chain inside or outside a generic, traps

**loads then traps · found in review of #3487 (`rv3487/round3`: m01c, m01d; m01, m01b, m01f move from loud to this trap with #3487; m01e is the control) · filed 2026-10-10 against master `00bf1871f`**

Repro:

    function a<T>(x: T): (t: T) => ((u: T) => T) | null { (t: T) => (u: T) => u }
    function pr(x: f64) {
      const f = a(x)(x)
      if f != null { print(f(x)) }
    }
    pr(2.5)
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch

Want:

    2.5

#### Mechanism

Not located. `a(x)` returns `((u: T) => T) | null`, a nullable function type, and the call chain
that D3912 types at the instance reads only a bare function type, so the value `a(x)(x)` is
not typed at the instance. With a non-generic `a` it runs.
