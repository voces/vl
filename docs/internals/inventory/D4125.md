### D4125 — an element or field of an un-annotated container of a generic function, delivered to an annotated binding, refuses at emit

**loud emit reject · clause 2: `vl check` is clean · found closing [D4123](D4123.md) · filed 2026-10-11 against master `efd3c3f15`**

Repro:

    function inner<U>(u: U) { print(u) }
    const fs = [inner]
    const k: (u: i32) => void = fs[0]
    k(3)
    // vl check: rc 0.  vl run: emitProgram: a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type

Want:

    3

#### Mechanism

From the ablation. The binding's annotation names the instance the element needs, but the list
literal is typed without it, so nothing instances `inner` and the element is the pruned stub.
The emitter refuses the stub as a value ([D4123](D4123.md)). Before D4123 closed, the module
failed validation, `expected i32, found (ref $4)`, and the record-field spelling trapped at run
time with `indirect call type mismatch`.
