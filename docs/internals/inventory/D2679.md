### D2679 — an explicit type argument binding `W` to a record or map left a `W | string` parameter unboxed when the argument was the other member

**closed 2026-09-26 by the W2 lane PR — the filed repro RUNS and prints `true` · was check-clean
invalid wasm, clause 1 · found grading D2676's positions · identical on master `525837973` ·
filed 2026-09-26 by the W2 lane**

Repro:

    type Q = { b: string }
    function h<W>(y: W | string) {
      y is string
    }
    function g<V>(x: string) {
      h<V>(x)
    }
    print(g<Q>("m"))
    // vl run on master: invalid module inside `h`, "type mismatch: expected i32,
    // found (ref $type)"

#### Mechanism

The instance `h` at `W := Q` pins its parameter `W | string` to `Q | string`, a union holding a
record. The parameter path handed `monoPinMintedUnion` the ARGUMENT's type, `string`, one member
of the union, so the gate saw no record and the union was never registered; the parameter
lowered as the bare string while the body tested a box. Where the argument's type names no
ref arm, the gate now reads the annotation substituted through the explicit type arguments.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the record binding (`g<i32>("m")`) | prints `true` | **yes** |
| the forwarding (`h<Q>("m")` at top level) | same invalid wasm | no |
| the outer explicit-only binding (`g<V>(z: V, x: string)`, `g<Q>({ b: "q" }, "m")`) | same invalid wasm | no |
| the record, for a map (`V := {[i32]: boolean}`) | same invalid wasm | no |
