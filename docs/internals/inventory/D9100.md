Repro:

    function inc0(a) { return a + 1 }
    const m = Map()
    m["k"] = inc0
    for k in m { print(k) }
    // vl check rc 0.  vl run: emit error: emitProgram: unsupported map value type (no rep for a union-member struct, ...)

Want:

#### Mechanism

The map's value type comes from the parameter types its calls pin on the value
slot (`monoPinMapValues`, `monoStoredSlotFnTy`, emit_mono.vl). With no call there is no
pin, so the value keeps the function's hole signature, which the map value layer has no
slot for. An uncalled hole function on its own is served by a stub (D6830); a map holding
one is not. The list spelling held in a record field fails at the field instead.
