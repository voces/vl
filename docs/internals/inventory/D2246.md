#### Mechanism

`emitIfExpr` picks a ref blocktype from `ifExprRefKind`, a ladder over the deciding arm's rep:
string, the string / f32 / f64 / i64 / ref / i32 lists, map, variant, struct. The packed byte
list had no rung, so a `u8[]` arm fell to `exprArray` (the i32 list, whose predicate claims
any list of i32-typed elements) or, where that declined too, to the numeric `i32` blocktype,
and the arm pushed a `(ref $u8wrap)` under it. The map read and the `??` in plumb's spelling
were scenery: two plain `u8[]` locals are enough. The fix adds the `u8list` rung ahead of the
other list rungs, `u8list` to the empty-hole kinds the ladder accepts, and the nullable twin
(`nulu8list` from `exprNulScalarListKind`'s null-arm rung, joined at `u8list`) so
`if c { bytes } else { null }` builds the nullable wrapper.
