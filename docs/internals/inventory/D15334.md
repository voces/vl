### D15334 — a record of an un-annotated function, handed back through an un-annotated parameter and called after, is refused at emit

**open · loud emit reject · `emitProgram: cannot take the generic function id1 as a value — a function value carries ONE signature` · clause 2 · a bare function or an annotated one runs · found grading D15301 M2 · filed 2026-11-04 against master `6f1693f5`**

Repro:

    function id1(a) { return a }
    function g(r) { return r }
    print(g({ f: id1 }).f(2))

Want:

    2

#### Mechanism

The call through the result, `.f(2)`, is outside `g`, so `g`'s instance pins nothing at the
hole parameter, and nothing delivers the literal at the signature its caller reads it at.
Handing the bare function back (`g(id1)(2)`) runs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the record (`g(id1)(2)`) | runs | **yes** |
| un-annotated `id1` → `inc(x: i32): i32` | runs | **yes** |
| the call inline → `const k = g({ f: id1 }); k.f(2)` | still refuses | no |
