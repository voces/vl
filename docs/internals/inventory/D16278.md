#### Mechanism

A call through a place that may run several un-annotated functions requires them to return one
type at the call's types; `holeSlotArgJudge` judges each argument a parameter's slot is handed.
An argument that reads a place through a binding (`r.a`) or a call's own result (`mk2()`) was
judged, but a field read straight off a call (`mk().a`) found no binding root in `cwSlotPath` and
was judged as nothing, so the instance typed the field at its first member, `(i32) => i32`, and
called `half`'s `(i32) => f64` thunk through that signature.
