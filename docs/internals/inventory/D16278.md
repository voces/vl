### D16278 — a function field of a list a call returns, read straight off the call into an un-annotated parameter, escaped the one-result judge and was called at its first member's signature

**closed · now a loud check reject, as its neighbours are · was a wasm trap (indirect call type mismatch) on a check-clean program · clause 1 · found by lane G in `record-held-list-fn-field-for-loop.matrix.vl` (argument, un-annotated) after #8225; the indexed spelling trapped before it · filed 2026-11-15 against master `60fd9a964` · closed 2026-11-15 by lane N: a place read straight off a call's result (`mk().a`) handed to a parameter is judged through the values the call returns (`holeSlotCallArgJudge`), as `r.a` with `const r = mk()` already was · cells `distilled/named/d16278_*`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function mk() { return { a: [{ f: inc0 }, { f: half }] } }
    function __take(a) { const v = a; let acc = 0.0; for e in v { acc = acc + e.f(3) }; print(acc) }
    __take(mk().a)
    // vl check rc 1: cannot store 'half' in 'a[].f': called at (i32) it returns f64, where 'inc0',
    // also stored in it, returns i32 — every function a call through 'a[].f' may run must return one type

#### Mechanism

A call through a place that may run several un-annotated functions requires them to return one
type at the call's types; `holeSlotArgJudge` judges each argument a parameter's slot is handed.
An argument that reads a place through a binding (`r.a`) or a call's own result (`mk2()`) was
judged, but a field read straight off a call (`mk().a`) found no binding root in `cwSlotPath` and
was judged as nothing, so the instance typed the field at its first member, `(i32) => i32`, and
called `half`'s `(i32) => f64` thunk through that signature.
