### D16765 — a `filter` or identity `map` result of a list a kept maker's build stores at a wider record, held in a record or list literal, is refused at emit

**loud emit reject · clause 2 · `emitProgram: field access receiver is not a struct` · the `struct_field_init` and `array_element` cells (un-annotated face) of `same-elems-result-of-built-list` and `map-callback-over-built-list` · residue of D16763 and D16211 · found by lane WIDTH · filed 2026-11-16 against master `8492d1704`**

Repro:

    type J = { f: i32 | null }
    function mk2() { return { f: null } }
    const dA: J = mk2()
    const src = [mk2()]
    const w = { f: src.filter((y) => y.f == null) }
    print(w.f[0].f)
    // vl check: rc 0.  vl run: emitProgram: field access receiver is not a struct

Want:

    null

#### Mechanism

The `filter` call is stamped at `J[]` (`elabSameSlotsAtBuild`), but the record literal's field is
laid out at the call's own type `{ f: null }[]`, so the read `w.f[0]` reaches a struct the field
type does not name. A receiver binding in the same place runs (`{ f: src }`): the literal takes
the binding's build for its field. A stamped same-elements call is not among the parts a literal
asks for a build.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `filter` (the field holds `src`) | runs, prints `null` | **yes** |
| the kept maker | runs | **yes** |
| the record literal (a list literal `[src.filter(…)]` instead) | the same emit refusal | no |

#### Grading list

`struct_field_init` and `array_element` (un-annotated) of both templates above.
