### D5471 — an un-annotated `Map()` whose only stored value is an empty list nothing stores into has no value rep

**closed · was loud emit reject · `vl check` rc 0 · clause 2 · found closing D5344 · filed 2026-10-17 against `ae9bb33e2` (PR #3980's head)**

Repro:

    const m = Map()
    m["k"] = []
    const x = m["k"]
    if x != null { print(x.length) }
    // vl check: rc 0.  vl run: emitProgram: unsupported map value type (no rep for a union-member struct, a nullable list over an unnamed element rep, or a nullable litunion-result closure; any other value type here interned no mv slot)

Want:

    0

#### Mechanism

The map's value is `_[]`, a list whose element nothing pins, and the map-value interner names
the slot by the value's spelling, which renders the hole as `""` (`mvShapeOfValNameArmTyGo`
returns `-3`). D5344 defaults such a hole when it is a record literal's FIELD; this is the same
hole as the map's own value, which `objFieldHolesToI32` did not visit and `flushUninferred`
does not grade, because the binding's type is the map, not the list.

Fixed in the checker. `objFieldHolesToI32` (`check_narrow_flow.vl`) now also visits the bare
`[]` of every index store `xs[k] = []` whose element is still open, after every pin. It gives
the literal its destination's element: the map's value row (or the list's element row) when
that is known, else the element every other store into the same destination writes, else
`i32`. A later `push` still pins first. Stores that disagree (`m["j"] = [1]` and
`m["l"] = ["s"]` beside the empty one) leave the row open, and that program keeps the emit
reject it had. Taking the store target's own type as the destination is not the fix, because a
map read's type is not the map's value row: with that version, a map that also stores `["s"]` later
became check-clean invalid wasm.

Graded by `map-store-empty-list.matrix.vl` (23 un-annotated cells refused before and run after,
56 of 64 run, 0 runs→not-runs; the other 8 refuse identically before and after, at the
template's own spelling: `.length` on a nullable map read and a hole parameter used as a map),
the `record-lit-*` and `recursive-record-eq` matrices (0 runs→not-runs) and
`tests/cases/maps/map-store-empty-list.vl` (top level, a function body, decided by a later
push, by an earlier and by a later store's element, an annotated map and a list's element
store).
