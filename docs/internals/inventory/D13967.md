### D13967 — a generic's declared record result whose function field reads a type parameter has no row

**loud emit reject · clause 2 · found 2026-10-26 ablating `generics/generic-function-into-nullable-function-slot` · pre-existing on master `5807f0fd7`**

Repro:

    function b<U>(y: U) { print(y) }
    function a<T>(x: T): { f: (t: T) => void } {
      return { f: b }
    }
    a(2.5).f(2.5)
    // vl check: rc 0.  vl run: emitProgram: ref valtype with no interned shape

#### Mechanism

The result type `{f: (t: T) => void}` is spelled at `T`, and no pass interns a row for it at the
instance's binding `{f: (f64) => void}`. A body that builds the same record as a typed local
and returns it refuses the same way, so the returned literal is not what the defect needs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `T` in the field's function type (`(t: i32) => void`) | runs | **yes** |
| the generic (`a(x: f64)`, field `(t: f64) => void`) | runs | **yes** |
| the function type (field `T \| null`) | runs | **yes** |
| `\| null` on the field | still refuses | no |
| the returned literal (a typed local returned instead) | still refuses | no |
| the record result (the literal bound in the body, not returned) | runs | **yes** |

#### Grading list

- `{ f: null }` returned at `{ f: ((t: T) => void) | null }`, which refuses the same way.
- D13968's witness, the same slot at a binding, which must keep running.
