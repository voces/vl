### D3121 — an un-annotated object literal whose field is a value narrowed to `K | null` out of a box is refused at emit

**loud emit reject · clause 2 · found grading lane NB's position grid (`nullit__field_un__*`) · the same on master `cc890c9f4` · filed 2026-09-28 against master `cc890c9f4`**

Repro:

    type K = "a" | "b"
    function t(e: K | null | i32) {
      if !(e is i32) {
        const o = { f: e }
        print(o.f == null)
      }
    }
    t("b")
    t(null)
    // vl check: rc 0.  vl run: emitProgram: object literal matches no union variant

Want:

    false
    true

#### Mechanism

Not localised past the ablation. The anonymous record's field is typed `K | null` by the
checker while its value is the `K | null | i32` box, and the object literal is matched against
the union rows instead of minting the record; the annotated record `O = { f: K | null }` takes
the atom-niche conversion ([D3118](D3118.md)) and runs.
