#### Mechanism

The instance of `ap` at `T = C` gives the un-annotated closure a synthesized return annotation
spelled by shape, `{r:i32}`. Its kind is read from the recorded type (`retVariantFlag`, the arm
`C`), so it is `variant`; its slot was read from the spelling (`variantIndexOf(tyNameOf(..))`),
which has a row for the name `C` and none for `{r:i32}`. The `$fnsig` result valtype was
(`variant`, -1), and `fbValtype`'s bounds guard refused it. The function's own functype
already read the row off the recorded type, so only the signature pool and the return seeds
disagreed. A `.filter`, `.map` to `i32` or identity `.map` callback inside a generic body is the
same closure and refused the same way. Annotating the closure's return (`(e: T): T => e`) ran.
