### D12900 — a closure inside a generic body whose `T` pins to a union-arm record has no interned shape for `T`

**loud emit reject · `vl check` rc 0 · clause 2 · found closing [D12820](D12820.md) · filed 2026-10-25 against master `db1d4f849`**

Repro:

    type C = { r: i32 }
    type S = { s: i32 }
    type U = C | S
    const cs: C[] = [{ r: 1 }, { r: 2 }]
    function ap<T>(x: T): T {
      const f = (e: T) => e
      f(x)
    }
    print(ap(cs[0]).r)
    // vl check: rc 0.  vl run: emitProgram: ref valtype with no interned shape

Want:

    1

#### Mechanism

The instance of `ap` at `T = C` lowers its closure's parameter and return at `C`, and `C`, an
arm of the declared union `U`, is laid out at a variant row rather than a struct row. The
closure's signature asks for a struct shape for `C` that the per-instance interning never
made, so the valtype has no shape and emit refuses. A `.filter`, `.map` to `i32`, or identity
`.map` callback inside a generic body is the same closure and refuses the same way.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `type U = C \| S` removed | prints `1` | **yes** (a union-arm record) |
| the closure removed (`function ap<T>(x: T): T { x }`) | prints `1` | **yes** |
| `T` pinned to the whole union (`ap(us[0])`, `us: U[]`) | runs | **yes** (the arm, not the union) |
| the closure monomorphic (`(e: C) => e` at top level) | prints `1` | **yes** (the generic instance) |
| `xs.filter((e) => true)` over `T[]` in place of the closure | the same refusal | no |
