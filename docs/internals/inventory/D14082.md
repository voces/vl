### D14082 — a record returned by an un-annotated lambda bound to a generic's `() => T | string` has no union box

**loud emit reject · clause 2 · `vl check` rc 0 · `emitProgram: a record value delivered into a union box this program never registered has no tag` · found closing [D14080](D14080.md) · present on master `2f8428da3` · filed 2026-10-26 against master `2f8428da3`**

Repro:

    type P = {a: i32}
    const p: P = {a: 1}
    function len<T>(f: () => T | string) {
      7
    }
    print(len(() => p))
    // vl check: rc 0.  vl run: emit error, a record value delivered into a union box this program never registered has no tag

Want:

    7

#### Mechanism

Not traced. `T` binds to `P` from the lambda's inferred result, but the lambda's body delivers
`p` into the `P | string` box. No `P | string` union is registered by that route. Annotating the
lambda's result or the type argument registers it.
