### D16564 — a generic whose type parameter only its return names is refused at a call with no destination, in a sentence that says no call can bind it

**loud check reject · "cannot infer type parameter A: mkId's return type names it and no parameter does, so a call has nothing to bind it from" · clause 2 · open · bucket (c), L2 inferred interfaces: with no destination only the later call `v(1.5)` binds `A` · every un-annotated position of `gfv-mkid-at-f64.matrix.vl` and `gfv-mkid-at-string.matrix.vl` (20 each), and the annotated `return_inferred` cell, whose destination is beyond an inferred return · filed 2026-11-15 against master `c8f0324da`**

Repro:

    function mkId<A>(): (x: A) => A { return (x: A) => x }
    const v = mkId()
    print(v(1.5))
    // vl check: cannot infer type parameter `A`: `mkId`'s return type names it and no parameter does

Want:

    1.5

#### Mechanism

No argument names `A`, and the call has no destination, so nothing at the call binds it. The annotated
faces run (`const v: (x: f64) => f64 = mkId()`, D16410's destination binding), so the refusal's
sentence is wider than the arm that fires: a call *with* a destination does bind `A`. With no
destination only the later call of the value binds it, which is [D16411](D16411.md)'s shape, an
inferred interface. Unlike the `sel(gid)` producers, this one is refused loudly rather than built at
the `i32` default.
