### D2651 — `??` over a nullable map value refuses at emit, so a nullable map has no default spelling

**loud emit reject · clause 2 · the `two_instances` cells of the D2519 lane's `all-null` templates (6 cells, every key rep) · identical on master · filed 2026-09-26 against master `19dfb80af`**

Repro:

    function mk(): {[string]: i32} {
      const m: {[string]: i32} = Map()
      m.set("a", 1)
      m
    }
    function pick(n: i32): {[string]: i32} | null {
      if n > 0 { return mk() }
      null
    }
    const v = pick(0)
    const w = v ?? mk()
    print(w.length)
    // vl check: rc 0.  vl run: emitProgram: `??` over this nullable value is not supported yet — narrow it first

#### Mechanism

The `??` lowering has a rung for each nullable rep it knows (the i32 sentinel, a nullable
struct or variant ref, a nullable list, the union box), and a nullable map ref is not one of
them, so the coalesce falls to the `not supported yet` floor. Spelled in place,
`(v ?? mk()).length` refuses one step earlier, at the `.length` receiver classifier, and
`(v ?? mk()).has("a")` as `callee is not a function name`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the binding (`print((v ?? mk()).length)`) | refuses at the `.length` receiver instead | no |
| the `??` (`if v != null { print(v.length) }`) | runs | **yes** |
| the string key (`{[i32]: i32}`) | the same refusal | no |

#### Grading list

The `two_instances` cells of `b6-map-*-all-null`, and the in-place spellings above.
