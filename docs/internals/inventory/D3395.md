### D3395 — a labelled block whose value is `null` is rewritten into a binding with no initializer

**loud emit reject · the #3315 review · filed 2026-09-30 against master `4ff12b994`**

Repro:

    function h() {
      const y = B: {
        print("b")
        null
      }
      print(y == null)
    }
    h()
    // vl check: rc 0.  vl run: emitProgram: local declaration needs an initializer

Want:

    b
    true

#### Mechanism

Not traced. The loop-value rewrite declares `let $lv: T = <init>` and gives a nullable `T` a
`null` initializer and a wide scalar a zero; a block whose value type is the `null` type itself
takes neither, and the binding reaches the emitter with none. The same block with an `i32` value
runs.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the value `5` instead of `null` | runs | **yes** (the `null` type) |
| `print(y ?? -1)` instead of `== null` | same refusal | no |
