### D4165 — `??` over a list element of a nullable number-literal union written from a type parameter, bound at `i32`, is invalid wasm

**check-clean invalid wasm · pre-existing, the same on master `5e770df5b` · found by the D3423 position matrix (`rv_NU_elem_*_bindS_decl_*`, 15 cells across bindS, retS and takeK) · filed 2026-10-11 against master `5e770df5b`**

Repro:

    type N = 1 | 2
    function g<T>(x: T) {
      const xs: (N | null)[] = [null]
      xs[0] = x
      const r: i32 = xs[0] ?? 0
      print(r)
    }
    const u: N = 1
    g(u)
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `g`: type mismatch

Want:

    1

#### Mechanism

The template keeps the non-null narrowing of `xs[0]` after the write ([D4164](D4164.md)), so the
`??` folds to its operand, which is read at the element's value box while the binding takes an
`i32`. Not ablated past the rows below; it may close with D4164.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `let s: N \| null` (a name) | runs | **yes** (a list element) |
| `(i32 \| null)[]` | runs | **yes** (a literal union) |
| `function g(x: N \| null)` (no type parameter) | runs | **yes** (a type-parameter write) |
