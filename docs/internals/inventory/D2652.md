### D2652 — a module global read before its initializer ran read the cell's zero default: `0`, `false`, `null`

**resolved by a runtime guard (owner ruling 2026-09-26: reading a module global before its initializer ran is a clear runtime error) — the witness now loads then traps with "`n` read before its initializer ran (line 3), via rn" · was check-clean silently wrong, printing `0` · found in the #3165 review · filed 2026-09-26 against master `979323f83` · `tests/cases/globals/read-before-init-scalar-traps.vl`**

Repro:

    function rn(): i32 { n }
    print(rn())
    const n = 3 + 4

#### Mechanism

A global whose initializer is not a wasm constant expression is a zero-initialized cell that the
start function fills when it reaches the declaration, and a function that top-level code calls
earlier read the cell as it stood. The checker refuses a DIRECT read before the declaration but
cannot see one through a call. Every cell whose zero default is a value of its type read wrong
silently: `i32`/`i64`/`f64` read `0`, `boolean` read `false`, and a nullable cell read `null`
(`r() ?? "none"` printed `none`); a non-null reference cell trapped anonymously instead (D2653).
The fix is `initGuardScan` (emit_sections.vl), a pass that walks top-level code in order and
marks every function it can call at each position; a global is guarded when a name mention
reaching it occurs at or before its declaration, and every read of it from a function reachable
by then (or never named by top-level code) checks one progress cell first (`emitInitGuard`,
wasmEmit.vl). A global whose initializer is a constant the module folds (`const n = 7`) has its
value from instantiation and is never guarded; a `const n = 7` spelling of this witness printed `7`
on master, which is why the witness initializes with `3 + 4`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the call before the declaration (`print(rn())` moved after it) | runs, prints `7` | **yes** |
| the non-constant initializer (`const n = 7`) | runs, prints `7` (the constant is the cell's own init) | **yes** |
| the function hop (`print(n)` before the declaration) | loud check reject: `n` is used before it is assigned | **yes** |
| the type (`string` instead of `i32`) | loads then traps, anonymous `null reference` (D2653) | no — changes the symptom |
