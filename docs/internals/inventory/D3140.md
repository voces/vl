### D3140 — a `.map` callback's declared `T | string` at a `string | null` pin boxes a nullable string no union row reads

#### Mechanism

The instance's callback returns `string | null | string`, which the clone types as a union and
so builds a value box (string tag 2, null tag 6). `string | null` is the nullable-string niche
everywhere else, so no `unNames` row holds exactly those members, D3129's member lookup finds
none, and the result falls back to the first row, whose reader casts the payload to a string.
Refusing instead (slot -1) costs the `.length` spelling, which runs today because every union
row shares one list type; the fix is for the clone to return the niche, or for the pin to
register a row whose reader dispatches on the null tag.

#### Close

`substTyDeep`'s union arm folds nullable members (`dropNullableInnerTwins`, `hoistNulLitMember`):
`T | string` at `T := string | null`, `K | null` or `K | L | null` is the `string | null` niche,
and `T | i32` at `K | null` is `(K | i32) | null`, each what the annotation route builds for the
same spelling. The annotation and canon routes read a grouped `(X | null) | Y` as `X | null | Y`
(`annNullableInner`, `canonHoistNullGroups`), a call recorded as a niche list reads as that list
(`callRecordedNicheList`), and a box delivered to a `string | null` result converts
(`emitBoxToNulStr`). A `K | null` niche entering a box widens its id to the member string or the
null tag, and into `string | null` to the member string or the null ref; a pin spelling with a
literal-union arm and a numeric or boolean arm registers its row; and a union-list literal of
niche values boxes into its destination. Graded against the #3287 review's `p`, `sub`, `hs`, `mx`
sets and this lane's NG, NB and `h` grids: no run lost, no loud to silent.
