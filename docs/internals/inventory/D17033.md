### D17033 — a generic returning its union at the arm free of the type parameter passes the checker, then trips emit's guard on a type written after an emit memo read it

**loud emit reject · clause 1, `vl check` accepts the program · `internal: an emit-phase write changed a type an emit memo may hold` (`emit_sections.vl`) · found by lane F2 ablating [D17032](D17032.md) · filed 2026-11-20 against master `de317fa31`**

Repro:

    type U<T> = { k: "g", n: i32 } | { k: "h", v: T }
    function mk<T>(x: T): U<T> {
      return { k: "g", n: 9 }
    }
    const a = mk(3)
    if a.k == "g" { print(1) }
    // vl check: rc 0.  vl run: emit error, internal: an emit-phase write changed a type an emit memo may hold

Want:

    1

#### Mechanism

The checker accepts the literal at the arm that holds no type parameter. During emit, a type the
instance needs is written after an emit memo may already have read it, and the guard in
`emit_sections.vl` refuses the write. Which write, and which memo, is not yet located.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the type parameter (`U` concrete, non-generic `mk`) | runs, prints `1` | **yes** |
| `T` in the other arm (`T` moved into the built arm) | check reject, [D17032](D17032.md) | **yes** |

#### Grading list

D17032's witness once it checks; the same literal at an argument position and in a `const`
annotated `U<T>`; a second instancing of `mk` at another type.
