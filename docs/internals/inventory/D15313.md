### D15313 — a `??` default held in a binding, for a read of a container built wider, is refused inside a list or record literal

**closed 2026-11-04 by lane destringify, runs, prints `4` · was loud check reject, clause 2 · since D15310 the general `??` arm builds a fresh `const` literal default at the read's record while it keeps its own type, so the join is one record and the literal slot holds it; `storeSlotHeldAt`'s refusal now asks the same predicate (`recCoalesceDefaultBuilt`) and keeps refusing only the defaults the record solve pins there, a `let` or a call held in a `const`, which are D15316 (the probe and the conceded literal moved with them) · fixture `soundness/built-read-held-literal-default-in-literal-runs.vl` · named set `d15313-held-literal-in-literal` · built invalid until D15312 · found closing D15312 · filed 2026-11-04 against master `f53e406f5`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const m = Map()
    m.set("a", mk())
    const wm: {[string]: J} = Map()
    wm.set("a", mk())
    const dl = { f: 1 }
    const xs = [m.get("a") ?? dl]
    print(xs[0].f ?? 0)

Want:

    4

#### Mechanism

A `??` default held in a binding is built at the read's record by adopting the binding there
(D15217, D15240), while the literal slot holding the join is built by the store column
(`storeSlotHeldAt`, D15312); the two builds do not meet, and emit refused the list element ("a value
that fits `J` may be stored as another arm") and built the record field invalid. `storeSlotHeldAt`
refused the slot at check instead. D15310 then built a `const` literal default at the read's record
while it keeps its own type, which leaves the join one record; the refusal narrowed to the
defaults still pinned there (D15316).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the binding (`[m.get("a") ?? { f: 1 }]`) | runs (D15312) | **yes** |
| the literal (`const b = m.get("a") ?? dl`) | runs (D15217) | **yes** |
| a call held instead (`const dl = mkd()`) | still refused (D15316) | no |
| a record literal `{ g: … }` instead of the list | still refused | no |
| the join bound first (`const b = m.get("a") ?? dl; [b]`) | still refused | no |
