### D16144 — two bound lists of records, one whose function-field members' results differ and one whose agree, handed to the same un-annotated parameter, are refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · the residue of [D16160](D16160.md) · filed 2026-11-14 against master `29d333d96`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function dbl(a) { return a * 2 }
    function take(v) { print(v[1].f(3)) }
    const l = [{ f: inc0 }, { f: half }]
    const m = [{ f: inc0 }, { f: dbl }]
    take(l)
    take(m)
    // vl run: emit error, "emitProgram: cannot take the generic function `half` as a value …"

Want:

    1.5
    6

#### Mechanism

Not ablated to a line. One parameter is handed both lists, so its hands join their field sets.
`l`'s set is tagged once the instance's call through it splits (D16160). `m`'s members agree,
so its list keeps closures. With both through one parameter, the planned set covers members of
both lists, and `half` reaches the value floor unpinned.

#### Ablation

| change | outcome |
| --- | --- |
| witness | emit reject |
| `take(m)` replaced by `other(m)`, a second callee | runs, prints `1.5` / `6` |
| `m` holds `dbl` and `half`, whose results also differ | runs, prints `1.5` / `1.5` |
| `take(l)` alone | runs, prints `1.5` (D16160) |

#### Grading list

The witness with `take(m)` before `take(l)`.
