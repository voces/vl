#### Mechanism

`monoCloneGenericCalls` re-mints the call `pass(t)` for the instance, so the `Member` over it is
re-made too. The re-made read had no `nodeSrc`, so the instance's elaboration record for the
read was not found, and `emitIs` saw the template's type `i32 | string`, a union with no box at
the pin. With the source noted, the read is `i32` (or `string`) and D15544's arm answers `true`.
The false direction then needed D15606's arm for an effectful operand: the call is evaluated and
dropped, and the test is `false`.
