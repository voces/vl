### D17426 — a hole function that reads its parameter through `?.` and returns it, delivered wider, emits an invalid module

**check-clean invalid wasm · clause 1 · `vl check` rc 0, `vl run`: invalid module inside `g` · legacy's bytes · filed 2026-11-25 by lane S1 against master `c59738bbd`, found by D17047's grid**

Repro:

    type A = { d: i32 | null }
    function g(v) {
      print(v?.d)
      return v
    }
    const c: A = g({ d: 5 })
    print(c.d ?? -1)
    // vl check: 0 errors.  vl run: invalid module, inside `g`

Want:

    5
    5

#### Mechanism

D17047's spelling with `?.` in place of `.`. D17047's fix admits a `.` field read before the
hand-back, but admitting `?.` there alone does not make this run: another site still builds the
parameter at the literal's own row. `?.` on an annotated `v: A`, or an un-annotated `c`, runs.

#### Grading list

`print(v?.d ?? 0)`, and a `?.` read nested in an `if` condition.
