### D4081 — `if r is B` over a record `A` does not narrow `r` when `B` narrows a field to a string literal set

**loud check reject · clause 2 · residue of the D4058 close · filed 2026-10-11 against master `5a9535c91`**

Repro:

    type A = { k: string }
    type B = { k: "p" | "r" }
    function take(b: B): string { b.k }
    function g(b: A): string {
      if b is B { return take(b) }
      "no"
    }
    print(g({ k: "p" }))
    // vl check: rc 1, "argument 1: expected B, got A"

Want:

    p

#### Mechanism

The test itself runs (D4058). The then-arm is not narrowed to `B`, because `B` stores a
string-literal-set field as an atom and `A` stores it as a string, so the `A` value cannot be
delivered where a `B` is wanted. Narrowing it there was check-clean invalid wasm. The
`checkIsExprNode` side gates the narrowing on `recFitNarrowKeepsRep`. A close needs a
conversion from `A`'s layout to `B`'s at the narrowing, or a narrowing of the field read
alone.

#### Ablation

| variant | outcome |
| --- | --- |
| `B = { x: 1 \| 2 }` over `A = { x: i32 }` (numeric set) | runs, narrowed |
| the narrowed `b` read as `const y: "p" \| "r" = b.k` | refused, "cannot assign string" |
| the narrowed `b` returned as `B \| null` | refused, "return type mismatch" |
