Repro:

    function k<T>(v: T) { return ((p: T) => p)(v) }

#### Mechanism

D2037's rung is the one that types an instance whose result can be null, from the template's
checked signature, and it declined any return naming a type parameter. The checked return here
is the bare `T`, so the instance kept the `i32` default while the lambda's per-instance clone
returned the `string | null` niche. The rung now substitutes the checked return through the
instance's binding and applies it when the result bears null, registering a union the pin mints
(D1042's `monoRegisterPinUnion`). It is D2574's second half: one rung, two spellings.
