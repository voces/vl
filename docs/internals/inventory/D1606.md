### D1606 — a declared struct NO union claims donates its heap type to a union-annotated binding's slot

**check-clean invalid wasm · 1 mechanism, 3 witnesses collapsed by ablation · filed 2026-09-05 against master `ec28b12e`**

Repro:

    type A = { q: i32 }
    type Q = { q: i32 }
    type U = Q | i32
    function mkA(): Q { { q: 5 } }
    function main() {
      const x: U = mkA()
      if x is Q { print(x.q) }
    }
    main()
    // vl check: rc 0.  vl run: invalid module,
    // type mismatch: expected (ref $type), found (ref $type)
    // should print 5 — every other delivery position of this value does

Line removal alone minimises to the first six lines: the `is` read and the `main()` call are
not needed for the outcome, and are kept so that a close has a value to be right about.

#### Mechanism

The disassembly names both elided types. `$1` is `(struct (field (mut i32)))` — the row
`collectS` minted for `A`, the twin no union claims; `$3` is `(struct (field i32))`, the
variant heap type for the arm `Q`; `$2` is the union box `(struct (field i32) (field anyref))`.
`main` declares `(local $0 (ref $1))` and then stores `(struct.new $2 (i32.const 0) (call
$mkA))` into it: the slot's valtype is the TWIN's struct, the value is the box. `mkA` itself
returns `(ref $1)`, so the arm's own `$3` is minted and never used. The slot kind is
`collectLocals`' — `emitLet` calls it "the authoritative rep" — and it classified this binding
`struct` against `A`'s row instead of `union`, because `collectS` skips a `TypeDecl` the
emitter's `uVariants` claims and so `Q` has no struct row for the initializer to resolve to,
while the unclaimed twin does. Remove the twin and there is no row at all and the slot is
correctly the box.

#### Grading list

The three witnesses this collapsed, each of which must run when it closes: the nested-shape
spelling (`type A = { d: { q: i32 } }` with `type Q = { q: i32 }`), the same program with the
union `==` that first exposed it, and the `Q | B` struct-second-arm form. Beyond them,
[D1490](D1490.md) is the same-shape union's registry pin and must keep running — its twins are
both arms, which this row's ablation says is the case that works — and
`tests/cases/soundness/call-result-union-binding.vl` is the module-scope face that already runs.
The four positions that run today (argument, return, module-scope binding, `const` hop) are the
position matrix a fix must re-grade, since each reaches the destination through a different
delivery.
