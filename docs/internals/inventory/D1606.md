### D1606 — [CLOSED 2026-09-05] a union annotation and the initializer's arm claimed the same cell, and only one of them wrote it

**closed · was check-clean invalid wasm · 1 mechanism, 3 witnesses collapsed by ablation · filed 2026-09-05 against master `ec28b12e`, fixed in #PR**

Repro:

    type A = { q: i32 }
    type Q = { q: i32 }
    type U = Q | i32
    function mkA(): Q { { q: 5 } }
    function main() {
      const x: U = mkA()
      if x is Q { print(x.q) }
    }
    main()
    // prints 5

Line removal alone minimises to the first six lines: the `is` read and the `main()` call are
not needed for the outcome, and are kept so that a close has a value to be right about.

#### Mechanism

Two producers answer "what rep does this cell have", and they read different inputs.
`collectLocals` classified the binding from its INITIALIZER — `letIsVariant` fell through to
`exprVariantIndex(mkA())`, the arm `Q`, so the slot was the kind-8 variant ref
`(ref $(uVarHeap[Q]))`. `emitLetDeclStmt` coerced the value against the ANNOTATION,
`emitUnionCoerce(body, "U", …)`, which boxes. The store and the cell were one heap type apart.

The twin is what makes them disagree OUT LOUD, and the filed reading of it was wrong: the
slot is classified identically with the twin and without it. What the twin changes is the
STORE. `emitUnionCoerce`'s arm rung goes through `unionArmVariantForStructExpr`, which opens
`structIndexOfExpr(exprIx) < 0 → -1`; `collectS` skips a `TypeDecl` that `uVariants` claims,
so the arm `Q` has a struct row only when an unclaimed layout twin donates one. With the twin
the rung fires and boxes into a variant cell — invalid. With no twin it declines, the value
passes raw, and the raw ref happens to fit the variant cell — which is why the un-twinned
spelling ran. Probe of the rung's input, both spellings, on `ec28b12e`:

    p1 (twin, call init)  letAnnIsUnion=T letIsVariant=T variantIndexOfLet=0 letIsUnion=T
    p3 (no twin, same)    letAnnIsUnion=T letIsVariant=T variantIndexOfLet=0 letIsUnion=T
    p2 (twin, obj literal) letAnnIsUnion=T letIsVariant=F variantIndexOfLet=-1 letIsUnion=T

The `is Q` arm was not independently wrong: `(i32.const 1)` plus a bare `struct.get` is the
correct read of a kind-8 cell, and it lowers as a tag compare and a `ref.cast` the moment the
cell is the box.

#### Fix

The annotation wins the cell: `letIsVariant` and `variantIndexOfLet` decline an init-derived
variant under a value-union annotation, so a union-annotated binding is always the box — the
same rep `globalCellKind` has always given a union GLOBAL. The binding boundary then boxes an
arm value through `emitUnionArmValueBox`, the rung lifted out of `emitUnionBoxArg` that the
argument and global boundaries already deliver through (#1678 wired those two).

`compile(candidate, master source)` is byte-identical to master's fixpoint: the compiler's own
source carries none of this shape.
