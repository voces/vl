Repro:

    function id<T>(x: T): T { x }
    function inc(x: i32): i32 { x + 1 }
    const ys = [id]
    ys.push(inc)
    function run<U>(a: ((x: U) => U)[], u: U): U { a[1](u) }

The owed outcome is a check refusal.

#### Mechanism

[D10080](D10080.md)'s delivery judge reads the push row at the type the delivery fixes, and
this delivery fixes none it can read: the argument binds `U` to `T`, `id`'s own type
variable, so the delivered element type still carries a type variable and the judge skips
it. The slot judge of [D10120](D10120.md) runs only for an un-annotated parameter.
