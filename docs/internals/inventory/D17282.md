### D17282 — a two-level optional chain to a literal-set field its layout family stores as a string emits an i32 where the string is

**check-clean invalid wasm · clause 1 · found by IR-V3 verifying #9970, filed by lane IR-N8 · filed 2026-11-24 against master `8695362aa`, the same with and without the IR's claims**

Repro:

    type K = "circle" | "round"
    type A = { kind: K, r: i32 }
    type B = { kind: string, r: i32 }
    function mk(n: i32): A | B {
      if n == 0 { return { kind: "round", r: 1 } }
      return { kind: "zz", r: 2 }
    }
    type W = { a: A | null }
    function deep(w: W | null): K | null { return w?.a?.kind }
    print(deep({ a: { kind: "round", r: 1 } }) ?? "none")
    print(mk(1).r)
    // vl check: rc 0.  vl run: invalid module, inside `deep`: type mismatch: expected i32,
    // found (ref $0); $0 is `string`

Want:

    round
    2

#### Mechanism

Not traced. `B` beside `A` in `A | B` makes the layout family store `A.kind` as the string
(D14752); a one-level `a?.kind` reads that string, and a two-level `w?.a?.kind` writes the atom's
`i32` where the field holds the string. The ablation fixes the ingredients.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `B` and `mk` (no layout family) | runs | **yes** |
| one `?.` level: `a?.kind` off `A \| null` | runs | **yes** |
| the return: `print(w?.a?.kind == "round")` instead | still invalid | no |
| the inner link's null: `W = { a: A }`, `w?.a.kind` | still invalid | no |
| the result widened to `string \| null` | still invalid | no |

#### Grading list

The `==` spelling above, and `return w?.a?.kind` at `string | null`.

Traced 2026-11-25 by SOUND (not closed by D17283's fix, which is a generic body's context): the
chain's leaf is written by the shared `emitOptLeafHead`/`emitOptLeafTail` (wasmEmit.vl, called by
legacy and by the IR's optional read alike), whose `sentinel` arm for a `K | null` niche reads the
field and closes the `if`, with no decode of a field the family stores as the string. A one-level
`a?.kind` is the atom hook's (`pre-path atom hook`): the IR declines it and legacy decodes. The close
is a decode in the sentinel arm, which needs the atom staging slot (`atomStage`) reserved for the
leaf by both emitters' reservations; legacy's is frozen (O3).
