#### Mechanism

`B` beside `A` in `A | B` makes the layout family store `A.kind` as the string
(D14752); a one-level `a?.kind` reads that string, and a two-level `w?.a?.kind` writes the atom's
`i32` where the field holds the string. A one-level `a?.kind` is the atom hook's (`pre-path atom
hook`); a deeper leaf is written by the shared `emitOptLeafHead`/`emitOptLeafTail`, whose
`sentinel` arm read the field and closed the `if` with no decode. The ablation fixes the
ingredients.
