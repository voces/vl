### D2938 — a spread copy of an un-annotated list of nested-record literals takes the first-declared record of the same layout

**check-clean invalid wasm · clause 1 · open · the same on master `8615a730d` · D2933's grading-list spread form, which is a different mechanism from D2933 · filed 2026-09-28 against master `8615a730d`**

Repro:

    type A = { v: i32 }
    type J = { f: A | null }
    type I = { f: A }
    const il = [{ f: { v: 7 } }]
    const cp = [...il]
    print(cp.length)
    // vl check: rc 0.  vl run: invalid module in the top-level code

Want:

    1

#### Mechanism

Not localised past the ablation. `il` is built as a list of `I`, and the spread builds a copy of
that list. `cp`'s cell is a list of `J`, the first-declared record whose field names match and
whose field is stored the same way: a nested record field is `(ref null $A)` in both. The two
records are still two heap types in the recursion group, so the copy is stored into a cell of
the other type. Nothing delivers either list to `J`.

#### Grading list

A string field (`{ f: string | null }` beside `{ f: string }`) runs, so grade the nested-record
field against the other reference fields a record can hold: a list field, a map field and a
nullable string.
