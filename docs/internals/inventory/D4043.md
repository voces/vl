#### Mechanism

`gen`'s instance at `A` builds an `A[]`, and the element is resolved through a registration that
the unrelated `A | null` binding put in place, so the element is looked up as a union atom rather
than as a list. Neither the generic alone nor the `A | null` alone reaches it. Not yet traced.
