### D15825 — a field read off a record built wider, delivered at the read's own type, hands on the wider record

**check-clean invalid wasm · clause 1 · open · found grading D15822 · the same on master `4e65bd710`**

Repro:

    type J = { f: i32 | null }
    type K = { j: J }
    const y = { j: { f: 4 } }
    const ks: K[] = [y]
    const w: { f: i32 } = y.j
    print(w.f)
    // vl run: invalid module — expected (ref null `{f:i32}`), found (ref `J`)

Want:

    4

#### Mechanism

`y` is built at `K` (here a literal binding a `K[]` takes), so `y.j` holds a `J`, which stores `f` as `i32 | null`. Delivered where the
read's own type `{f: i32}` is declared, the reference is handed on as it is built, and no copy or
refusal is recorded for it: the delivery seam judges the read by its own type, which equals the
destination. A binding read held at another record is judged by its held record
(`storeHeldArgsAt`); a field read is not.
