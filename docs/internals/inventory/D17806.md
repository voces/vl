#### Mechanism

The bound choice is a set value with no one instance, so `fvaAdapt` took the escape route
(`fnTagEscapeNote`), which builds each member's closure at its own signature: the trampolines
return `i32` and the call through the parameter is made at the union-result type. The inline
choice ran because each arm is delivered alone, through its own adapter. Before the fix: Inside a function the same program traps instead (D17805).
