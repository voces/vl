### D2798 — a generic whose returns join a nested list of its parameter with a nested `i32` list builds both arms as the `i32` one

**check-clean invalid wasm · clause 1 · found grading D2783's positions · the same on master `b586b6063` · filed 2026-09-27 against master `b586b6063`**

Repro:

    function h<T>(c: boolean, t: T) {
      if c { return [[t]] }
      [[1]]
    }
    const q = h(true, "s")
    if q is string[][] { print(q[0][0]) } else { print(-1) }
    // vl check: rc 0.  vl run: invalid module inside `h`

#### Mechanism

At `T := string` the instance's result is the union `string[][] | i32[][]`, but both returns are
boxed under the `i32[][]` arm's tag and built as that list, so `[[t]]` stores a string list where
an i32 list is declared. The outer literal's own type in the template is `T[][]`, which the
return's arm selection cannot read at the pin. The one-level `[t]` beside `[1]` builds (D2766),
and the same function with `t: string` spelled out runs since D2768. Not yet localised further.

| --- | --- | --- |

| one level of nesting (`[t]` beside `[1]`) | runs | **yes** |
