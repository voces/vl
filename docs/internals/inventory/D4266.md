### D4266 — a field read in the then-arm of a cross-arm `is` is refused when the arms store the field differently

**closed 2026-11-14 — the then-arm read dispatches on the box tag, widening `A`'s atom to the string `B` stores · was loud emit reject, `emitProgram: field access receiver is not a struct` · clause 2 · follows D4056: before it the union itself was refused · found by the review of #3579 · filed 2026-10-12 against master `3efb1763c`**

Repro:

    type A = { v: "a" | "b" }
    type B = { v: string | null }
    function f(u: A | B) {
      if u is A { print(u.v) } else { print("B") }
    }
    const b: B = { v: "a" }
    f(b)
    // vl check: rc 0.  vl run: emitProgram: field access receiver is not a struct

Want:

    a

#### Mechanism

`u is A` is true of a `B` whose `v` holds `"a"`, so in the then-arm `u` may be either arm's
struct. `A` stores `v` as a literal-set atom and `B` as a nullable string, so no single
`struct.get` reads it, and the read finds no struct row for the receiver.

#### Ablation

| variant | outcome |
| --- | --- |
| this witness | emit refusal |
| `print("A")` in place of the read | runs |
| `B = { v: string }` | runs, `a` |
| no `is`: `print(sh(u.v))` over `{ v: i32 \| null } \| { v: string \| null }`, `sh` typed at the join | the same refusal |
| a `k: "a"` / `k: "b"` discriminant added | the same refusal (master refuses the union when it lays it out) |

The review-round-2 grid (`d4056_then_read_positions.py`, 13 field types, 8 positions) puts 119
of its 1,248 cells here.

#### Closed by

The shared-field dispatch D15882 opened: `sharedFieldNulStrPlan` now admits a member storing a
string literal set at the atom, so the plan reads `B`'s nullable string as the string and widens
`A`'s atom to its string. A `B` holding `"zz"` fails `is A` and prints `B`. The `no is` row of the
ablation already ran on master `2509180f3`.
