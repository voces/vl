### D4266 — a field read in the then-arm of a cross-arm `is` is refused when the arms store the field differently

**loud emit reject · clause 2 · follows D4056: before it the union itself was refused · found by the review of #3579 · filed 2026-10-12 against master `3efb1763c`**

Repro:

    type A = { v: "a" | "b" }
    type B = { v: string | null }
    function f(u: A | B) {
      if u is A { print(u.v) } else { print("B") }
    }
    const b: B = { v: "a" }
    f(b)
    // vl check: rc 0.  vl run: emitProgram: field access receiver is not a struct

Want:

    a

#### Mechanism

`u is A` is true of a `B` whose `v` holds `"a"`, so in the then-arm `u` may be either arm's
struct. `A` stores `v` as a literal-set atom and `B` as a nullable string, so no single
`struct.get` reads it, and the read finds no struct row for the receiver.

#### Ablation

| variant | outcome |
| --- | --- |
| this witness | emit refusal |
| `print("A")` in place of the read | runs |
| `B = { v: string }` | runs, `a` |
| no `is`: `print(sh(u.v))` over `{ v: i32 \| null } \| { v: string \| null }`, `sh` typed at the join | the same refusal |
| a `k: "a"` / `k: "b"` discriminant added | the same refusal (master refuses the union when it lays it out) |
