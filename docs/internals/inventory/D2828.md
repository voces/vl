### D2828 — a bare `null` argument to a `boolean | null` parameter of a function value is refused

**loud emit reject · clause 2 · found by #3213's review · identical on master · filed 2026-09-27 against master `2bbc5c412`**

Repro:

    function f(b: boolean | null): i32 { if b == true { return 1 } 0 }
    function g(fn: (boolean | null) => i32): i32 { fn(null) }
    print(g(f))
    // vl check: rc 0.  vl run: emitProgram: bare null needs a struct-typed context

#### Mechanism

`boolean | null` is the i32 sentinel niche and has no `$fnsig` token, so the value call
keys no signature. It reaches the all-i32 arity functype, which is sound for this niche since
D2810. The argument loop, though, emits each argument under the expectation the key's
parameter kind gives it. With no key there is no `nulbool` expectation, so a bare `null`
reaches the struct-null floor instead of lowering to the sentinel. A non-null argument
needs no expectation and runs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `null` argument (`fn(true)`) | runs, prints `1` | **yes** |
| the function value (`f(null)` directly) | runs, prints `0` | **yes** |
| `boolean` (an `i32 \| null` parameter, the value-union box) | runs | **yes** |
| the named function (a lambda `(b, n) => …` over `(boolean \| null, i32) => void`) | refuses the same way | no |
