#### Mechanism

A served check merges only S, so `crProgRoot` is S's root, and `crInfoOf` answers "who writes
`g`" from S alone. Main's `w` writes `g` and escapes into `reg`, which makes `noop()` end the
narrowing; the S-only check never saw `w` and kept it. Every whole-program question that walks
the program root has the same blind spot: `crNameAssignedInRoot`, `crNameNulledInProgram`,
`crRootMayKeep`, `crEscapesIn` at the root, and the sole-reference rows.
