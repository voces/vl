### D9492 — a function returning a mixed-width numeric literal union is not assignable to one returning `i64`

**loud check reject · clause 2 · CAPABILITY: the value converts (`const b: i64 = a` runs), and a single-width union (`5000000000 | 6000000000`) relates to `() => i64` since D9382 · found closing [D9382](D9382.md) · present on master `56e51b394` · filed 2026-10-21 against master `56e51b394`**

Repro:

    type N = 1 | 2 | 5000000000
    const a: N = 2
    const f: () => N = () => a
    const g: () => i64 = f
    print(g())
    // vl check: cannot assign () => N to 'g' of type () => i64

Want:

    2

#### Mechanism

Not traced. `numLitUnionBaseTy` answers -1 for a union whose literals soften to two widths, so
D9382's slot rule (`fnSlotStoreTy`) does not apply and the slot compares `ESC_BOX` against
`ESC_I64`. Whether the union reps as `i64` or as a box decides between sharing the signature
and an adapter.
