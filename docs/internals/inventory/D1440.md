#### Mechanism

`TyNullable.nInner` is `-1` while the inner type is still a HOLE — which is exactly what a
bare-`null` list literal with nothing to pin its element leaves behind. `nodeTyIsNulBool`
guarded its OWN lookup (`if ty < 0 { return false }`) and then read `T.tys[t.nInner]`
unguarded, so the arena read at `-1` trapped. The trap is downstream of an `emitFail` that
already recorded `bare null needs a struct-typed context`: emission continues after a
recorded failure by design, and the next parallel-table read has to survive it.

Localised with `vl build compiler/entry.vl --names`, then that module as the `--compiler`
seed: the backtrace names `nodeTyIsNulBool$m9` instead of `<wasm function 1052>`.
