### D3059 — a written record list passed to a `readonly Shape[]` parameter, or stored into a `readonly Shape[]` module binding, is refused at emit

**closed · a fresh `const` literal is skipped by the view note only where nothing writes it, and a spilled tail-statement store carries the note to the read it delivers · fixture `tests/cases/arrays/readonly-record-view-written-literal.vl` · was loud emit reject · the record twin of [D3042](D3042.md) · closes [D1806](D1806.md) and [D1807](D1807.md) as well · found by the #3266 review · the same on master `b09566e16` · filed 2026-09-28 against master `b09566e16`, closed 2026-09-28 against master `67ca68cf3`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    function rd(r: readonly Shape[]): i32 { return r.length }
    const l: Circle[] = [{ r: 1 }]
    function grow() { l.push({ r: 2 }) }
    grow()
    print(rd(l))
    // vl check: rc 0.  vl build: emitProgram: covariant list delivery: a Circle[] cannot be
    // delivered into a Shape[] here.

Want:

    2

#### Mechanism

Two gaps, one per position. At the argument, `emitRefListWidenSite` declines the copy because
`covarValueWriteState` sees `l` written, and a declined delivery into a `readonly` destination is
a [D3041](D3041.md) view only where the checker recorded it (`noteRefListView`). That note
skipped every root `covarRootFreshLocal` calls fresh, a `const` bound to a list literal, on the
ground that the copy serves it. The copy serves it only while nothing writes it, so the note now
skips a fresh root only where the write state is 0. At the module-binding store, `keep = x` was
the tail statement of `st`, which [D2398](D2398.md) spills as `const asg#N#nv = x; keep =
asg#N#nv`. The spilled read was a new node with no note, so the store was declined for any root,
fresh or not. `spillLocal` now carries the note to the read (`refViewCarry`).

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| no write to `l` | runs, prints `1` (the copy is licensed) | **yes** |

| the store `keep = x` followed by another statement in `st` | runs | **yes**, at the store (the spill) |
| the store's argument a call result `const l = mk()` | the same refusal | no, at the store |
| the store into a `readonly Shape[]` module binding instead of an argument | the same refusal | no (position) |
