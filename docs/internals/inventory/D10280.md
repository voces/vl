#### Mechanism

The checker types the join in the generic body `T | f64`, so `r is i32` passes `vl check`. The
pin of `g` at `i32` re-joins the arms through `joinPinnedArmLit` (check_emit_queries.vl), which
asks `njFnReached` of the pinned function; a generic that mentions itself is gated there
([D3494](D3494.md)), so the re-join widens to `f64` and the test reads `false`. The returned
spelling of the same join is refused by the checker, which is D3494's face.
