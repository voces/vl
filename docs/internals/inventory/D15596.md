### D15596 — a capturing nested HOLE function of a generic encloser, handed to a parameter that calls it at two types, gets no pin

**loud emit reject · clause 2, `vl check` rc 0, then `emitProgram: a generic function taken as a value reaches no call that fixes its type` · D15595's neighbour · filed 2026-11-09 against master `714c5595`**

Repro:

    function mid<F>(a: F) {
      print(a("x"))
      print(a(2))
    }
    function outer<U>(u: U) {
      function same(k) {
        print(u)
        k
      }
      mid(same)
    }
    outer(7)
    outer(true)

Want:

    7
    x
    7
    2
    true
    x
    true
    2

#### Mechanism

D15595 hands a generic nested `same<T>` as a bundle, one closure per signature built in each
`outer` instance (`elabNestedGeneric`). A hole `same(k)` is not admitted there: bundled the same
way, the program builds and traps with `indirect call type mismatch` once `outer` has two
instances (`outer(7)` and `outer(8)` run), so the closure a second encloser instance hands is not
the one its signature names. Unbundled, mono pins `mid(same)`'s argument from the open type.
