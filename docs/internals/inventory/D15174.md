### D15174 — an un-annotated map of functions handed to a hole parameter that calls a value it reads by `get` has no call to emit

**loud emit reject · `emitProgram: callee is not a function name` · clause 2 · open, target `6` · found closing [D15167](D15167.md), the map half of [D15161](D15161.md) · filed 2026-11-03 against master `93bcb08d7` plus the D15167 PR**

Repro:

    function half(a) { return a * 2 }
    const m = Map()
    m.set("b", half)
    run(m)
    function run(m) {
      const g = m.get("b")
      if g != null { print(g(3)) }
    }
    // Want: 6

#### Mechanism

`vl check` accepts the program and the emitter cannot lower `g(3)` in `run`'s instance: the map's
value set reaches neither a direct call nor a dispatch there. Before D15167's PR the same program
refused with `a function-value call has no interned signature — no function value of type
`(i32)=>i32` reaches this call`; that PR records the instance's call through `g` as a mint fact,
which moves the message and not the outcome. The function is declared after its call because the
other order is the deliberate map-demand floor (`tests/cases/maps/error-infer-param-map-not-pinned.vl`,
ROADMAP E5), which refuses every map argument at check.
