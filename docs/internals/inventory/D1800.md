#### Mechanism

Not probed beyond the ablation. [D1784](D1784.md) routed `letIsNulNone` through
`letRepAnnOf`, so the binding's CELL is now the `nulnone` one an un-annotated `const x = null`
gets — and the refusal moved not at all, which is what says the deciding site is elsewhere.
The message is emitted where a bare `NullLit` is LOWERED, not where the binding is classified:
that site asks for a struct-typed context and a negation supplies none, exactly as it supplies
no rep. `const x = null` runs because its context is the `nulnone` cell the classifier gives
it, so the two ends already agree there.
