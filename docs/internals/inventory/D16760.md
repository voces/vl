#### Mechanism

`constrainEmpty` pinned the binding's open element to `V[]`, which names the callee's unbound `V`,
so the caller's `e` was `V[][]` and its local had no shape. A binding's open list is now pinned to
an open inner list, and that inner list is held for `V` as D16758 holds a bare `V` element; the
argument is delivered at its own type, since `V[][]` names no type at the caller. A literal keeps
its per-call build. A later `e.push([2.5])` fixes the inner list's element from the pushed list.
