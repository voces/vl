### D16760 — an open `[]` binding handed to a generic `V[][]` parameter is refused at emit

**loud emit reject · clause 2 · `emitProgram: ref valtype with no interned shape` · found grading D16758's neighbours; unchanged by its close · filed 2026-11-16 against master `e33ab71cc`**

Repro:

    function probe<V>(v: V[][]) { return v.length }
    const e = []
    print(probe(e))
    // vl check: rc 0.  vl run: emit error, ref valtype with no interned shape

Want:

    0

#### Mechanism

`constrainEmpty` pins the binding's open element to `V[]`, which names the callee's unbound `V`, so
the caller's `e` is `V[][]` and its local has no shape. D16758's close holds a bare `V` element
open; an element that holds `V` inside a list is still pinned. Holding it as an open inner row
was tried and refused at the call (`expected V[][], got _[][]`), since an open inner row is not
assignable to `V[]`.
