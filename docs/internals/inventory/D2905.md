### D2905 — a lambda in a generic body whose tail is a value `if` is lifted without its pinned return type

**closed 2026-09-27 · was loads then traps, clause 1, on master `ed9f09f7f` · found by the GJ lane · filed 2026-09-27 against master `ed9f09f7f` · fixture `tests/cases/generics/lambda-tail-if-at-the-pin.vl`**

Repro:

    function g0<T>(a: T, b: T, c: boolean) { const f = () => if c { a } else { b }; const r = f(); if r == null { print("null") } else { print(r) } }
    const u: string | null = "n"
    const w: string | null = null
    g0(u, w, false)
    // vl check: rc 0.  vl run on master: wasm trap, null reference in `__lambda_1`

Want:

    null

#### Mechanism

A lambda cloned per pin is given a return annotation from its return expression's recorded
type (`fnRetExprOf`), and a tail `if` is not a return expression, so the clone had none. Its
return kind was then classified from the arms, which read `string` and dropped the `null`,
and the lifted function declared `(ref $string)`, casting the null arm to non-null. The clone
now takes the return type the template lambda was checked at when it has no return expression.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the value `if` (`() => b`) | prints `null` | **yes** |
| the lambda (`const r = if c { a } else { b }`) | prints `null` | **yes** |
| the type parameter (`a: string \| null`) | prints `null` | **yes** |
| the ref member of the pin (`T := i32 \| null`) | prints `null` | **yes** |

#### Grading list

`g0(u, w, true)` prints `n`, and the `i32 | null` pin prints `7` and `null`; the const-alias
(`const h = f`), nested-lambda and tail-`match` spellings print `null` then `n`. A lambda with
an un-annotated parameter, `(x) => if c { x } else { b }` called as `f(a)`, is instantiated per
call rather than cloned here and still traps, as on master; that path is not changed here.
