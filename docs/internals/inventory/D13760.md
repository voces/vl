**closed 2026-10-25 by lane L1 · runs, prints `5` · the field's inline literal had inherited the arm hint the list put on its element: `emitArrRef` seeds `variantIdx` for every element, `emitVariantCoerce` builds the element through `emitVariantStruct` without consuming it, so `{x: 5}` was built as `A` too. Repro:

    type P = {x: i32}
    type A = {p: P}
    type U = A | {n: i32}

    const xs: A[] = [{p: {x: 5}}]
    print(xs[0].p.x)

#### Mechanism

The element `{p: {x: 5}}` is built as `A`'s variant struct, and the field value for `p`, an inline literal that has to become a `P`, is not found among the literal's fields. So `emitVariantStruct` refuses. Not yet traced past that site. The answer probe at `objNestedFieldCompat` and `structIndexOfMemberExpr` sees no event on this program, so those two readers are not where the field goes missing.
