#### Mechanism

**BOTH REPS, OFF THE BYTES** (`wasm-dis`, binaryen 130, on the `is` witness). The SLOT was never
wrong: `local $1` is `(ref $2)` = `(struct (field i32) (field anyref))`, the union box, in every
face. What disagreed was the `??`'s own result rep — the desugared `if` took an `i32` blocktype
while both its arms pushed the box:

    (local $1 (ref $2))                                   ;; the binding: the union box
    (local.set $1 (if (result i32) … (local.get $0) …))    ;; the `??`: i32

After the fix the same `??` lowers as a statement-form `if` writing the box into `local $1`, and
the inferred face's module is byte-identical to the annotated face's.

`unionNameOfExpr` names a union by RENDERING the node's type (`tyToEmitName`) and then asking a
NAME-keyed registry scan (`isUName` over `unNames`). That answers for a spelling the program
wrote and misses one INFERENCE minted. Probed at the rung: for `let v = (srcOpt ?? …)` the init
node is the `IfStmt` D962's `??` desugaring produces, its recorded type renders
`{kind:string,r:f64}|{kind:string,w:f64,h:f64}` — the arms structurally, the literal
discriminants widened — and no `Shape` is there to find. `letUnionNameOf` therefore banked "",
`unionNameOfIdent("v")` answered "", `currentStructNarrowSetOf("v")` answered "", and
`sharedUnionFieldPlan` declined on an EMPTY member set before it ever looked at a variant.

The hole-param face is the same miss at the other arm. `passh(x)` has no return annotation, so
the `Call` arm falls through to `nodeUnionName`, which gates itself to an all-value-atom union
BEFORE rendering (the #494 cost discipline) and so declines a struct union by construction.

The fix is `unRowOfCanon` — the canon-keyed reverse index over the SAME registry rows, keyed on
the interned structural id rather than on a spelling. It names the row from the TYPE and hands
back `unNames[u]`, the declared spelling every downstream member-set, narrow and variant lookup
already keys on, so nothing below the producers had to change. The `AsExpr` and `IfStmt` arms
already carried a name-keyed `isUNameAB` rung for this shape; this is the same question asked of
the key that can answer it.
