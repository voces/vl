### D2254 — a map read keyed by a call, with a nullable `??` default, emits an invalid module

**closed 2026-09-23 — the witness prints `7` · was check-clean invalid wasm: the fused get's `if (result i32)` received the box-typed default · filed against master `3330dcaa3` · fixture `tests/cases/maps/coalesce-nullable-default-fused.vl`**

Repro:

    const m: {[string]: i32} = Map()
    m["b"] = 7
    const d: i32 | null = null
    function key(): string { "b" }
    const r7 = m[key()] ?? d
    print(r7 ?? -1)
    // vl check: rc 0.  vl run: invalid module,
    // "type mismatch: expected i32, found (ref $type)"

#### Close

The fused get's null-free scalar arms (the mono `i32` map, and the f64/i64/f32 slots) lowered
`m[k] ?? d` as `if entry { stored } else { d }` in the scalar's rep, which is only right when
`d` is non-null. With a nullable default the result is `S | null`, so `emitMapGetOrScalarBox`
now builds the box: a hit boxes the stored scalar, a miss delivers `d` through
`emitUnionCoerce`. Graded with D2253 over a 294-cell consumer grid (seven value types; if-joins,
map `??` over null-free and nullable maps at literal and call keys; `== null`, `!= null`, `??`,
`is null`, an argument, `&&`), each beside its bound twin: on the pre-fix seed 124 inline cells
failed (48 invalid wasm, 76 emit refusals) and 72 bound twins were invalid wasm; 0 after.

#### Mechanism

The same map (`{[string]: i32}`, value type excludes null) and the same nullable default
run correctly at a LITERAL key (`m["b"] ?? d`): the D2247/D2248 rewrite
(`emit_rewrite.vl:670`) desugars `m[k] ?? d` into `if m[k] != null { m[k] } else { d }`, but
only when the key is `exprReReadable` — duplicating a `Call` key would evaluate `key()`
twice. A call key declines the rewrite, so the read falls to the same FUSED
single-evaluation lowering D2253 reaches from the other side (`emitMapGetOr` /
`emitMapValDefault`'s scalar arm, `wasmEmit.vl:7652`), which does not correctly deliver a
NULLABLE default as the map's raw scalar kind.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the key being a call (`key()` replaced by the literal `"b"`) | runs | **yes** |
| the default `d`'s nullability (`i32` instead of `i32 \| null`) | runs | **yes** |
