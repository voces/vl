**closed 2026-11-14 · runs, prints `s` · was loud check reject, `cannot write 'str' to 'f': called at (i32) it returns string, where 'inc', also written to it, returns i32 — every function a call through 'f' may run must return one type` · clause 2 · the residue of [D16064](D16064.md) · filed 2026-11-14 against master `bd88d78b2` · fixed by leaving a widened binding handed on to the tag decision (`holeLetJudge`): a set it tags dispatches in the callee's instance, which gives the caller the members' join ([D16091](D16091.md)), and one it leaves a closure is re-checked at the initialiser's type, where the judge still refuses · residue [D16094](D16094.md) · fixtures `closures/written-let-of-hole-fns-handed-to-open-param.vl`**

Repro:

    function inc(a) { return a + 1 }
    function str(_a) { return "s" }
    function ap(g, x) { return g(x) }
    function run(c: boolean) {
      let f = inc
      if c { f = str }
      print(ap(f, 3))
    }
    run(true)
    // vl check: rc 1, the refusal above

Want:

    s

#### Mechanism

A call through the binding itself dispatches on the member it holds (D16064). Handed to `ap`'s
un-annotated `g`, the call happens in `ap`'s instance, where the pin judges the writes
(`holeLetWritesDisagree` from the hole-callee rung of the call check) with no call through the set
to defer to, so the refusal stands in for an instance bound to the set.
