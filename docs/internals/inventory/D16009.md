### D16009 — a re-pointed `let` or a choice of un-annotated functions whose results differ, handed to an open function parameter, is refused at check

**loud check reject · clause 2 · `cannot write 'str' to 'f': called at (i32) it returns string, where 'inc', also written to it, returns i32 — every function a call through 'f' may run must return one type` · the residue of [D16064](D16064.md), whose direct call now dispatches; [D13966](D13966.md)'s witness · neighbour [D15801](D15801.md) · filed 2026-11-14 against master `b53278055`**

Repro:

    function inc(a) { return a + 1 }
    function str(_a) { return "s" }
    function ap(g, x) { return g(x) }
    function run(c: boolean) {
      let f = inc
      if c { f = str }
      print(ap(f, 3))
    }
    run(true)
    // vl check: rc 1, the refusal above

Want:

    s

#### Mechanism

A call through the binding itself dispatches on the member it holds (D16064). Handed to `ap`'s
un-annotated `g`, the call happens in `ap`'s instance, where the pin judges the writes
(`holeLetWritesDisagree` from the hole-callee rung of the call check) with no call through the set
to defer to, so the refusal stands in for an instance bound to the set.

#### Ablation

| change | outcome |
| --- | --- |
| witness | check reject, `cannot write 'str' to 'f'` |
| `print(f(3))`, called directly | runs, prints `s` |
| `sel` returns the `let`, handed on as `ap(sel(true), 3)` (D13966's witness) | check reject, the same sentence |
| two `return`s in `sel`, handed on as `ap(sel(true), 3)` | check reject, `cannot choose 'str' here` |
| `sel` returns `if c { str } else { inc }`, handed on | check reject, `cannot choose 'str' here` |
| members agree (`inc` and `dbl`), handed on | runs |

#### Grading list

The four handed spellings above, each at `run(false)` too (want `4`); [D16091](D16091.md), the list
element handed on, which must not be closed into a run that gives a wrong value.
