Repro:

    type A = { k: i32 | null, x: i32 }
    type B = { k: string | null, y: string }

      print(u.k)
    }

#### Mechanism

From the code path, not ablated to a line. The read's type is `i32 | string | null`, and the
members store the field as two different reps: `A` as the `i32 | null` value box, `B` as a
nullable string reference. The shared-field plan (`sharedUnionFieldPlan`) has no conversion from
one member's box to the read's wider union, so the read falls through to the single-struct path.
