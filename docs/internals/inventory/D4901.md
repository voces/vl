### D4901 — a record literal of a `T[]` field mints no row in a generic body that returns a list

**loud emit reject · clause 2 · found closing D4888 · identical on master `687f37dd5` · filed 2026-10-15**

Repro:

    function h<T>(v: T[]): T[] {
      const r = { xs: v }
      print(r.xs[0])
      return v
    }
    print(h(["e"])[0])
    // vl check: rc 0.  vl run: emitProgram: object literal but no struct type declared

Want:

    e
    e

#### Mechanism

Not yet located. The same literal in a body that returns nothing runs since D4887, so the
return is what skips the mint. The likely gate is `instRetKeepsRecordsIn`, which declines a
body whose return is a constructor over a type parameter (the D2850 rule); not yet ablated.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the return (`h<T>(v: T[])`, no `return`) | runs | **yes** |
| the annotation (`return r.xs`, no `: T[]`) | still refused | no |
| the list (`v: T`, `{x: v}`, `: T`) | runs | **yes** |
