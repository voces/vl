### D10011 — a re-pointed `let` holding a nested list of an un-annotated function, iterated, is an unsupported iterable

**closed 2026-11-08 — the filed repro prints `4` · was loud emit reject (`unsupported for-in iterable`), clause 2 · closed by [D15562](D15562.md)'s fix: the tag pass takes a list of lists re-pointed to a literal of the same set as one holder (`ftListLeavesOfSet`), so the binding holds ids · found closing [D9981](D9981.md) · filed 2026-10-22 against master `00cbfe00b`**

Repro:

    function inc(a) { return a + 1 }
    function main() {
      let v = [[inc]]
      v = [[inc]]
      for r in v {
        print(r[0](3))
      }
    }
    main()
    // vl check: rc 0.  vl run: emit error unsupported for-in iterable

Want:

    4

#### Mechanism

Not yet probed. The loop's iterable is a `let` with two list literals reaching it, and the
nested element is planned once per literal, so the iterable has no single element rep. The flat
list `[inc]` re-pointed the same way runs.
