### D2297 — a closure returning `u8[]` had no `$fnsig` result token on the spelling path, so calling it through a list element refused

**closed 2026-09-24 — the witness prints `7` · was a loud emit reject (`function-value call arity has no interned signature`), clause 2 · fixture `tests/cases/closures/list-literal-into-function-value-param.vl` · found while grading D2295 · filed against master `a295cf301`**

Repro:

    const b: u8[] = [250, 7]
    const h = () => b
    const hs = [h]
    print(hs[0]()[1])
    // vl check: rc 0. vl run (as filed): emit error. Now prints 7.

#### Mechanism

The `$fnsig` key has two producers: the AST one (`cloParamTok`) reads the kind and has a `u8list`
token, and the spelling one (`annParamKind`, `annRetKind`) read `scalarListKindOfName`, which
named five scalar lists and not the packed byte list. A closure called through a list element is
keyed by its element's spelling, so its `() => u8[]` signature keyed nothing. The
classification now answers the list rep itself (`scalarListRepOfName`), `u8list` included, and
both producers take the token straight from `repSigTokOfKind`.
