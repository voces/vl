### D6480 — a generic handed through a `const` alias of a reassigned `let`, to a parameter the callee calls at one type, is refused at emit while the direct call runs

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the direct spelling through the reassigned binding runs, so the alias is a delivery the emitter has not wired (lane L1) · found closing [D6421](D6421.md) · filed 2026-10-18 against master `b21da3d5d`**

Repro:

    function id(a) { return a }
    function other(g) { return 7 }
    let lap = (g) => { return g(1) + 1 }
    lap = other
    const k = lap
    print(k(id))
    // vl check: rc 0.  vl run: emitProgram: a generic function is passed to a function value whose parameter type names a type parameter this closure does not bind, so no instance of it can be chosen — call the function value from the generic function's own body, or pass a function of a concrete type

#### Mechanism

From the ablation only. The callee's one signature fits one instance of `id`, so the
program is legal; through `lap` the emitter picks the instance, through the alias `k` it
does not.

#### Ablation

| spelling | outcome | needed? |
| --- | --- | --- |
| the witness | loud emit reject | — |
| `print(lap(id))`, no alias | runs, `7` | **yes** |
| `lap` called at two types | loud check reject, [D6421](D6421.md)'s contract | **yes** |

#### Grading list

The alias taken before the write, an alias chain, and the same program inside a function.
