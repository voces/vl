#### Mechanism

From the ablation only. The literal's leaf is a hole, so the literal is not retyped at the
parameter it reaches the way a literal of literals is ([D5840](D5840.md), [D5880](D5880.md));
the forwarder's instance takes the list at the type its leaf binds to, while the function it
calls takes `f64[][]`.
