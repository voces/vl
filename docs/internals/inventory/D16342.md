**closed 2026-11-16 · runs, prints `false` · was check-clean silently wrong, prints `true` · clause 1 under owner ruling (a) (DECISIONS "An annotation fixes an empty list's element type wherever the value goes") · found by the `annotated-empty-list-delivered-into-union-is` matrix's un-annotated `argument` and `early_return_guard` cells · filed 2026-11-15 against master `dbbaa6809` · fixed at the pins, from the parked branch `lane-j/d16342-instance-never`: each call re-asks a list `is` over a hole or type parameter (`BND_IS`, `validateIsCstrs`); a test every pin hands fixed lists apart from the tested type is `never` and its arms dead (`settleListIsPins`), an instance whose own fixed list is apart records `never` (`elabCapIsNote`, read by the emitter through `elabIsTyIn`), and a parameter handed both a fixed and an open empty list is refused at both calls (the ruling's interim) · residue [D16701](D16701.md) (a `V[]` operand), [D16447](D16447.md) (the container read) · fixtures `soundness/is-list-test-over-parameter-of-fixed-empty-list.vl`, `soundness/error-is-list-parameter-fixed-and-open-empty-list.vl`**

Repro:

    function take(v) { return v is f64[] }
    const m: i32[] = []
    print(take(m))

Want:

    false

#### Mechanism

Measured 2026-11-15 with temporary probes; nothing landed. The instance's receiver is the
argument's `i32[]`, whose element its annotation fixes, but the list test of disjoint elements
answers by emptiness (`emitListEmptyFitIs`, D4910). That is the rule for a list no write or
annotation fixed, and it should answer `false` here.

- **No call-site re-ask.** `noteIsCstr` (check_cstr_rows.vl) parks record tests only, so a list
  test inside a function with an un-annotated parameter is re-checked only per instance, by the
  elaboration. That recheck sees the arm as dead (`deadArm && isListFitsWhenEmpty`), which D4981
  rules live.
- **The instances cannot be told apart.** `take(m)` binds the annotation's row, and `take([])`
  binds a row the default settled on the emit side. The two are `tyEq`, both hold a concrete
  element, and the checker's `settledRows` records neither, so `rowSettledByDefault` cannot keep
  `take([])` vacuous. The defaulted local of D4910 (`f<T>() { const q: T[] = []; q is f64[] }`)
  is a third case: its `T` reaches an `is`, so `elabTpDefaulted` answers no, and only "no
  parameter names `T`" (`elabParamsMention`) identifies it.
- **The fact a fix needs.** At each call, whether the argument at an un-annotated parameter was
  an open collection, recorded against the binding row the instance is built from. The
  elaboration's per-instance `is` record (`elabCapIsNote`, read through `elabKeyAt(fnIx)`) would
  then bank `never` for a pinned instance. This is the binding fact L2 (inferred interfaces)
  records for un-annotated parameters.

#### The parked fix, 2026-11-15

Branch `lane-j/d16342-instance-never` parks list `is` tests over a hole or type parameter with
the record tests, counts at each pin whether the argument's element is fixed and cannot meet the
tested one, and settles a test only such pins reach as `never`; a fixed pin beside an open one is
refused. It prints `false` for the witness, `gen<T>` and a written list, keeps `take([])` and
D4910's defaulted local `true`, and turns the matrix's `argument` and `early_return_guard` cells
from WRONG to RUNS. It also flips the three corpus contracts above, which is why it waits.
