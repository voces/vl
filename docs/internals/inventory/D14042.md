### D14042 — `as? K[]` over a list of numeric literals refuses: the cast finds neither a value-union arm nor a variant arm

**loud emit reject · clause 2 · filed 2026-10-26 against master `76ab07e5e`**

Repro:

    type K = 0 | 1
    function g(x: K[] | string) {
      const y = x as? K[]
      if y == null { print(7) } else { print(y[0]) }
    }
    g([1])
    g("t")
    // vl check: rc 0.  vl run: emitProgram: `as K[]` is supported for a value-union arm or a struct-variant arm; this arm is neither

Want:

    1
    7

#### Mechanism

The `as?` lowering looks up the target in the union's interned arms. As in D14041, a list of
numeric literals is never interned as an arm, so neither the value-union path nor the variant
path takes it. The refusal also points to the `if x is K[]` ladder, which refuses too
(D14041). The cast is that `is` test followed by the unbox, so it shares D14041's fix: the
box tag plus a per-element literal test.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `K[]` → `i32[]` (in the type and the cast) | runs, `1` `7` | **yes** |
| `K = 0 \| 1` → `K = "a" \| "b"`, partner `i32` | runs, `a` `7` | **yes** (numeric literals) |
| partner `string` → `i32` | still refuses | no |
| cast `x as? string` instead of `x as? K[]` | runs, `7` `t` | **yes** (the `K[]` arm is cast to) |
