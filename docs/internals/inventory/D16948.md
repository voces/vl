### D16948 — [CLOSED 2026-11-17] a list literal whose elements differ in a nested record field builds invalid wasm: the union of records only the join spells has no row

**closed 2026-11-17 · was check-clean invalid wasm · clause 1 · found ablating [D16911](D16911.md) · filed 2026-11-17 against master `b028ce4d9` · fixed by registering the unions a list literal's record element type reaches (`collectU`, the walk an annotation's unions take) · fixture `tests/cases/records/list-literal-join-union-of-records.vl` · matrix `list-literal-join-union-of-records`**

Repro:

    const v = [{ z: { f: 5 } }, { z: { f: { a: true } } }]
    print(v.length)
    // vl check: rc 0.  vl run: failed to parse WebAssembly module

Want:

    2

#### Mechanism

The literal's recorded type is the checker's join of its elements, `{z: {f: i32} | {f: {a: boolean}}}[]`:
the field `z` is a union of two records that no annotation or literal spells. `collectU` registers
the unions an annotation spells and an un-annotated literal's top element union, never one nested
in a record element, so the union had no row and its box was written against heap types that do
not exist. Spelling that union in any annotation in the program made the witness run.
