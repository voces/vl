#### Mechanism

Not localised past the ablation. `s`'s type joins its literal `0` with `s + r.y`, where `r` is the
narrowed value of a key-value walk over a hole whose value type admits `null`. Each re-check of the walk
re-derives `r`'s narrowed face, and the join does not reach a fixed point within the re-check budget. A
value type without `null`, or an annotated `s`, settles it.
