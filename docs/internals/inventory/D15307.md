### D15307 — a record literal written whole into a field or element slot widened by its function field is built at its own row

**closed · runs, prints `2` then `2.5` · was a loud emit reject (`emitProgram: cannot take the generic function id1 as a value`), clause 2 · found grading D15306 · filed 2026-11-04 against master `4eaf52bb` · fixed by answering a field or element slot of a binding the field widener widened with the slot's record: `recAsgFnWidenedTy` (check_fit_rules.vl) walks the place to its binding and down its type, so the assignment-stamp producer `recLitPlaceBuiltTy` builds the literal there, and fn-tag's write join reads the same answer. A choice written into such a place is [D15335](D15335.md); a push or a map set is [D15336](D15336.md)**

Repro:

    function id1(a) { return a }
    function id2(a) { return a }
    const h = { r: { f: id1 } }
    h.r = { f: id2 }
    print(h.r.f(2))
    print(h.r.f(2.5))

Want:

    2
    2.5

#### Mechanism

D15306's binding of a written literal is the store column's (`storeLetsResolve`), which queues
only `let` bindings; a field slot (`h.r = …`) or an element slot (`xs[0] = …`) has no producer
that builds the written literal at the slot's record. The fn-tag join over the written literal's
fields is gated to bindings the field widener widened: ungated, both slots were **check-clean
invalid wasm** (the set tagged, the literal still built at its own row).

#### Ablation

| --- | --- | --- |

| the write | runs | **yes** |
| field slot → element slot (`xs[0] = { f: id2 }` onto `[{ f: id1 }]`) | still refuses | no |

The matrix rows this row once listed did not move, and are not this row: each writes a value
`if` of records into a container annotated at a closed function type (`const w: __W = …`), which
is D15301's. A plain literal into such an annotated slot runs.
A nested element slot (`xs[0][0] = { f: id2 }`) refuses with `ref
valtype with no interned shape` before and after, which is not this row. Fixture:
`tests/cases/closures/record-literal-written-into-slot-of-fn-widened-binding-runs.vl`.
