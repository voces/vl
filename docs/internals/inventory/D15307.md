### D15307 — a record literal written whole into a field or element slot widened by its function field is built at its own row

**open · loud emit reject · `emitProgram: cannot take the generic function id1 as a value — a function value carries ONE signature` · clause 2 · one call type runs · found grading D15306 · filed 2026-11-04 against master `4eaf52bb`**

Repro:

    function id1(a) { return a }
    function id2(a) { return a }
    const h = { r: { f: id1 } }
    h.r = { f: id2 }
    print(h.r.f(2))
    print(h.r.f(2.5))

Want:

    2
    2.5

#### Mechanism

D15306's binding of a written literal is the store column's (`storeLetsResolve`), which queues
only `let` bindings; a field slot (`h.r = …`) or an element slot (`xs[0] = …`) has no producer
that builds the written literal at the slot's record. The fn-tag join over the written literal's
fields is gated to bindings the field widener widened: ungated, both slots were **check-clean
invalid wasm** (the set tagged, the literal still built at its own row).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the second call type (`h.r.f(2)` only) | runs | **yes** |
| `id2` (`h.r = { f: id1 }`) | runs | **yes** |
| the write | runs | **yes** |
| field slot → element slot (`xs[0] = { f: id2 }` onto `[{ f: id1 }]`) | still refuses | no |

Grading list: the `struct_field_assign`, `array_element_assign`, `array_push`, `map_set` and
`map_value` rows of `capability-matrix.vl -- if-arm-record-fn-field-two-members`, which refuse at
the same sentence.
