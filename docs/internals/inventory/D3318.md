### D3318 — a null test in the else arm of a path already held non-null read the storage type after the then arm retired it, while the emitter still narrowed

**closed 2026-09-29 (the else arm of a null test restates a path a live overlay already holds non-null as its own fact, `narPathHeldNonNull`) · loud emit reject in #3304 round 3, refused at check on master · clause 2 · the path-place sibling of D3302 · fixture `tests/cases/unions/flow-join-write-after-retire.vl`, hazard `else_restates_held_path`**

Repro:

    function f(): i32 {
      const a: (i32 | null)[] = [null]
      a[0] = 7
      if a[0] == null {
        a[0] = null
        a[0] = 7
      } else {
        if a[0] == null { return 5 }
      }
      return a[0] + 1
    }
    print(f())
    // round 3: emitProgram: bare null needs a struct-typed context
    // now: prints 8

Want:

    8

#### Mechanism

`a[0] == null` adds no else fact when `a[0]` is already `i32`, so the else arm read whatever the
overlay said when it began, and the then arm's write had retired that overlay in place. The
checker typed the inner test over `i32 | null`; the emitter's else push had narrowed `a[0]` to
`i32`; the compare had no null to lower. The else arm now restates a held path as its own fact,
which is what a live overlay already said.
