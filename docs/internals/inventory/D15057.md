#### Mechanism

`objShapeAdapterless` judges each member of a union source against the destination with
`direct` off, so `D` into `Pet`'s arm `A` is not a width lift there, while a value already
narrowed to `D` is. At the rep the two differ too: a `D | B` box carries `D`'s tag, which
`Pet` does not have, so the delivery has to re-tag the box at run time by its tag: `D`'s tag
becomes `A`'s, and `B`'s stays.
