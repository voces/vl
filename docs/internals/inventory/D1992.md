### D1992 — an if-expression arm ending in a builtin member call the checker types non-void (`s.slice(…)`, `xs.map(f)`, `xs.push(v)`, `m.has(k)`) was classified a statement, and refused as "a void call"

**closed 2026-09-22 — was loud emit reject, `vl check` rc 0, clause 2 · reported by plumb (PL-008, `~/plumb/docs/vl-issues.md`) · filed against master `af07f4ae0` · fix in `ifArmIsValue`, `blockTailIsValue` and `exprPopBitsGo` (`compiler/emit_classify.vl`), refusal re-anchored in `ifArmNoValueFail` (`compiler/wasmEmit.vl`); fixture `tests/cases/expressions/if-arm-member-call-value.vl`**

Repro:

    function f(s: string): i32 {
      const sp = s.indexOf(" ")
      const n = if sp < 0 { s.slice(1, s.length) } else { s.slice(1, sp) }
      n.length
    }
    print(f("#1 a"))
    // was: vl check rc 0; vl run: h.vl:1:10: emitProgram: if-expression arm ends in a void call, which yields no value
    // now prints 1

#### Mechanism

An if-expression arm lowers only when `ifArmIsValue` says its tail is a value, and that asked
only `stmtIsTailValue`. For a `Call` whose callee is a `Member`, `stmtIsTailValue` accepts a
closure-field call (D980) and nothing else, so every builtin method fell through to "statement".
The function-body tail never showed it: D1240 had taught `emitFuncBody`/`emitStmtTail` to consult
`memberCallYieldsValue` (the checker's type of the call) as a separate rung, and the arm path had
no such rung. The fix adds that rung to `ifArmIsValue` and to `blockTailIsValue` (the nested-`if`
and function-tail-`if` reading), leaving `stmtIsTailValue` alone: its lambda-return walk reads the
last statement of every block, and widening it made a non-tail `if c { xs.pop() }` inside a lambda
a return value (invalid wasm; `std:array`'s own `array-sort-inplace.vl` caught it). One layer
unmasked: `xs.push(v)` in an arm (the new length, D1592) needed its grow frame, and
`exprPopBitsGo` did not descend an if-expression — it now walks the arms. A genuinely void arm
still refuses, now anchored at the arm's callee instead of the function name.

#### Ablation

| ingredient changed | outcome before | needed? |
| --- | --- | --- |
| builtin method → user UFCS `v.twice()` / std UFCS `a.padLeft(…)` | runs | **yes** (builtin member) |
| builtin method → plain call `g(s)` | runs | **yes** |
| arm tail `s.slice(…)` → `s.slice(…).length` (a `Member`) | runs | **yes** (call at the tail) |
| if-expression → function-body tail, one arm a literal | runs | **yes** (value position) |
| binding → return / argument / assignment / struct field / nested if / `match` arm / `else if` / lambda binding | still refuses | no |
| annotated binding `const n: string = …` | still refuses | no |
| string method → list `map`/`slice`/`push`, map `has`, i32-returning `indexOf` | still refuses | no |
