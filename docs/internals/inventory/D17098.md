### D17098 — a tagged choice handed straight to a parameter of a closed function type whose result admits every member is refused at check

**loud check reject · clause 2 · found by the capture-shapes PR's Q58 position sweep (`useK(g)`) · beside [D17097](D17097.md) and [D16094](D16094.md) · owner S2 · filed 2026-11-24 against master `4435b3e3`**

Repro:

    function inc(a) { return a + 1 }
    function str(_a) { return "s" }
    function ap(g, x) { return g(x) }
    function useK(k: (a: i32) => i32 | string) { print(k(4)) }
    function run(c: boolean) {
      const g = if c { str } else { inc }
      print(ap(g, 3))
      useK(g)
    }
    run(true)
    // vl check: cannot choose 'inc' here: called at (i32) it returns i32, where 'str', also chosen here, returns string — every function a call through the choice may run must return one type

Want:

    s
    s

#### Mechanism

The parameter's declared result, `i32 | string`, admits both members' results. The same choice
bound to `const k: (a: i32) => i32 | string = g`, or handed through `id(g)`, checks clean. The
refusal names the closure mechanism (one result type per call through the choice), not a contract
the parameter states. Unablated.

#### Grading list

- `const k: K = g` checks and runs on master and must keep doing so.
- `useK(id(g))` checks clean and is D17097 at run time.
