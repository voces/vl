#### Mechanism

Not traced. Inside `take`'s instance at `() => i32` the argument `a` now names its pinned
function type ([D10132](D10132.md)), but D10133's binding and adapter run at the call's check,
where `a` is still a hole, so nothing binds `T` and no adapter boxes the result. The instance of
`len` is then asked for a call through `f` whose result has no type.
