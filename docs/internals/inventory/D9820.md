#### Mechanism

The monomorphizer's argument classifier (emit_mono.vl) bound `T` by matching the argument's
spelling against the parameter's annotation. A function-valued argument is spelled as its
signature key, which has no form to meet `((x: T) => T) | null`, so no instance type was found.
A binding already typed `((x: i32) => i32) | null` was accepted because its spelling matched.
The close walks the two arena types together (`monoBindArenaWalk`). It treats a nullable
function parameter as a function slot (`monoAnnIsFnSlot`) and peels the `| null` from its
result (`monoBindArrowRet`).
