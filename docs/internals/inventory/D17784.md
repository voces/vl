### D17784 — an expression-bodied lambda returning a record of a container of un-annotated lambdas has no record layout

**closed 2026-11-28 by COV-UNION · runs, its witness prints its expected value · was a loud emit reject, `emitProgram: ref valtype with no interned shape` (`object layout` for an in-place read) · a function body's tail record value is pinned as a `return`'s argument is (`monoPinReturnedObj` in `monoWalkFnBodyIn`), and D17770's call retype reads the returned literal through `collectRetValues` · pinned by `tests/cases/closures/hole-fn-container-expression-maker.vl` · filed against master `c0a118d8d`**

#### Mechanism

An expression body is a synthesized block whose tail is the function's value. The walk pinned a
`return`'s record literal (`monoPinReturnedObj`) but the tail arm (D6340) pinned only a returned
list, so the literal kept its open field type and had no layout; and D17770's retype found the
returned literal by `return` statements alone. Both now read the function's result values.
