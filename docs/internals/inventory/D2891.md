### D2891 — an inferred return set of a record list and a scalar list has no row as an anonymous object's field

**loud emit reject · clause 2 · found by the D2818 delivery grid (its field position) · filed 2026-09-27 against master `d39c809c1`**

Repro:

    type P = { x: i32 }
    function w(t: P, b: boolean) {
      if b { return [t] }
      [1, 2, 3]
    }
    const o = { f: w({ x: 4 }, true) }
    if o.f is P[] { print(o.f[0].x) } else { print("N") }
    // vl check: rc 0.  vl run: emitProgram: object literal matches no union variant

#### Mechanism

Not localised past the ablation. `w`'s inferred return is the union `P[] | i32[]`, which renders
`{x:i32}[]|i32[]` and has no registered row when the anonymous shapes are collected, so the
literal `{ f: … }` mints no struct row and falls to the union-box builder, which has no variant
for it either. At a generic's pin the row is registered by the monomorphizer, after the shapes
are collected, so the same holds there. It is what blocks D2818's dedupe: keeping a written
`T[] | i32[]` apart turns `{ f: wrap(p) }` at a record pin from a program that runs into this
refusal (four cells of the grid), and a field `for`-`in` over it into a cast trap.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the record element (`w("s", true)`, `string[] \| i32[]`) | runs | **yes** |
| the anonymous holder (`type H = { f: P[] \| i32[] }`, `const o: H`) | runs, prints `4` | **yes** |
| the field (`const a = w(…)`, or `[w(…)]`) | runs | **yes** |
| the inference (`: P[] \| i32[]` written on `w`) | runs | **yes** |
| a type parameter (`w<T>`) | still refuses | no |

#### Grading list

`function len<T>(t: T, b: boolean) { const v = w(t, b); print(v.length) }` called with an
anonymous record, `len({ x: 1 }, true)` with no `type P` declared, a loud emit reject where a
declared `P` runs; a record list's element read `const e = v[0]` over `P[] | i32[]`
("only i32 locals are supported"); and D2818's dedupe re-applied, graded on
`const o = { f: wrap({ x: 4 }) }` for `.length`, `for`, `is` and an element read.
