### D3392 — a closure capturing an un-annotated `??` of a nullable map cannot read the capture as a map

**loud emit reject · pre-existing · 4 cells of the D3370 position grid (the map value captured, every loop kind) · filed 2026-09-30 against master `4ff12b994`**

Repro:

    function mk(k: i32): Map<string, i32> {
      const m: Map<string, i32> = Map()
      m["a"] = k
      m
    }
    function h(n: i32) {
      let o: Map<string, i32> | null = null
      if n == 2 { o = mk(100) }
      const v = o ?? mk(102)
      const c = () => (v["a"] ?? 0)
      print(c())
    }
    h(0)
    h(2)
    // vl check: rc 0.  vl run: emitProgram: `??` over this nullable value is not supported yet

Want:

    102
    100

#### Mechanism

Not traced. The refusal is the closure's own `v["a"] ?? 0`: a captured map resolves its shape
from the parent frame's binding (`mapShapeOfExpr`'s capture arm), which reads an un-annotated
`LetDecl` through `letMapShapeOf` of its initializer, and a `??` over a nullable map there has
no answer. Annotating `v` runs.
