### D15556 — a returned `match` choosing between lists of records holding different functions is refused at emit

**open · loud emit reject · `emitProgram: ref valtype with no interned shape` · clause 2 · the same choice spelled as a value `if` runs since D15510's close · found closing [D15510](D15510.md) · filed 2026-11-08 against master `2a9d12a1`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function pick(n: i32) { return match n { 0 => [{ fs: [inc0] }], _ => [{ fs: [dbl] }] } }
    print(pick(1)[0].fs[0](3))
    print(pick(0)[0].fs[0](3))

Want:

    6
    4

#### Mechanism

A value `if`'s arms join through `joinArmTys`, which takes the deep function-set join (`elabFnJoinDeepTy`), so the function's result holds the tagged set and each arm's literal is built there. A `match`'s arms join elsewhere, without the deep join, so the result holds no tagged set at the arms' path (`elabRetTaggedJoinTy` answers -1) and each arm's literal keeps its own row.
