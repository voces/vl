#### Mechanism

`emitRefIfArm` seeds the ambient list build (`LBK_REF_AT_SLOT` at the join's row, or the
join's scalar list code) and the record seed before it lowers an arm's value, and nothing put
them back: a list build is never consumed, so it stayed set after the `if`. A delivery
position (`let`, an argument, a return) saves and restores the context around its value; a
`for` iterable does not, since it delivers nothing. The next list literal with no destination
of its own, a `for` over `["x", "y"]` later in the same function or in a function emitted
after it, then built at the leaked rep. The close scopes the seeds to the arm:
`emitIfArmOpen` records the context, and `emitIfArmClose` puts back the list build and any
record seed the arm set and left unconsumed (`armSeedRestore`), for every arm emitter.
