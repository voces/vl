### D16441 — a call's fresh record, or fresh record list spread, as a part of a list literal beside a held part at a wider record is refused

**loud emit reject · clause 2 · `emitProgram: this branch hands over a record whose field types differ from the record the branches join to` · found with [D16440](D16440.md) · filed 2026-11-15 against master `6adb40099` · open**

Repro:

    function mk() { return { x: 1 } }
    const a = { x: 2.5 }
    const l = [a, mk()]
    print(l[1].x)
    // vl check: rc 0.  vl run: emit error, this branch hands over a record whose field types differ

Want:

    1

#### Mechanism

Not yet located past the list stamp. A call's result is fresh, so it is copied where it lands
(D14817, D15652), but `recListCallCopy` runs only when a part built elsewhere sets the list's
build (`bt`). Here `a` is held at its own storage, so no build is set, no copy is recorded, and the
emitter meets the `{x: i32}` record at the `{x: f64}` join. The spread face,
`[a, ...mk()]` with `mk` returning `[{ x: 1 }]`, was check-clean invalid wasm and is refused at
check since D16440 (`recListSpreadsApartRefuse`), a refusal this row owes a copy for.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `mk(): { x: f64 }` annotated | prints `1` | **yes** |
| `mk` returning `{ x: 1.5 }` | prints `1.5` | **yes** (the storage apart) |
| `[{ x: 2.5 }, mk()]` or `[mk(), a]` | the same refusal | no |
| `[a, s[0]]` with `const s = [{ x: 1 }]` | the same refusal | no (a held read; the design may refuse it, at check) |
| `const m = mk(); [a, m]` | a check refusal, [D16442](D16442.md) | no |

#### Grading list

- `[a, ...mk()]` and `[...mk(), a]`, `mk` returning `[{ x: 1 }]`: refused at check since D16440.
- `[a, s[0]]`: the emit refusal should be a check refusal naming the shared record, if the design
  owes one.
