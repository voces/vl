### D3336 — a `match` joining type parameters pinned at `K` and `K | null` with a non-member string arm builds invalid wasm

**check-clean invalid wasm · clause 1 · open · the same on master `b6378e95b` · found by the lane JW grid (`k-kn__match__str__{field,arg}__{print,is}__tp`) · filed 2026-09-30**

Repro:

    type K = "a" | "b"
    function g<T0, T1>(a0: T0, a1: T1, k: i32) {
      const o = { v: match k {

#### Mechanism

Not localised past the ablation. The join is `K | K | "z"` with a null, a `string | null` at
the pin, whose atom arms must widen to their strings. The `if`-chain spelling of the same join
reaches the widening's loud refusal (`literal-union string widening with no members`, as the
direct spelling does); the `match` spelling does not reach it and builds the atom arm into a
string join.
