### D3336 — a `match` joining type parameters pinned at `K` and `K | null` with a non-member string arm builds invalid wasm

**closed 2026-10-11 — the filed repro prints `a`, `null`, `z` · was check-clean invalid wasm, clause 1, the same on master `faabd3e87` · found by the lane JW grid (`k-kn__match__str__{field,arg}__{print,is}__tp`) · filed 2026-09-30 · fixtures `tests/cases/literal-unions/nullable-atom-string-join-{generic,direct}.vl`, `null-arm-string-join.vl` · residue D4170–D4174**

Repro:

    type K = "a" | "b"
    function g<T0, T1>(a0: T0, a1: T1, k: i32) {
      const o = { v: match k {
        0 => a0
        1 => a1
        _ => "z"
      } }
      print(o.v)
    }
    const x0: K = "a"
    const x1: K | null = null
    g(x0, x1, 0)
    g(x0, x1, 1)
    g(x0, x1, 2)
    // vl check: rc 0.  vl run: invalid module inside `g` (expected i32, found (ref $type))

Want:

    a
    null
    z

#### Mechanism

Three seams, one fact: a join of a literal-union atom, a null and a string is `string | null`.
The `if`/`match` classifier knew a non-null `string` join as the string ref but not its nullable
twin, so the instance built the join as an `i32` atom (`ifExprRefKindOf`). The direct spelling
never got there: the checker joined `K | null` with `string` as `"a" | "b" | string | null`
(`joinVariantTys` absorbed the members only without the null), which the emitter boxed and
refused. Once that joined as `string | null`, two readers still took the join for the atom's
niche — `exprIsLitAtom` and `exprNulLitUnion`'s null-arm rung — and an inferred
`string | null` return did not widen an atom arm.

#### Ablation

| ingredient changed | outcome on master | needed? |
| --- | --- | --- |
| the `if` chain `if k == 0 { a0 } else if k == 1 { a1 } else { "z" }` | a loud emit reject (`literal-union string widening with no members`) | **yes** (the `match`) |
| `function g(a0: K, a1: K \| null, …)`, the direct spelling | the same loud emit reject | **yes** (the type parameters) |
| `x1: K` in place of `K \| null` | prints `a b z` | **yes** (the null) |
| `null` in place of the `"z"` arm | runs with lane JW (`a null null`); a loud emit reject on master | **yes** (a string arm) |
