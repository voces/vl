### D15337 — two widened bindings of one function set, one writing its initialiser's function back from an `if` arm, are refused at emit

**closed 2026-11-11, runs and prints `2`, `2.5`, `2.5` · was loud emit reject, clause 2, `emitProgram: cannot take the generic function id1 as a value — a function value carries ONE signature` · found grading D15335 · filed 2026-11-04 against master `2cf5c5fa` · closed with [D15643](D15643.md): a sub-set's holder that is an arm's tail of a join holding a wider set not yet decided now decides that set with it (`ftJoinWiderNeed`, check_fn_tag.vl), so `{id2}`'s plan no longer refuses `r`'s arm literal · `--names` build dispatches by `i32.eq` with no `call_indirect` · fixture `tests/cases/functions/widened-bindings-of-one-set-writing-back-from-an-arm.vl`**

Repro:

    function id1(a) { return a }
    function id2(a) { return a }
    function id3(a) { return a }
    const c = 1 > 0
    const n = 3
    let r = { f: id1 }
    r = if c { { f: id2 } } else { { f: id3 } }
    print(r.f(2))
    print(r.f(2.5))
    let e = { f: id1 }
    e = if n > 5 { { f: id2 } } else if n > 1 { { f: id3 } } else { { f: id1 } }
    print(e.f(2.5))

Want:

    2
    2.5
    2.5

#### Mechanism

Both bindings widen to one interned set `{id1, id2, id3}`. `e`'s arm writing `id1` back makes
fn-tag decide that set from sub-sets, and sub-set `{id2}`'s plan refuses `r`'s arm literal
`{ f: id2 }` in `ftHoldCtxOk`: the arm is delivered to the `if`, typed at the whole set, not
at the sub-set (probe: `scanfail` on that literal, its rep stamped at the binding's record).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `r` (only `e`) | runs | **yes** |
| `e`'s arm `{ f: id1 }` → `{ f: id2 }` | runs | **yes** |
| `e` called at two types | still refuses | no |
| `e`'s choice → plain writes `e = { f: id2 }; e = { f: id1 }` | runs | **yes** |
| `r`'s choice → `match` | still refuses | no |
