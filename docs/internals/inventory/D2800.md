### D2800 — a boolean pin beside an `i32` list builds one list and reads the `i32` arm as booleans

**check-clean silently wrong · clause 1 · found by the #3211 review · the same on master `2bbc5c412` · filed 2026-09-27 against master `2bbc5c412`**

Repro:

    function h<T>(c: boolean, t: T) {
      if c { return [t] }
      [1]
    }
    print(h<boolean>(false, false)[0])
    // PRINTS true

#### Mechanism

`boolean[]` and `i32[]` are stored as the one i32 list, so at `T := boolean` the instance builds
one list and the call is typed as the parameter's list, `boolean[]` (D2766, D2783). The `[1]`
arm's element is then printed as a boolean. The value carries no tag that could say which arm
built it, which is D2769's question for the concrete spelling. The mirror (`[1]` returned
when `c`, `[t]` otherwise) prints `true` on #3211 and printed `1` on master.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the type parameter (`t: boolean`, tested `is i32[]`) | prints `1` | **yes** |
| the shared storage (`T := string`) | the union, refused at `[0]` | **yes** |

#### Grading list

The mirror above; `h<boolean>(true, false)[0]` (prints `false`).
