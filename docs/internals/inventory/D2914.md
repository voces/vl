### D2914 — an adopted object-literal list read at its own `{ f: i32 }` type is invalid wasm

**now a loud emit reject · clause 2, still open · was check-clean invalid wasm, the same on master `a41bd80e8` · the use that hands the list or an element on at its own record is refused (`rsNarrowUseRefuse`) · fixtures `tests/cases/soundness/error-reseated-record-list-handed-on-at-own-type.vl`, `tests/cases/soundness/reseated-record-list-converting-uses-run.vl` · found by the #3235 review · filed 2026-09-27 against master `1f092d569`**

Repro:

    const i: { f: i32 } = { f: 4 }
    type I = { f: i64 | null }
    const il = [{ f: 7 }]
    const ic: I[] = il
    const z = il.map((e) => e.f)
    print(z[0])
    // vl check: rc 0.  vl run: invalid module in the top-level code

Want:

    7

#### Mechanism

D2881 builds `il` at `I`'s row, which its declared destination names, but the checker still
types `il` and its elements `{ f: i32 }`. A field read, `.length`, a `for` over it and a
delivery into `I`'s own row read the storage where it is; every other use hands an `I` record
to a place built for `{ f: i32 }`: a call argument or annotated binding of the list or an
element (`show(il[0])`, `takeN(il)`, `first(il)`), a method call (`il.map`, `il.filter`), a
spread, a list literal around it, a return, an `if` arm, an assignment into a `{ f: i32 }`
binding. A record is shared, not converted (DECISIONS.md "Record depth covariance"), so no copy
can serve those uses without losing a write through the other handle; making them run needs
either a per-value rep that follows the storage into every such use, or a ruling that a
re-seated list's own binding takes the destination's type. Until then the emitter walks the
list's scope, following un-annotated aliases and `for` variables, and refuses the first such
use loudly. The walk does not follow an inferred return into its callers ([D2922](D2922.md)),
has no scope for a top-level block's binding ([D2923](D2923.md)), and leaves an un-annotated
object literal's list field alone ([D2924](D2924.md)).
