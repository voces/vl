#### Mechanism

`memo-generation-probe.py` derived its population with six regular expressions (a declaration
shape and five guard shapes). `std:str` states "no regex and no pattern arguments", so
`scripts/memo-generation-probe.vl` spells each as a function of `idEnd`, `skipWs` and
`hasAt`: about 130 lines against 20. The port is correct (its `--list` was byte-identical to
the Python on the tree and on two red trees), but each shape took a hand derivation of
what `\s*`, a lazy `.*?` and a `\b` accept, and the next shape added to the census pays that
again. The same hand-rolling is in `lint-filter.vl`, `check-filed-witnesses.vl` and
`scripts/lib/common.vl`.
