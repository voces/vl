#### Mechanism

The refusal is the monomorphizer's parameter pin (`monoArgTyFail`, the closed-pin check beside
`openArg`). The loop element `k` has no pin name of its own, though its pin type in the instance
is the closed `Tree<string>`. The pin now accepts an argument whose pin type closes (no type
variable, no inference hole) and binds from it; a parameter that still does not close is refused
at the next check, as before.
