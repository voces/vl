#### Mechanism

A literal whose elements are `null` and a function is boxed per element, and the box asks the
element's name of its render. A depth-12 `--names` profile puts 78% of the samples under
`emitStartGlobalInitValue` → `emitArr` → `arrLitIsStr` and `arrLitNumKind` → `arrLitBoxElem` →
`arrLitNulBoxElem` → `nulRefElemNameOfArrTy` (emit_shape_rows.vl), which spells the element
with `nulRefElemEmitName`, `7·2^depth` characters, and classifies the spelling with
`nameIsRefArray`, `refArrShapeKind` and `refArrElemName`. The list's annotation, a parameter
of it and a literal of one function alone are polynomial since D9770's close.
