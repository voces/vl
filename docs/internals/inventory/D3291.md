### D3291 — a join over a literal-union pin, returned from a generic or passed to a generic, reaches its reader as the raw atom id

**check-clean silently wrong · clause 1 · open · the same on `313a071b4`, `f5ecc7995` and with the D3281 close · found by the D3281 lane's grid · filed 2026-09-29**

Repro:

    type K = "a" | "b"
    function g<T>(a: T, b: T, c: boolean) {
      if c { a ?? "b" } else { b }
    }
    const u: K = "a"
    const w: K = "b"
    print(g(u, w, true))
    print(g(u, w, false))
    // vl check: rc 0.  vl run: prints the atom ids `0` and `1`

Want:

    a
    b

#### Mechanism

Not localised past the ablation. At `T := K` the instance lowers the join as the `K` atom and
returns its `i32` id, while the call is typed `string` (`const q: boolean = g(u, w, true)` reports
`cannot assign string`): the `??` result resolves at the pin to the join of `K` with the default's
`string`. Nothing widens the atom at the return, and the caller prints the `i32` it receives.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `function g(a, b, c: boolean)`, the hole spelling | prints `0 1` | no |
| `{ a }` in place of `{ a ?? "b" }` | prints `a b` | **yes** (the coalesce) |
| `a ?? "b"` as the whole body (no join) | prints `a a` | **yes** (the join) |
| `type K = string` | prints `a b` | **yes** (the literal union) |
| `a ?? 5` (a number default) | prints `a b` | **yes** (a string default) |
| `a ?? "z"` (a non-member default) | prints `0 1` | no |
| the first result bound before it prints | prints `0 1` | no |

#### Grading list

The row is wider than its witness. At the hole spelling the `??` is not needed:
`function g(a, b, c: boolean) { show(if c { a } else { b }) }` with `show<U>(x: U) { print(x) }`
prints `0 1` at `K` (the #3303 review's `h/w1.vl`), where the generic spelling prints `a b`.
Nested `if`, `match` and `K | null` joins do the same, and at a nullable pin a `null` prints
`-1`. The D3281 lane's grid has 32 such cells (`join_{tp,hole}_{K,AB}_{mem,non}_ret` and the `pass`
delivery), and the #3303 review's generator 25 more (`g0022`, `g0053`, `g0080`, `g0091`, `g0111`,
`g0162`, `g0169`, `g0268`, `g0283`, `g0299`, `g0363`, `g0421`, `g0433`, `g0479`, `g0495`, `g0516`,
`g0535`, `g0544`, `g0565`, `g0575`, `g0577`, `g0579`, `g0587`, `g0590`, `g0591`). They share a
reader that takes the atom where a string was typed; whether they are one mechanism is not yet
ablated.
