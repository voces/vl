### D3291 — a generic returning `if c { a ?? "b" } else { b }` at a literal-union pin hands back the atom id where its call is typed `string`

**check-clean silently wrong · clause 1 · open · the same on `313a071b4`, `f5ecc7995` and with the D3281 close · found by the D3281 lane's grid · filed 2026-09-29**

Repro:

    type K = "a" | "b"
    function g<T>(a: T, b: T, c: boolean) {
      if c { a ?? "b" } else { b }
    }
    const u: K = "a"
    const w: K = "b"
    print(g(u, w, true))
    print(g(u, w, false))
    // vl check: rc 0.  vl run: prints the atom ids `0` and `1`

Want:

    a
    b

#### Mechanism

Not localised past the ablation. At `T := K` the instance lowers the join as the `K` atom and
returns its `i32` id, while the call is typed `string` (`const q: boolean = g(u, w, true)` reports
`cannot assign string`): the `??` result resolves at the pin to the join of `K` with the default's
`string`. Nothing widens the atom at the return, and the caller prints the `i32` it receives.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `function g(a, b, c: boolean)`, the hole spelling | prints `0 1` | no |
| `{ a }` in place of `{ a ?? "b" }` | prints `a b` | **yes** (the coalesce) |
| `a ?? "b"` as the whole body (no join) | prints `a a` | **yes** (the join) |
| `type K = string` | prints `a b` | **yes** (the literal union) |
| `a ?? 5` (a number default) | prints `a b` | **yes** (a string default) |
| `a ?? "z"` (a non-member default) | prints `0 1` | no |
| the first result bound before it prints | prints `0 1` | no |
