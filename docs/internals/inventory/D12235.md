### D12235 — a lambda capturing the parameter of a hole lambda, inside a function instanced at two types, refuses with "captured variable not found"

**loud emit reject · `vl check` rc 0 · `emitProgram: captured variable not found in enclosing frame` · clause 2 · CAPABILITY: one instance runs, and so do both instances when the inner lambda captures nothing · wasmEmit.vl `emitCaptureRead` · found surveying emit refusals for L3 family (d) · filed 2026-10-24 against master `84b98d149`**

Repro:

    function two(a: i32, b: (n: i32) => i32) { b(a) }
    function twof(a: f64, b: (n: f64) => f64) { b(a) }
    function outer(h, x) {
      return h(x, (n) => {
        const g = (m) => m + n
        return g(n)
      })
    }
    print(outer(two, 3))
    print(outer(twof, 1.5))

#### Mechanism

`outer` is instanced once with `two` and once with `twof`, and the lambda handed to `h` is
lifted once per instance. The inner lambda `g` captures `n`, the outer lambda's parameter; in
the second instance the env build for `g` looks `n` up in a frame where it is neither a local,
a global nor a capture of the enclosing closure, so `emitCaptureRead` falls through to its
refusal. Which frame index the lookup uses was not measured.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the second instance (`outer(twof, 1.5)` only) | runs, prints `3` | **yes** |
| the capture (`(m) => m + 1`) | runs, prints `4 2.5` | **yes** |
| the inner lambda's parameter (`const g = () => n; g()`) | runs, prints `3 1.5` | **yes** |
| the inner lambda (`(n) => n + 1`) | runs, prints `4 2.5` | **yes** |

#### Grading list

The capture of a second outer parameter; the inner lambda called twice.
