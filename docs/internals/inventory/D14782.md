### D14782 — a returned `let` list of lists of un-annotated functions, written whole before the return and handed to an un-annotated parameter, has no interned shape for its rep

**loud emit reject · `vl check` rc 0 · `nested arrays are not supported` · clause 2 · the nested twin of [D9764](D9764.md), whose flat spelling runs · filed 2026-11-01 against master `71f598d24` · bucket (a), slot store, secondary (e) (the 2026-11-14 clause-2 map)**

Repro:

    function inc(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function deliverNested(_n) {
      let u = [[inc, dbl]]
      u = [[dbl, inc]]
      return u
    }
    function take2(a) { print(a[0][1](3)) }
    take2(deliverNested(1))

Want:

    4

#### Mechanism

Not traced. Before [D9764](D9764.md)'s close the pin of `take2`'s parameter was refused
(`unsupported argument type for 'a' in a call to 'take2'`). With the parameter pinned at the
elaboration's closed nested function-list type, the instance is built and the emitter then finds
no interned shape for the nested list's element rep. Since `deliverNested`'s recorded result
closes to `((i32) => i32)[][]` (2026-11-08), the emitter refuses earlier, at the nested list.
