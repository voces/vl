### D4667 — `??` over a nullable field of a record that is an anonymous union arm has no receiver rep to read the field through

**closed 2026-10-14 — the witness prints `5` · `emitCoalesceGo`'s field arm reads the receiver through `emitCoalArmRecv` for four receiver kinds (a struct, a bare arm, a narrowed union box, a nullable arm) instead of the struct kind alone · fixtures `tests/cases/unions/coalesce-arm-nullable-field.vl` and its `-unannotated` twin · template `arm-nullable-field-literal-map-read.matrix.vl` runs 29 → 48 of 48, 0 runs → not-runs, 0 silent · was loud emit reject · clause 2 · found closing D4636 · filed 2026-10-14 against master `1c1740512`**

Repro:

    type U = { q: i32 | null } | { r: i32 }
    const v: { q: i32 | null } = { q: 4 }
    print((v.q ?? 0) + 1)
    // vl check: rc 0.  vl run: emitProgram: `??` over this nullable value is not supported yet

#### Mechanism

The annotation `{ q: i32 | null }` names an anonymous arm of `U`, so `v` is a bare-arm
(`variant`) cell, not a plain struct. The `??` lowering's field arm accepted only a struct
receiver and fell through to the refusal for every other receiver rep the arm can take.
