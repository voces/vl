### D3058 — a closure returning a record list as `readonly Shape[]` is invalid wasm inside the lambda

**check-clean invalid wasm · clause 1 · found by the #3266 review · the same on master `b09566e16` · filed 2026-09-28 against master `b09566e16`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    function mkf(x: Circle[]): () => readonly Shape[] { return () => x }
    const f = mkf([{ r: 1 }])
    print(f().length)
    // vl check: rc 0.  vl run: invalid module, inside `__lambda_0`: type mismatch:
    // expected (ref $type), found (ref $type)

Want:

    1

#### Mechanism

Not investigated past the ablation. The lambda's return is the covariant delivery of a captured
`Circle[]` into `readonly Shape[]`. The same delivery from a plain function's `return` is built
(as a copy or, since [D3041](D3041.md), a view), so the lambda's return seam appears never to
reach `emitRefListWidenSite`, and the raw `Circle[]` wrapper is returned where the union-box
list wrapper is declared.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| a plain function `function mk(x: Circle[]): readonly Shape[] { return x }` | runs, prints `1` | **yes** (the lambda) |
| the lambda returns `readonly Circle[]` | runs, prints `1` | **yes** (the widening) |

#### Grading list

The same lambda returning each element pair D3028 and D3041 view (`i32[]` as `readonly i64[]`,
`(string | i32)[]` as `readonly (string | i64)[]`), and a lambda bound to a typed `const`.
