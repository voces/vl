#### Mechanism

It is D8122's program with the literal union spelled inline. The print declines, as in D8122,
and with inline members the fall-through reads the box as the `string | null` niche, which
fails validation. D8122's close covers it while one call pins the hole. When two calls pin it
apart, the instance's binding is softened to `string | null` and the program is still invalid
wasm: [D8181](D8181.md).
