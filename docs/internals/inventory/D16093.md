Repro:

    function inc(a) { return a + 1 }
    function str(_a) { return "s" }
    function app<T, R>(g: (x: T) => R, v: T): R { return g(v) }

      const fs = [inc]
      if c { fs[0] = str }

    run(true)
    // vl run: prints `s`

Want:

    s

#### Mechanism

Handed to an un-annotated `ap(g, x)` the element dispatches and `ap`'s result is the members' join
(D16091). A generic parameter `g: (x: T) => R` binds `R` from one signature, and the emitter
refuses to take an un-annotated member as a value of the instanced function type.
