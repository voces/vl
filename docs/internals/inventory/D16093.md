### D16093 — a list element of un-annotated functions whose results differ, handed to a generic `(x: T) => R` parameter, is refused at emit

**loud emit reject · clause 2 · ``emitProgram: cannot take the generic function `inc` as a value — a function value carries ONE signature`` · found closing [D16091](D16091.md) · filed 2026-11-14 against master `2e9641972`**

Repro:

    function inc(a) { return a + 1 }
    function str(_a) { return "s" }
    function app<T, R>(g: (x: T) => R, v: T): R { return g(v) }
    function run(c: boolean) {
      const fs = [inc]
      if c { fs[0] = str }
      print(app(fs[0], 3))
    }
    run(true)
    // vl run: the emit refusal above

Want:

    s

#### Mechanism

Handed to an un-annotated `ap(g, x)` the element dispatches and `ap`'s result is the members' join
(D16091). A generic parameter `g: (x: T) => R` binds `R` from one signature, and the emitter
refuses to take an un-annotated member as a value of the instanced function type.

#### Ablation

| change | outcome |

| witness | emit reject |
| `ap(g, x)` un-annotated | runs, prints `s` |
| members agree (`inc`, `dbl`) | not graded |
