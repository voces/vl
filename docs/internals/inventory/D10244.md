### D10244 — a narrower-result function value through a hole parameter into a concrete `() => i32 | string` parameter is refused

**loud check reject · `argument 1: expected () => i32 | string, got () => i32` · clause 2 · CAPABILITY: the same value passed to `len` directly runs · present on master `57b3adb1e` · found closing [D10210](D10210.md) · filed 2026-10-22 against master `57b3adb1e`**

Repro:

    function len(f: () => i32 | string) {
      const t = f()
      if t is string { 0 } else { 1 }
    }
    function take(a) { print(len(a)) }
    take((): i32 => 3)
    // vl check: argument 1: expected () => i32 | string, got () => i32

Want:

    1

#### Mechanism

Not traced. A direct call adapts a narrower-result function value into the union result
([D10133](D10133.md)); through the hole parameter the demand is re-asked at the pin, where
the value's type `() => i32` is compared with the declared parameter and refused rather than
adapted. The generic twin, `len<T>(f: () => T | string)`, runs since [D10210](D10210.md).

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `len(() => 3)` called directly | runs, `1` | **yes** |
| `len` generic, `() => T \| string` | runs, `1` | **yes** |

#### Grading list

The un-annotated lambda `take(() => 3)`, and a `string`-result lambda through the hole.
