### D3310 — a union-member record read from a non-null field and passed to a hole parameter builds invalid wasm

**closed 2026-10-03 by D3593 — the witness prints `7` · was check-clean invalid wasm, clause 1 · pre-existing, the same on master `e70102886` and with D3301's fix · found by the #3306 review grid (`uni*_noop_*_multi`, `m11`) · filed 2026-09-29 against master `e70102886`**

Repro:

    type O = { n: i32 }
    type P = { m: i32, k: i32 }
    type U = O | P
    type W = { w: O }
    function u(q) {
      return 7
    }
    const ww: W = { w: { n: 4 } }
    print(u(ww.w))
    // vl check: rc 0.  vl run: invalid module

Want:

    7

#### Mechanism

`O` is a member of a declared union, so it has a variant row and no struct row (`collectS`
skips a record that is a union member). A code-15 field read is stored `(ref null …)`, and the
instance's parameter is the non-null `variant`, whose argument-boundary recover asked only the
`nulvariant` predicate. Closed by the emitter half of D3593's change, under which a `struct` or
`variant` destination owes the recover for either record niche (`exprNullableRecord`); the
emitter half alone runs it. D3311 is the same argument reaching an `is` test in the callee and
stays open.
