#### Mechanism

`cwWrites` walks `P.nodes` for every list write in the module and asks `cwHas(set, rn)` of the
receiver's ROOT NAME, where `set` is the alias closure built the same way. Neither side resolves
a name to a binding, so `decoy`'s `b` and `f`'s `b` are one name to the analysis. D793's refusal
then fires on `f`'s assignment, which no handle in the program writes through. The message says
"somewhere in this program", which is honest about the analysis and not about the program: the
sentence describes the ARM that fired, and grading it one scope per row is what separates the
design rule (a covariant list assignment that IS written through is refused) from the mechanism
(a name matched without a scope).
