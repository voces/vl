### D2603 — an assignment's null test over a nullable arm of a declared struct union has no struct context for `null`

**closed 2026-09-26 — the witness prints `5` then `false` · was a loud emit reject after `vl
check` rc 0, clause 2 · filed 2026-09-26 against #3178 at `fb5a20f60`, found by its re-review
(`rv3178-att2/n8.vl`) · fixture `tests/cases/soundness/assignment-test-narrows-union-arm.vl`**

Repro:

    type A = { r: i32 }
    type B = { s: string }
    function mkA(n: i32): A | null {
      if n == 0 { return null }
      { r: n }
    }

      if n == 0 { return null }

#### Mechanism

Once `A` is an arm of a declared union, `A | null` is the `nulvariant` niche rather than a
nullable struct, and D2602 taught only `exprNullableStruct` to read an assignment as its target
cell. `exprNullableVariant` now reads it the same way, so the null test finds the niche and the
`null` literal its heap.

#### Ablation

| ingredient changed | outcome at `fb5a20f60` | needed? |
| --- | --- | --- |
| no `A \| B \| null` union in the program | runs | **yes** |
| `x = mkA(5); if x != null` | runs | **yes** (the assignment test) |
| `(x = mkA(5)) == null` with the read in the else arm, or after an early return | still refused | no |
