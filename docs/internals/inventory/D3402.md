### D3402 — a `T[]` pinned at `i32[]` handed to an `f64[]` parameter passes the check, which the direct spelling refuses as an implicit container widening

**check-clean invalid wasm · clause 1 · open · found by the #3317 review (`rv3317-7c184e7a`, P1) · the same on master `8df60e472` · filed 2026-09-30 against master `8df60e472`**

Repro:

    function h(a: f64[]) {
      a[0] = 1.5
      return a.length
    }
    function g<T>(xs: T[]) { return h(xs) }
    const xs: i32[] = [1]
    print(g(xs))
    print(xs[0])
    // vl check: rc 0.  vl run: invalid module inside `g`

#### Mechanism

The direct spelling `h(xs)` with `xs: i32[]` is refused by the container rule (`i32[] is not
f64[]: a container never widens implicitly`), which `assignableExpr` raises through
`objShapeAdapterlessAt` only outside `inferQuiet`. D3253's composite-argument demand
(`ACF_COMP`) re-asks the argument's node at the pin under `inferQuiet`, so it gets
`assignableExpr`'s `true` and never asks the container rule. The demand needs the rule's
predicate (`objShapeAdapterlessAt`/`listWidenWalk`) and the direct message at the pin.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `function g(xs: i32[])`, the direct spelling | loud check reject | **yes** (the type parameter) |
| `h` only reads (`a[0] / 4.0`) | runs, prints `0.25`, a delivery the direct spelling refuses | no, a second face |
| `g([3 > 2])`, a `boolean` pin | loud check reject at the pin (D3253; invalid wasm on master) | **yes** (an `i32` pin, whose element converts) |

#### Grading list

The read-only face, and the `[...xs]` and `[x]` arguments at an `i32` pin, which build at the
destination and must keep running.
