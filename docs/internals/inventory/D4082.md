### D4082 — `r is B` over a record `A` is refused at emit when `B` narrows a field other than to a literal set

**closed · runs, prints `4` · was a loud emit reject, clause 2 · residue of the D4058 close · filed 2026-10-11 against master `5a9535c91` · fixed 2026-11-15: a record test whose tested type keeps the record's fields and narrows some is minted as a test of each narrowed field at that field's own type (`recFieldFitBuild`, check_annot_resolve.vl), so a contained record field recurses through its own check; a union operand's partial arm, `match` and `as?`/`as!` take the same check. A field narrowed to a literal set over two bases is left to the emitter, refused as before: [D16326](D16326.md), [D16327](D16327.md); a generic operand is [D16325](D16325.md). Matrices `record-is-narrows-union-field`, `record-cast-narrows-union-field`, `record-match-narrows-union-field`. Fixture: `tests/cases/narrowing/record-is-narrows-non-literal-field-runs.vl`. Probe: `record-is-test-narrows-non-literal-field.vl`**

Repro:

    type A = { x: i32 | null }
    type B = { x: i32 }
    function g(b: A): i32 {
      if b is B { return b.x }
      return 0
    }
    print(g({ x: 4 }))
    // vl check: rc 0.  vl run: rc 1, "`is` over a record tests a field that is not a literal set narrowed from the declared field, which has no lowering yet"

Want:

    4

#### Mechanism

`emitRecordFitIs` tests a narrowed field by comparing it with each member of a literal set.
A field narrowed from `i32 | null` to `i32`, or from one record to a contained one, has no
literal set, so the rung refuses rather than fold. Before the D4058 close the test folded to
a constant, `0` here, check-clean and silently wrong. A close needs a value-fit test per field
type: a null test for a nullable field, and the same rung applied recursively for a record
field.

#### Ablation

| variant | outcome |
| --- | --- |
| `A = { x: i32 \| null }`, `B = { x: i32 }` | emit refusal |
| `A = { v: I }`, `B = { v: J }`, `J` contained in `I` | emit refusal |
| `B = { x: 1 \| 2 }` over `A = { x: i32 }` | runs |
| `A = { x: i32 \| null }`, `B = { x: 1 \| 2 \| null }` (a literal set with `null`) | emit refusal; printed `false` for every value before |
