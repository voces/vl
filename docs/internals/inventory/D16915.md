### D16915 — a record re-pointed between lists of lists of different un-annotated functions, with no call through them, has no interned shape at emit

**loud emit reject · clause 2 · the residue of [D16834](D16834.md), whose called spelling runs · found by lane AE closing D16834 · filed 2026-11-16 against master `6cd505a50`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    let r = { f: [[inc0]] }
    r = { f: [[dbl]] }
    print(r.f.length)
    // vl check: rc 0.  vl run: emit error, "emitProgram: ref valtype with no interned shape"

Want:

    1

#### Mechanism

No call goes through the joined set, so the tag decision never tries it and the set stays a list
of closures. One list level stores an untagged closure list with no element key; at two levels the
outer list needs a key for its element, a list of an open function type, which has no nominal
render (`anonRefListElemKeyOfTy`), so the binding gets no struct row.

| `print(2)`, `r` unread | the same refusal | no |
