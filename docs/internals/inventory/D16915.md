**closed 2026-11-17 by lane AE — the witness prints `1` · mono pins a record field left open at a list of functions to the signature its elements are instanced at (`monoPinFieldContainer`), and stopped at a list of lists: `monoPinFieldListOfLists` (`compiler/emit_mono.vl`) pins the inner lists from every element they hold, so the record's field is closed and its row minted, called or not, re-pointed or not · fixture `tests/cases/closures/record-list-of-lists-of-hole-fns-uncalled.vl` · the three-deep, bare-list and field-write spellings are [D16921](D16921.md) · was: loud emit reject · clause 2 · the residue of [D16834](D16834.md) · found by lane AE closing D16834 · filed 2026-11-16 against master `6cd505a50`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    let r = { f: [[inc0]] }
    r = { f: [[dbl]] }
    print(r.f.length)
    // vl check: rc 0.  vl run: emit error, "emitProgram: ref valtype with no interned shape"

Want:

#### Mechanism

No call goes through the set, so it stays an untagged closure list and the field keeps an open
function type. Mono closes such a field at one list level (`monoPinFieldContainer`, D9061) but
returned -1 for a list of lists, so the field stayed open, had no element key with no nominal
render, and the binding got no struct row. A re-point is not needed: `{f: [[inc0]]}` alone, read
only by `.length`, was refused too.
