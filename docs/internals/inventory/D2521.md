### D2521 — a closure capturing a loop variable that binds a `T | null` box has no union name for it, so `??` refuses and a narrowed read is invalid wasm

**closed 2026-09-25 — the filed repro RUNS and prints `4` / `-1` · was check-clean invalid wasm, clause 1, and its `??` spelling a loud emit reject · pre-existing on master `ca544493e` · found by [D2511](D2511.md)'s grading list · filed 2026-09-25 against master `ca544493e`**

Repro:

    const xs: (i32 | null)[] = [3, null]
    for v in xs {
      const g = () => {
        if v != null { return v + 1 }
        return -1
      }
      print(g())
    }
    // vl check: rc 0.  vl run: invalid module inside `g`, expected i32, found (ref $type)

#### Mechanism

Inside the closure the captured name's member set comes from `capturedUnionName`, which answered
only a parameter or a `let` of the parent frame. A loop variable has neither, so the closure saw
no union: the narrowed read `v + 1` pushed the box where an `i32` belongs, and `v ?? -1` found no
`??` lowering. The loop-variable arm now asks the iterable, through the same two rungs
`forInLoopVarUnionName` uses for the uncaptured read (`forInIterUnionElemName`, and
`forInPairUnionElemName` for a pair walk's value).
