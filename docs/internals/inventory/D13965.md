Repro:

    function inc(a) { return a + 1 }
    function str(a) { return "s" }
    function sel(c: boolean) {
      if c { return inc }
      return str
    }
    print(sel(false)(3))
    // was: vl check rc 0, then wasm trap, indirect call type mismatch

#### Mechanism

`joinRetTys` joins the two returns at `inc`'s own row, so `sel`'s result carries the singleton
`Fn#inc` set. A call through it is typed and emitted as a call of `inc`, which returns `i32`,
while the value it reaches at run time may be `str`. The `if` spelling of the same choice
(`const g = if c { inc } else { str }`, then `g(3)`) is refused by `holeChoiceJudge`: `cannot
choose 'str' here: called at (i32) it returns string`. Slice 4 gives this spelling the
same refusal. That closes the trap, but it is not the end state. The refusal is a capability gap,
not a design rule, and it ends when a call through a join dispatches on the member it holds.
