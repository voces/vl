### D15717 — a maker joining a record holding a nested record with one holding `null` reads that field as no struct

**loud emit reject · check-clean, clause 2 · `emitProgram: field access receiver is not a struct` · found closing D15265 (its nested leg) · present on #7200's tree · filed 2026-11-11 against master `161d481c` plus #7200**

Repro:

    type J = { a: i32 }
    const go = [1].length > 0
    const v = if go { { j: { a: 1 } } } else { { j: null } }
    print(v.j?.a ?? 5)

Want:

    1

#### Mechanism

Not ablated. The join of a record literal holding `{ a: 1 }` with one holding `null` is the union
`{j: {a: i32}} | {j: null}`. The read `v.j?.a` is shared over its members, and no shared-field plan
reads a field one member stores as a record and another as `null`.
