### D15717 — a maker joining a record holding a nested record with one holding `null` reads that field as no struct

**loud emit reject · check-clean, clause 2 · `emitProgram: field access receiver is not a struct` · found closing D15265 (its nested leg) · present on #7200's tree · filed 2026-11-11 against master `161d481c` plus #7200**

Repro:

    type J = { a: i32 }
    type K = { j: J | null }
    function mk(b: boolean) { if b { { j: { a: 1 } } } else { { j: null } } }
    const _k: K = mk(false)
    const y = mk(true)
    print(y.j?.a ?? 0)

Want:

    1

#### Mechanism

Not ablated. `mk` joins a record literal holding `{ a: 1 }` with one holding `null`, so its result
is `{ j: { a: i32 } | null }`. The read `y.j?.a` reaches emit with a receiver no struct row
answers. The delivery at `K` is not needed: without it the read fails the same way.
