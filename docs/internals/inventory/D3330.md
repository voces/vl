### D3330 — a recursive hole callee over a self-referential record was pinned at the non-null record, so its null base case never ran and the recursion trapped

**closed 2026-09-30 — the witness prints `1` · was loads then traps · clause 1 · fixed by #3306, found before it while filing D3328/D3329 · filed 2026-09-30 against master `b6378e95b`**

Repro:

    type O = { n: i32, next: O | null }
    function depth(q) {
      if q == null { return 0 }
      return 1 + depth(q.next)
    }
    const o: O = { n: 1, next: { n: 2, next: null } }
    print(depth(o.next))
    // was: wasm trap, null reference (in `depth` at `depth(q.next)`)

Want:

    1

#### Mechanism

Not traced here; #3306 closed it. Before it, `o.next` is `O | null` and the call sat at a
non-null value, so the instance appeared to be pinned at `O`, where `q == null` is unreachable
and `depth(q.next)` handed a possibly-null field to a non-null parameter; the trap fired at the
last node. (An earlier draft of this row wanted `2`; `o.next` is the one-node list, so `1` is
right, and `depth(o)` is `2`.)
