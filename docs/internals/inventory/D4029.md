### D4029 — the dead-null-test warning names a module-merged binding by its mangled name

**open · runs today and must keep running · a wording defect: the warning prints `y$m0` where the source says `y` · found by the #3526 cb-audit (`arrays/filled-nullable-closure-shape-element-beside-union.vl`) · filed 2026-10-11 against master `1df3c8f91`**

Repro:

    import { filled } from "std:array"
    type Item = { n: i32 }
    const a: (Item | null)[] = [null]
    a[0] = { n: 1 }

    print(filled(1, 0).length)
    // vl check: rc 0, one warning: `y$m0 != null` is always true here (y$m0 is Item)

Want:

    1
    1

#### Mechanism

`recordDeadNullTest` (`compiler/typecheck.vl`) builds the warning from `placeKeyOf(subjIx)`, the
checker's place key, which carries the module merge's `$m<N>` suffix on every top-level name of a
program that imports anything. The message is never passed through `demangleMsg`, which every
other free-form diagnostic uses for exactly this.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `import` (any std import) | warning names `y` | **yes** |
| `y` at top level (moved into a function) | warning names `y` | **yes** |
| the store `a[0] = …` that narrows the read | no warning | **yes** (it is what makes the test dead) |
