### D2642 — a list of nullable records whose record type comes only from an object literal has no struct row for its element

**loud emit reject · clause 2 · pre-existing on master `979323f83` · found by the
`container-null-fill-list-record` matrix and the #3188 review's `c07`/`d03` witnesses · filed
2026-09-26 against master `979323f83`**

Repro:

    function main() {
      const xs = [null, { v: 3 }]
      const e = xs[1]
      if e != null { print(e.v) }
    }
    main()
    // vl check: rc 0.  vl build: emitProgram: field access receiver is not a struct

#### Mechanism

Not traced. The element is `{v: i32} | null`, and the only thing that spells the record is
an object literal: no annotation and no declared struct names it. The same list annotated
`({ v: i32 } | null)[]` runs, and so does the non-null `{ v: i32 }[]`, so the missing step is
the struct row, or its lookup, for a nullable element whose shape came from a literal. The
failure moves with the program. A read into a local refuses `field access receiver is not a
struct`. An instance of a hole parameter over the list refuses `a nullable-{v:i32} list element
has no rep`. D2506's push spelling (`xs.push(null)`, `xs.push({ v: 3 })`) reaches this row on
the PR, where master refused it at check.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `xs` annotated `({ v: i32 } \| null)[]` | prints `3` | **yes** — no annotation spells the record |
| the `null` element removed (`[{ v: 3 }]`) | prints `3` | **yes** — the nullable element |
| `type A = { v: i32 }` declared, `const a: A = { v: 3 }`, `[null, a]` | prints `3` | **yes** — no declared struct |
