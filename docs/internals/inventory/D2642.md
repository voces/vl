### D2642 — a list of nullable records whose element is spelled by a shape a declared struct matches has no rep at a hole parameter's instance

**loud emit reject · clause 2 · pre-existing on master `a2d2ca88f` · found by the
`container-null-fill-list-record` matrix's un-annotated `argument` cell · filed 2026-09-26
against master `a2d2ca88f`**

Repro:

    type C = { a: i32 }
    function take(a) {
      const e = a[1]
      if e != null { print(e.a) } else { print("miss") }
    }
    const y: C | null = null
    const o = []
    o.push(y)
    o.push({ a: 7 })
    take(o)
    // vl check: rc 0.  vl build: emitProgram: a nullable-{a:i32} list element has no rep; use a non-null element type

#### Mechanism

Not traced. The list's element is `C | null` by the checker, and the instance of `take` names
it by its structural shape, `{a:i32}|null`, for which no ref-list row exists: the row was
interned under the nominal `C|null`. D2506's close had the same disagreement at a synthesized
binding annotation and fixed it there by taking the nominal spelling first; the parameter
annotation an instance synthesizes is a second site that still takes the structural one. That
is a prediction from the message, not an ablation of the instance's annotation.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `take`'s parameter annotated `(C \| null)[]` | prints `7` | **yes** — the instance |
| the list built from an annotated `({ a: i32 } \| null)[]` with no `type C` | prints `7` | **yes** — a declared struct the shape matches |
| `o.push(y)` replaced by `o.push(null)` (D2506's spelling) | still refuses | no |
