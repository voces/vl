#### Mechanism

[D9645](D9645.md)'s close follows an argument one hop, to an un-annotated `const` whose
initialiser is the record literal (`monoRecSrcBinding`, emit_mono.vl). An alias of that binding,
a `let`, a parameter relaying the record or a function returning it is a read it does not
follow.
