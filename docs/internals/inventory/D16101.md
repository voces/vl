### D16101 — a null test of a `null`-typed field read through another record's row is refused as struct equality

**closed · runs, prints `true` `false` · was loud emit reject, clause 2 · fixed 2026-11-14: a value the checker types `null` tests null by its type · found beside [D16100](D16100.md) · filed 2026-11-14 against master `55e8faf3b`**

Repro:

    type Node = { v: i32, left: Node | null }
    let q: Node | null = null
    print((q = { v: 5, left: null }).left == null)
    print((q = { v: 6, left: null }).left != null)

Want:

    true
    false

#### Mechanism

The assignment yields the row-less literal, whose `left` the checker types `null`, while the
value is stored at `Node`'s row, where `left` is a nullable `Node` ref. No null-test arm claimed a
read whose type is `null` and whose rep is not a nullable one, so the compare fell through to the
struct-equality refusal (`struct equality is not supported yet`).

#### Closed (2026-11-14)

`emitNulIsNullTest` folds a test of an operand the checker types `null` to its constant, running
the operand for its effects (the dead null test), beside the existing fold for a read narrowed to
`null`.
