### D3708 — a generic instance returning a local bound to `(x as? f64) ?? n` is invalid wasm where the cast never converts

**check-clean invalid wasm · clause 1 · the binding sibling of [D3704](D3704.md) · found by the #3387 review (`rv87`) · the same on master `0948a28e3` · filed 2026-10-05 against master `0948a28e3`**

Repro:

    function F<T>(x: T, n: i32) {
      const y = (x as? f64) ?? n
      y
    }
    print(F("s", 3))
    // vl check: rc 0.  vl run: invalid module inside `F`, type mismatch

Want:

    3

#### Mechanism

Not traced. The `??` joins an `f64` and a runtime `i32`, which is `i32 | f64` under the
numeric-join ruling; at a pin where the cast never converts, the instance's local and its
returned value disagree about which rep that is. [D3704](D3704.md) is the returned-directly
spelling at a numeric pin.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| a record pin (`F(r, 3)`, `r: { a: i32 }`) | same invalid module | no |
| an `i32 \| null` pin | same invalid module | no |
