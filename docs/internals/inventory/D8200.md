### D8200 — a generic `(T | L)[]` bound at a numeric literal-union alias is built as a union of two literal sets

**closed · was check-clean invalid wasm · clause 1 · present on master `be738c9f0` · found grading [D7041](D7041.md) · filed 2026-10-20 against master `be738c9f0`**

Repro:

    type K = 1 | 2
    type L = 3 | 4
    function l<T>(x: T, o: L): (T | L)[] { return [x, o] }
    const a: K = 2
    const w: (K | L)[] = l(a, 4)
    print(w[0] + w[1])
    // master: vl check rc 0, then invalid module

Want:

    6

#### Mechanism

The string face of [D7041](D7041.md) with numeric members. `substUnionRebuild`
(check_relate_core.vl) rebuilt `T | L` at `T := K` as a union of the two alias sets. A numeric
literal set is an `i32` rep, so the relation accepted the list, and the emitter then built the
element as a two-member union box. Closed by the same flatten as D7041: when every kept member
is a literal set, the rebuild joins them through `annUnionInnerTy`, the annotation route.
