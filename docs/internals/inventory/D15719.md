**closed 2026-11-11 by #7262 (lane w311), runs and prints `5` · was check-clean invalid wasm, clause 1, master too · the maker's literals and a join of them are built at `K` where the result is delivered there (`recFnBuiltAtDst`, `recUnionLandsAt`, check_fit_rules.vl) · graded by `scripts/capability-probes/matrix/maker-union-of-records-at-declared-record.matrix.vl` and, for a join of the literals, `record-literal-join-at-declared-record.matrix.vl` (all 23 annotated cells run on master `ddb13d5e`; the un-annotated face floors on D15717's shared read) · fixtures `tests/cases/objects/maker-union-of-records-at-declared-record-runs.vl`, `tests/cases/soundness/record-literal-join-at-declared-record-runs.vl` · found closing D15717 · filed 2026-11-11 against master `ebbc4bc2`**

Repro:

    type J = { a: i32 }
    type K = { j: J | null }
    function mk(b: boolean) { if b { { j: { a: 1 } } } else { { j: null } } }
    const _k: K = mk(false)
    print(_k.j?.a ?? 5)

Want:

    5

#### Mechanism

Not ablated. `mk`'s result is the union `{j: {a: i32}} | {j: null}` of its two literals, and the
binding is declared at the one record `K`, whose field `j` is `J | null`. The call is called
once, so its literals would be built at `K` (D3444), but the union of the two arm records reaches
the binding unconverted.
