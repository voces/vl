### D15719 — a maker's union-of-records result delivered at a declared record holding a nullable record field is check-clean invalid wasm

**check-clean invalid wasm · clause 1 · `the emitted module failed to validate inside the module's top-level code` · present on master `ebbc4bc2` · found closing D15717 · filed 2026-11-11 against master `ebbc4bc2`**

Repro:

    type J = { a: i32 }
    type K = { j: J | null }
    function mk(b: boolean) { if b { { j: { a: 1 } } } else { { j: null } } }
    const _k: K = mk(false)
    print(_k.j?.a ?? 5)

Want:

    5

#### Mechanism

Not ablated. `mk`'s result is the union `{j: {a: i32}} | {j: null}` of its two literals, and the
binding is declared at the one record `K`, whose field `j` is `J | null`. The call is called
once, so its literals would be built at `K` (D3444), but the union of the two arm records reaches
the binding unconverted.
