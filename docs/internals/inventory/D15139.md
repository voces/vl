### D15139 — the index read of a map written two functions of different result types is refused at emit

**closed · runs, prints `1.5` · was loud emit reject, `emitProgram: scalar map read has no value-box type`, and before D15137 a loud check reject · clause 2 · split from [D15137](D15137.md) · filed 2026-11-03 against master `b813a46b` · closed 2026-11-03: the collect pass registers a map index read's `T | null` box as it registers a `.get` read's (emit_collect.vl), so the scalar box route that already serves `get` has its value box. A `get` anywhere in the program had registered it, which is why `get` and an index read beside it ran**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const m = Map()
    m.set("a", inc0)
    m.set("b", half)
    const g = m["b"]
    if g != null { print(g(3)) }
    // Want: 1.5

#### Mechanism

The index read of a map whose value set is joined over its `set` writes routes to the scalar box (`emitMapGetScalarBox`), which has no box for a function value. `m.get("b")` on the same map runs since D15137. [D14648](D14648.md) measured that excluding a tagged value from the scalar route then refuses `union atom has no value box`, so the index read needs lowering as `get` is.
