### D17660 — a filter callback's parameter, captured by a closure that passes it to an un-annotated function and stored in a record, is passed at the build's row where the callee's instance takes the read's

**check-clean invalid wasm · 1 cell (the `capture binding` sweep of lane COV-CLOS) · filed 2026-11-26 against master `a39d4847`**

Repro:

    type J = { f: i32 | null }
    function mk2() { return { f: null } }
    const dA: J = mk2()
    const src = [mk2()]
    function takeAny(x) { return x.f == null }
    const r = src.filter((y) => {
      const b = () => takeAny(y)
      b()
      const h = { w: y }
      return true
    })
    print(r.length)
    // vl check: rc 0.  vl run: invalid module inside `b`: expected `{f:null}`, found `J`

Want:

    1

#### Mechanism

Not traced. `dA` stores `mk2()`'s build at `J`, so the callback is instanced at `J` and its
parameter `y` is held there, while every read of `y` is typed `{ f: null }` (D17084). The closure
`b` passes its capture of `y` to `takeAny`, whose instance takes `{ f: null }`; legacy writes the
`J` struct it holds. The record `{ w: y }` is what moves the capture's storage to `J`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `const dA: J = mk2()` (no build at `J`) | runs, prints `1` | **yes** |
| `const h = { w: y }` | runs, prints `1` | **yes** |
| the closure (`print(takeAny(y))` directly) | runs | **yes** |
| `filter` (a plain `function k(y: J)`) | runs | **yes** |
