### D2181 — every name read in a frame scanned the live scope stack, so a function with many locals bound at function scope compiled in quadratic time

**closed 2026-09-23 — a frame of 2,500 live locals builds in 0.13 s CPU where master took 2.2 s, output byte-identical · was a compile-time cost, not a miscompile: every spelling ran · older than the PL-019 range (4789d71f2 reads the same 2.2 s), found while ablating D2180 · filed 2026-09-23 against master `a453c09c5`**

Repro (runs, prints `26`):

    let g = 3
    function f(a: i32): i32 {
      let acc = 0
      const m0 = a + 0; acc = acc + m0 * g
      const m1 = a + 1; acc = acc + m1 * g
      const m2 = a + 2; acc = acc + m2 * g

      acc
    }
    print(f(0) + 8)
    // The cost is in the count of live locals: at 2,500 of them, `vl build` took 2.2 s CPU on
    // master a453c09c5 and takes 0.13 s after the fix. A `@@repeat` cannot mint the distinct
    // names, so the scaling pair `live locals in one scope` is the size witness.

#### Mechanism

`scopeSlotOf` (compiler/emit_state.vl) answered a name's slot by scanning the lexical scope
stack from the top, comparing strings. Every classifier that asks "is this name a live local"
(`declaredSlotOf`, `localIndexOf`, `paramTypeNode`, and #3050's `loopVarCloSigKey`) goes through
it. D2090's sibling-block shape keeps the stack short, because each block pops its bindings. A
frame whose locals are all bound at function scope keeps every one of them live, so each read
cost O(locals). The guest profile of the witness: 93.5% inclusive in `scopeSlotOf`, 60% self in
`__str_eq__`.

The fix keeps a name index beside the stack: per entry, the position of the next-outer live
binding of the same name, and per name, the position of its innermost one. Push and pop keep
it, and a read is one map probe. The four places that reset the stack by reassigning it are
covered by validating each read against `scopeNames`: an index entry the stack no longer
holds reads as absent.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| function scope, each binding in its own block (D2090's shape) | linear | **yes** |
| the reads, bindings never read | not measured | — |
| one function, the same locals spread over 50 functions | 0.61 s against 3.15 s | **yes**, it is the axis |
