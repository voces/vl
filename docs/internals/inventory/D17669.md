### D17669 — a call straight off a function returning a `??` join of un-annotated functions reaches no signature

**loud emit reject · clause 2 · found by COV-CLOS writing the position sweep for `map read default rep` · filed 2026-11-26 against master `af1e95952`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    const m = Map()
    m["k"] = inc0
    function pick(key: string) {
      return m[key] ?? dbl
    }
    print(pick("j")(7))
    // vl check: rc 0.  vl run: emitProgram: a function-value call has no interned signature — parameter 1 of type `_` has no representation in the function-value ABI

Want:

    14

#### Mechanism

Not located. `pick`'s result is the join of the map's un-annotated value and the default `dbl`, and
the call `pick("j")(7)` is the only use that fixes its signature; the callee is a call, so the
signature key (`cloCallSigKey`) reads the join's own type, whose parameter is still a hole. Bound
first, the same value is called at `i32` and runs.
