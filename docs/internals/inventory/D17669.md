#### Mechanism

Not located. `pick`'s result is the join of the map's un-annotated value and the default `dbl`, and
the call `pick("j")(7)` is the only use that fixes its signature; the callee is a call, so the
signature key (`cloCallSigKey`) reads the join's own type, whose parameter is still a hole. Bound
first, the same value is called at `i32` and runs.
