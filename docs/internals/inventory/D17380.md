### D17380 — a union box narrowed to a nullable closure and copied out is written as the box into the closure's slot

**check-clean invalid wasm · clause 1 · `vl check` rc 0 · found by lane IR-D1's Q58 sweep over `(F | null)[]` walks (the union-parameter position) · filed 2026-11-24 against master `9fc46f2d1`, pre-existing**

Repro:

    function g(f: ((i32) => i32) | null) { print(f == null) }
    function su(w: ((i32) => i32) | null | string) {
      if w is string { return }
      g(w)
    }
    su(null)
    // vl check: rc 0.  vl run: invalid module inside `su`: expected (ref null $4), found (ref $7); $4 is struct {structref, i32, i32}; $7 is `union box`

Want:

    true

#### Mechanism

The closure sibling of [D17086](D17086.md). A read narrowed out of a union box to `F | null`, a
nullable closure, is delivered as the box itself: no arm converts the box's null tag to the
closure's `ref.null` and any other tag to its payload cast to the closure struct. A null test and a
call through the read in place ran; every copy (a binding, an argument, a return) did not.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the copy (`print(w == null)` on the read itself) | runs | **yes** |
| the copy (`if w != null { w(1) }` in place) | runs | **yes** |
| the `null` arm (`((i32) => i32) \| string`) | runs | **yes** |
| the third arm (`((i32) => i32) \| null`, no box) | runs | **yes** |
| `string` as the third arm (`\| i32` instead) | still invalid | no |
| the delivery (an argument; a `const`, a `let`, a return) | still invalid | no |
