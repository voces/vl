#### Mechanism

The temps a retag (`repTemp`) or a direct call's result builds were typed through `repTyOf(dst)`,
the type that first minted the rep node. `Node`'s row inside `Node | R` is a twin of `M`'s: a
recursive cycle or a hash-cons hit redirected that minting type's memo to the other node, so
`repNodeOfTy(repTyOf(dst)) != dst`. Legacy emits both functions, so the output never moved.

#### Ablation

| ingredient | outcome | needed? |
| --- | --- | --- |
| `g` and its `Node \| R \| null` | holds | **yes** |
| `M` an intersection (`M` := `Node`) | holds | **yes** |
| `Node` recursive (a plain field for `next`) | holds | **yes** |
| `null` in `g`'s union | still fails | no |
| `f`'s call to `pickNext` (`f` reads `m.v`) | `@start` alone fails | no |
