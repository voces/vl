#### Mechanism

Not ablated to a rung. The element is `"x" | null`, which D2827 made the `string | null`
niche. A `null` element takes its rep from the element context, and the context this literal
hands down does not name the nullable string. `(string | null)[] = [null]` and
`("x" | "y" | null)[] = [null]` both run, and so does `("x" | null)[] = ["x", null]`.
