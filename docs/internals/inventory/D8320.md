### D8320 — a field read through `is N` finds no struct when a record of another union shares the field's name

**loud emit reject · clause 2 · open · present on master `cb1894c33` · found writing D8260's fixture · filed 2026-10-20 against master `cb1894c33`**

Repro:

    type J = { r: i32 }
    type N = { r: i32 | null }
    const a: J | string = { r: 5 }
    const b: N | string = { r: 7 }
    if b is N { const v = b.r
     print(v ?? 0) }
    // vl check: rc 0.  vl run: emitProgram: field access but no struct type declared

Want:

    7

#### Mechanism

Not traced. The read of `b.r` under `is N` resolves no struct once `J`, holding a field of the
same name, is an arm of another union. It may be a relative of [D4614](D4614.md), where a
same-shape record registered under another union hides the narrowed arm, but here the two
records differ in the field's type. Spelled `b.r ?? 0` directly, the refusal is instead
`` `??` over this nullable value is not supported yet ``.

#### Grading list

The bound read, the direct `b.r ?? 0`, the `!= null` test, and the `string`-field spelling.
