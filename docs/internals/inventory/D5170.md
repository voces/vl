#### Mechanism

The row is wider than its witness: ONE call of a written `let` at any `T | null` argument was
refused. The flow table's pins (`ffPinSigsOf`, `fn_flow_shadow.vl`) rendered each parameter
with `tyToStr`, which spells a union `S | null`; an instance's signature and a function type's
name spell the same type `S|null`. `monoLetPinTake` compared the two strings, found the
binding pinned at a signature no instance had, and refused. The pins are now spelled the way an
instance spells its parameter.
