### D5170 — a written `let` of a generic called at a nullable string literal union and at a nullable `string` has no one instance

**loud emit reject · `vl check` rc 0 · clause 2 · OPEN · as on master · found while closing D4244 · filed 2026-10-17 against master `83752e744`**

Repro:

    function gA<U>(u: U) { print("A"); print(u) }
    function gB<V>(v: V) { print("B"); print(v) }
    type S = "p" | "q"
    const a: S | null = "q"
    const b: string | null = "r"
    let x = gA
    x = gB
    let y = x
    x(b)
    y(a)
    // vl check: rc 0.  vl run: the reassigned function binding `x` holds functions called at more than one argument type

Want:

    B
    r
    B
    q

#### Mechanism

The instance record banks a marked binding at its call's signature only when an argument is
a literal union (`fsbLitUnionArg`, `check_assignable.vl`). `S | null` is a nullable union, not
a literal union, so the binding is not banked: the copy `y` fixes the binding's type at the
nullable union's rep and the `string | null` call wants another, which the write refuses.
Running it needs the bank to take a nullable literal union as well, with the call at
`string | null` converting nothing.
