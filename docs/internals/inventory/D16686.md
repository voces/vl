#### Mechanism

`checkIdentUndeclared` (typecheck.vl) said only that the name was undeclared unless it was an
exact export some module or std had. `undeclaredNearNote` (check_node_rules.vl) now says when the
name is a declared type read as a value, else offers the nearest value in scope within
`tySuggestBudget` (`tyEditDist` over `scopeVisibleNames`, the module's functions and the
builtin calls), else the nearest program or std value export with its import
(`mimpNearExport`). Types are never candidates for a value. A missing field names the
nearest declared field (`fieldNearNote`, on the member and `?.` refusals). The note rides a
plain error with no code, so no quick-fix or `--fix` applies a guess.

#### Grading list

Over the corpus (7,763 files in `tests/cases`), 18 undeclared-identifier and 26 no-field
diagnostics: none gains a note (each names something deliberately absent or out of scope), so
there is no false suggestion there either; the fixtures carry the positive cases.
