### D2727 — an un-annotated list literal of a record and a string is built as a list of the record

**now a loud emit reject, 2026-09-27 — the list is the union's box list and a `y is A` read of its element refuses as [D2761](D2761.md) · was check-clean invalid wasm · the literal alone, and returned from one or two returns (`[{ v: 1 }]` beside `[{ v: 2 }, "s"]`) · identical on master · filed 2026-09-26 against master `90b63b840`**

Repro:

    type A = { v: i32 }
    function f() {
      const x = [{ v: 2 }, "s"]
      const y = x[0]
      if y is A { print(y.v) }
    }
    f()

#### Mechanism

The checker types the literal `({v: i32} | string)[]`, but `arrLitIsRef`'s first-element probe
claims an object-literal-first literal as a record list, and the registration pass
(`arrLitInferUnionElemName`) declined to mint the union's box row for any literal that probe
claims, so the classifiers had no union to name and built `array (mut (ref null $A))` with the
string stored into it. Closed for the build: a literal whose first element is a record and whose
recorded element union has a member that is no record now registers its box row, and every
classifier reads the box list; an element read then tests `is string` and prints. The witness
reaches the next layer: `y is A` names the declared `A` against a union that spells its arm
`{v:i32}`, and the variant lookup is by name — [D2761](D2761.md), which the annotated structural
spelling `({ v: i32 } | string)[]` already hit on master.
