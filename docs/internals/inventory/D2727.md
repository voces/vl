### D2727 — an un-annotated list literal of a record and a string is built as a list of the record

**check-clean invalid wasm · open · the literal alone, and returned from one or two returns (`[{ v: 1 }]` beside `[{ v: 2 }, "s"]`) · identical on master · filed 2026-09-26 against master `90b63b840`**

Repro:

    type A = { v: i32 }
    function f() {
      const x = [{ v: 2 }, "s"]
      const y = x[0]
      if y is A { print(y.v) }
    }
    f()

#### Mechanism

The checker types the literal `(A | string)[]`, but the emitter builds it as an `A` list
(`array (mut (ref null $A))`) and stores the string element into it. The annotated spelling,
`const x: (A | string)[] = …`, runs; the literal's own element join never reaches the union-box
row, so this is the literal's classification, not a destination. At module scope the same
program fails as `failed to parse WebAssembly module` with no bug banner.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the string element | runs | **yes** |
| the annotation `(A \| string)[]` on `x` | the annotated spelling runs | **yes** |
| the enclosing function | invalid wasm, unbannered | no |

#### Grading list

The un-annotated and annotated spellings above; the lane's `q04_two_ref` and `s1`–`s3` cells.
