### D4086 — `r is B` with a field narrowed from `i32 | string` to a mixed literal set is refused at emit

**loud emit reject · clause 2 · found reviewing the D4058 close (#3549); printed `true` for every value before it · filed 2026-10-11 against master `5a9535c91`**

Repro:

    type A = { x: i32 | string }
    type B = { x: 1 | "a" }
    function g(r: A) { r is B }
    print(g({ x: 1 }))
    print(g({ x: "a" }))
    print(g({ x: 2 }))
    print(g({ x: "b" }))
    // vl check: rc 0.  vl run: rc 1, "a discriminant field of this storage has no membership compare"

Want:

    true
    true
    false
    false

#### Mechanism

`emitRecordFitIs` compares a narrowed field against each member of its literal set through
`emitFieldLitEq`, which knows a field stored as an `i32`, an atom or a string. A field
declared `i32 | string` is stored as a value box, and a set mixing number and string literals
needs a tag test before each compare. Before the D4058 close the test folded to `true` for
every value, so the move is silent to loud.

#### Ablation

| variant | outcome |
| --- | --- |
| `A = { x: i32 \| string }`, `B = { x: 1 \| "a" }` (the repro) | emit reject |
| `B = { x: 1 \| 2 }` over `A = { x: i32 }` | runs |
| `B = { x: "a" \| "b" }` over `A = { x: string }` | runs |

#### Grading list

`B = { x: 1 \| 2 }` over `A = { x: i32 \| string }` (one-kind set over a boxed field), and the
then-arm read `r.x` at `1 | "a"`.
