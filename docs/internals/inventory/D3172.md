### D3172 — `??` over a value narrowed to `K | null` out of a wider box is refused

**loud emit reject · clause 2 · found by lane WV's D3161 grid (`narcopy`, the `K | null | i32` `coal` cells, 8 of 232, every copy spelling) · the same on master `a0b9acaf8` · filed 2026-09-29 against master `a0b9acaf8` · bucket (d), L1 typed IR, secondary (e) (the 2026-11-14 clause-2 map)**

Repro:

    type K = "a" | "b"
    function t(e: K | null | i32) {
      if !(e is i32) {
        print(e ?? "b")
      }
    }
    t("a")
    t(null)
    // vl check: rc 0.  vl build: emitProgram: `??` over this nullable value is not supported
    // yet — narrow it first, e.g. `if v != null { … }`

Want:

    a
    b

#### Mechanism

The rewrite desugars a re-readable `x ?? d` to `if x != null { x } else { d }` when `x` reads a
nullable value-union box. It keys that on the storage the read reads (`narrowedFromTyOf`), so a
read narrowed out of a box to a scalar, list or record residual desugars and runs. A literal set's
residual is left out: its then-arm re-read is a copy, and a literal set read out of a box lowers
as its atom or as its string by the delivery the checker records on the read
(`strLitTakesAtom`, `nodeCtxTyIxOf`), which the copy has none of. Desugared anyway, the read
loads the box's string into the `??`'s `i32` atom: invalid wasm. The hand-spelled null test runs
because the checker stamps that delivery. Closing it needs the checker to record the null-test
twin's arm delivery, not an emit-side rewrite.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `e: K \| null`, no box | runs | **yes** (the box) |
| `string \| null \| i32` narrowed the same way | runs | **yes** (a `string \| null` residual takes the `nulstr` niche) |
| `i32 \| string \| null` narrowed to `i32 \| null`, `x ?? 0` | runs (the storage-keyed desugar) | **yes** (the literal set) |
| `i32 \| f64 \| null` narrowed to `i32 \| null`, `x ?? 0` | runs | **yes** |
| `if e != null { … } else { … }` | runs | **yes** (the `??`) |
| `const c: K \| null = e`, then `c ?? "b"` | runs | **yes** (the direct read) |
| a module-scope walk over `(K \| null \| i32)[]` | the same refusal | no |
| `const c = e`, then `const f = () => c ?? "N"` (the #3284 review) | the same refusal | no |
