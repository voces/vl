#### Mechanism

The rewrite desugars a re-readable `x ?? d` to `if x != null { x } else { d }` when `x` reads a
nullable value-union box, keyed on the storage the read reads, so a name narrowed out of a box
desugars. A string literal set read out of a box lowers as its atom or as its string by the
delivery the checker records on the read (`strLitTakesAtom`); the desugar's re-read is a copy with
no delivery, so it read the box's string into the `??`'s atom: invalid wasm. The re-read is the
null test's arm, so it is now delivered at the `??`'s type, as an `if`'s arm is at the `if`'s.
Stamping the left operand itself at the result instead broke a `??` over a read narrowed to
`null` and over a `?.` read: only the operand's non-null part is delivered there.
