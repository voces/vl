### D15776 — D15773's `const` choice handed to a hole parameter and also called directly is refused at emit

**loud emit reject · clause 2 · `emitProgram: a function-value call has no interned signature — parameter 1 of type `_` has no representation in the function-value ABI` · found closing [D15773](D15773.md) · filed 2026-11-12 against master `22d35fe4`**

Repro:

    function both(f) {
      print(f("a"))
      print(f(1))
    }
    function nested(c: boolean, n: i32) {
      function inner(s) { print(n); return s }
      function ask(s) { return s }
      const g = if c { inner } else { ask }
      both(g)
      print(g("z"))
    }
    nested(true, 9)

Want:

    9
    a
    9
    1
    9
    z

#### Mechanism

`inlineConstRecArgs` writes a pure `const` choice into its reads only when every read is a
positional argument of a named call (D15451, D15773). A direct call `g("z")` is a callee read,
so the binding stays one closure, which `both` calls at two signatures. Unmeasured beyond that.
