### D8000 — `is` on a value-union field of a map read narrowed by `!= null` names no union variant

**closed 2026-10-20 by lane L6 · `is` on a field of a member receiver goes through the narrowed-variant read only when the narrowing names a variant, as a plain field read does; a map read narrowed by `!= null` is the record itself. The repro prints `true`, pinned by `tests/cases/literal-unions/is-on-field-of-map-read-narrowed-by-null.vl` · was loud emit reject · clause 2 · found by the D7900 position matrix (`map_value_place`) · filed 2026-10-20 against master `981320f30`**

Repro:

    const m: { [string]: { f: i32 | string } } = Map()
    m["k"] = { f: 3 }
    if m["k"] != null {
      print(m["k"].f is i32)
    }
    // vl check: rc 0.  vl run: emitProgram: narrowed receiver names no union variant

Want:

    true

#### Mechanism

The receiver of `.f` is the map read `m["k"]`, narrowed to non-null by the enclosing
`!= null` test. `emitIs`'s `recv.f is T` arm sent every narrowed member receiver to
`emitNarrowedMem`, which reads a field through the variant a narrowing names. A `!= null`
narrowing of a record names none, so it refused. `emitMem` already asks
`memNarrowVariantIndex` before taking that path, and the `is` arm now asks it too. Bound to a
local first, the same read never took the path.

| a map of the union itself (`m["k"] is i32`) | runs | **yes**, a record field |
| a generic producer of the record (the D7900 matrix template) | refuses the same way | no |
