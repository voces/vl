#### Mechanism

Ablated 2026-11-15. The pin's re-ask (`asPinHolds`, check_relate_core.vl) now asks the shared
type-test predicate, as the cast itself does, and refuses where no member may fit. Answering
`null` there is the design, but skipping the re-ask for `as?` (tried) built an invalid module:
the instance's niche cast over `string | null` to `Set<i32>` has no lowering for a miss, so the
emitter needs an instance-keyed "this cast cannot hit" fact before the refusal can go. The same
holds for `as? i32` at a `string` pin. The cast is parked on the parameter and re-asked at each
pin (`check_demands.vl`, D2906), where `string | null` names no `Set<i32>` and the re-ask
refuses as the direct spelling would; an `as?` that cannot fit there is a `null`, not a contract
the program broke.
