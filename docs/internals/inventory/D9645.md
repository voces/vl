### D9645 — a `const`-bound record of an un-annotated function handed to an un-annotated parameter also handed a record of an annotated lambda leaves the function unpinned

**loud emit reject · `vl check` rc 0 · `emitProgram: cannot take the generic function `inc0` as a value` · clause 2 · found closing [D9572](D9572.md) · the un-annotated cells of matrix `hole-fn-record-beside-lambda-record` · present on master `9e81d3ee3` · filed 2026-10-22 against master `9e81d3ee3`**

Repro:

    function inc0(a) { return a + 1 }
    function take(a) {
      print(a.f(3))
    }
    const r = { f: inc0 }
    take(r)
    take({ f: (x: i32): f64 => 1.5 })
    // vl check rc 0.  vl run: emit error: emitProgram: cannot take the generic function `inc0` as a value

#### Mechanism

[D9572](D9572.md)'s close pins the function at the field's call arguments only when the record
literal is the call's own argument (`monoOpenFnRecListPin`, emit_mono.vl). Following the binding
to its literal is sound only while nothing else reads the binding at another type, which the pin
does not yet check.
