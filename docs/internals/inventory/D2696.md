### D2696 — an un-annotated list literal passed to a lambda's typed parameter is built with the wrong element storage

**closed 2026-09-26 — the witness prints `10`; on master `f8709e41c`/`1be1363d9` it was check-clean invalid wasm (`type mismatch` inside `f`) · filed 2026-09-26 by the #3196 review against master `1be1363d9`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    function sum(xs: Shape[]): i32 {
      let t = 0
      for e in xs { if e is Circle { t = t + e.r } else { t = t + e.s * 10 } }
      t
    }
    function f(n: i32) {
      const k = (xs: Shape[]) => sum(xs)
      if n == 1 {
        const out = [{ s: 1 }]
        print(k(out))
      }
    }
    f(1)
    // prints 10

#### Mechanism

An un-annotated literal of one union arm (`[{ s: 1 }]`) types itself as a plain `Sq[]` unless
a declared destination says the list must hold union boxes (`letRefListDestSlotK`, D381). The
destination scan's call form (d) resolved a callee only as a top-level `function` by name
(`fnParamKindListSlot`), so `k(out)` into a lambda's `xs: Shape[]` found no destination and
the plain list reached a box-list parameter. Closed by resolving the callee name through
scope first (`dsCalleeParamSlot`): the binding at the call in its own frame, then an
enclosing frame's, then a module global's, and only when none binds it a top-level function.
A lambda answers with its parameter, a function-typed parameter or annotation with its
recorded `TyFunc`, a `const` naming a top-level function with that function's. The same gap was masked
in sibling blocks on master: the whole-arena fallback [D2685](D2685.md) removed had found a
sibling binding's `take(out)` and borrowed its destination, which is why the #3196 review's
27 generated programs with a sibling `take(out)` ran on master and not on the first cut.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the lambda (call a `function take(xs: Shape[])`, form (d)) | runs on master | **yes** |
| the single-arm literal (`[{ r: 1 }, { s: 1 }]` infers `Shape[]` itself) | prints 11 on master | **yes** |
| the enclosing `if` block | still invalid on master, prints 10 after | no |
| the lambda, for a function-typed parameter `h: (Shape[]) => i32` | invalid on master, runs after | no — the same gap |
| the lambda, for `const a = sum` | invalid on master, runs after | no — the same gap |
| the lambda parameter's annotation (`(xs) => sum(xs)`) | invalid wasm on master AND after | no — a lambda whose parameter type is inferred from its body is a second gap this form does not reach |
