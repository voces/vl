### D16217 — a compound write used as a value, whose place's index or receiver has an effect, runs that effect twice

**closed 2026-11-14 · runs, prints `2` then `1` · was a silently wrong count on master, `calls` printed `2`, clause 1, refused at emit while this row was open · closed by spilling the place inside a value `if` (`drwCompoundValueSpill`, `emit_rewrite.vl`) · found by lane I closing D4055 · filed 2026-11-14 against master `685b59c13`**

Repro:

    let calls = 0
    function k(): i32 {
      calls = calls + 1
      0
    }
    const xs = [1, 2]
    print(++xs[k()])
    print(calls)
    // master, vl run: 2 then 2 (the index ran twice). Now: 2 then 1.

Want:

    2
    1

#### Mechanism

A compound write reads and writes its place through one target node. As a statement,
`spillCompoundPlace` (`emit_rewrite.vl`) spills a receiver or index that is not re-readable
ahead of it, so it runs once. As a value nothing spilled it, and the place ran twice: a silently
wrong count. `drwCompoundValueSpill` now rewrites such a write to `if true { <spills> p } else
{ <zero> }`, the value `if` the rewrite already mints, so the spills run where the write stands
and the sibling operands keep their order. A write whose type has no literal for the dead arm
(neither a number nor a string) keeps the emit refusal.

#### Ablation

| spelling | before | after |
| --- | --- | --- |
| the witness, `++xs[k()]` as a value | silently wrong count (`calls` 2) | runs, `calls` 1 |
| `(xs[k()] += 1)`, `*= 2.0`, `+= "z"`, `++pick().n`, `r()[1]--` as values | silently wrong count | runs, each effect once |
| `m() + ++xs[k()]` | silently wrong count | runs, `m` before `k` |
| `print(xs[k()]++)` | parse error | runs |
| `xs[k()]++` or `++xs[k()]` as a statement | runs, `calls` 1 | runs, `calls` 1 |
| `print(xs[0]++)`, a re-readable place | parse error | runs |
