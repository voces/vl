### D16630 — `sel(gid)` returned through an inferred return or held as a list element, then used at `f64`, is refused at check: nothing at the call binds `A`

**loud check reject · clause 2 · open · bucket (c), L2 inferred interfaces: `A` is bound only by a use after the value leaves the call, through an inferred return or an un-annotated list element; `sel<f64>(gid)`, an annotated return, or an annotated element type runs · `vl check` rc 1 · `cannot assign (i32) => i32 to 'v' of type (x: f64) => f64 (`sel`'s `A` is bound by nothing at its call, so it is `i32` there: write `sel<f64>(…)`)` · the run face of [D16562](D16562.md), whose close made it loud; the local face is [D16411](D16411.md) · the annotated `return_inferred` and un-annotated `array_element` cells of `generic-fn-at-generic-fn-param-bound-by-destination.matrix.vl` · filed 2026-11-15 against master `6f9bafb92`**

Repro:

    function gid<A>(x: A): A { return x }
    function sel<A>(f: (x: A) => A): (x: A) => A { return f }
    function __deliver() {
      return sel(gid)
    }
    const v: (x: f64) => f64 = __deliver()
    print(v(1.5))
    // vl check: loud check reject, `sel`'s `A` is bound by nothing at its call

Want:

    1.5

#### Mechanism

Nothing at `sel(gid)` names `A`: the call has no destination of its own, and the only use that
would bind it is reached through the inferred return of `__deliver` or a read of the list's
element. The call binds `A` at the unbound default (D4551), so the use at `f64` is refused. Running
it needs the use's type to flow back to the call (inferred interfaces).

#### Grading list

The matrix cells above (each must print `1.5`), D16411's witness, and the `string` and `i64`
spellings of the same destinations.
