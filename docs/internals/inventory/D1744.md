### D1744 — a deep-`is` site ANYWHERE in the module flattens the union alias, so a plain `is J` over `J | i32` elsewhere is refused as "not a variant" — the refused function type-checks alone and only fails in company

**loud check reject on a `vl check`-clean program — `` `is` check type 'J' is not a variant
of boolean | f64 | string | J[] | {[string]: J} | i32 | null `` · found 2026-09-06 by the
ROADMAP re-grade while grading the `as`-trio-over-`Json` item · clause 2**

Repro:

    type J = null | boolean | f64 | string | J[] | { [string]: J }
    type Cfg = { port: f64 }

    function f(d: J | i32) {
      if d is J { print(1) }
    }
    function g(e: J) {
      if e is Cfg { print(2) }
    }
    f(1)
    // check reject: `is` check type 'J' is not a variant of boolean | f64 | string |
    // J[] | {[string]: J} | i32 | null — DELETE `g` and the same `f` checks clean

#### Mechanism

`checkIsNode`'s arm gate refuses when `!assignable(chkTy, baseTy) || isWidenNotVariant(chkTy,
baseTy)` (`compiler/typecheck.vl` ~33795). `f` alone passes it: `J` is a member of `J | i32`
under its own name. Adding `g` — whose `e is Cfg` is the deep-`is` JSON-shape route D1035
built (`jsonDeepIsSite`, `compiler/json_walk.vl` + `driver.jwSecondPass`) — makes the same
gate refuse, and the message shows why: the operand renders **flattened**, with `J`'s six
members inlined, so the alias name it was matching against is gone. `g` is reported UNUSED in
the same run, so a function nothing calls decides whether another function type-checks. The
effect is whole-program, not sequential: declaring `g` BEFORE `f` refuses identically, which
rules out a pass-state leak and points at the registry the deep-`is` registration mutates —
the "arena and canon are two producers" family, where one producer keeps the declared member
spelling and the other expands it.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `g` deleted entirely | `Checked 1 file, no errors.` | **yes** |
| `g`'s target changed to a real member (`e is string`) | checks clean | **yes — it must be a struct shape** |
| `g`'s body replaced by a `Cfg` value that is never `is`-tested | checks clean | no — declaring `Cfg` is not the ingredient |
| `g` moved ABOVE `f` | refuses identically | no — order-independent |
| `std:json` instead of the local alias | refuses identically | no — std is scenery |

#### Grading list

* `f` alone, which must keep checking clean (the control).
* The `as` half of the same design item: `d as Cfg` over a `Json` is a separate loud refusal
  (`` `as Cfg` names a type that is not a member of Json ``) and is NOT closed by this row.
* D1035's own witness, which must keep printing `3`.
* D1190 and D1198, the other two deep-`is` rows, whose refusals must not widen.
