### D4037 — an un-annotated `const` of an `else if` chain whose inner link is all string literals stays `string` beside a literal-union arm

**loud check reject · clause 2 · found closing DV-1207 · filed 2026-10-11 against master `98a4ed71b`**

Repro:

    type Look = "knife" | "none"
    type Holder = { look: Look }
    function pick(ok: boolean, h: Holder): Look {
      const look = if ok { h.look } else if h.look == "none" { "knife" } else { "none" }
      look
    }
    print(pick(false, { look: "knife" }))
    // vl check: "expected Look, got string"

#### Mechanism

DV-1207 types an `if` whose arms are a literal-union value and string literals of it as the
union, arm by arm. The inner `else if` link is checked first, has only literal arms, and
joins to `string`; the outer join then sees a `Look` arm beside a `string` arm that is not a
literal tail, so it does not adopt. An annotated destination banks its type on every link and
runs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the inner link (`else { "none" }`) | runs, prints none | **yes** |
| the un-annotation (`const look: Look = …`) | runs, prints none | **yes** |
| the binding (the chain as the function's tail) | runs, prints none | **yes** |
