### D3160 — a closure returning a generic call on a literal union narrowed out of a box is invalid wasm

**closed · a function whose result is a literal-union atom never widens its return value to a string · fixture `tests/cases/closures/closure-generic-call-narrowed-literal.vl` · was check-clean invalid wasm · clause 1 · found by the #3281 round-2 review (`rv3281r2-5785/a/p01.vl`) · the same on master `b1794003a` · filed 2026-09-29 against master `b1794003a`, closed 2026-09-29 against master `a0b9acaf8`**

Repro:

    type K = "a" | "b"
    function id<X>(a: X): X { return a }
    function t(e: K | i32) {
      if !(e is i32) {
        const f = () => id(e)
        print(f())
      }
    }
    t("a")
    // vl check: rc 0.  vl run: invalid module inside `f`: type mismatch: expected i32, found
    // (ref $type)

Want:

    a

#### Mechanism

The lambda is pinned at a synthesized `: K`, so `retLitUnion` holds and its result is the `i32`
atom. The synthesized annotation also reads as `string` to the spelling tests beside it
(`nodeTyIsStringPrim`, `retNulStringFlag`), and `id(e)` at the `K` instance is an atom, so
`retStrWiden` was set as well and the return widened the atom into a string ref against an
`i32` result. An atom result now clears the widen (`emitReturnValue`, wasmEmit.vl).

#### Ablation

| ingredient changed | outcome | needed? |

| `e: K`, no box | runs | **yes** (the narrowing out of a box) |
| `string` in place of `K` | runs | **yes** (the literal union) |
