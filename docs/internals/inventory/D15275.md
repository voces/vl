### D15275 — an unbound call's returned record, its field called directly beside a widened binding of the same function, is refused

**open · loud emit reject · `emitProgram: cannot take the generic function id0 as a value — a function value carries ONE signature` · clause 2 · the read spelling runs · found grading D15273 · filed 2026-11-04 against `lane/g2-d15273` with D15273**

Repro:

    function id0(a) { return a }
    function id1(a) { return a }
    function mk() { return { f: id1 } }
    const r = mk()
    r.f = id0
    print(r.f(2))
    print(r.f(2.5))
    print(mk().f(7))

Want:

    2
    2.5
    7

#### Mechanism

D15273 joins the bindings a call of `mk` initialises. `mk().f(7)` binds nothing, so its type
stays the closure, and its field call adopts `mk`'s literal at the call's closed row (`holeFieldCallAdopt`).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `mk().f(7)` read as `const h = mk().f; h(7)` | runs | **yes** (the direct call) |
| `mk().f(7)` bound first (`const s = mk(); s.f(7)`) | runs (D15273) | **yes** (the unbound call) |
