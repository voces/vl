### D15275 — an unbound call's returned record, its field called directly beside a widened binding of the same function, is refused

**closed · runs · was loud emit reject `emitProgram: cannot take the generic function id0 as a value — a function value carries ONE signature` · clause 2 · the read spelling runs · found grading D15273 · filed 2026-11-04 against `lane/g2-d15273` with D15273 · closed with D15279 by the record solve declining a literal its field calls build apart**

Repro:

    function id0(a) { return a }
    function id1(a) { return a }
    function mk() { return { f: id1 } }
    const r = mk()
    r.f = id0
    print(r.f(2))
    print(r.f(2.5))
    print(mk().f(7))

Want:

    2
    2.5
    7

#### Mechanism

`mk().f(7)` binds nothing, so D15273's sibling join does not reach it, and its field call
adopted `mk`'s literal at the call's closed row while `r`'s calls through its widened field
skipped the adoption. A call through a call-bound binding's widened field now declines its own
judged call's group in the record solve instead of skipping it, and the solve declines every
other call's build of a literal a declined group builds (D15279), so the literal stays at its
own row and both bindings' sets dispatch.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `mk().f(7)` read as `const h = mk().f; h(7)` | runs | **yes** (the direct call) |
| `mk().f(7)` bound first (`const s = mk(); s.f(7)`) | runs (D15273) | **yes** (the unbound call) |
