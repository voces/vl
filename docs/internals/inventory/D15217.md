### D15217 — a read of a map whose values are built wider, defaulted with `??` to a held record, is not built at the map's record

**open · check-clean invalid wasm · clause 1 · found grading the destringify lane's map `??`-literal-default fix · filed 2026-11-04 against master `214d93f91`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const m = Map()
    m.set("a", mk())
    const wm: {[string]: J} = Map()
    wm.set("a", mk())
    const d = { f: 1 }
    const b = m.get("a") ?? d
    print(b.f)

Want:

    4

#### Mechanism

`m`'s values are built at `J` (`wm` widens `mk`'s result), so `m.get("a")` reads a record of `J`'s
storage; `d` is a held binding built at its own `{f: i32}`. The `??` joins the two records, and `b`
is handed one of each storage. A literal default is built at the read's record (the store column,
`recCoalesceLitAdopt`); a held record is shared, so it cannot be.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `??` default (`m.get("a")`, read with `?.`) | runs | **yes** |
| `wm` (the map's values not built wider) | runs | **yes** |
| `d` inlined as `{ f: 1 }` | runs, prints `4`, with the literal-default fix; invalid without it | **yes** |
