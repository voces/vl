#### Mechanism

Probed against the D7183 close; the same on master. The lambda has no declaration the split can
copy per call type, and the element instances call a function the emitter never minted.

Traced at the close: the fix is emitter-only. The element typing (`monoElemParamTys`) read only a
declared function as the argument. A lambda still holding
a hole, or a `const` naming one, is now typed there at what the elements' calls give it, and the
call counts as handing an open argument (`monoElemsParamArgs`).
