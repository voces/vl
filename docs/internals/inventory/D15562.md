### D15562 — a global list of records assigned a joined function result of a wider set is refused at emit

**open · loud emit reject · `emitProgram: ref valtype with no interned shape` · clause 2 · the global initialised from the call, or a record rather than a list, runs · found closing [D15559](D15559.md) · filed 2026-11-08 against master `07eeefc8`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function pick(b) {
      const a = [{ fs: [inc0] }]
      if b { return a }
      return [{ fs: [dbl] }]
    }
    let g = [{ fs: [dbl] }]
    g = pick(true)
    print(g[0].fs[0](3))

Want:

    4

#### Mechanism

Not a set widening. The global's cell is a `reflist` whose row `letCellSlot` resolves to -1 (`letRefListSlot` falls through every rung), so `fbValtypeNullable` refuses it. The ingredients are a module global, initialised by a list literal that nests a function list, and reassigned from a call. The call may return the same set.
