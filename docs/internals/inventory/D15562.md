### D15562 — a global list of records assigned a joined function result of a wider set is refused at emit

**open · loud emit reject · `emitProgram: ref valtype with no interned shape` · clause 2 · the global initialised from the call, or a record rather than a list, runs · found closing [D15559](D15559.md) · filed 2026-11-08 against master `07eeefc8`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function pick(b) {
      const a = [{ fs: [inc0] }]
      if b { return a }
      return [{ fs: [dbl] }]
    }
    let g = [{ fs: [dbl] }]
    g = pick(true)
    print(g[0].fs[0](3))

Want:

    4

#### Mechanism

Not yet ablated. `g` is typed by its initialiser, a list of records of set `{dbl}`, and the assignment writes `pick`'s joined `{inc0, dbl}`. A `let` of a function widens its reads to every function written to it (`elabFnLetTy`); nothing does that for a list of records holding functions.

| spelling | outcome |
| --- | --- |
| the witness | loud emit reject |
| `let g = pick(true)`, then `g = pick(false)` | runs |
| the record twin, `let g = { fs: [dbl] }` and `g = pick(true)` over records | runs |
