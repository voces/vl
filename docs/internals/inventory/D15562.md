**closed 2026-11-08 — the filed repro prints `4` · was loud emit reject (`emitProgram: ref valtype with no interned shape`), clause 2 · three holes: the checker's `let` widening read a whole write of a call as a bail, so the global kept its literal's set (`cwSlotDescend` now reads a call as its returned values while `cwFollowCalls`); the tag pass took a stored list only at the identical type index, and refused a smaller set's store into a wider holder (`ftListLeavesOfSet` matches lists nested alike, noting the smaller set with `ftSubsetNote`); and a store ending a loop body read as a delivery (`ftLoopBodyStmt`). Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function pick(b) {
      const a = [{ fs: [inc0] }]
      if b { return a }

    }

Want:

    4

#### Mechanism

The global's cell is a `reflist` whose row `letCellSlot` resolves to -1 (`letRefListSlot` falls through every rung), so `fbValtypeNullable` refuses it: the binding's set was never tagged. The checker kept the global at its literal's set, because its widening bailed on the whole write of a call. The tag pass took a stored list only at the identical type index. The ingredients are a module global, initialised by a list literal that nests a function list, and reassigned from a call. With the same set throughout, only the second hole bites.
