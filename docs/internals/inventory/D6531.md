#### Mechanism

The callee `k` is a parameter, so the call has no declared slot to read the argument's
parameter types from, and the coercion that instances `id` at a concrete function type ran
only at a declared slot. The type is on the value: `k`'s recorded type is
`(g: (x: i32) => i32) => i32`.
