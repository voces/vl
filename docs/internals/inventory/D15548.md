### D15548 — a list of a generic function's returned records holding a set, the set called through the list, has no interned signature

**closed · runs, prints `2` · was loud emit reject, `emitProgram: a function-value call has no interned signature`, clause 2 · fixed 2026-11-08: a generic instance's copy of a record literal reads the slot pins of its template (`monoStoredSlotFnTy`) · found closing [D15297](D15297.md) · filed 2026-11-08 against master `82072a24`**

Repro:

    function inc0(a) { return a + 1 }
    function mk<T>(x: T) { return { fs: [inc0], x: x } }
    const rs = [mk(1), mk(2)]
    print(rs[1].fs[0](rs[0].x))

Want:

    2

#### Mechanism

`monoPinFieldContainer` instances the functions a record literal's list field holds at the
slot's pins (`monoStoredSlotFnTy`). The slots are keyed by the template literal, and a generic
instance's copy keys none, so the copy read as a slot nothing calls: `inc0` was never instanced
at `(i32) => i32` and was served by its uncalled stub. The tagged id of a lone record reached the
call through the id table, so it ran; a list of the records, or an annotated closure list as
the destination, built a closure at the stub. Since D15297, the annotated spelling was a
check-clean trap (`indirect call type mismatch`) on that branch; it never reached master.
