#### Mechanism

Traced to emit by probe (2026-11-12, `wasm-dis` and the tag pass's `ftTry`). The tag pass tries no
set here: no call goes through a set, since `g(3)` reads through the annotated closure type. So
`fnMap` and `m2` stay maps of closures (`$8`, a list of the closure struct). The joined map's value
type, the fresh function type `elabFnJoinMapTy` makes, keys no closure row, so `deliver`'s result
storage falls back to an `i32`-valued map (`$6`). The function's `if` builds `$8` and returns it as
`$6`.

A returned `fnMap` alone at the annotation is pinned by `monoPinMapValues`, which refuses loudly.
A join written at the annotated binding directly takes the annotation's storage. The fix is in mono's
pin of a returned map's function values at its annotated use, or in keying the joined fresh type's
closure row from its arms.
