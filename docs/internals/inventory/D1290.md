* **IT IS THE BOX, NOT THE NULL.** `i32 | null` and `f64 | null` are code 16 — a `{tag, value}`
  BOX, two cells with a discriminant — not the `(ref null $H)` niche [D1180](#d1180)'s guard
  serves, and `nulFieldInnerCode` has no entry for 16. The compare is a TAG compare plus a
  payload compare per member, and that dispatch already existed for two operands: what was
  missing was a way to reach it with two CHAIN READS instead. `unionBoxEqColumns` is the
  admission gate (asked before a byte is written, so an unservable arm set still declines to
  the loud refusal) and `emitUnionBoxEqStaged` is the core, over two boxes on the stack.

* **THE ARM SPELLING IS THE SAME FIX, ONE TABLE OVER.** `variantFieldComparable` grew a
  code-16 rung and `emitVariantFieldEqCoreAt` the matching core; the ARM's operands already
  arrive on the stack, so it is the same staged call.
