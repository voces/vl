### D4899 — a record holding the complement of `is i32[]` over a parameter matches no row when the ARGUMENT is the union `string[] | i32[]`

**closed · was a loud emit reject (`emitProgram: object literal matches no union variant`), identical on master `c2dbf639e` · fixture `tests/cases/generics/complement-list-record-scalar-and-hole.vl` · filed 2026-10-15**

Repro:

    function h(v) {
      if v is i32[] { print(0) } else {
        const r = { xs: v }
        print(r.xs[0])
      }
    }
    const a: string[] | i32[] = ["e"]
    h(a)
    // vl check: rc 0.  vl run: emitProgram: object literal matches no union variant

Want:

    e

#### Mechanism

In the hole face the field's type is a derived hole, `HD_GNOT` of the parameter less
`i32[]`, and `holePinReadOf` answered `-1` for every `HD_GNOT` with a non-null alternative,
so `pinnedValTyOf` gave the literal no type and `mintPinnedObjLit` minted no row. Closed in
`typecheck.vl`'s `holePinReadAt`: the arm reads the base hole's pin and subtracts the
alternative (`string[] | i32[]` less `i32[]` is `string[]`), or keeps the pin where nothing
is subtracted. The `<T>` face is a separate check-side gap, filed as D4922.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the record (`print(v[0])`) | runs | **yes** |
| the hole (`h<T>(v: T[] \| i32[])`) | still refused | no |
| the hole (`h(v: string[] \| i32[])`) | runs | **yes** |
| the union argument (`h(["e"])`) | still refused: `object literal but no struct type declared` | no |
