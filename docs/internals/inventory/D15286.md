### D15286 — an empty list literal spread into a push is refused at emit

**closed 2026-11-13 · runs, prints `1` · an empty spread source is typed at the list it appends to, and a spread literal whose sources carry no list kind builds at its own type · was loud emit reject · `emitProgram: a spread's source is not a list this rep knows` · `vl check` rc 0 · clause 2 · found grading [D15285](D15285.md) · filed 2026-11-04 against master `930a8aae`**

Repro:

    const zs = [1]
    zs.push(...[])
    print(zs.length)

Want:

    1

#### Mechanism

`spreadDestKind` (compiler/emit_classify.vl) took the list kind from the first spread source's
type. An untyped `[]` has none, so it returned null and `emitArrSpread` refused. Every spread
position failed alike: a push, a list literal, and a rest-parameter call. For a push, the spread
literal is synthesized from the arguments and has no type of its own, and `checkListPushArgs`
(compiler/check_member_call.vl) typed a spread literal from the receiver only when it had an
element type. The close types an empty `[]` push source at the receiver's list type, and falls
back to the literal's own list type when no source carries a kind. Test cells:
`tests/cases/lists/spread-empty-literal-every-position.vl`.
