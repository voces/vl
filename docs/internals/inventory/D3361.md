### D3361 — a join of two type parameters read out of lists, or joined in a nested generic function, answers `is boolean` false for `false`

**check-clean silently wrong · clause 1 · open · the same on master `455e553ca` · found by the #3310 round-3 re-review (`rv3310r3/m/ls1.vl`, `ng1.vl`; the g5 grid's `list_scalars`, `list_plus_scalar` and `nested_gen` programs) · filed 2026-09-30**

Repro:

    function g<T, U>(xs: T[], ys: U[], k: i32) {
      const a = xs[0]
      const b = ys[0]
      const r = if k == 0 { a } else { b }
      print(r is boolean)
    }
    const x0: i32 | null = null
    const x1: boolean = false
    g([x0], [x1], 0)
    g([x0], [x1], 1)
    // today it prints false false

Want:

    false
    true

#### Mechanism

Not localised past the ablation. The same join of two bare parameters answers right since
#3310 (the kept-apart join, D3268), but that join is gated off in a body taking a list of a
type parameter (D3357) and in a generic declared inside another function, so both shapes keep
master's typing, in which the join's `boolean` arm does not survive to the `is`. The nested
spelling is `function outer(k: i32) { function inner<V, W>(a: V, b: W, k2: i32) { … } }`
with the same bindings, and prints the same `false false`. The second arm is read at the
first's type whatever its member: a `string` or `K` second arm answers `is string`/`is K`
false (and a `K` answers `is i32` true), and a `string | null` second arm holding `null`
traps on a null reference. A lambda in the generic body joining the two parameters does the
same. A record arm is D4046, whose ablation differs.

#### Ablation

| ingredient changed | outcome on master | needed? |
| --- | --- | --- |
| concrete `(i32 \| null)[]` and `boolean[]` parameters | prints `false true` | **yes** (the type parameters) |
| `x0: i32 = 0` in place of `i32 \| null` | prints `false false` | no |
| `r is null` added | first call `true`, second `false` | no (only `is boolean` is wrong) |
| `x1: string = "s"` with `r is string`, or `x1: K` with `r is K` | prints `false false` | no (any second-arm member) |
| `x1: string \| null = null` with `r is null` | prints `true`, then traps on a null reference | no (the trap face) |
| `print(r)` in place of the `is` | prints both arms right | **yes** (an `is` reader) |
| a nested function capturing `a`, `b` of the outer generic | prints `false true` | **yes** (the gated shapes) |
