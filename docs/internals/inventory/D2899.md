### D2899 — a list literal of a hole-typed `null` at a `string | null` pin traps on a null reference

**check-clean trap after load · clause 1 · found working [D2854](D2854.md) (the `nnul` cells of this lane's grid) · the same on master `089c6ff56` · filed 2026-09-27 against master `089c6ff56`**

Repro:

    function mk(x) {
      const xs = [x]
      return xs[0]
    }
    const vnn: string | null = null
    const w0 = mk(vnn)
    if w0 != null { print(w0) } else { print("null") }
    // vl check: rc 0.  vl run: wasm trap: null reference, in `mk`

Want:

    null

#### Mechanism

Not localised. The instance builds `[x]` as a list whose element excludes `null` and casts the
element on the way in, so a `null` argument traps; a non-null `string | null` value runs. The
list literal's element is typed at the hole's variable, which no instance binding substitutes
([D2898](D2898.md) is the same gap at a union or list pin, closed by annotating the local; a
nullable scalar element was left out of that rung).
