### D6743 — a generic handed to two hole parameters of a call inside a hole function's body, beside another hole function handed it at module scope, builds invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · found closing [D6705](D6705.md) · filed 2026-10-18 against master `73713bacf`**

Repro:

    function id(a) { return a }
    function app(g, h) { print(g(1)); return h("s") }
    function use(n) { print(n); return app(id, id) }
    print(use(1))
    function app3(g) { return g(1) }
    print(app3(id))
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `app`: current function requires result type [(ref $2)] but callee returns [i32]; $2 is `string`

Want:

    1
    1
    s
    1

#### Mechanism

From the ablation only. `h` is called at `string` and is given `id` at its `i32` instance, the
one `app3`'s module-scope call takes; the call `app(id, id)` sits in `use`, whose hole parameter
makes its body generic, and without `app3` the by-name plan of [D6705](D6705.md) runs it.
