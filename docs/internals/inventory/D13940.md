### D13940 — a module-global list of lists widening an `i32[]` element is initialised in a constant expression when a later global refuses

**loud emit reject (`emitProgram: ref valtype with no interned shape`) since #5141 gave a global's and a local's cell slot one producer, still open · was invalid wasm, check-clean · filed 2026-10-26 against master `6eae61d51`**

Repro:

    const e1 = [[1.5], [1]]
    const e3 = [["a"], [1, "b"]]
    print(e1[1][0] + 0.5)
    print(e3.length)
    // vl check: rc 0.  vl run: invalid wasm, constant expression required: non-constant
    // operator f64_convert_i32_s

#### Mechanism

`e1`'s element `[1]` is widened to `f64[]`, and the `f64.convert_i32_s` that widens it lands
in `e1`'s global initializer, where only constant operators are valid. `e3` alone is a loud
emit reject (`leaf-scalar widening across a nested array is unsupported`), and that refusal is
lost when `e1` is declared first: the module is written with `e1`'s initializer and no error.
Declared in the other order, the program is the loud reject.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `e3` (and its print) | runs, `1` then `2` | **yes** |
| `e1` (and its print) | loud emit reject | **yes** |
| `e3` written `[["a"], ["b"]]` or `[[1, "b"]]` | runs | **yes** (the refusing shape) |
| `e3` declared before `e1` | loud emit reject | **yes** (the order) |
| both bindings moved into a function | loud emit reject (`.length` receiver's ref-list element does not resolve) | **yes** (module globals) |
| `[1.5]` produced by a call, `[mf(), [1]]` | invalid wasm | no |

#### Grading list

The close re-grades the swapped order and the function-local spelling, which must agree with
the module-global one, and `e3` alone, whose refusal is the nested-array widening gap.
