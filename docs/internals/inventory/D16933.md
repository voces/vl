### D16933 — a generic function handed to a callee that returns it in a closure, the closure bound to a `const` and called once, finds no function-value signature for the generic's type parameter

**loud emit reject · clause 2 · filed 2026-11-17 against master `4005967cc`**

Repro:

    function same<T>(k: T): T { return k }
    function wrap<G>(g: G) { return () => g }
    const w = wrap(same)
    print(w()(3))
    // vl check: no errors.  vl run: emit error, a function-value call has no interned signature, parameter 1 of type `T` has no representation in the function-value ABI

Want:

    3

#### Mechanism

At the top level `same` is no parameter, so no tagged set carries it (D16843 closes the handed
parameter); its one instance comes from the call its read flows to. Unbound, `wrap(same)()(3)` runs:
the flow reaches the call. Through the `const` the call `w()(3)` is not reached, so the closure's
result keeps `same`'s open type and the call through it has no signature.

#### Ablation

| change from the repro | outcome | needed? |
| --- | --- | --- |
| `print(wrap(same)()(3))`, no binding | runs, prints `3` | **yes** |
| `const f = w()` then `f(3)` | same refusal | no |
| a concrete `inc(k: i32)` for `same` | runs, prints `4` | **yes** (a generic) |
| `pass(g) { return g }` for `wrap`, bound | runs, prints `3` | **yes** (the closure) |
| `const h = () => same` then `const w = h` | runs, prints `3` | **yes** (a callee's closure) |
