### D17063 — one mutable module cell of the IR's `Opnd` union makes checking the compiler 20% dearer

**runs today and must keep running · a checker cost defect · filed 2026-11-23 against master `930dc5c5a` by lane IR-N1**

Repro:

    type A = { a: i32 }
    type B = { b: i32 }
    type U = A | B
    let g: U = { a: 0 }
    function setG(u: U) { g = u }
    function f(u: U): i32 {
      if u is A { return u.a }
      return 0
    }
    setG({ b: 2 })
    print(f(g))
    // vl run: 0

Want:

    0

#### Mechanism

Checking pays per use of a union whose type a mutable module-level `let` also holds. In the compiler,
one `let fitRecvO: Opnd = { oiRep: -1, oiBits: 0 }` in `compiler/ir_lower.vl`, read and written by
four functions, raised the L2 self-compile fuel 9.4%, all of it in `5 checkProgram`. `Opnd` is used
across every IR module. Holding the same value in `const fitRecvOs: Opnd[] = []` (push and pop)
costs nothing measurable. The repro is the shape and runs; at its size the cell costs only a few
percent of the check (the ablation's last two rows), so the cliff needs the compiler-scale witness.
