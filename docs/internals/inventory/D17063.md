### D17063 — one mutable module cell of the IR's `Opnd` union makes checking the compiler 20% dearer

**fixed 2026-11-23 · runs today and must keep running · a checker cost defect · filed 2026-11-23 against master `930dc5c5a` by lane IR-N1 · fixed by `crwMentionersInto` (check_capture_walks.vl): `crInfoOf`'s reacher closure is a worklist over an index of each function's mentions, not a rescan of every function against every handle per round**

#### Mechanism

A module `let` is narrowed by its initializer (`let g: U = { a: 0 }` reads as `A` until a write or
a call ends it), and a `const` of a list never is. Every later call, and every `crFilterCond`, then
asks whether it can reach a writer of the cell (`crCallReaches`, `crMayBeWritten`), under the module
root. `crInfoOf` answered with a fixpoint that rescanned every function of the program against
every handle found so far until a round added none: rounds × functions × handles. With
`fitRecvO` written by `irFitTail`, the reachers are every function on a call path into IR lowering,
and the cost was quadratic. The closure is now a worklist: each handle, once added, reaches the
functions an index of mentions names for it. The escape scan over uses tests a key set instead of
the handle list, and `crBodyReads` keys its walk by interned name instead of a concatenated string.
