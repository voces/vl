Repro:

    function G<A, B>(k: i32, a: A, b: B) {
      const g = () => { if k == 0 { a } else if k == 1 { b } else { null } }
      const v = g()
      print((v ?? 9) is i32)
    }
    G(1, 3, "t")
    // PRINTS true

Want:

    false

#### Mechanism

A lambda's inferred return over the enclosing body's type parameters was a deferred hole join
(`A | B | null`), and every call of the lambda collapsed it to its first member
(`collapseDeferredJoin`): `g()` typed `A | null`, so at the pin `(i32, string)` the body read
the lambda's box as `i32 | null` and folded `is i32` to `true`. The lambda's own instance
built the box. Closed in the checker: a lambda's join whose only holes are two or more of an
enclosing body's type parameters or parameter holes is that body's kept-apart join
(`openParamJoinOf`, marked apart), so the lambda's instance and every caller re-join it at the
pin the same way. The lambda's clone takes that signature as its return (`emit_mono`), and a
`??` over it with a record arm names and registers its box at the pin.
