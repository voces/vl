### D14162 — a named alias intersecting a recursive record type with another record has no struct row at a parameter or list element

**loud emit reject · `emitProgram: field access receiver is not a struct` · clause 2 · found ablating the G12 field-set-scan cells · pre-existing on master `bbdd4e720` · filed 2026-10-26 against master `bbdd4e720` · narrowed 2026-11-10 (binding and return positions run)**

Repro:

    type Node = { v: i32, next: Node | null }
    type M = Node & { v: i32 }
    function f(m: M): i32 { m.v * 10 }
    print(f({ v: 1, next: null }))
    // vl check: rc 0.  vl run: emit error at 3:27, field access receiver is not a struct

Want:

    10

#### Mechanism

The intersection flattens to `Node`'s own shape, which refers to itself through `next`, so
`collectS` interns no row under the alias name `M`. The alias's type is a one-member union over
that shape. Since 2026-11-10 the structural reader (`repStructRowOfTy`) and the annotation-side
`recordStructRow` fold that union to its record, so a binding `const n: M` and a return `(): M`
find `Node`'s row and run. A parameter's body read and a list element `M[]` still ask by the
alias name, which has no row.
