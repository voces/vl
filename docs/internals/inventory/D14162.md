### D14162 — a named alias intersecting a recursive record type with another record has no struct row at emit

**loud emit reject · `emitProgram: field access receiver is not a struct` · clause 2 · found ablating the G12 field-set-scan cells · pre-existing on master `bbdd4e720` · filed 2026-10-26 against master `bbdd4e720`**

Repro:

    type Node = { v: i32, next: Node | null }
    type M = Node & { v: i32 }
    const n: M = { v: 1, next: null }
    print(n.v)
    // vl check: rc 0.  vl run: emit error at 4:9, field access receiver is not a struct

Want:

    1

#### Mechanism

The intersection flattens to `Node`'s own shape, which refers to itself through `next`. The
spelling written inline at the binding gets a struct row, and the same intersection reached
through the alias `M` does not, so the read of `n.v` has no struct to read from. Without the
read the binding itself is invalid wasm.

#### Ablation

| ingredient removed or changed | outcome | needed? |
| --- | --- | --- |
| the recursion (`next: i32 \| null`) | runs, `1` | **yes** |
| the alias (`const n: Node & { v: i32 } = …`) | runs, `1` | **yes** |
| the read (`print(1)`) | check-clean invalid wasm at the binding, expected (ref null $type) | no |
| the second record (`type M = Node & Node`) | same refusal | no |
| recursion through a list (`kids: Node[]`) | same refusal | no |
| a field `Node` lacks (`Node & { w: i32 }`, `print(n.w)`) | same refusal | no |

#### Grading list

The no-read spelling (`print(1)`), which is clause 1 rather than clause 2, and the
`kids: Node[]` spelling.
