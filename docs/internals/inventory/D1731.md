### D1731 — a narrowed field read UNWRAPPED A BOX the place never held, so an un-annotated map's arm value miscompiled at the place

**closed 2026-09-06 · filed as an un-annotated carrier's missing value row, which the close
refutes: the annotation is not the ingredient, the receiver's REP is · 0 corpus cells**

Repro:

    type Q = { q: i32 }
    type U = Q | i32
    function mkQ(): Q { return { q: 5 } }
    const m = Map()
    m["k"] = mkQ()
    if m["k"] is Q { print(m["k"].q) } else { print(0) }
    // prints 5

#### Mechanism

D1719 gave the narrowed-read ladder its place receiver, and `emitMem` then routed every
narrowed place to `emitNarrowedMem`, whose whole body is `struct.get $uBox 1 · ref.cast ·
struct.get`. That is right for a receiver that IS a union box and wrong for one whose
declared type is the ARM: the cell holds the bare ref, the narrowing renames its rep rather
than changing it, and the unwrap reads a box the module never built.

The gate is `exprUnion` on the receiver, which is the pairing `narrowedArmNeedsUnbox` already
makes on the delivery side. The annotated spelling ran only because its map slot happened to
carry the box; the same program with a NON-union arm value was silent too, at the annotated
face, which is what refutes the filed reading.
