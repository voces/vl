#### Mechanism

The map value's own rep decides it, and the annotation is what pins that rep: with
`const m: { [string]: U } = Map()` the same six lines print `5`. The read at the place is
D1719's route and it is wired — `m["k"].q` under an annotated map runs — so what is missing
is the un-annotated carrier's value row, not the narrowed read.

It is the map twin of D1723, which is the same declared-versus-inferred split at the argument
boundary. Both keep the box where a consumer wants the arm, and both run the moment the union
is spelled somewhere the carrier can see.
