#### Mechanism

The lambda's result is inferred from its list literal alone, `boolean[]`, unless a rung of
`inferRetAdoptUnionElemList` (check_inferred_return.vl) adopts the contextual result. Each rung
named one element shape (value union, variant box, map union and so on); a union holding a function
arm, or a list-of-records arm, matched none, and a list never widens, so the conversion was refused.
