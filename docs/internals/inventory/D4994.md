      const q: V[] = []

#### Mechanism

Not ablated. `listDisjointDepth` answers the record pair, so the arm is entered, but
`forceListLeafRepsOfTy` (emit_collect.vl) interns the empty `Q[]` row only for a record
`structNameOfTy` names, so the arm's read has no row to be handed and refuses.
