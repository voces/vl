#### Mechanism

`forceListLeafRepsOfTy` (emit_collect.vl) interns the empty `Q[]` row only for a record
`structNameOfTy` names, so the arm's read has no row to be handed and refuses.

#### Close

`forceListLeafRepsOfTy` interns an anonymous tested record's shape and takes its row name from
`internShapeDeepOfTy`, then `ensureRefElemTy` builds its list row, and the arm's reads name it
through the type-taking `listFitArmTyOf` of [D4993](D4993.md) rather than a row looked up by
declaration.
