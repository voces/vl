### D9713 — a record literal whose field is an inline nested list of an un-annotated function has no interned shape

**loud emit reject · `vl check` rc 0 · `ref valtype with no interned shape`, no position · clause 2 · found closing [D9662](D9662.md) · present on master `e8163edd5` · filed 2026-10-22 against master `e8163edd5`**

Repro:

    function inc(a) { return a + 1 }
    const w = { f: [[inc]] }
    print(w.f[0][0](3))
    // vl check rc 0.  vl run: emit error: emitProgram: ref valtype with no interned shape

Want:

    4

#### Mechanism

Not traced. The flat twin `{ f: [inc] }` runs, which [D9061](D9061.md) closed by pinning the
field's list from its calls. The nested field has no such pin, so the field's type stays open at
a function and its list-of-lists shape is never interned. The same field initialised from a bound
`const u = [[inc]]` runs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the nesting (`{ f: [inc] }`, `w.f[0](3)`) | runs, `4` | **yes** |
| the un-annotated parameter (`inc(a: i32): i32`) | runs, `4` | **yes** |
| the inline literal (`const u = [[inc]]`, `{ f: u }`) | runs, `4` | **yes** |

#### Grading list

The field initialised by a call returning the list inline from a function with an un-annotated
parameter (`function give(_n) { return [[inc]] }`, `{ f: give(1) }`), which refuses the same way;
[D9714](D9714.md) is its flat twin.
