#### Mechanism

[D9061](D9061.md)'s close pins a field's list from the calls through the field's slot
(`f.<name>` then `e`). `monoPinFieldContainer` took that arm only for a flat list, so a nested
field kept its element open at a function and its list-of-lists shape was never interned. It now
pins the inner element at `monoSlotPath(fld, ["e","e"])`, and the same arm covers a field beside
other fields and a field inside a function body.
