### D2731 — an un-annotated `if` joining two record literals that differ in one field's type is invalid wasm

**check-clean invalid wasm · open · the `i32 \| string` field, a map field, and a union-of-maps field (D2730's un-annotated face) · identical on master · filed 2026-09-26 against master `90b63b840`**

Repro:

    function g(sel: i32) {
      const sx = if sel == 0 { { f: 1 } } else { { f: "s" } }
      const v = sx.f
      if v is string { print(v) } else { print(v + 1) }
    }

#### Mechanism

The checker types the join `{f: i32} | {f: string}`, a union of two anonymous records with the
same field name. The emitter declares the binding's cell at one arm's row and builds the other
arm's field at its own type, so the `i32` store meets a string ref. The same union as a LIST
element refuses as `cannot be discriminated — variants … have the same field name`, which is
the discrimination question this join also has to answer. The annotated spelling
(`const sx: { f: i32 | string } = …`) runs.
