### D17402 — a record literal holding `{ r: null }` in a field, beside a declared union member of that shape, has no rep

**closed 2026-11-24 by lane IR-C1 — the witness prints `true` · D17400's close for a record field: the field's slot (`sFieldTgtStructIdx`, emit_atom_kinds.vl) now takes the struct row of the one union arm a rowless record narrows to · fixture `tests/cases/structs/rowless-record-narrowed-to-arm-as-field.vl`, matrix `rowless-record-narrowed-to-arm.matrix.vl` · was loud emit reject, `vl check` rc 0, clause 2 · found ablating D17400 (lane IR-C1) · filed 2026-11-24 against master `cea354ff6`**

Repro:

    type Shape = Circle | Sq
    type Sq = { s: i32 }
    type Circle = { r: i32 | null }
    const o = { v: { r: null } }

    // vl check: rc 0.  vl run: emit error, `emitProgram: ref valtype with no interned shape`

#### Mechanism

D17400's root in a record field: the literal type `{ r: null }` has no struct row of its own,
and the one declared record it is narrower than (`recNarrowRecordOf`), `Circle`, is a union arm
with no struct row either, so the field's valtype names no interned shape. The field now takes
the arm's struct row.
