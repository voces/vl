### D9431 — a generic over an inline record parameter returned from an un-annotated function and stored in an un-annotated `Map()` has no map value slot

**loud emit reject · clause 2 · `vl check` rc 0 · CAPABILITY: the generic stored directly runs · found closing [D9381](D9381.md) · present on master `3a918d6cc` (as `ref valtype with no interned shape`) · filed 2026-10-21 against master `3a918d6cc`**

Repro:

    function pick<T>(r: { k: T }): T { r.k }
    function deliver() { return pick }
    const m = Map()
    m["k"] = deliver()
    const mv = m["k"]
    if mv != null {
      const v = mv
      print(v({ k: 4 }) + 1)
    }
    // vl run: emitProgram: unsupported map value type (no rep for a union-member struct, a nullable list over an unnamed element rep, or a nullable litunion-result closure; any other value type here interned no mv slot)

Want:

    5

#### Mechanism

Not traced. Before D9381's close this refused as `ref valtype with no interned shape`: the
instance spelled its record parameter with the pin's spacing. With that fixed, the map's value
type, fixed only by the read's call through `deliver`'s return, still interns no mv slot.
Stored directly (`m["k"] = pick`), the same map runs and prints `5`.
