### D9431 — a generic over an inline record parameter returned from an un-annotated function and stored in an un-annotated `Map()` has no map value slot

#### Mechanism

Past `deliver`'s return, the flow table pins `pick`'s parameter as the inline record
`{k: i32}` rendered with a space after each colon. `monoSlotPinName` and `monoStoredSlotFnTy`
copied that text into a function type, and `nameToTy` does not parse the spaced spelling. The
instance's annotation and the map slot's type both came back open, no mv slot was interned, and
`Map()` refused. Stored directly (`m["k"] = pick`), the store itself typed the slot, so the
spelling was never read.

The fix: `monoSlotPinAnn` respells a brace pin through `monoPinShapeSpell`, the spelling the
record's shape is interned under. Both the returned-generic instance and the stored slot read
it. [D9430](D9430.md) is the function-parameter twin.
