#### Mechanism

`i32 | null` is repped here as a value-union box, `(struct (field i32) (field anyref))`. In
the `while` body the local `q` is collected with the box valtype — `(ref $1)` in the
disassembly — while `emitExpr` lowers `v ?? 0` to the unboxed `i32` the narrowing recovered,
so the `local.set` pushes an i32 into a ref slot. The `if` spelling of the same body agrees
about both halves and runs, which is what makes this the loop narrowing's own gap rather than
the coalesce lowering's: `setNarrowFromCond`'s loop consumer is restricted
(`narrowStripNullOnly`) and the binding classifier never sees the strip.
