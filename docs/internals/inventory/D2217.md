### D2217 — an un-annotated generic `if` returning a scalar list builds its blocktype as `i32` at a scalar pin

**check-clean invalid wasm · found by the review of #3069 · filed 2026-09-23 against master `327b15510`**

Repro:

    function pick<T>(c: boolean, x: T) { if c { [x, x] } else { [x] } }
    print(pick(true, 3).length)
    // vl check: rc 0.  vl run: invalid module inside `pick`, `expected i32, found (ref $type)`

#### Mechanism

Not yet ablated. No empty `[]` is involved. The same body at `T = string` runs and prints
`2`, and so does the annotated return `: T[]` at `T = i32`. So does a tail with no join
(`function one<T>(x: T) { [x] }`). Only a join at a scalar pin builds the list arms under an
`i32` blocktype. The `T = f64` pin and the `match` spelling fail the same way.

#### Grading list

`T = f64`, and `function pick<T>(k: i32, x: T) { match k { 1 => [x, x], _ => [x] } }` at
`T = i32`.
