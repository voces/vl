### D2825 — an if-expression whose arm yields another `if`'s prelude local, or whose join is a generic instance's list, is classified at i32

**closed 2026-09-27 — the witness prints `5` · was check-clean invalid wasm (`type mismatch: expected i32, found (ref $type)`), clause 1, at a binding initializer and a `return` on master, and at every other position once D2785 lowered the arm (15 cells the #3215 review found loud on master and invalid on its first head) · filed 2026-09-27 against master `cf6d7f102` · fixtures `tests/cases/conditionals/if-arm-nested-local-join.vl`, `tests/cases/generics/if-arm-nested-local-generic.vl`**

Repro:

    type P = { a: i32 }
    function f(c: boolean, d: boolean): P {
      return if c { if d { const x: P = { a: 5 }; x } else { { a: 7 } } } else { { a: 6 } }
    }
    print(f(true, true).a)
    // vl check: rc 0.  vl run: invalid module inside `f` — expected i32, found (ref $type)

#### Mechanism

A join is classified from its arms' tail values before any arm lowers. Three readers could not
see a tail that is a local of an arm's own prelude. The emit-time scope that D2821 opens bound
only the top-level arms, so an inner `if`'s arm locals were never bound. A module global's cell
is classified outside any scope. And in a generic instance, a list join refused its arms'
answer (`listRepGateAdmits`' `if-join` gate), so it fell to i32 even with no prelude at all.
The close:
- `armPreludeBind` recurses into an arm whose value is an `if`.
- The arm-tail readers (`armTailValue`) see an unbound prelude local through to its initializer.
- The monomorphizer pins through a nested tail.
- An if-join whose recorded type holds a type variable answers its arms' list rep, which also closes D2272.
