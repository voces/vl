### D9912 — a lambda over a hole's `??` binding at a never-null pin computes at the pin where its result is the join's

**check-clean invalid wasm · clause 1 · `vl check` rc 0 · the binding read without the operator, `() => r2`, prints `4` · found closing [D9870](D9870.md) · present on master `8700f0727` · filed 2026-10-22 against master `8700f0727`**

Repro:

    function take(a) {
      const r2 = a ?? 0.5
      const f = () => r2 + 2
      print(f())
    }
    const z: i64 = 4
    take(z)
    // vl run: the emitted module failed to validate inside `__lambda_1`: type mismatch: expected (ref $7), found i64; $7 is `union box`

Want:

    6

#### Mechanism

Not traced. The lifted lambda's result is the join the checker typed (`i64 | f64` at an `i64`
pin, `f64` at an `i32` one), but its body reads the captured binding at the pin's scalar and
computes the operator at that width. [D9870](D9870.md)'s close gives the instance's own
operators and result the join; the lambda's are separate.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `() => r2`, no operator | runs, prints `4` | **yes** |
| the pin `i32` | `expected f64, found i32` inside `__lambda_1` | no |
| the lambda inlined, `print(r2 + 2)` | runs, prints `6` | **yes** |

#### Grading list

The `i32`, `i64` and `f64` pins, the operators `- * <`, and the lambda returned from `take`.
