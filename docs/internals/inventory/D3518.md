### D3518 — a generic's `U[]` pinned by a callback result of a mixed-width literal union has no list element row

**loud emit reject · clause 2 · open · found by lane LU's `std:array` sweep for the #3340 review · the same on master `878f6ebe8` · filed 2026-10-03 against master `878f6ebe8`**

Repro:

    type D = 9000000000 | 1
    function mi<T, U>(self: T[], f: (T) => U): U[] {
      const out: U[] = []
      out.push(f(self[0]))
      out
    }
    const a: D[] = [9000000000, 1]
    print(mi(a, (x: D) => x)[0])
    // vl check: rc 0.  vl run: "emitProgram: a ref list's element row does not resolve"

Want:

    9000000000

#### Mechanism

Not confirmed. The instance's `U[]` is a list of the `D` box, and the ref-list element row is
looked up by a name that the alias `D` (a literal union) does not register under, while
`T[]` pinned to the same `D` resolves. `std:array`'s `mapIndexed` is the shipped spelling.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `type D = i32 | i64` | runs, `9000000000` | **yes** (a literal union) |
| no `T[]` parameter, `mi<U>(f: () => U)` with `(): D => 9000000000` | runs | **yes** (two type parameters) |
| the lambda annotated `(x: D): D => x` | still refuses | no |
| `mapIndexed(a, (x: D, i: i32) => x)` from `std:array` | still refuses | no |

#### Grading list

`mapIndexed` at `D` with the narrow and the wide member; the all-`i32` and all-`i64` sets.
