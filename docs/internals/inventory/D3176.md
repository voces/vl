### D3176 — a hole callee parameter whose argument is a module-scope function value is called at the first instance's `i32` result, so `true` prints as `1`

**check-clean silently wrong · clause 1 · found by the #3283 review (`rv3283-3186/w/p1.vl`, `p5.vl`) · the same on master `934f169f4` · filed 2026-09-29 against master `934f169f4`; possibly D3167's mechanism**

Repro:

    function F(g) {
      print(g())
    }
    const c0 = () => 7
    F(c0)
    const c1 = () => true
    F(c1)
    // prints 7, then 1

Want:

    7
    true

#### Mechanism

Not localised past the ablation. `() => i32` and `() => boolean` share a wasm signature, and the
second call's result is printed at the first's `i32`. Inline lambda arguments are told apart,
bindings are not. This may be D3167's mechanism (one instance serving two signatures of the same
wasm type) reached without an intermediate generic; grade both rows on either close.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `F(() => 7)`, `F(() => true)` inline | prints `7`, `true` | **yes** (the binding argument) |
| `c1` a `(): "a" \| "b" => "a"` | prints `7`, `0` | no (the literal-union face) |
