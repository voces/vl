#### Mechanism

`cwEscapedFields` records the container-field edge (`{ xs: b }` puts a list inside a struct and
`bx.xs` takes it back out) keyed by the container's BINDING NAME plus the field name, and guards
it with `cwBoundOnce(nm)` — "is `nm` bound exactly once in the whole program and never assigned?"
That guard is a COUNT over `P.nodes`, not a scope lookup, so a binding of the same name in an
unrelated function makes it answer false, the pair is never recorded, the alias closure never
sees the escaped handle, and D852's soundness refusal is not raised. Unlike D1609 the ingredient
is not arena ORDER — the decoy refuses identically above and below `f` — it is the count, which
is why this is a separate row rather than the same fix.
