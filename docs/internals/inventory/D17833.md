### D17833 — a hole parameter reading a map whose storage holds a tagged set's ids is instanced as if the map held closures

**closed 2026-11-28 · runs, prints `4` `4` · fixed in ir_build.vl: a tag dispatch arm's member result is typed by the rep its signature gives (`tagArm`), not by the arm node's own type, which an instance types at the dispatch's joined result; one reader for both scopes · pins `maps/tagged-set-map-read-in-a-hole-parameter-called.vl` (the read called, bound, and at a float) · D17813's two spellings stay loud refusals, case (iii) below · was loud emit reject, `internal compiler error: … verifier rule 3 (v8's rep is not its type's)` · clause 1 (`vl check` rc 0) · owner I8-PREP · filed 2026-11-28 against branch `cov-clos-d17820` (568a1ca71) by COV-CLOS-3, moved out of [D17820](D17820.md)'s grading list (COV-IS's spelling (c))**

Repro:

#### Mechanism

Not an instance key (traced by I8-PREP, 2026-11-28). The module-level `t(3)` tags the set
`{g, dbl}`, and `walk`'s instance is keyed `?walk.0={[string]: (_) => _}#8#14`: the tagged set's
own type is that open function type, so keying `walk` by `m`'s storage gives the same key. The
failing variable was the dispatch arm's temp for `g(3)`: rep `i32`, the member instance's
signature result, typed `f64`, because `tagArm` typed it by `exprTyOf(arm)` and an instance types
the arm node at the dispatch's joined result. The arm's value is now typed by the rep its
signature gives, then converted to the call's type as before; at module scope the two already
agreed. The reader is not one of [D17825](D17825.md)'s `identDeclOf` classes.

#### Case (iii): the open-storage spellings

With no module-level call, the set is not tagged and `g`, a hole lambda called only through
`walk`'s read, takes its signature from that read's pin alone: `m`'s storage is open at its
writes, so no storage decides `walk`'s instance (coordinator ruling: a slot is decided by its
stored values, never by a read's pin). The outcome is one instance and the loud
`convert map -> map`, no trap, pinned as expected refusals. This is a capability gap (clause 2),
not a design refusal. Candidate mechanism for later: an untagged set's map storage is closures,
and an open hole lambda written into it is instanced at the signature the slot's calls give it,
the per-width lift at a map write, with `walk` keyed by type alone. Owner COV-CLOS-3, after D17832.
