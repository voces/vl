### D16963 — [CLOSED 2026-11-18] a union of a numeric list and its literal twin binds no type parameter at a generic list parameter

**closed 2026-11-18 · now a loud check reject, the refusal the design owes; was a loud emit reject · clause 1 · fixed in check_calls.vl: `openArgTyParamRefused` no longer exempts a one-list union, since no one `T` is accepted for both members (a list never widens: `first<i32>(q)` and `first<K>(q)` are refused alike) · fixtures `tests/cases/generics/error-union-of-twin-lists-leaves-type-param-open.vl`, `union-of-twin-lists-copied-binds-type-param.vl` · its `as!` advice runs since [D16966](D16966.md)'s fix · found closing [D16959](D16959.md) · filed 2026-11-18 against master `0b8c7beb2` by lane F1**

Repro:

    function first<T>(xs: T[]): T { return xs[0] }
    type K = 1 | 2
    const q: i32[] | K[] = [1, 2]
    const b: boolean = first(q)
    print(b)
    // vl check: cannot infer type parameter `T` in this call to `first`: its argument is `i32[] | K[]`

#### Mechanism

`i32[] | K[]` over a numeric literal union `K` is one list (`oneListUnionRender`, D4743), so
D16959's refusal left it alone. The call still binds no `T`, so its result `T` fits `boolean`,
and monomorphization, handed the union, has no list to bind `xs` at. Binding `T` at the one list
does not serve: the checker accepts neither member as the other's list (`f(xs: i32[])` refuses
`q`), so `T = i32` would let the body write an `i32` into a `K[]`. The call is refused instead.
Whether such a call should instead run once per member is [D2772](D2772.md)'s open ruling, and
covers this union as it does `string[] | i32[]`.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `q: K[]`, one list type | check refuses `K` into `boolean` | **yes** (the union) |
| `K` spelled inline, `i32[] \| (1 \| 2)[]` | the same | no |
| `print(first(q))`, no destination | check clean, the same emit reject | no (the clause-1 half needs a destination) |
| `n<T>(xs: T[]): i32`, `T` not in the result | check clean, the same emit reject | no |
| `string[] \| K[]` over a string literal union | refused at check (D16959): not one list (D4906) | **yes** (a numeric twin) |
