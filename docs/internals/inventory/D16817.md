### D16817 — a maker called at a wider pin whose result nothing calls, then at a narrower pin that is called, builds the lambda at the wider pin only

**open · check-clean invalid wasm · clause 1 (`vl check` rc 0, no diagnostic) · the unbound neighbour of [D16815](D16815.md) · filed 2026-11-16 against master `fae99e93f`**

Repro:

    function adder(n) { return () => n }
    adder(2.5)
    const w = adder(5)
    print(w())
    // vl check: rc 0.  vl run: invalid module, `__lambda_1`: type mismatch: expected i32, found f64

Want:

    5

#### Mechanism

Not traced. The two maker calls pin `n` at `f64` and at `i32`. Only the second call's result is
called, yet the module holds one lambda, built at the first call's `f64` pin, and the call
through `w` reads it at the `i32` signature its binding was typed at.
