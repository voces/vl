Repro:

    function run(fs) {

#### Mechanism

From the ablation only. `ls` takes a type from the calls through its own elements
(`monoPinListElems`, by the flow table's element-slot pins); a call through `run`'s parameter
gives it none, so the binding keeps its open element type.
