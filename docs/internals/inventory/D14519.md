### D14519 — a call stored into a record literal's field keeps its record at its own row while another call of the same function delivers it as a declared record

**closed · now runs, prints `5` / `4` · was check-clean invalid wasm, clause 1 · filed 2026-10-27 against master `76227d1d5`, closed 2026-10-27 against `7480d5bae` · closed by `recStoreDeclOf` naming an un-annotated record literal binding as the container of its field values and of `w.f = v`, and `recStoresAgree` building that record field by field; `recBuiltReadRefuse` refuses a read of any built container handed on at its own type · fixtures `objects/unannotated-record-call-field-built-at-wider-record.vl`, `soundness/built-container-read-handed-on-at-own-type-runs.vl`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const w = { a: mk() }
    print(w.a.f + 1)
    print(wideJ.f ?? 0)

Want:

    5
    4

#### Mechanism

`const wideJ: J = mk()` builds `mk`'s record at `J`. [D14518](D14518.md) and [D14509](D14509.md)
serve a second call stored into an un-annotated list or `Map()`: the container is built where its
stored values are (`recStoresAgree`). A record literal's field is not such a container
(`recStoreDeclOf` answers -1), so `{ a: mk() }` keeps `mk`'s own row in field `a` and `wideJ`
receives the record as `J`. Both seeds fail validation on line 3.

#### Close

A record literal binding is the same container as a list or map: its field values, and the
values `w.f = v` stores, count as its build, and the record is built with each such field
retyped to its stored values' build. A later `w.a = other()` whose value is not built there
refuses at its own row, as a list store does.

Building any container opens a read path the checker types at the container's own type: on
`7480d5bae`, `g(xs[0])` with `g(r: { f: i32 })`, `hs(xs)`, and `g(m.get(1) ?? { f: 0 })` were each
check-clean invalid wasm. `89cf95adb` refused all three; `76227d1d5` moved the map read, and
`7480d5bae` the two list reads. `g(w.a)` and `h(w)` would have joined them. Each own-storage
delivery of a built container, or of an element or field read out of it, now refuses at the read,
a clause-2 floor filed open as [D14532](D14532.md).

The generic spelling from this row's grading list is filed as [D14530](D14530.md), and a list
literal read without a binding as [D14531](D14531.md).
