### D16859 — a list of un-annotated functions of different result types held below the top of a generic's argument is refused at emit

**loud emit reject · clause 2 (`vl check` rc 0) · the residue of [D16839](D16839.md): the same nesting with two result types · refused before D16839 too · filed 2026-11-16 against master `06f1673d5`**

Repro:

    function id(x) { return x }
    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const r = id({ l: [inc0, half] })
    print(r.l[1](3))
    // vl check: rc 0.  vl run: emit error, `monomorphize: unsupported argument type for `x` in a call to `id``

#### Mechanism

Not traced. D16839's pin closes the argument at the type its place classes close; a list whose
functions return two types has no one closed element type, so `eplValueTy` leaves it open and no
rung pins the argument. The same list handed as the argument itself runs, as a tagged set.
