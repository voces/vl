### D17171 — a hole function's nested field read with `?.` inline off a maker call emits no module

**loud emit reject · check-clean, claimed and claimless alike · clause 2 · filed 2026-11-24 against master `3ede426f5` by lane IR-N2 (found while probing D17163's optional spellings)**

Repro:

    function inc0(a) { return a + 1 }
    function mk(f) { return { r: { f: f } } }
    print(mk(inc0).r?.f(3))
    // vl check: rc 0.  vl run: "emitProgram: object literal field count does not match struct" (rc 1), claimed and claimless alike

    4

#### Mechanism

Not established. The refusal is legacy's (the claimless compiler refuses identically), and the
ablation below bounds the family: a function with an un-annotated parameter, stored by a maker whose
record type is inferred, read through a nested or optional field.
