### D10351 — an `is` test of an element read straight off an unbound `.map` result of a union is refused at emit

**closed 2026-11-14 · runs, prints `true` · was a loud emit reject, clause 2, `emitProgram: .map/.filter scratch frame not reserved` · closed by descending into a test, a conversion and a match in the scratch-frame scan (`mfScan`, `emit_collect.vl`) · found closing [D10290](D10290.md) · filed 2026-10-22 against master `a72f9a7fe`**

Repro:

    function f(k: i32, a: i32, b: string): i32 | string {
      if k == 0 { return a }
      b
    }
    print([1].map((i) => f(0, 7, "s"))[0] is i32)
    // vl check: rc 0.  vl run (before the close): emit error, `emitProgram: .map/.filter scratch frame not reserved`

Want:

    true

#### Mechanism

The scratch-frame scan (`mfScan`) reserves a frame for every `.map`/`.filter` call it reaches, and
the emitter asks for one at each call. The scan treated an `is` test, an `as` conversion and a
`match` as leaves, so a call inside one of them was emitted with no frame; a bound receiver ran
only because the call then sat in a `const`, which the scan reaches. The scan now descends into
the test's and the conversion's operand and into the match's scrutinee and arm bodies.
