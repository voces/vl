### D9182 — a `let` map or record of un-annotated functions reassigned with a fresh literal is not pinned

**loud emit reject · `vl check` rc 0 · `emitProgram: ref valtype with no interned shape` · clause 2 · found closing [D9101](D9101.md) · present on master `cc73e3543` · filed 2026-10-21 against master `cc73e3543`**

Repro:

    function inc0(a) { return a + 1 }
    const hm = Map()
    hm["k"] = inc0
    let v = { m: hm }
    v = { m: hm }
    const x = v.m["k"]
    if x != null { print(x(3)) }
    // vl check rc 0.  vl run: emit error: emitProgram: ref valtype with no interned shape

Want:

    4

#### Mechanism

Not traced. D9101 pins a `let` like a `const` only when each write stores a read of a
binding already typed at the pinned type (`monoLetWritesClosed`, emit_mono.vl). A write of a
literal has no type until it is pinned too, so the binding declines. The map spelling
(`let m = Map()`, `m = Map()`, then writes and reads of `m`) fails with
`unsupported map value type`.
