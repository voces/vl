### D6885 — a record field holding a written `let`'s first uncalled function, called through the field, is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: with no write `r.f(add)` runs; the hole function and its `<F>` twin refuse alike · found closing [D6830](D6830.md) · the same on master `cbd8ffec5` · filed 2026-10-18 against master `cbd8ffec5`**

Repro:

    function apply3(g) { print(g(1, 2)) }
    function apply4(g) { print(g(3, 4)) }
    function add(a: i32, b: i32) { a + b }
    let h = apply3
    const r = {f: h}
    h = apply4
    r.f(add)
    // vl check: rc 0.  vl run: emitProgram: a function-value call has no interned signature — parameter 1 of type `` has no representation in the function-value ABI

Want:

    3

#### Mechanism

From the ablation only. The written-binding passes instance `h` at the write's value; the copy
the record took before the write is called at a type nothing instanced, so the call through
`r.f` has no signature to intern.
