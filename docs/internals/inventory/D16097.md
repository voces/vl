### D16097 — a record field written with un-annotated functions whose results differ, handed to a generic `(x: T) => R` parameter, builds an invalid module

**closed 2026-11-14 · runs, prints `s` · was check-clean invalid wasm · clause 1 · `vl check` rc 0 · `the emitted module failed to validate inside \`app\`: type mismatch: current function requires result type [(ref $9)] but callee returns [i32]` · the field twin of [D16093](D16093.md) · found grading D16093 · filed 2026-11-14 against master `84b0f334c` · fixed with [D16093](D16093.md): the field's set is tagged at its delivery and the instance's call dispatches · residue [D16098](D16098.md), [D16099](D16099.md) · fixtures `closures/set-element-and-field-handed-to-generic-fn-param.vl`**

Repro:

    function inc(a) { return a + 1 }
    function str(_a) { return "s" }
    function app<T, R>(g: (x: T) => R, v: T): R { return g(v) }
    function run(c: boolean) {
      const o = { f: inc }
      if c { o.f = str }
      print(app(o.f, 3))
    }
    run(true)
    run(false)
    // vl run: prints `s` and `4`

Want:

    s
    4

#### Mechanism

Not ablated to a line. The checker types `app(o.f, 3)` as the members' join (`i32 | string`), so
`app` is instanced with `R` the join. The instance's call `g(v)` returns the `i32` of one member's
signature where its result is the join's box. A list element in the same position is refused at
emit instead (D16093), and a choice runs.

#### Ablation

| witness | runs, prints `s` / `4` (was invalid module) |

| `if c { str } else { inc }` handed instead | runs, prints `s` / `4` |
