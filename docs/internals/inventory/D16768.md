#### Mechanism

The witness is `tests/cases/closures/maker-result-called-in-place.vl`, trimmed. Mono's pin
readers ask what a slot is delivered at during mono: `monoDeclPathKeysIn`, `monoPinFnParamTys`,
`monoFlowSlotPins` and `monoSlotDeliveryTy`, and the lambda readers `monoLamParamPinAnn`,
`monoLamPinRetAnn`, `monoPinLamAtDelivery`, `monoPinNoteReachLets` and `monoPinOpenCallLams`.
The delivery walk (`elabSlotDeliveries`) answers them, reading tables the emit rewrite fills,
such as `lvExitLoops`. Read from the place classes instead, `q`'s class held no call.

The classes are not rebuilt during mono: `eplBuild` runs at or before the end of the
elaboration. The cause is engine gaps, cases the walk reaches and the classes do not. Here it is
the value `break @B other` hands to its labelled block: it reached the block only through
`lvExitLoops`, which the loop rewrite fills after the classes are built. In all, 8 of 7,811
`tests/cases` programs failed to build and 10 changed bytes.

The coordinator's ruling: the classes never read a table the emit rewrite fills; each gap closes
by an engine rule drawn from the checked tree, graded by `tests/cases` byte identity; then the
elaboration fills a pin table that mono reads and never re-derives.
