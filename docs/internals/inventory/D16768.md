#### Mechanism

The witness is `tests/cases/closures/maker-result-called-in-place.vl`, trimmed. Mono's pin
readers (`monoDeclPathKeysIn`, `monoPinFnParamTys`, `monoFlowSlotPins`, `monoSlotDeliveryTy`, and
the lambda readers `monoLamParamPinAnn`, `monoLamPinRetAnn`, `monoPinLamAtDelivery`,
`monoPinNoteReachLets`, `monoPinOpenCallLams`) ask what a slot is delivered at during mono. They
ask while the flow rewrite is repointing reads such as `q`'s callee. The delivery walk
(`elabSlotDeliveries`) re-reads the live program at each ask, so it tracks those rewrites.

The place classes are built once. Read from them, `q`'s class held no call, so mono refused the
generic `other` as a value. In all, 8 of 7,811 `tests/cases` programs failed to build and 10
changed bytes. Building the classes before mono for every compile did not close it. The
coordinator's ruling: the target is an elab-time pin table that mono reads and never re-derives;
invalidating the classes on each rewrite is the wrong shape.
