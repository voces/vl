### D5611 — a generic handed to an un-annotated parameter that is called at two signatures has no single instance

**loud emit reject · `vl check` rc 0 · clause 2 · found closing [D5402](D5402.md) · filed 2026-10-17 against master `7fe51e77c`**

Repro:

    function same<T>(k: T): T { k }
    function take(a) {
      print(a("x"))
    }
    function take2(a) {
      print(a(3))
    }
    function mid(a) {
      take(a)
      take2(a)
    }
    mid(same)
    // vl check: rc 0.  vl run: emitProgram: a function-value call has no interned signature — the callee has no function type to key a signature from

Want:

    x
    3

#### Mechanism

From the ablation only. A function value carries one signature, and `mid`'s hole is reached by
pins at two, `(string) => string` and `(i32) => i32`. With one pin the hole is instanced at it
(D5402's close); with two there is no single pin and the forwarded value stays open. Whether
the hole should be instanced once per pin (one `mid` per signature) or the program refused at
`vl check` is the question this row carries; until then it is a clause-2 violation.
