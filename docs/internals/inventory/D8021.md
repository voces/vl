### D8021 — a record literal handed through a generic identity into a union of a wider record is invalid wasm

Repro:

    type J = { r: i32 | null }
    function idn<T>(v: T): T { v }
    const u: J | string = idn({ r: 4 })

#### Mechanism

The literal's re-seat at the destination reads the union member (`recLandingOf` in
`check_fit_rules.vl`), so the literal is built as `J`. The emitter took `idn`'s instance from
the argument's record name, and a union member's row lives in `uVariants`, not the record
table, so the instance was `idn<{r: i32}>` and its result was boxed as a non-member. Closed by
a rung in `monoArgTyNameRep` (`emit_mono.vl`): an object-literal argument whose `nodeRepTyIx`
is a variant row pins that row's name. The `generic-identity-literal-into-record-union` matrix
goes from 28 to 62 of 62 graded cells running, with 0 silent and 0 runs→not-runs. Its one other
cell, `array_element_place` annotated, is [D8145](D8145.md) and is skipped. The same delivery
beside an instance at the literal's own row is [D8203](D8203.md).
