#### Mechanism

The literal's re-seat at the destination now reads the union member (`recLandingOf` in
`check_fit_rules.vl`), so the literal is built as `J`. The emitter still takes `idn`'s
instance from the argument's record name, and a union member's row lives in `uVariants`, not
the record table, so the instance is `idn<{r: i32}>` and its result is boxed as a non-member.
A rung in `monoArgTyNameRep` (`emit_mono.vl`) closes it. The rung names an object-literal
argument by its variant row, `monoAnnPinName(uVariants[variantRowOfTy(nodeRepTyIxOf(arg))])`.
Measured with that rung, the `generic-identity-literal-into-record-union` matrix goes from 28
to 63 of 64 cells running, with 0 silent; the remaining cell is [D8145](D8145.md).
