### D8021 — a record literal handed through a generic identity into a union of a wider record is invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · open · present on master `981320f30` with or without a declared record of the literal's fields · found grading [D7941](D7941.md) · owner lane S5 · filed 2026-10-20 against master `981320f30`**

Repro:

    type J = { r: i32 | null }
    function idn<T>(v: T): T { v }
    const u: J | string = idn({ r: 4 })
    if u is J { print(u.r ?? 0) }
    // vl check: rc 0.  vl run: invalid module, "expected (ref null $type), found (ref $type)": a union box expected, the literal's own row found

Want:

    4

#### Mechanism

The call's instance is taken at the literal's own record, and the union delivery boxes the
result as it would a `{r: i32}`, which is not a member of `J | string`. The literal's re-seat
at the destination (D7941) reads only a record destination, so a union never reaches it.

#### Ablation

| change | outcome | needed? |
| --- | --- | --- |
| `const u: J | string = { r: 4 }` | prints `4` | **yes**, the type parameter |
| `J`'s field `r: i32` | prints `4` | **yes**, the field stored differently |
| `const u: J | null = idn({ r: 4 })` | prints `4` | **yes**, a union of two members |
| `J | Z` with `type Z = { q: string }` | invalid wasm | no |
| `type Col = { r: i32 }` declared | invalid wasm | no |

#### Grading list

The `J | Z` record-union spelling, and the same through `const s = idn({ r: 4 })` then
`const u: J | string = s`.
