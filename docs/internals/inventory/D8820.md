### D8820 — a type-parameter write into a field, list element or module global of a several-member or number-literal nullable union keeps the template's read

**check-clean silently wrong · clause 1 · open · the residue of [D3446](D3446.md), whose close covers a function's own local · identical on master `3f8abb772` · filed 2026-10-21 against master `3f8abb772`**

Repro:

    type R = { s: string | i32 | null }
    function g<T>(x: T, r: R) {
      r.s = x
      print(r.s == null)
    }
    const v: string | i32 | null = null
    g(v, { s: 1 })
    // PRINTS false

Want:

    true

#### Mechanism

`tvNameWrite` (`check_leaf_steps.vl`) gives a local the pin's `HD_TVW` read over any nullable
union, because the emitter re-reads a written local at its pin (`monoPinRetype`, Ident reads
only). A field, a list cell and a module global go through `tvPlaceWrite`, which still declines a
several-member or number-literal union: admitting them there sent `??` over the place a box
while its read landed at the member, invalid wasm or an emit reject at every such place. So the
template's non-null narrowing after `r.s = x` stands, and a nullable pin folds `r.s == null` to
`false`. The close needs the emitter to retype a Field, Index and global read at the pin as it
retypes an Ident.
