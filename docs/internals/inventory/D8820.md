### D8820 — a type-parameter write into a field, list element or module global of a several-member or number-literal nullable union keeps the template's read

**closed 2026-10-21 · runs, prints `true` · was check-clean silently wrong · clause 1 · `tvPlaceWrite` (`check_leaf_steps.vl`) gives every place the pin's `HD_TVW` read over any nullable union, and an instance's re-readable list cell takes the `??` null test (`emitCoalesceNullableRefs`, `wasmEmit.vl`) · pin: `tests/cases/generics/type-param-write-union-place-reads-at-pin.vl` · matrices `type-param-write-several-member-{field,element,global}` and `type-param-write-number-litunion-{field,element,global}` · the residue of [D3446](D3446.md), whose close covers a function's own local · identical on master `3f8abb772` · filed 2026-10-21 against master `3f8abb772`**

Repro:

    type R = { s: string | i32 | null }
    function g<T>(x: T, r: R) {
      r.s = x
      print(r.s == null)
    }
    const v: string | i32 | null = null
    g(v, { s: 1 })
    // PRINTS false

Want:

    true

#### Mechanism

`tvPlaceWrite` (`check_leaf_steps.vl`) declined a several-member or number-literal union at a
field, a list cell and a module global, so the template's non-null narrowing after `r.s = x`
stood and a nullable pin folded `r.s == null` to `false`. Admitting them is enough for a field
and a global, whose reads the pin already retypes. A list cell's `??` reaches the pin typed at a
box that the concrete spelling's desugar (`emit_rewrite.vl`) never saw, and refused "`??` over
this nullable value is not supported yet"; at a pinned instance it now takes that desugar's null
test (`coalNullTestIf`).

#### Ablation

| ingredient changed | outcome | needed? |

| the place is a local `let s` | prints `true` (D3446) | **yes** (a non-local place) |
