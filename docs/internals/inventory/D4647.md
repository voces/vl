### D4647 — a generic-typed comparator passed through a lambda to `sorted` in a generic body is refused at emit

**closed 2026-10-14: runs, prints 1 · was a loud emit reject with `vl check` rc 0, clause 2 · found closing D4032 (L2 stage 4) · filed 2026-10-14 against master `147ef9a87`**

Repro:

    import { sorted } from "std:array"
    function h<T>(xs: T[], lt: (a: T, b: T) => boolean): T {
      const k = (ys: T[]) => sorted(ys, lt)[0]
      k(xs)
    }
    print(h([3, 1, 2], (a, b) => a < b))
    // vl check: rc 0. vl run: emitProgram: monomorphize: unsupported argument type for
    // `less` in a call to `sorted`

Want:

    1

#### Mechanism

`monoArgFnTypeName` (`compiler/emit_mono.vl`) names a function-typed argument by its node
type's name. Inside a lambda in a generic body, `lt`'s type is `(a: T, b: T) => boolean`,
which rides the instance's `T` and has no name, so the argument fell through to the lifted-
callback arms, found no lifted function, and the call refused. The type pinned at the
instance, `(i32, i32) => boolean`, was never asked for.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the lambda (`sorted(xs, lt)[0]` directly in `h`) | runs, prints 1 | **yes** |
| the comparator (`ys.reverse()[0]` in the lambda) | runs | **yes** |
| the lambda parameter (`() => sorted(xs, lt)[0]`, capturing `xs`) | still refuses | no |
| the captured comparator (an inline `(a, b) => lt(a, b)`) | runs | **yes** |
| a captured comparator for a passed one (`k(xs, lt)`, `f` a parameter of `k`) | still refuses | no |

So the ingredient is a function-typed name whose type rides `T`, read inside a lambda in a
generic body and passed to a generic callee's function-typed parameter.

#### Close

`monoArgFnTypeName` now names such an argument by its type pinned at the instance
(`monoExactPinTyOf`), when that type no longer holds a type variable. The witness, the
captured-only spelling, the passed-parameter spelling and the `i32`, `f64` and `string`
instances run: `tests/cases/generics/lambda-comparator-into-generic-call.vl`. The spelling
with an un-annotated lambda parameter, `(ys) => sorted(ys, lt)[0]`, refuses on `self`
instead, and is D4661.
