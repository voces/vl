### D3941 — a reassigned let written with an if-expression of generic functions traps

**closed 2026-10-13 by lane SC · runs · was loud emit reject · pins: `tests/cases/closures/written-let-if-expression-of-generics.vl` · found in review of #3493 (`rv3493/d10`) · filed 2026-10-10 against master `00bf1871f`**

Repro:

    function ci(f: (n: i32) => void, n: i32) { f(n) }
    function inner<U>(u: U) { print("I"); print(u) }
    function other<V>(v: V) { print("O"); print(v) }
    function run(b: boolean, n: i32) {
      let k = inner
      k = if b { other } else { inner }

Want:

    O
    1

#### Mechanism

D3930 instanced each generic a write names only when the write's value is a name; an `if`
expression of generics names them only in its arms. Closed by lane SC (fn-value-flow §(f) step 3):
`monoValueNamesGenerics` reads an `if` expression whose every arm names a declared generic as
naming generics, for `monoCoerceNamedGeneric`; removing it alone restores the refusal. An arm that
is a concrete lambda is still refused (D4307).
