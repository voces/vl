#### Mechanism

The refusal names a mechanism, not a contract: a delivered value's functions are not converted
on the way. A readonly list, a record delivered at a record type, and a nullable function are
covariant positions. A value copied fresh at the destination's type could convert each function
it holds, as the literal spelling already does (`const z: readonly … = [inc]` runs and prints
`4`), so the design permits the program. A mutable list or map is passed as the same storage, and
its refusal names that contract (D17812's close split that sentence out). This arm was recorded
as "by design" in [D16296](D16296.md), but that ruling predates the per-site conversion work
(D17756, D17810, D17805), which converts a function value at its delivery site.

#### Ruling

Coordinator, 2026-11-28: no copy, since the destination aliases the source. The list and record
faces close by instancing a function per its arguments' storage rep, as mono keys an instance by
type, and adapting each element at the read through the wider type. A uniform widening call per
element, and keeping the face refused, are both refused. The same mechanism closes COV-IS's
row (a) from D17817.

#### Grading list

- A record: refused by design (coordinator ruling, 2026-11-28). A record's fields are mutable, so a
  function field's type is invariant, and VL has no readonly record field; the refusal names that
  contract (`a record's fields are mutable, so a function field's type is invariant`). The
  covariant spelling that runs is the readonly list face.
- A nullable function: runs since its own close (2026-11-28, coordinator ruling): a function
  value is immutable, so `fvaAdapt` delivers it through its function's adapter, built only where
  it is not null (`fvaAdaptNullable`, check_assignable.vl); pinned by
  `closures/nullable-fn-delivered-at-a-wider-result.vl`.
- The `@error` fixtures citing this sentence: `closures/error-fn-value-container-declared-first.vl`,
  `closures/fn-value-in-container-at-wider-type-alias.vl`, `closures/error-fn-value-in-record-delivered-to-union-arm.vl`.
