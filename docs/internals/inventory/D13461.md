### D13461 — a labelled block handing out an `if` of hole functions, bound and passed to a parameter called at two types, is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same `if` passed directly, `both(if c { inner } else { ask })`, runs ([D13360](D13360.md)) · open · `monomorphize: unsupported argument type for `f` in a call to `both`` · found closing [D13360](D13360.md) · filed 2026-10-25 against master `ad209bcf6`**

#### Mechanism

From the code path, not ablated to a line. D13360's plan selects a slot's argument by an arm
index only when the choice is the call's argument (`fsChoiceArgStmt`, fn_split.vl). Here the
argument is an identifier bound to a labelled block, so the plan sees a `const` carrying one
function value and has no arm to hand each per-type slot.
