### D9880 — a nullable-list result of a call through an indexed or returned function value refuses when compared with `null`

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same call through a `const` bound to the element runs, and a `string | null` result runs · found closing [D9781](D9781.md) · present on master `ba2918226` · filed 2026-10-22 against master `ba2918226`**

Repro:

    const xs: ((x: i32) => f64[] | null)[] = [(x: i32): f64[] | null => [1.5]]
    const a = xs[0](1)
    if a != null { print(a.length) }
    // vl run: emitProgram: bare null needs a struct-typed context

Want:

    1

#### Mechanism

Not traced. The refusal points at the `null` of the comparison, so the call's result type the
emitter reads for `a` is not the nullable list the checker gave it when the callee is an
`Index` or a `Call` rather than a name.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the indexed callee (`const f = xs[0]`, `f(1)`) | runs, `1` | **yes** |
| the list result (`string \| null`, `print(a)`) | runs | **yes** |
| the `.length` read (`print(a == null)`) | still refuses | no |
| the list of functions (`h()(1)` for `function h(): (x: i32) => f64[] \| null`) | still refuses | no |

#### Grading list

`h()(1)` for a function returning the function value; a `string[] | null` and an `R[] | null`
result; the `fn-value-named-result-map-nullable` matrix's cells that print
`bare null needs a struct-typed context` may share it.
