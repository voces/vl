#### Mechanism

The classifiers that decide a call's nullable result kind (`exprNullableList`,
`exprNulScalarListKind`, `exprNullableMap`, `exprIsNulNone`, emit_classify.vl) resolved a
function-value callee only when it was a name, through `calleeRetKindAt`. For an `Index`, a
`Member` or a `Call` callee they answered "not nullable", so `a` was bound as a non-null value
and the `null` of the comparison had no context.

#### Grading list

`h()(1)` for a function returning the function value; a `string[] | null` and an `R[] | null`
result; the `fn-value-named-result-map-nullable` matrix's cells that print
`bare null needs a struct-typed context` may share it.
