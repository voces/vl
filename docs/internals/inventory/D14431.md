#### Mechanism

The field-held tagged set serves the top-level spelling: the field keeps the set's tag rep and
the call through it dispatches to the member's instance at its own tuple. The call here sits in
the body of `f<S>`, so its tuple is `(S)` until an instance closes it. A set's tag is decided
once for the whole program, and `ftInOpenFn` leaves a set whose holder sits in a generic
function untagged. The untagged field has no pin either, since no call outside an instance
fixes its type, so the emitter refuses. The per-instance mint decides the set inside each
instance's own check, which closes `(S)` to `(string)` and tags the field.
