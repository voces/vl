### D15350 — a list literal of a list of a record of an un-annotated function, the function called at two types, is refused at emit

**closed · runs · was loud emit reject `emitProgram: ref valtype with no interned shape`, clause 2 · one call type ran · found checking D15234's mechanism against `xs[0][0] = { f: id2 }` · filed 2026-11-04 against master `9a45989d`**

Repro:

    function id1(a) { return a }
    const xs = [[{ f: id1 }]]
    print(xs[0][0].f(2))
    print(xs[0][0].f(2.5))

Want:

    2
    2.5

#### Mechanism

Not D15234's. Fn-tag plans and tags `{id1}` (`try ok`), but the module global `xs` keeps the
type `{f: (_) => _}[][]`: no row is interned for a hole function two lists deep, so the
global's valtype has no shape (`emitGlobalSection` → `fbValtypeNullable`). The one-level
list `[{ f: id1 }]` at two types runs.

#### Close

The tag stamps a held list of lists, its inner list literals and their records at a rep where
a record's tagged function field is its `i32` id (`fnTagHeldNote`, `fnTagHeldInner`). A binding
of a read of a stamped place takes that place's rep (`fnTagPlaceRep`), the list slot reads the
stamp (`letRefListSlot`), and a record written or pushed into the holder is rebuilt at its
stamped record (`ftWrittenLits`). Residue: D15356, D15357, D15358, D15359.
