### D15350 — a list literal of a list of a record of an un-annotated function, the function called at two types, is refused at emit

**open · loud emit reject · `emitProgram: ref valtype with no interned shape` · clause 2 · one call type runs · found checking D15234's mechanism against `xs[0][0] = { f: id2 }` · filed 2026-11-04 against master `9a45989d`**

Repro:

    function id1(a) { return a }
    const xs = [[{ f: id1 }]]
    print(xs[0][0].f(2))
    print(xs[0][0].f(2.5))

Want:

    2
    2.5

#### Mechanism

Not D15234's. Fn-tag plans and tags `{id1}` (`try ok`), but the module global `xs` keeps the
type `{f: (_) => _}[][]`: no row is interned for a hole function two lists deep, so the
global's valtype has no shape (`emitGlobalSection` → `fbValtypeNullable`). The one-level
list `[{ f: id1 }]` at two types runs.
