### D3219 — an immediately called lambda taking a nullable-element list, given a list literal, is invalid wasm

**check-clean invalid wasm · clause 1 · found by the #3287 split-head review (`rv3287s-4099`) as the direct twin of a hole-callee cell · the same on master `94670f728` · filed 2026-09-29 against master `94670f728`**

Repro:

    type N = 1 | 2
    print(((x: (N | null)[]) => x.length)([1, 2]))
    // vl check: rc 0.  vl run: invalid module in the top-level code: type mismatch:
    // expected (ref $type), found (ref $type)

Want:

    2

#### Mechanism

Not localised. The list literal builds at a list type other than the one the lambda's parameter
names, and nothing converts it at the call.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `(i32 \| null)[]` | the same invalid module | no (the literal union) |
| `N[]` | prints `2` | **yes** (the nullable element) |
| a named `function f(x: (N \| null)[])` | prints `2` | **yes** (the lambda callee) |
| `const xs: (N \| null)[] = [1, 2]`, passed | prints `2` | **yes** (the literal argument) |
