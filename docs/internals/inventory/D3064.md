Repro:

    type AB = "a" | "b"

    function h<W>(w: W[]) { print(w[1]) }

#### Mechanism

Not localised past the ablation. The neighbour of [D3061](D3061.md), whose close reserves the
list pair a hole local's literal needs, but here the literal is an ARGUMENT to a generic: its pin
is taken from the literal's recorded element, a hole, so `h` is cloned without the member texts
at a literal-union pin and at the `i32` list against a string or `f64` list at those pins.
