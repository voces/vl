### D2167 — a `T | "err"` result with `T` bound to an inline literal union is refused at the box's atom test

**closed 2026-10-20 by lane L1 · runs, prints `A` · was a loud emit reject, clause 2 (`emitProgram: union box atom test on a union with no recorded members`) · the instance's `T | "err"` at `T := "a" | "b"` is rebuilt as one literal set by [D7041](D7041.md)'s flatten in `substUnionRebuild` · fixture `tests/cases/generics/litunion-result-beside-type-param-bound-to-litunion.vl` · filed 2026-09-23 against master `f81d01486`**

Repro:

    function wrap<T>(x: T, fail: boolean): T | "err" { if fail { return "err" } x }
    function ka(): "a" | "b" { "a" }
    function main() {
      const r = wrap(ka(), false)
      if r == "a" { print("A") } else { print("not A") }
    }
    main()

Want:

    A

#### Mechanism

The pin binds `T` to the inline set, so the instance's result is the set plus `"err"`, minted
during emit, after the checker wrote the declarations of the hidden literal-union aliases. That
union was registered as a box with no recorded members, and `r == "a"` asked the box for the
atom's tag. A written alias for `"a" | "b"` gave the same refusal, so this was the pin's union
row, not the inline spelling. `substUnionRebuild` now flattens a rebuilt member set whose arms
are all literal sets into one literal union (D7041), which has its members.

#### Grading list

`T` bound to a written alias; `r is "a"`; `print(r)`; and `wrap(ka(), true)` reaching the
`"err"` arm. All run in the fixture.
