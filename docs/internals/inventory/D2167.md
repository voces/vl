### D2167 — a `T | "err"` result with `T` bound to an inline literal union is refused at the box's atom test

**loud emit reject · clause 2 (`emitProgram: union box atom test on a union with no recorded members`) · the same on master and on the D2150 branch · found by the #3056 review · filed 2026-09-23 against master `f81d01486`**

Repro:

    function wrap<T>(x: T, fail: boolean): T | "err" { if fail { return "err" } x }
    function ka(): "a" | "b" { "a" }
    function main() {
      const r = wrap(ka(), false)
      if r == "a" { print("A") } else { print("not A") }
    }
    main()

#### Mechanism

Not yet ablated. The pin binds `T` to the inline set, so the instance's result is the set plus
`"err"`, minted during emit, after the checker wrote the declarations of the hidden literal-union
aliases. That union is registered as a box with no recorded members, and `r == "a"` asks the box
for the atom's tag. A written alias for `"a" | "b"` gives the same refusal on master, so this is
the pin's union row, not the inline spelling.

#### Grading list

`T` bound to a written alias; `r is "a"`; `print(r)`; and `wrap(ka(), true)` reaching the
`"err"` arm.
