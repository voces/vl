### D17786 — a fresh record whose two fields hold one set at two closed signatures has no value arm, so the conversion has no instance to take

**closed 2026-11-28 by lane START-2 — the witness prints `8.5` · value arms are keyed by signature as well as site and set, so each field pins the member at its own signature · fixture `tests/cases/functions/record-set-fields-converted-at-two-signatures.vl` · was: loud emit reject · clause 2 · filed 2026-11-28 against master `870b7f9a0`**

Repro:

    function id(a) { return a }
    function two() { return { f: id, g: id, n: 3 } }
    const w: { f: (a: f64) => f64, g: (a: i32) => i32, n: i32 } = two()
    const x = two()
    print(w.f(2.5) + w.g(1) + x.f(2) + w.n)
    // vl check: rc 0.  vl build: loud emit reject (before D17777's guard: wasm trap)

Want:

    8.5

#### Mechanism

The arm table holds one arm list per (site, set), so `ftBuildValueArms` builds a value arm only
when every field holding the set closes at one signature; at two it builds none, and the
conversion's guard (`tagCloMemberFe`) refuses rather than take the member's own instance at
another signature. The close keys value arms by signature as well as site and set.
