#### Mechanism

The checker types `hole`'s result as the parameter's own type variable, so `recordInferRet`
skips it as generic and no inferred-return row exists. The monomorphizer's D2037 rung reads the
checked return at the instance's binding, but `monoBindCols` binds only the variables an
annotation names, and an un-annotated parameter has none, so the result stayed a variable and
no annotation was pinned. Return inference then classified `v` from its synthesized parameter
annotation with no nullable arm (`"str"`, a list), so the result was the non-null rep and the
body cast a null to it; a map, set or closure fell to `i32` and was invalid wasm. The close
binds each hole parameter's variable to its instance column for that rung (`monoHoleRetSubst`).
