### D3589 — a named generic helper returning a join of its two type parameters is read by its caller at the numerically widened type

**check-clean silently wrong · clause 1 · open · found by lane KJ's grid (its `helper` shape, 22 wrong cells) · filed 2026-10-03 against master `7073d9d03`**

Repro:

    function G<A, B>(k: i32, a: A, b: B) { if k == 0 { a } else { b } }
    function F<A, B>(k: i32, a: A, b: B) {
      const v = G(k, a, b)
      print(v is f64)
    }
    F(0, 2.5, 3)
    F(1, 2.5, 3)
    // vl run: true, then true

Want:

    true
    false

#### Mechanism

Not localised. `G`'s un-annotated return joins `A` and `B`, two runtime arms, which a body keeps
apart; at `(f64, i32)` the caller reads the call at `f64`, so the `i32` arm arrives widened and
`is f64` holds of it. The direct join in `F`'s own body answers right, and so does `G` with an
annotated return `A | B`.
