### D15807 — an `if` joining record literals whose function field holds un-annotated functions returning different types, handed inline to an un-annotated parameter and called through, passes check and traps at run

**runtime trap · `wasm trap: indirect call type mismatch`, `vl check` reports 0 errors · clause 1 · open · on master · found grading D15801's record if-join family (`record-fn-field-two-results.matrix.vl`, its `argument` cell traps on both seeds) · filed 2026-11-12 against master `0671904bf`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function two() { [1, 2].length }
    function take(r) { return r.f(3) }
    print(take(if two() > 5 { { f: half } } else { { f: inc0 } }))

Want:

    4

#### Mechanism

Not traced. The parameter's instance is built at one record type. The trap appears exactly when
the arm taken at run time is not the first, which fits the inline join's closure being built at
the first arm's signature while the other arm's function has another. The judge reads an
argument that is a list literal (D15802) or a binding, but not an `if`, so nothing at check
sees the two results.
