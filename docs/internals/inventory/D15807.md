### D15807 — an `if` joining record literals whose function field holds un-annotated functions returning different types, handed inline to an un-annotated parameter, is refused at check, where bound to a name first it runs

**loud check reject · `cannot store 'inc0' in 'r.f': called at (i32) it returns i32, where 'half', also stored in it, returns f64` · clause 2 · open · was a runtime trap, `indirect call type mismatch` with `vl check` clean, clause 1, whenever the arm taken was not the first · found grading D15801's record if-join family (`record-fn-field-two-results.matrix.vl`, its `argument` cell) · filed 2026-11-12 against master `0671904bf`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function two() { [1, 2].length }
    function take(r) { return r.f(3) }
    print(take(if two() > 5 { { f: half } } else { { f: inc0 } }))

Want:

    4

#### Mechanism

The parameter's instance is built at one record type, and the inline join's closure at the first
arm's signature, so a call through the other arm's function traps. Bound first, `const q = if …;
take(q)`, the same value runs. The two spellings take different routes from the checker on.

The close needs a judgment of whether the arms' results differ. That is a type fact, which a
pre-check rewrite cannot see. A hoist binding every inline record `if` argument first made every
spelling here run, but it broke [D15301](D15301.md)'s inline join of generic functions (an emit
reject), and D15719's and D15720's declared-record joins (an invalid module). Those run inline and
fail once bound, and before the check they look the same as this row.

So the judge refuses instead. `holeSlotArgJudge` (check_relate_core.vl) reads an inline `if` or
`match` argument on a field path, at any depth through forwarding parameters, and judges each
arm's function at the call. Where the call passes another parameter, its types are open while the
callee is checked. `holeOpenIfNote` leaves the parameter for after the pass, and
`holeSlotOpenIfArgs` judges it at each call site's argument types:
`cannot hand this `if` to 'r.f' inline: … bind the `if` to a name first`.

#### Ablation

| spelling | outcome |
| --- | --- |
| the witness (first arm `half`, `inc0` taken) | loud check reject (was runtime trap) |
| first arm `inc0`, `half` taken | loud check reject (was runtime trap) |
| an `else if` chain, the second or third arm taken | loud check reject (was loud emit reject) |
| a `match` | loud check reject (was runtime trap) |
| forwarded, `function fwd(r) { return take(r) }; fwd(if …)` | loud check reject (was runtime trap) |
| the call passes another parameter, `function take2(n, r) { return r.f(n) }; take2(3, if …)` | loud check reject, `cannot hand this `if` …` (was runtime trap) |
| bound first, `const q = if … ; take(q)`, either order | runs, `4` / `1.5` |
| one result type at the call, `dbl` for `half`, or `id1` / `id2` through `take2(3, …)` | runs, `4` / `3` |
| results that agree at the call site's types, `half` / `inc0` through `take2(2.5, …)` | runs, `3.5` |
| a `const` lambda callee, `const take = (r) => r.f(3)` | runtime trap: [D15808](D15808.md) |

The price, spellings that ran on master and are now refused: an inline join of different results
whose first arm is the one taken at run (`take(if c { { f: half } } else { { f: inc0 } })` with
`c` true, `1.5`), and two such joins summed with both first arms taken (`8`). Each ran only because
of which arm was taken; the same program with the other arm traps. The corpus holds none: a
local sweep of the refusal's first cut (a literal call only), against master `0671904bf`, moved 0
of 24,037 cells; the PR's CI sweep grades the refusal as shipped.
