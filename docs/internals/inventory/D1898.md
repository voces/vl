Repro:

    type K = "a" | "b"

    function pri(k: K | null): i32 {
      match k {
        "a" => { return 1 }
        "b" => { return 2 }
        null => { return 0 }
      }
      0
    }

    print(pri("b"))
    // vl run: 2

#### Mechanism

**The refusal's sentence named the wrong ingredient and the message's own tail refuted it.** It
said "a union with literal members" and printed `got K | null`: the BARE set matched at every
spelling — a declared alias, an inline parameter, a local from a call, an or-pattern arm, a
match whose arm returns the litunion — and the checker enforced exhaustiveness there by name.
Only the nullable spelling was refused, and an explicit `null` arm did not help.

**Both spellings are the same rep, so there was nothing to build in the emitter.**
`vtKindOfType` answers `"i32"` for the bare alias and `"i32"` for `K | null`, whose own arm
records that `null` rides the spare `-1` and needs no box. Confirmed behaviourally before
editing: the if-chain a `match` desugars to (`if k == null` then `if k == "a"`) already ran, and
so did `k is null` — which is the exact node `desugarMatchAt` produces from a `null` pattern.

So the whole gap was in the checker: `checkMatchExprNode` gated the member-string vocabulary on
`tyIsLitUnion(st)`, which a `TyNullable` over a litunion (and the expanded `"a" | "b" | null`
`TyUnion`) both fail. The close routes both forms in through the existing
`tyIsNullableLitUnion`, reads the member texts through the nullable wrapper, accepts a `null`
type pattern as covering the null member, and names `null` last in the exhaustiveness sentence.
The pattern-vocabulary message offers `null` only where the scrutinee carries it, so a bare
set's sentence is unchanged.

**It could not ship with its own first consumer.** Converting `forceAnnLeafReps`'s
`VKind | null` chain in the same PR makes the SEED unable to compile the source —
`refresh-compiler.sh` says so by name — because the seed predates the construct. The enabling
change lands first; the conversion is the next step, once a seed carrying it is on master.
