### D1898 — `match` over a NULLABLE literal union is refused, while the bare and the null-narrowed spellings both run

**loud check reject · `match over a union with literal members is not supported — compare them
with `==` in an if-chain, got K | null` · clause 2 · filed 2026-09-07 against master
`6066dfb17` while grading ROADMAP row 24's third tranche · 0 corpus cells**

Repro:

    type K = "a" | "b"

    function pri(k: K | null): i32 {
      match k {
        "a" => { return 1 }
        "b" => { return 2 }
        null => { return 0 }
      }
      0
    }

    print(pri("b"))
    // vl check: match over a union with literal members is not supported

#### Mechanism

**The refusal's sentence names the wrong ingredient, and the message's own tail refutes it.**
It says "a union with literal members", and it prints `got K | null`: the BARE literal union
matches fine, `_`-less and exhaustive, at every spelling tried — a declared alias, an inline
`"a" | "b" | "c"` parameter, a local from a call, an or-pattern arm, and a `match` whose arm
returns the litunion. The checker even enforces exhaustiveness there by name
(`non-exhaustive match — missing "c" (add the arm or a `_`)`). Only the NULLABLE spelling is
refused.

The gap is a capability one rather than an exhaustiveness one, which the `null` arm above
settles: naming `null` explicitly does not help, so what is missing is the nullable litunion's
scrutinee lowering, not a missing case. And the same program with the null stripped first —
`if k == null { return 0 }` and then the match — runs, so the arms themselves lower fine at
this type.

Wording: `is not supported` is one of the phrases `goal-scoreboard.py` counts as conceding the
program is legal, and a neighbouring spelling running is what says the concession is real.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `\| null` (a bare `K`) | runs | **yes** |
| the null, stripped by `if k == null { return 0 }` first | runs | **yes** |
| the `null` arm (arms cover only `"a"`/`"b"`) | refuses identically | no |
| the alias (an inline `"a" \| "b" \| null` parameter) | refuses identically | no |
| the arms, made an or-pattern | refuses identically | no |

#### Grading list

The five ablation rows; the five bare-litunion spellings that must keep running (declared
alias, inline parameter, local from a call, or-pattern arm, litunion-returning arm); the
`non-exhaustive match — missing "c"` refusal, which must stay a refusal; and
`compiler/emit_classify.vl`'s three `VKind` matches (`retKindPri`, `fieldCodeOfVKind`,
`vkNulNicheOf`), which are bare-`VKind` scrutinees and must keep compiling. A close should also
say whether `VKind | null` — the shape `forceAnnLeafReps` and `collectMapFilterUse` carry, and
the reason both are still `if` chains — becomes matchable.
