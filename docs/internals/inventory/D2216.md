### D2216 — a literal-union atom narrowed by `is` cannot initialise a local annotated with the narrowed literal type

**loud emit reject · `emitProgram: only i32 locals are supported` · found closing D2205 · filed 2026-09-23 against master `0d5421468`**

Repro:

    type M = "x" | "y"
    function f(m: M) {
      if m is "y" {
        const k: "y" = m
        print(k)
      }
    }
    f("y")

#### Mechanism

`checkLocalI32` admits an annotated local only when its type's scalar base is `i32` or
`boolean`, or when the annotation names a literal-union ALIAS (`nodeTyIsLitUnionAlias`). A
one-literal annotation (`"y"`), or an inline literal union with a `null` (`"x" | null`), is
neither, so the local is refused even though the value is the i32 atom the alias case takes.
The check passes the same value as an argument (`onlyY(m)` with `k: "y"`), so only the local
declaration position refuses.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the annotation (`const k = m`) | runs | **yes** |
| the local (pass `m` to a `k: "y"` parameter) | runs | **yes** |
| the `is` test (`const k: "y" = "y"`) | runs | **yes** |
| the declared alias (`m: "x" \| "y"` inline) | refuses | no |
| the else-branch spelling (`const r: "x" \| null = m` over `"x" \| "y" \| null`) | refuses | no |
