### D16962 — a `??` over a field read of another `??`, inside a function with an un-annotated parameter, is refused at emit

**loud emit reject · clause 2 (`vl check` accepts it; the refusal names a codegen limit) · open · found by the `argument` cell (un-annotated face) of `rec-adopt-chain-coalesce-k1..k4.matrix.vl`, refused before and after #9014 alike · filed 2026-11-18 against master `bce749a59` by lane F2**

Repro:

    function take(a) {
      print((a[0] ?? { f: 0 }).f ?? 0)
    }
    take([{ f: 4 }])
    // vl run: emit error at 1:10, "emitProgram: `??` over this nullable value is not supported yet — narrow it first, e.g. `if v != null { … }`"

Want:

    4

#### Mechanism

The inner `??` joins a read of the parameter's container with a fresh literal inside a function
instanced at its argument's type; the outer `??` reads a field of that join directly. The emitter
has no value form for the outer operand there: bound to a local first, the same read builds, as it
does at module scope and with an annotated parameter. Not yet located below the emitter's refusal.
