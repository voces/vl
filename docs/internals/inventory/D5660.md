#### Mechanism

From the ablation only. D5531's close copies `mk` once per RESULT, keyed by the binding each
result initializes; here one binding carries both pins, so there is one key and no copy. The
binding itself needs a slot per type, and `fn_split`'s let slots copy only a name, a lambda, or
a name through an identity call: `mk()` is none of them, and calling it once per slot would
run its body twice.
