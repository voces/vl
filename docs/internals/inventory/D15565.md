### D15565 — a hole function parameter handed on inside a list literal to a hole list parameter is typed as the list's unbound element default, `i32`

**loud check reject · `called value is not a function (i32)` · clause 2 · CAPABILITY: the same list built from a declared function at the call site prints `5`, and an annotated parameter `g: (v: i32) => i32` prints `5` · found re-grading step 3's w00 family (y05 spelling) · filed 2026-11-08 against master `113b2740`**

Repro:

    function h(v) { return v }
    function call0(fs, x) { print(fs[0](x)) }
    function run(g) { call0([g], 5) }
    run(h)
    // vl check: called value is not a function (i32)

Want:

    5

#### Mechanism

Not traced. The diagnostic lands on `fs[0](x)` in `call0`, so the element type `call0`'s hole
`fs` is checked at is `i32`: the element of `[g]`, a list of `run`'s hole parameter, reaches
`call0` as the unbound default rather than as the function `run` is called with.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `run`'s parameter (`call0([h], 5)` in `run()`) | runs, `5` | **yes** |
| the list (`call1(g, 5)` calling `f(x)`) | runs, `5` | **yes** |
| the list literal at the call (`const fs = [g]`, then `call0(fs, 5)`) | the same check reject | no |
| the declared `h` (`run((v) => v)`) | the same check reject | no |
| `g`'s hole (`g: (v: i32) => i32`) | runs, `5` | **yes** |

#### Grading list

The step 3 w00 family's other container spellings: `apply2([h][0], 5)` inside a hole-parameter
owner (an emit reject), and `callF({ f: h }, 5)` there (an emit reject).
