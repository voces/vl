### D3484 — a duplicate key in an object literal is accepted: the first wins, later initialisers are dropped or run once per duplicate squared

**closed by ruling · now a loud check reject at the repeated key · owner ruling 2026-10-03 (A): a key given twice in one object literal is a check error, shorthand and quoted keys included · was check-clean silently wrong (first wins), with the evaluation fixed in #3336/#3337 · the emitter machinery those two PRs added for repeated keys is deleted, unreachable now · fixture `tests/cases/objects/error-duplicate-key.vl` · found 2026-10-03 · filed against master `e5ff25ff9`**

Repro:

    const o = { a: 1, a: 2 }
    print(o.a)
    // vl check: error [1:19] key `a` is given twice in this object literal (first at 1:13)
    // was: rc 0, printed 1

#### Mechanism

Neither the parser nor the checker compared an object literal's keys with each other, so the
literal's struct laid out one slot per occurrence (`{a: i32, a: i32}`) and every read of `.a`
took the first slot. #3336 and #3337 made each initialiser run once, in source order, at any
joined shape. The owner ruled (A) on 2026-10-03: a repeated key is a slip, refused at `vl check`.
`checkObjLitNode` now raises `objLitDupKeyErr` for every key a literal gives a second time, at
the repeated key's token, naming the first one's `line:col`; it runs for every object literal,
so binding, argument, return, nested, element, closure, generic body, declared record and union
arm, and the editor (the LSP reads the same checker) all refuse it. The literal-shape-drop
refusal no longer reports the repeat as an undeclared field with an empty name. VL has no map
literal: an object literal at a `{[K]: V}` type is already refused as not a map value, and its
repeated key is reported beside that. The emitter's repeated-key paths (`objFieldValAt`,
`objFieldSrcPairs`, `objLitDupSkew`, `objDupSlotRepeats`, the occurrence count in
`objFieldSrcOrder`) were proved unreachable with an `emitFail` probe (a control seed with the
check off fired it on every witness; with the check on it fired on none of 4,441 test files,
the distilled corpus or the self-compile) and are deleted; the seed shrinks 1,577 bytes.

#### Ablation

The table is the pre-ruling record; every spelling in it is now refused at `vl check` (the
fixture holds one per position), except `type P = { a: i32, a: i32 }`, which is a type
declaration and is D3537.

#### Grading list

Every spelling above, at every position (binding, shorthand `{ seq, seq: 5 }` and `{ seq, seq }`,
quoted `{ "a": 1, a: 2 }`, method shorthand, argument, return, nested, element, closure, generic
body, declared record, union arm, `{[string]: V}` context, three repeats): one error per repeat,
spanning the repeated key. The census found no duplicate-key literal in `compiler/`, `std/`,
`scripts/`, the consumers or the distilled corpus; the two `eval-order` fixtures that pinned the
first-wins evaluation are replaced by the check-reject fixture.
