#### Mechanism

Not localised past the ablation. `boolean[]` and `i32[]` share one list rep, so the box the
join is built as tags both lists alike, and the read of the element dispatches on a tag that
cannot tell them apart. A literal union's list beside another list has the same collision, and
lane JW refuses that shape at the instance (`a join of lists with a literal-union element …`)
rather than build it; this one it does not refuse, because the two-list `boolean[]` / `i32[]`
joins run on master and a refusal there loses them.
