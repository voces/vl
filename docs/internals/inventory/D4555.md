### D4555 — an un-annotated return narrowed to one record arm of a union is declared as the union box

**closed · was check-clean, then `emitProgram: ref valtype with no interned shape` or `field access but no struct type declared` at build · filed 2026-10-14 against master `eb2603843`**

Repro:

    type Out = { a: i32 }
    type Err = { msg: string }
    function f(r: Out | Err) {
      if r is Out { return r }
      return { a: 5 }
    }
    print(f({ msg: "m" }).a)

Want:

    5

#### Mechanism

The checker infers the function's return as the narrowed arm (`Out`), and every caller trusts
that type. The emitter classified the returned identifier by its DECLARED union
(`criClassify` → `exprUnion` answers "union" for an Ident before the variant arm runs), so
the result was declared as the union box and nothing unboxed it. The annotated spelling `: Out`
worked because `emitReturnValue` unboxes to a nominal variant return. The fix pins the
checker's inferred return to the arm's nominal name in `synthNulListRetAnns`
(`compiler/emit_rewrite.vl`), the same pin family as D1062/D2731, so the un-annotated spelling
takes the annotated one's path. The first witness used `std:process`'s `runProgram` result
narrowed past `IoError` by `exit`; the minimal one above needs no std and no `never`.
