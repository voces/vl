### D2916 — a generic join with a `??` arm, bound and then read outside a sink, is delivered at the template's rep into the instance's union box

**check-clean silently wrong · clause 1 · open · regression of #3233 (a loud emit reject on `829bd497c`) · found in the #3236 review · filed 2026-09-27 against master `0284dc2a8`**

Repro:

    function g<T>(a: T, b: T, c: boolean) {
      const r = if c { a ?? 5 } else { b }
      const s = r
      s
    }
    print(g(true, false, true))
    // vl check: rc 0.  vl run: prints 1

Want:

    true

#### Mechanism

#3233 annotates the instance's inferred return at its value-atom box (`boolean | i32`), and the
binding of the join keeps the template's rep, since its type is a hole of `T`. D2912 re-types
the join when its binding is read only by a return or a `print`; any other read (an alias, an
argument, an `==`, a reassignment) leaves it at the template's rep, and the box then carries a
scalar. Withholding the box annotation in every such body (so these refuse loudly again, as on
`829bd497c`) was tried in #3236 and refused: at an `i32` pin with a `"d"` default the same
bodies run only because of the box, and 57 of the review grid's 1,107 cells stopped running.
The fix is to re-type the binding at every read, not to withhold the box.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the alias (`r` returned directly) | prints `true` (D2912) | **yes** |
| the `??` (`if c { a } else { b }`) | prints `true` | **yes** |
| the `boolean` pin (`g(3, 4, true)`) | prints `3` | **yes** |

#### Grading list

The same body with the second line replaced, at `boolean` (prints `1`/`0`) and with a `"d"`
default (traps with `cast failure`): `let r = …; if !c { r = b }; r`; `sink(r); r`;
`return idf(r)`; `if r == b { … }; r`. At `string | null` the alias and `idf` shapes are invalid
wasm, loud before #3233. The #3236 review grid (`rv3236-k7q`, `twoNames`, `reassign`,
`reassignA`, `sink`, `idret`, `eq`, `closureTail` shapes) holds them all.
