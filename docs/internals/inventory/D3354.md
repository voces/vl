### D3354 — an integer `match` whose first arm is a `never` call classifies its binding by that arm, so a nullable-record value is check-clean invalid wasm

**check-clean invalid wasm · 4 cells of the #3293 review grid `h5` · filed 2026-09-30 against master `455e553ca`**

Repro:

    type Rec = { r: i32 }
    function die(msg: string): never {
      print(msg)
      __trap__()
    }
    function pass1(x: Rec | null): Rec | null { x }

#### Mechanism

The `match` twin of D3258. The `if` spelling of the same program (`if n == 99 { die("dead") }
else { o }`) runs since the loop-values change, because `ifThenValueIx` reads the else arm when
the then arm's tail is a `never` call. The integer `match` desugars to an if-chain its own way
(`desugarMatchAt`, an integer-switch head), and the binding is still classified `i32` from the
`never` arm, while the other arm delivers a `(ref null $Rec)`.
