### D1432 — `x?.n ?? d` refuses at emit when `x` is NOT nullable, at every spelling, while the nullable twin runs

**loud emit reject · clause 2 · OPEN · found 2026-09-03 while grading the `?.` twin of
[D1431](D1431.md)'s member read · ZERO corpus cells**

Repro:

    const x: { n: i32 } = { n: 5 }
    print(x?.n ?? 0)
    // vl check: rc 0.  vl run: emitProgram: a standalone `?.` has no rep for this
    //   result type — read it through `?? d` or a `!= null` guard
    // Should print 5.

#### Mechanism

The refusal's own sentence prescribes the edit the program already made — the `?.` IS read
through `?? d`. What decides the outcome is the receiver's NULLABILITY, not the reading:
declare `x` as `{ n: i32 } | null` and the identical line prints `5`. So the rep the emitter
looks for is the nullable one, and a `?.` over a provably non-null receiver reaches a rung
with nothing to select. The checker is content, which is what makes it clause 2 rather than a
diagnosis it owed.

Two spellings, two DIFFERENT sentences for one mechanism: inside a function body the same
read is `emitProgram: unsupported statement in body`, at 1:9, naming neither `?.` nor a rep.
Grade the message with the outcome.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the non-nullability (`{n: i32} \| null`) | prints `5` | **yes** |
| the `?.` (plain `x.n`) | prints `5` | **yes** |
| the `?? 0` | same refusal, same sentence | no |
| the function body (top level vs body) | refuses either way, DIFFERENT sentence | no |

#### Grading list

* The generic and hole spellings — `function g<T>(x: T): i32 { x?.n ?? 0 }` and
  `function g(x) { x?.n ?? 0 }` — which refuse EARLIER, at check, with `member access '?.n'
  on non-object`. They agree with each other (that is [D1431](D1431.md)'s property) and both
  are upstream of this row; closing this one does not move them.
* `docs/guide/` on `?.` being null-only (owner preference): if a non-nullable receiver is a
  DESIGN error, the checker owes the diagnosis and this row closes as a check reject with a
  sentence naming redundancy — not as a lowering.
