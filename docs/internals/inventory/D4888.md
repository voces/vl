### D4888 — a record literal holding the complement of `is i32[]` over a PARAMETER `v: T[] | i32[]` matches no row

**closed · was a loud emit reject (`emitProgram: object literal matches no union variant`), identical on master `b8dc4604d` · fixture `tests/cases/generics/generic-param-complement-list-record.vl` · filed 2026-10-15**

Repro:

    function h<T>(v: T[] | i32[]) {
      if v is i32[] { print(0) } else {
        const r = { xs: v }
        print(r.xs[0])
      }
    }
    h(["e"])

Want:

    e

#### Mechanism

`mintPinnedObjLit` mints an instance's row for a literal whose field holds a type parameter
from `pinSubOperandTyOf`, which reads the parameter's binding off an argument's pin. The
field's `T[]` is the complement of `is i32[]` over `v: T[] | i32[]`, and no argument pin names
`T` alone, so it answered nothing and no `{xs: string[]}` row was minted. The literal now falls
back to `exactOperandTyOf`, the operand's type substituted through the exact instance.
