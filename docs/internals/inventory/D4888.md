#### Mechanism

Not yet located. The same literal over a local `const v = w(t, b)` of the same inferred type
runs since D4886 and D4887, and reading `v[0]` in this else runs, so the parameter's declared
union is what the row resolver keys the literal on. With an `f64` instance beside it the
refusal moves to `index receiver is not an array or string`.
