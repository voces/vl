### D16849 — an unread binding of a runtime `if` of records of un-annotated functions is refused at emit once another such record is read

**open · loud emit reject · clause 2 (`vl check` rc 0) · the residue of [D16842](D16842.md): six cells of `hole-fn-value-unresolved-read.matrix.vl` · refused before D16842 too · filed 2026-11-16 against master `a8512d420`**

Repro:

    function inc0(a) { return a + 1 }
    function inc1(a) { return a + 2 }
    function inc2(a) { return a + 3 }
    function id(x) { return x }
    const n = 3
    const _r = id(if n > 2 { { f: inc0 } } else { { f: inc1 } })
    print(id({ f: inc2 }).f(3))
    // vl check: rc 0.  vl run: emit error, `cannot take the generic function `inc0` as a value`

#### Mechanism

Not traced. The binding `_r` is never read, so the class of its `if`'s fields has no call and
gives no signature (`eplValueSig` -1), and its functions stay values. Alone, an unread binding
runs, nothing of it being emitted as a value; with another record literal of a generic read in
the program, the unread one's values are emitted and the value floor refuses them.
