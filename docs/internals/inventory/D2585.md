#### Mechanism

D2584's: the write through `q` did not end `p.f`'s narrowing to `i32 | string`, so the checker
typed the else arm's `p.f` as `string` and the emitter cast the box's payload to a string ref
while the cell held `null`. The same held for `A | B` narrowed by `is B` and written `A` through
the alias (`cast failure` at `p.f.q`), for the index cell and the nested field, and
(`null reference`) for a loop or a nested function that read the path before the alias write. The
close ends the narrowing at the write, so the else arm reads `string | null` and `+` refuses; a
program that re-tests after the write runs.
