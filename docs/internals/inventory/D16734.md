### D16734 — a record delivered to a type that drops one of its fields seven or more levels down builds an invalid module, because `tyReachesHole`'s budget runs out first and answers "reaches a hole"

**check-clean invalid wasm · clause 1 · found by the type hash-cons 6b depth grid (`hash6b-deep-nesting`) · filed 2026-11-16 against master `5cb1969a7`**

Repro:

    function show(x: {a: {b: {c: {d: {e: {g: {h: {v: i32}}}}}}}}) { print(x.a.b.c.d.e.g.h.v) }
    const r = { a: { b: { c: { d: { e: { g: { h: { v: 1, w: "s" } } } } } } } }
    show(r)
    // vl check: rc 0.  vl run: invalid module, "type mismatch: expected (re…" in the top-level code

Want:

#### Mechanism

`tyReachesHole(t, 8)` answers `true`, "reaches a hole", when its budget runs out, and a record
seven levels deep spends the budget of 8 on its leaf. The width-dropping delivery then takes the
route for a source that still holds a hole, and the module is built with the source's own record
rows where the destination's are read. Deepening that one cap (the 6b depth grid's ablation, every
other cap left alone) makes every depth from 7 to 14 print `1`. Raising every `recordRepTyAdopt`
budget to 64 does not, and neither does lane AE4's D16731/D16732 branch.

#### Ablation

At seven levels:

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the extra field `w` | runs | **yes** |
| `w` at the leaf (moved to the top level) | runs | **yes** |
| the call (`const x: {…} = r` instead) | invalid module | no |
| the binding (the literal passed inline) | invalid module | no |
| `w` a string (`w: 2` instead) | invalid module | no |
| the callee's read of `v` (`print(1)`) | invalid module | no |
| one level (six deep) | runs | **yes** |
