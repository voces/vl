#### Mechanism

Not located. One instance runs, so the loop variable's call is pinned at one instance's binding
and not at the second's. The value-flow question follows the loop variable's reads
(`vrForVar`), so the gap is in how an instance keys that call, not in whether the question
reaches it. Not probed further.
