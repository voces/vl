### D15774 — a module-scope `let` bundle holder read into an annotated binding inside a function is refused at emit

**closed 2026-11-12, runs and prints `5` `4` · was loud emit reject, clause 2, `a function-value call has no interned signature — parameter 1 of type `` has no representation in the function-value ABI` · found closing D15863 · filed 2026-11-12 against master `a0e195a9` · closed in `elabTypedReadsHold` and `elabHolderCopiesHold` (emit_elab.vl): a module-scope `let` holder nothing writes (`cwDeclAssigned`) is one record whichever function reads it, as a `const` is · a `let` holder that is written stays refused · fixture `tests/cases/closures/bundle-holder-in-unwritten-module-let-read-in-functions-runs.vl`**

Repro:

    function lap(f) {
      f(2.5)
      f(3)
      return f
    }
    let c = lap((a) => a + 1)
    function main() {
      const m: (f64) => f64 = c
      print(m(4))
      print(c(3))
    }
    main()

Want:

    5
    4

#### Mechanism

`elabTypedReadsHold` (`emit_elab.vl`) admits an annotated read of a module-scope holder from
any function only where the holder is a `const` (D15863), as `elabHolderCopiesHold` does for a
copy. A `let` holder at module scope may be written from any function, so its record is no
longer one fact. Unmeasured beyond that.
