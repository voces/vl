### D1741 — an UN-ANNOTATED binding of a narrowed struct arm keeps the box, so a field read refuses and every other consumer does not validate

**closed 2026-09-06 — the witness prints `8` · was a loud emit reject · filed 2026-09-06
against master `92dd09cc0` · found as the last SILENT cell of D1685's matrix, where the
capture turned out to be scenery · fixture
`tests/cases/unions/narrowed-arm-unannotated-binding.vl`**

Repro:

    type A = { r: i32 }
    function st(): A { return { r: 8 } }
    function mk(b: boolean) {
      if b { return st() }
      7
    }
    function f() {
      const p = mk(true)
      if p is A {
        const c = p
        print(c.r)
      }
    }
    f()
    // vl check: rc 0.  vl run: prints 8.

#### Mechanism

A narrowed struct arm is the `{tag, payload}` box, and every delivery boundary with a
destination row unboxes to it — the binding, the argument, the return (D1723) and the two
assignments (D1685). An un-annotated binding had no annotation to give the cell a row, so
`letIsUnion`'s init half claimed it and the cell was the box, while the CHECKER typed the
binding at the arm. Both faces of an instrumented probe read the same arena type on the init
and disagreed only about the cell:

| face | cell kind | slot | cast target | init's arena type | narrowing |
| --- | --- | --- | --- | --- | --- |
| `const q: A = p` | `variant` | 0 | 0 | variant row 0 | row 0 |
| `const q = p` | `union` | -1 | **-1** | variant row 0 | row 0 |

The unbox was already owed at the un-annotated face; `armDestHeapOf("union", -1)` gave it no
target, so nothing was emitted and the box reached consumers that all read it as the arm.

The fix is an arena rung in the one home of that ladder, `letInitCellKind`, mirrored in
`collectLocals` and in the capture companion index: where the checker recorded a concrete
variant row for an un-annotated init whose value is the union box, the cell is the arm. The
binding boundary's `letArmOwed` takes the same predicate as a second disjunct, so a cell typed
at the arm cannot be reached without its unbox — without that the emitter's own narrowing
stack, which does not key `ys[0][0]`, left the box in an arm cell and traded eleven loud
refusals for invalid wasm.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the capture (`const c = p` then `print(c.r)`) | loud refuse, `field access receiver is not a struct` | no — it only changed loud to silent |
| the annotation restored (`const c: A = p`, captured) | ran, printed `8` | **yes** |
| the inference (`type M = i32 \| A`, `mk(): M`) | **still refused** | **no** |
| the narrowing (no `is A` guard) | check refuses | — |

The inference line is a correction to this row as filed: the declared union refused
identically at the un-annotated binding, so the defect was never inference-specific. The
place grid confirms it — the `declared` and `inferred` faces both moved.
