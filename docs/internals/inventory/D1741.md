#### Mechanism

A narrowed struct arm of an inferred union is the `{tag, payload}` box, and every delivery
boundary that has a destination row unboxes to it — the binding, the argument, the return
(D1723) and the two assignments (D1685). An UN-ANNOTATED binding has no annotation to give
the cell a row, so the cell takes the box's own kind and the arm is never recovered: the
field read then has a box where it wants a struct, and refuses.

**The capture is scenery, and that is what makes this its own row.** D1685's matrix reported
`fn_body_capture/unann` as check-clean invalid wasm, which reads as a capture defect. Removing
the closure leaves the same program refusing LOUDLY at the field read, and annotating the
binding (`const c: A = p`) makes the captured version print `8`. So the ingredient is the
missing annotation on the binding, not the capture — the closure only converts the refusal
into an invalid module.

This is the shape CLAUDE.md names: a grid whose `bind-to-arm` consumer annotates cannot see
it, and D1685's could not.
