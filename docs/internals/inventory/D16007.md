#### Mechanism

An `is` guard over an un-annotated parameter registers its tested type as an alternative the
argument may meet instead of the demanded shape (`holeAltNames`). The registration reads the
`then` arm's narrowings. Under `!`, the guard's narrowing is the `else` arm's, so no alternative is
registered, and the argument must meet the `then` arm's `{y: _}` alone. D16004's member-by-member
check has no alternative for `A` to take.

The close registers a closed else-narrow of a hole as the alternative the `else` arm takes, closed
on that arm's divergence. An open else-narrow (a deferred remainder) is not registered: it names
no type an argument could be held to. An instance's elaboration noted a negated test that was
always true at its pin as making the `else` arm dead, the arm that runs. It now reads the signal
with the arms swapped, so a pin skips the arm it makes dead (`foobar({ foo: "f" })` over
`if !(v is { foo: string }) { v.bar }`).
