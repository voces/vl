### D16007 — a negated record `is` test over an un-annotated parameter registers no guard alternative, so the argument must meet the then-arm's reads alone

**loud check reject · clause 2 · found closing [D16004](D16004.md) · present on master `7b0b9d8ac` · filed 2026-11-13 against master `7b0b9d8ac`**

Repro:

    type A = { kind: "a", x: i32 }
    type B = { kind: "b", y: string }
    function mkval(): A | B { return { kind: "b", y: "yy" } }
    function take(p) {
      if !(p is A) { print(p.y) } else { print(p.x) }
    }
    take(mkval())
    // vl check: argument 1: expected {y: _}, got A | B
    // Should print yy; annotating `p: A | B` does, and so does `if p is A { … } else { … }`.

Want:

    yy

#### Mechanism

An `is` guard over an un-annotated parameter registers its tested type as an alternative the
argument may meet instead of the demanded shape (`holeAltNames`). The registration reads the
`then` arm's narrowings. Under `!`, the guard's narrowing is the `else` arm's, so no alternative is
registered, and the argument must meet the `then` arm's `{y: _}` alone. D16004's member-by-member
check has no alternative for `A` to take.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the missing annotation — `p: A \| B` | prints `yy` | **yes** |
| the negation — `if p is A { p.x } else { p.y }` | prints `yy` | **yes** |
