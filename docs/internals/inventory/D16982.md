### D16982 — two calls of a maker joining record literals, each in a different value join delivered at a declared record, leave the maker unbuilt there and build invalid wasm

**check-clean invalid wasm · clause 1 · found by lane F2 grading D16979 · filed 2026-11-18 against master `47ed1c966` by lane F2**

Repro:

    type J = { a: i32 }

    function mk(b: boolean) { return if b { { j: { a: 1 } } } else { { j: null } } }

#### Mechanism

Not localised past the ablation. `mk` is not built at `K` (D15719): it keeps its union-box result,
while the chain's links take `K`. With the two calls as arms of one `if`, or as plain deliveries, the maker
is built at `K`, so the calls' landing check does not follow a call through a second join.
