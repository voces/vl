### D5650 — a forward callee inferred on demand resolves its free names in the caller's scope

**closed · was check-clean silently wrong · `vl check` rc 0 · clause 1 · found closing D5593 · filed 2026-10-17 against master `7fe51e77c`**

Repro:

    const x = 1
    function act() {
      const x = 2.5
      print(x)
      return g()
    }
    function g() { return x }
    print(act())

Want:

    2.5
    1

#### Mechanism

`act` is inferred in the return pre-pass and calls `g` before `g` is inferred, so
`checkCallOnFuncTy` demand-checks `g`'s `FuncDecl` from inside `act`'s body. The body scope
`g` pushes sits on top of `act`'s, and `lookup` reads the innermost binding, so `x` in `g`
resolves to `act`'s local `const x = 2.5` instead of the module constant. `g` is then
inferred as returning `f64` and what it returns is the caller's value. With a `boolean` local
the same spelling is refused (`operator '+' is not defined for boolean and i32` at a use of
`act()`), and with a `string` local `act`'s own return cannot be inferred.

Fixed at the one place every on-demand path enters a body: `checkFuncDeclNode`. Every path
reaches it: the direct forward call, the UFCS call, the bound-member probe, a lambda or a chain of
forward callees. For a top-level declaration it now calls `scopeHideEnter` (`check_scopes.vl`).
That takes every binding above the module frame out of `scopeDepthsOf` and records each
(name, depth) pair it removed, so the caller's locals, parameters, nested functions and narrowing
layers are not visible from the callee's body. `scopeHideLeave` puts back exactly those pairs, in
depth order, once the body's own frames are popped. Pass 2 checks a top-level function at the
module frame, where hiding is a no-op. A first version restored whole frames by depth window
instead of recorded pairs. It passed every case slice, but it left a stale depth in
`scopeDepthsOf` when the compiler checked itself, which trapped in `lookup` from
`preInferOne`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |

#### Grading list

The `boolean` and `string` spellings above; a forward callee reading a module `let` that the
caller shadows with a parameter; a narrowing of a module global live in the caller at the
forward call, which the callee's body must not see.
