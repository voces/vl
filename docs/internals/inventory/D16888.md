#### Mechanism

The contextual-return adoption's general rung asks whether every returned value is delivered to
the expected result. A list literal of another element type fits the list member, but the fit of
the union holding it is not asked of its members, so the lambda kept `string[]` and the function
slot refused it. The annotated twin `(q0): (string | i32)[] | f64 => ["r"]` builds the literal at
the member.
