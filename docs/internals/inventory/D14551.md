**runs today and must keep running · open: the registrars at sites 41, 42 and 46 still mint from the spelling's re-parse · was a refutation pin for deleting `recordUnMemTys`'s last spelling path · filed 2026-10-27 against master `ffe16aa08` · the twin-list face is fixed, because every other registrar passes the arena type it holds and `mintInlineUnion` takes it as given. The twin-record spelling path (`unionHasTwinRecordList`, `listOfTwinRecord`) is deleted · pins: `tests/cases/generics/nullable-fold-nominal-lists-and-literal-box.vl` and the 32 fixtures under Grading list**

Repro:

    type Rec = { x: i32 }
    type Rec2 = { x: i32 }

    const r2: Rec2[] | null = [{ x: 8 }]

Want:

    false

#### Mechanism

The list's element is the arena union `(Rec2[] | null) | (Rec[] | null)`, and `repOfArray`
asks for its row by canon id. The row was minted by `registerInlineUnionOfChild`, which passed
no type, so `mintInlineUnion` re-parsed the spelling. The re-parse dedupes the twin lists to
`Rec2[] | null`, which has a different canon id. While `recordUnMemTys` kept a twin spelling
branch, the row read four atoms and the list found it.

Fixed: `registerInlineUnionGo` (`compiler/emit_collect.vl`) mints at the arena type its
registrar holds. The child registrar (map value, ref-array atom sub-union, list element),
closure results 34 and 35, the inferred return 44 and the array-literal element 45 pass it,
and a site outside the spelling family that arrives with no type is a named `emitFail`. Over
`tests/cases` and the distilled corpus, that refusal fires zero times.

Open: `unSiteMintsFromSpelling` keeps the re-parse at the annotation sites 41 and 42, and at
site 46 (`registerInlineUnionOfTy` passes no type, and its other caller passes the `??` merged
type). The held type keeps what the re-parse expands:

* a generic application or alias head. `Box<i32>` is the arena `TyObj` `{v: i32}` plus a
  nominal sidecar, so it has the same canon id but a different index.
* a literal-narrowed map value (`{[string]: 1 | 2}`), with a different canon id.
* a union alias as one member (`Shape | ParseError` against `Circle | Rect | ParseError`).

`boxRowMembersInto` renders members nominally (`Box<i32>`), while the row's name and its
struct variants are keyed by the structural spelling. Minted at the held type, the box members
miss their variant rows, and the 32 fixtures below stop running. The fix is for the box
members and the struct variants to key by the same arena node. Then `unSiteMintsFromSpelling`
and the re-parse are deleted, and this row closes.
