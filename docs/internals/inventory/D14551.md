### D14551 — an inline union row takes its arena type from its spelling's re-parse, which merges twin records and expands generic-application and alias heads

**closed 2026-10-27 · runs, prints `false` · filed 2026-10-27 against master `ffe16aa08` · fixed: every registrar, the annotation sites 41 and 42 and the spelling registrar 46 included, mints its row at the arena type it holds, and `unSiteMintsFromSpelling` and the re-parse are deleted. A row is found by the canon id of its flat member set, so a union alias member, a nullable alias member and a literal-narrowed map value key the row their spelled-out twins key · pins: `tests/cases/generics/nullable-fold-nominal-lists-and-literal-box.vl`, the 32 fixtures under Grading list, `tests/cases/unions/alias-member-union-narrows-at-every-position.vl`, `tests/cases/std/json-union-narrows-at-top-level.vl` and `tests/cases/maps/set-valued-map-union-arm-is.vl`**

Repro:

    type Rec = { x: i32 }
    type Rec2 = { x: i32 }
    const rl: Rec[] | null = [{ x: 7 }]
    const r2: Rec2[] | null = [{ x: 8 }]
    function G<A, B>(k: i32, a: A, b: B): (A | null) | B {
      if k == 0 { return a }
      if k == 1 { return b }
      return null
    }
    const w = [G(1, r2, rl)]
    print(w[0] == null)

Want:

    false

#### Mechanism

The list's element is the arena union `(Rec2[] | null) | (Rec[] | null)`, and `repOfArray`
asks for its row by canon id. The row was minted by `registerInlineUnionOfChild`, which passed
no type, so `mintInlineUnion` re-parsed the spelling. The re-parse dedupes the twin lists to
`Rec2[] | null`, which has a different canon id. While `recordUnMemTys` kept a twin spelling
branch, the row read four atoms and the list found it.

Fixed: `registerInlineUnionGo` (`compiler/emit_collect.vl`) mints at the arena type its
registrar holds. The child registrar (map value, ref-array atom sub-union, list element),
closure results 34 and 35, the inferred return 44 and the array-literal element 45 pass it,
and a site outside the spelling family that arrives with no type is a named `emitFail`. Over
`tests/cases` and the distilled corpus, that refusal fires zero times.

The annotation sites 41 and 42 and site 46 kept the re-parse (`unSiteMintsFromSpelling`). The
held type keeps four things the re-parse expanded, and each one had to key the same row:

* a generic application or alias head. `Box<i32>` is the arena `TyObj` `{v: i32}` plus a
  nominal sidecar. `boxRowMembersInto` renders a generic-application member of a 2+-member
  row as its shape (`boxRowGenAppShapes`, `compiler/check_program.vl`), the key its variant
  row carries, unless that would merge two atom positions.
* a union alias as one member (`Shape | ParseError` against `Circle | Rect | ParseError`), or a
  nullable alias (`Json | JsonError`, where `Json` holds `null`). The canon id of a union
  flattens a union member into its members and a nullable member into its inner and a `null`
  (`hcUnionId`, `compiler/emit_rep.vl`), never deduping a position.
* a literal-narrowed map value (`{[string]: 1 | 2}`). Under the canon key a map value that is a
  union of one base's integer literals keys as that base, as the map stores it (`repMapValTy`).
* a Set-valued map member (`{[string]: Set<i32>}`). The mv slot is named by the boolean map a
  Set is stored as, so the mv key folds a Set to that map as the canon key does
  (`repKeyFoldsSet`). The held type is the right one here: the re-parse's render had dropped
  the Set, and the slot answered only for the render.

Fixed: all three sites pass the type they hold, `unSiteMintsFromSpelling` and the re-parse are
deleted, and a registrar with no type is the named `emitFail`.
