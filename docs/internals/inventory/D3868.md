### D3868 — an uncalled top-level function that reads and rewrites a module-scope alias of a hole lambda is emitted with the alias at the wrong signature

**check-clean invalid wasm · the module-scope twin of D3864 · found by the rv3458 review of #3457/#3458 · filed 2026-10-08 against master `fd225840b`**

Repro:

    const x = "a"
    const n = 4
    const c = (y) => y + y
    const e = (y) => y + y + y
    let d1 = e
    print(d1(x))
    print(d1(n))
    let d3 = d1
    let d4 = d3
    function rw2(): string { const r = d4(x); d4 = c; r }
    print(d4(n))
    // vl check: rc 0.  vl run: rc 70, invalid module inside `rw2`, `type mismatch: expected i32, found (ref $type)`

#### Mechanism

`d1` is called at two argument types (`x` a string, `n` an `i32`), so its closure signature is
decided per CALL, and the aliases `d3` and `d4` inherit that. The reassigning function `rw2`
reads `d4` at the string call and writes `c` into it; `rw2` is never called, and it is emitted
with `d4(x)` against the `i32` form of the signature. Calling `rw2` from the top level does not
change the outcome (`print(rw2())` is still invalid inside `rw2`), so the fault is in how the
function's body is typed, not in whether it runs. The same program with `rw2` deleted runs and
prints `aaa`, `12`, `12`. Which of the two forms the alias is held at, and which the body
reads, was not printed.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the function `rw2` | runs, `aaa` / `12` / `12` | **yes** |
| `rw2` being uncalled (`print(rw2())` added) | still invalid, inside `rw2` | no |
| the write `d4 = c` inside `rw2` | loud emit reject, `a function-value call has no interned signature` | **yes** |
| the read `d4(x)` inside `rw2` (the write only) | runs | **yes** |
| the write's right side (`d4 = e` instead of `c`) | still invalid, inside `rw2` | no |
| the alias chain (`d4 = d1`, one alias) | still invalid, inside `rw2` | no |
| every alias (`rw2` reads and writes `d1` itself) | loud emit reject, `called at more than one argument type` | **yes** |
| the module-scope call `d1(n)` | loud emit reject, `called at more than one argument type` | **yes** |
| the final `print(d4(n))` | loud emit reject, `no interned signature` | **yes** |
| `d1(n)` made a string call (`d1(x)`) | loud emit reject, `called at more than one argument type` | **yes** |
| the holes (`(y: string) => …`) | check rejects, `expected string, got i32` | **yes** |
