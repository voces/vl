### D15382 — a record whose field is a list binding of an un-annotated function, written whole with a list literal of another member, is refused at emit

**open · loud emit reject · `emitProgram: object literal field count does not match struct` · clause 2 · the field written inline runs since D15351 · found closing D15351 · filed 2026-11-04 against master `063e6712`**

Repro:

    function id1(a) { return a }
    function id2(a) { return a }
    const xs = [id1]
    let r = { f: xs }
    r = { f: [id2] }
    print(r.f[0](2))
    print(r.f[0](2.5))

Want:

    2
    2.5

#### Mechanism

Not yet ablated past its ingredients. The written literal `{ f: [id2] }` resolves no struct row (`structIndexOfObjCtx`): the binding's record is `{f: typeof xs}`, which D15351's join does not re-type the written list to. Refused the same way on master before D15351.
