### D1310 — a struct `==` inside a closure with a BLOCK body, over a binding declared in a module BLOCK, refuses `struct equality is not supported yet`

**loud emit reject: `emitProgram: struct equality is not supported yet` · `vl check` rc 0 · clause 2 · PRE-EXISTING: identical on `seed-latest` (2026-09-03) · ZERO corpus cells · found 2026-09-03 by `matrix/box-field-struct-eq.matrix.vl`, which reds at exactly the three `*_capture` positions and at no other**

Repro:

    type A = { p: i32 }
    const same: A = { p: 3 }
    if true {
      const c: A = { p: 3 }
      const f = () => {
        print(c == same)
      }
      f()
    }
    // vl check rc 0; vl run -> emitProgram: struct equality is not supported yet

#### Mechanism

The compare is refused while the CAPTURED operand is resolved, not while a field is: the
field rep is irrelevant (a plain `i32` field refuses identically), and so is the second
operand's provenance. What the two ingredients have in common is that the operand is a
module-BLOCK binding read from inside a closure whose body is a BLOCK — the shape in which
the capture frame, not the binding, is what the struct-row resolver is handed.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the nullable/box field (plain `{p: i32}`) | still refuses | no |
| the closure's BLOCK body (`() => c == same`) | runs | **yes** |
| the module block (`if true { … }`) | runs | **yes** |
| the closure (compare in the block directly) | runs | no — subsumed by the two above |
