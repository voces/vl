### D16216 — a postfix `++` or `--` on an `f64` or `i64` name, used as a value, undoes its step with an `i32` operation

**closed 2026-11-14 · runs, prints `1.5` · was check-clean invalid wasm, `type mismatch` in the module's top-level code · closed by undoing the step at the place's own width (`emitExpr`'s postfix arm, `wasmEmit.vl`) · found by lane I closing D4055 · filed 2026-11-14 against master `685b59c13`**

Repro:

    let y = 1.5
    print(y++)
    // was, vl run: the emitted module failed to validate: type mismatch

Want:

    1.5

#### Mechanism

The postfix wrapper's value is the new value with the step undone, `(x + 1) - 1`. The undo was
emitted as `i32.const 1` and `i32.sub` whatever the place's type, so an `f64`, `f32` or `i64`
place built an invalid module. A statement-position `y++` discards the value and ran.
