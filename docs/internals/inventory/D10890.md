### D10890 — an un-annotated `.map` result over nullable records reads its elements as non-null records

**closed 2026-10-25 by PR #PRNUM · runs, prints `null` · built, not refused: a `.map` whose call is typed as a list of a nullable record takes the row of that element type, `| null` kept (`mfNulRecResultElemTy`, emit_classify.vl), interned at collect, instead of the callback's non-null record row · pins: `tests/cases/lists/map-nullable-record-result.vl` · the hole-function spelling `function t(x)` is still [D10891](D10891.md), and a union-arm record element is [D12820](D12820.md) · was loads then traps, `vl check` rc 0, `wasm trap: null reference` · clause 1 · found grading D10794 (the record spelling of its witness) · present on master `b84cf89cb` · filed 2026-10-23 against master `b84cf89cb`**

Repro:

    type P = { x: i32 }
    const a: P | null = null
    const m = [a].map((e) => e)
    for y in m { print(y?.x) }
    // vl check: rc 0.  vl run: wasm trap, null reference

Want:

    null

#### Mechanism

The list `m` holds `(ref null $P)` elements, but the `for` loop reads each one through
`ref.as_non_null` before the `?.` test, so the null element traps. The binding's element
kind is decided from the `.map` result as a non-null record, the record twin of D10794's
string read. Comparing an element with `null` instead (`print(y == null)`, or `m[0] == null`)
is the loud emit reject `struct equality is not supported yet`, the same lost `| null` seen
by the equality arm.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const m: (P \| null)[] = ...` | prints `true` for `y == null` | **yes** (the inferred binding) |
| the callback annotated `(e): P \| null => e` | still refuses `y == null` | no |
| `.filter((e) => true)` in place of `.map` | prints `true` for `y == null` | **yes** (`.map`) |
| the source annotated `const l: (P \| null)[] = [a]` | still refuses `y == null` | no |
| `const a: string \| null = null` | prints `true` for `y == null` | **yes** (a record element) |

#### Grading list

`print(y == null)` and `print(m[0] == null)` in place of `print(y?.x)`, each wanting `true`,
and the same inside a hole function `function t(x)` called with `a` (D10891's shape).
