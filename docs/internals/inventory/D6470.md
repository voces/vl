### D6470 — a generic parameter copied into a binding called at another type is one value called at two types, which one type parameter cannot build

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the program is well-typed, and `b = a` removed runs · found closing [D6423](D6423.md) · filed 2026-10-18 against master `b21da3d5d`**

#### Mechanism

From the ablation only. `b = a` makes `a` one value called at `string` through `take` and at
`i32` through `b`; the hole split gives a parameter a slot per call type only when each read is a
call or a forward, and a copy into a binding is neither, so `F` would be built at one instance.
Running it wants the per-call-type record the D3975 ruling describes, delivered through the copy.
