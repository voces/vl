#### Mechanism

From the ablation only. A direct call checks each argument against its hole's array demand
(and, since [D6332](D6332.md), its write demand). A method call's receiver fills the same
`self` hole by another path, which checked neither, so a string reached the `.push` lowering.
The checker owes the refusal the direct spelling gets.
