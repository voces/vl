### D3420 — a call, alias or closure write in the else arm of a hole field's `is` test does not end the remainder the instance reads

**loads then traps · clause 1 · open · pre-existing, the same on master `5e277ab52` · 11 cells of lane NW's `nw/g3` grid · filed 2026-09-30 against master `5e277ab52`**

Repro:

    type A = { v: i32 }
    type B = { s: string }
    type W = { h: A | B, n: A | null }
    function wA(w: W) { w.h = { v: 7 } }
    function F<Z>(z: Z) {
      if z.h is A {
        print(z.h.v)
      } else {
        wA(z)
        print(z.h.s)
      }
    }
    const x: W = { h: { s: "bee" }, n: { v: 1 } }
    F(x)
    // vl check: rc 0.  vl run: wasm trap, cast failure

#### Mechanism

Not localised past the ablation. The direct spelling refuses the read (`'z.h' is no longer
narrowed to B: the call to 'wA' … may reassign it`). In the `<Z>` body the else arm of `is` on a
hole field carries no path narrowing the call can end, so the read after the call is typed at
the field's hole and no pin re-asks it, while the instance's emitter narrows the else arm to the
remainder `B` itself and nothing retires that after the call. A literal write in the same arm
is D3233's shape and refuses at the pin.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `function F(z: W)` | check refuses | **yes** (a hole or type parameter) |
| `function F(z)` | check refuses; traps for a nested field `z.w.h` | no, for a nested field |
| the call in the then arm | check refuses | **yes** (the else arm) |
| `z.h = { v: 9 }` in place of the call | check refuses at the pin | **yes** (a call, alias or closure write) |
| `const al = z` then `al.h = { v: 8 }` | traps | no (any write the body cannot name) |

#### Grading list

The `nw/g3` cells `*_isA_{call,alias,clo}e_{gen,hole}` (11 traps) and their `isB` twins, which
run only because the value takes the then arm.
