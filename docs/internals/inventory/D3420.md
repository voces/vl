### D3420 — a call, alias or closure write in the else arm of a hole field's `is` test does not end the remainder the instance reads

**closed 2026-09-30 · now a loud check reject, as the direct spelling · was loads then traps, clause 1, pre-existing on master `5e277ab52` · 11 cells of lane NW's `nw/g3` grid · filed 2026-09-30 against master `5e277ab52`, closed against master `47aa2950b` · fixtures `tests/cases/generics/error-hole-field-else-arm-write-ends-remainder.vl`, `tests/cases/generics/hole-field-else-arm-admitted-write-keeps-remainder.vl`**

Repro:

    type A = { v: i32 }
    type B = { s: string }
    type W = { h: A | B, n: A | null }
    function wA(w: W) { w.h = { v: 7 } }
    function F<Z>(z: Z) {
      if z.h is A {
        print(z.h.v)
      } else {
        wA(z)
        print(z.h.s)
      }
    }
    const x: W = { h: { s: "bee" }, n: { v: 1 } }
    F(x)
    // vl check: rc 0.  vl run: wasm trap, cast failure

#### Mechanism

Not localised past the ablation. The direct spelling refuses the read (`'z.h' is no longer
narrowed to B: the call to 'wA' … may reassign it`). In the `<Z>` body the else arm of `is` on a
hole field carries no path narrowing the call can end, so the read after the call is typed at
the field's hole and no pin re-asks it, while the instance's emitter narrows the else arm to the
remainder `B` itself and nothing retires that after the call. A literal write in the same arm
is D3233's shape and refuses at the pin.

| `const al = z` then `al.h = { v: 8 }` | traps | no (any write the body cannot name) |

#### Close

The else arm of `is T` on a hole's field, for a record `T`, now carries the hole itself as the
place's fact (`collectElseNarrowsRaw`), and `holeElseTested` records `T` for it. A call, closure
or alias write in the arm then ends that fact as it ends any path narrowing, and a member read
after it is re-asked at the pin (`noteMemCstr`), where the field's full union refuses `.s` as
the direct spelling does. For an un-annotated parameter the re-ask is taken only for such an `is`
remainder ended by a write, a call `callKillSure` settles, or an alias write
(`holeRemainderEndedSure`), so a read a hole callee's opaque call ended keeps its old outcome
([D3325](D3325.md)). An alias write that stores no `T` (`tyMayHoldTy`) lands in the remainder and
keeps it, as the direct spelling keeps it.
