Repro:

    function f(): f64 {
      let v: boolean | f64 = 1.5
      const k = (): void => { v = true }
      if v is f64 {
        const r = (): f64 => v * 2.0
        k()
        return r()
      }
      0.0
    }
    print(f())
    // vl check: rc 0.  vl run: wasm trap: cast failure

#### Mechanism

A lambda body is checked where it is written, under the narrowings live there, and the emitter
replays the same narrowings into the lifted body (`capNarrowRecord`). But the body runs when it
is CALLED: `k()` sets `v` to `true` in between, and `r()` then reads the cell as the f64 member.
D2390 ends the narrowing in the enclosing body at `k()`, which is correct and does not reach a
body already checked. A captured narrowing is sound only for a binding nothing writes after the
closure is made; for a closure-written binding the lambda body should read the declared type.

#### Grading list

The same with `r` stored and called from another function; with a path narrowing (`o.v`)
captured instead of a bare name.

#### Close

A nested function made under a narrowing of a binding some function may write
(`crCaptureWiden`) either keeps the narrowing or reads the binding at its declared type. It keeps
it when it is called only by its handle in the body that makes it, its own body neither writes
nor tests the binding, and then every call of it is refused unless the binding still holds the
captured type there (`crCapRecCheck`); it keeps it too as a lambda handed straight to an array's
`map`/`filter`, or to a declared function that only calls that parameter, when the call
reaches no writer. Otherwise (it escapes, writes or re-tests the binding) the body reads the
declared type, and the emitter skips replaying that narrowing into it (`capWidenOf`). A path read
under the narrowing by a nested function makes a later writing call refused
(`crCaptureCallCheck`), except a call of that function itself; every later writer is asked,
whether or not an earlier call already ended the narrowing, unless the reader's only handle has
gone out of scope without escaping. A lambda a generic's instance clones
answers what its template did (`recordClonedCallRetire` at the lambda mints). The re-test variant printed a
wrong `-2` before; it prints `2`.
