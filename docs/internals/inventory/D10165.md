### D10165 — a generic returning an inner `let x = w` under an outer literal `const x = 7` emits invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · `type mismatch: expected (ref $3), found i32` inside `g` · clause 1 · was a loud emit reject on master `9ca7e7751` (`field access receiver is not a struct`), the `const` face of [D3327](D3327.md) · found closing D3327 · filed 2026-10-22 against master `9ca7e7751`**

Repro:

    function g<T>(w: T) {
      const x = 7
      if true {
        let x = w
        return x
      }
      w
    }
    const r1 = g({ a: 1, b: "r" })
    print(r1.b)
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `g`: type mismatch: expected (ref $3), found i32

Want:

    r

#### Mechanism

Not traced. The return set at the pin now joins the inner `x`'s record, so the instance's result
is the record. The returned `x` still lowers as an `i32`, which looks like the outer
`const x = 7` being substituted for the name in the emitted body. An annotated
`const x: i32 = 7` runs.
