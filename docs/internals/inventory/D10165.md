#### Mechanism

`monoInferRetSetUnionName` and `monoInferRetExprTy` re-check each return expression alone, after
the body's scopes have closed. There the returned `x` resolves to the outer `const x = 7`, and the
literal-const inliner (`lbiInlineLit`) rewrites the Ident node in place into the literal `7`. The
instance's result type is the record, read from the pinned re-check, but the node now returns an
`i32`. The `f64` face, an inner `let x = 2.5` under `const x = 7`, printed `7`: runs but wrong
value. The fix raises `lbiKeepName` around those bare re-checks, so the name stays a name.
