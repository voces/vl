### D2413 — a `u8[]` binding a closure writes is boxed into a cell whose element read no classifier names as the byte list

**loud emit reject · clause 2 · pre-existing on master `a277bf7b0` · filed 2026-09-25 against
`a277bf7b0`, found grading [D2399](D2399.md)**

Repro:

    function f() {
      let v: u8[] = [1]
      const q = () => { v = [2, 3] }
      q()
      print(v.length)
    }
    f()
    // vl check: rc 0.  vl run: emitProgram: '.length' on a receiver the emitter cannot classify as a list, string, map or set

#### Mechanism

A binding a closure writes is boxed into a one-element cell, and every read becomes `v[0]`
(`captureBoxRewrite`). For the other element types the cell's element read classifies as the
list it holds; for the packed byte list no receiver classifier answers `u8list` from the
cell's element, so `.length` has no receiver kind and refuses. The same refusal reaches
`u8[] | null` under `if v != null`.

#### Ablation

| ingredient removed | outcome on `a277bf7b0` | needed? |
| --- | --- | --- |
| the closure's write (`const q = () => { v }`) | runs | **yes** |
| `u8` for `f64` | prints `2` | **yes** |
| the nullability (`u8[]`, not `u8[] \| null`) | still refuses | no |
