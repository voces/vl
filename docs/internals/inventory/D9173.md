### D9173 — a list of un-annotated functions nested in another list, called inside a `.map` callback, has no function to call

**loud emit reject · `vl check` rc 0 · `emitProgram: call to unknown function` · clause 2 · found closing [D9093](D9093.md) · filed 2026-10-21 against master `c2df9510f`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    const ws = [[inc0, dbl]]
    print(ws[0].map((f) => f(3))[1])
    // vl check rc 0.  vl run: emit error: emitProgram: call to unknown function

#### Mechanism

Not traced. D9093's close types a list from a callback's calls when the receiver is a
binding whose annotation a pin wrote; a receiver that is an element of another list has no
such binding.
