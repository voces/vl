**runs today and must keep running · legacy class, open · clause 2 · as shipped it runs, by the IR's claim of the function; claimless (legacy alone) a loud emit reject, `vl check` rc 0, "emitProgram: ref valtype with no interned shape" · a claim that declines or falls back ships the refusal · found by IR-N4 locating D17201 · owner IR-N4 · filed 2026-11-24 against the #9936 head `5dc627a17`, claimless built from that tree's own source (`CLAIMED` emptied as `ir-identity.sh --build-claimless` does)**

#### Mechanism

Legacy's lowering of the argument boxes the join into `A | B | null` (`emitUnionBoxArg`) and
reaches a ref valtype for the join's record arm with no interned row, so `fbValtype`'s bound guard
refuses. The rung that asks for the row is not yet named; the annotated binding's delivery is not
reached. As shipped the IR claims `arm`, so legacy never lowers it; the same holds at module
scope, in a generic function and in a closure.
