Want:

    1.5

#### Mechanism

The smallest program of the family needs neither the annotation nor a second map:

    function half(a) { return a / 2.0 }
    const m4 = Map()
    m4.set("a", half)
    const ys = [m4]
    print(ys.length)

A probe at `monoPinListElems` printed `ys`'s elaborated type as open (`_`), the checker's as
`{[string]: (_) => _}[]`, and its slot fact (`elabSlotTyAt`) as `{[string]: (i32) => i32}[]`. The
global cell's `letCellSlot` was -1. `monoPinListElems` reads only the path `["e"]` of a function
element. It never read that fact for a list whose elements are maps, so a list nothing calls
through stayed open. A call through it (`ys[0].get("a")!(3)`) pins it, and that ran.
