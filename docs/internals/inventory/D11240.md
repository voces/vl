### D11240 — an un-annotated `let` seeded by a call returning a numeric literal union takes a ref slot once it is reassigned, while each value stored is the bare scalar

**check-clean invalid wasm · clause 1 · filed 2026-10-23 against master `c5a14222d`**

Repro:

    type N2 = 1 | 2
    function g(): N2 { return 1 }
    function f() {
      let v = g()
      v = g()
      print(v + 10)
    }
    f()
    // vl check: rc 0.  vl run: invalid module inside `f`: type mismatch: expected i32, found (ref $type)

Want:

    11

#### Mechanism

`N2` reps as its base `i32`, and `g()` returns that scalar. When the `let` is reassigned, the
binding's slot is typed as a ref, so the scalar that `g()` returns no longer fits the slot.
Without the reassignment the slot is the `i32` and the program runs. The same failure happens at
top level, where it is reported in the module's top-level code.
