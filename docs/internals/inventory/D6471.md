### D6471 — two record literals each holding a generic function, called at different types, handed to one parameter of a narrower declared record, are refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same two records handed to two parameters of one declared type run · found closing [D6422](D6422.md) · filed 2026-10-18 against master `b21da3d5d`**

Repro:

    type G = { g: i32 }
    function k<T>(x: T): T { return x }
    function k2<T>(x: T): T { return x }
    function show(o: G) { print(o.g) }
    const r = { f: k, g: 7 }
    print(r.f(1))
    show(r)
    const r2 = { f: k2, g: 7 }
    print(r2.f("s"))
    show(r2)
    // vl check: rc 0.  vl run: emitProgram: a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type

Want:

    1
    7
    s
    7

#### Mechanism

From the ablation only. The two literals share one shape and so one row; a parameter given both
reads that row's function field at one signature, which neither literal's calls fix alone.
