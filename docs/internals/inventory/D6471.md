**closed 2026-10-18 by lane L1 · runs, prints `1 7 s 7` · was loud emit reject · `vl check` rc 0 · clause 2 · the flow walk of a generic callee now keys a call handing it an open generic signature by the call site even when the signature arrives inside a widened record, so the two records no longer join; a record handed to a parameter declared as a closed record type holding no function cannot have a function read out of it, so the monomorphizer treats that argument as inert; the inline-literal and two-type spellings are [D6701](D6701.md) and [D6702](D6702.md) · pins: `tests/cases/objects/records-of-generics-at-two-types-into-one-narrower-param.vl` · found closing [D6422](D6422.md) · filed 2026-10-18 against master `b21da3d5d`**

#### Mechanism

From the ablation only. The two literals share one shape and so one row; a parameter given both
reads that row's function field at one signature, which neither literal's calls fix alone.
