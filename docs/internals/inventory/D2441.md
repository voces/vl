### D2441 — a value-position assignment to a binding a closure also assigns has no lowering

**loud emit reject · clause 2 · filed 2026-09-25 against master `a20d69104`, the review
residue of [D2391](D2391.md)'s close**

Repro:

    function g() {
      let v: i32 | string = "s"
      const k = () => { v = 7 }
      const r = (v = 3)
      k()
      print(r + 1)
    }
    g()
    // vl check: rc 0.  vl run: emit error: only an identifier assignment is a value expression

#### Mechanism

The closure's write boxes `v` into a cell, so the capture rewrite turns `v = 3` into
`v[0] = 3`. `assignTargetReReads` admits an index target only when its checked type is the
assignment's, and the rewrite (per `cboxWalk`'s own comment) types the cell read at the declared union while the value is
typed `i32`, so the `=` arm declines and refuses. A statement-position write runs.

On `dist/vl` built from `a20d69104`.
