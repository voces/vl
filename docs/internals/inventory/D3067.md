### D3067 — a hole function's `.filter` or `.map` callback that captures is invalid wasm at a non-`i32` list pin

**closed 2026-09-28 — the witness prints `a` · was check-clean invalid wasm · `monoCloneLambdaSubst` pins a hole instance's lambda through the instance's hole binding, and the template every instance cloned is pruned (`monoLamSlotIsHoleTemplate`) · grid rows graded against master `d408f2da4`, 0 runs lost · fixture `tests/cases/generics/hole-callback-reads-element-and-captures.vl` · first filed as: check-clean invalid wasm · clause 1 · found grading D3060's receivers · the same on master `6c2dafc0b` · filed 2026-09-28 against master `6c2dafc0b`**

Repro:

    function g(h, z) {
      return h.filter((e) => e != z)
    }
    const b: string[] = ["a", "b"]
    print(g(b, "b")[0])
    // vl check: rc 0.  vl run: invalid module inside `g`, expected i32, found (ref $type)

Want:

    a

#### Mechanism

A hole function's callback lambda is typed at the hole's variable, and the lambda clone (`monoCloneLambdaSubst`) substituted only through the parameter binding, which for a hole function is empty: the callback kept the template's `i32` element. The clone now joins the instance's hole binding (`monoJoinBinding`), so its parameter and return are annotated at the pin, and a template every instance cloned is pruned (`monoLamSlotIsHoleTemplate`), since its body still reads the `i32` element and would not validate.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `(e) => true`, no capture, no element read | prints `a` | **yes** |
| `(e) => e != "a"`, no capture | invalid wasm ([D3083](D3083.md)) | no |
| a capture of `h` instead of `z` (`h[0] = z`, `h.length`) | invalid wasm | no |
| `.map` in place of `.filter` | invalid wasm | no |
| an `i32[]` pin | runs | **yes** |
| an `f64[]` pin | invalid wasm | no |
| a record-list pin | loud emit reject, list type not collected | no (a sibling) |
| `function g<T>(h: T[], z: T)` | prints `a` | **yes** (the hole) |
| the clone without the hole binding, or without the prune | invalid wasm | **yes** (the fix, both halves) |
