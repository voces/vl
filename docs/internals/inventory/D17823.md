Repro:

    function inc(a) { return a + 1 }
    function id<T>(t: T): T { return t }
    const g = id(inc)
    print(g(4))
    const k: (a: i32) => i32 = g
    print(k(4))
    // vl run: emitProgram: cannot take the generic function `inc` as a value

Want:

    5
    5

#### Mechanism

The direct call `g(4)` makes the tag decision tag `{inc}`, so `g` holds the set's id, and the
closed delivery builds `fvaAdapt`'s stable adapter `($fp0: i32): i32 => g($fp0)` around a minted
`g`. `fvaCopyCalleeAtInstance` retyped that callee read to the adapter's closed signature, so
emit read `g` as a plain closure, followed `id(inc)` to `inc`, and refused it as a value. A
hand-written `(x: i32): i32 => g(x)` ran. Without the direct call nothing is tagged and the copy
is the closure it needs.

| --- | --- | --- |

| `inc`'s hole (`inc(a: i32)`) | runs | **yes** |
| the let destination (a parameter `k: (a: i32) => i32` of a called function) | still refuses | no |
