### D2627 — the arm join after a one-branch write absorbs a numeric member into the one it widens to

**closed 2026-09-26 — the filed repro runs and prints `true` · was a loud check reject, clause 2,
and under #3184's first candidate a check-clean trap · filed 2026-09-26 against master
`06930fb68`, found by the review of #3184 · fixture
`tests/cases/soundness/narrowed-write-join-keeps-numeric-members.vl`**

Repro:

    function c1(): boolean { return true }
    function src(): i32 | f64 | null { return 5 }
    function go() {
      let x: i32 | f64 | null = src()
      if x is i32 {
        if c1() { x = 1.5 }
        const y: i32 | f64 | null = x
        print(y is f64)
      }
    }
    go()
    // now prints `true`

#### Mechanism

After an `if` whose arm wrote a name or place, the checker joins the arms' end types with
`joinTys`, whose first step is mutual assignability, and `i32` is assignable to `f64` by
widening. So `i32` (the untaken path) and `f64` (the write) joined to `f64`, a type the place
does not hold when the arm did not run: the value is the `i32` member of the declared box. Master
did not trust the join in the emitter and refused `x is i32` after it as a test that can never
match; a candidate that trusted it unboxed the `i32` member as an `f64` and trapped. The close
joins arm end types with `narJoinTys`, which keeps a numeric member no variant of the other side
IS as its own member (`i32 | f64`), and otherwise joins as before.

An `else if` chain with no final `else` had the same fault from another cause, found by #3184's
re-review: the link has no block of its own, so its arm's write sat at the depth the outer `if`
reads as the else arm's own statements and counted as unconditional, which dropped the path
where no arm ran (`i32 | string | null` narrowed to `i32`, then `if a { x = "s" } else if b {
x = "t" }`, joined to `string` alone and trapped; the `i32 | string` spelling trapped on master
too). The close takes a link's end type from the link's own join (`narChainEndTy`), which does
count that path, and records the outer statement's join so the emitter pushes it.

#### Ablation

| ingredient changed | outcome on master | needed? |
| --- | --- | --- |
| the write in both arms | runs | **yes** (a one-branch join) |
| `i32 \| string` for the declaration | runs | **yes** (a member that only widens) |
| `f64 \| f32`, `i64 \| i32` | refused the same way | no |
| a field, list cell or map cell for the name | refused the same way | no |
| an `else if` chain of two or three links, no final `else` | the join drops the no-arm path | no (same join, D2627's second cause) |
