#### Mechanism

A stored generic that nothing calls is typed at the uncalled slot type when its read is in
`monoInertValues` / `monoInertCalled`, and the read of `id` in `fill` is noted there. `fill`'s
parameter is un-annotated, so each instance compiles a copy of its body
(`monoCloneGenericCallsRaw`, emit_mono.vl), and the copy's read of `id` is a freshly minted
node that carried none of the original's marks: the copy's `id` reached the emitter open. The
clone now carries both marks onto the node it mints, so every copy's read is as inert as the
original's.
