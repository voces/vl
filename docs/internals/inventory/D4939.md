### D4939 — a captured, field or element receiver that `is` fits as an empty list of another arm traps on its narrowed read

**closed 2026-10-15 — now prints `0` · was trap after load, clause 1 · a narrowed list read whose payload is another arm's wrapper now builds an empty list of the tested arm instead of casting; a `.push` receiver keeps the cast (D4949) · found closing D4915 · filed 2026-10-15 against branch `fix-list-union-is-empty` over master `c2dbf639e` · pin: `tests/cases/unions/empty-list-is-no-store-back.vl`**

Repro:

    function cap(a: f64[] | string[]) {
      const f = () => if a is string[] { a.length } else { 9 }
      print(f())
    }
    const ef: f64[] = []
    cap(ef)
    // vl check: rc 0.  vl run: wasm trap: cast failure — a value was not an instance of the type it was narrowed to

Want:

    0

#### Mechanism

D4915's close answers `is string[]` true for an empty `f64[]` (D4771) and re-boxes the
receiver as an empty `string[]` so the then-branch reads that arm. It can store back only to a
local or a global; a captured variable, a record field (`b.items`) and a list element
(`arr[0]`) keep the `f64[]` payload, and the narrowed read casts it to the `string[]` wrapper.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `a` read in `cap` itself, not the closure | prints `0` | **yes** (a receiver with no store-back) |
| `print("cs")` in place of `a.length` | prints `cs` | **yes** (a narrowed read) |
| `const ef: f64[] = [1.5]` | prints `9` | **yes** (empty) |

#### Grading list

`b.items.length` on `type Box = { items: i32[] | string[] }` holding an empty `i32[]`, and
`arr[0].length` on `(i32[] | string[])[]` holding one.
