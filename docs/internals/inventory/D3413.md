### D3413 — a lambda inside a hole's body that reads the parameter's atom-valued map cannot print the result

**loud emit reject · clause 2 · open · found by the #3318 review (`g2/r12`) · the same on master `8df60e472` · filed 2026-09-30 against master `8df60e472`**

Repro:

    type AB = "a" | "b"
    type A = { n: {[i32]: AB} }
    function mkA(): A {
      const n: {[i32]: AB} = Map()
      n[0] = "b"
      { n: n }
    }
    function use(p) {
      const g = (i: i32) => p.n[i] ?? "a"
      print(g(0))
    }
    use(mkA())
    // vl run: emitProgram: print of a literal-union atom whose type carries no member texts

#### Mechanism

Not traced. The lambda is lifted out of the instance and may be shared by every instance, so
the per-instance readers decline inside it (`holeOperandTyOf`, D2921), and the call's result
type is the lambda's inferred return, which names the hole. `print` classifies the result as an
atom (the call returns an i32) and finds no member texts to spell it with.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `function use(p: A)` | prints `b` | **yes** (the hole) |
| `function use<T>(p: T)` | the same refusal | no |
| the read outside a lambda, `print(p.n[0] ?? "a")` | prints `b` | **yes** (the lambda) |
