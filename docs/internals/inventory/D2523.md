### D2523 — a closure capturing a `let` bound from a `T | null` loop variable finds no union for it

**loud emit reject · clause 2 · pre-existing on master `ca544493e`, and after [D2521](D2521.md)'s close · found by D2521's ablation · filed 2026-09-25 against master `ca544493e`**

Repro:

    const xs: (i32 | null)[] = [3, null]
    for v in xs {
      const w = v
      const g = () => {
        if w != null { return w + 1 }
        return -1
      }
      print(g())
    }
    // vl check: rc 0.  vl build: emitProgram: bare null needs a struct-typed context

#### Mechanism

Not traced; a prediction to grade. The closure resolves `w`'s member set through
`capturedUnionName` → `letUnionNameOf(w, parent)` → `unionNameOfExpr(v, parent)`, and a loop
variable's union is answered by `forInLoopVarUnionName`, which reads the LIVE scope slot. The
closure's env field and body are typed with no scope of the parent frame bound, so the chain
answers "" and `w` is not seen as the box. [D2521](D2521.md) closed the same gap for the loop
variable captured directly, whose rung reads the `for` node instead of a slot.
