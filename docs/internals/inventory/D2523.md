#### Mechanism

The prediction held. The closure resolves `w`'s member set through `capturedUnionName` →
`letUnionNameOf(w, parent)` → `unionNameOfExpr(v, parent)` → `unionNameOfIdentAt`, whose loop
rung `forInLoopVarUnionName` reads the live scope slot, and none of the walking frame's slots is
live while a closure body is emitted. `readLoopUnionName` (`emit_classify.vl`) is the rung
after it: the `for-in` loop enclosing the read, found by `readLoopNodeOf`, names the iterable's
element set. Closing the refusal alone would have been loud→invalid: the env field of `w` was
typed `i32` for the same reason, which [D3139](D3139.md) fixes in `letIsUnion`.
