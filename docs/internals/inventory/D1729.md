### D1729 — the COMPLEMENT of a literal `is` at an index place keys nothing, because the rungs that claim it subtract from a set canon already softened

**closed 2026-09-06 · found by an `array_element_place` matrix position that did not exist,
and needed BOTH halves: the rung's own `Ident`-only ladder and its ORDER · 0 corpus cells**

Repro:

    const xs: (i32 | "err")[] = [5]
    if xs[0] is "err" { print(0) } else { print(xs[0] * 2) }
    // prints 10

#### Mechanism

`litElseNarrow` is the rung that answers a literal complement from the ARENA, because by the
time the emitter subtracts from a member set canon has softened `"err"` to `string` and the
tested member is not there to remove (D1193). It had an `Ident`-only receiver ladder, so an
element place keyed nothing and fell through.

Giving it the place key alone does NOT fix the cell, which is the half a reading would miss.
The two PLACE arms of `setNarrowFromCondElse` sit ABOVE it and subtract from that same
softened set: finding no `"err"`, they push the whole set back and return true, so the rung
below never runs and `narrowedValueAtomOf` has a two-atom spelling and no atom. The rung now
runs ahead of them. An `Ident` receiver reaches it either way, so the order decides only a
place's answer.
