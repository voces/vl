### D4269 — a list-valued field named like a scalar field of a union's record arm reads as that scalar and emits invalid wasm

**closed 2026-10-27 · runs today and must keep running · fixed by D14493: the literal `{ a: [7] }` keeps its own row, since the checker's row for it is no arm of `i32 | { a: i32 }`, and the field-name arm scan that matched it to `{ a: i32 }` is deleted · was check-clean invalid wasm · clause 1 · the list face of D3461, split out of it when D4056 fixed its record face · filed 2026-10-12 against master `641b6f84d`**

Repro:

    const v: i32 | { a: i32 } = 5
    const n = { a: [7] }
    print(n.a[0])
    // vl check: rc 0.  vl run: invalid module, "type mismatch: expected i32, found (ref $type)"

    7

#### Mechanism

[D3461](D3461.md)'s `{ a: { b: 7 } }`; a list-valued field still meets the arm's `i32` field `a`
where the list should be.
