### D4883 — an `if` bound to a local in a generic body, joining a parameter's list with another list, has no list rep at a nullable-element pin

**loud emit reject · clause 2 · found by L2 §13.30, the binding position of D4862 · filed 2026-10-15 against master `5be21bb0a`**

Repro:

    function g<T>(t: T, b: boolean, q: i32[]) {
      const v = if b { [t] } else { q }
      print(v.length)
    }
    const x: i32 | null = null
    const q2: i32[] = [5, 6]
    g(x, true, q2)
    g(x, false, q2)
    // vl check: rc 0.  vl run: emitProgram: `.length` receiver's ref-list element does not resolve

#### Mechanism

Not yet ablated past the table below. The same join RETURNED from a generic body runs (D4862's
close re-joins the body's return values, keeping apart each list not a fresh literal); bound to a local
it goes through the body's `if` join and the pin's local re-type, which D4862 did not touch.
The direct spelling refuses the join, so the program the pin should see is a check reject or a
kept-apart pair, not a list with no element rep.
