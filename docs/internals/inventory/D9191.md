### D9191 — a record literal whose field is an `if` choosing generic functions, read and called in place, refuses

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same record bound to a `const` first runs, and so does a single generic in the field · found closing [D9160](D9160.md) · present on master `8747b6432` · filed 2026-10-21 against master `8747b6432`**

Repro:

    function idg<T>(t: T): T { return t }
    function kg<T>(t: T): T { return t + t }
    const c = [1].length > 0
    print({ h: if c { kg } else { idg } }.h("s"))
    // vl check rc 0, vl run: emitProgram: a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type

#### Mechanism

Not traced. The call through the field does fix the type, `(string) => string`, but the
emitter does not see that call from the choice's arms when the record is a literal that no
binding holds.
