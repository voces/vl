### D2872 — module-scope value writes inside one function cost a scan of every earlier local and a shift of every later statement

**closed 2026-09-27 — runs today and must keep running · the defect was its cost: `n` statements `const y<i> = (a = h(<i>))` inside one function, `a` a module `f64`, compiled in 3.27G / 12.25G / 48.91G guest fuel at n = 3,000 / 6,000 / 12,000 (quadratic) against 0.93G / 2.17G / 5.57G for the same lines at module scope; now 0.83G / 1.67G / 3.36G in the function and 0.78G / 1.56G / 3.13G at module scope, linear · filed 2026-09-27 against master `460a67010`**

Repro:

    function h(i: i32): i32 { i }
    let a: f64 = 0
    function main() {
      const y0 = (a = h(0))
      const y1 = (a = h(1))
      const y2 = (a = h(2))
      print(a)
    }
    main()
    // prints 2; the cost grows with the square of the number of `const y<i>` lines

Want:

    2

#### Mechanism

Two per-statement walks, each linear in the statements already seen. `igWalk`
(compiler/emit_sections.vl, the read-before-init guard scan of D2652) kept the names a
parameter or local binds as a list and asked `strListHas` of it for every identifier, so each
`a` and `h` scanned every earlier `y<i>`: `strListHas` 49.9% inclusive and `__str_eq__` 25.6%
self of the n = 3,000 build. `igWalk` now carries an `IgShadow`, the same stack plus a count
per name, pushed and popped in lockstep. Second, `asvList` (compiler/emit_rewrite.vl, D2398's
value-write spill) spliced each moved write into the statement list by shifting every later
statement, 16.8% self at n = 12,000 once the first was gone; it now walks every statement and
rebuilds the list once, which is safe because no walk reads the list it is rewriting. Neither
is a memo: the count lives for one walk, and the rebuild keeps node creation in the same order.
Output is byte-identical over `tests/cases` and `std` (3,222 modules, 0 differ).

#### Ablation

| the type difference (`let a: i32`) | `asvList` moves nothing; master 1.10G → 3.22G for 3,000 → 6,000 | half: the `igWalk` scan remains |
