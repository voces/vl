### D5119 — the module-scope `else` of `is i32[]` over a generic instance's returned `T[] | i32[]` finds no member set

**loud emit reject · `vl check` rc 0 · clause 2 · found closing D5111 · the same on master `40ea46748` · filed 2026-10-16 against master `40ea46748`**

Repro:

    function w<T>(t: T, b: boolean) {
      if b { return [t] }
      [1, 2, 3]
    }
    function rest<T>(t: T, b: boolean) {
      const u = w(t, b)
      if u is T[] { return w(t, false) } else { return u }
    }
    const v = rest("s", false)
    if v is i32[] { print(1) } else { print(9) }
    // vl check: rc 0.  vl run: emitProgram: union atom has no value box

Want:

    1

#### Mechanism

The refusal is at the module-scope `else` arm. Pushing that complement asks the member-set pool
for the union's set by its spelling, `string[]|i32[]`, and gets no set, though the pool holds a
row with that rendering. So the complement binds no type and the arm's read takes the scalar
union path. Inside a function the same `if`/`else` runs. Not ablated past the ingredients below.
