#### Mechanism

The refusal is at the module-scope `else` arm. Pushing that complement asks the member-set pool
for the union's set by its spelling, `string[]|i32[]`, and gets no set, though the pool holds a
row with that rendering. So the complement binds no type and the arm's read takes the scalar
union path. Inside a function the same `if`/`else` runs.

The set was missing because `msSetOfText` banked a miss per spelling, stamped only with the
pool's generation. A module-scope walk asks for `string[]|i32[]` before `rest<string>`'s
returned-union row is registered, and registering a row does not advance that generation, so
the stale miss hid the row carrying that very key. The close removes the miss bank; a miss
asks the key lookup (`unRowOfSetText`), a key render and a map probe.
