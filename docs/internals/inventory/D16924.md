### D16924 — a lambda's list literal at a generic's `() => (T | null)[]` is refused at check

**loud check reject · clause 2 · `a function of type () => i32[] cannot be used as () => (i32 | null)[] here` · pre-existing on master `3f567259f` · found grading [D16918](D16918.md) · filed 2026-11-17 by lane AE4**

Repro:

    function gen<T>(f: () => (T | null)[]) { return f().length }
    print(gen(() => [1]))

Want:

    1

#### Mechanism

Not traced. A bare `T` inside the nullable binds through the ordinary walk, not a union arm, so
D10133's bound-type delivery, where [D16918](D16918.md) builds the lambda's literal at the bound
type, is not entered, and the plain delivery refuses a list that would have to widen.
