### D17541 — `m[k]?.f ?? d` over a map whose record value holds `f` as a value-union box has no leaf for the box

**loud emit reject · clause 2 · owner COV-UNION · found by COV-UNION's staged-receiver position sweep · filed 2026-11-25 against master `4fbb60971`**

Repro:

    type J = { f: i32 | null }
    const m: {[string]: J} = Map()
    m["a"] = { f: 2 }
    print(m["a"]?.f ?? 0)
    // vl check: rc 0.  vl run: emit error, `?.` over a map read has no `if` blocktype for this field's rep

Want:

    2

#### Mechanism

`emitCoalesceOptMapField` (the fused `mapField` arm of `coalOptArmOf`) reads the field off the
probe's hit through `optLeafKindOf`, which answers only a plain numeric leaf (`i32`, `i64`, `f64`,
`f32`). A field the value row holds as a value-union box (`T | null`, `A | B`) has no leaf there, so
the arm refuses; the nullable-record arm has a box leaf for the same field
(`emitOptCoalesceBoxLeaf`), and the same read through a local takes it.

#### Ablation

| spelling | outcome |
| --- | --- |
| `f: i32 | null` (the witness), `f: f64 | null`, `f: i32 | string`, an `i32` key | refuses |
| `f: i32` (no box) or `f: string | null` (a niche, no box) | runs |
| `const j = m["a"]` then `j?.f ?? 0` | runs |
