### D9862 — a `.map` over a list of an un-annotated function, its named callback un-annotated, has no list type where its result is returned or stored

**loud emit reject · `vl check` rc 0 · `index receiver is not an array or string` · clause 2 · 12 of 24 un-annotated cells of matrix `fn-value-hole-list-named-callback` · found closing [D9761](D9761.md) · filed 2026-10-22 against master `ba2918226`**

Repro:

    function inc(a) { return a + 1 }
    const v = [inc]
    function ap(r) { return r(5) }
    function mk() { return v.map(ap) }
    print(mk()[0])
    // vl check rc 0.  vl run: emit error: emitProgram: index receiver is not an array or string

Want:

    6

#### Mechanism

The checker types `v.map(ap)` as `_[]`: the element `(_) => _` is open, so `ap`'s body result is
read at no closed parameter (`holeFnArgRetAtParams` refuses an open one). [D9761](D9761.md)'s
close records the closed result on the `.map` node at the monomorphizer and retypes the reads of
an un-annotated binding it initialises. A returned value, a record field, a list element, a map
value, a global read in another frame and a capture each keep the checker's `_[]`. The lambda
spelling runs at every position, because the checker closes a hole lambda's body at the element.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |

| the un-annotated callback, for `ap(r: (a: i32) => i32): i32` | runs, `6` | **yes** |
| the inferred return, for `mk(): i32[]` | runs, `6` | **yes** |
