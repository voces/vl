### D3418 — a generic `??` over `V | null` with a bare `null` argument and a float literal default, at an `f32` collection, is check-clean invalid wasm

**check-clean invalid wasm · clause 1 · open · the generic twin runs at `f64`; the non-generic spelling runs at `f32` · found by the #3318 review (`rv3318-4082`, `g1` f32 `coal` and `store` cells) · the same on master `5e277ab52` · filed 2026-09-30 against master `5e277ab52`**

Repro:

    function g<V>(m: Map<string, V>, v: V | null, d: V) { m.set("a", v ?? d) }
    const m: Map<string, f32> = Map()
    g(m, null, 2.5)
    print(m.get("a") ?? 0.0)
    // vl check: rc 0.  vl run: invalid module in the top-level code,
    // `type mismatch: expected (ref $type), found (ref $type)`

#### Mechanism

A prediction. `V` is bound to `f32` by the collection, while the bare `null` binds nothing and
the literal `2.5` types its own parameter at the default `f64`, so the coalesce's result is an
`f64` delivered to an `f32` slot. The eight cells of the review's `g1` grid were cleared with
the scratchpad when the machine rebooted, so they were not re-run verbatim; this row rests on
the witnesses rebuilt from the brief's description, and the eight cells remain to be
re-graded against it.
