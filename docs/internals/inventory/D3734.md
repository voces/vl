### D3734 — a closure-shared `i64` assigned a value `if` of hex literals as an annotated closure's tail returns the 32-bit pattern

**closed 2026-10-06 — the witness prints `4294967294` twice · was check-clean silently wrong, clause 1 · found by lane L2 while grading [D3664](D3664.md) against master `687b42dbe`: the shared-cell spelling of [D3733](D3733.md) · closed by lane S4 against master `a37097b64` · fixture `tests/cases/literals/hex-width-through-assignment-value.vl`**

Repro:

    function t(c: boolean) {
      let x: i64 = 0
      const u = (): i64 => {
        x = if c { 0xfffffffe } else { 1 }
      }

#### Mechanism

[D3733](D3733.md)'s: the checker typed the assignment at the right side's 32-bit join while the
delivery built the join at 64 bits, and the closure's tail yielded the `i32` reading,
sign-extended to `-2`. The written-capture lowering is not an ingredient: the same tail on a
closure-local binding was invalid wasm, and the un-annotated closure already ran. One close,
`asgRadixPinnedTy`, fixes both.
