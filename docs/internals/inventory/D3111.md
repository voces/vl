### D3111 — a closure over a parameter narrowed by a literal complement (`a is "err"`, else arm) is invalid wasm

**check-clean invalid wasm · clause 1 · open · found by the #3274 review (`rv3274-5974/p/nb/i2.vl`) · the same on master `d408f2da4` · filed 2026-09-28 against master `d408f2da4`**

Repro:

    function orErr(bad: boolean): i32 | "err" {
      if bad { return "err" }
      return 5
    }
    function takeErr(a) {
      if a is "err" { print(0) } else {
        const k = () => a * 2
        print(k())
      }
    }
    takeErr(orErr(false))
    // vl check: rc 0.  vl run: invalid module inside the lambda, type mismatch

Want:

    10

#### Mechanism

Not localised past the ablation. The else arm narrows `a` to `i32` by the literal complement
([D1243](D1243.md)/[D1412](D1412.md)'s `HD_GNOT` remainder); the closure's capture of `a` is
typed from the box and read as the narrowed `i32`, or the reverse.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `print(a * 2)`, no closure | prints `10` | **yes** (the capture) |
| `function takeErr(a: i32 \| "err")` | prints `10` | **yes** (the hole) |
| `i32 \| null` with `a is null` | prints `10` with #3274, invalid wasm on master | **yes** (the literal complement) |
