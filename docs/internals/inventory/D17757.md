#### Mechanism

`monoPinListElems` annotates the list at the element type its slot's calls pin, and types the
list literal and its elements; a `const` bound to an `m[i]` read is resolved from the list's
annotation when called. A `const` bound to `m.pop()` or `m.get(i)` keeps the checker's
`((_) => _) | null`, so its narrowed read has no closure signature. A named generic member reaches
the same refusal once its set is not tagged (COV-CLOS-3's loss `fn-list-pop-get-un-annotated-member-called`).
