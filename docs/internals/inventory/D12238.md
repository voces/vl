#### Mechanism

The hole-slot judge (`holeSlotFixedJudge`, check_relate_core.vl) judges a call through the
written element at the call's argument types. Inside `g` those types are `T`, a type parameter,
and the judge skips a parameter type that carries a type variable, since only an instance knows
it. The instance `g<i32>` calls the element at `(i32, i32)` while the lambda takes `string`, and
only the monomorphizer sees that instance. The close is to judge the call per instance, or to
refuse a type-variable argument against an annotated parameter it cannot always fit.
