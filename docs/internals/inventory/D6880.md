Repro:

    function add(a, b) { return a + b }
    print(add(1, 2))
    print(add(1.5, 2.5))
    function apply2(g) {
      print(g(1, 2))
      print(g(1.5, 2.5))
    }
    const fs = [apply2]
    fs[0](add)
    print(fs.length)
    // vl check: rc 0.  vl run: emitProgram: cannot take the generic function `add` as a value — a function value carries ONE signature

    3
    4
    3
    4

#### Mechanism

From the ablation only. The split rewrites a list element's call per call type only while every
other read of the list is a call through it; a `.length` read keeps the list one value, its
element one function type, and `add` handed to it has one instance to choose for two calls.
