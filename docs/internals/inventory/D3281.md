### D3281 — a join of `a ?? 5` with `b` at a literal-union pin builds invalid wasm, a regression from #3290

**closed 2026-09-29 · was check-clean invalid wasm, clause 1, from `73bbd20bb` (#3290) to `f5ecc7995`, and a loud emit reject (`literal-union string widening with no members`) on `313a071b4` · found in the #3297 round-3 re-grade of the CK grid (`tp_lit_coal_ret`, `tp_lit_coal_bind`, `tp_lit_coal_retbind`) · fixture `tests/cases/generics/coalesce-join-at-literal-union-pin.vl`**

Repro:

    type K = "a" | "b"
    function g<T>(a: T, b: T, c: boolean) {
      const r = if c { a ?? 5 } else { b }
      r
    }
    const u0: K = "a"
    const w0: K = "b"
    print(g(u0, w0, true))
    print(g(u0, w0, false))
    // vl check: rc 0.  vl run: invalid module inside `g` (expected i32, found (ref $type))

Want:

    a
    b

#### Mechanism

Two classifiers disagreed about the join at `T := K`, whose pinned type is the box `K | i32`.
`emitIfExpr` lowers it as that union box, while `exprIsLitAtom` read only its arms, both atoms,
and called the join an atom, so `r` took an `i32` local and the box was stored into it. #3290
exposed it: its pin rung in `litAtomWidenTexts` reads `K | i32`'s string members, which
`emitAtomToStr` then widened with instead of refusing. The fix asks the join the question the
lowering asks (`exprUnion` and `ifJoinUnionName`) before reading the arms.

The same grid's `K | null` pins then reached a second disagreement, the checker's join of the
`??` result with `b` dropping `b`'s null (D2915's mechanism, filed here as D3290). A string `if`
whose link can yield `null` now says so to `exprNullableString`, so its binding takes the
`(ref null)` local its block already has, and a string join typed non-null while an arm widens a
`K | null` atom is refused rather than built.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `function g(a: K, b: K, …)`, the direct spelling | prints `a b` | **yes** (the type parameter) |
| `{ a }` in place of `{ a ?? 5 }` | prints `a b` | **yes** (the coalesce) |
| `type K = string` | prints `a b` | **yes** (the literal union) |
| `"a" \| "b"` spelled inline in place of `K` | same invalid wasm | no (the alias) |
