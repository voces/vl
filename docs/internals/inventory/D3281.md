### D3281 — a join of `a ?? 5` with `b` at a literal-union pin builds invalid wasm, a regression from #3290

**check-clean invalid wasm · clause 1 · open · a loud emit reject (`literal-union string widening with no members`) on `313a071b4`, invalid wasm from `73bbd20bb` (#3290) on, the same on `569caa36c` and with #3297 · found in the #3297 round-3 re-grade of the CK grid (`tp_lit_coal_ret`, `tp_lit_coal_bind`, `tp_lit_coal_retbind`) · bisected by building each seed from its commit's source · filed 2026-09-29**

Repro:

    type K = "a" | "b"
    function g<T>(a: T, b: T, c: boolean) {
      const r = if c { a ?? 5 } else { b }
      r
    }
    const u0: K = "a"
    const w0: K = "b"
    print(g(u0, w0, true))
    print(g(u0, w0, false))
    // vl check: rc 0.  vl run: invalid module inside `g` (expected i32, found (ref $type))

Want:

    a
    b

#### Mechanism

Not localised past the ablation. The bisect places it in #3290 (`73bbd20bb`), which made a
nullable literal-union function result the atom niche at every call and let its `-1` widen and
coalesce. Its parent `313a071b4` refused this instance loudly at the call's print. From #3290 on,
the `??` arm at `T := K` is lowered at the atom's `i32` while the join `r` holds the widened
string box, so one arm of the `if` hands the other's local the wrong type.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `function g(a: K, b: K, …)`, the direct spelling | prints `a b` | **yes** (the type parameter) |
| `{ a }` in place of `{ a ?? 5 }` | prints `a b` | **yes** (the coalesce) |
| `type K = string` | prints `a b` | **yes** (the literal union) |
| `"a" \| "b"` spelled inline in place of `K` | same invalid wasm | no (the alias) |

#### Grading list

The CK grid's `tp_lit_coal_bind` (`print(r)` in the body) and `tp_lit_coal_retbind` (the result
bound before it prints) fail the same way from the same commit.
