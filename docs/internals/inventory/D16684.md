### D16684 — `round(x)` and `Math.round(x)` are undeclared names with no pointer to the `nearest` intrinsic

**loud check reject · first-error quality · lane AE conversion audit · filed 2026-11-16 against master `6356d3e7d`**

Repro:

    function f(u: f64): i32 {
      return round(u) as! i32
    }
    print(f(2.5))
    // vl check: undeclared identifier 'round'

#### Mechanism

The float intrinsics are `floor`, `ceil`, `trunc` and `nearest` (`floatIntrArity`,
check_intrinsics.vl); `round` and the `Math.` spellings a JS or C author reaches for are not
spelling-near any of them, so the undeclared-name report suggests nothing. A fixed alias note
(`round` → `nearest`, which rounds half to even; `Math.f` → `f`) would answer the first error.
