### D6331 — a lambda literal handed to a hole parameter called at two types has no inferred parameter type

**loud check reject · clause 2 · found closing [D6300](D6300.md) · filed 2026-10-18 against master `5e3ba8429` on lane L3's `l3-d6250` base `f30a3c7ce`**

Repro:

    function lap(g) {
      print(g(1) + 1)
      return g("s")
    }
    print(lap((a) => a))
    // vl check: rc 1, cannot infer a type for parameter `a`

Want:

    2
    s

#### Mechanism

From the ablation only. A lambda held by a `const` and handed to the same parameter is split,
one copy per type ([D6212](D6212.md)). A lambda literal written at the argument is instanced in
place at one type, and with two calls disagreeing there is none, so its parameter is reported
uninferable before any split is planned.
