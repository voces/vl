### D15672 — a kept maker's call handed to std:array's `insert` or `concat` on a list built at its record is refused

**loud check reject · clause 2 · `this value is built as J where line 4 delivers it, and it is handed on here at its own type, which stores a field differently` · found closing D15657 · filed 2026-11-11 against master `ada32709`**

Repro:

    import { insert } from "std:array"
    type J = { f: i32 | null }
    function mk2() { { f: 1 } }
    const dA: J = mk2()
    print(dA.f ?? 0)
    const xs = [mk2()]
    xs.insert(0, mk2())
    print(xs[0].f ?? 0)

Want:

    1
    1

#### Mechanism

Not ablated. `insert` is a generic free function, so its value argument is an own-storage delivery
at the instance's element type; the list's store column (`recStoreDeclOf`) answers `xs[i] = v` and
`xs.push(v)` but no generic call, so D15180's refusal fires on a call kept at `J`.
