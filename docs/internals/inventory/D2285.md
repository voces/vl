### D2285 — a closure writing its maker's local boxed the local only for a numeric or string literal init, so every other init left the write with no slot

**closed · was a loud emit reject (`emitProgram: assignment target is not a parameter, local, or global`) · reported by plumb as PL-033 · filed 2026-09-23 against master `ba5378dd5`**

Repro:

    function f(g: (i32) => i32): i32 { g(1) }
    function h(): boolean {
      let bad = false
      f((i) => { bad = true; 0 })
      bad
    }
    print(h())
    // vl check: rc 0.  vl run: true

#### Mechanism

Closures capture by value, so `captureBoxRewrite` (`compiler/emit_rewrite.vl`) boxes a local a
nested function writes into a length-1 list and rewrites every use to `c[0]`. The box was
gated on `cboxInitScalar`, which admitted only a `NumLit` or `StrLit` init. A `false` init, a
call, a struct, a `null`, a list, a map, a char or a negated number left the local unboxed, and
the lambda's `bad = true` found no parameter, local or global to store to. The delivery position
was scenery: the same write in a `const`-bound closure, a returned closure, a nested named
function or a module block refused identically. The fix boxes every captured-written `let` with
an init, types the cell of an un-annotated binding from its init's recorded type (so a boolean
reads back as `true`, not `1`), parenthesizes a composite annotation's cell spelling (`(i32 |
string)[]`, not `i32 | string[]`), and types the left of a `??` or `=` over the cell at the
declared type (a closure may write the cell after any narrowing the maker saw).

Boxing opened a second position: a closure whose LAST statement writes the cell is valued by
that write. The `=` lowers store-then-re-read, which the emitter admits (`assignTargetReReads`)
only when the target's type is the assignment's, and compared the two by arena INDEX, so a
struct, list or closure type rebuilt at a new index refused the re-read. The tail was then
emitted as a statement under a result-bearing signature: invalid wasm, or `unreachable` for a
closure-typed cell even when the caller discarded the value. The comparison is now structural
(`tySame`), which also runs master's plain `v[0] = {x: 5}` tail. Where the cell is WIDER than
the value (`Q` into `Q | null`, `"z"` into `i32 | string`), the rewrite turns the tail into
`const t = e; v = t; t`; a literal `e` keeps its store and is yielded as a copy.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `false` init replaced by `0` (the lambda writes `1`) | runs | **yes** |
| the lambda bound to a `const` first, then passed | still refuses | no |
| the write moved out of the lambda | runs | **yes** |
