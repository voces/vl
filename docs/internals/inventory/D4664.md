### D4664 — a narrowed `u8[] | null` passed as a `u8[]` argument keeps its nullable ref

**closed 2026-10-27 · runs, prints `same` then `0` · fixed: a read the checker narrowed to the non-null twin of its cell's nullable ref kind recovers at the read (`readOwesNonNullRecover`, emit_classify.vl, called once from `emitExpr`), so the byte-list argument is delivered non-null like every other list leaf · pins: `tests/cases/soundness/narrowed-nullable-read-recovers.vl` · was check-clean invalid wasm, clause 1 · filed 2026-10-14 against master `1c1740512`, found porting `corpuscmp.py`**

Repro:

    function same(a: u8[]): boolean { a.length == 2 }
    function one(a: u8[] | null): i32 {
      if a != null {
        if same(a) { print("same") }
      }
      0
    }
    const x: u8[] = [1, 2]
    print(one(x))
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `one`:
    // type mismatch: expected (ref $5), found (ref null $5); $5 is `u8[]`

Want:

    same
    0

#### Mechanism

The narrowed local still holds the `(ref null u8[])` the `u8[] | null` rep lowers to, and the
argument delivery into a `u8[]` parameter emits no `ref.as_non_null` for the byte-list leaf,
while the same delivery for an `i32[]`, `f64[]` or `string[]` leaf does. Not yet located in
the emitter; the ablation below bounds it.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `u8[]` → `i32[]`, `f64[]` or `string[]` | runs | **yes** |
| `if a != null { … }` → `if a == null { return 0 }` then the call | still invalid | no |
| the call → `const b: u8[] = a` (binding, not argument) | runs | **yes** (argument position) |
| the value from a function returning `u8[] \| null` instead of a parameter | still invalid | no |

#### Grading list

The binding, return, field and element positions of the same narrowed value; the `i8[]`,
`u16[]` and `i16[]` packed leaves; `scripts/silent-sweep/corpuscmp.vl`'s `one`, which binds each
narrowed byte array to a `u8[]` local before passing it, as a workaround.
