### D15564 — a call's returned record written whole into a widened record global is built at the call's own row when another holder tags its smaller set

**closed 2026-11-08 — the filed repro prints `4` and `4` · was check-clean invalid wasm, clause 1 · the `let` widening followed `r = mkr()` into the call's returned record but never noted that record's own set as a source of the widened set, so `{inc0}` and `{dbl, inc0}` fell in two set groups and their records keyed two rows; [D15562](D15562.md)'s close papered over it by building the call's literal at the holder's `i32` rep, a third row. `elabFnFieldTy` now notes each followed call's returned set (`fnLeafSetAt`), the literal, the callee's result and the holder's cell key one row by the group, and the `i32`-rep restamp (`ftWrittenCallNote`) is removed · each half alone, both inside a function, and a holder grown by a third write run · fixture `tests/cases/closures/reassigned-record-and-record-list-twins-share-one-row-runs.vl` · found closing [D15562](D15562.md) · filed 2026-11-08 against master `75b1870c`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function mkr() { return { fs: [inc0] } }
    let r = { fs: [dbl] }
    r = mkr()
    print(r.fs[0](3))
    function mkl() { return [{ fs: [inc0] }] }
    let k = [{ fs: [dbl] }]
    k = mkl()
    print(k[0].fs[0](3))
    // vl check: rc 0.  vl run: invalid module, expected (ref null $4), found (ref $3)

Want:

    4
    4

#### Mechanism (as filed)

`r` and `k` both widen to `{dbl, inc0}`. The list store `k = mkl()` decides `{inc0}` with
it, so `{inc0}` is tagged. `mkr`'s literal is then built at the held rep row `{fs:i32[]}`
(`ftWrittenCallNote`). The global `r`'s cell is at its declared type's row, an identical
layout under another wasm type. Building the literal at the declared type instead breaks
`mkr`'s own result row. The literal, the callee's result and the holder's cell need one row.
