### D15042 — an if of record literals delivered to a generic's annotated union of records holding the type parameter is invalid wasm

**closed 2026-11-12, runs and prints `1` then `2.5` · was check-clean invalid wasm, clause 1 · closed by building a literal whose own type holds the type parameter at that type substituted for the instance (`litInstTy`, `emit_value_sites.vl`): the generic body adopted `{f: t}` at the first arm its field names fit, `{f: i32}`, and the union pick read that adoption · the residue of [D15020](D15020.md)'s close, from D14021's grid · filed 2026-11-02 against master `4f6f62f6`, pre-existing**

Repro:

    function g<T>(b: boolean, t: T) {
      const v: {f: i32} | {f: T} = if b { {f: 1} } else { {f: t} }
      print(v.f)
    }
    g(true, 2.5)
    g(false, 2.5)
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `g`

Want:

    1
    2.5

#### Mechanism

The checker, at the generic body, adopts `{f: t}` (own type `{f: T}`) at the first arm of
`{f: i32} | {f: T}` its field names fit, which is `{f: i32}`, since `T` is open there. In the
instance, `unionArmOfLitTy` (`emit_value_sites.vl`) picked the arm by that adoption (`nodeRepTyAt`)
and built the `f64` (or `string`) value into the `i32` arm's struct. The fix reads the literal's
own type substituted at the instance (`elabInstTyAt`), which is exactly one arm, and skips the
field-fit check that the substituted type already settles. A bare `{f: t}` delivery (no `if`) was
the minimal witness.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| concrete `{f: i32} \| {f: f64}`, no type parameter | runs, `1` `2.5` | **yes** (the generic) |
| `{f: i32 \| T}`, one record | runs, `1` `2.5` | **yes** (the union of records) |
| `T := string` | still invalid wasm before the fix; runs after | no |
