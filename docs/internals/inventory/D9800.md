#### Mechanism

The checker joins the `f32` element with the `i32` call apart, into the `f32 | i32` box. The
nullable-value lowering had arms for a default of the element's own number type and for a
union operand, and none for a plain nullable element read whose result is a numeric union
neither side is, so it fell to the refusal.
