### D16938 — an uncalled hole function whose body reads a member of its parameter, stored as a record into a map read back from a map, has no result type at the `i32` default

**loud emit reject · clause 2 · the member-read residue of [D16927](D16927.md) · filed 2026-11-17 against master `406e47810`**

Repro:

    function g(x) { return x.n }
    const __m = Map()
    __m.set("k", { m: Map() })
    const __mv = __m.get("k")
    if __mv != null {
      __mv.m["k"] = { f: g }
      print(__mv.m.length)
    }
    // vl check: no errors.  vl run: emitProgram: field access receiver is not a struct

Want:

    1

#### Mechanism

Nothing calls `g`, so the slot pins the elaboration's stored default (`elabStoredHoleDefaults`,
`compiler/emit_elab.vl`), every parameter at `i32`. A member read, an index or a method call on
an `i32` does not check, so the instance has no result type. On master its body is lowered and
refuses at the read. With D16927's fix (#8936) the body is not built, but the record field's
function type still has no result: the refusal moves to the function-value signature
(`emitProgram: a function value's signature is not yet supported`, `cloSigKeyExt` empty). No call
can reach the default (a call keys its own instance), so any representable result would do; the
gap is that check closes the slot's function type with none.

#### Ablation

| change from the repro | outcome | needed? |
| --- | --- | --- |
| body `x.n + 1` | same refusal | no |
| body `x[0] + 1` | loud, `index receiver is not an array or string` | no, any member read |
| body `x.toUpperCase()` | loud, `callee is not a function name` | no, any member read |
| body `x + "a"` or `x.length` | D16927: invalid wasm / loud on master, runs under #8936 | **yes**, a result type exists |
| `const r = { f: g }` or a plain `Map()` | runs, prints `1` | **yes** (the map read back from a map) |
| `r.f({ n: 5 })` called through the slot | runs, prints `5` | **yes** (no call) |
