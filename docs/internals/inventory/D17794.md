### D17794 — a `.map` lambda annotated at a closed function type returning a list-of-records element's hole function emits a lambda reading an id as the record

**closed 2026-11-28 by lane START-2 — the witness prints `2`, `2.5` · the lambda's result keeps the set's value type (no substitution copy) and its parameter's function type reads the type the tag decision closes · fixture `tests/cases/functions/list-of-records-set-field-through-map.vl` · was: loud emit reject · clause 2 · `vl check` rc 0, `emitProgram: a .map/.filter callback needs an instance at the list's element type, and none was built for this call` (lane START-2's guard, 2026-11-28; it built invalid wasm before) · filed 2026-11-28 against master `2693ffdcf` (lane START-2)**

Repro:

    function id(a) { return a }
    function deliver() { return [{ f: id }] }
    const u = deliver()
    print(u[0].f(2))
    const v = deliver().map((r): (a: f64) => f64 => r.f)
    print(v[0](2.5))
    // vl check: rc 0.  vl build: loud emit reject (was invalid wasm)

Want:

    2
    2.5

#### Mechanism

The lambda's parameter is laid out as an `i32` while its body reads it as the element record
`{f: (i32) => i32}`: the instance the lambda is built at disagrees with the rep its element is
passed at, once `u[0].f(2)` pins the list's hole function. The family of [D17792](D17792.md).
