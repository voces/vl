#### Mechanism

The checker types the last arm's `p["k"]` as `string`: null and `i32` are both ruled out. The
emitter's else of `p["k"] is i32` subtracts the tested member only for a LIST cell (the element
union row `indexElemUnionName` names); a map cell has no such row, so no complement was pushed
and the read lowered at the `i32 | string` box the null test left, fed to a string concat. The
converse order has the same hole on both containers: the else of `xs[0] is i32` leaves
`string | null`, and a following `xs[0] != null` pushed the DECLARED set minus `null` instead of
what the `is` had left. The close pushes the map complement (`pushIndexMapComplement`) and lets a
null test start from a live narrowing that an `is` left narrower and still null-bearing
(`indexCellCurSet`, and the same rung in `pushIndexMapNullNarrow`).
