#### Mechanism

`as?` naming a union yields a nullable union binding, and the `is` narrowing inside the
`!= null` test reaches the field read without a struct row: the emitter looks the receiver up
as a struct and finds none. Arms that share a field name (`{ v: i32 } | { v: string }`, legal
since D4056) fail the same way. Annotating the binding `const u: (A | B) | null` gives the read
its struct rows and runs.
