### D4058 — `v is B` over a value whose declared type is a single record `A` that contains `B` folds to `true`, whatever the value

**closed 2026-10-11 · runs today and must keep running · was check-clean silently wrong value · clause 1 · found writing `docs/spec/narrowing.md` (lane SPEC) · filed 2026-10-11 against master `98a4ed71b`**

Repro:

    type A = { x: i32 }
    type B = { x: 1 | 2 }
    function g(b: A): boolean { b is B }
    print(g({ x: 7 }))
    // vl check: rc 0.  vl run: rc 0, prints false (printed true until the close)

Want:

    false

#### Mechanism

By the owner's ruling on D3885 (A, 2026-10-10), `is` tests whether the VALUE fits the type.
`{ x: 7 }` does not fit `B`, so the test must be false. When the operand's declared type is a
union `A | B`, the test does read the field and answers correctly. When the declared type is
`A` alone, or `A | null`, the emitted function returns a constant. Its whole body, by
`wasm-dis`, is `(return (i32.const 1))`. The fold treats `B` as a member of `A` and answers
`true` without reading the value. That is the declared-type answer the ruling replaced.

The fold also narrows. In the then-branch `b` reads at `B`, so a field read is typed
`1 | 2` while it holds `7`, and that value passes into a binding annotated `1 | 2`:

    type A = { x: i32 }
    type B = { x: 1 | 2 }
    function g(b: A): i32 {
      if b is B {
        const y: 1 | 2 = b.x
        return y
      }
      0
    }
    print(g({ x: 7 }))
    // vl check: rc 0.  vl run: rc 0, prints 0 (printed 7 until the close)

Closed by a rung in `emitIsTest` (`emitRecordFitIs`) that reads each field `B` narrows and
ORs its literal set, under a null test when the operand is `A | null`. The checker names the
narrowed fields (`recFitNarrowedFields`). Two shapes stay refused and are filed as their own
rows: a field narrowed to a STRING literal set narrows the test but not the then-arm binding,
because `B` stores that field as an atom and `A` as a string (D4081); and a field narrowed
other than to a literal set, such as `i32 | null` to `i32` or one record to a contained one,
is a loud emit refusal (D4082). Both were silently wrong before.

#### Ablation

| variant | outcome |
| --- | --- |
| operand declared `A`, `B = { x: 1 \| 2 }`, value `{ x: 7 }` | `true` (wrong) |
| operand declared `A \| null`, same value | `true` (wrong) |
| `A = { k: string }`, `B = { k: "p" }`, value `{ k: "q" }` | `true` (wrong) |
| two fields, `B` narrows one of them | `true` (wrong) |
| operand declared `A \| B`, value `{ x: 7 }` | `false`, correct |
| operand `n: i32`, `n is 1 \| 2`, `n = 7` | `false`, correct |
| twin shapes, `A = B = { x: i32 }`, value `{ x: 7 }` | `true`, correct |
| operand declared `A`, value `{ x: 1 }` | `true`, correct |

#### Grading list

Every row of the ablation table should give the value-fit answer, and `g({ x: 1 })`
should stay `true`. In the then-arm of
`if b is B`, `b.x` should read at `1 | 2`.
