### D17180 — a `?.` call on an un-annotated function's result, a map read of a record whose field is a hole function, has no interned shape

**loud emit reject · clause 1 · `vl check` accepts, `vl run` refuses "emitProgram: ref valtype with no interned shape" · filed 2026-11-24 against master `fd2d6cd6e` (found by IR-N3 writing the effect-order witness for `boxed tag dispatch`) · owner FREE**

Repro:

    function half(a) { return a / 2.0 }
    const m = Map()
    m["b"] = { f: half }
    function get() { return m["b"] }
    print(get()?.f(4) ?? -1.0)
    // vl check: rc 0.  vl run: emitProgram: ref valtype with no interned shape

Want:

    2

#### Mechanism

The function `get` returns an un-annotated map's read, a record whose field `f` is a hole
(un-annotated) function, so its result type is that record or `null`. An optional call through
the result (`get()?.f(4)`, or `r?.f(4)` after `const r = get()`) reaches the emitter with a
reference valtype no shape was interned for. The same optional call on the map read itself, or a
plain call after a null check on the bound result, runs.
