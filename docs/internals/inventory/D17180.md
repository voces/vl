#### Mechanism

The function `get` returns an un-annotated map's read, a record whose field `f` is a hole
(un-annotated) function, so its result type is that record or `null`. An optional call through
the result (`get()?.f(4)`, or `r?.f(4)` after `const r = get()`) reaches the emitter with a
reference valtype no shape was interned for. The same optional call on the map read itself, or a
plain call after a null check on the bound result, runs.

Localized by IR-N10 on master `4a0d6ba5`, with throwaway debug seeds. The refusal is
`fbValtypeNullable("nulstruct", si)` with `si < 0`, written by `emit_sections.vl`'s global-cell
declaration loop: `letCellSlot` answers -1 for the top-level binding's cell. That binding is `r`
in `const r = get()`, or the cell the top-level `?.` expression lands in, anchored at `5:11`. The
cell's record type, `get`'s inferred `{ f: <hole fn> } | null`, has no struct row interned on the
`?.` call path. The same binding read by a plain `r.f(4)` under `if r != null` reaches an
interned row. Inside a function the same expression fails with a second symptom, "field access
receiver is not a struct". Both point at the hole-function record's struct row on the optional
path, a legacy shape-interning gap, not an IR rung.
