### D6530 — a binding seeded with a generic, written with a hole parameter and called at two types, traps at the second call

**loads then traps · `vl check` rc 0 · clause 1 · found closing [D6520](D6520.md) · filed 2026-10-18 against master `698648f78`**

Repro:

    function same<T>(k: T): T { k }
    function mid(a) {
      let b = same
      b = a
      print(b("x"))
      print(b(3))
    }
    mid(same)
    // vl check: rc 0.  vl run: prints x, then a wasm trap inside `mid`

Want:

    x
    3

#### Mechanism

From the ablation only. D6520 calls the parameter itself at one type and the copy at another,
and the split gives the parameter one slot per type. Here every call goes through the copy
`b`, and `b` holds one function value, so one signature carries both calls. The parameter is
not split, because no call of `a` itself pins a type the copy's call misfits.
