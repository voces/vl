### D3468 — an `is` test on a record-union field of a list element refuses at emit in the then arm

**loud emit reject · clause 2 · open · pre-existing, the same on master `47aa2950b` · the `elem_*` cells of lane NW's `nw/g3` grid, direct spelling included · filed 2026-09-30 against master `47aa2950b`**

Repro:

    type A = { v: i32 }
    type B = { s: string }
    type W = { h: A | B }
    const z: W[] = [{ h: { v: 3 } }]
    if z[0].h is A {
      print(z[0].h.v)
    }
    // vl check: rc 0.  vl run: emitProgram: field access receiver is not a struct

Want:

    3

#### Mechanism

Not localised past the ablation. The checker narrows the path `z[0].h` to `A`; the emitter does
not take the narrowing for a field reached through an index, so the read `z[0].h.v` meets the
union box. Each half alone works: an element union `z[0] is A`, and a field of a field `z.w.h`.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const e = z[0]`, then `e.h is A` | prints `3` | **yes** (the index step) |
| an element union `(A \| B)[]`, `z[0] is A` | prints `3` | **yes** (the field step) |
| `z.w.h is A`, a field of a field | prints `3` | **yes** |
| a nullable field `h: A \| null`, `!= null` | prints `3` | **yes** (a union of records) |
| a scalar union `h: i32 \| string`, `is i32` | prints `4` | **yes** |
| inside a function, `F(z: W[])` | the same refusal | no |
