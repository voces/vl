### D16427 — a callee's write into the inner list of a bound `[[]]` is checked against the default element, so a legal program is refused

**closed 2026-11-15 — the witness runs and prints `0.5` · was: loud check reject · clause 2 · bucket (f), a local fix: the flat bound list and a bound record's list field both take the callee's write, so only the second level of a bound list misses it · found closing D16425 · filed 2026-11-15 against master `ab210efa`**

Repro:

    function t(a) { a[0].push(0.5); print(a[0][0]) }
    const l = [[]]
    t(l)
    // vl check: the callee's body writes f64 into the list passed here, whose element is i32

Want:

    0.5

#### Mechanism

`checkCalleeWrites` (D3775) checks a hole callee's write into a binding's list against that list's
final element, and does not pin it. A binding's open lists under a `| null` or a record field are
recorded at the binding (`notePendingNulList`, D6270) and pinned at scope close to the element a
callee wrote. A list's own element list was not walked, so the inner list of a bound `[[]]` was
left at the default and the callee's write was refused against it. `notePendingNulList` now
walks a list's closed element too, at any depth. Fixture:
`tests/cases/closures/bound-nested-list-written-by-hole-callee.vl`.
