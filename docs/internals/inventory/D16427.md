### D16427 — a callee's write into the inner list of a bound `[[]]` is checked against the default element, so a legal program is refused

**loud check reject · clause 2 · bucket (f), a local fix: the flat bound list and a bound record's list field both take the callee's write, so only the second level of a bound list misses it · found closing D16425 · filed 2026-11-15 against master `ab210efa` · open**

Repro:

    function t(a) { a[0].push(0.5); print(a[0][0]) }
    const l = [[]]
    t(l)
    // vl check: the callee's body writes f64 into the list passed here, whose element is i32

Want:

    0.5

#### Mechanism

Not yet located. `checkCalleeWrites` (D3775) checks a hole callee's write into a binding's list
against that list's final element, and does not pin it. The direct spelling's own push pins the
inner `[]`, and so does a write through a record field of a bound list. The inner list of a
bound `[[]]` is left at the default, and the callee's write is then refused against it.
