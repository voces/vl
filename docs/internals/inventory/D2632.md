### D2632 — an assignment to a closure-captured union binding is not lowered as a value

**loud emit reject (`emitProgram: only an identifier assignment is a value expression`) on a `vl check`-clean program · the read spelling of D2626 · filed 2026-09-26 against master `7c572571f`**

Repro:

    function src(): i32 | string { return 3 }
    function g() {
      let x: i32 | string = src()
      const k = () => x
      if x is string { x = "t" }
    }
    print(g())

#### Mechanism

`g()` is read, so `g` keeps its inferred `string | null` return and its tail `if`'s arm `x = "t"`
is lowered as a value by storing and re-reading its target. The capture rewrite has turned `x`
into the cell a closure shares, and `assignTargetReReads` (emit_classify.vl) does not re-read
that cell for a union binding, so the emitter refuses. D2626, the same program with the result
unread, closed by making `g` void (D2631); this spelling still needs the re-read.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the closure `k` capturing `x` | runs | **yes** |
| the read of `g()` (a statement call) | runs (D2631) | **yes** |
