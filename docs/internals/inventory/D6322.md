### D6322 — a block-local maker of a generic, called in a generic body instanced at two types, has no signature

**loud emit reject · `vl check` rc 0 · clause 2 · found closing [D6205](D6205.md) · the same on master `5e3ba8429` and before #4072 · filed 2026-10-18 against master `5e3ba8429`**

Repro:

    function k<T>(x: T): T { return x }
    function g<U>(u: U) {
      function mk() { return k }
      const a = mk()
      print(a(u))
    }
    g(1)
    g("z")
    // vl check: rc 0.  vl run: emitProgram: a function-value call has no interned signature — parameter 1 of type `` has no representation in the function-value ABI

Want:

    1
    z

#### Mechanism

From the ablation only. D6205's per-instance copy takes only a module-scope maker; a maker
declared inside the body is not a dependency it can copy, and the copy of the body would carry
its own `mk` anyway, so what is missing is a copy of `g` per instance with nothing renamed.
