#### Mechanism

From the ablation only. D6205's per-instance copy takes only a module-scope maker; a maker
declared inside the body is not a dependency it can copy, and the copy of the body would carry
its own `mk` anyway, so what is missing is a copy of `g` per instance with nothing renamed.
