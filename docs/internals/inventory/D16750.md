#### Mechanism

The literal binding is exempt from the nested-width refusal as an un-annotated object binding
(`srcIsUnannotatedObjBinding` in `objShapeSameNamesAdapts`), and the D3339 adoption declines a
destination whose nested record drops a field, so `sv` is built at `u`'s shape while the checker
types it at its own, as D3431 was. Ruling (b) takes such a record at its own type only where no
field's storage differs; here `pet` goes from `O` to `O | null`, so D2996 governs. The owed outcome
is its check refusal, the one `recDropAdopt` gives a flat drop: "`sv` is a record built where it is
declared and is read for `pet` … Copy it here with an object literal".
