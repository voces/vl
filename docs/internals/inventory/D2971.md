### D2971 — `[...ll, null]` over an `i32[][]` has no context for its `null`

**loud emit reject · clause 2 · found by the #3246 review, the same on master `fe1fa1bec` · filed 2026-09-28 against master `fe1fa1bec`**

Repro:

    const ll: i32[][] = [[3]]
    const q = [...ll, null]
    print(q.length)
    // vl check: rc 0.  vl run: emit error: bare null needs a struct-typed context

Want:

    2

#### Mechanism

Not localised. The literal is `(i32[] | null)[]`, a nullable-ref element that shares the source's
storage (`[...cs, null]` over a record list runs). The plain run `[null]` is a synthesized
literal with no recorded type, so it is built with no nullable-list context, the same shape as
[D2964](D2964.md)'s string case.
