**closed 2026-10-26 — now prints `2` · was loud emit reject, clause 2 · the plain run beside the spread is linked to the list holding it (`elabSpreadRunNote`, emit_elab.vl) and built at that list's `(i32[] | null)[]` · found by the #3246 review · filed 2026-09-28 against master `fe1fa1bec` · pin: `tests/cases/arrays/spread-run-built-at-holder.vl`**

Repro:

    const ll: i32[][] = [[3]]

    print(q.length)
    // vl check: rc 0.  vl run: emit error: bare null needs a struct-typed context

Want:

    2

#### Mechanism

Not localised. The literal is `(i32[] | null)[]`, a nullable-ref element that shares the source's
storage (`[...cs, null]` over a record list runs). The plain run `[null]` is a synthesized
literal with no recorded type, so it is built with no nullable-list context, the same shape as
[D2964](D2964.md)'s string case.
