### D9593 — a `const` alias of a `const` bound to a call returning a generic, called at two types, reaches no call that fixes its type

**loud emit reject · `vl check` rc 0 · `a generic function taken as a value reaches no call that fixes its type` · clause 2 · found closing [D9481](D9481.md) · present on master `49a7d0b10` · filed 2026-10-22 against master `49a7d0b10`**

Repro:

    function id<T>(x: T): T { x }
    function mk() {
      print("mk")
      return id
    }
    const v = mk()
    const w = v
    if w(2) == 2 {
      print(w("abc"))
    }
    // vl check rc 0.  vl run: emit error: emitProgram: a generic function taken as a value reaches no call that fixes its type

Want:

    mk
    abc

#### Mechanism

Not traced. From the ablation only: `v` bound to the call and called directly runs, and so does
`v` put in a list (D9481), so the refusal needs the second `const` link to be called; the
direct-call path that serves `v` does not follow an alias whose own value is a call-bound
`const`.
