### D2288 — storing `null` into an element of a `(string | null)[]` asks for a struct-typed context

**loud emit reject · `emitProgram: bare null needs a struct-typed context`, `vl check` rc 0, clause 2 · found by the PL-033 position grid ([D2285](D2285.md)) · filed 2026-09-23 against master `2d8341305`**

Repro:

    function h(): string {
      const ss: (string | null)[] = ["x"]
      ss[0] = null
      ss[0] ?? "none"
    }
    print(h())
    // vl check: rc 0.  vl run: emitProgram: bare null needs a struct-typed context (should print none)

#### Mechanism

Not ablated past the table below. The element store lowers its right operand with the list's
element as the context, and `emitNullLitNode` finds a heap type only when that context is a
struct. A nullable STRING element is a `(ref null $string)` niche with no struct index, so a
bare `null` there has nothing to name. The same store at `(i32 | null)[]` runs, so this is the
ref-niche element, not the nullable list.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `null` replaced by `"y"` | runs | **yes** |
| the element type `i32 \| null` in place of `string \| null` | runs, prints `-1` | **yes** |
| the store moved into a closure over the list | still refuses | no |
| the store written through a boxed `let v: string \| null` cell (`v = null` in a closure) | still refuses | no |

#### Grading list

The boxed-cell spelling `let v: string | null = "a"; const w = () => { v = null }; w()`; a
`(P | null)[]` store of `null` with `P` a struct (a control: it has a struct context).
