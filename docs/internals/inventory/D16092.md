### D16092 — a lambda in a covering test's dead arm that reads the `never` operand infers `void`, so a use of its result is refused

**loud check reject · clause 2 · `print expects a value, got void` · the residue of [D16006](D16006.md)'s (a) close · filed 2026-11-14 against master `1336c2abc`**

Repro:

    function take(p: i32) {
      if p is i32 { print(p + 1) } else {
        const f = () => p + 1
        print(f())
      }
    }
    take(4)
    // vl check: rc 1, the refusal above

Want:

    5

#### Mechanism

In the dead arm `p` reads as `never`, so the lambda's body `p + 1` is `never`. Return inference
drops a `never` witness (D1972: an un-annotated function that only traps infers `void`), so `f`
returns `void` and `print(f())` is refused. Before D16006(a) the arm read `p` at `i32` and the
program printed `5`. Under the ruling every use of the `never` operand checks, so the lambda's
result should be `never` too.

#### Ablation

| change | outcome |
| --- | --- |
| witness | check reject |
| `print(p + 1)` directly in the arm | runs, prints `5` |
| `f()` as a statement | runs |
