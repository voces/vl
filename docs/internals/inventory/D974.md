#### Mechanism

D973 compared a struct union's arms through the VARIANT table because the struct table is
EMPTY when a union is declared, and declined every ref field. A nested shape is the exception:
the ARM has no struct row, but its nested shape DOES.

And it needed the opposite lookup from the arms. A **NAMED** nested type resolves through
`structIdxOfElemName`; only an INLINE shape needs `internInlineShapeTy`, which answers -1 for
`type C = {r: i32}`. Asking the name first is what makes the common spelling work — #2183
measured `nm=[C] row=-1 nrows=1`, a row that existed and an intern that could not find it. With
the row in hand the nested pair is parked in a struct-heap-typed slot (`structEqStashSlot`,
code 16, keyed by struct-table row) and compared by the ordinary recursive machinery through
`emitStructEqRec`'s `-2` / `-3` sentinels.
