### D12050 — a `K | null | i32` box read from a list element or a call result fails `== "a"` and `is K`

**check-clean silently wrong · open · clause 1 · found while closing [D3137](D3137.md) (L6 slice A3) · filed 2026-10-24 against master `5888be183`**

Repro:

    type K = "a" | "b"
    const zz: (K | null | i32)[] = ["a"]
    print(zz[0] == "a")
    // PRINTS false

Want:

    true

#### Mechanism

Not localised past the ablation. The value reaches the reader as a box whose literal-union arm
does not answer `is K` (a call `id("a")` returning `K | null | i32` takes the `else` of
`if r is K`), so `== "a"` compares against an arm that never matches. A binding annotated with the
same union keeps the arm; a list element and a function return lose it. Dropping either `null`
or the literal union `K` from the member set removes the defect.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `(K \| i32)[]`, no `null` | `true` | **yes** (`null`) |
| `(string \| null \| i32)[]` | `true` | **yes** (a literal-union member) |
| `(K \| null)[]` | `true` | **yes** (a third member) |
| a binding `const k: K \| null \| i32 = "a"` | `true` | **yes** (a list element or call result) |
| `function id(v: K \| null \| i32): K \| null \| i32 { v }`, `id("a") == "a"` | `false` | no |
| the element `"b"`, compared `== "b"` | `false` | no |

#### Grading list

The call-result spelling above, `id("a") is K`, and D3137's null-first spelling
`(null | K | i32)[]`, which since its close lowers the same way.
