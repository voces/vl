### D12050 — a `K | null | i32` box read from a list element or a call result fails `== "a"` and `is K`

**closed 2026-10-24 by lane-D12050 · runs, prints `true` · was check-clean silently wrong, clause 1 · closed by reading a union box's member set off its arena type when its union name is an annotation spelling no row is bound under (`msSetOfUnionBox`, wasmEmit.vl), at `==`/`!=` against a literal, `is K` and `match` · fixture `literal-unions/nullable-mixed-box-eq-across-delivery.vl` · D3137's null-first spelling prints `true` with it · the call-result `is K` over `K | i32`, no `null`, filed open as [D12060](D12060.md) · found while closing [D3137](D3137.md) (L6 slice A3) · filed 2026-10-24 against master `5888be183`**

Repro:

    type K = "a" | "b"
    const zz: (K | null | i32)[] = ["a"]
    print(zz[0] == "a")
    // PRINTS false

Want:

    true

#### Mechanism

`emitUnionConcreteEq`, `emitUnionLitIs` and the `is` literal-union gate looked the box's member
set up by its union NAME (`msSetOfUnion`). A list element, a call result and a parameter carry
the annotation spelling (`K|null|i32`); only the canonical spelling a local gets (`K|i32|null`)
is bound to the interned row. The miss returned -1, so the `K` arm read as absent and `== "a"`
folded statically to `i32.const 0` (and `!=` to 1, `is K` to the else arm). The fix falls back
to the row keyed by the operand's arena type (`msSetOfNameTy`).

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `(K \| i32)[]`, no `null` | `true` | **yes** (`null`) |
| `(string \| null \| i32)[]` | `true` | **yes** (a literal-union member) |
| `(K \| null)[]` | `true` | **yes** (a third member) |
| a binding `const k: K \| null \| i32 = "a"` | `true` | **yes** (a list element or call result) |
| `function id(v: K \| null \| i32): K \| null \| i32 { v }`, `id("a") == "a"` | `false` | no |
| the element `"b"`, compared `== "b"` | `false` | no |

The call-result spelling above, `id("a") is K`, and D3137's null-first spelling
`(null | K | i32)[]`, which since its close lowers the same way.
