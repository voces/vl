### D17401 — a `??` chain of two `boolean | null` operands with a default of another type yields the boolean as an `i32`

**check-clean silently wrong · clause 1 · found ablating the `map read default rep` corpus cells (lane IR-C1) · filed 2026-11-24 against master `f7e47d34a`, the same under the IR and the claimless compiler**

Repro:

    function f(): boolean | null { return null }
    function g(): boolean | null { return true }
    print(f() ?? g() ?? 2)
    // vl check: rc 0.  vl run: PRINTS 1

Want:

    true

#### Mechanism

Legacy writes the inner `f() ?? g()` at the `boolean | null` niche (`2` for null) and joins it
with `2` into `boolean | i32` without tagging the boolean arm, so `true` reaches the union as the
`i32` `1`. Bound to a `const` first, the inner join is a boolean and the outer one boxes it
right. Not yet located past that.
