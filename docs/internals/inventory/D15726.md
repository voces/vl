### D15726 — a fresh call's record holding a record, delivered at a record storing that field as a union of records, is refused

**closed 2026-11-12, runs and prints `1` then `true` · was a loud check reject, clause 2, `this value is built as Ring where line 7 delivers it, and it is handed on here at its own type …` (D14385's interim refusal) · the copy's rule admits a record into the one member of a union of records with its field names (`recUnionRecMember`, check_fit_rules.vl), and the copy builds the member's row and boxes it under the member's tag (`emitRecCopyIntoMember`, wasmEmit.vl) · graded by `scripts/capability-probes/matrix/kept-maker-delivery-record-union-member.matrix.vl` · fixture `tests/cases/structs/kept-maker-record-copied-into-union-member-runs.vl` · a member shape of [D14385](D14385.md) · filed 2026-11-12**

Repro:

    type Cir = { c: i32 }
    type Sq = { s: i32 }
    type Ring = { r: Cir | Sq }
    function one() { { r: { c: 1 } } }
    const h = one()
    print(h.r.c)
    const h2: Ring = one()
    print(h2.r is Cir)

Want:

    1
    true

#### Mechanism

The copy's rule (`recCopyBoxesAt`) admits a record field into a record or `record | null`, and
a scalar into a union member, but not a record into a union of records. The delivery is not
recorded as a copy, so D14385's refusal of the other call fires. A union-of-records field is a
box of a tag and the member's struct, so the copy has to build the member's row and box it.

members sharing field names (stays refused: no one member to build at).
