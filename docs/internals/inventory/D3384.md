### D3384 — a named function returned from a function with an inferred return is called with no signature

**loud emit reject · clause 2 · open · found by the `fn-value-*` matrices' `return_inferred` rows · the same on master `3291e99e1` · filed 2026-09-30 against master `3291e99e1`**

Repro:

    function mkC(): i32 { return 7 }
    function deliver() { return mkC }
    const v = deliver()
    print(v())
    // vl check: rc 0.  vl run: emitProgram: a function-value call has no interned signature

Want:

    7

#### Mechanism

Not localised past the ablation. `deliver`'s inferred result is `() => i32`, and the call
`v()` resolves no `$fnsig` key for it: neither the binding (un-annotated, initialised from a
call) nor the callee's arena type yields an interned key, and the call site refuses. The
annotated destination (`const v: () => i32 = deliver()`) runs.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const v: () => i32 = deliver()` | runs, prints `7` | **yes** (un-annotated) |
| `function deliver(): () => i32 { return mkC }` | runs, prints `7` | **yes** (inferred return) |
