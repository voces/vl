### D17162 — an assignment of a `null`-typed binding to a never-filled `let m = null`, read as a value, emits an invalid module

**check-clean invalid wasm · claimed and claimless alike · 1 spelling family · filed 2026-11-24 against master `3da65c5f` by lane IR-N2, found while probing #9916 on train KO2 (a sibling of [D17120](D17120.md))**

Repro:

    const n = null
    let m = null
    print((m = n) == null)
    // vl check: rc 0.  vl run: invalid module, "the emitted module failed to validate" at 3:1

Want:

    true

#### Mechanism

The value of `m = null` into a never-filled `let m = null` hole is the `null` unit
(`asgYieldsNulHole`, D17120), but that predicate takes only a `null` literal on the right. With a
`null`-typed binding on the right, the predicate declines and the assignment's value takes another
arm, which emits a module that fails validation. A statement assignment (`m = n` whose value is not read) runs.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `(m = null)`, the literal on the right | runs, `true` | **yes**, a binding on the right |
| `m = n` as a statement, then `print(m == null)` | runs, `true` | **yes**, the value read |
| `n` a `let n = null` | still invalid | no |
| `const r = (m = n)`, or `print(m = n)` | still invalid | no |
| the three lines inside a function body | still invalid | no |
| `m` an annotated `let k: i32 \| null = 3` | runs, `true` | **yes**, the never-filled hole |

#### Grading list

- Each spelling above, and `(m = n)` with `n` read before its declaration from a function body.
