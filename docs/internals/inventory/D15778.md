#### Mechanism

`iisPushFieldElem` keys a ref-list field's element (code 5) by `refArrElemName` of the field's
spelling (`{w:i32}|null`); the field's type names the declared twin (`Tex|null`). A differential
`emitFail` probe, comparing the type answer (`shapeFieldElemName`) with the spelling ladder,
differs on 21 of the 7,816 `tests/cases` fixtures (12 `generics/`, 5 `unions/`, 3 `std/`, 1
`modules/`) and not in the self-build. In 20 the type names the nominal twin (`A`, `S`,
`Tex|null`, `I<i32>`, `GB<i32>|null`) where the spelling keys the structural render; in one,
`generics/declared-return-holds-litunion-beside-type-param.vl` (`(T|K)[]`), the type names nothing
(D15779). Keyed type-first, all 21 print the same and 5 build different bytes of the same size and
type count. Which name keys a twin's element slot is Family B's decision.

Ruled type-first (#7306: no row key needs declaration identity). `iisPushFieldElem` now reads the
element name off the field's type, and the spelling ladder (`refArrElemName` and its cluster) is
deleted. The pin stands: the witness must keep running.
