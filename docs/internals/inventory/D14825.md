#### Mechanism

The closed-type rung above it keys a read by the read's type at the instance (`nodeTyAt`), and
answers only when that type is a closed function type whose key is interned. A probe that records
why, each time the fallback answers, over the 214 files the deletion broke (one of them is this
witness, `distilled/named/d3204_r1_gi_disc_ifelse_lam_a_decl.vl`):

| why the closed-type rung did not answer | reads | files |
| --- | --- | --- |
| the type holds a type variable and an inference hole | 2,283 | 190 |
| `nodeTyAt` has no type (closure bindings such as `h`, `run`, `k`) | 242 | 17 |
| a closed key not yet interned, equal to the fallback's | 57 | 4 |
| a closed key not yet interned, different from the fallback's | 20 | 1 |
| a closed type `sigKeyOfTy` cannot key | 4 | 1 |

15 split-plan files are not measured, because the probe's forced failure changes their rounds.
The first row is the instance cell whose type the instance never closed, which G1's (d) closes;
the second needs a recorded type for those bindings. The 20 differing reads are `f` in
`closures/captured-lambda-alias-call.vl`'s `mkA`: its type keys `>s0` and its own signature
reads `>i`, which no emitted call uses (the call is direct, and `const g = f`, `call0(f)` and
`[f][0]()` all run), so it is a stale fact rather than a miscompile.

#### Ablation

Not ablated row by row: the population above is the measurement, and the witness is one of the
190 files in its first row, which went to rc 1 with the rung deleted.

#### Close

The replacement measured for the first row, keying the callee read by its call's per-instance
type ahead of the binding's own signature (branch `claude/step7-d1`, 87de90c7d), is refuted: it
traps the compiler in `closures/block-local-maker-of-generic-in-generic-body-at-two-types.vl`
and prints a wrong value in `closures/generic-fn-value-one-binding-two-pins.vl`. A held closure
is called through the signature it was BUILT at, which is the binding's lowered signature and not
the type at any one call. The rung is renamed for that in `calleeCloSigKeyOfRead` and stays.
A value holding a hole lambda that crosses at a signature other than the one it was built at is
the per-delivery token design, which is not this row.

#### Acceptance cells

The closure-at-delivery design (`docs/internals/closure-at-delivery-2026-11.md`) takes this row's two refutation files as its acceptance cells, both refused with the split plan off today:

- `closures/generic-fn-value-one-binding-two-pins.vl` runs once the binding bundle and the delivery token land (steps (b) and (c));
- `closures/block-local-maker-of-generic-in-generic-body-at-two-types.vl` runs once a nested body is instanced per encloser, its creation site keyed by instance.
