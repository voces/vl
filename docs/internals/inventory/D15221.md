### D15221 — a call through a field of a function's returned list of records is not judged for one result, where the same call through a binding of it is refused

**loud emit reject · `emitProgram: ref valtype with no interned shape` · clause 2 · open · the bound twin (`const rs = mk(); rs[1].f(3)`) is refused at check: `cannot store 'half' in 'rs[].f': called at (i32) it returns f64, where 'inc0', also stored in it, returns i32 — every function a call through 'rs[].f' may run must return one type` · so the check owes that refusal here, and the emit reject is what stands between this program and a trap · found grading [D15203](D15203.md)'s fallback, which made the two-return spelling trap until the row it read was recorded with its function sets · present on master `aaf9ba5c` · filed 2026-11-04 against master `214d93f9`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function mk() { return [{ f: inc0 }, { f: half }] }
    print(mk()[1].f(3))

#### Mechanism

`holeSlotJudge` judges a call through a slot of a binding (`rs[].f`) against every function stored there, following the binding to its initialiser; a call whose root is a call to the function (`mk()[1].f`) reaches no binding, so the functions the returned literal stores in `f` are never judged at the call's arguments.
