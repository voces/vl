### D15221 — a call through a field of a function's returned list of records is not judged for one result, where the same call through a binding of it is refused

**closed · now a loud check reject, `cannot store 'half' in 'mk()[].f': called at (i32) it returns f64, where 'inc0', also stored in it, returns i32 — every function a call through 'mk()[].f' may run must return one type`, the bound twin's sentence · was loud emit reject, `emitProgram: ref valtype with no interned shape`, clause 2 · DESIGN refusal, as the bound twin's · found grading [D15203](D15203.md)'s fallback · filed 2026-11-04 against master `214d93f9` · fixed by judging a slot read whose root is a call through the values the call returns, as a binding the call initialises is (`holeSlotCallRootJudge`), at every root the judge traces to a call; named set `d15221-call-root`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function mk() { return [{ f: inc0 }, { f: half }] }
    print(mk()[1].f(3))

#### Mechanism

`holeSlotJudge` judges a call through a slot of a binding (`rs[].f`) against every function stored there, following the binding to its initialiser; a call whose root is a call to the function (`mk()[1].f`) reaches no binding, so the functions the returned literal stores in `f` are never judged at the call's arguments.
