### D14890 — a call in a list literal handed to a generic list identity with a second call is invalid wasm

**open · check-clean invalid wasm, clause 1 · blocked on [D14385](D14385.md), ruled B and backlogged · the residue of [D14813](D14813.md) · filed 2026-11-01 against master `88e31332`**

Repro:

    type Circle = { r: i32 | null }
    function sink(_x: Circle) { }
    function mkcall() { { r: null } }
    sink(mkcall())
    function keep<T>(xs: T[]): T[] { xs }
    const ks = [{ r: null }]
    print(keep(ks).length)
    const k = keep([mkcall()])
    print(k[0].r ?? 12)

Want:

    1
    12

#### Mechanism

`sink(mkcall())` builds `mkcall`'s record at `Circle`, so `[mkcall()]` is a `Circle[]`. Mono pins
the literal's call at that rep and builds `keep` at `Circle[]` (`elabListArgAtRep`), but the
binding `k` is held at the call's own type `{r: null}[]`, which `keep(ks)` also instances. The
call's `Circle[]` result is stored into a `{r: null}[]` local, which does not validate. With no second
call the record solve takes the rep (`recListRetTakesRep`, D14813), and the binding runs.

#### Blocked on D14385

The first invalid instruction is `sink(mkcall())` itself: `mkcall` returns its own `{r: null}` row
where `sink` takes `Circle`. The second `keep` instance at the own type (`keep(ks)`) keeps
`mkcall`'s literal at its own storage, while the checker accepted the `Circle` delivery. That is
[D14385](D14385.md)'s shape, one function result delivered into a wider record and kept at its own
type elsewhere. D14385 is ruled B (build the result at the destination) and backlogged as
ROADMAP.md §"Backlogged: ruled, waiting to be built", an inferred result built at its destination. This row waits on that item. Giving `k`'s cell the call's rep list does not help while
the body is built at the own type.

D14385's interim refusal (2026-11-02) does not reach this row. It refuses a use kept at its own type
only where the destination boxes a union the result does not, and this row's widening is into a
`| null` field, which a build at the destination already serves. What breaks here is the second
`keep` instance at the own type.
