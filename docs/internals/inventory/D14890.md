### D14890 — a call in a list literal handed to a generic list identity with a second call is invalid wasm

**open · check-clean invalid wasm, clause 1 · the residue of [D14813](D14813.md) · filed 2026-11-01 against master `88e31332`**

Repro:

    type Circle = { r: i32 | null }
    function sink(_x: Circle) { }
    function mkcall() { { r: null } }
    sink(mkcall())
    function keep<T>(xs: T[]): T[] { xs }
    const ks = [{ r: null }]
    print(keep(ks).length)
    const k = keep([mkcall()])
    print(k[0].r ?? 12)

Want:

    1
    12

#### Mechanism

`sink(mkcall())` builds `mkcall`'s record at `Circle`, so `[mkcall()]` is a `Circle[]`. Mono pins
the literal's call at that rep and builds `keep` at `Circle[]` (`elabListArgAtRep`), but the
binding `k` is held at the call's own type `{r: null}[]`, which `keep(ks)` also instances. The
call's `Circle[]` result is stored into a `{r: null}[]` local, which does not validate. With no second
call the record solve takes the rep (`recListRetTakesRep`, D14813), and the binding runs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `print(keep(ks).length)` | prints `12` (D14813) | **yes** |
| `sink(mkcall())` | runs | **yes** |
| `ks` typed `{ r: i32 }[]` in place of `{ r: null }` | still invalid | no |

#### Grading list

Each is the Repro's first five lines with the rest replaced:

* the same calls inside a function body: invalid inside it.
* `const k = keep([mkcall()])`, `const c: Circle = k[0]`, `print(c.r ?? 12)` with no second call:
  invalid wasm, the element bound at an annotation.
* `const ks: K[] = [{ r: null }]` over `type K = { r: null }` beside the literal's call: a loud
  refusal, which must not turn silent.
