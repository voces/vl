### D16069 — a recursive record alias spelled with a top-level `| null` builds an invalid module once a binding of it is reassigned from its own field

**closed 2026-11-14 · runs, prints `true` · after pass 0b a recursive null-fold alias's record names its own nullable, not the wrapper (`nulFoldTieKnots`), and a literal delivered into the wrapper is built at that record · was check-clean invalid wasm, clause 1 · found grading D3034's recursive generic union cases · filed 2026-11-14 against master `6800e3dfc`**

Repro:

    type LL = { v: i32, n: LL } | null
    let c: LL = { v: 1, n: { v: 2, n: null } }
    if c != null { c = c.n }
    print(c != null)
    // prints true since the close; before it, vl run: the emitted module failed to validate

Want:

    true

#### Mechanism

Not yet located. The declaration folds to a one-member union over `{ v: i32, n: LL }?`, and the
field `n` points back at that wrapper rather than at the nullable inside it. The binding and the
field read are therefore two arena types for one value, and the reassignment stores one through
the other's rep.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |

| `type N = { v: i32, n: N \| null }`, binding `N \| null` | runs, `true` | **yes** (the alias-level `\| null`) |
| a field read in place of the reassignment, `const d = c.n; if d != null { print(d.v) }` | loud check reject, `field 'v' is not on every member of LL` | second face |

#### Grading list

#### Close

`nulFoldTieKnots` (`check_relate_core.vl`, run by `check_top_level.vl` after pass 0b) decides which
null-fold wrappers are recursive, then re-points each such record's field that names a wrapper (as
the field, a list's element, or under `| null`) at the wrapper's nullable. A generic instance is tied
the same way in `gaUnionUnwrap` and then unwraps to that nullable. `recordRepTyAdopt` peels the
wrapper (`nulFoldMemberTy`), so a literal delivered into it is built at the record's row. Both faces
above run, as do the `null`-first and `| null`-field spellings and the generic one
(`tests/cases/soundness/recursive-nullable-alias-{reassign,functions}.vl`). Left open:
[D16152](D16152.md) (a mutual pair, since closed), [D16153](D16153.md) (a list field, since closed),
[D16154](D16154.md) (a generic function over the generic spelling, since closed).
