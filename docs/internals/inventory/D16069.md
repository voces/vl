### D16069 — a recursive record alias spelled with a top-level `| null` builds an invalid module once a binding of it is reassigned from its own field

**check-clean invalid wasm · clause 1 · found grading D3034's recursive generic union cases · filed 2026-11-14 against master `6800e3dfc`**

Repro:

    type LL = { v: i32, n: LL } | null
    let c: LL = { v: 1, n: { v: 2, n: null } }
    if c != null { c = c.n }
    print(c != null)
    // vl check: rc 0.  vl run: the emitted module failed to validate inside the module's top-level code

Want:

    true

#### Mechanism

Not yet located. The declaration folds to a one-member union over `{ v: i32, n: LL }?`, and the
field `n` points back at that wrapper rather than at the nullable inside it. The binding and the
field read are therefore two arena types for one value, and the reassignment stores one through
the other's rep.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| no reassignment, `print(c != null)` only | runs, `true` | **yes** |
| `type N = { v: i32, n: N \| null }`, binding `N \| null` | runs, `true` | **yes** (the alias-level `\| null`) |
| a field read in place of the reassignment, `const d = c.n; if d != null { print(d.v) }` | loud check reject, `field 'v' is not on every member of LL` | second face |

#### Grading list

The generic spelling `type LL<T> = { v: T, n: LL<T> } | null` walked with `c = c.n`, which fails
at emit with `nested-struct field element type is not interned` since [D3034](D3034.md); the
second face above.
