### D3850 — a `let` alias of a hole lambda written through its capture cell, written more than once, written into two aliases, or initializing an alias nothing calls left a hole lambda at its `i32` default

**closed 2026-10-08 by lane SC · was check-clean invalid wasm · found by the rv3443 alias generator (37 of its 150 programs on master `e64f78985`) · pins: `tests/cases/closures/hole-lambda-alias-mutate-then-read.vl`**

Repro:

    function mk(x: string) {
      const c = (y) => y + "C"
      const e = (y) => y + "E"
      const g = (y) => y + "G"
      let d1 = g
      print(d1(x))
      print((() => d1(x))())
      let d2 = c
      const w4 = (): i32 => { d1 = d1; 0 }
      w4()
      print(d2(x))
      let d4 = e
      print(d4(x))
    }
    mk("a")
    // vl check: rc 0.  vl run: invalid module inside `g`, `expected (ref $2), found i32`

Want:

    aG
    aG
    aC
    aE

#### Mechanism

Four gaps in the alias resolution of D3844/D3845/D3848, each leaving a hole lambda unpinned:

* a value read through the rewrite's capture cell, `d1[0]` (the spill of `d1 = d1`), or a
  `let` whose initializer is that cell `[v]`, did not resolve to the lambda, so the write
  counted as untraceable (`monoLamValueFe` follows both now);
* a lambda written into one binding more than once (a loop, a repeated store) counted as two
  peers (`monoAssignedPeerFe` dedupes by target);
* a lambda written into two bindings had no peer; it now takes theirs where they agree;
* a lambda that only initializes a `let` written with another lambda had no peer
  (`monoInitPeerFe`).

D3832's stub of an unread lambda now also covers a lambda read only to initialize another
binding nothing reads, or only to be written into one (`const d1 = c` with `d1` unread), and
a call through `let d4 = d2` where `d2` is a capture cell resolves through it. A chain with a
cell on it counts as written, so its call keeps its function-value call (D3849's rule).

Over the rv3443 generator, 600 programs: 132 move from SILENT and 28 from LOUD to the right
output, none regress, and none print a wrong value. 30 remain silent, 24 of them
[D3851](D3851.md); an intermediate cut of this close printed wrong values in 3 of them,
caught by the generator before it landed.
