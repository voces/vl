### D16061 — an anonymous record handed to an un-annotated parameter keeps its field typed at the hole, so the field recorder resolves the element's name

**runs today and must keep running · 3 programs of the sweep population · filed 2026-11-13 against master `6d8f552d`**

Repro:

    type A = { r: i32 }
    function ns1(): A[] | null { return [{ r: 4 }] }
    function take(a) {
      const l = a.xs
      if l != null { print(l[0].r) } else { print(0) }
    }
    take({ xs: ns1() })
    // vl check: rc 0.  vl run: prints `4`

Want:

    4

#### Mechanism

The literal `{ xs: ns1() }` is a call argument to `take`, whose parameter has no annotation.
The literal's row records its field `xs` at the open hole, not at `A[] | null`. So the
anonymous-literal recorder (`emit_collect`) has no element type to hand
`recordSFieldElemRowTy`. `recordFieldElemRow` falls back to resolving the element name `A`
(`fieldElemTyIxOfName`). Lane H's probe found this fallback, after cut 2 (#7706), reached on
an anonymous literal's field only with the field typed at the hole. The witnesses are this
program, `tests/cases/generics/narrowed-nullable-at-pin.vl` and
`tests/cases/maps/list-held-map-pinned-by-callee-store.vl`.

#### Ablation

| ingredient changed | outcome | name fallback reached? |
| --- | --- | --- |
| none (the witness) | runs, `4` | yes |
| `function take(a: { xs: A[] \| null })` | runs, `4` | no |
| the literal bound first, `const o = { xs: ns1() }; take(o)` | runs, `4` | no |

#### Grading list

The three witnesses above. The close: the literal's row takes the field type the argument has
at the instance it is delivered to, the anonymous recorder hands it, and
`recordFieldElemRow`'s name fallback is deleted.
