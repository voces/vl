### D1492 — two rows one key, one of them with an EMPTY variant slice, and `merge-diffset` scores it 0

**runs today and must keep running · 1 fused pair of 312 · filed 2026-09-03 against master `fd95c79f`**

Repro:

    type Sc = { n: i32 }
    type Dg = { m: i32 }
    type AS = (Sc | Dg)
    const cell: Sc | Dg = { n: 3 }
    const also: AS = { m: 9 }
    if cell is Sc { print(cell.n) } else { print(0) }
    // prints 3. Row `Sc|Dg` holds the variant slice [Sc, Dg]; row `AS` holds [].

#### Mechanism

A union's box tags are positional over its VARIANT SLICE (`unVarStart`/`unVarCount` into
`uVariants`), so the licence the key rests on is that two rows one key cannot tell apart hold
the same slice. Step 3 asserted that as `keySweep/merge-diffset` — a compare of the recorded
member-set STRING — and that predicate is a proxy which is wrong in **both** directions:

* **It misses this.** `type AS = (Sc | Dg)` is a ONE-member `UnionDecl` over an inline union, so
  `collectU` records the member set `Sc|Dg` (the alias expansion) while its variant list is
  built from the declaration's single member and comes out EMPTY. Same key, same set string,
  slices `[Sc, Dg]` and `[]`. `merge-diffset` reads **0** for this pair; the slice compare reads
  **1**, and 1 is what the corpus scores on master today.
* **It over-reports.** Normalising `null` to one end of the key — 4a's deferred miss #3 — moves
  `merge-diffset` from 0 to **25**, and every one of the 25 pairs differs *only* by where `null`
  sits (`f64|null` against `null|f64`, `boolean|f64|string|Json[]|{[string]:Json}|null` against
  the same list with `null` first). No variant moves: `registerInlineUnion` skips a `null` atom
  when it pushes `uVariants`, and a value atom's tag is `scalarTagOfKind`, which reads the KIND.
  The slice compare stays at 1 under the normalisation.

So the normalisation is **not shipped here**: the sharper assertion is not yet 0, and re-keying
rows while the licence is unmet is the wrong order. `keySweep/merge-diffvar` ships instead, and
closing this pair is what unblocks both it and step 5's switch.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the alias `type AS = (Sc \| Dg)` | one row, no merge | **yes** |
| the second binding `also: AS` | the `AS` row is still minted by the declaration | no |
| making `AS` a multi-member declaration (`type AS = Sc \| Dg \| i32`) | different key, no merge | **yes** |
