### D4575 — a list of a generic returned by an un-annotated function and bound at an annotated list type reaches no call

**closed 2026-10-14 by lane SC · runs · was loud emit reject · an annotated binding initialized by a call of a concrete function that returns only literals, when every call of it initializes a binding annotated alike, delivers each returned literal at that annotation, and a generic in it is instanced only where the instance's return is the annotation's own (`monoFlowAnnLits`; `fn-value-flow-design.md` §(f) step 4) · pins: `tests/cases/closures/generic-list-returned-to-annotated.vl` · found by `fn-value-generic-list-read.matrix.vl` (`return_inferred`, annotated face) · filed 2026-10-14 against `bd616c03b`**

#### Mechanism

The flow reads in `compiler/emit_mono.vl` (`monoFlowRetVals`) follow a call into the literal its
callee returns, but only when the reading binding is un-annotated; an annotated destination is
expected to pin the value instead. The pin for an annotated `const` (`monoNoteBindDeliveryAt`)
coerces a literal or a name at the annotation, and a CALL returning the literal is neither, so
`id` inside `d` is instanced by nothing.
