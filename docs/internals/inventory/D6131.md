#### Mechanism

#4012 (`f05cc1f67`, S5) made a module's merge suffix a stable id instead of its discovery
position, so `name$m3` became names like `name$m1258554952`. The write-effect summaries
(D6130) carry those names in their `=name$mID,` shapes, and every type and symbol key carries
them as well. In a `--names` profile from `99d9b571f` to `f05cc1f67`, `weScanShapes` went from
17.26% to 19.35% inclusive, which is about 538 of the 988 added samples. `__str_hash__` went
from 3.25% to 4.06%, `tyTopIndexOf` from 1.61% to 2.29%, and `tyHasSepByte` from 0.89% to
1.19%. Most of the jump is longer strings inside D6130's probe, so closing D6130 shrinks this
row too.
