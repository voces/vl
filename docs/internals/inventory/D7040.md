### D7040 — a declared record return `{ v: T | K }` read directly at a scalar `T` has no interned shape

**loud emit reject · clause 2 · found by lane L6 step 3's ablations · the same on master `6ca1ebc5c` · filed 2026-10-19 against master `6ca1ebc5c`**

Repro:

    type K = "a" | "b"
    function r<T>(x: T): { v: T | K } { return { v: x } }
    print(r(3).v)
    // vl check: rc 0.  vl run: emitProgram: ref valtype with no interned shape

Want:

    3

#### Mechanism

The instance's return record has the field `i32 | K`, a scalar beside a literal-union atom with
no reference arm. The field code ladder has no code for that pinned spelling, so the shape intern
gets `-1` and the record's valtype has no shape. The same record built without the pin
(`type R = { v: i32 | K }`), or delivered to an annotated binding, is built fine. Not D3567 or
D3709: those are un-annotated returns. This return is declared.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the type parameter (`r(x: i32): R`, `R = { v: i32 \| K }`) | runs | **yes** |
| the direct read (`const q: { v: i32 \| K } = r(3)`) | runs | **yes** |
| the record (`r<T>(x: T): T \| K`) | runs | **yes** |
| the alias (`{ v: T \| "a" \| "b" }`) | still refuses | no |
| `i32` for `f64` or `boolean` | still refuses | no |
| a scalar `T` (`r("a")`, `T := L`) | runs | **yes** |

#### Grading list

`T := L | null` with `{ v: T | i32 }`, and `T := i32 | null` with `{ v: T | K }`, both refuse
the same way. `T := i32 | string` runs, because a string arm gives the field a box.
