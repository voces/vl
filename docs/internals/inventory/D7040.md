### D7040 — a declared record return `{ v: T | K }` read directly at a scalar `T` has no interned shape

**closed · was loud emit reject, clause 2 · found by lane L6 step 3's ablations · filed 2026-10-19 against master `6ca1ebc5c` · closed by lane L6 against master `6d9597a6e`**

Repro:

    type K = "a" | "b"
    function r<T>(x: T): { v: T | K } { return { v: x } }
    print(r(3).v)

Want:

    3

#### Mechanism

`collectU` registers every union the program's types reach, and it runs before
monomorphization. The instance's declared result `{ v: i32 | K }` exists only after its pin, so
its field union `i32 | K` had no registered row, the field code ladder had no code for it, and
the shape intern got `-1`. `monoMakeInstanceRetAnn` registered the result type itself but not
the unions inside it. It now walks the result through `registerTyReachUnions`, the same
reachability walk `collectU` uses, and reassigns the tags when the walk added a row. A
`(T | K)[]` result, which refused as `union atom has no value box`, closes with it.
