### D1758 — D1476's paired capture rungs were built for the STRUCT rep only, so a captured un-annotated PROJECTION of a union, a nullable scalar or a map is still check-clean invalid wasm

**check-clean invalid wasm · clause 1 · filed 2026-09-06 against master `dcbf7521c`, re-graded as filed on `b35b2a093` · found by `scripts/day-one/sample.py` seeds 3001–3005 (2,500 pairs), 11 of the 25 SILENT programs · residue of [D1476](D1476.md), whose own witness runs · 0 corpus cells**

Repro:

    type MaybeN = i32 | null
    function mkval(): MaybeN { return 4 }
    function go() {
      const xs = [mkval()]
      const held = xs[0]
      const get = () => held
      print(get() ?? 0)
    }
    go()
    // vl check: rc 0.  vl run: exit 70,
    // the emitted module failed to validate inside `go`:
    // type mismatch: expected i32, found (ref $type)

Annotate the binding — `const held: MaybeN = xs[0]` — and it prints `4`. That is
[D1476](D1476.md)'s own sentence; what is new is that D1476's element is a STRUCT and this
one is not.

#### Mechanism

Predicted from D1476's own measurement, not re-probed. D1476 records that the capture of a
binding whose initialiser is a PROJECTION carries no committed rep, so it falls to
`captureValKind`'s i32 default and the closure's frame declares an i32 where the value
arrives; its close added PAIRED arena rungs (a kind and its companion slot) to
`letInitCellKind` and `captureValStructIdx` for the struct case. Every other non-i32 rep
still has the default: a struct-union box, a value-union box, a nullable-scalar niche and a
map all reproduce the row verbatim at a non-struct element, and the message is D1476's own
first message (`expected i32, found (ref $type)`).

**Which spellings escape is which secondary rung happens to answer, not a second mechanism.**
An INDEX projection refuses at every scope but plain module; a FIELD projection refuses only
inside a module-level block (`if true { … }` or a module `while`) and runs in a function
body. A DECLARED holder type is enough to show the field face is this row and not
[D1757](D1757.md)'s anonymous mint — `type Boxed = { it: Shape }` fed by a helper still
refuses at the module block and still runs in the function body — and the binding annotation
fixes both faces, which D1757's does not.
