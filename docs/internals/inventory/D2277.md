### D2277 — twelve `exprListRep` positions answer only the list reps an old predicate named there

**runs today and must keep running — the witness prints `7`; it is a loud emit reject (`ref valtype with no interned shape`) when the `empty-hole` gate admits the ref list · open follow-up of D2275: each gate is a behaviour change to make, or to rule out, one at a time · filed against master `2d8341305`**

Repro:

    type S = { m: i32 }
    function sinkStruct(xs: S[]) {
      xs.push({ m: 7 })
      print(xs[0].m)
    }
    function fqStruct() { return [] }
    sinkStruct(fqStruct())
    // vl check: rc 0. vl run: 7.
    // With `listRepGateAdmits("empty-hole", "reflist")` true: emit error, ref valtype with
    // no interned shape — the returned `[]` claims a ref list before its row exists.

#### Mechanism

`exprListRep`'s syntactic rungs are the union of the seven old `expr*Array` ladders, and D2275
kept each rung answering only the kinds whose predicate carried it, so the union changed no
program. Those restrictions are the `ListRepGate` arms of `listRepGateAdmits`
(`compiler/emit_classify.vl`), and every gated position reads through `gatedListRep`:
`grep -c 'gatedListRep(' compiler/emit_classify.vl` counts them. Un-gating a position is a
one-arm change to `listRepGateAdmits`. The recorded type answers first at every position, so
most gates are unobservable today. The table was measured by building a compiler with one gate
admitting every list rep, and running `list-kind-grid.py --run` plus the four programs the
all-gates-open build moved in `tests/cases`, the distilled corpus, `std` and the capability
probes.

#### Grading list

Per gate: `list-kind-grid.py --run --only <kind>` for each kind the gate would newly admit, and
the corpus byte A/B against the gated seed. A gate whose un-gating moves nothing needs a probe
that reaches the position without a recorded type, such as a monomorphized body or an
un-annotated inferred return, before it can be called safe or useful.

After D2295 gave every integer list-code table a `u8` row, the five `u8` exclusions (`map-read`,
`capture`, `callee-value`, `map-filter`, `callee-return`) were measured open together: the grid's
u8 column is unchanged (457 of 458), and the emitted bytes are identical over `tests/cases`, the
distilled corpus, the capability probes and a hand probe of un-annotated returns, captures, map
reads and closure results over `u8[]`. A `u8` cannot bind a type parameter, so no monomorphized
body reaches these positions either. Unobservable is not shown safe, so they stay gated;
`spread` stays gated for its own reason above.
