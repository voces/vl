#### Mechanism

`A_i = {l: A_(i-1), r: A_(i-1)}` shares each level's type twice, so a walk that renders or
compares it structurally visits 2^depth nodes. Master rendered the pin's name structurally
(3.6 s at depth 16) and trapped at 18. Since #3208 every whole-type walk carries a node budget,
and each walk reads a shared part once, so depths 12 to 16 pin and run (16 slowly) where master
emitted an invalid module; 18 and beyond still trap in the spelling renderers. A fix keys shared subtrees once (a memo per type index) rather than walking paths.
