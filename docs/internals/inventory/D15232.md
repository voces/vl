### D15232 — a binding holding a container read built wider, reassigned with a literal whose field is itself such a read, is refused at emit

**closed 2026-11-04 · runs, prints `4` then `4` · was loud emit reject, `emitProgram: object literal matches no union variant`, `vl check` rc 0 · clause 2 · found grading [D15188](D15188.md) · filed 2026-11-04 against master `dc27d0a9` · closed by the assignment and push stamps reading where an element of `xs` is built from `xs`'s list literal rep stamp (D15181's field-wise build) when the build table has no row: `recElemReadStampTy` for an assignment into a binding of `xs[i]`, and `recHeldElemBuilt` for a push into `xs` · fixture `tests/cases/soundness/record-list-literal-element-built-by-stamp-runs.vl`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const xs = [{ a: mk() }]
    let b = xs[0]
    b = { a: xs[0].a }
    print(b.a.f)
    print(wideJ.f ?? 0)

Want:

    4
    4

#### Mechanism

`b` holds an element of `xs`, and the literal assigned into it has a
field that is itself a read built at `J`. D15188's stamp builds a literal assigned into such a
binding at the binding's record; this one reaches the emitter as a literal no row matches.
