### D15232 — a binding holding a container read built wider, reassigned with a literal whose field is itself such a read, is refused at emit

**loud emit reject · `emitProgram: object literal matches no union variant` · `vl check` rc 0 · clause 2 · open, target `4` then `4` · found grading [D15188](D15188.md) · filed 2026-11-04 against master `dc27d0a9`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const xs = [{ a: mk() }]
    let b = xs[0]
    b = { a: xs[0].a }
    print(b.a.f)
    print(wideJ.f ?? 0)

Want:

    4
    4

#### Mechanism

Not ablated past the table. `b` holds an element of `xs`, and the literal assigned into it has a
field that is itself a read built at `J`. D15188's stamp builds a literal assigned into such a
binding at the binding's record; this one reaches the emitter as a literal no row matches.
