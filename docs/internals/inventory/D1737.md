### D1737 — a `??` join's STRUCT default names no arm of its result union when another struct row precedes the arm's, because the arm lookup reads a variant-table index as a struct-table row

**loud emit reject · filed 2026-09-06 against master `6de9fd11a` · the price D1714's close
paid rather than pass a raw `(ref $struct)` into a box blocktype · 0 corpus cells**

Repro:

    type A = { r: i32 }
    type W = { f: string | null }
    function st(): A { return { r: 8 } }
    function mkS(): string | null { return null }
    const w: W = { f: mkS() }
    const v = w.f
    const k = v ?? st()
    if k is A { print(k.r) } else { print(0) }
    // vl check: rc 0.  vl run: exit 1,
    // emitProgram: `??` default names no arm of the union its result is

#### Mechanism

The `??` joins `string | null` with an `A` default, so the result is the union box and D1714's
arm boxes both sides. Boxing the DEFAULT asks `unionArmVariantForStructExpr`, which resolves
the value's struct row through `structIndexOfExpr` and then compares that row's field layout
against each of the union's variant arms. `structIndexOfExpr` answers a VARIANT-table index for
a variant-returning call — its own comment says so — and the two index spaces coincide only
while the arm's struct is the first row in the struct table. Declaring `W` puts a second row
there, the layout compare reads `W` instead of `A`, no arm matches, and the boxing declines.

Before D1714's close the decline fell through to `emitUnionCoerce`'s `exprStruct` passthrough
and put a bare `(ref $A)` under a `(ref $uBox)` block type — check-clean invalid wasm. The
close refuses instead, because the block type is the result's rep and no raw struct can satisfy
it; the refusal is the price, not the fix.

**One annotation hides it.** Annotating the RESULT (`const k: M = v ?? st()` with
`type M = string | A`) runs and prints `8`, because the declared destination routes the default
through its own alias rather than through the arm lookup. Annotating the OPERAND does not:
`const v: string | null = w.f` refuses identically.
