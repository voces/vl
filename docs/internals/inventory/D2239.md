**check-clean invalid wasm · clause 1 · found by the `nullable-list-hole-param-u8` matrix while closing D2238 · filed 2026-09-23 against master `f2234c2e5`**

    const src: u8[] | null = [200]
    const xs: (u8[] | null)[] = []
    xs.push(src)
    const v: u8[] | null = xs[0]

#### Mechanism

Not yet located. The same program over an `f32[] | null` element prints `1.5`, as do the `i64`,
`f64` and `string` leaves (the `nullable-list-join-null-*` matrices run every container
position), so the gap is the `u8` leaf's nullable niche as a REF-LIST element: the push stores a
nullable wrapper where the list's element type is the non-null one, which reads as the element
slot being built from `u8[]` rather than `u8[] | null`.
