Repro:

    function a<T>(x: T) {
      const r: { f: ((t: T) => void) | null } = { f: null }
      print(r.f == null)
    }
    a(2.5)

#### Mechanism

The elaboration records the literal `{ f: null }` per instance as `{f: null}`. It does not
record the instance's declared slot `{f: ((t: f64) => void) | null}`. So the mint's per-instance
read (`elabLitInstTys`) finds no type of its own, and the literal's row is the template's. Today
the field-set scan maps that row onto the slot's row by field set. Without the scan, the
binding's declared row and the literal's row differ. The other two family-A1 cells that the
instance key does not reach need other work: `generics/hole-list-literal-in-record-field-at-two-types`
(`{xs: boolean[]}` and `{xs: i32[]}` collide in one row, step-7 row identity) and
`index/generic-trap` (a map-keyed literal shape gets no interned shape).

#### Ablation

Each row is run with the scan deleted.
