#### Mechanism

`T` was bound only where it stood alone or as a top-level union arm, so a `T` inside a list
element, nullable, record field or map value (`(T | i32)[]`) stayed unbound. The instance's
parameter then carried an open `T` and its list had no slot. Two binders now walk into those
positions and pair each inner union with the argument's: `bindGenInnerUnionArms` in the checker
and `monoBindInnerUnionArms` in the monomorphizer. The per-argument pin `monoBindInnerArmPins`
runs before the textual `monoBindFromAnn`. That textual match pairs `(S | T)[]` with
`({ g: i32 } | string)[]` by spelling and bound `T` to the whole element union, which left the
instance's union box un-narrowed in an `else` arm (invalid wasm, D10931).
