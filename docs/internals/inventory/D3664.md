#### Mechanism

`captureBoxRewrite` decides by-reference capture from the syntax tree, before `cloLiftScan`
knows a closure will be lifted. It now asks `cloUnboxPick` (`compiler/emit_lift.vl`) first: a
scalar `let` (`i32`, `i64`, `f64`, `f32`, `boolean`) stays unboxed when every function that
names it is nested directly in the frame and passes the same syntactic lift test `cloLiftScan`
applies (`clSyntax`), in a frame chain with no type parameter, no un-annotated parameter and no
parameter whose type reaches a function (so neither monomorphization nor callback
specialisation clones it later), no argument of a call
to a capturer can change the binding, and every assignment to it is typed as the binding is.
`cloLiftScan` re-checks that each such capturer was lifted and refuses loudly otherwise. A
lifted function that assigns a capture declares it as an extra result after its own; `fbReturn`
and the function's `end` push it, a self call in tail position stays `return_call` (the
write-back is dropped with it), and `emitDirectCall` writes each returned value back into the
caller's local, last result first. Inside the callee the capture is its own parameter, read and
written in place (`localIndexOf`).
