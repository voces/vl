**loud check reject · clause 2 · open, target `6` then `6` · found closing [D15238](D15238.md) · filed 2026-11-04 against master `7338b7d2`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const xs = [mk()]
    let y = mk()
    let z = xs[0]

#### Mechanism

Not ablated past the table. Both bindings are held at `J`, so `r` is built at `J` at both. The
built-read assignment is answered at the pass end, before the store column records the call's
build, so its refusal of `r`'s other own-storage deliveries refuses `y = r`.
