### D15282 — a fresh record binding assigned into a built-read binding and a built-call binding is refused

**closed 2026-11-04 · runs, prints `6` then `6` · was a loud check reject, clause 2 · found closing [D15238](D15238.md) · filed 2026-11-04 against master `7338b7d2` · closed by one producer for the assignment stamp: the pass end's `recLitPlaceBuiltTy` reads a call-initialised binding's build (`callBuiltTy`, through the `checkerForceFn` slot, unless the record solve copies the call back) beside a built read's, and the store column's `storeAsgLitsBuild` is deleted, so each place's own-storage refusal skips every place · fixture `tests/cases/soundness/record-binding-assigned-into-read-and-call-held-bindings-runs.vl`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const xs = [mk()]
    let y = mk()
    let z = xs[0]
    const r = { f: 6 }
    y = r
    z = r
    print(y.f)
    print(z.f)

    6
    6

#### Mechanism

Both bindings are held at `J`, so `r` is built at `J` at both. The
built-read assignment is answered at the pass end, before the store column records the call's
build, so its refusal of `r`'s other own-storage deliveries refuses `y = r`.
