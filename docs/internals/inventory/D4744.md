### D4744 — a function-local `i32[] | K[]` captured by a closure is read as a union box while its slot holds the list

**check-clean invalid wasm · inline `i32[] | K[]` (a numeric literal union `K`) bound in a function and narrowed inside a closure · clause 1 · the annotated `block_if_capture`, `block_while_capture`, `block_bare_capture` and `fn_body_capture` cells of a capability matrix over `i32[] | K[]` · filed 2026-10-14 against master `3a8eb2b61`**

Repro:

    type K = 0 | 1
    function g() {
      const c: i32[] | K[] = [1, 0, 1]
      const f = () => {
        if c is i32[] { print(c.length) }
      }
      f()
    }
    g()
    // vl check: rc 0.  vl run: invalid module, expected (ref $0) union box, found (ref $5) list

Want:

    3

#### Mechanism

The local renders `i32[]` (the union collapses its two one-list members), so its slot is a
plain list. The closure's capture types the captured `c` from the union's member set and lays
it out as a union box, and the capture copies the list in with no box. Each side reads a
different producer for one type.
