### D16800 — a reassigned `let` holding an element a kept maker's build stores at a wider record, handed to an annotated narrower parameter, builds a module that fails to validate

**check-clean invalid wasm · clause 1 · `type mismatch` at the call · an index read and a loop variable alike · the same before D16787 · found by lane WIDTH closing D16787 · filed 2026-11-16 against master `e056e7cea`**

#### Mechanism

`show` is instanced at `J` for the argument `w` (D14532 reads the binding's initialiser, a built
read). The emitter lays a reassigned `let` out at its checker type `{ f: null }`: its build rungs
(`letHeldTyOf`, `emit_classify.vl`) answer only for a binding that holds its initialiser alone. So a
narrow local reaches a `J` parameter. A `const` (or an un-reassigned `let`) runs.

| the call (`print(w.f)`) | runs for a loop variable's `let` (D16787) | **yes** |
| the index, a loop variable instead (`let w = y`, `w = y`) | invalid module | no |
