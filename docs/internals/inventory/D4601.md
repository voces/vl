### D4601 — a tagged union arm with a value-union or nullable field is never adopted by a record literal

**loud check reject · clause 2 · ablated over 44 hand probes · filed 2026-10-14 against master `56e06d91c`**

Repro:

    type U = { kind: "a", q: i32 | null } | { kind: "b" }
    const u: U = { kind: "a", q: 4 }
    if u.kind == "a" { print(u.q == null) }
    // vl check: cannot assign {kind: string, q: i32} to 'u' of type U

#### Mechanism

`assignableExpr` delivers a record literal into a union by trying each record arm field-wise,
so a bare `"a"` keeps its literal type against the arm's `kind: "a"`. It only tries arms that
`unionArmBoxSafe` admits, and that gate refuses an arm with a value-union field (`i32 | string`)
or a nullable field whose inner type is not a literal union or `f32` (`i32 | null`,
`string | null`, `Bi | null`, `i32[] | null`). With the arm skipped, only plain `assignable`
is left, which sees the softened `{kind: string, …}` and fails against every arm. Without a
literal field the plain check passes, and the emitter boxes the same arm and reads it back:
`{ inner: { q: Bi | null } } | { n: i32 }` prints `7`, and `{ tag: string, q: i32 | string } | { n: i32 }`
prints `s`. So the gate refuses a rep the emitter already builds. `unionArmSeedSafe` (the seed
gate) is not the cause: admitting nullable and union fields there moves none of the probes.

#### Ablation

| spelling | outcome | needed? |
| --- | --- | --- |
| reported: `{ kind: "a", inner: { q: Bi \| null } } \| { kind: "b" }`, `q: null` or `q: { v: 3 }` | refuses | — |
| field `q: i32 \| string`, `string \| null`, `i32[] \| null` | refuses | no (any value union) |
| field `q: i32`, `Bi`, `i32[]`, a literal union `"x" \| "y"` | runs | **yes** |
| tag `kind: string` (no literal field) | runs | **yes** |
| numeric tag `k: 1` | refuses | no |
| one record arm, `{ kind: "a", q: i32 \| null } \| null` or no union | runs | **yes** |
| position: argument, return, `let` assignment, list element, value `if` | refuses | no |
| the other arm literal (`{ kind: "b" }`) | runs | **yes** |
