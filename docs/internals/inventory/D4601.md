### D4601 — a tagged union arm with a value-union or nullable field is never adopted by a record literal

**closed 2026-10-14 — the witness prints `false` · `unionArmBoxSafe` admits an arm whose field is a nullable or a union of box-safe members (a self-referential arm through a seen set), and a literal leaving out a nullable field is built as the arm the checker adopted rather than the narrower arm its written names fit · fixture `tests/cases/unions/tagged-arm-nullable-field-literal.vl` · templates `tagged-arm-nullable-field.matrix.vl` (runs 23 → 56 of 66, 0 runs → not-runs) and `tagged-arm-omitted-nullable-field.matrix.vl` (runs 0 → 32 of 64) · was loud check reject · clause 2 · ablated over 44 hand probes · filed 2026-10-14 against master `56e06d91c`**

Repro:

    type U = { kind: "a", q: i32 | null } | { kind: "b" }
    const u: U = { kind: "a", q: 4 }
    if u.kind == "a" { print(u.q == null) }
    // vl check: cannot assign {kind: string, q: i32} to 'u' of type U

Want:

    false

#### Mechanism

`assignableExpr` delivers a record literal into a union by trying each record arm field-wise,
so a bare `"a"` keeps its literal type against the arm's `kind: "a"`. It only tried arms that
`unionArmBoxSafe` admitted, and that gate refused an arm with a value-union field (`i32 | string`)
or a nullable field whose inner type is not a literal union or `f32` (`i32 | null`,
`string | null`, `Bi | null`, `i32[] | null`). With the arm skipped, only plain `assignable`
was left, which sees the softened `{kind: string, …}` and fails against every arm. The gate now
descends a nullable's inner type and every member of a union field. Admitting the arm also
admitted a literal that leaves the nullable field out (`{ kind: "a" }`), whose written names
match the `{ kind: "b" }` arm exactly: three resolvers (`objLitUnionArm` in the checker,
`objVariantNameCtx` and `unionArmVariantForObj` in the emitter) now take the arm the checker
adopted when the literal omits one of its fields, which also closes the same trap that the `f32 | null`
and literal-union-`| null` spellings already had on master.
