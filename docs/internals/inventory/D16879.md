### D16879 — an empty list literal inside a list literal used in expression position is refused at emit

**closed 2026-11-16 — the witness runs and prints `1` · was: loud emit reject · `a list literal's element type gives its list no element rep` · clause 2 · the `for` spelling is [D16273](D16273.md) · found closing D16273 · filed 2026-11-16 against master `2a0b71c1a`**

Repro:

    print([[]].length)

Want:

    1

#### Mechanism

The inner literal's element is a hole nothing writes. A binding of the literal is noted pending
and scope close defaults the hole (`flushUninferred`); D16273 notes a literal a `for` iterates the
same way. A literal in expression position was neither, so the hole reached emit open.
`checkArrayLitNode` (`compiler/check_container_lits.vl`) now notes such a literal on a default-only
list (`notePendingLit`), and the program's last scope close (`flushUninferred(0)`) takes the
read-only default for what is still open, after every write, a later one in the same expression
or a callee's included. The list is never named in a refusal, so a binding's own keeps its name.
