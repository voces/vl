### D2245 — a function's own local boxed into a union return takes a same-named top-level block binding's arm

**closed 2026-09-23 — the witness prints `false` · was check-clean silently wrong: `readAll()` returned its `i32[]` boxed under `Err`'s tag, so `is Err` answered `true` and a `.msg` read trapped with `cast failure` · reported by consumer plumb (PL-024: `readFile`'s `b is IoError` trapped once the program also bound `const r = writeFile(…)` in a block, because `std:fs`'s `readFile` returns its own local `r`) · filed against master `91d4210a0` · fixture `tests/cases/unions/local-shadows-module-block-binding.vl`**

Repro:

    type Err = { code: i32, msg: string }
    function readAll(): i32[] | Err {
      const r: i32[] = [1, 2, 3]
      r

#### Mechanism

`emitUnionArmValueBox` boxes a value that is already one arm of a union; its niche rung asks
`exprNullableVariant` / `nulVariantIdxOfExpr` whether the value is a `Variant | null` niche.
For an `Ident` both ask the parameter, the declared local, the capture and the global, then
the frame's own `let` (`frameLetOf`, which answers -1 for the frame being emitted) and last the
module frame's block-scoped `let`s by NAME (`moduleLocalLetOfUnique`). A top-level block's
bindings are visible only inside that block, but the lookup never asked whether the reading
frame binds the name itself: inside `readAll`, `r` is a `list` local, so every earlier rung
declined and the module rung answered with the block's `r: Err | null`. The list was boxed
with `Err`'s tag (`uTags[vi]`), so the caller's `is Err` tag compare held. `structIndexOfExpr`
had the same rung. The fix is `moduleLocalLetSeenFrom`: the module-frame lookup declines when
the reading function has a parameter, a `let` or a loop variable of that name. Across modules
the collision is by name alone, which is how a user's block-local `r` reached `std:fs`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the top-level block binding `r` | prints false | **yes** |
| the block (binding at top level, a global) | prints false | **yes** |
| `Err \| null` on the block binding (`Err`, `string \| null`, `i32 \| null`) | prints false | **yes** |
| the local `r` (a parameter `r` instead) | prints true | no |
| the tail return (`return r`, or a binding `const q: i32[] \| Err = r`) | prints true | no |
