### D2879 — a list literal of a hole parameter's field, built at a `boolean` pin and a literal-set pin, prints the second pin's member as a number

**check-clean silently wrong · clause 1 · identical on master `8e10ef58b` · found by the RF lane's `hcelem` grid · filed 2026-09-27**

Repro:

    type K = "x" | "y"
    function hc(o) {
      const xs = [o.f]
      print(xs[0])
    }
    hc({ f: true })
    const k: K = "x"
    hc({ f: k })
    // vl check: rc 0.  vl run: prints `true` then `0`

Want:

    true
    x

#### Mechanism

Not localised past the ablation. The list literal is shared by both instances of `hc`, and
the literal-set instance's element read is not claimed as an atom, so it prints the atom id.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `boolean` pin (`hc({ f: k })` only) | runs, prints `x` | **yes** |
| the list (`print(o.f)`) | runs | **yes** |
| `3` for `true` | prints `3` then `0` | no |
