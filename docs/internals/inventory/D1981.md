### D1981 — an F32x4 inside an array, struct field, map, nullable or union has no lowering, so the checker refuses the container

**loud check reject · clause 2 (capability) · filed 2026-09-22 against master `a8a104432`, refusal added by SIMD S3 · the nullable and union members lower since D2633; the array, struct field and map still refuse**

Repro:

    import { splatF32 } from "std:simd"
    const b = { pos: splatF32(6.0), m: 1.0 }
    print(b.m)
    // vl check: {pos: F32x4, m: f64} holds a 128-bit vector inside an array, struct field, map,
    //   nullable or union, which has no lowering yet  (D2633: now "…inside an array, struct field or map…")

#### Mechanism

A `v128` value has a scalar rep (valtype `0x7b`) in locals, params, returns and globals, and
nowhere else: there is no struct-field code for it, no `(array (mut v128))` list kind, no
union box arm and no nullable twin. Before S3 these positions emitted invalid wasm (the
annotated array, struct and nullable refused at emit; the inferred array literal was
check-clean invalid wasm). S3 moved all of them to one checker refusal,
`v128NestCheck` in `typecheck.vl`, which fires on the first node or annotation typed with a
container reaching a `v128` within eight levels, and at every generic call that binds a type
parameter to a vector (`noteNestCstr`/`validateNestCstrs`, the `print` constraint's shape) —
a generic body's `[x, x]` holds no vector until the pin. WasmGC allows `v128` struct fields
and array elements, so this is a capability gap, not a design rule.

Not every position is caught by the checker. Two stay LOUD EMIT refusals: a `T | i32`
annotation inside a generic body bound to `F32x4` (`emitProgram: only i32 locals are
supported`), and a vector `let` REASSIGNED inside a closure (`assignment target is not a
parameter, local, or global`) — a mutated capture lowers through a one-element list cell,
which is this row's missing `v128` list; the `f32` twin of that program runs.

#### Grading list

The struct field first (a rigid body is `{ pos: F32x4, vel: F32x4 }`), then the element
list. Each needs its annotated AND inferred spelling, a read back through a field or index,
and a store into a `Buf`. Lift `v128NestCheck`'s arm for a position only after that
position lowers.
