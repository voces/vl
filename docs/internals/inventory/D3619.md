### D3619 — `(v ?? 9) is i32` over an annotated `A | null` holding `null` answers false at a `string` pin

**closed 2026-10-04 — the witness prints `true` · was check-clean silently wrong, clause 1 · found by the #3368 review · filed 2026-10-04 against master `0c087fb3c`, closed against master `32b753681` · fixture `tests/cases/generics/coalesce-param-default-keeps-its-type.vl`**

Repro:

    function F<A>(a: A) {
      const v: A | null = null
      print((v ?? 9) is i32)
    }
    F("s")
    // PRINTS false

Want:

    true

#### Mechanism

[D3580](D3580.md)'s mechanism: the template typed `v ?? 9` as `A` because `9` is assignable to a
type parameter, so at a `string` pin the `is` answered from `string`. The `??` now joins its
default as its `if` spelling does (`A | i32`), and an unbound use registers the pinned box
(`monoPinRetype`).
