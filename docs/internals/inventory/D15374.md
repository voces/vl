### D15374 — a reassigned fresh record `let` pushed into a list built at a wider record is check-clean invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · open, target `7` · found closing [D15283](D15283.md), its reassigned spelling · filed 2026-11-04 against master `c65607c9`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const xs = [mk()]
    let r = { f: 6 }
    r = { f: 7 }
    xs.push(r)
    print(xs[1].f ?? 0)

Want:

    7

#### Mechanism

Not ablated past the table. D15283 builds a `let` nothing reassigns as a `const`. A reassigned `let`
holds every value written into it, so each must be built at `J` where it is delivered there: a
literal stamped, and a record held at its own storage refused. The adoption that would retype the
binding does not run for a written `let`.
