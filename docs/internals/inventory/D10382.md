### D10382 — a generic delivered to an un-annotated parameter and handed on to a generic's function parameter at two types is typed at the first

**loud check reject · `argument 1: expected (string) => string, got (i32) => i32` · clause 2 · CAPABILITY: the parameter called directly, `a(2) + a("ab").length`, prints `4`, and one call `run(a, 2)` prints `2` · found closing [D10310](D10310.md), the un-annotated `argument` cells of fn-value-generic-unannotated-return-handed-open (an emit reject there, `__take(mk())`) and fn-value-generic-repointed-let-listed-open (this check reject, over `[a]`) · present on master `34af3ccc6` · filed 2026-10-22 against master `34af3ccc6`**

Repro:

    function id<T>(x: T): T { x }
    function run<U>(f: (x: U) => U, u: U): U { f(u) }
    function take(a) {
      print(run(a, 2) + run(a, "ab").length)
    }
    take(id)
    // vl check: argument 1: expected (string) => string, got (i32) => i32

Want:

    4

#### Mechanism

Not traced. The hole parameter `a` takes the function type of its first use as an argument of
`run`, `(i32) => i32`, and the second use at `string` is then checked against it, where direct
calls of `a` at two types are accepted.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the second call `run(a, "ab")` | runs, `2` | **yes** |
| `run` replaced by direct calls `a(2)`, `a("ab")` | runs, `4` | **yes** |
| the order: the `string` call first | the mirrored check reject, `a` typed `(string) => string` | no |
