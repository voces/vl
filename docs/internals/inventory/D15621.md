### D15621 — a hole list parameter handed whole to a callee that calls its element at two types is taken as a value with no signature

**loud emit reject · clause 2 · `vl check` rc 0, then `emitProgram: a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type` · the callee called with the literal directly runs since [D15566](D15566.md) · found closing D15612 · filed 2026-11-09 against master `deeca2a1`**

Repro:

    function id(v) { return v }
    function mid(fs, x) { print(fs[0](x)) }
    function call0(fs, x) { mid(fs, x) }
    function run(g) {
      call0([g], 5)
      call0([g], "s")
    }
    run(id)

Want:

    5
    s

#### Mechanism

Not traced. `call0`'s `fs` is a list parameter read whole as an argument; the mint facts note
a forward of a bare parameter read only where its own set is a function set, and a list's is
held, so no forward from `call0`'s `fs` to `mid`'s is noted and `mid`'s set never reaches
`run`'s hole.

| the second call at `6` | runs, `5` `6` | **yes** |
