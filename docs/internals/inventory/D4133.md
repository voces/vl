### D4133 — a binding initialised from a union binding narrowed to a record takes the narrowed record type, and keeps it after a write that ends the narrowing

**parked pending an owner ruling (2026-11-01) · check-clean silently wrong · found grading the #3568 position matrix · filed 2026-10-11 against master `efd3c3f15`**

Repro:

    type A = { x: i32 }
    type B = { x: 1 | 2 }
    function f(base: A) {
      const a: A | B = base
      if a is B {
        const c = a
        base.x = 7
        const y: 1 | 2 = c.x
        print(y)
      }
    }
    f({ x: 1 })
    // PRINTS 7

#### Mechanism

`a is B` narrows `a` to `B` because the object's fields fit `B` now, and a write that may reach
the object ends that narrowing. `const c = a` declares `c` at `a`'s narrowed type `B`: `c` is
an ordinary binding of type `B`, so nothing ends it, and `c.x` reads as `1 | 2` after
`base.x = 7` stored `7`. The fit was a fact about the object's current state; delivering it
into a declaration turns it into a type the object no longer has.

#### Ablation

| ingredient changed | outcome on master | needed? |
| --- | --- | --- |
| the write removed | prints 1 | **yes** |
| `const c: B = a`, annotated | prints 7 | no |
| the read `a.x` instead of `c.x` | check reject (the narrowing ends) | **yes** (the copy) |

#### Grading list

`a` passed to a `B` parameter inside the arm, and stored into a `B` field or a `B[]`, each
followed by a write through `base` and a read through the copy.

#### Parked

Parked pending an owner ruling (2026-11-01): binding the copy at the declared type refuses a correct copy read with no later write; the same question as D4084. Two options:

1. **Refuse, consistently with ruling (c) for lists (D4928).** A record narrowed by `is B` from a
   type that stores a field wider than `B` is read as `B` but never delivered as one. Every escape
   position refuses and names the copy `{ x: a.x }`. An un-annotated copy binds at the declared
   type, and `as B` from such a union is refused. This closes D4084, D4133 and D4134. Across 17,493
   tests and corpus files, the delivery rule moved one file: D14752's
   `tests/cases/unions/layout-family-literal-set-beside-string.vl`, a correct program that would
   need the copy.
2. **Keep correct no-later-write programs.** The three rows stay open until a write-aware rule
   exists.
