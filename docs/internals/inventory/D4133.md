### D4133 — a binding initialised from a union binding narrowed to a record takes the narrowed record type, and keeps it after a write that ends the narrowing

**closed 2026-11-01 by lane step7 under the owner ruling (option (a)) · now a loud check reject (`cannot assign i32 to 'y' of type 1 | 2`): an un-annotated copy of a record narrowed by its fields binds at the declared type · was check-clean silently wrong · found grading the #3568 position matrix · filed 2026-10-11 against master `efd3c3f15` · pins: `tests/cases/soundness/record-is-narrowing-copy-binds-declared-reject.vl`, `record-is-narrowing-copy-runs.vl` · the no-write refinement is D14827**

Repro:

    type A = { x: i32 }
    type B = { x: 1 | 2 }
    function f(base: A) {
      const a: A | B = base
      if a is B {
        const c = a
        base.x = 7
        const y: 1 | 2 = c.x
        print(y)
      }
    }
    f({ x: 1 })
    // PRINTS 7

#### Mechanism

`a is B` narrows `a` to `B` because the object's fields fit `B` now, and a write that may reach
the object ends that narrowing. `const c = a` declares `c` at `a`'s narrowed type `B`: `c` is
an ordinary binding of type `B`, so nothing ends it, and `c.x` reads as `1 | 2` after
`base.x = 7` stored `7`. The fit was a fact about the object's current state; delivering it
into a declaration turns it into a type the object no longer has.

#### Ablation

| ingredient changed | outcome on master | needed? |
| --- | --- | --- |
| the write removed | prints 1 | **yes** |
| `const c: B = a`, annotated | prints 7 | no |
| the read `a.x` instead of `c.x` | check reject (the narrowing ends) | **yes** (the copy) |

#### Grading list

`a` passed to a `B` parameter inside the arm, and stored into a `B` field or a `B[]`, each
followed by a write through `base` and a read through the copy.

#### Close

Owner ruling, 2026-11-01: records follow list ruling (c) (D4928). A record narrowed by `is` or
`as?` to a record its declared type stores wider is read at the narrowed type but not delivered
as it, and the error names the copy. An un-annotated copy binds at the declared type, and `as B`
from a union with a wider record member is refused. A delivery no later write can reach needs no
copy in principle; that refinement is D14827.
