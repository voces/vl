    function inc0(a) { return a + 1 }

Not traced. Measured 2026-11-03: without the re-pointing write, `let v = xs; print(v[0](3))` runs, so the refusal needs `v = xs`. A `let` bound twice is outside the list alias rule (`cwSlotAliasOf` requires a binding bound once), which is the first place to look.
