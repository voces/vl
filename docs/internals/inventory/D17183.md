#### Mechanism

`a ?? b ?? d` is lowered re-associated, `a ?? (b ?? d)` (`coalChainMint`). Over a literal union's
`K | null` the chain is no box, so the minted inner link `boxK(mkK(n)).v ?? "a"` carries no type of
its own and reps as its chain's atom. Where that inner link's left operand is a field read off a
call, the code written for the re-associated link reads a local that no declaration in the
function opened, and the module does not validate. The same read bound to a `const` first, or the
two-link spelling, declares it.
