#### Mechanism

Closed with D3024: the arm matcher compared field names only, so `{ f: v0 }` (an `i32 | null`
field) was built as the arm `{ f: boolean }` of `{ f: boolean } | i32`. Before that close it was
not localised past the ablation. The greedy line minimiser keeps every line above: the
`{ h: { g: r0 } }` literal's inner record is resolved against a union arm row the other
declarations mint, and matches none. Alone, `const n = { h: { g: r0 } }` runs.
