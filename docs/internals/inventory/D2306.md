#### Mechanism

`lintRegroupWalkPhase` (`compiler/lint.vl`) reorders the findings the single structural walk
appended from node-major into rule-rank order, so a same-position tie reads the old rule-major
sequence. It permuted `lintCodes`, `lintMsgs`, `lintSevs`, `lintLines` and `lintCols` — and not
`lintEnds`, the column added when lint findings grew real spans. Whenever two walk rules fired
in the opposite order to their ranks, the end columns stayed in walk order and each finding
underlined a width measured on a different token. The regroup now carries `lintEnds` too.
