### D16878 — a set of functions with different results handed to an un-annotated parameter inside a record field is called at one signature and traps

**closed 2026-11-16 by lane AE · now a loud emit reject; `vl check` passes it (contract breach, [D16881](D16881.md)) · the refusal is [D16747](D16747.md)'s (`this call runs a function value that may hold any of a set of functions returning different types, …`) · was loads then traps, clause 1 · the sets a handed value holds are now noted through record fields as well as lists (`elabHeldSetsInto`, check_elab_cap.vl), so D16747's guard sees them · fixture `tests/cases/closures/error-set-in-record-handed-to-hole-param-two-orders.vl` · found by lane AE grading D16859 · filed 2026-11-16 against master `2a0b71c1a`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function id2(x) { return x }
    function app(o) { return o.l[0](3) }
    const ll = id2([half, inc0])
    print(app({ l: [inc0, half] }))
    print(app({ l: [half, inc0] }))
    // vl check: rc 0.  vl run on master: prints 4, then wasm trap: indirect call type mismatch

Want:

    4
    1.5

#### Mechanism

`id2` handed the list leaves the set `{inc0, half}` untagged, so the lists hold closures. `app`
gets one instance, keyed at `(i32) => i32`, and calls `o.l[0]` by `return_call_indirect` at that
signature; `half`'s closure holds no `i32` entry. D16747's guard refuses such a call when the set
was handed to the parameter, but `fnParamHandNote` noted only a set held as the value or a list's
elements, not one in a record's field.

#### Ablation

| ingredient changed | outcome on master | needed? |
| --- | --- | --- |
| no `id2` (`const ll = [half, inc0]`) | runs, `4 1.5` (a tagged set) | **yes**: the set left closures |
| the same order twice | runs, `4 4` | **yes**: `half` at the called slot |
| `app` reads `l[1]` | traps on the first call | no |
| `app` over a bare list parameter | a loud emit reject | **yes**: the record field |
| `id2(…)` as a statement, no binding | traps | no |
| a nested list (`id2([[half], [inc0, half]])`) | traps | no |

The program the design permits still does not run: dispatching each member at its own signature
is [D16747](D16747.md)'s open clause 2.
