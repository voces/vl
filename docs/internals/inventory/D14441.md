### D14441 — an un-annotated record literal binding of a union arm's shape is adopted into the arm's variant row by the emitter, not the checker

**runs today and must keep running · 1 fixture (`unions/unann-local-reassign-arm-literal`) · filed 2026-10-26 against master `641c18ca1`**

Repro:

    type T = { kind: "t", n: i32 | null } | { kind: "u" }
    function tagged() {
      let v = { kind: "t", n: 4 }
      print(v.n)
    }
    tagged()

Want:

    4

#### Mechanism

The checker types `v` as the literal's own record `{kind: "t", n: i32}`; master's emitter
adopts the literal into `T`'s first arm (`objLitVariantIdxNoStructRow`, D4613) and the binding
and its reads follow that variant row. Step 7 slice 3 reads the binding's rep from its type,
which has no row of its own, so `v.n` finds no struct. The adoption is an emitter-side type
source: the record the literal is stored as belongs where the checker types the literal, and
the binding reads it from there.
