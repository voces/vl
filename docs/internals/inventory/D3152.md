### D3152 — the compile cost of a closure that narrows a captured union grows quadratically with the number of narrowings

**runs today and must keep running · open · compile cost, not output · found by the #3281 review (`rv3281-5793/sc`) · the same on master `fc4b2159f` · filed 2026-09-29 against master `fc4b2159f`**

Repro:

    type C = { r: i32 }
    type S = { s: i32 }
    function mk(p: C | S) {
      const f = () => {
        if p is C { print(p.r + 0) } else { print(p.s) }
        if p is C { print(p.r + 1) } else { print(p.s) }
        if p is C { print(p.r + 2) } else { print(p.s) }
        if p is C { print(p.r + 3) } else { print(p.s) }
      }
      f()
    }
    mk({ r: 1 })
    // vl check: rc 0.  vl run: prints 1, 2, 3 and 4 — the row is the cost of building it

Want:

    1
    2
    3
    4

#### Mechanism

Not localised. Guest fuel of one `vl build` (`VL_FUEL=1`), N the number of `if p is C` guards,
on master `fc4b2159f`:

| shape | N = 100 | N = 400 | ratio |
| --- | --- | --- | --- |
| module walk, no closure (`s1`) | 72,996,776 | 283,976,146 | 3.9× |
| a function narrowing a global (`s3`) | 46,310,441 | 180,408,327 | 3.9× |
| a closure narrowing a captured parameter (`s2`, this repro) | 439,166,799 | 6,188,306,210 | 14.1× |
| a closure inside a walk narrowing the walk variable (`s4`) | 2,894,996,622 | 38,194,597,276 | 13.2× |

The two closure shapes grow as N², the two without a closure linearly. A captured union is
narrowed through the recorded declaration-site narrowing (`capNarrowRecord` / `capNarrowSeed`),
and each guard in the closure body re-asks the capture's union through a lookup that walks
what the earlier guards pushed. That is the suspect, not a measurement.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| no closure, the guards in the frame | linear | **yes** (the closure) |
| a global narrowed in a function | linear | **yes** (the capture) |
| the capture a walk variable, not a parameter | quadratic | no |
