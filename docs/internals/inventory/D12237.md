### D12237 — an exported generic read where the flow analysis cannot prove the read inert still passes the checker and refuses at emit

**loud emit reject · `vl check` rc 0 · `emitProgram: exported function `id` is generic over `T` and nothing in the program calls it` · clause 2 · DESIGN: the same export with no read is refused at check (D3817), and so are the reads [D12211](D12211.md) moved to the checker · emit_mono.vl, the exported-generic floor · found closing D12211 · filed 2026-10-24 against master `84b98d149`**

Repro:

    export function id<T>(x: T): T { x }
    const k = () => id
    print(1)

#### Mechanism

D12211's close asks `vrOuterReadsInert` (value_reach.vl) whether every read of the export
outside its body reaches nothing. Value reach is conservative where it cannot follow the value:
a lambda's result, a `Map` element, a record field written after construction, and a closure
reading an alias. Each such read counts as one that may reach a call, so the checker passes the
export, and the monomorphizer, which sees that no call instances it, refuses at the floor. The
close is to let the checker see what the monomorphizer sees for these four positions, or to
make value reach follow them; value reach is shared with mono and fn_split, so its answers
there must not change.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the lambda (`const k = id`) | check reject, D3817 | **yes** |
| a call of the lambda's result (`print(k()(9))`) | runs, prints `9` | **yes** |
| `export` | runs | **yes** |
