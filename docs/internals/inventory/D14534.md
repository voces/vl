#### Mechanism

`twoListValueTy` (`emit_fn_ret_kinds.vl`) decides whether a receiver still holds a two-list
union, which the D2766 refusal and `monoTwoListArgFail` read. It asked twice: whether the
emit narrowing stack held a variant for the name (`narrowVariantFor`), and whether the
checker's read type (`nodeTyAt`) is one `TyArray`. The checker answers in both arms of the
`is`, so the stack test was a second producer of the same fact and is deleted. A probe with
only that test removed matched master on all 967 `??` fixtures, while an instrumented build
showed the test reached by 130 of them.
