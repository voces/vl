#### Mechanism

Legacy re-associates `(a ?? b) ?? d` to `a ?? (b ?? d)` in `coalChainMint`. It types the inner
link `b ?? d` only when the chain is struct-bearing, holds numbers apart, or has the default's own
type. In a hole instance the chain's type is open, so the inner link has no type of its own, and
`nodeTyAt`, `nodeTyIxOf` and `coalResultTyOf` all answer `_`. Legacy writes the link at the kind
its consumer asks: here the hole map read's null-test `if` (`coalHoleMapIfOf`) at a
`boolean | i32` union box, the link's map read built at the map's value kind and boxed as that
member. The IR asks the link's own rep and misses. Typing the link at mint time would mean running
the checker's `??` rule (`checkCoalesceBinNode`, which records lints and hole notes) at emit time.
