### D16937 — [CLOSED 2026-11-19] a record literal holding a lambda, written into a list of records of un-annotated functions with different results, is refused at emit

**closed 2026-11-19 · runs, prints `9` · fixed in wasmEmit.vl: `emitStructFieldValueUnder` refuses a lambda in a field that takes no closure only where the tag decision made it no leaf; a lambda leaf of the tagged set is stored as its id, as `emitExpr` emits it · the record bound before the push is [D16998](D16998.md), an annotated lambda [D16999](D16999.md) · with [D17000](D17000.md), so a call before the push is typed with the lambda; matrix `hole-lambda-in-record-of-tagged-set` (its literal-store and call-before-push cells run in both faces) · pin `closures/hole-lambda-record-pushed-into-tagged-set-list.vl` · was loud emit reject, clause 2 · found by lane AE grading D16858's neighbours · filed 2026-11-17 against master `a68eff941`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const xs = [{ f: inc0 }, { f: half }]
    xs.push({ f: (x) => x * 3 })
    print(xs[2].f(3))

Want:

    9

#### Mechanism

The list's set of named functions has two results, so the tag decision builds its records with an
id in `f`. A lambda literal written in place into such a record has no id, and the record literal's
emit finds the slot a non-closure one. A lambda bound to a name first is a member the decision tags,
and runs. The decision stamps the in-place lambda as a leaf too; the emitter's field guard refused
it before reading that stamp.
