### D2556 — a call that nulls a module binding does not end a guard on it inside a top-level function narrowed at module scope

**closed 2026-09-25 — the filed repro RUNS and prints `5` · was check-clean silently wrong (printed `null`), clause 1 · pre-existing, identical on master `680b67486` · found by #3169's review · filed 2026-09-25**

Repro:

    let vv: i32 | null = null
    vv = 1
    function clear() { vv = null }
    function f() {
      if vv != null {
        clear()
        print(vv ?? 5)
      }
    }
    f()
    // PRINTS null

#### Mechanism

`crNameIsGlobal` decides whether a narrowed name is a module binding by walking its scope layers
down to the first one with no narrowing bank row. The module-level `vv = 1` banks its row at
depth 0, the module scope itself, so the walk ran off the bottom and answered "not global". The
D2401 writer analysis then looked for writers only inside `f`, found none, and kept the guard
through `clear()`. The emitter lowered `vv ?? 5` as the narrowed read and printed the box. A
layer below the first function's base is now a module binding whatever its bank row, and the
declared-type layer `crDeclareWidened` binds (D2529) is looked through like a narrowing one.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the module-level `vv = 1` (initialiser `= 1`) | prints `5` | **yes** — an assignment row at depth 0 |
| `f` declared before `vv = 1` | prints `5` | **yes** |
| the binding a local and the writer a closure | prints `5` | **yes** — a module binding |
| `clear` and `f` in another module | same, now prints `5` | no |

#### Grading list

* The cross-module spelling: `a.vl` exporting `vv`, `clear` and `f`; `main.vl` calling `f()`.
