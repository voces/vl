### D3220 — a hole callee called with more arguments than the pinned function takes is invalid wasm

**check-clean invalid wasm · clause 1 · found by the #3287 split-head review (`rv3287s-4099`, `p3/a1`) · the same on master `94670f728` · filed 2026-09-29 against master `94670f728`**

Repro:

    function H(h) {
      return h(1, 2)
    }
    print(H((x: i32) => x))
    // vl check: rc 0.  vl run: invalid module inside `H`: type mismatch: expected structref,
    // found i32

Want:

    check reject: the direct call `((x: i32) => x)(1, 2)` is refused for its arity

#### Mechanism

Not localised. A call of a hole records no arity, so the pin is never asked whether the pinned
function takes two arguments; the instance then calls it with two.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `h(1)` | prints `1` | **yes** (the extra argument) |
| `((x: i32) => x)(1, 2)`, no hole | check reject | **yes** (the hole) |
