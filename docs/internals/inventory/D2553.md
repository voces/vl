Repro:

    function id<U>(x: U): U {
      return x
    }
    function g<T>(r: T): T {
      const f = () => id(r)
      return f()
    }
    print(g(7))
    print(g("q"))

#### Mechanism

`monomorphize` walks every pre-pass lifted slot, the template lambda included, and
instantiates `id(r)` there with `r: T`, pinning the default. The per-instance clones share the
template's body, so they share that `Call` node and its in-place callee rename: every clone
called `id` at `i32`. `monoCloneLambdaSubst` now gives each clone its own copy of the generic
calls in its body (`monoCloneGenericCalls`, as an instance body already had), and
`monoInstantiate` walks each clone's body once the instance is registered, so the capture
resolves through the instance's frame.

One cell of D2551's grid stays loud: `app(() => app(() => r))` at a function-typed `T`
(`unsupported argument type for f in a call to app`); the non-generic twin runs.
