### D15201 — a function written through an alias of a list element or of a field of one builds an invalid module

**check-clean invalid wasm · `the emitted module failed to validate` at the read · clause 1 · open · found grading D15199's controls · present on master `f6b19ca4` · filed 2026-11-03 against master `f6b19ca4`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const rs = [{ fs: [inc0] }]
    const a = rs[0].fs
    a[0] = half
    print(rs[0].fs[0](3))

Want:

    1.5

#### Mechanism

Not traced. The alias of a binding's own field (`a = r.fs`) is widened by `elabFnFieldListTy` and runs; an alias rooted at a list element is not, so the write's function reaches an element typed at the literal's set. The un-annotated read is enough, so this is not D15199's delivery.

| an agreeing write (`dbl`), read at `(x: i32) => i32` | invalid module | no |
| no write | runs | **yes** |
