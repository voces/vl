### D2040 — an if-EXPRESSION in a value slot whose arm ends in a nested else-less `if` types `T | null` but refuses at emit

**closed 2026-09-27 — the witness prints `5` · was a loud emit reject, `vl check` rc 0, then `emitProgram: union if-expression arm ends in a statement, which yields no value` (or the non-union `if-expression arm ends in …` twin), clause 2 · filed 2026-09-22 against master `ee4c28b60` with the D1995 else-less-arm ruling · closed with D2822: an arm ending in an if-expression lowers that `if` at the outer join's own rep, nullable frame included, and a sunk union return's else-less link returns the function's null · fixture `tests/cases/conditionals/if-arm-nested-join.vl`**

Repro:

    function f(c: boolean, d: boolean) {
      const x = if c { if d { if d { 5 } } } else { 6 }
      x
    }
    print(f(true, true))
    // vl check: rc 0.  vl run: emit error, union if-expression arm ends in a statement

#### Mechanism

The owner ruling on D1995 makes an else-less `if` ending an arm a `T | null` value, and the
checker now types the arm that way in every position (`checkBlockNode`). The TAIL position
lowers it (`emitIfTail` through `armTailIsValue`, falling through to the function's `null`
padding), but the value-slot if-expression lowering has no arm that turns an else-less `if`
into `then-value else null`, so it declines the arm as a statement. Depth 1 with an `i32`,
`string` or union value already runs; a struct value, and any depth from 2, refuse.

#### Grading list

The 18 binding-position cells of the else-less-arm grid (depth 1–3 × `i32` / `string` / struct /
`i32 | string`, inferred and `T | null`-annotated), for example
`const x: P | null = if c { if d { { a: 5 } } } else { { a: 6 } }`.

On the close all 24 cells (depth 1–3 × the four values × inferred/annotated) print the right
value on each of the three paths, and `if-expr-nested-elseless-{struct,i32,string}.matrix.vl`
run 62 of 62 cells each, both faces.
