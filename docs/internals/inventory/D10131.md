### D10131 — a generic's `T[] | i32` parameter narrowed by `is i32` and joined with a literal infers its return as the box

**check-clean invalid wasm · `vl check` rc 0 · `type mismatch: expected i32, found (ref $4)` in the module's top-level code (printed directly, `emitProgram: print of a union value whose arms the tag dispatch cannot classify`) · clause 1 · found closing [D10031](D10031.md) · present on master `3931f9468` · filed 2026-10-22 against master `3931f9468`**

Repro:

    function len<T>(t: T[] | i32) {
      if t is i32 { t } else { 5 }
    }
    const r: i32 = len([1, 2])
    print(r)
    // vl check: rc 0.  vl run: the emitted module failed to validate inside the module's top-level code: type mismatch: expected i32, found (ref $4); $4 is `union box`

Want:

    5

#### Mechanism

Not traced. Both arms are `i32` (the narrowed `t` and the literal `5`), and the checker types the
call `i32`, since the binding `const r: i32` accepts it. The instance's inferred return is
nonetheless the union box, so the call site stores a box into an `i32` local. Reading
`t.length` in the else arm instead of a literal returns `i32` and runs, so the inference keeps
the parameter's union rep for the narrowed `t` arm when no other arm forces `i32`.

#### Grading list

The direct `print(len([1, 2]))` spelling in the last row; an early `if t is i32 { return t }`
before a literal tail; the function-parameter form `f: () => T[] | i32` with the same arms.
