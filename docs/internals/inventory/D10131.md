#### Mechanism

At each pin, `monoInferRetSetUnionName` (check_emit_queries.vl) re-checks the body's statements
and then re-checks every return node alone to join the return set. Alone, a return of the
narrowed `t` read the narrowing in force at the END of the body, which is the complement `T[]`,
so the join was `i32[] | i32` and the instance returned the box into the caller's `i32`. The
re-check now records each return's type while the statements run (`retWatchArm` /
`retWatchNote`, check_core_state.vl, noted in `checkNode`), and the join takes that reading.
A re-check that raised a diagnostic, which is how a test the pin makes dead shows there
(`v is {foo: string}` at a `{bar: i32}` pin), keeps the bare readings, since a dead arm's
narrowed return is no value the instance can return (`inference/hole-is-guard-return-join.vl`).
