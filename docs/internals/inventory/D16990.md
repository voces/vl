#### Mechanism

`callArmWritePinOpen` (`check_calls.vl`) pins the caller's empty map at the type the generic's `is`
arm writes it at, in place. The caller's later write meets that pinned type at an ordinary mismatch
site, which knows only the pinned type, not which arm fixed it. Naming the arm needs the pin's origin
(the `is` node) carried to the mismatch sites a pinned hole can reach: an index store, a `push`, an
assignment.
