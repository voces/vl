### D2052 — a value `if` whose arm has a statement before its value refuses in every position but a binding initializer, and the refusal names a local the arm does not declare

**loud emit reject · `vl check` rc 0, clause 2 · 180 of 1,080 cells of the D2050 jump grid (ten delivery positions) · filed 2026-09-22 against master `a6af81bbd`**

Repro:

    function id(x: i32): i32 { x }
    function f(n: i32): i32 {
      return id(if n == 1 {
        print(9)
        5
      } else { 7 })
    }
    print(f(1))
    // vl check: rc 0.  vl run: emit error — an if-expression arm that declares a local is
    // supported only as a binding initializer inside a function

#### Mechanism

An arm's prelude (the statements before its value) is lowered by `emitIfArmOpen` only when the
`if` initialises a binding; anywhere else the emitter refuses. The sentence says the arm
"declares a local", but a prelude with no declaration at all (`print(9)`, or `if c { continue }`)
takes the same refusal, so the message is broader than what it names.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `return id(if …)` → `const v = if …` then `return id(v)` | runs, prints `9` then `5` | **yes** (the position) |
| the `print(9)` prelude removed | runs | **yes** (a prelude) |
| `id(…)` → `0 + (…)`, `[…]`, `{ x: … }`, `m ?? (…)`, `c && (…)`, `acc = acc + (…)` | still refuses | no |

#### Grading list

Every refusing column of the D2050 grid: call argument, binary operand, array element, struct
field, `??` right side (plain, list read, optional chain), `&&`/`||` right side, and assignment
right side, each with a `break`/`continue`/`return` in the arm. Once they build, a jump inside
them is counted by the frame openers themselves (D2050), so each must print the jump's answer.
