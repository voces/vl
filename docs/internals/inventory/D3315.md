#### Mechanism

The then arm's alias write retired the `a.v` overlay in place. The else arm's `a.v = null` then
found no live narrowing and, storing null, no null strip either, so it pushed no ledger row. The
join saw the else path as untouched and started it at the entry type, `i32`, the type the
then arm's kill row recorded. A path write now always leaves a row.
