### D5342 — an un-annotated global record literal whose nested element matches a declared record builds a non-constant global initialiser

    type M = { v: i32, kids: { v: i32 }[] }
    const w = { v: 1, kids: [{ v: 2, kids: [] }] }

#### Mechanism

The outer literal has `M`'s field names, so it is built at `M`, whose element type is
`{ v: i32 }`: the inner element's `kids` is a field that shape DROPS. `objLitDropsField`
(`emit_base.vl`) then sent the literal down the D1696 path, which stashes every dropped
initialiser in a local so its side effects still run, and a global's initialiser is a constant
expression, where `local.set` is invalid. Fixed there: a dropped field whose initialiser is
constant (`isConstInit`) cannot be observed or trap, so it no longer forces the stash, and the
literal stays a constant expression. Graded by `record-lit-drops-const-field.matrix.vl` (30 cells
SILENT before, in both faces, 64 of 64 run after) and `tests/cases/structs/record-lit-drops-const-field.vl`.
