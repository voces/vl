### D5342 — an un-annotated global record literal whose nested element matches a declared record builds a non-constant global initialiser

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · OPEN · found closing D5282 · filed 2026-10-17 against master `cd07cb6a8`**

Repro:

    type M = { v: i32, kids: { v: i32 }[] }
    const w = { v: 1, kids: [{ v: 2, kids: [] }] }
    print(w.v)
    // vl check: rc 0.  vl run: failed to parse WebAssembly module: constant expression required: non-constant operator: visit_local_set

Want:

    1

#### Mechanism

Not yet derived. The inner element `{ v: 2, kids: [] }` has the same field names as the
declared `M`, and the global's initialiser is emitted with a `local.set` in it, which a
constant expression may not hold. The same literal inside a function refuses loudly instead
(`a ref list's element row does not resolve`).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the declaration `type M` | runs, prints `1` | **yes** |
| the inference, `const w: { v: i32, kids: M[] }` with a matching literal | runs | **yes** |
| the outer field `v` | runs | **yes** |
| module scope (the binding inside a function) | loud emit reject, `a ref list's element row does not resolve` | **yes** for the silent face |
