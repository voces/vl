### D15054 — a record compare whose `(string | null)[]` field holds a null traps

**closed · runs, prints `true` · was loads then traps, clause 1 · the string-list compare core tests every element pair for null, whatever position reaches it (a record's field, a union arm's, a nested list's), so no caller has to ask, and a list of such records is admitted at check · matrices `record-nullable-string-list-field-eq`, `arm-nullable-string-list-field-eq`, `record-list-nullable-string-list-field-eq` · pre-existing on master `bb40408f5` · filed 2026-11-02 against master `bb40408f5`, closed 2026-11-03**

Repro:

    type R = { xs: (string | null)[] }
    const r: R = { xs: ["x", null] }
    print(r == r)
    // was: vl check rc 0, vl run: wasm trap: null reference

Want:

    true

#### Mechanism

The record's field-wise compare runs the string-list core over the field, and that core reads each
element with `ref.as_non_null`. With no null in the field (`["x", "y"]`) the compare runs and prints
`true`. The top-level list compare now has a null-guarded mode (`emitListEqSCore`'s `nulElems`),
and the field compare does not ask for it.
