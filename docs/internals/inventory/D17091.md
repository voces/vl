### D17091 — a staging `??` boxed into a union argument writes its box's tag before the leads it stages

**closed 2026-11-24 · runs, prints `abool` `bbool` · was check-clean invalid wasm · clause 1 · `vl check` rc 0 · the IR's claim, not legacy: a claimless compiler builds and runs it · fixed in ir_lower.vl: along an arm that stages its leads (`coalArmStagesLeads`), `stashIfBoxHead` no longer writes the out's box head ahead of the `??`, and `coalBox` writes it after `stageLead`, as `valuedIfOpen` does for a valued `if` · pins: `tests/cases/null/coalesce-boxed-argument-after-a-lead-{concat,interpolation,argument,controls}.vl` · found by lane IR-N11 when its `valBox` staging candidate made `scripts/silent-sweep/distilled/ir-shadow.vl` build invalid wasm · filed 2026-11-24 against master `86dd79148`, pre-existing**

Repro:

    function show(v: i32 | boolean): string {
      if v is boolean { return "bool" }
      return "int"
    }
    function g(f: string, rc: boolean | null): string {
      return f + show(rc ?? false)
    }
    print(g("a", true))
    print(g("b", null))
    // vl check: no errors. vl run: invalid module, "type mismatch: expected i32, found (ref $0)" in `g`.

Want:

    abool
    bbool

#### Mechanism

A `??` along a staging arm (`litUnion`, `nulBool`, `nulRef`, `nulStr`) writes an earlier operand's
pending temps below its `if` (`stageLead` in ir_lower's `coalBox`). Its out here is boxed into the
union parameter, and `stashIfBoxHead` wrote that box's head (the tag) before the `??` opened, so
the stack held `[tag, f, if]` where legacy writes `[f, tag, if]`. The tag reached the concat's
first operand and `f` the box's tag field. A valued `if` already wrote the head after its staged
leads (`valuedIfOpen`'s `joinBoxHead(t, true)`). The verifier flags it: the armed shadow reports
`fail a claimable function did not match` for `g` under modes 1 and 6. A production build emits
claims without the shadow, so the escape was a shape absent from every armed population: no corpus
cell, tests/cases program or capability probe had it.

#### Ablation

| ingredient | outcome | needed? |
| --- | --- | --- |
| the `??` not inside a concat (`return show(rc ?? false)`) | runs | **yes**: a lead |
| `show(v: boolean)`, so the `??` is not boxed | runs | **yes** |
| `k + show(..)` over i32 for the string `+` | runs | **yes**: a staged lead |
| `const s = show(..)`, then `f + s` | runs | **yes** |
| `pair(f, rc ?? false)` with `pair(f: string, v: i32 \| boolean)` | invalid | no: any earlier operand |
| the arm `nulBoolJoin` (`rc ?? 3`) | runs | **yes**: a staging arm whose box has no head |
| a claimless compiler | runs | **yes**: the IR's lowering |

#### Grading list

Arms `litUnion`, `nulBool`, `nulRef` and `nulStr` in four contexts each, all invalid on base and
all running on the fix, with output identical to a claimless compiler: `f + show(rc ?? d)`,
`"\{f}\{show(rc ?? d)}"`, `two(f, show(rc ?? d))` and `pair(f, rc ?? d)`. The `nulBoolJoin` arm
and the unboxed `f + plain(rc ?? d)` ran before and still run.
