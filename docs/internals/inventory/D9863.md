### D9863 — a `.map` over an inline list literal of an un-annotated function calls an unknown function

**loud emit reject · `vl check` rc 0 · `call to unknown function` · clause 2 · found closing [D9766](D9766.md) · filed 2026-10-22 against master `ba2918226`**

Repro:

    function inc(a) { return a + 1 }
    print([inc].map((r) => r(5))[0])
    // vl check rc 0.  vl run: emit error: emitProgram: call to unknown function

Want:

    6

#### Mechanism

Not traced. The same list bound first (`const v = [inc]`, `v.map(...)`) runs, with a lambda or a
named callback. The pin the flow gives the receiver is read from a binding's annotation
(`monoPinnedListAnnTy`), and an unbound literal has none to read. A declared callback
(`ap(r: (a: i32) => i32)`) refuses with `cannot take the generic function `inc` as a value`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the un-annotated parameter of `inc` (`inc(a: i32): i32`) | runs, `6` | **yes** |
| the inline literal, for `const v = [inc]` | runs, `6` | **yes** |

#### Grading list

A lambda, a declared and an un-annotated named callback; `.filter`.
