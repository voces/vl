### D3991 — `filled` with a `null` fill at `string | null` traps on a null reference

**closed 2026-10-10 by lane CK · runs · was loads then traps · found closing D3990 · filed 2026-10-10 against master `e5128703a` · pins: `tests/cases/arrays/filled-null-typed-by-destination.vl`, `tests/cases/arrays/filled-explicit-nullable-string-fill.vl`**

Repro:

    import { filled } from "std:array"
    const xs = filled<string | null>(3, null)
    print(xs.length)
    // vl check: rc 0.  vl run: wasm trap: null reference

Want:

    3

#### Mechanism

`(string | null)[]` shares the string list's backing, whose slot is nullable, but the
`__array_new__` lowering emitted the fill as a `string` and so as `ref.as_non_null`. The fill of
a string list is now seeded as a `(string | null)[]` element is (`pendingNulString`) whenever the
fill is a nullable string.
