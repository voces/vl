### D3366 — a `??` arm in an `else if` chain with a member literal builds invalid wasm at a literal-union pin

**check-clean invalid wasm · clause 1 · the same at the `<T>` spelling (`g0308`) and on master `6e6a5301b` · found by lane UG re-grading the D3303 generator (`rv3303-12883/gen`, `g0308`, `g0392`) · filed 2026-09-30**

Repro:

    type K = "a" | "b" | "c"
    function show<T>(x: T) { print(x) }
    function g(a, b, c: boolean) {
      show(if c { a ?? 5 } else if !c { b } else { "c" })
    }
    const u: K = "c"
    const w: K = "a"
    g(u, w, true)
    g(u, w, false)
    // vl check: rc 0.  vl run: invalid module inside `g`

Want:

    c
    a

#### Mechanism

Not localised past the ablation. The chain joins the `a ?? 5` arm (`K | i32` at the pin, a box)
with `b` and the member literal `"c"`, and the instance builds one arm as a string ref where the
join reads an `i32`. D3303's hole typing is not the cause: the `<T>` spelling is invalid the
same way.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `function g<T>(a: T, b: T, …)` | the same invalid wasm | no |
| `a` in place of `a ?? 5` | runs (D3303's elif cells) | **yes** (the `??`) |
