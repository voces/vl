### D3421 — a `??` over a gradual union holding a type parameter folds at a pin that makes it nullable

**closed · runs, prints `n`, `q` · was check-clean invalid wasm, clause 1 · closed by the column-G1 lane: `emit_rewrite` folded `s ?? d` to `s` in the shared body because the checker types the read at the template's gradual view (`string`); a read of a binding whose written type holds a type variable (`readOfOpenBinding`) is no longer folded there, and the lowering folds it only where the instance's own type excludes null · fixture `generics/coalesce-over-gradual-union-at-nullable-pin.vl` · pre-existing, the same on master `5e277ab52` · found by lane NW beside D3240 · filed 2026-09-30 against master `5e277ab52`**

Repro:

    function g<T>(x: T) {
      const s: T | string = x
      print(s ?? "n")
    }
    const v: string | null = null
    g(v)
    g("q")

Want:

    n
    q

#### Mechanism

Not localised past the ablation. The body checks `s ?? "n"` against the union's concrete member
`string` (`tpGradualView`), where the default is dead, and the shared body lowers the `??` as its
operand at every pin. At a `string | null` pin the union is `string | null` and the default is
live. The read of `s` is recorded as `string`, so its value read recovers the non-null ref
and the null pin traps on `ref.as_non_null`; it used to print `null` instead. The same fold reaches a type-parameter write joined with a literal write
(`if c { s = x } else { s = "k" }` into `s: string | null`), whose join is such a union.

| --- | --- | --- |

| `const t: string \| null = s` then `t ?? "m"` | check refuses `string \| null \| string` into `string \| null` | no (a second face, a false refusal) |
