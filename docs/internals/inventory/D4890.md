### D4890 — a call of a list element instances a written `let` of the same generic at the call's type

**closed · was loads then traps · found while closing D3975 · filed 2026-10-15 against master `5be21bb0a`**

Repro:

    function k<T>(x: T): T { return x }
    function main() {
      let f = k
      f = k
      print(f("s"))
      const fs = [k]
      print(fs[0](1))
    }
    main()

Want:

    s
    1

#### Mechanism

The write `f = k` records a deferred destination constraint for `f`. Type variables bind by
name, so the unnamed call `fs[0](1)` validated that constraint with its own binding `T = i32`,
and the pin stored `f` at `(i32) => i32` while `f("s")` called it at `string`: an indirect call
type mismatch at run time. `validateLetCstrs` now skips the row when the call cannot reach the
written value (`wrUnreachedBy`): the call sits in the binding's own function and is not through
it, and that function reads the binding only as a callee or a write target.
