### D17008 — a nested record re-pointed at a smaller function set in its list field is refused at emit

**loud emit reject · clause 2 · `emitProgram: object literal field count does not match struct` · the nested-record spelling of [D16920](D16920.md), whose list-of-lists spelling runs · found by lane STORE closing D16920 · filed 2026-11-19 against master `894554dda`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    let r = { a: { f: [inc0, dbl] } }
    r = { a: { f: [dbl] } }
    print(r.a.f[0](3))
    // vl check: rc 0.  vl run: emit error, "emitProgram: object literal field count does not match struct"

Want:

    6

#### Mechanism

Not traced. The re-point's inner record `{ f: [dbl] }` is not built at the binding's inner record:
D16920's close builds a written record at the held binding's rep only when one of its own fields
holds a list of lists (`ftRecListsAtRep`). A nested record's list field is one record deeper, and
`recFnFieldsWiden` compares a nested record field by `tySame`.

#### Ablation

| spelling | outcome |
| --- | --- |
| the witness | loud emit reject |
| one level, `let r = { f: [inc0, dbl] }`, `r = { f: [dbl] }` | runs, `6` |
| a list of lists, `let r = { f: [[inc0, dbl]] }`, `r = { f: [[dbl]] }` | runs, `6` (D16920) |
| the nested record's list of lists, `{ a: { f: [[inc0, dbl]] } }` → `{ a: { f: [[dbl]] } }` | the same refusal |
