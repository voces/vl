Repro:

    type J = { f: i32 | null }
    function mk2() { { f: 1 } }
    const dA: J = mk2()
    print(dA.f ?? 0)
    const k = 1
    const b = if k > 0 { { f: 4 } } else { mk2() }
    print(b.f)

Want:

    a check reject at `mk2()`, as `m.get("z") ?? mk2()` is refused

#### Mechanism

Not ablated past the table. `mk2` is kept at `J` by the annotated binding, so its calls are built
there. A `??` default is checked assignable to the left operand's type, which pends it
(`recPend`, check_assignable.vl), and `recKeptConflicts` refuses it at its own type. An `if` or
`match` join unifies its arms with no pending pair, so the call arm is never asked: the join is
typed `{f: i32}` and the arm hands over a `J`.
