### D10934 — a generic's returned record with a `(T | null)[]` field holding a bare `null` refuses the `null` at a literal-union pin

**loud emit reject · clause 2 · `vl check` rc 0 · present on master `8be0b10be` · found by lane D10880 closing D10881 · filed 2026-10-23 against master `8be0b10be`**

Repro:

    type K = "a" | "b"
    function f<T>(x: T): { g: (T | null)[] } { return { g: [x, null] } }
    const k: K = "a"
    print(f(k).g.length)
    // vl check: rc 0.  vl run: emitProgram: bare null needs a struct-typed context

#### Mechanism

D10881 with `T` a literal union of strings. The list literal's element classifiers read the
instance's `K | null`, which is neither a nullable string nor a nullable `i32`, so the `null`
falls through to the struct-typed arm. The list-result spelling of the same pin is D2525's
designed boundary and refuses as `a nullable-K list element has no rep`. The record field has
no such check, so it reaches the literal and refuses with this sentence instead.
