### D5281 — `==` over a list of records refuses when a field is a string, a list or a literal union

**closed · was loud check reject · clause 2 · eardstap EV-005 · filed 2026-10-17 against master `3f6a785db`**

Repro:

    type M = { n: string }
    const a: M[] = [{ n: "q" }]
    const b: M[] = [{ n: "q" }]
    print(a == b)

Want:

    true

#### Mechanism

The checker admitted `==` over `M[]` only when every field of `M` was a flat scalar
(`eqStructFieldFlatTy`), and the emitter's record-list compare core had no arm for a field
needing its own compare. Both now take a field whose own `==` has a core (string, list,
literal union, nested record), and the list compare calls the record's field-wise core per
element (`eqgStructElemNeeds`, `emit_eq_rows.vl`; `leqgNoteRep`, `emit_collect.vl`).

#### Ablation

| field type of `M` | outcome on master | needed? |
