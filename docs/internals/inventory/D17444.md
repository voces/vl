### D17444 — `.get` on a union of maps handed through a call is refused

**closed 2026-11-24 by S2 · runs, prints `5` · was loud emit reject, clause 2, legacy (the claimless build refused the same) · an instance's `.get` on a union of maps whose receiver has no pinned operand type (a call) is read at its walk type and spelled as the index read the arm dispatch lowers (`emit_mono.vl`, `elabWalkTy`) · owner S2 · found by the D17443 sweep · filed 2026-11-24 against master `ca404e1f`**

Repro:

    type MI = { [string]: i32 }
    type MS = { [string]: string }
    function mk(k: i32): MI | MS | i32 {
      if k == 0 { return 0 }
      const m: MI = Map()
      m["a"] = 5
      return m
    }
    function id<T>(x: T): T { return x }
    function g(a) {
      if a is i32 { return }
      print(id(a).get("a") ?? "none")
    }
    g(mk(1))
    // vl check: rc 0.  vl build: emitProgram: callee is not a function name

Want:

    5

#### Mechanism

An instance spells `m.get(k)` on a union of maps as the index read `m[k]`, which the per-arm
dispatch lowers (`emit_mono.vl`). The arms come from the receiver's pinned operand type
(`monoPinnedOperandTy`), which a call has none of, so `id(a).get(k)` stayed a call and fell to
`emitCall`'s floor. Now a receiver with no pin is read at its walk type (`elabWalkTy`), and its
index read lowers per arm as D17443 made a call receiver's do.

| `id(a)["a"]`, the index spelling | runs, `5` |
| `id(a).has("a")`, `id(a).length` | runs |

#### Grading list

- `.get` on a union-of-maps call receiver, generic and not, inside `??` and bound by a `const`.
