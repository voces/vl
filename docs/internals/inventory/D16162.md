### D16162 — a map whose value is a record nesting a record with an un-annotated function nothing calls is refused at emit as a generic value

**loud emit reject · check-clean, so clause 1 · `emitProgram: cannot take the generic function `inc0` as a value — a function value carries ONE signature` · found closing [D16161](D16161.md) · filed 2026-11-14 against master `817490bcd`**

Repro:

    function inc0(a) { return a + 1 }
    const m = Map()
    m["k"] = { r: { f: inc0 } }
    print(m.has("k"))

Want:

    true

#### Mechanism

`monoPinMapValues` (emit_mono.vl) pins a map whose value the checker left open at a function, or
at a list or record of them, to the default instance of each function stored there.
`monoPinStoredRecords` declines a stored record with a field that is itself a record literal, so
the nested `{ f: inc0 }` keeps its open function type. The value floor then refuses it.

#### Ablation

| spelling | outcome |
| --- | --- |
| the witness | loud emit reject |
| the record bare, `m["k"] = { f: inc0 }` | runs, `true` |
| the nested record in a bound list, `const xs = [{ r: { f: inc0 } }]; print(xs.length)` | runs, `1` |
| the nested record in a list as the map's value, `m["k"] = [{ r: { f: inc0 } }]` | loud emit reject, the same message (since D16161's close; `unsupported map value type` before) |
| a call through the field, `const v = m["k"]; if v != null { print(v.r.f(3)) }` | runs, `4` |
