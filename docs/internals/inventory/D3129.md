    type AB = "a" | "b"

#### Mechanism

`mapCbDeclRetPinTy` substitutes the declared return through the instance's binding, and the
substitution nests rather than flattens: `T | i32` at `T := i32 | null` is `i32 | null | i32`,
whose canon id matches no `unNames` row. `mapUnionResultRow` answered -1 and `mfResultSlotOf`
fell back to `unNames[0]`, the first union the module registers. With `type AB = "a" | "b"`
declared that row's reader unboxes a string, and the `i32 | null` box the callback built traps
on the cast. With no other union declared the first row happened to be `i32 | null` itself.
