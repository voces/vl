#### Mechanism

The refusal came from elaboration: `hinc`'s instance at `?hinc.0 = string` was enqueued from
`app`'s `string` instance by `elabSetCallRows`, which for a call through an open parameter takes
the functions the instance's own calls handed it (`elabParamArgTargets`). That found no targets
for the lambda literal argument (`elabCalleeTargets` of a literal is empty) and answered `[-1]`,
so the call fell back to every function the parameter was handed across all calls. A literal
argument now holds itself. A named hole function at the second call already ran, since its
targets resolve.
