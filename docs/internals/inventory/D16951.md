#### Mechanism

The shared read's boxing plan (`sharedFieldArmsBoxable`) admitted atom-stored arms, nullable lists
and, since D16949, records the read's union has an arm for. A non-null list arm was none of these,
so the plan declined and the read fell to the plain struct read. It now rides the box as its ref
under its kind's tag, as a `T[] | null` arm already did (`emitSharedFieldNulListBox`).
