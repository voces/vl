### D16951 — a field read across record arms whose shared field is a list in one arm and an atom in another has no struct receiver

**loud emit reject · `emitProgram: field access receiver is not a struct` · clause 2 · found grading [D16949](D16949.md) · filed 2026-11-17 against master `fdd8f589f`**

#### Mechanism

The shared read's boxing plan (`sharedFieldArmsBoxable`) admits atom-stored arms, nullable lists
and, since D16949, records the read's union has an arm for. A non-null list arm is none of these,
so the plan declines and the read falls to the plain struct read. A `T[] | null` arm boxes under
its list tag already (`emitSharedFieldNulListBox`).
