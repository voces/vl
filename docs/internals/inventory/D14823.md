#### Mechanism

`deliver0()` returns a list literal whose element is the hole function `inc0`, and the two
calls read that element at `i32` (in `take0`) and at `f64` (directly). D9553 closed the
`.map` spelling by asking for a copy of `deliver0` per pin wherever a call's result stays
open (`monoAskSplitRetCopies`). An index call `xs[0](x)` on the result does not leave it open
that way, so one instance of `deliver0` serves both reads and the `f64` call is emitted against
the `i32` instance. The same holds with the index call inside `take0` and `.map` outside: then
`__lambda_0` expects `f64` from a callee returning `i32`.
