### D1311 — the compare-frame pre-pass walks only the TOP-LEVEL struct row, so a NESTED struct's list field gets a core with no frame — silent at `string[]`, loud at the rest

**check-clean invalid wasm: `unknown local 12: local index out of bounds` · clause 1 · PRE-EXISTING: identical bytes and identical offset on `seed-latest` (2026-09-03) · ZERO corpus cells · found 2026-09-03 while grading [D1291](#d1291)'s close one construct deeper**

Repro (`vl check` rc 0; the module fails to instantiate):

    type Deep = { s: string[] }
    type Outer = { d: Deep }
    const a: Outer = { d: { s: ["a"] } }
    const b: Outer = { d: { s: ["a"] } }
    const c: Outer = { d: { s: ["b"] } }
    print(a == b)
    print(a == c)
    // vl check rc 0; vl run -> unknown local 12: local index out of bounds

#### Mechanism

`leqNoteBin` reserves one compare frame per LIST-repped field of the row `binEqStructRow`
resolves — and that is the row of the OPERANDS. A code-15 field recurses at emit time
(`emitStructEqFieldAt` calls `emitStructEqRec` one level down) but the pre-pass never
follows it, so the nested row's own list fields are cores emitted against a frame nobody
reserved. `shapeHasCloField` is the same walk done correctly, with a `seen` list bounding
the recursion; this one has no recursion at all.

The SEVERITY splits by rep, which is why the family is easy to under-count from its message:
a `string[]` nested field reaches `emitListEqSCore`, whose slots are lazily numbered and
simply run off the end (silent); a ref list or a `T[] | null` niche reaches
`emitListEqGCore`, which checks its frame and refuses loudly.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the nesting (`{ s: string[] }` compared directly) | runs | **yes** |
| the list field (nested `{ p: i32 }`) | runs | **yes** |
| `string[]` → `Inner[]` | loud `list compare frame was not reserved for this rep` | no — same family, other severity |
| `Inner[]` → `Inner[] | null` | same loud refusal | no |

#### Grading list

The witness; the `Inner[]` and `Inner[] | null` nested spellings, which are the LOUD half of
the same mechanism; a nested struct with a plain scalar field (runs today and must keep
running); the two-level nesting, which must reserve at every level.
