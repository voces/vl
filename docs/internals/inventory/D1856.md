### D1856 — the rest parameter's packed literal does not travel the array-literal pin channel, so its element join reaches the monomorphizer unrendered

**loud check reject · filed 2026-09-07 against master `cc4f42623`**

Repro:

    function f<T>(...xs: T[]) { return xs.length }
    print(f(1, "x"))
    // vl check: a rest parameter's element is inferred from the arguments, and these join to i32 | string — a boxed union a type parameter cannot be pinned to. Spell the element out, `...xs: (i32 | string)[]`, or pass one element type

#### Mechanism

[D1851](D1851.md) closed the LIST face by giving `monoArgTyName`'s array-literal channel the
array-element grouping rule (`arrLitElemSuffixed`), so `g([1, "x"])` renders `(i32 | string)[]`,
pins and prints `2`. The REST face of the same join does not reach that channel: the checker
packs the trailing arguments into a SYNTHESIZED `ArrayLit` and the pin is taken somewhere the
grouping fix does not serve, so the join arrives spelled the way it always was.

That the two are independent is measured rather than argued. With the renderer fixed and
`restHoleUnionErr` disabled, `f(1, "x")` and `f("x", true)` are **check-clean invalid wasm** —
the outcome the refusal was shipped to prevent — while their list-face twins run. The refusal
therefore blocks no runnable program and stays until this row closes.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the refusal (`restHoleUnionErr` disabled) | check-clean invalid wasm | it is the only thing holding the line |
| the rest face (`g([1, "x"])`, a list argument) | runs — D1851's close | **yes** |
| the boxed join (`f(1, true)`, the i32 spine) | runs, both faces | **yes** |
| the generic (`f(...xs: (i32 \| string)[])`) | runs | **yes** |

#### Grading list

`tests/cases/functions/error-rest-element-hole-boxed-union.vl` must keep refusing at the checker
while this is open, and `rest-element-hole-joins.vl` must keep running — a close here moves the

is the control that says the join itself is representable, so a close that also changes the list
face has gone wider than this row.
