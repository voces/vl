#### Mechanism

The `.map` receiver was typed from a returned literal only when the receiver binding's one
initialiser is the call ([D9410](D9410.md)): `monoPinnedAnnTyAt` refused any binding with a
write, and had no arm for a list literal, an element read or a `??`. A second write to the
binding, or a read back out of a list or map the call was stored in, left the receiver open, so
the callback's call through `f` named no function. The map-value spelling read by index failed
one step earlier: `monoPinMapSlot` typed a function-list value slot only when every stored
value is a list literal.
