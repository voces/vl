### D9502 — a returned list of un-annotated functions that reaches its `.map` through a reassigned `let` or a list element calls an unknown function

**loud emit reject · `vl check` rc 0 · `call to unknown function` · clause 2 · found closing [D9450](D9450.md) · present on master `56e51b394` · filed 2026-10-21 against master `56e51b394`**

Repro:

    function inc(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function deliver() { return [inc, dbl] }
    let v = deliver()
    v = deliver()
    print(v.map((f) => f(3))[1])
    // vl check rc 0.  vl run: emit error: emitProgram: call to unknown function

Want:

    6

#### Mechanism

Not traced. The `.map` receiver is typed from a returned literal only when the receiver binding's
one initialiser is the call ([D9410](D9410.md)). A second write to the binding, or a read back out
of a list the call was stored in, leaves the receiver open, so the callback's call through `f`
names no function.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the reassignment (`let v = deliver()` alone) | runs, `6` | **yes** |
| the return (`let v = [inc, dbl]`, `v = [inc, dbl]`) | runs, `6` | **yes** |
| the `.map` callback (`print(v[1](3))`) | runs, `6` | **yes** |
| the reassignment, read through a list (`const xs = [deliver()]`, `const v = xs[0]`) | same refusal | no |
| the reassignment, read through an un-annotated `Map()` value | same refusal | no |

#### Grading list

The list-element and map-value spellings in the ablation. The map-value spelling read by index
(`v[1](3)`) refuses with `unsupported map value type` instead and must be graded with it. Matrix
`hole-fn-list-returned-called-at-two-types`, un-annotated `local_assign`, `array_element`,
`global_assign`, `map_value` and `map_set`.
