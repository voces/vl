### D4201 — the else of a literal test on a list element of a boxed union claims the element as an atom

**closed 2026-10-12 by lane CK · runs · was check-clean invalid wasm · found reviewing #3577 · filed 2026-10-12 against master `0bf4c3bb6` · pins: `tests/cases/literal-unions/index-place-literal-else.vl`**

Repro:

    type M = 1 | "a" | "b"
    function f(xs: M[]) {
      if xs[0] is 1 { print(0) } else { print(xs[0] + "!") }
    }
    f(["a"])

Want:

    a!

#### Mechanism

Under the else narrowing, the checker types `xs[0]` as `"a" | "b"`. `exprIsLitAtom`'s Index arm
(`compiler/emit_classify.vl`) read that as a pure literal union and claimed an atom, so `+`
converted an atom to a string over what the emitter unboxes to a string ref. An element of a
box-repped list now falls through to the narrowed member's own rep.

#### Grading list

`!=`, a negated test, the then-arm read.
