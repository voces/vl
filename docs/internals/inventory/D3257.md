### D3257 — `??` over a nullable map is refused at emit

**loud emit reject · filed 2026-09-29 against master `d48a56b17`**

Repro:

    function mk(n: i32): Map<string, i32> {
      const m = Map<string, i32>()
      m["a"] = n
      m
    }
    function h(n: i32, c: boolean): i32 {
      const o: Map<string, i32> | null = if c { mk(n) } else { null }
      const z = o ?? mk(-1)
      z["a"] ?? -9
    }
    print(h(2, true))
    print(h(2, false))
    // vl check: rc 0.  vl run: emitProgram: `??` over this nullable value is not supported yet

Want:

    2
    -1

#### Mechanism

The `??` lowering has no arm for a `nulmap` left operand: a nullable map read of a map (`m[k]`)
is served by the fused get-with-default, but a plain `Map | null` value reaches the generic
refusal. A `for` loop value of map type (pending, the follow-up to #3293) is `Map | null`,
so it meets this too.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `??` (`if o != null { o["a"] ?? -9 } else { -1 }`) | runs | **yes** |
| the map (`o: i32[] \| null`, `o ?? [0]`) | runs | **yes** |
