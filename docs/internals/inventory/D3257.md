#### Mechanism

The `??` lowering has no arm for a `nulmap` left operand: a nullable map read of a map (`m[k]`)
is served by the fused get-with-default, but a plain `Map | null` value reaches the generic
refusal. A `for` loop value of map type is `Map | null` (the loop can run out), so
`(for … { break m }) ?? m2` is refused the same way, as are the `?? ` cells of the #3293
review grids whose value arm is a nullable map.
