### D4089 — `r is B` over `r: A | C`, with `B` contained in the member `A`, is refused at emit

**loud emit reject · clause 2 · found reviewing the D4058 close (#3549) · filed 2026-10-11 against master `5a9535c91`**

Repro:

    import { toString } from "std:fmt"
    type A = { x: i32 }
    type B = { x: 1 | 2 }
    type C = { z: string }
    function g(r: A | C): string { if r is B { const y: 1 | 2 = r.x; return "B " + y.toString() } "no" }
    print(g({ x: 1 }))
    print(g({ x: 7 }))
    print(g({ z: "s" }))
    // vl check: rc 0.  vl run: rc 1, "`is` names a type that is not a union variant"

Want:

    B 1
    no
    no

#### Mechanism

`emitRecordFitIs` answers a record operand; over a union operand it declines, and the union
`is` lowering looks `B` up among the union's arms and finds none. The value-fit test here is
a tag test for the `A` arm followed by the field test on the unboxed record. The checker's
hint for this program names the type as `B$m0`, an internal spelling, which the close should
also correct.
