### D15920 — a record of un-annotated functions joined by an `if` and bound, handed to an un-annotated parameter the callee binds to a second name and calls through, is refused at emit

**loud emit reject · `emitProgram: this record `if` stores functions of different signatures in one field, and a call through the joined record is lowered at one of them` (#7517's floor fires first; before it, `cannot take the generic function `half` as a value`) · clause 2 · open · found grading [D15807](D15807.md) (the record matrix's `argument` cell, whose callee aliases its parameter) · filed 2026-11-12 against master `0671904bf`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function two() { [1, 2].length }
    function __take(a) {
      const v = a
      print(v.f(3) + v.f(4))
    }
    const r = if two() > 5 { { f: half } } else { { f: inc0 } }
    __take(r)

Want:

    9

#### Mechanism

Not traced. The alias `const v = a` is the ingredient: the same callee calling through `a`
itself runs. The functions' results do not matter, since the one-result twin is refused too. The
message's "no call site pins `half`" suggests that a call through the alias does not pin the
functions that the parameter's call sites hand it.
