### D9092 — a list literal of un-annotated functions with different results, called at an index that is not a constant, calls every element at the first one's signature

**closed 2026-10-29 · runs, prints `1.5`: a call through the element fixes the tuple of the member it runs (D3975 A, [D14435](D14435.md)) · was a loud check reject from 2026-10-21, `cannot store 'half' in an element of 'xs'`, and before that loads then traps (`indirect call type mismatch`), `vl check` rc 0 · clause 1 · found closing [D9060](D9060.md) · present on master `361494943` · filed 2026-10-21 against master `361494943` · closed by `holeSlotJudge` (check_relate_core.vl) judging the literal's own elements, DESIGN, as the annotated twin's union element is refused at the call · fixtures `closures/hole-fn-list-literal-results-differ.vl`, `closures/hole-fn-list-literal-looped-over.vl`, `closures/error-hole-fn-record-list-field-looped-over.vl`, `closures/hole-fn-written-over-slot-results-agree.vl` · residue [D9140](D9140.md)**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const xs = [inc0, half]
    const i = xs.length - 1
    print(xs[i](3))
    // vl check rc 0.  vl run: wasm trap: indirect call type mismatch

#### Mechanism

Not traced. The literal's element is typed `(i32) => i32` from its first element. A call at
a constant index is devirtualised to that element and runs, which hides the disagreement; a
call at a computed index goes through the slot. The annotated twin,
`const xs: (((a: i32) => i32) | ((a: i32) => f64))[]`, is refused at check (`called value is
not a function`), so the checker owes a refusal here or the element a type both fit.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the computed index (`xs[1](3)`) | runs, `1.5` | **yes** |
| the second result (`half` replaced by `function dbl(a) { return a * 2 }`) | runs | **yes** |

#### Grading list

`for f in xs { print(f(3)) }` prints `4` and then traps. A constant-index call
`print(xs[1](3))` in the same program as a computed-index one also traps, though it runs alone.

#### Closing decision and its price

The refusal is DESIGN: written with annotated lambdas, the literal is accepted and every call
through its element, at a constant index or a computed one, is refused (`called value is not a
function`). The un-annotated literal is now judged the same way at every call through it.
Price: three spellings that ran on `361494943` are now refused. `print(xs[1](3))` alone printed
`1.5`, `print(xs[0](3))` printed `4`, and `const g = xs[1]; print(g(3))` printed `1.5`.
Literals whose functions agree at the call's types keep running, for example `[inc0, half]`
called at `3.0`, and so does a record `{ f: inc0, g: half }`.
