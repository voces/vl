`type mismatch: expected i32, found f64` at a module global, and a loud emit reject
`emitProgram: only i32 locals are supported` at a local · clause 1 and clause 2 in one shape ·
filed 2026-09-06 against master `b839ad265` as the measured residue of [D1773](D1773.md) ·

`tests/cases/unions/negation-binding-every-scalar-rep.vl`**

Repro:

    const x: !string = 1.5
    print(x)
    // vl check: rc 1, `!string` is a NEGATION, which says what a value is not

#### Mechanism

[D1773](D1773.md) made three ladders read through a negation — the binding's cell, the
global's cell and the local gate — which is enough for every value whose rep the surviving
ladders already infer from an un-annotated init. It is not enough for a rep whose deciding
rung is a `letIs*` classifier, because they all open with the same shape:

    if d.letType >= 0 { …read the annotation…; return false }

The annotation short-circuits before the initializer is consulted. `letIsF64` is both the
cell's classifier and, through `globalIsF64Sid`, the `print` arm's, so the global took an f64
cell from `globalKind` while the read took `__print_i32__` — `wasm-dis` shows it in two lines,
`(local $0 f64)` holding `(f64.const 1.5)` read by `(call $fimport$0 …)`.

`letRepAnnOf` is the one home: the annotation node whose type NAMES a rep, or -1. Six
classifiers ask it now — `letIsF64`, `letIsI64`, `letIsF32`, `letInfersF32`, `letIsNulNone`
and `letInitIsLitAtom` — plus `globalIsF32Sid`, which gained the inference fallback its f64
twin has built in, and `declLitUnionTyAt`, which carries the atom's member texts.

**The capture is a second cell for the same value, and moving only the first is a
regression.** With the binding rungs alone, four capture positions of the f64 matrix went from
a loud refusal to check-clean invalid wasm: the local became an f64 while `captureValKind`
kept reading the annotation for the env field. Both moved together, with
`captureValStructIdx` as the companion column.

#### What the refusal forecloses

The measurements above are kept as the record of what a written negation would have cost had
it stayed legal — they are what the ruling decided against, not a gap still owed. `A & !B`
remains legal and unchanged: there the negation is an intersection OPERAND, subtracted from
the operand beside it, and the annotation's own type is the positive remainder.
