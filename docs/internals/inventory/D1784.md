### D1784 — a negation-annotated binding is transparent for i32, boolean and string, and NOT for f64: the `letIs*` ladder short-circuits on the annotation, so an f64 global is check-clean invalid wasm and an f64 local refuses

**check-clean invalid wasm — `type mismatch: expected i32, found f64` at a module global; a
loud emit reject `emitProgram: only i32 locals are supported` at a local · clause 1 and
clause 2 in one shape · filed 2026-09-06 against master `b839ad265` as the measured residue
of [D1773](D1773.md), whose close reaches i32, boolean and string and stops there · the
matrix could not see it because its `@@VALUE@@` is `5`**

Repro:

    const x: !string = 1.5
    print(x)
    // vl check rc 0; vl run -> type mismatch: expected i32, found f64

#### Mechanism

Not probed beyond the ablation. [D1773](D1773.md) made three ladders read through a negation
to the initializer — the binding's cell, the global's cell, and the local gate — and that is
enough for every value whose rep the surviving ladders already infer from an un-annotated
init. It is not enough for f64, because the rung that decides f64-ness is `letIsF64`, whose
shape is the one every `letIs*` classifier shares:

    if d.letType >= 0 { …read the annotation…; return false }

The annotation short-circuits before the initializer is ever consulted. `letIsF64` is both the
cell's classifier and, through `globalIsF64Sid`, the `print` arm's — so the global gets an f64
cell from `globalKind` while the read takes `__print_i32__`, and the local never leaves
`checkLocalI32`'s i32-only floor. `wasm-dis` shows the split in two lines: `(local $0 f64)`
holding `(f64.const 1.5)`, read by `(call $fimport$0 …)`, the i32 print import.

Closing it means the negation reading through in the `letIs*` family, which is ~30 functions
each carrying that same short-circuit — so the unit of work is a shared home for "this
annotation names no rep", not another rung. That is why it is filed rather than folded into
[D1773](D1773.md).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the f64 value, for an `i32` / `boolean` / `string` | runs | **yes** |
| the negation, for `const x: f64 = 1.5` | runs, prints `1.5` | **yes** |
| the annotation entirely (`const x = 1.5`) | runs, prints `1.5` | **yes** |
| the inline spelling, for a `type N = !string` alias | same outcome, both faces | no |
| the module scope, at a LOCAL | a loud refusal instead of invalid wasm | no — the other class |
