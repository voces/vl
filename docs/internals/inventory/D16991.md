### D16991 — an `is` test of a map or set type over an empty `Map()` or `Set()` handed to a generic answers by the hole default's type, not by emptiness

**closed 2026-11-18 — the witness prints `7` · was check-clean silently wrong, clause 1 · an `is K` arm that only tests a type parameter's receiver is a use that fixes it: the first such arm in source order binds the parameter, never clashing and overridden by any arm that writes (`tpArmWriteTy`, `compiler/check_tp_arm_writes.vl`), and the caller's empty container is pinned there, so a map and a set pass the test as a list does · fixture `tests/cases/generics/empty-container-passes-the-first-is-arm-that-tests-it.vl` · the map twin of [D4910](D4910.md) · found closing [D16986](D16986.md) · filed 2026-11-18 against master `8365bb0bd` by lane F1**

Repro:

    function f<T>(x: T) {
      if x is {[i32]: f64} { return 7 }
      return 0
    }
    print(f(Map()))
    // PRINTS 0

Want:

    7

#### Mechanism

An empty container handed to a bare type parameter is closed at the hole default
(`elabHoleContainerClosed`, `emit_elab.vl`): a map key `string`, a value `i32`. The `is` test then
compares that instance type with `{[i32]: f64}` and answers false. A list in the same place answers
by emptiness (D4910), and under DECISIONS.md §"No default type" an unfixed empty container passes
every container test of its kind, so the map should too.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `is {[string]: i32}`, the default's own type | prints `7` | **yes** (a type other than the default) |
| a plain `const m = Map()` tested in place, no generic | prints `7` | **yes** (the type parameter) |
| `Set()` with `is Set<i32>` | prints `0` | no |
| a list, `f([])` with `is f64[]` | prints `7` (D4910) | **yes** (a map or set) |
