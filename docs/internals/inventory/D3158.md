#### Mechanism

The direct spelling `function f(z: AB)` refuses `z == "z"`: comparing a literal-union place
with a literal outside its set can never be true (DESIGN, the closed-set rule). The hole defers
the comparison to the pin, which recorded the literal as `string`, and `AB` against `string`
passed the mutual-assignability test. The pin now records the literal's own type. A member
literal holds (`z == "b"` runs), and a non-member is refused as the direct spelling refuses it.
