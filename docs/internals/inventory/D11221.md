#### Mechanism

The `as` lowering finds the target among the operand box's arms, either as a value-union arm or
as a struct variant. A literal-union arm is neither, because it rides the box as an atom of its
base (`i32` for `1 | 2`, `string` for `"a" | "b"`). So no arm matches, and the cast refuses.
The `if u is N2 { … }` ladder the message suggests runs and prints 2. A cast between two literal
unions (`w as! K` with `w: "a" | "b" | "c"`) is a different route, and it runs.
