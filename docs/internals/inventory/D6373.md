### D6373 — a record literal holding a generic function merges onto a declared record of the same field names, and is check-clean invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · found closing [D6342](D6342.md) by its capability matrix · the same on l1-split6 `f4f18b627` · filed 2026-10-18 against l1-split6 `f4f18b627`**

Repro:

    function k<T>(x: T): T { return x }
    type W = { f: i32 }
    const r = { f: k }
    print(r.f(41))
    // vl check: rc 0.  vl run: the emitted module failed to validate inside the module's top-level code: type mismatch: expected i32, found (ref $1)

Want:

    41

#### Mechanism

From the ablation only, and the same family as [D1411](D1411.md): the literal `{ f: k }` takes
the declared row of `W`, whose one field is named like its own, though a function value does
not fit an `i32` field. `W` is never used. With a non-generic `k` the same merge is a loud
refusal rather than a bad module.
