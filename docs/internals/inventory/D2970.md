#### Mechanism

Not localised. The same spread with a concrete `i32[]` source and an `(i32 | null)[]`
destination runs (D2869, D2868). Inside the instance the literal's recorded type is the
template's `(T | null)[]`, so `spreadOwnBoxRow` finds no row for it and no pending row is
threaded from the return.

#### Close

[D2968](D2968.md)'s mechanism: `spreadBoxingSource` and its siblings read the literal's template
type, `(T | null)[]`, so at `T := i32` the boxing path never saw a scalar source to box. They now
read the instance's types.
