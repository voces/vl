### D3863 — a generic record holding a list of records, `Box<A[]>` beside `Box<B[]>` of same-shaped `A` and `B`, reads its element as one of the two, and the other's `self`-function is never called

**closed (2026-10-08, lane SC) · was check-clean silently wrong value · found grading D3834's nominal-pin matrix · filed 2026-10-08 against master `1af9fe52f` · pins: `tests/cases/modules/same-shape-record-pin-by-name/`**

Repro:

    // file: r1.vl
    export type A = { x: i32 }
    export function d(self: A): string { "RA" }
    // file: r2.vl
    export type B = { x: i32 }
    export function d(self: B): string { "RB" }
    // file: main.vl
    import { A, d } from "./r1"
    import { B, d } from "./r2"
    type Box<T> = { v: T }
    function h<T>(x: T): string { x.d() }
    const a: A = { x: 1 }
    const b: B = { x: 2 }
    const ba: Box<A[]> = { v: [a] }
    const bb: Box<B[]> = { v: [b] }
    print(h(ba.v[0]))
    print(h(bb.v[0]))
    // vl check: rc 0.  vl run: prints RA, RA

Want:

    RA
    RB

#### Mechanism

`h` is instantiated at the name `monoArgPinName` gives its argument, and for a value read out of
a list (an index, a `for` variable), a map read or a forwarding generic's parameter, that name
came from the type's render or from the first declared record with that render. `A` and `B`
render alike, so `bb.v[0]` was pinned at `A`, and whichever instance was minted first answered
both. Where the checker types the argument as a declared record and the name the ladder
reached renders the same, the record's own name is now the pin (`monoDeclRecPinName`). The
same reading fixed a record's list field, `Pair<A[], B[]>`, `Box<Box<B>[]>`, a capture and
`idt(bb.v[0])`, all wrong on master too. A list of lists pins as `B[][]` at any depth, which the
one-level rule for a list of records (`monoDeclRecListPinName`, D3792) did not reach, so
`fw<T>(xs: T[][])` called with `[[b]]` read `xs[0][0]` as `A`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the list (`Box<A>`, `Box<B>`, `h(bb.v)`) | `RA`, `RB` | **yes** |
| the generic record (`const bs: B[] = [b]`, `h(bs[0])`) | `RB` | **yes** |
| the call at `A` (only `h(bb.v[0])`) | `RB` | **yes** |
