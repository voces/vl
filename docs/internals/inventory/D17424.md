#### Mechanism

D17423's route, `nulNoneEqRoute` (`emit_plan_null.vl`, #9992), takes an assignment as the
`null` unit only when its right side is the `null` literal (`asgYieldsNullLit`). An assignment of
a `null`-typed call (`eff()`, or a generic `same(null)`) into a cell typed `null` is not taken,
so the compare falls to `numeric` as D17423's did. The fix is a third side kind on the two
`asgYieldsNullLit` lines of `nulNoneEqRoute` (`const la = …` and `const ra = …`), using N9's
`asgYieldsNulNoneValue`.
