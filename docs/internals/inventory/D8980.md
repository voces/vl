### D8980 — an un-annotated function reading `.length` of its parameter is accepted at a function type whose parameter is `i32`

**loud emit reject · `vl check` rc 0 · clause 2 · the checker owes the refusal: the direct call `bad(3)` is refused as `member access '.length' on non-object i32` · found closing [D8944](D8944.md) · present on master `efbbf5f06` · filed 2026-10-21 against master `efbbf5f06`**

Repro:

    function bad(s) { return s.length > 1 }
    const f: (a: i32) => boolean = bad
    print(f(3))
    // vl run: emitProgram: '.length' on a receiver the emitter cannot classify as a list, string, map or set

#### Mechanism

Not traced. The delivery of an un-annotated function at a function type judges its body at
the type's parameters for an arithmetic demand but not for a member read: the same delivery
of `bad(s) { return s + 1 > 1 }` at `(a: string) => boolean` is refused by the checker.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the delivery (`print(bad(3))`) | check refuses, as owed | **yes** |
| `.length` for `+ 1` (at `(a: string) => boolean`) | check refuses, as owed | **yes** |
| the annotated binding, for a `(h: (a: i32) => boolean)` parameter | same emit refusal | no |
| the binding, for `[1, 2].filter(bad)` | same emit refusal | no |
| `> 1` (`(a: i32) => i32`, returning `s.length`) | same emit refusal | no |
