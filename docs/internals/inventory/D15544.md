Closed in `emitIs` (wasmEmit.vl): a primitive operand tested against its own primitive is true · the false direction (`is string` at an `i32` pin, or `is i32` at a `string` one) still refuses, filed as [D15606](D15606.md) · fixture `generics/is-over-bound-field-pinned-narrow.vl`**

Repro:

    function boundShow<T: { x: i32 | string }>(t: T) {
      if t.x is i32 { print(t.x) }
    }
    const a: { x: i32 } = { x: 7 }
    boundShow(a)
    // vl check: rc 0.  vl run: emit error, `is` names a declared union member with no interned arm representation

Want:

    7

#### Mechanism

The bound lets `T` pin at `{x:i32}`, a record whose field `x` is a plain `i32`. The body's `t.x is
i32` names a member of the bound's declared union `i32|string`, and the emitter resolves that member
against the instance's field type, which is no longer a union. It finds no interned arm and refuses,
though the test is decidable at the pin (always true for `i32`, always false for `string`). The
direct spelling `show(p: {x:i32|string})` is a loud CHECK reject (a shared record does not widen), so
only the generic spelling reaches the emitter.
