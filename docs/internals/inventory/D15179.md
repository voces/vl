#### Mechanism

Not yet located. The delivery into `J` reaches the record the literal `mk()` returns when it is direct (`const m: J = k`) or when `k` holds the literal itself (`const k = { r: 15, g: 1 }`), and both run. Through the identity, with `k` holding a call, the instance of `idn` is built at `J` while the value `k` reads is built at its own record.
