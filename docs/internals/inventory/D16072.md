### D16072 — a call of a `const`-bound lambda is a value call to the elaboration, so a hole lambda it returns into an un-annotated binding is never pinned

#### Mechanism

The named spelling, `function outer()`, runs and prints `42`. The checker types `v` as `(_) => _`
in both spellings. The emit-side elaboration closes a call's held value through the callee's
declaration (`elabHeldValTy` asks `identFnDeclOf(cf)`), and `identFnDeclOf` answers only a
`FuncDecl`. A callee bound by `const` to a lambda resolves to its `LetDecl`, so the call is a
value call, the returned hole lambda is never pinned at `v`'s calls, and the call through `v`
has no signature. `identFnDeclOf` has 14 readers in emit_elab alone. D16070's
`monoIdentCalleeDecl` resolves the same callee for mono's delivery path only.
