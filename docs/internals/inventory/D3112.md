### D3112 — a generic function value stored through a nullable binding or a map index, then called, traps with an indirect-call type mismatch

**trap after load · clause 1 · open · found by #3275's review · the same on master `d408f2da4` · filed 2026-09-28 against master `d408f2da4`**

Repro:

    function show<T>(x: T) { print(x * 3) }
    let h: ((i32) => void) | null = null
    h = show
    if h != null { h(2) }
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch

Want:

    6

#### Mechanism

Not localised past the ablation. Delivered to a written `(i32) => void` binding the generic is
built at `T = i32` and the call runs; delivered through a nullable binding's assignment, or stored
as a map value (`fs["k"] = two` into `{[string]: (i32, string) => void}`), the table slot the call
reads holds a function of another signature.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const h: (i32) => void = show`, no `null` | prints `6` | **yes** (the nullable or map carrier) |
| `function show(x: i32)`, not generic | prints `6` | **yes** (the type parameter) |
| a map value `{[string]: (i32, string) => void}` holding a two-parameter generic | traps | no |

#### Grading list

The nullable `let` (assigned and initialised), the map value, and a record field of nullable
function type, each holding a generic and called at `i32`.
