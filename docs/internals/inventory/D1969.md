### D1969 — a module global read after a NESTED function of the same name was declared lowers as that function, not the global

**check-clean invalid wasm · clause 1 · filed 2026-09-22 against master `0eb92ecea`, found writing [D1966](D1966.md)'s fixture**

Repro:

    function a() {
      function s(): i32 { return 1 }
      print(s())
    }
    a()
    const s = "top"
    print(s)
    // vl check: rc 0.  vl run: invalid module — failed to validate inside the module's
    //   top-level code: type mismatch: expected (ref $type), found ...

#### Mechanism

Not yet isolated past the ablation. The checker scopes the two names correctly (rc 0, and the
nested `s` is only visible inside `a`); the emitter reads the top-level `s` with the nested
function's name in view, so the global read is lowered against the wrong declaration. The nested
function's return is annotated in the witness, so this is not [D1966](D1966.md)'s inferred-return
row: it is name resolution between a lifted function and a module global.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the nested function renamed (`t`) | runs, prints `1` then `top` | **yes** |
| the global an `i32` (`const s = 7`) or `f64` | still invalid wasm | no |
| the read as `s + "!"` instead of `print(s)` | still invalid wasm | no |
| the global moved into a function (`const s` local to `main`) | runs | **yes** (module global) |
| the nested `function s` → `const s = (): i32 => 1` | runs | **yes** (named declaration) |

#### Grading list

A global declared BEFORE the function holding the nested namesake, and the nested function
un-annotated (`function s() { 1 }`), which after D1966's close takes the node-keyed row.
Its frame-local twin, invalid wasm on base and after D1966's close alike: a call of the TOP-LEVEL
`k` placed BEFORE a nested `function k(): i32` in the same body (`const before: string = k()`).
The checker binds the nested name from its declaration on; the emitter's scope chain sees the
nested function for the whole frame, so the earlier call lowers against it.
