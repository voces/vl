### D2843 — a generic caller reading another generic's two-list return set in its own body is refused (#3211)

**closed 2026-09-27 · was loud check reject, clause 2, on master `d39c809c1` · the refusal #3211 introduced when it typed a return set of `[t]` beside `[1]` apart (`T[] | i32[]`); the program ran on `95ad622d8` · found by the #3214 review (h5 `c2`, `c4`) · filed 2026-09-27 against master `7323baf55` · fixture `tests/cases/generics/generic-body-list-union-read-ops.vl`**

Repro:

    function p<T>(t: T, c: boolean) {
      if c { return [t] }
      [1]
    }
    function k<T>(t: T, c: boolean) {
      print(p(t, c).length)
      0
    }
    k(3, true)

Want:

    1

#### Mechanism

#3211 types `p`'s return set `T[] | i32[]`, the union the direct spelling has, and re-joins it
at each pin, so a top-level `p(3, true).length` runs (the join is `i32[]`) and `p("s", true)`
answers `string[] | i32[]`. Inside `k` the call is read while `T` is open, the join is still two
lists, and a body read (`.length`, an element, `for`, a flow into a closure) refuses where every
pin `k` is actually called at would run. The only instance is `T := i32`, and the program ran on
`95ad622d8`, which collapsed the join to `T[]`.

Restoring that behaviour is unsound. #3214 tried it for five review rounds, as a collapse to
`T[]` while the parameter is open, a recorder of each body use, and a re-check of the recorded
uses at every pin; each round found another use shape the recorder did not see, and each
produced invalid wasm or a wrong value at a pin that keeps the lists apart: widening flows
(`i32[]` beside `f64[]` returned, re-bound or put in a literal), the `bsame` print path (a
boolean element printed as a number, [D2820](D2820.md)), closure capture and closure
parameters, a `for` loop's captured element, and a nested closure that swaps the rep between
layers. The close needs a sound typing of a union of lists inside a generic body, one the pin
can refine without re-checking the body, which is a design question, not a collapse.

Evidence, the #3214 review directories (session scratchpad): `rv3214-h1`..`rv3214-h5` and
`rv3214-g1`/`rv3214-g3` (round 1), `rv3214r2-x9`, `rv3214r3-k4`, `rv3214r4-q7` and
`rv3214r5-z2` (`genv.py`, `keep5/`).

Closed by the list-union read rewrite reaching a generic body (the D2876 lane): `.length`,
an index read and `for`-`in` over `T[] | i32[]` are an `is` chain whose bindings keep the
checker's union and whose last member is tested too, lowered per pin, which is the typing
this paragraph asked for. `k("s", true)` now prints `1`, as the direct spelling has since
#3229. The closure face (`c2`, `c4`) stays a loud check reject: a function value's two-list
return is not built as the union at the pin, which D2894 files.
