### D16325 — a record `is` narrowing a non-literal field, over a generic or un-annotated operand, is refused at emit

**open · loud emit reject · ``emitProgram: `is` over a record tests a field that is not a literal set narrowed from the declared field, which has no lowering yet`` · clause 2 · the annotated spelling runs since D16324's close · found closing D16324 · filed 2026-11-15 against master `5683d3b2c`**

Repro:

    type A = { x: i32 | string }
    type B = { x: i32 }
    function g<T>(a: T) { a is B }
    const a: A = { x: 1 }
    print(g(a))

Want:

    true

#### Mechanism

The checker mints a record's per-field content check only over a concrete operand type
(`recFieldFitBuild` refuses a type with a type variable), so the instance's test reaches the
emitter's own record lowering, which covers literal-set fields only. An un-annotated parameter
(a hole) is the same shape: the matrix's `argument` and `early_return_guard` cells in the
un-annotated face refuse with this message on both seeds.

#### Ablation

On master `5683d3b2c` plus D16324's fix.

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the parameter annotated `a: A` | runs | **yes** |
| the field narrowed to a literal set (`B = { x: 1 \| 2 }` over `x: i32`) | runs | **yes** |
