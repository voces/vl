### D9381 — a generic over a record parameter returned from an un-annotated function and bound at a function type refuses

**loud emit reject · clause 2 · `vl check` rc 0 · CAPABILITY: the same generic bound directly runs · found closing [D9282](D9282.md) · present on master `a28f82fcb` · filed 2026-10-21 against master `a28f82fcb`**

Repro:

    type K = "x" | "y"
    type R = { k: K }
    function pick<T>(r: { k: T }): T { r.k }
    function deliver() {
      return pick
    }
    const v: (r: R) => K = deliver()
    print(v({ k: "y" }) + "!")
    // vl run: emitProgram: a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type

#### Mechanism

Not traced. Past `deliver`'s return the flow table's pin is read for `pick`, and the record
parameter `{ k: T }` does not bind `T` from the pin's `R`, so no instance is built and the value
reaches the emitter's floor. Bound directly (`const v: (r: R) => string = pick`) it runs and
prints `y!`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `deliver` (`const v: (r: R) => K = pick`) | runs, `y!` | **yes** |
| the record (`same<T>(k: T): T` at `(k: K) => K`) | runs | **yes** |
