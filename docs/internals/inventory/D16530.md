### D16530 — a literal-union value copied off a hole parameter, narrowed by `==` to one member, reads `??` as a string ref

**check-clean invalid wasm · clause 1 · open · `vl check` rc 0 · `the emitted module failed to validate inside `__take`: type mismatch: expected (ref $0), found i32; $0 is `string`` · the un-annotated `argument` cell of `inline-litunion-nullable.matrix.vl`, reported by lane L · filed 2026-11-15 against master `ab210efa2`**

Repro:

    function pick(n: i32): "red" | "green" | null {
      if n > 1 { return null }
      if n > 0 { return "green" }
      "red"
    }
    function __take(a) {
      const v = a
      if v == "green" { print(v ?? "none") }
    }
    __take(pick(1))
    // vl check: rc 0.  vl run: invalid module, expected (ref $0) `string`, found i32

Want:

    green

#### Mechanism

The literal union reps as an `i32` atom. Inside the hole function, the local copy `v`
narrowed by `== "green"` is handed to `??` as if it were already the string `"green"`, but
the atom was never widened to a string ref; `??` on the parameter itself, or on an
annotated parameter's copy, widens it. From the ablation; the instance's locals have not been
printed.
