### D2976 — a generic record guard refuses when the body is pinned at a record and at a literal union in one program

**closed by the D3140 close: `T | string` at a `K` pin no longer builds a box the `is` receiver test cannot read · fixture `tests/cases/generics/niche-pin-sibling-closes.vl` · was loud emit reject · clause 2 · the #3247 review's `g2` grid · filed 2026-09-28 against master `fe1fa1bec`, closed 2026-09-29 against master `a6cb22568`**

Repro:

    type R = { x: i32 }
    type K = "a" | "b"
    function h<T>(a: T, c: boolean): i32 {
      const r: T | string = if c { a } else { "z" }
      if r is R {
        print(r.x)
        return 1
      }
      print("no")
      return 0
    }
    const pv0: R = { x: 9 }
    h(pv0, true)
    const pv1: K = "a"
    h(pv1, true)
    // vl check: rc 0.  vl run: emitProgram: `is` receiver is not a union value

Want:

    9
    no

#### Mechanism

Not localised. At the `K` pin, `r` is `K | string`, which reps as a string, not a box. The `R`
guard there should be false. Each pin alone runs, so the refusal needs both instances in one
program, which suggests the `R` pin's union registration reaches the `K` instance's test.
