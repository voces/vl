#### Mechanism

At the `K` pin, `r` is `K | string`, which reps as a string, not a box. The `R` guard there is
false; `emitIs` now decides it from the pin's type, which `assignable` relates to no tested member. Each pin alone runs, so the refusal needs both instances in one
program, which suggests the `R` pin's union registration reaches the `K` instance's test.
