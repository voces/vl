### D17792 — a `.map` lambda calling a list-of-records element's hole function at another signature than an outer call pinned is refused at emit

**open · loud emit reject · clause 2 · `vl check` rc 0, `emitProgram: the compiler cannot yet lower this statement (method f)` · filed 2026-11-28 against master `2693ffdcf` (lane START-2)**

Repro:

    function id(a) { return a }
    function deliver() { return [{ f: id }] }
    const u = deliver()
    print(u[0].f(2))
    const v = deliver().map((r) => r.f(2.5))
    print(v[0])
    // vl check: rc 0.  vl build: loud emit reject (method f)

Want:

    2
    2.5

#### Mechanism

A hole function held in a list of record literals is one slot instance, the one `u[0].f(2)`
pins at `(i32) => i32`, not a set; the lambda's call at `f64` has no instance to reach. The
record form (`{ f: id }`) mints a set and runs. The family of [D17790](D17790.md).
