### D3208 — a `K | L | null` function result returned through `string | null` calls at the caller's signature

**loads then traps · clause 1 · pre-existing on master `d48a56b17` · found by the D3198 grid (`nluKL_bound_retw_*`) · filed 2026-09-29 against master `94670f728` · the #3290 close was reverted with the `K | L | null` flatten, and `cloCallSigKey`'s nullable-literal-union override stays for the inline spelling**

Repro:

    type K = "a" | "b"
    type L = "c" | "d"
    const g: () => K | L | null = () => "c"
    function w(): string | null { return g() }
    print(w() ?? "n")

Want:

    c

#### Mechanism

`K | L | null` is the box it is on master, since D3198's flatten covers only an inline list of
string literals. The call site in `w` keys `call_indirect` at `w`'s own `string | null`
signature. `cloCallSigKey` prefers the callee's arena key for a nullable literal-union result.
The inline spelling (`"a" | "b" | "c" | "d" | null`) runs; the box spelling still traps, as on
master.

| `print(g())` inside a function | runs | **yes** |
