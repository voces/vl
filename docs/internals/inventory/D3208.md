### D3208 — a `K | L | null` function result returned through `string | null` calls at the caller's signature

**closed 2026-10-03 — the witness prints `c` · was check-clean invalid wasm · clause 1 · closed with [D3382](D3382.md)'s return position (`emitBoxToNulStr`) · fixture `tests/cases/unions/literal-union-box-returned-as-nullable-string.vl` · the call now keys at the callee's box signature, and what is left is [D3382](D3382.md), the box delivered as `string | null` · found by the D3198 grid (`nluKL_bound_retw_*`) · filed 2026-09-29 against master `94670f728`, re-graded 2026-09-30 against master `3291e99e1`**

Repro:

    type K = "a" | "b"
    type L = "c" | "d"
    const g: () => K | L | null = () => "c"
    function w(): string | null { return g() }
    print(w() ?? "n")

Want:

    c

#### Mechanism

`K | L | null` is a box, since D3198's flatten covers only an inline list of string literals.
The call site keyed `call_indirect` at `>N` (`string | null`): `calleeCloSigKeyAt` read `g`'s
annotation, which has no arena type, through its emit spelling `()=>string|null`, which softens
the two aliases to `string`. The key was interned only when `w`'s own signature interned it,
hence the ablation's second row. The annotation arm now prefers the callee's checker type
(`>u`, the box) when that key is interned, so the call matches the lambda. The box then reaches
`w`'s `string | null` result with no conversion, which a direct function returning
`K | L | null` shows on its own ([D3382](D3382.md)); this row closes with that one.
