### D9911 — a record field holding `x ?? <default>` in an un-annotated or `<T>` body at a never-null pin has no struct shape at emit

**loud emit reject · clause 2 · `vl check` rc 0 · CAPABILITY: the same body at an `i32 | null` pin prints `5`, and `function f(x: i32)` prints `5` · found closing [D9870](D9870.md) · present on master `8700f0727` · filed 2026-10-22 against master `8700f0727`**

Repro:

    function f(x) { return { v: x ?? 1.5 } }
    const z: i32 = 5
    print(f(z).v)
    // vl run: emitProgram: ref valtype with no interned shape

Want:

    5

#### Mechanism

Not traced. At a never-null pin the `??` folds to its left operand, so the field computes at the
pin, while the record's field type is the join the template was checked at. No struct is
interned for the record the instance builds.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the pin `i32 \| null` | runs, prints `5` | **yes**, a never-null pin |
| `function f(x: i32)` | runs, prints `5` | **yes**, the pin |
| `const w = x ?? 1.5` / `{ v: w }` | same refusal | no |
| `function f<T>(x: T)`, default `2` | same refusal | no |

#### Grading list

The `i64`, `f64` and `f32` pins, an integer and a float default, the hole and `<T>` faces.
