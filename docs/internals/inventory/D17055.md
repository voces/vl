#### Mechanism

Not yet located. The ablation below points at the join: the map's value is a list of two
un-annotated (hole) functions, and the `??` default is a list literal naming only one of them,
so the two operands of the join are built as two distinct wasm list types where legacy declares
the join at one. A default naming both functions, or annotated parameters, gives both operands
one type and the program runs.
