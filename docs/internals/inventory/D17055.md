#### Mechanism

The function-set decision (`check_fn_tag.vl`) re-types a holder's write to the set's ids: a
store's value and a map entry's literal are joined at the holder's type
(`ftRecWriteJoins`, `ftMapEntryLitJoins`). A `??` whose left side is a holder of the set had no
such arm. So the default list literal `[inc0]` kept its own one-function type and was built as a
list of closures, while the map's value and the join are a list of the set's `i32` ids. The
holder loop now joins the default of a `??` whose left side is the holder at the `??`'s own type,
through `ftRecWriteJoins`, as a write's value is. The literal is re-typed to the set's list and its
elements are joined as ids.

| module scope (inside a function instead) | still invalid wasm | no |
| the result read by `.map` or by an index call | invalid either way | no |
