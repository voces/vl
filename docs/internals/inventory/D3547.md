### D3547 — `g() is L` for a numeric literal union over a lambda joining two parameters answers false at a pin of members

Repro:

    type L = 1 | 2
    function F<A, B>(k: i32, x: A, y: B) {
      const g = () => { if k == 0 { x } else { y } }
      print(g() is L)
    }
    F(0, 1, 1)
    F(1, 1, 1)
    // vl check: rc 0.  vl run: prints false twice

Want:

    true
    true

#### Mechanism

Not localised. The pin is `(i32, i32)` and both values are `1`, a member of `L`, but the
membership test over the lambda's call answers `false`; the lambda's join of `x` and `y`
collapses at the call ([D3520](D3520.md)).
