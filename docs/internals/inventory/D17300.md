### D17300 — a closure's write of `null` to a `null`-typed binding it captures emits an invalid module

**check-clean invalid wasm · 1 spelling family · filed 2026-11-24 against master `fd2d6cd6` by IR-N9, found while grading D17120's positions**

Repro:

    function body() {
      let n = null
      const f = () => {
        n = null
      }
      f()
    }
    body()
    // vl check: no errors.  vl run: invalid module, type mismatch: expected i32, found nullref

#### Mechanism

A `null`-typed binding (a never-filled `let x = null`, or one annotated `null`) has rep `nullref`.
A closure that captures it holds it in a capture cell, and the write through that cell stores a
`ref.null` where the code expects an `i32`. A read through the same capture prints `null`, so only
the write is wrong. Not yet traced to the capture cell's slot type.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `print(n)` in the closure instead of the write | prints `null` | **yes** (a write) |
| the write outside the closure | runs | **yes** (a capture) |
| `let n: null = null` (annotated) | invalid module | no |
