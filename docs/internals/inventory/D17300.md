### D17300 — a write of `null` to a `null`-typed binding a closure shares by reference stores a `ref.null` into the cell's i32 sentinel slot

**fixed 2026-11-24 · closed, runs `null` · was: check-clean invalid wasm · clause 1 · filed 2026-11-24 against master `fd2d6cd6` by IR-N9 · fixed by `idxStoreNullUnitUnstamped` (wasmEmit.vl): a `null[]` store whose `null` carries no niche stamp writes the sentinel 2; the IR skips that store (`store null unit sentinel`) · fixture `closures/write-null-to-a-captured-null-binding.vl`**

Repro:

      let n = null
      const f = () => {
        n = null
      }
      f()

    body()
    // vl check: no errors.  vl run: invalid module, type mismatch: expected i32, found nullref

Want:

    null

#### Mechanism

A binding a closure assigns is shared by reference (`cboxByRef`): `cboxBoxLet` rewrites it to a
one-element cell and each write to `c[0] = v`. A `null`-typed binding's cell is a `null[]`, whose
element rides the i32 spine holding the sentinel 2 (D4671). The store's `null` arm emits the
value from its delivery stamp, and the rewritten store's `null`, checked as `n = null` at the
`null` type, has none, so it built the bottom ref. A hand-written `c[0] = null` over a declared
`null[]` is stamped and ran.

#### Ablation

| ingredient changed | outcome before | needed? |
| --- | --- | --- |
| `let n: null = null` (annotated) | invalid module | no |
| the write in the frame after the capture, not in the closure | invalid module | no |
| `let n: string \| null` | runs | **yes** (the `null` unit) |
| a read-only capture | runs | **yes** (a write) |
| `const c: null[] = [null]; c[0] = null` written by hand | runs | **yes** (the rewrite) |
