#### Mechanism

Two splits between the literal-atom ladders and the rep layer over the binding's held type.
`k`, read off the bare single-literal discriminant arm (D1460), is a literal atom to the ladder
and `string` to the held type. `t`, read off a field narrowed to non-null by the assignment
before it, is a nullable literal union (null niche) to `letNulLitUnion` and the non-null atom
to the held type. `closures/capture-walk-variable-literal-union`'s captured `const c = n` of a
narrowed loop element shows the second split too. One producer has to own which storage these
bindings get before either ladder can be deleted.
