#### Mechanism

D15533's close keeps a `.set` record literal at the slot's joined record when a call through the
field re-validates the stored value (`elabSlotRecSetHolds`), but only where every field of the
literal is a set member; the `n` field is not, so the re-validation adapted `k2` to the call's
closed instance as before. Fixed: the literal holds when at least one field is a set member and
every other field's recorded type has no hole and no type variable, so the re-validation at the
call's argument types could not change it.
