### D4953 — `is L` over a nullable union answers false for an empty list of another arm

**check-clean silently wrong · found closing D4949 · filed 2026-10-15 against branch `d4949-empty-list-push` over master `bb21e081b`**

Repro:

    const e: f64[] = []
    let v: f64[] | string[] | null = e
    if v is string[] {
      print("fits")
    } else {
      print("no")
    }
    // PRINTS no

Want:

    fits

#### Mechanism

An empty list fits every list type (D4771), and `emitListIsAcrossReps` answers that for a box
union whose list arm is in another rep (D4915). It declines a nullable operand
(`nodeTyIsNullable`), so `is string[]` falls back to the tag compare, which sees the `f64[]` arm.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `let v: f64[] \| string[] = e` (no `null` arm) | prints `fits` | **yes** |
| `const e: f64[] = [1.5]` | prints `no` (correct) | **yes** (empty) |

the then-branch (the store-back D4949 added has to reach this path too).
