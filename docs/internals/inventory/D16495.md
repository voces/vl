### D16495 — a never-fitting `as? u8` of a radix constant whose 32-bit pattern is negative is not refused, while the decimal of the same value is

**check-clean silently wrong against E8.2 only: accepted and prints `null` where a constant cast that can never succeed is refused; the printed `null` is the right runtime value, so not a clause violation · open · low priority · bucket (f) · `vl check` rc 0 · the decimal spelling `-1 as? u8` is refused (`constant -1 does not fit u8`) · found grading the oracle's `u8` domain (#8375) · filed 2026-11-15 against master `df784b45f`**

Repro:

    print(0xFFFFFFFF as? u8)
    // vl check: rc 0.  vl run: prints null

Want: a check reject, as `-1 as? u8` and `0x1FF as? u8` are refused:

    constant 0xFFFFFFFF does not fit `u8` (0..=255)

#### Mechanism

Not ablated to a function. The pattern: the constant decision (`castConstDecide`,
check_cast_bound.vl) refuses a radix literal whose pattern is a non-negative `i32` outside
0..255, and a decimal at its value. It accepts a radix constant whose 32-bit pattern is negative
(bit 31 set), so the cast is left to the runtime, which misses.

#### Ablation

| spelling | `vl check` | run |
| --- | --- | --- |
| `0xFFFFFFFF as? u8` | rc 0 | `null` |
| `0xFFFFFF00 as? u8`, `0x80000000 as? u8`, the 32-digit binary all-ones | rc 0 | `null` |
| `(-0x1) as? u8` | rc 0 | `null` |
| `-1 as? u8` (decimal) | refused | — |
| `0x1FF as? u8` (pattern `511`) | refused | — |
| `0xFFFFFFFF as u8` (bare) | refused, as a null propagation at module scope | — |
| `0xFFFFFFFF as? i32` | rc 0 | `-1` (fits; correct) |

#### Grading list

- Every rc-0 row of the ablation table is refused with the decimal spelling's words.
- `0xFFFFFFFF as! u8` (a trap on every run today) follows the same rule.
