### D2889 — a `[null]` literal returned into `(f64 | null)[] | i32[]` is refused at emit

**loud emit reject · clause 2 · found by the #3229 review · the same on master `8e10ef58b` · filed 2026-09-27 against master `8e10ef58b`**

Repro:

    function mk(b: boolean): (f64 | null)[] | i32[] {
      if b { return [null] }
      [1]
    }
    const w = mk(true)
    if w is (f64 | null)[] { print(w[0]) } else { print("i32") }
    // vl check: rc 0.  vl build: emitProgram: bare null needs a struct-typed context

Want:

    null

#### Mechanism

Not localised past the ablation. A list literal whose only element is `null` has no element type
of its own, and the union return does not hand it the `(f64 | null)[]` member it can only be, so
the element is lowered as a bare `null` with no rep.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| an all-`null` literal (`[null, 1.5]`) | runs, prints `null` | **yes** |
| the literal (`const n: (f64 \| null)[] = [null]`, return `n`) | runs, prints `null` | **yes** |

#### Grading list

`[null]` into `(string | null)[] | i32[]`, and as an argument to a parameter of that union.
