#### Mechanism

D14160 closed the dropped field by building the literal at its own record and typing the parameter
at it. The elaboration still answers that record for the call (`elabCallParamTy` is
`{ f: i32, g: i32 }`), but mono pins the instance at the declared `G`, so the literal is built at
`G`'s one-field row and `o is H` reads false. Which change moved the instance back to the declared
row is not yet bisected. D14160's own row still grades as filed because its witness' `// PRINTS`
line is only read for a silently-wrong row.
