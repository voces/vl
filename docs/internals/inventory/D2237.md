#### Mechanism

Not yet located. The hole parameter `a` is pinned to the argument's inferred type, a list of an
anonymous `{ x: i32 }` shape joined with `null`. The list itself is served (`a.length` prints
`1`), so the parameter's slot holds the right wrapper; what is missing is the element's struct
row when `a[0]` is read inside the instance. The ANNOTATED spelling of the same type, bound
first and then passed, runs, so the two spellings of one type disagree about the element's rep
at the pin: print the rep of both before choosing a site.
