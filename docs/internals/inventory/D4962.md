### D4962 — an instance's `is Q[]` over an empty list of another record type is false

**closed 2026-10-15 — now prints `10` then `1` · was check-clean silently wrong value, clause 1 · D4771 says an empty list fits every arm · two records are list-disjoint when the tested one names a field the other lacks, so the test is the D4910 emptiness test and the arm reads an empty `Q[]` · a `.map` callback over that receiver is [D4993](D4993.md), an anonymous tested record [D4994](D4994.md), a `for` over the list once a push in the arm grew it [D4995](D4995.md) · pins: `tests/cases/generics/is-list-arm-record-other-record.vl`, `is-list-arm-record-push-through.vl` (a push through the arm, with D4934) · filed 2026-10-15 against branch `d4934-empty-arm-push` over master `e2efbc0af`**

Repro:

    type P = { x: i32 }
    type Q = { y: string }
    function g<V>(a: V[]) {
      const q: V[] = []
      if q is Q[] {
        print(q.length + 10)
      }
      print(a.length)
    }
    const ps: P[] = [{ x: 1 }]
    g(ps)
    // PRINTS 1

Want:

    10
    1

#### Mechanism

`listDisjointDepth` (typecheck.vl) reported a depth only for a primitive leaf against a
primitive or a list, so `P` against `Q` had none, and `emitListEmptyFitIs` left the test to
`monoStaticIsResult`'s fold, `false` at `V = P`. The scalar spellings (`q is f64[]` over an
`i32[]`) entered the arm since D4911.

#### Close

A record lacking a field the tested record names can never fit it, since a record value is
built at its declared shape, so `listDisjointDepth` answers that depth too. Three pieces the
record pair needed and the scalar one did not: the empty `Q[]` the arm reads gets a ref-list
row when `Q` is declared, even when nothing else builds one (`forceListLeafRepsOfTy`), a read of the receiver in the
arm names that row (`refListElemNameOfExpr` asks `listFitShadowRow`), and a `for` over it is
not emitted, since its loop slots are typed at `P` and the list never iterates unless a push in
the arm grew it (D4995). A nonempty
`P[]` stays false, a record carrying every field of `Q` keeps the old answer, and a
`V[] | i32` receiver holding an empty `P[]` fits (D4912's arm test). A closure reading `q` in
the arm, which printed `1` the same way before, reads the same list (D4935). A push
through the arm (D4934) reserves its frame at `Q`'s row (`recordFitPushSlot`).
