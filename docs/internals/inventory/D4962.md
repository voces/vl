### D4962 — an instance's `is Q[]` over an empty list of another record type is false

**check-clean silently wrong · clause 1 · D4771 says an empty list fits every arm, and the arm is skipped · the same before and after the D4934/D4935 close · filed 2026-10-15 against branch `d4934-empty-arm-push` over master `e2efbc0af`**

Repro:

    type P = { x: i32 }
    type Q = { y: string }
    function g<V>(a: V[]) {
      const q: V[] = []
      if q is Q[] {
        print(q.length + 10)
      }
      print(a.length)
    }
    const ps: P[] = [{ x: 1 }]
    g(ps)
    // PRINTS 1

Want:

    10
    1

#### Mechanism

Not ablated. The scalar spellings (`if q is f64[]` over an `i32[]`) enter the arm since D4911;
this record pair does not, and a closure reading `q` in the arm prints `1` the same way.
