### D15253 — emit decides a literal `is` pattern from its text, not from the checker's tested type

**closed 2026-11-04 by lane column-G1 · runs, prints `true`, `false`, `false` · emit read the pattern's text at four literal-test sites · residue of [D15250](D15250.md) · filed 2026-11-04 against master `306ef2b8f` by lane column-G1**

Repro:

    function g<T>(x: T) { x is 2 }
    print(g(2))
    print(g(3))
    print(g("s"))
    // vl run: true, false, false

#### Mechanism

D15250 moved the variant row an `is` names onto the checker's tested type (`isTestedRowOf`).
Three emit sites still read the pattern's own text (`IsExpr.isVariant`) to tell a literal
pattern apart, a fact the tested type already carries:

* `wasmEmit.vl`, the literal-box arm before `emitIsTestNumLit`: `primNameStr(...) == isVariant`
  picks the literals of a base scalar (`x is i32` over `1 | 2 | "a"`, D3522).
* `wasmEmit.vl`, `emitIs`: `isLitVariantName(isVariant)` sends a literal pattern to
  `emitLitMemberEq`, which compares the receiver to that text.
* `emit_sections.vl` and `emit_fn_scans.vl`: a pattern whose text starts with a quote is a string
  literal.

#### Progress

The first two sites read stamps (2026-11-04, lane column-G1). The literal pattern is
`isTestedLitLex(isVarTyIx)`. The base-scalar test reads the pattern's own type, `isPatTyIx`, which
`checkIsExprNode` banks beside the meet: `x is i32` over `7 | 1` is met to `1`, so `isVarTyIx`
cannot tell it from `x is 1`. Probed over the 7,770 files with an `is`: 0 disagreements at either.

The string pool (`strPoolIsTest`) and the scratch-frame scan (`exprHasStrOp`) then read the
pattern's own type too: a string literal set, named or spelled out. Their text tests had excluded
a NAMED set, which cost it the inline compare: `x is K` called `__str_eq__` once per member where
`x is "a" | "b"` compared inline. That was a missed inlining, not a mis-staging, since both
spellings printed alike. Pinned by `tests/vl_named_litset_inline_test.ts`.

Adding a receiver test to the scan was measured and refused. Neither `nodeTyComparesAsString`
(the template's type) nor `exprString` (the instance's) counts a box with a string arm, whose
payload compare is a string compare, so either one dropped staging there and turned 9 inline
compares into calls.

#### Witness

The witness first filed here reached none of the four sites: an earlier rung decides both of its
tests. The witness above reaches the literal arm. One build per site, over the 7,770 files with an
`is`: the literal arm is reached by 6, the base scalar arm by 1
