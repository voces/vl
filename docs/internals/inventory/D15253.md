### D15253 — emit still reads an `is` pattern's text beside the checker's tested type at six sites

**runs today and must keep running · residue of [D15250](D15250.md) · filed 2026-11-04 against master `306ef2b8f` by lane column-G1**

Repro:

    type K = 1 | 2 | "a"
    function f(x: K) {
      if x is i32 { print("num") } else { print("str") }
      if x is "a" { print("is a") }
    }
    f(1)
    f("a")
    // vl run: num, str, is a

#### Mechanism

D15250 moved the variant row an `is` names onto the checker's tested type (`isTestedRowOf`). The
emitter still compares the pattern's own text (`IsExpr.isVariant`) at these sites, each a fact
the checker could stamp instead:

| site | what the text decides |
| --- | --- |
| `wasmEmit.vl`, `emitIsTestLitArms`' tail: `primNameStr(...) == isVariant` | `x is i32` over a literal box tests the literals of that base (D3522) |
| `wasmEmit.vl`, `emitIs`: `isLitVariantName(isVariant)` | a literal pattern compares the receiver to that literal |
| `wasmEmit.vl`, `monoStaticIsResult`: `sk == isVariant` | a sigkey pin's function-type test (D951) |
| `emit_rewrite.vl`: `isVariant == tyToStr(s)` | a narrowed read's present arm |
| `emit_sections.vl`, `emit_fn_scans.vl`: a quoted leaf | the pattern is a string literal |
| `== "null"` across `wasmEmit.vl`, `emit_atom_kinds.vl`, `emit_rewrite.vl` | the pattern is `null` |

#### Grading list

The witness, and every `is` fixture under `tests/cases/`: none may change outcome when a site
moves to a stamp.
