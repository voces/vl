### D17700 — [CLOSED 2026-11-27] a named function's closure stored into a map slot holding a bundle record is refused at the bundle's store

**closed 2026-11-27 · runs, prints `true` · fixed in emit_elab.vl: `elabSlotRecordNote` takes a typed named function whose signature is one of the slot record's members as a producer of the record (`elabWrapFnOf`); in ir_build.vl: `deliver` and the map store build it as that record (`bundleWrapBuild`), its closure in every field, the other members unreachable by typing (coordinator ruling, bundle-record unit (e)) · pins `maps/named-fn-stored-beside-bundle-record-positions.vl` · a call at the other signature is [D17726](D17726.md) · was loud emit reject · clause 2 · `vl check` rc 0 · `emitProgram: a function returning a parameter called at two signatures is called where its result is not used at one of them` at the bundle's store · the named-function face of [D17572](D17572.md) · filed 2026-11-26 against master `58ea7ebb6` by SOUND**

Repro:

    function lap(f) {
      const _a = f(2.5)
      const _b = f(3)
      return f
    }
    function dbl(a: f64): f64 { return a * 2.0 }
    const m = Map()

    function g() {
      m["b"] = dbl
      return m.has("a")
    }
    print(g())
    // vl check: rc 0.  vl run: emit error at `lap(`, "a function returning a parameter called at two
    // signatures is called where its result is not used at one of them"

Want:

    true

#### Mechanism

The map's slot holds `lap`'s record of one closure per signature (`(f64) => f64`, `(i32) => i32`).
D17572's producer rule builds a hole lambda written into such a slot as the record, instancing it at
each signature; a named function's closure is no such producer, so `elabSlotRecordNote` declines the
slot and the bundle's store is refused. An un-annotated named function could be instanced at each
signature as the hole lambda is; an annotated one, as here, has one signature and no member at the
other, so the record needs a closure per signature built from it, or the slot a union of the two
shapes. The claim-fallback tests' refused control (`tests/ir-claim-fallback/closure-stored-from-function-refused.vl`)
is this program.
