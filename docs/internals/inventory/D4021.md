### D4021 — two parameters of one declared record type both handed wider records are refused

**open · loud check reject · clause 2 · found by the #3516 review (w25) · filed 2026-10-11 against master `4d0501a9e`**

Repro:

    type Pos = { x: f64, y: f64 }
    type A = { k: i32, y: f64, x: f64 }
    type B = { y: f64, s: string, x: f64 }
    function d(p: Pos, q: Pos): f64 { p.y = p.y + 1.0; p.x - q.x }
    const a: A = { k: 7, y: 3.0, x: 10.0 }
    const b: B = { y: 30.0, s: "q", x: 1.0 }
    print(d(a, b))
    print(d(b, a))
    print(d(a, a))
    print(a.y)
    print(b.y)
    // vl check: an object value of shape A flowing into Pos drops the field `k`

Want:

    9
    -9
    0
    5
    31

#### Mechanism

D3992 passes a wider record to a declared record parameter by making that parameter generic,
and declines a parameter whose type another annotation of the signature names, since one
rewrite cannot retype both. `q: Pos` names it, so `dist(p, q)` — the common two-record case —
keeps the width refusal. Rewriting every parameter that shares the type, each to its own type
parameter, would serve it.
