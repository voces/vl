#### Mechanism

S1 (D3678) inlined record FIELDS; an array of `(ref null $V3)` still stored references. The
`-O`/`-O3` host step now flattens such an array to `(array (mut f64))` at three times the
length when its record qualifies as S1's does, its fields share one number type, and every op
on the array type is one the step rewrites (`scripts/vl-host/src/flat.rs`). Map value lists
share the backing type and flatten with it. A store takes the stored value apart where it is
produced, so the producer's call gets a multi-value twin. sunpa `ce4e1c3`'s feet check
allocates 37,120 `Q` boxes where it allocated 601,198, output identical.
