#### Mechanism

S1 (D3678) inlines record FIELDS; an array of `(ref null $V3)` still stores references. S2
flattens such an array to `(array (mut f64))` at three times the length: every array op on
the type rewritten (`array.new*`, `array.get`/`set`, `array.copy`, `array.len`, `array.fill`),
map value lists included. The design measures push+iterate 1.4–2.0x faster on V8 and
5.8–8.2x on wasmtime, but an iterate-only loop 1.1–1.7x SLOWER (three bounds-checked
`array.get`s instead of one), so it waits for sunpa's per-frame split of list against field
stores.

#### Grading list

The witness at `-O`/`-O3`; a list built once and read many times must be measured before and
after, since that is the shape S2 can slow down.
