### D3357 — a join of two list parameters `T[]`/`U[]` read through an element builds invalid wasm at a nullable pin

**runs · CLOSED 2026-10-27 by building the element read's narrowing chain at the type its instance substitutes, folded, and un-gating the kept-apart join over list parameters; pinned by `tests/cases/generics/list-param-join-nullable-element.vl` and `tests/cases/generics/join-gated-list-and-lambda.vl`. Was: loads then traps · clause 1 · invalid wasm on master `88beda4cf` and `78abe1318`, a null-reference trap once the join binding took the cell of its instance type `(string | null)[]` (step 7 slice 3), and a check reject on the returning spelling (`got string | null | string | null`) · found by the #3310 round-2 re-review (`rv3310r2-Q7ZK/x/t6.vl`, `t7.vl`, `pf6.vl`, `pf9.vl`) · filed 2026-09-30**

#### Mechanism

The two lists join apart as `T[] | U[]` (D2760), and the element read `r[0]` rewrites to a
narrowing chain whose arms join `T` with `U`. Two facts were read at the template instead of the
instance:

* The substitution kept `T | U` at `T, U := string | null` nested
  (`string | null | string | null`), by a carve-out for a join of bare type parameters no
  annotation wrote. That nested union is not a `TyNullable`.
* The chain's blocktype asked whether the join can yield `null` of its template type `T | U`
  (`nodeTyIsNullable`), which never is. So every arm was built non-null, a `ref.as_non_null`
  over the nullable element, and the join's `null` trapped.

The close deletes the carve-out, together with the annotation table only it read
(`annUnionTys`), so the substitution folds to `string | null`. `ifLinkYieldsNull` now reads
the join's type at the instance (`nodeTyAt`). With both in place, the kept-apart join of
D3268 no longer needs gating off in a body taking a list of a type parameter, and that gate
in `tyParamOfInnermostBody` is deleted too.

Lifting that gate let the kept-apart join reach a `K | null` element bound to a local, which
the box's atom arm refused (`literal-union string widening with no members`) in an instance
whose function declares no return: a parameter test there overwrote the local's answer. A
local now keeps it, as it already did in a function with a declared return.
