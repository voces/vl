### D2685 — a later same-named un-annotated list literal in one function scans the whole program for its destination

**closed 2026-09-26 — runs today and must keep running · the defect was its cost, which the grader does not measure: the self-compile of `compiler/` with its 432 redundant annotations removed (the 23 `const out: i32[]` in `ast.vl`'s `nodeChildren` among them) cost 88.18G fuel on master against 51.68G for master's own source, and 51.15G after; `tests/vl_scaling_shape_test.ts` "un-annotated list literals" is the gate (14.13 on master, 1.13 after, bar 2.5) · filed 2026-09-26 against master `f8709e41c`**

Repro:

    type U = i32 | string
    function kids(n: i32): i32[] {
      if n == 0 {
        const out = [n, n + 1]
        return out
      }
      if n == 1 {
        const out = [n, n + 2, n + 3]
        return out
      }
      const out = [n]
      out
    }
    print(kids(0).length + kids(1).length + kids(2).length)
    // prints 6; each `const out` after the first cost one walk of every node in the program

#### Mechanism

The emitter asks every un-annotated non-empty list literal whether a declared destination
re-types it (`letRefListDestSlotK`, D381), walking only the binding's scope (D661). The scope
came from `dsScopeRootOf`, which knew a function body only when `parentLetOf(body, name)`
answered this very binding — true for the FIRST `const out` in a function and for no later
one, since `parentLetOf` answers the first. Every later binding fell to the whole-arena
fallback: `dsDestSlotAt` at every node of the program, and at every call `g(out)` anywhere
in it, `fnParamKindListSlot`, itself a whole-arena scan. So each such literal cost the
program (about 1.6G fuel in the compiler's own `nodeChildren`, 23% of that build in
`fnParamKindListSlot`). Closed by rooting a later binding's walk at the block that holds it
(`parentLetOwnerOf`, the plan's own owner column), which is the binding's whole scope. The
inferred types and the emitted code are unchanged: the candidate reproduces master's seed
from master's source byte for byte, and from the annotation-stripped source too.
