### D2525 — a `(T | null)[]` over a type parameter was refused on the generic original's own annotation, before any instance bound `T`

**closed 2026-09-25 — the filed repro RUNS and prints `7` · was a loud emit reject, `emitProgram: a nullable-V list element has no rep; use a non-null element type` · clause 2 · found building `std:idtable` (collections Q4) · filed 2026-09-25 against master `ca544493e` · fixture `tests/cases/generics/nullable-type-param-list.vl`**

Repro:

    function at<V>(xs: (V | null)[], i: i32): V | null {
      if i < 0 || i >= xs.length { return null }
      return xs[i]
    }
    const s: (i32 | null)[] = [null, 7]
    print(at(s, 1) ?? -1)

#### Mechanism

`collectA`'s ref-array rung classifies the annotation `(V | null)[]` of the generic ORIGINAL,
whose element names the type parameter itself. Its kind-2 element is a two-part nullable that is
not a value union, so the rung refused it as a niche with no list rep. The original is never
emitted: each instance re-runs the pass over its substituted spelling. `genTyParamArr` already
skips `T[]` for this reason but declines every ref-array name, so it never saw the nullable
spelling. The fix adds its nullable twin, `genTyParamNulArr`, as a rung ahead of the ref-array
rung. The instances then build wherever `V | null` is a box (`i32`, `i64`, `f64`, `f32`, an integer
literal union) or a nullable reference (a record, a nullable record, a list, a map). Where it is a
NICHE (`string`, `boolean`, a literal union of strings, a function type) the instance's element
reads take the template's rep — a push of `null` trapped at `string` and `boolean` was invalid
wasm — so `monoNicheNulListCheck` refuses those instances with the original sentence, naming the
bound type.

The refused set, exactly, each loud with `a nullable-<T> list element has no rep`:

* at any position, `T` a `string`, a `boolean`, a literal union of strings or a function type
  (`monoNicheNulListCheck`);
* at any position, `T` a union of records (`Circle | Square`): the instance annotation
  classifies by name as a union box, which the ref-array rung still refuses (the concrete
  `(Sh | null)[]` runs because its node carries an arena type);
* inside a generic that declares a lambda, `T` a list or any union, including an integer literal
  union (`monoCurHasLam`, `monoLamNulUnionListCheck`): the closure's capture read the element at
  the template's rep, invalid wasm for lists, and the literal-union twin is D2535's concrete defect;
* a generic record alias's `(T | null)[]` field applied at a generic application
  (`Bx<GB<i32>>`, and so `IdTable<GB<i32>>` and `IdTable<IdTable<Tex>>`), where a list literal
  holding `null` built its elements at the wrong rep (`gaeNulParamListAtApp`).

Measured by #3168's review grid (23 value types × 7 positions, 161 cells): 88 run, 73 are
loud, 0 are silent; master ran none of them.
