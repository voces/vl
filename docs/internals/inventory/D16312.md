### D16312 — an element read of a list of a nullable union with a ref member, inside a function, binds a non-null local the nullable element does not fit

**check-clean invalid wasm · clause 1 · bucket (f) · 2 of the 16 unsound fuzz findings of 2026-11-14 · filed 2026-11-14 against master `fe9585a72`**

Repro:

    function useIt(p: (string[] | i32 | null)[]) {
      const t0 = p[0]
      print(t0 == null)
    }
    useIt([["ftr"]])

Want:

    false

#### Mechanism

The list stores each `string[] | i32 | null` element as a nullable union-box ref, `null` being a
null ref. The local the read binds is declared at the non-null box, `(ref $box)`, so the element
does not fit it and the module fails to validate inside `useIt`. A global binds a nullable cell, so
the same read at the top level runs. Without the `null` member, or without the scalar member (a
`string[] | null` list is no box), the element and the local agree.
