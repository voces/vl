### D15247 — a function's record result delivered beside an own-type binding to a record that stores a number wider behind `| null` passes check

**open · check-clean invalid wasm · `type mismatch: expected (ref null $0), found (ref $4)` · clause 1 · the checker owes the refusal its plain spelling gets · found grading D15214 · filed 2026-11-04 against master `39579d12f`**

Repro:

    type J = { f: f64 | null }
    type K = { j: J }
    function mk() { { j: { f: 4 } } }
    const _k: K = mk()
    const y = mk()
    print(y.j.f)
    print(_k.j.f ?? 0.5)

#### Mechanism

A record shared between an own-type binding and a destination that stores a number wider has no
conversion, and the checker refuses it: `{j: {f: i32}} is not K: they store field `` differently,
and a record is shared, not copied` for `J = { f: f64 }`. The refusal does not look through
`| null`, at a top-level field, an inner one or an outer one, so the delivery passes check and the emitter
hands `K` a record of `mk`'s own row.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `\| null` on `f` (`J = { f: f64 }`) | loud check reject | **yes** |
| `\| null` on `f`, with `K = { j: J \| null }` instead | still invalid wasm | no |
| `const y = mk()` | runs | **yes** |
| the nested record (`K = { f: f64 \| null }`, `y.f`) | still invalid wasm | no |
