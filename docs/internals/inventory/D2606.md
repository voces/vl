Repro:

    // vl check: rc 0.  vl run: invalid module, inside `main`:
    // "type mismatch: expected i32, found (ref $type)"

#### Mechanism

An un-annotated captured binding is typed for its env field (`captureValKind`) from its
initializer, in a frame whose locals are not registered, so a copy of a local falls to the
`i32` default. D2598's `synthCaptureReadAnns` writes the annotation first, but only for a
narrowed read to a scalar arm and for a nullable list. A value union's box, and a string or list
narrowed off a nullable, got none. A third face: when a closure also writes the copied binding,
`captureBoxRewrite` has already replaced its read `x` with the cell read `x[0]`, which carries no
type, so even the scalar-arm synthesis declined. The close records each replaced read's checker
type (`cboxReadTy`) and synthesizes the copy's annotation from the recorded type for a value
union, a narrowed string or list, and a nullable list (`synthCaptureCopyAnn`), and the arm
annotation through a cell read (`synthCellNarrowedReadAnn`).
