### D2901 — a list literal of a local holding a nested lambda's `string | null` result refuses at a hole pin

**closed 2026-09-27 — the filed repro prints `n` · was loud emit reject, clause 2, the same on master `a41bd80e8` · closed by [D2899](D2899.md)'s rung, which annotates the list literal at its nullable element list and re-makes it at that type · fixture `tests/cases/generics/hole-list-literal-local-nullable.vl` · found working [D2854](D2854.md) · filed 2026-09-27 against master `089c6ff56`**

Repro:

    function mk(x) {
      const g = (z) => z
      const r = g(x)
      const xs = [r]
      return xs[0]
    }
    const vn: string | null = "n"

#### Mechanism

Not localised. The local `r` is typed at the lambda instance's `string | null` result, while the
literal `[r]` is typed at the hole's variable; the emitter builds a string-list literal and finds
no string-list row collected for it. `[g(x)]` with no local, and `[x]`, run.
