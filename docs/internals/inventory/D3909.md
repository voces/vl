### D3909 — a generic function stored as a value at a type built from an enclosing generic's T traps with `indirect call type mismatch`

**closed 2026-10-09 by lane SC · runs · was loads then traps · found in review of #3478 (`rv3478c/p4`–`p6`: y02, y07, y10, y11, x08) · filed 2026-10-09 against master `097937914` · pins: `tests/cases/generics/generic-function-value-in-list-per-instance.vl`, `tests/cases/generics/generic-function-value-in-generic-alias-record-field.vl`, `tests/cases/generics/generic-function-value-stored-after-construction.vl`**

Repro:

    type R<V> = { f: (v: V) => void }
    function b<U>(y: U) { print(y) }
    function a<T>(x: T) {
      const fs: ((t: T) => void)[] = [b]
      const r: R<T> = { f: b }
      fs[0](x)
      r.f(x)
    }
    a(false)
    a("s")
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch

Want:

    false
    false
    s
    s

#### Mechanism

Three gaps on one path: a generic function delivered as a value inside a generic body.

1. **Shared node.** An instance body is a copy-on-write clone, so a value `Ident` naming `b` in a
   list element, a field or a binding was one node for every instance of `a`. Each instance
   renamed it to its own `b` instance, and the last rename won for all of them (D2854's shape,
   which copied callees only). Closed: `monoCloneGenericCalls` copies such an `Ident` per instance.
2. **Generic alias field.** `monoStructFieldTypes` looked a record type up by exact declaration
   name, so `R<string>` found no fields and `b` in `{ f: b }` lowered with `U` unbound (an empty
   one-parameter function). This traps at one instance. Closed: `monoGenAliasFieldTypes` reads the
   alias's fields substituted at the application's arguments.
3. **Stores after construction.** `fs[0] = c`, `gs[1][0] = c`, `r.f = c`, `fs.push(b)` and a
   nested literal `[[b], [c]]` read the slot's type off the checker's record, which still names
   `T` inside an instance, so nothing coerced the value. These also trap at one instance. Closed:
   `monoStoreAnnName` reads the slot's type from the local binding's annotation as the instance
   spells it, through each index and field, and a list literal whose element is a list or a record
   is coerced element-wise.

The matrix (`~/.claude/vl-tools/generators/d3909_fnvalue_positions.py`): 17 positions × a nested or
top-level `b` × one, two and three instances. 68 of 102 cells trapped or refused on master and
now print the right output. The other 34 already ran, or refuse loudly as before (D3912, D3913).
