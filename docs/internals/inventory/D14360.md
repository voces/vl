### D14360 — a module `let` with no initializer, read through a function before its first write, reads the cell's zero

**resolved 2026-10-26 by D2652's guard, positioned where the binding is assigned (`daTopAssignedAt` in `compiler/check_definite.vl` names the first top-level statement after which the checker finds it assigned on every path; `initAtCompute` in `compiler/emit_sections.vl` makes that the binding's position and numbers the progress cell by it) — the witness now loads then traps with "`i` read before its initializer ran (line 1), via readI" · was check-clean silently wrong, printing `0` · clause 1 · the no-initializer face of [D2652](D2652.md), reachable since [D14281](D14281.md) gave the binding a cell · a read inside the assigning statement itself is [D14361](D14361.md) · filed 2026-10-26 against master `bcfaf4328` · fixtures `tests/cases/globals/read-before-assign-*-traps.vl`, `read-unassigned-at-top-level-traps.vl`, `read-after-assign-unaffected.vl`**

Repro:

    let i: i32
    function readI() { return i }
    print(readI())
    i = 2

#### Mechanism

The checker's definite-assignment pass orders a write before every read in top-level code,
but not before a read inside a function body, which may run at any call. D2652's guard
covers that read for a binding with an initializer: the start function advances a progress
cell past the declaration, and a read checks it. A binding with no initializer had no such
point, so `gInitGuard` stayed 0 and the read returned the cell's zero default. Its point is
now the first top-level statement after which the checker finds it assigned on every path
(none when only a function assigns it: the checker refuses a top-level read after such a
call as well).
The progress cell numbers globals by that position rather than by declaration, so a guarded
global declared between the binding and its assignment cannot carry the cell past it.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the scalar type (`let s: string`) | trapped `null reference`, loud, naming no binding | yes, for the silent outcome |
| the read inside a function (`print(i)` at top level) | check reject, used before assigned | **yes** |
| the call before the write (`i = 2` first) | runs, `2` | **yes** |
