#### Mechanism

`destAdopts` (`check_statements.vl`) requires one leaf of the destination to narrow the
literal's own type, because a filled literal with none is that type already. An empty list is a
hole, not its `i32` default, so the reason does not hold for it, and the hole keeps the
default where the destination names `{r: i32}`.
