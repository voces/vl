### D2855 — a generic record join `{a: t}` beside `{a: 1}` at a string pin builds invalid wasm

**check-clean invalid wasm · clause 1 · found grading D2809's string twin · the same on master `721781075` · filed 2026-09-27 against master `721781075`**

Repro:

    function h<T>(c: boolean, t: T) {
      if c { return { a: t } }
      { a: 1 }
    }
    const r = h(false, "x")
    print(1)
    // vl check: rc 0.  vl run: invalid module inside `h` — type mismatch: expected i32,
    // found (ref $type)

#### Mechanism

Not localised past the ablation. The record join of `{a: T}` and `{a: i32}` is built as one
record at the pin, as at `T := boolean` ([D2809](D2809.md)), but there the two fields share the
i32 storage and the value is merely misread; at `T := string` the string ref is stored into the
i32 field. The concrete spelling (`t: string`) joins to a record whose field is the union and runs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the type parameter (`t: string`) | runs, `r.a is string` answers false for the `1` arm | **yes** |
| the read of `r.a` (`print(1)` only) | still invalid wasm | no |
| the string pin (`T := f64`, `h(false, 2.5)`) | loud emit reject, `object literal field count does not match struct` | **yes** |
| the string pin (`T := boolean`) | runs, prints `true` for the `1` ([D2809](D2809.md)) | **yes** |
