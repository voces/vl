### D16980 — a record field typed as a union of nested lists that spell one list interns no ref-list slot for the field

**loud emit reject · clause 2 · found closing [D16969](D16969.md) · filed 2026-11-18 against master `f87150f71` by lane F1**

Repro:

    type K = 1 | 2
    type R = { g: i32[][] | K[][] }
    const r: R = { g: [[3, 4]] }
    print(r.g[0][1])
    // vl run: emitProgram: ref-list field element type is not interned

Want:

    4

#### Mechanism

A binding annotated `i32[][] | K[][]` is stored as the one list `i32[][]` (D16969). A record
field typed that way reaches the struct layout as a ref-list field (`FC_REF_LIST`) whose slot no
field-table pass resolved, so `pushFieldStorage` refuses. The field's slot is looked up from the
field's own union type, not from the one list it is stored as.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the field `i32[][]` alone | runs, prints `4` | **yes** (the union) |
| the field `K[][]` alone | runs | **yes** (the union) |
| the field spelled through `type A = i32[][] \| K[][]` | the same reject | no |
| the field handed a bound `i32[][]`, not a literal | the same reject | no |
| the field `i32[] \| K[]`, one level | runs | **yes** (the nesting) |
| the union as a binding, not a field | runs (D16969) | **yes** (the field) |
