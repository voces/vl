### D15772 — a hole function's `const` record read twice, handed on and called through its field at another type, is refused at emit

**loud emit reject · clause 2 · `emitProgram: a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type` · found closing D15639 · filed 2026-11-12 against master `04fad9d17`**

Repro:

    function id(v) { return v }
    function call0(r, x) { print(r.f(x)) }
    function run(g) {
      print(g(5))
      const r = { f: g }
      call0(r, "s")
      print(r.f(true))
    }
    run(id)

Want:

    5
    s
    true

#### Mechanism

`inlineConstRecArgs` (D15700) writes a `const` record into its argument only when the binding
is read once, so with a second read (`r.f(true)`) the binding stays a record of closures and
`call0`'s hand-on reaches no call that fixes the hole's type. Unmeasured beyond that.

#### Ablation

| spelling | outcome | needed? |
| --- | --- | --- |

| the hand-on `call0(r, "s")` removed | runs, `5` `true` | **yes** |
| the second read at the direct call's type, `r.f(7)` | still refused (a check reject on master) | no |
