### D2783 — a two-list pinned result that escapes its call or binding is read as the one list the checker typed

**closed 2026-09-27 — the filed repro runs, reading `.length` off each member since [D2874](D2874.md); the one-list uses (a `string[]` argument, binding or return, `push`) stay refused · was check-clean invalid wasm · the checker types the call as the pinned union, so its own rules refuse every one-list use · the #3207 round-3 review · filed 2026-09-27 against master `f6db92e0d` · fixture `tests/cases/generics/error-return-join-two-lists-escapes.vl`**

#### Mechanism

The checker types `h(true, "s")` as `string[]`, while the instance returns `string[] | i32[]`
(D2766). #3207 refuses a use that needs one list only where it can see the call: the call
itself, or an un-annotated binding of it. The gate is syntactic, so every other route by which
the value reaches a one-list reader is read as a `string[]` and builds invalid wasm. These are
an alias (`const r = q`), `for v in h(…)`, and an argument to a non-generic
`f(x: string[])`. So are a `string[]` binding or return (`k(): string[]`, or a wrapper that
returns the call), a record field (`{ a: h(…) }`), `q.push`, `[h(…)].length`, and the else arm
of an `is` test. Every one is invalid wasm on master too. The fix is the checker typing the call
as the union, which D2766 leaves open.

Closed in the checker. In the return-set join (and its re-join at a pin), a declared type
parameter under a list or nullable is apart
from a concrete type (`tyParamBesideConcrete`), and a union holding such a member keeps a
concrete arm it would otherwise absorb (`tyParamArmAbsorbs`). The body's return is then
`T[] | i32[]`, re-joined at each pin as the direct join is (`tpJoinUnions`); a join inside the
body keeps the collapse its own reads are checked under (`tpApartConcrete`). The floor
for an inferred union return defers a union over a type parameter to the instance. The alias,
`for`, argument, binding, return, `push`, field and list-literal uses are refused with the
concrete spelling's sentences, and the `is` else arm and a union destination run.
