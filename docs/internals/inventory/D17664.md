### D17664 — a lambda handing a captured hole function a float, inside the hole function's instance, writes the call at the i32 default

**check-clean invalid wasm · 1 cell (the `rep unsup of call` position sweep of lane COV-CLOS) · clause 1 · filed 2026-11-26 against master `903f71519`**

Repro:

    function add(a, b) { return a + b }
    function app(g, s) { return g(s, s) }
    function p4(h) {
      const run = (x) => app(h, x)
      print(run(1.5))
    }
    p4(add)
    // vl check: rc 0.  vl run: invalid module inside `p4`: expected i32, found f64

Want:

    3

#### Mechanism

Not traced. `run` is instanced at its float argument, but the call `run(1.5)` in `p4`'s instance is
written at the i32 default its hole parameter would take, so the f64 argument meets an i32 slot.
