### D3528 — an annotated `A | B | null` binding read through `??` at a pin binding both parameters alike is built at the box's rep

**check-clean invalid wasm · clause 1 · open · the same on master `331f5e998` · found by lane LJ's grid (its `annif` and `annlam` shapes, 36 cells) · filed 2026-10-03 against master `331f5e998`**

Repro:

    function F<A, B>(k: i32, a: A, b: B) {
      const v: A | B | null = if k == 0 { a } else if k == 1 { b } else { null }
      print((v ?? 9) is i32)
    }
    F(2, 3, 3)
    // vl check: rc 0.  vl run: invalid module inside `F`, "expected (ref null $type), found i32"

Want:

    true

#### Mechanism

Not localised past the ablation. The annotation is a union of the parameters that the checker
did not build as a kept-apart join, so the `??` result is a deferred join `A | B`. At `(i32,
i32)` the binding is `i32 | null` and the `??` unboxes to `i32`, but the `is` reads the result
as the box. The un-annotated spelling, whose join is kept apart, runs.
