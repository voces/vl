#### Mechanism

A `string` became a header struct `{backing: (array mut i8), start, len, hash}` (#1845 slice
header, #1848 UTF-8 bytes, #1851 cached hash). Every hash probe and content compare now
reads the header and then the backing, one dependent load more than the flat array it
replaced. This is attribution by bisect: no ablation has separated the header load from
the UTF-8 compare.
