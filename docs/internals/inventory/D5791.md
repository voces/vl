#### Mechanism

From the ablation only. [D5751](D5751.md)'s close walks a call through an un-annotated `const`
hole lambda in the instance context mono builds for that call. A `let` binding is not taken
there, because it can be written, so the call is walked once in the lambda's declaring context
and the pin of `g(x)` stays open. Closing it needs the same walk for a `let` the program never
writes, or for each value a written one can hold.
