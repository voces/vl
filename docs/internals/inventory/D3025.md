### D3025 — a nested function whose parameter shadows a captured name takes the capture's cell when it calls a sibling that captures that name

**closed · was check-clean invalid wasm, identical on master `3a71bb1f9` · `shadowRespell` gives a binding its own spelling when a nested function reads it through another nested function whose parameter shares its name, and a parameter that needs one is copied into a respelled local, since a named argument matches the parameter's own spelling · the 120-cell grid (outer local, constant, parameter, loop variable, lambda and nested frame x read and write x six shadowing callers x two types) moves 40 invalid and 30 wrong cells to runs · fixture `tests/cases/closures/sibling-capture-beside-shadowing-param.vl` · filed 2026-09-28 against master `cac5e4ad5`**

Repro:

    function main() {
      let g = "a"
      function k() { print(g) }
      function inner(g: i32) { k(); print(g) }
      inner(5)
      print(g)
    }
    main()
    // vl check: rc 0.  vl run: invalid module, inside `inner`: type mismatch: expected (ref $type), found i32

Want:

    a
    5
    a

#### Mechanism

Not localised. `inner` calls `k`, which captures `g`, so `inner` has to carry `k`'s capture of
the outer `g` through to the call. Inside `inner` the name `g` resolves to its own `i32`
parameter, and that is what reaches the slot typed for the captured string. The capture is
passed on by name, where it should be passed on by binding: `capSiblingFrees` folds `k`'s
free `g` into `inner`'s frame, where the parameter binds it. The close respells the outer
binding so the forwarded name is its own.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| no call to `k` in `inner` | runs | **yes** |
| `k` a lambda (`const k = () => { print(g) }`) | runs | **yes** (a nested declaration) |
| `inner` a lambda | invalid wasm | no |
| `k` writes `g` instead of reading it | invalid wasm | no |
| `g` an `i32` (`let g = 1`) | invalid wasm | no |
| a narrowing of the outer `g` around `inner` | invalid wasm | no |
