### D3614 — the emitter resolves a block-local function over its whole frame, so a call outside its block calls it

**check-clean invalid wasm · open · filed 2026-10-04 by lane SC against master `c473889d1`, while grading D3608**

Repro:

    function k(): string { "mod" }
    function f() { if true { function k(): i32 { 2 }; print(k()) }; const s: string = k(); print(s) }
    f()
    // vl check rc 0; vl run: "the emitted module failed to validate inside `f`: type mismatch: expected (ref $type), found i32"

Want:

    2
    mod

#### Mechanism

The checker scopes a nested `function` to its block, so `k()` after the `if` is the module's
`k(): string`. The emitter resolves a callee name with `nestedFnOnChain` →
`nestedFnDeclaredIn` (`compiler/emit_classify.vl`). That walks the calling frame's nested
functions by name only, with no block and no position, so it finds the `if` block's `k` and
calls it. That is invalid wasm when the two signatures differ. When they agree it is a silent
wrong value: the same program with `function k(): i32 { 1 }` prints `2` where the checker typed
the module's `1`. The block half is independent of D3608's ruling, since under either answer the
block-local function is not visible after its block. The position half (a call ABOVE the
declaration) waits on that ruling.

#### Ablation

| spelling (module `k(): string`, nested `k(): i32`) | outcome on master |
| --- | --- |
| a call after the nested function's block | invalid module (this witness) |
| a call above it in its own block, bound to `string` | invalid module (ruling-dependent, D3608) |
| a lambda created above it, called after | invalid module (ruling-dependent) |
| a sibling nested function above it calling `k` | invalid module (ruling-dependent) |
| the two signatures equal | runs and prints the nested function's value (silently wrong under the checker's typing) |

#### Grading list

The fix is positional resolution in `nestedFnDeclaredIn`: a nested function answers a read only
inside its own block, and from its declaration on if D3608 rules (A). Grade the four spellings
above, in single and merged compiles.
