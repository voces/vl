### D17209 — a module inferred-null binding filled with a wider record literal than the record a function's join reads it beside builds invalid wasm

**check-clean invalid wasm · clause 1 · pre-existing, the same before and after #9975 · a sibling of [D17208](D17208.md), found by V4 verifying #9975 (LAF2) · owner IR-N4 · filed 2026-11-24 against #9975's head `915156c9e` and master `09e329d2b`**

Repro:

    type In = { v: i32 }
    const rec: In = { v: 9 }
    let m = null
    function pick(flag: boolean) { return if flag { m } else { rec } }
    m = { v: 4, k: 1 }
    print(pick(false)?.v ?? -1)
    print(pick(true)?.v ?? -1)
    // vl check: rc 0.  vl run: invalid module inside `pick`, "type mismatch: expected (ref null
    // $1), found (ref null $0)"

Want:

    9
    4

#### Mechanism

As [D17208](D17208.md), with the fill's record the literal's own `{v: i32, k: i32}` row rather
than a named `Sub`: the join is re-banked at `In | null`, and the arm's struct is not a declared
subtype of `In`'s.
