### D15265 — a record copied at its delivery has no copy for a number converted behind `| null`, or for a nullable record it holds

**open · check-clean invalid wasm · clause 1 · flat as well as nested · found closing [D15264](D15264.md) · filed 2026-11-04 against master `62165625b` plus the nested copy**

Repro:

    type K = { f: i64 | null }
    function mk() { { f: 4 } }
    const _k: K = mk()
    const y = mk()
    print(y.f)

Want:

    4

#### Mechanism

`mk` is read at its own row by `y` and delivered to `K`, which stores `f` as a nullable `i64`.
The converting copy (`recCopyConverts`) converts a number only where neither side is `| null`,
and copies a nested record only where the source's is never null (`recCopyNestable`), so neither
this delivery nor `K = { j: J | null }` handed `mk(false)`'s `{ j: null }` has a copy, and `_k`
is handed a record of `mk`'s own row. A nullable DESTINATION record is copied.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `f: i64` (not nullable) | runs (the delivery copies) | **yes** |
| `const y = mk()` removed | runs | **yes** |
