### D15265 — a record copied at its delivery has no copy for a number converted behind `| null`, or for a nullable record it holds

**closed 2026-11-11, runs and prints `4` · was a loud check reject, clause 2, `converting it into K is not yet supported: the converting copy does not reach a nested or nullable field` · closed by the copy gate widening a number into a nullable (`recNumWidens`, check_fit_rules.vl; `rcWidenTo`, wasmEmit.vl), with the fresh-call copy of #7200 · the nested leg, a nullable record field, is [D15717](D15717.md) · found closing [D15264](D15264.md) · filed 2026-11-04 against master `62165625b` plus the nested copy**

Repro:

    type K = { f: i64 | null }
    function mk() { { f: 4 } }
    const _k: K = mk()
    const y = mk()
    print(y.f)

Want:

    4

#### Mechanism

`mk` is read at its own row by `y` and delivered to `K`, which stores `f` as a nullable `i64`.
The converting copy (`recCopyConverts`) converts a number only where neither side is `| null`,
and copies a nested record only where the source's is never null (`recCopyNestable`), so neither
this delivery nor `K = { j: J | null }` handed `mk(false)`'s `{ j: null }` has a copy, and the
delivery is refused as the copy's gap. It lifts to `runs` when the copy reaches these fields. A nullable DESTINATION record is copied.

| --- | --- | --- |
