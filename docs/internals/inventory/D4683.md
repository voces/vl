### D4683 — a generic function returning a `.map` whose record has a field typed `T` has no element row

**closed 2026-10-14 — the witness runs and prints `6` · was loud emit reject · clause 2 · `.map` was scenery: the generic ORIGINAL's list-of-records annotation was validated as if concrete, and an instance's pinned one before the shape passes had interned its row, and an inferred list-local return was spelled with the checker's spaced render, which the shape interner cannot split · closed by skipping the original's annotation (`annArrOverTyParam`), deferring the instance's to `collectA#2`, and spelling the pinned list return by its row (`emit_mono.vl`) · fixture `tests/cases/generics/record-field-at-type-param-list-return.vl` · found while closing D2575 (`rep-descriptor-campaign.md` §13.16) · filed 2026-10-14 against branch `rep-l2-stage5`**

Repro:

    function wrap<T>(xs: T[]) { return xs.map((e) => { v: e, n: 1 }) }
    print(wrap([5, 6])[1].v)
    // vl check: rc 0.  vl run: emitProgram: only i32[] arrays and struct/union element arrays are supported

Want:

    6

#### Mechanism

Three steps refused one program. `collectA`'s first walk saw the generic original's list
annotation (`{v: T, n: i32}[]`, `W<T>[]`) and asked `checkArrName`, which skipped only a bare
`T[]`. The walk `monoRebuild` resumes saw each instance's pinned annotation before
`collectGenAliasShapes` and `collectAnnShapes` had interned its record. And an inferred return
of a list LOCAL (`const ws = [{ v: x, n: 1 }]; return ws`) was annotated with
`tyToStructStr`'s render, `{v: i32, n: i32}[]`, whose spaces `shapeInnerFieldSplit` cannot
split, so no row matched it.
