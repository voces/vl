### D4683 — a generic function returning a `.map` whose record has a field typed `T` has no element row

**loud emit reject · clause 2 · found while closing D2575 (`rep-descriptor-campaign.md` §13.16) · the same on the seed before that close · filed 2026-10-14 against branch `rep-l2-stage5`**

Repro:

    function wrap<T>(xs: T[]) { return xs.map((e) => { v: e, n: 1 }) }
    print(wrap([5, 6])[1].v)
    // vl check: rc 0.  vl run: emitProgram: only i32[] arrays and struct/union element arrays are supported

Want:

    6

#### Mechanism

Not yet ablated past the program. D2575's close names a `.map` result's row from the
callback's record during return inference; here the record's field rides `T`, so the row
the instance needs is only known at the pin, and the inferred return gets no element row.
