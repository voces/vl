### D4615 — a union arm with a nullable field of its own union has no struct-field rep, and the declaration alone refuses

**loud emit reject · clause 2 · found writing D4601's fixture · filed 2026-10-14 against master `56e06d91c`**

Repro:

    type Node = { v: i32, next: Node | null } | { e: i32 }
    const n: Node = { e: 1 }
    print(1)
    // vl check: rc 0.  vl run: struct field type `Node|null` has no struct-field rep

Want:

    1

#### Mechanism

The arm's field is the nullable of the union that declares it. The field-rep ladder has a rung
for a nullable record and for a field typed as the union itself, but none for the nullable of a
union still being declared, and the refusal fires while the declaration is collected, before
any value is built.
