#### Mechanism

The arm's field is the nullable of the union that declares it. `fieldCodeOfSpelling` asked the
spelling's binding rather than its key, and `Node|null` has no binding, so the declaration
refused while it was collected. Read by key it found the row, but canon spells the arm twice:
rolled (`next: Node | null`) and unrolled (`next: <Node's members> | null`, its tags softened).
The two keyed apart and minted two heap types for one arm, so a value built at one spelling
failed the other's `ref.cast`. The close folds a variant onto an earlier one with the same
layout whose arena type is equal once a lone literal compares as its base (`tyEqSoftLits`),
and keys the alias name to the row its unrolled member set registered.
