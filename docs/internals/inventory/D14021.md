### D14021 — a generic if-join whose pin widens a record field to a union has no struct row for that join

**trap after load · clause 1 · open · was check-clean invalid wasm until the emitter stored the `{f: t}` arm in the field's union box · split from [D14001](D14001.md) · filed 2026-10-26 against `lane/d14001-if-row` on `f6b07866f`**

Repro:

    function g<T>(t: T, b: boolean) {
      const v = if b { {f: 1} } else { {f: t} }
      print(v.f)
    }
    g("s", true)
    g("s", false)
    // vl check: rc 0.  vl run: wasm trap: cast failure at `print(v.f)` in the first call

Want:

    1
    s

#### Mechanism

At `T := string` the pin's join is `{f: i32 | string}`, a record no source position spells. The
emitter makes a row for a widened record join only when the checker set `recordJoinMinted`
(`recordJoinSeen`, read by `joinedRecordRowOf` and its siblings), and `joinTys` sets it only
after its type-parameter branches have returned. The template's join is `{f: i32 | T}`, so the
flag is never set for this program. Then no row exists for the pinned join, and the if
blocktype and both arms fall back to rows that do not hold an `i32 | string` field. The
non-generic `{f: 1}` / `{f: t}` with `t: string` mints the row and runs.

The producer is the checker's template join. It drops `{f: 1}` and types `v` as `{f: T}`, so
at the pin `v.f` is `string` and the read unboxes the field's box to `string`, a cast that
fails when the box holds `1`. The store side boxes both arms. `g("s", false)` alone runs.
