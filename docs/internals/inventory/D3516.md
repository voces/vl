### D3516 — `??` over a nullable mixed-width literal union with a narrow default is refused at check as the join `9000000000 | 1 | i32`, which an `i64` destination rejects

**loud check reject · clause 2 · open · found by the #3340 review · the same on master `878f6ebe8` · filed 2026-10-03 against master `878f6ebe8`**

Repro:

    type E = 9000000000 | 1 | null
    function g(x: E): i64 { x ?? 5 }
    print(g(null))
    // vl check: "expected i64, got 9000000000 | 1 | i32"

Want:

    5

#### Mechanism

Not confirmed. The `??` result joins the non-null members of `E` with the default's type, and the
default `5` joins as its softened base `i32` rather than as a literal, so the join is a union
with one non-literal member. That join no longer softens to an integer type (a literal union
with a primitive member is left alone), and the delivery into `i64` is refused. Under the
owner's numeric-join ruling a literal adapts, so `5` should adopt the destination; every member
then fits `i64`.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `x ?? 9000000000` (a wide default) | accepted, then invalid wasm (D3517) | **yes** (a narrow default) |
| `type E = 3 | 1 | null`, return `i32` | runs, `5` | **yes** (two widths) |
| `if x != null { return x }` then `5` | runs, `5` / `1` | **yes** (`??`) |

#### Grading list

`x ?? 5` into `i64` and into a `const w: i64` binding; `x ?? 5` into `E` itself; the
one-width set, which runs today and must keep running.
