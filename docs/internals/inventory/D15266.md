### D15266 — a call built wider and handed to a non-binding place, then written through the binding that place lands in, is built at the wider record

**open · check-clean invalid wasm · clause 1 · the positions [D15246](D15246.md)'s copy does not reach · found closing D15246 · filed 2026-11-04 against master `d8ba9c452`; its witness is invalid wasm with and without D15246's parked copy**

Repro:

    type J = { f: i32 | null }
    type K = { j: J }
    function mk() { { j: { f: 4 } } }
    const _k: K = mk()
    const xs = [mk()]
    const v = xs[0]
    v.j = { f: 5 }
    print(v.j.f)

Want:

    5

#### Mechanism

D15246's copy is decided at a call site that initialises a binding: the record solve copies the
call's result back to its own record when that binding is written through. A call handed to a list
element, an argument, a map value or set, an inferred return or a struct field initialiser is not a
binding's initialiser, so it shares `mk`'s build at `K`, and the binding the value is later read
into is written at its own row. The position matrix
`own-binding-of-wider-build-written.matrix.vl` grades these six positions SILENT: `argument`,
`array_element`, `map_value`, `map_set`, `return_inferred`, `struct_field_init`.

#### Returns, closed; arguments, measured

A call returned by a function is now asked through the function's call sites
(`recValueWrittenThrough`, which also answers the let-initialiser case), with the same copy back as
D15246, and `callBuiltTy` reads the copy at any call; the matrix's `return_inferred` cell runs, and
so does a recursive return (fixture `soundness/record-written-into-binding-of-returned-wider-build-runs.vl`).
Five positions remain SILENT. The `argument` cell (`__take(mk())` into a hole parameter) never
reaches the read-back arm: its site lands at the build through the hole parameter's queued
delivery. Deciding the copy there emits the copy at the argument, but the generic's instance is
still keyed at `K`: the call-binding row's rep types (`callBindRepTysAt`, read by
`callArgRepTy` and mono's `monoArgRepRowTy`) are produced while the call is checked, before the
record solve decides the copy. `__take(k)` handed an annotated `K` runs. The list, map and struct
field positions are the container phases.
