### D5230 — a binding aliasing a generic, delivered into an annotated `void` function type inside a module-scope block, emits a `drop` after the call

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · OPEN · 12 cells of the D5170 and D5171 matrices (the six annotated block positions of each) · found while closing D5170 and D5171 · filed 2026-10-17 against master `697de45d6`**

Repro:

    function gA<U>(u: U) { print(u) }
    const x = gA
    {
      const v: (s: i32) => void = x
      v(4)
    }
    // vl check: rc 0.  vl run: the emitted module failed to validate inside the module's top-level code: type mismatch: expected a type but nothing on stack

Want:

    4

#### Mechanism

The start function calls `v` by `call_indirect` at the `void` signature and then emits a
`drop`, as though the call left a value. The ablation puts it at the statement call through a
block-local binding whose value is an alias of a generic: neither a global `v` nor a block in a
function body does it. Where the `drop` is decided is not yet found.
