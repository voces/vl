### D15287 — a bound list of records spread into a list held at a wider record is check-clean invalid wasm

**closed 2026-11-04 · runs, prints `7` · was check-clean invalid wasm, `vl check` rc 0 · clause 1 · found closing [D15285](D15285.md), its bound spelling · filed 2026-11-04 against master `930a8aae` · re-scoped to the single-level spelling on closing: the original nested witness, a bound list of record LISTS, now lives verbatim in [D15370](D15370.md) · closed by a spread binding of a fresh list being delivered whole as the list, which adopts it as an annotated binding does: on the check side for an annotated receiver (`pushSpreadFreshList`), and at the pass end for a receiver built wider (`recHeldListSpreadAdopt`, refusing its other own-storage deliveries as D15237 does) · fixture `tests/cases/soundness/record-list-binding-spread-into-wider-list-runs.vl`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const xs = [mk()]
    const more = [{ f: 7 }]
    xs.push(...more)
    print(xs[1].f ?? 0)

Want:

    7

#### Mechanism

A fresh list binding delivered whole to a list of a wider record adopts that list
(`const w: J[] = more` runs). Spread into a push, it was delivered element by element at the
element type and never adopted, so `more` stayed `{f: i32}[]` and its records were handed to a
list of `J`.
