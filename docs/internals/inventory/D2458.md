### D2458 — an un-annotated declared function passed as a value to a generic HOF has no monomorphization pin

**loud emit reject · clause 2 · found reviewing #3152, filed 2026-09-25 against master `20651a88b`**

Repro:

    function show(a) { return a + 1 }
    function run<T>(cb: (T) => i32, v: T) { return cb(v) }
    print(run(show, 3))
    // vl check: rc 0.
    // vl run: emit error, emitProgram: monomorphize: unsupported argument type for `cb` in a
    // call to `run`.

#### Mechanism

Not yet located. `monoArgFnTypeName` builds the argument's function-type name from the
declaration's annotations and answers "" for an un-annotated parameter; the checker solved
`a` as `i32` (from `a + 1`), but that solution is not the name the pin reads.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `function show(a: i32)` | runs, prints 4 | the un-annotated parameter: **yes** |
| `show<U>(a: U)` | runs, prints 4 | **yes** |
| a lambda `(a) => a + 1` | runs, prints 4 (since D2426) | the declared function: **yes** |
