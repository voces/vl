### D2779 — a generic `T | string` pinned at a union that already holds `string` prints its union return through the wrong rep

**now a loud emit reject · clause 2 · was check-clean invalid wasm · found by #3208's review (item 2) · identical on master (invalid module) · filed 2026-09-27 against master `f6db92e0d`**

Repro:

    function f<T>(u: T | string): T | string { u }
    const x: i32 | string = 3
    print(f<i32 | string>(x))
    // vl run: emitProgram: print of a union value whose arms the tag dispatch cannot classify

#### Mechanism

At `T := i32 | string` the instance's return is spelled `i32|string|string`, a member list with
a duplicate that the print plan does not classify, so master fell through to `__print_i32__`
with the box on the stack. Since #3208 `print` refuses any union box it cannot classify rather
than print it as a scalar. A close dedupes the substituted union's members before the pin keys
it, so the return is the `i32 | string` union the direct spelling registers.

| --- | --- | --- |
| `string` in the pin (`f<i32>(x)`) | runs, prints `3` | **yes** |
| the `print` (`const y: i32 \| string = f<i32 \| string>(x)`) | not graded | no |
