### D2207 — a named function with a `u8[]` parameter, taken as a function value, emits a module that fails to validate

**check-clean invalid wasm · found by the std API review of #3064 · filed 2026-09-23 against master `6de01ea58`**

Repro:

    function w(p: string, d: u8[]): i32 { return p.length + d.length }
    const f: (string, u8[]) => i32 = w
    print(f("ab", [1, 2, 3]))
    // vl check: rc 0.  vl run: invalid module, `expected (ref $type), found (ref $type)`

#### Mechanism

Not yet ablated. The un-annotated binding `const f = w` fails the same way, while the same
shape over an `i32[]` parameter, or over a `u8[] | B` one narrowed in the body, runs and
prints `5`, so the packed `u8[]` parameter in the function-value signature is the suspected
ingredient.

#### Grading list

`const f = w` (no annotation); the call with an annotated `u8[]` local in place of the
literal; a `u8[]` RESULT in place of the parameter.
