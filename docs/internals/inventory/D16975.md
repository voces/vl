#### Mechanism

The argument check refuses the delivery as one a later write could widen: "a handle to it reaches
__show(…) on line 17, which this check cannot follow". The body only reads the map, and the
sentence names the check's own reach, not a contract.

The call's container demand admits a union of maps member by member
(`docs/internals/refactor-notes/2026-11-19-container-demand.md`). Past that check, the pin's re-check
cannot lower a union-of-maps read: `lmMembers` declines under `monoRecheckDepth`, so `a.has("k")`
refuses ("field 'has' is not on every member"). Read through `const v = a`, it passes `vl check`
and fails emit (`callee is not a function name`). That is why the delivery still refuses. The fix is
the map analogue of [D16897](D16897.md): the pin types the read, and its instance lowers it per arm.
