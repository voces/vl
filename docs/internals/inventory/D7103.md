### D7103 — a lambda written into a `let` a generic initialized, read into a list beside another instance of the generic, is invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · OPEN · found closing [D3978](D3978.md) · the same on master `6ca1ebc5c` · filed 2026-10-19 against master `6ca1ebc5c`**

Repro:

    function other<V>(v: V) { print("O"); print(v) }
    function main() {
      let k = other
      k = (n) => { print("L"); print(n) }
      const fs = [k]
      fs[0](3)
      other(true)
    }
    main()
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `main`: type mismatch: expected structref, found i32

Want:

    L
    3
    O
    true

#### Mechanism

Not located. From the ablation: the list element stores the lambda's value where a closure
record of `other`'s instance is expected, and only when `other` takes a second instance
elsewhere.
