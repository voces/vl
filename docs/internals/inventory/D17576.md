### D17576 — an un-annotated parameter delivered at its argument's build row is read into a record literal built at the parameter's binding

**closed 2026-11-26 · was check-clean invalid wasm · clause 1 · fixed in emit_elab.vl with D17660: a record literal whose field reads a parameter the key delivers at `#r.<i>` is built with that field at the row · fixture `tests/cases/records/hole-param-delivered-row-literal-field.vl` · filed 2026-11-26 against master `fa5d6e86e` by SOUND**

Repro:

    type J = { f: i32 | null }
    function mk2() { return { f: null } }
    const dA: J = mk2()
    function g(y) {
      const h = { w: y }
      return h.w.f ?? 7
    }
    print(g(mk2()))
    // vl check: rc 0.  vl run: invalid module inside `g`: expected `{f:null}`, found `J`

Want:

    7

#### Mechanism

`mk2()` is built at `J` and typed `{ f: null }`. The elaboration keys `g` at its hole binding
`{ f: null }` with D15173's delivered-row entry `#r.0` = `J`, and mono pins the parameter at `J`.
The re-check walks the body at the binding, so the literal `{ w: y }` is built at
`{ w: { f: null } }` and handed the `J` the parameter holds.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |

| `const v: J = mk2(); g(v)` | runs | the same |
| `return 1` (the literal unread) | invalid module | the read: no |
