### D17121 — a `boolean | null` local narrowed to `null`, read and then handed to an `i32 | null` parameter, writes an invalid module

**check-clean invalid wasm · clause 1 · legacy (the claimless build fails the same) · owner S2 · found by IR-N7 writing a `narrowed read` witness · filed 2026-11-24 against master `1784a86d`**

Repro:

    function pb(k: i32): boolean | null {
      if k == 0 { return null }
      return true
    }
    function takeI(x: i32 | null) {
      if x == null { print(1) } else { print(x) }
    }
    function t(k: i32) {
      const b = pb(k)
      if b is boolean { print(b) } else {
        print(b)
        takeI(b)
      }
    }
    t(0)
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `t`: type mismatch:
    // expected i32, found (ref $type)

    null
    1

#### Ablation

| ingredient | outcome |
| --- | --- |
| `takeI(b)` alone, or twice | runs, prints `1` |
| `print(b ?? false)` or `print(b == null)` before `takeI(b)` | invalid module |
| a `boolean \| null` or `string \| null` destination instead of `i32 \| null` | runs |
| a `string \| null` local into the `i32 \| null` parameter | runs; the IR's shadow bytes differ from legacy's |
