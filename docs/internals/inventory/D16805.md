### D16805 — a list literal of un-annotated functions pushed onto a list of such lists has no interned shape at emit

**closed 2026-11-16 — the witness runs and prints `4` then `1.5` · was: loud emit reject · clause 1 (check accepts what emit refuses) and clause 2 · found closing [D16742](D16742.md) · filed 2026-11-16 against master `e056e7cea`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const xs = [[inc0]]
    xs.push([half])
    for x in xs { print(x[0](3)) }
    // vl check: rc 0.  vl run: emit error, "emitProgram: ref valtype with no interned shape"

Want:

    4
    1.5

#### Mechanism

The tag plan (`compiler/check_fn_tag.vl`) let a list of the set's ids take `push`, `slice`, `pop`
and `get` (`ftSlotOp`, hold kind 1), and a list of records or of maps take a pushed element, but
not a list of lists (kind 4): the set stayed untagged and the list was held as closures over
hole functions, which key no row. A list of lists now takes those operations, and a pushed or
index-stored list (`xs[0] = [half]`, a slot write now, `ftSlotWrites`) is judged as its literal's
element is (`ftListElemOk`): a literal of the set, or of a smaller set re-typed to the element.

#### Grading list

- Members with one result (`inc0`, `dbl`): ran, still run.
- Three levels (`[[[inc0]]]`, `push([[half]])`), an index store, a `let` re-pointed after the
  push, `slice` and `pop` of the list or of a literal list of lists: run.
- A named or returned list pushed (`xs.push(q)`, `xs.push(mk())`, `xs.push(ys[0])`): still
  refused, as the same element in a literal is, [D16812](D16812.md).
- Pushed through an un-annotated parameter (`function add(xs) { xs.push([half]) }`): still
  refused, `monomorphize: unsupported argument type`.
- An empty list pushed and then pushed into (`xs.push([])`, `xs[1].push(half)`): still refused.
