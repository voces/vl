### D3929 — a never-written alias of a generic function pushed into a list of functions traps

**loads then traps · found in review of #3490 (`rv3490/q2_push_alias_toplevel`, `q1`) · filed 2026-10-09 against master `255fc7a6c`**

Repro:

    function inner<U>(u: U) { print(u) }
    const fs: ((n: i32) => void)[] = []
    const k = inner
    fs.push(k)
    fs[0](1)
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch

Want:

    1

#### Mechanism

Not located. `fs.push(inner)` runs, so the alias is the ingredient: a push delivers a value at the
list's element type through the binding-delivery path, which names a lambda binding or a generic
function by its own name, and the alias `k` of a generic function reaches no instance. No
nesting, capture or enclosing generic is needed; a capturing nested generic inside a non-generic
function traps the same way (q1).
