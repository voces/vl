### D3929 — a never-written alias of a generic function pushed into a list of functions traps

**closed 2026-10-09 by lane SC · runs · was loads then traps · found in review of #3490 (`rv3490/q2_push_alias_toplevel`, `q1`) · filed 2026-10-09 against master `255fc7a6c` · pins: `tests/cases/generics/binding-of-generic-function-delivered-as-value.vl`**

Repro:

    function inner<U>(u: U) { print(u) }
    const fs: ((n: i32) => void)[] = []
    const k = inner
    fs.push(k)
    fs[0](1)
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch

Want:

    1

#### Mechanism

A push delivers its argument at the list's element type through the binding-delivery path,
which pins a hole lambda but instanced no generic function: `fs.push(inner)` ran only because the
emitter resolves a bare generic name, and an alias `k` reached nothing. Closed: a push coerces
each argument at the element's function type (`monoCoerceFnValueName`), so a generic function by
name or through a never-written alias is instanced there, into any list.
