#### Mechanism

`monoArgTyName` reaches its union floor (`monoUnionPinName`), which pins through the union
registry (`unRowOfCanon`). An inferred `i32 | string` join that no annotation spells has no row
there: a binding of the same join registers its own (`inferLetIx`), an argument registers
nothing, so the floor answered "" and the refusal fired. The close has the floor register the
join's value-union name at the pin (`valueUnionRetName`, `monoRegisterPinUnion`), the row a
binding would have minted, and pin the parameter at it.
