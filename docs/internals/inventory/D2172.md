### D2172 — a `let` initialised to `null` that a closure writes is never boxed

**loud emit reject · clause 2 · filed 2026-09-23 against master `a453c09c5`, residue of [D2168](D2168.md)**

Repro:

    function main() {
      let k: i32 | null = null
      const set = () => { k = 5 }
      set()
      print(k ?? 0)
    }
    main()
    // vl check: rc 0.  vl run: emitProgram: assignment target is not a parameter, local, or global

#### Mechanism

`captureBoxRewrite` boxes a captured `let` a closure assigns only when `cboxInitScalar` accepts
its initializer, a number or string literal. `null` is neither, so the binding stays captured by
value and the closure's write has no cell to reach. The nullable binding needs the same
one-element cell over its declared `T | null`.

#### Grading list

`let k: K | null = null` over a literal union (the D2168 twin, which refuses on its widening
first); `let s: string | null = null`; a struct `let p: P | null = null`.
