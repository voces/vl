#### Mechanism

A `??` default typed J over a read typed `{h: {f: i32}} | null` joins as `{h: {f: i32}} | J`, and
any read of `.h` off that union went through `sharedUnionFieldTy`, which joined the members'
`h` records into the wider `H`. `K` stores `{f: i32}` at `h`, so `H` named a record no member's
field holds and emit had no struct row for the receiver. The same read failed on a declared
`K | J`, a function returning one, and a plain `a: K | null ?? d: J` with no map at all; the flat
spelling ran because a scalar field of the box needs no struct row. The `??` join was never the
defect: it typed the union correctly.
