Repro:

    type O = { v: string | null }
    function clr(o: O) { o.v = null }
    function f(o: O) {
      function h() { clr(o) }
      if o.v != null {
        h()
        print(o.v.length)
      }
    }
    f({ v: "abc" })
    // vl check: rc 0.  vl run: wasm trap: null reference

#### Mechanism

A path narrowing ends at a call whose callee may write it (`callInvalidatesReal`). For a callee
that takes no argument the only leg is its free-variable summary (`fnWriteFreePaths`), which
records an assignment rooted at a free name and composes a nested call's own free writes, and
nothing else. Two writes escape it:

* **through an argument**: `h`'s body hands the captured `o` to `clr`, which writes `o.v` through
  its parameter; `callFreeEffects` asks `clr` only for its free writes, never for what it writes
  through a parameter it was handed a free name in (`fnWriteEffects`). A method receiver
  (`o.clear()`) is the same leg.
* **through an alias**: a write rooted at another name bound to the same object — a local
  `const p = o`, a list holding it (`os[0].v`), a second parameter the caller passed the same
  object to, a module binding the narrowed parameter was passed — is recorded under that name,
  and `pathHitsAny` compares names.

#### Close

The write summary a path narrowing is judged by is now `fnWriteShapes`: the writes a function may
make to an object that existed before it was called, keyed by what they replace rather than by
the name they are spelled through — `.f` a field stored, `[k]` / `[]` a cell stored, `-[k]` /
`-[]` a map cell removed, `=g` a free name rebound. It folds in every callee and operator
declaration. A call of the function's own parameter `i` is `@i`, and a call site replaces it with
what its argument there writes, so a read-only callback keeps the narrowing and a writing one ends
it, however deep the call to it sits (inside a lambda handed to `map`, through a forwarding
function, at module scope). Any other unknown callee is opaque. A call ends a path narrowing when
a shape hits a step of the path (`shapesHitKey`); this replaces the name-keyed argument,
free-variable and index-cell legs, which it covers. Precision:

* a cell shape carries its container's kind and element type (`#a<T>` list, `#m<V>` map), and
  hits a step only when one element type is assignable to the other;
* a built-in method's shape applies only when the receiver's type has that built-in, so a record's
  own `clear` is its declaration, and a std function reached by the method spelling (resolved
  through the site's UFCS alias) is summarised from its body;
* a write one step below a `const` the function builds itself is left out, and a store into the
  path's own last step is harmless when that place stores exactly the narrowed type.

A field shape is scoped only by name: a write of `.x` through any reachable object ends an `.x`
narrowing, and must, since width subtyping lets a `{ x, y }` record stand in for a `{ x }` one.
With the summary sound, a `const`-bound lambda is a call to its body whatever it writes, and a
callback forwarded to a function that only calls it runs inside the call (`crParamUsesOnlyCall`),
which lets #3150's recorded refusal `s1` run. `l1` stays refused: its callee is a function-typed
parameter, so the call is unknown and may be a closure holding the object.
