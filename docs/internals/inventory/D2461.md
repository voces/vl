### D2461 — a callee's free-variable write summary misses a write through an argument or an alias

**loads then traps · clause 1 · filed 2026-09-25 against master `70450b586`, found by the second
review of #3150 · open**

Repro:

    type O = { v: string | null }
    function clr(o: O) { o.v = null }
    function f(o: O) {
      function h() { clr(o) }
      if o.v != null {
        h()
        print(o.v.length)
      }
    }
    f({ v: "abc" })
    // vl check: rc 0.  vl run: wasm trap: null reference

#### Mechanism

A path narrowing ends at a call whose callee may write it (`callInvalidatesReal`). For a callee
that takes no argument the only leg is its free-variable summary (`fnWriteFreePaths`), which
records an assignment rooted at a free name and composes a nested call's own free writes, and
nothing else. Two writes escape it:

* **through an argument**: `h`'s body hands the captured `o` to `clr`, which writes `o.v` through
  its parameter; `callFreeEffects` asks `clr` only for its free writes, never for what it writes
  through a parameter it was handed a free name in (`fnWriteEffects`). A method receiver
  (`o.clear()`) is the same leg.
* **through an alias**: a write rooted at another name bound to the same object — a local
  `const p = o`, a list holding it (`os[0].v`), a second parameter the caller passed the same
  object to, a module binding the narrowed parameter was passed — is recorded under that name,
  and `pathHitsAny` compares names.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the call `h()` | runs, prints `3` | **yes** |
| the argument (`h` writes `o.v = null` itself) | loud check reject | **yes** — the free leg sees it |
| the named nested function (a `const h = () => …` lambda, on #3150) | loud check reject | no — #3150 trusts a lambda's body only when it writes no place, so the lambda stays opaque |

#### Grading list

On master, all load then trap:
* `r1`: a top-level `clrQ` writes the module `const q` that the narrowed parameter aliases;
* `r2`: a top-level `clrQ() { clr(q) }` hands a module binding to a writer;
* `q17`: a named nested function writes through `const p = o`.

The `const`-lambda spellings, which #3150 refuses (the lambda is opaque unless it writes no place):
* `q6`: `p.v = null`, with `p` another parameter bound to the same object;
* `q7`: `clr(o)` from a lambda;
* `q9`: `os[0].v = null`, with `os` a list holding `o`;
* `q16`: `const p = o`;
* `q18`: `o.clear()`.

The review's probes are in its scratchpad `rv3150r2-q4z/p/`.

Fix direction: a free name handed as an argument or receiver to a callee counts as that callee's
parameter summary applied to the name; an unknown callee counts as a write. An alias writes the
same paths: conservatively, any write through a reachable name of the same type counts.
