### D2646 — a lambda whose tail `else if` chain assigns two members of a union global fails validation

**check-clean invalid wasm · clause 1 · found by the review of #3186, identical on master `50c627ce4` · filed 2026-09-26**

Repro:

    let gv: i32 | string = 0
    const f = (c: boolean, n: i32) => {
      if !c { gv = "z" } else if c { gv = 5 }
    }
    f(true, 0)
    print(gv)
    // vl check: rc 0.  vl run: inside `f`: type mismatch: expected i32, found (ref $type)

#### Mechanism

Not ablated past the table. The lambda's tail is an `else if` chain whose links are assignments
of a `string` and an `i32`. Its inferred result joins them, so the lambda's `$fnsig` carries a
result that one arm's value does not match. Lambdas are not voided by D2631, which covers
named top-level functions only. The named-function spelling runs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `else if` link (a plain `else`) | runs | **yes** |
| the lambda (a named `function f`) | runs | **yes** |
