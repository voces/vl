### D16143 — a call result's un-annotated function handed to a generic `(x: T) => i32` parameter whose `T` only the call's result type fixes is refused at emit

**loud emit reject · clause 2 · ``emitProgram: cannot take the generic function `inc` as a value — a function value carries ONE signature`` · found closing [D16099](D16099.md) · filed 2026-11-14 against master `7cdda1fef`**

Repro:

    function inc(a) { return a + 1 }
    function pick1(_c: boolean) { return inc }
    function apt<T>(g: (x: T) => i32, v: T): T { return v }
    const q = apt(pick1(true), 3)
    print(q)
    // vl run: the emit refusal above

Want:

    3

#### Mechanism

Not ablated to a line. `apt` never calls `g`, so no call through it pins `inc`'s parameter. The
checker now types the call at `T = i32` (D16099), but the emitter takes `inc` as a closure
value with its parameter still open.

#### Ablation

| change | outcome |
| --- | --- |
| witness | emit reject |
| `apt` calls `g(v)` in its body | not graded |
| `const g = pick1(true); apt(g, 3)` | not graded |

#### Grading list

The witness with `inc` annotated `a: i32` (want `3`).
