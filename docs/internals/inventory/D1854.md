### D1854 — an INFERRED anonymous struct holding a `u8[]` was refused a row, by a rung that declined the field code its declared twin already has

**closed · filed 2026-09-07 against master `a9d76dee3`, closed against `2a2fb2170`**

Repro:

    const src: u8[] = [4, 5, 6]
    const h = { f: src }
    print(h.f[1])
    // prints 5

#### Mechanism

`anonFieldCode`'s first rung asked `tyIsU8ArrayTy(nodeRepTyIxOf(valIx))` and answered **-1**,
on the stated premise that the packed byte list has no field code. It has one: D1008 gave
`u8[]` code **35**, and `fieldCodeOfSpelling("u8[]")` returns 35 for the exact spelling this
rung holds. The rung was placed correctly and answered wrongly — it is the only rung that can
see a `u8[]` field, because every rung below it reads the field VALUE's own literal form and a
bare `[4, 5, 6]` never infers `u8[]`; `nodeRepTyIxOf` carries the destination the literal
adopts. Declining there sent the field into the guessing rungs, none of which claims a `u8[]`,
so the literal reached the spellability gate with no code, its shape was never interned, and
`vl check` rc 0 was followed by `emitProgram: ref valtype with no interned shape`.

The declared twin `type H = { f: u8[] }` runs because it never asks this ladder — it reads its
code from `fieldCodeOfSpelling`. The two paths disagreed about a code only one of them had
looked up.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `u8` element (`const h = { f: s2 }`, `s2: i32[]`) | runs | **yes** |
| the inference (`const h: { f: u8[] } = …`) | runs | **yes** |
| the inline shape (`type H = { f: u8[] }`) | runs | **yes** |
| the struct (a bare `const c = src`) | runs | **yes** |

#### Fix

One rung, `-1` → `35` (`compiler/emit_classify.vl`). Ten anonymous-struct shapes grade `RUNS`
at both `u8[]` and its `i32[]` twin: inferred field read, inferred with an annotated binding,
declared type, two `u8[]` fields in one row, a `u8[]` field beside an `i32` field, an anonymous
row nested inside another, an element write through the field, a `push` through it, a list of
the shape, and the shape returned from a function. Fixture:
`tests/cases/objects/u8-list-anon-struct-field.vl`.

`scripts/capability-probes/matrix/spread-u8-packed-list.matrix.vl` no longer skips
`struct_field_init`; it grades **46 of 46, 0 silent**. D1853 is the map-value half and was
closed the same way — a classifier ladder that enumerated the scalar backings and missed the
packed one. Both were filed off one matrix cell whose LABEL named a position, not a mechanism.
