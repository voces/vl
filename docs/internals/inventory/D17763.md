### D17763 — a fresh binding is not adopted at a nullable or union destination, so its literal is refused there

**loud check reject · clause 2, a mechanism limit of F2's adoption (coordinator ruling 2026-11-27), not design · `cannot assign {r: i32} to 'c' of type Circle | null` · filed 2026-11-27 against master `1faa021d1` by lane CENSUS**

Repro:

    type N = 1 | 2
    type Circle = { r: N }
    const lv1 = { r: 1 }
    const c: Circle | null = lv1
    print(c?.r)
    // vl check: rc 1, "cannot assign {r: i32} to 'c' of type Circle | null"

Want:

    1

#### Mechanism

`destAdopts` (`check_statements.vl`) admits only a destination that is one type at every depth.
A nullable or a union of shapes has arms the returned-binding rows choose between, and building
the binding at the whole union changed its own reads (D17760, D17761); the arm the literal
belongs to would be the destination to adopt.

#### Grading list

* `type Sq = { s: N }; const c: Circle | Sq = lv1` (a union of records), refused the same way.
* The F2 census cells with a nullable or record-union destination.
