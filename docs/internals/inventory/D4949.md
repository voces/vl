### D4949 — a `.push` through a record field, capture or element that `is` fits as an empty list of another arm traps

**closed 2026-10-15 — now prints `1` · was trap after load, clause 1 · the `is` stores an empty list of the tested arm back into a field, a list element, or a capture made a cell, as it did a local or global · pin: `tests/cases/unions/empty-list-is-store-back.vl` · found closing D4939 · filed 2026-10-15 against branch `fix-list-union-is-empty` over master `0d089455a`**

#### Mechanism

`is string[]` fits the empty `f64[]` (D4771). A local or global receiver is re-boxed as an
empty `string[]` at the `is`, but a field, a capture and a list element are not, so the box
still holds the `f64[]` wrapper. D4939 lets a read of such a place see a stand-in empty
`string[]`; a push into that stand-in would be lost, so the push receiver keeps the plain cast
and traps. The fix is a store-back at the `is` site for every place a push can name: a field
`struct.set`, an element store, and a captured variable, which `captureBoxRewrite` now makes a
cell when a closure tests it so.
