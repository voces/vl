### D2136 — a getter's call of a function that writes state is refused, naming the write and the path to it

**loud check reject · by design (the getter contract, `property-access-design.md` §D3a-contract) · filed 2026-09-23 against master `b52b14e83`**

Repro:

    type V = new { n: i32 }
    let count = 0
    function bump(n: i32): i32 { count = count + 1; return n }
    function viaBump(n: i32): i32 { bump(n) + 1 }
    get g(self: V): i32 { viaBump(self.n) }
    const v: V = { n: 3 }
    print(v.g)
    // vl check: the getter `g` on V calls `viaBump`, which writes the module `let` `count`
    // (viaBump() → bump()), and a getter must not have side effects — make it a method: …

#### Mechanism

The callee's summary (D2135) carries the first write its body or a callee's makes, and the
callee row it came through. `gwCalleeCheck` refuses on the first failing fact in a fixed order:
a write, a read of a module `let` or `extern let`, a host call, a call of unknown effect (a
function value or an operator over an unbound type parameter), an allocation, no step bound
(a loop, recursion, a runtime string compare at the pinned type). The path follows each fact's
`via` column.

#### Grading list

Each refusal in `getters/getter-calls-functions-rejects.vl`: a generic at `string`, the write
through a callee, `print`, a function value, an allocation in one branch, a `while`, direct and
mutual recursion, a `.push()` into a parameter, string `+`, and a helper chain over the budget
(`g11 → f2() (3×) → f1() (2×) → f0() (3×)`).
