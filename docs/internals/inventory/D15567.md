#### Mechanism

[D15529](D15529.md)'s witness with an index store where it pushed. `elabListParamSource` takes a list
as its parameter's holder when its other reads are calls through an element, pushes of the
parameter's reads, or a hand whole to a named function; an index store is none of those, so no fact
mints for the calls through `xs[0]`, `{id}` stays an untagged closure, and the `.length` of a
`string` result has no receiver class.
