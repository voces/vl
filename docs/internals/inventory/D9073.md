#### Decision

Two rules govern a type parameter no argument binds. One is D4551's: a parameter only the BODY
names is default-bound at an inferred call, and the default is never observable. The other is
`checkRetTyParamBound`: a parameter the RESULT names, which no parameter names, is refused at
every direct call, also when the destination is annotated (`const ys: string[] = cnst(3)` is
refused). `U` here is in the result, so the second rule applies. A callback handed to `.map`,
`.filter` or a higher-order parameter is called by the receiver with arguments the receiver
chooses, which is a direct call. So the refusal is the direct call's, at the callback argument.
A body-only parameter keeps D4551's default at every one of those positions. The decision reads
the callback's own declaration (scope-resolved, `lookupFnDeclNode`), never the call site's type
variables, so an enclosing generic's open `T` (`xs.map(idg)` inside `h<T>`) is not asked.
