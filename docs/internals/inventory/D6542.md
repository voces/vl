### D6542 — an empty list literal handed through a hole to a declared generic's `T[]` parameter is refused at emit

**closed 2026-10-18 by lane L1 · runs, prints `0` · was a loud emit reject · clause 2 · the flow pin binder bound `T` to the empty list's hole element; it now binds the closed arguments first, then an empty list's element at `i32` where nothing else binds it, as the direct call does ([D4551](D4551.md)) · pin: `tests/cases/generics/hole-call-of-generic-at-its-own-instance.vl` · found closing [D6540](D6540.md) · filed 2026-10-18 against master `fc3856155`**

Repro:

    function len<T>(k: T[]): i32 { k.length }
    function via(a) {
      print(a([]))
    }
    via(len)
    // vl check: rc 0.  vl run: emitProgram: a function-value call has no interned signature — the callee has no function type to key a signature from

#### Mechanism

From the ablation only. `[]` leaves `T` open at the hole's call, so no instance of `len` is
bound for it and the emitter has no signature to take `len` at. The direct call binds `T` by
default ([D4551](D4551.md)'s ruling); the hole's call does not.
