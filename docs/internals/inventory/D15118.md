#### Mechanism

A list of maps whose maps hold a set's ids is D15187's kind 7. The second write opened a set of its
own: the elaboration's slot join (`elabSlotJoinTy`) joined only writes through a BOUND map, so
`ms[0].set("j", id1)` left the map's value type at the one-member set `{id0}`, fn-tag's scan refused
`id1` as no member, and the set stayed closures. The join now also reads the writes into a list
binding's elements' slots.
