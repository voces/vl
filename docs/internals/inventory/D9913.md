#### Mechanism

The first instance's `??` is `i64 | f64`, the join the checker reads at its holes. With one pin
the template's own node types spell that union and collect registers it. With two pins the
template spells only the hole, so nothing registered it, no `f64` value box was minted, and
boxing the default `0.5` refused. The fix registers the union from the instance's hole binding
in the mono pin walk, as the `<T>` face already did from its join.

un-annotated function pinned at `i64`, now runs and prints `3`. A function that returns the
