### D7122 — a function with an inferred return that returns a module global typed by a nullable literal union refuses at emit

**open · loud emit reject · clause 2 · found by the `nullable-litunion-inline-arm` matrix's `return_inferred` cells, closing [D7043](D7043.md) · present on master `e55677bd8` · filed 2026-10-19 against master `e55677bd8`**

Repro:

    const ga: ("a" | "b") | null = "a"
    function d() {
      return ga
    }
    print(d() == null)
    // vl check: rc 0.  vl run: emitProgram: an inferred return of a nullable literal union has no string result to widen into

Want:

    false

#### Mechanism

The refusal fires in the return emitter's string-widening arm, which declines a `K | null` atom
under an inferred return because no `string | null` result was declared ([D3198](D3198.md)).
Reaching that arm means the inferred result reads as a string widening when the source is a
module global, while the same value bound locally reads as the literal union and runs. Not yet
located by a probe.
