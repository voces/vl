### D7122 — a function with an inferred return that returns a module global typed by a nullable literal union refuses at emit

**closed · was loud emit reject, clause 2 · found by the `nullable-litunion-inline-arm` matrix's `return_inferred` cells, closing [D7043](D7043.md) · filed 2026-10-19 against master `e55677bd8` · closed by lane L6 against master `6d9597a6e`**

Repro:

    const ga: ("a" | "b") | null = "a"
    function d() {
      return ga
    }
    print(d() == null)

Want:

    false

#### Mechanism

The global's storage was a string, not the atom. `letIsString` (emit_classify.vl) classified a
global by its initialiser before its declared type, so a string literal initialiser made a
`K | null` global a string ref. A function returning it then read as a string widening into an
inferred `K | null` result, which the return emitter refuses ([D3198](D3198.md)). A local is
classified by its declared type and ran. `letIsString` now answers `false` for a declared
nullable literal union, so the global is the atom niche whatever literal initialises it.
