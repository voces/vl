### D7010 — a labelled block left by `break` with an uncalled hole function as its value is refused at emit, even into an annotated binding

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same program with `exclaim(s: string)` runs, and the block with no `break` runs ([D6990](D6990.md)) · found closing [D6990](D6990.md) · present on master `3fbefe6d6` · filed 2026-10-19 against master `3fbefe6d6`**

Repro:

    function exclaim(s) { return s + "!" }
    const x = @B { break @B exclaim }
    print(1)
    // vl check: rc 0.  vl run: emitProgram: local declaration needs an initializer

Want:

    1

#### Mechanism

From the code path. `lvRewriteAt` (`emit_rewrite.vl`) keeps a block no `break` leaves as its own
value since D6990, but a block a `break` leaves still stores into a carrier `let $lvN: T;` whose
`T` is the hole function's open signature. Nothing pins the carrier, and the i32 floor refuses a
declaration with no initializer. An annotated destination does not help here, unlike the block
with no `break`: the carrier keeps the value's own open type.
