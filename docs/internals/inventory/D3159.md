### D3159 — a `.map` whose callback joins two concrete scalars, returned from a generic, builds an invalid module

**check-clean invalid wasm · clause 1 · the J4 family of the #3280 round-3 review's `g1` grid (`rv3280r3-20852/g1`, 42 cells at the return, `if`-arm and tail deliveries) · the same on master `b1794003a` and on every #3280 seed · filed 2026-09-29 against master `b1794003a`**

Repro:

    function t<T>(x: T) {
      return [x].map((e) => {
        if 1 > 2 { return 1 }
        return "a"
      })
    }
    for y in t(4) { print(y) }
    // vl check: rc 0.  vl run: invalid module inside `t`, expected (ref $type), found (ref $type)

Want:

    a

#### Mechanism

Not localised past the ablation. The callback names no type parameter, so no pin is involved:
its returns join to the `i32 | string` box, and the list returned from the generic is typed as
something other than the box list the `.map` builds. Bound to a local and walked in place, the
same result runs. A declared `(e): i32 | string` return does not help, and the non-generic
spelling is refused at emit instead.
