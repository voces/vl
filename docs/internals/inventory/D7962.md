### D7962 — an annotated `??` over a nullable-`i32` map read with an atom-valued default is refused at emit

**closed 2026-10-20 by lane L6b · runs, prints `a` · was loud emit reject, "`??` over this nullable value is not supported yet" · clause 2 · `emitCoalesceGo` had no rung for a box-valued map read beside a default of another member set; the join is now built from the read's null test (`coalMapReadJoinNullTest`) and each arm is delivered into the box · pin: `tests/cases/literal-unions/coalesce-map-read-joins-atom.vl` · filed 2026-10-20 against master `aec7a5332`**

Repro:

    type AB = "a" | "b"
    type R = { a: {[i32]: i32 | null}, b: {[i32]: AB} }
    function mk(): R {
      const a: {[i32]: i32 | null} = Map()
      const b: {[i32]: AB} = Map()
      b[3] = "a"
      { a: a, b: b }
    }
    function use(p: R) { print(p.a[9] ?? p.b[3]) }
    use(mk())

Want:

    a

#### Mechanism

The annotated face sees the map read's real type, `i32 | null`, which is a box and not a
nullable ref, so every `emitCoalesceGo` rung declined it and the floor refusal fired.
The result is the `i32 | AB | null` box: the lowering desugars to
`if m[k] != null { m[k] } else { d }` and the join delivers each arm into that box.
