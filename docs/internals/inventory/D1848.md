### D1848 — the assignment narrowing has no PATH twin: a non-null write to `o.v` does not strip `null`, while the same write to a bare name does

**loud check reject · filed 2026-09-07 against master `a104c659a` · the residue
[D1847](D1847.md)'s close named — the write channel it built covers a write that RETIRES a
narrowing, and this one has no narrowing to retire · clause 2 · 0 corpus cells**

Repro:

    type N = { v: i32 | null }
    function f(o: N): i32 {
      o.v = 5
      print(o.v + 1)
      return 0
    }
    f({ v: null })
    // vl check: rc 1,
    // operator '+' is not defined for i32 | null and i32

#### Mechanism

Two write-side channels feed a narrowing and only one of them has a path arm. The one
[D1847](D1847.md) built runs inside `retireNarrowingsForWrite` and fires when the write
FALSIFIES a live narrowing — it retires the old fact and installs the written member. The one
this row names is the assignment narrowing, `checkNodeReal`'s `=` arm: a straight-line
`x = <non-null>` over a null-bearing binding banks the declaration under `NAR_KIND_ASG` and
`declare(nonNullTy(asgCur))`s the name for the rest of the block, with the emitter's
complement push (`pushNarrowComplement(name, set, "null")`) as its twin. Both of those are
keyed on a bare NAME: `asgTgt is Ident` gates the checker's, and `tgt is Ident` the emitter's.

A path reaches neither, so nothing happens at all — which is why the guard makes no
difference: `if o.v == null`, `if o.v is null` and no guard whatsoever all refuse the same
way, and the whole family is the missing arm rather than a narrowing that fails to survive.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the path (`let x: i32 \| null = null; x = 5`) | runs, prints `6` | **yes** |
| the guard (`if o.v == null` / `if o.v is null` around the write) | refuses identically | no |
| the nullable rep (`o.v: i64 \| boolean`, write `true`, read `if o.v`) | runs — that is D1847's channel | **yes** |
| the index spelling (`xs[0] = 5` over `(i32 \| null)[]`) | refuses identically | no |

#### Grading list

The four ablation rows, plus `tests/cases/unions/narrow-path-write-flips-variant.vl`'s
`ADMITTED` row (a write the narrowing admits, which must keep running) and the bare-name
assignment-narrowing fixtures, which must not move.

A close is the path twin of both halves: the checker's `=` arm needs a Member/Index leg that
pushes an `npKeys` entry at `nonNullTy` of the place's declared type, and the emitter's Ident
arm needs the same complement push keyed by the path string. **The two must land together** —
a checker that strips `null` while the emitter reads the nullable rep is check-clean invalid
wasm, which is the failure mode D1736's and D1847's closes each hit before their emitter half.
