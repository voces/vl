### D5280 — an `if` join of two literal-union lists binds the list as a string list while its arms are atom lists

**closed · was check-clean invalid wasm · eardstap EV-004 · filed 2026-10-17 against master `3f6a785db`**

Repro:

    type A = "x" | "y" | "z"
    const P: A[] = ["x", "y"]
    const Q: A[] = ["z"]
    function pick(c: boolean, i: i32): A {
      const pool = if c { P } else { Q }
      pool[i]
    }
    print(pick(true, 1))

Want:

    y

#### Mechanism

The un-annotated binding of an `if` expression took its list rep from the join's TYPE, which
renders the element as `string`, while both arms deliver the atom list a registered literal
union is stored as. The binding classifier now asks whether the arms agree on one list rep
(`ifArmsAgreeOnListRep`, `emit_classify.vl`) and takes theirs when they do.
