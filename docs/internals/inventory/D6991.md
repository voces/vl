### D6991 — an uncalled hole function bound through an `if` expression and called through the binding is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same program with `exclaim(s: string)` runs, and `const x = exclaim` called as `x("a")` runs · found closing [D6981](D6981.md) · present on master `4ad81c0e0` · filed 2026-10-19 against master `4ad81c0e0`**

Repro:

    function exclaim(s) { return s + "!" }
    const x = if true { exclaim } else { exclaim }
    print(x("a"))
    // vl check: rc 0.  vl run: emitProgram: cannot take the generic function `exclaim` as a value — a function value carries ONE signature

Want:

    a!

#### Mechanism

From the ablation only. A call through a binding of a hole function instances the function at
the call's argument types when the binding's initialiser names it directly. An `if` expression
of the name is not followed there, so the hole function is a value with no signature.
