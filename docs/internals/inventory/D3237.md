#### Mechanism

A function whose tail is an assignment takes its result from the target cell
(`fnAssignRetKind`). The five cell readers (`fnAssignCellKind`, `…Slot`, `…MapShape`,
`…TypeName`, `…Elem`) each resolved the target by `parentLetOf(body, name)`, the name's first
`LetDecl` anywhere in the body: here the dead-scoped `i64` one. They were handed only a NAME,
by `fnAssignRetTarget` (then `…TargetName`) and by the tail-`if` arm join. The currency is now
the target `Ident` node: `fnAssignRetTarget`, `armAssignTarget` and `ifTailAssignTarget`
return it, and `asgCellLetOf` resolves it with `bodyLetReadAt`. The arm join compares each
arm's own target, so two arms naming one variable from different scopes no longer agree by
name alone (`asgSameCell`).
