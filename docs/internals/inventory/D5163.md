### D5163 — a nullable union of inline arms that differ only in a lone literal has no rep once narrowed off `null`

**loud emit reject · clause 2 · found closing D5157 · the same refusal on master `76ca92ded` · filed 2026-10-17 against master `76ca92ded`**

Repro:

    type N = { tag: "a", v: i32 } | { tag: "b", v: i32 }
    const y: N = { tag: "b", v: 2 }
    const q: N | null = y
    if q != null { print(q.v) }
    // vl check: rc 0.  vl run: emitProgram: struct equality is not supported yet

Want:

    2

#### Mechanism

Not ablated past the table below. Without `| null` the same union keeps its box and shares
one row (D5157); with it the `!= null` compare treats the value as a struct. Letting canon's
union name keep the repeated shape (`{tag:string,v:i32}|{tag:string,v:i32}|null`) moves the
refusal to `ref valtype with no interned shape`, so the nullable spelling names no row.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the arms differ in a field type (`v: boolean` in one) | runs | **yes** |
| `q: N` without `\| null`, no compare | runs | **yes** |
| a parameter `f(q: N \| null)` in place of the binding | refuses, field access receiver is not a struct | no |
| `if q is N` in place of `q != null` | refuses, `is` names a type that is not a union variant | no |
