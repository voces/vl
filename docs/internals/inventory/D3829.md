### D3829 — a nested `<U>` generic whose signature names its enclosing function's `T` is emitted with `T` unsubstituted

**check-clean invalid wasm · found closing D3826 · filed 2026-10-08 against master `cab1ee907`**

Repro:

    function outer<T>(x: T): T {
      function inner<U>(u: U): T { x }
      inner(1)
    }
    print(outer("s"))
    // vl check: rc 0.  vl run: invalid module inside `outer`, `expected (ref $type), found i32`

Want:

    s

#### Mechanism

Not yet located. `inner`'s instance binds only its own `U`, so the `T` in its return
annotation has no substitution and lowers at the default `i32` while the body returns the
captured string. One instance of `outer` is enough. With the return annotation removed it runs
since D3826. A parameter annotated `T` (`y: T`) is a loud emit reject instead (`only i32, i64,
f64, f32, boolean, struct, union, array, or string parameters are supported`).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the return annotation `: T` | runs since D3826 | **yes** |
| the second `outer` instance | still invalid | no |
