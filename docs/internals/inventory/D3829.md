### D3829 — a nested `<U>` generic whose signature names its enclosing function's `T` is emitted with `T` unsubstituted

**closed 2026-10-08 by lane SC with D3831 · was check-clean invalid wasm · found closing D3826 · filed 2026-10-08 against master `cab1ee907` · pins: `tests/cases/generics/nested-generic-reads-enclosing-pin-positions.vl`**

Repro:

    function outer<T>(x: T): T {
      function inner<U>(u: U): T { x }
      inner(1)
    }
    print(outer("s"))
    // vl check: rc 0.  vl run: invalid module inside `outer`, `expected (ref $type), found i32`

Want:

    s

#### Mechanism

`inner`'s instance bound only its own `U`, so the `T` in its return annotation had no
substitution and lowered at the default `i32` while the body returned the captured string.
A nested generic's instance now also binds what its enclosing instance binds, for every type
parameter it does not redeclare (`monoEnclosingPinRow`, `emit_mono.vl`), and keys on those
bindings. A parameter annotated `T` (`y: T`) is still a loud emit reject (`only i32, i64, f64,
f32, boolean, struct, union, array, or string parameters are supported`).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the return annotation `: T` | runs since D3826 | **yes** |
| the second `outer` instance | still invalid | no |
