### D3478 — `vl fmt` expanded every object field shorthand `{ seq }` into `{ seq: seq }`, which pushed short literals past the width and split them (sunpa SP-004)

**closed 2026-10-03 — the witness runs, and `vl fmt` now prints it unchanged · was a `vl fmt` re-spelling of a `vl check`-clean program · fixed by printing a `FieldInit` whose `Ident` value sits at the key's own position as the bare name**

Repro (runs, prints `8`; `vl fmt` must print it byte for byte):

    type Intent = { seq: i32, moveX: i32, moveY: i32, aimX: i32, attack: boolean }
    function intents(seq: i32, moveX: i32, moveY: i32, aimX: i32) {
      const attack = true
      const pending: Intent[] = []
      const i: Intent = { seq, moveX, moveY, aimX, attack }

      pending.push({ seq: seq, moveX, moveY: 3, aimX, attack })
      i.seq + pending[0].moveX + pending[1].moveY + pending.length
    }
    print(intents(1, 2, 3, 4))
    // vl check: rc 0.  vl run: 8.  vl fmt (before): every `seq` became `seq: seq`.

Want:

    8

#### Mechanism

The parser desugars a shorthand field `{ seq }` to `FieldInit(seq, Ident(seq))`, the same
node a written `seq: seq` makes, and `fieldInitText` in `compiler/format.vl` printed every
field as `key: value`. So the formatter re-spelled the shorthand, and the longer text pushed
sunpa's `const i: Intent = { seq, moveX, moveY, aimX, aimY, attack, sprint }` and its one-line
`push({ … })` past 80 columns, where `wrapList` split them one field per line. The two
spellings differ in one place the arena keeps: the shorthand's `Ident` is minted at the key's
position (`fp0` in `parseObjLit`), while a written value starts after the `:`. The fix reads
that, so `seq` prints `seq` and `seq: seq` prints `seq: seq`. The layout rule (one line when
it fits, as calls and arrays) did not change; DECISIONS.md records why. Keeping the shorthand
exposed one meaning hazard, which D3475's round trip caught: a lone `{ id, }` in a body
position is an object only because of its comma, and the one-line form drops a trailing comma,
leaving the block `{ id }`. `loneShorthandComma` keeps that comma.
