#### Mechanism

Measured with a probe build. A plain maker's call is noted only in plain code or in each instance
of the named function enclosing it (`elabCallerKeys`). `elabInPlainCode` answered false for any
lambda body, and `elabCallerKeys` stopped at the lambda, which no instance key names, so a call
there got no member, holder or hand fact. Emit reads a lambda's facts under the key of the function
enclosing it, so both walks now pass through lambdas to the nearest named function (-1 at the top
level).
