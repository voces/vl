#### Mechanism

Not yet measured. A plain maker's call is noted only in plain code or in each instance of the
named function enclosing it (`elabCallerKeys`). `elabInPlainCode` answers false for any lambda
body, so a call there gets no member, holder or hand fact, and emit refuses the call's value.
