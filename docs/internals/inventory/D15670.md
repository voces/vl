**loud emit reject · check-clean, an internal message, clause 1 · `emitProgram: field access receiver is not a struct` · found closing D15657 · filed 2026-11-11 against master `ada32709`**

Repro:

    type J = { f: i32 | null }

#### Mechanism

is typed at `{ys: {f: i32}[]}`, so the field read `r.ys[0].f` asks for a struct the element rep is
not.
