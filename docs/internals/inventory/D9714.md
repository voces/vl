### D9714 — a record field initialised by a call returning a list of an un-annotated function, from a function with an un-annotated parameter, has no interned shape

**loud emit reject · `vl check` rc 0 · `ref valtype with no interned shape`, no position · clause 2 · found closing [D9662](D9662.md) · present on master `e8163edd5` · filed 2026-10-22 against master `e8163edd5`**

Repro:

    function inc(a) { return a + 1 }
    function give(_n) {
      return [inc]
    }
    const w = { f: give(1) }
    print(w.f[0](3))
    // vl check rc 0.  vl run: emit error: emitProgram: ref valtype with no interned shape

Want:

    4

#### Mechanism

Not traced. The call is an instance of `give`, whose returned list is typed by the pins its
reads take. Read through a record field, the read `w.f[0](3)` does not reach the instance's
returned slot, so the field's list stays open at a function.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the parameter of `give` (`give()`) | runs, `4` | **yes** |
| the record (`const w = give(1)`, `w[0](3)`) | runs, `4` | **yes** |
| the call in the field, bound first (`const g = give(1)`, `{ f: g }`) | runs, `4` | **yes** |
