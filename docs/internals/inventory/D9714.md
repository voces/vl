#### Mechanism

`monoWalkLetDecl` pins a record's field containers before it walks the initialiser. A field whose
value is a call to an instance of `give` is typed only once that walk gives the call its
instance, so at pin time the field's list was still open at a function and the record's shape was
built from it. When an un-annotated record literal still open after the walk has a call field, the
field containers are now pinned a second time, reading the type the instance returns.
