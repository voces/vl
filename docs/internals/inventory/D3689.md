### D3689 — `d is 1` with `d: f64` compares an `f64` operand against an `i32` constant

**loud emit reject · `emitProgram: an integer literal is test over a float has no settled answer` · refused at build by [D14642](D14642.md) pending the ruling below; it built an invalid module before · found by lane C2 grading [D3655](D3655.md) · filed 2026-10-05 against master `56af0f07e`**

Repro:

    const d: f64 = 1.0
    print(d is 1)
    // vl check: rc 0.  vl run: emit error, the answer waits on a ruling

#### Mechanism

Not traced. The `is` lowering over a scalar receiver and an integer literal emits the literal
at `i32` and compares it against the `f64` operand. The union spelling `d is C` with
`type C = 1 | 2` runs and prints `false`, so the two spellings also disagree about the answer;
under the numeric-join ruling a literal adapts to its use, which reads `1.0 is 1` as `true`.
Settle the answer (a ruling if `false` is meant) before fixing the lowering.
