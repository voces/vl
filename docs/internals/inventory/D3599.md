### D3599 — calling a binding that shadows a builtin said only "called value is not a function" (sunpa SP-028)

**now a loud check reject that names the binding, its declaration and the builtin it hides (fixed 2026-10-03) · the refusal was always right; its message did not say why `floor` was not a function**

Repro (`vl check` must refuse at 2:7 with "`floor` here is the `f64` declared at 1:7, which shadows the builtin `floor`; rename it"):

    const floor = 2.0
    print(floor(3.5))
    // vl check (before): called value is not a function (f64)

#### Mechanism

`checkCallNode` ends in one sentence for every callee whose type is not a function. A callee
that is a binding named like a module function, or like a builtin (`print`, `Map`, `Set`,
`fromCodePoint`, the numeric and memory intrinsics), now gets its own sentence from
`builtinShadowMsg`. It names the binding's declaration and, for a module function, where that
is declared. A literal `const` read is rewritten to its literal before the call is checked, so
the name comes from the callee's token. A shadowing PARAMETER gets the sentence without a
position. The sibling lint `shadowed-function` (`compiler/lint.vl`, tier `warning`) fires at the
binding when the same function calls the hidden function or builtin above it. Measured before
scoping it that way: warning on every binding that shares a name gave 13 hits in `compiler/` (12
of them `min`/`max`/`abs` parameters), 20 in plumb and 2 in sunpa, none of them a bug; the
scoped rule gives 0 in `compiler/`, `std/`, `scripts/`, `bench/`, plumb, sunpa and glean, and 7
in `tests/cases`. The emitter decided "is this name bound" for a numeric intrinsic by a scan of
the whole function, so `floor(x)` above a later `const floor` was check-clean and refused at
emit with `call to unknown function`. It now asks the live scope (`identNameIsLiveBound`).

#### Ablation

| spelling | message |
| --- | --- |
| module `const floor = 2.0` | names the declaration (1:7) |
| local `const floor = 2.0` in a function | names the declaration |
| `let floor = 2.0` | names the declaration |
| parameter `floor: f64` | names the shadowing, without a position |
| `const sqrt = [1]`, called | names the declaration (`i32[]`) |
| local `const over = 3` under module `function over` | names both declarations |
