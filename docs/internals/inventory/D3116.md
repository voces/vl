### D3116 — a hole's `if` joining its parameter with `null` traps on the `null` arm at an `i32 | string` pin

**closed 2026-09-30 · was loads then traps, clause 1, on master `6e6a5301b` · the `D_join__is`, `D_join__is5` and `D_join__is_is5` cells of the #3274 review's `gen3` grid · filed 2026-09-28 · closed by lane UG: a parameter's hole beside `null` joins as its nullable (`joinTyParamNull`), as a declared parameter does, and re-joins at the pin (D3333) · fixture `tests/cases/generics/hole-join-null-arm-at-union-pin.vl`**

Repro:

    function f(x, c: boolean) {
      const y = if c { x } else { null }
      print(y)
    }
    const v0: i32 | string = "u"
    f(v0, true)
    f(v0, false)

Want:

    u
    null

#### Mechanism

Not localised past the ablation. The join's type at the pin is `i32 | string | null`, a box, and
the `x` arm prints right, so the arm that reaches a cast it cannot pass is the `null` one: the
null the `else` arm builds is not the box the join's readers unbox.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `function f<T>(x: T, c: boolean)` | prints `u`, `null` | **yes** (the hole) |
| `x: i32 \| string` annotated | prints `u`, `null` | **yes** (the hole) |
| `const y: i32 \| string \| null = if …` | prints `u`, `null` | **yes** (the inferred join) |
| an `i32 \| null` pin | prints `5`, `null` | **yes** (a union pin without `null`) |
| `print(if c { x } else { null })` with `c` true | prints `u` | no (the `x` arm never trapped) |
