### D3297 — a generic function whose tail `if` assigns a capturing lambda in both arms is refused at an un-annotated caller

**loud emit reject · 32 cells of the generic shadowed-name grid's renamed control · filed 2026-09-29 against master `e70102886`**

Repro:

    function pick<T>(c: boolean, n: i32, x: T) {
      let s = (k: i32) => k + n
      if c {
        s = (k: i32) => k + n
      } else {
        s = (k: i32) => k + n
      }
    }
    const r = pick(false, 7, 3)
    print(r(1))
    // vl check: rc 0.  vl run: emitProgram: call to unknown function

Want:

    8

#### Mechanism

Not traced. The instance's result comes from the tail-`if` arm join (`ifTailAssignTarget`),
and each arm's lambda is minted per instance (`monoPinBodyLambdas`), so the call through `r`
reaches a lambda the instance never registered. A `(k) => k + 1` in each arm, which captures
nothing, runs; so does every variation below. The grid's other cells of this shape are
invalid wasm rather than this refusal.
