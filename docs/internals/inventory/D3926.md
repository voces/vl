### D3926 — a call through an annotated binding of an alias of a capturing nested generic, in a generic instantiated twice, builds invalid wasm

**check-clean invalid wasm · found closing D3902 (`d3902/m`: `alias__bind__*`, `chain__bind__*` at two and three instances) · filed 2026-10-09 against master `255fc7a6c`**

Repro:

    function outer<T>(x: T) {
      function inner<U>(u: U) { print(x); print(u) }
      const k = inner
      const h: (n: i32) => void = k
      h(2)
    }
    outer(7)
    outer("s")
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `outer`

Want:

    7
    2
    s
    2

#### Mechanism

Not located. A call through `h` is not a call through the alias `k` (an annotated binding is not
followed by the alias chain), so D3887's frame rename of the alias does not reach it. Since
D3902, passing `h` on as a value (`call(h)`) runs.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `outer("s")` removed | runs | **yes** |
| `h` passed on (`call(h)`) instead of called, alone | runs, since D3902 | **yes** |
| `h` passed on, beside another function with a nested generic | invalid wasm, the same | no |
| `h` un-annotated (`const h = k`) | runs | **yes** |
