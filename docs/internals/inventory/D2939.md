### D2939 — an un-annotated record literal handed to a rest parameter of another record type of the same field names is not re-seated

**check-clean invalid wasm · clause 1 · open · the same on master `8615a730d` · residue of D2933's binding close: the use walk names no destination row at a rest parameter, a list spread or a generic call · filed 2026-09-28 against master `8615a730d`**

Repro:

    type J = { f: i32 | null }
    type I = { f: i32 }
    function use(...js: J[]) {
      print(js[0].f ?? 0)
    }
    const r = { f: 7 }
    use(r)
    print(r.f + 1)
    // vl check: rc 0.  vl run: invalid module in the top-level code

Want:

    7
    8

#### Mechanism

D2933's close builds the literal at the record its binding is handed to, and
`rsElemDestRow` names that record. A rest parameter's checked type is the list `J[]`, so the
walk reads no record row from the call and leaves the literal at `I`, its own row. The
argument is then stored into the rest list unconverted. `use(r)` with a plain `j: J` parameter
runs.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `type I` removed | runs, prints `7` `8` | **yes** |
| a plain parameter `j: J` | runs, prints `7` `8` | **yes** |
| `const js: J[] = [...[r]]`, a list spread, instead of the call | still invalid | no (same gap) |
| `function id<T>(x: T): T { x }` and `use(id(r))` with `use(j: J)` | still invalid | no (same gap) |

#### Grading list

The list-spread and generic-pass forms in the ablation, and the permuted and nested-record
pairs of D2933's grid at the same three positions.
