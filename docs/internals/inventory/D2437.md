### D2437 — an integer array literal in a record field takes a declared numeric-list row whatever the record's destination

**check-clean invalid wasm · clause 1 · the D2423 family, found by the #3147 review, filed 2026-09-25 against master `a277bf7b0`**

Repro:

    type Q = { k: i32[] }
    type R = { k: f64[] }
    function mk() { return { k: [1, 2] } }
    const v: R = mk()
    print(v.k[1] / 4.0)
    // vl check: rc 0.
    // vl run: Error: invalid module. Without `type Q` it prints 0.5.

#### Mechanism

An un-annotated record literal's row comes from its field names and codes, and `[1, 2]` codes as
an `i32` list. A declared row with an `f64[]` field accepts it, because the literal can re-encode
its elements at the store. That leniency is also what lets an inferred return reach a declared
`R`: `mk()` returns `{ k: i32[] }`, the checker accepts it as an `R`, and it runs only because the
literal was built at `R`'s row. So it cuts both ways:

* A second row with the same field names (`Q` here, or an anonymous `{ k: i32[] }` another literal
  minted) wins the match, and the returned value is not an `R`.
* With no annotation anywhere, `const v = { k: [1, 2] }; print(v.k[1] / 4.0)` builds `v` at `R`'s
  row while the checker types it `{ k: i32[] }`. This is invalid wasm at 17 positions of the
  review's `a-f64list` matrix, on master and after #3147.

#3147 closed the positions where the literal has a destination the checker can name.
`recordListFieldWidenAdopt` stamps a record literal delivered into a record of another type, and
`structIndexOfObjCtxGo` builds that literal at the stamped row: a local reassignment (was invalid
wasm with a decoy) and every annotated position. The inferred return has no destination at the
literal. The fix is at the delivery `const v: R = mk()`, a covariant record delivery that has to
convert the field, and ownership of that decision is [D2060](D2060.md)'s.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| no `type Q` | runs, prints 0.5 | the second row: **yes** |
| `function mk(): R` | runs, prints 0.5 | the inferred return: **yes** |
| `let v: R = …; v = { k: [1, 2] }` in a function | runs after #3147 (invalid wasm before) | closed |
| `R = { k: i64[] }` or `{ k: f64[], m: f64 }` | same invalid module | no |
