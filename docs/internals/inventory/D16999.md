### D16999 — a lambda with annotated parameters, pushed into a list of un-annotated functions, is refused at emit as a call to an unknown function

**loud emit reject · `emitProgram: call to unknown function` · `vl check` rc 0 · clause 2 · found by lane F2 grading [D16937](D16937.md)'s annotated-lambda spelling · filed 2026-11-19 against master `938930861`**

Repro:

    function inc0(a) { return a + 1 }
    const xs = [inc0]
    xs.push((x: i32): i32 => x * 3)
    print(xs[1](3))
    // vl check: rc 0.  vl run: emit error at `xs[1](3)`, "emitProgram: call to unknown function"

Want:

    9

#### Mechanism

Not located. The call through the element names a member the emitter's function map does not
hold: the annotated lambda written in the push is not a function the call can reach by name.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the lambda un-annotated (`(x) => x * 3`) | runs, prints `9` | **yes** |
| only the parameter annotated (`(x: i32) => x * 3`) | `a function-value call has no interned signature` | no: another refusal |
| `inc0` annotated (`a: i32): i32`) | runs, prints `9` | **yes** (a hole member) |
| the lambda in the literal (`[inc0, (x: i32): i32 => x * 3]`) | runs, prints `9` | **yes** (written by the push) |
| a list of lambdas only (`[(x: i32): i32 => x + 1]`) | runs, prints `9` | **yes** |
| a second member of another result (`[inc0, half]`) | the same message | no |
| a record field (`xs.push({ f: (x: i32): i32 => x * 3 })` into `[{ f: inc0 }, { f: half }]`) | the same message | no |
| no call through the pushed element (`print(xs[0](3))`) | the same message | no |

#### Grading list

The record-field spelling above, and the two-member list.
