### D15372 — a fresh record binding as a part of a list literal whose other parts are built at a wider record is check-clean invalid wasm

**closed 2026-11-10, runs and prints `7` · was check-clean invalid wasm, `vl check` rc 0 · clause 1 · found closing [D15371](D15371.md) · filed 2026-11-04 against master `98f227f3` · closed by the list stamp building a part that reads a fresh record `const` (or an unwritten `let`) at the record the list's other parts are built at, its literal stamped there and its other own-storage deliveries refused (`recHeldLitPartStamp`, check_fit_rules.vl, from `recListLitBuild`), as D15237 builds one pushed into a built list · `[xs[0], r]`, `r` before the spread, `r` inside a function, and `r` also read or handed on at its own type run · fixture `tests/cases/soundness/record-list-literal-fresh-binding-part-runs.vl` · its other half, parts held at their own storage beside a held part built wider, stays an owed check refusal (`record-list-literal-held-and-own-parts-runs.vl`); a call's fresh record as a part is [D15652](D15652.md)**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const xs = [mk()]
    const r = { f: 7 }

#### Mechanism

Not ablated past the table. `xs`'s records are built at `J`. Nothing else holds `r` at its own
storage, nor a call's fresh result, so either can be built at `J` where the list takes it, as D15237 builds one pushed into a
built list; the list stamp (D15371) instead leaves it, and the list, unbuilt.
