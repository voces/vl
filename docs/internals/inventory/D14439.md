### D14439 — a two-member set handed to a hole parameter called at two tuples builds invalid wasm

**check-clean invalid wasm · `expected i32, found (ref $type)` inside `lapBack` · clause 1 · open · the one-member spelling `lapBack(wrap, pair, 4)` runs · deleted by the mint's emitter reader (D14430), which instances each call of the set at its own tuple · filed 2026-10-28 against master `4638042eb`**

Repro:

    function wrap(a) { return [a] }
    function wrap2(a) { return [a, a, a] }
    function pair(a) { return [a, a] }
    function lapBack(g, h, x) {
      print(h(g(x)).length)
      print(g(h(x)).length)
      return 0
    }
    const c = true
    lapBack(if c { wrap } else { wrap2 }, pair, 4)
    // Want: 2, 1

#### Mechanism

`g` is called at `i32` and at `i32[]` in one instance of `lapBack`, and `h` is called on
`g`'s result. With one member, the split plan gives `g` one copy per instance (D6210). With two,
the set is handed on as itself and the instance has one body, so one of the two calls is
emitted at the other's tuple. Not yet ablated past that.
