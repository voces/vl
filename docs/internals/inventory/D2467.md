### D2467 — `m[k] as? V` over a scalar-valued map refuses at emit: the read has no box and no nullable ref to test

**closed 2026-11-16 · runs, prints `null` · was loud emit reject, `` `as i32` needs a BOXED union operand or a nullable-REF one ``, clause 1 (check accepts what emit refuses) and clause 2 · fixed in wasmEmit.vl: `emitAsCast`'s `as?` arm takes a map read whose cast keeps its type as the read itself, a scalar-valued map's boxed by `emitMapGetScalarBox` as a consumed read is, a niche-bearing one as it is read · pin: `tests/cases/maps/scalar-read-as-opt.vl` · found grading D2466's consumers · filed 2026-09-25 against master `086466d1a`**

Repro:

    const m: {[string]: i32} = Map()
    print(m["zz"] as? i32)
    // was: vl check rc 0, vl build: `as i32` needs a BOXED union operand or a nullable-REF one

Want:

    null

#### Mechanism

`emitAsCast`'s `as?` arm lowers only a boxed union or a nullable ref. A bare scalar map read
is neither: its `null` is the probe's miss (D2466). The `as!` arm already fuses the probe; `as?`
has no such arm. The cast is also a no-op at the type level (`i32 | null as? i32` is the read
itself), so the fix is the probe fused the same way `as!` fuses it.
