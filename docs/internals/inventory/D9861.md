#### Mechanism

The only pin on the element slot of `xs` was the annotation of `ap`'s parameter, joined to it by
[D9766](D9766.md)'s flow link, and the agreed-pin read (`ffAgreedPinTys`, fn_flow_shadow.vl) took
call pins only, so the argument `[inc]` was never built at a signature. With `ap` un-annotated the
refusal is `index receiver is not an array or string`, which is [D9862](D9862.md)'s mechanism.
