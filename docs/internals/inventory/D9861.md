### D9861 — a list of an un-annotated function, handed to an un-annotated parameter and read by `.map` with a declared callback, takes no pin

**loud emit reject · `vl check` rc 0 · `cannot take the generic function `inc` as a value` · clause 2 · found closing [D9766](D9766.md) · filed 2026-10-22 against master `ba2918226`**

Repro:

    function inc(a) { return a + 1 }
    function ap(r: (a: i32) => i32): i32 { return r(5) }
    function run(xs) { return xs.map(ap) }
    print(run([inc])[0])
    // vl check rc 0.  vl run: emit error: emitProgram: cannot take the generic function `inc` as a value

Want:

    6

#### Mechanism

Not traced. [D9766](D9766.md)'s flow link joins `ap`'s parameter to the element of `xs`, but `xs`
belongs to the generic `run`, and the argument `[inc]` at the call is not given the pin its
instance's parameter took. With `ap` un-annotated as well, the refusal is
`index receiver is not an array or string` at `run(...)[0]`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the un-annotated parameter of `inc` (`inc(a: i32): i32`) | runs, `6` | **yes** |
| the un-annotated `xs`, for `xs: ((a: i32) => i32)[]` | runs, `6` | **yes** |
| the declared callback, for a lambda (`(r) => r(5)`) | runs, `6` | **yes** |

#### Grading list

`ap` un-annotated; `.filter`; the result bound before it is read.
