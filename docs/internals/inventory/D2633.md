#### Mechanism

A vector now boxes as a value-union atom, like the four numeric scalars. It takes kind code 14
(`valueAtomKind`), which is appended, so every existing tag keeps its number. Its payload is a
one-field `(struct (field v128))` value box behind the union box's `anyref`, and the slot bands
move up one tag only in a module that uses it (`uAtomBandTop`). `v128NestCheck` still refuses
a bare vector as an array element, struct field or map key or value, and no longer refuses one
as a nullable or union member. `v128 | null` boxes, because a vector has no spare bit pattern
for a niche.
Each consumer that listed the numeric kinds by hand gained the vector: the coercion ladder, the
nullable rep, the `as` trio, the map value kind and the print dispatch. The print dispatch
treats the vector arm as unreachable, since the checker refuses a print that could reach it.
`==` between two operands that may each hold a vector is refused, as a bare vector's is.
