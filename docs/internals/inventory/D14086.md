### D14086 — a labelled block joining two lists of different element types, bound inside a function, is refused at emit

**loud emit reject · open · clause 2 · `vl check` rc 0 · `emitProgram: union atom has no value box` · pre-existing on master `baa5cd694` and `b02fce014` · found closing [D14085](D14085.md), whose fix registers the union row for an `if`, `match` or block join but does not reach this one · filed 2026-10-26 against master `b02fce014`**

Repro:

    function h(a0: i32[], a1: string[], k: i32) {
      const r = @out {
        if k == 0 { break @out a0 }
        a1
      }
      if r is string[] { print(r.length) } else { print("i") }
    }
    h([1, 2], ["a"], 0)
    h([1, 2], ["a"], 1)

Want:

    i
    1

#### Ablation

Graded on master `b02fce014`. Each row changes one thing in the repro.

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `K[]` (`type K = "a" \| "b"`), `boolean[]`, or `string[]` beside `f64[]` | same refusal | no |
| `f64[]` in place of `string[]` | runs, but the join is typed `f64[]`: [D14087](D14087.md) | — |
| the `break` removed, the block's value an `if k == 0 { a0 } else { a1 }` tail | same refusal | no |
| both exits written as `break @out` | same refusal | no |
| one exit only (`@out { a1 }`) | runs | **yes** (two list types) |
| an `if` / `else` or a `match` in place of the labelled block | runs, `i` `1` | **yes** |
| the binding annotated `const r: i32[] \| string[]` | same refusal | no |
| the `is` test removed, `r` never read | same refusal | no |
| the function's return annotated | same refusal | no |
| the lists are the function's locals, or module globals it reads | same refusal | no |
| the labelled block not bound: `print((@out { … }) is K[])` | runs, `false` `true` | **yes** (binding) |
| the whole program at module scope | runs | **yes** (function scope) |
| scalars `string` and `i32` in place of the lists | runs, `false` `true` | **yes** (lists) |

The refusal does not need the `break`. It needs a bound labelled block, inside a function,
whose value joins two list types. The mechanism is not yet ablated below the emitter.
