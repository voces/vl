### D14086 — a labelled block joining two lists of different element types, bound inside a function, is refused at emit

**closed as `runs` · the repro prints `i` then `1` · a loop or labelled block is a join node (`exprJoinsArms`), so its list-union type is recorded for the emitter like an `if`'s; the refusal itself was the lowered block's `__trap__()` else arm, a `never` call, being boxed into the union, and a `never` call now enters any box unboxed (`emitUnionCoerceUnder`) · was loud emit reject · clause 2 · pre-existing on master `baa5cd694` and `b02fce014` · found closing [D14085](D14085.md) · filed 2026-10-26 against master `b02fce014` · fixtures `tests/cases/loops/break-join-lists-block.vl`, `tests/cases/loops/break-join-lists-block-annotated.vl`, `tests/cases/loops/break-join-lists-while.vl`, `tests/cases/loops/break-join-lists-while-annotated.vl`, `tests/cases/loops/break-join-lists-for.vl`, `tests/cases/loops/break-join-lists-for-annotated.vl`**

The refusal does not need the `break`. It needs a bound labelled block, inside a function,
whose value joins two list types.

#### Mechanism

A bound loop value lowers (`lvRewriteAt`) to `if true { …; $lv } else { __trap__() }`. The
`__trap__()` arm is typed `never`, and the bound-let path boxed it into the list union like any
other arm. The ladder gave a `never` call kind 0 (`i32`), and the union has no `i32` box, so the
emitter refused. Scalars ran because an `i32` box existed. The checker side was a separate gap:
`exprJoinsArms` excluded loops and labelled blocks, so the join's union row was never recorded.
The fix closes both. A loop is a join node, and a `never` call enters any box unboxed, since its
`unreachable` satisfies the destination.
