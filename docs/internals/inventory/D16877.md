### D16877 — a built-in member call on an un-annotated parameter from inside a closure has no per-instance lowering

**loud emit reject · `emitProgram: callee is not a function name` · `vl check` rc 0 · clause 2 · filed 2026-11-16 against master `b88be2644` (L2, sizing the alias-receiver family)**

Repro:

    const m4 = Map()
    m4.set("a", 7)
    function take(a) {
      const g = () => {
        const h = a.get("a")
        if h != null { print(h + 1) }
      }
      g()
    }
    take(m4)
    // vl check: rc 0.  vl run: the refusal above, at `a.get`

Want:

    8

#### Mechanism

The per-instance pick of a member call on an un-annotated parameter (D2517) is made on the
generic's own body, and it does not walk into a lambda's body. Inside a closure, `a.get` reaches
the emitter as a call whose callee no instance resolved. The checker refuses some built-ins
there instead: `a.indexOf(2)` and a string's `a.slice(0, 2)` get `expected {indexOf: _}, got
i32[]`, the hole's row demand left unanswered. Two built-ins already run: `.length` (a field
read) and `.has`. This is the closure half of [D2520](D2520.md); the alias half closed with the
alias-receiver change.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| no closure, `a.get("a")` in `take`'s body | runs, prints `8` | **yes** |
| `take(a: {[string]: i32})` annotated | runs | **yes** (the hole) |
| a function value stored instead of `7`, called through `h(3)` | the same emit refusal | no |
| the closure returned and called by the caller | the same emit refusal | no |
| `.indexOf(2)` on a list, or `.slice(0, 2)` on a string | loud check reject `expected {indexOf: _}, got i32[]` | no (another face) |
| `.length` or `.has("a")` | runs | **yes** (those built-ins) |
