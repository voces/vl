### D6424 — a maker's generic result in a module record field, called at two types, is refused when the whole record is returned or put in a list

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the record handed whole to an un-annotated parameter runs ([D6371](D6371.md)) · found closing [D6371](D6371.md) · filed 2026-10-18 against master `066d19373`**

Repro:

    function k<T>(x: T): T { return x }
    function mk() { return k }
    const r = { f: mk(), g: 7 }
    function get() { return r }
    print(r.f(1))
    print(r.f("z"))
    print(get().g)
    // vl check: rc 0.  vl run: emitProgram: a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type

Want:

    1
    z
    7

#### Mechanism

From the ablation only. The field-slot plan ([D6342](D6342.md)) follows a whole read of the
record into a parameter or a `const`, where every read is followed; a function's result or a
list element is not followed, so the plan declines and the field keeps one signature.
