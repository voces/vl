    function mk() { return k }

    function get() { return r }

#### Mechanism

From the ablation only. The field-slot plan ([D6342](D6342.md)) follows a whole read of the
record into a parameter or a `const`, where every read is followed; a function's result or a
list element is not followed, so the plan declines and the field keeps one signature.
