### D15754 — a map of un-annotated functions bound at an annotated map, one function also stored in a map nothing reads, is refused at emit

**open · loud emit reject · `monoPinMapValues: the map's stored functions close at another type than its slot fact` · clause 2 · reading the second map runs, as does the first map without the shared function · found by lane w321 grading D15394's matrix (every annotated cell) · filed 2026-11-12 against master `784c38bf`**

#### Mechanism

Not yet traced. `half` is in two maps. The annotation pins `fnMap`'s functions at `(f64) => f64`.
`m2`, never read, leaves `half` at its own type, and the slot fact of the two maps' shared value
storage disagrees with the pinned closures. The refusal names the mechanism (`monoPinMapValues`),
not a contract: the program's two maps are legal, and reading `m2` makes it run.
