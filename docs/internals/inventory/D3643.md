#### Mechanism

Not localised. One union argument binds both parameters of the written union, and the instance
lowers `v ?? 9` with an `i32` result while the operand is the `boolean | string | null` box.
`print(v)` alone runs (prints the value), so the binding of the parameter itself is sound.
