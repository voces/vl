### D3643 — a `??` over a declared `A | B | null` parameter bound from one union argument builds an `i32` result over the box

**check-clean invalid wasm · open · clause 1 · found by lane NJ ablating [D3618](D3618.md) · filed 2026-10-04 against master `32b753681`**

Repro:

    function F<A, B>(v: A | B | null) {
      print(v ?? 9)
    }
    const n: boolean | string | null = null
    F(n)
    // vl check: rc 0.  vl run: invalid module inside `F`: expected i32, found (ref $type)

Want:

    9

#### Mechanism

Not localised. One union argument binds both parameters of the written union, and the instance
lowers `v ?? 9` with an `i32` result while the operand is the `boolean | string | null` box.
`print(v)` alone runs (prints the value), so the binding of the parameter itself is sound.
