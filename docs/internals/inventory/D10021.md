### D10021 — a const bound to a call returning one of two generics, called at two types, reaches no call that fixes its type

**loud emit reject · `vl check` rc 0 · `a generic function taken as a value reaches no call that fixes its type` · clause 2 · CAPABILITY: both returns naming `id` prints `21`, `a` · found closing [D9596](D9596.md) · present on master `00cbfe00b` · filed 2026-10-22 against master `00cbfe00b`**

Repro:

    function id<T>(x: T): T { x }
    function same<T>(x: T): T {
      print("same")
      x
    }
    function pick(n: i32) {
      if n > 1 { return id }
      return same
    }
    const k = pick(3)
    print(k(21))
    print(k("a"))
    // vl check rc 0.  vl run: emit error: emitProgram: a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type

Want:

    21
    a

#### Mechanism

Not traced. [D9596](D9596.md) closed the same callee handed to a split parameter, where each
split parameter selects its own instance by the returned index; a binding has no split, so
`k` needs a value carrying an instance per call type, and the returns of `pick` are left
uninstanced.
