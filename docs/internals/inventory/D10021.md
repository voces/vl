#### Mechanism

[D9596](D9596.md) closed the same callee handed to a split parameter, where each split parameter
selects its own instance by the returned index. A binding had no such plan, so the returns of
`pick` were left uninstanced. The split pass now treats the emitter's ask at a generic named by
a `return` as an ask for the enclosing function. A `let`/`const` binding whose initialiser calls
it is split into a lane per call type. The binding calls the arm-index copy `pick$x…` once, and
each lane is `if sel == 0 { id } else { same }` at its own type.
