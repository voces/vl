### D3982 — a `??` on a binding of a guarded `pop()` keeps the generic never-null sentence

**runs today and must keep running · message only: the warning should name the length guard, as #3522 does for a direct `s.pop() ?? 0` · filed 2026-10-11 against master `1df3c8f91`, from the review of #3522**

Repro:

    const s = [1, 2]
    if s.length > 0 {
      const x = s.pop()
      print(x ?? 7)
    }
    // vl check: warning "this `??` default is never used: `i32` is never null".
    // The program runs and prints 2.

#### Mechanism

#3522 explains the unused default by naming the `length` guard that narrowed the pop, but
only when the `??` operand is the `pop()` call itself. Through a binding, the `??` sees a
plain `i32` and does not trace it back to the guarded pop.
