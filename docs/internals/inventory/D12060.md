#### Mechanism

The `is` lowering over a literal union tests the receiver once per member, re-reading it each
time, and refuses a receiver it cannot re-read (a call or an optional chain) instead of
spilling it to a local first. The refusal names the mechanism, not a contract. The numeric
twin is [D3617](D3617.md); the `K | string` spelling was pinned as a refusal by
`is-litunion-arm-call-receiver-rejected.vl`, whose header named the same missing spill slot.
That pin was a capability gap, not a design rule, and now runs as
`is-litunion-arm-call-receiver-evaluated-once.vl`.
