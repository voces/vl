#### Mechanism

The maker is built at `K` (D15719), because its value reaches `K` through `t`, so `mk` returns
`(ref K)`. The holder `t` is un-annotated, and its cell is read from the checker's type of the
call, the union of the two literal records, so the cell is the union box and `global.set` gets K.
The emitter stamps the call with the record it is built at (`litKeptStamp`), but the holder's cell
rungs (`letHeldTyOf`) never read that stamp for a call initialiser. Once given the record,
`bindCellGo` re-read it through `repOfNodeAt`, which boxes any node whose own type is a union. A
value `if` joining such a call with a literal is a third face, D16979.
