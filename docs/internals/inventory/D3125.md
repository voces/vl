### D3125 — a hole `.map` callback whose returns join its `i32 | null` element with a `string` builds invalid wasm

**check-clean invalid wasm · clause 1 · open, the join lift PARKED after four rounds of #3280 with its price named (`d3125-lift-price`, 521 cells) · found by the #3276 review · the same on master `cc890c9f4` · filed 2026-09-28 against master `cc890c9f4`**

Repro:

    function h(x) {
      print([x].map((e) => { if e == null { return "n" } return e })[0])
    }
    const a: i32 | null = null
    h(a)
    // vl check: rc 0.  vl run: invalid module inside `__lambda_1`, expected (ref $type), found i32

Want:

    n

#### Mechanism

Not localised past the ablation. The callback's returns join to `string | i32`, a box, but the
`return e` arm leaves the narrowed `i32` unboxed where the lambda's result expects the box. A
declared return, `(e): string | i32 => …`, boxes it and prints `n`.

`.map` callback that builds only at the instance's pin (D3125's return join, D3126's null

  destination's element, D3143), at an `if` arm and at a return: 285 cells of

- round 4 gated those deliveries on a literal receiver and a boxed, record, `f64` or niche
