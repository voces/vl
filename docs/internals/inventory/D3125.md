### D3125 — a hole `.map` callback whose returns join its `i32 | null` element with a `string` builds invalid wasm

**closed · a lambda clone whose body hands back two or more values takes its return annotation from the template's checked join, substituted at the pin, rather than from its first valued return alone · fixture `tests/cases/generics/lambda-returns-join-at-pin.vl` · was check-clean invalid wasm · clause 1 · found by the #3276 review, 140 invalid and 18 wrong-value cells of lane FF's `ff3` grid · the same on master `cc890c9f4` · filed 2026-09-28 against master `cc890c9f4`, closed 2026-09-29 against master `07d414042`**

Repro:

    function h(x) {
      print([x].map((e) => { if e == null { return "n" } return e })[0])
    }
    const a: i32 | null = null
    h(a)
    // vl check: rc 0.  vl run: invalid module inside `__lambda_1`, expected (ref $type), found i32

Want:

    n

#### Mechanism

`monoCloneLambdaSubst` annotates an un-annotated clone's return from `fnRetExprOf`, which
for a body with no tail value is the first valued return, `return "n"`. Its type names no type
parameter, so the clone got no annotation and its return was inferred as `string`, while the
`return e` arm delivers the narrowed `i32`. A body with a tail `e` took the tail's `T` alone
and annotated `i32`, the other half of the same miss. The template's checked signature holds
the join (`string | T`), and it is what a clone with two or more returned values now takes.
The result's readers take the same join: an inline callback with two or more returned values
answers its checked join at the pin (`mapCbJoinPinTy`), and a local holding the `.map` result in
a hole instance reads its element through its initializer, where it read the hole's variable
and recovered a `string | null` element non-null (the #3280 review's `g3` cells). An `if`
expression holding such results reads the element both arms agree on. Delivered through an
assignment, an `if` arm, a return or a tail value, such a result stays refused
(`mapPinLiftedDeliveries`), since those positions build it at their destination (D3143).

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `(e): string \| i32 => …` declared | prints `n` | **yes** (the inferred join) |
| `return 0` in place of `return "n"` | prints `0` | **yes** (a join wider than `i32`) |
| `function h<T>(x: T)` | invalid wasm | no (a type parameter does the same) |
| the pin value `4`, not `null` | invalid wasm | no (a validation failure, not a path) |
| top level, `[a].map(…)` | prints `n` | **yes** (the instance) |
