### D3125 — a hole `.map` callback whose returns join its `i32 | null` element with a `string` builds invalid wasm

**closed 2026-10-14 — the witness prints `n` · an un-annotated callback clone takes its template's checked return when that is a deferred join with a concrete, non-null arm (`string | _`, `tyIsArmedDeferredJoin`), as it already did for a kept-apart join, so the pin re-folds it to `string | i32` and boxes `return e` (`monoCloneLambdaSubst`) · fixture `tests/cases/generics/map-callback-hole-join-return.vl` · all 50 `J2` cells of `d3125-lift-price` run (22 were check-clean invalid wasm on master, 28 refused by the emitter), none of its 521 cells is lost or silenced, a `1 > 2`-guarded `return e` that printed `null` now prints `k`, and [D3188](D3188.md) closes with it · a named callback with the same join is still refused, [D4719](D4719.md) · was check-clean invalid wasm · clause 1 · found by the #3276 review · filed 2026-09-28 against master `cc890c9f4`**

Repro:

    function h(x) {
      print([x].map((e) => { if e == null { return "n" } return e })[0])
    }
    const a: i32 | null = null
    h(a)
    // vl check: rc 0.  vl run: invalid module inside `__lambda_1`, expected (ref $type), found i32

Want:

    n

#### Mechanism

The callback's returns join to `string | i32`, a box, but the `return e` arm left the narrowed
`i32` unboxed where the lambda's result expects the box. A declared return,
`(e): string | i32 => …`, boxes it and prints `n`. The per-pin clone of an un-annotated callback
took its return from its last return expression's type unless the checked return was a
kept-apart join (D3520). Here the checked return is a deferred join, `string | _`, so the clone
was typed `string` and the box was never built. The clone now takes that join too when it holds a
concrete, non-null arm. `_ | null` keeps the nullable lowering the last return gives it: taking
that join as well cost 8 runs and silenced 39 refusals of the set's `J1` cells. A join of holes
only (`_ | _`, D3616) is left too: taking it fixed D3616's witness but turned the same call bound
to a local into invalid wasm.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `(e): string \| i32 => …` declared | prints `n` | **yes** (the inferred join) |
| `return 0` in place of `return "n"` | prints `0` | **yes** (a join wider than `i32`) |
| `function h<T>(x: T)` | invalid wasm | no (a type parameter does the same) |
| the pin value `4`, not `null` | invalid wasm | no (a validation failure, not a path) |
| top level, `[a].map(…)` | prints `n` | **yes** (the instance) |

#### Price

#3280 lifted this refusal for four rounds, with D3125 and D3126 together, and PARKED it. A
`.map` callback that builds only at the instance's pin (D3125's return join, D3126's null
fold) is a result list whose element the callback alone decides, and the positions it is
delivered through each type it their own way:

- round 1 built the clone at its checked join, which runs when bound and read in place;
- round 2 found a hole instance reading the result through a local as the hole's variable,
  so a `string | null` element was recovered non-null (traps) and a `boolean | null` one printed
  `1` (#3280 review, `rv3280-17445/g3`, 12 cells);
- round 3 found the result silent at an assignment (`n = [x].map(…)` builds its receiver at the
  destination's element, D3143), at an `if` arm and at a return: 285 cells of
  `rv3280r2-21889/f` (264 invalid, 12 traps, 9 wrong values);
- round 4 gated those deliveries on a literal receiver and a boxed, record, `f64` or niche
  element, and missed both ways: a spread receiver was refused where master runs, and a call,
  a `.filter` receiver, a local and an argument position still went silent. Over
  `rv3280r4-3058/h` (14,580 cells) that was 224 runs lost and 297 refusals gone silent.

Those 521 cells are the named set `d3125-lift-price`
(`scripts/silent-sweep/census/d3125-lift-price.json`, grid `scripts/silent-sweep/d3125/gen.py`,
in `distilled/named/`), recorded at master's outcome: a lift may lose none of the 224 runs and
silence none of the 297 refusals. The order the rounds point to is to wire the deliveries first
(D3143's receiver built at the destination, the hole's local read, the `if` arm and the return
typed at the element), then lift the refusal, and grade every receiver of that grid at every
position.
