### D3831 — a block-local `<U>` generic reading a captured list of its enclosing generic's parameter reads the list at the wrong element rep

**closed 2026-10-08 by lane SC · was check-clean silently wrong · found in review of lane SC · filed 2026-10-08 against master `5a281ef27` · pins: `tests/cases/generics/nested-generic-reads-enclosing-pin.vl`, `tests/cases/generics/nested-generic-reads-enclosing-pin-positions.vl`**

Repro:

    function outer<T>(x: T) {
      const ys = [x, x]
      function inner<U>(u: U) { print(ys[1]) }
      inner(1)
    }
    outer(true)
    // vl check: rc 0.  vl run: rc 0
    // PRINTS 1

Want:

    true

#### Mechanism

`inner`'s instance bound only its own `U`. Every reader that types a value at a type parameter
from an instance's binding (`pinSubOperandTyOf`, `exactOperandTyOf`, `monoPinSubTyOf`) stopped
at the first row it met and gave up when `T` stayed open, so a capture typed at `T` fell back
to its rep. That rep is right for every type except `boolean` and a literal union, which share
`i32`. The close does three things:

* the nested instance binds the enclosing instance's parameters as well (`monoEnclosingPinRow`);
* the readers carry a partly substituted type on to the enclosing row;
* three classifiers that did not ask any reader now do: an element read, a for-in over a
  captured list (including an un-annotated enclosing function's hole), and a nullable-boolean
  capture. A generic argument naming a captured list's element also reads that element's type.

A nested generic that redeclares the enclosing name is left to master's path ([D3840](D3840.md)).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `inner`'s own `<U>` (`function inner(u: i32)`) | prints `true` | **yes** |
| the capture of `ys` (`print(x)` instead of `print(ys[1])`) | prints `true` | **yes** |
| `outer`'s `<T>` (`function outer(x)`, a hole) | still prints `1` | no |
| the pin of `U` (`inner("k")`) | still prints `1` | no |
| a second `outer` instance (`outer("s")` added) | check-clean invalid wasm inside `outer$1` (that row) | the neighbouring row |

#### Grading list

* `print(ys[1])` at an `f64`, `string` and record `T`: each should print the value.
* A closure over `ys` inside `inner` (`const g = () => print(ys[1])`).
* The lane SC rows for a nested `<U>` capturing an enclosing parameter close with this one; re-grade them together.
