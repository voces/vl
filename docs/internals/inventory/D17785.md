### D17785 — function-local lambdas whose set a second list tags have no read of their list's element

**closed 2026-11-28 by COV-UNION · runs, its witness prints its expected value · was a loud emit reject, `cannot yet lower this statement (narrowed read)` · a tag dispatch's local callee the set stores as its member id is read as stored, its build, whatever rep the call plans for its read (`tagCallee`, ir_build.vl), as a global's and a capture's already are · pinned by `tests/cases/closures/tagged-set-local-element-read.vl` · a callee its place stores as a closure over lambda arms (a popped element, an in-place element call) is D17799**

Repro:

    function main() {
      const f = (a) => a + 1
      const d = (a) => a * 2
      const two = [f, d]
      const s = two[1]
      print(s(3))
      const m = [f]
      print(m[0](3))
    }
    main()
    // vl check: rc 0.  vl run: emit error (narrowed read)

Want:

    6
    4

#### Mechanism

The local `s` is built as the tagged set's member id (`i32`), while the call's read of it was
planned at a closure (`exprRepOf`), so the dispatch's callee read refused. A module binding and a
capture were already read at their stored rep for the dispatch (`tagCallee`); a local was not.
