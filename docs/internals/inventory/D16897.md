#### Mechanism

The list-union rewrite replaces the read's node with an `is` per member (`luMembers`), which
would change every instance of the shared hole body, so it declines under a pinned re-check.
The pin's floor (`memberFloorMsg`, the index and `for` checks) then refuses the read. Ruling
(a): the pin types the read and its instance lowers it per arm; `.length` is done.
