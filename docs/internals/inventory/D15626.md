### D15626 — a list literal of joined functions handed through a hole callee that forwards it to the callee calling an element at two types is taken as a value with no signature

**loud emit reject · clause 2 · `vl check` rc 0, then `emitProgram: a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type` · found closing D15625 · filed 2026-11-09 against master `5db4b193`**

Repro:

    function id(v) { return v }
    function dbl(v) { return v + v }
    function call2(fs, x) { print(fs[1](x)) }
    function call1(fs, x) { call2(fs, x) }
    function runOne(g, h) {
      call1([g, h], 7)
      call1([g, h], "u")
    }
    runOne(dbl, id)

Want:

    7
    u

#### Mechanism

Not yet ablated to a mechanism. The join `{dbl, id}` is the set of `call2`'s call through `fs`;
`call1`'s `fs` forwards to it, and the hands of `g` and `h` sit in the literal handed to
`call1`, one forward further out than `ftFwdInSubsets` reaches from the call's own parameter.
