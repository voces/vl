### D17074 — a binding of a record union narrows to the wider arm while its literal is built at the arm with a nullable literal set

**check-clean silently wrong · filed 2026-11-23 against master `e6cb8541` (IR-N5)**

Repro:

    type C = { v: "a" | "b" | null }
    type D = { v: string }
    function g(u: C | D) { if u is C { return "C" } return "D" }
    let w: C | D = { v: "b" }
    print(g(w))
    print(w is C)
    // vl check: rc 0, warns "`is` check type 'C' can never match a value of type D"
    // vl run: prints C, then false

Want:

    C
    true

#### Mechanism

The literal `{ v: "b" }` is built at `C`, the arm its field value fits by value (D4056), so the
value carries `C`'s tag and `g` tests it as `C`. The checker narrows the binding `w` to `D`
instead, then folds `w is C` to `false` with a warning. The static narrowing and the runtime tag
disagree. The narrowing is the suspect: it must pick the arm the literal is built at.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the reassignment (literal in the initializer) | still `C` / `false` | no |
| a module global (a local binding instead) | still `C` / `false` | no |
| a literal only `D` can take (`{ v: "zz" }`) | `D` / `false`, correct | **yes** |
| `| null` in `C`'s literal set | `C` / `true`, correct | **yes** |
