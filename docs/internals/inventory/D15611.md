### D15611 — a generic called through a function parameter and through a list of it at two types traps on an indirect call

**loads then traps · clause 1 · `vl check` rc 0, prints `5`, then `wasm trap: indirect call type mismatch` · found filing D15609 · filed 2026-11-09 against master `d4901c70`**

Repro:

    function id(v) { return v }
    function call1(f, x) { print(f(x)) }
    function call0(fs, x) { call1(fs[0], x) }
    call1(id, 5)
    call0([id], "s")

    5
    s

#### Mechanism

Not traced. `call1` is one instance whose parameter `f` is a closure; the element `fs[0]` handed
to it at `string` is `id`'s closure at the other signature, and the call casts it at the first.
