#### Mechanism

D9935's close compares a struct row reading more than 32 fields through one helper,
`__eq_<row>__` (`eqHelpReserve`, wasmEmit.vl), whose body had no locals beyond its two
parameters. `eqHelpFieldPaths` declined a row holding a field whose compare needs frame slots,
a list's backing stash and counters or a nullable scalar's box, so every row above it compared
inline per path as before. The helper now lays out the same frame a function comparing that
row would, so such a field is one path and the row takes the helper.
