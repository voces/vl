#### Mechanism

D9935's close compares a struct row reading more than 32 fields through one helper,
`__eq_<row>__` (`eqHelpReserve`, wasmEmit.vl), whose body has no locals beyond its two
parameters. `eqHelpFieldPaths` declines a row holding a field whose compare needs frame slots,
a list's backing stash and counters or a nullable scalar's box, so every row above it compares
inline per path as before. Giving the helper the frame those fields use would close it.
