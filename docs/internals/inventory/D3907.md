### D3907 — a two-link alias chain to a capturing nested generic, called from a sibling function or a lambda, is refused at emit

**closed 2026-10-09 by lane SC, with D3902 · runs · was loud emit reject · found in review of #3480 (`rv3481/pr2/q07b`, `q07c`, `q07d`, `p07`) · filed 2026-10-09 against master `4a7f5604d` · pins: `tests/cases/generics/alias-of-capturing-nested-generic-delivered-as-value.vl`**

Repro:

    function outer<T>(x: T) {
      function inner<U>(u: U) {
        print(x)
        print(u)
      }
      const k = inner
      const j = k
      function sib() { j(5) }
      sib()
    }
    outer(7)
    outer("s")
    outer(false)
    // vl check: rc 0.  vl build: emitProgram: call to unknown function

Want:

    7
    5
    s
    5
    false
    5

#### Mechanism

A read of an alias of a generic was one node across instances of the enclosing generic, so a
two-link chain read from a sibling function reached no instance for its frame. Closed with D3902:
a value `Ident` naming a generic alias is copied per instance like a callee. The generic-sibling
spelling (q07c) still refuses, now with `captured variable not found`.
