### D3907 — a two-link alias chain to a capturing nested generic, called from a sibling function or a lambda, is refused at emit

**loud emit reject · found in review of #3480 (`rv3481/pr2/q07b`, `q07c`, `q07d`, `p07`) · filed 2026-10-09 against master `4a7f5604d`**

Repro:

    function outer<T>(x: T) {
      function inner<U>(u: U) {
        print(x)
        print(u)
      }
      const k = inner
      const j = k
      function sib() { j(5) }
      sib()
    }
    outer(7)
    outer("s")
    outer(false)
    // vl check: rc 0.  vl build: emitProgram: call to unknown function

Want:

    7
    5
    s
    5
    false
    5

#### Mechanism

Not located. D3894 resolves a chain read in the frame that declares it; from a sibling function
or a lambda the chain's first link is a capture, and the call reaches no function. Invalid wasm
on master, a loud refusal since D3894. A generic sibling (`function sib2<V>(v: V) { j(v) }`)
reads `captured variable not found in enclosing frame` instead.
