### D10370 — a `let` bound to a call returning one of two generics, written with a call whose arms are a different set and called at two types, refuses

**loud emit reject · `vl check` rc 0 · `a generic function taken as a value reaches no call that fixes its type` · clause 2 · CAPABILITY: the write spelled `k = pick(0)`, whose arms are the binding's own, runs as [D10322](D10322.md) · found closing [D10321](D10321.md) and [D10322](D10322.md) · present on master `cc89864b9` · filed 2026-10-22 against master `cc89864b9`**

Repro:

    function id<T>(x: T): T { x }
    function same<T>(x: T): T {
      print("same")
      x
    }
    function third<T>(x: T): T {

    function pick(n: i32) {
      if n > 1 { return id }
      return same
    }

      if n > 1 { return id }
      if n > 0 { return third }
      return same
    }

#### Mechanism

`fsPlanMember` (fn_split.vl) plans a choosing write only when the write's arms are the
binding's own (`wl.length != callLeaves.length` declines it). `pick3` has three arms against
the binding's two, so no lane is planned and the binding is called at two types with no split.
The refusal points at `return id` in `pick`.

| `k("a")` also called before the write | same refusal | no |
