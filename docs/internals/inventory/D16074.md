### D16074 — `monoInstanceFor` builds nothing, silently, when its pin list is shorter than the template's parameters; one caller relies on that

**closed · the no-op is now a named `emitFail`, and its one caller skips the call it relied on · found by lane I making the no-op loud for #7937 · filed 2026-11-14 against master `875f5c70`**

Repro:

    function inc(x) { x + 1 }
    function run(f) {
      const k = f
      print(2)
    }
    run(inc)

Want:

    2

#### Mechanism

`monoInstanceFor` (emit_mono) returns 0, with no instance and no failure, when
`params.length != pinnedNames.length`. The caller that depends on this is `monoCoerceFnValueTys`
(its `monoInstanceFor` call in the `Ident` arm). It is called when a generic function value
that nothing calls is delivered at a destination whose function type names no parameters, such
as an un-annotated hole parameter, `if`, labelled-block or list value. It passes the
destination's empty parameter list as pins, so no instance is built, and none is needed because
nothing calls the value. When the check was replaced with an `emitFail` naming the template,
these 19 programs stopped building:

- inventory: D6881, D6912, D6913, D6931, D6992, D7000, D7002, D14225 and D14780;
- `tests/cases/closures/`: called-hole-fn-param-alias-compared,
  hole-fn-called-by-name-and-aliased-by-param, hole-fn-if-to-hole-param,
  hole-fn-if-to-unread-param-called-elsewhere, hole-fn-labelled-block-value,
  hole-fn-list-to-unread-param, uncalled-hole-fn-alias-compared,
  uncalled-hole-fn-compared-in-callee, uncalled-hole-fn-inert-uses and
  uncalled-hole-fn-to-unread-param.

All of them came through `monoCoerceFnValueTys`; no other caller reached the check in the
24,301-program sweep population.

#### Grading list

Closed by making `monoCoerceFnValueTys` skip `monoInstanceFor` when the destination names no
parameters for a template that takes some (`monoPinsNoneFor`), and making `monoInstanceFor`'s
mismatch an `emitFail` naming the template. In the sweep population the refusal fires nowhere,
and every program, the 19 above included, builds byte-identically. With the skip disabled,
this row's witness reaches the refusal: "`inc` takes 1 parameter but its instance was asked for
at 0 pinned types".
