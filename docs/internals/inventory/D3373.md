### D3373 — `??` over a nullable function value has no lowering

**loud emit reject · pre-existing, the `fn_*_coal` cells of the #3295 review's `tw/` set · filed 2026-09-30 against master `6e6a5301b`**

Repro:

    function h(n: i32) {
      const v = (if n == 2 { (q: i32) => q + 100 } else { null }) ?? (q: i32) => q + 102
      print(v(1))
    }
    h(0)
    h(2)
    // vl check: rc 0.  vl run: emitProgram: `??` over this nullable value is not supported yet

Want:

    103
    101

#### Mechanism

The `??` ladder has rungs for a nullable struct, variant, list, string, map and value box, and
none for the nullable closure cell `(ref null $closure)`, so any `fn | null` left operand
reaches the floor, bound or not. The narrowing spelling (`if o != null { o(1) } else { … }`)
runs, and so does `??` over an `i32 | null` from the same if-expression.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the if-expression (an annotated `const o: ((i32) => i32) \| null = …`, then `o ?? d`) | same refusal | no |
| the `??` (`if o != null { print(o(1)) } else { print(103) }`) | runs | **yes** |
| the function (`if n == 2 { 100 } else { null }` with `?? 102`) | runs | **yes** |
