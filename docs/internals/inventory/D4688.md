#### Mechanism

The field `f` was laid out as a list of the struct `H` (`array (mut (ref null $H))`) rather
than of the union `H | string`, and the second element was pushed into it unboxed. The field's
code came from the arena, a ref list, but its element companion was read off the literal's FIRST
element alone. That element resolved to `H`'s row, so the list was typed by it. With no declared
`H`, or with the string first, no row resolved and the arena named the union.
