### D2334 — the pre-passes that reserve frames, lift closures, pin generics and rename module names had no `Spread` arm, so a spread's source was lowered against state none of them prepared

**closed 2026-09-24 — the witness prints `6` and `4`. Filed against master `816bda01e`, where it is check-clean invalid wasm (`expected i32, found (ref $type)`). Found by the D2331 sweep**

Repro:

    const b = [3, 4]
    const a = [1, ...(b + b), 9]
    print(a.length)
    print(a[4])
    // prints 4

#### Mechanism

The emitter lowers `...e` by emitting `e` in the enclosing function's frame, but every pre-pass
that prepares that frame walks expressions by hand and stopped at the `Spread` node: the concat
and compare scan (`leqScanExpr`), the map/filter/slice/keys scan (`mfScan`), the push/pop,
call-ref, string-op, map-op, stash, array-intrinsic and `??`-call scans, closure lifting
(`liftFnsInExpr`), the capture-box rewrite, the global-promotion mark, the monomorphizer's
walks and callback pin, and the module merge's rename (`modRwExpr`). A concat in a spread wrote
a frame whose slots were never declared at its type (invalid wasm), a slice, `.map`, `.filter`,
`.keys()` or `.values()` in one refused at emit, a generic call or closure call in one built
invalid wasm, and in any program that imports a module — a string interpolation imports
`std:fmt` — `[...b]` and `f(...b)` over a top-level binding refused at check with `undeclared
identifier`. Each walker now descends a spread's source like any other operand.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the spread (`b + b` bound to a `const`, then `...bb`) | runs | **yes** |
| top level (inside a function, a call's rest argument) | still invalid wasm | no |
| the concat (`.slice`, `.map`, `.filter`, `.keys()`, a closure call, a generic call, `.push`) | still refused or invalid wasm | no |
| a spread of a plain name with a module import (`[1, ...b]` beside `"\{x}"`) | check reject | no |
| the same without any import | runs | **yes** |

#### Grading list

`tests/cases/lists/spread-operand-walked.vl` — one line per walker, each refused, invalid or
rejected at check on master. Its last line is a callback under a plain list literal in a generic
(`[p.filter(f)]`), which the monomorphizer's callback pin also skipped and which was check-clean
invalid wasm on master.
