#### Mechanism

`recSpreadCallCopy` (check_fit_rules.vl) copies a call's spread list into the element only when
`recListElemRecCopies` accepts the pair, and that asked for a bare record destination; with
`{x: f64} | null` no copy was recorded and `recListSpreadsApartRefuse` refused the spread. The
copy itself (`emitRecListCopyTop`, wasmEmit.vl) converted records element by element with no
null arm. Both now read a nullable pair by its records, from the element types the checker
recorded, and the copy stores a null where the source element is one. A maker delivered whole at
a wider nullable-record list took the same rule, and was an invalid module (D16616).
