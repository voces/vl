### D16613 — a spread of a maker's list of nullable records beside a wider record part is refused, though the `const` spelling runs

**loud check reject · clause 2 · `this list holds elements built as {x: f64} | null where line 2 gives them, and elements held at their own {x: i32} | null here ... a record is shared, not copied` · a call's list is fresh, so nothing is shared · split from D16449's call face (`spread-call-nullable-record-list-wider.matrix.vl`) · filed 2026-11-15 against master `e56efd8c2` · open**

Repro:

    function mk() { return [{ x: 1 }, null] }
    const v = [...mk(), { x: 2.5 }]
    print((v[0] ?? { x: 0.0 }).x + 0.25)
    // vl check: this list holds elements built as {x: f64} | null where line 2 gives them, ...

Want:

    1.25

#### Mechanism

`recSpreadCallCopy` (check_fit_rules.vl) copies a call's spread list into the element only when
`recListElemRecCopies` accepts the pair, and that asks for a bare record destination; with
`{x: f64} | null` no copy is recorded and `recListSpreadsApartRefuse` refuses the spread. The
copy itself (`emitRecListCopyTop`, wasmEmit.vl) converts records element by element and has no
null arm, so accepting the pair at check is not enough: the copy needs a null test per element.
