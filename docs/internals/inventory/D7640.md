#### Mechanism

`__str_eq__` was 10–12% of self time in diderven's check and build, almost all of it on equal
strings that were different objects. Three sources made those objects:

* The lexer emptied its intern tables at every `tokenize`, so each module spelled every name
  afresh. The tables now persist for the compile and are emptied once the sources they keep
  alive pass `LEX_PIN_LIMIT` bytes (compiler/lexer.vl).
* Each importer rebuilt a merged name (`name + modSuffixOf(m)`) as a new concatenation.
  `modRenamePush` now hands every rename to one name the first string it saw (`modCanonTo`,
  compiler/driver.vl).
* `cloSigPosOfKey` scanned the `$fnsig` key list linearly. It now reads `cloSigPosBy`, a map
  maintained beside every push and reset of `cloSigKeys`.
