### D9382 — a function returning a numeric literal union is not assignable to one returning `i32`

**loud check reject · clause 2 · CAPABILITY: the value itself converts (`const b: i32 = a` runs), and a string literal union's function converts to one returning `string` · found closing [D9282](D9282.md) · present on master `a28f82fcb` · filed 2026-10-21 against master `a28f82fcb`**

Repro:

    type N = 1 | 2
    const a: N = 2
    const b: i32 = a
    const f: () => N = () => a
    const g: () => i32 = f
    print(b + g())
    // vl check: cannot assign () => N to 'g' of type () => i32

Want:

    4

#### Mechanism

Not traced. Function-type assignability does not take a numeric literal union's result as an
`i32` one, although the value converts and both are the same i32 representation. The same
refusal holds at a generic (`same<T>` bound at `(k: N) => i32`) and through an un-annotated
function's return.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `g` (call `f()` directly) | runs | **yes** |
| the numeric union (`type K = "x" \| "y"`, `() => string`) | runs | **yes** |
