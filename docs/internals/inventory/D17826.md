### D17826 — a binding of a `.map` over a list of a set's records, aliased into a list annotated at a closed function field, has no interned shape at emit

**open · loud emit reject · clause 1 · `vl check` rc 0, `emitProgram: ref valtype with no interned shape` · filed 2026-11-28 against master `3b5582185` (lane START-2)**

Repro:

    function id(a) { return a }
    function deliver() { return [{ f: id }] }
    const m = deliver().map((r) => r)
    const v: { f: (a: f64) => f64 }[] = m
    print(v[0].f(2.5))
    // vl check: rc 0.  vl build: emit error, ref valtype with no interned shape

Want:

    2.5

#### Mechanism

Not traced. `m` and `v` are one storage and every call through it is at (f64), so the container
contract lets it run (D17819's agreeing face). Delivered straight (`const v: … = deliver().map(…)`)
it runs after D17793's identity copy; through the binding the delivery is an alias, never a copy,
and the map's element is left at a layout no shape interns. The message names an internal error.
