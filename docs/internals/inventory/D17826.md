### D17826 — a binding of a `.map` over a list of a set's records, aliased into a list annotated at a closed function field, has no interned shape at emit

**closed 2026-11-28 by lane START-2 by design — now a loud check reject: `a {f: (_) => _} cannot be delivered as {f: (f64) => f64} here: … A record is shared, not copied, …` · the binding is the annotated list's storage, so the `.map` it holds is consumed at the closed element and its callback typed there (`fvaAliasNote` → `fvaMapCbTyped`); an identity callback is record sharing, and one building fresh records runs at the closed element · fixtures `tests/cases/functions/error-map-identity-binding-aliased-into-closed-list.vl`, `map-binding-of-fresh-records-aliased-into-closed-list.vl` · was: loud emit reject · clause 1 · `emitProgram: ref valtype with no interned shape` · filed 2026-11-28 against master `3b5582185` (lane START-2)**

Repro:

    function id(a) { return a }
    function deliver() { return [{ f: id }] }
    const m = deliver().map((r) => r)
    const v: { f: (a: f64) => f64 }[] = m
    print(v[0].f(2.5))
    // vl check: rc 0.  vl build: emit error, ref valtype with no interned shape

#### Mechanism

`m` and `v` are one storage, but the map's callback was typed only at its own open result, so
the set held as closures at `v` left `m`'s element at a layout no shape interns. Typing the
callback at the element the aliased storage closes (D17793's rule, applied at the alias) makes the
identity spelling the record-sharing refusal and a fresh-record callback run.

#### Ablation

| spelling | outcome |
| --- | --- |
| this repro | loud emit reject |
| `const m = deliver()` (no `.map`) | runs (`2.5`) |
| the map delivered straight to `v` | refused as record sharing (D17793) |
| a callback building fresh records `(r) => ({ f: r.f })` | runs (`2.5`) |
