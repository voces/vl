### D3326 — a generic's inferred return of a list local is invalid wasm when a dead inner block declares the same name at another type

**check-clean invalid wasm · clause 1 · found by #3307's review, present on master before it · the same on master `b6378e95b` · filed 2026-09-30 against master `b6378e95b`, re-run and unchanged on `6f4ddc8b2` (after #3307's shadowed-name close)**

Repro:

    function g<T>(w: T) {
      let x = ["p", "q"]
      if true {
        let x = 5
        print(x)
      }
      return x
    }
    const r1 = g(7)
    print(r1[0])
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `g`: type mismatch: expected (ref $type), found i32

Want:

    5
    p

#### Mechanism

Not traced. The instance's inferred return reads as the inner `let x = 5`, though the `return`
resolves to the outer list and the inner block has closed. Only a list or record-list outer
fails, and only against an inner value of another type (the same list type runs), so the two
bindings of one name disagree about their rep inside one instance. `vl check` is rc 0 and the
non-generic spelling is right.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `g` not generic, `(w: i32)` | runs, `5` then `p` | **yes** |
| `g<T>(w: T): string[]` annotated | runs, `5` then `p` | **yes** (an inferred return) |
| the inner `let x` renamed `y` | runs | **yes** (the same name) |
| the inner block shadowing the parameter `w` instead | runs | **yes** (the shadowed name is a local) |
| the `if true` removed, a bare `{ ... }` block | still invalid | no |
| the parameter a bare hole, `g(w)` | still invalid | no |
| the outer `let` made `const` | still invalid | no |
| the inner value unused, `let x = 5` alone | still invalid | no |
| the inner value an `f64`, `boolean`, `string` or list of another type | still invalid | no |
| the inner value a list of the SAME type | runs | **yes** (a different type) |
| the outer a `string`, `f64`, record or `string \| null` | runs | **yes** (a list outer) |
| the outer a record list `O[]` | still invalid | no |
