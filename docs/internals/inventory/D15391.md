### D15391 — a record nested in a record, its field a list of an un-annotated function, written whole, is refused at emit

**closed 2026-11-12, runs and prints `2` then `2.5` · the tag pass joins a written record's list literal at any depth, and builds the binding's own record literal at the written record's widened type, so the two share one row (`ftWrittenInitNote`, check_fn_tag.vl) · was a loud emit reject, clause 2, `emitProgram: ref valtype with no interned shape`; the field one record up ran since D15351, so a mechanism · found closing D15351 · filed 2026-11-04 against master `063e6712`**

Repro:

    function id1(a) { return a }
    function id2(a) { return a }
    let r = { g: { f: [id1] } }
    r = { g: { f: [id2] } }
    print(r.g.f[0](2))
    print(r.g.f[0](2.5))

Want:

    2
    2.5

#### Mechanism

D15351 joins only a list literal that is a direct field of the record written whole. Joined one record deeper, the outer written literal and the initialiser's outer literal mint two struct rows of one shape whose nested-field targets are different `#anon` names, and the module is check-clean invalid wasm; so the join stops at depth 0 and the program stays refused.
