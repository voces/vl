### D3135 — a closure capturing an un-annotated binding of a walk variable narrowed to `Circle | null` is invalid wasm

**check-clean invalid wasm · clause 1 · found by lane NB's position grid (`nulrec__bind_un_capt__walk`) and the #3279 review · the same on master `a29230611` · filed 2026-09-28 against master `a29230611`**

Repro:

    type Circle = { r: i32 }
    function show(w: Circle | null): i32 {
      if w == null { return 0 - 1 }
      return w.r
    }
    const zz: (Circle | null | string)[] = [{ r: 4 }, null, "s"]

      if !(e is string) {
        const c = e

#### Mechanism

Not localised past the ablation. This is probably the record twin of [D3119](D3119.md) and
[D3120](D3120.md). `c` takes the `nulvariant` cell ([D3107](D3107.md)), and the closure's
capture of it disagrees with that cell's rep. The same binding read without a closure runs, and
so does the same capture of `c` bound from a narrowed parameter.
