#### Mechanism

Ref-list slots dedup by rep, so the literal's slot can be the one the generic's template
interned first, whose stored union name is the template's `S | T`. `emitArrRef` boxed each
element under that stored name instead of the union the literal's own type keys to. Now
`rlUnionNameOfTy` reads the row of the list's closed element type whenever the slot's
element type is open. The inferred spelling `f(v)` refused loud before D10880. D10880's inner
binder made it reach the same boxing, and its first cut was invalid wasm there too: the
textual `monoBindFromAnn` bound `T` to the whole element union. `monoBindInnerArmPins`, which
pins `T` at the arena's arm first, closed that.
