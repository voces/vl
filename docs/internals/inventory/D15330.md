### D15330 — a `const` bound to a value `if` of records of un-annotated functions, handed to an un-annotated parameter, is refused at emit

**open · loud emit reject · `emitProgram: cannot take the generic function id1 as a value — a function value carries ONE signature` · clause 2 · the choice handed inline runs since D15301 M2 · found grading D15301 M2 · filed 2026-11-04 against master `6f1693f5`**

Repro:

    function id1(a) { return a }
    function id2(a) { return a }
    const c = 1 > 0
    function g(r) { return r.f(2) }
    const k = if c { { f: id1 } } else { { f: id2 } }
    print(g(k))

Want:

    2

#### Mechanism

The choice handed inline is delivered at the parameter's instance type by `monoElabDeliver`
(emit_mono.vl), which D15301 M2 taught a value `if`. A `const` read is a closed read there, and
the binding's choice is still open, so nothing delivers it. A `const` of one record literal runs
the same way, through the binding's own delivery.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the binding (`g(<choice>)` inline) | runs | **yes** |
| `id2` (both arms `{ f: id1 }`) | still refuses | no |
| the choice (`const k = { f: id1 }`) | runs | **yes** |
| a direct call `k.f(2)` before `g(k)` | runs | **yes** |
