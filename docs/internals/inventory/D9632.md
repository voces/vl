### D9632 — a list literal of two un-annotated parameters bound at `i32` and `i64` is not indexable at emit

**loud emit reject · clause 2 · `vl check` rc 0 · CAPABILITY: `function g(x: i32, y: i64)` prints `5000000000` · found closing [D9620](D9620.md) · present on master `54fb716a1` · filed 2026-10-22 against master `54fb716a1`**

Repro:

    function f(x, y) {
      const xs = [x, y]
      print(xs[1])
    }
    f(2, 5000000000)
    // vl run: emitProgram: index receiver is not an array or string

Want:

    5000000000

#### Mechanism

Not traced. The body's list literal joins two distinct holes. At the pin, the two holes are
two numeric widths, and the emitter finds no list type for the receiver. It may be one
mechanism with [D9631](D9631.md), where one element is a derived hole of the other.

#### Grading list

Both arguments at `i32` (the control: `f(2, 5)` prints `5`), `i32` beside `i64`, `i32` beside `f64`,
and the list returned rather than bound.
