### D9632 — a list literal of two un-annotated parameters bound at `i32` and `i64` is not indexable at emit

**closed · runs, prints `5000000000` · was loud emit reject, `vl check` rc 0, clause 2 · CAPABILITY: `function g(x: i32, y: i64)` prints `5000000000` · found closing [D9620](D9620.md) · filed 2026-10-22 against master `54fb716a1` · closed by reading a local whose type is a join the checker kept apart at its members' runtime join for the instance (`holeTyRead`, emit_ty_canon.vl), as the instance's binding of it is annotated · fixture `generics/hole-param-list-literal-mixed-width.vl`, matrix `hole-element-list-literal` 0 → 66 of 66 · with [D9631](D9631.md)**

Repro:

    function f(x, y) {
      const xs = [x, y]
      print(xs[1])
    }
    f(2, 5000000000)
    // vl run: emitProgram: index receiver is not an array or string

Want:

    5000000000

#### Mechanism

The checker types `[x, y]` as a list of the join `x | y` kept apart, and the per-instance
copy annotates the binding with the members' join at the pin, `(i32 | i64)[]`. The reads
of the binding asked `nodeTyInOf`, whose hole reader re-joined a kept-apart union only when
its members collapsed to one type, so `xs` at `i32` and `i64` read as -1 and the index had
no receiver type. The reader now answers the same runtime join the binding was annotated
with. Both arguments at `i32` collapsed to `i32[]` and ran before.

#### Grading list

Both arguments at `i32` (the control: `f(2, 5)` prints `5`), `i32` beside `i64`, `i32`
beside `f64`, two strings, the list returned rather than bound, a `for` over it, `.length`
and an `is` test of each element.
