#### Mechanism

`gl("s")` returns the gradual list `(T | i32)[]` (D3079's ruling), at the `string` pin a
`(string | i32)[]`. Stored un-annotated in a record field, the anonymous row records the
template's open `(T | i32)[]` as the field's storage type, whose rep is absent: the one row in
1,495 matrix templates (85,570 programs), the corpus, the distilled cells and the capability
probes whose storage type has no rep (a scratch compiler failing on every no-rep read, validated
on a control). The ref-list storage then has no interned element, and emit refuses.
