### D3965 — a `const` alias of a written `let` of a generic function, called, builds invalid wasm

**check-clean invalid wasm · clause 1 · found in review of #3500 (`rv3500/alias_in_loop`) · filed 2026-10-10 against master `eb81bdd89`**

Repro:

    function inner<U>(u: U) { print("I"); print(u) }
    function main() {
      let k = inner
      const a = k
      a(5)
      k = inner
    }
    main()
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `main`

Want:

    I
    5

#### Mechanism

Not located. `k` is written, so it holds one closure signature, and the call through the alias
`a` is where that signature would come from; the alias's call does not pin the seed, so `k` keeps
the generic's un-pinned type. D3962 is the reverse direction (an alias seeds the written `let`).
