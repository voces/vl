### D9552 — a list built from an un-annotated function parameter, returned and read by `.map`, calls an unknown function

**loud emit reject · `vl check` rc 0 · `call to unknown function` · clause 2 · found closing [D9501](D9501.md) · present on master `6b307f6ac` · filed 2026-10-22 against master `6b307f6ac`**

Repro:

    function inc(a) { return a + 1 }
    function deliver(g) { return [g, g] }
    const v = deliver(inc)
    print(v.map((f) => f(3))[1])
    // vl check rc 0.  vl run: emit error: emitProgram: call to unknown function

#### Mechanism

Not traced, and not probed. A guess: the returned literal's elements are the parameter `g`, not a
function's name, so the pin the callback gives the element slot has no function to instance
there, and `inc` reaches the callback still un-instanced.
