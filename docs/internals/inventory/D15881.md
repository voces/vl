### D15881 — a `K | null` literal-union field read through an un-narrowed union of records is refused at emit, where a `string | null` or `boolean | null` field there runs

**loud emit reject · clause 2 · `emitProgram: field access receiver is not a struct` · found probing `readFieldStoreKind`'s re-tag for the step-7 codecs (w314) · filed 2026-11-12 against master `8f3814d1`**

Repro:

    type K = "a" | "b"
    type R = { k: K | null, s: string }
    type S = { k: K | null, s: string, extra: i32 }
    const n: R = { k: null, s: "lo" }
    const u: R | S = n
    print(u.k == null)

Want:

    true

#### Mechanism

Not traced. The read is a shared field of an un-narrowed union of records (`memberFieldPos`
answers `FPOS_SHARED`). The field is the `K | null` niche, code 30. The ablation pins the family
to that one storage: the same read of a `string | null`, `boolean | null` or plain `K` field
runs, and so does the read under `is` narrowing.
