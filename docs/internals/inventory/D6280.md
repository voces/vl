    function add(a, b) { return a + b }
    function apply2(g) {
      print(g(1, 2))

#### Mechanism

From the ablation only. `apply2`'s hole `g` is split per type (D5611), and the outcome turns
on `app3` calling the same generic at the type of one of the split's slots. When `app3` calls
it at a type the split does not use, or when the generic is a `const` lambda, the program runs.
