### D3214 — a returned join of a type parameter with a literal at a nullable-record pin traps when the call yields null

**loads then traps · clause 1 · open · was check-clean invalid wasm on master `94670f728`, and this is what D2906's close turns it into · found by the GU lane re-grading the rv3236 `k1` grid (`recn_{5,s}_litarm_annot`) · filed 2026-09-29**

Repro:

    type P = { x: i32 }
    function g<T>(a: T, c: boolean) {
      const r = if c { a } else { 5 }
      r
    }
    const w: P | null = null
    const v: P | null | i32 = g(w, true)
    if v == null { print("null") } else if v is P { print(v.x) } else { print(v) }
    // vl check: rc 0.  vl run: prints nothing, then wasm trap: cast failure

Want:

    null

#### Mechanism

Not localised past the ablation. At `T := P | null` the join is the null-bearing union
`P | null | i32`; an inferred return that bears null is left unboxed for its caller
(`monoPinRetBox`), and the instance hands back the null inside a box the caller's `== null`
does not see, so `is P` casts the null arm.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `{ x: 1 }` for `w` | prints `1` | **yes** (a null value) |
| `function g(a: P | null, …)`, the direct spelling | prints `null` | **yes** (the type parameter) |
| `i32 | null` for the pin | prints `null` | **yes** (a reference arm) |
