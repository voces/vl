### D2404 — a path narrowing survives a writing call later in the same `&&` condition

**closed 2026-09-25 — now a loud check reject (the `as f64` return: `v.value` reads at `f64 |
boolean` in the then-arm) · was loads then traps, clause 1 · filed against master `2304ece42`,
closed against master `a277bf7b0` · fixture `tests/cases/soundness/call-in-condition-ends-path-fact.vl`**

Repro:

    type W = { value: f64 | boolean }
    function mutate(w: W): boolean {
      w.value = true
      true
    }
    function f(v: W): f64 {
      if v.value is f64 && mutate(v) {
        return v.value as f64
      }
      0.0
    }
    print(f({ value: 1.5 }))
    // vl check: rc 0.  vl run: wasm trap: cast failure

#### Mechanism

The then-arm's narrowings are collected from the condition after it is checked, and the call's
invalidation marks only the overlay entries live while the condition is checked; the arm's own
entry for `v.value` is pushed afterwards, unmarked. D2390 drops a bare name's condition fact
when a call inside the condition may write it (`crFilterCond`, mirrored by the emitter's
`condNarrowDropOf` window); the filter skips path keys, which is this row.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the write in `mutate` | runs, prints `1.5` | **yes** |
| the order (`mutate(v) && v.value is f64`) | runs, prints `0` | **yes** |

#### Grading list

The `||` twin guarding an early return (`if !(v.value is f64) || mutate(v) { return 0.0 }`),
and the index-cell and map-value spellings of the place.

#### Close

`crFilterCond` now drops a path fact too when a call in the condition may write the path, and
banks it for the emitter's decline window as it does a bare name. The `||` early-return spelling
and the index cell are covered.
