### D4265 — `is` over record arms whose shared field is a box with a member only some of whose values fit is refused at emit

**loud emit reject · clause 2 · follows D4056: before it the union itself was refused · found by the review of #3579 · filed 2026-10-12 against master `3efb1763c`**

Repro:

    type A = { v: "a" | "b" }
    type B = { v: i32 | string }
    function f(u: A | B) {
      if u is A { print("A") } else { print("B") }
    }
    const b: B = { v: "a" }
    f(b)
    const c: B = { v: 3 }
    f(c)
    // vl check: rc 0.  vl run: emitProgram: `is` across record arms whose shared field's box holds a member only some of whose values fit

Want:

    A
    B

#### Mechanism

`b`'s field `v` is a union box whose `string` member fits `A`'s `"a" | "b"` only for some
strings. The cross-arm term answers a box field by its member tag alone, which settles a member
every value of which fits or none does; a member that needs its value compared has no term.

#### Ablation

| variant | outcome |
| --- | --- |
| this witness | emit refusal |
| `A = { v: string }` (the member fits whole) | runs, `A B` |
| `A = { v: 1 \| 2 }`, `B = { v: i32 \| null }` | emit refusal |
