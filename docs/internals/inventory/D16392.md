#### Mechanism

`xs` is built at `J`, so the list `ws` is built there too, and the call `os0()`'s fresh result is
copied into that build (D15652). The copy (`recCopyBoxesOnly`) boxes a scalar into its `T | null`,
but has no arm for a reference (a function, or a record inside a list) into its nullable, so the
call's result keeps its own storage and the list refuses it. A call's result is fresh, so nothing
is shared; the refusal says so itself.
