#### Mechanism

[D10020](D10020.md)'s: the module-scope `m.set("k", inc)` into a map whose value is `id`'s own
`(T) => T` is a deferred row with no owner, and the call `r4(1.5)` binds `T` to `f64` by name
and re-validates it. The fill functions are scenery: two `Map()`s set with `id` directly
refuse the same way.
