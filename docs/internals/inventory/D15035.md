#### Mechanism

`cnt3` is never called, yet its member constraint (`x.each`, on `cnt3`'s own `T`) refused `both`'s
call `ks[0](7)`. A call through a value names no declaration (`CSTR_NODECL`), so `cstrOwnedBy`
re-validates every owner's constraints under the call's binding, and `ks[0]`'s binding, `id`'s
`T = i32`, bound `cnt3`'s `T` by name. Only the constant-list route reached it: the same program
through a `let`, a local, a parameter or an annotated list ran at `c3fecdab`.

#5898 closed it while this row was open: its parent `c3fecdab` refuses the witness, and #5898
built to its fixpoint prints `14`. An owner-aware validation of the call's member and UFCS
constraints, built for this row, then moved no `tests/**/*.vl` program on master and was dropped;
the fixture stays as the pin.
