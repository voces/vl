`monoClosedTyPin` of that type is `{[i32]:boolean}|string|null`: it renders the set at its map
rep. So both calls pin one instance, and `r(ns)` prints `false`. Measured with the
`elabTestsTyVar` decline removed from `monoElabCompositeTy`; with it in place, the composite path
answers and the program runs.
