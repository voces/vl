### D17223 — a `print` of an assignment of a call's result to a never-filled `let u = null` is written as an `i32` where the cell holds `nullref`

**closed 2026-11-24 by IR-N9, #9945 · runs, prints `null` · was check-clean invalid wasm, clause 1 (`type mismatch: expected i32, found nullref`, claimed and claimless alike) · #9945 widened `asgYieldsNulHole` to accept a right side `exprIsNulNone` answers, so `printArmOf` takes its `nulNone` arm for an assignment of a null-typed call · found by V7 (queue) verifying #9949 · filed 2026-11-24 against master `fa5e2ff9` by IR-N5**

Repro:

    function same<T>(x: T): T { return x }
    function f() { let u = null; print(u = same(null)) }
    f()
    // vl check: rc 0.  vl run before #9945: invalid module; since #9945: prints null.

Want:

    null

#### Mechanism

The value of an assignment into a `null` cell is printed on `printArmOf`'s `nulNone` arm only for
an assignment of `null` itself (`asgYieldsNulHole`); one whose right side is a call takes a scalar
arm and prints an `i32` where the store leaves the cell's `nullref`. D17222 is the captured
binding's statement spelling of the same `null`-cell write.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the call (`print(u = null)`) | runs, prints `null` | **yes** |
| the `print` (`u = same(null); print(u)`) | runs | **yes** |
| `print` for a binding (`const y = (u = same(null)); print(y)`) | runs | **yes** |
| the generic (`same(x: null): null`) | still invalid | no |
| the function (the same at module scope) | still invalid | no |
