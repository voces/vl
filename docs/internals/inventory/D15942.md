#### Mechanism

Not yet traced. The pushed argument is the `if` expression itself. Bound first (`const j = if k { m2 }
else { fnMap }; xs.push(j)`), the program runs. So the push delivery types the join's maps at the
list's `(f64) => f64`, while the stored closures keep another signature, and nothing refuses.
