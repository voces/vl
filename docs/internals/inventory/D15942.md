#### Mechanism

Probed 2026-11-12. In the trapping module `half` was the uncalled stub `(func $half)`, with no
parameters, and its closure trampoline was `(structref) -> ()`. Bound first, it was
`(param f64) (result f64)`. `elabSlotDeliveries` for the branch maps was empty inline and
`(f64) => f64` bound: the check stamps the bare argument `j` with the element type, but not the
`if` argument, whose branch reads carry only the join's open type. The original note follows. The pushed argument is the `if` expression itself. Bound first (`const j = if k { m2 }
else { fnMap }; xs.push(j)`), the program runs. So the push delivery types the join's maps at the
list's `(f64) => f64`, while the stored closures keep another signature, and nothing refuses.
