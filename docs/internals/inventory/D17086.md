**closed 2026-11-23 · runs, prints `false` `true` · was check-clean invalid wasm · clause 1 · `vl check` rc 0 · fixed in emit_classify.vl and wasmEmit.vl: `nicheReadKindAt` names a value-atom list's box tag for a read narrowed to `L[] | null`, `readRepKinds` reads it at that nullable list, and `emitNicheReadTail` turns the box's null tag into the list's `ref.null` and any other tag into its payload cast to the list wrapper · pin: `tests/cases/unions/box-narrowed-to-nullable-list-copied.vl` · found by lane IR-N7 sizing the IR's `narrowed read` class, which already refused the read · filed 2026-11-23 against master `1b69a6af1`, pre-existing**

#### Mechanism

A read narrowed out of a union box to a niche `A | null` converts the box at the read
(`identReadArmOf`'s `niche` arm, D2590): the null tag becomes the niche's null, any other tag the
unboxed payload. `nicheReadKindAt` named only `boolean | null` and `string | null`, so a read
narrowed to a value-atom list's `L[] | null` took the plain `local` arm and wrote the box itself
into a destination the checker types as the nullable list. A null test and a `??` read the box's
tag, so those spellings ran; every copy (a binding, an argument, a return, a field read) did not.
