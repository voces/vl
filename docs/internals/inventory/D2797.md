### D2797 — a list literal of the second record arm of a union of two record lists is built at the first arm's row

**loud emit reject · clause 2 · 24 cells of the D2783 grid (`*_Sq_Circle_*`) · the same on master `b586b6063` · filed 2026-09-27 against master `b586b6063`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: f64 }
    const q: Sq[] | Circle[] = [{ r: 3 }]
    if q is Circle[] { print(q[0].r) } else { print(-1) }
    // vl check: rc 0.  vl run: emitProgram: object literal is missing a struct field

#### Mechanism

A list literal of object literals delivered into `Sq[] | Circle[]` builds its elements against
the union's first record-list arm, so `{ r: 3 }` is checked against `Sq`'s fields and refused.
The first arm's literal (`[{ s: 1.5 }]`) and a `Circle`-typed value (`[c]`) both run. Not yet
localised further.
