### D9231 — a `.map` whose callback builds a new closure gives a list nothing can call

**closed · runs, prints `9` · was loud emit reject, `emitProgram: callee is not a function name`, `vl check` rc 0 · clause 2 · was `emitProgram: ref valtype with no interned shape` on master `12b0bac7e` · found closing [D9171](D9171.md) · filed 2026-10-21 against master `12b0bac7e` · closed by grouping a bare function element before its `[]` when a ref-list row's kind is read off its name (`refElemArrName`, emit_shape_rows.vl), so the row a `.map` interns for its function-valued result is a closure list · fixture `closures/map-builds-closure-list.vl` · matrix `map-builds-closure-list.matrix.vl`**

Repro:

    const xs = [1, 2]
    const gs = xs.map((k) => (y: i32): i32 => y + k)
    print(gs[1](7))
    // vl check rc 0.  vl run: prints 9

#### Mechanism

`collectMapFilterUse` interns the ref-list row for a `.map` whose callback returns a function,
under the element's rendered name `(i32)=>i32`. `refElemArrName` re-formed that as
`(i32)=>i32[]`, which reads as a function returning `i32[]`, so the row took the struct kind
rather than the closure kind; the index read then found no closure element to call. A list
literal or an annotation of the same function type interned the row correctly, which is why
`.map` over a list of functions (D9171) and every annotated spelling ran. Without a call,
`gs.length` alone was check-clean invalid wasm through the same row.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the capture (`(y: i32): i32 => y + 1`) | same refusal | no |
| the fresh lambda (`(_k) => inc`, a declared function) | same refusal | no |
| an annotation `((y: i32) => i32)[]` anywhere in the program | runs | **yes** |
| the call (`print(gs.length)`) | check-clean invalid wasm | no |

#### Grading list

The same inside a function, returned from a function, handed to an un-annotated parameter,
read in a loop, read through a binding, at `f64` and `() => string`, and a `.map` over the
result all run. `.map` over a list of functions returning a wrapper
`(f) => (y: i32): i32 => f(y) + 1` ran before the fix and still does.
