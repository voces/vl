### D3950 — a capture cell seeded with a hole lambda and delivered as a value is refused at emit

**loud emit reject · clause 2 · found in review of #3498 (`rv3498/p16`) · filed 2026-10-10 against master `429e7b093`**

Repro:

    function ci(f: (n: i32) => void, n: i32) { f(n) }
    function other<V>(v: V) { print("O"); print(v) }
    function main() {
      let k = (x) => { print("L"); print(x) }
      const flip = () => { k = other }
      ci(k, 1)
      flip()
      ci(k, 2)
    }
    main()
    // vl check: rc 0.  vl run: emitProgram: ref valtype with no interned shape

Want:

    L
    1
    O
    2

#### Mechanism

Not located. The hole lambda that seeds the cell is pinned by a call through the cell (D3845)
but not by a delivery of the cell read, so the cell's element has no function type when the
cell is built. A declared generic seed is instanced at the delivered type (D3939); a hole
lambda seed is not.
