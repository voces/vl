### D3950 — a capture cell seeded with a hole lambda and delivered as a value is refused at emit

**closed 2026-10-10 by lane SC · runs · was loud emit reject · clause 2 · pins: `tests/cases/closures/captured-cell-hole-lambda-seed-delivered.vl` · found in review of #3498 (`rv3498/p16`) · filed 2026-10-10 against master `429e7b093`**

Repro:

    function ci(f: (n: i32) => void, n: i32) { f(n) }
    function other<V>(v: V) { print("O"); print(v) }
    function main() {
      let k = (x) => { print("L"); print(x) }
      const flip = () => { k = other }
      ci(k, 1)
      flip()
      ci(k, 2)
    }
    main()
    // vl check: rc 0.  vl run: emitProgram: ref valtype with no interned shape

Want:

    L
    1
    O
    2

#### Mechanism

The hole lambda that seeds the cell was pinned by a call through the cell (D3845) but not by a
delivery of the cell's read, so the cell's element had no function type when it was built. A hole
lambda written into a capture cell as a literal is now pinned at the type the cell is delivered or
called at (`monoCellLamTake`), and a second signature for it is the binding conflict, refused.
