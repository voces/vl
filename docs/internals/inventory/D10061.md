#### Mechanism

Under the numeric-join ruling's `??` extension a runtime `i32` and a runtime `f64` join as
`i32 | f64`, so rewriting `if q != null { q } else { b }` as `q ?? b` keeps `is i32`.
`coalJoinApart` (check_fit_rules.vl) declined when the left operand was a field, an index or a
method call (`coalLhsParts`), a gate D3451 added because the emitter of that day read those at
the operand's own rep; the emitter now builds every one of them at the union. `coalesceAtomKind`
(emit_classify.vl) carried the same gate and drops it with it. In a recursive function the join
still widens for every spelling, the `if` one included: [D10090](D10090.md).
