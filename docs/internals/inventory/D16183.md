### D16183 — a `return` of a write to a captured binding of a wider type, or of a field written in a returned `if` arm, has no value lowering

**closed · was a loud emit reject, `an assignment used as a value whose type is not its target's has no value lowering` · clause 2 · the tail spelling of the same write ran (D2285, D2170) · filed 2026-11-15 against master `3d526470a`**

Repro:

    type K = "ww" | "zz"
    function f() {
      let k: K | null = null
      const set = () => {
        return k = "ww"
      }
      print(set())
      print(k)
    }
    f()

Want:

    ww
    ww

#### Mechanism

An assignment yields its right side, but a captured binding's cell holds the binding's
declared type, so the cell's re-read is not the value at the write's type. `cboxYieldTail`
split a function's tail write `v = e` into `const t = e; v = t; t` (a literal kept its store and
was yielded as a copy), and `spillTail` spilled a tail `if`'s field-write arms; both read only
the body's last statement. A `return v = e`, and a returned `if` whose arm writes a field, kept
the unsplit write, whose value the emitter has no rung for. `cboxYieldRets` and
`spillValueWrites` now give every `return` the split its tail spelling gets.
