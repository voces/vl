**closed · now a loud check reject, `cannot write 'inner' to 'm': called at (i32) it returns void, where 'retV', also written to it, returns i32` · DESIGN (owner ruling 2026-11-05, B2: a `let` seeded with a function that returns a value refuses a write of one that returns nothing; one seeded with a function that returns nothing takes a value-returning write, whose result its calls drop, and reading that result is refused) · was loads then traps, clause 1 · the void-result twin of [D9003](D9003.md), found re-minimising the split plan's W-named census group (W-split) · filed 2026-11-02 against master `a29c90e7`**

#### Mechanism

D9003's `holeLetWritesDisagree` compares the results of the functions written to one `let` at
the types it is called at, and refuses a write whose result differs. A function whose body
returns nothing is not compared against one that returns a value, so the write is accepted
and the call through the binding is lowered at the seed's signature while the slot holds the
written function. The generic spelling traps the same way when the seed returns a value; seeded
with the function that returns nothing, it runs.
