### D3745 — a record pushed into an empty `[]` argument by a hole callee, whose own empty list field the callee then pushes a record into, is refused at emit

**closed · was loud emit reject · clause 2 · found by the #3398 review · on master `082c36f12` the same program is the positioned `object literal field count does not match struct`; with #3398 it is the positionless sentence below · filed 2026-10-06**

Repro:

    function take(a) {
      a.push({ x: 1, ys: [] })
      a[0].ys.push({ z: 2 })
      print(a[0].ys[0].z)
    }
    take([])
    // vl check: rc 0.  vl run: emitProgram: only i32[] arrays and struct/union element
    // arrays are supported

#### Mechanism

Not traced to the line. [D2218](D2218.md)'s close pins the argument's element from the
body's first push, giving `{ x: i32, ys: _[] }`. The second push's receiver is a field of an
element of the parameter, and the pin pass only follows an element of the parameter, so
`ys`'s element is likely still open when the emitter names the instance. The name it
builds (`monoArgTyName`'s empty-literal rung, through `monoAnnPinName`) is then refused by
`checkArrName`. Not confirmed by printing the pin; that is the first step for whoever takes
the row.

Closed by D5344's fix. `objFieldHolesToI32` defaults the literal's `ys` hole at program end
through `arrDefPinHoleElem`, which takes the hole callee's first write (`{ z: i32 }`), so the
field has an element and the instance is named. The witness prints `2`, and is pinned in
`tests/cases/structs/record-lit-empty-list-field.vl`. The element-store spelling also runs. A
second call at a different inner element is still not built, and is [D5472](D5472.md).

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the direct spelling (`const a = []` at module scope) | runs, prints `2` | **yes**: the hole parameter |
| `a: { x: i32, ys: { z: i32 }[] }[]` annotated | runs, prints `2` | **yes** |
| the inner list non-empty (`ys: [{ z: 0 }]`, read `ys[1]`) | runs, prints `2` | **yes**: the inner empty list |
| declared `type H`/`type Z` and `a: H[]` | runs, prints `2` | **yes** |

#### Grading list

* The same body with the inner push replaced by an element store (`a[0].ys[0] = …` after a push).
* A second call of `take` with a different inner element type: the pin must not leak through
  the template's own literal row.
