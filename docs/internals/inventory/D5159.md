### D5159 — a written `let` initialised with a generic that fixes a union parameter is refused as holding two call types when called at one

**loud emit reject · `vl check` rc 0 · clause 2 · found closing D4892 · filed 2026-10-16 against master `83752e744`**

Repro:

    function s<A, B>(a: A, b: B) { print("S") }
    function w<B>(a: i32 | string, b: B) { print("W"); print(a); print(b) }
    function main() {
      let k = w
      k = s
      k(5, true)
    }
    main()
    // vl check: rc 0.  vl run: emit error, the reassigned function binding `k` holds functions called at more than one argument type

Want:

    S

#### Mechanism

There is one call, at `(i32, boolean)`, and the split still counts two argument types. The
initializer is the binding's declaration, so `k`'s type starts from `w`'s `(i32 | string, B)`,
and the planner appears to count that declared parameter as a second call type beside the
call's `i32`. D4892's write adapter does not reach it, because the adapter rewrites a WRITE, and
the initializer is not one of `k`'s owner-row writes. That reading has not been ablated beyond
the table below.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| no write at all (`let k = w; k(5, true)`) | runs, `W 5 true` | **yes** |
| the write `k = w` instead of `k = s` | still refuses the same way | no (`s` is scenery) |
| `w`'s first parameter `i32` | runs, `S` | **yes** |
| the order swapped (`let k = s; k = w`) | runs, `W 5 true` (D4892, closed) | **yes** |

#### Grading list

- the same binding delivered by value into a parameter `(a: i32, b: boolean) => void`
