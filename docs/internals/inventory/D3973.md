### D3973 — a narrowed nullable function written by a closure into a nullable-annotated capture cell traps

**loads then traps · found in review of #3498 (`rv3498/round6/n01`, `n03`) · filed 2026-10-10 against master `56f77d80f`**

Repro:

    function inner<U>(u: U) { print("I"); print(u) }
    function other<V>(v: V) { print("O"); print(v) }
    function main() {
      let k: ((n: i32) => void) | null = (n: i32) => { print("P"); print(n) }
      const f: ((n: i32) => void) | null = (n: i32) => { print("Q"); print(n) }
      const w = () => { if f != null { k = f } }
      if k != null { k(1) }
      w()
      if k != null { k(2) }
    }
    main()
    // vl check: rc 0.  vl run: prints P 1, then wasm trap: wasm `unreachable` instruction executed in `w`

Want:

    P
    1
    Q
    2

#### Mechanism

Not located. The cell `k` is annotated `((n: i32) => void) | null`, so its writes never reach
`monoCellValueTake`; the store of `f`'s narrowed read in the closure `w` traps. D3972 is the
un-annotated spelling, refused; D3974 the non-null annotated one.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `k = f` with `f` not narrowed (no `if f != null`) | runs (`round6/n02`) | **yes** |
| `k` seeded with a generic, `let k: … = other` (`round6/n03`) | still traps | no |
