### D2840 — an object literal whose shape mentions a type parameter has no struct row outside a binding

**loud emit reject · clause 2 · the residue of D2804 · filed 2026-09-27 against master `7323baf55`**

Repro:

    function f<T>(t: T) { { v: [t] } }
    print(f(7).v.length)
    // vl check: rc 0.  vl run: emitProgram: ref valtype with no interned shape

#### Mechanism

D2804's mechanism at every position that is not an un-annotated binding. No anonymous row is
minted for a literal whose recorded shape carries a type parameter, and D2804's fix gives only
a `let` an annotation to intern from. A literal returned, passed as an argument, read by
`.field` directly, or held as a list element still has no row. The un-annotated function
`function f(t) { const o = { v: [t] } }` is the same gap: it is not cloned, so no pin
substitutes its hole. The general fix mints a row per instance for each clone's literal from
the substituted shape, which needs the clone to own its literal node rather than share it.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the type parameter | runs | **yes** |
| the position (bind the literal first) | runs | **yes** |

#### Grading list

`g({ v: t })` into an un-annotated `g` (`monomorphize: unsupported argument type`),
`print({ v: t }.v)` (`field access but no struct type declared`), `const o = [{ v: t }]`
(`ref array literal with no interned element type`), and `function f(t) { const o = { v: [t] };
print(o.v.length) }` with `f(7)` (`object literal but no struct type declared`).
