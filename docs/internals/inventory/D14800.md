### D14800 — a returned join of literal-bound consts delivered its arms at its literal set, though the inferred return widens to `string`

**closed · runs, prints `zz`, `none` · was a refutation pin for step 5's string-to-atom hook · re-graded 2026-11-01 (coordinator ruling (b)): the contextual type was the wrong side, not the storage. The checker types an inferred return widened, like a `let` (`(n: i32) => string`, `string | null`), so the return is a string and stored as one; only the join's arms carried the set, stamped by `joinLeavesAt`, and nothing re-stamped them with the result they are delivered to. `adoptRetLits` now re-stamps a returned value, and the leaves of a returned join, delivered at a set of widening literals with the inferred result (`retJoinWidens`, check_inferred_return.vl), so they lower as that result's strings · the return-position twin of [D14757](D14757.md) · filed 2026-11-01 against master `4eb649fb`**

Repro:

    const Z = "zz"
    const W = "ww"
    const f = (n: i32) => if n > 0 { Z } else { W }
    print(f(1))
    function g(n: i32) { if n > 0 { Z } else { null } }
    print(g(0) ?? "none")

Want:

    zz
    none

#### Mechanism

The join's value leaves recorded the join's type as their contextual type: `"zz" | "ww"`, or
`"zz" | null` (D7446's one-literal niche), both of which rep as the i32 atom. The inferred return
widens that set to `string` (`finishInferredReturn`'s `widenLitTy`), and the function's type, its
callers' reads and its storage all agree on the string. A `let` re-stamps its initializer's leaves
with its bound type (`recordCtxTy(n.letInit, bound)`); a return re-stamped nothing, so a reader of
the contextual type saw the set where the value lands in a string.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the const reads (`if n > 0 { "zz" } else { null }`) | the leaves' record widens, agreeing with the storage | **yes** |
| the inferred return (`(n: i32): string \| null => …`) | the return is stored as its annotation, agreeing | **yes** |
| the return position (`const v = if … { Z } else { null }`) | runs under the switch since D14757's fix | **yes** |
