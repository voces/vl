#### Mechanism

Not ablated past the table. The list stamp waits on a call's rep row (`recListCallRepTy`) for a
`const` holding a call, and asks it again in the late pass; by then the pass's build table is gone,
so the held part `xs[0]` answers unbuilt too, and neither the D15372 refusal nor a build fires.
