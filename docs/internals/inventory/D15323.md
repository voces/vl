### D15323 — a holder of a returned record of members, copied into a record field or list element, refuses at emit

**open · loud emit reject · clause 2 (`emitProgram: a function returning a parameter called at two signatures is called where its result is not used at one of them`) · owned by lane bundle · found grading [D15321](D15321.md) · filed 2026-11-04 against master `bf39d33f0`**

Repro:

    function lap(f) {
      const _a = f(2.5)
      const _b = f(3)
      return f
    }
    const u = lap((a) => a + 1)
    const w = { f: u }
    print("\{w.f(4)} \{w.f(1.5)}")

Want:

    5 2.5

#### Mechanism

Not yet measured. A holder's fact (D15144) admits a read only as a call through it, a hand, a
copy into a `const`, a `return` or a link (B2d). A read as a field or element of a literal is none
of them, so `u` gets no fact. The slot facts (B2a, B2b) take only a call stored in the literal
directly.

#### Ablation

| spelling | outcome |
| --- | --- |
| the call stored directly, `{ f: lap((a) => a + 1) }` | runs (B2a) |
| `const xs = [u]`, then `xs[0](4)` | the same refusal |

#### Grading list

- The list spelling above, and the record field read through a copy (`const v = w.f`).
