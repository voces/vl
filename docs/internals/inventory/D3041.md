### D3041 — D791's record-into-union converting copy snapshots a list the caller writes after the delivery

**closed · a record list delivered as a list of union boxes from a root other than a fresh `const` literal is a VIEW: a final subtype of the union-box list's wrapper that keeps its source, whose element and length reads box through the source (`__rv_get__`, `__rv_len__`) and whose whole-list reads refresh its snapshot first (`__rv_sync__`); a `readonly` destination the write analysis declined is served by the same view · fixtures `tests/cases/unions/readonly-record-view-reads-source-annotated.vl`, `readonly-record-view-reads-source-inferred.vl` · matrix `readonly-record-view-written.matrix.vl` · was check-clean silently wrong · the ref twin of [D3028](D3028.md), found re-grading [D2162](D2162.md) · filed 2026-09-28 against master `3a71bb1f9`, closed 2026-09-28 against master `6c2dafc0b`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    function view(xs: Circle[]): readonly Shape[] { return xs }
    const a: Circle[] = [{ r: 1 }, { r: 2 }]
    const b = view(a)
    a[0] = { r: 7 }
    const e = b[0]
    if e is Circle { print(e.r) }
    // PRINTS 1

Want:

    7

#### Mechanism

`emitRefListWidenSite` copies a `Circle[]` delivered as a list of `Shape` boxes, boxing each
record, where `rlWidenAllowed` finds the root unwritten. As in D3028 that analysis follows a
local root's aliases only, so for the parameter `xs` it answers "unwritten" without seeing the
caller's `a`, and the copy is a snapshot the caller's writes never reach. D3028's fix does not
reach this pair: its view keeps a scalar source, and a view of a record list would read each
record through its source and box it at the read, over the ref-list wrapper's own type.

Built at the close, on D3028's design. Every union-box list shares one wrapper (its twin
signature is the box), so there is one destination: its wrapper opens as `sub`, and each record
row the checker saw delivered into it from an unfresh root (`refViewSrcTys`, recorded at the
delivery seam, a literal's fields and elements one seam down) gets a view type
`{back, len, cap, src}`. The view is keyed on the row's twin representative and the variant it
boxes as; a nullable row shares its non-null twin's view, which then tests each element for
`null` and boxes it under the null tag, as the copy does. Reads: an index read and `.length`
call `__rv_get__`/`__rv_len__`; a walk whose body may write does too; `.map`, `.filter`,
`.slice`, spread, concat, `==` and `.get` call `__rv_sync__` first; a hoisted index declines a
receiver that may be a view. A module with no such delivery mints nothing, so the compiler's own
seed is unchanged but for the new code.

The same view also serves the deliveries `emitRefListWidenDeclined` refused where the
destination is `readonly` (a record field's list, an element of a list of lists, a call
result): a view reads the source as it is, so it needs no write proof. The refusal still stands
for a mutable destination.
