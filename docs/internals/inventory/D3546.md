### D3546 — `is` a numeric literal union over an annotated join of type parameters answers true for a string

**closed 2026-10-03 by lane KJ — the witness prints `false` · was check-clean silently wrong, clause 1 · found by the #3344 review (`rv3344-aZMQ/isg`, `il__annjoinn__a-a`) · filed 2026-10-03 against master `f6e17953b` · fixture `tests/cases/generics/annotated-join-string-is-numeric-literal-union.vl`**

Repro:

    type L = 1 | 2
    function F<A, B>(x: A, y: B) {
      const v: A | B | null = x
      print(v is L)
    }
    F("a", "a")
    // master printed true

Want:

    false

#### Mechanism

At `("a", "a")` the annotation is `string | null`, a niche, and `is` over a niche is its
null test unless `nulNicheIsTestImpossible` proves the type no member of it. That proof named
records and string literal unions but not a numeric literal union, so the test answered
"present" for every string, and for `true` and a record at their pins too. A numeric literal
union is now no member of any niche.
