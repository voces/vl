Repro:

    type J = { f: i32 | null }
    function mk2() { return { f: null } }
    const dA: J = mk2()
    const src = [mk2()]
    function show(z: { f: null }) { print(z.f) }

#### Mechanism

The literal `[src[0]]` holds a `J` element. `recElemVarList` (D16783) names the literal as the
loop's list, but `recBuiltElemIn` reads a build only for a binding or a same-elements call, not
for a list literal whose parts are built reads. So `show` is not instanced at `J` and receives
a `J` struct at `{ f: null }`.
