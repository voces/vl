#### Mechanism

Cubic in the chain, and the trap was the null collector's heap filling with the garbage. Every
operator's emission (`emitBinExprNode`) asks its operands' width — `exprIsF32`, `exprIsF64`,
`exprIsI64`, `exprIsStrConcat` — and each of those recursed through the whole left subtree, so
one level cost O(n) and the emission O(n²). `exprIsF32` was a factor worse: at every level of
its own recursion it asked `binMixHardF64` of the left operand, which asked `exprIsF64` of the
whole subtree again, so one `exprIsF32` query was O(n²) and the emission O(n³). Named
backtrace: `repMk` ← `repOfTy` ← `tyKindOf` ← `exprIsF64` (× depth) ← `exprHasHardF64` ←
`binMixHardF64` ← `exprIsF32` (× depth) ← `emitBinExprNode`. The walkers that reserve the
string and list-compare frames (`exprHasStrOp`, `leqScanExpr`) asked `exprIsStrConcat` per
level the same way.

The parser marks the root of every chain of 16 or more arithmetic operators (`binRegion`,
`parseBinary`), including a chain an operator outside the arithmetic tiers is about to wrap
(`a + … + a == 0`, `if a + … + a > limit`, `b && a + … + a > 3`), and the classifiers memoise their answer per node for one SESSION: one
classification, or one emission or reservation walk, of the region under a marked root
(operators, parens, unary `-`/`~`; `bcSpineEnter`, `compiler/emit_classify.vl`). The session's
tables cover that region's node range alone and are dropped when it closes. Nothing a
classifier reads changes during a session — a region's operands are classified before any of
them is emitted — so the answers are the ones an unmemoised walk gives, and every
`tests/cases` program and distilled-corpus cell builds byte-identical. Code outside a marked
region pays one flag test per classification: 20 real plumb units +0.026% to +0.037% fuel (four re-read after the comparison round: +0.022% to +0.031%)
(the first round's program-wide switch cost +0.71% to +1.46% there, per the review, because `rt.vl`, which
every unit imports, holds one 16-operator string concatenation), the compiler's self-compile
−0.27%.
