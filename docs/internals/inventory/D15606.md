### D15606 — `is` over a bounded type parameter's field is refused when the pin makes the test false

**loud emit reject · clause 2 · `vl check` rc 0, then `emitProgram: \`is\` names a declared union member with no interned arm representation` · the true direction runs since D15544 · filed 2026-11-09 against master `de73ab0c`**

Repro:

    function boundShow<T: { x: i32 | string }>(t: T) {
      if t.x is string { print(t.x) } else { print(0) }
    }
    const a: { x: i32 } = { x: 7 }
    boundShow(a)
    // vl check: rc 0.  vl run: emit error, `is` names a declared union member with no interned arm representation

Want:

    0

#### Mechanism

At the pin `t.x` is a plain `i32`, so `is string` is false, and answering it so is not enough:
the instance types the then-branch's `t.x` as `string`, the template's narrowing, not `never`.
An emitter that answered `0` built `print(t.x)` as a string read of an `i32` and produced
invalid wasm (measured while closing D15544). The checker owes the instance's narrowing of a
pinned non-union operand by a disjoint test: `never`, which the emitter already lowers as
unreachable (D3178).
