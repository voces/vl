### D14535 — a `??` over an operand narrowed to non-null folds on the checker's read type; the emitter's narrowing-stack fold of it was unreachable

**runs today and must keep running · a Step 6 pin: the emit stack's second answer is deleted · filed 2026-10-27 against master `9549ca33a`**

Repro:

      if c { return 7 }
      null
    }

    if x != null { print(x ?? 0) }

#### Mechanism

`emit_rewrite` folds `x ?? d` to `x` whenever `nodeTyExcludesNull` holds of the operand, and
the checker types a narrowed read at its non-null arm, so a narrowed `??` never reaches
`emitCoalesceGo`. That function still carried an arm folding an `Ident` operand on
`narrowExcludesNull` (the emit narrowing stack). An instrumented build that failed loudly in
that arm fired on none of the 967 `??` fixtures nor on this witness, so the arm is deleted.
Reads the narrowing may no longer cover (D2801's `narrowedToNullKey`) are untouched.
