### D14423 — a call through a choice of hole functions whose argument is a function mints no member instance at that argument's type

**runs today and must keep running · refutation pin for the holes-close pin-caller deletion · found grading holes-close with `monoCallIfBound` and `monoIfBoundRetAtPin` removed · filed 2026-10-27 against master `ad860e97d`**

Repro:

    function add(a: i32, b: i32) { return a + b }
    function apply2(g) { print(g(1, 2)) }
    function apply3(g) { print(g(10, 20)) }
    function main(c: boolean) {
      const f = if c { apply2 } else { apply3 }
      f(add)
    }
    main(true)
    main(false)
    // today: 3, 30.  with both pin callers removed: emit reject, call to unknown function

#### Mechanism

`f(add)` dispatches over {apply2, apply3}, and each arm is a direct call of a member at the
call's argument tuple, here `Fn#add`. Without the pin, no instance of `apply2` or `apply3` is
enqueued at a function-typed tuple, so the arm names a function the emitter never built.  The
fixture is `closures/if-join-hole-fns-concrete-arg.vl`, which fails at its first such call.
