### D15748 — a module-scope `const` bundle returned from a function whose result is used as one member is refused at emit

**closed 2026-11-12, runs and prints `4` · was loud emit reject, clause 2, `a function returning a parameter called at two signatures is called where its result is not used at one of them` (invalid wasm on master before #7321) · found closing [D15740](D15740.md) · closed in the elaboration: a returned holder made in plain code holds its record under no instance, so an instanced returner's record (`elabRetValuesRecord`, emit_elab.vl) is read under the plain key and the caller picks its member as for a returned call · fixture `tests/cases/closures/hole-lambda-bundle-module-const-returned-one-member.vl` · not reached: a holder read where one member's type is expected, filed as [D15749](D15749.md)**

Repro:

    function lap(f) {
      f(2.5)
      f(3)
      return f
    }
    const c = lap((a) => a + 1)
    function g() { return c }
    const w = g()
    print(w(3))

Want:

    4

#### Mechanism

The returner is elaborated as an instance, and `elabRetValuesRecord` asked the returned holder's
initialiser call for its record under that instance; the call sits in plain code, so it had none
and the returner was not a record returner, while the holder still held the whole record. The
initialiser is now read under the plain key.
