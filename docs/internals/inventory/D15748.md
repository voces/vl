### D15748 — a module-scope `const` bundle returned from a function whose result is used as one member is refused at emit

**loud emit reject · clause 2 · `a function returning a parameter called at two signatures is called where its result is not used at one of them` · found closing [D15740](D15740.md) · filed 2026-11-11 against master `0a9e9948`**

Repro:

    function lap(f) {
      f(2.5)
      f(3)
      return f
    }
    const c = lap((a) => a + 1)
    function g() { return c }
    const w = g()
    print(w(3))

Want:

    4

#### Mechanism

The returner's call takes one member of the bundle record, by its holder (every read a call at
one signature) or by its destination (an annotation naming one member's type), so emit lowers the
returner at that member; the returned `const` is still the whole record. On master this built
invalid wasm (silent); `elabGlobalReturnerWhole` (emit_elab.vl) now keeps the refusal instead.
The fix is to project the member from the returned holder, as a returned call already is.

#### Ablation

| spelling | outcome | needed? |
| --- | --- | --- |
| `print(g()(3))` (no holder) | runs | **yes** |
| `const w = g()`, `w` called at both signatures | runs (D15740) | **yes** |
| `function g() { const k = lap((a) => a + 1); return k }` | refuses on master as well | no |
| `const w: (f64) => f64 = g()` | refuses (silent on master) | no |
| `function u(f: (f64) => f64) { print(f(4)) }` and `u(g())` | refuses (silent on master) | no |
