### D17065 — a union compare against a `string | null` operand, over a union with no `null` arm, reads the nullable operand as a non-null string

**check-clean invalid wasm · a soundness defect · filed 2026-11-23 against master `eeac5bb6` by lane IR-S1**

Repro:

    type U = i32 | string
    function g(u: U, k: string | null): boolean { return u == k }
    print(g("s", "s"))
    print(g(1, null))
    // vl check: rc 0.  vl run: invalid module (type mismatch: expected (ref $string), found (ref null $string))

Want:

    true
    false

#### Mechanism

`emitUnionConcreteEq` (`compiler/wasmEmit.vl`) tests a `string | null` operand's null only on the
`nulStrOther` leg, which requires the box's union to hold `null` (`unionSetHasNullTy`). With no
`null` arm the plain tail runs: the box's string payload is compared with the operand by the
non-null string compare, and the operand's `(ref null $string)` reaches a `(ref $string)` slot.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `null` added to `U` (`i32 \| string \| null`) | runs | **yes** |
| the operand's `\| null` (`k: string`) | runs | **yes** |
| the box a parameter (a call, a global) | still invalid | no |

#### Grading list

The same compare with the box a call result (`mk() == k`) and a module global (`gu == k`), and
each operand order.
