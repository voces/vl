#### Mechanism

`emitUnionConcreteEq` (`compiler/wasmEmit.vl`) tested a `string | null` operand's null only on the
`nulStrOther` leg, which required the box's union to hold `null` (`unionSetHasNullTy`) and the box
to be a place. Otherwise the plain arm ran: the box's string payload was compared with the
operand by the non-null string compare, and the operand's `(ref null $string)` reached a
`(ref $string)` slot. A `K | null` atom operand took the same path.
