#### Mechanism

The one-result judge's lift for a bound list's nested record path (`holeSlotFieldLift`,
`check_relate_core.vl`, D15805) reaches only a bounded number of fields. Past it, the judge's
one-result rule applies again and names a contract the shallower spellings do not have. The
refusal is a mechanism (depth), not a design rule.
