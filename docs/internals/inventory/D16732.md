`elabFnJoinDeepAt` (`check_elab_cap.vl`), which returned the join unchanged past six levels. The
read's set then held `inc0` alone, `holeSlotSetHolds` refused the lift, and the one-result judge
applied. The join walk now follows the type with an on-path list instead of a depth, as the rest
of [D16731](D16731.md)'s walks do; the refusal was the mechanism, not a design rule.
