### D3446 — a type-parameter write into a multi-member nullable union or a list cell keeps the template's read, so its pins read the wrong member

**check-clean silently wrong · clause 1 · open · the residue of #3321's scope ([D3240](D3240.md)), which left these places at master's read · identical on master `39097fdcb` · found by the #3321 review (`rv3321-htal/g1`) · filed 2026-09-30 against master `39097fdcb`**

Repro:

    function g<T>(x: T) {
      let s: string | i32 | null = null
      s = x
      print(s == null)
    }
    const v: string | i32 | null = null
    g(v)
    // PRINTS false

Want:

    true

#### Mechanism

D3240 re-types a place a `T` write narrowed at each pin (`HD_TVW`, `writeMemberTy`) for a name
or field declared `X | null` with one non-literal `X`. Two kinds of place keep master's read, by
the measured choice D3240 records: a union of several members, whose box the template's member
narrowing unboxes, and a list cell, whose narrowing a closure over the list would inherit
([D3419](D3419.md)). The literal-union place is [D3423](D3423.md). At those places the body is
still narrowed to non-null after `s = x`, so a nullable pin folds its null tests (a wrong
value), reads a null (a trap), or, for a list cell, emits the pin's value where the narrowed
cell type is expected (invalid wasm, even at a non-null pin).

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `let s: string \| null` | prints `true` (D3240's place) | **yes** (several members) |
| the direct spelling `g(x: string \| i32 \| null)` | prints `true` | **yes** |
| `const v: string \| null = null` (a narrower nullable pin) | prints `false` | no |
| `let s: string \| i32 \| null = 3` | prints `false` | no |
