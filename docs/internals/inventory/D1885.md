### D1885 — `match` refuses an un-annotated parameter that `is` and `==` both narrow, at every union element type

**loud check reject · clause 2 · 13 of the 16 disagreements in a 200-pair `narrowing` sample
(seed 201), a message that appears 0 times in the same seed's pre-`match` run · filed
2026-09-07 against master `d601f702b` by the day-one sampler's new `match` axis**

Repro:

    type Color = "red" | "green"

    function mkval(): Color {
      return "red"
    }

    function take(p) {
      match p {
        "red" => print(1)
        "green" => print(0)
      }
    }

    take(mkval())
    // vl check: [ERROR]: match scrutinee must be a union or an integer, got _
    // Should print 1; annotating `p: Color` does, and so do the `is` and `==` spellings
    // of the same test on the same un-annotated parameter.

#### Mechanism

**Found by pairing, so the control is attached**: the sampler generated this program's `==`
and `is` twins from the same plan, and both RUN. The refusal is therefore about the SPELLING
of the test, not about the hole — the checker resolves the same parameter's type for `is` and
for `==` and declines only for `match`.

The `got _` is the hole rendering. The generic spelling refuses too, with `got T` — **two
messages, one mechanism**, which is why this row is grouped by its ablation and not by either
sentence.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the missing annotation — `p: Color` | prints `1` | **yes** |
| `match` — the same test spelled `==` | prints `1` | **yes** |
| `match` — the same test spelled `is` | prints `1` | **yes** |
| the PARAMETER — the same `match` over an un-annotated LOCAL | prints `1` | **yes** |
| the UNION — an integer scrutinee through the same hole | prints `1` | **yes** |
| the literal union — a value union (`i32 \| string`) through the hole | refuses identically | no |
| the literal union — a struct union (`A \| B`) through the hole | refuses identically | no |
| the hole — a generic `T` parameter | refuses, `got T` | no |

The last four rows are the scope: **every union element type refuses**, and the integer
scrutinee the message names as accepted runs — so the message's own vocabulary is accurate
about integers and the gap is the whole union half of it.
