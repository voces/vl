### D15137 — a map written two functions of different result types by `set` is refused at check

**loud check reject · `cannot write 'half' to an element of 'm': called at (i32) it returns f64, where 'inc0', also written to it, returns i32` · clause 2 · open, target `1.5` · split from [D14648](D14648.md) (step 2, the map) · filed 2026-11-03 against master `097fd927`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const m = Map()
    m.set("a", inc0)
    m.set("b", half)
    const g = m.get("b")
    if g != null { print(g(3)) }
    // Want: 1.5

#### Mechanism

The list spelling runs because `elabFnListLetTy` widens the list binding over its writes and
`holeSlotJudge` lifts its comparison for a binding so widened. A `Map()` has no such widening.
D14648's row measured the lift for a map: `set` and `get` then run, and the index read `m["b"]`
routes to the scalar box (`scalar map read has no value-box type`). So the index read is its own
step after this one.
