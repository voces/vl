### D14550 — recordUnMemTys re-parses a member's spelling because the arena row spells `null` as a -1 hole

**runs today and must keep running · refutation pin for the arena-first `recordUnMemTys` · filed 2026-10-27 against master `a22130bcc`**

Repro:

    import { parseJson } from "std:json"
    const r = parseJson("[1, [2]]")
    print(r is null)
    // runs, prints false. Under the refused change (every member taken from
    // boxRowMembersInto, no spelling fallback) the compiler that change builds refuses
    // std:json itself, at L1 and at L2's seed-provenance sanity step:
    //   std:json:517:10: emitProgram: array value does not match any array member of the
    //   union (leaf-scalar widening across a nested array is unsupported)

Want:

    false

#### Mechanism

`recordUnMemTys` (`compiler/emit_rep.vl`) fills a union row's member columns from
`boxRowMembersInto`, whose contract returns `-1` for the `null` member. On master a member
whose arena type is not a `TyObj`, or is `-1`, is replaced by `unMemAtomTyIx` of its
spelling, which resolves `null` to the interned null primitive. Taking the arena row for
every member pushes the `-1` into `unMemTys` as though it were a type, and std:json's
`Json` (`boolean | f64 | string | Json[] | {[string]: Json} | null`) then has no member the
emitter can match an array value against. It is not canon flattening the recursive member
differently from the arena row: a probe that named every `-1` slot found exactly one
member, `null` (arena `-1`, spelling `TY_NULL`), in the unrolled `Json` row. The `Json[]`
member's arena and spelled types are distinct indices that render alike; that difference
moved no fixture.

The arena row now answers every member, its `-1` read as `TY_NULL`. A row with no arena type
is a named `emitFail`, and no program in tests/cases, std, the corpus, diderven or the
compiler reaches it. The spelling still answers only a row `boxRowMembersInto` declines.
On 2026-10-27, 13 tests/cases programs reached that branch and nothing else did:

* 11 have a member reaching a cycle by no declared name (`type J = null | f64 | {[string]: J}`);
* 1 has a list of a twin record (`nullable-fold-nominal-lists-and-literal-box.vl`);
* 1 has a generic function arm canon cannot render
  (`generic-written-into-function-or-string-union-slot.vl`).
