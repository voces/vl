#### Mechanism

D10131's close reads each return as the pinned re-check of the statements typed it, but only
when that re-check raised nothing. Here `x is string[]` at the `i32[]` pin is a test the pin
makes dead, the re-check raises on it, and every return keeps its bare reading, so the
narrowed `return x` reads the complement `i32[]` and the join is the box, as D10131 did before
its close. Telling the dead arm's return apart from the live ones would let the rest keep the
narrowed reading.
