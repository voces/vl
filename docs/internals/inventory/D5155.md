### D5155 — a self-referential arm built nested and read through its union gets two tags

**closed 2026-10-16 as `runs` · was loads then traps (clause 1, `cast failure`) · `variantRowsTagEqual` gives one tag to two rows of different unions whose records are the rolled and unrolled spellings of one arm (`fieldTysRolledAlike`, each row's union from `rowUnionOf`), so the nested literal's box carries the tag the reading union tests · fixture `tests/cases/unions/rolled-unrolled-arm-one-tag.vl` · found closing D5105 · filed 2026-10-16 against master `9518cc8f5`**

Repro:

    type Node = { kind: "a" | "b", w: i32, v: i32, next: Node | null } | { kind: "end", w: i32 }
    function wOf(n: Node | null): i32 {
      if n == null { return 0 }
      return n.w + wOf2(n)
    }
    function wOf2(n: Node): i32 {
      if n is { kind: "a" | "b", w: i32, v: i32, next: Node | null } { return wOf(n.next) }
      0
    }
    const a: Node = { kind: "a", v: 3, w: 1, next: { kind: "b", v: 2, w: 10, next: { kind: "end", w: 100 } } }
    const b: Node = { kind: "b", v: 4, w: 1000, next: null }
    print(wOf(a))
    print(wOf(b))
    // vl check: rc 0.  vl run: wasm trap: cast failure in `wOf`

Want:

    111
    1000

#### Mechanism

The nested literal `next: { kind: "b", ... }` is built under the arm's rolled spelling, whose
`next` field names the alias, while the union the reader tests is laid out from the unrolled
spelling. The two rows belonged to different union runs and `variantRowsTagEqual` compared
their records exactly, so they drew different tags and the box the reader cast was another
arm's. Rows whose records agree once each side's self-reference is rolled now share one tag.
