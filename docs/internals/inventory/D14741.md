### D14741 — a call returning a binding of a call built at a wider record, handed to a hole parameter, keeps the hole at the literal's row

**open · check-clean invalid wasm, clause 1 · filed 2026-10-31 against master `54db9267`**

Repro:

    type J = { f: i32 | null }
    function mk4() { { f: 4 } }
    function r4() {
      const k = mk4()
      return k
    }
    const d: J = mk4()
    function u(a) { a.f }
    print(u(r4()))
    print(d.f ?? 0)
    // vl check: rc 0.  vl run: expected (ref ${f:i32}), found (ref $J)

#### Mechanism

`const d: J = mk4()` builds `mk4`'s record at `J`, and `r4` hands that build back through the
binding `k`. The hole parameter `a` of `u` takes its rep from the argument's build
(`recArgBuiltTyOf`, check_bind_adopt.vl), whose chain does not follow a call of a function that
returns a binding. So `u`'s instance stores `a` at the literal's own row while the argument is a
`J`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `r4()` replaced by `mk4()` | runs | **yes** |
| `r4()` replaced by `id(mk4())`, `id<T>(x: T): T` | runs | **yes** |
| `const d: J = mk4()` | runs | **yes** |
| `type II = { f: i32 }` declared as well | still invalid wasm | no |
