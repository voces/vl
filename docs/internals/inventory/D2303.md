### D2303 — a function returning a struct `.map` result with no return annotation interns no shape for its return

**closed · return inference names the `.map` result's row from the named callback's record (`rep-descriptor-campaign.md` §13.16); fixture `tests/cases/lists/map-record-result-inferred-return.vl` · the parameter-callback spelling still refuses and is D4684 · found beside D2301 · filed 2026-09-24 against master `c2f040366`**

Repro:

    type A = { v: i32 }
    type B = { w: i32 }
    function toB(a: A): B { return { w: a.v + 1 } }
    function go(xs: A[]) {
      const ys = xs.map(toB)
      return ys
    }
    const r = go([{ v: 4 }])
    print(r[0].w)
    // vl check: rc 0.  vl run: prints 5
    // (was: emitProgram: ref valtype with no interned shape)

Want:

    5

#### Mechanism

Return inference runs before `collectMapFilterUse` interns the `.map` result's ref-list row,
so the inferred ref-list return had no element name. D2575's close names the row from the
callback's own record when the callback is a lambda or a named function. A callback passed as
a parameter has neither, and is D4684.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| a `: B[]` return annotation added | runs | **yes** |
| the callback passed as a parameter `f: (A) => B` | still refuses | no |
| `return xs.map(f)` with no intermediate binding | still refuses | no |

#### Grading list

The parameter-callback spelling (`function go(f: (A) => B, xs: A[])`), which D2301's close made
reach this refusal instead of a trap. It still refuses, and is D4684.
