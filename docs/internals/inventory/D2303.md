### D2303 — a function returning a struct `.map` result with no return annotation interns no shape for its return

**loud emit reject · found beside D2301 · filed 2026-09-24 against master `c2f040366`**

Repro:

    type B = { w: i32 }
    function toB(a: A): B { return { w: a.v + 1 } }

return's ref-list rung, not a `.map` defect: the callback's delivery is scenery.
