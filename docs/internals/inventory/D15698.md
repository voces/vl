**loud check reject · clause 2 · `is built as {ys: J[]} where line 8 delivers it, and it is handed on here at its own type` · found closing D15695 · filed 2026-11-11 against master `94b382ce`; master emitted invalid wasm for it**

#### Mechanism

Not ablated. D15695 instances an annotated parameter at the record's build only where the callee
reads the parameter for a field (`recHeldArgTakesRep`). Here it binds the parameter to `q`, so the
instance is not taken, and the delivery at the parameter's own storage is refused
(`recHeldReadsOwnRefuse`).
