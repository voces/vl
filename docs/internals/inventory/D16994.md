### D16994 — a read-only empty map whose key or value is read into a typed destination takes the unbound default before the read

**loud check reject · clause 2 · census rows 7 and 8 of the no-default ruling (DECISIONS.md §"No default type"), the map face of [D16993](D16993.md) · filed 2026-11-18 against master `e7861b6fd` by lane F1**

Repro:

    const m = Map()
    for k in m.keys() { const z: string = k; print(z) }
    print(m.length)
    // vl check: cannot assign i32 to 'z' of type string

Want:

    0

#### Mechanism

A map nothing but reads ever uses takes the unbound default for its value at its declaration
(`defaultReadOnlyContainer`), and its key at the first key read or iteration (`pinIterKey`,
`pinReadKey`, `check_narrow_flow.vl`). A key or value read into a `string` is then refused.
D16993's list path does not cover a map: the key iterates through `keys()` or `for k, v in`, and
a value read goes through `?? d`, neither of them an element read delivered whole.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| a value read, `const v: string = m["a"] ?? "d"` | refused: `cannot assign i32 \| string` | no |
| the key read typed `i32` | runs | **yes** (another type than the default) |
