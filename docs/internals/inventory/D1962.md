### D1962 — a LIST field shared by every member of an un-narrowed struct union has no field-read lowering

**loud emit reject · `emitProgram: field access receiver is not a struct`, `vl check` rc 0, clause 2 · found beside [D1960](D1960.md) (plumb PL-005's residue) · filed 2026-09-22 against master `a8a104432`**

Repro:

    type S = { rva: i32 }
    type A = { xs: S[], k: i32 }
    type B = { xs: S[] }
    function n(u: A | B): i32 { u.xs.length }
    print(n({ xs: [{ rva: 4 }] }))
    // vl check: rc 0.  vl build: emitProgram: field access receiver is not a struct

#### Mechanism

`memFieldTypeCode` resolves a field every member of an un-narrowed struct union carries at one
code (`sharedUnionFieldPlan`), so the classifiers call `u.xs` a list; the member-read emitter
has no arm that dispatches on the box's tag to read a LIST field from each arm, and refuses.
Scalar shared fields are not this row. Before D1960 the `for s in u.xs` spelling refused
earlier, as `unsupported for-in iterable`; it now reaches this refusal.

#### Grading list

The `i32[]` field twin (`type A = { xs: i32[], k: i32 }`, `for s in u.xs`) refuses as
`field access but no struct type declared`; the `for s in u.xs` and `u.xs[0].rva` spellings.
