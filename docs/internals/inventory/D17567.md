### D17567 — a `?.` read after a write to the field, in a hole identity instanced at the adopted record, hands on the box under a narrowed `i32`

**check-clean invalid wasm · clause 1 · inside `g`, expected i32, found the union box · found grading D17426's close · owner SOUND · filed 2026-11-25 against master `aa2c1e18`**

Repro:

    type A = { d: i32 | null }
    function g(v) {
      v.d = 8
      print(v?.d)
      return v
    }
    const c: A = g({ d: 5 })
    print(c.d ?? -1)
    // vl run: invalid module inside `g`, expected i32, found (ref union box)

Want:

    8
    8

#### Mechanism

The instance is keyed at `A` (D17426), but the write `v.d = 8` narrows the field, so the
elaboration records `v?.d` as `i32` while the `?.` read builds `A`'s boxed field and hands it on
unconverted. Without the write the read is `i32 | null` and runs. Invalid on master before D17426's
close too, at the literal's key.

#### Ablation

| spelling | outcome |
| --- | --- |
| `v.d = 8` then `print(v?.d)` | invalid |
| `print(v?.d)` alone | runs (D17426) |
| `function g(v: A)` | runs, `8` `8` |
