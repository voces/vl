### D3946 — a value read of a top-level generic function binds its type parameter for a later direct call, so a valid program is refused

**loud check reject · clause 2 · found closing D3939 (`p39/o1`–`o6`, `n1`–`n8`) · related to D3927 · filed 2026-10-10 against master `f4b15af9c`**

Repro:

    function ci(f: (n: i32) => void, n: i32) { f(n) }
    function inner<U>(u: U) { print(u) }
    const k = inner
    ci(k, 1)
    inner("s")
    // vl check: argument 1: expected (i32) => void, got (string) => void (at `ci(k, 1)`)

Want:

    1
    s

#### Mechanism

Not located. The alias `k` reads `inner` without freshening `U`, so the later direct call
`inner("s")` binds `U` to `string` and the earlier delivery `ci(k, 1)` is then checked against
`(string) => void`. D3927 is the same refusal for two nested generics sharing a type-parameter
name; this row needs neither nesting nor a second generic.
