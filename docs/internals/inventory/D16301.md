### D16301 — moving a program's function declarations after its top-level code changes the outcome of 318 corpus programs, 39 of them to a wrong answer, a trap or an invalid module

**loads then traps · clause 1 · open · a declaration-order dependence: function declarations are hoisted, so their position must not change a program's meaning · found by lane J's reorder A/B while closing [D16300](D16300.md) · filed 2026-11-14 against master `089d6e0b`**

Repro:

    c2("q", true)
    function w<T>(t: T, b: boolean) { if b { return [t, t] } }
    function c2<T>(t: T, b: boolean) {
      let v = w(t, b)
      if !(v is i32[]) { print("not") }
    }
    // vl check: rc 0.  vl run: wasm trap in `c2`.

Want:

    not

The first witness, a re-pointed `let` of generics called at a second type (unfiled: D16281), runs
since `letFnWriteNarrows` reads a declaration below the write by its hoisted signature, inferring a
pending result as a forward call does. This one is the caller-before-callee rung: it traps whenever
`c2`'s first call is checked before `c2` and `w` are declared, at top level or from a function
declared above them, and runs with `w`'s result annotated.

#### Mechanism

The first witness: with the two declarations first, it printed `2` and `true`. With them last,
`g(true)` was lowered at `f`'s first instance, so the `boolean` reached `gB` as the `i32` `1`. A write
narrows a re-pointed `let`'s reads only when every function it holds has a known result
(`letFnWriteNarrows`), and that was read from the declaration's own record, which a declaration
below the write does not have yet. The caller-before-callee rung's mechanism is not yet located. The
population says where to look: 245 of the 318 programs are in `tests/cases/closures/`, and almost every
one holds a function value in a binding, a list or a field that is written or re-pointed. That is the
function-holding slot facts (the elaboration's slot and set rows, `cwIx`), computed while the
top-level statements are checked in source order, so a statement before a declaration is judged
before the facts its callee contributes exist. [D16300](D16300.md) was one member with its own
mechanism (a quiet pre-pass sentinel), and closing it moved one program.

#### Ablation (the first witness)

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| declarations first | prints `2`, `true` | **yes** (the order) |
| `const f = g` with no re-point | prints `2`, `true` | **yes** (the written binding) |
| un-annotated `gA(u)` / `gB(v)` | check reject at `g(true)` | the annotated generic: **yes** |
| one `let f` written once, called at two types | emit reject, the owed one-signature sentence | **yes** (the copy `g = f`) |

#### The instrument

Each single-file `@run` case of `tests/cases` (no import, no expected error, 5,083 after leaving out
cases with a brace-less function, which the line-level reorder cannot move) is rewritten with every
top-level `function` block moved to the end, and both versions are run on one seed. 318 differ:
201 newly an emit reject, 78 newly a check reject, 22 trap, 9 build an invalid module, 8 print
another answer. By directory: closures 245, functions 26, generics 23, soundness 10, maps 7, objects
3, inference 2, structs 1, unions 1.
