**loads then traps · clause 1 · open · a declaration-order dependence: function declarations are hoisted, so their position must not change a program's meaning · found by lane J's reorder A/B while closing [D16300](D16300.md) · filed 2026-11-14 against master `089d6e0b`**

#### Mechanism

Not yet located for the remaining members. The first witness (`let f = gA; let g = gB; f = gB;
g = f; f(2); g(true)`, declarations last) runs since the tag decision asks an un-annotated member
declared after a call through its set for its result by checking it then (D16381). That closed 22
of the 39 clause-1 movers; 17 remain, this witness among them. The population says where to look: 245 of the 318 programs are in `tests/cases/closures/`, and almost every
one holds a function value in a binding, a list or a field that is written or re-pointed. That is the
function-holding slot facts (the elaboration's slot and set rows, `cwIx`), computed while the
top-level statements are checked in source order, so a statement before a declaration is judged
before the facts its callee contributes exist. [D16300](D16300.md) was one member with its own
mechanism (a quiet pre-pass sentinel), and closing it moved one program.

#### The instrument

Each single-file `@run` case of `tests/cases` (no import, no expected error, 5,083 after leaving out
cases with a brace-less function, which the line-level reorder cannot move) is rewritten with every
top-level `function` block moved to the end, and both versions are run on one seed. 318 differ:
201 newly an emit reject, 78 newly a check reject, 22 trap, 9 build an invalid module, 8 print
another answer. By directory: closures 245, functions 26, generics 23, soundness 10, maps 7, objects
3, inference 2, structs 1, unions 1.
