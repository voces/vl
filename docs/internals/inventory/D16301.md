#### Mechanism

The first witness: with the two declarations first, it printed `2` and `true`. With them last,
`g(true)` was lowered at `f`'s first instance, so the `boolean` reached `gB` as the `i32` `1`. A write
narrows a re-pointed `let`'s reads only when every function it holds has a known result
(`letFnWriteNarrows`), and that was read from the declaration's own record, which a declaration
below the write does not have yet. The caller-before-callee rung's mechanism is not yet located. The
population says where to look: 245 of the 318 programs are in `tests/cases/closures/`, and almost every
one holds a function value in a binding, a list or a field that is written or re-pointed. That is the
function-holding slot facts (the elaboration's slot and set rows, `cwIx`), computed while the
top-level statements are checked in source order, so a statement before a declaration is judged
before the facts its callee contributes exist. [D16300](D16300.md) was one member with its own
mechanism (a quiet pre-pass sentinel), and closing it moved one program.

201 newly an emit reject, 78 newly a check reject, 22 trap, 9 build an invalid module, 8 print
