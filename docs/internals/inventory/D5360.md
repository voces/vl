### D5360 — a generic returned bare from an un-annotated function reaches no call that fixes its type

**loud emit reject · `vl check` rc 0 · clause 2 · found closing [D5290](D5290.md) · filed 2026-10-17 against master `15bd386db`**

Repro:

    function k<T>(x: T): T { return x }
    function mk() { return k }
    function main() { const h = mk(); print(h(1)) }
    main()
    // vl check: rc 0.  vl run: emitProgram: a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type

Want:

    1

#### Mechanism

From the ablation only. The inferred return of `mk` is `k`'s open `(T) => T`, and `h(1)` binds
it at `(i32) => i32`, but the bare `return k` is emitted as a value of the generic's stub: no
pin of `mk`'s return slot reaches the `return`. D5062's close carries a pin across an inferred
return for a WRITTEN `let` of a generic (`monoRetypePinCalls`); a bare `Ident` naming the
generic is not that route.
