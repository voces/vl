### D6700 — a maker's generic result in a module record field, called through a returned or listed record at a type the record's own first call does not take, is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same call at the first call's type runs ([D6473](D6473.md)) · found closing [D6473](D6473.md) · filed 2026-10-18 against master `ca2adfdc7`**

Repro:

    function k<T>(x: T): T { return x }
    function mk() { return k }
    const r = { f: mk(), g: 7 }
    function get() { return r }
    print(r.f(1))
    print(r.f("z"))
    print(get().f("w"))
    // vl check: rc 0.  vl run: emitProgram: a generic function taken as a value reaches no call that fixes its type — annotate the destination's function type

Want:

    1
    z
    w

#### Mechanism

From the ablation only. The field-slot plan keeps the record's field at its first call's types
and rewrites each other direct call to a call of `k` by name; a call through a returned or listed
record keeps its receiver, so the plan declines unless that call is at the kept types.
