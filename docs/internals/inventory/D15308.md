### D15308 — a `const` record of one function, assigned into a binding widened to two, is not built at the binding's row

**open · loud emit reject · `emitProgram: cannot take the generic function id2 as a value — a function value carries ONE signature` · clause 2 · a widened source runs · found grading D15306 · filed 2026-11-04 against master `4eaf52bb`**

Repro:

    function id1(a) { return a }
    function id2(a) { return a }
    const q = { f: id2 }
    let r = { f: id1 }
    r = q
    print(r.f(2))
    print(r.f(2.5))

Want:

    2
    2.5

#### Mechanism

D15306 builds a LITERAL written into the widened binding at the binding's row. A binding written
in is a record already built at its own row (`q`'s, of `{id2}` alone), and nothing widens the
source to the destination's set. A source whose own field is widened (`let q`, reassigned) runs.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the second call type (`r.f(2)` only) | check reject: `a {f: (_) => _} cannot be delivered as {f: (i32) => i32}` | **yes** |
| `const q` of `id2` → of `id1` | runs | **yes** |
| `const q` → `let q = { f: id2 }; q = { f: id1 }` | runs | **yes** |
