### D2718 — a function value whose parameter is a nullable map has no function-value signature

**loud emit reject · clause 2 · found by D2684's close (15 `closurep` cells of the review's pin grid) · identical on master · filed 2026-09-26 against master `74bd044d7`**

Repro:

    const f = (x: {[i32]: boolean} | null) => x == null
    const m: {[i32]: boolean} = Map()
    print(f(m))
    print(f(null))
    // vl check: rc 0.  vl run: emitProgram: a function value's signature is not yet supported — parameter `x` of type `{[i32]:boolean}|null` has no representation in the function-value ABI

#### Mechanism

The closure ABI gives each parameter a token from its rep, and a nullable map (a map niche: a
nullable reference with no box) has none, so the lambda's `$fnsig` cannot be minted. A named
function with the same parameter runs, and so does a lambda over the bare map; only the
function-value boundary lacks the nullable-map token.
