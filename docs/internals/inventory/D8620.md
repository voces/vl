### D8620 — a record literal handed to an un-annotated parameter is built at a declared record that stores its field differently

**closed 2026-10-20 · runs, prints `5` · was check-clean invalid wasm · clause 1 · a record literal handed to an un-annotated parameter, directly or through an un-annotated binding of it, whose body reads a field off the parameter and never tests it with `is`, no longer takes a declared row that boxes that field where the literal holds a bare scalar (`litHoleReadsField`, `litFieldBoxedApart`, `emit_classify.vl`); `is` of a record over such a literal's own row folds on the record the literal was built from (`anonRowOwnTyOf`, `monoStaticIsResult`, `wasmEmit.vl`) · pins: `tests/cases/soundness/record-literal-into-hole-beside-boxed-row.vl` and its annotated twin `record-literal-into-annotated-param-beside-boxed-row.vl` · matrix `record-literal-into-hole-beside-boxed-row` · present on master `02d8f4c21` and `a0af58b15` · found closing [D8302](D8302.md) · filed 2026-10-20 against master `02d8f4c21`**

Repro:

    type J = { f: i32 | null }
    function rd(r) { return r.f + 1 }
    print(rd({ f: 4 }))
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `rd`: expected i32, found (ref $type)

Want:

    5

#### Mechanism

The checker types the literal `{f: i32}` and binds `rd`'s hole at it, so `r.f + 1` is `i32`
arithmetic. Emit maps an anonymous record to a declared row by its field names, and `J` is the
only declared record with field `f`, so the literal is built at `J`; the hole's instance is
pinned at the literal's row, and `r.f` reads `J`'s boxed `i32 | null` field where the body adds
an `i32`. Declaring `type II = { f: i32 }` gives the literal its exact row and the program runs.

The close refuses a boxing declared row in emit's row choice when the literal is delivered to
an un-annotated, non-rest parameter whose body reads that field off it, so the literal keeps a
row of its own. The deliveries are resolved from the call's callee declaration while the node
table is scanned, before any call is rewritten to an instance. A body that tests the parameter
with `is` keeps the declared row, because the test pins the hole at the tested record, and a
body that only uses the parameter whole never reads the box. With the literal on its own row,
an `is J` inside the instance has an operand type still open, so `monoStaticIsResult` answers
from the pin's record: for an anonymous row, the literal's own type.
