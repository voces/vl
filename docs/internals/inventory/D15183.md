#### Mechanism

The held `k` pins `f` at `K`, so [D14817](D14817.md) builds `mkcall()` at `Circle` and copies it into
`K` where it is delivered. The monomorphizer then bound `T` from the copied call at its BUILD row:
the instance's pins read `[Circle | {r: null}]`, `[Circle | {r: null}]`, `[Circle[] | K[]]`. The two
bare parameters still came out `K`, because the clone takes their banked type, but `c: T[]` took the
substituted `Circle[]` while `ks` is a `K[]`. The copy's destination was recorded as the call's own
structural type `{r: null}`, which has no nominal pin to name. (Filed first as `recRepArgsNote`
handing the list the wide rep. Guarding that changed nothing, and `ks` takes no rep.)
