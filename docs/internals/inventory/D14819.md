Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    function back(r) { return r }
    const wideJ: J = mk()
    const xs = [mk()]
    function take(v: { f: i32 }): i32 { v.f }
    print(take(back(xs[0])))
    print(wideJ.f ?? 0)
    // vl check: this {f: i32} is stored at J, ... type-valid but not supported yet

Want:

    4
    4

#### Mechanism

`xs`'s elements are built at `J`, and `back`'s by-rep instance (D14532) returns a `J`. A result
reads the rep when it is read for a field, handed on by rep, bound to a `const` read only for
fields, or stored in a `const` list literal indexed only for a field (`recRetTakesRep`). Every
other delivery hands a `J` to a position typed `{f: i32}`, and `recBuiltReadRefuse` refuses it.
