### D14819 — a by-rep result compared, handed to an annotated parameter, or held other than in a read-only list refuses

**open · loud check reject · clause 2 (the refusal says `type-valid but not supported yet`) · the residue of [D14811](D14811.md) · filed 2026-11-01 against master `88e31332`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    function back(r) { return r }
    const wideJ: J = mk()
    const xs = [mk()]
    function take(v: { f: i32 }): i32 { v.f }
    print(take(back(xs[0])))
    print(wideJ.f ?? 0)
    // vl check: this {f: i32} is stored at J, ... type-valid but not supported yet

Want:

    4
    4

#### Mechanism

`xs`'s elements are built at `J`, and `back`'s by-rep instance (D14532) returns a `J`. A result
reads the rep when it is read for a field, handed on by rep, bound to a `const` read only for
fields, or stored in a `const` list literal indexed only for a field (`recRetTakesRep`). Every
other delivery hands a `J` to a position typed `{f: i32}`, and `recBuiltReadRefuse` refuses it.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `take`'s annotation (a hole `take(v)`) | runs | **yes** |
| `const wideJ: J = mk()` | runs | **yes** |
| `back` (`take(xs[0])`) | runs | **yes** |

#### Grading list

Each spelling below replaces the `take` line, over the Repro's prelude:

* `print(back(xs[0]) == xs[0])`
* `let b = back(xs[0])` then `print(b.f)`
* `const keep = [back(xs[0])]`, `const z = keep[0]`, `print(z.f)`
* `const keep = [back(xs[0]), mk()]` then `print(keep[1].f)`
* `const keep = { a: back(xs[0]) }` then `print(keep.a.f)`
* `const keep = [back(xs[0])]` with a write `keep.push(mk())` or a `{ f: i32 }[]` alias: these
  hand the list on narrow and should stay refused until a converting copy exists.
