### D3075 — a lambda parameter's inline union is never registered, so its box type is never minted

**closed · `collectInlineUnions` registers the unions a lambda's parameters, result and body spell, as it does a declared function's · fixture `tests/cases/closures/lambda-record-union-nullable-param.vl` · was check-clean invalid wasm · clause 1 · found beside [D3074](D3074.md) · the same on master `67ca68cf3` · filed 2026-09-28 against master `67ca68cf3`, closed 2026-09-28 against master `e1e40ac99`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    const f = (w: Circle | Sq | null) => w == null
    print(f(null))
    // vl check: rc 0.  vl run: invalid module in the top-level code: type mismatch: expected
    // i32, found nullref

Want:

    true

#### Mechanism

`collectInlineUnionsIn` walks statements, so it reaches a declared function's parameters but
never a lambda, which sits in an expression. When the lambda was the only place
`Circle | Sq | null` was spelled, no union was registered, `uDeclared` stayed false, the box type
was never allocated, and `uBoxIdx` kept its default of 0: the parameter was declared at an
unrelated struct heap and the `null` argument was built into it. After the statement walk, every
`FuncDecl` the walk did not reach is walked the same way (`ciuFnSeen`). The pass runs before
`collectFns` lifts the lambdas into `fnStmts`, so it reads them from `funcDeclNodes`, the list
`mkFunc` keeps: a whole-arena scan for them cost the plumb-shape units +0.14% guest fuel, the
list +0.01%.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the argument a typed binding `const n: Circle \| Sq \| null = null` | runs, prints `true` | **yes** (the binding's annotation registers the union) |
| the argument an object literal `{ r: 1 }` | runs, prints `false` | **yes** |
| a named `function g(w: Circle \| Sq \| null)` bound as `const f = g` | runs, prints `true` | **yes** (a lambda) |
| a scalar union parameter `i32 \| string \| null` | runs, prints `true` | **yes** (record members) |
| a body that reads a field, `if w is Sq { w.s }` | loud emit reject, `field access receiver is not a struct`, before the close | no (the same unregistered union) |

#### Grading list
