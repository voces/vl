### D3075 — a bare `null` argument to a lambda whose parameter is a nullable union of records is passed unboxed

**check-clean invalid wasm · clause 1 · found beside [D3074](D3074.md) · the same on master `67ca68cf3` · filed 2026-09-28 against master `67ca68cf3`**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    const f = (w: Circle | Sq | null) => w == null
    print(f(null))
    // vl check: rc 0.  vl run: invalid module in the top-level code: type mismatch: expected
    // i32, found nullref

Want:

    true

#### Mechanism

Not investigated past the ablation. The validator reads an `i32` where the call puts `nullref`,
so the lambda's `Circle | Sq | null` parameter is not lowered at the rep the call site builds
the bare `null` for. A named function taken as a value, with the same parameter, runs, so the
difference is in how the lambda's own parameter is lowered, not in the function-value call.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the argument a typed binding `const n: Circle \| Sq \| null = null` | runs, prints `true` | **yes** (a bare `null`) |
| the argument an object literal `{ r: 1 }` | runs, prints `false` | **yes** |
| a named `function g(w: Circle \| Sq \| null)` bound as `const f = g` | runs, prints `true` | **yes** (a lambda) |
| a scalar union parameter `i32 \| string \| null` | runs, prints `true` | **yes** (record members) |

#### Grading list

The same lambda value-bound, passed to a generic and to a concrete function, held in a record
field and returned; a `null` literal and a `null`-valued `if` expression as the argument.
