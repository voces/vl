### D1893 — ANY `std:` import makes an operator on an un-annotated parameter refuse, and deleting the import line makes the same program run

**closed 2026-09-08 by [D1891](D1891.md)'s mirror flow — the witness prints `12` · was a loud check reject, found by the `scenery` axis, which varies exactly this · clause 2 · filed 2026-09-07 against master `f3cac5fe5` · all ten ablation cells run, the structural twin its grading list named included · the TWO-hole twin is still open as [D1931](D1931.md)**

Repro:

    import { toString } from "std:fmt"
    type Sca = new { x: i32 }
    function "*"(self: Sca, k: i32): Sca {
      const r: Sca = { x: self.x * k }
      return r
    }
    function mkval(): Sca {
      const r: Sca = { x: 3 }
      return r
    }
    function take(p) {
      print((p * 4).x)
    }
    take(mkval())
    // vl check: 14:6: argument 1: expected {x: _}, got Sca
    //           14:6: argument 1: operator '*' is not defined for Sca and i32
    //                 (the body of `take` applies '*' to this argument)
    // Delete line 1 and the same program prints 12.

#### Mechanism

Un-annotated parameters are solved against their call sites, and the solve behaves
differently once a std module joins the graph — the same function body, the same argument,
one extra module. Without the import the hole binds to `Sca` and the operator is found;
with it the solve synthesises the STRUCTURAL shape `{x: _}` from the `.x` in the body and
then rejects the nominal argument against it, and the operator lookup it also performs does
not know about the `"*"` declared six lines above.

The second sentence is the sharper half: it says the operator is not defined for `Sca` and
`i32`, which is precisely the declaration in the file. So the operator table is being asked
about the right type and answering no — a different failure from [D1891](D1891.md), where the
left operand had no type to ask about at all.

Two features that each work alone, which is D1514's shape and the reason the `scenery` and
`imports_pair` axes exist.
