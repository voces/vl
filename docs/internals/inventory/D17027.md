Repro:

    type A = { v: i32 }
    type B = { s: string, w: i32 }
    type W = { h: A | B }
    function show(h: A | B): string {
      if h is A { return "A" }
      return "B"
    }
    function F(z: W) { if z.h is B { print(show(z.h)) } }
    F({ h: { s: "b", w: 1 } })
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `F`: type mismatch:
    // expected (ref union box), found (ref B)

Want:

    B

#### Mechanism

Inside the `is B` arm `z.h` is a read of record `B` at its own type out of the union box the
field holds (`boxedArmOfMember`), and the field-read tail casts the box's payload to `B`. The
argument's delivery to `show`'s `A | B` parameter does not box that `B` again: `F`'s bytes hand
`ref.cast B (struct.get box.1 …)` straight to the call. The checker records the box, and
`holeBoxPlanOf` answers `ladder`: its record rung asks `armValuePlainOf`, which asks
`exprVariantIndex`, and `memberVariantRow` names no row for a read `boxedArmOfMember` casts.
