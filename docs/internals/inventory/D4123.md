### D4123 — an un-annotated list literal holding a generic function, never called through an element, builds a module no engine parses

**check-clean invalid wasm · clause 1: `vl check` is clean · found by lane SC while grading a matrix of generic functions written into list elements · filed 2026-10-11 against master `8411b89d5`**

Repro:

    function inner<U>(u: U) { print(u) }
    const fs = [inner]
    print(fs.length)
    // vl check: rc 0.  vl run: failed to parse WebAssembly module: expected struct type at index 4, found (func)

Want:

    1

#### Mechanism

From the ablation only. The list's element type is `inner`'s generic function type. Nothing
instances `inner` at a concrete type unless a call through an element does, so the element
reaches the emitter with no instance and no function-value signature. The module's type section
is then malformed. The failing rung's input has not been printed.
