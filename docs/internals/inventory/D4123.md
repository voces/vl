### D4123 — an un-annotated list literal holding a generic function, never called through an element, builds a module no engine parses

**closed 2026-10-11 by lane SC · runs · was check-clean invalid wasm · clause 1 · found by lane SC while grading a matrix of generic functions written into list elements · filed 2026-10-11 against master `8411b89d5` · pins: `tests/cases/closures/list-of-generic-read-only-for-length.vl`, `tests/cases/closures/list-of-generic-with-return-read-only-for-length.vl`, `tests/cases/closures/list-of-generic-instanced-elsewhere-read-only-for-length.vl`, `tests/cases/closures/generic-function-value-never-read.vl`**

Repro:

    function inner<U>(u: U) { print(u) }
    const fs = [inner]
    print(fs.length)
    // vl check: rc 0.  vl run: failed to parse WebAssembly module: expected struct type at index 4, found (func)

Want:

    1

#### Mechanism

A generic function that no call instances is pruned to a no-parameter, `void` stub. The list's
element type is the generic's own function type, and `nodeArrayElemName` rendered it as `""`.
The emitter then never marked the element as a function value, so it never declared a closure
struct for it, and `struct.new` named a function type. The element now renders at the stub's
own signature, `() => void`, so the list builds.

That makes every value of the stub a value the stub's signature cannot serve. The emitter
therefore refuses any value of a pruned generic unless nothing can call it: the initializer of
an un-annotated binding whose every use is `.length` or a write, or the value of a binding
write, which the written-binding passes ([D3939](D3939.md)) instance or refuse. Everything else
is a loud emit reject in place of the invalid module, trap or silent wrong value it was.
