#### Mechanism

Only an uncalled hole function fails. Every other value kind runs in a record field's map: i32,
boolean, f64, i64, string, record, list, an annotated function or lambda, and a called hole
function. The elaboration gave the record no slot fact, because `elabHeldClosedTyAt`'s map arm
declined any field with an initial value, a fresh `Map()` included. The struct row was minted
before mono from the checker's open literal type. The closed type mono pinned then found that row
by layout (`annShapeLayoutRowOf`) and kept its open recorded type, so the field's map shape was
unsupported. Closed by closing a fresh `Map()` field over the holder's writes
(`elabFreshMapSlotTy`), and minting a `const` binding's literal at that fact's row first
(`elabLitBindingFact` in `anonMintLiteral`).
