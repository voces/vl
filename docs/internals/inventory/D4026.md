### D4026 — a binding initialised by a generic call on a bare `null` is refused by the emitter

**closed by D4550 — `id<null>` takes its parameter as the `nulnone` cell · was loud emit reject · clause 2 · found grading D4024's position matrix (`dst-generic-id-null`, un-annotated face) · filed 2026-10-11 against master `3667afbf9`**

Repro:

    function id<T>(x: T): T { x }
    const v = id(null)
    print(v == null)
    // vl check: rc 0.  vl run: emitProgram: bare null needs a struct-typed context

Want:

    true

#### Mechanism

`T` binds to the null type and `v` is a `null`-typed binding, which `const v = null` already
lowers and runs. The `id<null>` instance has no reference type to carry its parameter, so the
emitter refuses the bare `null` argument. Every un-annotated position of the matrix but the
three that deliver into an existing typed slot refuses the same way.
