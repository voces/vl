#### Mechanism

The value is `AB | i32`: an atom on a hit, the default on a miss. No spelling lowers that join.
The direct spelling `function __take(a: R)` refuses it at check (`tErrUnsupported`: "`??` over
an atom-valued map needs a member-literal (or atom) default"), and the same join over a plain
binding, `const x: AB | null = …; print(x ?? 3)`, is an emit refusal ("not supported yet").
Through a hole, the read resolves at the map pin (lane MH, [D3155](D3155.md)) except under a `??`
whose default is not a member, a member atom or `null` (`coalMapReadForeignDefault`): there the
instance keeps the template's reading and fuses the read as a plain `i32` map, so a miss yields
the default and a hit yields the atom's id, printed as a number. Resolving that read too makes
the emitter refuse loudly, which loses the twelve `runs` cells of `d3127-coal-price` whose key
misses. The fix is the capability: a `K ?? scalar` join that boxes both arms.
