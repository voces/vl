### D2336 — `-O` ran `ssa-nomerge` over a translated unit's one huge function, and the locals it split off made `coalesce-locals` and `code-pushing` quadratic

**closed 2026-09-24 — `vl build --names -O --import-memory`, BINARYEN_CORES=1, CPU min of 2 interleaved, before = master host + seed, after = this fix and D2335: plumb's `chunk_335` 12.8 → 3.7 s, `chunk_334` 13.2 → 6.5 s, `chunk_568` 15.0 → 6.2 s, `chunk_393` 11.9 → 8.3 s, `chunk_101` 10.1 → 7.2 s, the median `chunk_0` 3.66 → 3.64 s (unchanged: it has no function over the bar); a build-time cost, not a miscompile: every spelling ran · filed 2026-09-24 against master `84efc195a`**

Repro:

    function f(n: i32): i32 { n * 2 + 1 }
    print(f(20))
    // runs, prints `41`. The defect needs a function with more than 8,192 `local.set`s, which
    // no repro block holds: build `scripts/perf/gen-plumb-shape.vl -- --shape tail` at `-O`
    // with `$VL_PROFILE=1` and read `opt.rung` (4.5 s CPU before, 1.4 s after).

#### Mechanism

At `-O` (`-Os` to binaryen) the function pipeline opens with `ssa-nomerge`, which gives every
`local.set` whose reads see no merge a local of its own. In a translated x86 function every
register write is one, so `chunk_335`'s `f_012ddc00` (19,902 sets, 3,026 locals as emitted)
reached `coalesce-locals` with 9,271 locals. That pass keeps a locals-by-locals matrix which
turns from a vector into a hash map at 8,192 (`sparse_square_matrix::DenseLimit`), and
`pickIndicesFromOrder` sets one entry per pair of locals, twice: 2.4 s for one call. The
split locals are also single-assignment, which is what `code-pushing` pushes, and its
`optimizeIntoIf` re-walks the rest of the block per `if` (2.3 of `chunk_101`'s 5.2 s). And
`inlining-optimizing` re-runs the whole function pipeline on every function it inlines into:
once the leaf helpers are inlined (PL-027, 28,270 calls in 335) the giant function paid both
passes again, 6.9 s of the unit's 11.0.

#### Fix

The host scans the rung input it already parses for the run-once marks (`rung_scan`,
scripts/vl-host/src/main.rs) and adds `--skip-pass=ssa-nomerge` when any function holds more
than 8,192 `local.set`/`local.tee`. A module with no such function gets the pass list it had,
so its output is unchanged: all 47 `bench/` programs and `tools/decode-bench.vl` build
byte-identical. On the units it changes, output is −0.7% to +0.5% in size, and a runnable
stand-in (one 12,000-block translated-style function called 400,000 times) runs in the same
time on V8 (3.12 vs 3.11 s) and 6% faster on wasmtime (5.18 vs 4.86 s). DECISIONS.md,
"`-O` skips `ssa-nomerge` for a function over 8,192 sets".
