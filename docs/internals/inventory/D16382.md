### D16382 — a plain nested block as a value `if` arm is not read as its tail's value

**loud check reject · clause 2 · open · waiting on the hybrid return flag day and detail A1 (whether braces are always a block, open with the owner; DECISIONS, "A function's block body returns a value only through `return`") · the value-arm face of [D3477](D3477.md) · filed 2026-11-15 against master `63edf3ddd`**

Repro:

    function f(id: i32): i32 {
      const v = if true { { id } } else { 0 }
      return v
    }
    print(f(3))
    // vl check: rc 1, "this arm yields no value, but the `if` is the value of `v`", at `{ { id } }`

Want:

    3

#### Mechanism

The value-arm check (`ifNoValueArmAt`, from `letDeclInitVerdicts`) reads an arm's last statement
as its value only when it is an expression or another value construct; a plain nested block is
typed `void`, as D3477's function-tail block is. Whether `{ id }` there is a block at all is detail
A1 of the hybrid return ruling, so the fix waits on it.
