### D4896 — a list of a union with a `boolean[]` arm beside one with an `i32[]` arm answers `is i32[]` false

**check-clean silently wrong · clause 1 · pre-existing on master; both spellings annotated · found closing [D4894](D4894.md) · filed 2026-10-15 against master `8b65df0a7`**

Repro:

    const a: (string[] | boolean[])[] = [["a"], [true]]
    const a1 = a[1]
    if a1 is boolean[] { print(a1[0]) }
    const z: (string[] | i32[])[] = [["a"], [1]]
    const z1 = z[1]
    if z1 is i32[] { print(z1[0]) }
    // PRINTS true

Want:

    true
    1

#### Mechanism

Not yet located. `boolean[]` and `i32[]` share one list storage and are told apart by their
own atom codes ([D2769](D2769.md)); in a union-of-lists element box the second program-order
union's arm is boxed under a tag its `is` test does not read. Whichever union comes first
answers correctly.
