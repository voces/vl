#### Mechanism

`monoDeliverCallAt` (emit_mono) delivers a call's returned hole lambda at the destination's
function type, and `monoDeliverCallRets` refuses a second delivery at another type, since the one
value the function returns has one signature (D6522). It acts only on "a call of a function
declared by name": `identDeclOf(callee)` must be a `FuncDecl`. A callee bound by `const` to a
lambda resolves to its `LetDecl`, so `monoDeliverCallRets` returns 0 and neither delivery is
recorded. The returned closure keeps one signature, and the second binding calls it through the
other type.
