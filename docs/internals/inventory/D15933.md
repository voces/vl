### D15933 — a kept maker's value handed on through a let, a record field's list, or a `filter` callback is refused where its build serves it

**open · loud check reject, clause 2 · filed 2026-11-12 against master `f050912e` · the three positions of `kept-maker-delivery-null-field.matrix.vl` left after [D15932](D15932.md)'s close: `global_assign`, `field_push` and `filter_lambda`, un-annotated**

Repro:

    type J = { f: i32 | null }
    function mk2() { { f: null } }
    const dA: J = mk2()
    let a = mk2()
    let b = mk2()
    b = a
    print(b.f)
    // vl check: this value is built as J where line 3 delivers it, and it is handed on here at its own type

Want:

    null

#### Mechanism

Each value here is a call of `mk2`, kept at `J`, handed to a place that holds another such call:
`b` holds `mk2()`; `r.ys.push(mk2())` pushes into a list of them reached through a record
field; `xs.filter((y) => y.f == null)` hands the elements to a callback instanced at the
element's own type (D15697's refusal, `recBuiltCallbackRefuse`). The checker judges the place by
its type, not by the build its values share, so it refuses the hand-on at the own type.

#### Grading list

* `const xs = [mk2()]`, `const r = { ys: xs }`, `r.ys.push(mk2())`, `print(r.ys[1].f)`.
* `const xs = [mk2()]`, `const ys = xs.filter((y) => y.f == null)`, `print(ys[0].f)`.
