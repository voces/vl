### D15933 — a kept maker's value handed on through a let, a record field's list, or a `filter` callback is refused where its build serves it

**closed · the `global_assign` and `field_push` positions of `kept-maker-delivery-null-field.matrix.vl` run; `filter_lambda` is D16134 · filed 2026-11-12 against master `f050912e`**

Repro:

    type J = { f: i32 | null }
    function mk2() { { f: null } }
    const dA: J = mk2()
    let a = mk2()
    let b = mk2()
    b = a
    print(b.f)

Want:

    null

#### Mechanism

Each value here is a call of `mk2`, kept at `J`, handed to a place that holds another such call:
`b` holds `mk2()`; `r.ys.push(mk2())` pushes into a list of them reached through a record
field; `xs.filter((y) => y.f == null)` hands the elements to a callback instanced at the
element's own type (D15697's refusal, `recBuiltCallbackRefuse`). The checker judges the place by
its type, not by the build its values share, so it refuses the hand-on at the own type.

#### Grading list

- Closed for a place every value of which is the kept maker's build. `recLandsAtSameBuild`
  (check_program) lets the hand-on through when its destination is a `let` whose every written
  value has that maker as origin, or a list reached from a binding through fields
  (`cwSlotWrittenValues`) whose every element, through any alias, has it. A place holding
  another build still refuses, as on master: `let b = { f: 3 }; b = a` and pushing onto
  `[{ f: 5 }]`.
- `filter_lambda` is not closed. Its callback is instanced at the element's own type, and
  lifting the refusal emits "ref valtype with no interned shape", so the callback needs building
  at the container's build: D16134.
- `tests/cases/soundness/kept-maker-handed-on-same-build-runs.vl`.
