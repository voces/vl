### D3440 — a type parameter's record field written at two pins, one nullable, is refused at emit

**loud emit reject · clause 2 · open · pre-existing, the same on master `c00198389` · the #3321 review's `h/t5` · filed 2026-09-30 against master `c00198389`**

Repro:

    type A = { v: i32 }
    function g<Z>(z: Z) {
      z.h = { v: 9 }
      print(z.h.v)
    }
    const x: { h: A | null } = { h: null }
    g(x)
    const y: { h: A } = { h: { v: 1 } }
    g(y)
    // vl run: emitProgram: ref valtype with no interned shape

Want:

    9
    9

#### Mechanism

Not localised past the ablation. Each pin alone builds and prints `9`; the two together refuse,
so the record literal the shared body writes is given one row for the two instances, one field
`A | null` and one `A`, and one of them finds no interned shape for it.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| only `g(x)` | prints `9` | **yes** (two pins) |
| only `g(y)` | prints `9` | **yes** |
| `function g(z: { h: A \| null })` with `g(x)` | prints `9` | **yes** (a type parameter) |
| `function g(z)` | prints `9` for `g(x)` alone | no |
