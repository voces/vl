### D15288 — a record literal spread into a list built at a wider record, beside another list literal of its own record type, is check-clean invalid wasm

**check-clean invalid wasm · `vl check` rc 0 · clause 1 · open, target `7` then `1` · found writing [D15285](D15285.md)'s fixture · filed 2026-11-04 against master `930a8aae`**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    const wideJ: J = mk()
    const xs = [mk()]
    xs.push(...[{ f: 7 }])
    const os = [{ f: 1 }]
    print(xs[1].f ?? 0)
    print(os[0].f)

Want:

    7
    1

#### Mechanism

Not ablated past the table. The spread literal `[{ f: 7 }]` is `{f: i32}[]` built at `J[]`
(D15235). With another `{f: i32}[]` literal anywhere in the module, the module fails to validate
(`expected (ref null $type), found (ref $type)`), so something the spread lowering reads is keyed by
the literal's own list type, which the other literal's row then decides.

| `const o = { f: 1 }`, a record rather than a list | runs |
