### D16896 — `.length` read straight off a box narrowed to a union of lists builds invalid wasm

**check-clean invalid wasm · clause 1 · `vl check` rc 0 · found building [D16894](D16894.md)'s ablation · filed 2026-11-16 against master `854e949d9`, pre-existing**

Repro:

    function f(x: i32[][] | f64[][] | string) {
      if x is string { print(0) } else { print(x.length) }
    }
    const a: i32[][] = [[1], [2]]
    f(a)
    // vl check: rc 0.  vl run: invalid module, inside `f`: expected (ref null $4), found (ref $10); $4 is `i32[][]`, $10 is `union box`

Want:

    2

#### Mechanism

The else arm reads `x` at `i32[][] | f64[][]`, so `.length` takes the ref-list path
(`exprRefArray`, `arrLenTail`), but the narrowed read still holds the union box: nothing
converts it, so `struct.get` of the list wrapper meets the box.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const y = x` then `y.length` | runs, `2` | **yes** (the read in place) |
| `string` → `null`, `if x != null` | runs, `2` | **yes** (a box) |
| `i32[] \| f64[] \| string` | runs, `1` | **yes** (a ref-list arm) |
| `i32[][] \| f64[] \| string` | invalid wasm | no (one ref-list arm is enough) |
| `i32[][] \| string[][] \| string` | invalid wasm | no |
| `if !(x is string)` | invalid wasm | no |

#### Grading list

`K[][] | i32[][] | string` with `K = 0 | 1`, the same read, is a loud emit reject
(`only i32[] arrays and struct/union element arrays are supported`) and must run too.
