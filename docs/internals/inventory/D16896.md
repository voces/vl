### D16896 — `.length` read straight off a box narrowed to a union of lists builds invalid wasm

**closed 2026-11-16 · runs, prints `2` · was check-clean invalid wasm · clause 1 · fixed in emit_collect.vl: `collectInlineUnions` also walks each expression-position `if` (`valueIfNodes`), so a binding in its arms, the list-union rewrite's receiver `$luN` among them, registers the union it holds and its cell is the box · `narrowed-box-list-union-length.matrix.vl` 68 cells SILENT → RUNS, 76 of 78 run (the other two are [D16897](D16897.md)) · pin: `tests/cases/unions/narrowed-box-list-union-reads.vl` · `vl check` rc 0 · found building [D16894](D16894.md)'s ablation · filed 2026-11-16 against master `854e949d9`, pre-existing**

Repro:

    function f(x: i32[][] | f64[][] | string) {
      if x is string { print(0) } else { print(x.length) }
    }
    const a: i32[][] = [[1], [2]]
    f(a)
    // vl check: rc 0.  vl run: invalid module, inside `f`: expected (ref null $4), found (ref $10); $4 is `i32[][]`, $10 is `union box`

Want:

    2

#### Mechanism

The emitter reads the narrowed `x` at `i32[][]`, the first list member, not at the union the
checker reports: `nodeTyAt` and `nodeTyInOf` both give `i32[][]`. So `identReadContainerAt`
answers `RC_REF_LIST`, `exprUnion` is false, and `.length` takes the ref-list path
(`exprRefArray`, `arrLenTail`). But the read itself emits the box with no unbox. A copy
(`const y = x`) is delivered through the per-arm dispatch and runs. Traced: the rewrite binds
its receiver in a `const $luN` inside an expression-position `if`, which the union registry's
statement walk never entered, so `i32[][] | f64[][]` named no box and the cell was a list.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const y = x` then `y.length` | runs, `2` | **yes** (the read in place) |
| `string` → `null`, `if x != null` | runs, `2` | **yes** (a box) |
| `i32[] \| f64[] \| string` | runs, `1` | **yes** (a ref-list arm) |
| `i32[][] \| f64[] \| string` | invalid wasm | no (one ref-list arm is enough) |
| `i32[][] \| string[][] \| string` | invalid wasm | no |
| `if !(x is string)` | invalid wasm | no |

#### Grading list

`K[][] | i32[][] | string` with `K = 0 | 1`, the same read, is a loud emit reject
(`only i32[] arrays and struct/union element arrays are supported`) and must run too.
