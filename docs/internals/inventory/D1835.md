#### Mechanism

`refListElemNameOfExpr` fell off its own end for both operands of `self[i] == needle` inside
`indexOf$m1`, for two independent reasons, and `refListSlotOfExpr` then clamped the miss to
slot 0. Neither reason is a type variable: the monomorphizer rewrites the instance's
annotations to concrete spellings, and a probe at the clamp reads `ann[(i32[][]|null)[]]` for
`self` and `ann[(i32[][]|null)]` for `needle`.

The `Index` rung asks `nameIsArray(outer)` of the receiver's element name. `outer` resolves
correctly to `i32[][]|null`, but that name ends `ll`, not `[]`, so the nested-array rung
declines; the kind-18 nullable rung above it is gated on `narrowVariantFor`, and `indexOf`
compares without a null narrow. The `Ident` rung reaches `paramNulRefArray`, which asks the
ARENA and answers true, then hands the SPELLING to `nullablePartOf` — which splits on a
depth-0 bar, and the monomorphizer's grouped `(i32[][]|null)` hides it at depth 1. Two
producers disagreeing about one type, which is the family this campaign exists to remove.

Slot 0 is a real row, so the clamp is correct exactly while row 0 is this list's. `ss`
displaces it and the borrow becomes a check-clean invalid module.
