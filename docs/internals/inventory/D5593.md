### D5593 — a callee's write summary depends on whether its body was checked before the caller asks

**closed 2026-10-17 — the witness prints `b7` · was a loud check reject, clause 2, structural · residual of D5592 · filed 2026-10-17 against master `44ed9635a` · fixtures `tests/cases/soundness/callee-declared-after-keeps-narrowing.vl` and `tests/cases/soundness/index-operator-writing-receiver-declared-after-ends-narrowing-reject.vl`**

Repro:

    type Box = { kind: "a" | "b" | "c" }
    function "[]="(self: Box, _i: i32, _v: i32) { self.kind = "a" }
    function "[]"(self: Box, i: i32): i32 { if self.kind == "a" { 0 } else { i } }
    type Intent = { kind: "a" | "b" | "c" }
    function act(i: Intent, xs: i32[]): string {
      if i.kind == "a" { return "a" }
      fill(xs)
      match i.kind { "b" => "b\{xs[0]}", "c" => "c" }
    }
    function fill(xs: i32[]) { xs[0] = 7 }
    print(act({ kind: "b" }, [0]))
    // vl check refused it: the call to 'fill' on line 7 may reassign 'i.kind'

Want:

    b7

#### Mechanism

`fnWriteShapes` reads `nodeTyOf` over the callee's body, and that table is filled as bodies
are checked: un-annotated ones in the inference pre-pass or on demand at a forward call,
annotated ones in source order in pass 2. When the narrowing diagnostic is decided while the
callee's body is still unchecked, `xs[0] = 7` has no receiver type, D5590's built-in test
cannot apply, and the site is charged with every declared index operator. D5592 stopped that
answer being cached; it is still the answer given at that moment. The structure that removes
the class is one producer of per-function write facts that does not depend on check order:
check a callee's body on demand before summarising it, with an in-progress guard for
recursion, or compute the summaries in a pass after every body is typed.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `fill` declared before `act` | runs | **yes** |
| `act`'s return annotation | still refused | no |
| user operators replaced by `import { Buf } from "std:buffer"`, record list read | still refused | no |

#### Grading list

The same-module spellings of D5592's witness with `foeName` declared after `foeActs`, with and
without `foeActs: void`; D5592's fixture; first-use inference fixtures under
`tests/cases/inference/`, since checking an annotated body early reorders what pins a global.

#### Fix

Pass 2 checks a top-level function's body only after every later-declared top-level function
the body names, or dispatches an operator to, whose write summary still reads an untyped node
(`progCheckCalleeFirst`, `check_top_level.vl`). Each callee is checked at module scope with
the ordinary per-statement sequence, and a statement is marked done on entry, so a cycle
keeps source order. The probe that asks whether a summary is settled exposed one more answer
that was cached before its body was typed: an `Ident` argument with no type recorded was not
counted as untyped in `weArgShapes`, so D5591's scalar test cached `"*"`. It now counts.
Demand inference of a forward callee inside a caller's body is a different path and leaks the
caller's scope into the callee: D5650.
