### D3132 — an un-annotated parameter as a record literal's field value mints no row

**loud emit reject · clause 2 · pre-existing on master `a29230611` · split from [D3123](D3123.md) by the #3278 review · filed 2026-09-28 against master `a29230611`**

Repro:

    function f(v) { { m: v } }
    const x: {[i32]: i32} = Map()
    x[3] = 7
    print(f(x).m[3] ?? -1)
    // vl check: rc 0.  vl run: emit error, emitProgram: ref valtype with no interned shape

Want:

    7

#### Mechanism

Not traced. The field's value is the hole parameter, whose type is a `TyVar` in the template.
`anonFieldCode` has no rung for it, so the literal mints no row and the inferred return has no
shape. The instance's pin is what would give the field a code. The defect is not specific to
maps, so the D3123 map rung does not reach it.
