### D2892 — an un-annotated binding of an `if` whose arm is a narrowed list-union name is invalid wasm

**check-clean invalid wasm · clause 1 · found while ablating D2876 · filed 2026-09-27 against master `d39c809c1`**

Repro:

    function mk(b: boolean): string[] | i32[] {
      if b { return ["z"] }
      [1]
    }
    const v = mk(true)
    const q = if v is string[] { v } else { ["w"] }
    print(q[0])
    // vl check: rc 0.  vl run: invalid module — expected (ref null $type), found (ref $type)

Want:

    z

#### Mechanism

Not localised past the ablation. The then arm reads `v` narrowed to `string[]`, whose storage is
the union box; the join is `string[]`, and the arm is lowered as the box rather than unboxed to
the list the join's blocktype names. Annotating the binding routes it through the delivery that
unboxes.

| --- | --- | --- |

| the list members (`string \| i32`, `v`/`"w"`) | runs | **yes** |

`const q = if v is T[] { v } else { [t] }`), a loud emit reject at `string` and `boolean` pins.
