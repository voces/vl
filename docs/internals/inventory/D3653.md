### D3653 — arithmetic over a numeric union declared by ALIAS is refused when no inline numeric union appears in the program

**closed 2026-10-04 — the witness prints `3` · was a loud check reject the inline spelling does not owe, clause 2 · found by lane WV while closing [D3543](D3543.md), the same mechanism · filed and closed against master `32b753681` · fixture `tests/cases/unions/alias-numeric-union-arith.vl`**

Repro:

    type N = i32 | f64
    function h(c: boolean): N {
      if c { return 2 }
      2.5
    }
    const x: N = h(true)
    print(x + 1)
    // master: operator '+' is not defined for N and i32

Want:

    3

#### Mechanism

[D3543](D3543.md)'s. The per-member operator hooks are gated on `numUnionMinted`, which
`mkUnionTy` raised from the members it was handed; a declared union's placeholder is minted empty
and filled in place, so an alias never raised it. The fill now asks the same
`noteUnionMembers` the inline mint does.

#### Ablation

| ingredient changed | outcome on master | needed? |
| --- | --- | --- |
| an inline `const zz: i32 \| f64 = 1` before the use | prints `3` | **yes** (no inline numeric union) |
| `const x: i32 \| f64 = h(true)` | prints `3` | **yes** (the alias) |
