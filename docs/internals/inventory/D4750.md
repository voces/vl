### D4750 — a `??` over an atom-valued map refuses a default that is another arm of the destination union

**loud check reject · clause 2 · found closing [D4643](D4643.md) · filed 2026-10-14 against master `8d35ed838`**

Repro:

    type K = "a" | "b"
    const m: Map<string, K> = Map()
    m["k"] = "a"
    const u: K | i32 = m["k"] ?? 3
    print(u is i32)
    // vl check: rc 1, `??` over an atom-valued map needs a member-literal (or atom) default

Want:

    false

#### Mechanism

The checker's `??` arm for a map whose value type is a literal-union atom requires the
default to be a member literal or an atom (`tErrUnsupported`), so a default that is another
arm of the annotated destination union is refused before the emitter sees it. The refusal
names a mechanism, not a contract: the same program over an `i32`- or record-valued map runs.

#### Grading list

The miss-key spelling (`m["z"] ?? 3`, which should print `true`), the `.get` form and the
un-annotated destination.
