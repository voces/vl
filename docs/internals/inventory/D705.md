#### Mechanism

`exprString`'s `Ident` arm ended `return globalIsStringSid(sidOfNode(exprIx))` — a module
NAME-table lookup taken *after* the local/param/capture probes each answered "not a string",
which is not the same answer as "not a local". Measured at that rung with an `emitFail` probe
(validated against a control that must fire, `declaredSlotOf=-1`): `name=sh fnIx=9
declaredSlotOf=0 paramIndexOf=-1 scopeSlotOf=-1 localNamesLen=1 -> GLOBAL string`. So the
name WAS a declared local of the frame and the site answered from the module table anyway;
`print` took the STRING arm and the i32 landed in the string scratch. `identBoundInFrame`
now asks `localIndexOf` + `capturedKindOf` — the two resolvers `emitIdentNode` itself uses —
so classifier and lowering cannot disagree about the storage class.
