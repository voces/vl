#### Mechanism

Traced at the close: the function-flow table (`ffMethodAt`, fn_flow_shadow.vl) returned a
`slice` call's receiver as its result, so `ys[0] = inc` flowed `inc` into the source literal's
element and the slot took a second instance. Filed text follows. The refusal points at the source literal `[id]`. Since the close of
[D10082](D10082.md), the same program with `ys.push(inc)` and `ys[1](2)` runs, so the index
write through the copy is the ingredient that differs. The spread copy runs with the same index
write, so the copy's missing expansion in the flow pass (`mfrSliced`, emit_mono.vl) is the
likely seat, as for [D10190](D10190.md). Left open by the lane that closed
[D10202](D10202.md) and [D10204](D10204.md): an emit mechanism the checker changes there do
not reach.
