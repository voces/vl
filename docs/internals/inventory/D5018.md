### D5018 — a function value stored into a binding from a list, a field or a call result makes every call through it write anything

**loud check reject · the fallback D5017 left out · filed 2026-10-16 against master `8135c1f73`**

Repro:

    type Box = { m: string | null }

    function countNone(_n: i32): i32 { 0 }
    function bump(n: i32): i32 { n + 1 }
    let counter: (n: i32) => i32 = countNone
    function counterSet(f: (n: i32) => i32) { counter = f }

    function show(b: Box): i32 {
      if b.m != null {
        const k = counter(1)
        return b.m.length + k
      }
      -1
    }

    const fs = [bump]
    counterSet(fs[0])
    print(show({ m: "abc" }))
    // vl check: 'b.m' is no longer narrowed to string: the call to 'counter' on line 10 may reassign it

#### Mechanism

D5017 charges a call through a binding the union of every function stored into it, but only
while each stored value is a named function, a lambda, or another binding with a known set
(`cwFvAddValue`, `check_write_scan.vl`). `fs[0]` is none of those, so the set is unknown and the
call writes anything. The sound fallback is the union of the write effects of every
address-taken function or lambda whose type fits the binding's: no function outside that set
can reach a function-typed slot. Neither `bump` nor `countNone` writes `b.m`.

#### Ablation

| variant | outcome | needed? |
| --- | --- | --- |
| `counterSet(bump)` | runs, prints 5 | **yes** |
| `const hd: Holder = { h: bump }` then `counter = hd.h` | still refuses | no |
| `function pick(): (n: i32) => i32 { bump }` then `counter = pick()` | still refuses | no |

#### Grading list

- The writer control: the same shape with a function in `fs` that writes a `Box` it can reach
  must still cancel the narrowing.
- The address-taken set has to include a function reached only through another module's
  export, and a lambda stored straight into a list.
