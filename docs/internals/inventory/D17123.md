#### Mechanism

The IR claims `take` and lowers its map read by calling legacy's shared helper
`emitMapGetScalarBoxTail` (ir_lower.vl, the `RMapGet` box arm), which refuses with
`emitFail` when the value atom has no value-box type. `emitFail` latches the compile's first
message, and the claimed body is lowered before legacy would reach its own refusal in that
function. So the helper's message stands, and it is not the refusal legacy raises.

`emitFail` also resets the module writer, so a claim cannot decline after a helper has
refused. The decline has to come from inside the claim's lowering, before the refusal latches.
The IR lowering imports 42 legacy helpers that call `emitFail` directly (more transitively),
so this row is a class, not one site.
