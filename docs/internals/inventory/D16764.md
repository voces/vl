#### Mechanism

`elabCbAtBuild` instances a callback at the receiver's build only when its parameter is
un-annotated: the instance key is the parameter's row entry (`#r.0`), and an annotation fixes the
parameter at `{ f: null }`, which no element is stored at. Running it needs the callback's
annotated parameter re-typed at the build, the D3992 parameter rewrite applied to a lambda: the
annotation becomes a bound the build must fit, and the instance takes the build. Until then
`recCbTakesBuild` refuses it.
