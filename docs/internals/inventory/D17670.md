#### Mechanism

`lap2` returns its parameter, which it calls at two signatures, so its result is a bundle that
one signature set picks from. A call whose result is bound to a name no read ever picks from
has no set to pick, and legacy refuses it. The IR names the same point `bundle result pick
refused`. The discarded-result spelling (the call as a statement) runs, as does a binding
whose value is read or stored.
