### D14436 — an un-annotated function held in a record field's list is called through the emitter's element pin only

**runs today and must keep running · carried by the emitter's element pin, not by the checker · without the pin the build refuses with `ref valtype with no interned shape` · filed 2026-10-27 against master `9b5bfd1b8`**

Repro:

    function inc7(a) { return a + 1 }
    function ap(r: (a: i32) => i32) { return r(7) }
    const rec = { fs: [inc7] }
    print(ap(rec.fs[0]))
    // Want: 8

#### Mechanism

The list a record field holds gets its element representation from the emitter's flow pin.
The checker resolves `v[0]` of a bound list literal to its member when it adapts the argument,
but `rec.fs[0]` reads through the field, so with the pin's element answer removed nothing gives
the field's list an interned element shape. Deleted when a field-held list's element rep is
the one its literal was built at, read through the field.
