### D15694 — a `for` over a list read off a record field types its loop variable at the list's checked element, not where the list is built

**loud emit reject · check-clean, an internal message, clause 1 · `emitProgram: field access receiver is not a struct` · found closing D15690 · filed 2026-11-11 against master `f50936aa`**

Repro:

    type J = { f: i32 | null }
    function mk2() { { f: 1 } }
    const dA: J = mk2()
    print(dA.f ?? 0)
    const r = { ys: [mk2()] }
    for y in r.ys { print(y.f ?? 0) }

Want:

    1
    1

#### Mechanism

Not ablated. The field `ys` holds a list built at `J[]`, while the loop variable `y` is typed at the
field's checked element `{f: i32}`, so the read `y.f` asks for a struct the element is not.
