#### Mechanism

[D7220](D7220.md) at the list-element position. The checker reads `KC` as the literal
`"circle"`, so `"circle"[]` and `KC[]` are one type and the delivery needs no copy. The
emitter repped a list of a named literal union as an i32 atom list and a list of one inline
literal as a string list, because the element was asked through `tyIsLitUnion`, which
answers only for a `TyUnion`, and a lone literal is a bare `TyLit`. The close does not widen
that predicate: the list constructor stores a lone string-literal element as its one-member
set, so the arena type, the emit name (`tyToNameGo`, `canonEmitNameTs` at `RC_ELEM`,
`nameIsLitUnionArray`) and the generic pins (`monoArgLitUnionPin`, an explicit `<"circle">`
type argument, a `T` result bound to the literal) all read one atom list. A lone literal at a
scalar position still softens to `string` ([D7440](D7440.md)).
