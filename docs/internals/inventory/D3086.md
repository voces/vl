Repro:

    type CD = "c" | "d" | "e"
    function idi<T>(x: T) { x }
    function g<T>(x: T) { const y = idi(x); const f = () => print(y); f() }

#### Mechanism

Not localised past the ablation. `y` is captured into the lambda's env as the atom, and the
lifted lambda's `print` asks `litAtomWidenTexts` for members; the capture carries the rep but
not the instance's pin, which the lambda's frame (not an instance) cannot substitute.
