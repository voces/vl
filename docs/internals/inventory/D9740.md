#### Mechanism

The record-list rung that lets an anonymous lambda's `[]` adopt its expected return
(`structElemListRetName`, check_ret_name_shapes.vl) pins the lambda by the emitter-format
RENDER of the list type, `irRendered(tyToEmitName(er))`, which `synthRetAnnots` reads back. A
record that nests one record twice per level doubles that render per level, so the rung
declines once `sefpWidth` counts more than `SEFP_WIDTH_CAP` (4,096) field positions, rather
than render. `A11` holds 6,143. Running it needs the pin keyed by the arena type rather than
by its spelling.
