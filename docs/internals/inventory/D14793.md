### D14793 — a parenthesized void member call used as a statement inside a function body builds invalid wasm

**check-clean invalid wasm · clause 1 · open · pre-existing on master `4c4e4225f` · found by step 4's tail-value grid around D3466 · filed 2026-11-01 against master `4c4e4225f`**

Repro:

    const xs: i32[] = [1]
    function h() {
      (xs.push(2))
      print(xs.length)
    }
    h()
    // vl check: rc 0.  vl run: invalid module inside `h`, unknown local 3: local index out of bounds

Want:

    2

#### Mechanism

Not yet traced. A parenthesized call statement is lowered as that call (D2637), and the module
fails with a local index the function never declared, so the discard of a void member call
inside a function body takes a path the unparenthesized statement does not. The ablation is
what is known: the parentheses, a function body, and a void member call are each needed.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the parentheses (`xs.push(2)`) | runs, prints `2` | **yes** |
| inside a function (the statement at top level) | runs, prints `2` | **yes** |
| a void member call (`(s.includes("b"))`, valued) | runs | **yes** |
| a member call (`(v())`, a free void function) | runs | **yes** |
| a local list (`const xs` inside `h`) | same invalid wasm | no |
