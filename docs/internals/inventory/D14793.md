### D14793 — a parenthesized void member call used as a statement inside a function body builds invalid wasm

**closed 2026-11-01 by `blockPushPopBits` reading a parenthesized call statement as that call, so the push scratch locals are reserved · the witness prints `2` · was check-clean invalid wasm, clause 1, on master `4c4e4225f` · fixture `tests/cases/arrays/paren-push-statement-in-function.vl` · found by step 4's tail-value grid around D3466 · filed 2026-11-01 against master `4c4e4225f`**

Repro:

    const xs: i32[] = [1]
    function h() {
      (xs.push(2))
      print(xs.length)
    }
    h()
    // vl check: rc 0.  vl run: invalid module inside `h`, unknown local 3: local index out of bounds

Want:

    2

#### Mechanism

A parenthesized call statement is lowered as that call (D2637), but `blockPushPopBits`, which
decides which inline-push scratch locals a function body reserves, had no arm for a `Paren`
statement, so a parenthesized `.push` statement reserved none and its grow sequence read locals
the function never declared. Top level reserves its push frame by another walk.
