### D15292 — a list of records holding a record of a list of an uncalled un-annotated function, returned or bound, has no interned rep shape

**closed · runs, prints `1` · was loud emit reject, `emitProgram: ref valtype with no interned shape`, clause 2 · found closing [D15207](D15207.md) · filed 2026-11-04 · fixed with [D15294](D15294.md): the elaboration's held type closes a nested record's function leaves at any depth**

Repro:

    function inc0(a) { return a + 1 }
    const rs = [{ r: { fs: [inc0] } }]
    print(rs.length)

Want:

    1

#### Mechanism

`monoPinStoredRecords` pins a record field that holds a function or a list literal of functions, and a field holding a closed binding's type; a field holding another record literal whose own field is an open list of functions is neither, so the pin refuses (-1) and the list keeps its open element.
