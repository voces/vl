#### Mechanism

Two readers disagreed with the cell. The print arm asked `asgYieldsNulHole`, which accepted a
plain name target only, so the capture's cell element `x[0]` fell to the hole's `i32` arm. The IR's
value arm had no value: the cell's store does not build a call's right side where the capture can
stash it, and only a scalar literal was rebuilt. The value is now the cell read back after its
store, at the cell's rep.
