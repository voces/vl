#### Mechanism

A union box carries a list member as its wrapper ref under a tag. `u8[]` takes the
value-atom code 13 (`valueAtomKind`), and the unbox reads its wrapper off that code
(`listWrapHeapOfKind`). D16043 gave `i8[]`, `u16[]` and `i16[]` the packed list's
kind with a wrapper per row, but no tag. `rtOfUnion` (`emit_rep`) refuses such a union
before any row mints, in place of the invalid module it produced before. The close keys
the member's tag by its checked type, not by a new atom code (step 7's typed tags, D16052).

#### Close

`i8[]`, `u16[]` and `i16[]` take value-atom kind `PK_KIND_BASE + row` (`pkKindOfRow`), above
every other kind, so no fixed-kind compare matches one. Their tag is minted on first use at
`scalarTagOfKind`, from `pkTwinRows`, at codes above the map twins and below the atom-leaf list.
`u8[]` keeps kind and code 13. The unbox reads the row's wrapper, `==` compares at the row, and
the `rtOfUnion` refusal is deleted. `packed-list-union-arm-{u8,i8,u16,i16}.matrix.vl` grade it.
