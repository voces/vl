### D2854 — a closure called inside a hole-parameter function at two pins builds one instance's value into the other's rep

**check-clean invalid wasm · clause 1 · identical on master `721781075` · found by the #3220 round-3 review (`r3/K6.vl`) · filed 2026-09-27**

Repro:

    function mk(x) {
      const c = (y) => y
      return c(x)
    }
    print(mk(7))
    print(mk("s"))
    // vl check: rc 0.  vl run: invalid module inside `mk` — expected (ref $type), found i32

#### Mechanism

Not ablated to a rung. `mk` is cloned per pin, but the nested lambda is shared between the
clones rather than re-minted at the hole's binding, so one lambda body is lowered for two
parameter reps. A record built through such a closure (`{ f: c(x) }`, or a closure returning
`{ f: x }`) reaches the same defect. D2850's per-pin return row therefore declines any body
with a nested function, which keeps those shapes the loud refusal master gives them.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the second pin (`mk(7)` only) | runs | **yes** |
| the closure (`return x`) | runs | **yes** |
