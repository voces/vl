#### Mechanism

A monomorphized instance shares its template's leaf expressions, so the checker's type of the
arm's tail `w` is `T`. Three readers classify the join from that tail before the arm's prelude
is lowered, when `w` is not yet in scope: `emitIfExpr` choosing the blocktype, the collect pass
classifying the binding `r`, and the monomorphizer pinning a generic callee handed the `if`
(`monoArgTyName`). Each fell to the i32 default. The close binds each arm's prelude locals to
their collected slots while the join and the binding are classified (`armPreludeBindChain`,
`letInitArmsFirst`), and the pin reads the local's initializer (`monoArmTailLocalInit`).

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const w = a; w` → `a` | runs | **yes** (the prelude local as the tail) |
| `wrap<T>` → `wrap(c: boolean, a: string, b: string)` | runs | **yes** (the type parameter) |
| `const w = a` → `const w: T = a` | still invalid | no |
| the binding → `return if …` | still invalid | no |
