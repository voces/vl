### D1991 — `match` re-evaluates a non-variable scrutinee once per tested arm

**closed 2026-09-22 · was check-clean silently wrong, clause 1, wrong value · pre-existing on master · filed 2026-09-22 against master `4d64edc` (#3017 review) · fixture `tests/cases/match/computed-scrutinee-evaluated-once.vl` · residue D2038 (positions the binding cannot reach), D2039 (a pre-existing emit refusal the nested-arm case now meets)**

Repro:

    let n = 5
    function next() {
      n = n + 1
      n
    }
    const r = match next() { 5 => "five", 6 => "six", 7 => "seven", _ => "other" }
    print("\{r} \{n}")
    // was: PRINTS other 8
    // now: prints six 6

#### Mechanism

`desugarMatchAt` builds each arm's test as `scrut == pat` over the SAME scrutinee node, so the
chain it produced emitted the scrutinee expression again at every tested arm (n−1 times for n
arms). The fix is `hoistMatchScrutinees` in `typecheck.vl`, run at `checkProgram` entry before
the typed-IR tables are sized: a scrutinee that is neither a literal nor a place `placeKeyOf`
keys is bound to `const $scrut<match>` immediately before the statement holding the match (or
at the head of the enclosing match arm), and the scrutinee, the type patterns and the payload
reads all name that binding. The binding is an ordinary local, so a monomorphized instance
types it per instance, a payload clause over a call now narrows (it was a check reject), and an
integer match over a computed scrutinee is `br_table`-eligible. At module scope the binding is a
global, and `topStmtOrderKey` orders its start-function initializer just before the statement.
The climb stops, leaving the match as parsed, wherever moving the evaluation would reorder or
skip one (D2038).

#### Grading list

A 261-cell grid (8 scrutinee kinds: call, field, field-through-call, index, index-by-call,
arithmetic, literal, variable × 5 match kinds: `i32`, `i64`, literal union, union with payload,
nullable × 9 positions: statement, local initializer, module initializer, tail, `return`,
argument, lambda body, generic body, nested arm), each printing the arm and the side-effect
count: before 97 runs / 90 wrong value / 74 refused, after 233 runs / 0 wrong / 28 refused,
**no `runs` cell lost**. The 28 still refused are the pre-existing arm-prelude gap (a payload
match in a module initializer or an argument, refused identically for a variable scrutinee)
and D2039. `tests/vl_match_br_table_test.ts` `computed_scrutinee` now counts one table.
