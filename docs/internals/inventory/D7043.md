### D7043 — a module global typed by an alias that nests a nullable literal-union alias widens with no scratch frame

**check-clean invalid wasm · clause 1 · open · found by lane L6 step 3's ablation of [D4041](D4041.md) · a loud emit reject (`literal-union string widening with no members`) on master `6ca1ebc5c`, invalid wasm since L6 step 3 lets the widening run · filed 2026-10-19 against master `6ca1ebc5c`**

Repro:

    type A = ("a" | "b") | null
    type U = A | { tag: i32 }
    const a: ("a" | "b") | null = "a"
    const u: U = a
    print(u == null)
    // vl check: rc 0.  vl run: invalid module, top-level: unknown local 4: local index out of bounds

Want:

    false

#### Mechanism

The start function's widening of the `K | null` atom into `U`'s box uses the string-op scratch
frame. The scan that reserves that frame for a module global, `globalInitWidensAtomToStr`, asks
`unionTakesAtomAsStr` of the target's spelling. With `U` written over the alias `A` that test
appears to miss the literal arm, so no frame is reserved and the widening reads a local that does
not exist. Not yet confirmed by a probe.
