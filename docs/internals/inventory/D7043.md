#### Mechanism

The start function's widening of the `K | null` atom into `U`'s box uses the string-op scratch
frame. The scan that reserves that frame for a module global, `globalInitWidensAtomToStr`, asks
`unionTakesAtomAsStr` of the target's spelling. `unionTakesAtomAsStr("U")` answers false, because
the spelling names an alias and the literal arm is two aliases down, so no frame is reserved and
the widening reads a local that does not exist. Confirmed by a probe that recorded each
reservation answer into the emit failure's message. The scans for a `let` binding and a declared
return asked the same spelling question, which is [D7120](D7120.md) and [D7121](D7121.md).
