### D15608 — `is` outside a branch condition, over a bounded type parameter's field, is refused where the pin makes it false

**loud check reject · clause 2 · `vl check` rc 1 at the pin: `` `is` check type 'i32' can never match a value of type string `` · the same test as an `if` condition runs (D15606), and at the true pin it prints `true` · found closing D15607 · filed 2026-11-09 against master `5f4d4da2`**

Repro:

    function boundShow<T: { x: i32 | string }>(t: T) {
      print(t.x is i32)
    }
    const b: { x: string } = { x: "s" }
    boundShow(b)
    // vl check: the instance's re-check refuses the `is` as never true

Want:

    false

#### Mechanism

Not traced. The instance re-check types `t.x` as `string`, the pin's field, and the "can never
match" diagnostic fires on the value position. In a branch condition the same re-check treats
the test as deciding a dead arm and raises nothing. The generic body is legal for every type its
bound admits, so a pin cannot make it ill-typed.
