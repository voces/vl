### D3976 — a written `let` alias of a capture cell's read, reassigned and returned, builds invalid wasm

**check-clean invalid wasm · clause 1 · found in review of #3501 (`rv3501/r05`) · filed 2026-10-10 against master `56f77d80f`**

    function inner<U>(u: U) { print("I"); print(u) }

#### Mechanism

Not located. `r` is a `let` initialized with the cell's read and then written (`r = q`), so the
alias rule of D3948, which follows only aliases never written after their initializer, does not
apply, and the cell's element keeps the generic seed's un-pinned type while `r` is built at the
return type.
