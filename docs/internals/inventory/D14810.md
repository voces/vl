### D14810 — a by-rep parameter's value handed back, stored or captured where the rep is not read refuses

**closed · now runs, prints `4` then `4` · was loud check reject, clause 2 · filed 2026-11-01 against master `8ab2cf7d` · closed 2026-11-01 against master `9d601ea5`: a returned by-rep value bound to a `const` read only for fields is bound at the build (`recBoundForFields`, `callBuiltTy`) · fixture `soundness/built-container-read-returned-by-rep-bound-runs.vl` · storing, comparing, passing the binding on and capturing it in the callee are [D14811](D14811.md)**

Repro:

    type J = { f: i32 | null }
    function mk() { { f: 4 } }
    function back(r) { return r }
    const wideJ: J = mk()
    const xs = [mk()]
    const b = back(xs[0])
    print(b.f)
    print(wideJ.f ?? 0)
    // vl check: this {f: i32} is stored at J, ... type-valid but not supported yet

#### Mechanism

`xs`'s elements are built at `J`. A by-rep instance (D14532) serves a hole or type parameter whose
uses read the rep (`recParamTakesRep`). With D14754's close, that includes a value the function
returns to a call whose result is read for a field or handed on by rep (`recRetTakesRep`). Every
other use of the value at the caller, or in the body, hands a `J` on to a position typed
`{f: i32}`:

* binding the result, as in the Repro;
* storing it in a literal's field or a list;
* handing it to an annotated parameter;
* comparing it;
* capturing it in a closure.

`recBuiltReadRefuse` refuses those deliveries.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `const b = …` then `b.f` replaced by `back(xs[0]).f` | runs (D14754) | **yes** |
| `const wideJ: J = mk()` | runs | **yes** |
| a generic `back<T>(r: T): T` in place of the hole | still refuses | no |
