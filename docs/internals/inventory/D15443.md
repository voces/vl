#### Mechanism

D15442's: the tag decision declines `{apply2}` at the alias call, which the check did not note
through the set, and `viaFor(add)` hands a tagged `{add}` id into the `{apply2}` closure. The
module spelling is closed by noting a module alias's call handed a set. Inside a function the
same note reaches calls whose argument is a parameter bundle or a number, which the corpus does
not survive; the close has to tell those apart, which is also D15441's remaining decline
(`const k = apply2; k(h)` in `viaAlias`).
