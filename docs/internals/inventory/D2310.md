### D2310 — two emit-side membership tests scanned a whole-program list per query: the arm-prelude blocks per if-expression arm, and the extern declarations per call

**closed 2026-09-24 — `markArmPrelude` and `externLinkOf` fell from 5.1% and 4.7% of plumb's `chunk_662` compile (guest profile, `--names` seed) to nothing measurable, output byte-identical · was a compile-time cost, not a miscompile: every spelling ran · filed 2026-09-24 against master `ab942030b`**

Repro:

    function f(c: boolean): i32 {
      let acc = 0
      @@repeat(3000, "{ const v = if c { const t = 2; t * 3 } else { 1 }; acc = acc + v } ")@@
      acc
    }
    print(f(true))
    // runs, prints `18000`

#### Mechanism

`armPreludeBlocks` (compiler/emit_state.vl) listed every if-expression arm with a prelude in
the whole PROGRAM, and both `markArmPrelude` (the collect walk, which also deduped against it)
and `armPreludeWalked` (the emitter) answered membership by scanning it, so a program of n such
arms paid O(n²). `externLinkOf` (compiler/ast.vl) answered a call's extern link row by scanning
every `extern function` declaration of the graph, once per call site; plumb's units declare
~100 externs and call them from every function.

#### Fix

`armPreludeBlocks` is a mark column indexed by arena node. `externLinkOf` reads a name-keyed
index of each name's first declaration row, which `externAdd` extends in place and a rename
(`externRenameDecl`, the module merge) marks stale for one rebuild. Both answer exactly what the
scan answered, first match included; the three plumb chunks and the self-compile are
byte-identical.
