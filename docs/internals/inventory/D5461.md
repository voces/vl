### D5461 — a container read of a declared `Pa | Pb | null` over same-shape records has no pool set

**runs today and must keep running · `sharedUnionFieldPlan` (`emit_classify.vl`) finds no member-set pool set for the receiver `Pa|Pb|null`, and reads its atoms only by splitting the spelling text; a compiler that declines on the miss refuses `__m["k"].val` with `field access receiver is not a struct` · found by lane L6 deleting that split after closing [D5380](D5380.md): the capability matrix `same-shape-union-into-nullable` lost `array_element_place` and `map_value_place` in the annotated face · filed 2026-10-17 against master `4b58283cf`**

Repro:

    type Pa = { tag: i32, val: i32 }
    type Pb = { tag: i32, val: i32 }
    function pick(n: i32): Pa | Pb {
      const b: Pb = { tag: 2, val: n }
      return b
    }
    const m: { [string]: Pa | Pb | null } = Map()
    m["k"] = pick(4)
    if m["k"] == null {
      print("null")
    } else {
      print(m["k"].val)
    }

Want:

    4

#### Mechanism

`Pa | Pb | null` is `Pa | null` to the checker (D4989), and no union row is minted under the
spelling the receiver's set is read at. The same holds for a `(Pa | Pb | null)[]` element
(`xs[0].val`). The un-annotated faces of both cells hit the pool.

A row cannot be minted under that spelling alone: the spelling is the nullable record at a
binding and the union box at a cell, and a row makes every name-keyed delivery between the two
read the box. Minting it made both reads hit the pool and broke five of eight delivery positions
([D5540](D5540.md)). The pool cannot cover the set through the `Pa|Pb` row either, since a set
is a subset of one row's members and that row has no `null`. Close once the cell's rep is
decided by type, then retire the text split in `sharedUnionFieldPlan`.
