### D17732 — a member read of a binding holding an element of a list literal reads the anonymous record the union arm's stamp left rowless

**loud emit reject · 1 witness (b000858 reduced) · filed 2026-11-27 against master `d29f3434`**

Repro:

    type Circle = { r: i64 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    function rd() {
      const dd = [{ r: 7 }][0]
      print(dd.r)
      const gp: Circle = dd
      print(gp.r)
    }
    rd()
    // vl check: rc 0.  vl run: emit error (member record with no row)

#### Mechanism

The delivery to `gp: Circle` stamps the list literal as `Circle[]`, and the binding `dd` is held at
`Circle` (`letElemReadHeldTy`, #10622), but the IR's member read of `dd` takes the operand's row from
the anonymous `{ r: i64 }`, which no literal builds once its only literal is stamped as the arm.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `print(dd.r)` before the delivery | runs (named/elem_lit_read_alias_union_arm) | **yes** |
| the list literal, named first (`const xs = [..]; xs[0]`) | runs | **yes** |
| `type Shape = Circle \| Sq` | runs | **yes** |
