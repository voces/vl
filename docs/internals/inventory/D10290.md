### D10290 — a function read by value widens its runtime `i32`/`f64` join to `f64` at a direct call

**check-clean silently wrong · clause 1 · found closing [D3494](D3494.md) · present on master `d5ec7f160` · filed 2026-10-22 against master `d5ec7f160`**

Repro:

    function f(k: i32, a: i32, b: f64) {
      if k == 0 { return a }
      b
    }
    const h = f
    print(f(0, 7, 2.5) / 2)
    // PRINTS 3.5

Want:

    3

#### Mechanism

`njGateScan` (check_nj_gate.vl) records a function read other than as a callee, `const h = f`
here, and `njFnReached` then holds every join in `f`'s body at master's widening, so the direct
call's result is `f64` and `7 / 2` divides as a float. The value read is what the gate defends
(a function value's signature has one result type), but the direct call reads the join too.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const h = f` removed | prints `3` | **yes** |
| `const h = f` replaced by `[1].map((i) => f(0, 7, 2.5))` | prints `3.5` | no (a lambda mention holds it too) |
