### D15729 — a fresh call's record holding a list of numbers, delivered at a record storing that list's elements as a union, is refused

**closed 2026-11-12, runs and prints `5` `2` `true` · was a loud check reject, clause 2 (D14385's interim refusal) · the copy boxes each element of the list into the union (`recListElemCopies`; `emitScalarListBoxTop`) · graded by `scripts/capability-probes/matrix/kept-maker-delivery-list-elem-union.matrix.vl` · fixture `tests/cases/structs/kept-maker-list-elements-boxed-at-wider-row-runs.vl` · a member shape of [D14385](D14385.md) · filed 2026-11-12**

Repro:

    type U = { f: (i32 | string)[] }
    function ul() { { f: [4] } }
    const h = ul()
    print(h.f[0] + 1)
    const h2: U = ul()
    h2.f.push("s")
    print(h2.f.length)
    print(h2.f[0] is i32)

Want:

    5
    2
    true

#### Mechanism

The copy's rule (`recListElemCopies`) admits a list whose element widens or is a record, not one
whose element is boxed into a union member, so the delivery is not a copy and D14385's refusal of
the other call fires. The emitter's spread already boxes a scalar list element by element
(`emitScalarListBoxTop`); the copy does not call it.
