Repro:

    import { F32x4, splatF32 } from "std:simd"
    function take(a) { if a != null { print(a.y) } }

    // vl check: rc 0.  vl run: emit error, field access receiver is not a struct


#### Mechanism

Not traced. A member read on an un-annotated parameter is taken as a record field the
parameter's type must carry. At a non-null vector argument the call is refused at check
(argument 1 expects `{y: _}`, and `y` on `F32x4` is a getter). At a `F32x4 | null` argument, read
under a null test, that check does not fire, so the instance reaches the emitter with a field
read on a vector. Either face may be the answer: the getter run (as the annotated
`a: F32x4 | null` runs), or the non-null face's check refusal; today's emit refusal is neither.
