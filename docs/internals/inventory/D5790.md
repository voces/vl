### D5790 — a rest-parameter function handed to an un-annotated parameter and called there with the rest spread out is check-clean invalid wasm

**closed 2026-10-17 by lane L3 · now a loud check reject, "argument 2: expected i32[], got i32", naming the call of `g` · was check-clean invalid wasm · clause 1 · the program is ill-typed: a rest is not part of a function's type (variadics-design.md §4.1), so a call through the value passes the list · an argument demand re-checked at the pinning call asks a composite pair the same question the direct spelling asks (`argCstrFitsAt`), where it used to leave every non-scalar pair to the emitter · pins: `tests/cases/functions/error-fn-value-to-hole-param-wrong-arg-type.vl` · found closing [D5750](D5750.md) · filed 2026-10-17 against master `519a09fef`**

Repro:

    function rst(a: i32, ...xs: i32[]): i32 { a + xs.length }
    function apply(g, x, y) { return g(x, y) }
    print(apply(rst, 3, 4))
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `apply`

Want:

    a `vl check` error, as the direct spelling gives: `argument 2: expected i32[], got i32`

#### Mechanism

From the ablation only. As a value, `rst` has the type `(i32, i32[]) => i32`, and a call
through a function value does not spread its arguments into the rest list. Both annotated
spellings below are refused at `vl check`. Through the hole, the argument demand recorded for
`g(x, y)` is re-checked at the pin and does not compare `y` with the `i32[]` parameter, so the
instance calls `rst` with an `i32` where its signature takes a list.

#### Close

Graded one spelling per row on the closing seed, each one check-clean invalid wasm or a wrong
value on master before it: a rest given one element, a body literal `g(x, 7)`, a `const`
lambda, a rest-only function, a plain `i32[]` parameter given an `i32` or a `boolean`, a
`string` into `string[]`, an `i32[]` into `string[]` or into `i32`, a record into `i32`, a
`string` into a record, an `i32` into a function type and into `i32[] | null`. All are now
refused at the pinning call with the direct spelling's sentence. A list given to the rest,
`i32` into `i32 | null`, `f64 | null` and `i32 | string`, `[1]` into `f64[]` and a covariant
list still run. An empty list, a string literal into a literal union and a nested list
literal through the same hole are legal and still build invalid wasm; they are [D5840](D5840.md).
