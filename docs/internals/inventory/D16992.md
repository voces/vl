#### Mechanism

Not yet profiled. Each first instance runs `monoRegisterInstance` (compiler/emit_mono.vl), which
resumes `buildFnMap(monoProgStmts)` over the program and clears the capture memo
(`capMemoNoteEdit`). D3761 stopped `buildFnMap` re-classifying every function per instance; the
growth that remains is per instance and proportional to the program, the shape of one or more
whole-program passes repeated per instance. The axis comment's readings (300 at 2.0, 600 at 2.76)
predate this measurement. A profile (docs/internals/profiling-the-compiler.md) names the pass.
