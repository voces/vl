#### Mechanism

Profiled at 1600 instances on master `a472ea60d` (`VL_PROFILE_GUEST`, a `--names` seed). Four
passes ran once per first instance and walked the whole program each time:

1. `instAllocsOf` (check_assignable.vl, 34.6% of the run) found its function's nodes by testing
   `cwFrameOf` on every arena node. It now walks the function's own subtree. This cost came in with
   #9029, and the implicit-hole design parked with F2 would delete the pass altogether.
2. `declAnnRawTyName` / `declAnnRawTsOf` (check_gen_alias_anns.vl, 8.2% self) scanned the collected
   field list for their node. They now read a node-to-row map filled as the list is.
3. `monoDeclIsAssigned` (emit_mono.vl, 5.9%) re-read every `=` in the arena per query. Its list is
   now bucketed by target name.
4. `fnStmtsIndexOf` (emit_state.vl, 4.3%) dropped its whole position index on every `fnStmts` slot
   write, which a first instance makes, and on every `fnParent` write, which it does not read. A
   slot write now re-points the one entry (`fnPosNoteSlotWrite`; an entry held at two positions still
   drops the index), and a `fnParent` write leaves it.

Each fix moved the 1600 reading, applied in order: 4.536G, then 2.528G, 1.882G, 1.613G, 1.142G.
