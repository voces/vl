### D3230 — a call through a nullable function field refuses directly and runs through a hole

**loud check reject · clause 2 · informational, the direct spelling of [D3197](D3197.md) · pre-existing, the same on master `94670f728` · found by the #3290 round-2 review (`rv3290-4029/tw/t5.vl`) · filed 2026-09-29 against master `94670f728`**

Repro:

    type R = { v: i32, f: (() => "a" | "b" | null) | null }
    const r: R = { v: 1, f: () => "a" }
    print(r.f() ?? "n")
    // vl check: called value is not a function ((() => "a" | "b" | null) | null)

#### Mechanism

The checker refuses a call of a `| null` function at its direct spelling, while
`function h(z) { print(z.f() ?? "n") }; h(r)` reads the pin's function and prints `a`. The two
spellings disagree. [D3197](D3197.md) holds the ruling on which is right, and #3289 makes the
hole spelling refuse too.

#### Ablation

| --- | --- | --- |
| the call in a hole instance `h(r)` | prints `a` | **yes** (the direct spelling) |
| field `() => "a" \| "b" \| null`, not nullable | prints `a` | **yes** (the nullable field) |
