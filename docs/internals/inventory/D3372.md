### D3372 — a module-scope `let` with no initializer is refused as a global

**loud emit reject · pre-existing, found by the #3295 review · filed 2026-09-30 against master `6e6a5301b`**

Repro:

    let y: (i32) => i32
    if 3 > 2 { y = (x: i32) => x * 4 } else { y = (x: i32) => x - 1 }
    print(y(3))
    function h(): i32 { y(3) }
    print(h())
    // vl check: rc 0.  vl run: emitProgram: module global has no initializer

Want:

    12
    12

#### Mechanism

A top-level binding is a wasm global, and the global section needs a constant initializer the
emitter takes from the binding's own; a `let` with none reaches the global-init emitter with
nothing to lower and refuses. The same body inside a function runs (D3256). A nullable global
initialized to its rep's `null`, or a scalar's zero, would serve, since the checker orders the
first write before any read.
