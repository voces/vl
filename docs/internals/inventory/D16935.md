**loud emit reject · clause 2 · the `idx_map_in_map` cells of `uncalled-hole-fn-stored-default` · filed 2026-11-17 against master `abf14795b`**

Repro:

#### Mechanism

Only the map-in-map position builds an uncalled hole function's body; every other position emits a
stub (D16927). The body is built from the elaboration's default instance, which is enqueued as a
guess key, and the member call `x.indexOf` finds no callee there. Enqueuing that instance as a real
key moves the refusal to "cannot take the generic function `g` as a value" and makes the
`idx_field_map` cells stop building, so it was not taken.
