### D16314 — an all-`null` list literal delivered to a union whose list member holds `string | null` or a nullable function is refused at emit

**loud emit reject · clause 2 · bucket (f) · found by the fuzz-sweep triage of 2026-11-14 as the second face of a D16310 witness (`plain` leg): with the lambda's result annotated, the program stops at this refusal · filed 2026-11-14 against master `63c8d7a67`**

Repro:

    const r: (string | null)[] | boolean = [null]
    if r is (string | null)[] { print(r.length) }
    // vl run: emit error, `emitProgram: union atom has no value box`

Want:

    1

#### Mechanism

A list literal whose every element is `null` names no element type of its own, so it takes its
element from the list member it is delivered to. When that member sits in a union (a value box)
and its element is `string | null` or a nullable function, the literal reaches the union's
boxing with no value box for that element, and emit refuses. A nullable integer, float, boolean,
record or list element runs, as does any literal with a non-`null` element, and so does a
union whose other member is `null`, where the list is not boxed.
