#### Mechanism

The call's signature key (`cloCallSigKey`, `emit_classify.vl`) read the callee's recorded
type, which a generic's instances share and which names the frame's type parameter. Only the
list-element spelling substituted the instance's binding ([D7142](D7142.md)). The key now
substitutes it for every callee shape through one helper, `cloInstanceSigKey`, which also
replaces D7142's inline block. The alias of a list element (`const h = fs[0]; h(x)`) closed
with it. The alias of a field read (`const h = o.f; h(x)`) did not, and is [D7283](D7283.md).
