### D3507 — `print` of a `Rec | string | null` binding an assignment and then an `is Rec` narrow to `string` reads the box

**check-clean invalid wasm · clause 1 · open · a function local is a loud emit reject instead (`print of a union value whose arms the tag dispatch cannot classify`) · pre-existing on master · found while closing [D3500](D3500.md) · filed 2026-10-03 against master `937445a42`**

Repro:

    type Rec = { x: i32 }
    let v: Rec | string | null = null
    v = "s"
    if v is Rec { print(v.x) } else { print(v) }
    // vl check: rc 0.  vl run: invalid module, "expected i32, found (ref $type)"

Want:

    s

#### Mechanism

Not localised past the ablation. The assignment narrows `v` to `Rec | string` (its null
dropped), and the `else` of `is Rec` to `string`; the read then reaches `print`'s scalar tail
as the box rather than unboxed as the string arm. `is string` in place of the `else` unboxes it,
and so does the `else` of `is Rec` with no assignment before it (the remainder is
`string | null`, D3500's neighbour).
