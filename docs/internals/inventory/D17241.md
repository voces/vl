### D17241 — a claim that falls back has already interned atoms, so the shipped build numbers them unlike legacy

**runs today and must keep running · shipped bytes differ from the claimless (legacy-only) build: the atom ids swap, the output agrees · a recorded defect, not a chosen divergence · filed 2026-11-24 against master `80d557f6f` by lane IR-N6**

Repro:

    type K = "a" | "b"
    function p(s: K | null): boolean { return "a" == (s ?? "b") }
    print(p("a"))
    print(p(null))

Want:

    true
    false

#### Mechanism

The IR tries `p` and fails to lower it (`unlowered: operand above a valued if's value`). Legacy's
`atomEqPlanOf` takes the `static` arm, with the literal on the left; the IR builds that side and
then the `??` over the atom, and the lowering finds the literal above the `??`'s valued `if`. The
claim falls back and legacy writes `p`. By then the attempt has interned the atoms, `"b"` before
`"a"`, so the shipped module numbers them unlike the claimless build. That build swaps `0` and `1`
at the three atom sites of `p` and `__start__`:

    shipped     (i32.const 1) ... (i32.const 0) ... (i32.const 1)
    claimless   (i32.const 0) ... (i32.const 1) ... (i32.const 0)

The output agrees because each module is consistent with itself. A failed claim must leave legacy's
bytes as legacy writes them alone. `scripts/ir-divergence-baseline.txt` lists this program so that
`--claimless` reads it as an expected divergence; the fix deletes that entry. The fallback is also
counted in `scripts/silent-sweep/distilled/claims-fallbacks.txt`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the literal moved to the right, `(s ?? "b") == "a"` | claimed, matched | **yes** |
| the `??` bound to a local first, `const t = s ?? "b"` | claimed, matched | **yes** |
| `s` a `string \| null`, not an atom | claimed, matched | **yes** |
| `==` made `!=` | still falls back | no |
| the literal a member of the `??`'s default (`"b" == (s ?? "b")`) | still falls back | no |
