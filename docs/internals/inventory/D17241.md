### D17241 — a literal-left atom compare against a `??` is unlowered by the IR, which stages the `??` above the literal

**runs today and must keep running · IR coverage: the armed shadow mismatches 1 function, `unlowered: operand above a valued if's value` · filed 2026-11-24 against master `80d557f6f` by lane IR-N6**

Repro:

    type K = "a" | "b"
    function p(s: K | null): boolean { return "a" == (s ?? "b") }
    print(p("a"))
    print(p(null))

Want:

    true
    false

#### Mechanism

Legacy's `atomEqPlanOf` takes the `static` arm, with the literal on the left (`aqStaticLeft`). It
writes the literal's atom id and then the `??` over the atom, whose join is a valued `if`. The IR's
`atomCompare` builds the static side and then `atomSide` of the `??`. The lowering then finds the
static operand on the stack above the `??`'s valued `if` and refuses: `unlowered: operand above a
valued if's value`. The program runs because legacy writes the function. The IR does not claim it.
