#### Mechanism

Not traced. The literal is never bound; the IR's ref-list read (`refReadWhy`,
`ir_lower_ref.vl`) finds no row for the receiver `[[dbl]]`. The outer length,
`print([[dbl]].length)`, refuses as `array ref`. Under the onesig rule the called spelling
`print([[[[dbl]]]][0][0][0][0](3))` refuses the same way.
