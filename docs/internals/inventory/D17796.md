### D17796 — an unbound list literal of lists of an un-annotated function refuses a read that does not call through it

**closed 2026-11-28 by COV-UNION · runs, its witness prints its expected value · was a loud emit reject, `cannot yet lower this statement (index ref slot)` · a list literal whose recorded type names a hole and whose stamp closes it at a list of ref lists mints and records its rows at that stamp where the intern pass visits it (`emitCollect`'s literal visit, emit_collect.vl): the row is minted where the stamp is decided, not looked up afterwards · pinned by `tests/cases/closures/hole-fn-list-of-lists-literal-unbound-read.vl`**

Repro:

    function dbl(a) { return a * 2 }
    print([[dbl]][0].length)
    // vl check: rc 0.  vl run: emit error, "index ref slot"

Want:

    1

#### Mechanism

The stamp pass closes the literal at `((i32) => i32)[][]`, but the intern pass decides whether a
literal is a ref list by its recorded type, `((_) => _)[][]`, whose hole has no build
(`listTyBuildsRef` reads `listBuildOfTyHeld`, which mints nothing). So no row was minted under the
stamp and `refListSlotOfExpr` found none. A literal in a function body answered by its frame's
closed type (`arrLitFrameRefTy`); a bound one by its binding's slot.
Keying the lookup by the outer literal's closed stamp (`litRepTyAt`, then `rlSlotOfTyOrTwin` of its
element) was tried first and changed nothing, as no row was minted under it: the row has to be
minted where the stamp is decided, which is the intern pass's visit.
