### D1895 — an `is` over a union whose arms are all DISTINCT heap types tests the arm twice, because the tag compare and the narrowed read's `ref.cast` are separate instructions

**runs today and must keep running · filed 2026-09-07 against master `52d0150f6` · the successor
ROADMAP row 16's close named: `ref.test` is not the win, `br_on_cast` is, and only here · clause
2 (a cost, not a refusal) · 0 corpus cells**

Repro:

    type A = { a: i32 }
    type B = { b: string }
    type U = A | B
    function f(v: U): i32 {
      if v is A { return v.a }
      return 0
    }
    print(f({ a: 7 }))
    // vl run: 7

#### Mechanism

`emitIs` over a boxed union compares the box's tag, and the narrowed read then casts the
payload — two independent checks of the same fact. `wasm-dis` on the witness:

    (if (i32.eq (struct.get $2 0 (local.get $0)) (i32.const 0))
      (then (return (struct.get $0 0 (ref.cast (ref $0) (struct.get $2 1 (local.get $0)))))))

WasmGC has one instruction for test-and-bind, `br_on_cast_fail`, which does both and leaves the
value typed on the taken edge. Assembled by hand at the same three types, the three forms are
**79 bytes (tag compare), 79 bytes (`ref.test`), 74 bytes (`br_on_cast_fail`)** — so the win the
row is about is the elision of the second check, not the shape of the first.

**It is available only where the arms are all distinct**, and that is why it is a separate row
rather than part of `emitIs`. Two structurally identical arms are ONE WasmGC type — measured:
`type A = { a: i32 }` and `type C = { a: i32 }` in one union emit a single
`(struct (field (mut i32)))`, so no cast-based test can tell them apart and the tag is the only
discriminator. A close therefore owes an arms-alias analysis before it owes a lowering, and a
wrong answer there is a miscompile rather than a slower program.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the box (`A \| null`, the nullable-ref niche) | already optimal: `ref.is_null` + `ref.as_non_null`, no tag and no cast | **yes** |
| the arms being distinct (`A \| C`, same fields) | one wasm struct type for both; the tag is the only discriminator | **yes** |
| the narrowed READ (`if v is A { return 1 }`) | the cast disappears and the tag compare is already minimal | **yes** |

#### Grading list

The three ablation rows, every `is` fixture under `tests/cases/unions`, and the `as` trio, which
share `emitIs`'s tag path. A close is graded on `wasm-dis` showing ONE type check where there
are two today, on byte identity naming each module that SHRINKS (and confirming its output), and
on `rep-fuzz-check.sh`, since the narrowed read's rep is what changes.
