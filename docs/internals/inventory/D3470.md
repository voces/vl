### D3470 — a write of `null` to a list cell a closure captured narrowed is refused as `cannot assign null to i32`, not as an ended narrowing

**loud check reject · clause 2 · open · the refusal is owed, its sentence is not; pre-existing, the same on master `c17016a1e` · filed 2026-10-02 against master `c17016a1e`**

Repro:

    function f() { const g: (i32 | null)[] = [7]
      if g[0] != null { const h = () => g[0] ?? -1
        g[0] = null
        print(h()) } }
    f()
    // vl check: rc 1, "cannot assign null to i32"

#### Mechanism

Not localised past the ablation. A closure that captures a narrowed list cell makes the checker keep
the cell's narrowed type, and the write that follows is graded against `i32` rather than against
the declared `i32 | null`. The bare-name spelling of the same shape refuses the right way, with the
sentence that names the closure and the narrowing a write may have ended. The write itself is
legal (without the closure it runs and prints `-1`); the refusal the narrowing-invalidation ruling
owes is at the call `h()`, naming `h` and `g[0]`. No Want is filed: the right answer is that
refusal, and it waits on the sentence, not on a value.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| a bare name, `let g: i32 \| null`, `g = null` | check reject, `'h', made on line 2, reads 'g' as i32, a narrowing a write since then may have ended` | **yes** (the cell) |
| no closure, `print(g[0] ?? -1)` after the write | prints `-1` | **yes** (the closure) |
| no guard, the closure over the cell and the write | prints `-1` | **yes** (the narrowing) |
| `h()` called before the write as well | the same refusal at the write | no |
| a `string \| null` cell | `cannot assign null to string` | no |
| `g[0] = 5` in place of `null` | emit reject, `print of a union value whose arms the tag dispatch cannot classify` | no (a different outcome) |
| no write at all, the closure only | the same emit reject | no (a different outcome) |

#### Grading list

The last two ablation rows are a different defect, filed as [D3472](D3472.md) (a closure that
reads a narrowed cell with `??` does not emit, at any write); it is why the program cannot run
once the sentence is fixed. Grade the close on both spellings of the sentence, bare name and cell.
