#### Mechanism

Not traced. The list spelling of the same two members beside `null` holds the joined set's
nullable ids since D17875 (`elabFnJoinTy` unions the sets under `| null`); the `if` join reaches
its type by another route, so the two members' sets are not unioned there, the set is left a
closure, and the closure has no one signature.
