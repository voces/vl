### D15577 — a list of one hole parameter, slot-written with a second, its literal's parameter bound to a different generic at each of two calls, is refused

**loud emit reject · clause 2 · `vl check` rc 0, then `emitProgram: a generic function taken as a value reaches no call that fixes its type` · found closing [D15574](D15574.md) · filed 2026-11-08 against master `0cfd71c8` plus D15573 and D15574's closes**

Repro:

    function id<T>(x: T): T { x }
    function id2<U>(x: U): U { x }
    function id3<V>(x: V): V { x }
    function use(ys) { print(ys.length) }
    function take(a, b) {
      const xs = [a]

      use(xs)
      print(xs[0]("abc").length + xs[0](2))

    take(id, id2)

#### Mechanism

Not traced. Since D15574 both calls join at the list's element set `{id, id2, id3}`, as the calls
through `xs[0]` are typed. It refuses only when the two calls hand the LITERAL's parameter `a`
different sets; handing the slot-written `b` different sets runs.
