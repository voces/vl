#### Mechanism

The list literal's template type carries the last instance's element set, not the union, so call 1
bound `take` at `{id, id2}` and call 2 at `{id2, id3}`. With the join read from every call's hands,
both bind at `{id, id2, id3}`, and that set is tagged. Two producers still built per-call instances:
the checker's hole-pin rows, which name `a` alone or `a` and `b` at their own sets, and mono's late
demand for each root call, whose `elabCallArgSetTy` answered the argument's own tagged singleton
`{id}` before any join. A row recorded under an instance keeps its binding: re-keying those breaks
the forwarded join (D15573).
