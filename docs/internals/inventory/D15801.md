**closed 2026-11-14, runs and prints `1.5` · was loud check reject, `cannot write 'half' to 'm[][].f'`, clause 2, the judgment [D15791](D15791.md) lifted for a list's own initialiser · closed by lifting `holeSlotJudge`'s one-result judgment for a place through a map entry whose functions all sit in literals written whole to an entry (`holeSlotMapLitWrites`, check_relate_core.vl), with the tag decision taking `m[k] = lit` as `set` does and building each entry literal at the map's value row (`ftMapEntryLitJoins`, check_fn_tag.vl) · graded by the `map_value` and `map_set` cells of `record-list-fn-field-two-results.matrix.vl` and `record-held-list-fn-field-for-loop.matrix.vl` · fixture `tests/cases/closures/record-map-fn-field-two-results.vl` · found closing D15791 · filed 2026-11-12 against master `0921d19fd`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const m = Map()
    m["k"] = [{ f: inc0 }, { f: half }]
    const v = m["k"]
    if v != null { print(v[1].f(3)) }

Want:

    1.5

#### Mechanism

`holeSlotJudge` lifts its one-result judgment for a place through an element when the list
holds only its initialiser's functions (D14435's `nW == 0`, or a widening lift). A map entry
written with the list counts the write, and the judge then asks every function stored there for
one result, and refuses. A field through an element of a written binding is lifted as its
initialiser's is, since the call dispatches on the set every write joins; a map value is not, and
with the judgment lifted its emitter has no shape for the set (`ref valtype with no interned
shape`).

#### The map-value family

Closed for entries written as literals. The lift needed four further changes:

* `fnTagPlaceRep` (check_elab_cap.vl) reads an index or `get` step on a map as its value,
  `| null`, and peels a narrowed `| null` before each step, so `const v = m["k"]` is stamped.
* `ftHoldKind` (check_fn_tag.vl) answers a `TyNullable` its inner kind when that is 4 or 6, so
  that binding is a planned holder.
* `ftSlotWrites` takes an entry store into a map of records as `set` does, and `ftMapSetValTy`
  takes a map of records (kind 8). Each entry literal, a record or a list of records, is re-typed
  to its place in the map's value row (`ftMapEntryLitJoins`).
* `collectAHeldRep` (emit_collect.vl) interns a held map's list-of-records value row, and
  `letHeldTyOf` (emit_classify.vl) gives a map read's binding its stamped `| null` rep.

The lift stays off, and the judge still refuses, where the emitter cannot follow:
