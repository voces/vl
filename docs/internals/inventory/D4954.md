#### Mechanism

The read of `u.items` under both narrowings (the record variant, then the list arm) went
through `emitNarrowedMem`, whose own unbox of a value-union field knew only scalar atoms and
refused a list arm. It now unboxes through `emitUnionFieldNarrowUnbox`, the home the bare-arm
read already used, whose container arm casts the box payload to the narrowed list.
