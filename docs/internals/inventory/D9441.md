### D9441 — an un-annotated empty list filled by `.push` with a generic function and called through its element at two types has no interned shape

**loud emit reject · `vl check` rc 0 · `ref valtype with no interned shape` · clause 2 · found closing [D9310](D9310.md) · present on master `af839a093` · filed 2026-10-21 against master `af839a093`**

Repro:

    function id<T>(x: T): T { x }
    const xs = []
    xs.push(id)
    print(xs[0](2))
    print(xs[0]("s"))
    // vl check rc 0.  vl run: emit error: emitProgram: ref valtype with no interned shape

Want:

    2
    s

#### Mechanism

Not traced. From the ablation only: the list's element is pinned by the push, and with two
call types the element has no one instance. A list literal holding `id` runs through the read
devirtualisation; a pushed value is not one of a literal's values, so it declines.
