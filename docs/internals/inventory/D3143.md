### D3143 — a union-element `.map` result assigned over a local in an instance builds its receiver at the destination's element

**check-clean invalid wasm · clause 1 · the `INVALID -> INVALID` cells of the #3280 round-2 review's `f` grid (`rv3280r2-21889/f`, the assignment and `if`-arm holders) · the same on master `fc4b2159f` · filed 2026-09-29 against master `fc4b2159f`**

Repro:

    function t<T>(x: T) {
      let n = [x].map((e): T | null => e)
      n = [x].map((e): T | null => e)
      print(n[0])
    }
    t(4)
    // vl check: rc 0.  vl run: invalid module inside `t`, expected (ref $type), found (ref $type)

Want:

    4

#### Mechanism

Not localised past the ablation. On the assignment's right, the receiver literal `[x]` is built
as a list of the destination's element, the `i32 | null` box, and is then stored into the plain
`i32` list local the `.map` lowering reads it from. The binding spelling runs. #3280 keeps a
callback that builds only at the pin (D3125's join, D3126's fold) refused at this position,
and at an `if` arm, a return and a tail value, with `a .map result whose callback builds only
at this pin is lowered only as a local's initializer or read in place`, so it fails loudly and
not through this row.
