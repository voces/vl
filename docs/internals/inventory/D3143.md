#### Mechanism

Not localised past the ablation. On the assignment's right, the receiver literal `[x]` is built
as a list of the destination's element, the `i32 | null` box, and is then stored into the plain
`i32` list local the `.map` lowering reads it from. The binding spelling runs. It is the first
delivery D3125's lift needs wired: with that lift parked, a callback that builds only at the pin
is refused before it reaches this position (`bare null needs a struct-typed context`).
