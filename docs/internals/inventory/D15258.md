#### Mechanism

`compiler/wasmEmit.vl`:

  when the pattern's own type is that base. Its only reachers, read from text, were names canon
  had softened (`v is One` with `type One = 1` spelled `i32`), whose pattern type is the literal.

The witness is D15251's, which runs without `litIsPinNever`.
