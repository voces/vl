### D3875 — un-annotated callbacks over `Box<A[]>` and over an inline `{ v: A }` in one program refuse to build, though each alone runs

**loud emit reject · found extending D3834's fixture under the structural ruling · filed 2026-10-08 against #3464's head `441218435` with #3455's rework**

Repro:

    type A = { x: i32 }
    function h<T>(x: T) { x.x }
    type Box<T> = { v: T }
    const ba: Box<A[]> = { v: [{ x: 1 }] }
    print([ba].map((e) => h(e.v[0]))[0])
    const o: { v: A } = { v: { x: 1 } }
    print([o].map((e) => h(e.v))[0])
    // vl check: rc 0.  vl build: emitProgram: field access receiver is not a struct

Want:

    1
    1

#### Mechanism

Not located. Each callback alone runs, and so does each with the other one annotated
(`(e: Box<A[]>) =>`, `(e: { v: A }) =>`). Together, an instance of `h` is lowered at a pin that
is not the record, the shape D3834 had for one callback alone.
