### D1520 — the un-annotated-parameter solve adopts a multi-arm UNION destination as the parameter's own type, so the body refuses its own operators

**closed 2026-09-03 (`noteHoleFlowGo` declines a multi-arm `TyUnion` destination) · reported by the `~/glean` WC3 replay player as **VL-004**, VL's first external consumer, at their pin `2fb8b271` · filed against master `bd500845` · ZERO corpus cells**

Repro (their program, verbatim — `vl check` rc 0 now; two errors before):

    type Err = { msg: string }
    function tryParse(x): i32 | Err {
      if x > 5 { return { msg: "too big" } }
      x * 2
    }
    // was: comparison expects numeric operands, got i32 | Err and i32
    //      operator '*' is not defined for i32 | Err and i32

#### Mechanism

`solveUnannotParams` probes the body with diagnostics suppressed and reads the flow
constraints its holes accumulated, taking the FIRST concrete destination per parameter
(`noteHoleFlowGo`, the hook inside `assignableExpr`). A binary operator over a hole hands
the hole straight back as its own result type, so the tail `x * 2` reaching the declared
return records `hole(x) → i32 | Err`. The solve adopts that whole union as `x`'s type, the
real pass then types `x` as `i32 | Err`, and both of the body's numeric uses refuse —
including `x > 5`, which is upstream of the return that caused the pin.

`assignable` admits a hole against `i32 | Err` because ANY arm would do, so the position
carries no unique answer to adopt. [D1431](D1431.md)'s ruling applies unchanged: an open
hole defers to the call that pins it. Declining the union leaves `x` a hole, `tryParse(1)`
pins it to `i32`, and `validateRetCstrs` re-asks the annotation at that pin.

A LITERAL union (`"a" | "b"`, `0 | 1`) is exempt: its members share one rep and one base,
so the destination does carry a single answer, and adopting it is what the annotated
spelling already means.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the un-annotated parameter (`x: i32`) | runs | **yes** |
| the union return annotation (`: i32`) | runs | **yes** |
| the parameter reaching a RETURN (`return 1`) | runs | **yes** |
| the bare tail (`return x * 2` spelled out) | still refuses | no |
| the struct arm (`i32 \| string`) | still refuses | no |
