### D15225 — a call through a field of a function's returned record, where its returns hold un-annotated functions of different results, traps

**closed · runs, prints `1.5`, since 2026-11-12 ([D15801](D15801.md)'s returned-record family: the field keeps its set and the call dispatches on the member) · was a loud check reject, `cannot store 'half' in 'pick().f': … must return one type`, the bound twin's sentence, ruled DESIGN and overruled by [D15791](D15791.md)'s ruling (DECISIONS.md, "A set of functions in one slot need not return one type") · before that, trap after load, `vl check` rc 0, `wasm trap: indirect call type mismatch`, clause 1 · DESIGN refusal, as the bound twin's · found planning [D15209](D15209.md) · filed 2026-11-04 against master `9d55d14e` · fixed with [D15221](D15221.md), by judging the call-rooted read; named set `d15221-call-root`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function pick(b: boolean) { if b { return { f: inc0 } } return { f: half } }
    print(pick(false).f(3))

Want:

    1.5

#### Mechanism

`holeSlotJudge` judges a call through a slot against every function stored there only when the slot's root is a name; `pick(false).f` is rooted at a call, so the functions `pick` returns in `f` are never judged at the call's arguments, and the call runs `half` through `inc0`'s signature.
