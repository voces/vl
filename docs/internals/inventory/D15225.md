### D15225 — a call through a field of a function's returned record, where its returns hold un-annotated functions of different results, traps

**trap after load · `wasm trap: indirect call type mismatch` · clause 1 · open · the bound twin (`const r = pick(false); r.f(3)`) is refused at check: `cannot store 'half' in 'r.f': called at (i32) it returns f64, where 'inc0', also stored in it, returns i32 — every function a call through 'r.f' may run must return one type` · the same judge gap as [D15221](D15221.md), at a record result, where no emit refusal stands in the way · found planning [D15209](D15209.md) · filed 2026-11-04 against master `9d55d14e`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function pick(b: boolean) { if b { return { f: inc0 } } return { f: half } }
    print(pick(false).f(3))

Want:

    a check reject naming `half`, as the bound twin's

#### Mechanism

`holeSlotJudge` judges a call through a slot against every function stored there only when the slot's root is a name; `pick(false).f` is rooted at a call, so the functions `pick` returns in `f` are never judged at the call's arguments, and the call runs `half` through `inc0`'s signature.

#### Ablation

| spelling | outcome |
| --- | --- |
| the witness | trap after load |
| `const r = pick(false); print(r.f(3))` | check reject, the sentence above |
| `dbl` (`a * 2`) for `half` | runs, `6` |
| `pick(true)` | runs, `4` |
| `return inc0` / `return half`, called as `pick(false)(3)` | runs, `1.5` |
