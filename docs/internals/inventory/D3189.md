### D3189 — a literal-union value delivered to a `string | null` slot without a narrowing, at a closure-value argument or an annotated binding, is invalid wasm

**closed 2026-11-01 as `runs` · was check-clean invalid wasm, clause 1 · a function-value call widened an atom argument only into a `string` parameter (`emitCallRefArg`), so a `string | null` one took the raw i32 atom; it now widens into both, as a direct call does · the grading list's annotated-binding and return spellings already run · fixture `tests/cases/literal-unions/atom-to-nullable-string-value-call.vl` · found by the #3287 review (`rv3287-q7k2`) and lane NI's D3174 ablation · filed 2026-09-29 against master `36d233f66`**

Repro:

    type K = "a" | "b"
    const f = (x: string | null) => x ?? "none"
    const k: K = "a"
    print(f(k))
    // vl check: rc 0.  Prints `a`.

Want:

    a

#### Mechanism

Not localised past the ablation. A `K` atom (an interned i32) reaches a slot whose rep is the
nullable string ref, and no widening runs at the closure-value call's argument. The same family
at other positions: `const r: K | null | string = a` over `a: K | null`, and over a bare
`K | L | null` (a nullable string where declared, a box where pinned) `return e` into a
`string` result and `let w: K | L | null = null`.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `function f(x: string \| null)` called by name | prints `a` | **yes** (the closure value) |
| `const k: string = "a"` | prints `a` | **yes** (the atom) |

#### Grading list

`const r: K | null | string = a` with `a: K | null = "a"`, and
`function t(e: K | L | null): string { if e == null { return "N" } return e }`.
