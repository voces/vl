### D10024 — a list literal holding a generic, spread into a copy that is then pushed a non-generic, is typed at the source's last read by the checker

**loud check reject · `push: cannot add (i32) => i32 to ((string) => string)[] (the callee's body at the call's argument types)` · clause 2 · CAPABILITY: the copy written `ys[0] = inc` instead prints `3`, `2`, `s` since [D9595](D9595.md) · found closing [D9595](D9595.md) · present on master `00cbfe00b` · filed 2026-10-22 against master `00cbfe00b`**

Repro:

    function id<T>(x: T): T { x }
    function inc(x: i32): i32 { x + 1 }
    const xs = [id]
    const ys = [...xs]
    ys.push(inc)
    print(ys[0](2))
    print(xs[0](2))
    print(xs[0]("s"))
    // vl run: type error: push: cannot add (i32) => i32 to ((string) => string)[] (the callee's body at the call's argument types)

Want:

    2
    2
    s

#### Mechanism

Not traced. The spread copies `xs`'s element type, which the checker takes from its last read
`xs[0]("s")`, so the push of `inc` into `ys` does not fit; an index write is let through and
the emitter keeps the lists apart since [D9595](D9595.md).

| --- | --- | --- |
| `.push` (an index write instead) | runs, `3`, `2`, `s` | **yes** |
