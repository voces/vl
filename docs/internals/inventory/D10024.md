Repro:

    function id<T>(x: T): T { x }
    function inc(x: i32): i32 { x + 1 }
    const xs = [id]
    const ys = [...xs]
    ys.push(inc)
    print(ys[0](2))
    print(xs[0](2))
    print(xs[0]("s"))
    // vl run: type error: push: cannot add (i32) => i32 to ((string) => string)[] (the callee's body at the call's argument types)

Want:

    2
    2
    s

#### Mechanism

[D10020](D10020.md)'s: the module-scope `ys.push(inc)` into a list whose element is `id`'s own
`(T) => T` is a deferred row with no owner, and `xs[0]("s")` binds `T` by name and
re-validates it. The spread is scenery: `const ys = [id]` refuses the same way. The index
write ran only because its row was not live at module scope.
