### D1894 — a hole parameter that reads a field solves to a STRUCTURAL shape, so a `new`-branded argument no longer satisfies its own parameter

**loud check reject · no operator and no import in the witness · filed 2026-09-07 against master `f3cac5fe5`**

Repro:

    type Pln = new { x: i32 }
    function mkval(): Pln {
      const r: Pln = { x: 3 }
      return r
    }
    function take(p) { print(p.x) }
    take(mkval())
    // vl check: 7:6: argument 1: expected {x: _}, got Pln
    // Drop `new` from line 1 and the same program prints 3.

#### Mechanism

The un-annotated-parameter solve reads the body's uses to build the parameter's type. A
field read contributes the structural shape `{x: _}`, and that shape is then what the
argument is checked against — so a NOMINAL type, whose whole point is not to be
interchangeable with its structure, fails against a constraint derived from its own field.
The call site knows the argument is `Pln` and the body would be well-typed at `Pln`; the
solve simply never proposes it.

This is the same sentence [D1893](D1893.md) prints, reached without an operator and without
an import, which is what makes it a row of its own rather than that one's message. The
neighbouring closed row [D1520](D1520.md) is the same solve declining a multi-arm union
destination; a nominal destination is the case it does not cover.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `new` brand (`type Pln = { x: i32 }`) | runs, prints `3` | **yes** |
| the parameter is un-annotated (`take(p: Pln)`) | runs, prints `3` | **yes** |
| the field read (pass the hole to an annotated function instead) | runs, prints `3` | **yes** |
| a `std:` import in the module | still refuses, same sentence | no |
| the argument is an object literal (`take({ x: 3 })`) | runs, prints `3` | no |

#### Grading list

The structural twin and `take(p: Pln)` run today and must keep running. The close has to
decide whether the solve proposes the ARGUMENT's type before synthesising a shape, or whether
a synthesised shape accepts a nominal whose structure matches — those differ for two brands
over one structure, so grade `take` called with a `Pln` and with a second `new { x: i32 }`
brand in the same program. [D1893](D1893.md) prints this sentence too and is not fixed by
this row's close on its own.
