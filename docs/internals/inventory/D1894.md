### D1894 — a hole parameter that reads a field solves to a STRUCTURAL shape, so a `new`-branded argument no longer satisfies its own parameter

**closed 2026-09-08 — the witness prints `3` · was a loud check reject, no operator and no import in the witness · clause 2 · filed 2026-09-07 against master `f3cac5fe5` · 24 of 24 branded cells (4 field shapes x 6 positions) move `check` to `runs`, the structural twins the control · fixture `tests/cases/objects/hole-field-read-satisfied-by-brand.vl`**

Repro:

    type Pln = new { x: i32 }
    function mkval(): Pln {
      const r: Pln = { x: 3 }
      return r
    }
    function take(p) { print(p.x) }
    take(mkval())
    // vl check: 7:6: argument 1: expected {x: _}, got Pln
    // Drop `new` from line 1 and the same program prints 3.

#### Mechanism

The un-annotated-parameter solve reads the body's uses to build the parameter's demand. A
field read contributes the structural shape `{x: _}` (`holeMemberTy`), and `holeDemandOk`
then checked the branded argument against that shape with the ordinary nominal rule — so
`Pln`, whose whole point is not to be interchangeable with its structure, failed a constraint
derived from its OWN field. The call site knows the argument is `Pln` and the body is
well-typed at `Pln`; the solve simply refused the type that induced the demand.

The demand is purely structural — member reads are the only thing that builds a shape — and a
brand is erased at run time ("the arena stays structural and nominal-ness is a column beside
it"), so the underlying structure is exactly what the body reads. Closed by retrying the shape
check against `nomErasedTyIx(at)` when the direct check fails: the nominal barrier no longer
refuses a field demand a nominal argument structurally satisfies. It bites only where the
body has a REAL nominal use — passing the hole to a function typed `B` still refuses `got A`,
the soundness control the fix leaves standing.

This is the same sentence [D1893](D1893.md) prints, reached without an operator and without
an import, which is what made it a row of its own. [D1520](D1520.md) is the same solve
declining a multi-arm union destination; a nominal destination was the case it did not cover.
