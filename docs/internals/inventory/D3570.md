### D3570 — `e is L` over a numeric literal union, where `e` is not a re-readable place, folds to `false` and drops `e`

**closed 2026-10-03 for an `i32` literal union — the witness prints `true`, `false`, `true` and `1` · was check-clean silently wrong, clause 1 · found by lane KJ's grid (the annotated `coalis` cells at the `lit-i32` pin, once [D3528](D3528.md) read them at the pin) · filed and closed against master `3b9319528` · fixture `tests/cases/literal-unions/numeric-is-once-read-receiver.vl`**

Repro:

    type L = 1 | 2
    function f(x: i32): i32 { x }
    let n = 0
    function bump(): i32 {
      n = n + 1
      n
    }
    print(f(1) is L)
    print(f(4) is L)
    print(bump() is L)
    print(n)
    // master printed false, false, false, 0

Want:

    true
    false
    true
    1

#### Mechanism

The membership test over a numeric literal union reads its receiver once per member, so it
claims only a re-readable place (`unionEqOperandOk`). A call, an operator or a `??` fell through
to `monoStaticIsResult`, whose fold compares the receiver's rep name (`i32`) to the union's
(`L`) and answers `false` without evaluating the receiver. An `i32` receiver is now read once
into a fresh slot and compared with every member. A single-member union never reached the fold.
An `i64` literal union over a call still folds to `false` (`5000000000 | 6000000000`); no
fresh `i64` slot exists for it yet, and it is not filed.

#### Ablation

| ingredient changed | outcome on master | needed? |
| --- | --- | --- |
| `const y = f(1); print(y is L)` | runs, `true` | **yes**: a receiver that is not a place |
| `type L = 1` | runs, `true` `false` | **yes**: two or more members |
| `(f(1) + f(1)) is L`, `(x ?? 2) is L` | `false` | no |
| a generic lambda's call, `g() is L` at `(1, 1)` | `false` | no: [D3547](D3547.md) |
