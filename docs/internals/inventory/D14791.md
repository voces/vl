### D14791 — in a generic body, a lambda whose tail is an `else`-less `if` writing a `T`-function cell records a function result the emitter lowers void, so binding it is invalid wasm

**check-clean invalid wasm · clause 1 · open · pre-existing on master `a6a5e3631` · found by the emitted-function result shadow (`fn_ret_shadow.vl`) once an instance's open template result closes under its binding · filed 2026-11-01 against master `a6a5e3631`**

Repro:

    function inner<U>(u: U) { print(u) }
    function other<V>(v: V) { print("O") }
    function c<T>(x: T) {
      let k: (t: T) => void = inner

        if x == x { k = other }
      }

#### Mechanism

An `else`-less `if` is a value: the arm's value, or `null` when the arm does not run. So `toO`'s
recorded result, the written function or `null`, is right, and the non-generic spelling lowers it
that way (its bound result calls, `r(7)`, or is `null`). In the generic instance the emitter lowers
the tail `if` as a statement, so `toO` returns nothing while the binding `r` expects the reference
the checker promised. The emitter is the side to fix; the shadow's `recorded value, emitter void`
class names this lambda.
