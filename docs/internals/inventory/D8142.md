#### Mechanism

`idn(mk())` is refused as an existing record (D8020), but the outer identity's pass-through
looked through to the inner call and read it as fresh, so the delivery was accepted with the
instance still taken at `Col`. The pass-through branch of `recAdoptNote` now refuses the same
way when the inner call is a generic call over a function that builds a literal.

D8303 then built the call at the destination when each identity is pinned by that argument
alone, ahead of that refusal, so the witness runs.
