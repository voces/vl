### D4164 — a type-parameter value written into a nullable number-literal union place reads the template's narrowing at a nullable pin

**closed 2026-10-21 · runs, prints the Want · was check-clean silently wrong · clause 1 · fixed at a local with [D3446](D3446.md)'s write (`tvPlaceWrite`); its field, list element and module global closed with [D8820](D8820.md) · pin: `tests/cases/generics/type-param-write-union-local-reads-at-pin.vl` · matrix `type-param-write-number-litunion-local` · pre-existing, the same on master `5e770df5b` · found by the D3423 position matrix (`nu_*`, `rv_NU_*` at the `nul` and `MULTI` pins) · filed 2026-10-11 against master `5e770df5b`**

Repro:

    type N = 1 | 2
    function g<T>(x: T) {
      let s: N | null = null
      s = x
      print(s == null)
    }
    const v: N | null = null
    const u: N = 1
    g(v)
    g(u)

Want:

    true
    false

#### Mechanism

`tvPlaceWrite` takes D3240's `HD_TVW` read (the pin decides whether the place is null) only for a
place of one member or of a string-literal union. A number-literal union keeps the template's
non-null narrowing of `s` after `s = x`, so the shared body folds `s == null` to `false` and `s ??
d` to `s` at every pin. Admitting it there sent the `??` arms the value box while the read landed
at `N`, which was invalid wasm at a join; the D3423 fix leaves number unions declined.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `type N = "a" \| "b"` | runs | **yes** (a number-literal union) |
| `let s: i32 \| null` | runs | **yes** (a literal union) |
| `function g(x: N \| null)` (no type parameter) | runs | **yes** (a type-parameter write) |

#### Grading list

Every place (name, field, list element, global) at the `decl` face: `print`, `bind` and `==
null` read wrong, and `??` delivered to an `i32` binding, return, parameter or join is invalid
wasm. [D4165](D4165.md) is the list-element case that is invalid wasm at a non-null pin too.
`match` over `N` refuses at check at every spelling, which is not this mechanism.
