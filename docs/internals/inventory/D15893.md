### D15893 — an element of a generic list identity's result, delivered at a record storing a field wider, builds invalid wasm

**closed · now runs, prints `12` · was check-clean invalid wasm, clause 1, `type mismatch` at the delivery · [D14890](D14890.md)'s grading-list item 2, which needs no call and no second instance · filed 2026-11-12 against master `b2a576aad` · closed 2026-11-12 against master `7f90ec87` by [D15930](D15930.md)'s close: the list literal an element read of the generic's result wants is stamped at the destination's list, and the instance is taken there · fixture `soundness/fresh-list-element-built-at-wider-record-runs.vl`; the ablation's `{ r: 4 }` and the grading list (an annotated parameter, an index write into a `Circle[]`, `return xs`) run too**

Repro:

    type Circle = { r: i32 | null }
    function keep<T>(xs: T[]): T[] { xs }
    const k = keep([{ r: null }])
    const c: Circle = k[0]
    print(c.r ?? 12)

Want:

    12

#### Mechanism

The literal `{ r: null }` is built at its own row and `keep` is instanced at that list, so
`k[0]` holds the own row. Its delivery at `Circle` is accepted by the checker as a record read
built at the destination, but nothing converts it, and the element lands where `Circle` is
wanted. Without the generic (`const k = [{ r: null }]`) the same delivery runs: the literal is
built at `Circle`.

#### Ablation

| spelling | outcome |
| --- | --- |
| this repro | invalid wasm |

| `{ r: 4 }` in place of `{ r: null }` | invalid wasm |
| the literal from a call `mkcall()` called once | invalid wasm |

#### Grading list

The element bound at an annotated parameter, an index write of the element into a `Circle[]`,
the generic spelled `keep<T>(xs: T[]): T[] { return xs }`.
