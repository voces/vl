### D14440 — an un-annotated record literal whose shape is a union arm's has two rows, one for its binding and one for a generic instance's parameter

**closed · runs, prints `7` · was check-clean invalid wasm inside `exactTwin` on the step 7 slice 3 branch · test `tests/cases/generics/pin-inline-shape-no-struct-row.vl` · filed 2026-10-26 against master `641c18ca1`**

Repro:

    type Circle = { r: i32 }
    type Wide = { r: i64 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    type WideU = Wide | Sq
    function idg<T>(x: T): T { return x }
    function exactTwin() {
      const c = { r: 7 }
      print(idg(c).r)
    }
    exactTwin()

Want:

    7

#### Mechanism

Master builds `c` (type `{r: i32}`) at `Wide`'s `{mut i64}` row, the first row a widened field-set
scan fits it into. Step 7 slice 3 gives the local `repOfTy({r: i32})`, `Circle`'s variant row
`{mut i32}`. The instance was still pinned through `monoArgTyNameBound`, which recursed into the
binding's initializer, and the record literal's scan named `Wide`'s row, so the call passed a
`(ref $Circle)` where `(ref $Wide)` was expected. The pin now reads the type the binding's cell
holds (`letBindTy`) whenever the binding's rep is a record, so the instance and the local name
one row.

`nearTwin` and `nominalControl` in the same fixture; any instance of a generic whose type
argument is an anonymous record with a union-arm twin.
