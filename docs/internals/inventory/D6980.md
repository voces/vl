**closed 2026-10-19 by lane L1 · runs, prints `a!` · was check-clean invalid wasm · clause 1 · the statement emitter emits nothing for a discarded bare name of a fully annotated function, or of a hole function the prune noted inert · pins: `tests/cases/closures/uncalled-hole-fn-discarded-statement.vl` · found closing [D6960](D6960.md) · present on master `641dc8172` · filed and closed 2026-10-19 against master `641dc8172`**

Repro:

    function exclaim(s: string) { return s + "!" }
    exclaim
    print(exclaim("a"))
    // vl check: rc 0.  vl run: failed to parse WebAssembly module: expected struct type at index 3, found (func (param (ref (id 2))) (result (ref (id 2))))

Want:

    a!

#### Mechanism

A discarded expression statement went through `emitExpr` and `drop`, and a function's name
there builds a closure with `struct.new` of the closure type. That type is minted only when some
use reads the function as a value (`fnValUsed`, `mAssignClosureTypes`); a discarded statement is
not one, so the index named the function's own `func` type. The statement has no effect, so it
now emits nothing.
