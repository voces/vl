Repro:

    function id<T>(x: T): T { x }
    const xs = []
    xs.push(id)
    const ys = [...xs]
    print(ys[0](2))
    print(ys[0]("s"))
    // vl check rc 0.  vl run: emit error: emitProgram: a generic function taken as a value reaches no call that fixes its type

Want:

    2
    s

#### Mechanism

A spread declined a source list that has pushes (`monoFlowSpreadUse`, emit_mono.vl), so the
pushed `id` reached `ys` as an open value; the literal twin `const xs = [id]` runs because its
elements are expanded into `ys`. A pushed list cannot be expanded, so the host's element reads
now resolve through the source's leaves (`monoFlowElemLeaves`, `monoFlowGrownSpreadSrc`), the
two lists' roots are tied so either one's decline declines both, and the host is typed as an
inert list (`monoSpreadHostInert`).
