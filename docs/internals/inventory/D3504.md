### D3504 — a declared return nesting a nullable parameter, `(A | null) | B`, has no rep at its pins

**check-clean invalid wasm · clause 1 · open · and a loud emit reject at `print` · the same on master `04ec2ef6f` and with #3337 · found by #3337's review (its `g3` grid: 361 of the `nestA` and `nestB` cells) · filed 2026-10-03 against master `04ec2ef6f`**

Repro:

    function F<A, B>(k: i32, a: A, b: B): (A | null) | B {
      if k == 0 { return a }
      if k == 1 { return b }
      return null
    }
    const u = F(0, true, 4)
    if u is i32 { print(u) } else { print(0) }
    // vl check: rc 0.  vl run: invalid module, "expected i32, found (ref $type)"

Want:

    0

#### Mechanism

Not localised past the ablation. The annotation is a union whose first member is a nullable,
not the nullable wrapper `A | B | null` is, so neither the substitution's union arm nor D3499's
fold in its nullable arm flattens it, and the instance's `boolean | null | i32` disagrees with
what the caller narrows. `print` of the same call is a loud emit reject.

A second defect is filed here for want of an id, and it is not this mechanism: a closure body
that joins two parameter holes and a `null` drops the null, because a hole is not kept apart
inside a lambda (`tyParamOfInnermostBody` answers false under `lamCheckDepth`, D3357), so at a
record pin the closure returns `null` where `(ref $Rec)` is owed (invalid wasm inside
`__lambda_1`). Witness:

    type Rec = { x: i32 }
    const r7: Rec = { x: 7 }
    function F(k: i32, a, b) {
      const g = () => { if k == 0 { a } else if k == 1 { b } else { null } }
      g()
    }
    print(F(2, r7, r7) == null)

It runs with declared parameters `F<A, B>` or with one hole; at `(1, 2)` it is a loud emit reject.
