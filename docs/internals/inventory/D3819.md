### D3819 — a plain call whose argument type does not fit the local function names none of the imported candidates the name also binds

**loud check reject · filed 2026-10-07 against lane OV's branch (#3423 review)**

Repro:

    // file: s.vl
    export function d(self: string): string { "S" }
    // file: main.vl
    import { d } from "./s"
    function d(self: i32): string { "L" }
    print(d("x"))
    // vl check: `argument 1: expected i32, got string` — and nothing names `d` from "./s"

#### Mechanism

A plain call reaches the local declaration (rule (e)), and a mismatch against it should name
the imported candidate and its method spelling (`"x".d()`). The arity mismatch does
(`ovPlainHint`, appended where the checker reports the argument count); the argument-type
mismatches are reported by shared helpers (`argMismatchErr` and its siblings) that are not
handed the call node, so they cannot ask `ovPlainSetOf`. The refusal itself is right; only the
hint is missing.

#### Grading list

`tests/cases/modules/err-overload-plain-call-local-mismatch/` (the arity spelling) must keep
its hint.
