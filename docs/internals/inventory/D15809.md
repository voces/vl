### D15809 — three calls handing records of un-annotated functions to two un-annotated parameters, each of which runs alone, trap together

**loud emit reject · clause 2 · open · `emitProgram: this record `if` stores functions of different signatures in one field, and a call through the joined record is lowered at one of them` · contains the clause-1 indirect-call type mismatch the program hit before #7517 · found writing [D15807](D15807.md)'s fixture · filed 2026-11-12 against master `0671904bf`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function dbl(a) { return a * 2 }
    function two() { [1, 2].length }
    function take(r) { return r.f(3) }
    function take2(n, r) { return r.f(n) }
    const q = if two() > 5 { { f: half } } else { { f: inc0 } }
    print(take(q))
    print(take2(3, if two() > 5 { { f: dbl } } else { { f: inc0 } }))
    print(take2(2.5, if two() > 5 { { f: half } } else { { f: half } }))

Want:

    4
    4
    1.25

#### Mechanism

Traced on scratch builds (disassembly and trap probes, `build/` untouched). The checker types
every record here `{f: (_) => _}`, so the signatures are decided after it. `half` is pinned at
`(f64) => f64` by the call that passes `2.5`, and `inc0` at `(i32) => i32` by the call that passes
`3`. `q`'s join holds both, and `take`'s instance calls `r.f` through `return_call_indirect` at
`half`'s signature, so `q` holding `inc0`'s closure traps. With no pin on `inc0`, the value floor
refuses it loudly; the pin silences that floor.

The run fix is a tagged set, since the set splits on results at `take`'s call, but the tag plan
refuses it. A record literal handed to `take2` is built at a closed closure record, and
`ftNamedAtClosed` asks `ftLitBuiltAt`, not the literal's rep. Accepting the rep there lets the
plan commit, with no regression on the ablation set. The call `r.f(n)` in `take2` is then lowered
as an id dispatch while `take2`'s own literals hold closures (`callee is not a function name`).
Closing it needs that call lowered per instance: id dispatch where the parameter holds ids, a
closure call where it was adopted at a closure record.

The floor (#7517, `joinCloSigSplitField`, wasmEmit.vl) refuses a record `if` whose object-literal
arms store functions of different `$fnsig`s in one field, unless the field is a tagged set's. It
does not cover a `match` or block join. A returned record no longer reaches here: since #7515 its
field-call adoption declines, and the field dispatches.

#### Ablation

| spelling | outcome |
| --- | --- |
| the witness | loud emit reject (was runtime trap) |
| literal records to `take2`, `take2(3, { f: inc0 })` and `take2(2.5, { f: half })` | loud emit reject (was runtime trap) |
| every call at one type, `take2(3, { f: inc0 })` and `take2(3, { f: half })` | loud emit reject (was runtime trap) |
| the `2.5` call through a second callee `take3` | loud emit reject (was runtime trap) |
| `take(q)` beside either `take2` call alone | loud emit reject |
| the two `take2` calls, without `take(q)` | runs, `4 1.25` |
| `q` sharing no function with the other records (`inc2`, `half2`) | runs, `4 4 1.25` |
| `q = { f: inc0 }`, no join | runs, `4 4 1.25` |
| `take(q)` alone | runs, `4` (a tagged set) |
| any one print alone | runs |

The price: `q` with its `half` arm taken (`two() > 1`) beside the same calls printed `1.5 4 1.25`
on master. It ran only because the first arm was taken, and its other arm is the witness. It is
now a loud emit reject.
