### D15809 — three calls handing records of un-annotated functions to two un-annotated parameters, each of which runs alone, trap together

**loud emit reject · clause 2 · open · `emitProgram: this record `if` stores functions of different signatures in one field, and a call through the joined record is lowered at one of them` · contains the clause-1 indirect-call type mismatch the program hit before #7517 · found writing [D15807](D15807.md)'s fixture · filed 2026-11-12 against master `0671904bf`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function dbl(a) { return a * 2 }
    function two() { [1, 2].length }
    function take(r) { return r.f(3) }
    function take2(n, r) { return r.f(n) }
    const q = if two() > 5 { { f: half } } else { { f: inc0 } }
    print(take(q))
    print(take2(3, if two() > 5 { { f: dbl } } else { { f: inc0 } }))
    print(take2(2.5, if two() > 5 { { f: half } } else { { f: half } }))

Want:

    4
    4
    1.25

#### Mechanism

Not traced. The repro is delta-debugged: removing any one line stops the trap, and each print
runs alone, printing what Want says; `take(q)` beside either `take2` call is a loud emit reject.
The trap is in `take`. The suspicion is that the sets of the three records merge through the
functions they share, `inc0` and `half`, so `take`'s instance is built at a signature one of them
does not have.
