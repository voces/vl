### D4884 — an `if` of two list literals bound to a local in a generic body builds a union box where an `f64` list is expected

**check-clean invalid wasm · clause 1 · found by L2 §13.30, beside D4883 · filed 2026-10-15 against master `5be21bb0a`**

Repro:

    function h<T>(t: T, b: boolean) {
      const v = if b { [t, t] } else { [1, 2, 3] }
      print(v.length)
    }
    h(2.5, false)
    h(2.5, true)
    // vl check: rc 0.  vl run: invalid module inside `h` (a union box where a list is expected)

#### Mechanism

Not yet ablated past the table below. Both arms are fresh list literals, so the join at
`T := f64` is `f64[]` and each literal should be built at it, as the direct spelling does. The
local's `if` join is re-typed at the pin outside the return-set path D4862 fixed. Possibly one
family with D4883; that is a prediction until one fix moves both.
