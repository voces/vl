### D3932 — a module generic stored into a nullable function slot inside a generic traps

**loads then traps · found in review of #3489 (`rv3489/p20b`, `p20d`; `p20e` concrete is the control) · filed 2026-10-09 against master `255fc7a6c`**

Repro:

    function b<U>(y: U) {
      print("generic")
      print(y)
    }
    function c<T>(x: T) {
      let h: ((t: T) => void) | null = null
      h = b
      if h != null { h(x) }
    }
    c(2.5)
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch

Want:

    generic
    2.5

#### Mechanism

Not located. A sibling of D3112 and of D3916's store slots: the slot's type
`((t: T) => void) | null` names `T` behind a nullable, and the assignment of the generic `b` is
not instanced at the slot's function type at the instance. With `c(x: f64)` it runs.
