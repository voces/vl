### D3932 — a module generic stored into a nullable function slot inside a generic traps

**closed 2026-10-10 by lane SC · runs · was loads then traps · found in review of #3489 (`rv3489/p20b`, `p20d`; `p20e` concrete is the control) · filed 2026-10-09 against master `255fc7a6c` · pins: `tests/cases/generics/generic-function-into-nullable-function-slot.vl`**

Repro:

    function b<U>(y: U) {
      print("generic")
      print(y)
    }
    function c<T>(x: T) {
      let h: ((t: T) => void) | null = null
      h = b
      if h != null { h(x) }
    }
    c(2.5)
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch

Want:

    generic
    2.5

#### Mechanism

A generic function value is instanced at the function type it is delivered at by reading that
type's parameters, and a nullable slot's spelling `((t: T) => void) | null` decomposed to none, so
`b` was never instanced at the slot and the call through it reached the template. Closed: the
value coercion reads the slot's function type past `| null` and its grouping parentheses. The same
holds for a nullable record field, list element and return. An argument to a generic callee's
nullable function parameter is still refused (D3933).
