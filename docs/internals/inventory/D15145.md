### D15145 — a returned bundle parameter held in a generic caller's instance has no member fact there

**loud emit reject · clause 2 · `a function returning a parameter called at two signatures is called where its result is not used at one of them` · filed 2026-11-03 against master `e2207958`**

Repro:

    function lap(f) {
      print(f(2.5))
      print(f(3))
      return f
    }
    function mid<T>(x: T, k: i32) {
      const r = lap((a) => a + k)
      print(r(4))
      print(x)
    }
    mid("s", 2)
    // vl check: rc 0.  vl run: emitProgram: a function returning a parameter called at two signatures is called where its result is not used at one of them

#### Mechanism

The elaboration notes the member a call's value is used as for calls outside every instance
(`elabResultMembersNote` reads `elabCallInstFrom(c, -1)`). Inside `mid`'s instance the call is a
clone, which has no fact, so the pick refuses. The fix keys the fact per instance.
