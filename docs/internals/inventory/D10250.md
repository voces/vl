### D10250 — an inline list literal of a generic handed to a generic function at two types is refused by emit as an internal error

**closed · runs, `s` then `5` · was loud emit reject, `vl check` rc 0, `emitProgram: internal: a parameter type the valtype ladder has no rung for — every parameter type the checker accepts has one above`, clause 2 · CAPABILITY: the calls spelled `run<string>([id], "s")` and `run<i32>([id], 5)` print `s`, `5`, and so does a `const` list per call · found closing [D10204](D10204.md) · present on master `d5576d929` · filed 2026-10-22 against master `d5576d929` · closed against master `d5ec7f160` by leaving a list literal of generics out of emit's pre-binding of a generic call's non-arrow arguments, as the checker binds it after them (`monoPreBindNonArrowArgs`, emit_mono.vl), and by counting a literal element the checker typed as a still-open function as a generic (`monoLitHoldsGenericFn`), so the literal no longer binds `U` from its own pin, which names whichever instance `id` has elsewhere · fixture `closures/generic-list-literal-of-generic-to-generic-at-two-types.vl` · new matrices fn-value-generic-list-literal-arg-two-types 0 → 44 of 46 runs and its -open twin 0 → 13 (the annotated face is `(x: i32) => i32` and refuses `"ab"` by design; the un-annotated residue is [D10310](D10310.md), [D10311](D10311.md) and [D10312](D10312.md)) · with [D10251](D10251.md)**

Repro:

    function id<T>(x: T): T { x }
    function run<U>(a: ((x: U) => U)[], u: U): U { a[0](u) }
    print(run([id], "s"))
    print(run([id], 5))
    // vl check rc 0.  vl build: internal: a parameter type the valtype ladder has no rung for

Want:

    s
    5

#### Mechanism

Emit pre-binds a generic call's type variables from every non-arrow argument
(`monoPreBindNonArrowArgs`) by reading the argument's pin. A list literal of a generic pins
as `(() => void)[]` once the generic has instances at two types, so `U` bound to `void`
before the value argument was read, and the instance of `run` carried no valtype for it.

#### Ablation
