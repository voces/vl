### D9551 — a nested list of un-annotated functions returned from a function with an un-annotated parameter has no interned shape

**closed 2026-10-22 by lane-D9550 · runs, prints `6` · was loud emit reject, `ref valtype with no interned shape`, no position, `vl check` rc 0 · clause 2 · closed by recording the inner literal's closed type at an instance's own copy of its template's body, which the shared-node guard of `monoRecordOpen` had left open (`monoRecordInstOpen`, emit_mono.vl); a node the template's body still holds stays open · fixture `closures/hole-fn-list-returned-inline-call.vl` · residue [D9600](D9600.md) · found closing [D9503](D9503.md) · filed 2026-10-22 against master `6b307f6ac`**

Repro:

    function inc(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function deliver(n) { return [[inc, dbl]] }
    const v = deliver(1)
    print(v[0][1](3))
    // vl check rc 0.  vl run: emit error: emitProgram: ref valtype with no interned shape

Want:

    6

#### Mechanism

The nested literal is instanced at the pin its inner element slot `e.e` takes
(`monoRetFnListTy`, emit_mono.vl), and that pin is found. The inner literal's closed type was
then recorded through `monoRecordOpen`, which declines in an instance's frame because the
instance may share its body nodes with the template. With an un-annotated parameter, `deliver`
is instanced and its instance holds its own copy of the literal, which stayed
`((_) => _)[][]` with no shape.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the parameter (`deliver()`) | runs, `6` | **yes** |
| the nesting (`return [inc, dbl]`, `v[1](3)`) | runs, `6` | **yes** |
| the index call, read by `.map` (`v[0].map((f) => f(3))[1]`) | same refusal | no |

Graded at close: the witness prints `6`, and the `.map` spelling `deliver(1)[0].map((f) =>
f(3))[1]` prints `6`. A second call at a `string` argument read at `f64` (`w[0][0](1.5)`)
prints `2.5`. The inner list bound to a local first (`const w = [inc, dbl]; return [w]`) still
refuses, as [D9600](D9600.md).
