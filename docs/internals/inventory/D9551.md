### D9551 — a nested list of un-annotated functions returned from a function with an un-annotated parameter has no interned shape

**loud emit reject · `vl check` rc 0 · `ref valtype with no interned shape`, no position · clause 2 · found closing [D9503](D9503.md) · present on master `6b307f6ac` · filed 2026-10-22 against master `6b307f6ac`**

Repro:

    function inc(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function deliver(n) { return [[inc, dbl]] }
    const v = deliver(1)
    print(v[0][1](3))
    // vl check rc 0.  vl run: emit error: emitProgram: ref valtype with no interned shape

Want:

    6

#### Mechanism

Partly traced. The nested literal is instanced at the pin its inner element slot `e.e` takes
(`monoRetFnListTy`, emit_mono.vl). A probe on that read counted one pin at `e.e` in `deliver`'s
frame for `deliver()` and zero for `deliver(n)`, so, as in [D9550](D9550.md), the flow table does
not bank the caller's pin where a template's frame reads it. The flat spelling `[inc, dbl]` with
the same parameter does find its pin at `e`.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the parameter (`deliver()`) | runs, `6` | **yes** |
| the nesting (`return [inc, dbl]`, `v[1](3)`) | runs, `6` | **yes** |
| the index call, read by `.map` (`v[0].map((f) => f(3))[1]`) | same refusal | no |
