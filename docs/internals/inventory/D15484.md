### D15484 — a hole function and a closed-typed function handed to one parameter through a list or joined callee leave the tag decision unsettled

**loud check reject · clause 2: the refusal is the elaboration's, which runs as the last step of check, and names no type error · found writing the shared-slot witness for the only-call forward climb (§3.3) · filed 2026-11-06 against master `44a8b6c4`**

Repro:

    function id(x) { return x }
    function onceF(h) { print(h(2.5)) }
    const gs = [onceF]
    gs[0](id)
    gs[0]((x: f64) => x * 2.0)
    // vl check and vl run: emitProgram: internal: the tag decision after the elaboration did not settle

Want:

    2.5
    5

#### Mechanism

`elabPrepare` (emit_sections.vl) alternates the elaboration with `fnTagRedecide` until no
decision tags another set, and refuses when the rounds end with the decision still moving. Here
`onceF`'s parameter `h` is one slot handed both a hole function (`id`, whose set is taggable)
and a function of a closed type, and the call reaching it goes through a callee that is a list
element or a joined value, not a name the elaboration resolves to `onceF` directly. The same two
arguments through a direct call or a `const` alias of `onceF` settle. Which arm keeps the
decision moving (a set re-tagged each round, or an instance a round mints and the next drops) is
not yet measured.

#### Ablation

| `const g = if c { onceF } else { onceF }` for the list | still refuses | no, either value callee |

| the lambda's `x: f64` annotation removed | runs | **yes**, a closed type |
| `id` replaced by a non-generic `function inc(x: f64)` | runs | **yes**, a hole function |

#### Grading list

The if-joined spelling in the ablation's first row, and `dbl` in place of the lambda. Both
must print `2.5` then `5`.
