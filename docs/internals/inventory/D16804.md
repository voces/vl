### D16804 — a returned list of lists of un-annotated functions beside a literal of a wider set pins the result at no one closed type

**closed 2026-11-16 — the witness runs and prints `1.5` then `1.5` · was: loud emit reject · clause 1 (check accepts what emit refuses) and clause 2 · found closing [D16742](D16742.md) · filed 2026-11-16 against master `e056e7cea`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function dbl(a) { return a * 2 }
    function mk() { return [[inc0], [half]] }
    const zs = mk()
    print(zs[1][0](3))
    const ys = [[dbl], [inc0, half]]
    print(ys[1][1](3))
    // vl check: rc 0.  vl run: emit error, "emitProgram: internal: a function slot pinned at one signature has no one closed type the elaboration delivers it at"

Want:

    1.5
    1.5

#### Mechanism

Not the return: a bound `[[inc0], [half]]` written before `[[dbl], [inc0, half]]` failed the same
way, and written after it ran. Planning the smaller set `{inc0, half}` meets its literal
`[inc0, half]` inside `ys`, a list of lists of the wider set, and `ftHoldCtxOk`
(`compiler/check_fn_tag.vl`) refused it there: a literal in a list literal had to sit in a holder
of its own set. A list of maps or of records of a wider set already decided the smaller set with
it (`ftHolderListOfWider`); a list of lists now does too (`ftListListOfWider`). With the wider
set written first, its plan had already taken the smaller one in.

#### Grading list

- Three levels of lists, returned and bound: run.
- Walked by nested `for` loops, held in a record's fields: run.
- A returned `let` (`const r = [[inc0], [half]]; return r`): still refused at check, another
  mechanism ([D14782](D14782.md)'s family).
