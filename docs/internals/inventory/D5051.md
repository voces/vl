### D5051 — `is R` over a type parameter's inferred join with a literal, pinned to a record, finds no interned arm

**loud emit reject · clause 2 · pre-existing, the same on master `74aaec8f9` · found closing D3282 (its two-pin grading item, `twopin.vl`) · filed 2026-10-16 against master `74aaec8f9`**

Repro:

    type R = { f: i32 }
    function g<T>(a: T, c: boolean) {
      const r = if c { 5 } else { a }
      return r
    }
    const u: R = { f: 1 }

#### Mechanism

Not localised past the ablation. The complement test `is i32` over the same value runs, so the
instance's union holds the record; the positive test names `R`, and the inferred join's pin
registers no arm under that name.
