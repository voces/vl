### D15336 — a record literal of an un-annotated function pushed onto a list or set into a map beside another member is refused at emit

**open · loud emit reject · `emitProgram: cannot take the generic function id1 as a value — a function value carries ONE signature` · clause 2 · a write into a slot runs since D15307 · found grading D15307 · filed 2026-11-04 against master `23c9f7db`**

Repro:

    function id1(a) { return a }
    function id2(a) { return a }
    const xs = [{ f: id1 }]
    xs.push({ f: id2 })
    print(xs[0].f(2))
    print(xs[1].f(2.5))

Want:

    2
    2.5

#### Mechanism

A push or a map `set` delivers the literal through a call argument, not a write, so neither
`recAsgFnWidenedTy` nor fn-tag's write join sees it; the element's set is not widened by the
pushed literal's function.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the second call type (`xs[1].f(2)` only) | runs | **yes** |
| push → index write (`xs[0] = { f: id2 }`) | runs (D15307) | **yes** |
| push → `m.set("b", { f: id2 })` beside `m.set("a", { f: id1 })` | still refuses | no |

The capability matrix's slot rows (`if-arm-record-fn-field-two-members`) are not this row: they
write into a container annotated at a closed function type, which is D15301's.
