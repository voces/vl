### D4302 — an alias of a nested generic, shadowed in a block of a generic outer with two instances, names the first instance's nested function from the second

**check-clean invalid wasm · clause 1 · found by the function-value flow table in shadow mode (fn-value-flow-design.md §(f) step 1) over the review witnesses (`rv3490`: s1, s3, s6, s7, t1, t3, t4, t5, u5, p14; each `*one` variant, one instance of the outer, runs) · filed 2026-10-13 against master `aa43e52ef` with #3542 applied**

Repro:

    function call(f: (n: i32) => void, n: i32) { f(n) }
    function outer<T>(x: T, tag: string) {

#### Mechanism

`inner` captures `x`, so each instance of `outer` owns its own `inner`. The outer `k` read in
`outer$1` resolves to the `inner` nested in the FIRST instance, whose capture is an `i32`; the
block's shadowing `k` is what makes the reference resolve by name rather than by binding. The
flow table grades it `disagree: a nested instance used outside its owner | reference`.
