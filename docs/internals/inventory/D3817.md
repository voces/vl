### D3817 — a function no call instantiates, whose un-annotated parameter receives a `self`-function call, is emitted with the parameter's `i32` default against the callee's ref result

**check-clean invalid wasm · filed 2026-10-07 against master `dfe8e92b3` (found by lane OV)**

Repro:

    // file: s.vl
    export function describe(self: string): string { "string " + self }
    // file: main.vl
    import { describe } from "./s"
    export function d(x) { x.describe() }
    print(1)
    // vl check: rc 0.  vl run: invalid module, `requires result type [i32] but callee returns [(ref …)]` inside `d$m0`

Want:

    1

#### Mechanism

`d` has no instance (nothing calls it), so its template is emitted with the hole parameter's
default representation, while the member call it holds was typed by `describe`'s `string`
result. The overloaded form of the same shape is refused at check time since receiver
overloading (`tests/cases/modules/err-overload-uninstantiated/`), because no instance picks its
candidate; the single-candidate form is not.
