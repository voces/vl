### D7967 — `??` over a named `K | null` atom niche with a number default is refused at emit

**closed 2026-10-20 by lane L6b · runs, prints `7` · was loud emit reject, "`??` over this nullable value is not supported yet" · clause 2 · the null test's `then` arm re-read a field or map read at its non-null member set but returned a name as it was, still `K | null`, so delivering it into the `K | i32` box refused; `coalNarrowedReRead` now mints the name too, typed at its non-null set · pin: `tests/cases/literal-unions/coalesce-map-read-joins-atom.vl` · filed 2026-10-20 against master `aec7a5332`**

Repro:

    type AB = "a" | "b"
    const n: AB | null = null
    print(n ?? 7)

Want:

    7

#### Mechanism

`n ?? 7` lowers to `if n != null { n } else { 7 }` joined into the `AB | i32` box.
`coalNarrowedReRead` supplied the narrowed `then` arm only for a `Member` or an `Index`,
so a name reached the box delivery at its declared nullable type, and the atom-niche
delivery refused a set the box carries no null arm for.
