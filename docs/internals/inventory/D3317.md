### D3317 — a loop's write to another literal cell of a narrowed element's receiver ended the narrowing

**closed 2026-09-29 (`loopWriteMayReach` reads a literal subscript as naming its cell, as the straight-line rule does) · runs lost in #3304 round 3, never on master · fixture `tests/cases/unions/flow-join-write-after-retire.vl`, hazard `loop_other_literal_cell`**

Repro:

    function f(a: (i32 | null)[]): i32 {
      a[0] = 2
      let s = 0
      let i = 0
      while i < 3 {
        s = s + a[0]
        a[1] = null
        i = i + 1
      }
      return s
    }
    print(f([null, 1]))

Want:

    6

#### Mechanism

Round 3's loop rule treated any index write as reaching an element key, so `a[1] = null` (and
`b[1] = null`, `a[1] = [null]`) retired `a[0]` before the loop. A literal subscript names its
cell; only a computed one (`a[i % 1]`) may reach every cell.
