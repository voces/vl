#### Mechanism

The cell of a `boolean | null` local is a `(boolean | null)[]`, an i32 list holding 0, 1 or
the sentinel 2, and each read is a synthetic `v[0]` with no recorded type. `exprNulBool`
answered for a checked element through its recorded type only, so the synthetic read was not
the niche: `is boolean` did not lower as the sentinel test, and `!= null` emitted a bare
`null` with no context. `pushIndexNicheNarrow` pushed no narrowing for the element either,
and `exprIsBool` had no arm for a narrowed one. The element is now the niche until a narrowing
excludes `null`, the narrowing is pushed, and a narrowed element prints as a boolean.
