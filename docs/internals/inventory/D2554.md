### D2554 — a `.filter` over a list literal of a function-typed `T` inside a generic builds the list at the `i32` default

**closed 2026-09-26 — the filed repro RUNS and prints `3` · was check-clean invalid wasm · clause 1 · found grading D2551's position grid (`hof-filter` at a function type) · filed 2026-09-25 against master `a09d1f6bc` · fixture `tests/cases/generics/lambda-niche-signature-per-instance.vl`**

Repro:

    function g<T>(r: T): T {
      const xs = [r, r].filter((x) => true)
      return xs[0]
    }
    print(g((x: i32) => x + 1)(2))

#### Mechanism

Not yet ablated past the rows below. The list literal `[r, r]` is the receiver of an inlined
`.filter`, and its recorded type is the template's `T[]`; at `T` a function type the literal
builds an `i32` list (the module declares `(array (mut i32))` for it) while its elements are
closures. The same literal bound first (`const xs = [r, r]`) runs, and so does the
non-generic twin. The annotated callback spelling `(x: T) => x == r` was a loud refusal on
master (the lambda's signature was interned at the unsubstituted type); D2551's clone lets it
through to this row's site, so it is invalid wasm now. The same receiver refuses loudly at a
record (`struct array elements are not supported`, for `.map((x) => x)` and `.filter`) and a
list (`nested arrays are not supported`, `.filter`), where the non-generic twins run.

The close: a list literal read as a receiver (`[r].map(…)`, `[r][0]`) is re-typed at the
instance's binding (`monoPinRecvLit`). A literal holding `null` itself (`[x, null]`, typed
`(V | null)[]` since D2533) keeps the template's type: re-typed, its `.map` reaches an inferred
expression-body `.map` return that declares an `i32` result, a defect its concrete twin
`function g(x: i32) { [x, 7].map((e) => e == 7) }` has on master too (not yet filed).

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `.filter` (`const xs = [r, r]; return xs[0]`) | runs | **yes** |
| the type parameter (`r: (i32) => i32`) | runs | **yes** |
| `T` bound to `i32` or a string | runs | **yes** |
