#### Mechanism

A literal union is an interned i32 atom, and the local's cell should be that atom — which is
what the NAMED alias spelling gets. Written inline, the annotation is an anonymous union type
node, and the binding's kind ladder does not recognise it as a literal union, so the local
reaches `checkLocalI32` with a non-i32 annotation and gets that gate's sentence. The message is
the arm that fired, not the feature: the same inline annotation initialized from a LITERAL runs,
so the refusal is not about the annotation alone but about the annotation together with an
initializer whose atom the ladder has to read off the list.

Module scope runs, which places the defect in `collectLocals`' arm rather than in the global
ladder's.
