#### Mechanism

`cloCallSigRejectWhat` builds the refusal's text with `tyToEmitName`, the emitter's spelling. That
spelling has no name for a type variable or an inference hole, so it renders them as the empty
string. The message is for a person, so the checker's renderer is the right one. It names `T` and
`_`, as the checker's own diagnostics do.
