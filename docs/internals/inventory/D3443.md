### D3443 — a literal-holding binding delivered to a union whose record member stores its integer as `f32` is refused where the annotated twin runs

**closed · runs, prints `3.5` · was a loud check reject, clause 2 · the adoption lands on the union member the value lands on · fixture `tests/cases/soundness/record-literal-binding-adopts-union-member.vl` · found by the #3322 review (`rv3322-6397`) · filed 2026-09-30 against master `afb0ecc08`, closed 2026-09-30 by lane RC3**

Repro:

    type F = { v: f32 }
    const q = { v: 7 }
    const u: F | string = q
    print(q.v / 2)
    // vl check: "cannot assign {v: i32} to 'u' of type F | string"

Want:

    3.5

#### Mechanism

`i32` into `f32` is a pair the literal's own type refuses outright, so the delivery reaches
the checker's failure path, where `recAdForce` (`compiler/typecheck.vl`, owner ruling D3339
(A)) lets a literal-holding binding adopt the destination record instead. It notes the
adoption through `recAdoptNote` with the destination's non-null part as the record, so a bare
`F` or `F | null` adopts and runs, but a union with any other member hands it the union, which
is not a record the binding can adopt, and the ordinary refusal stands. At `f64` the pair is
assignable in the first place, so the delivery never reaches the forced path and the same
program runs. The same refusal stands wherever the forced
path is the only way in and the source is not the bare binding: a union parameter, an `if`
join, and a generic identity call.

**Close (lane RC3).** The demand now lands on the union's one record member of the binding's
field names (`recAdLanding`), or for a list literal binding its one list of records
(`recAdLandingList`), unless a member already stores it as the literal does or several could
take it. `F | i32`, `F | G`, the union parameter, a nested record and a list of records all run
at the twin's values; the float-literal spelling `{ v: 7.5 }` runs and prints `3.75`.

#### Ablation

All on master `afb0ecc08`; "twin" is the same program with `const q: F = { v: 7 }`.

| spelling | outcome | needed? |
| --- | --- | --- |
| the twin | runs, `3.5` | **yes** |

| `F \| null` | adopts, runs, `3.5` | **yes** |
