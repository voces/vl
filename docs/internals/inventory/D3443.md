### D3443 — a literal-holding binding delivered to a union whose record member stores its integer as `f32` is refused where the annotated twin runs

**loud check reject · clause 2 · open · the same on master `afb0ecc08` · found by the #3322 review (`rv3322-6397`) · filed 2026-09-30 against master `afb0ecc08`**

Repro:

    type F = { v: f32 }
    const q = { v: 7 }
    const u: F | string = q
    print(q.v / 2)
    // vl check: "cannot assign {v: i32} to 'u' of type F | string"

Want:

    3.5

#### Mechanism

`i32` into `f32` is a pair the literal's own type refuses outright, so the delivery reaches
the checker's failure path, where `recAdForce` (`compiler/typecheck.vl`, owner ruling D3339
(A)) lets a literal-holding binding adopt the destination record instead. It notes the
adoption through `recAdoptNote` with the destination's non-null part as the record, so a bare
`F` or `F | null` adopts and runs, but a union with any other member hands it the union, which
is not a record the binding can adopt, and the ordinary refusal stands. At `f64` the pair is
assignable in the first place, so the delivery never reaches the forced path and the same
program runs. The same refusal stands wherever the forced
path is the only way in and the source is not the bare binding: a union parameter, an `if`
join, and a generic identity call.

#### Ablation

All on master `afb0ecc08`; "twin" is the same program with `const q: F = { v: 7 }`.

| spelling | outcome | needed? |
| --- | --- | --- |
| the twin | runs, `3.5` | **yes** |
| no union (`const u: F = q`) | adopts, runs, `3.5` | **yes** |
| `F \| null` | adopts, runs, `3.5` | **yes** |
| field `f64` (`F = { v: f64 }`) | adopts, runs, `3.5` (and `u.v / 2` reads `3.5`) | **yes** |
| field `i64` | runs, `q.v + 1` prints `8` | **yes** |
| field `i32` (no width change) | runs, `3` | **yes** |
| `F \| i32` or `F \| G` with `G = { w: string }` | same refusal | no |
| the union as a parameter (`take(u: F \| string)`, `take(q)`) | same refusal, "argument 1: expected F \| string" | no |
| bare `F` as a parameter (`take(u: F)`) | adopts, runs, `3.5` `3.5` | **yes** |
| an object literal (`const u: F \| string = { v: 7 }`) | runs, `3.5` | **yes**: only a binding is refused |
| a float literal (`q = { v: 7.5 }`) | same refusal, "cannot assign {v: f64}" | no |
| delivered through an `if` join into bare `F` | same refusal, "cannot assign {v: i32} to 'd' of type D" | no: D3441's `f32` face |
| delivered through a generic identity call into bare `F` | same refusal | no: D3442's `f32` face |

#### Grading list

- `F | i32`, `F | G`, the union parameter and the float-literal spelling above.
- The `if`-join and generic-identity spellings at `f32`, which are D3441's and D3442's faces
  and may move with this row or with them.
- The `f64` twin, which must keep adopting.
