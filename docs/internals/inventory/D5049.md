### D5049 — an inferred return set of an anonymous record list and a scalar list has no list arm to box into

**loud emit reject · clause 2 · found closing D2891 (its grading list) · filed 2026-10-16 against master `03c935872`**

Repro:

    function w(b: boolean) {
      if b { return [{ x: 19 }] }
      [1, 2, 3]
    }
    const v = w(true)
    if v is i32[] { print("N") } else { print(v[0].x) }
    // vl check: rc 0.  vl run: emitProgram: array value does not match any array member of the union (leaf-scalar widening across a nested array is unsupported)

Want:

    19

#### Mechanism

Not localised past the ablation. The return set renders `#anon0[] | i32[]`, and that union's
row covers no arena members (`unionArmMemberTys` answers none), so the returned `[{ x: 19 }]`
finds no list arm to box into. A declared `type P` in the literal's place runs, and so does the
same union written on `w`, so the gap is the anonymous record's row in an inferred union's key.
