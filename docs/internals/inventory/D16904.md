#### Mechanism

`collectFrameLeafRow` keys a function frame's list-of-lists row by the lead inner literal's frame
type, here `(string | f64 | null)[]`, a ref list, but interned it directly under the leaf name
`string[]`, so no row for the inner union element existed when `rlPairMint` looked for it. At
module scope the annotation's own path interns inner-first and the frame-leaf rung does not fire.
