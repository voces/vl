### D16971 — a list literal declared at `i64[] | K[]` traps at its first `is K[]` test

**trap after load · clause 1 · found beside [D16970](D16970.md) · filed 2026-11-18 against master `1d067b11e` by lane F1**

Repro:

    type K = 1 | 2
    const q: i64[] | K[] = [1]
    if q is K[] { print(1) } else { print(0) }

Want:

    1

#### Mechanism

Not localised. The same value held first in an `i64[]` binding (`const a: i64[] = [1]`, then
`q = a`) reads `0` without a trap ([D16970](D16970.md)), and held first in a `K[]` binding reads `1`,
so the literal is built at a rep the union's tag test then casts as another: the trap is
`cast failure`, with "a value was not an instance of the type it was narrowed to".

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `u8[] \| K[]` | prints `0` ([D16970](D16970.md)), no trap | **yes** (the `i64[]` arm) |
| the literal held in an `i64[]` binding first | prints `0`, no trap | **yes** (the literal at the union) |
| the literal held in a `K[]` binding first | prints `1` | **yes** |
