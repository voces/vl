#### Mechanism

Each instance of `take` notes the literal `{ f: half }` as stored at its own set
(`mintStoreNote`), `{inc0, half}` and `{dbl, half}`. The literal is one template node, and its
rep stamp is per node (`repStampHeldRead`), so it cannot be built at both sets' reps. The note
marks it `-2` and neither set takes the store. The close needs per-instance stamps of a literal.
