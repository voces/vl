### D16745 — a function with an un-annotated list parameter called with two lists of functions, one set inside the other, builds an invalid module

**check-clean invalid wasm · clause 1 · found closing [D16744](D16744.md) · filed 2026-11-16 against master `7de99c68a`**

Repro:

    function inc0(a) { return a + 1 }
    function dbl(a) { return a * 2 }
    function run(xs) { print(xs[0](3)) }
    run([inc0, dbl])
    run([dbl])
    // vl check: rc 0.  vl run: invalid module, "inside `run$1` … type mismatch: expected (ref null $9), found (ref $7); $9 is `list of i32-represented elements` … $7 is `((i32)=>i32)[]`"

Want:

    4
    6

#### Mechanism

Not yet located. `run` gets two instances. The second, for `[dbl]`, takes its parameter as the
first's tagged list of ids while the caller builds `[dbl]` as a list of closures. A smaller set
within a tagged one is decided with it, and the second call's literal is not built at that rep.
Results that differ (`half` for `dbl`) build the same invalid module.

#### Grading list

- The `for` spelling, the `while` spelling and a literal index.
- The calls in the other order.
