### D17026 — an `if x is A { x } else { null }` delivered to an `A | null` binding writes the union box where A's nullable row is owed

**check-clean invalid wasm · clause 1 · the un-annotated spelling is a loud emit reject (`ref valtype with no interned shape`) · found by lane F2 probing union-field `??` receivers · filed 2026-11-20 against master `890abde55`**

Repro:

    type A = { k: "a", v: i32 }
    type B = { k: "b", w: i32 }
    function h(x: A | B): i32 {
      const r: A | null = if x is A { x } else { null }
      if r != null { return r.v }
      return 0
    }
    print(h({ k: "a", v: 2 }) + h({ k: "b", w: 9 }))

Want:

    2

#### Mechanism

The `then` arm reads `x`, narrowed by `is` to the arm `A`, but delivers it as the `A | B` union box
(`(ref $box)`) into a valued `if` whose block type is `A`'s nullable row (`(ref null $A)`): the
validator reports `expected (ref null $A), found (ref $box)` inside `h`. No unbox to the arm's row is
written at that delivery. The same narrowed read at a plain binding (`const r: A | null = x` inside
`if x is A`) runs, so the miss is the valued `if`'s arm delivery of a narrowed union box, not the
narrowing. The neighbour is D16973 (a `.map` callback returning an arm or `null`),
closed through the element read; this row is the binding-initializer spelling, which that close does
not reach.
