#### Mechanism

Not localised past the ablation. The annotated element type names `Holder`, whose nested field
is `{ x: i32 | null }`, but the emitter interns the outer literal's field at the literal's own
inferred type `{x: null}`, which has no struct-field rep. It needs the list to carry a second,
non-record element: a one-element list, or a `Holder[]`, builds the declared struct.

#### Grading list

The read of the element after the list builds: `const a = xs[0]` then
`if a is Holder { print(a.h.x == null) }` should print `true`. The same read over a
non-null leaf (`[{ h: { x: 3 } }, "t"]`) refuses today with
`field access receiver is not a struct`, and should print `false`.
