#### Mechanism

`srcs[0]` holds a list of `J`. The function's inferred result is the checker's `{ f: null }[]`, laid
out narrow, so the body returns a `J` list where the result is narrow. Returning `src` itself is
refused by `recBuiltRetListsRefuse` (D16772's family), but that check reads a built list through
`recBuiltElemIn`, which does not follow an index into a list of lists. So this spelling is neither
refused nor rebuilt.
