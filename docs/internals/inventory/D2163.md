### D2163 — a covariant list STORED into a container (push, index store, map store) takes the copy licence but no store position lowers the copy

**closed 2026-09-23: the push, indexed-store, map-store and global-assignment boundaries lower the copy (`emitNestedListWidenSite`, and the ref site at `global.set`); the field store (`h.v = ints` into a `readonly f64[]` field) lowers it too (`emitFieldListWidenSite`), and `m.set(k, v)` is filed by the write analysis as the store `m[k] = v` is; one map both index-stored and `.set` with the same list still declines the licence and refuses; the mutable spellings are refused by design ([D2161](D2161.md)) · was check-clean invalid wasm · 4 store forms, numeric and ref-copy pairs · filed 2026-09-23 against master `b52b14e83`**

Repro:

    const a: i32[] = [1, 2]
    const outer: (readonly f64[])[] = []
    outer.push(a)
    print(outer[0][0])
    // vl check: rc 0.  vl run: invalid module — type mismatch: expected (ref $type), found (ref $type)

#### Mechanism

`push`, `xs[i] = v` and `m[k] = v` check their value through `assignableExpr`, the seam every
delivery shares, so a read-only `i32[]` stored into an `f64[][]` passes the D965 licence exactly
as a binding does. The emitter's converting copy is wired at the binding, argument, return,
assignment, struct-field, literal-element, global-init and global-assignment positions and at
none of the store forms, so the store hands the `i32[]` reference to a slot typed for `f64[]`.
The same gap holds for the ref copy (`Circle[]` pushed into a `Shape[][]`), which is also
invalid at a module global's ASSIGNMENT (`let b: Shape[] = []`, then `b = a` in a function).

#### Grading list

Every ablation row, and the grid's `push` column (`i32_f64`, `i32_i64`, `f32_f64`, `ro_f64`,
`circ_shape`, `ro_shape`) plus `circ_shape`/`ro_shape` at `gasg`. Under the 2026-09-23 ruling
the recommended close is a design REFUSAL at the store forms (the message the other positions
give when the value is written), since none of these cells runs today and a refusal costs no
working program; wiring the copy instead would widen what the ruling wants retired.
