### D9970 — a lambda delivered at a function type whose result is a list of functions or a scalar, with no `null`, refuses at the list it returns

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same lambda with its result annotated runs, and the same result widened with `| null` runs · found closing [D9783](D9783.md) · present on master `0f0face1e` · filed 2026-10-22 against master `0f0face1e`**

Repro:

    function take(v: () => (() => string)[] | i32) {
      const t = v()
      if t is i32 { print(t) } else { print(t[0]()) }
    }
    take(() => [() => "z"])
    // vl check: rc 0.  vl run: emitProgram: array value does not match any array member of the union (leaf-scalar widening across a nested array is unsupported)

Want:

    z

#### Mechanism

Not traced. The refusal is at the list literal the lambda returns, before any call: the
literal's element is built as `() => string` and the union's list arm is matched against it
by its spelling, which the arm-matching in the union delivery does not find. With the
lambda's result annotated the literal is built at the arm's own type and runs. The call
through the value is not involved — before [D9783](D9783.md) closed, the declared-function
spellings refused earlier, at the call.
