#### Mechanism

`K[]` and `i32[]` ride one list rep, so a list-to-list `is` is decided from the rep and folds to
true; no element is tested against `K`. The owner's D3885 ruling makes `is` a value-fit test
for record arms, and this row asks whether that reaches list elements: either the test walks
the elements, or the checker says the test is decided by type and the D3885 hint names it.
