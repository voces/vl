### D17462 — a function's returns joining a nested record literal and a maker's record are refused at emit

**closed 2026-11-25 by IR-N5 on branch `legacy-inferred-return-record-delivery` · now runs, prints `7` · was a loud emit reject, `this branch hands over a record whose field types differ from the record the branches join to`: an inferred result's returns are now delivered to it as a written result's are ([D17224](D17224.md)) · clause 2 · filed 2026-11-24 against master `ec08ae2c3` by lane IR-P1 (found ablating [D17461](D17461.md); the sentence is [D16610](D16610.md)'s family)**

Repro:

    function mk2() { return { f: null, g: 7 } }
    function pick(m) {
      if m { return { a: { f: 1, g: 7 } } }
      return { a: mk2() }
    }
    print(pick(true).a.g)
    // vl check: rc 0.  vl run: prints the Want block below

Want:

    7

#### Mechanism

`pick`'s returns join `{ a: { f: i32, g: i32 } }` with `{ a: { f: null, g: i32 } }`, a record
`mk2` builds. The second branch hands over that built record, whose field types are not the join's,
and records are shared rather than converted, so emit refuses. The check accepts the join.
