### D15150 — two union arms of one field set that differ only by a map field are not refused, and `is` answers true for both

**check-clean silently wrong · clause 1 · filed 2026-11-03 against master `4a114e6cd` by lane column-G1, found grading D15098's control**

Repro:

    type A = { n: i32, g: Map<string, string> }
    type B = { n: i32, g: Map<string, string> }
    type U = A | B
    const gb: Map<string, string> = Map()
    const b: B = { n: 4, g: gb }
    const u: U = b
    if u is A { print(1) } else { print(2) }
    // PRINTS 1

Want:

    2

#### Mechanism

Not traced. Two arms whose fields agree in name and storage share a layout, and the emitter
refuses the union loudly when `is` cannot tell them apart (`union `U` cannot be discriminated —
variants `A` and `B` have the same …`). With a map field the refusal does not fire, both arms
build at one heap type, and `is A` answers true for a `B`.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the field `g: R` / `g: S` (a record, not a map) | refuses loudly, `cannot be discriminated` | **yes** (the map) |
| the field `g: R[]` / `g: S[]` (a list) | refuses loudly | **yes** (the map) |
| the map values `R` and `S`, both `{ r: i32 }` | still prints `1` | no |
| the map values both `R` | still prints `1` | no |
| `u is B` | prints true too | — |

#### Grading list

The witness; the map values `R`/`S`; a nullable map field; a third arm of the field set; the
same pair held by a plain struct (prints `1` too, where it no longer refuses).
