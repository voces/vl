### D6990 — a labelled block whose value is an uncalled hole function, bound and never read, is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same program with `exclaim(s: string)` runs, and the same `if` expression runs ([D6981](D6981.md)) · found closing [D6981](D6981.md) · present on master `4ad81c0e0` · filed 2026-10-19 against master `4ad81c0e0`**

Repro:

    function exclaim(s) { return s + "!" }
    const x = @B { exclaim }
    print(1)
    // vl check: rc 0.  vl run: emitProgram: local declaration needs an initializer

Want:

    1

#### Mechanism

From the ablation only. A labelled block's value is lowered by rewriting the block into a
declaration of the binding that each exit assigns. With a hole function as the value, that
rewrite produces a declaration with no initializer, which the local emitter refuses. The
inertness walk is not reached, so this is not D6981's mechanism.
