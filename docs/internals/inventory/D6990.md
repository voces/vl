### D6990 — a labelled block whose value is an uncalled hole function, bound and never read, is refused at emit

**closed 2026-10-19 by lane L1 · runs, prints `1` · was loud emit reject · `vl check` rc 0 · clause 2 · CAPABILITY: the same program with `exclaim(s: string)` runs, and the same `if` expression runs ([D6981](D6981.md)) · a labelled block no `break` leaves, whose value holds a function of an open signature, is rewritten as an `if` whose arm is the block itself rather than a carrier binding, so the value flow question follows its last statement · pins: `tests/cases/closures/hole-fn-labelled-block-value.vl` · found closing [D6981](D6981.md) · present on master `4ad81c0e0` · filed 2026-10-19 against master `4ad81c0e0`**

Repro:

    function exclaim(s) { return s + "!" }
    const x = @B { exclaim }
    print(1)
    // vl check: rc 0.  vl run: emitProgram: local declaration needs an initializer

Want:

    1

#### Mechanism

From the code path and the ablation. Before the instancer runs, `lvRewriteAt`
(`emit_rewrite.vl`) rewrites the block into `if true { let $lvN: T; @B while true { $lvN =
exclaim; break }; $lvN } else { __trap__() }`. `T` is the value's type, here the hole
function's open signature spelled by its type variables. A non-null `T` gets no initializer.
The instancer's value walks follow an `if` arm to its last statement, which is the read of
`$lvN`, and do not follow the assignment inside the loop back to `exclaim`, so nothing pins it.
`$lvN` keeps the open spelling, no local rung classifies it as a closure, and the i32 floor
(`checkLocalI32`, the message's only site) refuses the declaration with no initializer. An
annotated destination closes `T` before the rewrite, so the same block runs. A fix gives the
value walks the carrier's writes as its values, or has the rewrite keep a block with no
`break` to it a plain block value.
