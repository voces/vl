#### Mechanism

The deep `is` rewrite reads the converted copy (`__vljv<n>`) in place of the tested place up to
the statement that writes it ([D1190](D1190.md), `jwSubstScoped`). A closure that writes it runs
when it is called, which no statement order in the arm says, so the rewrite has no point at which
to stop substituting.

The checker already says where: it ends the narrowing at a call that may run the write (the
writer's call, an alias's call, a call that is handed the writer), records that call
(`crRetCalls`), and types the place unnarrowed inside the writer's body. The rewrite runs after a
clean check, so it cuts at that recorded call. In the cut statement it substitutes only the reads
the check typed narrowed (`r.length + run(clear)`), and it leaves the writer's body unsubstituted.
An assignment used as an expression still refuses; that is [D16474](D16474.md).
