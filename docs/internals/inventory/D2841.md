### D2841 — two anonymous record literals whose field is `boolean` in one and `i32` or a literal set in the other share one row, and the second reads back in the first's format

**closed 2026-09-27 · was check-clean silently wrong, clause 1, on master `7323baf55` · found by the #3220 review · filed 2026-09-27 · fixture `tests/cases/structs/anon-row-code0-kinds.vl`**

Repro:

    const a = { f: true }
    const b = { f: 4 }
    print(b.f)
    // PRINTS true
    // vl check: rc 0.  vl run: prints `true`, want `4`

#### Mechanism

Field code 0 holds `i32`, `boolean` and a string literal set's atom alike, and a field read
formats by its row's recorded field type. Three literal-to-row readers matched a code-0 field
by name and code only:

- `anonValueFitsField` (a literal to an anonymous row), so `{ f: 4 }` took `{ f: true }`'s row;
- `declRowScalarFits` (a literal to a declared row), which let a literal set take a declared
  `boolean` or `i32` row;
- the arena field-set scan `structRowOfObjFieldSetK`.

All three now ask one comparator, `code0KindOf` (`i32`, `boolean`, string literal set). An atom
field, anonymous or declared, takes only a string literal among its members. So
`type R = { k: "a" | "b" }` no longer captures `{ k: "zz" }` (it printed `b`), nor `{ k: s }`
with `s: string` (invalid wasm). A nested row a declared row would capture no longer holds a
string where the declared row holds a non-string scalar or list: `{ w: { f: "q" } }` beside
`type W = { w: { f: i32 } }` was invalid wasm and runs now.

The rendered-spelling readers (`annShapeIndexOf`, `structIndexOfTypeName`) deliberately do not
split. A record whose field is still a hole (a generic or hole constructor's result, D2850)
cannot choose between two split rows, and splitting them turned a loud refusal into invalid
wasm. So the annotated generic `const o: { f: T } = { f: v }` at `g(true); g(4)` still prints
`true` twice, as on master. A literal handed straight to an un-annotated parameter still
records the parameter's hole as its row type, so a lone `p({ f: true })` prints `1`; that is
D2762, open.
