Repro:

    type LS = "a" | "b"
    function g<T>(x: T): T { return x }
    function f<T>(x: T) { const y = g(x)
      print(y) }
    function go() {

#### Mechanism

Not localised past the ablation. `y` is claimed as the atom, but `litAtomWidenTexts` finds no
member texts: its declaration's initializer is a call whose annotated return is the callee's own
type parameter, and `y` records the caller's. Reading `y` at the explicit instance's substitution
(`exactOperandTyOf`) did not supply them, so the recorded type is not the caller's `T` alone.
