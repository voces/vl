### D2280 — a map's index resized on its live count while deleted entries' slots stayed probe markers, so churn filled it and the next probe never ended

**closed 2026-09-23 — the witness prints `done` · was a hang: `vl check` rc 0, `vl run` never returns (the 17th distinct key's probe spins over a 16-slot index with no free slot) · reported by consumer plumb (PL-031) · filed against master `ba5378dd5` · fixtures `tests/cases/maps/churn-window-past-sixteen-keys.vl`, `churn-sliding-window-every-rep.vl`, `churn-random-against-reference.vl`**

Repro:

    const m: {[i32]: i32} = Map()
    for k in 0 until 100000 {
      m[k] = k
      if k >= 4 { m.delete(k - 4) }
    }
    print("done")
    // prints done

#### Mechanism

`m.delete` tombstones the entry (`live[e] = 0`) and leaves its `index` slot pointing at it, so
the probe chain through that slot stays intact. The slot is only reclaimed by compaction, which
`delete` runs once dead entries exceed `size + 8`. `__map_resize__` gated growth on
`size * 2 >= len(index)`, the LIVE count, so a map holding 4 entries kept its 16-slot index while
16 entries were appended; at `count = 16` there were 12 dead entries, one short of compaction,
and every slot was occupied. The next insert's probe (`__map_probe__` / `__map_probe_i32__`)
looks for a match or an empty slot and found neither, forever. Swept over windows 1–40 of live
keys (2,000 inserts each), the windows that hung were 4–6, 12–14 and 28–30. The gate is now `count * 2 >= len(index)`
(`count` bounds the occupied slots, live and dead), and each probe's back-edge re-enters only
until it wraps to its start slot, then traps, so no index state can spin.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `delete` (insert-only) | runs | **yes** |
| the key rep (`{[string]: i32}` instead) | still hangs | no |
| the value rep (struct, f64, i64, nullable, list, union, Set) | still hangs | no |
| a window of 8 live keys instead of 4 | runs (index grows to 32 first) | **yes** (4–6, 12–14, 28–30 hang) |

#### Grading list

Every key rep (i32, string, and the Set forms of both) and the value reps above, in
`churn-sliding-window-every-rep.vl`; delete-then-reinsert of one key; a randomized
insert/overwrite/delete run checked against a reference after every op.
