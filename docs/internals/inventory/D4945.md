### D4945 — an inner list of a numeric list narrowed by `is K[][]` is delivered as `K[]` and aliased

**closed · now a loud check reject · was check-clean silently wrong value (clause 1) · related to D4928 (a narrowed list delivered as `K[]`) · filed 2026-10-15 against master `23dcd80be`**

Repro:

    type K = 0 | 1
    const b: i32[][] = [[0], [1]]
    let k: K[] = []
    if (b is K[][]) {
      k = b[0]
    }
    b[0][0] = 5
    print(k[0])
    // vl check: 'b[0]' is narrowed by `is` only for reading its elements; it is still
    // declared i32[] and a later write may widen it, so it cannot be delivered as K[]. Copy it
    // with 'b[0].map((x) => x)'

#### Mechanism

D4928 refuses delivering `b` itself as `K[][]`, but a read of one of its rows, `b[0]`, types as
`K[]` under the guard and is delivered by reference. The row is the same list object `b` still
holds at its declared `i32[]`, so a store through `b` after the guard reaches `k`. The same
shape lets `b.map((x) => x)` deliver `K[][]` whose rows are `b`'s own rows. A string literal
union is not affected: `m[0]` under `m is S[][]` reads as `string[]` and is refused.

#### Close

Owner ruling (c) on #3792 at every depth: a numeric literal-set `is` on a bare name narrows its
element reads only, so a row `b[0]` (or a `for` variable over `b`) reads as `i32[]` with its
elements as `K`. Delivering the row where `K[]` is wanted is the D4928 check error, naming the
row and its `map` copy; an un-annotated alias (`const r = b[0]`) and `b.map((x) => x)` are
`cannot assign i32[] to K[]` / `i32[][] to K[][]`. A store or push whose value stays in `K`
keeps the narrowing standing, as D4926 kept it at depth one, and a `for` body that copies its
row with `map` no longer retires the guard. A member place (`o.xs is K[]`) keeps its by-name
narrowing and is D4957.

#### Grading list

`let kk: K[][] = []` with `kk = b.map((x) => x)` under the guard, then `b[0][0] = 5` and
`print(kk[0][0])`: prints 5 today. The copy the D4928 message names at this depth,
`b.map((r) => r.map((x) => x))`, makes fresh rows and prints 0.
