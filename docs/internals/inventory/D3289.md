#### Mechanism

Not localised past the ablation. The cost multiplies by the fan-out per level, so some walk
of a function type expands every alias reference it meets instead of reusing the answer for a
name it has already resolved: two parameters per level double it, three triple it. The walk
belongs to the annotated position, not to the declarations: the aliases alone are cheap, and
each further annotated binding or parameter adds the same slice again. With three parameters
per level at depth 8 one binding is ~3.4G fuel, and 300 such bindings exhaust the null
collector's heap (`an allocation larger than the GC heap can ever hold`). Parameter names play
no part: every spelling here is unnamed.
