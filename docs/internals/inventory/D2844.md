### D2844 — an inferred union with a list-of-lists arm, bound at the top level with no annotation, has no union row

**loud emit reject · clause 2 · found closing D2819 · the same on master `7323baf55` · filed 2026-09-27 against master `7323baf55`**

Repro:

    const xs: string[][] | null = null
    const q = xs ?? [[1]]
    if q is i32[][] { print(q[0][0]) } else { print(-1) }
    // vl check: rc 0.  vl run: emitProgram: `is` test but no union type declared

#### Mechanism

The join is typed `string[][] | i32[][]`, but nothing registers a union row for it: no
annotation spells it, no function returns it, and `markInferredJoinAtoms` (emit_collect.vl)
is reached only for an `if` expression and mints value-atom kinds, which a list-of-lists arm
is not. With no row, no box is declared and the `is` has no tag to test. The same `??`
returned from a function runs (D2819), since the return type registers the row.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the join returned from a function instead of bound | runs | **yes** |
| one level (`string[] \| null ?? [1]`) | runs, prints `2` | **yes** |
| an `if` join instead of `??` (`if t() { xs } else { [[1]] }`) | loud emit reject, `is names a declared union member with no interned arm representation` | no |
| the same binding inside a function body | the same reject | no |

#### Grading list

The `if` join above; the binding inside a function (`function f(xs) { const q = xs ?? [[1]] … }`).
