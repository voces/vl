#### Mechanism

The join is typed `string[][] | i32[][]`, but nothing registers a union row for it: no
annotation spells it, no function returns it, and `markInferredJoinAtoms` (emit_collect.vl)
is reached only for an `if` expression and mints value-atom kinds, which a list-of-lists arm
is not. With no row, no box is declared and the `is` has no tag to test. The same `??`
returned from a function runs (D2819), since the return type registers the row.
