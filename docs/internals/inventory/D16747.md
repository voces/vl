#### Mechanism

Traced by lane INIT. The tag decision leaves the set partial (closures); `substTyDeep` keeps a
set's function type as its id only when the set is tagged, so the instance's binding of the
parameter becomes the first member's signature, `((i32) => i32)[]`, a type the checker refuses when
spelled. Every callee under that key reads `(i32) => i32`. The stopgap refuses a closure call
typed at a signature an untagged set handed to a parameter splits at (`closureCallSetSplits`).
No decider finds the set today: the check's producer reaches no call through a `for` element of a
list parameter, and the late pass has no mint rows for these calls, so tagging it needs each
member's result at the call's argument types, the at-call solve S3.4d. A second dispatch on the
closure's function id is ruled out. The witness raises a late demand for `run` on master too,
while it traps; the fix must remove it.

The written copy is a read of the parameter that is not a callee, so the set is partial and
stays closures ([D16744](D16744.md)'s mechanism), and the closure call has one signature. Any
spelling that leaves a set of different results as closures inside an instance and calls through
it traps this way. The general net is an emit-time refusal, or a dispatch, where a closure call's
set splits its result.
