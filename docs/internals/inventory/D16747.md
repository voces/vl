### D16747 — a `let` copy of a list parameter's element, re-pointed to a member of its set, is called at one signature and traps

**loads then traps · clause 1 · found closing [D16744](D16744.md) · filed 2026-11-16 against master `7de99c68a`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    function run(xs) {
      for x in xs {
        let y = x
        y = half
        print(y(3))
      }
    }
    run([inc0, half])
    // vl check: rc 0.  vl run: wasm trap: indirect call type mismatch

Want:

    1.5
    1.5

#### Mechanism

The written copy is a read of the parameter that is not a callee, so the set is partial and
stays closures ([D16744](D16744.md)'s mechanism), and the closure call has one signature. Any
spelling that leaves a set of different results as closures inside an instance and calls through
it traps this way. The general net is an emit-time refusal, or a dispatch, where a closure call's
set splits its result.
