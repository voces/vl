#### Mechanism

Not localised past the ablation. The READ of such a list keeps the `null` since D3089's close;
the trap is at the STORE, where the hole value is written into the `(string | null)[]` backing
through a non-null recover. A `.push` of the same value and a flat literal `[x]` both store it
nullable, so the index-assignment store and a nested literal's inner element are the two paths
that classify the hole value as a non-null string.
