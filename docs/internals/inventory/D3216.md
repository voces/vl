### D3216 — the else arm of an `is` record test on a hole's field reads the field at the whole union

**closed · the else arm of `is T` for a record `T` over a hole's field carries the deferred remainder, whose member reads are re-asked at the pin · fixture `tests/cases/generics/hole-field-is-test-else-reads-the-remainder.vl` · was a loud check reject, clause 2, and under #3289's first round a price of 120 `runs` whose twins run · pre-existing, the same on master `94670f728` · found by the #3289 review (`rv3289-q8x4/p/k05.vl`, grid `gi`) · filed and closed 2026-09-29 against master `94670f728`**

Repro:

    type H = { v: i32 }
    function F(z) { if z.h is H { print(z.h.v) } else { print(z.h) } }
    const a: { h: H | i32 } = { h: 5 }

Want:

    5

#### Mechanism

A hole has no member list for `subtractTy`, so the else arm of `is T` defers the remainder to
the pin as an `HD_GNOT` hole, except that `holeElseRemainderOk` declined a record `T`: reads
off the remainder would grow a shape no argument check sees. So the else arm read the field at
the whole union: `print` refused `H | i32`, and once D3204 re-asked member reads off a hole's
field, `z.h.s` in the else arm of `z.h is A` refused `field 's' is not on every member` where
the direct spelling reads `B`. A record `T` is now admitted over a hole's FIELD, and a member
read off that remainder records a `memCstrTy` row like a read off the field
(`hdMemberReasked`), so the pin checks it against `U − T`: `no field 'v' on B` refuses as the
direct spelling does. A second test over the remainder mints a remainder of the remainder, to
any depth (`hdFieldRooted`), and a read in an arm some test in its chain makes dead at the pin
(`{ h: { v: 3 } }` in the else arm of `is A`) is not re-asked (`gnotArmDeadAt`), as a guarded
call at a `null` pin is not. A parameter hole's remainder is still declined (D3234). The price
is D3231: printing a remainder that holds a scalar or `null` was refused and is now the same
invalid wasm the annotated spelling gives.
