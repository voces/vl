### D17025 — a narrowed read of a union field off a record that is itself a union member skips the box's payload cast

**closed 2026-11-20 by lane IR6 (#9251) · now runs, `3` · was check-clean invalid wasm · `variantUnionBoxTail` now writes the member record's unbox cast that `boxedArmOfMember` names, as `structUnionBoxTail` does · pins: `tests/cases/narrowing/narrowed-field-of-a-union-member-record.vl`, `narrowed-field-of-a-union-member-record-row.vl` · found writing `ir_lower.vl`'s map-read default lowering (`r.mgDef is OVar`, then `r.mgDef.ov`) · filed 2026-11-20 against master `50563c118`**

Repro:

    type A = { ov: i32 }
    type B = { bits: i32 }
    type O = A | B
    type R = { d: O }
    type S = { q: i32 }
    type U = R | S
    function f(r: R): i32 {
      if r.d is A { return r.d.ov }
      return -1
    }
    const a: O = { ov: 3 }
    print(f({ d: a }))
    // vl check: rc 0.  vl run: the emitted module failed to validate inside `f`: type mismatch:
    // expected (ref null A), found (ref union box)

Want:

    3

#### Mechanism

`r.d is A` narrows the field path `r.d`, and the narrowed read `r.d.ov` takes the field's
value as an `A` reference with no cast from the `{tag, payload}` union box the field holds.
That happens only once `R` is a member of some union (`U`, which nothing else needs to
use). With no such union the same program runs. The IR shadow covers and matches `f`, so
both writers emit these bytes. The shared field-read tail off a variant receiver
(`variantUnionBoxTail`) left the box where `boxedArmOfMember` named the member's record.

#### Grading list

The spelling found in the compiler, `if !(r.mgDef is OVar) || varSlot(r.mgDef.ov) >= 0`
inside `ir_lower.vl`'s `mapGetOr(r: RMapGetOr)`, where `RMapGetOr` is a member of `Rhs`.
`ir-map-default-body` binds the field to a local instead (`const dout = r.mgDef`).
