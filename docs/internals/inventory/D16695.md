#### Mechanism

Not traced. The un-annotated binding `src` is a fresh list in the generic body, so every instance
shares its literal; one instance's build of `id` is read where the other's signature is called.
`pushSpreadFreshList` (check_member_call.vl) declines a function element, so the binding is
delivered through `bmArgOk` and `fvaListSetCopy` only.
