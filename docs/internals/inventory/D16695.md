Repro:

    function id<T>(x: T): T { return x }
    function run<T>(_x: T) {
      const rs: ((x: T) => T)[] = []
      const src = [id]
      rs.push(...src)
      return rs
    }
    print(run(3)[0](3))
    print(run("ab")[0]("ab"))
    // was: vl check rc 0, vl run wasm trap: indirect call type mismatch

Want:

    3

#### Mechanism

The un-annotated `src` is pinned by `monoPinListElems` (emit_mono.vl) from the slot facts the
elaboration gives its element. Its only use is `rs.push(...src)`, which neither the delivery walk
(`elabSlotReadDeliveries`, whose spread arm followed only a spread into a list literal) nor the place
graph (`eplEdgeAt`, the same) followed. So the slot read as one nothing calls, and `id` was built at
no signature, shared by every instance. Measured with temporary probes: before, `pins=0` and the
uncalled arm; after, one pin per instance (`i32`, `string`).
