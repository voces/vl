### D2801 — printing a `T | null` value box in the branch where it is null emits an invalid module

**check-clean invalid wasm · clause 1 · found by #3208's review (`gPr` `nnar` cells) · identical on master · filed 2026-09-27 against master `b586b6063`**

Repro:

    const v: i32 | null = 5
    if v != null { print(v) } else { print(v) }
    // vl run: invalid module — type mismatch: expected i32, found (ref $type)

#### Mechanism

Not ablated to a rung. `i32 | null` is a value box; in the `else` arm the complement narrowing
leaves `null` as the sole member, and `print` treats the narrowed value as the `i32` its first
arm names, calling `__print_i32__` with the box still on the stack. The same happens for `f64`,
for `i32 | string | null` (the member set left in the `else` arm), and inside a generic
instance at those pins.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the `else` print | runs, prints `5` | **yes** |
| the box (`string \| null`, a niche) | runs | **yes** |
