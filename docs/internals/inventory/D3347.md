**closed 2026-09-30 · was a loud emit reject, clause 2, on master `78abe1318` (`` `==` over a struct union is not supported yet``, `literal-union string widening with no members`) at the direct spelling, and a coincidental run at the generic one · found by the #3310 review (`w4.vl`, `w7.vl`, `litN_*_eq`) · fixture `tests/cases/unions/literal-union-arm-box-null-and-eq.vl`**

#### Mechanism

Two gates of the box a literal-union arm rides as its member string. A `K | null` parameter
entering such a box was refused because its `-1` has no string (D3140); it now boxes the `-1` under
the null tag and any other id as its member string, reading the id once, for a parameter of a
function with no declared return (a call's result or a binding may hold a box its producer
already built, D3140's own cells). And `==` between two boxes admitted only value unions; a box
carrying a literal-union arm is one, so it compares by the shared arms, and a `K | null` operand
against a box with a null arm tests the null tag when it is `-1`.
