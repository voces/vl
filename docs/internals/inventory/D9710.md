### D9710 — an element of a returned local nested list of un-annotated functions, handed to an un-annotated parameter, is refused as an argument type

**loud emit reject · `vl check` rc 0 · `monomorphize: unsupported argument type for `f` in a call to `use`` · clause 2 · found closing [D9662](D9662.md) · present on master `e8163edd5` · filed 2026-10-22 against master `e8163edd5`**

Repro:

    function inc(a) { return a + 1 }
    function use(f) { return f(3) }
    function deliver() {
      const u = [[inc]]
      return u
    }
    const v = deliver()
    print(use(v[0][0]))
    // vl check rc 0.  vl run: emit error: emitProgram: monomorphize: unsupported argument type for `f` in a call to `use`

Want:

    4

#### Mechanism

Not traced. The direct call `v[0][0](3)` and a `const g = v[0][0]` both run, so the element has
a lowering. Handing the element read to `use` asks the call's argument type, which stays open at
the element of the returned local's list.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| the local (`return [[inc]]`) | runs, `4` | **yes** |
| the nesting (`const u = [inc]`, `use(v[0])`) | runs, `4` | **yes** |
| the un-annotated parameter of `inc` (`inc(a: i32): i32`) | runs, `4` | **yes** |
| the un-annotated parameter of `use` (`use(f: (a: i32) => i32)`) | runs, `4` | **yes** |
| the call through `use` (`print(v[0][0](3))`) | runs, `4` | **yes** |
| a parameter of `deliver` (`deliver(n)`, `deliver(7)`) | same refusal | no |
