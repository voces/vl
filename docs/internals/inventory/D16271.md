**closed · runs, prints `41` · was check-clean invalid wasm, `vl check` rc 0, `type mismatch: expected (ref null $8), found (ref $4)`, clause 1 · regressed from [D5062](D5062.md) (closed): matrix `written-fn-binding-inferred-return`, cells `map_value` and `map_set` · first bad on master `733972162` (#6555) · filed 2026-11-14 against master `c522f8dd1` · closed: a binding whose roots hold a function plans its reads as values a map read gave, so only a call or a narrowed argument reads it as the generic (`monoFlowUsePlanAt`, emit_mono.vl) · fixture `closures/generic-alias-read-from-map-null-tested.vl` · matrix `written-fn-binding-inferred-return` 62 → 64 of 64**

#### Mechanism

Since #6555, `monoFlowDeclVals` answers from the elaboration's roots, and `mv`'s root is the
function the map read gave, not the `Map()` literal. `monoFlowUsePlanAt` set `viaMap` only
for a map root, so the read in `mv != null` was planned as a read of `k` and emitted as
`k`'s closure where the test reads `mv`'s union box. `m["k"] = k` stores the generic's name,
whose root the walk reaches the old way.

#### Ablation

| --- | --- | --- |

| a call result (`m["k"] = mk()`, `mk` returning `k`) instead of `g` | invalid wasm the same | no |
| `m.set` / `m.get` instead of indexing | invalid wasm the same | no |
| the null test (`print(mv == null)`) | loud emit reject, `reaches no call that fixes its type` | **yes** |
