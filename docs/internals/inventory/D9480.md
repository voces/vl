#### Mechanism

One map handed to `fill` runs since D9440 was narrowed. Handed two, `fill`'s parameter has two
candidate values, and `monoFlowAliasMap` (emit_mono.vl) accepted an alias only when it held
exactly one map, so the store through `mm` counted as neither map's, the read plan declined,
and `mm["k"] = id` reached the emitter with the map left open. The alias now holds every map
it is handed, and the maps' literal roots are tied in `mfrTied`, so a decline on one declines
them all.
