#### Mechanism

Not located. With [D10192](D10192.md) closed, a write by a choosing call gives each of the
binding's lanes a selection by the new arm index (`fsApplyChoiceWrite`, fn_split.vl). The
refusal comes back when one call type's lane is read only after the write. The refusal
points at `return id` in `pick`, so the arm-index copy the plan needs for that lane is not
made.

#### Ablation

| ingredient removed | outcome | needed? |
| --- | --- | --- |
| `k("a")` also called before the write | runs, as [D10192](D10192.md) | **yes** |
| `k(22)` after the write (string read after, both before) | runs | no |
| `k = id` as the write | runs | **yes** |

#### Grading list

The same shape with a write from a function with a different set of arms: `k = pick3(0)`,
where `pick3` can also return a third generic, still refuses. `fsPlanMember` declines a
write whose arm set differs from the binding's own.
