### D3655 — `e is C` with `e: i32` over an integer literal union spanning two widths is refused as "can never match"

**loud check reject · clause 2 · found by lane WV while closing [D3590](D3590.md) · filed 2026-10-04 against master `32b753681`**

Repro:

    type C = 1 | 3000000000
    const d: i32 = 1
    print(d is C)
    // vl check: `is` check type 'C' can never match a value of type i32

Want:

    true

#### Mechanism

Not traced. `1` is a member of `C` and an `i32` value, so the test can match; the checker's
"can never match" rung reads the union as having no `i32` member, likely because a union over
two widths has no single base (`numLitUnionBaseName` is "") and its `1` member is compared by
base rather than by value. The `i64` receiver of the same union runs since D3590.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| `const d: i64 = 1` | prints `true` | **yes** (the `i32` receiver) |
| `type C = 1 \| 2` | prints `true` | **yes** (two widths) |
