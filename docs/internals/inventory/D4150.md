### D4150 — an un-annotated literal binding delivered into a recursive-alias list `J[]` builds invalid wasm

**check-clean invalid wasm · clause 1 on master · filed 2026-10-11 against master `66f24dbe6` · found by #3563's review (probes `d02`/`d01`)**

Repro:

    type J = null | string | J[]
    const xs = ["a"]
    const k: J[] = xs
    print(k.length)
    // vl check: rc 0.  vl run: failed to parse WebAssembly module, type mismatch: expected (ref $type), found (ref $type)

Want:

    1

#### Mechanism

The binding `xs` is a literal list that adapts to the first destination it is delivered to. A
destination whose element is a union with a list arm of its own recursive alias is not
a position the delivery knows how to widen, so `xs` keeps its `string[]` rep and the module is
invalid at the store. #3563 turns this into a loud container-widening refusal (fixture
`tests/cases/unions/error-recursive-alias-list-into-list.vl`); once it lands, that fixture
should point here, and the row should be re-graded as clause 2 only if the refusal is not the one the
non-recursive spelling already gives.

#### Ablation

| --- | --- | --- |

`J[]` destination at argument, return, field and push positions.
