### D17087 — a top-level record binding's IR cell is noted at its checked type's rep, not at legacy's storage row

**closed · 1 start of tests/cases (`start uncovered argument coercion`), closed 2026-11-24 against master `89ce9eefe` (filed against `a79dae1d9`)**

Repro:

    // file: a.vl
    export type W = { z: boolean, x: i32 | string }
    export function poke(self: W): i32 {
      self.x = "s"
      return 0
    }
    // file: b.vl
    export type V = { y: i32, x: i32 | string }
    export function poke(self: V): i32 { return 1 }
    // file: entry.vl
    import { W, poke } from "./a"
    import { V, poke } from "./b"
    function g<T>(v: T): i32 { return v.poke() }
    const i = { y: 2, x: 9 }
    print(g(i))
    print(i.x + 1)
    // vl run: 1, 10.  VL_IR_SHADOW=1 after #9772: `start uncovered argument coercion`

Want:

    1
    10

#### Mechanism

`globalRep` notes the cell of `const i` at the rep of its checked type (`scopeTyAt`), whose record
has no legacy struct (`structIndexOfTy` -1), while legacy stores the cell at the binding's storage
row, `letBindTy` — `./b`'s `V` row (D14760). Once a direct call delivers a struct parameter at
legacy's declared row (#9772's `calleeParamTy`), `g(i)` asks for the global at `V`'s row. The
verifier reads a global only at its noted rep, and `recRowRetag` finds no heap for the checked rep,
so the start falls back to legacy, which emits the same bytes. Probe at the miss: cell rep 7, scope
rep 7, storage-row rep 6, delivery rep 6. The close is the initializer storing a record cell at its
storage row where legacy does (`globalInitValue`).

#### Close

`globalRep` holds a record global whose checked rep has no struct heap at its storage row's rep
(`letBindTy`) where that has one (`cellAtStorageRow`), as its initializer stores it. A read of a
field the row stores as a union box, where the read keeps it plain, is legacy's unbox tail
(`ir_build_ref`'s stored-row field read). The start is covered, verified and matched; a top-level
`let` and a closure read of the same global are too; an annotated binding of the literal's type is
refused by the checker on both seeds (only a fresh record widens into `V`).
