#### Mechanism

The parameter `x` is inferred from the delivery to `J`; the list literal is passed as `string[]`
and boxed into the `J` union without the list arm being recognised, so `is J[]` tests false. A
list value that fits the arm must answer `true` under the structural `is` ruling.
