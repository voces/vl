### D4151 — a list delivered through an un-annotated parameter to a recursive alias `J` answers `is J[]` false

**check-clean silently wrong · clause 1 · the un-annotated-parameter face of [D4150](D4150.md) · filed 2026-10-11 against master `66f24dbe6` · found by #3563's review (probes `c07`/`d08`)**

Repro:

    type J = null | string | J[]
    function g(x): J { const j: J = x; j }
    const r = g(["a"])
    print(r is J[])
    // PRINTS false

Want:

    true

#### Mechanism

The parameter `x` is inferred from the delivery to `J`; the list literal is passed as `string[]`
and boxed into the `J` union without the list arm being recognised, so `is J[]` tests false. A
list value that fits the arm must answer `true` under the structural `is` ruling.
