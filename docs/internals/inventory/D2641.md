### D2641 — an un-annotated record literal whose field is a map-typed name has no interned shape

**loud emit reject · clause 2 · pre-existing on master `a2d2ca88f` · found by the
`container-null-fill-map-*` matrices' un-annotated `struct_field_init` cells · filed 2026-09-26
against master `a2d2ca88f`**

Repro:

    const o: {[string]: i32} = Map()
    const w = { f: o }
    print(1)
    // vl check: rc 0.  vl build: emitProgram: ref valtype with no interned shape

#### Mechanism

Not traced. The record literal's shape `{f: {[string]: i32}}` reaches the type section with its
map field's ref valtype pointing at no interned struct. A `Map()` constructor as the field value
(`{ f: Map() }`) runs, and so does the same literal under an annotated binding, so the missing
step is the shape intern for a map field whose value is a NAME: the map row is keyed off the
constructor or the annotation, and this literal has neither. The value type does not matter
(`i32`, `i32 | null`, `string | null`, a record), though the sentence varies: with a later read
of the field some spellings refuse `object literal matches no union variant` instead.

#### Ablation

| the value type `i32` replaced by `i32 \| null` or `string \| null` | still refuses | no |
| a second field `g: 1` added | still refuses | no |
