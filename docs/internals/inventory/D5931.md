### D5931 — a lambda literal in a function body handed to a hole callee at a different function type in each instance is refused at emit

**loud emit reject · `vl check` rc 0 · clause 2 · found closing [D5881](D5881.md) · filed 2026-10-17 against master `3e78365df`**

Repro:

    function two(a: i32, b: (n: i32) => i32): i32 { b(a) }
    function twof(a: f64, b: (n: f64) => f64): f64 { b(a) }
    function outer(h, x) { return h(x, (n) => n * 2) }
    print(outer(two, 3))
    print(outer(twof, 1.5))
    // vl check: rc 0.  vl run: emitProgram: this lambda is handed on at two different function types, and one lambda literal has one signature

Want:

    6
    3

#### Mechanism

From the ablation only. The lambda literal is one function shared by every instance of
`outer`, and it is pinned in place at the first instance's function type; the second instance
wants it at another, and one literal is not copied per instance.
