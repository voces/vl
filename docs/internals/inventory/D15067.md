### D15067 — a written binding of a generic set spread into a push onto a list of a closed function type is refused at emit

**loud emit reject · clause 2 · `the reassigned function binding f holds functions called at more than one argument type` · found ablating the literal positions of `written-fn-binding-two-types-delivered-by-value.vl` · filed 2026-11-03 against master `5ba642c3`**

Repro:

    function id<T>(x: T): T { return x }
    function loud<T>(x: T): T {
      print("loud")
      return x
    }
    function main() {
      let f = id
      print(f(1))
      print(f("s"))
      const ys: ((x: i32) => i32)[] = []
      ys.push(...[f])
      f = loud
      print(ys[0](40))
    }
    main()
    // vl check: rc 0.  vl run: emit error, with the split plan on and off

Want:

    1
    s
    40

#### Mechanism

Not located. A spread of a list literal holding the written binding is delivered to the list's
closed element type without an adapter per element, so the set stays one closure called at two
types. The same binding pushed directly, `ys.push(f)`, runs.
