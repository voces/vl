### D15067 — a written binding of a generic set spread into a push onto a list of a closed function type is refused at emit

**closed 2026-11-03 · runs, prints `1` `s` `40`, with the split plan on and off · was a loud emit reject, clause 2, `the reassigned function binding f holds functions called at more than one argument type` · `checkListPushArgs` (check_member_call.vl) types a spread list literal at the destination list and delivers each element through its adapter (`fvaAdaptListLit`), as a direct push delivers its value · fixture `tests/cases/closures/written-binding-of-generics-spread-literal-pushed-onto-closed-list.vl` · the spread of an inferred binding is D15069 · filed 2026-11-03 against master `5ba642c3`**

Repro:

    function id<T>(x: T): T { return x }
    function loud<T>(x: T): T {
      print("loud")
      return x
    }
    function main() {
      let f = id
      print(f(1))
      print(f("s"))
      const ys: ((x: i32) => i32)[] = []
      ys.push(...[f])
      f = loud
      print(ys[0](40))
    }
    main()
    // vl check: rc 0.  vl run, before: emit error, with the split plan on and off

Want:

    1
    s
    40

#### Mechanism

`checkListPushArgs` checked a spread with the operand node but the ELEMENT types, so `fvaAdapt`'s
literal arm, which needs a list destination, never delivered the literal's elements, and the
literal kept its own type: a list of the set. The direct push adapts its value. The spread literal
is now stamped at the destination list (`recordCtxTy`, `nodeTySetGrow`) and adapted element by
element, so it is built as closures at the closed type and the push copies that list.
