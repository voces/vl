### D1683 — the covariant-write closure resolves a callee by name to a declared function, so handing the value to a function VALUE ends it and the read-only copy is declined

**closed 2026-09-06 · was a loud emit reject · filed 2026-09-06 against master `294417dc2` · D1658/D1659's residue · 0 corpus cells**

Repro:

    type Circle = { r: i32 }
    type Sq = { s: i32 }
    type Shape = Circle | Sq
    function __other() {
      const w: Shape[] = []
      w.push({ s: 3 })
      print(w.length)
    }
    function f() {
      const a: Circle[] = [{ r: 7 }]
      const b: Shape[] = a
      const take = (ys: Shape[]) => { print(ys.length) }
      take(b)
    }
    f()
    // vl check: rc 0.  vl run: prints 1.

#### Mechanism

`take` only reads, so nothing writes either list and the element-converting copy is
unobservable. The argument edge asked `cwParamName(callee, position)`, which resolved through
`cwIxFnDecl` — the first NAMED `FuncDecl` for the interned name. A lambda is a `FuncDecl` with
an empty name and is never filed there, so a call through a function-valued binding resolved to
nothing, `cwGrowCall` answered `2`, and the licence fell back on the rep-scoped scan, which
`__other`'s unrelated write had already disqualified.

`cwCalleeDeclOf` resolves the callee EXPRESSION rather than the name: the declared function the
name binds, or the lambda a once-bound, never-re-pointed `const` was initialised with — which
the arena carries whether or not the name-keyed index does. `cwParamNameAt`/`cwParamFrameAt`
are what the argument edge and the container alias edge both ask, so a lambda reached by either
gets its parameter into the alias set and a write through that parameter is found. The type is
not consulted: a function TYPE says nothing about whether the body writes, so reading the
parameter's declared type would have had to answer "may write" for every callee and would have
refused the read-only lambda this row is about. A callee whose parameter list the program does
not spell — a function-typed parameter, a re-pointed binding, a lambda held in a field — still
declines (D1687).
