### D9313 — a generic function in a record held as an un-annotated `Map()`'s value, called through `?.` after an earlier same-shaped record literal's call, has no value box

**loud emit reject · `vl check` rc 0 · `union atom has no value box` · clause 2 · found closing [D9065](D9065.md) · present on master `cf1b1a8d3` (as `unsupported map value type`) · filed 2026-10-21 against master `cf1b1a8d3`**

Repro:

    function half(a) { return a / 2.0 }
    function id<T>(x: T): T { x }
    const b = { f: half }
    print(b.f(3))
    const j = Map()
    j["k"] = { f: id }
    print(j["k"]?.f(2) ?? 0)
    // vl check rc 0.  vl run: emit error: emitProgram: union atom has no value box

#### Mechanism

Not traced. Likely the shared struct row of [D9312](D9312.md): `{ f: half }` and
`{ f: id }` have the same field names, and the `?.` call is classified through the first
literal's closure, so the `?? 0` meets an f64 where the call builds an i32.
