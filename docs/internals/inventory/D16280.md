#### Mechanism

#5774 gives a list literal's binding the closed signature its writes add (`letFnListClosedSig`)
and notes the literal closed, so `monoCoerceListLitElems` instances each element naming a
generic at it. An element that is a binding keeps the representation its own flow chose: the
captured alias is built in `frame`'s frame, whose one instance of `id` is the `string` call's, so
the call through `ys[0]` reaches `id<string>` at `(i32) => i32`.
