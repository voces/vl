### D15860 — a returned bundle bound at one member's annotated type, before a holder of the same call called at the other, is refused at check

**loud check reject · clause 2 · `cannot assign (i32) => i32 to 'v' of type (f64) => f64 (the body of \`w\` at the call's argument types)` · found closing D15748 · filed 2026-11-12 against master `5e0a0ccf6`**

Repro:

    function lap(f) {
      f(2.5)
      f(3)
      return f
    }
    function g() { return lap((a) => a + 1) }
    const v: (f64) => f64 = g()
    print(v(4))
    const w = g()
    print(w(3))

Want:

    5
    4

#### Mechanism

Unmeasured. The message names the later binding `w` while rejecting the earlier `v`, so the
annotated binding is checked against a type the un-annotated holder's call fixes after it: an
order dependence in the checker's typing of `g()`.

#### Ablation

| spelling | outcome | needed? |
| --- | --- | --- |
| the two pairs of statements swapped (`w` first) | runs | **yes** |
| `const w = g()` and its call removed | runs | **yes** |
| the annotation on `v` and its call removed | runs | **yes** |
| `v` annotated `(i32) => i32`, `w` first | runs | no |
