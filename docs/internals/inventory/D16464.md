### D16464 — a field write in a returned `if`'s arm is not spilled, so a write whose value is not its target's type refuses

**closed 2026-11-15 · runs, prints `6` · was loud emit reject, clause 2 (`an assignment used as a value whose type is not its target's has no value lowering`) · fixed in `spillValueWrites` (`emit_rewrite.vl`), which spills a returned value `if`'s arm tails as `spillTail` spills the tail `if`'s · fixture `tests/cases/conditionals/return-if-lowers-as-tail-if.vl` · found grading D16460's close against its tail twin's disassembly · filed 2026-11-15 against master `41739762`**

Repro:

    type O = { f: i32 | null }
    function w(o: O, c: boolean) {
      return if c { o.f = 5 } else { 2 }
    }
    print(w({ f: null }, true) + 1)

Want:

    6

#### Mechanism

An assignment yields its right side, which a re-read of a field delivers at the field's rep, not
the value's (D2170). The rewrite spills such a write, `const v = 5; o.f = v; v`, where it is a
function's value: `spillTail` walks each arm of a tail `if`, and `spillValueWrites` a `return`
whose value is the write itself. A returned `if` was neither, so its arm reached emit unspilled.
The returned value `if` now spills its arm tails through the tail's walk (`spillIfTail`).
