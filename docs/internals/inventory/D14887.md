### D14887 — a hole lambda handed through an identity in a function nothing calls, and used nowhere else, is refused at emit

**loud emit reject · clause 2 · `vl check` rc 0 · `emitProgram: monomorphize: unsupported argument type for f in a call to fw` · pre-existing, the same with rung B · found ablating D14885 · filed 2026-11-01 against master `5aacb348`**

Repro:

    function fw(f) { return f }
    const lam = (x) => x
    function deliver() { return fw(lam) }
    print(1)

Want:

    1

#### Mechanism

`deliver` is never called and `lam` is used nowhere else, so nothing gives `lam` a closed
signature: no call, no delivery to a declared type, and no instance in the elaboration. Mono still
builds `deliver`'s body and has no pin for `fw`'s parameter. A value nothing reads needs no
particular instance, so any one builds a correct program.
