### D3750 — the list-op receiver resolver staged only a field, a call or (for `.push`) an index, so `.clear`/`.pop`/`.get` on any other list-valued expression was refused

**closed — the witness prints `0` · was loud emit reject (`.clear receiver must be a local or struct field`) · sunpa SP-044 · lane SP · filed 2026-10-06 against master `082c36f12`**

Repro:

    const l: i32[][] = [[1], [2]]
    export function clr(): i32 {
      l[0].clear()
      l[0].length
    }
    print(clr())
    // vl check: rc 0.  master: emit error, `.clear receiver must be a local or struct field`.

Want:

    0

#### Mechanism

`listOpRecvLocal` (wasmEmit.vl) resolves the receiver of `.push`, `.pop`, `.clear`, `.get(i)`
and the fused `.pop() ?? d`. A bare local is used in place. A global, a capture, a field and a
call are staged once into the op frame's `recvRef` scratch slot. An `Index` receiver was
staged only when the caller passed `allowIndex`, and only `.push` did. Every other expression
(`(xs)`, `(m.get(k) ?? ys)`, `(if c { a } else { b })`) fell to the refusal, for every op.
The scratch frame was never the gap: `listOpRecvStages` (emit_classify.vl) already reserves
it for every receiver that is not a bare identifier. The resolver now stages every
non-identifier receiver, and `allowIndex` is gone.

#### Ablation

Graded by `l` × op × element type, each cell printing a value read back through the original
container. 22 cells refused on master (element-of-list ×3 ops ×2 faces of the global, a
parenthesised list ×4, an `if` value ×4, a `??` value ×8). With the element type as an axis
(i32, f64, i64, boolean, string, record, nested list, u8; annotated and inferred), 165 of 256
cells refused on master and all 240 type-valid cells run after. The 16 left are `u8[]` with an
inferred `[[7, 8]]`, which is `i32[][]`: a check reject the design owes.

| receiver | `.push` | `.pop` | `.clear` | `.get` |
| --- | --- | --- | --- | --- |
| local, global, capture, field, field of an element, call | runs | runs | runs | runs |
| `l[0]` | runs | **refused → runs** | **refused → runs** | **refused → runs** |
| `(l)`, `(if c { a } else { b })`, `(m.get(k) ?? d)` | **refused → runs** | **refused → runs** | **refused → runs** | **refused → runs** |

Maps were graded at the same positions (`set`, `[k] =`, `get`, `has`, `delete`, `length`,
`keys`, `values`): all ran on master. `m.get(k).clear()` is a check reject the design owes
(the receiver is `T[] | null`), and `Map` has no `.clear`.
