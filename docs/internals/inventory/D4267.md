### D4267 — `is` over record arms whose shared field is a nested record only some of whose values fit is refused at emit

**loud emit reject · clause 2 · follows D4056: before it the union itself was refused · found by the review of #3579 · filed 2026-10-12 against master `3efb1763c`**

Repro:

    type A = { v: { x: i32 } }
    type C = { v: { x: i32 | string } }
    function f(u: A | C) {
      if u is A { print("A") } else { print("C") }
    }
    const c1: C = { v: { x: 1 } }
    const c2: C = { v: { x: "s" } }
    f(c1)
    f(c2)
    // vl check: rc 0.  vl run: emitProgram: `is` across record arms whose shared field holds a value only some of which fit, outside a union box

Want:

    A
    C

#### Mechanism

`C`'s field `v` is a record whose own field `x` fits `A`'s only for some values. The cross-arm
test compares a scalar field against a literal set, or answers a box field by its tag; it does
not descend into a nested record.

| this witness | emit refusal |
