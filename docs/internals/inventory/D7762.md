### D7762 — a top-level function read as a value before its declaration was never demand-inferred

**closed 2026-10-20 · runs, prints `2` · was `loud check reject` (`cannot infer a return type for 'use'`) only with `inferReturnsPrePass`'s whole-module sweep removed; master's pre-pass inferred every function first · clause 2 · pin: `tests/cases/functions/forward-function-value-inferred.vl` · filed against master `573358403`**

Repro:

    function use() {
      const g = f
      return g(1)
    }
    function f(n: i32) { return n + 1 }
    print(use())

Want:

    2

#### Mechanism

Demand inference ran only at a call (`checkCallOnFuncTy`, `ufcsInferCallee`, operator
dispatch). A bare read of `f` as a value returned its hoisted `TyFunc` with the return still
pending (`-2`). Calling it through `g` then gave `TY_ERR`, so `use` had no basis for its return.
`checkIdentNode` now infers a pending top-level function at a value read too, unless the
function is already on the inference stack.

#### Ablation

Pre-pass sweep off, before the fix. Master runs every row.

| delivery of `f` | outcome |
| --- | --- |
| `const g = f`, then `g(1)` | `use` cannot infer |
| `[f, g]`, then `fs[1](2)` | `use` cannot infer |
| `id(f)` bound, then called | `use` cannot infer |
| `apply(f, 2)` against a declared function parameter | runs |
| `[1, 2].map(f)` | runs |
| `return f` under a declared function return type | runs |
