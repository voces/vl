### D14647 — a function list written through an alias or a parameter, re-pointed, or held in a record field, is refused at check when the results differ

**loud check reject · `cannot write 'half' to an element of 'xs'` · clause 2 · open · the direct spellings `xs.push(half)` and `xs[0] = half` run ([D14645](D14645.md), [D14646](D14646.md)), so the refusal is the gap under D3975 (A), not a design rule · found closing D14646 · filed 2026-10-29 against master `5ea95968`**

Repro:

    function inc0(a) { return a + 1 }
    function half(a) { return a / 2.0 }
    const xs = [inc0]
    const ys = xs
    ys[0] = half
    print(xs[0](3))
    // Want: 1.5

#### Mechanism

`elabFnListLetTy` (check_elab_cap.vl) widens a list binding's set over the writes its own scope
makes through its own name, and `holeSlotJudge` lifts its comparison only for a binding so
widened. Measured with the comparison lifted for every written element: a write through an alias
traps (`indirect call type mismatch`), a parameter's write and a re-pointed `let` refuse at emit,
a record's list field builds `ref valtype with no interned shape`, and a map index write refuses
(`scalar map read has no value-box type`). Each needs its writes joined into the set the
binding's reads carry before the judge can lift for it.
