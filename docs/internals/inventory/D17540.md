#### Mechanism

The write's value is typed `i32` (`asgValueArmOf` `boxedArm`: the stored box unboxed to the
value's arm), but the interpolation hole formats a union and its box plan is `pass`, which takes
a box as is. Legacy writes the unboxed `i32` where the plan expects the box.

#### The close

Where the hole's box plan passes a box and its value is the unbox of an assignment's parked box,
the IR passes that parked box itself (`parkedBoxOf`), read under the hole's union (`RStage`). The
claimed build prints the `Want:` under `VL_IR_STRICT=1`; the claimless build still writes invalid
wasm, so `scripts/ir-divergence-baseline.txt` lists `interp` as legacy-wrong (O3).
