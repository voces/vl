### D17090 — an assignment of `null` delivered into a union box writes the cell's typed null into the box's `i32` slot

**check-clean invalid wasm · clause 1 (`vl check` accepts it, 0 errors) · found by lane S1 grading D17088's callers · filed 2026-11-24 against #9807's head `e52f678fd`**

Repro:

    function f() {
      let s: string | null = "a"
      const u: i32 | null = (s = null)
      print(s == null)
      print(u == null)
    }
    f()
    // vl check: 0 errors.  vl run: invalid module, `type mismatch: expected i32, found (ref null $0)`

#### Mechanism

`exprIsNulNone` (`emit_classify.vl`) names a value of the `null` unit for a read, a call, a `?.`,
a value `if` and a `??`, but not for an assignment of `null`. So a union box destination does not
take the `null` unit's box (`emitNulNoneBoxPayload`), and the assignment's value, the cell's own
typed null, is boxed as if it were the arm's payload.
