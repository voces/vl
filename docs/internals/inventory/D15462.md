### D15462 — a value `if` joining an un-annotated parameter with a named function traps when the named function's arm runs

**open · loads then traps, `vl check` rc 0, `vl run`: `wasm trap: indirect call type mismatch` in `go`, clause 1, with the split plan on and off · found probing the flow table's join edges (`ffJoin2`) after the fn_flow_shadow audit's deletion · filed 2026-11-05 against master `34b01a716`**

Repro:

    function inc(x) { x + 1 }
    function dbl(x) { x * 2 }
    function go(k: boolean, f) {
      const h = if k { dbl } else { f }
      print(h(1))
    }
    go(true, inc)

Want:

    2

#### Mechanism

The value `if` joins the parameter `f`, whose type is an open hole, with the named function `dbl`.
The join keeps the hole beside the function type (`_ | ((i32) => i32)`) instead of binding the
hole to it, so the instance of `go` types `h` at the parameter's closure signature while the `dbl`
arm delivers a value of another one, and the indirect call through `h` traps. With an annotated
`dbl` the same join reaches the checker, which refuses the call: `called value is not a function
(_ | ((i32) => i32))`, a clause-2 refusal of the same program.

#### Ablation

| ingredient changed | outcome | needed? |
| --- | --- | --- |
| the arm taken is `f` (`go(false, inc)`) | runs, `2` | **yes** (the named arm runs) |
| `f` handed `dbl` itself (`go(true, dbl)` against `if k { f } else { dbl }`) | runs | **yes** (another function) |
| `dbl` annotated `(x: i32): i32` | check reject, `called value is not a function (_ | ((i32) => i32))` | no (another face) |
| `f` annotated `(x: i32) => i32` | runs, `2` | **yes** (the open parameter) |
| `h` annotated `(x: i32) => i32` | runs, `2` | **yes** (the inferred join) |
| a `let h = dbl; if k { h = f }` instead of the value `if` | runs, `2` | **yes** (the value `if`) |
| the join called in place, `(if k { f } else { dbl })(1)` | loud emit reject, `cannot take the generic function `dbl` as a value` | no |
