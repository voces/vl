# IR coverage step: a short packed (u8) list literal, 2026-11-19

Lane F2. A coverage step under `ir-design-2026-11.md` §10, after the ref-list step (#9121), on
which it was stacked; measured on fixpoint seeds of this branch and master `d1de0b7d4` (`ca5cd449b`).

## Why this class

The self-compile's blocker census put `array u8` at 68 functions it alone keeps uncovered, and 121
first-misses. The corpus holds few packed list literals.

## What landed

- **One shared tail.** `arrLitPackedShortTail` writes the packed backing at a row's
  `pkBackAt`, its length and capacity, and `pkWrapAt`'s wrapper; legacy's `emitArrU8` ends
  through it, and its chunked build through `arrLitLenCap`.
- **The IR.** `arrayLit` takes the `u8` arm within `arrLitShort`'s cap, each element delivered
  at the unpacked i32 rep (the backing truncates, as legacy's `emitExpr` of each element does);
  `makeList` writes the shared tail at the build pair's packed row.
- **Where it covers.** The self-compile's packed literals are almost all empty `[]` (279 of 286),
  built at a returned or argument destination; a non-empty one still misses at its delivery's
  coercion (`return coercion`, `argument coercion`), which this step does not touch.
- **No mirrored decision.** Legacy's u8 arm takes every element through `emitExpr` and chooses
  only by length, which is `arrLitShort`'s own cap; the IR's `for`-iterable exclusion only makes
  it miss.
