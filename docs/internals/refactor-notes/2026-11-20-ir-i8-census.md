# The I8 census: every population, claimed and first misses (2026-11-20, lane IR-D1)

ir-design §10.3 sets I8's precondition as 100% claimed on every population, not only the
corpus. Until now the claim census read only the self-compile and the distilled corpus. This note
measures all five populations §10.3 names, and the legacy drivers each one reaches.

## Commands

```
scripts/ir-i8-census/census.sh build/vl-compiler.wasm <out>      # claimed share, first misses
scripts/ir-i8-census/summary.sh <out> 15                         # the summary below, re-read
CENSUS_PROGRAMS=<out>/programs.txt scripts/ir-driver-census.sh build/vl-compiler.wasm <out>/drv.tsv
```

`census.sh` builds a throwaway compiler with one extra row per function: `fnc <name>` for a
claimed function, `fnu <name> | <first miss>` for one that is not. Every program then runs once
with claiming on, as shipped (`$VL_IR_SHADOW=5`). The census counts:
- **Distinct functions:** a std function carries its module in its mangled name (`$m<id>`), so it
  counts once however many files use it. An entry module's functions count per file.
- **Start bodies:** `@start` and `@init` are counted apart from functions.
- **`read of <name>`:** one class. It is `identRead`'s last return, a name that is neither a local,
  a global nor a function. In practice it is a captured variable read inside a nested function or
  lambda, and the raw rows split it by variable name.

`witnesses.vl` writes the `Repro:` of every inventory row filed `runs` (both inventories) as files.

## What a fully claimed program still needs from legacy

A throwaway compiler had legacy's 14 expression and statement entry points emptied to an
`emitFail`: `emitExpr` and kin, `emitStmt` and kin, `emitFuncBody` and `emitWidened`. It was not
committed. Of the programs the census calls fully claimed (every function and start body claimed):

| population | programs with functions | fully claimed | still need legacy | build with legacy gone |
|---|---:|---:|---:|---:|
| distilled | 9,053 | 4,139 | 1,955 | 2,184 |
| tests/cases | 7,269 | 1,678 | 453 | 1,225 |
| probes | 279 | 53 | 19 | 34 |
| witnesses | 4,971 | 1,442 | 360 | 1,082 |

Every one of the 2,787 that still need legacy fails at the same place: `emitConstCellInit`, the
global section's constant initializers (`const a = 1` is enough). None fails in a claimed
function's lowering, so no claimed function reaches the 14 entry points through a re-entry. The
const cell writer is a module pass that §10.1(b)'s staging does not name.
