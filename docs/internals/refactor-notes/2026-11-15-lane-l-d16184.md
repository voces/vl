# An assignment's value over a `K | null` local is its atom, D16184 — 2026-11-15

Lane L, lane D's D16184 (unowned).

## Mechanism

An assignment used as a value is lowered as a store, then a re-read of its target, so its value
is an atom exactly when the target is (`exprIsLitAtom`, D2168). That test asked for the target's
literal members (`litAtomMemberTy`), which a `K | null` niche target does not answer, so the
classifier said "not an atom" while the re-read pushed one. Each consumer then took the atom for
the value's own rep: a string return built an invalid module, `print` printed the atom's number,
and a call's result failed the narrowing.

## What moved

- A re-read `K | null` niche target makes the assignment's value an atom (`exprIsLitAtom`'s
  assignment arm, two lines); the existing delivery widening turns it into the member's string.
  `wasm-dis` of the witness: the function returns the member string, no `i32` reaches the result.
