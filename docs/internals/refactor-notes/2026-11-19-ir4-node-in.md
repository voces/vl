# IR seam: `irLowerNodeIn`, the legacy-to-IR door (2026-11-19, lane IR4)

The op seam's second direction: a legacy writer lowers one node through the IR, in legacy's frame,
so that legacy's own arm for a family can delete before I8 (§5.2, §10). The frame rules are
[2026-11-19-ir-seam-frame-model](2026-11-19-ir-seam-frame-model.md), item 2.

## The door

`irLowerNodeIn(ix, fnIx, ty): string` (`ir_build.vl`) builds node `ix` as an expression fragment
of function `fnIx`, verifies it, and lowers it onto the buffer legacy is writing, at the stack
position legacy's writer leaves its value. It answers `""` when written. Otherwise it answers the
miss and has written nothing: the buffer is cut back, its relocation rows trimmed (`relTrim`) and
the dead-function callees popped. A caller whose arm is deleted reports a miss with `emitFail`.

- **Rep.** `ty` is the type legacy's writer builds the node at (-1: the node's own). A fragment
  whose value is at another rep misses `fragment rep`. The armed count found 18 occurrences that
  differed without this check: `const xs: f64[] = [self]` with `self: i32`, where legacy builds at
  the holder's type and writes `f64.convert_i32_s`.
- **Variables.** Variables are legacy's slots: `declVarAt` reads `declaredIndexAt(fnIx, slot)`, the
  slot `localIndexOf` answers. A parameter is registered as the whole-function build registers it,
  except that a parameter the IR could not hold is left out, so only reading it misses.
- **No locals, no seats.** A temp is consumed on the stack at its one use; the fragment's value
  consumes what the body left pending, as a `return` value does (`fragmentBody`). No seat is read
  or set. `ctrlDepth` must come back as found (`fragment control depth`), and a fragment that would
  return misses (`fragment return`).
- **Rows** bank as legacy's writers bank them, at offsets in the buffer written. An element read's
  row is banked only where the `vl-src` section is written, else noted for the shadow (`shIdx*`), as
  `emitIndexBanked` does. A statement's row is always banked.
- **Nesting.** The builder's state (`IbFrame`, `ibSave`/`ibRestore`) and the lowering's
  (`LwFrame`, `lwSave`/`lwRestore`) are saved around the fragment and restored on every exit. So
  the door may be entered from inside a claimed function's lowering, through a re-entry that is
  still open.
- **Hosts.** A `FuncDecl` (not a template), or the start body while legacy writes it
  (`gPromoInStart`), under the guards `buildStart` takes (`string accumulator`, `progress cell`).
  Anything else misses `fragment outside a body`. The global context is legacy's live one
  (`globalCtxNow`).

## The instrument

`irNodeInShadow(ix, fnIx, ty, from)` is the per-occurrence count a deleting slice is graded on
(§10, "Fully matched is counted per occurrence"). Under the armed shadow only, it lowers the
fragment into a scratch buffer with `probe` set: no rows banked, and callees and `uBoxNewEnd` put
back. It compares the result with the bytes legacy wrote from `from` on, and counts
`node-in <kind>: matched`, `differ` or `miss <why>`. Mode 2 adds both byte strings to a `differ`.
The first site wired is `emitArr` (list literals, F2's slice), typed at `arrLitBuildTyOf`, which is
split out of `arrLitListBuild`. That site is measurement only: no arm deletes in this PR.

The list-literal count over `cells/` and `named/` (12,301 cells, armed, master 93c5fe0f1 plus this
branch):

| row | occurrences |
|---|---|
| matched | 1,540 |
| differ | 0 |
| miss fragment outside a body | 1,532 |
| miss rep map | 1,011 |
| miss array ref | 1,005 |
| miss expression object | 412 |
| miss array spread | 248 |
| miss pre-path tag leaf | 202 |
| miss rep null | 104 |
| miss rep closure | 83 |
| miss fragment rep | 67 |
| other misses | under 60 each |

`fragment outside a body` is top-level code outside the start body's promotion window
(`gPromoInStart`), such as a global's constant initializer. The start body itself hosts fragments,
which added 188 matched.
