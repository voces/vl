# IR coverage: v128 as a value rep, and the SIMD intrinsics as one op (2026-11-20, lane IR-N7)

The blocker census over `tests/cases` at 2ebfe622 has 2,391 v128 rep rows: `parameter rep v128`
831, `rep v128` 705, `result rep v128` 691 and `local rep v128` 164. Split by callee on an
instrumented copy, `intrinsic none` (3,446) is mostly not SIMD:

| callee family | functions (any) |
|---|---|
| memory load and store (`__load_*__`, `__store_*__`; #9310's) | 2,239 |
| memory management (`__heap_base__`, `__memory_size/grow/fill/copy__`, `__heap_limit__`) | about 700 |
| SIMD (`__extract_lane_f32x4__` 161, `__store_v128__` 37, …) | 232 |
| fs host imports, extern host functions | about 150 |

No SIMD row was ever a function's only blocker: every one also stopped at `rep v128`, and the
census stops a statement at its first miss, so the SIMD ops that produce a v128 were hidden
behind it. The rep and the ops therefore land together.

## Design

- **`v128` is already a rep.** E's arena holds it as `RPrim` `v128`, and `F32x4`, `Mask32x4` and
  every other `new v128` resolve to it, so the IR needs no new RepId kind. The builder's
  `valueRep` now admits it. `valtypeOf` answers 0x7b, so a v128 local, parameter or result is
  declared as legacy declares it, and `irSlotRunAgrees` counts 0x7b as a scalar run.
  `repIsScalar` is unchanged: no `PrimOp` is defined over v128, and `primOpcode` still has no
  opcode for it.
- **One op, `RSimd { sdArgs, sdAt }`.** Legacy's `emitSimdIntrinsic` was split around its
  operands:
  - a plan, `simdOperandPrim(row, i)` (each argument's prim, or "" for a lane or shuffle index,
    which is an immediate and no operand) and `simdResultPrim(row)`;
  - a tail, `simdTail` (the 0xFD instruction with its lane or shuffle immediates).
  Legacy and the IR both write them. Routing is `simdCallNamed`, legacy's own test (the name,
  with no binding owning it). The verifier holds every operand and the result at the row's
  prims. The plan lives in `wasmEmit.vl`, which already reads the checker's table, so the IR
  modules import no checker symbol for it (phase state unchanged).
- **A brand cast is its operand.** `v as F32x4` (`asCastArmOf`'s `plain` arm at a v128 target)
  and `v as! v128` (its `v128` arm) re-brand the same bits, which legacy writes as the operand
  alone. The builder returns the operand when both reps are v128. A union operand is a named
  miss, `vector as union`.
- `RSimd` is family `other`, so claiming does not widen.

## Left as named misses

- `simd memory access` (71 in `tests/cases`): `__load_v128__` and `__store_v128__` take their
  address through legacy's `emitMemAddr`. Once #9310's `memAddrPlanOf` lands, they take its
  `const`/`rest` arms as `RMemAccess` does.
- `expression if valtype` (1): legacy's `ifExprPlainWhy` puts a v128 value `if` on another path.
- `vector as union` (10).

## Measured

See the PR body, vs merge-base 2ebfe622 with fixpoint seeds on both sides. `tests/cases`
functions with no blocker: 54,061 → 54,920 (+859). The four v128 rep classes: 2,391 → 0.
`intrinsic none`: 3,446 → 2,906. The self-compile and the distilled corpus hold no SIMD and are
flat. The shadow row `SIMD_ROWS` (`tests/vl_ir_shadow_test.ts`) covers 12 functions over every
value-operand shape. Each is a `result rep v128`, `parameter rep v128` or `intrinsic none` miss on
the base seed.
