## The split

None of the six is a judge in group 2's sense.

| function | what it is | body part | call part |
|---|---|---|---|
| `holeLinksReset` | the per-program reset of `check_hole_links.vl`'s tables | none | none |
| `holeLinkSiteSet` | an ambient register naming the delivery whose links follow | none: it stamps `holeLinkAt`/`holeLinkSrcTop`/`holeLinkDstTop` on each row `noteHoleLink` writes | none |
| `holeLinkClosure` | a read of the `holeLinkA`/`holeLinkB` rows | the D1470 link rows, which the body's stores write (`noteHoleLink`): two open list rows that must carry one element | none |
| `holeLinkPinFrom` | one sweep step of the `__array_new_default__` fixpoint (`check_annot_resolve.vl`) | the link rows | it hands a resolved element across a link: a pin |
| `holeLink` | the union of two open children in `holeSol` (lane H, stage 2c-1), reached from `tyLinkElem`/`tyLinkKey`/`tyLinkVal` | none | it is the pin mechanism, the solver's write |
| `holeRemainderEndedSure` | whether a hole's `is` remainder is ended by a write, a call or an alias | the function's narrowing-path rows (`npFnSlotOf`, `holeElseTested`, `crRows.aliasWr`, `crRows.npKillSure`), which the body's scan writes | none |

- **The link rows are already a body record.** Each one says two open rows carry one type. That is
  an equality bound between two variables, which §2.2 spells as a pair of `BK_LOWER` bounds. S2
  moves `holeLinkA`/`holeLinkB` into the scheme with the other rows. The delivery stamp travels with
  each row, and `holeLinkSiteSet` stays the register that names it.
- **`holeLink` and `holeLinkPinFrom` are pins.** They belong to the solver, which at S3 makes the
  pins itself (design §10, M3). The 11 fit programs entering `holeLink` are pins made inside a fit
  question. They are outside group 5's question, which concerns recording. They are what S3's
  assertion (design §10) watches for.
- **`holeRemainderEndedSure` answers from the body's narrowing scan.** That scan is a per-function
  product, stable once the body is scanned. The remainder itself is a `BK_NARROW` bound's input.
