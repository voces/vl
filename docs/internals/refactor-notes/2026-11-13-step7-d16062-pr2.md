# Step 7, lane H: D16062 PR 2, class A joins the rule and the literal-arm channel goes, 2026-11-13

PR 1 (#7783) made `valueBoxOfTy` the value-union verdict, the rep tree's own boxing decision asked
of the type. It held one class back: a numeric literal set with `null` (`N | null` over
`N = 1 | 2`, class A). This PR brings it under the rule. D16062 closes.

## Class A

PR 1 measured class A both ways, on full sweeps:
- the rule at every site lost 16 programs;
- "not a value union" at every site lost 8, the D16062 witnesses.

Two further measurements found the cause, each enabling class A at the ten row-registering sites:
- **one site at a time:** only `fieldCodeOfTy` lost anything alone (1 program);
- **every site but one:** the 16 return when either `registerValueUnionNameTy` or
  `valueUnionTyIsFlat` is held back.

`valueUnionTyIsFlat` says its value union has "no literal member, which the spelling softens to its
base", but it only rejected nested unions. `N | null`'s inner `N` is a union of literals, so it
passed as flat, and `registerValueUnionNameAB` registered it by its type instead of its declared
name. The function now rejects a literal member, as its contract says. All 16 recover with output
identical to master, and `valueBoxRowOfTy` (PR 1's rule-minus-class-A wrapper) is deleted. Every
site asks `valueBoxOfTy`.

## The literal-arm channel

`registerValueUnionNameTy` admitted a union by the rule or by `nameIsLitUnionArmValueUnion(name)`,
the parse of `K | i32` that admitted a literal-union alias arm. Under the rule, such an arm is a
value box arm: it rides at the string tag. The type now decides alone. `nameIsLitUnionArmValueUnion`
has no caller left and is deleted, along with its entry in the census's parser list.

`emitNameLitUnionVerdict` (check_ret_names) stays. It decides only whether an inferred return gets a
name at check time. Since PR 1 removed the inferred-return verdict column, the emitter reads the
verdict from the return's type.

## The member-row question, named

`mintValueUnionRowOfTy` mints a row for a value box, and also for a set of literals whose rep is one
value (`"a" | "b"` is the atom, `1 | 2` is `i32`). A literal `is` test reads that row's members. That
is not a value-union question, so it is its own predicate, `litSetNeedsMemberRow`, decided over the
key text's kinds.

## Not in this PR

Lane G's slice producers banking `boxTagOfTy` (`msFreeSlicePush`, `recordUnMemTys`) lose 57
programs on their own. Every one fails in the literal-union coercion readers, which read the old
`-1` as "an atom arm". By the coordinator's ruling, G lands the producer switch and its readers
together, on top of this PR.
