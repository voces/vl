# The fresh-call copy reaches a nullable field one record down, 2026-11-11

Lane w320, stacked on #7247. Checker gate plus emit.

**The gap.** A kept maker `function mk() { { j: { f: 4 } } }` delivered at
`{ j: { f: i64 | null } }` needs its nested `f` boxed. `recCopyBoxesOnly` admitted only top-level
fields, and `rcWrapKind` refused a non-empty path, so the call was built at the wide row and the
unannotated read `mk().j.f` lost (named cell `d15247_i64_null_inner`).

**The change.** `recCopyBoxesAt` (check_fit_rules.vl) recurses into a field both sides store as a
record, bounded by `REC_STORE_DEPTH`. `rcWrapKind` (wasmEmit.vl) resolves the field's source and
destination types along the copy path with `rcPathTy`, so the converting copy boxes at any depth.

**Graded.** `scripts/capability-probes/matrix/kept-maker-delivery-nested.matrix.vl`: with #7247's
seed 44 cells run; now 125 of 125 graded run, 3 owed refusals (the annotated held cells, as in the
flat template), 0 silent. `d15247_i64_null_inner` prints 4. Fixture:
`tests/cases/structs/kept-maker-nested-nullable-field-copied-at-wider-row-runs.vl`.

**Variant destinations.** Where the destination is a union arm's variant row (`m.get("z") ?? d`
joins the map's own row with `J`), the copy names the nested row by the field's checked type
(`rcRowOfTy`), so the nested field is converted there too; regress's `d15310_annotated`,
`d15314_nest_ann_bound` and `d15314_nest_ann_coal` caught it and run.

**Rows.** D15247 closes: its witness runs, printing `4` then `4`. Its `f64_outer_null` neighbour, a
non-null `f64` one record under a nullable field, is still refused, since the copy gate widens only
into a nullable or a union.
