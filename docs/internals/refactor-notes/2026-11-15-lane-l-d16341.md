# An unwritten container stored as a map value is defaulted with its holder, D16341 — 2026-11-15

Lane L, D16341 (invalid module) and its `Set()` twin D16432 (emit refusal).

## Mechanism

`m["k"] = Map()` pins `m`'s open value to the inner literal's row, whose key and value nothing
writes. At the scope's end `flushUninferred` defaults a pending binding's open holes, but a
binding whose own row is closed is looked into only along a record path (`recOpenHolePath`), so
the inner map kept its holes; the emitter then built it at its holder's own shape and stored it
in an `i32` value slot. A `const inner = Map()` was spared: the binding is pending itself.

## What moved

- A pending binding with no record path left open defaults the containers it holds
  (`defaultUnfixed`, a no-op when there are none), as a binding of each would.
