# D14420: a `never` operand outside a dead arm

**Change.** `checkBinExprNodeReal` (`check_operators.vl`) types an operator over a `never`
operand as `never` everywhere, not only in a dead arm (D16006): the condition loses its
`inDeadArm` test and gains the two exceptions, a short-circuit operator and a string
concatenation, which already types `never` as a string and whose lowering takes it so.

**Measured.** `never-operand.matrix.vl` (new, 16 cells), master fixpoint against this branch's:
13 cells move from a check reject to runs in both faces; 0 runs → not-runs, 0 silent. Without the
string exception, `"s" + fail()` was check-clean invalid wasm.

**Size.** Net +4 compiler lines (a generalisation: the dead-arm condition is gone); pin-helper
delta 0.
