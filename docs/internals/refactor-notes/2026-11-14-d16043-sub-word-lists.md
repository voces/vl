# D16043: sub-word lists on the packed `u8[]` path (2026-11-14)

`i8[]`, `u16[]` and `i16[]` join `u8[]` as packed lists. The owner ruling (DECISIONS, "A
sub-word field of a `flat` record has storage semantics") makes all four widths storage types,
legal as a list element and as a `flat` field; D15978 built the field, this builds the list.

## Shape

- **One kind, a row per width.** `"u8list"` stays the one packed-list `VKind`; no value kind,
  list-build kind, field code or ref-list kind was added. Its heap pair comes from a row:
  `pkBackTy(row)`/`pkWrapTy(row)` (`emit_state`), rows `PK_U8`, `PK_I8`, `PK_U16`, `PK_I16`,
  each an `(array (mut i8))` or `(mut i16)` backing under the scalar list wrapper.
- **The row rides the slot.** Wherever the emitter pairs a kind with a slot (valtypes,
  lazy frames, hoist rows, field storage, `$fnsig` tokens, list builds, compare frames), a
  packed list's slot is its row, as a ref list's is its ref-list row. It is read off the
  checked type only (`exprPackedRow`, `tyPackedRow`, `repSlotOfKind`); there is no default
  width, and an unresolved row fails loudly (`pkWrapAt`).
- **The sign at the one read writer.** `fbArrayGet` picks `array.get_s` or `_u` from the
  backing's row, so no element read site can miss it.
- **`$fnsig` tokens.** A packed list's slot is optional: the bare token is the `u8` row, so a
  `u8[]` signature keys as it did before.
- **Push frames.** One push quad per row a function pushes onto (`fnPackedPushRows`), with
  push-kind bits 128, 1024, 2048 and 4096.

## Measurement

- `capability-matrix.vl` on `sub-word-list-{u8,i8,u16,i16}.matrix.vl`, master `875f5c70`
  fixpoint → this branch: `u8` 94 of 94 run before and after; `i8`, `u16`, `i16` 0 of 96 →
  94 of 94; 4 owed refusals each (the out-of-range literal, a bare `x: W`), 0 silent.
- Sweep, fixpoint seeds, 24,300 programs: 0 bytes-only movers, 0 runs → not-runs, 4 output
  movers (D16043 to runs; three refusal sentences reworded).
- Wrong-row control: a scratch compiler building every packed literal at the `u8` row makes
  `i16[]` and `i8[]` literals fail wasm validation, `i8` included, though its storage matches
  `u8`'s: each row is its own rec-group type.
- 125 `tests/cases` programs spelling `u8[]` cloned to each width: every clone runs with the
  original's output, or a width-legit one, or is refused at check by a `u8[]`-only interop
  (`bytes()`, fs, utf8) or an `as u8` cast, or is a union member (D16046).
