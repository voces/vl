# IR coverage step: a push onto a packed `u8` list, 2026-11-20

Lane F2. A coverage step under `ir-design-2026-11.md` §10, the first of the push family. Measured on
fixpoint seeds of this branch and master `47e3dc38c`.

## Why this class

`push operand coercion` held 75 self-compile functions on its own. Every one is an `i32` value
pushed onto a `u8` list, which is how the compiler's byte buffers are built. `pushRhs` delivered the
value at the list's element rep, a packed `u8` that no value delivers to, and missed.

## What landed

- **Builder.** `pushRhs` delivers the value at `i32` when the element rep is the packed `u8`. Legacy
  pushes the plain `i32` and the backing's packed store truncates it. This is the rule `arrayLit`
  already applies to a packed list literal's elements.
- **Verifier.** RListPush admits a value at `vfI32` for a `u8` element, and nothing else.
