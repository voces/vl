## Method

Each sample is one first-parent commit of `ccd16f91c..1d5177707` (908 commits). Its `compiler/` and
`std/` are archived. Master's fixpoint seed builds S1, S1 builds S2, and S2 builds S3 under
`$VL_FUEL=1`. Every sample's S2 == S3 byte for byte, so each reading is a fixpoint's. Two columns:

* **own**: S2 compiling its own `compiler/`, what the tripwire grades.
* **fixed**: S2 compiling `ccd16f91c`'s `compiler/`. It moves only with per-line cost.

Source grew 391,012 → 394,352 lines (+0.85%), so own − fixed is mostly new compiler code that is
dear to compile, not volume. Coarse pass every 15 commits, then each interval that moved over
1% was read at every commit touching `compiler/` or `std/`. One sample (`597704eca`) did not
build at S2; its neighbours bracket it.

Together +7.1 G of the +12.2 G. No other measured interval moved over 1%; the rest is drift
spread over the history.

* **#7056.** `unionNameOfRead` asks `regUnionNameOfTy` per read, and that re-renders the type's
  union key each time. At master it is 1.42 G inclusive. This PR memoises it per type id, stamped
  with `tyRegGenNow`, and clears it beside `tyRegMemoReset`. A first cut without the reset failed
  the sweep (123 runs → not-runs). `--batch` compiles many programs in one instance, the
  generation restarts per program, and type ids are reused.
* **#6716.** Not a thrash. `crMayBeWritten` asks a module binding under the program root (D2401),
  and the first such question in a module builds the writer analysis of the whole module: a
  linear walk, once per module. A two-root cache measured 80.24 G against 80.20 G, so it is
  not kept. The cost appeared when the compiler's own source first narrowed a module binding in
  a large module, which is why only the own column moved.
* **#6542.** `repNeverCanon` is memoised, but every call runs `rtSync` first, at every recursion
  level. Not yet cut.
