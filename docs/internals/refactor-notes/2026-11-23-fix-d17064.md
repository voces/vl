# Fix D17064: an operator over a `never` operand works at its other operand's width (IR-C1)

**Defect.** The operator is itself `never` (D14420), so `binNumWidth`'s pair rule had no answer for
it and fell to i32, and so did `widenPlanOf` for its destination. An f64 or f32 operand then reached
`i32.mul`, and the module failed to validate when that operand came after the `unreachable`.

**Change.** `neverBinWidth` (`emit_plan_union.vl`) returns the other operand's prim for an operator
with exactly one `never` operand. `binNumWidth` (`wasmEmit.vl`) uses it for the op, and
`widenPlanOf` uses it as the plain source kind of that operator's value. `fail() * x` with `x: f64`
is now `call; unreachable; f64.convert_i32_s; local.get x; f64.mul; return`. The convert is the dead
widening of the `never` operand, and the module is valid. The IR builds only the i32-sibling form
(#9692), whose plan and bytes are unchanged.

  and a `never` list element and `**` are refusals the design owes. None is invalid wasm.
