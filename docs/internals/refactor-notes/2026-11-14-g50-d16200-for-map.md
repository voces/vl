# D16200: a `for` loop variable over a map of maps reads its inner map's values at the map's type, 2026-11-14

Lane G, stacked on #8023 (D16121).

`for k, inner in mm` binds `inner` to each inner map. `monoRetypeMapReads` types the loop
variable's reads at the inner map's type. Unlike a `const` alias, it did not recurse into the
reads of that map's own values. A loop variable is no binding `monoReadLetFrame` resolves, so the
recursion's binding test could not name it either. `inner.get("a")` kept its open type, and the
call through it had no ABI signature.

## Change (`emit_mono`)

- `monoRetypeMapReads` recurses for a loop variable holding a map, as it does for a `const` alias.
  The loop variable's name comes from its loop.
- `monoReadIsBinding` matches a read of a loop variable by its declaration (`identDeclOf`). Before
  this, a loop variable declaration matched no read.
