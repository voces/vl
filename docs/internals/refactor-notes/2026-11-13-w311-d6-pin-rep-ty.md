# Step 7 D6: a cloned pin carries the type its spelling was minted at, 2026-11-13

Lane F, under lane D. Measured at master `ad5abe1b`.

## The parse

`recordClonedNodeTyFb` typed a cloned pin node by `nameToTy(name)`, parsing the pin's spelling.
It is reached through `synthTypeRefFb`, from `monoSynthPinRef` when the pin's type is open, in 146
programs. In 131 of them the name resolves, and in all 131 the resolved type equals neither mono
column (`pinTys`, `pinOwn`) for that pin.

Forcing control: replacing the resolution with -1 lost 129 runs, all refused with "a pinned
parameter has no resolved type to key its instance by". The parse carried information mono held
nowhere else.

## Where the spellings came from

A probe tagged every `pinned.push` site, and three sites cover all the resolving programs:

| mint site | programs | spelling | type the spelling names | now |
| --- | --- | --- | --- | --- |
| `monoPinHoleParam`, tagged set or id map | 124 | `fnTagListRepName(setTy)` or `monoPinSpellShaped(monoTagMapRepTy(setTy))` | `fnTagRepTyOf(setTy)` | derived at the synth point from `pinTys[pj]`: `monoPinRepTyOf` |
| `monoPinAnnotatedParam`, a list of ids → `T[]` | 5 | `fnTagListRepName(listSet)` | `fnTagRepTyOf(listSet)` | same |
| `monoPinHoleParam`, `pinned.push(an)` | 4 | from `monoArgPinName(args[i], ctx, [0 - 1])` | the type output that call discarded | captured as `anRep`, and used as `anTy` when the arm's type is still open |

Of the four, one is D16022's carried fallback: `tests/cases/closures/generic-list-to-unannotated-param.vl`
(`fb=(()=>void)[] ty=((T) => T)[]`, an uncalled generic in a list literal). No closed type exists
there. Its parse moves to its own arm in `monoArgTyNameRep`, beside D16022's floor, as the one
parse the row keeps (lane D's ruling).

## What changed

- `monoSynthPinRef(name, ty, held)` and `synthTypeRefFb(name, pos, tyFb, held)` carry the held
  type. `recordClonedNodeTyFb(n, held, pin, tyFb)` takes the held type in place of the name.
- `monoPinRepTyOf(pt)` returns a tagged set's or list's id rep (`fnTagRepTyOf`) and an id map's
  stored map (`monoTagMapRepTy`); -1 for any other type.
- A `PIN_NONE` pin with no held type is a loud floor: "a pin spelling carries no closed type".
  The `PIN_ANON` and `PIN_SIGKEY` branches, the twin-record rung and D16022's floor are
  unchanged.

Forcing control for the floor: an arm whose `monoPinRepTyOf` always returns -1 fires the floor in
127 programs, all runs → not-runs with its message, and moves nothing else.

## Measurement

- **Sweep:** fixpoint seeds, master `ad5abe1b` → this: all 24,221 the same (0 bytes-only movers,
  0 output movers, 0 runs → not-runs, 0 new traps).
- **Render-parse census:** totals are unchanged. The one `nameToTy` site moves from
