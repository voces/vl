# IR P1: `print` through one decision and legacy's own tails, 2026-11-16

Lane IR-C. M1's census named `call of a non-declaration` as the d3290 grid's co-blocker. A
throwaway that named each callee showed it is the builtin `print`, not a closure call:
- in the corpus, 2,958 functions name `print`, and 317 are held by it alone;
- `fromCodePoints` follows (2,362, none alone), then `f64bits` and `f64fromBits` (337 alone);
- let-bound and global-hook closure calls hold about 17 corpus and 14 self-compile functions
  alone.

By the coordinator's ruling the order is `print`, then `f64fromBits`/`f64bits`, then 2c-2, then
I8c. The closure calls stay named misses. `CLAIMED` stays empty, and no emitted byte moves.

## What landed

- **`printArmOf` is `print`'s decision.**
  - `emitCallCorePrint` dispatches on one `PrintArm`, in legacy's order: the `null` word, the
    ref niche, a narrowing lifted to the box, the map read, the atom niches, the string and
    boolean niches, the union dispatch, the string stream, then one scalar import each for
    `f32`, `f64`, `i64`, `bool` and `i32`.
  - Its tails are shared: `printStrTail` streams the string's code points and flushes, and
    `printScalarTail` calls the arm's host print import. The scalar tail is an exhaustive
    `match` that refuses a non-scalar arm by name.
- **`RPrint { pnV, pnAt }`**, in the `call` family, is a statement only, like a `.pop()`. It is
  built where:
  - the callee is the builtin (no declaration owns the name, and no template hole is pinned);
  - the arm is a string or scalar one;
  - the argument is at that arm's rep.

  Every other arm is a named miss (`print <arm>`).
- **Output is legacy's writers.** Float text comes from the host's `__print_f64__` and
  `__print_f32__`, the same imports legacy calls, so `-0` prints `0` (ECMA-262's `String`
  rule, recorded in `perf-landscape.md`), `NaN` prints `NaN`, and `2e+300` prints as is.
- **A nested list has no `print` arm.** The checker refuses it by contract ("print expects one
  scalar or string value"), so there is no writer to share.
- `PrintArm` is registered as a closed set in `compiler/lint.vl`, and `pnV` in its field tables.

## Pins

Each is a shared witness, one covered function matching legacy:
- a built string;
- f64 values `-0`, `NaN` and `2e+300`;
- an f32, an i64, a boolean, and an i32 followed by a bare `return`.

The void tail-call witness's callee now holds an array literal, so it stays the one covered
function in its program.
