# IR verifier: the last 16 legacy queries become noted facts (2026-11-22, lane IR-D1)

This closes D17049. After #9592 and #9629, ir_verify.vl still imported 16 helpers from 8 legacy
modules. These facts belong to a node, a variable or a rep rather than to one Rhs the builder
constructs in one place, so they are noted by one pass instead of at each constructor:
`irNoteVerifyFacts` (new module `ir_verify_facts.vl`, which imports legacy). It runs right
before every `irVerify`: the builder's six call sites go through `irBVerify`, and the runtime
helper's goes through `ir_helper.finish`. The verifier reads the results from `IrFn`:

| fact | IrFn field | replaces |
| --- | --- | --- |
| checked type of a global or field read's node | `irFactTy` | `nodeTyAt` |
| memory op void, literal-arms reads, narrowed map unbox, `null` kind | `irFactInt` | `memOpIsVoid`, `memOpPlanOf`, `litArmsReadsOf`, `narrowedMapReadOf`, `NULL_OWN_BOX`, `NULL_OWN_NONE` |
| a record's site type per layout position | `irFactKidTy` | `structFieldBoxTy`, `variantFieldBoxTy` |
| valtype of each rep compared stored alike (variables' reps and kids, the result, record fields, returned operands) | `irRepValtype` | `closureHeld`, `fbValtype`, `wTarget`, `rlWrapIdx`, `rlSlotOfTyOrTwin`, `tyRefArrElemOf` |
| an open variable's open parts are held functions | `irVarHeldIds` | `tyOpenHeldAsIds` |

`refRepValtype`, `repStoresAs`, `openRepTakes`, `undeclaredRepTakes` and `irTyHeldOpen` move
verbatim to ir_verify_facts. The builder and ir_build_ref import them from there. The verifier
keeps `irTyOpen` and `irUntypedClosure`, plus two fact-reading twins, `vfOpenTakes` and
`vfHeldOpen`. A fact the pass did not note reads as "none" (no valtype, no type), which is the
stricter answer, so a missed note can refuse but never admit.

The measurements are in the PR body.
