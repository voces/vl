# L2: the instance vector, recorded and read by nothing, 2026-11-16

STORE stage (a)'s input, per the approved design note. The approved key is the callee declaration
plus a binding vector over the callee's type variables (declared, then holes; unbound → `never`).
It is a vector over type variables, not parameter types, because a variable only the result
carries (`mk<T>(): T[]`) would otherwise be lost. STORE owns the closure and its consumers.

## The change

`instVecNote(ix, namedFn, rNames, rTys)` in `callFtyPinCstrs` (check_calls), after
`withUnboundAsNever`. `rNames`/`rTys` are the call's constraint binding (`cNames`/`cTys`) plus
`never` for each declared type parameter a parameter names and nothing binds. The table lives
beside the per-call bind rows (check_bind_rows) and is emptied with them. It records only from
the body check (`monoRecheckDepth == 0`, `!inferQuiet`), so a generic caller's vector holds its
own variables: the instance closure substitutes through it rather than reading re-check output.
A call through a function value records callee -1 and stays open until S3.4d's arrow rule.

Readers: `instVecAt`, `instVecCount`, `instVecIxAt`, `instVecCalleeAt`, `instVecNamesAt`,
`instVecTysAt`. Nothing calls them yet; A0's shadow is the first.
