# D16278 layer 1: a place handed on is stamped where the decision decides it, 2026-11-15

Lanes J and M. J found the rooting half; M the typing half, built on J's `lane-j/d16278-layer1-direct`.

## Mechanism (measured)

With J's rooting fix (`ftHandedHolder` recursing through a field or element) and the one-result
judge lifted, the direct form stored tag ids but failed at emit ("a call through a function set
has a result with no rep"). The call `v[i].f(3)` inside `take` was `<error>` because its instance
was the wrong one:

- mono pins the hole parameter at the argument's id rep, `{f: i32}[]`, in both forms;
- the bound form's `L` carries that rep as a held stamp (`fnTagHeldNote` through
  `fnTagPlaceRep`), so `elabPinsUnheld` reads the pin as the argument's own rep and the call's
  own instance (key 0, at `{f: (_) => _}[]`) takes it;
- `mk().a` had no stamp, so the elaboration minted a second instance at the rep (key 3,
  `?take.0 = {f: i32}[]`), where `f` is no function and the call is `<error>`.

Found with a scratch compiler, never refreshed into `build/`, in four steps:
- a trap at the post-freeze write, built `--names`, which led to `monoPinRecordTy` and `elabWalkTy`;
- a key dump (`ekNames`/`ekTys`);
- `elabDemandFrom`'s branch inputs (`elabCkHeldUsable`, `elabPinsUnheld`).

## Change

- **`ftHoldCtxOk`** (check_fn_tag.vl): a field or element read, or a named call's result, handed to a
  hole parameter joins the decision's held places. **`fnTagHeldNote`** (check_elab_cap.vl) stamps
  such a place with `fnTagPlaceRep`, as it stamps a binding of one, so emit's existing reader
  (`elabArgHeldRep` → `heldRepOf`) finds it. No new reader, no mono change, `emit_mono` 908.
- **`fnTagPlaceRep`** walks through an unwritten binding with no stamp whose initialiser is a call
  of a named function (`take(r.a)` with `const r = mk()`). A first version that walked any
  initialiser broke `nested-record-of-hole-fn-list-written-whole` `map_set` (an invalid module), so
  it stops at a name copy and a method call.
- **The one-result judge** (check_relate_core.vl) lifts a place read straight off a call
  (`holeSlotCallArgJudge`), a returned literal's field through an element, and a field read through
  a binding a call initialises (`holeSlotCallBound`).
- **`elabParamRowRoot`** (emit_elab.vl, outside the slot-store sections): a `for` over an
  un-annotated alias of the parameter walks the parameter, D15920's alias rule applied to D16279's
  loop rule. Without it the lifted judge turned D16278's own witness (`const v = a`) into a trap.
  Its bound twin trapped on master: [D16233](../inventory/D16233.md).

Net compiler lines: +48 / −9 (+39).
