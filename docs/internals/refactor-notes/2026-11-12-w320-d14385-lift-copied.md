# D14385's interim refusal skips a delivery the fresh-call copy converts, 2026-11-12

Lane w320. Stacked on #7446 (D15723). Check only.

**The defect (D15724).** `recKeptFnOwnCalls` (check_program.vl) refuses every other call of an
un-annotated function whose result one delivery builds wide, where the destination boxes a part the
result does not. A list-of-records result delivered at `{ f: i32 | string }[]` was queued by
`recWideListNote` and refused, though `recFreshCallCopy` had already recorded the delivery as a
copy, which leaves the body built at its own type.

**The change.** `recCallCopiedAt` skips both queues' entries whose delivery the copy converts: the
delivery carries a copy record and the copy's own rule (`recCopyBoxesOnly`) admits the pair. The
rule is re-checked because `recordListCopy` also writes `listCopyTyIx` at a call; keyed on the
table alone, D14385's own witness (a list of row unions) built invalid wasm.

**Proof.** The plainest programs D14385's refusal forbids, one per member shape: a scalar into a
union field already ran; a list result with a union field now runs; a record into a record-union
field, a list of numbers into a list of a union, and a list of row unions stay refused (no copy).
`kept-maker-list-result-delivery-union.matrix.vl`: 46/46 graded (0 before), 20 skipped as in the
`| null` list-result template. Fixture `kept-maker-list-result-union-field-copied-runs.vl`.
