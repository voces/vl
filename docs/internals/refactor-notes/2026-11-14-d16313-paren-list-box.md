# A union-coerced list is classified by the literal under its parens (D16313), 2026-11-14

Lane B, the first fix from the fuzz soundness census (`2026-11-14-fuzz-soundness-census.md`).

## What changed

`coerceValueAtomKind` (wasmEmit.vl) chooses the value-atom code a value boxes at when it enters a
union. Its list arms (`exprStringArray`, `exprF32Array`, `exprF64Array`, `exprI64Array`,
`exprU8Array`, `exprArray`) asked the delivered node, which under parens is the `Paren` node; that
node keeps the literal's own type (`string[]`) while the literal itself adopted the destination's
member (`K0[]`). They now ask `bareIx`, the paren-stripped node, as the ladder's other arms
(`memReadUnboxAtomKind`, `exprBoolListCode`) already did. Net compiler lines +2 (+8 / −6),
pin-helper delta 0.

## Evidence

- The witness and the three fuzz findings print their `@log` value; `((["rj"]))` (two parens)
  too, which master also got wrong. The scalar `("rj")`, a `string[]` member, `f64[]`, `i64[]`,
  `boolean[]` and a parenthesised list binding print the same as on master.
- `regress.vl` against master's fixpoint seed: `fz_d_witness` runs (its baseline line moved to
  `runs`); no other cell moves.
