# D16052 closed: a row-less member slice has no atom column, 2026-11-14

Lane G. After #7928, `sharedUnionFieldPlan` (emit_classify) was the only consumer of free-set
atoms. It read them twice:

- `msTextOf(setId)`, the rendered set text, tested only `!= ""`;
- `msMemberAtomsOfSet`, used for the member count and an `atoms[i] == "null"` skip beside the
  member types it already read.

Both now read types. The narrowed branch gates on `setId >= 0`, the count is `atomTys.length`,
and `null` is tested by type. The two `unionMemberSetOfRow` label gates stay for lane D's
`unRowBySid` PR.

That leaves the following with no reader, so they are deleted:

- `msTextOf`, `msSetText` and `msRenderSet`. `msSetIntern` matches sets by mask, so the text
  was never set identity.
- `msMemberAtomsOfSet` and `msSliceAtom`.
- `msFreeAtoms`.
- `canonUnionMembersLitsInto`.

`msFreeSliceOfTy` now builds the slice from `canonUnionMemberLitsOf` (types and literal flags;
the walk keeps its labels inside it). The free kind column records only what its three readers
ask: whether a member is `null`.

## Probes

- **`sharedUnionFieldPlan`.** Over 24,020 programs, 404 programs reach the member reads,
  11,177 calls in all: 0 length differences between atoms and types, and 0 differences between
  `null` by atom and `null` by type. On the narrowed branch, 49 programs make 1,686 calls, and
  `msTextOf(setId) != ""` never disagrees with `setId >= 0`.
- **The free kind column.** The canon walk pushes the atom `"null"` exactly where the member
  type is -1, or for the `null` primitive's render. So kind 0 by atom equals the type test
  `t < 0 || tyPrimNameIs(t, "null")`.

## Census

The render-parse census no longer finds the `msFreeSliceOfTy` → `canonUnionMembersLitsInto`
site. Its floor line is retired, the parser is dropped from the census's lists, and the
baseline's carried-floor count for emit_union_registry goes 1 → 0.
