# IR coverage, batch 10: a push receiver read with legacy's strict payload cast (2026-11-24, lane IR-N9)

Legacy sets `listCastForPush` while it writes a `.push` receiver, so `listPayloadCastTail` casts a
narrowed list arm strictly (a plain `ref.cast` that traps) rather than leniently (a stand-in empty
list a push would lose, D4949). `recvReadsListPayload` names the receivers whose read takes that cast.

- The builder (`pushRecvExpr`, ir_build.vl) notes each temp it creates while building such a
  receiver (`irPushRecvNote`, a per-temp key on `IrFn` beside `irCloFieldRetag`).
- The lowering (`tempRhsWrite`, ir_lower.vl) holds the flag only while one noted temp's own RHS is
  written: it reads the flag (`pushRecvCastOn`), sets it (`pushRecvCastSet`) and restores what it
  read, in locals, so it adds no module state and no saved emitter state (phase-state hidden stays
  17). Both accessors are new in wasmEmit.vl and called only by the IR.
  A temp is written lazily at its single use, so nothing else is written under it.
- Legacy's own push sites are unchanged.

## Legacy tails the IR calls

- `pushRecvCastSet(on)` (wasmEmit.vl): sets or clears `listCastForPush` around one push-receiver
  temp's write. Callers: the IR lowering's `tempRhsWrite` only.
- `pushRecvCastOn()` (wasmEmit.vl): reads `listCastForPush`, so `tempRhsWrite` restores the value it
  found rather than clearing it. Callers: `tempRhsWrite` only.
