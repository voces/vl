# IR step I0: types, verifier and a phase-A shadow, 2026-11-15

Lane I. This is step I0 of `ir-design-2026-11.md` §5.3, in the scope agreed with the L1 design lane. Measured on fixpoint seeds:
master `1020438b5` and this branch.

## What landed

- `compiler/ir.vl` (315 lines): the §1.2 node set, the per-function arena (`IrFn`) and a printer
  (`irFnText`).
  - There are 21 right-hand sides and 15 statements; §1.2's `SBr`/`SReturn` value is an `brHas`/`rtHas` flag beside the operand.
  - `RepId` is the `emit_rep.vl` tree id, `repIdOfTy`, until lane E's stage 1 lands the type.
  - `RCoerce` carries `CoerceKind` and a `TyId`; `coercionAt` lands at I3, with its first caller.
- `compiler/ir_verify.vl` (638 lines): rules 1–8 of §2. Rule 9 waits for the first pass that
  moves a check.
  - A verdict names the rule, the node and the reason. The verifier never reports through
    `emitFail`.
  - It is linear: a nested body's exit undoes its own definitions from a log.
- `compiler/ir_build.vl` (690 lines): a phase-A builder over I1's set, which is constants, `PrimOp`,
  locals, `if`/`while`/`break`/`continue`/`return`, `&&`/`||`, direct calls of declared,
  capture-free functions, and globals. Any other construct or rep leaves the function
  uncovered, with a counted reason.
  - The rep tree gives `void` the flat `i32` rep. The builder therefore takes `never`'s
    `RNoValue` for a void result.
- **The seam.** `emitFuncCode` calls `irShadowFn` after a function's legacy lowering, but only when the shadow
  is armed. It builds the function, verifies it and discards it. Nothing is claimed, so there is no dual emit
  and no `irClaimed` table yet.
- **Arming.** `irShadowArm` and `irShadowCorrupt` are seed exports. The native host arms the shadow under
  `VL_IR_SHADOW=1` and prints one `[ir] <path>: <n>\t<row>` line per row. The variable is a cache
  bypass. A verifier failure's row carries the printed function.
- `tests/vl_ir_shadow_test.ts` has four tests.
  - A program inside the set builds and verifies, and its armed output equals its unarmed output.
  - Two failing controls must fire: a swapped rep must fail rule 3, and a deleted temp definition must fail rule 4.
  - A program outside the set is uncovered by reason.
