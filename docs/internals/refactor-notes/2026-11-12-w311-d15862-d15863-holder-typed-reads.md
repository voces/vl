# D15862, D15863: annotated reads of a holder's copy and of a module-scope holder, 2026-11-12

D15749 lets an annotated binding of a bundle holder's read take the member its type names. Two
neighbouring spellings were refused at emit. In the first (D15862), the binding reads a copy of
the holder: `elabHolderCopiesHold` (`emit_elab.vl`) counted a copy's reads only as calls, hands,
returns and copies, so the annotated read left the count short. It now also counts the copy's
annotated reads, requires each to name a member (`elabTypedReadsHold`), and
`elabHolderRecordWith` records that member as it does for the holder's own reads. In the second
(D15863), the binding sits in a named function and reads a module-scope `const` holder.
`elabTypedReadsHold` admitted only the holder's own function and lambdas nested in it. Like the
copy test, it now admits a module-scope `const` from any function.
