## Cut

**`collectARefArrayAnn`.** Whether the annotation is the nullable ref list was
`nullablePartOf(spelling) != "" && tyIsNulRefArray(type)`. It is now `tyIsNulRefArray(type)`. The
peeled spelling had one reader: the kind fallback, taken when the type declines the element. For a
nullable list that fallback is now not taken. A declined element is a type parameter or a union of
lists. Neither is a niche, so the one reader of the kind, the niche-element check, does not fire.

**`cboxElemNeedsParens`.** A cell element is parenthesised when it is a function type. That is now
read off the element's type, not by finding a top-level arrow in its spelling. The union half (a
top-level `|` when the annotation has no atom count) is unchanged.
