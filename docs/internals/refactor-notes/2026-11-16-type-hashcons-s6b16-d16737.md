# Type hash-cons stage 6b: the value-chain walks without a hop budget, D16737 (lane H), 2026-11-16

`mfr_shadow.vl` holds three walks that follow a read back through bindings, arguments, returns and
literals: `mfrLeafHeldFn` (stopped after 8 hops), the `mfrDescend*` family (16) and the `mfrChain*`
family (24). D16737 is the last: a generic function taken as a value at the end of a 25-alias chain,
or a 128-deep chain of functions returning their argument, read as "link unknown", and emit refused
it as a value although its calls pin it.

Each walk now carries the route it is on instead of a count.

- `mfrLeafHeldFn` and `mfrDescend*` keep a path of nodes; a node met again on the route answers what
  the exhausted budget did (-1 and false).
- `mfrChain*` keeps (node, steps left) pairs. A read can reach one node twice on a route with
  different steps (a map read and a field read), so a node alone is not a cycle. The same steps again
  is a cycle; more steps than an earlier visit is a loop that lengthens them. Either answers "link
  unknown". Different steps no longer than every earlier visit's go on, so a route stays finite.

distilled cell (`d16121_argument_unann`) moving. The worktree's master already moves that cell, so
graded against its own fixpoint the branch moves nothing.
