# 2026-11-15 — lane L: `FC_V128`, a vector as a struct field (AE-004)

- New field code `FC_V128 = 38`. Both rep-derived ladders, `fieldCodeOfRep` (emit_fc_shadow)
  and `fieldCodeOfVKind` (emit_field_codes), already named `"v128"` as declining, and they now
  answer it. The code therefore comes from the rep, the form rep stage 3c derives. Beyond those
  two ladders, the only per-code arms are the valtype byte (emit_bytes, `0x7b`) and
  `anonCodeIsSelfContained` (emit_shape_rows).
- Ablated from a first cut, each with no witness or matrix cell needing it: the arms in
  `funcTypeFieldCodeSafe` (emit_shape_intern) and the eq-rows code-to-kind table. Removing the
  shape_rows arm breaks an anonymous record and a lambda returning one.
- Checker: `tyNestsV128` stops counting a bare struct field (it recurses as the nullable arm
  does), and `isEquatable` answers `false` for a `v128` primitive, so record `==` over a
  vector field is refused at check rather than at emit.
- Net compiler lines +23, no new functions; `emit_mono.vl` unchanged (908).
