# L1 deleted: the instance reads of an open type, re-counted on master, 2026-11-12

`ARCHITECTURE.md` §7's L1 line (§3.5, §4.1) could go once every emitter read of a type holding
type parameters, made while an instance is emitted, was either converted to `nodeTyAt(x, fnIx)`
or classified by design (`2026-11-12-l1-instance-reads-classified.md`). The 17 converts that
classification named are on master: #7330, #7243 and #7334. This note re-runs its two probes on
master `30871c538` to confirm none remains, and records the by-design readers that stay.

## Method

The same two probe compilers as the classification, generated by the same rewrite of every
one-line `nodeTyIxOf(x)` call in `compiler/emit_*.vl` and `wasmEmit.vl`. Each is built into
scratch by a master fixpoint seed and never refreshed into `build/`.

- **Reach** marks a site whose type holds a type parameter while an instance (`$` in
  `emitCurFnIx`'s name) is emitted.
- **Difference** marks a reached site only where `nodeTyAt(x, emitCurFnIx)` is a different,
  closed type.
- **Controls:** a generic `first<T>` called at two types marks sites in both probes, and a
  program with no generic marks none and runs.

Population: the sweep's 23,954 programs.

## Result

The difference probe on master, before this PR, marks **44** sites in 3,633 programs. 43 are
the classification's by-design sites whose instance type differs. The 44th is a convert it could
not see:

| site | function | programs | grade |
| --- | --- | --- | --- |
| `emit_shape_rows.vl:3485` | `arrLitNulRefElemKind` | 2 | convert, in this PR |

#7334 moved `arrLitNulRefElemName` to the instance type. Its paired kind reader stayed on the
template, and it reads only where the name answers, which before #7334 was never at an open type.
It now reads `nodeTyAt(arrIx, fnIx)`. The two programs that reach it,
`generics/declared-nested-list-result-at-union-pin.vl` and
`generics/record-nullable-type-param-list-field-literal.vl`, build byte-identical modules before
and after, and the seed grows by 2 bytes.

With the convert, the reach probe marks **67** sites in 3,666 programs, and **0 converts**
remain. All 67 are by design:

| class | sites | was (classification) |
| --- | --- | --- |
| the instance type never differs | 24 | 26 |
| a resolver, or a reader that also asks the instance type | 21 | 21 |
| an openness gate | 19 | 19 |
| a `…Tpl` function, by contract | 2 | 2 |
| storage built from the template (`nodeTyIsUnionRow`, D14487) | 1 | 1 |

Two of the classification's "never differs" sites are no longer reached at an open type:
`arrLitArenaRecElem`'s first read and `collectAArrayLit`'s. Every other site is the
classification's, at its current line.

- `bindGenWalk`: 2 call lines in `emit_mono.vl` and 22 in `emit_elab.vl`;
- `monoArgTyName`: 6 call sites, its definition aside.
