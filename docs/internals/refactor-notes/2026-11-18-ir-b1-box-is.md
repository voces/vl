# IR B1: a box's `is` test of a variant row, and the `box` family claimed, 2026-11-18

Lane IR2. The self-compile's door is a boxed-union local and its `is` test. B0 and B0b made
legacy's `is` ladder one decision (`isArmOf`) with exact plans; this step lets the IR take its
last rung, `variant`, where legacy answers by the box's tag alone, and claims the new family.

## What landed

- **`valueRep` admits a union box (`RBox`)** for locals, parameters, results and expressions.
- **`RTest { teV, teTarget }` is built for one shape** (`boxTest`). Each condition is a shared
  decision legacy itself reads:
  - `isArmOf(ix, fnIx, 0, false)` answers `variant`, and `isRecvStageRep` stages nothing;
  - `isBoxGuardPlain`: `emitIs` hands the test on over a plain read, with no storage read and
    no every-member tautology;
  - `isVariantTagPlain`: a tested row no other member shares, no static fold, no cross-tag fit
    and no discriminant field. `emitIsTestVariant` takes this path first, so the decision is
    one.

  Everything else is a named miss (`is staged`, `is rung`, `is guard`, `is variant shape`).
- **The lowering** writes the receiver, then `variantTagTail`, the tag compare legacy's tag
  rungs share. `variantNeedsDiscrim` is `emitVariantDiscrimTest`'s own test, lifted.
- **`RTest` is the `box` family, and `box` is claimed.** A box local is a reference slot, which
  `claimable()` admits since `list` is.
