# IR: `Map()` and `Set()` build an empty map, 2026-11-19

Once a map was a value rep (#9181), a `Map()` or `Set()` call still missed as `rep map`: the
builder had no arm for it. An instrumented scratch build named the first `rep map` miss in each
self-compile function on master `d32521247`, and the `Map()`/`Set()` call was the largest
population (226).

## The change

- `mapNewCall` (wasmEmit.vl) is the `Map()`/`Set()` test, and legacy's `emitCallNode` now
  dispatches on it. It answers false for a user function named `Map` or `Set` (D975).
- The builder builds `RMapNew` for the same calls. The lowering of `RMapNew` already existed: it
  is legacy's `emitMapNew`.

Compiler lines are +17 −10, 7 net (`ir_build.vl` +5, `wasmEmit.vl` +12 −10). No legacy line is
deleted; legacy's inline `Map()` test moved into the shared `mapNewCall`.
