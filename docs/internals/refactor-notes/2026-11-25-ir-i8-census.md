# The I8 census, re-measured (2026-11-25, lane CENSUS)

Ruling O1 (`orchestration-reset-2026-11-25.md`) makes the I8 census the programme's scoreboard.
It was last measured on 2026-11-20 at 6851d881 (`2026-11-20-ir-i8-census.md`). This note is the
same census over the same five populations, about 600 merges later.

## Commands

```
scripts/ir-i8-census/census.sh build/vl-compiler.wasm <out>         # claimed share, first misses
scripts/ir-i8-census/summary.sh <out> 30                            # the tables below
scripts/ir-i8-census/class-programs.sh <out> 15                     # per-class program lists
CENSUS_CLASS=scripts/ir-i8-census/classes/<slug>.txt \
  scripts/ir-i8-census/census.sh build/vl-compiler.wasm <out2>      # a census cut to one class
```

The seed is a fixpoint of master 7eddff27: a second `refresh-compiler.sh` was byte-identical
(`cmp`). The full census took 3 min 8 s wall and 5 min CPU on a 4-core box at `JOBS=4`, so a
daily run costs little.

## The census script

`class-programs.sh` derives the per-class lists from a census directory. `census.sh` takes
`$CENSUS_CLASS` and cuts each population to one list. On `box ladder`, the cut census reproduces the
master census's counts (5 / 39 / 10 distinct functions in distilled / tests/cases / witnesses). The
cut run exposed a latent bug in `census.sh`. Its `xargs` ran `vl check` with no paths when a
population was empty, and that checks the whole tree. `xargs -r` fixes it.
