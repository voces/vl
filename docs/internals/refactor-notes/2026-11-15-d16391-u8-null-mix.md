# D16391: a `u8[]` spread joined with `null` is refused as every other `u8` mix is, 2026-11-15

Lane B. Net compiler lines: +3 / −0 (+3). Pin-helper delta: 0.

## Change

`checkSpreadArrayLit` (compiler/check_container_lits.vl) queues a spread literal for the u8-mix
refusal (`flushU8MixLits`, D1852) when its element joins to a union holding `u8`. A `null`
element joins `u8` to a nullable, not a union, so it slipped past and the literal reached the
emitter, which refused it (`a spread whose elements must each be boxed into a union or nullable
element has no lowering yet`). The same predicate now also queues a join to `u8 | null`. The rule
and the sentence are the existing ones: `u8` is only an element type, so no list holds this join.

## Graded

On fixpoint seeds of the base and of this change:

- `[...s, 300]` is still refused at check;
- `[...t, null]` over an `i32[]` still runs.
