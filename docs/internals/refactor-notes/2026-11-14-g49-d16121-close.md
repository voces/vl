# D16121: a value set into an un-annotated map is delivered where that map's values are, 2026-11-14

Lane G. Closes the row the containment in #8018 left open, and retires that containment.

`m4` holds the un-annotated `half` and is set into `mm`. The only call reads `half` back through
`mm.get("k").get("a")`. The elaboration's delivery walk follows a read of `m4` through a list or
record literal, an assignment into an element, and a call's parameter. It did not follow
`mm.set("k", m4)` (outside a call search). So `m4`'s slot was delivered nowhere, `half` closed at
the uncalled default, and the read-back call had no instance at its signature.

## Change

- **`emit_elab`**: `elabSlotAliasOn`'s argument arm follows a value set into an un-annotated map
  binding (`elabSetRecvDecl`) to that binding's `v` slot, at the same remaining path. An
  annotated holder is already delivered at its value type by the check's stamp
  (`elabReadStampsAt`).
- **`emit_mono`**: `monoStoredMapFnsUncalled` and `monoMapValuesRead`, and the map-of-maps arm's
  decline that used them, are deleted. The pin-helper baseline goes 910 → 908.
- A check-side note of the call at the inner map's slot (`fnSlotCallNote` through the outer map's
  stored values) was tried first and is not needed: with the delivery alias alone the witness, its
  lambda-beside spelling and the trap cell run.
