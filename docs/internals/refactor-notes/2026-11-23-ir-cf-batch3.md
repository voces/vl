# IR: control-flow batch 3, 2026-11-23

Lane IR-N4, control flow. Base: master 930dc5c5a. Each class was ablated to a minimal witness
before the change. Legacy writes every case below already; the IR now builds the same bytes.

## Change

- **Else-less value `if`.** Legacy writes the missing arm as the join's own null. For a union box
  that is the null tag (`emitUnionIfValueLink`), also where a destination's union coercion takes
  the join (`emitUnionCoerceUnder`'s `IfStmt` arm, now `unionCoerceIfArmOf`). For a reference
  join it is the kind's typed null (`emitIfExprRefLink`), and for an atom or `boolean | null` join
  the `i32` niche (`emitIfExprAsLink`, now `ifNoElseNicheOf`). The IR asks
  `elseLessUnionIfWhy` and `ifNoElseNicheOf`, which legacy also calls. `ifExprShapeWhy` keeps its
  `no else` for a destination-typed link; `ifExprPlainWhy` lets the other rungs through.
- **Staged leads.** A binary operator's left operand, and a record literal's earlier fields off
  the order stash, are staged below a valued `if` anywhere in the later operand, as an earlier
  argument already was (`irBStageLeads`). The minimal witness was `a + id(if c { 5 } else { 1 })`.
- **A start body's bare block.** The guard from #9356 kept it legacy's, because a claimed start
  body minted closure globals out of order. All 32 programs it blocked are byte-identical claimed
  and claimless (`ir-identity.sh --claimless`), so the guard goes.
- **A decided `is` in a value or tail `if`.** Legacy reads the constant back from its bytes
  (`staticValueIfCond`, `emitGuardCond`). A value `if` writes its dead arm as `unreachable`; a tail
  `if` writes an empty then, or no `else`. The scalar chain, the reference and union links and the
  tail `if` build those. A list test read through a fit shadow stays a miss, as in the statement
  `if`.
- **A valued `break` out of a `for`.** Only `while` and labelled-block frames are typed
  (`lvFrameOpen`). Legacy writes a `for` loop's `break v` as the assignment before it and a plain
  `br`.
