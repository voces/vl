# IR: control-flow batch 3, 2026-11-23

Lane IR-N4, control flow. Base: master 930dc5c5a. Each class was ablated to a minimal witness
before the change. Legacy writes every case below already; the IR now builds the same bytes.

## Change

- **Else-less value `if`.** Legacy writes the missing arm as the join's own null. For a union box
  that is the null tag (`emitUnionIfValueLink`), also where a destination's union coercion takes
  the join (`emitUnionCoerceUnder`'s `IfStmt` arm, now `unionCoerceIfArmOf`). For a reference
  join it is the kind's typed null (`emitIfExprRefLink`), and for an atom or `boolean | null` join
  the `i32` niche (`emitIfExprAsLink`, now `ifNoElseNicheOf`). The IR asks
  `elseLessUnionIfWhy` and `ifNoElseNicheOf`, which legacy also calls. `ifExprShapeWhy` keeps its
  `no else` for a destination-typed link; `ifExprPlainWhy` lets the other rungs through.
- **Staged leads.** A binary operator's left operand, and a record literal's earlier fields off
  the order stash, are staged below a valued `if` anywhere in the later operand, as an earlier
  argument already was (`irBStageLeads`). The minimal witness was `a + id(if c { 5 } else { 1 })`.
- **A start body's bare block.** #9356 kept it legacy's for one reason. Claimed, the start body of
  `tests/cases/closures/sibling-fn-blocks-module-level.vl` minted its closures' two globals ahead
  of the constant ones, where legacy mints them after. The armed shadow matched it, and
  `ir-identity.sh --cases` found the difference. That program is now byte-identical claimed and
  claimless, as are the other 31 programs the guard blocked (`ir-identity.sh --claimless` over
  that list). The proof's `--cases` run (claimed against claimless over all of tests/cases and the
  probes) and `--claimless` run (distilled cells and witnesses) cover the whole corpus. So the
  mint order a claimed start body gives now agrees with legacy's, and the guard goes.
- **A decided `is` in a value or tail `if`.** Legacy reads the constant back from its bytes
  (`staticValueIfCond`, `emitGuardCond`). A value `if` writes its dead arm as `unreachable`; a tail
  `if` writes an empty then, or no `else`. The scalar chain, the reference and union links and the
  tail `if` build those. A list test read through a fit shadow stays a miss, as in the statement
  `if` (`decidedIsShadowed`). That guard reads `emptyFitPlanOf`, whose shadow arm is
  `listNarrowReadDisjoint`, a walk of the tree and the checker's types. It reads no table legacy
  fills while it emits; the emit-time table, `listFitShadowSet`, is what the guard keeps out.
- **A valued `break` out of a `for`.** The writer is `emitBreakStmtStmt`. It writes a
  `local.get` of the result binding only where a typed frame sits at the target's depth, and only
  `lvFrameOpen` (`while` and labelled blocks) pushes one. A `for` loop's `break v` is therefore the
  assignment before it, then a plain `br`. Witness: `tests/cases/loops/loop-value-runs-out-returned.vl`.
  Its `hv(n)` returns `for i in 0 until 4 { if i == n { break "b" } }` and logs `b` when the break
  carries the value and `null` when the loop runs out. All 5 of its functions are covered and match.
