# L2: what D16898 needs from check, scoped, 2026-11-17

SLOT handed slot-store stage 3 to L2: class readers that read facts fixed before mono must keep
[D16898](../inventory/D16898.md) running. The coordinator asked for a scope before anything is
built. Measured on master `d7a6bf679`, plus SLOT's refuted branch `slot-bprime-1` (class readers
read node types, annotations and bounds as of the freeze).

## What check already knows

Check's types, read by giving each value a wrong annotation and reading the diagnostic:

| expression | check's type |
| --- | --- |
| `__m`, after `__m.set("k", { m: Map() })` | `{[string]: {m: {[_]: _}}}` |
| `__mv` | `{m: {[_]: _}}` |
| `v.m`, after `v.m["k"] = { f: inc0 }` | `{[string]: {f: (_) => _}}` |
| `__m`, at the end of the program | `{[string]: {m: {[string]: {f: (_) => _}}}}` |
| `inc0` as a value | `(_) => _` |

- **The map holes are shared.** The write through `v` closes `__m`'s inner key at check.
- **The one part check leaves open is `inc0`'s own signature.** `inc0` is never called; it is
  only stored.

**So the whole gap is one fact:** the signature of an un-annotated function that is only taken
as a value. Close it, and freeze-time readers keep both gate cells running. No interface
inference for `__m`, `__mv` or `v` is needed; check already has those.

## Where master's answer comes from

On master `inc0` is emitted as `(i32) -> i32`. Mono's comment on `monoInstantiatedAny`: "a
template nothing instantiated still emits its body at the i32 default, and that body is only
accidentally valid". The witness runs because the value is served by `inc0`'s uninstantiated
template at that default, and mono's own pin of `v` lets its class readers accept it.

## The decision this needs (not L2's to make)

What type does an un-annotated function have when nothing calls it and nothing closes the slot
it is stored in?

1. **Make today's default a rule at check.** Each un-annotated parameter of a function that is
   only taken as a value gets the default mono emits (`i32` here; for a parameter an operator
   constrains, the same default the program-end flush gives an open hole). Check records the
   closed signature, so a freeze-time reader sees it, and mono's template emission matches.
   - D16898 and both gate cells keep running.
   - The cost: a program whose stored function is later called through the slot at another
     type would be checked against that default. Today mono decides that call late.
2. **Refuse at check**, asking for an annotation, like the value-floor refusal's own advice.
   - Clause 2: it turns three running programs (the witness and both cells) into refusals.
3. **Leave it to mono.** Stage 3's freeze-time readers then have to exempt hole functions taken
   as values, which is the S3a shape SLOT measured losing 13 `runs`.

L2's recommendation is option 1, scoped first to functions no call site instantiates and taken
as values only. Before building it, L2 would measure how many corpus programs hold such a
function and at what default each runs today.
