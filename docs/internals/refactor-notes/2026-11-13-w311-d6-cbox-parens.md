# Step 7 D6: a captured cell's element is parenthesized by its type, 2026-11-13

Lane F. Measured at master `31f92f78`.

## What changed

`cboxElemNeedsParens` decides whether a captured cell's element annotation is wrapped in parens
before `[]`. A function type or a union is wrapped. For an annotation the emitter minted, which has
no atom count (`annUnionAtomsOf` < 0), it searched the spelling for a top-level `|`
(`tyTopIndexOf`). The census grades that site source, but the spelling is emitter-minted by
construction (#7815).

Now the element type answers: a `TyUnion` or a `TyNullable`. The spelling parameter is gone. A
minted annotation with no element type has nothing to answer by and is a loud floor.

**Forcing control:** an arm that withholds the element type makes the floor fire in all 3, each
with "a captured cell's minted element annotation has no type".
