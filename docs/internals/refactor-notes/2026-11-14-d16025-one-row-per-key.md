# One union row per type key: the label index deleted (D16025), 2026-11-14

Lane D, the second of two steps. The first (#7955) deleted the armed-only type-key shadow.

## What changed

- `unTyKeyHasRow(ty)` (emit_union_tykey.vl) replaces `unNameAdoptTyKeyRow(name, ty)`. It answers
  whether the type's key already has a row, with no name, no binding, no declared-alias exclusion
  and no null-position test (`utkTyNullShape` / `utkRowNullShape` are deleted).
- These callers ask it:
  - emit_collect: `registerInlineUnionGo`, `registerInferredUnionTy`,
    `registerInferRetNominalUnion` and the array-literal element mint;
  - emit_union_atoms: `registerValueUnionNameTy`;
  - emit_mono: `monoRegisterPinUnion`.
- `monoPinMintedUnion` no longer returns early on a bound name. The registration it reaches gates
  on the key itself.
- Deleted:
  - `unRowBySid` (emit_state), together with its resets in `collectU` and `sidKeyedTablesReset`;
  - `unRowOfName` and `unNameBound` (emit_union_registry);
  - `unNameBindRow` and `unNameShareTyKeyRow` (emit_union_atoms);
  - `shareObjLitFieldUnionRows` and `annAdoptRegisteredName` (emit_collect).
- `unNamesPush` only appends to `unNames`.
