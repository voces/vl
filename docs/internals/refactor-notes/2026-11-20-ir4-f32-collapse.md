# List literals: the f32, f64 and i64 arms are one builder (2026-11-20, lane IR4)

This is step 4 of the f32 sequence, as IR-REV's (d) ruling put it. ir-design-2026-11.md §10
records the rule: an emitter whose operands are arbitrary expressions is collapsed before I8, not
deleted. Its decisions become the shared plan, its bytes the shared tails, and what remains is
the operand loop plus the tail call. Legacy stays the door's miss fallback.

## The collapse

`emitArrF32`, `emitArrF64` and `emitArrI64` were three copies of one builder:
- the hoisted `for` iterable (f64 only);
- past `NEW_FIXED_MAX`, one data segment or a chunked build;
- each element through `emitWidened` at the arm's width;
- the short tail `arrLitShortTail`.

They differed only in the element form (`ALD_*`), the backing and wrapper heap types, the
widening kind and the chunk name. They are now `emitArrWide(arrIx, elems, fnIx, w)`, with
`w: WideArm` (`"f32" | "f64" | "i64"`):
- `widePlanOf` holds the form and widening kind.
- `wideBackTy`, `wideWrapTy` and `wideChunkStart` are each one exhaustive `match` over the arm.
- The f32 and i64 arms now ask `arrLitHoistGlobal` too. It answers -1 for both, as before.

The IR side already read the shared decisions (`arrLitArmOf`, `arrLitShortWhy`,
`arrLitHoistGlobal`) and the shared short tail. So legacy and the IR now take one decision through
one tail at all three arms.

**Why each value match is its own function.** A value `match` over a string-literal union bound
to a local (`const back = match w { … }`) leaves its function uncovered (`rep ?`). So does a record
literal whose fields call functions inside a `match` arm (`object layout`). Either spelling took
`emitArrWide` or its plan out of the IR's coverage, and the self-compile's covered count fell by
two. A `return match` in a function of its own covers, so every helper here is one. The plain
witness, uncovered on master:

    type W = "f32" | "f64" | "i64"
    function f(w: W): i32 {
      const back = match w {
        "f32" => 1
        "f64" => 2
        "i64" => 3
      }
      return back
    }
    print(f("f32"))
    // VL_IR_SHADOW=1: `f` uncovered `rep ?`
