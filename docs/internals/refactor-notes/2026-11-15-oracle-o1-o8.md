# Oracle fixes O1–O8, from lane B's 50-seed triage (2026-11-15)

Lane B's sweep (`fuzz.sh --seeds 50 --count 200`) gave 51 new disagreements. B triaged them in
its triage note (#8144) and found 46 to be the oracle's own, in families
O1–O8. This note records what changed in `scripts/oracle/interp.ts` for each family.

| family | the oracle did | it now does | source |
| --- | --- | --- | --- |
| O1 | raised a TypeFault on any integer division of constants by zero | traps, as the compiled program does; the checker refuses a decimal tree's zero divisor itself | T1.2 |
| O2, O5, O8 | treated an `if` of constant arms as an exact constant | keeps it a `join` constant: it adopts its use's type (a destination, a peer, a return) but is no part of an exact tree | E9.1 does not list `if`; D16373's join adoption |
| O3 | read a radix constant at i32 beside a constant whose default is i64 | reads it at i64 there (`min(3000000000, 0xFFFFFFFF)` is `3000000000`) | T2.3 |
| O4 | computed `>>>` of a negative constant at i32 | uses the i64 destination's width (#8146) | D2709 |
| O6 | folded the subtrees of a float division by zero exactly | declines (`spec gap`); sent to the owner | owner question |
| O7 | widened an `if` join for a typed arm only against a literal arm | also against a constant-tree arm | T3.6 |

The re-run of the same 50-seed configuration also exposed these oracle gaps, now fixed:

- a block body's last expression did not have the function's return type as its context;
- a constant operand did not take its typed peer's type (D3043's operator-peer adoption);
- a radix tree as wide as i64 was wrapped at i32 before an integer cast;
- `~` dropped the `join` mark;
- `min`/`max`/`abs` had no static kind.

**Measured.** The same 50-seed run, 10,000 arithmetic programs on the D16375 branch's seed:

- before these fixes: 10 disagreements;
- after them: 5, all one class.

In that class, a radix constant in a join, or beside one, is read at i32 even at an i64
destination. Lane N matched it to D2617's fixture (`hex-width-through-value-if.vl`), and the owner's
spec question 2 decides it. The five cells, and lane N's three, are in `scripts/oracle/known.txt`
until that ruling; `interp.ts` does not model the class yet.

The distilled corpus (12,029 cells, 96.0% in the subset) and the 8-seed run show 0 new
disagreements. The smoke test passes 136 of 154 spec examples, as before.
