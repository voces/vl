# IR coverage: a staged root reads above the roots staged below it (2026-11-24, lane IR-N9, D17089)

`stageLead` (ir_lower.vl) writes the operands pending below a valued `if` before it opens, each
root left on the stack for its later reader. A root whose definition reads a stack value (a call
on an earlier `if`'s value) read it at the enclosing floor, where an earlier root still on the
stack sat lowest, so `liveTake` refused: `stack value read out of order`. While a root is staged
the floor now sits past the run of roots already on the stack from the floor up (`rootsFloor`),
then returns; those roots stay below, as legacy leaves them.

## Measured

- D17089's witness and `main` in tests/cases/unions/empty-list-is-store-back.vl: mismatch → matched.
- tests/cases shadow baseline: the two rows batch 10 took by ruling (`mismatch unlowered: stack
  value read out of order`, its `fail` twin) → 0 classes; claims fallbacks drop D17089's witness.
- Q58 sweep (`tests/cases/strings/two-union-list-lengths-at-every-position.vl`, 14 positions):
  base 6 mismatches, fix 0; 74 of 74 covered matched; `ifArm` is uncovered under both seeds by
  `expression if arm prelude unwalked`, a class this change does not touch.
