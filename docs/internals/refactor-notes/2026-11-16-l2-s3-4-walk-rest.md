# L2 S3.4: the remaining bound kinds join the body-order walk, 2026-11-16

This completes body order (`2026-11-16-l2-s3-plan.md`, option B), so that S3.6 can retire the
replay. It is identical.
- **What moves.** `BND_BIN`, `BND_PRINT`, `BND_NEST`, `BND_RET`, `BND_LET` and `BND_BM` each become
  a per-row rule (`binRule`, `printRule`, `nestRule`, `retRule`, `letRule`, `bmRule`), and their
  validators go. Each keeps its home step in `ruleKindOfStep`, so a caller's range and mask still
  choose it. `solveStep` is left with `SS_ARG` alone, whose rule is S3.4d's arrow rule (lane STORE).
- **Kind-specific details.**
  - The owner toggles stay per kind: `selfOwner` around BIN and LET.
  - `nestRule` keeps its vector precondition, and returns 1 at its first refusal to end the kind,
    as `isRule` does.
  - `retRule` reads the solve's `rNames`/`rTys`.
- **The one direct caller.** The direct return check in `check_calls.vl` (a call binding nothing,
  D14802) now runs through the walk as a solve of `SS_RET` alone.
