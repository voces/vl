# Known-failure snapshot for the rep-composition fuzz check (scripts/rep-fuzz-check.sh).
# Class-tagged `CLASS<TAB>@shape` — one line per (class, shape) that currently fails at the broad
# pinned seed set (see the SEEDS array in rep-fuzz-check.sh). Classes: INVALID-WASM (emitted bytes
# fail validation), TRAP (runtime trap), MISMATCH (silent wrong result), REJECT (loud parse/type/emit
# refusal). This is a COMMITTED known-issue list burned down over time; the CI invariant is NO
# REGRESSION — never a NEW or WORSE failure. A fix GRADUATES its line (remove it here + pin a
# tests/cases/ regression). When this list empties, the fuzzer is at true zero. Regenerate the deltas
# with scripts/rep-fuzz-check.sh (it prints exactly what to add/remove).
#
# SOUNDNESS IS NEVER BASELINEABLE: only REJECT lines may appear below. INVALID-WASM / TRAP /
# MISMATCH are miscompiles, not "known issues" — rep-fuzz-check.sh mechanically refuses to run
# if one shows up here. Fix the miscompile, or if it truly can't reach the buggy code path,
# make the compiler reject it loudly (REJECT) instead of baselining the unsound behavior.
#
# ── THE LAST LINE, AND WHY IT IS NOT A BUG TO BURN DOWN ───────────────────────────────────
# `p2r ((i32) => {f: boolean}[] | {w: i32}) | f64` — a closure-arm value union whose RESULT is
# itself a union of an ANONYMOUS-element ref-list and a struct. The generated program is
#
#     function makeIt(): ((i32) => {f: boolean}[] | {w: i32}) | f64 {
#       return (q0) => ([{f: true}])
#     }
#     function go() {
#       const v: ((i32) => {f: boolean}[] | {w: i32}) | f64 = makeIt()
#       const t0 = v
#       if t0 is (i32) => {f: boolean}[] | {w: i32} {
#         const t1 = t0(1)
#         if t1 is {f: boolean}[] { print(t1[0].f) } else { print("OTHER") }
#       } else { print("OTHER") }
#     }
#     go()
#
# THE MECHANISM. `refArmUnionRetName` declines an anonymous array element beside an OBJ
# sibling, so `synthRetAnnots` never pins the lambda; `(q0) => ([{f: true}])` self-infers the
# bare ref-list return (`>r<slot>;`) while every call site casts to the union box (`>u`). The
# arm therefore has no interned rep and the `is` floor refuses. The refusal is the ONLY thing
# standing between this program and a miscompile, measured three ways:
#   · seed the arm's reflist slot with an unrelated `{f: boolean}[] | {w: i32}` binding and the
#     `is` compiles — then TRAPS, `indirect call type mismatch` (lambda functype
#     `(structref,i32)->(ref $reflist)` vs the call's `call_indirect` to `->(ref $uBox)`);
#   · drop the inner `is` and the OUTER narrow silently answers FALSE — the closure boxes under
#     `cloArmTagOfTy` of its SELF-INFERRED type while `is` derives the tag from the DECLARED arm
#     (measured tags 12 vs 16), so a MISMATCH sits directly behind this REJECT;
#   · `t0 is () => {f: boolean}[]` — a type that is not a member of the union at all — answers
#     TRUE, which is the same tag disagreement seen from the other side.
# `tests/cases/closures/error-narrow-reflist-arm-of-closure-result-union.vl` is the corpus pin,
# and it records a fourth: enabling the shape interner element dedup turns this into a MISMATCH.
#
# WHY IT IS NOT WIDENED INTO THE `value-union closure RESULT is not yet representable` floor
# instead: that floor needs a resolvable PRODUCER, and a `makeIt()`-fed binding has none. The
# obvious widening — "no producer + a ref-array arm ⟹ reject" — is REFUTED BY A WITNESS rather
# than by trying it: `function use(g: () => {f: boolean}[] | {w: i32})` called as `use(mk)` has
# no producer inside `use` either, and it RUNS today (the value passed really does box). So
# `pk == ""` cannot be the discriminator. Lifting `refArmUnionRetName`'s `hasObjSibling` decline
# WAS tried (edited, rebuilt, measured): it does not fix this program, and it turns three
# construct-only neighbours that compile today into `array value does not match any array member
# of the union` rejects.
#
# THE BOUNDARY, all measured, all pinned by
# `tests/cases/closures/refarm-union-obj-sibling-result-representable.vl`: the same shape with a
# NAMED element type runs, the same union through a NAMED producer function runs, and the same
# union bound DIRECTLY runs. Only the anonymous-element arm reached through a closure RESULT is
# the hole, and closing it is the deferred value-union closure-result composition (#911's
# declared-twin gate) — a rep change, not a diagnostic one.
#
# GRADUATION CRITERION: the program above prints `true`. Until then this line stays, and the
# check's job is to notice if it ever gets WORSE than REJECT.
REJECT	p2r ((i32) => {f: boolean}[] | {w: i32}) | f64
